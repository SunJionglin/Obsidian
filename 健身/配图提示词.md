## 全局风格（每条都带上）

```
扁平矢量插画 + 信息图风格，米白色纸感背景，主色珊瑚橙 #F2724F 与墨绿 #1F4E45，
点缀奶油黄；圆角粗线条，微颗粒噪点，无渐变无 3D；
构图干净留白多，人物为圆头短肢的简笔小人（不画真实人脸）；
中文标注字体圆润，字号清晰可读；画面整体像一份精致的健身手账插图。
```

比例统一 4:3（横版），笔记里插在正文上方。

负面词：`照片感, 3D 渲染, 复杂背景, 写实肌肉男, 英文乱码, 文字错乱, 水印, logo`

## 饮食篇

**01｜封面：一碗白饭的仪式感**
俯视一人食托盘，中间一碗白米饭，四周摆鸡胸、西兰花、半颗牛油果、一杯牛奶，旁边一台小厨房秤和笔记本。暖色顶光。
标注：`吃得明白，才练得动`

**02｜热量到底从哪来**
一本打开的包装食品营养成分表，旁边三个小方块分别画米、肉、油，块上写 ×4 / ×4 / ×9，箭头汇进一个写着「千卡」的圆盘。角落一个换算小标签 1 大卡 ≈ 4.18 千焦。
标注：`热量 = 碳水×4 + 蛋白×4 + 脂肪×9`

**03｜别算热量，先定三个数**
体重秤上的简笔小人，头顶浮出三个色块球：橙球写「碳水」、绿球写「蛋白」、黄球写「脂肪」，每个球挂着一个小哑铃图标表示按每公斤体重算。
标注：`先定碳蛋脂，再调总热量`

**04｜经验配额，边吃边改**
一张手账表格，左侧是「起始配额」，右侧是「两周后」，中间一支笔在改数字；表格底部画一个向下的小箭头和 0.3~0.5 的小标签。
标注：`两周不掉秤，碳水降一点`

**05｜训练日怎么分碳水**
一个圆环分成四段：早餐、训前、训后、其他餐，训后那段最大并画闪电图标，其余依次变小。圆环旁边画一根血糖小曲线，午后有个小高峰。
标注：`碳水优先喂给训练`

**06｜休息日：摊平吃**
同一张圆环，四段等分，中间写「休息日」，旁边的小人躺在沙发上举着水杯，背景是日历上打叉的哑铃。
标注：`不练的日子，碳水均摊、总量降`

**07｜碳水 / 蛋白 / 脂肪 三栏食物图**
三列竖排卡片：第一列米饭、燕麦、红薯、香蕉；第二列鸡胸、鸡蛋、牛奶、虾；第三列橄榄油、坚果、牛油果、蛋黄。每列顶部一个对应色球。
标注：`照着买，不用背`

**08｜一餐长什么样**
一只分格餐盘：半盘蔬菜、四分之一主食、四分之一蛋白质，旁边一双筷子和一杯水。盘沿标注「一拳主食 / 一掌蛋白 / 两拳蔬菜」。
标注：`用手量就够了`

**09｜补剂：不是必需品**
桌上三样东西：一罐蛋白粉、一小袋肌酸、一瓶鱼油，每样下面一个勾选框，其中蛋白粉打勾、其余打问号。背景一个小人挠头。
标注：`先吃够饭，再谈补剂`

**10｜三个常见错误**
三格漫画：第一格小人只盯着一颗鸡蛋说「就吃它」；第二格小人对着计算器算到崩溃，饭菜凉了；第三格小人闭眼凭感觉夹菜，盘子里全是油。
标注：`食物决定论 / 热量决定论 / 凭感觉吃`

**11｜水、盐、纤维**
一只大水杯、一小勺盐、一盘粗粮蔬菜并排，各自带一个小进度条：水 1.5~1.7L、盐 ≤5g、纤维 25~30g。角落画一颗肾做提醒。
标注：`这些不起眼，但缺了会出事`

## 训练篇

**12｜封面：第一次进健身房**
简笔小人站在健身房门口，肩上一根空杠铃，身后是跑步机和哑铃架，地面有一道从门口延伸进去的脚印。
标注：`从空杆开始，也算开始`

**13｜肌肉为什么会长**
一块肌肉剖面，上面画几个向上的小箭头写「张力」，旁边一个写着「渐进超负荷」的螺旋楼梯，小人正扛着杠铃往上走。
标注：`一次比一次多一点，才叫训练`

**14｜五个动作模式**
五个圆形图标排成一圈：蹲（深蹲剪影）、髋铰链（硬拉剪影）、推（卧推剪影）、拉（划船剪影）、核心（平板支撑剪影），中间写「动作模式」。
标注：`动作千千万，模式就五种`

**15｜新手动作清单**
一张清单卡片，列 8~10 个动作名（深蹲、硬拉、卧推、划船、推举、下拉、箭步蹲、平板支撑），每行前面一个小方块，勾掉前三个。
标注：`先把这几个练熟，别贪多`

**16｜怎么排计划：全身 vs 上下肢 vs 推拉腿**
三张并列的小日历：第一张每周三格写「全身」，第二张分「上肢/下肢」，第三张分「推/拉/腿」，每张下面标注适合人群（新手 / 进阶 / 老手）。
标注：`一周练几次，决定怎么分`

**17｜一次训练的结构**
一条从左到右的时间轴四段：热身（动态拉伸小人）、主项（大重量杠铃）、辅助（哑铃）、收尾（拉伸 + 喝水），每段下方标注分钟数。
标注：`热身不是浪费时间`

**18｜组数、次数、休息**
三块仪表盘：组数指针停在 3~4，次数指针停在 8~12，休息指针停在 1~2 分钟；旁边画一个秒表。
标注：`增肌的甜蜜区`

**19｜加重量还是加次数**
一块跷跷板：左边是杠铃片，右边是记满次数的小本子，两端平衡。旁边一条阶梯线，从「8 次」爬到「12 次」再跳一级重量。
标注：`次数满了再加重`

**20｜动作质量三件事**
三格小图：第一格画缓慢下放的箭头写「离心 2 秒」；第二格画完整幅度的弧线写「全程」；第三格画呼吸箭头写「下吸上呼」。
标注：`重量可以轻，动作不能糊`

**21｜练完之后的恢复**
一张床、一个闹钟显示 8 小时、一碗饭、一个拉伸的小人，四样东西围成一圈，中间写「恢复也是训练」。
标注：`睡不够，练了也白练`

**22｜新手最容易犯的三个错**
三格漫画：第一格小人天天练同一块肌肉，胳膊上贴满创可贴；第二格小人盲目加重，杠铃压弯；第三格小人只练胸不练背，身体前倾成问号。
标注：`练得勤 ≠ 练得对`
