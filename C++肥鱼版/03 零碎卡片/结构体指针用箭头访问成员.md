## 结论

`p->x` 等价于 `(*p).x`；结构体数组名退化成指向首元素的指针。

## 语法 / 签名

`Student* p = &s; p->name;`

## 最小示例

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int score;
};

int main() {
    Student s{"小明", 90};
    Student* p = &s;

    cout << p->name << ' ' << p->score << '\n';
}
```

## 坑

1. 空指针用 `->` 直接崩。
2. `*p.x` 是 `*(p.x)`，优先级坑。
3. 结构体数组 `a[i].name`，指针 `p[i].name` 或 `(p+i)->name`。
