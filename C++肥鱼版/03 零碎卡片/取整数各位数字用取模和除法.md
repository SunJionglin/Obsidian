## 结论

个位 `n % 10`，去掉个位 `n /= 10`；这样从低位到高位取。

## 语法 / 签名

`while (n) { int d = n % 10; n /= 10; }`

## 最小示例

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 1234;
    while (n) {
        cout << n % 10 << ' ';   // 4 3 2 1
        n /= 10;
    }
}
```

## 坑

1. 负数取模还是负数，先转正。
2. `n = 0` 时循环不进，要特判。
3. 需要正序就用数组/栈存一下。
