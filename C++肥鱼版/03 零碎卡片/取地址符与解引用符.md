## 结论

`&变量` 取地址，`*指针` 解引用；`*` 在声明里是类型的一部分，在表达式里才是解引用。

## 语法 / 签名

`int* p = &a; *p = 10;`

## 最小示例

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1;
    int* p = &a;
    *p = 2;
    cout << a << '\n';   // 2
}
```

## 坑

1. `*` 有三种含义：乘法、指针声明、解引用。
2. 指针没初始化就解引用是未定义行为。
3. `&` 在表达式里是取地址，在声明里是引用符号，别混。
