## 结论

结构体成员可以是数组；结构体整体赋值时数组会一起拷贝。

## 语法 / 签名

`struct S { int a[5]; };`

## 最小示例

```cpp
#include <iostream>
using namespace std;

struct S {
    int a[3];
};

int main() {
    S x{{1, 2, 3}};
    S y = x;              // 数组一起拷贝
    y.a[0] = 9;
    cout << x.a[0] << ' ' << y.a[0] << '\n';   // 1 9
}
```

## 坑

1. 结构体里的数组长度固定，不能动态变长。
2. 大数组别放栈上的结构体里。
3. 结构体整体比较不能直接用 `==`（除非重载）。
