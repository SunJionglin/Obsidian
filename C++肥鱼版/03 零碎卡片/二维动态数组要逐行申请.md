## 结论

二维动态数组先申请指针数组，再逐行申请；释放也要逐行。

## 语法 / 签名

`int** g = new int*[n]; for (...) g[i] = new int[m];`

## 最小示例

```cpp
int n = 3, m = 4;
int** g = new int*[n];
for (int i = 0; i < n; ++i) g[i] = new int[m]();

// 使用 g[i][j] ...

for (int i = 0; i < n; ++i) delete[] g[i];
delete[] g;
```

## 坑

1. 只 `delete[] g` 会泄漏每一行。
2. 行列顺序别搞反。
3. 现代写法用 `vector<vector<int>>`。
