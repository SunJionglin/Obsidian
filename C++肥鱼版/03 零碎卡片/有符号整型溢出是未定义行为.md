## 结论

有符号溢出是未定义行为（可能回绕、可能被优化掉）；无符号按 `2^n` 回绕。

## 语法 / 签名

`INT_MAX + 1` 是 UB；大数用 `long long`。

## 最小示例

```cpp
#include <iostream>
#include <climits>
using namespace std;

int main() {
    cout << INT_MAX << '\n';           // 2147483647
    cout << (long long)INT_MAX + 1 << '\n';  // 2147483648
}
```

## 坑

1. 中间结果溢出：`(a * b) / 2` 先溢出。
2. 用 `1LL * a * b` 提升到 64 位。
3. 无符号回绕不是「安全」，是另一种坑。
