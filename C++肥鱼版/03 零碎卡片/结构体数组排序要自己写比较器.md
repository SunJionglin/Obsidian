## 结论

`sort` 不认识结构体，必须传比较器；比较器要满足严格弱序（相等返回 `false`）。

## 语法 / 签名

```cpp
sort(v.begin(), v.end(), [](const T& a, const T& b) {
    return a.key < b.key;
});
```

## 最小示例

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

struct Student {
    string name;
    int score;
};

int main() {
    vector<Student> v{{"小明", 90}, {"小红", 95}, {"小刚", 90}};

    sort(v.begin(), v.end(), [](const Student& a, const Student& b) {
        if (a.score != b.score) return a.score > b.score;  // 分数降序
        return a.name < b.name;                            // 同分按名字升序
    });

    for (auto& s : v) cout << s.name << ' ' << s.score << '\n';
}
```

## 坑

1. 比较器写 `<=` 会破坏严格弱序，`sort` 可能越界。
2. 多关键字排序要把所有关键字写全，否则同分顺序不稳定。
3. 结构体数组用 `sort(v, v + n, cmp)`，`vector` 用迭代器。
