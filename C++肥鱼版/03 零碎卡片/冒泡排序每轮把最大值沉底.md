## 结论

冒泡排序：相邻两两比较，每轮把当前最大值「沉」到末尾；加 `swapped` 标志可提前结束。

## 语法 / 签名

```cpp
for (i = 0; i < n - 1; ++i)
    for (j = 0; j < n - 1 - i; ++j)
        if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);
```

## 最小示例

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> a{5, 3, 8, 4, 2};
    int n = (int)a.size();

    for (int i = 0; i < n - 1; ++i) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; ++j) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;
    }

    for (int x : a) cout << x << ' ';   // 2 3 4 5 8
}
```

## 坑

1. 内层边界 `n - 1 - i`，少写 `- i` 会多比较已排好的部分。
2. 不加 `swapped`，已经有序也要跑满 `O(n²)`。
3. `n = 1e5` 别用冒泡，用 `sort`。
