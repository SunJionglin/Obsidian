## 结论

位运算直接操作二进制位，快；但优先级低，混用必须加括号。

## 语法 / 签名

| 运算 | 含义 | 例子 |
|---|---|---|
| `a << n` | 左移，乘 `2^n` | `5 << 1 = 10` |
| `a >> n` | 右移，除 `2^n` | `5 >> 1 = 2` |
| `a & b` | 按位与 | `5 & 3 = 1` |
| `a \| b` | 按位或 | `5 \| 3 = 7` |
| `a ^ b` | 按位异或 | `5 ^ 3 = 6` |
| `~a` | 按位取反 | `~5 = -6` |

## 最小示例

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    cout << (a & 1) << '\n';       // 1，判断奇偶
    cout << (a << 1) << '\n';      // 10
    cout << (a ^ a) << '\n';       // 0
    cout << (1LL << 40) << '\n';   // 1099511627776
}
```

## 坑

1. `a & 1 == 0` 等价于 `a & (1 == 0)`，要写 `(a & 1) == 0`。
2. `1 << 31` 对 `int` 是未定义/溢出，用 `1LL << 31`。
3. 左移负数位是未定义行为。
