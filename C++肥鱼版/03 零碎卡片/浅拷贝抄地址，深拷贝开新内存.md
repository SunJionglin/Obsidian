## 结论

浅拷贝只复制指针值，两个对象共用一块内存；深拷贝重新分配内存再复制内容。

## 语法 / 签名

```cpp
Person(const Person& other);   // 拷贝构造函数
```

## 最小示例

```cpp
#include <cstring>

class MyString {
public:
    MyString(const char* s) {
        p = new char[std::strlen(s) + 1];
        std::strcpy(p, s);
    }

    // 深拷贝：自己开新内存
    MyString(const MyString& o) {
        p = new char[std::strlen(o.p) + 1];
        std::strcpy(p, o.p);
    }

    ~MyString() { delete[] p; }

private:
    char* p;
};
```

## 坑

1. 不写拷贝构造，编译器生成浅拷贝，两个对象析构同一块内存 → 二次释放。
2. 深拷贝还要记得重载赋值运算符（三法则/五法则）。
3. 现代 C++ 优先用 `std::string` / `std::vector`，别自己管裸指针。
