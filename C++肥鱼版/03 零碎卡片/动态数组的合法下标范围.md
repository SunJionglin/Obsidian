## 结论

`new int[n]` 只有 `[0, n-1]` 合法；越界读写不报错，但已经是未定义行为。

## 语法 / 签名

`int* a = new int[n]; ... delete[] a;`

## 最小示例

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    int* a = new int[n]{1, 2, 3, 4, 5};

    for (int i = 0; i < n; ++i) cout << a[i] << ' ';
    delete[] a;
}
```

## 坑

1. 越界可能不崩，但会踩坏别的内存。
2. 数组释放必须 `delete[]`。
3. `n = 0` 时 `new int[0]` 合法但别解引用。
