## 结论

数组名在表达式里退化成首元素地址，可以当**随机访问迭代器**用；但它不是变量，不能赋值、不能 `++`。

## 语法 / 签名

```cpp
sort(a, a + n);          // a 是首地址，a+n 是尾后
int* p = a;              // 可以赋给指针
// a++;                  // 错误：数组名不是变量
```

## 最小示例

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a[5] = {5, 3, 1, 4, 2};

    sort(a, a + 5);

    for (int x : a) cout << x << ' ';   // 1 2 3 4 5
}
```

## 坑

1. `sizeof(a)` 是数组总字节，`sizeof(p)` 是指针大小，别混。
2. 数组名不能自增，`a++` 编译不过。
3. 传参后数组名变成指针，长度信息丢了。
