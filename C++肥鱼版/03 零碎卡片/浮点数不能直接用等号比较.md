## 结论

`0.1 + 0.2 == 0.3` 是 `false`；浮点比较一律用「差值小于 eps」。

## 语法 / 签名

```cpp
fabs(a - b) < 1e-9
```

## 最小示例

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a = 0.1 + 0.2;

    cout << (a == 0.3) << '\n';              // 0
    cout << (fabs(a - 0.3) < 1e-9) << '\n';  // 1
}
```

## 坑

1. `float` 只有约 7 位有效数字，`double` 约 15 位，别拿 `float` 算钱。
2. eps 不是越小越好：太小会把「本来相等」判成不等。
3. 金额计算用整数分，或用定点/`decimal` 方案，别用 `double`。
