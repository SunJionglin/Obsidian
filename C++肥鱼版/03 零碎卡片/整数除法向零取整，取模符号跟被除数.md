## 结论

C++ 整数除法**向零取整**，取模结果的符号跟**被除数**一致；浮点数不能做 `%`。

## 语法 / 签名

```cpp
a / b   // 两边都是整数时，结果截断小数
a % b   // 两边必须是整数
```

## 最小示例

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 7 / 2 << ' ' << -7 / 2 << '\n';    // 3 -3
    cout << 7 % 2 << ' ' << -7 % 2 << '\n';    // 1 -1
    cout << 7.0 / 2 << '\n';                   // 3.5
}
```

## 坑

1. `7 / 2` 是 `3`，要小数至少一边转 `double`。
2. `-7 / 2` 是 `-3`（向零），不是 `-4`——和 Python 的 `//` 不一样。
3. `5.0 % 2` 编译不过，浮点取模用 `fmod`。
