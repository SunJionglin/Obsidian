## 结论

`'A'` 是 `char`（1 字节）；`"A"` 是 `const char[2]`，末尾带 `'\0'`。

## 语法 / 签名

`char c = 'A'; const char* s = "A";`

## 最小示例

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << sizeof('A') << '\n';     // 1
    cout << sizeof("A") << '\n';     // 2
}
```

## 坑

1. `'AB'` 是多字符字面量，值由实现决定，别用。
2. `"A"` 不能赋给 `char`。
3. 字符串比较用 `strcmp` 或 `std::string`，别用 `==` 比指针。
