## 结论

`std::string` 的 `<` 就是逐字符字典序，直接 `sort` 即可。

## 语法 / 签名

`sort(v.begin(), v.end());`

## 最小示例

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    vector<string> v{"Bob", "alice", "Cindy"};
    sort(v.begin(), v.end());
    for (auto& s : v) cout << s << ' ';   // Bob Cindy alice
}
```

## 坑

1. 大写字母排在小写前面（ASCII）。
2. 中文按字节比较，不是拼音。
3. 要忽略大小写就自己写比较器。
