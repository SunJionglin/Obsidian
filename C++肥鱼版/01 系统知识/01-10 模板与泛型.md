## 0. 一句话

> [!tip] 一句话
> 模板是「类型的占位符」：写一遍，编译器替你生成 int 版、double 版、string 版。

## 1. 为什么需要它

交换 `int`、`double`、`string` 要写三个 `swap`；写个容器只能存 `int`。模板把这些重复劳动交给编译器。

## 2. 核心机制

### 2.1 函数模板

```cpp
template <typename T>
T myMax(T a, T b) { return a > b ? a : b; }
```

- `T` 是类型参数，调用时自动推导。
- 也可以显式指定：`myMax<double>(1, 2.5)`。

### 2.2 类模板

```cpp
template <typename T>
class Box {
public:
    void set(T v) { value = v; }
    T get() const { return value; }
private:
    T value{};
};
```

使用时必须写类型：`Box<int> b;`（C++17 起可 `Box b{1};` 推导）。

### 2.3 非类型参数

```cpp
template <typename T, int N>
class Array {
    T data[N];
};
```

`N` 必须是编译期常量。

### 2.4 特化

```cpp
template <>
class Box<bool> {
    // 针对 bool 的特殊实现
};
```

### 2.5 模板定义必须放头文件

编译器要在**使用处**看到完整定义才能实例化；放 `.cpp` 里通常链接失败。

    A["模板定义"] --> B["调用处实例化"]

## 3. 语法与用法

### 3.1 函数模板

```cpp
template <typename T>
void mySwap(T& a, T& b) {
    T t = a;
    a = b;
    b = t;
}
```

### 3.2 类模板成员函数类外定义

```cpp
template <typename T>
class Box {
public:
    void set(T v);
    T get() const;
private:
    T value{};
};

template <typename T>
void Box<T>::set(T v) { value = v; }

template <typename T>
T Box<T>::get() const { return value; }
```

## 4. 代码验证

### 4.1 函数模板 + 类模板

```cpp
#include <iostream>
#include <string>
using namespace std;

template <typename T>
void mySwap(T& a, T& b) {
    T t = a;
    a = b;
    b = t;
}

template <typename T>
class Box {
public:
    void set(T v) { value = v; }
    T get() const { return value; }
private:
    T value{};
};

int main() {
    int x = 1, y = 2;
    mySwap(x, y);
    cout << x << " " << y << '\n';   // 2 1

    Box<string> b;
    b.set("hello");
    cout << b.get() << '\n';         // hello
}
```

## 5. 易错点

> [!warning] 坑 1：模板定义放 `.cpp`
> 其他文件只看到声明，链接时报「undefined reference」。

> [!warning] 坑 2：推导冲突
> `myMax(1, 2.5)` 推导出 `T` 既像 int 又像 double，编译失败；显式写 `myMax<double>(1, 2.5)`。

> [!warning] 坑 3：类模板使用漏类型
> `Box b;` 在 C++17 前非法，必须 `Box<int> b;`。

> [!warning] 坑 4：非类型参数传变量
> `Array<int, n>` 里 `n` 必须是编译期常量，不能是运行时输入。

> [!warning] 坑 5：特化语法写错
> 全特化是 `template <> class Box<bool>`，少写 `<>` 会变成偏特化/重定义。

> [!warning] 坑 6：模板不能是虚函数
> 虚函数表在运行期确定，模板在编译期实例化，两者冲突（C++20 前）。

## 6. 与黑马的差异 / 补充

- **黑马提高编程阶段没有文本讲义**：模板部分只有压缩包，本笔记 `heima: null`，不假装引用。
- **补充 `auto` 与模板的区别**：`auto` 是编译期推导变量类型，模板是生成一组函数/类；两者都靠编译期。
- **补充 STL 就是模板的产物**：`vector<int>` 是类模板实例化。
- **补充 C++20 concepts**：给模板参数加约束，报错更可读（进阶再看）。

## 7. 自测

> [!question]- 函数模板和普通函数有什么区别？
> **答案**：模板只写一次，编译器按调用类型实例化出多个具体函数。

> [!question]- 为什么模板定义通常放头文件？
> **答案**：实例化发生在使用处，编译器需要看到完整定义。

> [!question]- `template <typename T, int N>` 里的 `N` 有什么要求？
> **答案**：必须是编译期常量。
