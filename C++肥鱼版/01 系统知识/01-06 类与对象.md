## 0. 一句话

> [!tip] 一句话
> 类是把「数据 + 操作」打包的模板，对象是它造出来的实例。

## 1. 为什么需要它

用结构体存学生信息，数据是有了，但「打印」「改分数」「算平均」这些操作只能散落在外面。类把数据和操作绑在一起，还能限制谁能改——这就是封装。

## 2. 核心机制

### 2.1 封装与访问权限

| 关键字 | 类内 | 类外 | 子类 |
|---|---|---|---|
| `public` | 可访问 | 可访问 | 可访问 |
| `protected` | 可访问 | 不可 | 可访问 |
| `private` | 可访问 | 不可 | 不可 |

`class` 默认 `private`，`struct` 默认 `public`——这是它俩唯一的区别。

### 2.2 构造与析构

- **构造函数**：对象创建时自动调用，函数名与类名相同，无返回值。
- **析构函数**：对象销毁时自动调用，`~类名()`，无参数。
- **初始化列表**：`Person(int a) : age(a) {}`，比函数体赋值更早、更高效。
- **拷贝构造**：`Person(const Person& other)`，用同类型对象初始化新对象时调用。

### 2.3 深浅拷贝

- **浅拷贝**：逐成员复制指针值，两个对象指向同一块内存 → 二次释放。
- **深拷贝**：重新 `new` 一块内存再复制内容。

### 2.4 this / static / const

- `this`：指向当前对象的指针，成员函数里隐含。
- `static` 成员：属于类，不属于某个对象；类内声明，类外定义。
- `const` 成员函数：`void show() const;`，承诺不改成员。

### 2.5 友元与运算符重载

- `friend`：允许外部函数/类访问私有成员。
- `operator+`：让对象支持 `+`；`operator<<` 常写成友元，方便输出。

> 继承与多态内容较多，单独放在 [[01-11 继承与多态]]（待建）。

## 3. 语法与用法

```cpp
class Person {
public:
    Person() : age(0) {}                 // 默认构造
    Person(int a) : age(a) {}            // 有参构造
    Person(const Person& o) : age(o.age) {}  // 拷贝构造
    ~Person() {}                         // 析构

    void show() const { cout << age; }   // const 成员函数
    static int count;                    // 静态成员声明

private:
    int age;
};

int Person::count = 0;                   // 静态成员定义
```

运算符重载：

```cpp
class Point {
public:
    Point(int x = 0, int y = 0) : x(x), y(y) {}
    Point operator+(const Point& o) const {
        return Point(x + o.x, y + o.y);
    }
    friend ostream& operator<<(ostream& os, const Point& p);

private:
    int x, y;
};

ostream& operator<<(ostream& os, const Point& p) {
    return os << "(" << p.x << "," << p.y << ")";
}
```

## 4. 代码验证

### 4.1 构造 / 拷贝 / 析构顺序

```cpp
#include <iostream>
using namespace std;

class Person {
public:
    Person() : age(0) { cout << "默认构造\n"; }
    Person(int a) : age(a) { cout << "有参构造\n"; }
    Person(const Person& o) : age(o.age) { cout << "拷贝构造\n"; }
    ~Person() { cout << "析构\n"; }

    void show() const { cout << "age=" << age << '\n'; }

private:
    int age;
};

int main() {
    Person p1(18);
    Person p2 = p1;
    p1.show();
    p2.show();
}
```

输出：

```text
有参构造
拷贝构造
age=18
age=18
析构
析构
```

### 4.2 静态成员计数

```cpp
#include <iostream>
using namespace std;

class Cat {
public:
    Cat() { ++count; }
    ~Cat() { --count; }
    static int count;

private:
    int age = 0;
};

int Cat::count = 0;

int main() {
    Cat a, b;
    cout << Cat::count << '\n';   // 2
}
```

## 5. 易错点

> [!warning] 坑 1：浅拷贝导致二次释放
> 类里有裸指针时，默认拷贝构造只复制指针值，两个对象析构同一块内存 → 崩。

> [!warning] 坑 2：静态成员只声明没定义
> 类内 `static int count;` 只是声明，类外必须 `int Cat::count = 0;`。

> [!warning] 坑 3：const 成员函数里改成员
> `void show() const { age = 1; }` 编译报错；要改就加 `mutable`（慎用）。

> [!warning] 坑 4：构造函数里用初始化列表 vs 赋值
> `const` 成员和引用成员**只能**在初始化列表里初始化。

> [!warning] 坑 5：析构顺序
> 后构造的先析构；成员按声明逆序析构。

> [!warning] 坑 6：空指针调成员函数
> `Cat* p = nullptr; p->show();` 只要不访问成员可能不崩，但这是未定义行为。

> [!warning] 坑 7：`class` 忘了写 `public:`
> 默认私有，构造函数都成私有的，对象根本创建不了。

## 6. 与黑马的差异 / 补充

- **`system("pause")`**：黑马示例常见，Windows 专用。
- **黑马用裸 `new/delete` 讲深拷贝**：现代 C++ 优先用 `std::string`、`std::vector`、智能指针，自动管理内存。
- **补充 `explicit`**：单参数构造函数加 `explicit`，防止隐式转换。
- **补充 `= default` / `= delete`**：显式要求/禁止编译器生成函数。
- **继承与多态**：黑马 4.6/4.7 内容很多，本鱼拆到 [[01-11 继承与多态]] 单独讲。

## 7. 自测

> [!question]- `class` 和 `struct` 的区别？
> **答案**：默认访问权限不同，`class` 默认 `private`，`struct` 默认 `public`。

> [!question]- 什么时候会调用拷贝构造函数？
> **答案**：用同类型对象初始化新对象、按值传参、按值返回（可能被优化）。

> [!question]- 静态成员属于类还是对象？
> **答案**：属于类，所有对象共享一份；通过 `类名::成员` 访问。
