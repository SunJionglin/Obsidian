## 0. 一句话

> [!tip] 一句话
> 程序一关数据就没，文件把数据从内存搬到磁盘。

## 1. 为什么需要它

通讯录、职工系统、游戏存档——不写文件，关掉程序就全没了。文件操作就是「持久化」的最简方案。

## 2. 核心机制

### 2.1 三个流类

| 类 | 用途 |
|---|---|
| `ofstream` | 只写 |
| `ifstream` | 只读 |
| `fstream` | 读写 |

都要 `#include <fstream>`。

### 2.2 打开方式

| 模式 | 含义 |
|---|---|
| `ios::in` | 读 |
| `ios::out` | 写（默认截断） |
| `ios::app` | 追加 |
| `ios::trunc` | 存在则清空 |
| `ios::binary` | 二进制 |
| `ios::ate` | 打开后定位到末尾 |

多个模式用 `|` 组合，如 `ios::out | ios::binary`。

### 2.3 文本 vs 二进制

- **文本**：按字符写，人能看懂，`<<` / `>>` / `getline`。
- **二进制**：按字节写，人看不懂，`write` / `read` + `reinterpret_cast`。

```mermaid
flowchart LR
    A["内存数据"] -->|"ofstream << / write"| B["磁盘文件"]
    B -->|"ifstream >> / read"| C["内存数据"]
```

## 3. 语法与用法

### 3.1 写文本

```cpp
ofstream ofs("test.txt", ios::out);
if (!ofs) { /* 打开失败 */ }
ofs << "hello" << '\n';
ofs.close();
```

### 3.2 读文本

```cpp
ifstream ifs("test.txt");
string line;
while (getline(ifs, line)) {
    cout << line << '\n';
}
```

### 3.3 二进制

```cpp
struct Student { char name[20]; int age; };

ofstream ofs("s.bin", ios::binary);
ofs.write(reinterpret_cast<const char*>(&s), sizeof(s));

ifstream ifs("s.bin", ios::binary);
ifs.read(reinterpret_cast<char*>(&s), sizeof(s));
```

## 4. 代码验证

### 4.1 文本写 + 读

```cpp
#include <fstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ofstream ofs("test.txt", ios::out);
    if (!ofs) { cerr << "open failed\n"; return 1; }
    ofs << "name: Tom\n" << "age: 18\n";
    ofs.close();

    ifstream ifs("test.txt");
    string line;
    while (getline(ifs, line)) cout << line << '\n';
    return 0;
}
```

### 4.2 二进制写结构体

```cpp
#include <fstream>
using namespace std;

struct Student {
    char name[20];
    int age;
};

int main() {
    Student s{"Tom", 18};

    ofstream ofs("s.bin", ios::binary);
    ofs.write(reinterpret_cast<const char*>(&s), sizeof(s));
    ofs.close();
}
```

## 5. 易错点

> [!warning] 坑 1：不检查打开是否成功
> 路径错、没权限都会失败；`if (!ofs)` 必须判。

> [!warning] 坑 2：默认 `ios::out` 会清空
> 想追加要显式 `ios::app`。

> [!warning] 坑 3：二进制直接写 `string`
> `string` 内部是指针，写进去的是地址；要写 `s.c_str()` 和长度。

> [!warning] 坑 4：`sizeof` 写结构体
> 结构体有内存对齐，跨平台/跨编译器可能不一致。

> [!warning] 坑 5：忘记 `close`
> 缓冲区可能没刷盘；用 RAII 或显式 `close()`。

> [!warning] 坑 6：相对路径
> 相对于**运行目录**，不是源文件目录。

## 6. 与黑马的差异 / 补充

- **`system("pause")`**：黑马示例常见，Windows 专用。
- **黑马用 `ios::out` 写文本**：现代 C++ 可以直接 `ofstream ofs("a.txt");`，默认就是 out。
- **补充 `<filesystem>`**：C++17 的 `std::filesystem` 做目录遍历、路径拼接比手写字符串安全。
- **补充 RAII**：流对象离开作用域会自动关闭，但还是建议显式 `close()` 并检查状态。

## 7. 自测

> [!question]- 文本读和二进制读分别用什么？
> **答案**：文本用 `>>` / `getline`；二进制用 `read` + `reinterpret_cast<char*>`。

> [!question]- 想往已有文件末尾追加，打开方式怎么写？
> **答案**：`ios::app`（可配合 `ios::out`）。

> [!question]- 为什么二进制不能直接写 `std::string`？
> **答案**：`string` 对象里存的是指向堆的指针，写进去的是地址不是内容。
