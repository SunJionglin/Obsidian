## 0. 一句话

> [!tip] 一句话
> 用哪个函数就查哪张表，别背；但 `#include` 漏了，编译器可不惯着你。

## 1. 怎么用这张表

1. 先看「头文件总表」找到要用的功能。
2. 再看「常用函数」确认函数名和参数。
3. 写代码时只 include 需要的头文件，别一把梭 `bits/stdc++.h`。

## 3. 常用函数速查

### 3.1 字符串

```cpp
string s = "hello";
s.size(); s.empty();
s.substr(1, 3);            // "ell"
s.find("ll");              // 2，找不到返回 string::npos
s.replace(0, 1, "H");
s.c_str();                 // 转 const char*
stoi("42"); to_string(42); // 字符串 ↔ 数字
```

### 3.2 算法

```cpp
sort(v.begin(), v.end());
reverse(v.begin(), v.end());
auto it = lower_bound(v.begin(), v.end(), x);   // 第一个 >= x
int mx = *max_element(v.begin(), v.end());
int c = count(v.begin(), v.end(), x);
```

### 3.3 格式化

```cpp
cout << fixed << setprecision(2) << 3.14159;   // 3.14
cout << setw(5) << 42;                          // 右对齐，宽度 5
```

## 4. 代码验证

### 4.1 常用头文件联合示例

```cpp
#include <iostream>
#include <iomanip>
#include <sstream>
#include <numeric>
#include <vector>
using namespace std;

int main() {
    cout << fixed << setprecision(2) << 3.14159 << '\n';   // 3.14

    stringstream ss("12 34");
    int a, b;
    ss >> a >> b;
    cout << a + b << '\n';                                 // 46

    vector<int> v = {1, 2, 3, 4};
    cout << accumulate(v.begin(), v.end(), 0) << '\n';     // 10
}
```

## 5. 易错点

> [!warning] 坑 1：`<cstring>` 和 `<string>` 搞混
> `strlen` 在 `<cstring>`，`std::string` 在 `<string>`；两者不是一回事。

> [!warning] 坑 2：`bits/stdc++.h` 不是标准
> 只有 GCC 有，MSVC/Clang 可能没有；正式代码按需 include。

> [!warning] 坑 3：头文件里写 `using namespace std;`
> 会污染所有包含它的文件，头文件里用 `std::` 限定。

> [!warning] 坑 4：漏 include 靠「间接包含」碰运气
> 换编译器/标准库就崩，用到的都显式 include。

> [!warning] 坑 5：`#include` 顺序
> 自己写的头文件放最后，标准库放最前，减少依赖冲突。

> [!warning] 坑 6：重复包含
> 头文件加 `#pragma once` 或 include guard。

## 6. 与黑马的差异 / 补充

- **黑马提高编程阶段没有文本讲义**：头文件部分以零碎卡片为主，本笔记是索引，`heima` 标 `null`。
- **补充 `stoi` / `to_string`**：比 `atoi` / `sprintf` 更安全。
- **补充 `string::npos`**：`find` 找不到时返回它，别拿 `-1` 直接比（类型是无符号）。
- **补充 `accumulate` 的初始值**：传 `0` 是 int，传 `0LL` 才是 long long，防溢出。

## 7. 自测

> [!question]- `strlen` 在哪个头文件？
> **答案**：`<cstring>`；`std::string` 在 `<string>`。

> [!question]- `find` 找不到返回什么？
> **答案**：`string::npos`，不是 `-1`。

> [!question]- 为什么头文件里不建议 `using namespace std;`？
> **答案**：会污染所有包含它的源文件，可能引发命名冲突。
