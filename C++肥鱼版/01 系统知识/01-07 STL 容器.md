## 0. 一句话

> [!tip] 一句话
> STL = 容器 + 迭代器 + 算法；把 `vector`、`map`、`sort` 用熟，能干掉 80% 的活。

## 1. 为什么需要它

手写动态数组要管扩容、手写哈希表要管冲突、手写排序要管边界——STL 全帮你做了，而且比你写得快、比你写得稳。

## 2. 核心机制

### 2.1 容器分类

| 类别 | 容器 | 特点 |
|---|---|---|
| 序列 | `vector` | 动态数组，随机访问 O(1) |
| 序列 | `deque` | 双端队列，头尾插入 O(1) |
| 序列 | `list` | 双向链表，插入删除 O(1)，不支持随机访问 |
| 序列 | `array` | 定长数组，栈上 |
| 序列 | `string` | 字符序列 |
| 有序关联 | `map` / `set` | 红黑树，有序，O(log n) |
| 无序关联 | `unordered_map` / `unordered_set` | 哈希，平均 O(1)，无序 |
| 适配器 | `stack` / `queue` / `priority_queue` | 限制操作的容器 |

### 2.2 迭代器

```cpp
for (auto it = v.begin(); it != v.end(); ++it) cout << *it;
for (int x : v) cout << x;          // 范围 for
```

- `begin()` 指向第一个，`end()` 指向「最后一个的下一个」。
- `vector` / `string` 支持 `it + n`，`list` / `map` 只支持 `++/--`。

### 2.3 算法

`<algorithm>` 里的 `sort`、`find`、`count`、`lower_bound`、`unique`、`reverse`、`max_element`；`<numeric>` 里的 `accumulate`。

```mermaid

```

## 3. 语法与用法

### 3.1 vector

```cpp
vector<int> v = {3, 1, 2};
v.push_back(4);
v.pop_back();
v.size(); v.empty(); v.clear();
v.front(); v.back(); v[0]; v.at(0);   // at 会做越界检查
sort(v.begin(), v.end());
```

### 3.2 map / unordered_map

```cpp
map<string, int> cnt;
cnt["apple"]++;              // key 不存在会插入 0 再 ++
cnt.insert({"banana", 2});
cnt.find("apple");           // 返回迭代器
cnt.count("apple");          // 0 或 1
for (auto& [k, val] : cnt) cout << k << val;
```

### 3.3 set / unordered_set

```cpp
set<int> s = {3, 1, 2, 3};   // {1,2,3}
s.insert(4);
s.erase(1);
s.count(2);                  // 1
```

## 4. 代码验证

### 4.1 vector 排序去重

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {3, 1, 2, 3, 2, 1};

    sort(v.begin(), v.end());
    v.erase(unique(v.begin(), v.end()), v.end());

    for (int x : v) cout << x << ' ';   // 1 2 3
}
```

### 4.2 map 词频统计

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> cnt;
    for (const string& w : {"a", "b", "a", "c", "a"})
        ++cnt[w];

    for (auto& [k, v] : cnt)
        cout << k << ":" << v << '\n';
}
```

## 5. 易错点

> [!warning] 坑 1：迭代器失效
> `vector` 扩容后所有迭代器失效；`erase` 会返回下一个有效迭代器，别 `it++` 后再用。

> [!warning] 坑 2：`v[i]` 不检查越界
> 越界是未定义行为；要检查用 `v.at(i)`，越界抛 `out_of_range`。

> [!warning] 坑 3：`map[]` 会插入
> `cnt["x"]` 即使只是读，也会插入一个默认值 0。只查不改用 `find`。

> [!warning] 坑 4：`unordered_*` 顺序不保证
> 遍历顺序和插入顺序无关，别依赖它。

> [!warning] 坑 5：`string` 和 `char*` 混用
> `s.c_str()` 转 C 字符串；`strlen` 要 `<cstring>`。

> [!warning] 坑 6：`size()` 返回无符号
> `for (int i = 0; i < v.size() - 1; ++i)` 在 `size() == 0` 时会溢出成巨大值。

> [!warning] 坑 7：`vector<bool>` 是特化
> 它不是真正的 `bool` 数组，取地址/引用会出问题；要位图用 `bitset`。

## 6. 与黑马的差异 / 补充

- **黑马提高编程阶段没有文本讲义**：只有压缩包和图片，所以本笔记的 `heima` 标 `null`，不假装引用。
- **补充 `emplace_back`**：比 `push_back` 少一次拷贝/移动，构造复杂对象时更快。
- **补充 `reserve`**：提前分配容量，避免反复扩容。
- **补充 `erase-remove` 惯用法**：`v.erase(remove(v.begin(), v.end(), x), v.end());`

## 7. 自测

> [!question]- `vector` 和 `list` 怎么选？
> **答案**：要随机访问/尾部增删用 `vector`；频繁中间插入删除用 `list`。

> [!question]- `map` 和 `unordered_map` 怎么选？
> **答案**：要有序遍历/范围查询用 `map`；只做键值查找、追求速度用 `unordered_map`。

> [!question]- `sort(v.begin(), v.end())` 后想稳定怎么办？
> **答案**：用 `stable_sort`。
