## 现象

`a[10]` 越界了，程序却照常运行，甚至能读到值。

## 最小复现

```cpp
int a[5] = {1,2,3,4,5};
cout << a[10] << '\n';   // 可能输出垃圾值
```

## 原因

越界访问是未定义行为，不保证崩溃；可能读到相邻内存，也可能踩坏别的变量。

## 结论

不崩不代表对，越界就是 bug。

## 预防

用 `vector::at` 做检查，或自己判 `0 <= i && i < n`。
