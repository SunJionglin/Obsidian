## 现象

`int f(); double f();` 编译报重定义。

## 最小复现

```cpp
int f();
double f();   // 错误
```

## 原因

调用时编译器只看函数名和实参，返回值不参与重载决议。

## 结论

重载必须靠参数类型/个数/顺序区分。

## 预防

参数确实一样就换个函数名。
