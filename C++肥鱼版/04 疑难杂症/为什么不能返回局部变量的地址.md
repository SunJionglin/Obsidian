## 现象

函数返回局部变量的指针，第一次能打印，第二次乱码。

## 最小复现

```cpp
int* bad() { int x = 10; return &x; }
int main() { int* p = bad(); cout << *p; }
```

## 原因

函数返回后栈帧销毁，局部变量所在内存随时被覆盖。

## 结论

返回栈地址是未定义行为，能编译不等于对。

## 预防

返回堆对象（`new`/智能指针），或直接返回值。
