## 现象

`for (size_t i = n-1; i >= 0; --i)` 停不下来。

## 最小复现

```cpp
for (size_t i = 3; i >= 0; --i) { }   // 死循环
```

## 原因

`size_t` 是无符号，`i >= 0` 永远为真；`0 - 1` 回绕成最大值。

## 结论

无符号数不能用来做「减到 -1 结束」的循环。

## 预防

用 `int` 倒序，或用反向迭代器。
