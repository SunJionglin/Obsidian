## 现象

两个对象析构时崩，报 double free。

## 最小复现

```cpp
class A { int* p; public: A(){p=new int(1);} ~A(){delete p;} };
A a; A b = a;   // 浅拷贝，两个 p 指向同一块
```

## 原因

默认拷贝构造只复制指针值，两个对象析构同一块内存。

## 结论

管理裸指针的类必须自己写拷贝构造/赋值（三法则）。

## 预防

优先用 `string`/`vector`/智能指针，别自己管裸指针。
