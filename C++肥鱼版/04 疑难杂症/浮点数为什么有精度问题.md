## 现象

`0.1 + 0.2` 不等于 `0.3`。

## 最小复现

```cpp
double x = 0.1 + 0.2;
cout << (x == 0.3) << '\n';   // 0
```

## 原因

二进制无法精确表示 0.1、0.2 这类十进制小数，只能近似存储。

## 结论

浮点比较用 `fabs(a-b) < 1e-9`，别用 `==`。

## 预防

金额用整数分或定点数；科学计算接受误差。
