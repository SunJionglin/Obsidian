## 现象

函数里 `sizeof(a)` 只有 8，拿不到数组长度。

## 最小复现

```cpp
void f(int a[]) { cout << sizeof(a) << '\n'; }  // 8
int main() { int a[10]; f(a); }
```

## 原因

数组作为函数参数时，类型会退化成 `int*`，长度信息丢失。

## 结论

传数组必须额外传长度，或改用 `std::array` / `vector` / 引用传数组。

## 预防

`void f(int (&a)[10])` 能保留长度；现代写法直接传 `vector`。
