## 现象

`a / 0` 或 `a % 0` 直接崩溃。

## 最小复现

```cpp
int a = 1, b = 0;
cout << a / b;   // 运行时错误
```

## 原因

整数除以零是未定义行为，取模本质也是除法，同样非法。

## 结论

除法/取模前必须判分母。

## 预防

`if (b != 0)`，或抛异常/返回错误码。
