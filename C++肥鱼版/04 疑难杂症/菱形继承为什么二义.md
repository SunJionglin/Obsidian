## 现象

`d.x` 编译报 ambiguous。

## 最小复现

```cpp
class A { public: int x; };
class B : public A {};
class C : public A {};
class D : public B, public C {};
D d; d.x;   // 二义
```

## 原因

`D` 里有两份 `A` 子对象。

## 结论

虚继承 `virtual public A` 只保留一份。

## 预防

菱形结构用虚继承，或直接组合代替多继承。
