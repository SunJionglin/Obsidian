## 现象

`sizeof(Student)` 比成员大小之和大。

## 最小复现

```cpp
struct S { char c; int i; };
cout << sizeof(S) << '\n';   // 8，不是 5
```

## 原因

CPU 按对齐边界访问更快，编译器会在成员之间插入填充字节。

## 结论

结构体大小不等于成员大小之和。

## 预防

调整成员顺序（大的在前）能减少填充；跨平台传输别直接写结构体。
