## 现象

`delete` 父类指针，子类析构没执行，资源泄漏。

## 最小复现

```cpp
Animal* p = new Dog();
delete p;   // 只调 ~Animal
```

## 原因

析构函数不是虚函数时，按静态类型调用。

## 结论

可能被继承的类，析构必须 `virtual`。

## 预防

基类写 `virtual ~Base() = default;`。
