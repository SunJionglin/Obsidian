## 现象

`int f(int a = 1, int b);` 编译不过。

## 最小复现

```cpp
int f(int a = 1, int b);   // 错误
int g(int a, int b = 2);   // 正确
```

## 原因

实参从左往右匹配，左边有默认值而右边没有，无法确定省略谁。

## 结论

默认值必须从最右边开始连续给。

## 预防

把带默认值的参数放后面。
