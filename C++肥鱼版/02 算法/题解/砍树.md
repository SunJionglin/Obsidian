| 一句话 | 求最高的砍树高度 H，使砍下的木材 ≥ M |

## 1. 题意与输入输出

有 `N` 棵树，高度 `h[i]`。选定一个高度 `H`，高于 `H` 的部分被砍下。求最大的 `H`，使总木材 ≥ `M`。

- 输入：
  ```text
  4 7
  20 15 10 17
  ```
- 输出：`15`
- 数据范围：`1 <= N <= 10^6`，`1 <= M <= 2*10^9`，`1 <= h[i] <= 4*10^8`
- 要求：`O(N log maxh)`

## 2. 思路

这是**二分答案**：答案 `H` 越大，砍下的木材越少，单调。

`check(H) = Σ max(0, h[i] - H) >= M`

- 成立：`ans = H`，试着砍更高。
- 不成立：降低 `H`。

上界取 `max(h)`，下界取 0。

## 3. 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long m;
    cin >> n >> m;

    vector<long long> h(n);
    long long maxh = 0;
    for (auto& x : h) {
        cin >> x;
        maxh = max(maxh, x);
    }

    long long l = 0, r = maxh, ans = 0;
    while (l <= r) {
        long long mid = l + (r - l) / 2;

        long long sum = 0;
        for (long long x : h) {
            if (x > mid) sum += x - mid;
        }

        if (sum >= m) {
            ans = mid;
            l = mid + 1;          // 试着砍更高
        } else {
            r = mid - 1;          // 砍太高了，降低
        }
    }

    cout << ans << '\n';
    return 0;
}
```

## 4. 复杂度

- 时间：`O(N log maxh)`，约 `10^6 * 29` 次判断。
- 空间：`O(N)` 存树高。

## 5. 边界与坑

> [!warning] 坑 1：`sum` 用 int
> 最坏 `10^6 * 4*10^8 = 4*10^14`，必须 `long long`。

> [!warning] 坑 2：`H = 0` 时也要算
> 下界从 0 开始，`ans` 初始 0；如果 M 很小，答案可能就是 0。

> [!warning] 坑 3：`m` 读成 int
> `M <= 2*10^9` 超过 `int` 上限，必须 `long long`。

> [!warning] 坑 4：`check` 写成 `>` 
> 题目要求「至少 M」，是 `>=`。

> [!warning] 坑 5：上界取 `1e9`
> 没必要，取 `max(h)` 就够，范围小一半。
