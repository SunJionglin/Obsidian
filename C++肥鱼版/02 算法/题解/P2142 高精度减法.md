## 1. 题意与输入输出

输入两个大整数 `a`、`b`，输出 `a - b`。

- 输入：`2 1`
- 输出：`1`
- 输入：`1 2`
- 输出：`-1`

## 2. 思路

先比较大小：

- `a >= b`：直接算 `a - b`。
- `a < b`：输出负号，再算 `b - a`。

减法逐位来，不够减就借位。

## 3. 代码

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

bool ge(string a, string b) {
    if (a.size() != b.size()) return a.size() > b.size();
    return a >= b;
}

string sub(string a, string b) {
    string res;
    int i = (int)a.size() - 1, j = (int)b.size() - 1, borrow = 0;

    while (i >= 0) {
        int x = a[i--] - '0' - borrow;
        int y = (j >= 0) ? b[j--] - '0' : 0;

        if (x < y) { x += 10; borrow = 1; }
        else borrow = 0;

        res.push_back(char('0' + x - y));
    }

    while (res.size() > 1 && res.back() == '0') res.pop_back();
    reverse(res.begin(), res.end());
    return res;
}

int main() {
    string a, b;
    cin >> a >> b;

    if (ge(a, b)) {
        cout << sub(a, b) << '\n';
    } else {
        cout << '-' << sub(b, a) << '\n';
    }
    return 0;
}
```

## 4. 复杂度

- 时间：`O(n)`。
- 空间：`O(n)`。

## 5. 边界与坑

> [!warning] 坑 1：没比较大小
> 直接 `sub(a, b)` 在 `a < b` 时会算出错误的正数。

> [!warning] 坑 2：借位顺序
> 先减 `borrow`，再判断是否 `< y`；顺序反了借位错。

> [!warning] 坑 3：结果前导零
> `100 - 99 = 1`，要删掉前导零；`0` 本身保留。

> [!warning] 坑 4：相等
> `a == b` 时返回 `"0"`，别输出 `"-0"`。
