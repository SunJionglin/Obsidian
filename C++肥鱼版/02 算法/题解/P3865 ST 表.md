## 1. 题意与输入输出

给长度 `n` 的数组和 `m` 次询问，每次问 `[l, r]` 的最大值。

- 输入：
  ```text
  8 8
  9 3 1 7 5 6 0 8
  1 6
  1 5
  2 7
  2 6
  1 8
  4 8
  3 7
  1 3
  ```
- 输出：每行一个最大值
- 数据范围：`1 <= n, m <= 10^5`

## 2. 思路

预处理 `st[k][i]`：从 `i` 开始、长度 `2^k` 的区间最大值。

- `st[0][i] = a[i]`
- `st[k][i] = max(st[k-1][i], st[k-1][i + 2^(k-1)])`

查询 `[l, r]`：

- `len = r - l + 1`，`k = floor(log2(len))`
- 答案 = `max(st[k][l], st[k][r - 2^k + 1])`

两段可以重叠，最大值不受影响。

## 3. 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<int> a(n);
    for (auto& x : a) cin >> x;

    vector<int> lg(n + 1, 0);
    for (int i = 2; i <= n; ++i) lg[i] = lg[i / 2] + 1;

    int K = lg[n] + 1;
    vector<vector<int>> st(K, vector<int>(n));
    st[0] = a;

    for (int k = 1; k < K; ++k)
        for (int i = 0; i + (1 << k) <= n; ++i)
            st[k][i] = max(st[k - 1][i], st[k - 1][i + (1 << (k - 1))]);

    while (m--) {
        int l, r;
        cin >> l >> r;
        --l;
        --r;
        int k = lg[r - l + 1];
        cout << max(st[k][l], st[k][r - (1 << k) + 1]) << '\n';
    }
    return 0;
}
```

## 4. 复杂度

- 预处理：`O(n log n)`。
- 单次查询：`O(1)`。
- 空间：`O(n log n)`。

## 5. 边界与坑

> [!warning] 坑 1：下标从 1 开始
> 题目输入是 1-indexed，代码里要 `--l; --r;`。

> [!warning] 坑 2：`K` 开小
> `K = lg[n] + 1`，`n = 1` 时也要至少 1 层。

> [!warning] 坑 3：查询两块写反
> 第二块起点是 `r - (1 << k) + 1`，不是 `r - (1 << k)`。

> [!warning] 坑 4：`1 << k` 溢出
> `k` 到 30 以上就危险，必要时 `1LL << k`。

> [!warning] 坑 5：ST 表不能修改
> 数组一变就得重建；要动态修改用线段树。
