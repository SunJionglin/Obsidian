## 1. 题意与输入输出

输入 `n` 个整数，按升序输出。

- 输入：
  ```text
  5
  4 2 4 5 1
  ```
- 输出：`1 2 4 4 5`
- 数据范围：`n <= 10^5`

## 2. 思路

直接用 `std::sort`，`O(n log n)`。

题目叫「排序」，但真正考的是「别手写冒泡」——`n = 1e5` 时 `O(n²)` 必 TLE。

## 3. 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> a(n);
    for (auto& x : a) cin >> x;

    sort(a.begin(), a.end());

    for (int i = 0; i < n; ++i) {
        cout << a[i] << (i + 1 == n ? '\n' : ' ');
    }
    return 0;
}
```

## 4. 复杂度

- 时间：`O(n log n)`。
- 空间：`O(n)`。

## 5. 边界与坑

> [!warning] 坑 1：手写冒泡
> `n = 1e5` 时冒泡 `1e10` 次，必超时。

> [!warning] 坑 2：输出格式
> 最后一个数后面不要多空格；用 `i + 1 == n ? '\n' : ' '`。

> [!warning] 坑 3：重复元素
> `sort` 不要求元素唯一，重复值照常排。

> [!warning] 坑 4：负数
> 默认比较器按数值排，负数没问题。
