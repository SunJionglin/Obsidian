## 三 · 生成规矩

1. **跟着阶段走**：现在是 P0/W2 段，就写 P0 待写那 3 篇；进入 P1 再写 P1 的力扣/洛谷。
2. **一批 ≤6 篇**：写多了质量掉。
3. **写完立刻回填三处**：本表 ✅、[[52-力扣题单]]/[[53-洛谷题单]] 的题解列、[[51-蓝桥题单]] 的题解列。
4. **卡住不跳**：想不出正解就先写「部分分档位 + 暴力代码」，标 🟡，下周补。
5. **格式**：按 `题解/` 里已有笔记的结构（一句话题意 → 解题逻辑 → 方法选择 → 关键点 → 代码 → 复杂度 → 易错点 → 一句话总结）。
