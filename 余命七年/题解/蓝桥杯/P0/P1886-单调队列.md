# P1886 【模板】单调队列 / 滑动窗口

> 长度 $n$ 的序列，窗口宽度 $k$，输出每个窗口的**最小值**和**最大值**。$n \le 10^6$，$k \le n$。

## 一 · 一句话题意

滑窗从左到右，每次输出窗口内最小值和最大值，分两行输出。

## 二 · 解题逻辑

**先想什么**　滑动窗口最值 → 每滑一次，左边出去一个、右边进来一个，求最值。

**朴素解法**　每个窗口扫一遍 $O(nk)$，1e6 × 1e6 必炸；用 `multiset` 是 $O(n\log n)$，能过但常数大。

**正解观察**　维护一个**双端队列**，存下标，保持「值单调递增」（求最小值时）：
- **队尾**：新元素进来，把队尾所有 ≥ 它的都弹掉——它们永远不可能再成为最小值（新元素更小、还更晚过期）。
- **队头**：检查是否过期（`q[head] <= i - k`），过期就弹。
- 队头就是当前窗口最小值。求最大值时把比较反过来。

**为什么 O(n)**：每个下标入队一次、出队最多一次。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 每窗口扫一遍 | $O(nk)$ | 必炸 |
| `multiset` / 堆 | $O(n\log n)$ | 能过、常数大，且要处理「删除过期元素」 |
| 线段树 / ST 表 | $O(n\log n)$ | 只是能过，不是考点 |
| 单调队列 | $O(n)$ | 标准解，也是后面「DP 优化」的基础 |

**选单调队列的理由**：它和单调栈是同一套思想的两个变体（栈管「下一个」，队列管「窗口」）；学会了，后面 `f[i] = min(f[j]) + c` 的单调队列优化就顺了。

## 四 · 关键点

1. **队列存下标**：要靠下标判断过期（`q[head] <= i - k`）。
2. **两个方向各跑一遍**：最小值弹「队尾 ≥ 新值」，最大值弹「队尾 ≤ 新值」。
3. **先弹队尾，再判队头**：顺序反了会误删还没过期的元素。
4. **输出从第 k 个开始**：前 $k-1$ 个还没形成完整窗口。
5. **数组模拟双端队列**：`int q[N]; int head = 0, tail = 0;`（`head` 指向队头元素，`tail` 指向下一个空位）。

## 五 · 实现逻辑

求最小值：遍历 $i$ → 弹队尾 → 压入 → 判队头过期 → $i \ge k$ 时输出队头。

**手推一遍**（`a = [1, 3, -1]`，`k = 2`，求最小）：

| i | a[i] | 弹队尾 | 队内下标 | 过期检查 | 输出 |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 | — | [1] | — | — |
| 2 | 3 | 无（1 < 3） | [1,2] | 1 > 2-2=0 有效 | 窗口 [1,3] → a[1]=1 |
| 3 | -1 | 弹 3、弹 1 | [3] | — | 窗口 [3,-1] → a[3]=-1 |

> [!warning]- 先自己写再展开 · C++（可提交）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> const int N = 1e6 + 10;
> int a[N], q[N];
>
> int main() {
>     int n, k; scanf("%d %d", &n, &k);
>     for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
>
>     // 最小值
>     int head = 0, tail = 0;
>     for (int i = 1; i <= n; i++) {
>         while (head < tail && a[q[tail - 1]] >= a[i]) tail--;   // 弹队尾
>         q[tail++] = i;
>         while (q[head] <= i - k) head++;                       // 弹过期队头
>         if (i >= k) printf("%d ", a[q[head]]);
>     }
>     puts("");
>
>     // 最大值（比较反过来）
>     head = tail = 0;
>     for (int i = 1; i <= n; i++) {
>         while (head < tail && a[q[tail - 1]] <= a[i]) tail--;
>         q[tail++] = i;
>         while (q[head] <= i - k) head++;
>         if (i >= k) printf("%d ", a[q[head]]);
>     }
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python（`deque` 版本）
> ```python
> import sys
> from collections import deque
> def main():
>     data = list(map(int, sys.stdin.buffer.read().split()))
>     n, k = data[0], data[1]
>     a = data[2:2 + n]
>
>     def slide(cmp):                       # cmp(a,b) 为 True 时弹队尾
>         dq, out = deque(), []
>         for i, x in enumerate(a):
>             while dq and cmp(a[dq[-1]], x): dq.pop()
>             dq.append(i)
>             while dq[0] <= i - k: dq.popleft()
>             if i >= k - 1: out.append(a[dq[0]])
>         return out
>
>     print(*slide(lambda u, v: u >= v))    # 最小值
>     print(*slide(lambda u, v: u <= v))    # 最大值
> main()
> ```

## 六 · 复杂度

时间：$O(n)$，两遍扫描，1e6 约 0.1s。
空间：$O(n)$（`a` 与 `q` 各 1e6 个 int，约 8MB）。

## 七 · 易错点

1. **忘删过期队头**：窗口外的值还在队头，输出的是旧最值——最经典的错。
2. **先判队头再弹队尾**：顺序反了，可能把还没过期的最小值弹掉。
3. **`>=` 与 `>` 的选择**：求最小值时弹 `>=`（保留最新的相等值，它对未来更有利）；写成 `>` 也能过，但要在过期判断上更小心。
4. **前 `k-1` 个不该输出**：`if (i >= k)`，不是 `i >= k-1`（1-based 时窗口在 $i=k$ 才满）。
5. **`std::deque` 在 1e6 上的常数**：C++ 用数组模拟更快；Python 只能 `deque`。
