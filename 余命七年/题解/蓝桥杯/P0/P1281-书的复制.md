# P1281 书的复制

> $m \le 500$ 本书、$k \le m$ 个人，第 $i$ 本页数 $a_i \le 10^4$。每个人必须抄**连续**的一段，求最短完成时间，并按「前面的人尽量少抄」输出分配方案。

## 一 · 一句话题意
把数组分成 $k$ 段连续区间，使**最大段和最小**，输出该值对应的段划分。

## 二 · 解题逻辑
**先想什么**　「最大值最小」是二分答案的标准信号。

**朴素解法**　枚举所有分段方案，$C(m,k)$ 爆炸。

**正解观察**　二分答案 $T$（完成时间），`check(T)` 用贪心从后往前（或前往后）验证「每段和 ≤ T 时能否用 ≤ k 段装下」。
输出方案：拿到最小的 $T$ 后，**从后往前**分段（让后面的人多抄），若剩下的人比剩下的书多，就每人一本——满足「前面的人尽量少抄」。

## 三 · 方法选择

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 枚举分段 | 指数 | 不可行 |
| **二分答案 + 贪心 check** | $O(m\log S)$ | 方案还原要多一步 |

## 四 · 关键点
1. **二分上界**：$\sum a_i$（一个人全抄），下界 $\max a_i$。
2. **check 贪心**：顺序累加，超 $T$ 就开新段，统计段数 ≤ k。
3. **方案从后往前还原**，保证前缀最小。
4. **每人至少一本**：剩下人数 == 剩余书数时，后面一人一本。
5. 输出每段起止编号，注意是 1-based 书号。

## 五 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int m, k, a[505];
> bool ok(long long T) {
>     long long cur = 0; int seg = 1;
>     for (int i = 1; i <= m; i++) {
>         if (a[i] > T) return false;
>         if (cur + a[i] <= T) cur += a[i];
>         else { seg++; cur = a[i]; }
>     }
>     return seg <= k;
> }
> int main() {
>     scanf("%d %d", &m, &k);
>     long long lo = 0, hi = 0;
>     for (int i = 1; i <= m; i++) { scanf("%d", &a[i]); hi += a[i]; lo = max(lo, (long long)a[i]); }
>     while (lo < hi) { long long mid = (lo + hi) >> 1; if (ok(mid)) hi = mid; else lo = mid + 1; }
>     // 从后往前还原
>     vector<pair<int,int>> segs;
>     long long cur = 0; int r = m;
>     for (int i = m; i >= 1; i--) {
>         if (cur + a[i] <= lo) cur += a[i];
>         else { segs.push_back({i + 1, r}); r = i; cur = a[i]; }
>     }
>     segs.push_back({1, r});
>     reverse(segs.begin(), segs.end());
>     // 前面的人尽量少：人数多于段数时拆开
>     int need = k - (int)segs.size();
>     for (auto &p : segs) {
>         int l = p.first, rr = p.second;
>         while (need > 0 && l < rr) { printf("%d %d\n", l, l); l++; need--; }
>         printf("%d %d\n", l, rr);
>     }
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     m, k = d[0], d[1]
>     a = [0] + d[2:2 + m]
>     def ok(T):
>         cur = 0; seg = 1
>         for i in range(1, m + 1):
>             if a[i] > T: return False
>             if cur + a[i] <= T: cur += a[i]
>             else: seg += 1; cur = a[i]
>         return seg <= k
>     lo, hi = max(a[1:]), sum(a[1:])
>     while lo < hi:
>         mid = (lo + hi) // 2
>         if ok(mid): hi = mid
>         else: lo = mid + 1
>     segs = []; cur = 0; r = m
>     for i in range(m, 0, -1):
>         if cur + a[i] <= lo: cur += a[i]
>         else: segs.append((i + 1, r)); r = i; cur = a[i]
>     segs.append((1, r)); segs.reverse()
>     need = k - len(segs)
>     for l, rr in segs:
>         while need > 0 and l < rr:
>             print(l, l); l += 1; need -= 1
>         print(l, rr)
> main()
> ```

## 六 · 复杂度
$O(m \log \sum a_i)$ ≈ 500 × 22，瞬时。

## 七 · 易错点
1. **check 里 `seg <= k` 而不是 `== k`**：允许空段。
2. **还原方向**：从后往前才能让前面少抄。
3. **输出方案忘了拆段**：人数没用满时前面的人必须每人至少一本。
4. **下界是 $\max a_i$**：比最大书页数小必然无解。

## 八 · 部分分档位

| 数据档 | 写法 | 得分 |
| --- | --- | --- |
| k = 1 | 输出 1..m | 20% |
| 只求最短时间 | 二分答案（不输出方案） | 部分 |
| 满数据 | 二分 + 还原 | 100% |

## 九 · 一句话总结
**「最大值最小」→ 二分答案；`check` 贪心分段；方案从后往前还原，前面的人尽量少抄。**
