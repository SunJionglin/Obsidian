# P1115 最大子段和

> $n \le 2\times10^5$，序列 $a_i$（可负）。求连续子段的最大和，允许选空段（答案 0）。

## 一 · 一句话题意
连续子数组最大和。

## 二 · 解题逻辑
**先想什么**　连续子段 → 要么接上前一段，要么自己开头。

**朴素解法**　枚举起终点前缀和差，$O(n^2)$，2e5 会炸。

**正解观察**　一维 DP：`f[i]` = 以 i 结尾的最大子段和
$$f[i] = \max(a[i],\ f[i-1] + a[i])$$
空间压成一变量 `cur`，答案取全程 max。等价视角：记录「到 i 为止的最小前缀和」，`ans = max(前缀[i] − 最小前缀)`。

## 三 · 方法选择

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 枚举起终点 | $O(n^2)$ | 4e10 必 TLE |
| **滚动 DP** | $O(n)$ | 无 |

## 四 · 关键点
1. **「接 or 不接」二选一**：`cur = max(a[i], cur + a[i])`。
2. **答案是全程 max**，不是最后的 `cur`。
3. **负数序列**：全负时答案 0（选空段），`ans` 初值 0。
4. `long long`：$n\times a_i$ 可到 2e9 以上。

## 五 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     int n; scanf("%d", &n);
>     long long cur = 0, ans = 0, x;
>     for (int i = 1; i <= n; i++) {
>         scanf("%lld", &x);
>         cur = max(x, cur + x);
>         ans = max(ans, cur);
>     }
>     printf("%lld\n", ans);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> d = list(map(int, sys.stdin.buffer.read().split()))
> n = d[0]
> cur = ans = 0
> for x in d[1:1 + n]:
>     cur = max(x, cur + x)
>     ans = max(ans, cur)
> print(ans)
> ```

## 六 · 复杂度
$O(n)$ 时间、$O(1)$ 空间。

## 七 · 易错点
1. **答案取最后的 `cur`**：最大子段可能在中途出现。
2. **`ans` 初值 0 还是 -INF**：本题允许空段所以 0；不允许空段（如「必须非空」版本）要用 `-INF` 并初始化 `ans = a[0]`。
3. **手写成 `cur = max(a[i], cur) + ...`**：转移公式写混。

## 八 · 部分分档位

| 数据档 | 写法 | 得分 |
| --- | --- | --- |
| n ≤ 500 | O(n²) 前缀和 | 40% |
| 满数据 | 滚动 DP | 100% |

## 九 · 一句话总结
**以 i 结尾的最大和 = max(自己, 接前一段)；全程取 max；负数序列答案 0。**
