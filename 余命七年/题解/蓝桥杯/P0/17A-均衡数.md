# 第十七届省赛 A 组 · 试题 A 均衡数

> 2026 省 A 的第 1 题，**结果填空（约 5 分）**：不交代码，只填一个整数。
> 定义：一个正整数写成二进制（无前导 0），若 1 的个数和 0 的个数**相同**，叫「均衡数」。
> ⚠️ 洛谷题面（P16224）里给的具体计数范围是本题的题眼，**答案数字随范围变化，这里只记方法 + 验算脚本**；做的时候把题面里的 N 代进脚本，先暴力验算一遍再手填。

## 一 · 一句话题意

统计满足「二进制中 0 与 1 数量相等」的整数个数（具体上界见原题面）。

## 二 · 解题逻辑

**先想什么**　「二进制里 0/1 各多少个」= 按位看 → 两类想法：① 直接枚举判；② 按长度分组用组合数算。

**朴素解法**　从 1 枚举到 N，每个数算一次 `popcount`，再比 `len(bin) - 2 - popcount`。$N$ 到 $10^7$ 大约 1 秒能跑完（C++）；到 $10^9$ 就得换法。

**正解观察**　长度 $2k$ 的二进制串一共 $2^{2k}$ 个，其中「1 有 $k$ 个」的有 $\binom{2k}{k}$ 个；但**首位必须是 1**（无前导 0），所以固定首位是 1 之后，剩下 $2k-1$ 位里要放 $k-1$ 个 1：
$$
\text{cnt}(2k) = \binom{2k-1}{k-1}
$$
长度必须是偶数（0 和 1 总数相等 → 偶数位），奇数长度一个都没有。上界 $N$ 不是 $2^{2k}-1$ 时，再按位「贴着上界」逐位累计。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 暴力枚举 + popcount | $O(N\log N)$ | $N>10^8$ 就慢；但**用于验算完全够** |
| 按长度组合数（全集） | $O(\log N)$ | 只能算「≤ 2^m − 1」的整段 |
| 组合数 + 按位贴合上界 | $O(\log^2 N)$ | 实现略绕，但一次算对 |

**选它（组合数 + 逐位）的原因**：省赛填空题的分是**答案对就给**，最快的路是「公式算一遍 + 暴力验算一遍」，两个结果对上就交。

## 四 · 关键点

1. **0 不算**：正整数、且「0」的二进制只有一位 1，不是均衡数——从 1 开始。
2. **长度必须偶数**：奇位数不可能 0/1 数量相等。
3. **无前导 0**：长度 $2k$ 的数，首位固定为 1，所以是 $\binom{2k-1}{k-1}$，不是 $\binom{2k}{k}$。
4. **贴合上界的逐位累计**：从高位往低扫，遇到 0 就跳过（这一位只能放 0），遇到 1 就先把「这一位放 0」的分支全部加上，再继续贴着走；扫完再把 $N$ 自己判一次。
5. **组合数要 `long long`**：$\binom{30}{15}$ 已经是 1.5e8，$\binom{40}{20}$ 超过 `int`。

## 五 · 实现逻辑

先写 20 行暴力当验算器 → 再写组合数版本算「≤ N 的个数」 → 两个数对上就交。

**手推一遍**（长度 4，即 2k=4, k=2）：

| 位 | 组合数计数 | 说明 |
| --- | --- | --- |
| 首位 | 必为 1 | 无前导 0 |
| 剩余 3 位选 1 个放「1」 | $\binom{3}{1}=3$ | 即 1001、1010、1100 |
| 合计 | 3 | 长度 4 的均衡数有 3 个 |

> [!warning]- 先自己写再展开 · 验算脚本（暴力，C++）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     long long N = 10000000;          // ← 换成题面里的上界
>     long long cnt = 0;
>     for (long long x = 1; x <= N; x++) {
>         int one = __builtin_popcountll(x);
>         int bits = 64 - __builtin_clzll(x);   // 二进制长度（无前导 0）
>         if (one * 2 == bits) cnt++;
>     }
>     printf("%lld\n", cnt);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · 正解（组合数 + 按位贴合上界，C++）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> long long C[64][64];
>
> long long count_upto(long long N) {      // 统计 [1, N] 的均衡数个数
>     if (N <= 0) return 0;
>     int L = 64 - __builtin_clzll((unsigned long long)N);   // N 的二进制长度
>     long long ans = 0;
>     // 整段：长度 2,4,...,L-1（若 L 为奇数则到 L-1）
>     for (int len = 2; len < L; len += 2) {
>         int k = len / 2;
>         ans += C[len - 1][k - 1];
>     }
>     // 贴合：长度 L（只有 L 偶数才有意义）
>     if (L % 2 == 0) {
>         int need = L / 2;                  // 总共需要 need 个 1
>         int ones = 0;
>         for (int i = L - 1; i >= 0; i--) { // 从高位到低位
>             int bit = (N >> i) & 1;
>             if (bit == 1) {
>                 // 这一位放 0，剩下的低位里还要放 need - ones 个 1
>                 int rem = i;              // 剩余可自由填的位数
>                 int must = need - ones;
>                 if (must >= 0 && must <= rem) ans += C[rem][must];
>                 ones++;                   // 贴着走：这一位放 1
>             }
>         }
>         if (ones == need) ans++;          // N 自己也是均衡数
>     }
>     return ans;
> }
>
> int main() {
>     for (int i = 0; i < 64; i++) { C[i][0] = 1; for (int j = 1; j <= i; j++) C[i][j] = C[i-1][j-1] + C[i-1][j]; }
>     long long N; scanf("%lld", &N);       // ← 换成题面里的上界
>     printf("%lld\n", count_upto(N));
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python（10 行暴力，最快验证）
> ```python
> N = 10**7                       # ← 换成题面里的上界
> print(sum(1 for x in range(1, N + 1) if bin(x).count('0') == bin(x).count('1')))
> ```

## 六 · 复杂度

暴力：$O(N\log N)$，$10^7$ 约 0.4s（C++）、Python 约 8s（改用正解或缩范围）。
正解：$O(\log^2 N)$，任何 $N$ 都是瞬间。

## 七 · 易错点

1. **把 0 算进去**：0 的二进制是 `0`，1 个 0、0 个 1，不均衡；但如果你从 0 遍历且用 `bin(0)='0b0'` 会切出 1 位，容易误判。
2. **前导 0 忘了**：用 `bin(x)` 切掉 `0b` 才是无前导 0 的表示，别用定宽 32 位去数 0。
3. **长度算错**：`len(bin(x))-2`；C++ 用 `64 - __builtin_clzll(x)`，`x=0` 时是未定义行为，所以要单独排除 0。
4. **组合数溢出**：`C[40][20]` 需要 `long long`；`C[62][31]` 会爆 `long long`，但本题范围用不到。
5. **填空题别交代码**：这类题只填整数，写了代码也不会被评；**但一定要用代码验算**，手算错一位就是 0 分。

## 八 · 部分分档位（蓝桥视角）

结果填空没有部分分：**对就是 5 分，错就是 0 分**。所以流程是「暴力跑一遍 → 正解算一遍 → 两个相等才交」。
如果只有 10 分钟：先写 10 行 Python 暴力，跑得动就直接信它。
