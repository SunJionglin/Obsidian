# P1090 合并果子

> $n$ 堆果子，每次合并两堆、代价 = 两堆之和，求合并成一堆的**最小总代价**。$n \le 10^4$，$a_i \le 2\times10^4$。

## 一 · 一句话题意

每次挑两堆合并，代价是它们重量和，总代价累加；求最小总代价。

## 二 · 解题逻辑

**先想什么**　每次合并的代价会**参与后面的合并**——所以越早合并的堆，被重复计算次数越多（哈夫曼树的深度）。

**朴素解法**　随便合并（比如按顺序两两并）：如果先并了两个大堆，它们会在后续每次都被算一遍，总代价爆炸。反例：`[1, 100, 100]`，先并 100+100 代价 200，再并 200+1 代价 201，总 401；正确顺序先并 1+100 = 101，再 101+100 = 201，总 302。

**正解观察**　每次合并**最小的两堆**——这就是哈夫曼树。用**小根堆**每次取两个最小，合并后放回去，$O(n\log n)$。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 按原顺序两两合并 | $O(n)$ | 结果不是最小，直接 WA |
| 每次排序后取前二 | $O(n^2\log n)$ | 1e4 勉强过，思路不干净 |
| 小根堆（优先队列） | $O(n\log n)$ | 标准答案 |
| 双队列（合并结果单调） | $O(n\log n)$ 或 $O(n)$ | 需要先排序 + 归并式取最小，进阶写法 |

**选堆的理由**：`priority_queue<int, vector<int>, greater<int>>` 三行搞定，是「贪心 + 动态取最值」的母题。

## 四 · 关键点

1. **小根堆**：`priority_queue<int, vector<int>, greater<int>>`；默认是大根，取出来是最大值就全错。
2. **`n == 1` 特判**：只有一堆时没有合并，答案是 0。
3. **答案用 `long long`**：$10^4$ 堆、每堆 2e4，最坏总代价约 $3\times10^9$，超 `int`。
4. **每次取两个**：循环 `n-1` 次，每次 `a + b` 累加再 push 回去。
5. **贪心为什么对**：交换论证——把「较小者」换到更早合并的位置，总代价不会变大（等价于哈夫曼树的证明）。

## 五 · 实现逻辑

全部入小根堆 → 循环 $n-1$ 次：弹出两个、累加代价、把和压回 → 输出总代价。

**手推一遍**（`[1, 2, 9]`）：

| 轮 | 取出的两堆 | 代价 | 总代价 | 堆内 |
| --- | --- | --- | --- | --- |
| 1 | 1, 2 | 3 | 3 | [3, 9] |
| 2 | 3, 9 | 12 | 15 | [12] |
| — | 结束 | — | **15** | — |

> [!warning]- 先自己写再展开 · C++（可提交）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
>
> int main() {
>     int n; scanf("%d", &n);
>     priority_queue<long long, vector<long long>, greater<long long>> pq;
>     for (int i = 0; i < n; i++) { long long x; scanf("%lld", &x); pq.push(x); }
>     long long ans = 0;
>     while (pq.size() > 1) {
>         long long a = pq.top(); pq.pop();
>         long long b = pq.top(); pq.pop();
>         ans += a + b;
>         pq.push(a + b);
>     }
>     printf("%lld\n", ans);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python（`heapq` 版本）
> ```python
> import sys, heapq
> def main():
>     data = list(map(int, sys.stdin.buffer.read().split()))
>     n, a = data[0], data[1:1 + data[0]]
>     heapq.heapify(a)
>     ans = 0
>     while len(a) > 1:
>         x = heapq.heappop(a); y = heapq.heappop(a)
>         ans += x + y
>         heapq.heappush(a, x + y)
>     print(ans)
> main()
> ```

## 六 · 复杂度

时间：$O(n\log n)$，1e4 规模瞬间。
空间：$O(n)$ 的堆。

## 七 · 易错点

1. **用了大根堆**：`priority_queue<int>` 默认大根，取出最大两个，答案偏大。
2. **答案 `int` 溢出**：最坏 $3\times10^9$，`int` 变负数。
3. **只取一个就 push**：`while` 条件写错会把单堆也「合并」一次。
4. **`n = 1`**：不特判也能过（`while` 不执行，输出 0），但要知道为什么。
5. **贪心没有证明**：面试会追问「为什么每次取最小的两个」——答哈夫曼树或交换论证。
