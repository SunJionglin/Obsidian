# P1182 数列分段 Section II

> 把 $n$ 个正整数分成 $m$ 段（连续、不重不漏），让**最大段和最小**。$n \le 10^5$，$m \le n$，$a_i \le 10^4$。

## 一 · 一句话题意

给定连续正整数序列与段数 $m$，求一种分法使「各段和的最大值」最小，输出这个最小值。

## 二 · 解题逻辑

**先想什么**　「让最大值最小」= 经典二分答案信号。二分的是**答案**（最大段和），不是位置。

**朴素解法**　枚举每种分法：$C(n-1, m-1)$ 种，组合爆炸。

**正解观察**　固定一个上限 $S$，问「能不能用 ≤ $m$ 段、每段和 ≤ $S$ 分完？」——从左往右**贪心**：能塞就塞，塞不下就开新段。段数 ≤ $m$ 说明 $S$ 够大。$S$ 越大越容易分 → **单调**，二分。

**边界**：下界 = $\max a_i$（单个数不能拆），上界 = $\sum a_i$（一段全包）。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 枚举分法 | 指数级 | 不可行 |
| DP（$f[i][j]$ 前 $i$ 个数分 $j$ 段） | $O(n^2m)$ | 1e5 必炸 |
| 二分答案 + 贪心 check | $O(n\log\sum a)$ | 需要想到「贪心判定」 |
| DP + 决策单调性优化 | $O(nm)$ 或 $O(n\log n)$ | 考场写不出 |

**选二分的理由**：判定函数只用一次线性扫描，代码 10 行，是这类题性价比最高的解。

## 四 · 关键点

1. **二分的是段和**，`l = max(a)`、`r = sum(a)`，别把 `l` 设成 0（不可能小于最大元素）。
2. **`check(S)` 是贪心**：`cur + a[i] > S` 就 `cnt++`、`cur = a[i]`；否则 `cur += a[i]`。返回 `cnt <= m`。
3. **段数从 1 开始数**：初始 `cnt = 1`，容易漏成 0 或多数一段。
4. **求最小值用下取整**：`mid = (l+r)/2` 配 `r = mid`；上取整配 `l = mid` 是求最大值，别混。
5. **`sum` 到 $10^9$**：$10^5 \times 10^4$，`int` 刚好卡线，用 `long long` 稳。

## 五 · 实现逻辑

先算 `max` 与 `sum` 定二分边界 → 每轮用贪心数段数 → 段数 ≤ m 就收右边界 → 输出 `l`。

**手推一遍**（`a = [4,2,4,5,1]`，`m = 3`）：

| 试的 S | 贪心分段 | 段数 | ≤3? | 动作 |
| --- | --- | --- | --- | --- |
| 6 | [4,2] [4] [5,1] | 3 | 是 | r=6 |
| 5 | [4] [2] [4] [5,1] | 4 | 否 | l=6 |
| 6 | 收敛 | — | — | 答案 6 |

> [!warning]- 先自己写再展开 · C++（可提交）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> const int N = 1e5 + 10;
> long long a[N], n, m;
>
> bool check(long long S) {
>     long long cnt = 1, cur = 0;
>     for (int i = 0; i < n; i++) {
>         if (cur + a[i] > S) { cnt++; cur = a[i]; }
>         else cur += a[i];
>         if (cnt > m) return false;
>     }
>     return true;
> }
>
> int main() {
>     scanf("%lld %lld", &n, &m);
>     long long l = 0, r = 0;
>     for (int i = 0; i < n; i++) { scanf("%lld", &a[i]); l = max(l, a[i]); r += a[i]; }
>     while (l < r) {
>         long long mid = (l + r) >> 1;
>         if (check(mid)) r = mid; else l = mid + 1;
>     }
>     printf("%lld\n", l);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python（对照用）
> ```python
> import sys
> def main():
>     data = list(map(int, sys.stdin.buffer.read().split()))
>     n, m = data[0], data[1]
>     a = data[2:2 + n]
>     lo, hi = max(a), sum(a)
>     while lo < hi:
>         mid = (lo + hi) // 2
>         cnt, cur = 1, 0
>         for x in a:
>             if cur + x > mid: cnt += 1; cur = x
>             else: cur += x
>         if cnt <= m: hi = mid
>         else: lo = mid + 1
>     print(lo)
> main()
> ```

## 六 · 复杂度

时间：$O(n\log\sum a)$，约 $10^5 \times 30$，C++ 几十毫秒。
空间：$O(n)$。

## 七 · 易错点

1. **下界设 0**：`check(0)` 永远false，但二分起点错会让轮数变多（不致命），真正致命的是**下界小于 max(a) 时无解判断**。
2. **`cnt` 初值写 0**：最后段数会多算 1，导致答案偏大。
3. **下取整/上取整混用**：求最小值用 `r = mid` + 下取整；写成 `l = mid` + 上取整也行，但两者不能交叉。
4. **`m > n`**：此时答案是 `max(a)`，程序要能处理（本题保证 $m \le n$）。
5. **求和用 `int`**：$10^5 \times 10^4 = 10^9$，刚好越过 `int` 安全区。

## 八 · 部分分档位（蓝桥视角）

| 数据档 | 写法 | 复杂度 | 预估得分 |
| --- | --- | --- | --- |
| $n \le 20$ | 枚举每个断点 | 指数 | 20% |
| $n \le 500$ | DP $O(n^2m)$ | 可过 | 40–50% |
| $n \le 10^5$ | 二分 + 贪心 | $O(n\log\sum a)$ | 100% |
