# P5788 【模板】单调栈

> 给 $n$ 个数，对每个 $i$ 输出**右边第一个比 $a_i$ 大的数的下标**，没有输出 0。$n \le 3\times10^6$。

## 一 · 一句话题意

求每个位置的「下一个更大元素」位置（1-based），不存在输出 0。

## 二 · 解题逻辑

**先想什么**　对每个 $i$ 往右找第一个更大的 → 暴力 $O(n^2)$，3e6 必炸。

**朴素解法**　双重循环，每个 $i$ 向右扫；最坏（全递减）是 $O(n^2)$ = 9e12。

**正解观察**　**倒着扫**，维护一个「从栈底到栈顶单调递减」的下标栈：
- 栈里装的是「还没找到更大值的候选」（都比我右边的小）。
- 对 $i$：把栈顶所有 $\le a_i$ 的弹掉（它们永远不可能是 $i$ 的答案，也轮不到前面的数），栈顶剩下的就是答案；然后把自己压栈。

**为什么是 O(n)**：每个下标**入栈一次、出栈一次**，总操作 ≤ 2n。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 双重循环 | $O(n^2)$ | 3e6 必炸 |
| 线段树 / ST 表二分 | $O(n\log n)$ | 能过但重，考场写慢 |
| 单调栈 | $O(n)$ | 需要想清楚「弹谁」 |

**选单调栈的理由**：这类「找左边/右边第一个更大/更小」的题，单调栈是唯一 O(n) 解，也是后面「柱状图最大矩形」「接雨水」的母题。

## 四 · 关键点

1. **栈里放下标，不放值**：要输出位置，且比较时用 `a[st[top]]`。
2. **倒着扫**：从 $n$ 到 1，这样「右边」的信息已经在栈里。
3. **弹的条件是 `<=`**：`a[st[top]] <= a[i]` 全弹掉——等于也不行，因为要找**严格更大**。
4. **栈用数组模拟**：$n=3\times10^6$，`std::stack` 会慢；`int st[N]; top` 更快。
5. **栈空 = 没有更大值**：输出 0。

## 五 · 实现逻辑

从 $n$ 到 1 → 弹掉栈顶 ≤ 当前值的 → 栈顶即答案（空则 0）→ 当前下标入栈。

**手推一遍**（`a = [5, 3, 4]`，倒着扫）：

| i | a[i] | 弹栈 | 栈（底→顶） | 答案 ans[i] |
| --- | --- | --- | --- | --- |
| 3 | 4 | 空 | [3] | 0 |
| 2 | 3 | a[3]=4 > 3，不弹 | [3, 2] | 3 |
| 1 | 5 | a[2]=3 ≤ 5 弹；a[3]=4 ≤ 5 弹 | [1] | 0 |

结果：`ans = [0, 3, 0]` —— 第 2 位的下一个更大是第 3 位，其余没有。

> [!warning]- 先自己写再展开 · C++（可提交，含快读）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> const int N = 3e6 + 10;
> int a[N], ans[N], st[N];
>
> inline int read() {
>     int x = 0; char c = getchar();
>     while (c < '0' || c > '9') c = getchar();
>     while (c >= '0' && c <= '9') { x = x * 10 + c - '0'; c = getchar(); }
>     return x;
> }
>
> int main() {
>     int n = read();
>     for (int i = 1; i <= n; i++) a[i] = read();
>     int top = 0;
>     for (int i = n; i >= 1; i--) {
>         while (top > 0 && a[st[top]] <= a[i]) top--;
>         ans[i] = top ? st[top] : 0;
>         st[++top] = i;
>     }
>     for (int i = 1; i <= n; i++) printf("%d ", ans[i]);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python（正着扫 + 弹栈，等价写法）
> ```python
> import sys
> def main():
>     data = list(map(int, sys.stdin.buffer.read().split()))
>     n, a = data[0], data[1:1 + data[0]]
>     ans = [0] * n
>     st = []
>     for i in range(n):                 # 正着扫：栈里是「等待答案」的下标
>         while st and a[st[-1]] < a[i]:
>             ans[st.pop()] = i + 1      # 1-based 下标
>         st.append(i)
>     sys.stdout.write(" ".join(map(str, ans)))
> main()
> ```

## 六 · 复杂度

时间：$O(n)$，每个下标进出栈各一次，3e6 约 0.1s。
空间：两个 `int` 数组，约 24MB。

## 七 · 易错点

1. **弹的条件写成 `<`**：找严格更大时 `a[st[top]] < a[i]` 会把「相等」留在栈里，导致答案错位。
2. **正着扫和倒着扫混用**：两种都对，但**正着扫时栈里存的是「还没被解决的下标」**，答案在弹栈那一刻填；倒着扫是「查完再压」。别把两套逻辑拼在一起。
3. **输出 0 还是 n+1**：题目要求没有时输出 0。
4. **`std::stack` 在 3e6 上的常数**：可能 TLE，用数组模拟。
5. **下标 0/1 起点**：C++ 版用 1-based（`st` 从 1 开始），Python 版用 0-based 再 +1，两边别混。
