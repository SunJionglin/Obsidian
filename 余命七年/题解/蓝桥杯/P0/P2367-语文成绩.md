# P2367 语文成绩

> $n$ 个分数，$p$ 次操作，每次给区间 $[l, r]$ 全部加 $c$，最后求**最低分**。$n,p \le 5\times10^6$。

## 一 · 一句话题意

区间加、最后一次全体查询（求最小值）。不是「边改边查」，是「全部改完再查一次」。

## 二 · 解题逻辑

**先想什么**　区间加 → 差分：$d_l += c,\ d_{r+1} -= c$，最后前缀和还原本值。$p$ 次操作变 $O(1)$ 一次。

**朴素解法**　每次操作循环 $[l,r]$ 加：$O(np)$ = 2.5e13，必超时。

**正解观察**　**只有最后查一次**，所以不需要线段树——线段树是给「边改边查」用的，这题用它是杀鸡用牛刀（常数还大）。差分 + 一趟前缀和，$O(n+p)$。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 暴力区间加 | $O(np)$ | 2.5e13，必炸 |
| 差分 | $O(n+p)$ | 只能离线（最后统一还原） |
| 线段树 / 树状数组 | $O((n+p)\log n)$ | 能过但常数大、代码长；这题不需要 |

**选差分的理由**：题目问的是**最终值**，天然离线；差分是这类「区间加、末尾查询」的最优解。

## 四 · 关键点

1. **差分数组要开 `n+2`**：`d[r+1] -= c` 在 $r = n$ 时越界。
2. **一遍前缀和还原**：`s[i] = s[i-1] + d[i]`，边还原边取 `min`。
3. **初值**：`d[1] = a[1]`、`d[i] = a[i] - a[i-1]`（也可以先把原数组差分成 $d$）。
4. **`n, p` 到 5e6**：输入必须快读（`scanf` 也慢，用 `fread` 或 `ios::sync_with_stdio(0)`）；`cin` 不解绑必 TLE。
5. **最小值可能为负**：题面数据保证正数，但代码别把初值设成 0 去比较。

## 五 · 实现逻辑

先读数组并构造差分 → 每次操作两点修改 → 最后前缀和还原、边还原边取 min。

**手推一遍**（`a = [1,2,3]`，操作「[1,2] 加 5」、「[2,3] 加 1」）：

| 步 | 动作 | d 数组 |
| --- | --- | --- |
| 初始 | 差分 | d = [1, 1, 1] |
| +5 到 [1,2] | d[1]+=5, d[3]-=5 | d = [6, 1, -4] |
| +1 到 [2,3] | d[2]+=1, d[4]-=1 | d = [6, 2, -4, -1] |
| 前缀和 | 6, 8, 4 | 原数组变 [6,8,4]，最小 4 |

> [!warning]- 先自己写再展开 · C++（可提交，含快读）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> const int N = 5e6 + 10;
> int a[N], d[N];
>
> inline int read() {
>     int x = 0, f = 1; char c = getchar();
>     while (c < '0' || c > '9') { if (c == '-') f = -1; c = getchar(); }
>     while (c >= '0' && c <= '9') { x = x * 10 + c - '0'; c = getchar(); }
>     return x * f;
> }
>
> int main() {
>     int n = read(), p = read();
>     for (int i = 1; i <= n; i++) { a[i] = read(); d[i] = a[i] - a[i - 1]; }
>     while (p--) {
>         int l = read(), r = read(), c = read();
>         d[l] += c; d[r + 1] -= c;        // r+1 可能等于 n+1，数组开 n+2
>     }
>     int cur = 0, mn = INT_MAX;
>     for (int i = 1; i <= n; i++) { cur += d[i]; mn = min(mn, cur); }
>     printf("%d\n", mn);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python（差分版本，注意速度）
> ```python
> import sys
> def main():
>     data = list(map(int, sys.stdin.buffer.read().split()))
>     n, p = data[0], data[1]
>     a = data[2:2 + n]

>     d[1] = a[0]
>     for i in range(1, n):
>         d[i + 1] = a[i] - a[i - 1]
>     idx = 2 + n
>     for _ in range(p):
>         l, r, c = data[idx], data[idx + 1], data[idx + 2]; idx += 3
>         d[l] += c; d[r + 1] -= c
>     cur, mn = 0, 10**18
>     for i in range(1, n + 1):
>         cur += d[i]
>         if cur < mn: mn = cur
>     print(mn)
> main()
> ```

## 六 · 复杂度

时间：$O(n+p)$，5e6 级别在 C++ 里约 0.2s。
空间：两个 `int` 数组 5e6 × 4B × 2 = 40MB（注意内存限制，能用一个数组就别开两个）。

## 七 · 易错点

1. **`r+1` 越界**：`d[r+1] -= c` 在 $r=n$ 时写下标 $n+1$，数组必须开 `n+2`。
2. **输入超时**：5e6 个数 + 5e6 次操作，`cin` 一定 TLE；用快读或 `sys.stdin.buffer.read()`。
3. **忘了 `d[1] = a[1]`**：直接从 0 开始差分，前缀和会错成「相对值」。
4. **用线段树/树状数组**：能过，但常数大、代码长，5e6 有 TLE 风险。
5. **内存超限**：`long long` 数组 5e6 是 40MB 一个，两个就 80MB；这题用 `int` 够（分数 ≤ 100，$p$ 次累加后仍 < 2^31）。
