# P2249 【深基13.例1】查找

> 单调不降序列里查 $q$ 个值，每个输出**第一次出现**的下标（1-based），找不到输出 $-1$。$n,q \le 10^6$。

## 一 · 一句话题意

$n$ 个单调不降的数，$q$ 次询问，每次给 $x$：输出最小的 $i$ 使 $a_i = x$；不存在输出 $-1$。

## 二 · 解题逻辑

**先想什么**　有序 + 多次查询 → 二分。但「找第一个等于」比「找一个等于」多一步：等于之后还要往左推。

**朴素解法**　`std::lower_bound` 找到第一个 $\ge x$ 的位置 $p$，再看 $a_p$ 是否 $== x$：是就输出 $p$，否则 $-1$。这就是标准解。

**优化观察**　手写二分的价值在于**边界**：`r = n` 作哨兵（下标 $[0, n)$），循环不变量是「答案在 $[l, r)$ 内」，全程不特判 `n-1`。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 线性扫描每次询问 | $O(nq)$ = 1e12 | 必超时 |
| `lower_bound` | $O(q\log n)$ | 能用，但考场手写更稳（有些环境模板库版本差异） |
| 手写二分左边界 | $O(q\log n)$ | 需要想清楚边界 |

**选它（手写左边界二分）的原因**：这题就是「左边界二分」的模板题；把 `[l, r)` + 哨兵这一套练熟，后面二分答案、离散化全部受益。

## 四 · 关键点

1. **左闭右开 + 哨兵**：`l = 0, r = n`，`while (l < r)`，`r = n` 表示「没有找到」。
2. **`mid = l + (r - l) / 2`**：避免 `l + r` 溢出（这里 n ≤ 1e6 不会，但养成习惯）。
3. **`a[mid] < x` 才右移**：`a[mid] >= x` 时答案可能在 `mid` 或左边，所以 `r = mid`（不是 `mid - 1`）。
4. **判断存不存在**：循环结束后 `l == n || a[l] != x` 就是不存在。
5. **1-based 输出**：答案下标加 1。

## 五 · 实现逻辑

先 `l=0, r=n` 二分缩到「第一个 ≥ x」→ 再判 `a[l] == x` → 输出 `l+1` 或 `-1`。

**手推一遍**（`a = [1,1,2,4,5]`，查 `x = 2`）：

| 轮 | l | r | mid | a[mid] 与 x | 动作 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 5 | 2 | 2 == 2 | r = 2（往左收） |
| 2 | 0 | 2 | 1 | 1 < 2 | l = 2 |
| 3 | 2 | 2 | — | 循环结束 | l=2 → 输出 3 |

> [!warning]- 先自己写再展开 · C++（可提交）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> const int N = 1e6 + 10;
> int a[N];
>
> int main() {
>     int n, q; 
>     scanf("%d %d", &n, &q);
>     for (int i = 0; i < n; i++) scanf("%d", &a[i]);
>     while (q--) {
>         int x; scanf("%d", &x);
>         int l = 0, r = n;                     // 答案在 [l, r)
>         while (l < r) {
>             int mid = l + (r - l) / 2;
>             if (a[mid] < x) l = mid + 1;
>             else            r = mid;          // a[mid] >= x，答案可能是 mid
>         }
>         if (l == n || a[l] != x) printf("-1 ");
>         else                     printf("%d ", l + 1);
>     }
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python（对照用）
> ```python
> import sys
> def main():
>     data = list(map(int, sys.stdin.buffer.read().split()))
>     n, q = data[0], data[1]
>     a = data[2:2 + n]
>     out = []
>     for x in data[2 + n: 2 + n + q]:
>         l, r = 0, n
>         while l < r:
>             mid = (l + r) // 2
>             if a[mid] < x: l = mid + 1
>             else:          r = mid
>         out.append(str(l + 1) if l < n and a[l] == x else "-1")
>     sys.stdout.write(" ".join(out))
> main()
> ```

## 六 · 复杂度

时间：$O((n + q)\log n)$，1e6 次查询 × 20 轮 ≈ 2e7 次比较，C++ 在 1s 内。
空间：$O(n)$ 存数组。

## 七 · 易错点

1. **写成 `r = mid - 1`**：那是在找「等于」的版本，会漏掉 `mid` 本身；找左边界必须 `r = mid`。
2. **`while (l <= r)` 版本混用**：用 `<=` 就必须配 `[l, r]` 闭区间和 `r = mid - 1`，两套不能混。
3. **不判 `l == n`**：全数组都比 `x` 小时 `l` 越界，直接 `a[n]` 读越界内存。
4. **忽略 `-1`**：题目要求输出 `-1` 而不是 `0`，格式错一分不给。
5. **`scanf` 慢读 1e6**：`cin` 不解绑会 TLE，这题正好当快读的练兵。
