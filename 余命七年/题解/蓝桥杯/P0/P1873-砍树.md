# P1873 砍树

> $n$ 棵树高 $a_i$，伐木机刀片高度 $H$：高于 $H$ 的部分被切下，求**最大的 $H$** 使总木材 $\ge M$。$n \le 10^6$，$a_i,M \le 2\times10^9$。

## 一 · 一句话题意

给定 $a_1..a_n$ 与 $M$，求最大的整数 $H$，使 $\sum \max(0, a_i - H) \ge M$。

## 二 · 解题逻辑

**先想什么**　「最大的 $H$」+「$H$ 越大木材越少」→ **单调性**，直接上二分答案。

**朴素解法**　从 $H=\max a_i$ 往下枚举，每次算一遍总和：$O(n \cdot \max a)$，2e9 × 1e6 完全不可能。

**正解观察**　把 $H$ 看成自变量：`f(H) = 能得到的木材`，它是**单调不增**的（$H$ 涨，砍下来的少）。于是「求最大的 $H$ 使 $f(H) \ge M$」= 二分。

**边界**：$H$ 的下界 $0$（总能砍到），上界 $\max a_i$（超过最高树就砍不到东西）。答案取「闭区间最后一个满足」的写法：`mid = (l+r+1)/2`，满足就 `l = mid`。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 枚举 $H$ | $O(n\max a)$ | 2e15 次运算，必超时 |
| 二分答案 | $O(n\log \max a)$ | 需要证明单调性（本题显然） |
| 排序 + 前缀和 + 解方程 | $O(n\log n)$ | 更快但难写，考场不值 |

**选二分的理由**：`check` 只有 5 行、单调性显然、常数小；省赛里这类「最大/最小 + 单调」的题一眼二分，能省 20 分钟。

## 四 · 关键点

1. **`check(H)` 必须用 `long long`**：$n \cdot a_i = 1e6 \times 2e9 = 2e15$，`int` 直接溢出。
2. **提前 return**：累加超过 $M$ 就 `return true`，避免大数相加再溢出。
3. **`mid = (l + r + 1) >> 1`**：求**最大值**时用上取整，配 `l = mid`，否则死循环。
4. **`r` 取 `max a_i`**：取 2e9 也行，但会多 30 轮无意义二分；取 `*max_element` 更稳。
5. **`H` 可以为 0**：如果 $M$ 很小，答案可能就是 0，别把下界设成 1。

## 五 · 实现逻辑

先读入、取 `mx` → 二分 `[0, mx]` → `check` 里贪心累加 → 输出 `l`。

**手推一遍**（`a = [20,15,10]`，`M = 7`）：

| H | 砍下 | 累加 | ≥ 7? | 动作 |
| --- | --- | --- | --- | --- |
| mid=10 | 10+5+0 | 15 | 是 | l=10 |
| mid=15 | 5+0+0 | 5 | 否 | r=14 |
| mid=12 | 8+3+0 | 11 | 是 | l=12 |
| … | … | … | … | 收敛到 H=13 |

验证：$H=13$ → $7+2+0=9 \ge 7$；$H=14$ → $6+1+0=7 \ge 7$；$H=15$ → $5 < 7$。所以答案 14。

> [!warning]- 先自己写再展开 · C++（可提交）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> const int N = 1e6 + 10;
> long long a[N], n, M;
>
> bool check(long long H) {
>     long long sum = 0;
>     for (int i = 0; i < n; i++) {
>         if (a[i] > H) {
>             sum += a[i] - H;
>             if (sum >= M) return true;   // 提前退出，防溢出
>         }
>     }
>     return false;
> }
>
> int main() {
>     scanf("%lld %lld", &n, &M);
>     long long mx = 0;
>     for (int i = 0; i < n; i++) { scanf("%lld", &a[i]); mx = max(mx, a[i]); }
>     long long l = 0, r = mx;
>     while (l < r) {
>         long long mid = (l + r + 1) >> 1;
>         if (check(mid)) l = mid; else r = mid - 1;
>     }
>     printf("%lld\n", l);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python（对照用）
> ```python
> import sys
> def main():
>     data = list(map(int, sys.stdin.buffer.read().split()))
>     n, m = data[0], data[1]
>     a = data[2:2 + n]
>     lo, hi = 0, max(a)
>     while lo < hi:
>         mid = (lo + hi + 1) // 2
>         if sum(x - mid for x in a if x > mid) >= m: lo = mid
>         else: hi = mid - 1
>     print(lo)
> main()
> ```

## 六 · 复杂度

时间：$O(n\log \max a)$ ≈ $10^6 \times 31$ 次加法，C++ 0.1s 内。
空间：$O(n)$。

## 七 · 易错点

1. **`int` 溢出**：$n \times a_i$ 到 $2\times10^{15}$，`int` 直接变负数，二分跑向错误方向。
2. **`check` 里不提前 return**：虽然 `long long` 能装下 2e15，但连加 1e6 次大数会变慢；提前退出更稳。
3. **上取整写错**：`mid = (l+r)/2` 配 `l = mid` 在 `r = l+1` 时死循环。
4. **下界设成 1**：$M$ 很小时正确答案是 0。
5. **读入格式**：这题第一行是 `n M`，第二行 $n$ 个数；用 `scanf("%lld")` 别用 `%d`。
