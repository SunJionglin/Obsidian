# P1106 删数问题

> $n \le 250$ 位正整数，删掉 $k$ 位（$k < n$），使剩下的数**最小**，输出去掉前导零的结果。

## 一 · 一句话题意
从高到低删 k 个数字，让剩余数字拼出的数最小。

## 二 · 解题逻辑
**先想什么**　删谁影响最大？**高位**。所以从高位往低位看。

**朴素解法**　枚举删哪 k 位，$C(n,k)$ 爆炸。

**正解观察**　贪心：从左往右找**第一个「下降点」**（前一位 > 后一位），删掉前一位——因为删掉大的高位，后面小的补上来，数变小。重复 k 次。用字符串模拟：每轮扫描删下降点，或一次性用栈（保持单调不减）删满 k 个。

## 三 · 方法选择

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 每轮扫描删 | $O(kn)$ | n=250 足够 |
| **栈维护单调不减** | $O(n)$ | 更优但要多想一步 |

## 四 · 关键点
1. **删高位大的**：`178543` 删第一个下降点 `8` → `17543`（删 8 而不是 7）。
2. **k 次删完为止**，若序列已单调不减还没删够，从末尾删。
3. **前导零去掉**：删完从第一个非零位输出；全零输出 `0`。
4. 用字符串操作，别转 int（250 位会溢出）。

## 五 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     string s; int k; cin >> s >> k;
>     while (k--) {
>         int i = 0;
>         while (i + 1 < s.size() && s[i] <= s[i + 1]) i++;   // 找下降点
>         s.erase(s.begin() + i);                              // 删 s[i]
>     }
>     int p = 0;
>     while (p + 1 < s.size() && s[p] == '0') p++;             // 去前导零，保留至少一位
>     cout << s.substr(p) << endl;
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> s, k = sys.stdin.read().split()
> s = list(s); k = int(k)
> for _ in range(k):
>     i = 0
>     while i + 1 < len(s) and s[i] <= s[i + 1]: i += 1
>     s.pop(i)
> p = 0
> while p + 1 < len(s) and s[p] == '0': p += 1
> print("".join(s[p:]))
> ```

## 六 · 复杂度
$O(kn)$，250×250 瞬时；栈版 $O(n)$。

## 七 · 易错点
1. **删「第一个下降点的前一位」**，不是删最大的数字（`178543` 删 8 不删 9——例子换 `954321` 这种才删 9）。
2. **前导零**：不处理会输出 `007` 这种。
3. **全删成零**：输出 `0` 而不是空串。
4. **删不够 k 时从末尾删**：`12345` 删 2 位 → `123`。

## 八 · 部分分档位

| 数据档 | 写法 | 得分 |
| --- | --- | --- |
| n ≤ 10 | 枚举子集 | 30% |
| 满数据 | 贪心删下降点 | 100% |

## 九 · 一句话总结
**高位优先：从左往右删第一个下降点的前一位，删满 k 位，再去前导零。**
