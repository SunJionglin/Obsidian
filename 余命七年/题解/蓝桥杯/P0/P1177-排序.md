# P1177 【模板】排序

> 给 $n$ 个数，升序输出。$n \le 10^5$。**考点不是「会不会 sort」，是「知道 sort 为什么不会退化」**。

## 一 · 一句话题意

读 $n$（≤1e5）个整数，按升序输出，一个一行。

## 二 · 解题逻辑

**先想什么**　`std::sort` 一行就完事——那这题就没意义了。这题真正在问：手写快排怎么不退化。

**朴素解法**　取第一个元素当 pivot 的快排，遇到**已经有序**或**全相同**的数据会退化成 $O(n^2)$：每次只切掉一个元素，递归 $n$ 层。P1177 的测试点里专门有这种构造（有序数组、全相等数组）。

**优化观察**　快排的复杂度取决于「切分是否均匀」，跟数据顺序无关的办法只有一个：**随机化**，或者**三数取中**。另外小区间（长度 ≤ 16）改用插入排序，减少递归开销。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| `std::sort` | $O(n\log n)$ | 考场能用，但学不到东西；且它是内省排序，无法解释「为什么快」 |
| 手写快排（固定 pivot） | 最坏 $O(n^2)$ | 有序/全相同数据直接 TLE |
| 手写快排 + 随机 pivot | 期望 $O(n\log n)$ | 实现细节多，但有理论保证 |
| 归并排序 | 稳定 $O(n\log n)$ | 多一倍空间；常数比快排大 |

**选它（随机化快排 + 小区间插排）的原因**：它是「学会快排为什么快」的最短路径，而且考场直接 `sort` 也不会被卡——两条路都要会，面试问的是前者。

## 四 · 关键点

1. **pivot 随机化**：`swap(a[l], a[l + rnd() % (r - l + 1)])`，把随机元素换到左端再取。
2. **三路切分处理重复**：`< pivot`、`== pivot`、`> pivot` 三段，全相同数据一趟就切完，退化成 $O(n)$。
3. **小区间插排**：长度 ≤ 16 时插入排序更快，因为少了函数调用和递归开销。
4. **边界用左闭右开**：`[l, r)` 比 `[l, r]` 少一类 off-by-one。

## 五 · 实现逻辑

先随机换 pivot → 再三路切分 → 最后对左右两段递归（小区间退插排）。

**手推一遍**（`a = [3,1,3,2]`，pivot 取 3）：

| 步骤 | 处理元素 | 归属段 | 三路状态 |
| --- | --- | --- | --- |
| 1 | 3 | `==` | lt=[], eq=[3] |
| 2 | 1 | `<` | lt=[1], eq=[3] |
| 3 | 3 | `==` | lt=[1], eq=[3,3] |
| 4 | 2 | `<` | lt=[1,2], eq=[3,3] |
| 5 | — | 左段 [1,2]、右段 [] 都已有序或为空 | 合并 → [1,2,3,3] |

> [!warning]- 先自己写再展开 · C++（三路快排，可提交）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int a[100010];
>
> void quick_sort(int l, int r) {          // [l, r)
>     if (r - l <= 16) {                   // 小区间插入排序
>         for (int i = l + 1; i < r; i++) {
>             int x = a[i], j = i - 1;
>             while (j >= l && a[j] > x) { a[j + 1] = a[j]; j--; }
>             a[j + 1] = x;
>         }
>         return;
>     }
>     swap(a[l], a[l + rand() % (r - l)]); // 随机 pivot
>     int p = a[l], lt = l, i = l, gt = r;
>     while (i < gt) {
>         if (a[i] < p)      swap(a[lt++], a[i++]);
>         else if (a[i] > p) swap(a[i], a[--gt]);
>         else               i++;
>     }
>     quick_sort(l, lt);
>     quick_sort(gt, r);
> }
>
> int main() {
>     srand(time(0));
>     int n; scanf("%d", &n);
>     for (int i = 0; i < n; i++) scanf("%d", &a[i]);
>     quick_sort(0, n);
>     for (int i = 0; i < n; i++) printf("%d ", a[i]);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python（考场交 C++，这版只作对照）
> ```python
> import sys, random
>
> def quick_sort(a, l, r):
>     if r - l <= 16:
>         for i in range(l + 1, r):
>             x, j = a[i], i - 1
>             while j >= l and a[j] > x:
>                 a[j + 1] = a[j]; j -= 1
>             a[j + 1] = x
>         return
>     p = a[random.randrange(l, r)]
>     lt, i, gt = l, l, r
>     while i < gt:
>         if a[i] < p:   a[lt], a[i] = a[i], a[lt]; lt += 1; i += 1
>         elif a[i] > p: gt -= 1; a[i], a[gt] = a[gt], a[i]
>         else:          i += 1
>     quick_sort(a, l, lt); quick_sort(a, gt, r)
>
> def main():
>     data = list(map(int, sys.stdin.buffer.read().split()))
>     n, a = data[0], data[1:1 + data[0]]
>     quick_sort(a, 0, n)
>     print(*a)
>
> main()
> ```

## 六 · 复杂度

时间：期望 $O(n\log n)$，最坏（极小概率）$O(n^2)$；三路切分让**全相同数据**变成 $O(n)$。
空间：递归栈期望 $O(\log n)$，最坏 $O(n)$（可以用「小的先递归」把它压到 $O(\log n)$）。

## 七 · 易错点

1. **固定 pivot 一定 TLE**：P1177 有 `n=1e5` 的有序/全相同数据，退化 $O(n^2)$ ≈ 1e10 次比较。
2. **`rand()` 不 `srand`**：每次跑同一个种子，随机化形同虚设；考场要 `srand(time(0))`。
3. **三路切分写错 `gt`**：`gt` 是开区间端点，`swap(a[i], a[--gt])` 之后 `i` **不能**自增，否则漏元素。
4. **输出格式**：洛谷这题接受空格分隔；蓝桥卷面常要求一行一个，**以题面为准**。
5. **Python 递归深度**：1e5 层递归会 `RecursionError`，要 `sys.setrecursionlimit`；这也是为什么考场交 C++。
