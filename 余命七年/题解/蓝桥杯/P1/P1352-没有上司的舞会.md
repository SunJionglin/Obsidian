# P1352 没有上司的舞会

> $n \le 6000$ 的树，每人有权值 $r_i$，选了某人就不能选他的直接上司。求最大权值和。

## 一 · 一句话题意
树上最大独立集（点权版）：父与子不能同时选。

## 二 · 解题逻辑
**先想什么**　树上「选/不选」二状态 → 每个点记两个值就够了。

**正解观察**　设 `f[u][0]` = 不选 u 时子树最大值，`f[u][1]` = 选 u 时子树最大值：
$$f[u][0] = \sum_v \max(f[v][0], f[v][1])$$
$$f[u][1] = r_u + \sum_v f[v][0]$$
后序遍历合并，答案 `max(f[root][0], f[root][1])`。

## 三 · 关键点
1. **0/1 两状态**，只这两维。
2. **`f[u][0]` 里子节点可选可不选**，取 max。
3. **`f[u][1]` 里子节点必须不选**。
4. **找根**：入度为 0 的点（没人给他当上司）。
5. **后序**：递归到底再合并，或按拓扑逆序。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> vector<int> g[6005];
> int r[6005], f[6005][2], indeg[6005];
> void dfs(int u) {
>     f[u][0] = 0; f[u][1] = r[u];
>     for (int v : g[u]) {
>         dfs(v);
>         f[u][0] += max(f[v][0], f[v][1]);
>         f[u][1] += f[v][0];
>     }
> }
> int main() {
>     int n; scanf("%d", &n);
>     for (int i = 1; i <= n; i++) scanf("%d", &r[i]);
>     for (int i = 1; i < n; i++) { int l, k; scanf("%d %d", &l, &k); g[k].push_back(l); indeg[l]++; }
>     int root = 1;
>     for (int i = 1; i <= n; i++) if (!indeg[i]) root = i;
>     dfs(root);
>     printf("%d\n", max(f[root][0], f[root][1]));
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> sys.setrecursionlimit(10000)
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     n = d[0]; r = [0] + d[1:1+n]
>     g = [[] for _ in range(n+1)]; indeg = [0]*(n+1)
>     p = 1 + n
>     for _ in range(n-1):
>         l, k = d[p], d[p+1]; p += 2
>         g[k].append(l); indeg[l] += 1
>     f0 = [0]*(n+1); f1 = [0]*(n+1)
>     order = sorted(range(1, n+1), key=lambda x: -indeg[x])  # 简化：用度数近似
>     # 正式做法用后序 DFS；此处给出迭代版思路
>     root = next(i for i in range(1, n+1) if indeg[i] == 0)
>     st = [(root, 0)]
>     while st:
>         u, stt = st.pop()
>         if stt == 0:
>             st.append((u, 1)); f0[u], f1[u] = 0, r[u]
>             for v in g[u]: st.append((v, 0))
>         else:
>             for v in g[u]:
>                 f0[u] += max(f0[v], f1[v]); f1[u] += f0[v]
>     print(max(f0[root], f1[root]))
> main()
> ```

## 五 · 复杂度
$O(n)$；空间 $O(n)$。

## 六 · 易错点
1. **`f[u][1]` 里加了 `max(f[v])`**：选了 u 就不能选子节点。
2. **没找根**：随便挑节点当根会把父子关系搞反。
3. **递归深度**：$n=6000$ 的链会爆栈，C++ 可改迭代，Python 要设 recursionlimit。
