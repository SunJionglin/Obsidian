# P1164 小 A 点菜

> $n \le 100$ 道菜，每道价 $a_i$，身上 $m \le 10^4$ 元，每道只能点一次。求**恰好花完 m 元**的方案数。

## 一 · 一句话题意
0/1 背包**计数**：恰好装满容量 $m$ 的方案数。

## 二 · 解题逻辑
**先想什么**　「方案数」和「最大价值」是两种 DP：一个用加法，一个用 max。

**朴素解法**　枚举子集，$2^{100}$ 不可能。

**正解观察**　`f[j]` = 花掉恰好 $j$ 元的方案数：
$$f[j] \mathrel{+}= f[j-a_i]$$
初值 `f[0] = 1`（花 0 元有 1 种方案：什么都不点），容量**逆序**（每道只能点一次）。

## 三 · 关键点
1. **加法不是 max**：`f[j] += f[j-w]`。
2. **`f[0] = 1`**：这是整个计数的种子，写成 0 就全 0。
3. **逆序**：0/1 语义，每道菜一次。
4. **答案 `f[m]`**：恰好花完，不是「不超过」。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int f[10005];
> int main() {
>     int n, m; scanf("%d %d", &n, &m);
>     f[0] = 1;
>     for (int i = 0; i < n; i++) {
>         int a; scanf("%d", &a);
>         for (int j = m; j >= a; j--) f[j] += f[j - a];
>     }
>     printf("%d\n", f[m]);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     n, m = d[0], d[1]
>     f = [0] * (m + 1); f[0] = 1
>     for a in d[2:2 + n]:
>         for j in range(m, a - 1, -1):
>             f[j] += f[j - a]
>     print(f[m])
> main()
> ```

## 五 · 复杂度
$O(nm)$ = 1e6，瞬时；空间 $O(m)$。

## 六 · 易错点
1. **`f[0]` 写成 0**：所有答案归零。
2. **用 max 不用加法**：那是「最大价值」，这里是「方案数」。
3. **正序枚举**：变成「每道菜可点多次」（完全背包计数）。
4. **答案取 `f[m]` 还是求和**：题意是恰好花完，只取 `f[m]`。
