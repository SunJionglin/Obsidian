# P1048 采药

> 总时间 $T \le 1000$，药材 $M \le 100$，每株有耗时 $t_i$ 与价值 $v_i$，每株只能采一次。求最大价值。

## 一 · 一句话题意
0/1 背包：容量 $T$，物品 $M$ 件，每件一次，最大化价值。

## 二 · 解题逻辑
**先想什么**　「选或不选、只选一次、有容量」= 0/1 背包标准模型。

**朴素解法**　枚举子集 $2^M$，$M=100$ 不可能。

**正解观察**　$f[j]$ = 容量 $j$ 时的最大价值，**逆序**枚举容量：
$$f[j] = \max(f[j],\ f[j-t_i] + v_i)$$
逆序的用处：保证 `f[j-t_i]` 还是「没放第 i 件」的旧值，即每件只用一次。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 枚举子集 | $O(2^M)$ | 爆 |
| 二维 DP | $O(MT)$ | 能过但多一维 |
| **一维逆序 DP** | $O(MT)$ | 无 |

## 四 · 关键点
1. **逆序**：`for j = T down to t[i]`，顺序就变成完全背包了。
2. **下界是 `t[i]`**：`j - t[i] >= 0`。
3. **初值 0**：不要求装满，全 0 即可。
4. **`f[T]` 就是答案**，不用扫全部。

## 五 · 实现逻辑
读入 → 外层物品、内层容量逆序 → 输出 `f[T]`。

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int f[1005];
> int main() {
>     int T, M; scanf("%d %d", &T, &M);
>     for (int i = 1; i <= M; i++) {
>         int t, v; scanf("%d %d", &t, &v);
>         for (int j = T; j >= t; j--) f[j] = max(f[j], f[j - t] + v);
>     }
>     printf("%d\n", f[T]);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     T, M = d[0], d[1]
>     f = [0] * (T + 1)
>     p = 2
>     for _ in range(M):
>         t, v = d[p], d[p + 1]; p += 2
>         for j in range(T, t - 1, -1):
>             f[j] = max(f[j], f[j - t] + v)
>     print(f[T])
> main()
> ```

## 六 · 复杂度
$O(MT)$ = 1e5，瞬时；空间 $O(T)$。

## 七 · 易错点
1. **正序枚举**：变成完全背包（同一株反复采）。
2. **`j` 从 0 开始**：`j - t` 会负。
3. **初值设 -INF**：这题不要求装满，设 -INF 反而错。
4. **多组测试数据不清零**：本题只有一组，但搬到别的题要注意。
