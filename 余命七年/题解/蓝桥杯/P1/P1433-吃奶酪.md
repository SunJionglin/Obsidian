# P1433 吃奶酪

> $n \le 15$ 块奶酪，从原点出发，求经过所有奶酪的最短路径长度（不用回到原点）。

## 一 · 一句话题意
TSP 变形：从原点出发、遍历所有点的最短哈密顿路径。

## 二 · 解题逻辑
**先想什么**　$n \le 15$ → 指数级但可状压：$2^{15} \times 15 \approx 5\times10^5$ 状态。

**正解观察**　`f[mask][i]` = 已经过集合 `mask`、最后停在 $i$ 的最短距离。
$$f[mask][i] = \min_{j \in mask,\, j \ne i}\{f[mask \setminus i][j] + \text{dist}(j,i)\}$$
初值 `f[1<<i][i] = dist(0, i)`（原点出发），答案是 $\min_i f[full][i]$。

## 三 · 关键点
1. **状压枚举子集**：`for mask in 1..(1<<n)-1`。
2. **先算小集合**：`mask` 从小到大，保证子集已算。
3. **距离预处理**：`dist[i][j]` 一次算好。
4. **答案是 min 不是某个点**。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> double x[16], y[16], d[16][16], f[1 << 15][15];
> int main() {
>     int n; scanf("%d", &n);
>     for (int i = 1; i <= n; i++) scanf("%lf %lf", &x[i], &y[i]);
>     x[0] = y[0] = 0;
>     for (int i = 0; i <= n; i++)
>         for (int j = 0; j <= n; j++) d[i][j] = hypot(x[i]-x[j], y[i]-y[j]);
>     for (int m = 0; m < (1 << n); m++) for (int i = 0; i < n; i++) f[m][i] = 1e18;
>     for (int i = 0; i < n; i++) f[1 << i][i] = d[0][i + 1];
>     for (int m = 1; m < (1 << n); m++)
>         for (int i = 0; i < n; i++) {
>             if (!(m >> i & 1) || f[m][i] >= 1e18) continue;
>             for (int j = 0; j < n; j++) {
>                 if (m >> j & 1) continue;
>                 int nm = m | (1 << j);
>                 f[nm][j] = min(f[nm][j], f[m][i] + d[i + 1][j + 1]);
>             }
>         }
>     double ans = 1e18;
>     for (int i = 0; i < n; i++) ans = min(ans, f[(1 << n) - 1][i]);
>     printf("%.2f\n", ans);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys, math
> def main():
>     d = list(map(float, sys.stdin.buffer.read().split()))
>     n = int(d[0]); pts = [(0.0, 0.0)] + [(d[1+2*i], d[2+2*i]) for i in range(n)]
>     dist = [[math.hypot(pts[i][0]-pts[j][0], pts[i][1]-pts[j][1]) for j in range(n+1)] for i in range(n+1)]
>     INF = float('inf'); full = 1 << n
>     f = [[INF]*n for _ in range(full)]
>     for i in range(n): f[1 << i][i] = dist[0][i+1]
>     for m in range(full):
>         for i in range(n):
>             if not (m >> i & 1) or f[m][i] == INF: continue
>             for j in range(n):
>                 if m >> j & 1: continue
>                 nm = m | (1 << j)
>                 v = f[m][i] + dist[i+1][j+1]
>                 if v < f[nm][j]: f[nm][j] = v
>     print(f"{min(f[full-1]):.2f}")
> main()
> ```

## 五 · 复杂度
$O(2^n n^2)$ ≈ 7e6，$n=15$ 可过（C++）；Python 偏慢但能过。

## 六 · 易错点
1. **距离算成 `int`**：必须浮点 + `hypot`。
2. **子集枚举顺序**：`m` 从小到大保证依赖已算。
3. **答案输出格式**：两位小数。
4. **$n=0$**：直接输出 `0.00`。

## 七 · 一句话总结
**状压 TSP：`f[集合][最后点]`，从小集合推大集合，答案是所有「全集合」终点的最小值。**
