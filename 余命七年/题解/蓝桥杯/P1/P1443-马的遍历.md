# P1443 马的遍历

> $n,m \le 400$ 的棋盘，马从 $(x,y)$ 出发，求到每个格子的**最少步数**，不可达输出 $-1$。

## 一 · 一句话题意
棋盘上 BFS 最短路，八个方向。

## 二 · 解题逻辑
**先想什么**　每步代价都是 1 → BFS；层数就是步数。

**正解观察**　`dis` 数组初值 -1，起点 0；队列里每次扩展 8 个方向，未访问就 `dis = dis[u]+1` 并入队。

## 三 · 关键点
1. **八方向**：`(±1,±2)` 与 `(±2,±1)`。
2. **`dis` 初值 -1** 同时当访问标记，省一个数组。
3. **边界**：`1 ≤ x ≤ n, 1 ≤ y ≤ m`。
4. **输出格式**：每格宽度 5（`%5d`）。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int d[405][405];
> int dx[8] = {1,1,-1,-1,2,2,-2,-2}, dy[8] = {2,-2,2,-2,1,-1,1,-1};
> int main() {
>     int n, m, sx, sy; scanf("%d %d %d %d", &n, &m, &sx, &sy);
>     memset(d, -1, sizeof d);
>     queue<pair<int,int>> q; q.push({sx, sy}); d[sx][sy] = 0;
>     while (!q.empty()) {
>         auto [x, y] = q.front(); q.pop();
>         for (int k = 0; k < 8; k++) {
>             int nx = x + dx[k], ny = y + dy[k];
>             if (nx < 1 || nx > n || ny < 1 || ny > m || d[nx][ny] != -1) continue;
>             d[nx][ny] = d[x][y] + 1; q.push({nx, ny});
>         }
>     }
>     for (int i = 1; i <= n; i++) {
>         for (int j = 1; j <= m; j++) printf("%5d", d[i][j]);
>         puts("");
>     }
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> from collections import deque
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     n, m, sx, sy = d
>     dis = [[-1]*(m+1) for _ in range(n+1)]
>     dis[sx][sy] = 0
>     q = deque([(sx, sy)])
>     mv = [(1,2),(1,-2),(-1,2),(-1,-2),(2,1),(2,-1),(-2,1),(-2,-1)]
>     while q:
>         x, y = q.popleft()
>         for dx, dy in mv:
>             nx, ny = x+dx, y+dy
>             if 1 <= nx <= n and 1 <= ny <= m and dis[nx][ny] == -1:
>                 dis[nx][ny] = dis[x][y] + 1; q.append((nx, ny))
>     sys.stdout.write("\n".join("".join(f"{dis[i][j]:5d}" for j in range(1, m+1)) for i in range(1, n+1)))
> main()
> ```

## 五 · 复杂度
$O(nm)$，1.6e5 格。

## 六 · 易错点
1. **方向写漏**：八个方向一个不能少。
2. **`dis` 初值 0**：起点之外全变 0，无法判访问。
3. **输出格式**：`%5d` 宽度不对会 PE。
