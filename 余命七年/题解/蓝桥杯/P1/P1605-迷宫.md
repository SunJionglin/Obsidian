# P1605 迷宫

> $n,m \le 5$ 的迷宫，无障碍格子可走，有 $T$ 个障碍。求从起点到终点的**路径条数**。

## 一 · 一句话题意
网格图数路径条数（四个方向、不能重复走、不能走障碍）。

## 二 · 解题逻辑
**先想什么**　「条数」不是「最短路」→ 必须回溯枚举所有路径，DFS。

**正解观察**　DFS(当前格) { 若到终点 ans++ 并返回；标记访问；四个方向递归；**取消标记** }

## 三 · 关键点
1. **回溯必须撤销标记**，否则其它路径走不了。
2. **到终点立刻返回**，不再往外走。
3. **障碍**单独用数组标记，不要和访问表混。
4. **起点本身也要标记**。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int n, m, t, sx, sy, ex, ey, ans;
> int vis[10][10], blo[10][10];
> int dx[4] = {1,-1,0,0}, dy[4] = {0,0,1,-1};
> void dfs(int x, int y) {
>     if (x == ex && y == ey) { ans++; return; }
>     for (int k = 0; k < 4; k++) {
>         int nx = x + dx[k], ny = y + dy[k];
>         if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
>         if (vis[nx][ny] || blo[nx][ny]) continue;
>         vis[nx][ny] = 1; dfs(nx, ny); vis[nx][ny] = 0;
>     }
> }
> int main() {
>     scanf("%d %d %d %d %d %d %d", &n, &m, &t, &sx, &sy, &ex, &ey);
>     for (int i = 0; i < t; i++) { int x, y; scanf("%d %d", &x, &y); blo[x][y] = 1; }
>     vis[sx][sy] = 1; dfs(sx, sy);
>     printf("%d\n", ans);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> sys.setrecursionlimit(10000)
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     n, m, t, sx, sy, ex, ey = d[:7]
>     blo = [[0]*(m+2) for _ in range(n+2)]
>     p = 7
>     for _ in range(t):
>         blo[d[p]][d[p+1]] = 1; p += 2
>     vis = [[0]*(m+2) for _ in range(n+2)]
>     vis[sx][sy] = 1
>     ans = 0
>     def dfs(x, y):
>         nonlocal ans
>         if x == ex and y == ey:
>             ans += 1; return
>         for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
>             nx, ny = x+dx, y+dy
>             if 1 <= nx <= n and 1 <= ny <= m and not vis[nx][ny] and not blo[nx][ny]:
>                 vis[nx][ny] = 1; dfs(nx, ny); vis[nx][ny] = 0
>     dfs(sx, sy)
>     print(ans)
> main()
> ```

## 五 · 复杂度
路径数指数级，但 $n,m \le 5$ 且障碍多，实际可过。

## 六 · 易错点
1. **忘记撤销访问**：只能走一条路。
2. **到终点没 return**：会越界继续走。
3. **起点没标记**：可能绕回起点。
4. **障碍与访问混用**：回溯时把障碍也清了。
