# P1091 合唱队形

> $n \le 100$，身高 $a_i$。要排成「先升后降」，求**最少移除几人**（= n − 最长先升后降子序列长度）。

## 一 · 一句话题意
找最长的「单峰」子序列（严格上升再严格下降），输出 $n - \text{maxlen}$。

## 二 · 解题逻辑
**先想什么**　单峰 = 左边上升 + 右边下降，峰顶是同一个点。

**朴素解法**　枚举峰顶 + 两段 LIS 各算一次：$O(n^3)$，n=100 也能过但没必要。

**正解观察**　预处理两个数组：
- `up[i]` = 以 i 结尾的最长上升子序列长度（从左往右）；
- `down[i]` = 以 i 开头的最长下降子序列长度（从右往左看上升）。

答案 $\max_i (up[i] + down[i] - 1)$，再 $n$ 减掉。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 枚举峰顶 + 每段 $O(n^2)$ | $O(n^3)$ | 代码重复 |
| **正反各一遍 $O(n^2)$ DP** | $O(n^2)$ | 无（n ≤ 100 足够） |
| 二分版 LIS | $O(n\log n)$ | 这里没必要 |

## 四 · 关键点
1. **`up` 正着推**：`up[i] = max{up[j]+1 | j<i, a[j]<a[i]}`。
2. **`down` 倒着推**：把「以 i 开头的最长下降」转成「以 i 结尾的最长上升」——从右往左枚举。
3. **峰顶只算一次**：`up[i]+down[i]-1`。
4. **严格**：比较用 `<`，相等不算上升。
5. **答案是最少出列人数**，不是最长长度。

## 五 · 实现逻辑
读入 → 正推 `up` → 倒推 `down` → 扫一遍取 `max(up[i]+down[i]-1)` → 输出 `n - best`。

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int a[105], up[105], dn[105];
> int main() {
>     int n; scanf("%d", &n);
>     for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
>     for (int i = 1; i <= n; i++) {
>         up[i] = 1;
>         for (int j = 1; j < i; j++) if (a[j] < a[i]) up[i] = max(up[i], up[j] + 1);
>     }
>     for (int i = n; i >= 1; i--) {
>         dn[i] = 1;
>         for (int j = n; j > i; j--) if (a[j] < a[i]) dn[i] = max(dn[i], dn[j] + 1);
>     }
>     int best = 0;
>     for (int i = 1; i <= n; i++) best = max(best, up[i] + dn[i] - 1);
>     printf("%d\n", n - best);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     n, a = d[0], d[1:1 + d[0]]
>     up = [1] * n
>     for i in range(n):
>         for j in range(i):
>             if a[j] < a[i]: up[i] = max(up[i], up[j] + 1)
>     dn = [1] * n
>     for i in range(n - 1, -1, -1):
>         for j in range(n - 1, i, -1):
>             if a[j] < a[i]: dn[i] = max(dn[i], dn[j] + 1)
>     print(n - max(up[i] + dn[i] - 1 for i in range(n)))
> main()
> ```

## 六 · 复杂度
$O(n^2)$ 时间、$O(n)$ 空间；n ≤ 100 瞬时。

## 七 · 易错点
1. **`down` 写成从左往右**：那是「以 i 结尾的下降」，不是以 i 开头的。
2. **忘记 $-1$**：峰顶被两个数组各算一次。
3. **答案写成最长长度**：题目要的是出列人数。
4. **用了 `<=`**：相等的身高不能构成严格上升/下降。
