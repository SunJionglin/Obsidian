# P3367 【模板】并查集

> $n \le 10^4$ 个元素，$m \le 2\times10^5$ 次操作：合并两个集合 / 查询是否同集合。输出 `Y`/`N`。

## 一 · 一句话题意
并查集模板：合并 + 查询连通性。

## 二 · 解题逻辑
**先想什么**　「集合合并 + 是否同集合」→ 每个集合用一棵树的根代表。

**正解观察**　路径压缩：`find(x)` 递归找根并把路径上所有点直接挂到根上，摊还接近 $O(1)$；合并时按秩/按大小把小树挂到大树上。

## 三 · 关键点
1. **初始化 `fa[i] = i`**。
2. **路径压缩写法**：`return fa[x] == x ? x : fa[x] = find(fa[x]);`。
3. **合并**：`fa[find(x)] = find(y)`。
4. **查询**：`find(x) == find(y)`。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int fa[10005];
> int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
> int main() {
>     int n, m; scanf("%d %d", &n, &m);
>     for (int i = 1; i <= n; i++) fa[i] = i;
>     while (m--) {
>         int z, x, y; scanf("%d %d %d", &z, &x, &y);
>         int rx = find(x), ry = find(y);
>         if (z == 1) { if (rx != ry) fa[rx] = ry; }
>         else puts(rx == ry ? "Y" : "N");
>     }
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     n, m = d[0], d[1]
>     fa = list(range(n + 1))
>     def find(x):
>         while fa[x] != x:
>             fa[x] = fa[fa[x]]; x = fa[x]
>         return x
>     out = []
>     p = 2
>     for _ in range(m):
>         z, x, y = d[p], d[p+1], d[p+2]; p += 3
>         rx, ry = find(x), find(y)
>         if z == 1:
>             if rx != ry: fa[rx] = ry
>         else:
>             out.append("Y" if rx == ry else "N")
>     sys.stdout.write("\n".join(out))
> main()
> ```

## 五 · 复杂度
摊还 $O(\alpha(n))$ ≈ $O(1)$ 每次操作。

## 六 · 易错点
1. **忘初始化**：`fa[i] = i` 少写就是死循环。
2. **合并写成 `fa[x] = y`**：必须用根，`fa[find(x)] = find(y)`。
3. **递归深度**：不压缩的链会退化成 $O(n)$，1e4 层能爆栈（C++ 建议递归 + 压缩，或写迭代）。

## 七 · 一句话总结
**并查集三件套：`fa[x]=x` 初始化、路径压缩的 find、`fa[find(x)]=find(y)` 合并。**
