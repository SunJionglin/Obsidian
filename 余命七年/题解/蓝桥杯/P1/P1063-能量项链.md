# P1063 能量项链

> 环形 $n \le 100$ 颗珠子，每颗有头尾两个数，相邻两颗合并释放 $a_i \cdot a_{i+1} \cdot a_{i+2}$ 的能量。求最大总能量。

## 一 · 一句话题意
环形石子合并的变体：合并代价是**三个数相乘**（而不是两段和）。

## 二 · 解题逻辑
**先想什么**　还是「最后一次合并拆区间」，但合并的代价与区间端点和分裂点有关。

**正解观察**　拆链加倍，`f[i][j]` = 合并区间 $[i,j]$ 的最大能量：
$$f[i][j] = \max_{i \le k < j}\{f[i][k] + f[k+1][j] + a_i \cdot a_{k+1} \cdot a_{j+1}\}$$
（把 $a_i$ 看作区间左端点的「头」，$a_{k+1}$ 是分界，$a_{j+1}$ 是右端点的「尾」。）

## 三 · 关键点
1. **数组开 $2n+2$**：右端点要用到 $j+1$。
2. **拆链**：`a[i+n] = a[i]`。
3. **代价是三元组相乘**，不是区间和。
4. **答案在 `f[i][i+n-1]` 里取 max**（合成一颗珠子用了 $n$ 个数）。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int a[205], f[205][205];
> int main() {
>     int n; scanf("%d", &n);
>     for (int i = 1; i <= n; i++) { scanf("%d", &a[i]); a[i+n] = a[i]; }
>     a[2*n+1] = a[1];
>     for (int len = 2; len <= n; len++)
>         for (int i = 1; i + len - 1 <= 2*n; i++) {
>             int j = i + len - 1;
>             for (int k = i; k < j; k++)
>                 f[i][j] = max(f[i][j], f[i][k] + f[k+1][j] + a[i] * a[k+1] * a[j+1]);
>         }
>     int ans = 0;
>     for (int i = 1; i <= n; i++) ans = max(ans, f[i][i+n-1]);
>     printf("%d\n", ans);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     n = d[0]; b = d[1:1+n]
>     a = [0] + b + b + [b[0]]
>     m = 2 * n
>     f = [[0]*(m+2) for _ in range(m+2)]
>     for L in range(2, n+1):
>         for i in range(1, m - L + 2):
>             j = i + L - 1
>             for k in range(i, j):
>                 v = f[i][k] + f[k+1][j] + a[i]*a[k+1]*a[j+1]
>                 if v > f[i][j]: f[i][j] = v
>     print(max(f[i][i+n-1] for i in range(1, n+1)))
> main()
> ```

## 五 · 复杂度
$O(n^3)$，$n=100$ 约 1e6。

## 六 · 易错点
1. **`a[j+1]` 越界**：要补一位。
2. **代价写成区间和**：这是三元相乘，套石子合并模板会错。
3. **长度枚举到 2n**：会算多余的区间。
4. **答案取 `f[1][n]`**：环形要从各起点取。
