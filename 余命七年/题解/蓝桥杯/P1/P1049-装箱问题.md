# P1049 装箱问题

> 箱子容积 $V \le 20000$，物品 $n \le 30$，每件体积 $v_i$，每件只能用一次。求**剩余空间最小**。

## 一 · 一句话题意
0/1 背包，物品的「体积」同时也是「价值」，求能装的最大体积，再 $V - \max$。

## 二 · 解题逻辑
**先想什么**　「剩余最小」= 装进去的尽量多。

**朴素解法**　枚举子集 $2^{30}$ ≈ 1e9，太慢。

**正解观察**　把体积同时当价值：$f[j] = \max$ 能装到体积 $j$ 时占用的容量。等价于 0/1 背包 `v = w = 体积`，答案是 $V - f[V]$。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 枚举子集 | $O(2^n)$ | 1e9 |
| **0/1 背包（体积当价值）** | $O(nV)$ | 无 |
| 搜索 + 剪枝 | 不确定 | 数据好能过，不稳 |

## 四 · 关键点
1. **`v = w`**：同一件物品的体积既是重量也是价值。
2. **逆序**：每件只能用一次。
3. **答案 `V - f[V]`**，不是 `f[V]`。
4. **`f` 全 0 初始化**：不要求装满。

## 五 · 实现逻辑
读 $V, n$ → 外层物品、内层容量逆序 `f[j] = max(f[j], f[j-w] + w)` → 输出 `V - f[V]`。

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int f[20005];
> int main() {
>     int V, n; scanf("%d %d", &V, &n);
>     for (int i = 0; i < n; i++) {
>         int w; scanf("%d", &w);
>         for (int j = V; j >= w; j--) f[j] = max(f[j], f[j - w] + w);
>     }
>     printf("%d\n", V - f[V]);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     V, n = d[0], d[1]
>     f = [0] * (V + 1)
>     for w in d[2:2 + n]:
>         for j in range(V, w - 1, -1):
>             f[j] = max(f[j], f[j - w] + w)
>     print(V - f[V])
> main()
> ```

## 六 · 复杂度
$O(nV)$ = 6e5；空间 $O(V)$。

## 七 · 易错点
1. **答案忘了减**：输出 `f[V]` 就错了。
2. **顺序写成正序**：变完全背包，物品可重复。
3. **`f` 初始化 -INF**：不要求装满，会出错。
