# P2024 食物链

> $n \le 5\times10^4$ 种动物，三种关系循环：A 吃 B、B 吃 C、C 吃 A。$k \le 10^5$ 条陈述，问有多少条是假话。

## 一 · 一句话题意
带「吃 / 被吃 / 同类」三种关系的并查集，统计矛盾陈述。

## 二 · 解题逻辑
**先想什么**　关系不只是「同不同类」，还有「谁吃谁」——普通并查集不够。

**正解观察**　**一拆三**：每种动物开 $x$（自己）、$x+n$（猎物）、$x+2n$（天敌）。
- 说「x 与 y 同类」：合并三对 $(x,y)$、$(x+n,y+n)$、$(x+2n,y+2n)$。
- 说「x 吃 y」：合并 $(x, y+2n)$、$(x+n, y)$、$(x+2n, y+n)$。

判定假话：同类时若 `find(x)==find(y+n)` 或 `find(x)==find(y+2n)` 就矛盾；吃时若 `find(x)==find(y)` 或 `find(x)==find(y+2n)`（y 吃 x）就矛盾。

## 三 · 关键点
1. **开 3n** 的空间，三份偏移。
2. **每次陈述要检查矛盾再合并**。
3. **「自己吃自己」直接是假话**：x 吃 y 且 x==y。
4. **取模类包装**：关系循环方向要一致。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int fa[150005];
> int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
> void uni(int a, int b) { fa[find(a)] = find(b); }
> int main() {
>     int n, k; scanf("%d %d", &n, &k);
>     for (int i = 1; i <= 3 * n; i++) fa[i] = i;
>     int ans = 0;
>     while (k--) {
>         int op, x, y; scanf("%d %d %d", &op, &x, &y);
>         if (x > n || y > n) { ans++; continue; }
>         if (op == 1) {
>             if (find(x) == find(y + n) || find(x) == find(y + 2 * n)) { ans++; continue; }
>             uni(x, y); uni(x + n, y + n); uni(x + 2 * n, y + 2 * n);
>         } else {
>             if (x == y || find(x) == find(y) || find(x) == find(y + 2 * n)) { ans++; continue; }
>             uni(x, y + 2 * n); uni(x + n, y); uni(x + 2 * n, y + n);
>         }
>     }
>     printf("%d\n", ans);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     n, k = d[0], d[1]
>     fa = list(range(3 * n + 1))
>     def find(x):
>         while fa[x] != x:
>             fa[x] = fa[fa[x]]; x = fa[x]
>         return x
>     def uni(a, b): fa[find(a)] = find(b)
>     ans = 0; p = 2
>     for _ in range(k):
>         op, x, y = d[p], d[p+1], d[p+2]; p += 3
>         if x > n or y > n: ans += 1; continue
>         if op == 1:
>             if find(x) == find(y+n) or find(x) == find(y+2*n): ans += 1; continue
>             uni(x, y); uni(x+n, y+n); uni(x+2*n, y+2*n)
>         else:
>             if x == y or find(x) == find(y) or find(x) == find(y+2*n): ans += 1; continue
>             uni(x, y+2*n); uni(x+n, y); uni(x+2*n, y+n)
>     print(ans)
> main()
> ```

## 五 · 复杂度
$O(k\,\alpha(n))$，1e5 次。

## 六 · 易错点
1. **只开 n 个点**：表达不了「吃」。
2. **合并顺序错**：三个 `uni` 任一方向反了就全错。
3. **先合再判**：矛盾陈述必须先判后合。
4. **越界编号**：`x>n` 也是假话。

## 七 · 一句话总结
**种类并查集 = 一拆三（自己/猎物/天敌）；先判矛盾、再合并三对，关系方向三个 `uni` 别写错。**
