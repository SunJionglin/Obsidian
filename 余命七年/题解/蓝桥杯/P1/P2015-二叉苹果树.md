# P2015 二叉苹果树

> $n \le 100$ 个节点的二叉树，每条边有苹果数，剪掉 $n-q-1$ 条边后保留 $q$ 条。求保留边权和最大值。

## 一 · 一句话题意
树上背包：选 $q$ 条边，必须与根连通，最大化边权和。

## 二 · 解题逻辑
**先想什么**　「保留 k 条边」是容量，「与根连通」保证是子树 → 树上背包。

**正解观察**　`f[u][j]` = 以 u 为根的子树里，保留 $j$ 条边的最大权值。合并子节点 v 时，分给它 $k$ 条边（含边 u-v 自己占 1 条）：
$$f[u][j] = \max\{f[u][j-k] + f[v][k-1] + w_{u,v}\}$$

## 三 · 关键点
1. **每条边算 1 条容量**，边权进答案。
2. **分组背包**：子节点之间互斥（每个孩子的分配要一次性定）。
3. **逆序**：$j$ 要逆序，避免同一孩子被重复取。
4. **答案 `f[root][q]`**。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> vector<pair<int,int>> g[105];
> int f[105][105], sz[105], n, q;
> void dfs(int u, int fa) {
>     sz[u] = 1;
>     for (auto [v, w] : g[u]) {
>         if (v == fa) continue;
>         dfs(v, u);
>         sz[u] += sz[v];
>         for (int j = min(q, sz[u] - 1); j >= 0; j--)
>             for (int k = 0; k <= min(j - 1, sz[v] - 1); k++)
>                 f[u][j] = max(f[u][j], f[u][j-1-k] + f[v][k] + w);
>     }
> }
> int main() {
>     scanf("%d %d", &n, &q);
>     for (int i = 1; i < n; i++) {
>         int u, v, w; scanf("%d %d %d", &u, &v, &w);
>         g[u].push_back({v, w}); g[v].push_back({u, w});
>     }
>     dfs(1, 0);
>     printf("%d\n", f[1][q]);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python

> import sys

>     f = [[0]*(q+1) for _ in range(n+1)]
>     def dfs(u, fa):
>         sz = 1
>         for v, w in g[u]:
>             if v == fa: continue
>             sv = dfs(v, u)
>             sz += sv
>             for j in range(min(q, sz-1), 0, -1):
>                 for k in range(0, min(j-1, sv-1) + 1):
>                     cand = f[u][j-1-k] + f[v][k] + w
>                     if cand > f[u][j]: f[u][j] = cand
>         return sz
>     dfs(1, 0)
>     print(f[1][q])
> main()

## 五 · 复杂度
$O(nq^2)$；$n,q \le 100$ 约 1e6。

## 六 · 易错点
1. **忘了边自己占 1 条**：`f[v][k] + w` 与 `f[u][j-1-k]` 里的 $-1$。
2. **`j` 不逆序**：同一子节点被重复使用。
3. **`sz` 不更新上界**：会超范围访问。
