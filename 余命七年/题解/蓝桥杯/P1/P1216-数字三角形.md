# P1216 数字三角形

> $r \le 1000$，每行 $i$ 个整数（|数| ≤ 100）。从顶走到底，每步只能走左下/右下，求路径和最大值。

## 一 · 一句话题意
三角形 $a[i][j]$，从 $(1,1)$ 走到第 $r$ 行任意位置，只能向下或右下，最大化路径和。

## 二 · 解题逻辑
**先想什么**　「路径和最大」+「只能往下走」= DAG 上最长路 → DP。状态就是「走到哪个格子」。

**朴素解法**　DFS 枚举所有路径：路径数 $2^{r-1}$，$r=1000$ 时天文数字。

**正解观察**　到达 $(i,j)$ 只能来自 $(i-1,j-1)$ 或 $(i-1,j)$——**两种来源**，取大的即可：
$$f[i][j] = a[i][j] + \max(f[i-1][j-1], f[i-1][j])$$
压成一维：从下往上算，`f[j] = a[i][j] + max(f[j], f[j+1])`。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 记忆化 DFS | $O(r^2)$ | 要开二维 + 递归，常数大 |
| 二维 DP | $O(r^2)$ | 1e6 个状态，能过但占内存 |
| **一维滚动 DP** | $O(r^2)$ 时间、$O(r)$ 空间 | 无 |

## 四 · 关键点
1. **状态定义**：`f[j]` = 从底部走到当前行第 j 列的最大和。
2. **倒推**：从倒数第二行往上算，避免边界判断。
3. **一维方向**：这一行的 `f[j]` 依赖下一行的 `f[j]` 和 `f[j+1]`，从前往后更新不会覆盖错。
4. **负数**：路径和可能为负，初值别设 0；直接 `-INF` 或用第一行初始化。
5. **读入**：三角形按行读，注意每行个数递增。

## 五 · 实现逻辑
先读成 `a[i][j]`（或边读边存）→ 用最后一行初始化 `f` → 从 `r-1` 行往上递推 → 输出 `f[1]`。

**手推**（`7 / 3 8 / 8 1 0`）：

| 步骤 | f 数组状态 |
| --- | --- |
| 最后一行 | [8, 1, 0] |
| 第 2 行 | [3+max(8,1)=11, 8+max(1,0)=9] |
| 第 1 行 | [7+max(11,9)=18] |

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int a[1010][1010], f[1010];
> int main() {
>     int r; scanf("%d", &r);
>     for (int i = 1; i <= r; i++)
>         for (int j = 1; j <= i; j++) scanf("%d", &a[i][j]);
>     for (int j = 1; j <= r; j++) f[j] = a[r][j];
>     for (int i = r - 1; i >= 1; i--)
>         for (int j = 1; j <= i; j++)
>             f[j] = a[i][j] + max(f[j], f[j + 1]);
>     printf("%d\n", f[1]);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python

> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     r = d[0]; idx = 1
>     a = [[0] * (r + 2) for _ in range(r + 1)]
>     for i in range(1, r + 1):
>         for j in range(1, i + 1):
>             a[i][j] = d[idx]; idx += 1

>     for i in range(r - 1, 0, -1):
>         for j in range(1, i + 1):
>             f[j] = a[i][j] + max(f[j], f[j + 1])
>     print(f[1])
> main()
> ```

## 六 · 复杂度
时间 $O(r^2)$（1e6 次），空间 $O(r) + O(r^2)$ 存数组（可边读边省，但没必要）。

## 七 · 易错点
1. **正推写成「从上一行取 $j$ 和 $j-1$」却忘了边界**：`j-1=0` 时要特判，倒推没有这个问题。
2. **一维数组更新方向搞反**：正推必须从后往前（否则用了本行刚更新的值）。
3. **负数路径**：初值 0 会让负路径被「忽略」，与真实答案不符。
4. **读入按行**：每行个数递增，别当成 $r \times r$。
