# P1616 疯狂的采药

> 总时间 $T$，草药 $M$ 种，**每种可以无限次采**。求最大价值。

## 一 · 一句话题意
完全背包：每种物品无限件。

## 二 · 解题逻辑
**先想什么**　跟 [[P1048-采药]] 只差一句「每种可以无限采」——循环方向从逆序改正序。

**为什么正序就行**　正序时 `f[j-w]` 已经是「本轮更新过」的值，也就是允许同一物品再放一次，正好是完全背包的语义。

**正解观察**
$$f[j] = \max(f[j],\ f[j-t_i] + v_i),\quad j: t_i \to T$$

## 三 · 关键点
1. **正序**：唯一与 0/1 背包的区别。
2. **答案 `f[T]`**：不要求装满，取最大值。
3. **`long long`**：$T$ 与价值都可能较大，用 `long long` 稳妥。
4. **常数**：`O(TM)` 的两重循环，本题数据下 C++ 可过；若 $T,M$ 同时取上界需加常数优化（见易错点 4）。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> long long f[10000005];
> int main() {
>     int T, M; scanf("%d %d", &T, &M);
>     for (int i = 0; i < M; i++) {
>         int t; long long v; scanf("%d %lld", &t, &v);
>         for (int j = t; j <= T; j++) f[j] = max(f[j], f[j - t] + v);
>     }
>     printf("%lld\n", f[T]);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     T, M = d[0], d[1]
>     f = [0] * (T + 1)
>     p = 2
>     for _ in range(M):
>         t, v = d[p], d[p + 1]; p += 2
>         for j in range(t, T + 1):
>             if f[j - t] + v > f[j]: f[j] = f[j - t] + v
>     print(f[T])
> main()
> ```

## 五 · 复杂度
时间 $O(TM)$，空间 $O(T)$（1e7 个 long long = 80MB，注意内存限制，必要时用 `int`）。

## 六 · 易错点
1. **写成逆序**：退化回 0/1 背包，答案偏小。
2. **`f` 用 int 溢出**：价值累加可能超 2e9。
3. **数组开小**：$T$ 可能到 1e7，动态 `vector` 更安全。
4. **卡常**：两重循环在最坏数据下慢，可按「性价比」剪枝或只保留每种物品的最优单位价值。
