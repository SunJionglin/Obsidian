# P2404 自然数的拆分

> 把 $n \le 8$ 拆成若干**正整数之和**，按字典序输出所有方案，且**每种方案内部非递减**（保证不重复）。

## 一 · 一句话题意
$n$ 的整数拆分，输出所有不重复方案。

## 二 · 解题逻辑
**先想什么**　枚举所有拆分 → 关键是**去重**。

**正解观察**　强制「下一项 ≥ 上一项」：`dfs(剩余, 上一项, 当前路径)`，从 `last` 枚举到 `剩余`。这样 `1+1+2` 与 `2+1+1` 只出现一次。

## 三 · 关键点
1. **`start = last`**：下一项不小于上一项。
2. **剪枝**：循环上界 `i <= remain`。
3. **出口**：`remain == 0` 输出（至少两项）。
4. **输出格式**：`+` 连接，行尾无多余符号。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int n, path[10], dep;
> void dfs(int remain, int last) {
>     if (remain == 0) {
>         if (dep < 2) return;
>         for (int i = 0; i < dep; i++) printf("%d%c", path[i], i + 1 == dep ? '\n' : '+');
>         return;
>     }
>     for (int i = last; i <= remain; i++) {
>         path[dep++] = i; dfs(remain - i, i); dep--;
>     }
> }
> int main() { scanf("%d", &n); dfs(n, 1); return 0; }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> n = int(sys.stdin.buffer.read())
> out = []
> def dfs(remain, last, path):
>     if remain == 0:
>         if len(path) >= 2: out.append("+".join(map(str, path)))
>         return
>     for i in range(last, remain + 1):
>         dfs(remain - i, i, path + [i])
> dfs(n, 1, [])
> sys.stdout.write("\n".join(out))
> ```

## 五 · 复杂度
输出本身是指数级，$n \le 8$ 时很小。

## 六 · 易错点
1. **不限「非递减」**：方案会重复。
2. **输出 `n` 本身**：`dep < 2` 要跳过。
3. **循环从 1 开始**：会退化成全排列。

## 七 · 一句话总结
**组合类回溯的去重口诀：强制递增（`next >= last`），就不会有排列重复。**
