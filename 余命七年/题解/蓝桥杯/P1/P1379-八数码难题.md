# P1379 八数码难题

> 3×3 棋盘，0 表示空格，每次可与上下左右交换。给定初始局面，求到 `123804765` 的最少步数。

## 一 · 一句话题意
八数码最短路：状态是 9 位字符串，边是「空格与相邻格交换」。

## 二 · 解题逻辑
**先想什么**　每步代价 1 → BFS。状态数 $9!/2 = 181440$，可搜完。

**正解观察**　单向 BFS + `unordered_map<string,int>` 记距离；或者**双向 BFS**（从起点和终点同时搜，相遇即答案），状态少时差别不大，但双向是这类题的通用加速。

## 三 · 关键点
1. **状态用 string 存**，0 的位置决定能往哪走。
2. **按字符交换**：`swap(s[pos], s[npos])`。
3. **`unordered_map` 存距离**，同时当访问标记。
4. **起点等于终点直接 0**。
5. **双向 BFS** 时两个 map 相遇 `d1+d2` 取最小。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++（单向 BFS，够用）
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     string s; cin >> s;
>     string goal = "123804765";
>     if (s == goal) { puts("0"); return 0; }
>     unordered_map<string, int> dis;
>     queue<string> q; q.push(s); dis[s] = 0;
>     int dx[4] = {1,-1,0,0}, dy[4] = {0,0,1,-1};
>     while (!q.empty()) {
>         string u = q.front(); q.pop();
>         int d = dis[u];
>         int p = u.find('0'), x = p / 3, y = p % 3;
>         for (int k = 0; k < 4; k++) {
>             int nx = x + dx[k], ny = y + dy[k];
>             if (nx < 0 || nx > 2 || ny < 0 || ny > 2) continue;
>             string v = u;
>             swap(v[p], v[nx * 3 + ny]);
>             if (dis.count(v)) continue;
>             dis[v] = d + 1;
>             if (v == goal) { printf("%d\n", d + 1); return 0; }
>             q.push(v);
>         }
>     }
>     puts("-1");
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> from collections import deque
> s = sys.stdin.read().strip()
> goal = "123804765"
> if s == goal:
>     print(0); sys.exit()
> dis = {s: 0}
> q = deque([s])
> while q:
>     u = q.popleft(); d = dis[u]; p = u.index('0'); x, y = divmod(p, 3)
>     for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
>         nx, ny = x + dx, y + dy
>         if 0 <= nx < 3 and 0 <= ny < 3:
>             v = list(u); np = nx * 3 + ny
>             v[p], v[np] = v[np], v[p]; v = "".join(v)
>             if v in dis: continue
>             dis[v] = d + 1
>             if v == goal:
>                 print(d + 1); sys.exit()
>             q.append(v)
> ```

## 五 · 复杂度
状态 $9!/2 \approx 1.8\times10^5$，每状态 4 个转移；C++ 毫秒级，Python 约数秒（可换双向 BFS）。

## 六 · 易错点
1. **坐标算错**：`p/3, p%3`，别写成 `p%3, p/3`。
2. **swap 后忘还原字符串**：用副本 `v = u`。
3. **目标串写错**：`123804765`（0 在中间）。
4. **Python 单向 BFS 超时**：改双向 BFS 或 A*（曼哈顿距离启发）。

## 七 · 一句话总结
**八数码 = 字符串状态 BFS；`swap(0, 邻格)` 生成新状态，`unordered_map` 记距离，Python 建议双向。**
