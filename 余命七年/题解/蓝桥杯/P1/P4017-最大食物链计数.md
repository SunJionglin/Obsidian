# P4017 最大食物链计数

> $n \le 5000$ 个物种，$m \le 5\times10^5$ 条捕食关系（DAG）。求食物链条数（从生产者到最高消费者的路径数）mod 80112002。

## 一 · 一句话题意
DAG 上从所有入度 0 点到所有出度 0 点的路径条数。

## 二 · 解题逻辑
**先想什么**　「路径条数」+「有向无环」→ 拓扑序上做加法。

**正解观察**　`f[u]` = 到 u 的路径数；入度 0 的点 `f = 1`；转移 `f[v] += f[u]`；答案是所有**出度 0** 的 `f` 之和。

## 三 · 关键点
1. **入度 0 起点置 1**。
2. **出度 0 才是终点**，不是编号最大的。
3. **边算模**：`% 80112002`。
4. **拓扑保证先算完所有前驱**。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> const int MOD = 80112002;
> vector<int> g[5005];
> int indeg[5005], outdeg[5005], f[5005];
> int main() {
>     int n, m; scanf("%d %d", &n, &m);
>     for (int i = 0; i < m; i++) {
>         int a, b; scanf("%d %d", &a, &b);
>         g[a].push_back(b); indeg[b]++; outdeg[a]++;
>     }
>     queue<int> q;
>     for (int i = 1; i <= n; i++) if (!indeg[i]) { f[i] = 1; q.push(i); }
>     while (!q.empty()) {
>         int u = q.front(); q.pop();
>         for (int v : g[u]) {
>             f[v] = (f[v] + f[u]) % MOD;
>             if (--indeg[v] == 0) q.push(v);
>         }
>     }
>     long long ans = 0;
>     for (int i = 1; i <= n; i++) if (!outdeg[i]) ans = (ans + f[i]) % MOD;
>     printf("%lld\n", ans);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> from collections import deque
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     n, m = d[0], d[1]
>     g = [[] for _ in range(n+1)]
>     indeg = [0]*(n+1); outdeg = [0]*(n+1)
>     p = 2
>     for _ in range(m):
>         a, b = d[p], d[p+1]; p += 2
>         g[a].append(b); indeg[b] += 1; outdeg[a] += 1
>     MOD = 80112002
>     f = [0]*(n+1); q = deque()
>     for i in range(1, n+1):
>         if indeg[i] == 0: f[i] = 1; q.append(i)
>     while q:
>         u = q.popleft()
>         for v in g[u]:
>             f[v] = (f[v] + f[u]) % MOD
>             indeg[v] -= 1
>             if indeg[v] == 0: q.append(v)
>     print(sum(f[i] for i in range(1, n+1) if outdeg[i] == 0) % MOD)
> main()
> ```

## 五 · 复杂度
$O(n+m)$，$m=5\text{e}5$ 约 0.05s。

## 六 · 易错点
1. **答案取 `f[n]`**：终点是所有出度 0 的点。
2. **忘了取模**：路径数会爆 `int`。
3. **入度为 0 的点既没入度也没出度**（孤立点）：既是起点又是终点，会被计入 1——本题数据保证不出现，但要意识到。

## 七 · 一句话总结
**DAG 路径计数：入度 0 置 1、拓扑转移累加、答案是出度 0 的点之和，全程取模。**
