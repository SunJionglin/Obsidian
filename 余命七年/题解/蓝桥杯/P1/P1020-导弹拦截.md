# P1020 导弹拦截

> $n \le 10^5$，高度序列 $a_i$。求：① 最长**不上升**子序列长度；② 最少几套系统能全部拦截（= 最长**上升**子序列长度）。

## 一 · 一句话题意
第一问最长不升子序列；第二问覆盖全序列所需的最少不升子序列条数。

## 二 · 解题逻辑
**先想什么**　两个问题分别对应「最长不升子序列」与「最少链覆盖」。

**朴素解法**　$O(n^2)$ DP：`dp[i] = max(dp[j]) + 1`（$j<i$ 且 $a_j \ge a_i$）。

**正解观察**　
- ① 不升子序列长度：二分维护一个**降序**的「尾巴数组」，每次替换第一个 $\ge a_i$ 的位置。
- ② 由 **Dilworth 定理**：最少不升子序列条数 = 最长上升子序列长度。所以第二问等价于 LIS（严格上升）。

两个都是 $O(n\log n)$，用 `upper_bound` / `lower_bound` 实现。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| $O(n^2)$ DP | 1e10 | 必 TLE |
| 树状数组维护前缀最值 | $O(n\log n)$ | 能过但代码长 |
| **二分尾巴数组** | $O(n\log n)$ | 需要想清「替换哪个位置」 |

## 四 · 关键点
1. **第 1 问用 `upper_bound` 找第一个 $< a_i$ 的位置**（不升允许相等，所以替换相等元素之后）。
2. **第 2 问用 `lower_bound` 找第一个 $\ge a_i$ 的位置**（严格上升，相等不算）。
3. **尾巴数组的大小就是答案**，不需要记录路径。
4. **第 2 问的等价性**：这是 Dilworth 的「最小链覆盖 = 最长反链」。
5. **相等元素**：第 1 问允许相等，第 2 问不允许——这两个 `bound` 别混。

## 五 · 实现逻辑
第 1 问：维护降序数组 `d`，`pos = upper_bound(d.begin(), d.end(), a[i], greater<int>())` → 替换或追加。
第 2 问：维护升序数组 `u`，`pos = lower_bound(u, a[i])` → 替换或追加。

**手推**（`a = [5, 3, 4, 2, 1]`）：

| i | a | 第 1 问 d（不升） | 第 2 问 u（上升） |
| --- | --- | --- | --- |
| 1 | 5 | [5] | [5] |
| 2 | 3 | [5,3] | [3] |
| 3 | 4 | [5,4] | [3,4] |
| 4 | 2 | [5,4,2] | [2,4] |
| 5 | 1 | [5,4,2,1] | [1,4] |

答案：① 4，② 2。

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     vector<int> a;
>     int x;
>     while (scanf("%d", &x) == 1) a.push_back(x);
>     vector<int> d, u;
>     for (int v : a) {
>         auto p = upper_bound(d.begin(), d.end(), v, greater<int>());
>         if (p == d.end()) d.push_back(v); else *p = v;
>         auto q = lower_bound(u.begin(), u.end(), v);
>         if (q == u.end()) u.push_back(v); else *q = v;
>     }
>     printf("%d\n%d\n", (int)d.size(), (int)u.size());
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys, bisect
> def main():
>     a = list(map(int, sys.stdin.buffer.read().split()))
>     d, u = [], []
>     for v in a:
>         p = bisect.bisect_right([-x for x in d], -v)   # 代价高，见易错点 5
>         if p == len(d): d.append(v)
>         else: d[p] = v
>         q = bisect.bisect_left(u, v)
>         if q == len(u): u.append(v)
>         else: u[q] = v
>     print(len(d)); print(len(u))
> main()
> ```
> Python 里对「降序」二分不友好，推荐 `d` 存负数后按升序二分。

## 六 · 复杂度
时间 $O(n\log n)$，1e5 约 0.02s；空间 $O(n)$。

## 七 · 易错点
1. **`upper_bound` 与 `lower_bound` 用反**：第 1 问允许相等 → `upper_bound`（配 `greater`）；第 2 问严格上升 → `lower_bound`。
2. **忘了 `greater<int>()`**：默认升序，拿降序数组直接二分是错的。
3. **第 2 问写成 $O(n^2)$**：知道 Dilworth 但没实现 $O(n\log n)$，1e5 会炸。
4. **输入不定长**：`while (scanf == 1)`，别假设只有一个 $n$。
5. **Python 对降序二分的处理**：`bisect` 只支持升序，要么自己写，要么存负数。
