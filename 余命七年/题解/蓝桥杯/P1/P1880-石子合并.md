# P1880 石子合并

> 环形 $n \le 100$ 堆石子，每次合并相邻两堆，代价为两堆之和。求最小/最大总代价。

## 一 · 一句话题意
环形区间 DP：合并相邻区间，代价 = 区间和。

## 二 · 解题逻辑
**先想什么**　「最后一次合并」把区间拆成两段 → 区间 DP。

**正解观察**　环形→**拆链加倍**：把数组复制成 $2n$，只枚举长度 $\le n$ 的区间。
$$f[i][j] = \min_{i \le k < j}\{f[i][k] + f[k+1][j]\} + \text{sum}(i,j)$$
最大值同理换 `max`。

## 三 · 关键点
1. **拆链**：`a[i+n] = a[i]`，长度枚举到 $n$。
2. **按长度递增**：`len` 从 2 到 n，保证子区间已算。
3. **前缀和**：`sum(i,j)` 用前缀和 O(1)。
4. **答案**：在 `f[i][i+n-1]`（所有起点）里取 min/max。
5. **初值**：min 用大数，max 用 0。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int a[205], s[205], f[205][205], g[205][205];
> int main() {
>     int n; scanf("%d", &n);
>     for (int i = 1; i <= n; i++) { scanf("%d", &a[i]); a[i+n] = a[i]; }
>     for (int i = 1; i <= 2*n; i++) s[i] = s[i-1] + a[i];
>     memset(f, 0x3f, sizeof f);
>     for (int i = 1; i <= 2*n; i++) f[i][i] = 0;
>     for (int len = 2; len <= n; len++)
>         for (int i = 1; i + len - 1 <= 2*n; i++) {
>             int j = i + len - 1;
>             for (int k = i; k < j; k++) {
>                 f[i][j] = min(f[i][j], f[i][k] + f[k+1][j] + s[j] - s[i-1]);
>                 g[i][j] = max(g[i][j], g[i][k] + g[k+1][j] + s[j] - s[i-1]);
>             }
>         }
>     int mn = INT_MAX, mx = 0;
>     for (int i = 1; i <= n; i++) { mn = min(mn, f[i][i+n-1]); mx = max(mx, g[i][i+n-1]); }
>     printf("%d\n%d\n", mn, mx);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> def main():
>     d = list(map(int, sys.stdin.buffer.read().split()))
>     n = d[0]; a = [0] + d[1:1+n] * 2
>     m = 2 * n
>     s = [0] * (m + 1)
>     for i in range(1, m + 1): s[i] = s[i-1] + a[i]
>     INF = 10**18
>     f = [[0]*(m+1) for _ in range(m+1)]
>     g = [[0]*(m+1) for _ in range(m+1)]
>     for i in range(1, m+1):
>         for j in range(1, m+1):
>             f[i][j] = INF if i != j else 0
>     for L in range(2, n + 1):
>         for i in range(1, m - L + 2):
>             j = i + L - 1
>             for k in range(i, j):
>                 w = s[j] - s[i-1]
>                 f[i][j] = min(f[i][j], f[i][k] + f[k+1][j] + w)
>                 g[i][j] = max(g[i][j], g[i][k] + g[k+1][j] + w)
>     print(min(f[i][i+n-1] for i in range(1, n+1)))
>     print(max(g[i][i+n-1] for i in range(1, n+1)))
> main()
> ```

## 五 · 复杂度
$O(n^3)$，$n=100$ 约 1e6；空间 $O(n^2)$。

## 六 · 易错点
1. **忘了拆链**：不拆只能算线性，环形会错。
2. **长度枚举到 `2n`**：会算到不需要的区间，且答案取错。
3. **答案只取 `f[1][n]`**：环形要从所有起点取最值。
4. **min 初值 0**：不设大数会全 0。
