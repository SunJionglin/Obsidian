# P1541 乌龟棋

> 格子 $n \le 350$，$m$ 张牌（每张走 1/2/3/4 格），四种牌各不超过 40 张。求走到底的最大得分。

## 一 · 一句话题意
从 1 号格出发，依次打出所有牌，每到一个格子得分 `a[pos]`，最大化总得分。

## 二 · 解题逻辑
**先想什么**　题目给的是「打牌顺序」，但打牌顺序不影响**最终位置**——位置完全由「用了多少张 1/2/3/4」决定：
$$\text{pos} = 1 + c_1 + 2c_2 + 3c_3 + 4c_4$$

**朴素解法**　枚举 $m!$ 种出牌顺序：40! 级，不可能。

**正解观察**　状态只由四种牌的**用量**决定：`f[c1][c2][c3][c4]` = 用掉这些牌时的最大得分。转移：从四个前驱（少用一张某牌）取最大。

状态数 $41^4 \approx 2.8\times10^6$，每个 4 个转移，可过。

## 三 · 为什么选这个方法

| 方案 | 复杂度 | 缺点 |
| --- | --- | --- |
| 枚举排列 | $O(m!)$ | 不可能 |
| 状压（记录每张牌用没用） | $2^m$ | $m$ 可能 40+，爆炸 |
| **按用量计数 DP** | $O(41^4)$ | 思路要转一下 |

## 四 · 关键点
1. **位置由用量推出**，不用额外存位置维度。
2. **四维数组**：$41^4$ 个 int ≈ 11MB，可以开。
3. **边界**：`f[0][0][0][0] = a[1]`。
4. **转移**：四种牌各看一张是否可用，取 max。
5. **每种牌数量 ≤ 40**，但总数 $m$ 不一定是 40 的倍数。

## 五 · 实现逻辑
先统计四种牌各几张 → `f[0][0][0][0] = a[1]` → 四重循环按用量枚举 → 每个状态从四个「少一张」的前驱转移 → 输出 `f[cnt[1]][cnt[2]][cnt[3]][cnt[4]]`。

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int a[355], cnt[5];
> int f[42][42][42][42];
> int main() {
>     int n, m; scanf("%d %d", &n, &m);
>     for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
>     for (int i = 1; i <= m; i++) { int x; scanf("%d", &x); cnt[x]++; }
>     f[0][0][0][0] = a[1];
>     for (int c1 = 0; c1 <= cnt[1]; c1++)
>     for (int c2 = 0; c2 <= cnt[2]; c2++)
>     for (int c3 = 0; c3 <= cnt[3]; c3++)
>     for (int c4 = 0; c4 <= cnt[4]; c4++) {
>         int pos = 1 + c1 + 2 * c2 + 3 * c3 + 4 * c4;
>         int best = -1;
>         if (c1) best = max(best, f[c1-1][c2][c3][c4]);
>         if (c2) best = max(best, f[c1][c2-1][c3][c4]);
>         if (c3) best = max(best, f[c1][c2][c3-1][c4]);
>         if (c4) best = max(best, f[c1][c2][c3][c4-1]);
>         if (best >= 0 && !(c1==0&&c2==0&&c3==0&&c4==0)) f[c1][c2][c3][c4] = best + a[pos];
>     }
>     printf("%d\n", f[cnt[1]][cnt[2]][cnt[3]][cnt[4]]);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python（四维 list 慢，用 dict 或 numpy 不划算，慎用）

## 六 · 复杂度
时间 $O(\prod(c_i+1)) \le 41^4 \approx 2.8\text{e}6$，空间同上（C++ 可开）。

## 七 · 易错点
1. **把位置当维度**：状态会变成五维，直接爆内存。
2. **初值 `f[0][0][0][0]` 忘设**：第一个格子不加就少了起点分。
3. **`pos` 算错**：从 1 号格起算，`1 + c1 + 2c2 + 3c3 + 4c4`。
4. **四重循环上界写成 40**：要写 `cnt[1]`，牌不一定满 40 张。
5. **Python 用四维 list**：$41^4$ 个元素建表就超时，用 dict。
