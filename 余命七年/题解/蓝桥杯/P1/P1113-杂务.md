# P1113 杂务

> $n \le 10000$ 个任务，每个任务有耗时，且有前驱任务。求完成全部任务的最短时间（可并行）。

## 一 · 一句话题意
DAG 上的「最长路」：每个任务最早开始时间 = 所有前驱完成时间的最大值。

## 二 · 解题逻辑
**先想什么**　任务间是依赖关系 → 拓扑序；答案 = 所有任务完成时间的最大值。

**正解观察**　`f[v] = max(f[v], f[u] + cost[v])`，按拓扑序推进。等价于 DAG 上的最长路。

## 三 · 关键点
1. **先算所有前驱再算自己** → 拓扑。
2. **`f[u]` 初值 = 自身耗时**。
3. **答案取全局 max**，不是最后一个出队的。
4. **输入格式**：每个任务一行，读到自己编号的 0 结束。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> vector<int> g[10005];
> int cost[10005], f[10005], indeg[10005];
> int main() {
>     int n; scanf("%d", &n);
>     for (int i = 1; i <= n; i++) {
>         int id; scanf("%d %d", &id, &cost[i]);
>         int x;
>         while (scanf("%d", &x) == 1 && x) { g[x].push_back(i); indeg[i]++; }
>     }
>     queue<int> q;
>     for (int i = 1; i <= n; i++) if (!indeg[i]) { f[i] = cost[i]; q.push(i); }
>     int ans = 0;
>     while (!q.empty()) {
>         int u = q.front(); q.pop();
>         ans = max(ans, f[u]);
>         for (int v : g[u]) {
>             f[v] = max(f[v], f[u] + cost[v]);
>             if (--indeg[v] == 0) q.push(v);
>         }
>     }
>     printf("%d\n", ans);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> from collections import deque
> def main():
>     lines = sys.stdin.read().strip().split("\n")
>     n = int(lines[0])
>     g = [[] for _ in range(n+1)]
>     cost = [0]*(n+1); indeg = [0]*(n+1)
>     for line in lines[1:]:
>         p = list(map(int, line.split()))
>         i, cost[i] = p[0], p[1]
>         for x in p[2:]:
>             if x == 0: break
>             g[x].append(i); indeg[i] += 1
>     f = [0]*(n+1); q = deque()
>     for i in range(1, n+1):
>         if indeg[i] == 0: f[i] = cost[i]; q.append(i)
>     ans = 0
>     while q:
>         u = q.popleft(); ans = max(ans, f[u])
>         for v in g[u]:
>             f[v] = max(f[v], f[u] + cost[v])
>             indeg[v] -= 1
>             if indeg[v] == 0: q.append(v)
>     print(ans)
> main()
> ```

## 五 · 复杂度
$O(n + m)$。

## 六 · 易错点
1. **忘了初始化源点 `f = cost`**：全是 0。
2. **答案取 `f[n]`**：任务编号不代表拓扑顺序。
3. **读入格式**：每行不定长，遇到 0 结束。

## 七 · 一句话总结
**DAG 最长路 = 拓扑 + `f[v] = max(f[v], f[u]+cost[v])`，答案是全局 max。**
