# P1135 奇怪的电梯

> $n \le 200$ 层，第 $i$ 层按按钮只能上 $k_i$ 层或下 $k_i$ 层（不能出界）。从 $a$ 到 $b$ 最少按几次，达不到输出 $-1$。

## 一 · 一句话题意
每个楼层能到 $i\pm k_i$，边权全 1，求最短路。

## 二 · 解题逻辑
**先想什么**　状态是楼层，转移固定，每步代价 1 → BFS。

**正解观察**　把楼层当点、`i ↔ i±k_i` 当边建图（系数为 1 的无向边不成立，方向固定），BFS 从 $a$ 开始，`dis[b]` 或 -1。

## 三 · 关键点
1. **两个方向**：`i+k[i]` 与 `i-k[i]`，都要判 $1..n$。
2. **`dis` 初值 -1** 当访问标记。
3. **`a == b` 直接输出 0**。
4. **边权为 1**，所以 BFS 而不是 Dijkstra。

## 四 · 实现

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int k[205], dis[205];
> int main() {
>     int n, a, b; scanf("%d %d %d", &n, &a, &b);
>     for (int i = 1; i <= n; i++) scanf("%d", &k[i]);
>     memset(dis, -1, sizeof dis);
>     queue<int> q; q.push(a); dis[a] = 0;
>     while (!q.empty()) {
>         int u = q.front(); q.pop();
>         if (u == b) break;
>         for (int v : {u + k[u], u - k[u]}) {
>             if (v < 1 || v > n || dis[v] != -1) continue;
>             dis[v] = dis[u] + 1; q.push(v);
>         }
>     }
>     printf("%d\n", dis[b]);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> from collections import deque
> d = list(map(int, sys.stdin.buffer.read().split()))
> n, a, b = d[0], d[1], d[2]; k = [0] + d[3:3+n]
> dist = [-1]*(n+1); dist[a] = 0
> q = deque([a])
> while q:
>     u = q.popleft()
>     for v in (u + k[u], u - k[u]):
>         if 1 <= v <= n and dist[v] == -1:
>             dist[v] = dist[u] + 1; q.append(v)
> print(dist[b])
> ```

## 五 · 复杂度
$O(n)$ 点、$2n$ 边。

## 六 · 易错点
1. **只判了一边**：上/下两个方向都要。
2. **`k_i = 0`**：原地打转，BFS 里会被 `dis` 拦住。
3. **`n=1`**：起点即终点，输出 0。

## 七 · 一句话总结
**"每步代价 1" 就是 BFS 的信号：楼层当点、`i±k[i]` 当边、`dis=-1` 判可达。**
