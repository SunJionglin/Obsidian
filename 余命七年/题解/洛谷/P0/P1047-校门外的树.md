# 04. 校门外的树

## 一句话题意

读入 L 和 M 个区间 [u,v]，输出 0..L 上没被挖的树数。

## 解题逻辑

**先想什么**：读完题第一反应是「给每棵树记个状态」，用数组把被挖的标记掉，最后数一遍还站着的。

**朴素解法**：开 bool 数组 `tree[0..L]` 全为「在」，每个区间 [u,v] 用内层循环把 `tree[j]` 置为「挖」，最后统计还「在」的数量。时间 O(M×L)，最坏 100×10000 = 1e6，本题数据小（L≤1e4、M≤1e2）能过；但重叠区间会把同一棵树反复标记，全是浪费，L、M 各涨到 1e5 就变 1e10，直接超时。

**优化观察**：标记法慢在「区间里每个点都要动一下」。区间整体操作其实只关心每个点**被覆盖的次数**，于是让每次区间操作只改两个端点——`diff[u]++`、`diff[v+1]--`，一个区间 O(1)；最后从 0 扫到 L 做前缀和，还原出每点被盖几次，盖 0 次的就是活树。靠「端点记账 + 前缀和还原」把时间从 O(M×L) 降到 O(L+M)。本题朴素也够用，练差分是为 L、M 都大的题，这里正好当模板入门。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| bool 标记 | O(M×L) | O(L) | 重叠区间重复遍历，数据一大就超时 |
| 区间排序 + 合并 | O(M log M) | O(M) | 要排序还得写合并逻辑，端点细节容易漏 |
| 差分数组 | O(L+M) | O(L) | 多一个「前缀和还原」的概念要理解 |

**选差分**：区间操作「只改两端、前缀和还原」是区间覆盖/区间加的标准模板；本题数据小用它也不亏，正好把模板练熟。

## 关键点

1. 模板句：区间 [u,v] 整体操作 = `diff[u]++`、`diff[v+1]--`，最后前缀和一扫还原。
2. 不变量：`cover` 是走到 i 时被覆盖的层数，`cover == 0` 等价于「树还在」。
3. 边界约定：坐标 0..L 共 **L+1** 个点；diff 要开 **L+2**，因为 v = L 时要写 `diff[L+1]`。
4. 覆盖层数可以叠：两个区间重叠时 cover 会到 2，只要不是 0 就挖了，不用去重。

## 实现逻辑

四个动作顺序做：**读 L、M → 每个区间改两个端点 → 前缀和扫 0..L 数 cover==0 → 输出 cnt**。

拿 L=5、M=2、区间 [1,3] 和 [2,4] 手推：操作完 `diff = [0,1,1,0,-1,-1,0]`（下标 0..6），前缀和还原：

| i（循环变量） | 当前值 diff[i] | 查什么（cover 累加后） | 结果 cnt | 数据结构状态 cover |
| --- | --- | --- | --- | --- |
| 0 | 0 | 0，是 0 | 1 | 0 |
| 1 | 1 | 1，不是 | 1 | 1 |
| 2 | 1 | 2，不是（两区间重叠） | 1 | 2 |
| 3 | 0 | 2，不是 | 1 | 2 |
| 4 | -1 | 1，不是 | 1 | 1 |
| 5 | -1 | 0，是 0 | 2 | 0 |

6 棵被挖 4 棵，剩 0、5 两棵，答案 2。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <cstdio>
> using namespace std;
> 
> int main() {
>     int L, M;
>     scanf("%d %d", &L, &M);          // 路长 L，区间数 M
>     int diff[10002] = {0};           // L<=10000，v+1 最大 10001，开 10002 防越界
>     for (int k = 0; k < M; k++) {
>         int u, v;
>         scanf("%d %d", &u, &v);
>         diff[u]++;                   // u 起覆盖 +1
>         diff[v + 1]--;               // v+1 起覆盖 -1
>     }
>     int cover = 0, cnt = 0;
>     for (int i = 0; i <= L; i++) {
>         cover += diff[i];            // 前缀和 = 第 i 点被几个区间盖住
>         if (cover == 0) cnt++;       // 没被盖 = 树还在
>     }
>     printf("%d\n", cnt);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> def main():
>     data = sys.stdin.read().split()
>     L, M = int(data[0]), int(data[1])
>     diff = [0] * (L + 2)             # 多开一位，v+1 不越界
>     idx = 2
>     for _ in range(M):
>         u, v = int(data[idx]), int(data[idx + 1])
>         idx += 2
>         diff[u] += 1                 # u 起覆盖 +1
>         diff[v + 1] -= 1             # v+1 起覆盖 -1
>     cover, cnt = 0, 0
>     for i in range(L + 1):
>         cover += diff[i]             # 前缀和 = 被盖次数
>         if cover == 0:
>             cnt += 1                 # 没被盖 = 树还在
>     print(cnt)
> 
> main()
> ```

## 复杂度

- 时间：O(L+M)，M 个区间各改两个端点 O(1)，最后扫一遍 0..L 做前缀和。
- 空间：O(L)，diff 数组 L+2 个 int。

## 易错点

1. 点数差 1：L=10 表示 0..10 共 11 棵。循环若写成 `for i in range(L)`，输入 `10 0` 会输出 10，正解 11——要 `range(L+1)`。
2. diff 越界：L=5、区间 [5,5] 时要写 `diff[6]`，数组只开 L+1 就炸，开 L+2 最稳。
3. 别用「总棵数减去区间长度」偷懒：重叠区间会多减。L=5、[1,3] 和 [2,4]，6-3-3=0，实际剩 2。
4. 闭区间别写成左闭右开：[u,v] 两端都挖，`range(u, v)` 会漏掉 v 那棵。L=5、[1,3] 会漏挖 3 号树。
5. 读入顺序：先 L 后 M，写成 `scanf("%d %d", &M, &L)` 全错。
