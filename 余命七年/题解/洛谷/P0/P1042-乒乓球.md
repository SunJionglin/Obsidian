# 13. 乒乓球 P1042

## 一句话题意

读 W/L/E 字符流，按 11、21 分制输出每局比分，E 结束。

## 解题逻辑

**先想什么**：这是一道纯模拟题，两个信息先确认——一局结束的条件（某一方到 11/21 分**且**领先对手至少 2 分），以及输入跨多行、读到 `E` 才停。

**朴素解法**：边读边按 11 分制算。问题是输入要按两种分制各算一遍，读一遍输入没法同时算两套；而且跨行的字符串处理会把代码搅乱。O(n) 已经到这题的下限，朴素解法的问题不在复杂度，在「结构」。

**优化观察**：把 W/L 先收集成一整个字符串，再写一个参数化的 `solve(k)`，11 和 21 分制只是 `k` 不同——**同一个函数跑两遍**，读入一次、逻辑复用。复杂度没有下降空间（下界就是读一遍 O(n)），这里的「优化」是把代码从两套复制粘贴变成一次抽象。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 边读边按 11 分制算 | O(n) | O(1) | 21 分制还得再读一遍输入，代码两套、最后未结束的局难处理 |
| 全读进字符串，solve(k) 跑两遍 | O(n) | O(n) | 多存一个串，n 很小无所谓 |
| 读进数组/vector 再处理 | O(n) | O(n) | 和字符串方案等价，但字符拼接用 string 最顺手 |

**选它**：输入跨多行、还要按两种分制各算一遍，所以「先收串、再一个 `solve(k)` 跑两次」最顺——读入一次，模拟逻辑只写一遍。

## 关键点

1. 一局结束条件：`(w >= k || l >= k) && abs(w - l) >= 2`——**只到 k 分不算，必须领先 2 分**（10:10 之后要打到 12:10 才结束）。
2. 模板句：`solve(k)` 一个函数两用；循环里输出「已结束的局」，循环后**无条件**输出最后没打完的局（哪怕 0:0）。
3. 边界约定：读到 `E` 立刻停，`E` 本身不算分，`E` 之后的内容一律不看。
4. 跨行输入：`cin >> c` 自带跳空白，Python 用 `if c in ('W','L')` 过滤，换行空格天然不碍事。

## 实现逻辑

先**收串**（逐字符读 stdin，W/L 拼进 s，遇 E 停）→ 再**模拟**（对 k=11 跑 solve，逐字符加分，触发结束条件就输出并清零）→ 最后**补尾局**（循环结束无条件输出当前比分，空一行，对 k=21 重复）。

拿 `s = "WWWWWWWWWWWLWE"`（11 个 W、1 个 L、1 个 W）按 k=11 手推：

| 字符（第几个） | w | l | 触发结束? | 输出 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 第 1~10 个 W | 10 | 0 | 否 | — | 没到 11 分，继续 |
| 第 11 个 W | 11 | 0 | 是（≥11 且领先 2） | 11:0 | 输出后清零 |
| L | 0 | 1 | 否 | — | 新局 |
| W | 1 | 1 | 否 | — | 读完了，退出循环 |
| 循环后 | — | — | — | 1:1 | 无条件补最后一局 |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <iostream>
> #include <string>
> #include <cmath>    // abs
> using namespace std;
> 
> string s;           // 收集到的 W/L 序列（不含 E）
> 
> void solve(int k) {                 // k = 11 或 21，一个函数两用
>     int w = 0, l = 0;
>     for (char c : s) {
>         if (c == 'W') w++;
>         else l++;                   // 串里只有 W/L，else 就是 L
>         if ((w >= k || l >= k) && abs(w - l) >= 2) {  // 到 k 分且领先 ≥2
>             cout << w << ":" << l << "\n";
>             w = l = 0;              // 开新局
>         }
>     }
>     cout << w << ":" << l << "\n";  // 无条件输出最后没打完的局
> }
> 
> int main() {
>     ios::sync_with_stdio(false);
>     cin.tie(nullptr);
>     char c;
>     while (cin >> c && c != 'E') {  // >> 跳过空白，换行不影响
>         if (c == 'W' || c == 'L') s += c;
>     }
>     solve(11);
>     cout << "\n";                   // 两组结果之间空一行
>     solve(21);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> data = sys.stdin.read()
> s = ""
> for c in data:
>     if c == 'E':
>         break                 # E 之后一律不看
>     if c in ('W', 'L'):       # 换行、空格自动滤掉
>         s += c
> 
> def solve(k):                 # k = 11 或 21，一个函数两用
>     w = l = 0
>     lines = []
>     for c in s:
>         if c == 'W':
>             w += 1
>         else:                 # 串里只有 W/L
>             l += 1
>         if (w >= k or l >= k) and abs(w - l) >= 2:  # 到 k 分且领先 ≥2
>             lines.append(f"{w}:{l}")
>             w = l = 0         # 开新局
>     lines.append(f"{w}:{l}")  # 无条件输出最后没打完的局
>     return "\n".join(lines)
> 
> print(solve(11))
> print()                       # 两组结果之间空一行
> print(solve(21))
> ```

## 复杂度

- 时间：O(n)，收串读一遍、11 和 21 分制各扫一遍，共 3n 次单字符操作。
- 空间：O(n)，把 W/L 序列存成一个字符串（Python 再存一个 lines 列表，也是 O(n)）。

## 易错点

1. **漏了领先 2 分**：输入 `WWWWWWWWWWLLLLLLLLLLWWWE`（10W+10L+3W），11 分制第一局应输出 `12:10`（10:10 后又打了两个球）；只判 `w >= 11` 会在 11:10 就错误切局。
2. **只判领先不判到分**：输入 `WWWWWE`，w=2、l=0 领先 2 但没到 11 分，不应切局——正确输出只有一行 `5:0`。
3. **忘输出最后一局**：输入 `WE`，11 分制要输出 `1:0`；整局恰好打完时（如 `WWWWWWWWWWWE`，11 个 W）还要多输出一行 `0:0`，最后一局无条件打印。
4. **E 之后的内容别读**：输入 `WWLWELLL`，E 后面的 `LLL` 不算，11 分制只输出 `2:2`。
5. **输出格式**：两组结果之间必须空一行（样例 `11:0\n11:0\n1:1\n\n21:0\n2:1`）；这题逐字节比对，漏空行或多空格都 WA。
