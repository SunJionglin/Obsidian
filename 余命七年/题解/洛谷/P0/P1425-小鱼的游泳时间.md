# P1425 小鱼的游泳时间

## 一句话题意

读入开始 `a:b` 与结束 `c:d`（同一天），输出游了几小时几分钟。

## 解题逻辑

**先想什么**：时分是两套单位，第一反应「小时减小时、分钟减分钟」，但分钟可能不够减。

**朴素解法**：`h = c - a; m = d - b`，若 `m < 0` 就 `h--; m += 60` 借位。O(1)，速度没有任何问题——不够好的地方不是慢，而是**要写 if 借位分支，边角一多就容易漏**，比如结束分钟恰好 0、开始和结束同一小时。

**优化观察**：把两个时刻**统一换成「从 0:00 起的总分钟数」**再相减，借位由减法自动完成，if 分支直接消失。靠「统一单位」这个套路把易错点整个删掉，而不是降复杂度（本来就是 O(1)）。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 小时、分钟分别相减 + if 借位 | O(1) | O(1) | 借位分支要写对，`d<b`、`c==a` 等边界容易漏 |
| 直接输出 `c-a` 和 `d-b`（不借位） | O(1) | O(1) | `12:50→19:10` 会输出 `7 -40`，分钟是负数，直接错 |
| 统一成总分钟再相减 | O(1) | O(1) | 公式稍长，但没有任何分支 |

**选统一单位**：一行公式同时覆盖所有边界，没有 if 就没有漏判的可能；三个方案复杂度相同，比的纯粹是**谁不容易写错**。

## 关键点

1. 模板句：`总分钟 = (c*60 + d) - (a*60 + b)`。
2. 不变量：题目保证开始早于结束且在同一天，开始总分钟 < 结束总分钟，差一定 > 0。
3. 拆回时分：小时 = `总分钟 / 60`（整除），分钟 = `总分钟 % 60`（取余），分钟一定落在 `0..59`。
4. 边界约定：`c == a`（同一小时）或 `d == 0`（整点结束）时公式照常成立，不需要特判。

## 实现逻辑

先读入 4 个整数 → 再把开始、结束都换算成总分钟 → 再相减得到总分钟 → 最后 `/60`、`%60` 拆成时分输出。

拿样例 `12 50 19 10` 手推（本题无循环，按计算步骤推）：

| 步骤 | 表达式 | 当前值 | 做什么 | 结果 | 状态 |
| --- | --- | --- | --- | --- | --- |
| 1 | `a b c d` | 12 50 19 10 | 读入 | — | start=12:50，end=19:10 |
| 2 | `a*60+b` | 12×60+50 | 开始时刻总分钟 | 770 | — |
| 3 | `c*60+d` | 19×60+10 | 结束时刻总分钟 | 1150 | — |
| 4 | `1150-770` | — | 相减 | 380 | total=380 |
| 5 | `380/60`、`380%60` | — | 拆回时分 | 6 20 | 输出 `6 20` |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <iostream>
> using namespace std;
> 
> int main() {
>     int a, b, c, d;
>     cin >> a >> b >> c >> d;                          // 开始 a:b，结束 c:d
>     int total = (c * 60 + d) - (a * 60 + b);          // 统一换算成总分钟再相减
>     cout << total / 60 << " " << total % 60 << endl;  // 整除得小时，取余得分钟
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> def main():
>     a, b, c, d = map(int, sys.stdin.read().split())   # 读四个整数，按空格切开转 int
>     total = (c * 60 + d) - (a * 60 + b)               # 统一换算成总分钟再相减
>     print(total // 60, total % 60)                    # 整除得小时，取余得分钟
> 
> if __name__ == "__main__":
>     main()
> ```

## 复杂度

- 时间：O(1)，四则运算固定几趟，和输入无关。
- 空间：O(1)，只存 4 个输入加 1 个中间量。

## 易错点

1. 不借位直接输出 `c-a` 和 `d-b`：`12 50 19 10` 输出 `7 -40`，分钟成负数。借位必须显式写，或改用统一单位法绕开。
2. Python 用 `/` 不用 `//`：`12 50 19 10` 下 `380/60` 得 `6.333...`，输出变成浮点，格式错。整除必须 `//`。
3. 结束整点忘输出分钟位：`10 0 12 0` 要输出 `2 0`，`%60` 得 0 也得把第二个数打出来。
4. 单位混搭：写成 `(c*60+b) - (a*60+d)`，`12 50 19 10` 会得 460 分钟 → 错输出 `7 40`。时刻换算时「时×60+分」要一一对齐。
5. C++ 顺手把 `total/60` 写成 `total/60.0`：会变成浮点除法，输出 `6.33333`，格式不符。保持两个操作数都是 int。
