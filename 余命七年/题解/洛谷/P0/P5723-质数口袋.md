# P5723 质数口袋

## 一句话题意

输入 L，从 2 起装质数直到和超过 L，先输出装下的质数、再输出个数。

## 解题逻辑

**先想什么**：读完题抓住两个关键词「质数」和「装不下就停」。口袋只进不出、从小到大装，所以整道题就是一个**边判质数、边累加**的单循环，判定和装载一趟做完。

**朴素解法**：对每个自然数 n 从 2 除到 n-1 判质数，每判一个数最坏 O(n) 次除法；口袋循环要扫到最大候选（L=1e5 时约 1151），总复杂度 O(N²)≈百万次除法。本题数据小能过，但每个数平均白除了一半，纯浪费。

**优化观察**：①试除到 √n 就够——若 n 有因子 d>√n，必有配对因子 n/d<√n 在前面已经试到过，单次判断从 O(n) 降到 O(√n)。②质数严格递增，装不下 p 时后面更大的更装不下，直接 break，剩下的数一眼都不用看。③除 2 外的偶数都不是质数，循环步长可以只扫奇数（可选，本题非必需）。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 朴素试除（2..n-1） | O(N²) | O(1) | 每个候选最坏除到 n-1，平均白除一半 |
| 埃氏筛先打表 | O(M log log M) | O(M) | 要预估上界 M，L≤1e5 杀鸡用牛刀，多写一个筛 |
| 试除到 √n + 超载即停 | O(N√N) | O(1) | 几乎无 |

**选试除到 √n**：N 实际只有约 1150，√N≈34，总除法约 4 万次，零预处理、代码最短；筛法在这个数据量下是纯开销。而且「`i <= n/i` 判质数」是以后所有质数题的通用模板，顺手就把模板练了。

## 关键点

1. 模板句：`for (int i = 2; i <= n / i; ++i) if (n % i == 0) return false;`——用 `n / i` 代替 `i * i` 防溢出，i 从 2 开始天然把 1 挡在质数外。
2. 不变量：每次装入前先查 `sum + p > L`，所以口袋负载 sum 恒 ≤ L；质数严格递增，一旦装不下就 break，后面的质数不用再看。
3. 装载顺序：必须「先判装得下 → 再 push_back → 再 sum += i」，顺序反了口袋就超载。
4. 输出约定：题目要求**先逐行输出质数、最后输出个数**，所以质数要先收进 vector，不能边装边输出——个数要压轴。

## 实现逻辑

四个动作：**读 L → i 从 2 起循环判质数 → 装得下就 push_back 并 sum+=i、装不下 break → 先输出质数、最后输出 size()**。

拿 `L = 10` 手推一遍：

| i | 当前 sum | 查什么 | 结果 | 口袋（vector）状态 |
| --- | --- | --- | --- | --- |
| 2 | 0 | 2 是质数，0+2=2≤10 | 装入 | [2]，sum=2 |
| 3 | 2 | 3 是质数，2+3=5≤10 | 装入 | [2,3]，sum=5 |
| 4 | 5 | 2 能整除 4，不是质数 | 跳过 | [2,3]，sum=5 |
| 5 | 5 | 5 是质数，5+5=10≤10 | 装入 | [2,3,5]，sum=10 |
| 7 | 10 | 7 是质数，10+7=17>10 | break | [2,3,5]，sum=10 |

输出 2、3、5 各一行，最后一行 3。C++ 里 vector 当口袋，`push_back` 装入、`size()` 拿个数；Python 里 `list.append`、`len(bag)` 同一套。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <iostream>
> #include <vector>
> using namespace std;
>
> bool isPrime(int n) {                 // 试除法判质数
>     if (n < 2) return false;          // 1 不是质数
>     for (int i = 2; i <= n / i; ++i)  // 只除到 sqrt(n)，n/i 防 i*i 溢出
>         if (n % i == 0) return false;
>     return true;
> }
>
> int main() {
>     int L;
>     cin >> L;
>     vector<int> bag;                  // 口袋，收集装下的质数
>     int sum = 0;                      // 口袋当前负载
>     for (int i = 2; ; ++i) {          // 从 2 开始依次扫自然数
>         if (!isPrime(i)) continue;    // 不是质数直接下一个
>         if (sum + i > L) break;       // 装不下就停，后面更大的更装不下
>         bag.push_back(i);             // 装入
>         sum += i;
>     }
>     for (int p : bag) cout << p << '\n';  // 先逐行输出质数
>     cout << bag.size() << '\n';           // 最后输出个数
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
>
> def is_prime(n: int) -> bool:
>     if n < 2:
>         return False
>     i = 2
>     while i * i <= n:                 # 只除到 sqrt(n)
>         if n % i == 0:
>             return False
>         i += 1
>     return True
>
> def main():
>     L = int(sys.stdin.readline())
>     bag = []                          # 口袋，收集装下的质数
>     total = 0                         # 口袋当前负载
>     i = 2
>     while True:                       # 从 2 开始依次扫自然数
>         if is_prime(i):
>             if total + i > L:         # 装不下就停，后面更大的更装不下
>                 break
>             bag.append(i)             # 装入
>             total += i
>         i += 1
>     out = [str(p) for p in bag] + [str(len(bag))]  # 先质数、后个数
>     sys.stdout.write('\n'.join(out) + '\n')
>
> if __name__ == '__main__':
>     main()
> ```

## 复杂度

- 时间：O(N√N)，N 是扫到的最大自然数（L=1e5 时约 1151），每个候选试除到 √n，总约 4 万次除法。
- 空间：O(K)，K 是装下的质数个数，vector/list 只存输出；其余辅助变量 O(1)。

## 易错点

1. 输出顺序颠倒：题目要先输出质数、最后输出个数。`L = 10` 正确输出是 `2 3 5` 各一行、末行 `3`；先打 3 再打质数直接 WA，这是本题最大的坑。
2. 把 1 当质数装进去：循环若从 `i = 1` 开始且判质数没挡 `n < 2`，`L = 10` 会多输出一个 1（变成 1 2 3 5…）。`isPrime` 里 `n < 2` 返回 false 兜底。
3. 先装后查导致超载：写成「push_back 之后才 if (sum > L)」时，`L = 10` 会把 7 也装进去输出 2 3 5 7；正确是装之前查 `sum + p > L`。
4. 漏 break 死循环：`for(;;)` / `while True` 全靠 break 收尾。`L = 2` 时装下 2 后 3 装不下，没 break 会一路扫下去 TLE。
5. L=1 空口袋：一个都装不下，只输出一行 `0`；若代码假设袋子里至少有一个元素（如直接访问 bag[0]），会越界崩溃。

## 一句话总结
