# P1428 小鱼比可爱

## 一句话题意

读入 n 条鱼的可爱值，对每条鱼输出左边比它小的鱼有几条。

## 解题逻辑

**先想什么**：鱼头朝左 = 只看左边，位置天然有序，第 i 条鱼只和下标 `0..i-1` 比，第一反应就是双重循环。

**朴素解法**：外层 `i` 枚举每条鱼，内层 `j` 从 0 扫到 `i-1`，统计 `a[j] < a[i]` 的个数。O(n²)。本题 n ≤ 100，最多 100×99÷2 = 4950 次比较，朴素解法已经足够；它「不够好」的地方在于 n 一旦上 1e5，约 1e10 次比较必超时。

**优化观察**：真正关心的只是「值比我小」的个数，跟鱼的位置无关，是值域上的前缀统计。题给 0 ≤ a[i] ≤ 10，开一个桶 `freq[11]` 存各值的出现次数，对第 i 条鱼，答案 = `freq[0] + … + freq[a[i]-1]`（至多 11 次加法），再 `freq[a[i]]++`。一趟 O(11n) ≈ O(n)，靠「按值聚合计数」把逐条比较降成查桶。值域大时桶换成树状数组，O(n log V)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 双重循环 | O(n²) | O(n) | n 上 1e5 必超时 |
| 值域桶 freq[11] | O(11n) | O(11) | 依赖 a[i] ≤ 10 的小值域 |
| 树状数组（权值） | O(n log V) | O(V) | 代码长，入门题用不上 |

**选双重循环**：n ≤ 100 时 O(n²) 只要 4950 次比较，代码最短、最不容易写错，是这道入门题的标准解；桶和树状数组是「数据变大」的备胎，思路记下防手生。

## 关键点

1. 模板句：外层定鱼，内层只扫 `j < i` 的左边，严格小于 `a[j] < a[i]` 才计数。
2. 不变量：`cnt` 始终等于「a[0..i-1] 里小于 a[i] 的个数」；相等不算「不如自己」。
3. 边界约定：`i = 0` 时内层不执行，`cnt = 0`；n = 1 时直接输出一个 `0`。
4. 输出格式：n 个数空格分隔，行末不留多余空格（洛谷评测忽略，本地 diff 会挂）。

## 实现逻辑

四个动作：**读入 n 和数组 → 外层枚举每条鱼 → 内层扫左边数更小的 → 拼空格输出**。

拿样例 `6 / 4 3 0 5 1 2` 手推一遍：

| i | 当前值 a[i] | 查什么（j 范围） | 更小的值 | cnt | 输出状态 |
| --- | --- | --- | --- | --- | --- |
| 0 | 4 | 无 | — | 0 | 0 |
| 1 | 3 | a[0]=4 | 无 | 0 | 0 0 |
| 2 | 0 | a[0..1]=4,3 | 无 | 0 | 0 0 0 |
| 3 | 5 | a[0..2]=4,3,0 | 4,3,0 | 3 | 0 0 0 3 |
| 4 | 1 | a[0..3]=4,3,0,5 | 0 | 1 | 0 0 0 3 1 |
| 5 | 2 | a[0..4]=4,3,0,5,1 | 0,1 | 2 | 0 0 0 3 1 2 |

C++ 用 `vector<int>` 存数组、`cout` 拼空格；Python 用 `list` 存、`" ".join` 一次性输出。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <iostream>
> #include <vector>
> using namespace std;
> 
> int main() {
>     int n;
>     cin >> n;
>     vector<int> a(n);
>     for (int i = 0; i < n; i++) cin >> a[i];      // 读入每只鱼的可爱值
> 
>     for (int i = 0; i < n; i++) {
>         int cnt = 0;
>         for (int j = 0; j < i; j++)               // 只看左边的鱼
>             if (a[j] < a[i]) cnt++;               // 严格小于才计数
>         cout << cnt << (i == n - 1 ? '\n' : ' '); // 空格分隔，行末换行
>     }
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> def main():
>     data = sys.stdin.buffer.read().split()        # 一次性读入，按空白切
>     n = int(data[0])
>     a = [int(x) for x in data[1:1 + n]]           # 只取前 n 个可爱值
>     ans = []
>     for i in range(n):
>         cnt = 0
>         for j in range(i):                        # 只看左边的鱼
>             if a[j] < a[i]:                       # 严格小于才计数
>                 cnt += 1
>         ans.append(str(cnt))
>     sys.stdout.write(" ".join(ans))
> 
> main()
> ```

## 复杂度

- 时间：O(n²)，两重循环共 n(n-1)/2 次比较，n=100 时约 4950 次。
- 空间：O(n)，数组存 n 个可爱值，输出直接拼接。

## 易错点

1. 内层写 `j <= i` 会把自己算进去：输入 `2` / `2 2`，正确输出 `0 0`，写成 `j <= i` 输出 `0 1`。
2. 用 `<=` 计数：输入 `4` / `3 3 3 3`，正确输出 `0 0 0 0`，写成 `a[j] <= a[i]` 输出 `0 1 2 3`——相等不算「不如自己」。
3. C++ 开 `vector<int> a;` 不先 `resize(n)` 就 `a[i]` 写，越界：输入 `1` / `5` 直接 UB；要 `vector<int> a(n)` 或先 `resize`。
4. Python 读入用 `data[1:]` 全取，输入带多余空行会多读元素：用 `data[1:1+n]` 只取 n 个。
5. 边界 n=1：输入 `1` / `5` 输出 `0`，内层循环一次都不跑，`cnt` 必须是初值 0。
