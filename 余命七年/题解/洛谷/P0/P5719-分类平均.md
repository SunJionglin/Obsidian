# 14. P5719 【深基4.例3】分类平均

## 一句话题意

读入 n、k，把 1~n 按能否被 k 整除分成 A、B 两类，输出两类平均数（各 1 位小数，空格隔开）。

## 解题逻辑

**先想什么**：读完题第一反应就是「一趟扫描」，每个数判一次 `i % k == 0`，是 k 的倍数就进 A 组，否则进 B 组，边扫边把和与个数记下来。

**朴素解法**：开两组计数器 `sumA/cntA`、`sumB/cntB`，循环 `i = 1..n`，按 `i % k == 0` 分流累加，最后各算 `sum / cnt` 输出。O(n)，n 最大 1e4，一秒内完全无压力——这题的「不够好」不在时间，而在**粗心**：整数相除会截断、忘记保留一位小数才是真杀手。但若 n 涨到 1e9，挨个判整除就超时了。

**优化观察**：k 的倍数就是 `k, 2k, 3k, …, m·k`（m = n / k 向下取整），构成**等差数列**——A 类不用扫，直接 `sumA = k·m·(m+1)/2`、`cntA = m`；B 类用总和对冲，`sumB = n(n+1)/2 − sumA`、`cntB = n − m`。靠「把遍历换成等差数列求和公式」把时间从 O(n) 压到 O(1)。入门阶段练遍历版就够，公式版是「为什么还能更快」的答案。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 一趟遍历分类 | O(n) | O(1) | n 极大（1e9 级）时慢 |
| 等差数列公式 | O(1) | O(1) | 多记一条公式，m、余数容易绕晕，可读性差 |
| 建数组再筛两遍 | O(n) | O(n) | 白占一个数组的内存，完全没必要 |

**选一趟遍历**：n ≤ 1e4 时 O(n) 绰绰有余，写法最直白、和「分类」的定义一一对应，是入门题该练的标准形态；公式版记着思路，留给超大 n 的场景。

## 关键点

1. 模板句：`i % k == 0` 判倍数，真进 A、假进 B，两路各累加一组 `sum/cnt`。
2. 不变量：每轮循环结束时，`sumA/cntA` 是「已扫过的数里 k 的倍数」的和与个数，`sumB/cntB` 同理；循环结束二者即全集，相除就是平均数。
3. 边界约定：题目保证两类都非空，`cnt` 不会为 0；n 最大 1e4，总和最大约 5e7，`int` 装得下，但除法前必须转 `double`。
4. 输出格式：一行两个实数，各保留 1 位小数，中间一个空格——C++ 用 `printf("%.1f %.1f")`，Python 用 `f"{:.1f}"`。

## 实现逻辑

三个动作走完：**读 n、k → 循环 1~n 按 `i%k` 分流累加 → 两组的 sum 各除 cnt，保留 1 位小数输出**。

拿 `n = 5, k = 2` 手推一遍：

| 循环变量 i | 当前值 | 查什么 | 结果 | 数据结构状态（sum/cnt） |
| --- | --- | --- | --- | --- |
| 1 | 1 | 1%2==0？ | 否 → B | sumA=0 cntA=0；sumB=1 cntB=1 |
| 2 | 2 | 2%2==0？ | 是 → A | sumA=2 cntA=1；sumB=1 cntB=1 |
| 3 | 3 | 3%2==0？ | 否 → B | sumA=2 cntA=1；sumB=4 cntB=2 |
| 4 | 4 | 4%2==0？ | 是 → A | sumA=6 cntA=2；sumB=4 cntB=2 |
| 5 | 5 | 5%2==0？ | 否 → B | sumA=6 cntA=2；sumB=9 cntB=3 |

循环结束：A 类平均 `6/2 = 3.0`，B 类平均 `9/3 = 3.0`，输出一行 `3.0 3.0`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <cstdio>
> using namespace std;
> 
> int main() {
>     int n, k;
>     scanf("%d %d", &n, &k);
>     int sumA = 0, cntA = 0, sumB = 0, cntB = 0;
>     for (int i = 1; i <= n; i++) {
>         if (i % k == 0) { sumA += i; cntA++; }   // k 的倍数 -> A 类
>         else            { sumB += i; cntB++; }   // 其余 -> B 类
>     }
>     printf("%.1f %.1f\n", (double)sumA / cntA, (double)sumB / cntB);  // 转 double 再除，否则截断
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> def main():
>     n, k = map(int, sys.stdin.readline().split())
>     sum_a = cnt_a = sum_b = cnt_b = 0
>     for i in range(1, n + 1):
>         if i % k == 0:          # k 的倍数 -> A 类
>             sum_a += i
>             cnt_a += 1
>         else:                   # 其余 -> B 类
>             sum_b += i
>             cnt_b += 1
>     print(f"{sum_a / cnt_a:.1f} {sum_b / cnt_b:.1f}")   # / 天然浮点，:.1f 留一位
> 
> main()
> ```

## 复杂度

- 时间：O(n)，1 到 n 每个数只判一次 `%`、最多累加一次。
- 空间：O(1)，只有两组固定的 `sum/cnt` 变量，不随 n 增长。

## 易错点

1. 忘记保留 1 位小数：输入 `5 2`，正确输出 `3.0 3.0`；只打 `3 3` 会 WA。C++ 用 `printf("%.1f")`，Python 用 `f"{:.1f}"`。
2. C++ 整数相除截断：输入 `10 5`，A 类 `{5,10}` 平均是 `7.5`，但 `sumA / cntA` 两个 `int` 相除得到 `7`——必须先 `(double)` 转一下再除。
3. 类别判反：把 `i % k == 0` 分进 B 组，输出两个数就对调了，比如 `100 16` 会打成 `50.1 56.0`——两个数都在、肉眼很难发现，交之前先拿样例对位置。
4. 输出带多余内容：输入 `5 2` 输出 `A=3.0 B=3.0` 会 WA，评测机只要 `3.0 3.0` 这一行。
5. 除零兜底：题目保证两类都非空，但自己拿 `5 1` 测试时 B 类为空、`sumB / cntB` 直接崩；输出前判 `cnt > 0` 是防御写法。
