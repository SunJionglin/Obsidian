# 10. 数字反转（P1307）

## 一句话题意

输入一个整数 N，输出各位数字颠倒后的数，负号保留、去前导零。

## 解题逻辑

**先想什么**：数字反转就是「低位变高位、高位变低位」，第一反应是把它当成字符串翻转。

**朴素解法**：读成字符串，负号单独摘出来，剩下的字符 reverse，再剥掉前导零拼回数字。O(d) 时间、O(d) 空间。不够好——负号放哪、全是 0 时剥完变空串、前导零剥不干净，分支一堆，纯属绕路。

**优化观察**：反转本质是「不断把个位搬到一个新数的末尾」——`ans = ans * 10 + n % 10`。这个式子里负号和前导零**全自动处理**（C++ 负数整除、取模都向零截断；ans 从 0 起步，个位是 0 乘进去也不留尾巴）。时间同为 O(d)，空间从 O(d) 降到 O(1)，还省掉一堆特判。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 数字拆位（选） | O(d) | O(1) | Python 负数要先转正再翻 |
| 字符串反转 | O(d) | O(d) | 负号、前导零、全零串都要特判 |
| 逐位倒序打印 | O(d) | O(1) | 1200 会打成 0021，负数打成 0-8-3，最后还得拼数 |

**选数字拆位**：一行核心循环，负号和前导零零特判，空间 O(1)，是这题最干净的标准写法。

## 关键点

1. 模板句：`while (n) { ans = ans * 10 + n % 10; n /= 10; }`，个位乘十累加就是反转。
2. 不变量：每轮循环结束时，`ans` 是「已摘掉的低位们的反转」，`n` 是「还没处理的数」；n 缩到 0 循环结束。
3. 边界约定：n == 0 不进循环，ans 保持 0，输出 0，不用特判。
4. 负数语义：C++ 整除、取模都向零截断，负号自动跟着走；Python 是向下取整，必须先 `abs` 转正、最后补负号。

## 实现逻辑

三步：**读入 → 循环摘个位拼数 → 输出**。循环里每次两件事，取个位 `n % 10`、丢个位 `n /= 10`。

拿 `n = -380` 手推一遍：

| 轮次 | n（当前值） | n % 10（取个位） | ans（结果） | 说明 |
| --- | --- | --- | --- | --- |
| 1 | -380 | 0 | 0 | 个位 0 乘进 ans 不动，前导零自动消 |
| 2 | -38 | -8 | -8 | 负号跟着个位一起进 ans |
| 3 | -3 | -3 | -83 | -8 × 10 + (-3) |
| 结束 | 0 | — | -83 | n 为 0 退出循环，输出 -83 |

（这题没有额外数据结构，`ans` 自己就是全部状态。）

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <cstdio>
> 
> int main() {
>     int n;
>     scanf("%d", &n);
>     int ans = 0;
>     while (n != 0) {             // n 为 0 时不进循环，直接输出 0
>         ans = ans * 10 + n % 10; // 个位接到 ans 末尾，前导零自动消
>         n /= 10;                 // 丢掉个位；向零截断，负号跟着走
>     }
>     printf("%d\n", ans);
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> n = int(sys.stdin.read().strip())
> neg = n < 0
> n = abs(n)                    # Python 负数 // % 语义不同，先转正
> ans = 0
> while n:
>     ans = ans * 10 + n % 10   # 个位接到末尾，前导零自动消
>     n //= 10
> print(-ans if neg else ans)
> ```

## 复杂度

- 时间：O(d)，d 是 N 的位数（这题最多 10 位），每位循环 O(1)。
- 空间：O(1)，只用一个 ans 变量，不建任何数组或字符串。

## 易错点

1. 输入 `0`：`while (n)` 直接跳过，ans 保持 0，输出 0，天然正确；别加多余的「0 特判分支」，字符串法里更别把 `'0'` 剥成空串再 `int`。
2. 输入 `-380`：Python 直接套 C++ 模板会翻车，`-38 % 10 = 2`、`-38 // 10 = -4`，到 n = -1 时 `-1 // 10` 还是 -1，直接死循环；必须先 `abs`、最后补负号。
3. 输入 `1230`：期望 321。不要先「去末尾 0」再翻，`ans` 从 0 起步，个位 0 乘进去自然不留尾巴；乱特判容易把 `100 → 1` 也搞坏。
4. 输入 `1000000000`：反转得 1。反转后的数最大不超过 1e9，`int` 装得下；心里没底就直接 `long long`（`%lld`），不亏。
5. 输入 `-380`（逐位打印的写法）：`while (n) { cout << n % 10; n /= 10; }` 会打出 `0-8-3`，必须拼成数再输出。
