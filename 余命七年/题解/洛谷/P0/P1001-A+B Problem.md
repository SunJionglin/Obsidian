# P1001 A+B Problem

## 一句话题意

输入两个以空格分隔的整数 a、b，输出 a+b。

## 解题逻辑

**先想什么**：读完题只有三件事——把两个数读进来、加起来、原样输出；没有循环没有搜索，唯一要先确认的是数据范围（|a|,|b| ≤ 10⁹），它决定变量类型。

**朴素解法**：开两个变量，读入后直接输出 a+b。时间 O(1)、空间 O(1)。这题朴素解法就是最优解，没有可优化的量级；真正的隐患在类型——和最大 2×10⁹，已经贴着 int 上限 2147483647。

**优化观察**：复杂度没有可降的空间，「优化」落在两处零成本细节上：类型用 long long（Python 的 int 天然无上限）让溢出从可能变成不可能；输出不带任何多余字符，因为洛谷的评测机会把提示语之类的内容判成 WA。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 读入相加（int） | O(1) | O(1) | 和最大 2×10⁹，离 int 上限只剩约 1.4×10⁸ 余量，数据稍放宽就溢出 |
| 读入相加（long long） | O(1) | O(1) | 比 int 多占 4 字节，代价可以忽略 |
| 字符串逐位模拟（高精度加法） | O(位数) | O(位数) | 这题范围根本用不到，代码又长又容易写错 |

**选 long long 直接相加**：代码最短、零成本杜绝溢出；高精度是留给超出 64 位范围的题目的，这里上它纯属绕路。

## 关键点

1. 模板句：`scanf("%lld %lld", &a, &b); printf("%lld\n", a + b);`——读、算、输出各一行，中间没有任何分支和循环。
2. 不变量：全程只有一次算术 a+b，类型从头到尾是 long long，不存在中途窄化。
3. 边界约定：a、b 可以为负，%lld 和 int() 都会自动解析负号，不用写正负判断；和的范围是 [-2×10⁹, 2×10⁹]。
4. 洛谷约定：main 必须是 int 类型且正常结束返回 0；输出除了结果本身不能有任何多余内容，提示语也算 WA。

## 实现逻辑

先声明两个 long long 变量 → 再用 scanf 从 stdin 一次读入两个整数 → 最后直接 printf 输出 a+b 并换行。

拿 a=1、b=2 手推一遍：

| 步骤 | a | b | 做什么 | 结果 |
| --- | --- | --- | --- | --- |
| 声明 | 未初始化 | 未初始化 | `long long a, b;` | 占 16 字节 |
| 读入 | 1 | 2 | `scanf("%lld %lld", &a, &b)` | a=1, b=2 |
| 计算 | 1 | 2 | 求 `a + b` | 3 |
| 输出 | 1 | 2 | `printf("%lld\n", a + b)` | stdout 打出 `3` |

C++ 里 scanf 会自动跳过空白符，输入多几个空格也不影响；Python 里 `input().split()` 按空白切分，`map(int, ...)` 把每个片段转成 int。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <cstdio>
>
> int main() {
>     long long a, b;                 // 和最大 2e9，贴着 int 上限，直接用 long long
>     scanf("%lld %lld", &a, &b);     // 从 stdin 读两个整数，%lld 对应 long long
>     printf("%lld\n", a + b);        // 输出和，行尾带换行
>     return 0;                       // main 必须是 int 类型，正常结束返回 0
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
>
> def main():
>     a, b = map(int, sys.stdin.readline().split())   # 读一行，按空白切成两段再转 int
>     sys.stdout.write(str(a + b) + "\n")             # 输出和并换行；Python 的 int 无上限
>
> if __name__ == "__main__":
>     main()
> ```

## 复杂度

- 时间：O(1)，读入、相加、输出各做一次，与数据无关。
- 空间：O(1)，只开两个变量。

## 易错点

1. 输出提示语直接 WA：样例「1 2」只能输出 `3`；输出「请输入两个数：3」这类内容，评测机判 Wrong Answer。
2. int 贴线：样例「1000000000 1000000000」→ 2000000000，int 装得下（上限 2147483647），但余量只剩约 1.4×10⁸，数据范围一放宽就溢出——直接用 long long。
3. 负数不用特判：样例「-5 3」→ -2，scanf 的 %lld 会自动解析负号，别自己写「谁大谁小」的判断。
4. C++ 格式符配错类型：a、b 是 long long 却写 `scanf("%d %d", &a, &b)`，只写入低 4 字节，高 4 字节留垃圾值，大数必错。
5. Python 忘 split：`map(int, input())` 对输入「1 2」会拿整个串去转 int，抛 ValueError——必须先 `.split()`。
