# P5721 数字直角三角形

## 一句话题意

输入 n，从 1 开始按两位补零格式输出边长为 n 的数字直角三角形。

## 解题逻辑

**先想什么**：读完题第一反应是「三角形」——行数逐行递减，每行数字个数跟着行号走，典型的双层 for；行内数字要接着上一行走，所以必须有一个**跨行共享的计数器**。

**朴素解法**：外层 `i` 从 n 到 1 控制行，内层 `j` 从 0 到 `i-1`，每次 `printf("%02d", num++)` 输出一个数。时间 O(n²)（总共输出 n(n+1)/2 个数），空间 O(1)。这题朴素解法就够——**输出量本身就是 O(n²)，任何算法都不可能低于它**。

**优化观察**：这题没有可降的时间复杂度，下界就是输出本身，n(n+1)/2 个数字一个都省不掉。真正要防的是 Python 里逐个数 `print(x, end='')` 的写法——函数调用翻倍、还容易忘了行尾换行；改用列表推导把一行拼成字符串再一次 `print`，常数更快、结构更清楚。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 逐个数 print，行尾手动判断换行 | O(n²) | O(1) | Python 里调用次数多、易漏换行 |
| 拼成整行字符串再输出 | O(n²) | O(n) | 多一行临时字符串，小题大做 |
| 双层 for + %02d 直接输出 | O(n²) | O(1) | 无，标准写法 |

**选双层 for + %02d**：输出 n(n+1)/2 个数是硬性下界，双循环是唯一结构；补零交给 `%02d` / f-string 的 `:02d`，一句搞定，代码最短。

## 关键点

1. 模板句：外层 `i` 从 n 到 1，内层循环 `i` 次，计数器 `num` 只在循环外声明一次、只增不减。
2. 不变量：每行输出前 `num` 恒等于「已输出的数字个数 + 1」，即第 i 行第一个数 = 前面 (n)+(n-1)+…+(i+1) 个数的总数再加 1。
3. 格式约定：`%02d` 不足两位补前导 0，超过两位（n≥14 时出现 100 等）照常输出。
4. 边界：n=1 时只输出一行 `01`。

## 实现逻辑

三个动作：**读 n → 外层 i 从 n 降到 1 → 内层循环 i 次每次输出 num++（补零两位）**，内层结束换一行。

拿 `n = 3` 手推一遍：

| 行 i | 内层次数 | 本行输出的 num | 行末 num | 本行输出 |
| --- | --- | --- | --- | --- |
| 3 | 3 | 1, 2, 3 | 4 | 010203 |
| 2 | 2 | 4, 5 | 6 | 0405 |
| 1 | 1 | 6 | 7 | 06 |

C++ 里 `printf("%02d", num++)` 一次完成补零和自增；Python 里用 `f'{num + j:02d}'`，`j` 从 0 走到 `i-1`，一行拼完再 `num += i`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <cstdio>
> 
> int main() {
>     int n;
>     scanf("%d", &n);                          // 读入直角边长度
>     int num = 1;                              // 计数器，跨行递增
>     for (int i = n; i >= 1; --i) {            // 第 i 行有 i 个数
>         for (int j = 0; j < i; ++j) {
>             printf("%02d", num++);            // 补零两位，输出后自增
>         }
>         printf("\n");                         // 一行结束换行
>     }
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> def main():
>     n = int(sys.stdin.readline())             # 读直角边长度
>     num = 1                                   # 计数器，跨行递增
>     for i in range(n, 0, -1):                 # 第 i 行有 i 个数
>         print(''.join(f'{num + j:02d}' for j in range(i)))
>         num += i                              # 计数器跳过本行 i 个数
> 
> if __name__ == '__main__':
>     main()
> ```

## 复杂度

- 时间：O(n²)，总共输出 n(n+1)/2 个数，每个数常数时间。
- 空间：O(1)，只用一个计数器；Python 版拼行会临时占一行 O(n) 的字符串。

## 易错点

1. 每行重新从 1 开始数：`n = 3` 输出成 `010203 / 0102 / 01`（错），正确是 `010203 / 0405 / 06`——`num` 必须声明在两层循环**外面**。
2. 忘补零：`n = 2` 正确输出 `0102` 换行 `03`；只写 `cout << num` 会得到 `12 / 3`，前导 0 没了。
3. 内层边界：写成 `j <= i` 时 `n = 2` 会输出 3 个数字（`010203 / 04`），比 n(n+1)/2 多一个，判错。
4. Python 逐个数 `print(x, end='')` 忘换行：`n = 2` 全挤在一行 `010203`；要么内层结束补 `print()`，要么像代码里拼一整行一次 print。
5. n=1 边界：外层写成 `i >= 0` 会多跑一轮 `i=0` 输出一个空行（或一个多余数字）；循环条件记准是 `i >= 1` / `range(n, 0, -1)`。
