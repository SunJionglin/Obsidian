# 15. 一尺之棰（P5720）

## 一句话题意

读入正整数 `a`，每天减半向下取整，输出木棍长度变为 `1` 的那一天。

## 解题逻辑

**先想什么**：题面就是「日取其半」的照字面模拟，第一反应直接 while 循环减半、数天数。

**朴素解法**：`days = 1` 起步，`while (a > 1)` 里 `a /= 2`、`days++`。O(log a)，a ≤ 1e9 时最多约 30 轮——这题的朴素解就是标准解，**没有超时风险**，不存在「不够好」。

**优化观察**：若硬要 O(1)，天数 = ⌊log₂a⌋ + 1，用 `cmath` 的 `log2` 加 `floor` 一步算。但浮点精度在 2^k 边界（如 a = 2³⁰）容易差一天，入门题绕这个远路纯属自找麻烦。**这题的关键观察反而是「别优化」：模拟已经到头，整数除法天然完成向下取整。**

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| while 模拟减半 | O(log a) | O(1) | 无，本题标准解 |
| 对数公式 ⌊log₂a⌋+1 | O(1) | O(1) | 浮点误差，2^k 边界易差一天，不直观 |
| 位移 `a >>= 1` | O(log a) | O(1) | 与 `/2` 等价但可读性差，仅正数安全 |

**选模拟**：最多 30 轮快如闪电，循环结构与「日取其半」一一对应，向下取整靠整数除法天然成立，是最不容易错、最能直译题面的写法。

## 关键点

1. **天数从 1 起**：第 1 天木棍长度就是 `a`，所以 `days = 1`（`a = 1` 时直接输出 1）。
2. **循环条件是 `a > 1`**：长度变 1 当天就停，写成 `a >= 1` 会多锯一刀。
3. 减半用**整数除法**：C++ 正数用 `/`，Python 用 `//`，都向下取整，不用管四舍五入。
4. a ≤ 1e9 < 2³¹−1，`int` 装得下；每轮只变小，不存在溢出。

## 实现逻辑

先读入 `a` → 初始化 `days = 1` → 循环里 `a /= 2`、`days++` → 输出 `days`。

拿 `a = 100` 手推一遍（答案 7）：

| 天数 days | 长度 a | 判断 a > 1 | 动作 | a 变多少 |
| --- | --- | --- | --- | --- |
| 1 | 100 | 是 | 减半 | 50 |
| 2 | 50 | 是 | 减半 | 25 |
| 3 | 25 | 是 | 减半 | 12 |
| 4 | 12 | 是 | 减半 | 6 |
| 5 | 6 | 是 | 减半 | 3 |
| 6 | 3 | 是 | 减半 | 1 |
| 7 | 1 | 否 | 循环结束 | 输出 7 |

注意 25 → 12：25/2 = 12.5，向下取整为 12，恰好验证了「锯掉一半」是整数除法。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <iostream>
> using namespace std;
> 
> int main() {
>     int a;
>     cin >> a;
>     int days = 1;                    // 第 1 天长度就是 a
>     while (a > 1) {                  // 长度还没变 1 就继续锯
>         a /= 2;                      // 减半；正数整数除法向下取整
>         days++;
>     }
>     cout << days << endl;
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> def main():
>     a = int(sys.stdin.readline())
>     days = 1                         # 第 1 天长度就是 a
>     while a > 1:                     # 长度还没变 1 就继续锯
>         a //= 2                      # 减半；// 向下取整
>         days += 1
>     print(days)
> 
> if __name__ == "__main__":
>     main()
> ```

## 复杂度

- 时间：O(log a)，每轮长度减半，a = 1e9 时最多约 30 轮循环。
- 空间：O(1)，全程只有 `a` 和 `days` 两个变量。

## 易错点

1. `days` 从 0 起：输入 `1` 应输出 `1`，从 0 数会输出 `0`。
2. 条件写成 `a >= 1`：输入 `1` 时多锯一刀，`a` 变 0、输出 `2`，错。
3. Python 用 `/` 不用 `//`：输入 `100` 时 `a` 变 `50.0 → 25.0 → 12.5 …`，浮点一路锯到 0.78 才停，输出 `8` 而不是 `7`。
4. 把「第几天」当成「锯了几刀」：输入 `100` 共锯 6 刀，但长度变 1 发生在**第 7 天**，要输出 7 不是 6。
5. 给 `a = 1` 加特判：while 天然不进入、直接输出 1，特判是多余的，写上反而多一个出错点。
