# P5736 质数筛

## 一句话题意

读入 n 个整数，按原顺序筛掉合数，输出剩余质数，空格分隔。

## 解题逻辑

**先想什么**：题目说「存进数组、去掉非质数」——本质就是对每个数判一次「是不是质数」，数组不用真的删元素，**边读边判边输出**就行。

**朴素解法**：对每个 x 从 2 试除到 x-1，中途整除就是合数。O(n·M)，n=100、M=1e5 时最坏 1e7 次，这题勉强能过，但每个数都白跑了 √x 到 x 一大段，M 一涨就废。

**优化观察**：合数 x 必有因子对 a·b（a ≤ b），且 a ≤ √x。所以试除到 √x 还没找到因子，后面就再也不会有了——每个数从 O(M) 降到 O(√M)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 试除到 x-1 | O(n·M) | O(1) | 最坏 1e7 次，白跑 √x 之后的一段 |
| 试除到 √x | O(n·√M) | O(1) | 无，n 只有 100 绰绰有余 |
| 埃氏筛预处理 | O(M log log M) | O(M) | 多开 1e5 的 bool 数组，n 这么小杀鸡用牛刀 |

**选试除到 √x**：总运算约 100×316 次，瞬间跑完；空间只要存输入的数组，代码最短。筛法留给「查询次数多、M 更大」的题。

## 关键点

1. 判定模板：先挡 `x < 2`（1 不是质数），再 `for (i = 2; i*i <= x; i++)` 试除。
2. 边界约定：题目 aᵢ ≥ 1，**1 必须被筛掉**，这是本题最容易漏的边界。
3. 不变量：循环中途没有整除返回，说明 2..√x 都除不尽 x，x 必为质数。
4. 循环条件用 `i*i <= x` 不用 `sqrt(x)`，避开浮点误差（见易错点 2）。

## 实现逻辑

四个动作顺序做：**读 n → 循环读每个数 → isPrime 判定 → 是质数就输出（第一个前不打空格）**。

拿输入 `1 4 9 5` 手推一遍（n=4，期望只输出 5）：

| 循环变量 k | 当前值 x | 查什么 | 结果 | 输出状态 |
| --- | --- | --- | --- | --- |
| 0 | 1 | x < 2 直接 false | 非质数 | 不输出 |
| 1 | 4 | i=2，4%2==0 | 非质数 | 不输出 |
| 2 | 9 | i=2 不行，i=3，9%3==0 | 非质数 | 不输出 |
| 3 | 5 | i=2 不行，i=3 时 9>5 停 | 质数 | 输出 "5" |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <iostream>
> using namespace std;
> 
> bool isPrime(int x) {
>     if (x < 2) return false;           // 0 和 1 不是质数
>     for (int i = 2; i * i <= x; ++i)   // 有因子必成对，只需试到 sqrt(x)
>         if (x % i == 0) return false;
>     return true;
> }
> 
> int main() {
>     int n;
>     cin >> n;
>     bool first = true;                 // 控制空格：质数之间空格，行尾不留
>     for (int k = 0; k < n; ++k) {
>         int x;
>         cin >> x;
>         if (isPrime(x)) {
>             if (!first) cout << ' ';
>             cout << x;
>             first = false;
>         }
>     }
>     cout << endl;
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> def is_prime(x: int) -> bool:
>     if x < 2:
>         return False                    # 0 和 1 不是质数
>     i = 2
>     while i * i <= x:                   # 有因子必成对，只需试到 sqrt(x)
>         if x % i == 0:
>             return False
>         i += 1
>     return True
> 
> def main() -> None:
>     data = sys.stdin.read().split()     # 一次读完，按空白切
>     n = int(data[0])
>     res = []
>     for j in range(1, n + 1):           # 从 1 开始，data[0] 是 n 不是数
>         x = int(data[j])
>         if is_prime(x):
>             res.append(str(x))
>     sys.stdout.write(" ".join(res))     # join 天然不带行尾多余空格
> 
> if __name__ == "__main__":
>     main()
> ```

## 复杂度

- 时间：O(n·√M)，n 个数每个最多试除 √M 次，M ≤ 1e5 时约 3e5 次运算。
- 空间：O(n)，只存输入的数组；除输入外辅助空间 O(1)。

## 易错点

1. **1 不是质数**：输入 `1\n1`，漏判 `x < 2` 会把 1 当质数输出。正确输出是空行。
2. **别用 `sqrt` 定边界**：`i <= sqrt(x)` 有浮点误差，x=49 时 sqrt 可能算成 6.9999，i=7 试不到，49 被误判质数。输入 `1\n49` 应无输出，用 `i*i <= x` 彻底避开。
3. **循环条件写成 `i < x`**：逻辑没错但每个数白跑 O(x) 而不是 O(√x)，M 一大就 TLE。
4. **Python 下标错位**：`data[0]` 是 n 不是数。输入 `3\n2 3 5`，若从 `data[0]` 开始判，会多判一个「3」；要从 `data[1]` 取到 `data[n]`。
