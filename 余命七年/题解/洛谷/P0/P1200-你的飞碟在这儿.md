# P1200 [USACO1.1] 你的飞碟在这儿 Your Ride Is Here

## 一句话题意

读两行大写字母串，各自按 A=1…Z=26 连乘对 47 取模，余数相等输出 GO，否则 STAY。

## 解题逻辑

**先想什么**：两串彼此独立，各算一个「特征值」再比大小即可；一看到「连乘」就要先想会不会溢出。

**朴素解法**：把字母映射成数字后一口气连乘，最后再 `% 47`。时间 O(n)，本题长度 ≤6，26⁶ ≈ 3.1e8 刚好塞进 int，朴素解在本题能过——但正确性押在「长度 ≤6」上，长度放开到 8（26⁸ ≈ 2.1e11）int 直接溢出，答案全错。

**优化观察**：模运算满足 (a×b) mod m = ((a mod m)×(b mod m)) mod m，所以**每乘一个字母就取一次模**，中间值永远小于 47×26 ≈ 1222。复杂度没变，但正确性从此和输入长度无关，不再碰运气。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 先全部乘完再 %47 | O(n) | O(1) | 长度放开就溢出，正确性依赖数据范围 |
| 边乘边 %47 | O(n) | O(1) | 每个字符多一次取模，代价可忽略 |
| Python 大整数硬乘 | O(n) | O(1) | 靠语言特性，C++ 里写不了 |

**选边乘边取模**：时间和空间都没有变差，多写一个 `%` 就把溢出隐患连根拔掉，是「求积 + 取模」类题的固定姿势。

## 关键点

1. 映射模板句：`c - 'A' + 1`（Python 里 `ord(c) - ord('A') + 1`），A=1…Z=26，**别漏掉 +1**。
2. 不变量：`ret` 每步之后都在 [0, 47)，即 `ret` = 当前前缀乘积 mod 47。
3. 模可搬运：(a×b) mod m = ((a mod m)×(b mod m)) mod m，取模可以搬进循环、随乘随模。
4. 边界约定：`ret` 初值是 **1**（乘法单位元）；输入保证 1~6 个大写字母、无空格，但读行养成 strip 的习惯。

## 实现逻辑

三个动作顺序走：**读两串 → 各自随乘随模 → 比余数出结果**。

拿样例 1 第一串 `COMETQ` 手推：

| 字符 | 字母值 c-'A'+1 | ret 乘完 | ret % 47 |
| --- | --- | --- | --- |
| C | 3 | 3 | 3 |
| O | 15 | 45 | 45 |
| M | 13 | 585 | 21 |
| E | 5 | 105 | 11 |
| T | 20 | 220 | 32 |
| Q | 17 | 544 | 27 |

`COMETQ` → 27；`HVNGAT` 同样手推得 27，相等 → 输出 `GO`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <iostream>
> #include <string>
> using namespace std;
>
> int main() {
>     string a, b;
>     cin >> a >> b;                                // 一行一个串，无空格，直接读
>     long long ra = 1, rb = 1;                     // 乘法单位元，初值必须是 1
>     for (char c : a) ra = ra * (c - 'A' + 1) % 47;  // 随乘随模，A=1…Z=26
>     for (char c : b) rb = rb * (c - 'A' + 1) % 47;
>     cout << (ra == rb ? "GO" : "STAY") << endl;   // 原样大写输出
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
>
> def val(s: str) -> int:
>     ret = 1
>     for c in s:
>         ret = ret * (ord(c) - ord('A') + 1) % 47   # A=1…Z=26，随乘随模
>     return ret
>
> def main() -> None:
>     a = sys.stdin.readline().strip()               # strip 防行尾 \r 混进乘积
>     b = sys.stdin.readline().strip()
>     print("GO" if val(a) == val(b) else "STAY")
>
> if __name__ == "__main__":
>     main()
> ```

## 复杂度

- 时间：O(n+m)，两个串各扫一遍，每个字符一次乘法和一次取模。
- 空间：O(1)，只存两个累乘余数和读入的串本身。

## 易错点

1. `ret` 初值写成 0，乘积恒为 0，两串恒相等——输入 `A` / `B` 应输出 STAY，却输出 GO。
2. 映射漏掉 +1（写成 `c - 'A'`），A 变成 0，乘积恒为 0——输入 `A` / `B` 应输出 STAY，却输出 GO。
3. 先全部乘完再 `% 47`，长度 ≤6 是侥幸（26⁶≈3.1e8 在 int 上限 2.1e9 内），长度 8 时 26⁸≈2.1e11 溢出——输入 `ZZZZZZZZ` / `ZZZZZZZY` 用 int 先乘后模，中间值已溢出，结果不可信。
4. Python 读行不 strip，数据行尾带 `\r` 时 `ord('\r') - 64 = -51` 是负数，乘积符号全乱——`COMETQ\r` / `HVNGAT` 用 input() 直读不 strip 会算错（洛谷是 LF 一般没事，但别赌）。
5. 输出大小写或格式不对，`go`、`GO.` 或漏换行都判 WA——样例 `COMETQ` / `HVNGAT` 输出 `Go` 直接 Wrong Answer。
