# 9. 计数问题

## 一句话题意

统计 1 到 n 每个整数里，数字 x 一共出现了多少次。

## 解题逻辑

**先想什么**：读完题第一反应是「把 1 到 n 每个数都拆成一位一位，数一数」，n 上限只有 1e6，直接枚举就够。

**朴素解法**：`for i` 从 1 到 n，把 i 复制给临时变量 `t`，`while (t > 0)` 里 `t % 10` 取个位和 x 比，一样就计数，然后 `t /= 10` 丢掉个位。每个数拆约 log10 n ≈ 7 位，总操作量约 7n ≈ 7e6 次取模，洛谷 1 秒内稳过。为什么不够好：n 再大（如 1e9），就要拆 7e9 次，铁定超时；而且「每个数逐位拆」对整批数有大量重复劳动。

**优化观察**：关键观察——「每个数里 x 出现几次」等于「x 在每个十进制位上的贡献之和」，可以反过来**按位统计**。对 10^k 这一位，把 n 切成三段 `high = n / 10^(k+1)`、`cur = (n / 10^k) % 10`、`low = n % 10^k`：x 是 1~9 时，`cur > x` 贡献 `(high+1)·10^k`，`cur == x` 贡献 `high·10^k + low + 1`，`cur < x` 贡献 `high·10^k`（x=0 时把 high 减 1 去掉前导零）。复杂度从 O(n log n) 降到 O(log n)，靠的是把「枚举每个数」换成「枚举每个数位」，一位 O(1) 算完一整批数的贡献。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 逐位拆分（%10、/10） | O(n log n) | O(1) | n 到 1e9 会超时 |
| 转字符串 count | O(n log n) | O(log n) | 每个数都建字符串，常数大 |
| 数位贡献法 | O(log n) | O(1) | 公式绕，x=0 的前导零容易错 |

**选逐位拆分**：n 上限 1e6，O(n log n) 也就七百来万次运算，代码又短又稳；数位法留给 n 到 1e9 的进阶题（见同类题力扣 233），入门题不引它入场。

## 关键点

1. 模板句：`for i: t = i; while (t > 0) { if (t % 10 == x) cnt++; t /= 10; }`——拆位必须用临时变量 `t`，循环变量 `i` 不能动。
2. 不变量：while 每轮取走 t 的个位，t 的位数减一；循环结束 t 变 0，cnt 恰好是 i 里 x 出现的总次数。
3. x 可以为 0：1..n 里没有「数字 0」，但 10、20 这些数的低位就是 0，拆位循环照样能数到，**不需要任何特判**。
4. 边界约定：1 ≤ n ≤ 1e6、0 ≤ x ≤ 9；n=1 时循环只跑一趟；答案最多约 7e6，`int` 存得下。

## 实现逻辑

三个动作：**读入 n、x → 枚举 i 拆位计数 → 输出 cnt**。

拿题目原样例 `11 1`（答案 4）手推一遍：

| i | 当前值 t | 查什么 | 结果（该数贡献） | cnt |
| --- | --- | --- | --- | --- |
| 1 | 1 | 1 % 10 == 1？ | 1 | 1 |
| 2~9 | 2~9 | 每一位都不等于 1 | 0 | 1 |
| 10 | 10 | 个位 0 不是，t→1；1 % 10 == 1？ | 1 | 2 |
| 11 | 11 | 个位 1 是，t→1；1 % 10 == 1？ | 2 | 4 |

2~9 每个贡献都是 0，合并成一行。循环结束输出 `cnt = 4`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <iostream>
> using namespace std;
> 
> int main() {
>     int n, x;
>     cin >> n >> x;
> 
>     int cnt = 0;
>     for (int i = 1; i <= n; i++) {
>         int t = i;                    // 临时变量：i 还要继续循环，不能直接拆
>         while (t > 0) {               // 拆到没有位为止
>             if (t % 10 == x) cnt++;   // 个位是 x 就计数
>             t /= 10;                  // 丢掉个位
>         }
>     }
>     cout << cnt << endl;
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> def main():
>     n, x = map(int, sys.stdin.readline().split())
>     cnt = 0
>     for i in range(1, n + 1):
>         t = i                     # 临时变量：i 还要继续循环，不能直接拆
>         while t > 0:              # 拆到没有位为止
>             if t % 10 == x:
>                 cnt += 1          # 个位是 x 就计数
>             t //= 10              # 丢掉个位
>     print(cnt)
> 
> if __name__ == "__main__":
>     main()
> ```

## 复杂度

- 时间：O(n log10 n)，每个数拆出约 log10 n ≈ 7 位，n=1e6 时约 7e6 次取模，稳过。
- 空间：O(1)，只有 `n`、`x`、`cnt`、`t` 几个整型变量，不随输入增长。

## 易错点

1. 直接拆循环变量：写成 `while (i > 0) { ...; i /= 10; }`，i 被拆成 0 后 for 的 `i++` 又把它变回 1，永远拆不完——输入 `11 1` 直接死循环。
2. 拆位条件写 `t >= 0`：t 到 0 之后 `0 % 10 == 0` 一直成立（x=0 时），`t /= 10` 还是 0——输入 `11 0` 死循环，必须是 `t > 0`。
3. 以为 x=0 时答案是 0：1..n 里确实没有数字 0，但 10、20 的低位就是 0——输入 `100 0` 答案是 11（10~90 十个 + 100 两个），不是 0。
4. 只拆个位（把 while 写成 if）：输入 `11 1` 只数到 1 的个位，10 的十位、11 的十位全漏，输出 1 而不是 4。
5. Python 用真除法拆位：写成 `t = t / 10`，t 会从 100 → 10.0 → 1.0 → 0.1 → 0.01… 永远大于 0——输入 `100 1` 死循环，整数拆位必须用整除 `//`（C++ 的 int 相除自动整除，没这个坑）。
