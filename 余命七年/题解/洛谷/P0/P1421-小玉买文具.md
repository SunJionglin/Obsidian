# 05. 小玉买文具（洛谷 P1421）

## 一句话题意

输入 a 元 b 角，笔每支 1 元 9 角，输出最多能买几支。

## 解题逻辑

**先想什么**：钱有两种单位（元、角），混着算容易乱，先把所有钱统一成最小单位「角」再动手。

**朴素解法**：按 19 角一支，写循环一支一支累加，数到钱不够为止，O(total/19) 次。a 最大 10000 时最多数 5263 次，其实也跑得动，但纯属多写一个循环和两个变量。

**优化观察**：「数到钱不够为止」的过程，本质就是**总角数 ÷ 单价**的向下取整——总角数 = a×10+b，一支 19 角，`total / 19` 的商天然向下取整，恰好等于最多能买的数量，一步 O(1) 出答案，循环直接省掉。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 循环数笔 | O(total/19) | O(1) | 要维护计数和剩余钱，写多错多 |
| 浮点除法 | O(1) | O(1) | 1.9 不是精确二进制数，有精度风险，还得截断回整数 |
| 整数除法 | O(1) | O(1) | 无，本题数据范围内完全够用 |

**选整数除法**：金额和单价都换成「角」后全是整数，「最多能买几支」恰好是整除的商，C++ 的 `/` 和 Python 的 `//` 一步到位，不碰浮点、不用循环。

## 关键点

1. 模板句：**单位统一到最小单位，再做整数除法取商**。
2. 不变量：a ≤ 10000，total ≤ 100009，商 ≤ 5263，全程在 int 范围内，不用 long long。
3. 边界约定：钱不够一支（如 18 角）时商为 0，直接输出 0，不用特判。
4. 全程整数：单价写作 19 角，别写 1.9 元，绕开浮点误差。

## 实现逻辑

三个动作一次做完：**读入 a、b → 合成总角数 total = a×10+b → 输出 total / 19**。

拿样例 `10 3` 手推一遍：

| 变量 | 当前值 | 算什么 | 结果 |
| --- | --- | --- | --- |
| a | 10 | 读入 | 10 元 |
| b | 3 | 读入 | 3 角 |
| total | 10×10+3 | 换算成角 | 103 角 |
| ans | 103 / 19 | 整除取商 | 5（余 8 角，买不起第 6 支） |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <iostream>
> using namespace std;
> 
> int main() {
>     int a, b;                        // a 元 b 角
>     cin >> a >> b;
>     int total = a * 10 + b;          // 全部换成「角」
>     cout << total / 19 << endl;      // 每支 19 角，int 除法向下取整
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> a, b = map(int, sys.stdin.readline().split())  # a 元 b 角
> print((a * 10 + b) // 19)                      # 每支 19 角，// 整除取商
> ```

## 复杂度

- 时间：O(1)，读入、一次乘加、一次整除，常数步。
- 空间：O(1)，只有 a、b、total 三个变量。

## 易错点

1. 忘把元换成角，写成 `total = a + b`：输入 `1 9` → 算成 10 角，10/19=0；正确答案是 19 角买 1 支。
2. Python 用了 `/` 浮点除：输入 `10 3` → 103/19 得 5.421…，输出 5.0 而不是 5，判 WA；必须用 `//`。
3. 单价换算错，把 19 角写成 190：输入 `10 3` → 103/190=0；实际能买 5 支。
4. 边界 `1 8`：18/19=0，一支也买不起，输出 0 是对的，别误写成 1。
5. 边界 `0 0`：0/19=0，直接输出 0 合法，不用特判。
