# 19. 最厉害的学生（P5740）

## 一句话题意

输入 n 个学生的姓名与语数英三科成绩，输出总分最高者的姓名和三科成绩。

## 解题逻辑

**先想什么**：读完题第一反应是「全读进来，按总分排个序，第一名就是答案」。

**朴素解法**：结构体数组存下所有学生，`sort` 按总分降序排，取下标 0。O(n log n) 时间、O(n) 空间。不够好——题目只问**最大**，不要求任何顺序，排序把没用到的大小关系全算了一遍，还得写比较函数。

**优化观察**：求最大值是「流式」问题，不需要留人。关键观察是——**最大值可以边读边滚动更新**。只保留「当前最优学生 + 最高总分」两个变量，读一个、算一个、比一个，一趟 O(n) 扫完，空间从 O(n) 降到 O(1)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 结构体数组 + sort 降序 | O(n log n) | O(n) | 只问最大却排全序，多写比较函数，白算 |
| 数组存完再线性扫 | O(n) | O(n) | 时间够优，但白存了整个数组 |
| 边读边比（滚动最大值） | O(n) | O(1) | 依赖「保证没有并列」 |

**选边读边比**：最大值天然支持流式处理，读一个比一个就能出答案，时间和空间同时到最优，代码还是三个方案里最短的。

## 关键点

1. 姓名直接用 `string` + `cin` 读，别用 `char[]` 操心长度。
2. 更新条件用**严格大于** `>`——题目保证总分没有并列，先出现者就是唯一最优。
3. `bestSum` 初始化为 -1（三科都 ≥ 0，总分最小是 0），保证第一个学生必被收下。
4. 输出的是姓名 + 语数英三科，**不是总分**。

## 实现逻辑

三个动作循环做：**读一组 → 算 sum → 严格更大就整组替换**；循环结束输出最优学生。

拿官方样例手推（3 人：senpai 114 51 4 / lxl 114 10 23 / fafa 51 42 60）：

| i | 当前学生 | sum | 比较 sum > bestSum | 结果 | best 状态 |
| --- | --- | --- | --- | --- | --- |
| 0 | senpai 114 51 4 | 169 | 169 > -1 成立 | 替换 | best = senpai, bestSum = 169 |
| 1 | lxl 114 10 23 | 147 | 147 > 169 不成立 | 不动 | 不变 |
| 2 | fafa 51 42 60 | 153 | 153 > 169 不成立 | 不动 | 不变 |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> #include <iostream>
> #include <string>
> using namespace std;
> 
> struct Student {
>     string name;
>     int chinese, math, english;
> };
> 
> int main() {
>     ios::sync_with_stdio(false);
>     cin.tie(nullptr);                    // 提速；不要与 scanf 混用
> 
>     int n;
>     cin >> n;
> 
>     Student best;
>     int bestSum = -1;                    // 总分最小为 0，-1 保证第一个必被收下
>     for (int i = 0; i < n; i++) {
>         Student s;
>         cin >> s.name >> s.chinese >> s.math >> s.english;
>         int sum = s.chinese + s.math + s.english;
>         if (sum > bestSum) {             // 严格大于：无并列，先出现者赢
>             bestSum = sum;
>             best = s;                    // 整组替换，连带姓名
>         }
>     }
> 
>     cout << best.name << ' '
>          << best.chinese << ' ' << best.math << ' ' << best.english << '\n';
>     return 0;
> }
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> import sys
> 
> def main():
>     data = sys.stdin.read().split()      # 一次读完，按空白切词
>     n = int(data[0])
>     idx = 1                              # 指向第一个学生的姓名
>     best_name = ""
>     best_chinese = best_math = best_english = 0
>     best_sum = -1                        # 总分最小为 0，-1 保证第一个必被收下
>     for _ in range(n):
>         name = data[idx]
>         chinese = int(data[idx + 1])
>         math = int(data[idx + 2])
>         english = int(data[idx + 3])
>         idx += 4                         # 每个学生占 4 个词
>         s = chinese + math + english
>         if s > best_sum:                 # 严格大于：无并列，先出现者赢
>             best_sum = s
>             best_name = name
>             best_chinese, best_math, best_english = chinese, math, english
>     print(best_name, best_chinese, best_math, best_english)
> 
> if __name__ == "__main__":
>     main()
> ```

## 复杂度

- 时间：O(n)，每个学生算一次总分、比一次，共 n 次常数操作。
- 空间：O(1)，只保留当前学生和当前最优，不存整个数组。

## 易错点

1. 更新用 `>=`：题面保证无并列，但数据若出现并列，`>=` 会取到**后出现**的那个，答案可能错。样例：
   ```
   2
   aaa 100 100 100
   bbb 100 100 100
   ```
   `>` 输出 aaa，`>=` 输出 bbb。
2. `bestSum` 初始化为 0、全班都考 0 分：第一个学生的 0 进不了 `sum > bestSum`，best 姓名空着。样例 `1 / zero 0 0 0` 会输出空行——初始 -1 才安全。
3. 输出总分而不是三科成绩：官方样例正确输出是 `senpai 114 51 4`，若输出 `senpai 169` 直接 WA。
4. C++ 漏 `#include <string>`：`cin >> string` 靠 iostream 间接带进来，换编译器可能编不过。
5. Python 手滑把 `idx += 4` 写成 `idx += 3`：第二个学生的姓名会把第一个学生的英语成绩读进来。样例：
   ```
   2
   a 1 2 3
   b 4 5 6
   ```
   b 会被误读成 3，后面全乱。
