# 66. 加一 Plus One

## 一句话题意

最高位在前存整数各位，返回加 1 后的数组。

## 解题逻辑

**先想什么**：加法只会影响低位，从最后一位（个位）开始加，看有没有进位。

**朴素解法**：把整个数组拼成一个整数，`+1` 后拆回数组。写法最短，但力扣样例里有上百位的数，`long long` 都装不下，直接溢出，不可用。

**优化观察**：进位只在「遇到 9」时发生，而且是一条从末尾往前的连续链——**9 全变 0，遇到第一个非 9 就 +1 并立刻停下**。一趟从后往前的扫描就能模拟完整个加法，不需要真去算大数。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 拼整数 +1 再拆 | O(n) | O(1) | 大数溢出，长样例直接炸 |
| 通用大数加法模板 | O(n) | O(n) | 这题只加 1，杀鸡用牛刀，还得多开数组 |
| 从末位模拟进位 | O(n) | O(1) | 无 |

**选模拟进位**：加数固定是 1，进位链「9 变 0、非 9 停下」是这题专属的简化，时间和空间都最优。

## 关键点

1. 模板句：从末位往前，`9 → 0` 继续，非 9 就 `+1` 返回。
2. 不变量：扫过的位（当前位的右侧）全是 0——它们原本都是 9，进位后归零。
3. 边界：循环走完都没返回，说明全是 9（如 `[9,9,9]`），要在头部补一个 1，结果 `[1,0,0,0]`，长度 +1。
4. 结果数组长度要么是 n，要么是 n+1，只会出现在头部多一位。

## 实现逻辑

三个动作循环做：**末位看是不是 9 → 是 9 改成 0 → 非 9 加一返回**；循环跑完还没返回，最后在头部插 1。

拿 `digits = [1,2,9]` 手推一遍：

| 循环变量 i | 当前值 | 查什么 | 结果 | 数组状态 |
| --- | --- | --- | --- | --- |
| 2 | 9 | 是 9 吗 | 改成 0，进位继续 | [1,2,0] |
| 1 | 2 | 是 9 吗 | 不是，+1 变 3，返回 | [1,3,0] |

再拿全是 9 的 `[9,9]` 看边界：i=1 和 i=0 都是 9，全改 0，循环结束不返回，头部插 1，得到 `[1,0,0]`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     vector<int> plusOne(vector<int>& digits) {
>         for (int i = (int)digits.size() - 1; i >= 0; i--) {
>             if (digits[i] == 9)
>                 digits[i] = 0;              // 9 变 0，进位继续向前
>             else {
>                 digits[i]++;                // 第一个非 9：加一即停
>                 return digits;
>             }
>         }
>         digits.insert(digits.begin(), 1);   // 全是 9：最高位补 1
>         return digits;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def plusOne(self, digits: list[int]) -> list[int]:
>         for i in range(len(digits) - 1, -1, -1):
>             if digits[i] == 9:
>                 digits[i] = 0                # 9 变 0，进位继续向前
>             else:
>                 digits[i] += 1               # 第一个非 9：加一即停
>                 return digits
>         return [1] + digits                  # 全是 9：头部补 1
> ```

## 复杂度

- 时间：O(n)，从末尾到开头最多扫一遍；全 9 时头部 `insert` 也是 O(n)，总体仍是 O(n)。
- 空间：O(1)，原地修改，只可能多出一个头部元素，不新开数组。

## 易错点

1. `[9,9,9]`：循环结束后忘了头部补 1，会返回 `[0,0,0]`——全 9 是这题唯一的「长度 +1」分支。
2. `[1,9,9]`：在第一个非 9 处 `+1` 后必须立刻 `return`，继续往前扫会把前面的位也误改。
3. 只改最后一位不处理进位：`[9]` 用 `digits[-1] += 1` 会得到 `[10]`（应是 `[1,0]`），`[1,9]` 会得到 `[1,10]`。
4. C++：`digits.size() - 1` 是 `unsigned` 类型，直接赋给 `int i` 有符号转换警告，且极端情况比较会出问题，先 `(int)` 转一下再倒序循环。
5. 别拼整数：`[1]` 后面跟 100 个 0 的样例，拼成整数超出 `long long` 范围，朴素解法直接溢出。
