# 10. 有序数组的平方 Squares of a Sorted Array

## 一句话题意

给一个**非递减**整数数组，返回**每个数平方后仍非递减**的新数组（下标从 0 开始，元素可重复、可为负）。

## 解题逻辑

**先想什么**：读完题第一反应是「每个数平方一下，再排个序」，负数平方后会变大、位置就乱了。

**朴素解法**：遍历一遍把每个元素平方，直接 `sort`。O(n log n)，能过但没用上「原数组已经有序」这个条件，排序那一步是白花的钱。

**优化观察**：原数组非递减，所以**平方后的最大值只可能在两端**——最左是最小的数（负得最狠，平方可能最大），最右是最大的数。两个指针一头一尾往里夹，每次比较两端谁的平方大，把大的填进答案的**最右端**，一趟 O(n) 搞定，连排序都省了。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 平方 + sort | O(n log n) | O(log n)（排序栈） | 没用上数组有序，多花一个 log n |
| 平方 + 计数排序 | O(n + M) | O(M) | 值域 M 很大时不划算，代码也绕 |
| 双指针 | O(n) | O(n)（答案数组） | 需要理解「最大值在两端」 |

**选双指针**：题目只要求返回平方后的有序数组，不要求原地，双指针一趟从两端往中间收，把「找最大值」从全局排序降成两端二选一，时间压到最优，是这题的标准解。

## 关键点

1. **不变量**：原数组非递减 ⇒ 剩余区间里，平方最大的数一定在 `left` 或 `right` 两端。
2. **从后往前填**：答案数组 `res` 从 `pos = n-1` 往 0 填，每轮填当前最大的平方。
3. 边界约定：循环用 `left <= right`，两个指针相遇时中间那个数还要填一次。
4. 比较两端用 `-nums[left] > nums[right]`（左边绝对值的平方更大），别直接用原值比。

## 实现逻辑

先开好答案数组 → 每轮比较两端绝对值 → 大的平方填进 `pos`、对应指针内移 → `pos` 前移，直到 `left > right`。

拿 `nums = [-4, -1, 0, 3, 10]` 手推一遍：

| 循环轮 | left | right | 两端平方比 | 填进 pos 的值 | res 状态（pos 位置） |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 4 | 16 > 100，取右 | 100 | [·,·,·,·,100] |
| 2 | 0 | 3 | 16 > 9，取左 | 16 | [·,·,·,16,100] |
| 3 | 1 | 3 | 1 < 9，取右 | 9 | [·,·,9,16,100] |
| 4 | 1 | 2 | 1 > 0，取左 | 1 | [·,1,9,16,100] |
| 5 | 2 | 2 | 指针相遇，取 0 | 0 | [0,1,9,16,100] |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     vector<int> sortedSquares(vector<int>& nums) {
>         int n = nums.size();
>         vector<int> res(n);                  // 答案从后往前填
>         int left = 0, right = n - 1, pos = n - 1;
>         while (left <= right) {
>             if (-nums[left] > nums[right]) { // 左端绝对值的平方更大
>                 res[pos--] = nums[left] * nums[left];
>                 left++;
>             } else {
>                 res[pos--] = nums[right] * nums[right];
>                 right--;
>             }
>         }
>         return res;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def sortedSquares(self, nums: List[int]) -> List[int]:
>         n = len(nums)
>         res = [0] * n
>         left, right, pos = 0, n - 1, n - 1
>         while left <= right:
>             if -nums[left] > nums[right]:   # 左端绝对值的平方更大
>                 res[pos] = nums[left] * nums[left]
>                 left += 1
>             else:
>                 res[pos] = nums[right] * nums[right]
>                 right -= 1
>             pos -= 1                        # 每轮都往尾部回退一格
>         return res
> ```

## 复杂度

- 时间：O(n)，每个元素只访问一次，两端指针合计走 n 步。
- 空间：O(n)，答案数组占 n；不计返回值的话额外空间 O(1)。

## 易错点

1. `nums = [-5, -4]`：负得最狠的在**左端**，平方后它才是大的。若从左往右顺着填会输出 `[25,16]` 错序——必须从右往左填。
2. `nums = [-1, 1]`：两端平方相等，填谁都对，但别忘了**另一端下一轮还要用**，只移一侧指针。
3. `nums = [5]`：单元素时 `left == right`，循环条件写 `<` 会直接跳过、返回全 0。要写 `<=`。
4. 比较两端时直接比 `nums[left] > nums[right]` 是错的（负数原值永远小），要比**绝对值**，即 `-nums[left]`。
5. C++：`res` 先开好大小再按下标填；别用 `push_back` 从头加，顺序会反过来。
