# 448. 找到所有数组中消失的数字 Find All Numbers Disappeared in an Array

## 一句话题意

给长度 n、元素都在 [1,n] 的数组（下标从 0 开始），返回 [1,n] 里没出现过的所有数。

## 解题逻辑

**先想什么**：读完题第一反应是「统计谁出现过」——拿个标记数组挨个打勾，最后数谁没勾上。

**朴素解法**：开布尔数组 `seen[n+1]`，遍历原数组把 `seen[x]` 置真，再扫 1..n 收集 `seen[x]` 为假的下标。时间 O(n)、空间 O(n)，正确但题面明确要求空间 O(1)（不算返回数组），不过关。

**优化观察**：关键观察是**值域 [1,n] 和下标 [0,n-1] 恰好一一对应**——值 x 的「家」是下标 x-1。既然一一对应，原数组本身就能当哈希表用：把「x 出现过」这个信息写成 `nums[x-1]` 的负号。负号是标记、绝对值是原值，两者互不干扰，空间从 O(n) 降到 O(1)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 排序 + 扫描 | O(n log n) | O(1) | 时间不满足 O(n) |
| 布尔标记数组 | O(n) | O(n) | 空间不达标 |
| 原地负号标记 | O(n) | O(1) | 每次要 abs 还原原值，思路略绕 |

**选原地负号标记**：题面把 O(n) 时间和 O(1) 空间都锁死了，前两个方案各卡一条；把「值 → 下标」的对应关系用起来、拿数组自身当哈希，是这题唯一的标准解。

## 关键点

1. 模板句：**值 x 映射到下标 x-1，把 `nums[x-1]` 取负，表示「x 出现过」**。
2. 不变量：数组在遍历中会被改负，读原值必须先 `abs(nums[i])`；第二次遇到重复的数时，它「家」里已是负数，**跳过不再取反**（负负得正会抹掉标记）。
3. 边界约定：答案从 1 数到 n，收集时是 `i+1` 不是 `i`；返回顺序任意，按 1..n 自然序收集即可。

## 实现逻辑

先**遍历打标**：每个位置取 `v = abs(nums[i])` 还原原值，找到家 `idx = v-1`，若 `nums[idx] > 0` 就取负。再**扫描收集**：凡 `nums[i] > 0`，说明 i+1 没人来认领，收进答案。最后**返回**。

拿 `nums = [4,3,2,7,8,2,3,1]`（n=8）手推打标过程：

| i | v=abs(nums[i]) | 查下标 v-1 | 该位置是正吗 | 动作 | 数组状态 |
| --- | --- | --- | --- | --- | --- |
| 0 | 4 | 3 | 是（7） | 标负 | [4,3,2,-7,8,2,3,1] |
| 1 | 3 | 2 | 是（2） | 标负 | [4,3,-2,-7,8,2,3,1] |
| 2 | 2 | 1 | 是（3） | 标负 | [4,-3,-2,-7,8,2,3,1] |
| 3 | 7 | 6 | 是（3） | 标负 | [4,-3,-2,-7,8,2,-3,1] |
| 4 | 8 | 7 | 是（1） | 标负 | [4,-3,-2,-7,8,2,-3,-1] |
| 5 | 2 | 1 | 否（已负） | 跳过 | 不变 |
| 6 | 3 | 2 | 否（已负） | 跳过 | 不变 |
| 7 | 1 | 0 | 是（4） | 标负 | [-4,-3,-2,-7,8,2,-3,-1] |

最后扫一遍：`nums[4]=8`、`nums[5]=2` 还正着，说明 5 和 6 没出现过，答案 `[5,6]`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     vector<int> findDisappearedNumbers(vector<int>& nums) {
>         int n = (int)nums.size();
>         for (int i = 0; i < n; i++) {
>             int v = abs(nums[i]);        // 先还原原值（可能已被标负）
>             int idx = v - 1;             // 值 v 的家是下标 v-1
>             if (nums[idx] > 0)
>                 nums[idx] = -nums[idx];  // 负号 = 「v 出现过」
>         }
>         vector<int> res;
>         for (int i = 0; i < n; i++)
>             if (nums[i] > 0)
>                 res.push_back(i + 1);    // 下标 i 没被认领 → i+1 失踪
>         return res;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def findDisappearedNumbers(self, nums: list[int]) -> list[int]:
>         n = len(nums)
>         for i in range(n):
>             v = abs(nums[i])            # 先还原原值
>             idx = v - 1                 # 值 v 的家
>             if nums[idx] > 0:
>                 nums[idx] = -nums[idx]  # 负号 = 出现过
>         return [i + 1 for i in range(n) if nums[i] > 0]
> ```

## 复杂度

- 时间：O(n)，打标和收集各扫一遍，每遍每元素 O(1)。
- 空间：O(1)，除返回值外只用了常数个变量，标记写在输入数组自身上。

## 易错点

1. 不取 abs 直接读：`nums = [1,1]` 第一次把 `nums[0]` 标成 -1，第二次若直接读 `nums[1]` 还是 1 没事，但更典型的 `nums = [2,1]` 第二次读 `nums[1]=1` 家是下标 0 已是 -1——**读原值永远先 `abs`**，否则负数当值会算出负下标越界。
2. 无条件取反而不是「正才取反」：`nums = [1,1]` 的第二个 1 会再把 `nums[0]` 负负得正，1 的标记被抹掉，答案错成 `[1,2]`——重复元素是这题最大的坑。
3. 标记用「取负」而不是「置 0/-1」：置成别的值就丢了原来那个位置的数，后面没法还原它是几。
4. 答案从 1 数起：`nums = [1]` 应该返回 `[]`（1 出现过，没人失踪），写成返回下标 `i` 会错成 `[0]`。
5. C++：`nums.size()` 是 `unsigned`，和 `int i` 比较会有符号转换警告，先 `(int)` 转一下；`abs` 整型版本在 `<cstdlib>`（`<cmath>` 自 C++11 起也提供）。
