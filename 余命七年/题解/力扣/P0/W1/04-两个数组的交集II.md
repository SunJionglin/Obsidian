# 350. 两个数组的交集 II Intersection of Two Arrays II

## 一句话题意

给两个整数数组，返回交集，每个元素出现次数取两数组中较小值，顺序任意。

## 解题逻辑

**先想什么**：读完题第一反应是「nums2 里每个数在 nums1 里出现过没有」，两层循环配对。

**朴素解法**：外层遍历 nums1，内层在 nums2 里线性找，找到后把 nums2 那个位置标记用过。O(m·n)，两边都到 1e4 时约 1e8 次比较，力扣会超时。

**优化观察**：关键观察是——结果里每个数出现几次，由「它在两个数组里出现次数的**较小值**」决定。所以只要一张「这个数还剩几次可拿」的计数表，一次建表、一次遍历就完事，查找从 O(n) 变 O(1)。再进一步，表只建在**较短**的数组上，空间压到 O(min(m,n))。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 两层循环 | O(m·n) | O(1) | 大数组超时 |
| 排序 + 双指针 | O(m log m + n log n) | O(1) | 排序开销大，相等时两个指针都得走，易写错 |
| 哈希表计数 | O(m + n) | O(min(m,n)) | 多用一点内存 |

**选哈希表计数**：时间线性最优；表建在较短数组上把空间压到 min(m,n)；返回顺序任意，哈希方案天然无序，正合适。

## 关键点

1. 结果次数 = 两数组出现次数的 min，用计数表「**收一个减一个**」实现。
2. **让 nums1 是较短的**再建表，空间 O(min(m,n))。
3. 顺序任意，直接返回哈希方案的结果即可，不用再排序。
4. 模板句：`cnt[x] > 0` 才收，收完 `--cnt[x]`。

## 实现逻辑

四个动作：**换（保证 nums1 短）→ 建表 → 收数 → 返回**。

拿 `nums1 = [1,2,2,1]`、`nums2 = [2,2]` 手推一遍：

| 循环变量 | 当前值 | 查什么 | 结果 | cnt 状态 |
| --- | --- | --- | --- | --- |
| x（nums2 第 1 个） | 2 | cnt[2]=2>0? | 收 2，cnt[2]→1 | {1:2, 2:1} |
| x（nums2 第 2 个） | 2 | cnt[2]=1>0? | 收 2，cnt[2]→0 | {1:2, 2:0} |

最后返回 `[2,2]`。C++ 里 `++cnt[x]` 依赖 `operator[]` 键不存在时自动插 0；Python 的 `Counter` 缺键返回 0，不会 KeyError。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     vector<int> intersect(vector<int>& nums1, vector<int>& nums2) {
>         if (nums1.size() > nums2.size())
>             swap(nums1, nums2);               // 保证 nums1 是较短的那个
>         unordered_map<int, int> cnt;
>         for (int x : nums1) ++cnt[x];         // 建计数表：数 -> 出现次数
>         vector<int> res;
>         for (int x : nums2)
>             if (cnt[x] > 0) {                 // 计数为正才收
>                 res.push_back(x);
>                 --cnt[x];                     // 收一个减一个
>             }
>         return res;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> from collections import Counter
> from typing import List
> 
> class Solution:
>     def intersect(self, nums1: List[int], nums2: List[int]) -> List[int]:
>         if len(nums1) > len(nums2):
>             nums1, nums2 = nums2, nums1   # 保证 nums1 较短
>         cnt = Counter(nums1)              # 建计数表：数 -> 出现次数
>         res = []
>         for x in nums2:
>             if cnt[x] > 0:                # 计数为正才收
>                 res.append(x)
>                 cnt[x] -= 1               # 收一个减一个
>         return res
> ```

## 复杂度

- 时间：O(m + n)，建表 O(m)（较短数组）+ 遍历 O(n)，每次哈希操作平均 O(1)。
- 空间：O(min(m,n))，计数表最多存较短数组里不同值的个数。

## 易错点

1. `nums1 = [1,1]`、`nums2 = [1,1,1]` 应返回 `[1,1]`：用 set 去重会漏掉重复次数——本题不是 349 题，次数要取 min。
2. `nums1 = [1,1,2]`、`nums2 = [1,1,1]`：只判断「在表里」却不减计数，会返回三个 1，多收一个——必须收一个减一个。
3. C++：在循环里用 `count(nums2.begin(), nums2.end(), x)` 现数一遍，复杂度退回 O(m·n)，1e4 规模会超时。
4. Python：用普通 dict 手写计数时访问不存在的键会 KeyError；`Counter` 缺键返回 0，所以本题直接 `cnt[x] > 0` 就够。
