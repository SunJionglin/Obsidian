# 242. 有效的字母异位词 Valid Anagram

## 一句话题意

给两个字符串 `s` 和 `t`，判断 `t` 是否由 `s` 重排字母得到（每个字母出现次数完全相同），是返回 `true`，否则 `false`。

## 解题逻辑

**先想什么**：读完题第一反应是「把 `s` 的字母打乱重排，能不能凑出 `t`」，等价于两串**每个字母出现次数一样**。

**朴素解法**：把 `s`、`t` 分别 `sort` 后直接比较相等。O(n log n)，正确但浪费——排序做的是「排顺序」的活，这题只关心「计数」，n 大时那个 log n 因子是白花的。

**优化观察**：字母只有 26 个（小写），出现次数就是 26 个整数。用**定长数组计数**：第一遍对 `s` 的每个字符 `++`，第二遍对 `t` 的每个字符 `--`，最后 26 格全 0 就是异位词。把「排序比较」降到「线性计数」，时间从 O(n log n) 压到 O(n)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 排序后比较 | O(n log n) | O(1) | 做了排序的活，只为了比对计数，浪费 |
| 两个哈希表计数 | O(n) | O(26) | 要建两张表再逐项比，多一遍 |
| 一个数组计数（++/--） | O(n) | O(1) | 只适用字符集有限（如小写字母） |

**选数组计数**：字母异位词的本质是「字符频率相同」，26 个格子的数组天生就是计数表——比排序省、比哈希快，一遍加一遍减还把两张表合并成一张。

## 关键点

1. 字母异位词 ⇔ 每个字符出现次数完全相同，跟顺序无关。
2. `cnt[c - 'a']` 把字符映射到 0~25 的下标（Python 用 `ord(c) - ord('a')`）。
3. **第一遍 ++、第二遍 --**，最后 26 格全 0 就是异位词；一张表当两张用。
4. 边界约定：长度不等直接返回 `false`；空串对空串返回 `true`。

## 实现逻辑

四个动作：**判长度 → 第一遍对 s 计数 ++ → 第二遍对 t 消数 -- → 扫 26 格看是否全 0**。

拿 `s = "abc"`、`t = "bca"` 手推一遍（只看 a、b、c 三格）：

| 循环 | i | 当前字符 | 动作 | cnt 状态 |
| --- | --- | --- | --- | --- |
| 第一遍 s | 0 | a | cnt[0]++ | [1,0,0] |
| 第一遍 s | 1 | b | cnt[1]++ | [1,1,0] |
| 第一遍 s | 2 | c | cnt[2]++ | [1,1,1] |
| 第二遍 t | 0 | b | cnt[1]-- | [1,0,1] |
| 第二遍 t | 1 | c | cnt[2]-- | [1,0,0] |
| 第二遍 t | 2 | a | cnt[0]-- | [0,0,0] |
| 检查 | 0~25 | - | 全为 0？ | 是 → 返回 true |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     bool isAnagram(string s, string t) {
>         if (s.size() != t.size()) return false;   // 长度不同必不是
>         int cnt[26] = {0};                        // 只含小写字母，定长数组计数
>         for (char c : s) cnt[c - 'a']++;          // 第一遍 ++
>         for (char c : t) cnt[c - 'a']--;          // 第二遍 --
>         for (int i = 0; i < 26; i++)
>             if (cnt[i] != 0) return false;        // 有字母没抵消干净
>         return true;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def isAnagram(self, s: str, t: str) -> bool:
>         if len(s) != len(t):                      # 长度不同必不是
>             return False
>         cnt = [0] * 26                            # 只含小写字母，定长数组计数
>         for c in s:
>             cnt[ord(c) - ord('a')] += 1           # 第一遍 ++
>         for c in t:
>             cnt[ord(c) - ord('a')] -= 1           # 第二遍 --
>         return all(x == 0 for x in cnt)           # 26 格全零才是异位词
> ```

## 复杂度

- 时间：O(n)，两趟遍历共 2n 个字符加固定扫 26 格，O(2n + 26) = O(n)。
- 空间：O(1)，`cnt` 固定 26 格，与输入长度无关。

## 易错点

1. `s = "a"`、`t = "ab"`：漏掉长度判断、只按 `s` 的长度遍历，会漏看 `t` 多出来的 `'b'`。入口处 `size` 不等直接返回 `false` 最省事。
2. C++：`int cnt[26]` 漏写 `= {0}`，局部数组装的是垃圾值，最后「全 0 检查」全乱，`s = "ab"`、`t = "ba"` 都可能判错。
3. 本题字符集限定小写字母才敢用 `c - 'a'`；若题目出现大写（如 `s = "aA"`、`t = "Aa"`），要换成 `unordered_map` 计数。
4. Python：`return sorted(s) == sorted(t)` 能过但偷偷是 O(n log n)；`Counter(s) != Counter(t)` 一行偷懒，面试要能说清数组计数版。
5. `s = "a"`、`t = "a"` 要返回 `true`，题目没要求两串必须不同，别画蛇添足去判 `s != t`。
