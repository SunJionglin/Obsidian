# 136. 只出现一次的数字 Single Number

## 一句话题意

给一个非空整数数组，除一个数外每个元素都出现两次，返回**只出现一次的那个数**（返回的是值，不是下标）。

## 解题逻辑

**先想什么**：要找「落单的」，第一反应是计数——统计每个数出现几次，出现 1 次的就是答案。

**朴素解法 1**：哈希表计数，`count[x]++` 后第二遍扫表找次数为 1 的。O(n) 时间、O(n) 空间，但进阶要求 O(1) 额外空间，不达标。

**朴素解法 2**：排序后成对的数必然相邻，两两比较找落单。O(n log n) 时间，比线性慢一档，也不够好。

**优化观察**：成对出现 = 相同的数互相**抵消**。位运算里异或正好有抵消律：`a ^ a = 0`、`a ^ 0 = a`，且异或满足交换律结合律，**与顺序无关**。把全部元素异或一遍，成对的归零，落单的留下，一遍 O(n)、额外 O(1)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 哈希计数 | O(n) | O(n) | 空间超进阶要求 |
| 排序 + 相邻比较 | O(n log n) | O(1) | 时间慢一档，还要处理边界下标 |
| 异或抵消 | O(n) | O(1) | 只适用「其他元素出现偶数次」的场景 |

**选异或**：同时满足 O(n) 时间和 O(1) 空间两条硬要求，一个 `res ^= x` 循环结束战斗，是位运算抵消思想的入门模板题。

## 关键点

1. 模板句：`res ^= x` 遍历一遍，`res` 就是答案。
2. 抵消律：`a ^ a = 0`、`a ^ 0 = a`，配合交换律结合律，成对元素无论顺序都会互相抵消。
3. 不变量：循环中 `res` 恒等于「已遍历元素里出现奇数次的那些数的异或」。
4. 边界约定：数组非空，只有一个元素时 `0 ^ nums[0]` 直接就是答案。

## 实现逻辑

三个动作：**先 `res = 0` → 再遍历每个元素做 `res ^= x` → 最后返回 `res`**。

拿 `nums = [4,1,2,1,2]` 手推一遍：

| 当前 x | 计算 | res | 说明 |
| --- | --- | --- | --- |
| 初始 | — | 0 | 0 是异或单位元，先跟 0 异或不变 |
| 4 | 0 ^ 4 | 4 | 落单候选 |
| 1 | 4 ^ 1 | 5 | 101 |
| 2 | 5 ^ 2 | 7 | 111 |
| 1 | 7 ^ 1 | 6 | 第二次出现的 1 被抵消 |
| 2 | 6 ^ 2 | 4 | 第二次出现的 2 被抵消，落单的 4 留下 |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int singleNumber(vector<int>& nums) {
>         int res = 0;                      // 0 是异或单位元
>         for (int x : nums)
>             res ^= x;                     // 成对的互相抵消，落单的留下
>         return res;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def singleNumber(self, nums: list[int]) -> int:
>         res = 0                           # 0 是异或单位元
>         for x in nums:
>             res ^= x                      # 成对的互相抵消，落单的留下
>         return res
> ```

## 复杂度

- 时间：O(n)，每个元素异或一次，一遍遍历结束。
- 空间：O(1)，只用一个 `res` 变量，满足进阶要求。

## 易错点

1. 把异或写成加法求和：`nums = [2,2,1]`，`sum` 是 5 但答案是 1——加法没有「相同即抵消」的性质，`a + a ≠ 0`。
2. 排序法步长写成 1：`nums = [1,1,2,2,3]` 排序后若 `i += 1` 判断相邻不等，在 i=1 处拿第二个 1 和 2 比，会错误提前返回 1；正确步长是 2，末尾落单元素还要单独处理。
3. 哈希计数只建表不扫第二遍：`nums = [4,1,2,1,2]` 建完 `{4:1,1:2,2:2}` 直接返回 `begin()` 的键——`unordered_map` 无序，拿到的未必是 4。
4. `res` 初始化为 `nums[0]` 但循环又从 0 开始：`nums = [4,1,2,1,2]`，4 被异或两次，最后返回 0——要么 `res = 0` 从头遍历，要么 `res = nums[0]` 且从 `i = 1` 开始。
