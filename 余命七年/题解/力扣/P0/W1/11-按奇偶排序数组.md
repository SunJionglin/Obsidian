# 905. 按奇偶排序数组 Sort Array By Parity

## 一句话题意

给一个整数数组，把偶数全挪到前面、奇数挪到后面，组内顺序随意，返回重排后的数组（下标从 0 开始）。

## 解题逻辑

**先想什么**：本质是「分区（partition）」——按一个条件把数组切成两段，谁在前谁在后由条件定。看到「偶数在前、奇数在后」，就该想到左右双指针。

**朴素解法**：开一个结果数组，先遍历一遍接上所有偶数，再遍历一遍接上所有奇数。O(n) 时间、O(n) 空间，能过，但多复制了整份数组；或者 `sort` 按 `x % 2` 排，O(n log n)，题目不要求组内有序，白花排序的钱。

**优化观察**：偶数在前 = 前半段不需要具体顺序，只要「左边全是偶数、右边全是奇数」。左右两个指针同时开工，左指针找奇数、右指针找偶数，找到一对就交换，各自往中间推进。空间从 O(n) 降到 O(1)，且一趟走完。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 两遍遍历装新数组 | O(n) | O(n) | 多复制一整份数组 |
| sort 按 `x % 2` 排序 | O(n log n) | O(1) | 不要求组内有序，排序是浪费 |
| 双指针原地交换 | O(n) | O(1) | 无，标准解 |

**选双指针**：不要求组内有序，意味着「交换」就够、不必「排序」；双指针一趟、原地、O(1) 空间，是 partition 类数组题的通用模板。

## 关键点

1. 不变量：`[0, left)` 全是偶数，`(right, n-1]` 全是奇数，`[left, right]` 是待处理区。
2. 内层两个 while 都要带 `left < right` 护栏，否则指针会越过对方甚至越界。
3. 终止条件：`left >= right` 时待处理区为空，分区完成。
4. 组内顺序随意，所以不用管稳定性，直接交换即可。

## 实现逻辑

四个动作循环做：**左跳偶 → 右跳奇 → 交换 → 指针靠近**。

拿 `nums = [3,1,2,4]` 手推一遍：

| left | right | nums[left] | nums[right] | 查什么 | 动作 | 数组状态 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | 3 | 3 | 4 | 3 是奇数、4 是偶数 | 交换，left→1、right→2 | [4,1,2,3] |
| 1 | 2 | 1 | 2 | 1 是奇数、2 是偶数 | 交换，left→2、right→1 | [4,2,1,3] |
| 2 | 1 | — | — | left ≥ right | 结束 | [4,2,1,3] |

C++ 里用 `swap(nums[left], nums[right])` 交换；Python 里一行 `nums[left], nums[right] = nums[right], nums[left]`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     vector<int> sortArrayByParity(vector<int>& nums) {
>         int left = 0, right = (int)nums.size() - 1;
>         while (left < right) {
>             while (left < right && nums[left] % 2 == 0) left++;   // 左指针跳过偶数
>             while (left < right && nums[right] % 2 == 1) right--; // 右指针跳过奇数
>             if (left < right) swap(nums[left], nums[right]);      // 左奇右偶，交换
>         }
>         return nums;                                              // 原地改好，直接返回
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def sortArrayByParity(self, nums: list[int]) -> list[int]:
>         left, right = 0, len(nums) - 1
>         while left < right:
>             while left < right and nums[left] % 2 == 0:   # 左指针跳过偶数
>                 left += 1
>             while left < right and nums[right] % 2 == 1:  # 右指针跳过奇数
>                 right -= 1
>             if left < right:
>                 nums[left], nums[right] = nums[right], nums[left]  # 一行交换
>         return nums
> ```

## 复杂度

- 时间：O(n)，左右指针各至多走 n 步，每个元素至多看一次。
- 空间：O(1)，只用了两个指针变量，原地交换。

## 易错点

1. 内层 while 忘写 `left < right`：`nums = [1,3,5]` 全奇时右指针一路 `right--` 到 -1，`nums[right]` 越界崩溃；`nums = [2,4,6]` 全偶时左指针同理跑出数组。
2. 外层循环写成 `left <= right`：`nums = [1]` 时 `left == right == 0`，两个内层 while 都不动、交换也不触发，指针永远不变，死循环。
3. 判断奇数用 `% 2 == 1`：本题元素非负没问题；若元素可能为负，C++ 里 `-3 % 2 == -1`，`== 1` 会漏判，负数场景要写 `% 2 != 0`。
4. 改完忘了返回：`nums = [3,1,2,4]` 原地改好后直接 `return nums`；另开 `ans` 数组复制一遍再返回也能过，但白花 O(n) 空间。
5. `nums.size()` 是 `unsigned`，C++ 里赋给 `int right` 前先 `(int)` 转一下，避免符号转换警告。
