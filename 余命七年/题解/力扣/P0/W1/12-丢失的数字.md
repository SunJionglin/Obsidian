# 268. 丢失的数字 Missing Number

## 一句话题意

数组里有 `[0, n]` 除一个数外的全部数，返回缺失的那个数本身。

## 解题逻辑

**先想什么**：数都在 `[0, n]` 这个小范围里，第一反应是排个序，找「值和下标对不上」的位置。

**朴素解法**：排序后扫一遍，第一个 `nums[i] != i` 的 `i` 就是缺失的数；扫完没断点说明缺的是 `n`。O(n log n)，时间全耗在排序上，只为找一个数不划算；缺 `n` 时还要单独补判断。

**优化观察**：关键观察是**下标序列 `0..n-1` 恰好是完整范围 `[0, n]` 的一份**——再补上 `n` 就凑齐整个范围。数组元素是 `[0, n]` 缺一个数，于是把「下标 + n」和「数组元素」全部异或一遍，除缺失数外每个数都出现两次，靠 `a ^ a = 0` 的抵消性质，最后剩下的就是缺失数。不需要排序、不占额外空间，一趟 O(n) 拿到答案。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 排序找断点 | O(n log n) | O(1) | 为一个数排整个数组；缺 n 时要单独判断 |
| 哈希集合 | O(n) | O(n) | 多开一个集合，空间换得没必要 |
| 求和公式 | O(n) | O(1) | C++ 里 `n*(n+1)/2` 用 int 算会溢出，要小心类型 |
| 位运算异或 | O(n) | O(1) | 需要理解异或抵消 |

**选异或**：时间和空间同时最优，还没有求和法的溢出问题；「成对抵消、剩下孤数」这个模板能直接迁移到 136 题。

## 关键点

1. 模板句：`a ^ a = 0`、`a ^ 0 = a`，异或满足交换律和结合律——成对的数全抵消，孤数留下。
2. 下标序列 `0..n-1` 加一个 `n`，正好覆盖完整范围 `[0, n]`；和数组元素各异或一遍，唯一配不上对的数就是答案。
3. 边界约定：缺失的可能是 `n` 本身，所以 `n` 必须参与异或——实现里用 `res = n` 初始化。
4. 返回的是数值本身，不是下标。

## 实现逻辑

三个动作：**先把 n 记进 res → 遍历时同时异或下标 i 和元素 nums[i] → 返回剩下的孤数**。

拿 `nums = [3,0,1]`（n = 3，缺 2）手推一遍：

| i | nums[i] | 异或操作 | res | 说明 |
| --- | --- | --- | --- | --- |
| 初始 | — | res = 3 | 3 | n 没有下标可配，先记上 |
| 0 | 3 | res ^= 0 ^ 3 | 0 | 0 和 3 互相抵消 |
| 1 | 0 | res ^= 1 ^ 0 | 1 | 1 和 0 互相抵消 |
| 2 | 1 | res ^= 2 ^ 1 | 2 | 剩下 2，就是缺失的数 |

C++ 里 `res ^= i ^ nums[i]` 一条语句完成配平；Python 里用 `enumerate` 同时拿 `i` 和 `x`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int missingNumber(vector<int>& nums) {
>         int res = (int)nums.size();          // n 先记上，数组里没有下标 n 可配
>         for (int i = 0; i < (int)nums.size(); i++)
>             res ^= i ^ nums[i];              // 下标与值两两抵消
>         return res;                          // 剩下孤数就是缺失的数
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def missingNumber(self, nums: list[int]) -> int:
>         res = len(nums)                      # n 先记上，数组里没有下标 n 可配
>         for i, x in enumerate(nums):
>             res ^= i ^ x                     # 下标与值两两抵消
>         return res                           # 剩下孤数就是缺失的数
> ```

## 复杂度

- 时间：O(n)，一轮遍历，每个元素做一次 O(1) 的异或。
- 空间：O(1)，只用一个 `res` 变量，没有额外结构。

## 易错点

1. `nums = [0,1]`（n = 2）：缺失的就是 `n` 本身。若只异或下标 `0..n-1` 和元素，结果是 0——因为 `n` 没参与。解决：`res` 初始化为 `nums.size()`。
2. `nums = [0]`（n = 1）：缺失 1。`res = 1` 配平 0 后得 1；若 `res` 从 0 起、循环只跑下标 0，会错得 0。
3. `nums = [1]`（n = 1）：缺失 0。数组里压根没有 0，但 `res = 1` 配平 `0 ^ 1` 后照样得 0，别一看没 0 就慌。
4. C++：`nums.size()` 是无符号数，和 `int i` 比较会有符号转换警告，先 `(int)` 转一下。
5. 求和公式做对照时，C++ 里 `n*(n+1)/2` 用 `int` 算，n 大时会溢出（int 上限约 2.1e9），要先转 `long long`；异或法没有这个坑，也是选它的原因之一。
