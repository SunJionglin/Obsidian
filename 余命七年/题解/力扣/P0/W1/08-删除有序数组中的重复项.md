# 26. 删除有序数组中的重复项 Remove Duplicates from Sorted Array

## 一句话题意

给一个升序数组，原地去重（每元素只留一个），返回新长度 k，前 k 位即结果。

## 解题逻辑

**先想什么**：数组是升序的，重复元素必然挨在一起，所以「去重」其实就是**把每个值第一次出现的位置挑出来**。

**朴素解法**：开一个新数组，遍历原数组，遇到和上一个不同的就 append，最后拷回原数组。时间 O(n)，但空间 O(n)——题目要求原地修改、额外空间 O(1)，不达标。

**优化观察**：有序 + 原地，天然指向**双指针**。把「写入位置」和「扫描位置」分开——慢指针 i 守「已就位的最后一个元素」，快指针 j 往前探。有序保证新元素 = 和 nums[i] 不同的元素，直接写到 i+1 就行。两个指针都只前进，一趟扫完，时间 O(n)、空间 O(1)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 新数组拷贝 | O(n) | O(n) | 不满足原地、额外空间要求 |
| set 去重再回写 | O(n)~O(n log n) | O(n) | 额外容器，还得再写回原数组，绕远路 |
| 双指针 | O(n) | O(1) | 几乎没有，边界要写对 |

**选双指针**：题目两个条件——有序、原地——就是为双指针准备的，它是这题的标准解，也是后面一堆「原地去重/移除元素」题的母模板。

## 关键点

1. 模板句：`if (nums[j] != nums[i]) nums[++i] = nums[j];`——**先挪指针再写入**。
2. 不变量：`nums[0..i]` 始终是去重结果，i 指向最后一个不重复元素的下标。
3. 边界约定：i 从 0、j 从 1 起步；返回 `i + 1`（长度 = 最后一个下标 + 1）；空数组特判返回 0。

## 实现逻辑

先特判空数组，慢指针 i 置 0；再让快指针 j 从 1 扫到尾，遇到和 nums[i] 不同的就把它写进 i+1 并前移 i；最后返回 i+1。

拿 `nums = [1,1,2,2,3]` 手推一遍：

| j | nums[j] | 查什么 | 结果 | 数组状态（i） |
| --- | --- | --- | --- | --- |
| — | — | 初始 i=0 | — | [1,1,2,2,3]（i=0） |
| 1 | 1 | nums[1] == nums[0]？ | 相同，跳过 | [1,1,2,2,3]（i=0） |
| 2 | 2 | nums[2] == nums[0]？ | 不同，nums[1]=2，i=1 | [1,2,2,2,3]（i=1） |
| 3 | 2 | nums[3] == nums[1]？ | 相同，跳过 | [1,2,2,2,3]（i=1） |
| 4 | 3 | nums[4] == nums[1]？ | 不同，nums[2]=3，i=2 | [1,2,3,2,3]（i=2） |

返回 `i + 1 = 3`，前 3 位是 `[1,2,3]`。注意数组后半截的脏数据不用管，评测只看前 k 位。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int removeDuplicates(vector<int>& nums) {
>         int n = (int)nums.size();
>         if (n == 0) return 0;              // 空数组特判，不然会返回 1
>         int i = 0;                          // 慢指针：最后一个不重复元素的下标
>         for (int j = 1; j < n; j++) {       // 快指针：从 1 扫到尾
>             if (nums[j] != nums[i])         // 有序数组：不同 = 新元素
>                 nums[++i] = nums[j];        // 先挪指针，再写入
>         }
>         return i + 1;                       // 长度 = 最后下标 + 1
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def removeDuplicates(self, nums: list[int]) -> int:
>         if not nums:                     # 空数组特判
>             return 0
>         i = 0                            # 慢指针
>         for j in range(1, len(nums)):    # 快指针
>             if nums[j] != nums[i]:
>                 i += 1                   # 先挪指针
>                 nums[i] = nums[j]        # 再写入
>         return i + 1
> ```

## 复杂度

- 时间：O(n)，快指针把数组从头到尾扫一遍，每步 O(1)。
- 空间：O(1)，只有两个指针变量，原地修改数组。

## 易错点

1. 先写后移覆盖首个元素：`nums = [1,1,2]` 若写 `nums[i] = nums[j]` 忘了先 `++i`，j=2 时把 2 写到下标 0，数组变成 `[2,1,2]`——正确是 `nums[++i] = nums[j]`。
2. 空数组返回 1：`nums = []` 时若不特判，i=0 直接返回 `i+1=1`，错误——空数组必须返回 0。
3. 返回的是长度不是下标：`nums = [1,1,2]` 去重后前 2 位是 `[1,2]`，正确返回 2；习惯性返回 i=1 就少了一个。
4. C++：`nums.size()` 是无符号数，`for (int j = 1; j < nums.size(); j++)` 会有符号/无符号比较警告，先存成 `int n` 或强转。
5. Python：`range(1, len(nums))` 当 `len(nums) == 0` 时循环不执行，i 保持 0 会误返回 1，所以 `if not nums` 特判不能省。
