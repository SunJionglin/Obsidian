# 169. 多数元素 Majority Element

## 一句话题意

给数组 `nums`，返回出现次数超过 ⌊n/2⌋ 的那个元素（题目保证一定存在）。

## 解题逻辑

**先想什么**：读完题第一反应是「给每个数数出现次数」，数完取次数最多的那个。

**朴素解法**：`unordered_map` 计数，再扫一遍找出次数 > n/2 的数。O(n) 时间、O(n) 空间；不够好的点是空间 O(n)，而且「找最大的」其实没用满「超过一半」这个强条件。

**优化观察**：多数元素超过一半，意味着**把任意一个多数元素和一个非多数元素两两抵消，最后必然还剩至少一个多数元素**——因为非多数元素总共不足一半，根本抵消不完。所以只需要一个候选人加一个计数器：同票 +1、异票 -1、归零换人，一趟 O(n)、O(1) 空间（摩尔投票）。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 哈希表计数 | O(n) | O(n) | 额外 O(n) 空间，面试常被追问优化 |
| 排序取中间 | O(n log n) | O(log n) | 时间没到最优，还改动原数组 |
| 摩尔投票 | O(n) | O(1) | 依赖「必存在多数」的保证，思路略绕 |

**选摩尔投票**：把「数出现次数」降维成「票数差」，一趟扫完时间空间双最优，是这类题的标准模板。

## 关键点

1. 模板句：**一个候选人 + 一个计数器**，同则 +1，异则 -1，归零换人。
2. 不变量：`cnt` 是「当前候选人票数减非候选人票数」的余量；每步最多抵消一对（多数，非多数），多数元素出现 > n/2 次，抵消后必有剩余。
3. 边界约定：循环统一从 `cnt = 0` 开始，第一个元素自动成为候选人，不用特判。

## 实现逻辑

三个动作循环做：**cnt 归零就换人 → 相等就加票 → 不等就减票**，最后返回候选人。

拿 `nums = [2,2,1,1,1,2,2]` 手推一遍：

| i | nums[i] | cnt 状态 | 动作 | cand | cnt |
| --- | --- | --- | --- | --- | --- |
| 0 | 2 | 0 | 换候选 | 2 | 1 |
| 1 | 2 | >0 | 同票 +1 | 2 | 2 |
| 2 | 1 | >0 | 异票 -1 | 2 | 1 |
| 3 | 1 | >0 | 异票 -1 | 2 | 0 |
| 4 | 1 | 0 | 换候选 | 1 | 1 |
| 5 | 2 | >0 | 异票 -1 | 1 | 0 |
| 6 | 2 | 0 | 换候选 | 2 | 1 |

返回 `cand = 2`。注意中间 `cand` 一度换成了 1，但最后多数元素 2 把余票吃回来了。

C++ 用范围 for 遍历，`x == cand ? cnt++ : cnt--`；Python 用 `elif` 三级分支，逻辑一样。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int majorityElement(vector<int>& nums) {
>         int cand = 0, cnt = 0;              // 候选人和票数余量
>         for (int x : nums) {
>             if (cnt == 0) {                 // 归零换人
>                 cand = x;
>                 cnt = 1;
>             } else if (x == cand) {         // 同票 +1
>                 cnt++;
>             } else {                        // 异票 -1
>                 cnt--;
>             }
>         }
>         return cand;                        // 保证有解，cand 必是多数
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def majorityElement(self, nums: list[int]) -> int:
>         cand, cnt = 0, 0                    # 候选人和票数余量
>         for x in nums:
>             if cnt == 0:                    # 归零换人
>                 cand, cnt = x, 1
>             elif x == cand:                 # 同票 +1
>                 cnt += 1
>             else:                           # 异票 -1
>                 cnt -= 1
>         return cand                         # 保证有解，cand 必是多数
> ```

## 复杂度

- 时间：O(n)，每个元素只做常数次比较，一趟扫完。
- 空间：O(1)，只用候选人和计数器两个变量。

## 易错点

1. `nums = [1,2,2,2,2]`：**先判断 cnt==0 再比较**。若顺序写反（先比相等再判断归零），`cnt` 会减成负数，候选永远卡在 1，错返回 1。
2. 摩尔投票只保证「若存在多数元素，最后剩下的候选就是它」：`nums = [1,2,3]` 会返回 3，但 3 不是多数——本题题目保证有解才安全，不保证时要做二次校验（见 229 题）。
3. 计数方案里 `cnt` 要数到 > n/2 才返回：`nums = [1,1,2]` 中 1 出现 2 次 > 1.5，别写成 `>= n/2`。
4. Python：`cand, cnt = x, 1` 是同时赋值，分开写两行中间没有依赖问题，但别把顺序写反成 `cnt = 1; cand = x` 后忘记 `cand`。
