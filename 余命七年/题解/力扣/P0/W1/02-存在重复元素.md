# 217. 存在重复元素 Contains Duplicate

## 一句话题意

给数组 `nums`，任一值出现至少两次返回 `true`，全不重复返回 `false`（不涉及下标）。

## 解题逻辑

**先想什么**：读完题第一反应是「每个数都往后扫一遍」，两层循环逐个比对。

**朴素解法**：外层固定 `nums[i]`，内层从 `i+1` 开始找有没有相等的。O(n²)，n 最大 1e5 时约 5e9 次比较，力扣必超时。

**优化观察**：内层循环其实在反复做同一件事——**「这个值之前出现过吗」**，这是一次集合查找。把「已经见过的值」放进哈希集合，查找就从 O(n) 变成 O(1)。再进一步：不需要预处理，**边遍历边查边插**，一趟结束，遇到重复立刻返回。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 两层循环 | O(n²) | O(1) | 1e5 数据直接超时 |
| 排序 + 扫相邻 | O(n log n) | O(log n) | 要动原数组（或复制一份），多一步排序 |
| 哈希集合 | O(n) | O(n) | 多用一点内存 |

**选哈希集合**：这题不求下标、不求位置，只问「在不在」，哈希集合 O(n) 时间压到最优，代码三行，是「判重」题的标准解。

## 关键点

1. 集合存**已经见过的值**，查找 O(1)。
2. 遇到重复**立刻返回 `true`**（早停），不用把数组扫完；整个数组走完才返回 `false`。
3. C++ 的 `insert` 返回 `pair<迭代器, bool>`，`second == false` 说明值已存在；Python 用 `if x in seen` 判断。
4. 空数组、单元素数组天然没有重复：循环不进或只走一次，直接落到 `return false`，不用特判。

## 实现逻辑

四个动作循环做：**建空集合 → 遍历 → 查到重复就返回 true → 没查到把自己插进去**。

拿 `nums = [1,2,3,1]` 手推一遍：

| i | 当前值 | 查什么 | 结果 | 集合状态 |
| --- | --- | --- | --- | --- |
| 0 | 1 | 1 在集合里吗 | 不在 → 插入 | {1} |
| 1 | 2 | 2 在集合里吗 | 不在 → 插入 | {1,2} |
| 2 | 3 | 3 在集合里吗 | 不在 → 插入 | {1,2,3} |
| 3 | 1 | 1 在集合里吗 | 在 → 返回 true | — |

C++ 里 `count` 等价于「在不在」，找到直接 `return true`；Python 里 `if x in seen` 判断，`add` 插入。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     bool containsDuplicate(vector<int>& nums) {
>         unordered_set<int> seen;              // 存已经见过的值
>         for (int x : nums) {
>             if (seen.count(x)) return true;   // 见过 = 重复，立刻返回
>             seen.insert(x);                   // 没见过才插入
>         }
>         return false;                         // 走完都没有重复
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def containsDuplicate(self, nums: list[int]) -> bool:
>         seen = set()                    # 存已经见过的值
>         for x in nums:
>             if x in seen:               # 见过 = 重复
>                 return True
>             seen.add(x)                 # 没见过才插入
>         return False                    # 走完都没有重复
> ```

## 复杂度

- 时间：O(n)，每个元素查一次、最多插一次哈希集合（平均 O(1)），共 n 次。
- 空间：O(n)，最坏所有值都不同，集合要存下全部 n 个。

## 易错点

1. 不排序就比相邻：`nums = [1,2,1]` 里 `nums[1] != nums[2]` 但 1 出现了两次——只扫一遍比较相邻会漏判，集合（或先排序）才对。
2. 用 `list` 当「已见」容器：`if x in seen` 对列表是 O(n)，整套变成 O(n²)，`nums = [0..49999 全不重复, 0]` 会超时——必须用 `set`。
3. C++：`unordered_set` 没有 `operator[]`，写 `seen[x]` 直接编译不过；查存在只能用 `count` / `find` / `insert` 的返回值。
4. C++：忘记 `#include <unordered_set>`，本地和力扣都会报「未声明」的编译错。
5. Python 一行式 `return len(set(nums)) < len(nums)` 也能过，但先建完整集合、不早停：`nums = [1,1] + [0]*100000` 时早停版第一次循环就返回，一行式要把 10 万个 0 全插完。
