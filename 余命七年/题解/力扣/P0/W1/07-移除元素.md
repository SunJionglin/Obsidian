# 27. 移除元素 Remove Element

## 一句话题意

原地删除所有等于 `val` 的元素，返回新数组长度 `k`，下标从 0 起。

## 解题逻辑

**先想什么**：读完题第一反应是「新建一个数组，把不等于 `val` 的抄进去」。但题目要求**原地**修改、只用 O(1) 额外空间，新建数组这一招被卡死。

**朴素解法**：遍历时每遇到 `val` 就 `erase` 删掉它。erase 会触发后面所有元素整体前移，删 m 个元素约 O(n²) 的搬移量，n 到 1e4 时力扣会超时。

**优化观察**：erase 慢在「删一个动一片」。换个思路——**不删，而是用保留元素把废弃位置覆盖掉**。快指针 `i` 从头扫到尾，慢指针 `k` 指着「下一个要写入的位置」，遇到保留元素就写到 `nums[k]` 并让 `k` 前进。一趟扫完，`[0, k)` 就是新数组，长度恰好是 `k`。靠「双指针各走各的、每个元素只处理一次」把 O(n²) 降到 O(n)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 新建数组 + 拷贝 | O(n) | O(n) | 不满足题目 O(1) 空间要求 |
| 边遍历边 erase | O(n²) | O(1) | 每次删除元素整体前移，大数据超时 |
| 快慢双指针 | O(n) | O(1) | 无 |

**选双指针**：原地、一趟、零额外空间，三个要求一次满足，而且不要求返回元素有序——它就是数组原地去值类问题的标准模板。

## 关键点

1. 慢指针 `k` 有双重含义：**下一个写入的位置**，循环结束时**恰好等于答案长度**。
2. 不变量：任意时刻 `nums[0..k)` 全是保留元素，`nums[k..i)` 是已扫过的废弃区。
3. 覆盖永远安全：`k <= i` 恒成立，写入位置不会超过快指针读到的位置，不会覆盖还没遍历的元素。
4. 判断条件是「**不等于** val 才保留」，等于的跳过，别写反。

## 实现逻辑

先初始化 `k = 0` → 快指针 `i` 扫数组，遇到 `nums[i] != val` 就 `nums[k++] = nums[i]` → 扫完返回 `k`。

拿 `nums = [3,2,2,3]`、`val = 3` 手推一遍：

| i | nums[i] | 判断 | 动作 | k | 数组状态 |
| --- | --- | --- | --- | --- | --- |
| 0 | 3 | ==3 跳过 | 无 | 0 | [3,2,2,3] |
| 1 | 2 | !=3 | nums[0]=2 | 1 | [2,2,2,3] |
| 2 | 2 | !=3 | nums[1]=2 | 2 | [2,2,2,3] |
| 3 | 3 | ==3 跳过 | 无 | 2 | [2,2,2,3] |

返回 `2`，`nums[0..2)` 是 `[2,2]`，尾部内容不用管。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int removeElement(vector<int>& nums, int val) {
>         int k = 0;                              // 慢指针，下一个写入位
>         for (int i = 0; i < (int)nums.size(); i++) {
>             if (nums[i] != val)                 // 保留的元素
>                 nums[k++] = nums[i];            // 覆盖写入，k 前进
>         }
>         return k;                               // 循环结束 k 即新长度
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def removeElement(self, nums: list[int], val: int) -> int:
>         k = 0                             # 慢指针，下一个写入位
>         for x in nums:                    # 直接迭代，比下标写法更 Python
>             if x != val:                  # 保留的元素
>                 nums[k] = x               # 覆盖写入
>                 k += 1
>         return k
> ```

## 复杂度

- 时间：O(n)，每个元素只被快指针扫过一次，处理 O(1)。
- 空间：O(1)，只用了一个变量 `k`，原地覆盖。

## 易错点

1. 返回 `k` 而不是 `nums.size()`：`nums = [3,2,2,3]`、`val = 3` 应返回 `2`，返回 `4` 会被判错。
2. 忘了写回数组：`nums = [0,1,2,2,3,0,4,2]`、`val = 2` 如果只计数不执行 `nums[k] = x`，数组原地没变，判题按前 `k` 个元素校验会挂。
3. 条件写反：`if nums[i] == val` 才写入，等于把「要删的」留下来，样例直接全错。
4. C++：`nums.size()` 是无符号数，和 `int i` 比较有符号转换警告，先 `(int)` 转一下。
5. Python：别用 `while` + `del/pop` 边删边遍历——`nums = [3,2,2,3]` 删掉下标 0 后元素前移，会漏扫元素；`remove` 还是 O(n) 的，整体退回 O(n²)。
