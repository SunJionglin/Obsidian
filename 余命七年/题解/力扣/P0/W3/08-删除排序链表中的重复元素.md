# 83. 删除排序链表中的重复元素 Remove Duplicates from Sorted List

## 一句话题意

升序链表去重，每个值只出现一次，返回原链表头节点。

## 解题逻辑

**先想什么**：链表有序，重复的元素一定紧挨在一起，「去重」就变成「相邻去重」。

**朴素解法**：用哈希表记录出现过的值，遇到见过的就删。O(n) 时间、O(n) 空间——虽然时间已经最优，但完全没用上「有序」这个条件，还多花一整个哈希表的内存。

**优化观察**：升序排列意味着**重复值必然相邻**，所以只要拿当前节点和它的下一个节点比：相等就跳过下一个，不等就前进。原地断链重连，空间从 O(n) 压到 O(1)，时间仍是 O(n)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 哈希表去重 | O(n) | O(n) | 浪费内存，没用到有序条件 |
| 新建链表逐个挑 | O(n) | O(n) | 额外节点开销，代码更长 |
| 原地单指针 | O(n) | O(1) | 连续多个重复时要小心别漏删 |

**选原地单指针**：有序 + 链式结构天然支持原地断链，一趟遍历时间空间都到理论下限，是最短最标准的写法。

## 关键点

1. 模板句：`while (cur && cur.next)` 遍历，`cur.next.val == cur.val` 时跳过下一个。
2. 不变量：`cur` 及它之前的链已经去重完毕；只有「不相等」才让 `cur` 前进。
3. 删掉重复节点后 **`cur` 原地不动**——连续 k 个重复要循环删 k-1 次，动了就会漏删。
4. 返回原 `head`：头节点的值一定是第一次出现，永远不会被删。

## 实现逻辑

三个动作循环做：**比相邻 → 相等就断链跳过 → 不等才前进**。

拿 `[1,1,2]` 手推一遍：

| 轮 | cur.val | cur.next.val | 相等吗 | 动作 | 链表状态 |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 | 1 | 是 | cur.next = cur.next.next，cur 不动 | 1→2 |
| 2 | 1 | 2 | 否 | cur 前进到 2 | 1→2 |
| 3 | 2 | 无 | 结束 | 循环退出 | 1→2 |

C++ 里比较 `cur->next->val == cur->val`，删节点是 `cur->next = cur->next->next`；Python 里同理，删完 `cur` 停在原地等下一轮比较。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     ListNode* deleteDuplicates(ListNode* head) {
>         ListNode* cur = head;
>         while (cur && cur->next) {            // 至少两个节点才需要比较
>             if (cur->next->val == cur->val) {
>                 cur->next = cur->next->next;  // 删掉重复节点，cur 不动
>             } else {
>                 cur = cur->next;              // 不重复才前进
>             }
>         }
>         return head;                          // 头节点不会被删，原样返回
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
>         cur = head
>         while cur and cur.next:              # 至少两个节点才比较
>             if cur.next.val == cur.val:
>                 cur.next = cur.next.next     # 删掉重复，cur 不动
>             else:
>                 cur = cur.next               # 不重复才前进
>         return head                          # 头节点不会被删
> ```

## 复杂度

- 时间：O(n)，每个节点最多被访问一次、删除一次，一趟遍历。
- 空间：O(1)，原地改 `next` 指针，只多一个 `cur`。

## 易错点

1. `[1,1,1]`：删掉一个 1 后 `cur` 原地不动，才能把第二个重复也删掉——`cur` 若前进就会漏删。
2. 空链表 `[]`：`head` 为空时直接解引用会崩，靠 `while (cur && cur->next)` 里 `cur` 的短路判断挡住。
3. `[1,2]` 无重复：循环结束时 `cur` 已走到末尾节点，返回 `cur` 会只返回最后一个节点，要返回 `head`。
4. C++：比较的是 `cur->next->val == cur->val`，删的也是 `cur->next`；写反成删 `cur` 自己会把第一个出现的值删掉。
5. Python：`head` 类型是 `Optional[ListNode]`，别直接写 `cur.next.val`，先判断 `cur and cur.next` 再取值。
