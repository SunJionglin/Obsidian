# 19. 删除链表的倒数第N个结点 Remove Nth Node From End of List

## 一句话题意

给一个单链表和整数 `n`，删掉**倒数第 n 个结点**（下标从 1 开始），返回删除后的头结点；`n` 保证不超过链表长度。

## 解题逻辑

**先想什么**：链表不能像数组那样直接按下标随机访问，要删「倒数第 n 个」，第一反应是数出总长再定位。

**朴素解法**：先完整遍历一遍数出长度 `len`，再走 `len - n` 步找到待删结点的前一个，改一下 `next` 指针。O(n) 时间、O(1) 空间，但要走**两遍**链表。

**优化观察**：倒数第 n 个，就是「离结尾差 n 步」的结点。让两个指针拉开固定间距 n——`fast` 先走 n 步，再让 `fast`、`slow` 一起走，`fast` 到链表尾时，`slow` 恰好停在待删结点的**前一个**。靠这个相对距离不变的不变量，一趟扫描就锁定位置，时间仍 O(n) 但只走一遍。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 数长度 + 再走一遍 | O(n) | O(1) | 遍历两遍，代码里要多记一个长度变量 |
| 栈（把结点压栈再弹 n 个） | O(n) | O(n) | 多花 O(n) 空间，删完还要处理栈顶指针 |
| 双指针 | O(n) | O(1) | 边界（删头结点）不加哨兵时要特判 |

**选双指针**：一趟扫描、不用额外空间，是「快慢指针定距」最标准的一道题；配一个哨兵结点还能把删头结点的特判一并消掉。

## 关键点

1. 模板句：`fast` 先走 **n 步**，然后 `fast`、`slow` 一起走到 `fast->next == nullptr`（fast 停在尾结点），`slow` 落在**待删结点的前一个**。
2. 不变量：两个指针的间距恒为 n，所以 fast 到尾时 slow 的位置就对应倒数第 n+1 个。
3. 边界约定：加**哨兵结点** `dummy`，即使删的是头结点，`slow` 也有「前一个」可操作，统一了所有情况。
4. 只动指针不改值：删除 = `slow->next = slow->next->next`，跨过目标结点即可。

## 实现逻辑

先造哨兵 `dummy` 并让两个指针都从它出发 → `fast` 先走 n 步 → `fast`、`slow` 一起走，直到 `fast` 到尾结点 → `slow->next` 跨过目标结点，返回 `dummy.next`。

拿 `head = [1,2,3,4,5]`、`n = 2` 手推（哨兵记作 D，目标 = 倒数第 2 个，即 4）：

| 循环变量 | fast 当前 | slow 当前 | 查什么 | 结果 | 链表状态 |
| --- | --- | --- | --- | --- | --- |
| i = 0..n-1 | 先走 2 步 | 停在 D | 走完没 | fast = 2 | D → 1 → 2 → 3 → 4 → 5 |
| fast->next 是否空 | fast = 2 | slow = D | fast->next 是否空 | 非空，一起走 | 同上 |
| fast->next 是否空 | fast = 3 | slow = 1 | fast->next 是否空 | 非空，一起走 | 同上 |
| fast->next 是否空 | fast = 4 | slow = 2 | fast->next 是否空 | 非空，一起走 | 同上 |
| fast->next 是否空 | fast = 5 | slow = 3 | fast->next 是否空 | 为空，停 | 3 正是 4 的前一个，删掉 4 |

C++ 里哨兵用栈上局部对象 `ListNode dummy(0, head)` 最省事，返回 `dummy.next`；Python 里 `dummy = ListNode(0, head)`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     ListNode* removeNthFromEnd(ListNode* head, int n) {
>         ListNode dummy(0, head);           // 哨兵，头被删时不用特判
>         ListNode *fast = &dummy, *slow = &dummy;
>         for (int i = 0; i < n; i++)        // fast 先拉开 n 步
>             fast = fast->next;
>         while (fast->next) {               // fast 到尾结点就停
>             fast = fast->next;
>             slow = slow->next;             // slow 停在待删结点的前一个
>         }
>         slow->next = slow->next->next;     // 跨过倒数第 n 个
>         return dummy.next;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
>         dummy = ListNode(0, head)          # 哨兵，头被删时不用特判
>         fast = slow = dummy
>         for _ in range(n):                 # fast 先拉开 n 步
>             fast = fast.next
>         while fast.next:                   # fast 到尾结点就停
>             fast = fast.next
>             slow = slow.next               # slow 停在待删结点的前一个
>         slow.next = slow.next.next         # 跨过倒数第 n 个
>         return dummy.next
> ```

## 复杂度

- 时间：O(n)，fast 一共走了 `n + (len - n) = len` 步，slow 走了 `len - n` 步，总步数与链表长度同阶，一趟扫完。
- 空间：O(1)，只多用了两个指针和一个哨兵，不随链表长度增长。

## 易错点

1. `head = [1]`、`n = 1`（删头结点）：不加哨兵时 `slow` 没有前驱，`if (slow == head) return head->next` 这类特判容易写漏——加 `dummy` 后天然统一。
2. `head = [1,2]`、`n = 1`（删尾结点）：循环条件写成 `while (fast)` 会让 fast 走到 `nullptr`，slow 多走一步落在**待删结点本身**，`slow->next` 指不到前驱。正确是 `while (fast->next)`，fast 停在尾结点。
3. `head = [1,2]`、`n = 2`（n 恰等于长度）：`fast` 先走 n 步后必须停在**尾结点 2**，不是空——`for` 循环只走 n 步，别多走。
4. `head = [1,2,3,4,5]`、`n = 5`（删的是头）：最后返回 `head` 就是错的，被删掉的结点还挂在前面；一律返回 `dummy.next`。
5. C++：忘写 `ListNode*` 的类型、或返回 `dummy`（哨兵本身）而不是 `dummy.next`，都会把 0 值结点带进结果。
