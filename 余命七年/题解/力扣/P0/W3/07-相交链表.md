# 160. 相交链表 Intersection of Two Linked Lists

## 一句话题意

给两个链表头结点 `headA`、`headB`，返回相交结点（同一结点而非值同），无交点返回 `null`。

## 解题逻辑

**先想什么**：两条链从交点开始往后完全重合，所以问题等价于「找到第一个被两条链共用的结点」。难点在两条链长度不一样，两个指针要能站到同一起跑线上同步走。

**朴素解法**：双重循环，把 A 的每个结点拿到 B 里逐个比对指针，O(m·n) 时间、O(1) 空间；m、n 都能到 3e4，最坏约 9e8 次比较，铁定超时。稍好一点的是哈希表，先把 A 的所有结点塞进 `unordered_set`，再遍历 B 查第一个命中的，O(m+n) 时间，但要 O(m) 额外空间。

**优化观察**：关键观察——两指针**同时出发，各自走完自己的链表后立刻切到对方链表头**。这样双方路程都变成 m+n，长度差被抹平：若相交，必然恰好在交点相遇；若不相交，会同时走到 null。靠「换路」把哈希表那份 O(m) 空间也省掉了。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 双重循环比对 | O(m·n) | O(1) | 大数据超时 |
| 哈希表存 A 再查 B | O(m+n) | O(m) | 多存一整条链的结点 |
| 双指针换路走 | O(m+n) | O(1) | 循环条件和换路方向不能写错 |

**选双指针**：时间和哈希一样都是 O(m+n)，空间压到 O(1)，核心代码只有四行；「走到头就换到对方头上」是链表相交题的标准模板，思路还能迁移到环形链表。

## 关键点

1. 模板句：`a = a ? a->next : headB; b = b ? b->next : headA;` 循环到 `a == b`，返回 `a`。
2. 不变量：每轮 `a`、`b` 走过的步数相同，双方路程差从 |m−n| 逐步抹平，最后都在「自己的尾巴 + 对方的路」上对齐。
3. 判相交比的是**结点指针相等**（同一结点），不是 `val` 相等——值相同也可能是两个不同结点。
4. 边界约定：无交点时两指针会**同时**走到 `null`，`a == b` 成立，返回 `nullptr`；空链表、两条链完全重合都不用特判。

## 实现逻辑

三个动作循环做：**各走一步 → 走到头就切到对方头 → a、b 相遇（或同归 null）即停**。

拿 A = [1,2,3]、B = [9,3]（公共尾结点 3）手推一遍：

| 步 | a 指向 | b 指向 | a == b? | 动作 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 0 | 1 | 9 | 否 | 出发 | A=1→2→3，B=9→3，3 是同一个结点 |
| 1 | 2 | 3(B尾) | 否 | 各走一步 | b 先踩到公共结点，a 还没到 |
| 2 | 3(A尾) | null | 否 | 各走一步 | b 走完 B，下一轮换路 |
| 3 | null | 1(A头) | 否 | 换路 | a 下一步切 B 头，b 已切到 A 头 |
| 4 | 9(B头) | 2 | 否 | 各走一步 | a 从 B 头重走 |
| 5 | 3(B尾) | 3(A尾) | 是 | 相遇返回 | 两个 3 是同一结点，答案正确 |

循环退出返回 `a`（即结点 3）。C++ 判等用 `a != b`，换路用三元运算符一行写完；Python 判等用 `is not`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
>         ListNode *a = headA, *b = headB;
>         while (a != b) {
>             a = a ? a->next : headB;   // a 走到头就切到 B 的头
>             b = b ? b->next : headA;   // b 走到头就切到 A 的头
>         }
>         return a;                      // 交点；无交点时二者同归 nullptr
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
>         a, b = headA, headB
>         while a is not b:              # 比的是结点身份，不是 val
>             a = a.next if a else headB # 走到头就换到对方链表
>             b = b.next if b else headA
>         return a                       # 交点；无交点时二者同为 None
> ```
>
> `Optional` 来自 `typing`，力扣环境已注入；本地跑补一句 `from typing import Optional`。

## 复杂度

- 时间：O(m+n)，两指针最多各走 m+n 步，无论有无交点都在 O(m+n) 内相遇或同归 null。
- 空间：O(1)，只多两个指针变量，哈希表都不用开。

## 易错点

1. **用 `val` 判断相交**：A = [1,3]、B = [2,3] 且两个 3 是不同结点，比 `val` 会误报相交返回 3，正确结果是 `null`——必须比结点本身（`a != b` / `is not`）。
2. **循环条件写成 `while (a && b)`**：A = [1,2,3,4]、B = [9,4]（公共结点 4），b 先走到 null 循环就退，返回结点 3，而答案是 4；条件必须是 `a != b`，让双方换路后继续走。
3. **不判空直接取 `next`**：A = [1,2]、B = [3] 无交点，b 先走到 null，下一轮 `b->next` 直接段错误；换路前必须先写 `b ? b->next : headA`。
4. **换路换错方向**：写成 `a = a ? a->next : headA`（切回自己头上），A = [1,2,3]、B = [9,3] 时 a 永远在 A 里绕、b 永远在 B 里绕，永不相等，死循环——必须切成**对方**的头。
5. **多此一举特判头相同**：A 和 B 完全同一串（如都指向 [1,2,3]），循环第一轮 `a == b` 直接返回 `headA`，加了特判反而容易写错。
