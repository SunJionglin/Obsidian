# 876. 链表的中间结点 Middle of the Linked List

## 一句话题意

给一个单链表的头结点，返回中间结点；下标从 0 数，偶数个返回第二个。

## 解题逻辑

**先想什么**：链表不知道总长，第一反应是数一遍结点个数，再从头走到一半的位置。

**朴素解法**：第一趟遍历数出长度 n，第二趟从头走 n/2 步，返回该结点。O(n) 时间、O(1) 空间。不够好：要走两趟，而且 n 是偶数时「n/2 到底是哪一个中间结点」得自己对着下标算，容易算错。

**优化观察**：一快一慢两个指针，快指针每轮走 2 步、慢指针走 1 步；快指针走到头（或走不动）时，慢指针恰好停在中间。两趟并成一趟，复杂度不变但只扫一遍，而且偶数长度时快指针「走空」的位置天然让慢指针落在**第二个**中间结点，不用额外算奇偶。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 两遍扫描 | O(n) | O(1) | 走两趟；偶数时下标要自己算，容易错 |
| 先存数组再取 n/2 | O(n) | O(n) | 多用一整条链表的空间 |
| 快慢指针 | O(n) | O(1) | 几乎无缺点，注意循环条件即可 |

**选快慢指针**：一遍扫描 + O(1) 空间，是链表找中点的标准写法，后面回文链表等题都要先用它找中点。

## 关键点

1. 快慢指针同起点出发，快走 2 步慢走 1 步，**快到头慢在中**。
2. 循环条件 `fast && fast->next`，两个都要判：偶数长度快指针走空、奇数长度快指针停在尾结点。
3. 偶数长度时循环正好把慢指针停在第二个中间结点，和题目约定一致，别在循环外再走一步。

## 实现逻辑

三个动作循环做：**判快指针能不能再走 2 步 → 慢走 1 步 → 快走 2 步**，不能走就返回慢指针。

拿 `[1,2,3,4]` 手推一遍（偶数长度，最容易错的）：

| 轮次 | slow | fast | fast && fast->next | 动作 | 结果 |
| --- | --- | --- | --- | --- | --- |
| 初始 | 1 | 1 | 1 && 2 = true | slow→2，fast→3 |  |
| 第 1 轮 | 2 | 3 | 3 && 4 = true | slow→3，fast→null |  |
| 第 2 轮 | 3 | null | null = false | 退出循环 | 返回 slow=3 ✓ |

3 是下标 2 的结点，正好是第二个中间结点。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> struct ListNode {
>     int val;
>     ListNode *next;
>     ListNode() : val(0), next(nullptr) {}
>     ListNode(int x) : val(x), next(nullptr) {}
>     ListNode(int x, ListNode *n) : val(x), next(n) {}
> };
> 
> class Solution {
> public:
>     ListNode* middleNode(ListNode* head) {
>         ListNode *slow = head, *fast = head;  // 同起点
>         while (fast && fast->next) {          // 先判空再走，顺序不能反
>             slow = slow->next;                // 慢指针走 1 步
>             fast = fast->next->next;          // 快指针走 2 步
>         }
>         return slow;                          // 快走不动时慢就在中点
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> from typing import Optional
> 
> class Solution:
>     def middleNode(self, head: Optional[ListNode]) -> Optional[ListNode]:
>         slow = fast = head                      # 同起点
>         while fast and fast.next:               # 两个条件缺一不可
>             slow = slow.next                    # 慢指针走 1 步
>             fast = fast.next.next               # 快指针走 2 步
>         return slow                             # 快走不动时慢就在中点
> ```

## 复杂度

- 时间：O(n)，快指针每轮走 2 步，最多 n/2 轮就走到头，只扫一遍。
- 空间：O(1)，只用了 slow、fast 两个指针。

## 易错点

1. `[1,2,3,4,5]`：循环条件写成 `while (fast)` 会崩——快指针停在尾结点 5 时，`fast->next->next` 解引用了空指针。
2. `[1,2,3,4]`：写成 `while (fast->next)` 也会崩——快指针走空（null）后还要访问 `fast->next`。正确条件必须是 `while (fast && fast->next)`。
3. `[1]`：链表只有一个结点，循环体一次都不该进；判断放在 while 里，别写成「先走一步再判断」。
4. `[1,2,3,4,5,6]`：答案是 4 不是 3，偶数长度要第二个中间结点；快慢指针天然满足，别在循环外手滑再走一步。
