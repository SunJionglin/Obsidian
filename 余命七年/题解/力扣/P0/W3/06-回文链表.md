# 234. 回文链表 Palindrome Linked List

## 一句话题意

给单链表头节点 `head`，判断节点值序列从头到尾和从尾到头是否相同，返回 `true` / `false`。

## 解题逻辑

**先想什么**：回文判断的本质是「两端字符往中间比」。数组里双指针随手就来，链表的难点在于左 → 右好走，右 → 左走不动。

**朴素解法**：遍历链表把值装进数组，再用 `i < j` 双指针从两端往中间比。O(n) 时间、O(n) 空间，答案是对的，但题目进阶要求 O(1) 空间，这只能拿基础分。

**优化观察**：链表没法从右往左走，但**反转链表**能让一段链倒过来走。把后半段原地反转，就得到一条从尾部向中间走的路径；头和反转后的后半段头两个指针往中间比即可。空间从 O(n) 降到 O(1)，靠的是反转操作原地改 `next` 指针，一个额外数组都不要。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 转数组 + 双指针 | O(n) | O(n) | 空间不达标，还丢了链表题的练习意义 |
| 递归（后序遍历比较） | O(n) | O(n) | 递归栈占 O(n) 空间，n 大时可能爆栈 |
| 快慢指针 + 反转后半段 | O(n) | O(1) | 会临时改动链表结构（本题比完不恢复也接受） |

**选快慢指针 + 反转**：它是链表版的「双指针从两端往中间比」，难点只在把「从右往左」变出来——反转后半段恰好给出从右往左读的指针，O(1) 空间一步到位，是这题的标准解。

## 关键点

1. 找中点模板句：`while (fast && fast->next) { slow = slow->next; fast = fast->next->next; }`——循环结束时，偶数长度 `slow` 停在**右半起点**，奇数长度停在**正中间节点**。
2. 反转模板句：`nxt = slow->next; slow->next = prev; prev = slow; slow = nxt;`——先存后改，三行倒链。
3. 比较不变量：右半段长度 ≤ 左半段，所以**以右半段指针 `r` 为空作循环终止**；奇数长度时正中间节点留在左半段不参与比较，天然没问题。
4. 边界约定：空链表或单节点直接返回 `true`，快指针的 `fast->next->next` 不用碰。

## 实现逻辑

三个动作串起来：**快慢指针找中点 → 反转后半段 → 左右两指针往中间比**，比较以右半段（较短）到头结束。

拿 `[1,2,2,1]` 手推一遍：

| 阶段 | 当前指针 | 查/做什么 | 结果 | 链表现状 |
| --- | --- | --- | --- | --- |
| 起步 | slow=fast=1(第0个) | 快慢指针就位 | — | 1→2→2→1 |
| 找中点·第1轮 | fast=1, fast->next=2 均非空 | 各走一步 | slow→2(第1个), fast→2(第2个) | 同上 |
| 找中点·第2轮 | fast=2, fast->next=1 均非空 | 各走一步 | slow→2(第2个), fast→null，循环结束 | slow 落在右半起点 |
| 反转 | prev=null, slow=2(第2个) | 三行倒链 | 后半段 [2,1] 变 [1,2]，prev 指向尾节点 1 | 左半 1→2，右半 1→2 |
| 比较·第1轮 | l=1(头), r=1(尾) | l->val == r->val? | 相等，l→2, r→2 | — |
| 比较·第2轮 | l=2, r=2 | 相等 | r→null，循环结束 | 返回 true |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     bool isPalindrome(ListNode* head) {
>         if (!head || !head->next) return true;   // 空链表 / 单节点必是回文
>         ListNode* slow = head;                   // 慢指针每次一步
>         ListNode* fast = head;                   // 快指针每次两步
>         while (fast && fast->next) {             // fast 到尾部时 slow 在中点
>             slow = slow->next;
>             fast = fast->next->next;
>         }
>         ListNode* prev = nullptr;                // 反转 slow 起的后半段
>         while (slow) {
>             ListNode* nxt = slow->next;          // 先存后改，防断链
>             slow->next = prev;
>             prev = slow;
>             slow = nxt;
>         }
>         ListNode* l = head;                      // 左端从原头开始
>         ListNode* r = prev;                      // 右端从反转后的头开始
>         while (r) {                              // 后半段短，以它为准
>             if (l->val != r->val) return false;
>             l = l->next;
>             r = r->next;
>         }
>         return true;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def isPalindrome(self, head: Optional[ListNode]) -> bool:
>         if not head or not head.next:          # 空链表 / 单节点必是回文
>             return True
>         slow = fast = head                     # 快慢指针找中点
>         while fast and fast.next:
>             slow = slow.next
>             fast = fast.next.next
>         prev = None                            # 反转后半段
>         while slow:
>             nxt = slow.next                    # 先存后改，防断链
>             slow.next = prev
>             prev = slow
>             slow = nxt
>         l, r = head, prev                      # 两端往中间比
>         while r:                               # 后半段短，以它为准
>             if l.val != r.val:
>                 return False
>             l = l.next
>             r = r.next
>         return True
> ```

## 复杂度

- 时间：O(n)，找中点约 n/2 步，反转约 n/2 步，比较约 n/2 步，合起来一趟半遍历。
- 空间：O(1)，全程只动了几个指针，没有额外数组。

## 易错点

1. `[1,2]`：比较循环若写成 `while (l && r)` 没问题，但**中点选错**（比如用 `while (fast->next && fast->next->next)` 却还从 `slow` 开始反转）会让右半段含左半尾部，奇数长度 `[1,2,1]` 时右段比左段长，`l` 走到 `null` 再取 `l->val` 直接崩。
2. `[1,2]`：反转时**先写 `slow->next = prev` 再取 `nxt`** 会断链——`nxt` 已经指回 `prev` 了，循环在原地打转。必须先存 `nxt` 再改 `next`。
3. `[1,0,1]`：值里有 0 时判断别写成 `if (!l->val != !r->val)` 之类花活，就朴素比 `l->val != r->val`；0 参与回文照样成立。
4. `[]` 或 `[1]`：不做提前返回直接进快指针循环，`fast->next->next` 会在单节点上解引用空指针。开头两行短路提前返回最稳。
5. Python：`nxt, slow.next = slow.next, prev` 一行等价 C++ 三行，但别自己写出 `slow.next, nxt = prev, slow.next`——右边求值时 `slow.next` 已经被左边改了。
