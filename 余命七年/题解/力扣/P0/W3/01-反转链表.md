# 206. 反转链表 Reverse Linked List

## 一句话题意

输入单链表头结点 `head`，**原地**反转后返回新的头结点（原链表的尾结点），结点值不变、只改指向。

## 解题逻辑

**先想什么**：反转就是让每个结点的 `next` 反过来指向前驱。但单链表只能朝后走，走到 `cur` 时它的前驱已经「过去」了，所以手里必须一直留着前驱。

**朴素解法**：递归，把问题缩成「先反转后半段，再把当前结点接到末尾」，O(n) 时间、O(n) 递归栈；力扣限制链长 5000，递归深度 5000 有爆栈风险，判题机也会判它不够稳。

**优化观察**：关键观察——每一步其实只需要**三个信息**，当前结点 `cur`、它的后继 `nxt`、前驱 `prev`。先把 `nxt` 存下来，再把 `cur->next` 拨向 `prev`，然后双指针整体前移一步。靠「用变量代替栈」把 O(n) 空间降到 O(1)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 递归 | O(n) | O(n) | 递归栈随链长增长，长链表爆栈 |
| 数组暂存再反接 | O(n) | O(n) | 多存一整份结点，写法绕 |
| 迭代双指针 | O(n) | O(1) | 必须先存后继再改指向，顺序不能反 |

**选迭代**：空间 O(1)、无爆栈风险，四行核心代码，是链表反转的标准答案，也是所有「翻转链表」变式题的模板。

## 关键点

1. 模板句：`nxt = cur->next; cur->next = prev; prev = cur; cur = nxt;` 一直循环到 `cur` 为空。
2. 不变量：`prev` 是已反转段的头，`cur` 是未处理段的头，两段始终相接。
3. 边界约定：空链表、单结点都**不用特判**，循环自然处理，返回 `prev` 即可（初始为 `nullptr`）。
4. 顺序铁律：先存 `nxt` 再改 `cur->next`，反了链表就断了。

## 实现逻辑

三个动作循环做：**存后驱 → 拨转 next → prev、cur 整体前移**。

拿 `head = [1,2,3]`（即 1→2→3→null）手推一遍：

| 轮次 | cur | nxt（存） | cur->next 改指 | prev | cur | 结构状态 |
| --- | --- | --- | --- | --- | --- | --- |
| 初始 | 1 | — | — | null | 1 | null←1→2→3→null |
| 1 | 1 | 2 | 1→null | 1 | 2 | 1→null，待 2→3→null |
| 2 | 2 | 3 | 2→1 | 2 | 3 | 2→1→null，待 3 |
| 3 | 3 | null | 3→2 | 3 | null | 3→2→1→null，cur 空退出 |

循环结束返回 `prev`，即结点 3。C++ 用三个 `ListNode*` 变量；Python 用元组同时赋值 `prev, cur = cur, nxt` 少写一行。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     ListNode* reverseList(ListNode* head) {
>         ListNode* prev = nullptr;      // 已反转段的头
>         ListNode* cur = head;          // 未处理段的头
>         while (cur) {
>             ListNode* nxt = cur->next; // 先存后继，防止改完回不去
>             cur->next = prev;          // 反转指向
>             prev = cur;                // 双指针前移
>             cur = nxt;
>         }
>         return prev;                   // 空链表返回 nullptr，天然正确
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
>         prev, cur = None, head       # 已反转段 / 未处理段
>         while cur:
>             nxt = cur.next           # 先存后继
>             cur.next = prev          # 反转指向
>             prev, cur = cur, nxt     # 同时前移
>         return prev
> ```
>
> `Optional` 来自 `typing`，力扣环境已注入；本地跑补一句 `from typing import Optional`。

## 复杂度

- 时间：O(n)，每个结点恰好访问一次。
- 空间：O(1)，只用 `prev`、`cur`、`nxt` 三个指针变量。

## 易错点

1. **先改指向再取后继会断链**：`head = [1,2]`，若先执行 `cur->next = prev` 再 `cur = cur->next`，cur 直接变成 `nullptr`，结点 2 就丢了，返回的只剩 [1]。
2. **返回 `cur` 而不是 `prev`**：循环结束时 `cur` 是空，`head = [1,2,3]` 会返回空链表，正确是返回 `prev`（指向 3）。
3. **`prev` 初始化成 `head`**：`head = [1,2]` 第一轮就把 1->next 指向 1 自己，链表成环，判题超时。`prev` 必须从 `nullptr` / `None` 开始。
4. **Python 省 `nxt` 省出问题**：先 `cur.next = prev` 再写 `prev, cur = cur, cur.next`，此时 `cur.next` 已经是 prev 而不是原后继，`head = [1,2,3]` 会漏掉后半段；`nxt` 必须在改指向**之前**取。
5. **无谓特判空/单结点**：`head = []` 直接返回 `nullptr`，`head = [1]` 返回 1，循环天然正确；加了特判反而容易写错。

## 一句话总结

**先存后驱、再拨指针、双指针前移**——`nxt = cur.next; cur.next = prev; prev = cur; cur = nxt`，一趟 O(n)、O(1) 空间的链表反转模板。
