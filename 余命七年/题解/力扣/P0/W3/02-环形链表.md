# 141. 环形链表 Linked List Cycle

## 一句话题意

给定链表头结点，判断链表里是否有环，有环返回 `true`，否则 `false`。

## 解题逻辑

**先想什么**：怎么知道「又走回老路了」——遍历时记住每个经过的结点，撞见重复的就有环。

**朴素解法**：哈希表存走过的结点地址，每走一步先查表再插入。O(n) 时间但 O(n) 空间，一条 1e4 的链表要额外存 1e4 个地址，纯为判环有点浪费。

**优化观察**：派两个速度不同的指针一起跑——快指针每次走两步、慢指针走一步。这是同向追及问题，相对速度是 1：有环时两个指针都在环里转圈，距离每轮缩短 1 格，**必然相遇**；没环时快指针先跑到 `nullptr` 结束。关键观察是用「速度差」替代「记住所有结点」，空间从 O(n) 直接降到 O(1)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 哈希表存结点 | O(n) | O(n) | 额外 set 存全部地址，空间不优 |
| 快慢指针 | O(n) | O(1) | 代码稍绕，相遇了也不知道环入口（那是 142 题的事） |
| 给结点打标记 | O(n) | O(1) | 会改动原链表，污染输入数据，不推荐 |

**选快慢指针**：空间 O(1)、不碰原链表，而且是链表题的通用套路——判中点（876）、找环入口（142）都建立在它上面，这题是它的入门款。

## 关键点

1. `slow`、`fast` 都从 `head` 出发，每轮 slow 走 1 步、fast 走 2 步，**先移动再比较**是否相遇。
2. 循环条件是 `fast && fast->next`，保证走两步不越界。
3. 有环必相遇：环内相对速度 1，距离每轮减 1，最多绕环一圈追上。
4. 循环正常结束（fast 走到空）= 无环。

## 实现逻辑

先两个指针都指向 `head` → 循环里 fast 走两步、slow 走一步 → 比较两者地址，相同返回 `true` → 循环退出返回 `false`。

拿 `head = [3,2,0,-4]`、`pos = 1`（3 → 2 → 0 → -4 → 回到 2）手推一遍：

| 轮次 | slow | fast | 相遇？ | 说明 |
| --- | --- | --- | --- | --- |
| 初始 | 3 | 3 | — | 都指向头结点 |
| 1 | 2 | 0 | 否 | slow 一步到 2，fast 两步到 0 |
| 2 | 0 | 2 | 否 | slow 到 0，fast 走 -4 → 2 |
| 3 | -4 | -4 | 是 | 相遇，返回 true |

C++ 里比较的是指针地址 `slow == fast`；Python 里用 `is` 比较对象同一性。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     bool hasCycle(ListNode *head) {
>         ListNode *slow = head, *fast = head;
>         while (fast && fast->next) {   // 快指针能再走两步才继续
>             slow = slow->next;         // 慢指针走一步
>             fast = fast->next->next;   // 快指针走两步
>             if (slow == fast)          // 相遇 = 有环
>                 return true;
>         }
>         return false;                  // 快指针走到空 = 无环
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def hasCycle(self, head: Optional[ListNode]) -> bool:
>         slow = fast = head
>         while fast and fast.next:   # 快指针能再走两步才继续
>             slow = slow.next        # 慢指针走一步
>             fast = fast.next.next   # 快指针走两步
>             if slow is fast:        # 相遇 = 有环
>                 return True
>         return False                # 快指针走到空 = 无环
> ```

## 复杂度

- 时间：O(n)，无环时快指针走不到 n 步就出循环；有环时进环后距离每轮减 1，加上进环前的路程总共也是 O(n)。
- 空间：O(1)，只有两个指针变量。

## 易错点

1. `head = []` 空链表：循环条件只写 `while (fast)` 的话，进去取 `fast->next->next` 就是解引用空指针；条件必须带上 `fast->next`。
2. `[1]` 单结点无环：fast 指向 1，`fast->next` 是空，`fast->next->next` 越界崩溃——`fast && fast->next` 两层判空一个都不能少。
3. `[1,2]` 且 2 指回 1（pos = 0）：循环写成 `while (slow != fast)` 会因为初始 slow == fast == head 直接不进入，误报无环；正确姿势是先移动再比较。
4. `[1,2,3,4,5]` 无环：fast 最后会落在 5 上，下一步取 `fast->next->next` 已经越界，靠循环条件挡住。
5. Python：判相遇用 `is` 而不是 `==`，比的是结点同一性，别让「值相同」干扰判断。
