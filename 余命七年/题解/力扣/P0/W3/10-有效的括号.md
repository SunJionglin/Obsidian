# 10. 有效的括号 Valid Parentheses

## 一句话题意

给一个只含括号的字符串，判断括号是否按正确顺序成对闭合，返回布尔值（无下标）。

## 解题逻辑

**先想什么**：读完题第一反应是「配对 + 嵌套」，这种「后出现的先配」正是栈的味道。

**朴素解法**：每遇到一个右括号，往前扫找最近的左括号配对，再把它俩划掉。每个右括号最坏要扫完前面所有字符，O(n²)；而且「最近没配掉的左括号」正是下一次要查的，反复扫浪费。

**优化观察**：右括号必须匹配**最近一个还没配掉的左括号**——这是天然的后进先出。用栈存左括号，栈顶就是每次要找的那个，检查一次 O(1)，一趟遍历就完成验证，时间从 O(n²) 降到 O(n)。配对关系「右括号 → 左括号」预先存进哈希表，查配对也是 O(1)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 计数法（+1/-1） | O(n) | O(1) | 只能处理一种括号，`([)]` 这种交错会误判 |
| 反复删 "()" "[]" "{}" | O(n²) | O(1) | 每轮扫描+替换，慢 |
| 栈 + 配对表 | O(n) | O(n) | 多用一点内存 |

**选栈**：括号的嵌套结构就是后进先出，栈顶天然是「最近未配对的左括号」；计数法省内存但判不了多种括号的顺序，反复删写起来又慢。栈是这题的标准解，也是「括号类」题目的通用骨架。

## 关键点

1. 右括号只和**栈顶**比：栈顶正是最近未配对的左括号，配对即弹栈。
2. 弹栈前先判空：空栈遇右括号直接 `false`，不然 `top()`/`pop()` 会崩。
3. 遍历完栈必须为空：剩左括号说明没配完。
4. 模板句：**左括号一律入栈，右括号匹配则出栈，配不上直接失败**。

## 实现逻辑

四个动作循环做：**判断左右 → 右括号查栈顶（栈空即失败）→ 配不上返回 false，配得上弹栈 → 左括号压栈**，最后看栈空不空。

拿 `s = "([])"` 手推一遍：

| i | 字符 | 查什么 | 结果 | 栈状态 |
| --- | --- | --- | --- | --- |
| 0 | `(` | 左括号 | 压栈 | `[(` |
| 1 | `[` | 左括号 | 压栈 | `([` |
| 2 | `]` | 栈顶 `[` 是否配对 | 是，弹栈 | `(` |
| 3 | `)` | 栈顶 `(` 是否配对 | 是，弹栈 | 空 |

最后栈空 → `true`。C++ 里用 `close.count(c)` 判断是不是右括号，Python 里用 `c in close`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     bool isValid(string s) {
>         stack<char> st;
>         unordered_map<char, char> close = {{')', '('}, {']', '['}, {'}', '{'}};
>         for (char c : s) {
>             if (close.count(c)) {                       // 是右括号
>                 if (st.empty() || st.top() != close[c]) // 空栈或配不上
>                     return false;
>                 st.pop();
>             } else {                                    // 左括号一律压栈
>                 st.push(c);
>             }
>         }
>         return st.empty();                              // 不允许剩左括号
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def isValid(self, s: str) -> bool:
>         st = []
>         close = {')': '(', ']': '[', '}': '{'}
>         for c in s:
>             if c in close:                          # 是右括号
>                 if not st or st.pop() != close[c]:  # 空栈或配不上
>                     return False
>             else:                                   # 左括号一律压栈
>                 st.append(c)
>         return not st                               # 不允许剩左括号
> ```

## 复杂度

- 时间：O(n)，每个字符至多入栈、出栈各一次，查配对 O(1)。
- 空间：O(n)，栈最坏存 n 个左括号。

## 易错点

1. `s = "]"`：空栈直接 `top()` 会崩——先判 `st.empty()` 再取栈顶。
2. `s = "([)]"`：栈里 `([`，遇 `)` 时栈顶是 `[`——只数个数不判顺序会误判成 `true`。
3. `s = "["`：遍历完忘记查栈空，剩一个左括号也会错返回 `true`。
4. Python：`if not st or st.pop() != close[c]` 顺序不能反，靠 `or` 短路保证空栈时不会 `pop`。
5. C++：判断右括号用 `close.count(c)`，别用 `close[c]`——后者会顺手往表里插新键。

## 一句话总结

**左括号进栈，右括号对栈顶，最后栈空**——括号合法的判断 = 一次遍历里栈始终配得平、收尾不剩。
