# W3 总结 · 链表 · 栈队列 · 二分入门

> 对应题单：[[P0-基础补强(W1-3)]] · 18 道。

## 一、链表：先想 dummy 和快慢指针

- **dummy 头结点**：统一「删头结点」和「删中间」的写法。
  - [[04-移除链表元素]]、[[08-删除排序链表中的重复元素]]、[[09-删除链表的倒数第N个结点]]（快指针先走 n 步）。
- **快慢指针**：
  - [[02-环形链表]]：一步两步，追上即有环。
  - [[05-链表的中间结点]]：快指针到头时，慢指针在中间。
  - [[06-回文链表]]：找中点 + 反转后半段 + 两段比较。
- **穿针引线**：
  - [[01-反转链表]]：三个指针 `pre/cur/nxt` 逐个翻转。
  - [[03-合并两个有序链表]]：两串比头，小的接上。
  - [[07-相交链表]]：两指针走到头就换到对方头上，第二次相遇即交点。

## 二、栈：括号与配对

- [[10-有效的括号]]：左括号入栈，右括号配对出栈。
- [[11-最小栈]]：**辅助栈**同步存当前最小值。
- [[14-删除字符串中的所有相邻重复项]]：字符入栈，和栈顶相同就弹。

## 三、队列与栈互实现

- [[12-用栈实现队列]]：双栈，出队时把入栈倒进出栈。
- [[13-用队列实现栈]]：每入队一个新元素，把前面的全部转一圈，让它排到队头。

## 四、二分：一套模板四种变体

统一模板：`l = 0, r = n-1`（或 n），`while (l <= r)`，`mid = l + (r-l)/2`。

- [[15-二分查找]]：标准找 `==`。
- [[16-搜索插入位置]]：找不到时 `l` 就是插入位。
- [[17-第一个错误的版本]]：找第一个 `true`，右边界收敛。
- [[18-x的平方根]]：二分答案 + 注意 `mid*mid` 溢出（用 `mid <= x/mid`）。

## 一句话提醒

链表题先画图再动手，**改指向的顺序反了就丢链**；二分题死磕一个模板，别每次现想边界。
