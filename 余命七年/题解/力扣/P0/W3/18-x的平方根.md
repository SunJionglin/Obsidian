# 69. x 的平方根 Sqrt(x)

## 一句话题意

给非负整数 `x`，返回 `x` 的算术平方根**向下取整**的整数部分（0 也合法），不能调用内置 `sqrt`。

## 解题逻辑

**先想什么**：读完题第一反应是「从 0 开始挨个试」，`i*i` 第一次超过 `x` 就返回 `i-1`。

**朴素解法**：`i` 从 0 线性扫到 `x`，找最大的 `i` 使 `i*i <= x`。O(√x)，`x` 到 2^31-1 时约 4.6 万次，不算太慢但也不优雅；更要命的是 `i*i` 本身会溢出（`i` 超过 46340 后 `i*i` 爆 int 变负数，判断全乱）。

**优化观察**：`f(mid) = mid*mid` 在非负数上**单调递增**，要找「最后一个满足 `mid² ≤ x` 的 mid」——单调函数上找分界点，正是二分的活。区间每次减半，复杂度从 O(√x) 压到 O(log x)；判断改用 `mid <= x / mid`，顺便把乘法溢出一起解决。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 线性扫描 | O(√x) | O(1) | 随 `x` 平方根增长；`i*i` 会溢出 |
| 牛顿迭代法 | O(log x)（收敛更快） | O(1) | 浮点运算，初值选择和收敛判断难记，面试不常用 |
| 二分查找 | O(log x) | O(1) | 边界和溢出要小心 |

**选二分**：`x` 最多 2^31-1，log₂(2^31) 就是 31 次内出结果，整数运算无精度问题；而且它就是二分模板「找满足条件的最大值」的变形，跟 W3 前几题同一套框架，最好记。

## 关键点

1. 模板句：`left <= right` + `ans` 变量，二分找**最后一个**满足 `mid² <= x` 的 mid。
2. 判断一律写 `mid <= x / mid`，绝不写 `mid * mid <= x`——`x = 2147483647` 时 mid 能到 1e9 量级，`mid*mid` 溢出成负数。
3. `x < 2` 提前返回 `x`，躲开 `mid = 0` 时 `x / mid` 的除零。
4. `mid` 用 `left + (right - left) / 2` 算，防 `left + right` 溢出。

## 实现逻辑

四个动作：**特判 `x < 2` → 算 `mid` → 用除法判断、更新区间 → 返回 `ans`**。

拿 `x = 8` 手推一遍：

| left | right | mid | mid ≤ x/mid? | 动作 | ans |
| --- | --- | --- | --- | --- | --- |
| 0 | 8 | 4 | 4²=16 > 8，不满足 | right = 3 | 0 |
| 0 | 3 | 1 | 1²=1 ≤ 8，满足 | ans = 1，left = 2 | 1 |
| 2 | 3 | 2 | 2²=4 ≤ 8，满足 | ans = 2，left = 3 | 2 |
| 3 | 3 | 3 | 3²=9 > 8，不满足 | right = 2 | 2 |

`left = 3 > right = 2` 退出循环，返回 `ans = 2` ✓

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int mySqrt(int x) {
>         if (x < 2) return x;                       // 0 和 1 直接返回，避免 mid=0 除零
>         int left = 0, right = x, ans = 0;
>         while (left <= right) {
>             int mid = left + (right - left) / 2;   // 防 left+right 溢出
>             if (mid <= x / mid) {                  // 等价于 mid*mid <= x，且不溢出
>                 ans = mid;                         // 记录当前可行解
>                 left = mid + 1;                    // 往更大处找
>             } else {
>                 right = mid - 1;
>             }
>         }
>         return ans;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def mySqrt(self, x: int) -> int:
>         if x < 2:
>             return x                      # 0 和 1 直接返回
>         left, right, ans = 0, x, 0
>         while left <= right:
>             mid = (left + right) // 2     # Python 大整数不溢出，直接相加即可
>             if mid <= x // mid:           # 等价于 mid*mid <= x，用 // 保持整数
>                 ans = mid
>                 left = mid + 1
>             else:
>                 right = mid - 1
>         return ans
> ```

## 复杂度

- 时间：O(log x)，每轮区间减半，`x` 最大 2^31-1 时不超过 31 轮。
- 空间：O(1)，只用了 `left`、`right`、`mid`、`ans` 几个整型变量。

## 易错点

1. `x = 2147483647`：写 `mid * mid <= x` 会溢出，`mid` 取到 1e9 量级时 `mid*mid` 爆 int 变负数，判断全乱——必须写 `mid <= x / mid`。
2. `x = 0`：不特判的话第一轮 `mid = 0`，`x / mid` 是 0/0 直接崩——`x < 2` 提前返回 `x`。
3. `x = 8` 答案是 2 不是 3：题目要**向下取整**。循环结束时 `left = 3` 已经越过答案，直接返回 `left` 是错的，要返回 `ans`。
4. C++：`left + right` 可能超过 INT_MAX（`x` 本身就到 2^31-1），中点的写法固定用 `left + (right - left) / 2`。
5. Python：`mid` 要用 `//` 整除，用 `/` 会得到 float，`x / mid` 也一并换成 `x // mid`，全程整数最干净。
