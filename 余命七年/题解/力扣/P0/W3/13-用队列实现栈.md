# 225. 用队列实现栈 Implement Stack using Queues

## 一句话题意

用队列模拟栈，实现 `push`、`pop`、`top`、`empty` 四个操作，`pop` 和 `top` 返回栈顶元素。

## 解题逻辑

**先想什么**：队列是先进先出（FIFO），栈是后进先出（LIFO），两者的顺序刚好相反。直接塞进队列的话，队头是「最先入栈」的元素而不是栈顶，所以核心矛盾是——**怎么让最后来的元素排到最前面**。

**朴素解法**：两个队列。`push` 时新元素先进 `q2`，再把 `q1` 里的所有元素按顺序倒进 `q2`，最后 `swap(q1, q2)`，让新元素永远守在 `q1` 队头。`push` O(n)，`pop`/`top` O(1)，空间 O(n)。能用，但每次 `push` 都要在两个容器之间倒来倒去，代码要维护「谁在存数据」的约定。

**优化观察**：倒腾结束后 `q2` 总是空的——它只是个中转站。既然中转站用完即弃，把「倒到另一个队列」换成「在同一个队列里旋转」：入队后，把队头的前 n−1 个元素依次弹出再插回队尾，新元素就被顶到了队头。少一个容器、少一次 `swap`，还顺手回答了力扣的进阶问题：**能否只用一个队列实现？能。**

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 两队列 · push 倒腾 | push O(n)，pop O(1) | O(n) | 两个容器换来换去，要记「谁是主队列」 |
| 两队列 · pop 倒腾 | push O(1)，pop O(n) | O(n) | `top` 也要倒腾 n−1 个元素，最常调用的操作反而慢 |
| 单队列 · push 旋转 | push O(n)，pop O(1) | O(n) | push 多 O(n) 次旋转 |

**选单队列 push 旋转**：只有一个容器、没有 swap 记账，`pop`/`top`/`empty` 全是 O(1)；而且「旋转」这个动作把「用队列模拟栈」的本质讲得最清楚。

## 关键点

1. 模板句：`push` = 入队 + 旋转 n−1 次（弹出队头、插回队尾），把新元素顶到队头。
2. 不变量：任意时刻**队头就是栈顶**，队列从队头到队尾正好是「栈顶 → 栈底」的顺序。
3. 旋转次数是入队后的 `size - 1`：刚入队的新元素排在队尾，转完 n−1 次它恰好转到队头，一次不多一次不少。
4. `top` 只看队头不弹出；`empty` 直接透传队列的 `empty`，不另设计数器。

## 实现逻辑

先 `push` 入队 → 再循环 `n-1` 次「弹出队头、插回队尾」→ 最后 `pop`/`top`/`empty` 全部只盯队头。

拿操作序列 `push(1), push(2), push(3)` 手推：`push(1)` 入队后 `[1]`，n=1 不旋转；`push(2)` 入队后 `[1,2]`，旋转 1 次变 `[2,1]`。现在看 `push(3)` 的旋转循环，入队后 `q = [2,1,3]`，n=3，旋转 2 次：

| i | 当前值 q.front() | 查什么 | 结果 | 数据结构状态（队头→队尾） |
| --- | --- | --- | --- | --- |
| 0 | 2 | 不查，无条件搬 | 2 弹出、插到队尾 | [1,3,2] |
| 1 | 1 | 不查，无条件搬 | 1 弹出、插到队尾 | [3,2,1] |

转完后队头是 3，即最后入栈的元素。之后 `top()` 返回 3、`pop()` 返回 3 并把队列变回 `[2,1]`，LIFO 顺序成立。

C++ 里 `q.front()` 取队头、`q.pop()` 只弹不返回；Python 的 `deque` 用 `popleft()` 弹出并返回，还能 `q[0]` 直接取队头。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class MyStack {
>     queue<int> q;
> public:
>     MyStack() {}
>
>     void push(int x) {
>         q.push(x);                          // 新元素先进队尾
>         int n = q.size();
>         for (int i = 0; i < n - 1; i++) {   // 旋转 n-1 次, 把 x 顶到队头
>             q.push(q.front());
>             q.pop();
>         }
>     }
>
>     int pop() {
>         int x = q.front();                  // 队头就是栈顶
>         q.pop();
>         return x;
>     }
>
>     int top() {
>         return q.front();                   // 只看不弹
>     }
>
>     bool empty() {
>         return q.empty();
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> from collections import deque
>
> class MyStack:
>     def __init__(self):
>         self.q = deque()
>
>     def push(self, x: int) -> None:
>         self.q.append(x)
>         for _ in range(len(self.q) - 1):    # 旋转, 把 x 顶到队头
>             self.q.append(self.q.popleft())
>
>     def pop(self) -> int:
>         return self.q.popleft()             # 弹出并返回队头(栈顶)
>
>     def top(self) -> int:
>         return self.q[0]                    # deque 支持下标取队头
>
>     def empty(self) -> bool:
>         return not self.q
> ```

## 复杂度

- 时间：`push` O(n)（旋转 n−1 次，每次 O(1)），`pop`/`top`/`empty` O(1)。
- 空间：O(n)，一个队列存下全部 n 个元素，没有额外结构。

## 易错点

1. 旋转次数写成 n：`push(1)`、`push(2)` 后若转 2 次，队列 `[1,2] → [2,1] → [1,2]`，`top()` 返回 1 而不是 2——新元素白转一圈又回队尾。
2. Python 用 `list` 当队列：`list.pop(0)` 是 O(n)，每轮 push 变 O(n²)；换成 `collections.deque`，`append`/`popleft` 都是 O(1)。
3. `top()` 顺手弹掉：`push(1)`、`push(2)` 后连续两次 `top()` 都应返回 2，若实现成弹出，栈顶元素就丢了。
4. 空栈边界：新栈 `empty()` 应为 `true`；`empty()` 直接透传队列状态，别自己维护 size 计数器导致不同步。
5. C++ 想用 `q[0]` 或迭代器取队头——`queue` 没有下标和迭代器，只能 `front()`/`back()`，漏写 `#include <queue>` 也会编译报错。
