# 704. 二分查找 Binary Search

## 一句话题意

升序数组里找 `target`，返回 0 起下标；不存在返回 -1。

## 解题逻辑

**先想什么**：数组已经排好序，第一反应是「猜中间那个数」——和 `target` 比一次大小，就能甩掉一半区间。

**朴素解法**：从左往右线性扫一遍，相等就返回下标，扫完没找到返回 -1。O(n)；n ≤ 1e4 时其实能过，但完全没用上「有序」这个条件，等于把二分题当搜索题做。

**优化观察**：关键观察是——有序数组里取中间元素 `nums[mid]`，和 `target` 一比就能断定目标落在左半还是右半，每轮排除一半。靠「有序」这个条件把查找范围每轮砍半，O(n) 降到 O(log n)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 线性查找 | O(n) | O(1) | 没利用有序性，慢 |
| 哈希表存值→下标 | O(n) | O(n) | 建表就要 O(n)，比二分更差，白瞎有序条件 |
| 二分查找 | O(log n) | O(1) | 要求数组有序、支持下标随机访问 |

**选二分**：有序 + 可随机访问，正是二分的主场；O(log n) 时间、O(1) 空间，另两个方案没一个能打。

## 关键点

1. 区间不变量：全程维护闭区间 `[left, right]`，`target` 若存在必在区间里。
2. `mid = left + (right - left) / 2`：防 `left + right` 溢出，且向下取整落在 left 一侧。
3. 收缩必须跳过 mid：小→`left = mid + 1`，大→`right = mid - 1`；mid 已查过，不 ±1 会死循环。
4. 循环条件 `left <= right`：闭区间只剩一个元素（`left == right`）时也要检查。

## 实现逻辑

先初始化 `left = 0`、`right = n - 1` 框住整个闭区间；然后每轮取中间 `mid` 和 `target` 比——相等直接返回下标，`nums[mid] < target` 就把左半甩掉（`left = mid + 1`），否则甩掉右半（`right = mid - 1`）；最后区间空了（`left > right`）退出循环，返回 -1。

拿 `nums = [-1,0,3,5,9,12]`、`target = 9` 手推一遍：

| 轮 | left | right | mid | nums[mid] | 查什么 | 结果 | 区间状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 0 | 5 | 2 | 3 | target=9 | 3 < 9，甩左半 | [3,5] |
| 2 | 3 | 5 | 4 | 9 | target=9 | 命中 | 返回 4 |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int search(vector<int>& nums, int target) {
>         int left = 0, right = (int)nums.size() - 1;  // 闭区间 [left, right]
>         while (left <= right) {
>             int mid = left + (right - left) / 2;     // 防溢出，向下取整
>             if (nums[mid] == target) return mid;     // 命中直接返回
>             if (nums[mid] < target) left = mid + 1;  // 甩掉左半
>             else right = mid - 1;                    // 甩掉右半
>         }
>         return -1;                                   // 区间空了，没找到
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def search(self, nums: list[int], target: int) -> int:
>         left, right = 0, len(nums) - 1               # 闭区间 [left, right]
>         while left <= right:
>             mid = (left + right) // 2                # Python 整数不限长，天然不溢出
>             if nums[mid] == target:
>                 return mid
>             if nums[mid] < target:
>                 left = mid + 1
>             else:
>                 right = mid - 1
>         return -1
> ```

## 复杂度

- 时间：O(log n)，每轮把区间砍半，最多约 log₂n 轮就空了。
- 空间：O(1)，只用 left / right / mid 三个变量。

## 易错点

1. `nums = [1,3]`、`target = 3`：收缩写成 `left = mid`（漏了 +1）时，mid 恒为 0、left 卡死不动，死循环超时——已查过的 mid 必须跳过。
2. `nums = [5]`、`target = 5`：循环条件写成 `left < right` 一步都不进，直接返回 -1，单元素数组错判——闭区间要用 `left <= right`。
3. `nums = [-1,0,3,5,9,12]`、`target = 2`：循环结束必须 `return -1`，别顺手 `return right` 或 `return nums[right]`，那会给出下标 1 或元素 0，都是错的。
4. C++：`right = nums.size() - 1` 里 `size()` 是无符号数，空数组会下溢成巨大值；本题 n ≥ 1 无碍，但先 `(int)` 转换是习惯。
5. C++：`mid = (left + right) / 2` 在 `left + right` 超过 INT_MAX（约 2.1e9）时溢出成负数，下标变负直接越界；统一写 `left + (right - left) / 2`，这是模板的一部分。
