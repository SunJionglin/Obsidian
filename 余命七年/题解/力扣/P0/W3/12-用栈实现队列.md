# 232. 用栈实现队列 Implement Queue using Stacks

## 一句话题意

用两个栈实现队列的 `push`/`pop`/`peek`/`empty` 四操作，输入保证所有调用合法。

## 解题逻辑

**先想什么**：栈是后进先出、队列是先进先出，正好反着——那「把栈倒一遍」顺序就正过来了，所以第一反应是拿第二个栈当「倒扣」的容器。

**朴素解法**：每次操作都全量倒一次。要么 `push` 时用临时栈把新元素垫到栈底（push O(n)），要么 `pop`/`peek` 时把 n-1 个元素弹到临时栈再弹回来（pop O(n)）。这样每次操作最坏 O(n)，更浪费的是同一批元素会被反复搬来搬去，明显不划算。

**优化观察**：关键观察——**每个元素只需要被整体颠倒一次**，就能永远保持队列顺序。靠「惰性倒栈」降复杂度：设两个栈各司其职，`in` 只负责接新元素，`out` 只负责出队；只有当 `out` 空了，才把 `in` 一次性全部倒进 `out`。每个元素从 `in` 到 `out` 至多搬一次，n 次操作总共搬 O(n) 次，均摊下来每次操作 O(1)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| push 时垫栈底 | push O(n)，其余 O(1) | O(n) | 每次入队都全量倒栈，入队频繁时很慢 |
| pop 时全量倒回 | push O(1)，pop O(n) | O(n) | 每次出队都 O(n)，且倒完又倒回，白搬 |
| 双栈 + 惰性倒栈 | push O(1)，pop/peek 均摊 O(1) | O(n) | 要理解均摊分析 |

**选双栈惰性倒栈**：把「全量倒栈」推迟到 `out` 空才做，每个元素只搬一次，均摊时间最优，是这题的标准解，也是「均摊复杂度」最入门的例子。

## 关键点

1. 模板句：**push 进 in；pop/peek 前，out 空才把 in 整个倒进 out**。
2. 不变量：`out` 栈顶永远是当前队列头（最早入队的元素）；`out` 非空时禁止倒 `in`，否则新元素插队。
3. 边界约定：`empty` 要 `in`、`out` 两个栈都空才算空；题目保证不会对空队列 `pop`/`peek`。

## 实现逻辑

先 push 直接压 `in` → 再 pop/peek 前检查 `out` 空不空，空了就把 `in` 全部倒进 `out` → 然后 pop 取 `out` 顶弹出、peek 只取不弹 → 最后 empty 看两个栈是否都空。

拿操作序列 `push 1,2,3 → pop → push 4 → peek → pop` 手推一遍：

| 操作 | 入参 | out 空吗 | 倒栈吗 | 结果 | in | out（顶在右） |
| --- | --- | --- | --- | --- | --- | --- |
| push | 1 | - | - | - | [1] | [] |
| push | 2 | - | - | - | [1,2] | [] |
| push | 3 | - | - | - | [1,2,3] | [] |
| pop | - | 是 | 3,2,1 倒入 | 返回 1 | [] | [3,2] |
| push | 4 | - | - | - | [4] | [3,2] |
| peek | - | 否 | 不倒（关键） | 返回 2 | [4] | [3,2] |
| pop | - | 否 | 不倒 | 返回 2 | [4] | [3] |

注意第 6 行：`push 4` 后 `out` 还压着 [3,2]，此时**绝不倒栈**，所以 4 乖乖排在 3 后面。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class MyQueue {
>     stack<int> in, out;
>     void pour() {                      // 只许 out 空时把 in 整个倒进去
>         if (out.empty())
>             while (!in.empty()) {
>                 out.push(in.top());
>                 in.pop();              // 边倒边清空，不残留
>             }
>     }
> public:
>     MyQueue() {}
>     void push(int x) { in.push(x); }
>     int pop()  { pour(); int x = out.top(); out.pop(); return x; }
>     int peek() { pour(); return out.top(); }   // 只取不弹
>     bool empty() { return in.empty() && out.empty(); }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class MyQueue:
>     def __init__(self):
>         self.ins, self.out = [], []    # list 当栈用：append 入、pop 出
> 
>     def _pour(self):                   # out 空时把 ins 整体倒进 out
>         if not self.out:
>             while self.ins:
>                 self.out.append(self.ins.pop())
> 
>     def push(self, x: int) -> None:
>         self.ins.append(x)
> 
>     def pop(self) -> int:
>         self._pour()
>         return self.out.pop()
> 
>     def peek(self) -> int:
>         self._pour()
>         return self.out[-1]            # 只取不弹
> 
>     def empty(self) -> bool:
>         return not self.ins and not self.out
> ```

## 复杂度

- 时间：push O(1)；pop/peek 均摊 O(1)——每个元素从 `in` 搬进 `out` 至多一次，n 次操作总搬动 O(n)，摊到每次就是 O(1)。
- 空间：O(n)，两个栈合计最多存 n 个元素。

## 易错点

1. `out` 非空时也倒栈：`push 1,2 → pop`（得 1）`→ push 3 → pop`，若第二个 pop 把 3 倒进 `out`，栈顶变 3，会返回 3 而不是 2——倒栈必须发生在 `out.empty()` 时。
2. 倒完不清空 `in`：`push 1 → peek → push 2`，若 peek 倒完 `in` 还留着 1，等 `out` 空后再倒会把 1 又倒一遍，pop 出重复的 1——要用 while 循环搬空，别只「复制」。
3. `empty` 只判一个栈：`push 1 → pop → push 2` 之后 `out` 空但 `in` 里有 2，只判 `out` 会误报队列已空。
4. 空队列调用 `pop`/`peek`：`out.top()` / `self.out[-1]` 会崩溃；力扣保证操作合法，但本地自测要先按 `empty` 兜底。
5. `peek` 复用 `pop` 时要放回 `out`（原位置），别放回 `in`——放回 `in` 会掉到队尾变成插队。
