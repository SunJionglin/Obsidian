# 35. 搜索插入位置 Search Insert Position

## 一句话题意

升序数组中找 `target` 下标（0 起），找不到返回插入位置。

## 解题逻辑

**先想什么**：上题 704 刚做完二分，这题多了一句话——「找不到就返回它按顺序插入的位置」。先别慌，拿 704 的代码想想：找不到的时候，循环退出那一刻手上有什么。

**朴素解法**：从左往右线性扫，第一个 `nums[i] >= target` 的位置就是答案（找到是下标，没找到是插入点）。O(n)；n ≤ 1e4 能过，但完全没用上「有序」，等于把二分题又退回成搜索题。

**优化观察**：关键观察是——**退出循环时的 `left` 恰好就是答案**。704 的收缩规则保证了循环中 `[0, left)` 全 < target、`(right, n-1]` 全 >= target，退出时 `left = right + 1` 正好骑在分界线上：target 在数组里，`left` 就是它的下标；不在，`left` 就是它该插的位置。靠「有序 + 每轮砍半」从 O(n) 降到 O(log n)，而且一行代码都不用多写，只改最后一行。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 线性扫描 | O(n) | O(1) | 没吃上「有序」红利，n 大或多组查询就慢 |
| 704 模板改一行（左闭右闭） | O(log n) | O(1) | 依赖上题模板，收缩方向写错会死循环 |
| 左闭右开 + lower_bound 风格 | O(log n) | O(1) | 和刚学的闭区间是两套记法，初学容易混 |

**选 704 模板改一行**：和上题无缝衔接、学习成本最低；O(log n) 达标，还能把「第一个 >= target 的位置」这条不变量练熟，给后面 34、278 题铺路。

## 关键点

1. 复用 704 三件套：`while (left <= right)`、`mid = left + (right - left) / 2`、收缩必 `mid ± 1`。
2. 唯一改动：末尾 `return -1` 换成 `return left`——退出循环时 `left` 就是第一个 >= target 的下标，找到是它、插入也是它。
3. 不变量：循环中 `[0, left)` 全 < target、`(right, n-1]` 全 >= target；退出时 `left = right + 1` 骑在分界线上。
4. 边界约定：答案允许落在 n（target 比所有元素都大），`left` 一路滑到 n 是正常路径，不用特判。

## 实现逻辑

先照 704 初始化 `left = 0`、`right = n - 1` 框住整个闭区间；然后每轮取中间 `mid` 和 `target` 比——相等直接返回下标，`nums[mid] < target` 甩掉左半（`left = mid + 1`），否则甩掉右半（`right = mid - 1`）；最后区间空了（`left > right`）退出循环，返回 `left`。

拿 `nums = [1,3,5,6]`、`target = 2`（找不到、要插中间的样例）手推一遍：

| 轮 | left | right | mid | nums[mid] | 查什么 | 结果 | 区间状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 0 | 3 | 1 | 3 | target=2 | 3 >= 2，甩右半 | [0,0] |
| 2 | 0 | 0 | 0 | 1 | target=2 | 1 < 2，甩左半 | left=1，空 |
| 退出 | 1 | 0 | — | — | — | left > right | 返回 left=1 |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int searchInsert(vector<int>& nums, int target) {
>         int left = 0, right = (int)nums.size() - 1;  // 704 同款闭区间 [left, right]
>         while (left <= right) {
>             int mid = left + (right - left) / 2;     // 防溢出，向下取整
>             if (nums[mid] == target) return mid;     // 找到就返回下标
>             if (nums[mid] < target) left = mid + 1;  // 甩掉左半
>             else right = mid - 1;                    // 甩掉右半
>         }
>         return left;                                 // 唯一改动：-1 换成 left，即插入位置
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def searchInsert(self, nums: list[int], target: int) -> int:
>         left, right = 0, len(nums) - 1               # 704 同款闭区间
>         while left <= right:
>             mid = (left + right) // 2                # Python 整数不限长，天然不溢出
>             if nums[mid] == target:
>                 return mid                            # 找到就返回下标
>             if nums[mid] < target:
>                 left = mid + 1
>             else:
>                 right = mid - 1
>         return left                                   # 唯一改动：-1 换成 left
> ```

## 复杂度

- 时间：O(log n)，区间每轮砍半，最多约 log₂n 轮就空了。
- 空间：O(1)，只用 left / right / mid 三个变量。

## 易错点

1. `nums = [1,3,5,6]`、`target = 2`：照抄 704 忘记改最后一行，找不到时返回 -1 直接 WA——应返回插入位置 1。
2. `nums = [1,3,5,6]`、`target = 0`：甩右半写成 `right = mid`（漏 -1）会卡在 `left == right == 0` 死循环超时——已查过的 mid 必须跳过。
3. `nums = [1,3,5,6]`、`target = 7`：不用写 `if (target > nums.back()) return n;` 特判，模板天然返回 left=4；特判写了反而多一条出错的路。
4. `nums = [1]`、`target = 0`：把左闭右开的 `right = n` 和 `left <= right` 混搭，`left == right` 时右缩不动，死循环——两套记法别混着用。
5. C++：`right = nums.size() - 1` 里 `size()` 是无符号数，空数组会下溢成巨大值；本题 n ≥ 1 无碍，先 `(int)` 转换是习惯。
