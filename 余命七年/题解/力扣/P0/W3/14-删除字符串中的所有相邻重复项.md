# 1047. 删除字符串中的所有相邻重复项 Remove All Adjacent Duplicates In String

## 一句话题意

给一个只含小写字母的字符串，反复删掉相邻的两个相同字符直到删不动，返回剩下的新字符串（无下标）。

## 解题逻辑

**先想什么**：删掉一对后，两边的字符会变成新的邻居，可能又凑成一对，所以第一反应是「多轮扫描，每轮删一次」。

**朴素解法**：每轮从头扫，看到 `s[i] == s[i+1]` 就把这两个字符抹掉，然后回到开头再扫，直到一整轮没有可删的为止。每轮 O(n)，最坏要 O(n) 轮（如 `"abccba"` 每次只凑出并删掉一对），总 O(n²)，长串会超时。

**优化观察**：删掉一对之后要比较的，永远只是「当前字符」和「还没被删掉的上一个字符」——新来的字符只跟栈顶比，这正是**后进先出**的模型。相等就 `pop`（一对一起消失），不等或栈空就 `push`。一趟扫完，所有可能的新配对都被顺手处理掉，靠栈把「反复回看」压成一次遍历。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 多轮扫描 | O(n²) | O(1) | 每轮重建字符串，最坏 O(n) 轮，超时 |
| 正则反复替换 | O(n²) | O(n) | 每次替换都重扫全文，实质还是多轮 |
| 栈（string 模拟） | O(n) | O(n) | 多用一份空间 |

**选栈**：相邻删除天然是「后进先出」，一次遍历就能处理删除后新产生的配对，时间压到最优，代码才 5 行，是这题的标准解。

## 关键点

1. 新字符**只和栈顶比**，不用回看整个前缀——这是栈能把 O(n²) 压到 O(n) 的原因。
2. 栈里存的是「还没被删掉的字符」，最后栈的内容就是答案，顺序天然正确，不用反转。
3. 相等就 `pop`（每轮恰好删两个字符），不等或栈空就 `push`。
4. C++ 直接用 `string` 的 `back()` / `pop_back()` / `push_back()` 当栈，不用单独开栈类。

## 实现逻辑

三个动作循环做：**取字符 → 和栈顶比 → 相等弹出、否则压入**，最后栈里剩下的串就是答案。

拿 `s = "abbaca"` 手推一遍：

| i | c | 查什么 | 动作 | 栈状态 |
| --- | --- | --- | --- | --- |
| 0 | a | 栈空 | push | `a` |
| 1 | b | 顶 `a != b` | push | `ab` |
| 2 | b | 顶 `b == b` | pop | `a` |
| 3 | a | 顶 `a == a` | pop | `(空)` |
| 4 | c | 栈空 | push | `c` |
| 5 | a | 顶 `c != a` | push | `ca` |

答案 `"ca"`。注意第 2、3 步：删掉 `bb` 后 `a` 和新来的 `a` 又相邻，栈自动接着消，一趟完成。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     string removeDuplicates(string s) {
>         string st;                        // string 直接当栈用
>         for (char c : s) {
>             if (!st.empty() && st.back() == c)
>                 st.pop_back();            // 一对相邻相同 → 一起删
>             else
>                 st.push_back(c);          // 不成对 → 压栈
>         }
>         return st;                        // 栈里剩下的就是答案
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def removeDuplicates(self, s: str) -> str:
>         st = []                           # list 当栈用
>         for c in s:
>             if st and st[-1] == c:
>                 st.pop()                  # 一对相邻相同 → 一起删
>             else:
>                 st.append(c)              # 不成对 → 压栈
>         return "".join(st)                # 栈里顺序就是答案
> ```

## 复杂度

- 时间：O(n)，每个字符至多进栈一次、出栈一次，共 O(n) 次操作。
- 空间：O(n)，最坏没有一对可删（如 `"abcdefg"`），栈存下全部 n 个字符。

## 易错点

1. **先判空再取栈顶**：`s = "a"` 时若先读 `st.back()` 会越界，必须把 `!st.empty()` 放在前面靠短路保护；Python 同理用 `if st and st[-1] == c`。
2. **相等是弹出不是压入**：`s = "aa"`，正确结果是 `""`；如果写成「相等也 push」会得到 `"a"`。
3. **返回栈的内容而不是个数**：`s = "abbaca"` 要返回 `"ca"`，别把栈长 2 交上去。
4. C++ 别写 `st.top()`——`string` 的栈顶接口是 `back()`，`top()` 是 `stack<char>` 才有的。
5. **空串直接返回空串**：`s = ""` 时循环不执行，`return st` 自然给 `""`，别在开头做多余判断。
