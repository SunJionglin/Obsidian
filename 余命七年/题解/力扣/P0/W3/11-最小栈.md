# 155. 最小栈 Min Stack

## 一句话题意

实现一个栈，支持 `push`/`pop`/`top`，且 `getMin` 在 O(1) 内返回当前栈中最小元素。

## 解题逻辑

**先想什么**：普通栈的 `push`/`pop`/`top` 天生 O(1)，难在 `getMin`。第一反应是每次调用时把栈里所有值扫一遍取最小。

**朴素解法**：单栈存值，`getMin` 现扫一遍找最小。`getMin` O(n)，其余 O(1)。题目明确要求每个函数都要 O(1)，朴素写法直接不满足要求。

**优化观察**：最小值只会在「压入一个更小的值」时变小，而它变回去的时刻，恰好是「那个最小值本身被弹出」的时候。既然最小值的变化只跟这两个动作挂钩，就用一个和数据栈**同步生长、同步缩短**的最小栈，把每个时刻的最小值都存下来——`getMin` 直接读栈顶，O(1)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 单栈 + 现扫 | getMin O(n) | O(1) | 不满足「每个函数 O(1)」的要求 |
| 双栈（数据栈 + 最小栈） | 全部 O(1) | O(n) | 多一个栈的内存 |
| 单栈存差值（val - min） | 全部 O(1) | O(1) 额外 | `top`/`pop` 要换算还原，差值还要用 `long long` 防溢出，绕且易错 |

**选双栈**：每个函数 O(1)、代码直白不易错，是面试标准解；差值法省空间但换算逻辑绕，先把双栈练成本能再说。

## 关键点

1. 最小栈和数据栈**同步 push、同步 pop**，两个栈永远一样长。
2. `push` 时最小栈压 `min(val, 当前最小)`，空栈时直接压 `val` 本身。
3. 不变量：**mn 栈顶 = 数据栈当前最小值**，`getMin` 就是读 `mn.top()`。
4. 边界约定：题目保证 `pop`/`top`/`getMin` 只在栈非空时调用，不需要判空。

## 实现逻辑

先 `push`，数据栈压 `val`、最小栈压 `min(val, mn.top())`。然后 `pop`，两个栈一起弹。再 `top`，读数据栈栈顶。最后 `getMin`，读最小栈栈顶。

拿官方样例 `push(-2), push(0), push(-3)` 手推一遍：

| 操作 | 参数 | 数据栈 st | 最小栈 mn | 返回 |
| --- | --- | --- | --- | --- |
| push | -2 | [-2] | [-2] | - |
| push | 0 | [-2, 0] | [-2, -2] | - |
| push | -3 | [-2, 0, -3] | [-2, -2, -3] | - |
| getMin | - | 不变 | 不变 | -3 |
| pop | - | [-2, 0] | [-2, -2] | - |
| top | - | 不变 | 不变 | 0 |
| getMin | - | 不变 | 不变 | -2 |

C++ 用 `stack<int>`，栈顶是 `top()`；Python 用 `list` 当栈，栈顶是 `[-1]`，末尾增删 `append`/`pop`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class MinStack {
>     stack<int> st;      // 数据栈,存全部值
>     stack<int> mn;      // 最小栈,与 st 同步,栈顶是当前最小值
> public:
>     MinStack() {}
>
>     void push(int val) {
>         st.push(val);
>         mn.push(mn.empty() ? val : std::min(val, mn.top()));  // 压 min(val, 当前最小)
>     }
>
>     void pop() {
>         st.pop();
>         mn.pop();       // 同步弹,维持两个栈一样长
>     }
>
>     int top() {
>         return st.top();
>     }
>
>     int getMin() {
>         return mn.top();    // 栈顶永远是当前最小值
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class MinStack:
>     def __init__(self):
>         self.st = []        # 数据栈
>         self.mn = []        # 最小栈,与 st 同步
>
>     def push(self, val: int) -> None:
>         self.st.append(val)
>         self.mn.append(val if not self.mn else min(val, self.mn[-1]))
>
>     def pop(self) -> None:
>         self.st.pop()
>         self.mn.pop()       # 同步弹
>
>     def top(self) -> int:
>         return self.st[-1]
>
>     def getMin(self) -> int:
>         return self.mn[-1]
> ```

## 复杂度

- 时间：每个函数都是 O(1)，`push`/`pop` 各做常数次栈操作，`top`/`getMin` 只读栈顶。
- 空间：O(n)，两个栈各存 n 个元素，共 2n，常数倍不改变量级。

## 易错点

1. `pop` 只弹数据栈、忘了弹最小栈：`push(5), push(1), pop()` 后 st=[5] 但 mn=[5,1]，`getMin` 错误返回 1。
2. `push` 用严格 `<` 才压 mn、`pop` 却无条件双弹，两个栈会错位：`push(2), push(1), push(3)` 时 mn=[2,1]，pop 一次后 mn=[2] 但 st=[2,1]，`getMin` 错返 2。要么无条件同步压弹，要么压用 `<=`、弹时 `st.top() == mn.top()` 才弹。
3. 空栈压栈没特判：新对象直接 `push(3)` 时访问 `mn.top()`，空栈解引用是未定义行为，Python 里 `mn[-1]` 直接 IndexError。
4. `getMin` 里现场扫一遍栈：结果对，但 `getMin` 变 O(n)，违背题目「每个函数 O(1)」的要求。
5. 差值法用 `int` 存 `val - min`：`val = INT_MIN` 且 `min = INT_MAX` 时差值溢出，差值必须用 `long long`。
