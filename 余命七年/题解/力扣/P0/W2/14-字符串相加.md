# 14. 字符串相加 Add Strings

## 一句话题意

给两个非负整数字符串 `num1`、`num2`（无前导零），返回两数之和的字符串，不能直接转成整数。

## 解题逻辑

**先想什么**：读完题第一反应是直接转 `int` 相加再转回来。但题目说数字可能长达数千位，`int`（甚至 `long long`）装不下，转数这条路直接走死，只能像小学列竖式一样**按位模拟加法**。

**朴素解法**：把较短的串前面补零对齐成等长，再从末尾逐位相加、处理进位。O(n) 时间、O(n) 空间，已经能过，但补零这步纯属多余——短串扫完当 0 处理就行。

**优化观察**：两个指针各指一个串的末尾（最低位），每位的和 = `本位数a + 本位数b + 进位`。关键观察：**这个和最大是 9+9+1=19，进位永远只会是 0 或 1**，所以本位结果就是 `sum % 10`，进位就是 `sum / 10`。靠这个观察，不用对齐、不用转数，一趟从尾到头扫完 O(n)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 转 int 相加 | O(n) | O(1) | 大数直接溢出，且违反题意 |
| 补零对齐后逐位加 | O(n) | O(n) | 多一步对齐，白花空间 |
| 双指针从尾模拟竖式 | O(n) | O(1) | 结果低位在前，要反转一次 |

**选双指针模拟竖式**：这是高精度加法的标准模板，一次循环同时推进两串，哪个先扫完哪个当 0，时间压到最优、额外空间 O(1)，还能原样套到二进制求和、链表相加上。

## 关键点

1. 循环条件模板句：`while (i >= 0 || j >= 0 || carry)`，**必须带上 `carry`**，否则 `999 + 1` 会丢掉最高位。
2. 不变量：`carry` 只会是 0 或 1（`sum` 最大 19）；本位 = `sum % 10`，进位 = `sum / 10`。
3. 边界约定：某串先扫完（`i < 0` 或 `j < 0`）时该位当 0 处理；两串都无前导零，但结果最高位可能因进位多出一位。
4. 字符与数字互转：C++ 用 `num1[i] - '0'` 和 `char('0' + sum % 10)`；Python 用 `ord()` / `chr()`。

## 实现逻辑

先初始化 `i = len(num1) - 1`、`j = len(num2) - 1` 指向两串末尾，`carry = 0`；然后在循环里算 `sum = carry + 两串当前位（越界当 0）`，把 `sum % 10` 转成字符追加到结果尾部，更新 `carry = sum / 10`，两个指针各自前移一位；最后反转结果串返回。

拿 `num1 = "456"`、`num2 = "77"` 手推一遍：

| i | j | num1[i] | num2[j] | sum(含进位) | 追加 | carry | res（反转前） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2 | 1 | 6 | 7 | 13 | '3' | 1 | "3" |
| 1 | 0 | 5 | 7 | 13 | '3' | 1 | "33" |
| 0 | -1 | 4 | 无(当0) | 5 | '5' | 0 | "335" |

反转后得 `"533"`。`carry` 让循环多跑一轮的情形看 `999 + 1`：三轮回合后 `carry = 1`，`i`、`j` 都已越界，靠 `carry` 这个条件再补一位 `'1'`，得到 `"1000"`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     string addStrings(string num1, string num2) {
>         int i = (int)num1.size() - 1, j = (int)num2.size() - 1;
>         int carry = 0;
>         string res;
>         while (i >= 0 || j >= 0 || carry) {   // 带上 carry，防最高位漏加
>             int sum = carry;                  // 先带上进位
>             if (i >= 0) sum += num1[i--] - '0';   // 越界当 0
>             if (j >= 0) sum += num2[j--] - '0';
>             res.push_back(char('0' + sum % 10));  // 低位在前
>             carry = sum / 10;
>         }
>         reverse(res.begin(), res.end());      // 反转成高位在前
>         return res;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def addStrings(self, num1: str, num2: str) -> str:
>         i, j = len(num1) - 1, len(num2) - 1
>         carry = 0
>         res = []
>         while i >= 0 or j >= 0 or carry:      # 带上 carry，防最高位漏加
>             s = carry                          # 先带上进位
>             if i >= 0:                         # 越界当 0
>                 s += ord(num1[i]) - ord('0')
>                 i -= 1
>             if j >= 0:
>                 s += ord(num2[j]) - ord('0')
>                 j -= 1
>             res.append(chr(ord('0') + s % 10)) # 低位在前
>             carry = s // 10
>         return ''.join(res[::-1])              # 反转成高位在前
> ```

## 复杂度

- 时间：O(max(n, m))，两串各扫一遍，每个字符只处理一次。
- 空间：O(1)，除结果串外只用常数个变量，不补零、不建中间数组。

## 易错点

1. `num1 = "999"`、`num2 = "1"`：循环条件漏写 `carry` 会得到 `"000"`，正确答案 `"1000"`——最后那个 `1` 全靠 `carry` 兜住。
2. `num1 = "456"`、`num2 = "77"`：忘了反转结果会返回 `"335"` 而不是 `"533"`，因为模拟时是从低位往高位拼的。
3. `num1 = "0"`、`num2 = "0"`：结果必须是 `"0"`，别手滑返回空串；也别在最后画蛇添足剥前导零。
4. C++：`res.push_back(sum % 10)` 会把数字当字符码塞进去变成控制字符，必须写成 `char('0' + sum % 10)`。
5. Python：`ord(num1[i])` 忘了减 `ord('0')`，加出来的是 ASCII 码之和，`"0" + "0"` 会变成 `'h'`；另外 `carry = s // 10` 要用整除，写成 `/` 会得到浮点。
