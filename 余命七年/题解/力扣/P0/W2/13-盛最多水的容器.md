# 13. 盛最多水的容器 Container With Most Water

## 一句话题意

给一个非负整数数组 `height` 表示柱子高度，返回两条柱子（下标从 0 开始）之间能盛的最大水量。

## 解题逻辑

**先想什么**：读完题第一反应是「任意两条柱子都试一遍」，两层循环枚举左右端点取最大。

**朴素解法**：外层固定左端点 `i`，内层枚举右端点 `j`，面积 = `min(height[i], height[j]) * (j - i)`，一路取最大。O(n²)，n 到 1e5 时约 5e9 次计算，力扣必超时。

**优化观察**：面积 = **短板高度 × 宽度**。宽度的最大值固定是 `n-1`（两端两根柱子），之后只会越缩越小，所以想变大只能让短板变长。于是从两端开始，每次移动**较短**的那根指针——移高板，宽度变小、短板不变或更矮，面积必不增；移矮板才有机会变大。一趟扫描 O(n)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 两层循环枚举 | O(n²) | O(1) | n=1e5 时约 5e9 次，超时 |
| 单调栈 | O(n) | O(n) | 要记每根柱子左右更高的界，绕远路 |
| 双指针 | O(n) | O(1) | 需要理解「谁矮移谁」的正确性 |

**选双指针**：时间压到 O(n) 的同时空间 O(1)，不借助任何数据结构，靠「宽度单调减」这个单调性把 n² 组配对剪成 n 步，是这题的标准解。

## 关键点

1. 面积模板句：`min(height[l], height[r]) * (r - l)`，宽度是 `r - l`，不是 `r - l + 1`。
2. **谁矮移谁**：`height[l] < height[r]` 则 `l++`，否则 `r--`；相等移哪边都行，但必须动一边。
3. 不变量：指针从两端相向收缩，宽度单调递减，被跳过的组合都不可能超过当前 `ans`。
4. 边界约定：题目保证 `n >= 2`；循环条件是 `l < r`，两指针永不重叠。

## 实现逻辑

先初始化双指针 `l = 0`、`r = n - 1` 和答案 `ans = 0`，然后循环里算当前面积并更新 `ans`，最后比较两端高度、矮的那边指针向内移一步，指针相遇退出返回 `ans`。

拿 `height = [1,3,2,5]` 手推一遍：

| l | r | height[l] | height[r] | area | ans | 动作 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | 3 | 1 | 5 | min(1,5)×3 = 3 | 3 | 左矮，l=1 |
| 1 | 3 | 3 | 5 | min(3,5)×2 = 6 | 6 | 左矮，l=2 |
| 2 | 3 | 2 | 5 | min(2,5)×1 = 2 | 6 | 左矮，l=3，退出 |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int maxArea(vector<int>& height) {
>         int l = 0, r = (int)height.size() - 1;   // 两端双指针，size() 转 int
>         int ans = 0;
>         while (l < r) {                           // 指针不重叠
>             int area = min(height[l], height[r]) * (r - l);  // 短板 × 宽度
>             ans = max(ans, area);
>             if (height[l] < height[r]) l++;       // 谁矮移谁
>             else r--;
>         }
>         return ans;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def maxArea(self, height: List[int]) -> int:
>         l, r = 0, len(height) - 1          # 两端双指针
>         ans = 0
>         while l < r:
>             area = min(height[l], height[r]) * (r - l)   # 短板 × 宽度
>             ans = max(ans, area)
>             if height[l] < height[r]:       # 谁矮移谁
>                 l += 1
>             else:
>                 r -= 1
>         return ans
> ```

## 复杂度

- 时间：O(n)，每轮循环必有一个指针向内移一步，最多共 n 步。
- 空间：O(1)，只有两个指针和一个答案变量。

## 易错点

1. 宽度算错：`height = [1,1]`，面积是 `min(1,1)*(1-0) = 1`，写成 `r-l+1 = 2` 就错了——两根柱子之间不含端点本身，宽度就是下标差。
2. 移错指针：`height = [6,10,5,10]`，第一轮 `h[0]=6 < h[3]=10` 应移较矮的左指针，`l++` 后两个 10 相遇组成面积 20；若写成「谁高移谁」移了右指针，最优解 20 就被跳过了——面积上限由矮的那根决定，移它才可能变大。
3. 相等时不动会死循环：`height = [1,1]`，若只写 `if (h[l] < h[r]) l++; else if (h[l] > h[r]) r--;`，相等时两个指针都不动，`while(l < r)` 死循环——`else` 必须兜住相等情况。
4. 溢出边界：本题 `height[i] <= 1e4`、`n <= 1e5`，最大面积 `1e4 * 1e5 = 1e9 < 2^31-1`，`int` 够用；若数据范围再放大要换 `long long`。

## 一句话总结

**左右指针向中间夹，谁矮谁动，面积 = 短板 × 宽度**——用「宽度单调减」换掉一层循环，O(n) 过 1e5 的双指针入门模板。
