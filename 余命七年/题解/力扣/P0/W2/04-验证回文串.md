# 125. 验证回文串 Valid Palindrome

## 一句话题意

给一个字符串 `s`，只认**字母和数字**、忽略大小写，判断它是不是回文，返回 `bool`。

## 解题逻辑

**先想什么**：判断回文第一反应是「两头往中间比」，双指针从 `0` 和 `n-1` 出发。

**朴素解法**：先扫一遍，把字母数字过滤出来、转小写，拼成一个新串，再拿它和它的反转比较。O(n) 时间、O(n) 空间——时间已经到底了，但白开一个辅助串，反转比较还得再 O(n) 拷贝一轮。

**优化观察**：过滤出来的字符**不需要真的存下来**——双指针可以「边跳过脏字符边比较」，标点空格当场跳过，比较用 `tolower` 统一大小写。辅助串没了，空间从 O(n) 降到 O(1)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 过滤 + 反转比较 | O(n) | O(n) | 多建一个反转串，多一轮拷贝 |
| 过滤 + 双指针 | O(n) | O(n) | 辅助串占空间 |
| 原地双指针 | O(n) | O(1) | 跳标点稍绕，内层容易漏 `l < r` |

**选原地双指针**：时间是这题的理论下限 O(n)，空间压到 O(1)，一趟扫完不用任何额外结构，是这题的标准解。

## 关键点

1. 不变量：**每次比较前，`s[l]` 和 `s[r]` 一定是字母数字**——先跳再比。
2. 大小写统一用 `tolower` / `lower()`，数字不受影响、原样保留。
3. 内层跳标点的 `while` 必须带 `l < r` 条件，全标点串才不会越界。
4. 空串、纯标点串：循环没比到任何字符，直接返回 `true`，视为回文。

## 实现逻辑

三个动作循环做：**l 右跳脏字符 → r 左跳脏字符 → 转小写比较，不等就返回 false**，循环条件 `l < r`。

拿 `s = "a b A"` 手推一遍：

| 轮 | l | r | l 停在 | r 停在 | 比较 | 动作 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 0 | 4 | `'a'` | `'A'` | 转小写后 a == a | l=1, r=3 |
| 2 | 1 | 3 | `'b'`（跳过空格） | `'b'`（跳过空格） | b == b | l=3, r=1，`l < r` 不成立 |
| 退出 | 返回 `true` |  |  |  |  |  |

C++ 里 `isalnum` 判断字母数字、`tolower` 统一小写；Python 里对应 `str.isalnum()` 和 `str.lower()`。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     bool isPalindrome(string s) {
>         int l = 0, r = (int)s.size() - 1;
>         while (l < r) {
>             while (l < r && !isalnum((unsigned char)s[l])) l++;  // 跳过非字母数字
>             while (l < r && !isalnum((unsigned char)s[r])) r--;
>             if (tolower(s[l]) != tolower(s[r])) return false;    // 忽略大小写比较
>             l++; r--;
>         }
>         return true;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def isPalindrome(self, s: str) -> bool:
>         l, r = 0, len(s) - 1
>         while l < r:
>             while l < r and not s[l].isalnum():  # 跳过非字母数字
>                 l += 1
>             while l < r and not s[r].isalnum():
>                 r -= 1
>             if s[l].lower() != s[r].lower():     # 忽略大小写比较
>                 return False
>             l += 1
>             r -= 1
>         return True
> ```

## 复杂度

- 时间：O(n)，l、r 两个指针各把字符串扫一遍，每个字符最多看一次。
- 空间：O(1)，只有两个指针，原地比较。

## 易错点

1. `"0P"` 应返回 `false`：数字 `0` 和字母 `P` 不是一回事——`tolower('0')` 还是 `'0'`，别自己写 `s[l] + 32` 统一大小写，`'0'(48) + 32 = 'P'(80)`，正好把这个坑写成 bug。
2. `".,"` 应返回 `true`：全标点串没比到任何字符，直接 `true`，别在开头特判「非空才继续」。
3. C++：`isalnum(s[l])` 直接传 `char`，若字节为负值行为未定义，先转 `(unsigned char)` 再传。
4. `"!!!"` 会越界：内层 `while` 忘写 `l < r`，`l` 会一路加到 3 越界读 `s[3]`——两个内层循环都要带上条件。
5. Python：`str.isalnum()` 按 Unicode 定义，会把中文字符也当字母数字，力扣这题只考 ASCII 没事，但要知道它不是「只认英文数字」。
