# 205. 同构字符串 Isomorphic Strings

## 一句话题意

判断两个字符串能否按字符建立双向一一对应，返回 bool。

## 解题逻辑

**先想什么**：读完题第一反应是「s 的第 i 个字符永远映射成 t 的第 i 个字符」，直接建一张 `s → t` 哈希表逐位查。

**朴素解法**：只建一张 `s2t` 表，遇到没登记过的字符就登记，登记过的就比对映射值。O(n) 时间、O(n) 空间，但**不够好——它漏了反向约束**：`s = "ab", t = "aa"` 时，a 和 b 都映射到 a，单表一路放行，误判 true。

**优化观察**：关键观察是**映射必须双向唯一**——s 的两个不同字符不能落到同一个 t 字符上。朴素解法已经 O(n)，优化不是降复杂度，而是补正确性：再开一张 `t → s` 表当「占用登记簿」，任何字符被第二个来源抢占，O(1) 内当场拦下。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 只建 s→t 一张表 | O(n) | O(n) | 漏反向约束，`ab`~`aa` 误判 true |
| s→t 表 + set 记已占用 | O(n) | O(n) | 表和 set 要同步维护，多一层心智负担 |
| 双向两张哈希表 | O(n) | O(n) | 多一半哈希开销（可忽略） |
| 归一化成首次出现序号再比较 | O(n) | O(n) | 跑两遍、开两个 string，写法绕 |

**选双向哈希**：双向唯一就是同构的定义本身，两张表把定义直译出来，背法和写法都最省心。

## 关键点

1. 模板句：**正向查映射、反向查占用，两张表同时登记**。
2. 不变量：处理完第 i 位后，s[0..i] 与 t[0..i] 的对应保持双向一致。
3. 判定只认「冲突」：已有映射值不等、或目标已被别人占用，任一发生立即返回 false。
4. 边界约定：题目保证 `t.length == s.length`，开头判长度是防御性兜底。

## 实现逻辑

四个动作：**比长度 → 逐位取 (a, b) → 查两张表找冲突 → 双向登记**。

拿 `s = "egg"`、`t = "add"` 手推一遍：

| i | a | b | s2t 查到 | t2s 查到 | 动作 | 表状态 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | e | a | 无 | 无 | 双向登记 | s2t={e:a}，t2s={a:e} |
| 1 | g | d | 无 | 无 | 双向登记 | s2t={e:a, g:d}，t2s={a:e, d:g} |
| 2 | g | d | 有，值=d 一致 | 有，值=g 一致 | 通过 | 不变 |

C++ 里 `find` 返回迭代器，判冲突用 `it != end()` 再比 `it->second`；Python 里 `a in s2t` 判存在、`s2t[a]` 取值。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     bool isIsomorphic(string s, string t) {
>         if (s.size() != t.size()) return false;        // 防御性兜底（题目保证等长）
>         unordered_map<char, char> s2t, t2s;            // 正向映射 + 反向占用
>         for (int i = 0; i < (int)s.size(); i++) {
>             char a = s[i], b = t[i];
>             auto it1 = s2t.find(a);                    // a 是否已映射
>             auto it2 = t2s.find(b);                    // b 是否已被占用
>             if (it1 != s2t.end() && it1->second != b) return false;  // a 映射到别人
>             if (it2 != t2s.end() && it2->second != a) return false;  // b 被别的字符占用
>             s2t[a] = b;                                // 双向登记
>             t2s[b] = a;
>         }
>         return true;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def isIsomorphic(self, s: str, t: str) -> bool:
>         if len(s) != len(t):              # 防御性兜底（题目保证等长）
>             return False
>         s2t, t2s = {}, {}                 # 正向映射 + 反向占用
>         for a, b in zip(s, t):
>             if a in s2t and s2t[a] != b:  # a 已映射到别人
>                 return False
>             if b in t2s and t2s[b] != a:  # b 已被别的字符占用
>                 return False
>             s2t[a] = b                    # 双向登记
>             t2s[b] = a
>         return True
> ```

## 复杂度

- 时间：O(n)，逐位遍历一遍，每步两张表各查一次，平均 O(1)。
- 空间：O(n)，两张表各最多存「字符种数」个键值对，上界 n。

## 易错点

1. 只建一张表：`s = "ab", t = "aa"` 会被误判 true——b 和 a 抢同一个映射目标 a，没有第二张表拦不住。
2. C++ 用 `s2t[a]` 查询会顺手插入默认值：一访问就把 a 登记成 `'\0'`，污染映射表；查存在一律用 `find`。
3. Python 用 `zip(s, t)` 但开头不判长度：`s = "ab", t = "a"` 时 zip 只跑到短的，返回 true——先判长度再循环。
4. 频次一致 ≠ 同构：`s = "aba", t = "baa"` 两串每个字符出现次数完全一样，但 a 在第 0、2 位要映射成 b 和 a，冲突。
5. Python 别用 `if s2t.get(a) != b` 判冲突：a 未登记时 `get` 返回 None，`None != b` 恒真，`("egg", "add")` 第 0 位就误判 false；先 `a in s2t` 再取值。
