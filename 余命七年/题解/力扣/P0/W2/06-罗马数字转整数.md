# 13. 罗马数字转整数 Roman to Integer

## 一句话题意

给一个罗马数字字符串 `s`，返回它表示的整数（值在 1～3999）。

## 解题逻辑

**先想什么**：每个罗马符号有固定数值，第一反应是「逐个字符查表、累加起来」。

**朴素解法**：建一张「符号 → 值」的表直接累加，O(n)。但这样 `"IV"` 会算成 1+5=6，答案是 4——**无脑累加不满足减法规则，会错**。想修对，就要把 `IV/IX/XL/XC/CD/CM` 这 6 个双字符组合也塞进表里（共 13 个键），先贪心匹配两个字符、再匹配一个字符，代码啰嗦。

**优化观察**：减法规则其实只有一种形状——**小值符号紧挨在大值符号的左边**。所以每步只要比「当前字符」和「下一个字符」：当前小就减、否则加，末尾必加。靠这一个相邻比较，把 13 个键压回 7 个键，O(n) 一遍扫完，不用预判任何组合。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 双字符+单字符查表贪心 | O(n) | O(1) | 要维护 13 个键、先匹配两个字符再匹配一个，啰嗦易漏 |
| 从左到右比紧邻 | O(n) | O(1) | 要理解「小在大左就减」这条规则 |
| 从右往左扫（遇小减） | O(n) | O(1) | 方向反直觉，加减容易写反 |

**选从左到右比紧邻**：读起来自然，每步只做一个「当前 vs 下一个」的比较，一张 7 键的表搞定，时间空间都是最优，是这题最标准的写法。

## 关键点

1. 减法规则：**小值符号在大值符号左边**时减（`IV`=4），否则加。
2. 只和**右边紧邻**的符号比：每对相邻字符只被看一次，不需要回头看。
3. 末尾字符没有「下一个」，**必加**；C++ 里 `s[i+1]` 要先判 `i+1 < n` 防越界。
4. 不变量：扫完前 `i` 个字符时，`ans` 恒等于这段前缀的值。

## 实现逻辑

三个动作循环做：**查当前值 → 和下一个比 → 小就减、否则加**。

拿 `s = "XLII"`（42）手推一遍：

| i | 当前 | 下一个 | 比较 | 动作 | ans |
| --- | --- | --- | --- | --- | --- |
| 0 | X(10) | L(50) | 10 < 50 | 减 | -10 |
| 1 | L(50) | I(1) | 50 ≥ 1 | 加 | 40 |
| 2 | I(1) | I(1) | 1 ≥ 1 | 加 | 41 |
| 3 | I(1) | 末尾 | 无下一个 | 加 | 42 |

C++ 用 `unordered_map<char,int>` 建表，`val[s[i]]` 取值；Python 用 `dict`，`enumerate` 同时拿下标和字符。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int romanToInt(string s) {
>         unordered_map<char, int> val = {
>             {'I', 1}, {'V', 5}, {'X', 10}, {'L', 50},
>             {'C', 100}, {'D', 500}, {'M', 1000}
>         };
>         int ans = 0;
>         for (int i = 0; i < (int)s.size(); i++) {
>             if (i + 1 < (int)s.size() && val[s[i]] < val[s[i + 1]])
>                 ans -= val[s[i]];            // 小在大左 -> 减
>             else
>                 ans += val[s[i]];            // 否则加；末尾必加
>         }
>         return ans;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def romanToInt(self, s: str) -> int:
>         val = {'I': 1, 'V': 5, 'X': 10, 'L': 50,
>                'C': 100, 'D': 500, 'M': 1000}
>         ans = 0
>         for i, c in enumerate(s):
>             if i + 1 < len(s) and val[c] < val[s[i + 1]]:
>                 ans -= val[c]        # 小在大左 -> 减
>             else:
>                 ans += val[c]        # 否则加；末尾必加
>         return ans
> ```

## 复杂度

- 时间：O(n)，每个字符查一次表（O(1)）、和下一个比一次，共 n 次。
- 空间：O(1)，表固定 7 个键，不随输入增长。

## 易错点

1. `"IV"` 无脑累加会得 6，答案是 4——漏了「小值在大值左边要减」这条规则。
2. `"III"` 连续相等必须加：把判断写成 `<=`（相等也减），会得 -1。
3. `"IX"` 比较方向写反：写成「当前 > 下一个才减」，I 会被加，得 11（正确 9）。
4. `"III"` 末尾越界：循环里直接用 `s[i+1]` 不判 `i+1 < n`，最后一位会读越界（C++ 未定义行为 / Python 抛 IndexError）。
5. 末尾字符必加：忘了 else 分支或把最后一位漏掉，`"I"` 会得 0。
