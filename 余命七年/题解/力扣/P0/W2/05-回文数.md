# 9. 回文数 Palindrome Number

## 一句话题意

给一个整数 `x`，判断正着读反着读是否一样，是返回 `true`，负数一律不是。

## 解题逻辑

**先想什么**：读完题第一反应是「转成字符串，左右双指针对着走」。

**朴素解法**：`to_string` 转字符串，`s[i]` 和 `s[n-1-i]` 逐一比较。O(n) 时间、O(n) 空间，n 最多 10 位，完全能过；但进阶要求「不转字符串」，而且平白多占一个字符串。

**优化观察**：回文是**对称**的，根本不需要读完全部——把数字的后半段「摘个位、拼翻转数」，翻到**翻转数 ≥ 剩余数**就停，比较两者是否相等即可。全程只动两个 `int`，不碰字符串；翻转数最多和剩余数位数相同，**天然不会溢出**。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 转字符串 + 双指针 | O(n) | O(n) | 不满足进阶要求，多占一个字符串 |
| 全翻转后和原数比 | O(n) | O(1) | 翻转值可能溢出 int（2147483647 → 7463847412） |
| 只翻一半 | O(log n) | O(1) | 奇数位要多一步 `/10` |

**选只翻一半**：全翻转会溢出，字符串浪费空间；翻一半用「x > reverted」当停止条件，翻转数位数不超过原数一半，永远安全，时间和空间都是最优。

## 关键点

1. 模板句：负数、非 0 的尾 0（`x % 10 == 0 && x != 0`）第一行直接毙掉，`0` 本身要放行。
2. 停止条件是 `x > reverted`，不是 `x != 0`——翻一半才不溢出，翻完会溢出。
3. 偶数位比较 `x == reverted`，奇数位比较 `x == reverted / 10`。
4. 全程不转字符串，O(1) 空间。

## 实现逻辑

先特判负数与尾 0 → 循环「摘个位拼翻转」直到 `x <= reverted` → 按奇偶比较返回。

拿 `x = 1221` 手推：

| 轮 | x（剩余前半） | x % 10（摘下的个位） | reverted 更新后 | x > reverted | 动作 |
| --- | --- | --- | --- | --- | --- |
| 初始 | 1221 | — | 0 | — | 开始 |
| 1 | 122 | 1 | 1 | 122 > 1 是 | 继续 |
| 2 | 12 | 2 | 12 | 12 > 12 否 | 停 |

`x == reverted`（12 == 12）→ `true`。奇数位如 `12321`：停下时 `x = 12`、`reverted = 123`，用 `reverted / 10 = 12` 比较。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     bool isPalindrome(int x) {
>         if (x < 0 || (x % 10 == 0 && x != 0))   // 负数、尾0(0本身除外)必不是
>             return false;
>         int reverted = 0;
>         while (x > reverted) {                  // 翻到一半就停，不溢出
>             reverted = reverted * 10 + x % 10;  // 摘个位拼到翻转数上
>             x /= 10;
>         }
>         return x == reverted || x == reverted / 10;  // 偶数位 / 奇数位
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def isPalindrome(self, x: int) -> bool:
>         if x < 0 or (x % 10 == 0 and x != 0):   # 负数、尾0(0本身除外)必不是
>             return False
>         reverted = 0
>         while x > reverted:                     # 翻到一半就停，不溢出
>             reverted = reverted * 10 + x % 10
>             x //= 10                            # 必须整除，别写成 /
>         return x == reverted or x == reverted // 10
> ```

## 复杂度

- 时间：O(log₁₀ n)，每轮 `x /= 10` 剥掉一位，最多循环位数的一半。
- 空间：O(1)，只有 `reverted` 一个额外变量。

## 易错点

1. 负数：输入 `-121`，不写 `x < 0` 时靠循环条件也能碰巧返回 false，但换成「全翻转」写法或别的语言就翻车——负数第一行毙掉，别赌运气。
2. 尾 0：输入 `10`，`10 % 10 == 0 && x != 0` 直接 false；但别把 `0` 也毙了——`0` 是回文数，要放行。
3. 奇数位：输入 `12321`，停下时 `x = 12`、`reverted = 123`，直接比 `x == reverted` 得 false，必须 `reverted / 10`。
4. 停止条件：写成 `x != 0` 等于全翻转，输入 `2147483647` 时 `reverted` 会溢出成负数，永远对不上；`x > reverted` 保证翻转数位数不超过原数一半。
5. Python：`x //= 10` 必须用整除，写 `/` 会得到 float，比较和后续运算全乱；且 Python 负数 `//` 向下取整（-12 // 10 = -2），所以负数更要提前 return。
