# 58. 最后一个单词的长度 Length of Last Word

## 一句话题意

给一个字符串（串尾可能有多余空格），返回**最后一个单词**的长度。

## 解题逻辑

**先想什么**：「单词」就是空格切出来的段，第一反应自然是按空格切分，取最后一段。

**朴素解法**：Python 用 `s.split()`，C++ 用 `stringstream` 或手动 `find` 切分，取最后一个单词的 `length`。O(n) 时间、O(n) 空间——为了一个长度把整张单词表建出来，力扣能过，但空间纯属浪费。

**优化观察**：最后一个单词就躺在**串尾**，从右往左看，结构是「若干空格 + 单词 + 空格」。所以根本不用切分——**从最后一个字符出发，先跳过尾部空格，再一路数到下一个空格**。答案只和「从右往左看第一个非空格连续段」有关，一趟扫描、零额外空间。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 按空格切分（split / stringstream） | O(n) | O(n) | 为取一个数建整张表，C++ 写法还啰嗦 |
| 先去尾部空格再数（rstrip） | O(n) | O(n) | rstrip 生成新串，多一趟拷贝 |
| 从右往左一趟扫描 | O(n) | O(1) | C++ 下标循环要防无符号下溢 |

**选反向扫描**：时间不可能低于 O(n)——最坏整个串就是一个单词，必须读完；能省的只剩空间。反向一趟把空间压到 O(1)，两段 while 短到几乎不会写错。

## 关键点

1. 两段式：第一段 `while (i >= 0 && s[i] == ' ')` 跳尾部空格，第二段 `while (i >= 0 && s[i] != ' ')` 数单词。
2. 不变量：进入第二段时，`i` 停在最后一个单词的最后一个字母上；退出时 `len` 恰是该单词长度。
3. C++ 下标用 `int i = (int)s.size() - 1`，绝不用 `size_t`——`i >= 0` 对无符号数永远为真，越界下溢。
4. 题目保证至少一个单词，空串不用特判；但两个 while 的 `i >= 0` 不能省，它是「串里没有空格」时的退出条件。

## 实现逻辑

先 `i = len(s) - 1`，再 while 跳尾部空格，然后 while 数非空格字符，最后返回 `len`。

拿 `s = "a b "` 手推一遍：

| 循环变量 i | 当前值 s[i] | 查什么 | 结果 len | 阶段 |
| --- | --- | --- | --- | --- |
| 3 | ' ' | 是空格 | 0 | 跳尾部空格，i → 2 |
| 2 | 'b' | 不是空格 | 1 | 数单词，i → 1 |
| 1 | ' ' | 是空格 | 1 | 停，返回 1 |

C++ 里 `s[i]` 是 `char`，比较用 `' '`（单引号）；Python 里同样用 `' '`，`s[i]` 是单字符 str。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int lengthOfLastWord(string s) {
>         int i = (int)s.size() - 1;              // size_t 转 int，防无符号下溢
>         while (i >= 0 && s[i] == ' ') i--;      // 1. 跳过尾部空格
>         int len = 0;
>         while (i >= 0 && s[i] != ' ') {         // 2. 数单词
>             len++;
>             i--;
>         }
>         return len;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def lengthOfLastWord(self, s: str) -> int:
>         i = len(s) - 1
>         while i >= 0 and s[i] == ' ':   # 1. 跳过尾部空格
>             i -= 1
>         ans = 0
>         while i >= 0 and s[i] != ' ':   # 2. 数单词
>             ans += 1
>             i -= 1
>         return ans                      # 别叫 len，会盖掉内置函数
> ```

## 复杂度

- 时间：O(n)，最坏整个串是一个单词或全串要扫完，`i` 最多走 n 个字符。
- 空间：O(1)，只用一个下标 `i` 和一个计数 `len`。

## 易错点

1. 漏掉「先跳尾部空格」：`s = "a "` 直接数会返回 0，正确是 1——第一段 while 不能省。
2. C++ 循环变量用 `size_t`：`s = "a"` 时 `i >= 0` 永远为真，`i` 减到 -1 会下溢成巨大数，越界访问。
3. Python 用 `split(" ")` 带参数：`s = "a  "`（尾部两个空格）最后一个元素是空串，`len` 得 0，正确是 1；不带参的 `split()` 才自动吞掉连续空格。
4. 第二段 while 忘写 `i >= 0`：`s = "abc"` 没有空格，Python 里 `i` 减到 -1 后 `s[-1]` 还是 `'c'`，永远不等于空格，死循环。
5. 全串没有空格时靠 `i >= 0` 退出：`s = "a"` 数完 `len = 1`、`i = -1` 正常返回，别画蛇添足加特判。
