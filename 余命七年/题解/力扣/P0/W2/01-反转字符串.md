# 344. 反转字符串 Reverse String

## 一句话题意

原地反转字符数组 `s`，要求 O(1) 额外空间，无返回值（C++ 传 `vector<char>&`，Python 直接改 `s`）。

## 解题逻辑

**先想什么**：反转就是「首尾对调」，第一反应是倒着读进一个新数组。

**朴素解法**：新建一个数组，从 `n-1` 往 0 倒序拷贝。O(n) 时间、O(n) 空间，但题面明确要求原地、O(1) 额外空间，不满足。

**优化观察**：反转本质是「`s[i]` 与 `s[n-1-i]` 交换」，每换一对，两头各少一格。既然首尾互相是对方的对称位置，就让两个指针从两端相向走，**边交换边靠拢，走到相遇就全部换完**——不需要任何额外空间，时间还是 O(n)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 新数组倒序拷贝 | O(n) | O(n) | 违反「原地 O(1) 空间」要求 |
| 库函数 `reverse` / `s.reverse()` | O(n) | O(1) | 一行作弊，练不到双指针 |
| 双指针对称交换 | O(n) | O(1) | 无 |

**选双指针**：原地 O(1) 是题面硬要求，双指针恰好 O(n) / O(1) 达标，是这题的标准解，也是相向双指针的最小模板。

## 关键点

1. 左右指针 `l = 0`、`r = n - 1`，循环条件 **`l < r`**，相遇就停。
2. 只换一半：对称位置只交换一次，**全遍历会换两遍又换回去**。
3. 原地修改，不建临时数组；C++ 用 `swap`，Python 用 `s[l], s[r] = s[r], s[l]`。

## 实现逻辑

三个动作循环做：**初始化左右指针 → 交换 s[l] 和 s[r] → l++、r-- 靠拢**；`l >= r` 时循环结束，反转完成。

拿 `s = ['h','e','l','l','o']` 手推一遍：

| l | r | s[l] | s[r] | 动作 | 数组状态 |
| --- | --- | --- | --- | --- | --- |
| 0 | 4 | h | o | 交换 | o e l l h |
| 1 | 3 | e | l | 交换 | o l l e h |
| 2 | 2 | — | — | l==r 相遇，停 | o l l e h |

奇数长度中点自己不用动；偶数长度两指针直接交错，也都靠 `l < r` 兜住。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     void reverseString(vector<char>& s) {
>         int l = 0, r = (int)s.size() - 1;   // 左右指针；(int) 防无符号下溢
>         while (l < r) {
>             swap(s[l], s[r]);               // 对称交换
>             l++;
>             r--;
>         }
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def reverseString(self, s: list[str]) -> None:
>         l, r = 0, len(s) - 1                 # 左右指针
>         while l < r:
>             s[l], s[r] = s[r], s[l]          # 元组交换，原地
>             l += 1
>             r -= 1
> ```

## 复杂度

- 时间：O(n)，共交换 n/2 对，每次 O(1)。
- 空间：O(1)，只有两个指针变量，原地修改。

## 易错点

1. 全遍历交换两遍：`s = ['a','b','c']`，写成 `for i in range(n): s[i], s[n-1-i] = s[n-1-i], s[i]`，i=2 时把 i=0 换好的又换回去，结果还是 `['a','b','c']`。
2. Python 切片不原地：`s = ['h','e','l','l','o']`，写 `s = s[::-1]` 只改了函数内的局部引用，调用后原数组纹丝不动，判题直接 WA。
3. C++ 空数组下溢：`s = []`，`size_t r = s.size() - 1` 会变成极大无符号数，`while (l < r)` 进去后 `s[r]` 越界崩溃；先 `(int)s.size()` 再减。
4. C++ 异或交换配 `l <= r`：`s = ['a','b','c']`，走到中点 l==r 时自己异或自己得 0，中间字符被抹成 `\0`；用 `swap` 且严格 `l < r`。
