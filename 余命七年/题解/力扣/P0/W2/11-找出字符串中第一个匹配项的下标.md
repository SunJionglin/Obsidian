# 28. 找出字符串中第一个匹配项的下标 Find the Index of the First Occurrence in a String

## 一句话题意

在 `haystack` 中找 `needle` 第一次出现的下标（从 0 开始），找不到返回 -1。

## 解题逻辑

**先想什么**：字符串匹配第一反应是「把 needle 放到 haystack 每个位置对一遍」，枚举起点逐字符比。

**朴素解法**：外层枚举起点 `i ∈ [0, n-m]`，内层拿 `haystack[i..i+m-1]` 和 needle 逐字符比。O(nm)，n、m 到 1e4 时最坏 1e8 次比较，卡着超时线——最惨的是全 a 串，每个起点都比到最后一位才失败，前一步比过的字符下一步又从头重比。

**优化观察**：朴素失配后起点只右移 1 格，已比对的字符信息全扔了。关键观察是**失配时「已匹配的那一段」里有信息**——如果已匹配部分自己存在「相同的前后缀」，失配后 needle 可以整段滑过去、从那个前后缀处接着比，中间那些必然失败的起点直接跳过。靠什么降复杂度？**前缀函数 pi**：预先算好 needle 每个位置的最长相等前后缀，失配时回退 `j = pi[j-1]`，匹配就从 O(nm) 压到 O(n+m)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 朴素枚举起点 | O(nm) | O(1) | 全 a 串等最坏情况退化，重复比较 |
| 库函数 `find` / `str.find` | O(n+m) 上下 | O(1) | 依赖库实现，面试不让用，学不到匹配思想 |
| KMP | O(n+m) | O(m) | 要记前缀函数，代码稍长 |

**选 KMP**：线性时间、不依赖库，是字符串匹配的标准解；前缀函数学一次，能在「重复子串」「回文」类题里反复复用，这笔账划算。

## 关键点

1. **前缀函数**：`pi[i]` = `needle[0..i]` 的最长相等前后缀长度；失配时 j 回退到 `pi[j-1]`，已匹配的前 `pi[j-1]` 个字符不用重比。
2. **模板句**：`while (j > 0 && haystack[i] != needle[j]) j = pi[j-1]; if (haystack[i] == needle[j]) j++; if (j == m) return i - m + 1;`
3. **不变量**：每轮循环结束时，j 是以 `haystack[i]` 结尾、能与 needle 前缀匹配的最长长度；j == m 时起点就是 `i - m + 1`。
4. **边界约定**：下标从 0 计；n < m 直接返回 -1；needle 为空返回 0（题目保证非空，防御性写）。

## 实现逻辑

四个动作：**先建 pi（needle 和自己匹配）→ 再扫 haystack（同一条回退规则）→ 匹配满 m 个字符返回 `i - m + 1` → 最后扫完没中返回 -1**。

拿 `haystack = "aabaabaaf"`、`needle = "aabaaf"` 手推一遍（pi = [0,1,0,1,2,0]）：

| i | haystack[i] | needle[j] | 比对结果 | j（已匹配长度） |
| --- | --- | --- | --- | --- |
| 0 | a | a | 相等，j++ | 1 |
| 1 | a | a | 相等，j++ | 2 |
| 2 | b | b | 相等，j++ | 3 |
| 3 | a | a | 相等，j++ | 4 |
| 4 | a | a | 相等，j++ | 5 |
| 5 | b | f | 不等，回退 j=pi[4]=2，再比 needle[2]=b 相等，j++ | 3 |
| 6 | a | a | 相等，j++ | 4 |
| 7 | a | a | 相等，j++ | 5 |
| 8 | f | f | 相等，j++，j==6 | 返回 8-6+1=3 |

第 5 步是 KMP 的精华：b 和 f 失配后不是从 0 重来，而是靠「已匹配 aabaa 的前后缀长度 2」把 j 滑回 2 接着比。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int strStr(string haystack, string needle) {
>         int n = (int)haystack.size(), m = (int)needle.size();
>         if (m == 0) return 0;                  // 约定空串在开头（题目保证非空，防御性写）
>         if (n < m) return -1;                  // 剪枝：不可能包含
>         // 1. 预处理前缀函数：pi[i] = needle[0..i] 的最长相等前后缀
>         vector<int> pi(m, 0);
>         for (int i = 1, j = 0; i < m; i++) {
>             while (j > 0 && needle[i] != needle[j]) j = pi[j - 1];  // 失配连续回退
>             if (needle[i] == needle[j]) j++;
>             pi[i] = j;
>         }
>         // 2. 扫描匹配：j = 已匹配的 needle 长度
>         for (int i = 0, j = 0; i < n; i++) {
>             while (j > 0 && haystack[i] != needle[j]) j = pi[j - 1];
>             if (haystack[i] == needle[j]) j++;
>             if (j == m) return i - m + 1;      // 起点下标从 0 计
>         }
>         return -1;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def strStr(self, haystack: str, needle: str) -> int:
>         n, m = len(haystack), len(needle)
>         if m == 0:
>             return 0
>         if n < m:                              # 剪枝：不可能包含
>             return -1
>         # 1. 前缀函数：pi[i] = needle[0..i] 的最长相等前后缀
>         pi = [0] * m
>         j = 0
>         for i in range(1, m):
>             while j > 0 and needle[i] != needle[j]:
>                 j = pi[j - 1]
>             if needle[i] == needle[j]:
>                 j += 1
>             pi[i] = j
>         # 2. 扫描匹配：j = 已匹配的 needle 长度
>         j = 0
>         for i in range(n):
>             while j > 0 and haystack[i] != needle[j]:
>                 j = pi[j - 1]
>             if haystack[i] == needle[j]:
>                 j += 1
>             if j == m:
>                 return i - m + 1
>         return -1
> ```

## 复杂度

- 时间：O(n + m)，建 pi 走 m 步、匹配走 n 步；j 只随相等递增、回退总次数不超过总递增次数，while 回退摊还后仍是线性。
- 空间：O(m)，前缀函数数组 pi。

## 易错点

1. 回退只写 `if` 不写 `while`：`haystack = "aabaa"`、`needle = "aaa"`（应 -1）——只回退一次后 needle[j] 可能还不等，带着错位的 j 继续比会错报 2；必须连续回退到 j==0 或相等为止。
2. `while` 条件漏 `j > 0`：j 为 0 时 `pi[j-1]` 下标越界；`haystack = "abc"`、`needle = "bcd"` 第一步就失配且 j==0。
3. 返回 `i` 而不是 `i - m + 1`：`haystack = "sadbutsad"`、`needle = "sad"` 命中时 i=2，起点才是 0。
4. 漏 needle 为空的兜底：`haystack = "abc"`、`needle = ""` 应返回 0，否则 pi 数组和 `needle[0]` 全越界（题目保证非空，防御性写）。
5. C++：`haystack.size()` 是 `size_t` 无符号数，赋给 `int` 前先 `(int)` 转换，避免后续比较的符号警告。

## 一句话总结
