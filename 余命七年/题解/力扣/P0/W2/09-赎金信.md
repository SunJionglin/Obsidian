# 383. 赎金信 Ransom Note

## 一句话题意

给两个字符串 `ransomNote` 和 `magazine`，判断能否用 `magazine` 里的字符拼出 `ransomNote`，每个字符只能用一次，返回布尔值。

## 解题逻辑

**先想什么**：读完题第一反应是「逐个字符去 magazine 里找」，找到一个就用掉一个。

**朴素解法**：对 `ransomNote` 的每个字符，去 `magazine` 里线性找一个相同且还没用过的字符，找到就删掉或标记已用。每找一次 O(m)，总共 O(n·m)，两串都到 1e5 时约 1e10 次比较，力扣会超时。

**优化观察**：字符集只有 26 个小写字母，唯一要紧的信息是每个字母的**个数**（字母在哪个位置出现根本不重要）。把 `magazine` 里每个字母的个数先数出来装进 26 个桶，之后每消耗一个字符就从对应桶里拿一个，不够就是 false。查找从「线性扫 magazine」变成「下标直接定位」，O(n+m) 一趟结束。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 双层循环找字符 | O(n·m) | O(1) | 两串都长时超时 |
| 排序 + 双指针 | O(m log m + n log n) | O(n+m) | 排序打乱原串还得复制，绕远路 |
| 26 桶计数 | O(n+m) | O(1) | 只适用于字符集固定且小的情况 |

**选桶计数**：字符集只有 26 个字母，定长数组就是最轻的哈希表——连哈希函数的开销都省了，时间 O(n+m)、空间 O(1)，两个维度同时最优，是计数类问题的标准姿势。

## 关键点

1. 先统计 `magazine`（供方）每个字母的个数，再逐个消耗 `ransomNote`（需方）。
2. 每消耗一个字符，对应桶减 1；**减成负数**就是不够用，直接 false。
3. 小写字母用 `c - 'a'`（Python 里 `ord(c) - ord('a')`）映射到 0~25。
4. 减到 0 是合法的（刚好用完），判断条件是 `< 0` 而不是 `<= 0`。

## 实现逻辑

三个动作循环做：**统计 magazine → 逐个消耗 → 桶变负就 false**。

拿 `ransomNote = "aa"`、`magazine = "aab"` 手推一遍：

| 步骤 | 当前字符 | 桶怎么变 | 检查什么 | 结果 | 桶状态 |
| --- | --- | --- | --- | --- | --- |
| 统计 magazine | a, a, b | cnt[a] 两次 +1，cnt[b] 一次 +1 | — | 建好桶 | {a:2, b:1} |
| 消耗第 1 个 a | a | cnt[a] 2→1 | ≥0 | 继续 | {a:1, b:1} |
| 消耗第 2 个 a | a | cnt[a] 1→0 | ≥0 | 继续 | {a:0, b:1} |
| 全部消耗完 | — | — | — | 返回 true | — |

换成 `magazine = "ab"` 时，第二个 a 会把 cnt[a] 从 0 减到 -1，直接返回 false。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     bool canConstruct(string ransomNote, string magazine) {
>         if (ransomNote.size() > magazine.size()) return false; // 供方都不够长，直接剪枝
>         int cnt[26] = {0};                                      // 26 个桶，全 0
>         for (char c : magazine) cnt[c - 'a']++;                 // 统计供方
>         for (char c : ransomNote)                               // 逐个消耗需方
>             if (--cnt[c - 'a'] < 0) return false;               // 先减后查，负数=不够
>         return true;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def canConstruct(self, ransomNote: str, magazine: str) -> bool:
>         if len(ransomNote) > len(magazine):          # 供方不够长，直接剪枝
>             return False
>         cnt = [0] * 26                               # 26 个桶，全 0
>         for ch in magazine:                          # 统计供方
>             cnt[ord(ch) - ord('a')] += 1
>         for ch in ransomNote:                        # 逐个消耗需方
>             cnt[ord(ch) - ord('a')] -= 1
>             if cnt[ord(ch) - ord('a')] < 0:          # 负数 = 不够用
>                 return False
>         return True
> ```

## 复杂度

- 时间：O(n + m)，magazine 和 ransomNote 各遍历一遍，桶操作每次 O(1)。
- 空间：O(1)，26 个桶是固定大小，不随输入增长。

## 易错点

1. 只查「有没有这个字母」不计数：`ransomNote = "aa"`、`magazine = "ab"`，a 虽然出现过但只有一个，用 set 或「是否出现」判断会错判 true——必须计数并每用一次减 1。
2. 减到 0 是合法的：`ransomNote = "aab"`、`magazine = "aab"`，最后一个 b 用完桶变 0，应返回 true；把判断写成 `<= 0`（0 也算不够）会错判 false。
3. C++：`int cnt[26]` 必须写 `= {0}`，不初始化读的是垃圾值，计数全乱。
4. Python：对每个字符现数 `magazine.count(ch)` 结果没错，但每个字符都重扫一遍 magazine，`ransomNote = "a" * 10000`、`magazine = "b" * 10000 + "a" * 10000` 时直接超时——先统计一次再消耗。
5. 空串边界：`ransomNote = ""` 时循环不执行、直接返回 true（空串永远拼得出来）；`magazine = ""` 且 note 非空时必须返回 false。
