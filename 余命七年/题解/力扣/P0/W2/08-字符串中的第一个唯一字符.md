# 387. 字符串中的第一个唯一字符 First Unique Character in a String

## 一句话题意

给一个只含小写字母的字符串，返回**第一个只出现一次**的字符下标（从 0 开始）；全都不唯一返回 `-1`。

## 解题逻辑

**先想什么**：读完题第一反应是「每个字符往后面扫一遍，看有没有和它相同的」，两两对照。

**朴素解法**：对每个位置 `i`，再开一层循环把整个字符串扫一遍找相同字符，全串没有第二个才算「唯一」。O(n²)，n 到 1e5 时约 1e10 次比较，力扣会超时。

**优化观察**：一个字符「是否唯一」只取决于它在**全串的出现次数**，跟它站在哪无关——位置只在「谁排第一」时用得上。所以先一趟把 26 个小写字母的次数全数出来，再按原顺序第二趟找第一个次数恰为 1 的下标。靠「全局计数 + 原序扫描」两趟 O(n)，把内层的重复比较整层压掉。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 两层循环 | O(n²) | O(1) | n=1e5 必超时 |
| unordered_map 计数 + 第二遍 | O(n) | O(26) | 哈希常数开销大，还不能遍历它找答案（不保序） |
| 定长数组 cnt[26] + 第二遍 | O(n) | O(26)=O(1) | 依赖「只含小写字母」的约定 |

**选数组**：字母表固定 26 个，`s[i] - 'a'` 直接当下标，比哈希更快、空间常数级，是这题的标准解。

## 关键点

1. 两遍扫描模板：第一遍只数次数，第二遍按原顺序找第一个 `cnt == 1` 的下标。
2. 判断标准是**恰好 1 次**（`cnt == 1`），不是「出现过」——重复字符跳过，全重复返回 -1。
3. 第二遍必须按 `s` 的原下标顺序扫，哈希表不保证顺序，不能拿它输出「第一个」。
4. 边界约定：题目保证只含小写字母、长度 ≥ 1，所以 `cnt[26]` 定长数组成立。

## 实现逻辑

先开 `cnt[26]` 全置 0 → 第一遍遍历 `s`，`cnt[s[i] - 'a']++` 数次数 → 第二遍按原顺序遍历，第一个 `cnt[s[i] - 'a'] == 1` 的返回下标 `i` → 扫完都没有，返回 -1。

拿 `s = "abac"` 手推：第一遍数完 `cnt = {a:2, b:1, c:1}`。

| i | s[i] | 查什么 | 结果 | cnt 状态 |
| --- | --- | --- | --- | --- |
| 0 | a | cnt[a]==1? | 2，跳过 | 不变 |
| 1 | b | cnt[b]==1? | 1，命中 | 返回下标 1 |

C++ 里 `cnt[c - 'a']` 把字符当下标；Python 里 `Counter(s)` 一行数完，`enumerate` 顺手带上标。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     int firstUniqChar(string s) {
>         int cnt[26] = {0};                    // 题目保证只含小写字母
>         for (char c : s)
>             cnt[c - 'a']++;                   // 第一遍：只数次数
>         for (int i = 0; i < (int)s.size(); i++)
>             if (cnt[s[i] - 'a'] == 1)         // 第二遍：原顺序找第一个 1 次
>                 return i;
>         return -1;                            // 全重复，没有唯一字符
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> from collections import Counter
>
> class Solution:
>     def firstUniqChar(self, s: str) -> int:
>         cnt = Counter(s)                      # 第一遍：一行数完全部次数
>         for i, ch in enumerate(s):            # 第二遍：按原顺序
>             if cnt[ch] == 1:
>                 return i
>         return -1                             # 全重复
> ```

## 复杂度

- 时间：O(n)，两趟独立的线性扫描，每趟每个字符 O(1)。
- 空间：O(1)，cnt 固定 26 个 int，与 n 无关（Python 的 Counter 同样只 26 个键）。

## 易错点

1. `s = "aabb"`：用「出现过」的集合代替计数，扫到第一个 a 就返回 0，正解是 -1——必须记**次数**，第二个 a 要能把计数翻成 2。
2. `s = "ba"`：两个都唯一，答案是 0；C++ 遍历 `unordered_map` 找答案可能先吐 a 返回 1——哈希表不保序，第二遍必须按原串顺序扫。
3. `s = "aabb"`：两遍扫完没人次数为 1，循环外漏写 `return -1`，C++ 走到函数末尾无返回，未定义行为。
4. C++：`int cnt[26];` 没初始化，里面是垃圾值，判断随机出错——要写 `= {0}`。
5. `s = "leetcode"` 答案是 0：下标 0 是合法答案，别用「答案非 0 才返回」之类的写法把 0 当假值处理。
