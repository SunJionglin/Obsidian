# 15. 反转字符串中的单词 Reverse Words in a String

## 一句话题意

给一个可能带前导/尾随/连续空格的字符串 `s`，返回单词顺序反转、单词间只剩一个空格的字符串。

## 解题逻辑

**先想什么**：读完题先确认两点——空格不只出现在单词之间（首尾、连续都有可能），结果里单词间**只能有一个空格**。所以「把整串倒过来再把每个单词内倒回来」行不通，空白会被一起带着跑。

**朴素解法**：双指针手动扫——`i` 跳过空格找单词头，`j` 向后走到单词尾，截出 `s[i..j]` 攒进 `vector`，最后倒序拼接。O(n)，但每个边界（开头没空格、结尾有空格、中间连续空格）都要单独处理，下标一写错就崩。

**优化观察**：单词 = 被空白隔开的「令牌」，而**标准库早就内置了按空白切词的工具**——C++ 的 `istringstream` 用 `>>` 抽取、Python 的 `split()`，它们天然吞掉所有多余空白，单词被一个不漏地抽出来。剩下的工作只剩一件：**倒序拼回去**。复杂度没变，靠的是把最容易出错的「空白处理」外包给库，代码从几十行缩到几行。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 双指针手动切词 | O(n) | O(n) | 前导/尾随/连续空格的边界全要手写，下标易错 |
| 存 vector 再倒序遍历 | O(n) | O(n) | 多一层容器，代码量也不小 |
| stringstream / split 切词 + 倒序拼 | O(n) | O(n) | 依赖库的切词行为，面试被追问时要说清「按任意空白切」 |

**选 stringstream / split**：题目唯一刁钻的地方就是各种空白，把「识别单词」交给流抽取，天然跳过连续空格、不产生空单词，正确性由库保证；自己只写一行倒序拼接，是这题最干净、最不容易错的标准解。

## 关键点

1. `>>` 抽取和 Python 无参 `split()` 都**按任意连续空白切词**，不会产生空字符串单词。
2. 倒序拼接 = **新单词永远插到结果最前面**；结果非空时先补一个空格再插。
3. 边界约定：输入可能有前导、尾随、连续空格；输出保证单词间单空格、无首尾空格。空串输入返回空串。

## 实现逻辑

三步走：**用流切词 → 每次抽一个单词 → 新单词拼到结果前头（非空时补空格）**。

拿 `s = "  a bb  "` 手推一遍：

| 抽取次数 | 抽到的 word | ans 当前值 | 查什么 | 动作 | 结果 ans |
| --- | --- | --- | --- | --- | --- |
| 1 | `a` | 空 | 空吗？空，不补空格 | `a` 拼到前面 | `a` |
| 2 | `bb` | `a` | 空吗？不空，先补空格 | `" " + "bb"` 拼到前面 | `bb a` |
| 抽完 | — | — | 流耗尽退出循环 | — | `bb a` |

C++ 里 `ss >> word` 抽不到就返回假、循环自然结束；Python 里 `reversed(s.split())` 返回倒序单词的迭代器，`join` 用单空格缝上。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     string reverseWords(string s) {
>         istringstream ss(s);               // 按空白切词，连续/首尾空格自动跳过
>         string word, ans;
>         while (ss >> word) {               // 每次抽一个完整单词，抽完返回假
>             if (!ans.empty()) ans = " " + ans;   // 已有内容先补一个空格
>             ans = word + ans;              // 新单词插到最前 = 倒序
>         }
>         return ans;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def reverseWords(self, s: str) -> str:
>         return " ".join(reversed(s.split()))   # split() 无参按任意空白切；倒序后单空格拼接
> ```

## 复杂度

- 时间：O(n)，切词扫一遍字符串、拼接总长度也是 n，整体线性。
- 空间：O(n)，答案字符串和切出来的单词加起来不超过 O(n)。

## 易错点

1. `s = "the sky is blue"`：把空格补到 `word` 后面（`ans + word + " "`）会得到尾随空格，正确位置是**插新单词之前**补。
2. `s = "a good   example"`：用 `split(" ")`（带参数按单个空格切）会切出空串，拼出来 `example   good a` 带多余空格——无参 `split()` 或 `>>` 抽取才吞连续空格。
3. `s = "  hello world  "`：手动双指针版本若漏掉「跳过前导空格」会输出 ` hello world`，开头多一个空格。
4. C++：误用 `getline(ss, word, ' ')` 也会把连续空格读成空单词，切词要用 `>>` 抽取。
5. Python：返回值是 `"".join()` 会把单词缝在一起，必须是 `" ".join()`，分隔符是空格。
