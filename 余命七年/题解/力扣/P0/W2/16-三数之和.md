# 15. 三数之和 3Sum

## 一句话题意

给一个整数数组，返回所有和为 0 且**互不重复**的三元组 `[nums[i], nums[j], nums[k]]`（i、j、k 互不相同），顺序任意，无解返回空。

## 解题逻辑

**先想什么**：固定一个数 `nums[i]`，剩下两个数就是「两数之和」——直接上三层循环穷举。

**朴素解法**：三层循环枚举 i < j < k 的所有组合，判断和是否为 0。O(n³)，n 到 3000 时约 2.7e10 次比较，必超时；就算过了时间，去重还得再花一遍功夫。

**优化观察**：本题和两数之和最大的区别是——**返回的是值，不是下标**，所以排序合法。排序后固定 `nums[i]`，剩下两个数用**双指针**从 `i+1` 和 `n-1` 相向逼近，一趟 O(n) 就能扫完所有配对；更妙的是有序数组让重复元素挤在一起，去重只需「跳过和上一个相同的」这一句话，不用额外开 set。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 三层循环 | O(n³) | O(1) | 大数据超时，去重还要额外处理 |
| 固定数 + 哈希表 | O(n²) | O(n) | 去重麻烦，结果要放进 set 才能保证不重复 |
| 排序 + 双指针 | O(n²) | O(1) | 会改变原数组顺序，但本题不需要下标 |

**选排序 + 双指针**：返回的是值，排序的副作用不存在；双指针借有序性把内层从 O(n²) 压到 O(n)，去重顺手完成，时间空间双优，是这题的标准解。

## 关键点

1. **不变量**：排序后固定 `i`，双指针 `l = i+1`、`r = n-1`，始终保持 `i < l < r`，三个下标天然互不相同。
2. 和 `s < 0` 则 `l++`（需要更大的数），`s > 0` 则 `r--`（需要更小的数），`s == 0` 收答案。
3. **三重去重**：`i` 与 `nums[i-1]` 相同就跳过；收到答案后 `l` 与 `nums[l+1]` 相同就右移、`r` 与 `nums[r-1]` 相同就左移，最后 `l++、r--` 收口。
4. `i` 的去重**必须和前一个比**（`nums[i] == nums[i-1]`），不能和后一个比——否则会漏掉 `[-1,-1,2]` 这种同一值用两次的合法解。

## 实现逻辑

先 **排序**，再**固定 i**（跳过重复值），然后用**双指针查和**，找到就**收答案 + 双端去重 + 双指针收口**。

拿 `nums = [-1,0,1,2,-1,-4]` 排序后 `[-4,-1,-1,0,1,2]` 手推：

| i(nums[i]) | l(nums[l]) | r(nums[r]) | s | 动作 | ans |
| --- | --- | --- | --- | --- | --- |
| 0(-4) | 1(-1) | 5(2) | -3 | s<0，l 一路右移到 l==r，本轮无解 | [] |
| 1(-1) | 2(-1) | 5(2) | 0 | 收 [-1,-1,2]，去重后 l=3、r=4 | `[-1,-1,2]` |
| 1(-1) | 3(0) | 4(1) | 0 | 收 [-1,0,1]，l=4、r=3 结束 | `[-1,-1,2],[-1,0,1]` |
| 2(-1) | — | — | — | nums[2]==nums[1]，跳过 | 同上 |
| 3(0) | 4(1) | 5(2) | 3 | s>0，r 左移后 l==r，无解 | 同上 |

C++ 里用 `long long` 存和避免溢出（本题 ±1e5 用 int 也够，纯属保险）；Python 没有溢出问题。

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     vector<vector<int>> threeSum(vector<int>& nums) {
>         sort(nums.begin(), nums.end());                  // 排序后才能用双指针
>         vector<vector<int>> ans;
>         int n = nums.size();
>         for (int i = 0; i < n - 2; i++) {
>             if (i > 0 && nums[i] == nums[i - 1]) continue;    // 去重：和前一个固定值比
>             int l = i + 1, r = n - 1;
>             while (l < r) {
>                 long long s = (long long)nums[i] + nums[l] + nums[r];
>                 if (s == 0) {
>                     ans.push_back({nums[i], nums[l], nums[r]});
>                     while (l < r && nums[l] == nums[l + 1]) l++;  // 去重 l，带 l<r 防越界
>                     while (l < r && nums[r] == nums[r - 1]) r--;  // 去重 r
>                     l++; r--;                          // 收口，必须同时动两端
>                 } else if (s < 0) l++;                 // 和太小，左指针右移
>                 else r--;                              // 和太大，右指针左移
>             }
>         }
>         return ans;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def threeSum(self, nums: list[int]) -> list[list[int]]:
>         nums.sort()                                    # 排序后才能用双指针
>         ans = []
>         n = len(nums)
>         for i in range(n - 2):
>             if i > 0 and nums[i] == nums[i - 1]:       # 去重：和前一个固定值比
>                 continue
>             l, r = i + 1, n - 1
>             while l < r:
>                 s = nums[i] + nums[l] + nums[r]
>                 if s == 0:
>                     ans.append([nums[i], nums[l], nums[r]])
>                     while l < r and nums[l] == nums[l + 1]:   # 去重 l，带 l<r 防越界
>                         l += 1
>                     while l < r and nums[r] == nums[r - 1]:   # 去重 r
>                         r -= 1
>                     l += 1                             # 收口，必须同时动两端
>                     r -= 1
>                 elif s < 0:
>                     l += 1                             # 和太小，左指针右移
>                 else:
>                     r -= 1                             # 和太大，右指针左移
>         return ans
> ```

## 复杂度

- 时间：O(n²)，排序 O(n log n) + 固定 n 次 × 双指针每轮 O(n)，总 O(n²)。
- 空间：O(1)，除了答案数组不额外开空间（排序是原地的，递归栈 O(log n) 不计）。

## 易错点

1. `i` 去重和后一个比：`nums = [-1,-1,2,0]` 时 `i=0` 看到 `nums[0]==nums[1]` 就 continue，`[-1,-1,2]` 永远收不到——去重条件必须是 `nums[i] == nums[i-1]`。
2. 内层去重不写 `l < r`：`nums = [0,0,0,0]` 找到解后 l、r 连续去重会一路冲出数组边界——两个 while 都要带 `l < r`。
3. 收到答案后只动 `l` 或只动 `r`：下一步和不变还是 0，死循环；必须 `l++、r--` 同时收口。
4. 无解要返回**空的** `vector<vector<int>>{}`（或 `[]`），不是返回 nullptr 或别的哨兵值。
5. C++ 里 `nums.size()` 是 `unsigned`，循环用 `int i` 比较会有警告，先取 `int n = nums.size()` 再循环。
