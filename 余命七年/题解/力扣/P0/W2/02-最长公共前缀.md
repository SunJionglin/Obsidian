# 14. 最长公共前缀 Longest Common Prefix

## 一句话题意

给一组字符串，返回最长共同前缀；没有就返回空串。

## 解题逻辑

**先想什么**：前缀是所有串共有的开头，一个位置只要有一个串不一样，前缀就到此为止。

**朴素解法**：水平扫描——拿第一个串当基准，逐个和后面的串求公共前缀，前缀只减不增。最坏 O(S)（S 是所有字符总数），但每轮都要 `substr` 复制一份新前缀，代码啰嗦，还容易在空串上多写特判。

**优化观察**：公共前缀有个强约束——**第 i 位的字符要么所有串都一样，要么前缀就在 i 结束**。与其两两求前缀，不如直接**逐列竖扫**：外层枚举列 i，内层枚举每个串比第 i 位，遇到「有串到头」或「字符不同」立即返回。靠这个不变量，一趟 O(S) 扫完，一次复制都不用。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 水平扫描（两两求前缀） | O(S) | O(1) | 反复 `substr`，写法绕 |
| 排序 + 比首尾两串 | O(N·M·log N) | O(log N) | 排序本身没必要，串长时吃亏 |
| 逐列竖扫 | O(S) | O(1) | 内层要记得先判「串到头」 |

**选逐列竖扫**：一趟 O(S)、零额外空间、没有排序开销，是最顺的写法；排序方案花排序的代价只换来「只比两个串」，不划算。

## 关键点

1. 循环骨架**外层列、内层行**：外层扫基准串的每个位置 i，内层扫每个串的第 i 位。
2. 边界约定：内层**先判 `i == len(s)`**（有串先到头）再取 `s[i]`，否则越界。
3. 不变量：循环中 `strs[0][:i]` 始终是所有串的公共前缀，i 只增不减，出错直接 `return`。
4. 基准串取任意一个都行，用 `strs[0]` 最省事；题目保证至少一个串。

## 实现逻辑

先取基准串第 i 位的字符 → 再扫所有串比这一位 → 有串到头或字符不同就返回当前前缀，全通过就拼上这个字符；扫完整个基准串就返回。

拿 `strs = ["flower","flow","flight"]` 手推一遍：

| i | 基准字符 c | 查什么 | 结果 | 前缀 |
| --- | --- | --- | --- | --- |
| 0 | 'f' | 三个串第 0 位都是 'f' 吗 | 是 | "f" |
| 1 | 'l' | 三个串第 1 位都是 'l' 吗 | 是 | "fl" |
| 2 | 'o' | "flight"[2]='i' ≠ 'o' | 不同，返回 | "fl" |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     string longestCommonPrefix(vector<string>& strs) {
>         string ans;
>         for (int i = 0; i < (int)strs[0].size(); i++) {   // 列：基准串的每个位置
>             char c = strs[0][i];
>             for (auto& s : strs) {                          // 行：所有串在这一列
>                 if (i == (int)s.size() || s[i] != c)        // 有串到头 / 字符不同
>                     return ans;                             // 前缀到此结束
>             }
>             ans += c;                                       // 这一列全通过，拼上去
>         }
>         return ans;
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def longestCommonPrefix(self, strs: list[str]) -> str:
>         ans = []
>         for i in range(len(strs[0])):        # 列：基准串的每个位置
>             c = strs[0][i]
>             for s in strs:                   # 行：所有串在这一列
>                 if i == len(s) or s[i] != c: # 有串到头 / 字符不同
>                     return "".join(ans)      # 前缀到此结束
>             ans.append(c)                    # 这一列全通过，拼上去
>         return "".join(ans)
> ```

## 复杂度

- 时间：O(S)，S 是所有字符串的字符总数；每个字符至多被比较一次。
- 空间：O(1)，除答案外不占额外空间。

## 易错点

1. `strs = ["ab","a"]`：内层必须先判 `i == len(s)`，否则取 `s[i]` 越界（C++ 里是未定义行为）。
2. `strs = ["","abc"]`：基准串为空，循环直接不进、返回 `""`——别想当然先取 `strs[0][0]`。
3. C++：`strs[0].size()` 是无符号数，和 `int i` 比较会有符号转换，先 `(int)` 转一下。
4. 别用 `all(s.startswith(prefix))` 每轮从头比：`["aaaaab","aaaaac"]` 这类会把一趟扫描退化成每轮重扫，最坏 O(N·M²)。
5. 没有公共前缀要返回 `""`，不是 `None`，力扣判题按字符串比较。
