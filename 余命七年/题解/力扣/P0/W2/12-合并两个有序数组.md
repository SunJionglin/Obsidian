# 88. 合并两个有序数组 Merge Sorted Array

## 一句话题意

把 `nums2` 的 n 个有序元素原地并入 `nums1`（总长 m+n，尾部 n 个 0 占位），使整体有序，不返回值。

## 解题逻辑

**先想什么**：两个数组各自有序，合并 = 反复取「两个头部里较小的」。第一反应是像归并那样开个新数组，从前往后填。

**朴素解法**：两条路都各有毛病——把 `nums2` 拷进 `nums1` 尾部再 `sort` 一遍，O((m+n) log(m+n))，白白浪费「两边各自有序」的条件；开辅助数组从前往后归并再拷回，O(m+n) 时间但多花 O(m+n) 空间。

**优化观察**：从前往后写有个死穴——`nums1` 前 m 位是「还没读的数据」，往前写会覆盖它们。关键观察是 **`nums1` 尾部那 n 个 0 本来就是空占位**，把写入方向掉个头，从 `m+n-1` 往前填，覆盖的永远是已经处理过的位置。靠什么降复杂度：用白送的尾部空位当缓冲区，空间从 O(m+n) 压到 O(1)，时间保持 O(m+n)。

## 为什么选这个方法

| 方案 | 时间 | 空间 | 缺点 |
| --- | --- | --- | --- |
| 拷进尾部 + sort | O((m+n) log(m+n)) | O(1) | 没用上两数组各自有序，白付排序钱 |
| 开新数组从前往后归并 | O(m+n) | O(m+n) | 多一份数组，最后还要整段拷回 |
| 从后往前原地归并 | O(m+n) | O(1) | 方向反着写，下标容易绕晕 |

**选从后往前**：两个有序数组合并本来就只需 O(m+n)，这题又白送 n 个尾部空位当缓冲区，时间和空间同时拿满，代价只是「倒着写」的习惯问题。

## 关键点

1. **三个指针倒着走**：`i = m-1`（nums1 待取位）、`j = n-1`（nums2 待取位）、`k = m+n-1`（写入位），每轮取 `nums1[i]` 和 `nums2[j]` 里**大的**放进 `nums1[k]`。
2. **模板句**：`while (j >= 0) nums1[k--] = (i >= 0 && nums1[i] > nums2[j]) ? nums1[i--] : nums2[j--];`
3. **不变量**：k 始终领先 i 至少 n 个位置（初始差 n，之后只增不减），写入位永远碰不到 nums1 还没读的部分。
4. **边界约定**：循环条件只看 `j >= 0`——nums2 搬完即结束；nums1 先取完（i < 0）靠 `i >= 0` 短路兜住，此时剩下的全是 nums2 的元素，直接依次落位。

## 实现逻辑

三个动作：**两指针从各自尾部起步 → 每轮把大的那个填进 k 并回退对应指针 → j < 0 即 nums2 搬完收工**（nums1 没取完的部分本来就在原位）。

拿 `nums1 = [1,2,3,0,0,0]`、`m = 3`、`nums2 = [2,5,6]`、`n = 3` 手推：

| k | i | j | nums1[i] | nums2[j] | 取谁 | 写入 | nums1 状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 5 | 2 | 2 | 3 | 6 | 6（大） | nums1[5]=6 | [1,2,3,0,0,6] |
| 4 | 2 | 1 | 3 | 5 | 5（大） | nums1[4]=5 | [1,2,3,0,5,6] |
| 3 | 2 | 0 | 3 | 2 | 3（大） | nums1[3]=3 | [1,2,3,3,5,6] |
| 2 | 1 | 0 | 2 | 2 | 相等取 nums2 | nums1[2]=2 | [1,2,2,3,5,6] |
| 1 | 1 | -1 | — | — | j<0 结束 | — | [1,2,2,3,5,6] |

## 代码

> [!warning]- 先自己写再展开 · C++
> ```cpp
> class Solution {
> public:
>     void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
>         int i = m - 1, j = n - 1, k = m + n - 1;
>         while (j >= 0) {                        // 只看 j：nums2 搬完即结束
>             if (i >= 0 && nums1[i] > nums2[j]) { // i>=0 短路，防 nums1[-1] 越界
>                 nums1[k--] = nums1[i--];
>             } else {
>                 nums1[k--] = nums2[j--];
>             }
>         }
>     }
> };
> ```

> [!warning]- 先自己写再展开 · Python
> ```python
> class Solution:
>     def merge(self, nums1: list[int], m: int, nums2: list[int], n: int) -> None:
>         i, j, k = m - 1, n - 1, m + n - 1
>         while j >= 0:                        # 只看 j：nums2 搬完即结束
>             if i >= 0 and nums1[i] > nums2[j]:  # i>=0 短路，防越界
>                 nums1[k] = nums1[i]
>                 i -= 1
>             else:
>                 nums1[k] = nums2[j]
>                 j -= 1
>             k -= 1
> ```

## 复杂度

- 时间：O(m+n)，i、j 两指针总共回退 m+n 次，每轮恰好回退一个。
- 空间：O(1)，只有三个下标变量，全程原地写。

## 易错点

1. 从前往后写会覆盖没读的数据：`nums1=[4,5,6,0,0,0]`、`m=3`、`nums2=[1,2,3]`——正向合并第一步把 1 写进 `nums1[0]`，4 就丢了，结果错成 [1,2,3,1,2,3]。
2. 条件漏 `i >= 0`：`nums1=[0]`、`m=0`、`nums2=[1]`——i=-1 时直接读 `nums1[-1]` 越界；`i >= 0` 必须写在 `&&` 前面短路。
3. 循环条件写成 `i >= 0 && j >= 0`：`nums1=[2,0]`、`m=1`、`nums2=[1]`——i 先取完循环就停了，nums2 剩的 1 没搬进去，结果 [2,0]；条件只看 `j >= 0`。
4. 下标起步忘减一：`i = m` 会把尾部的占位 0 当数据，`nums1=[1,2,3,0,0,0]`、`nums2=[2,5,6]` 时第一步拿 0 和 6 比，把 0 写进 `nums1[5]`；正确起步是 `i=m-1, j=n-1, k=m+n-1`。
5. 返回值：函数签名是 `void` / `None`，别 `return nums1` 也别新开数组交出去——判题直接检查原地修改后的 `nums1`。
