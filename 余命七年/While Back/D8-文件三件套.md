### 1.1 K1 `open` 与文件模式　`★★★ 60 分钟`

**是什么**　`open(path, mode, encoding)` 打开一个文件，返回**文件对象**——它是你操作文件的窗口，带一个「位置指针」记录读到哪了。文件不在内存里，文件对象只是把手。

**四种模式，一字之差**：

| 模式 | 语义 | 文件不存在时 | 文件存在时 |
| --- | --- | --- | --- |
| `r` | 只读（默认） | 报 `FileNotFoundError` | 指针在开头 |
| `w` | 只写 | 自动创建 | **先清空再写** |
| `a` | 追加写 | 自动创建 | 指针在末尾，不清空 |
| `x` | 独占创建 | 自动创建 | 报 `FileExistsError` |

组合后缀，`+` 加读写（`r+` 可读可写不截断，`w+` 截断后可读写）、`b` 二进制（图片/压缩包必须 `rb/wb`）、`t` 文本（默认）。

**encoding 为什么必写**　`open` 不写 `encoding` 时用系统默认——macOS/Linux 多是 UTF-8，Windows 多是 GBK。同一份代码换台机器，中文全变乱码。所以规矩是**永远显式写 `encoding="utf-8"`**；读带 BOM 的文件用 `utf-8-sig`。

**最小例子**：

```python
# 写
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n第二行\n")

# 追加（不清空）
with open("note.txt", "a", encoding="utf-8") as f:
    f.write("第三行\n")

# 独占创建（防止覆盖别人）
try:
    with open("note.txt", "x", encoding="utf-8") as f:
        f.write("hi")
except FileExistsError:
    print("文件已存在，不覆盖")
```

**原理一步**：文件对象的底层是操作系统给的「文件描述符」（一个整数编号），进程能同时打开的数量有限。`open` 申请一个，`close` 归还——这就是为什么「用完要关」不是洁癖，是资源账。

**边界与反例**：
- `w` 打开已有文件 = **文件瞬间被清空**，连 tab 都不提示。改数据前先 `Path(p).exists()`，或者先 `r` 读一遍。
- `open("目录")` 会报 `IsADirectoryError`——路径指到目录了。
- `open("a.txt", "r", encoding="gbk")` 读 UTF-8 文件报 `UnicodeDecodeError`——编码不是随便写。
- 忘记 `close()`：程序不退出就一直占着 fd，循环里打开会 `Too many open files`。

**易错清单**：
1. `w` 当 `r` 用，清空数据
2. 不写 `encoding`，换机器乱码
3. `x` 已存在没接 `FileExistsError`
4. 文件名写错导致 `r` 报错，先 `ls` 确认

**关系**：前置 W1 K16；K2（with）解决「总是忘 close」，K3（读法）决定「怎么把内容拿出来」。

### 1.2 K2 `with` 上下文管理器　`★★★ 45 分钟`

**是什么**　`with open(...) as f:` 是 try/finally 的语法糖。进入时调 `__enter__`（返回文件对象），退出时**无论正常还是异常**都调 `__exit__`（里面做 `close`）。

**为什么**　三个理由：
1. 手写 `try/finally` 容易漏，`with` 一行顶六行
2. 异常路径也会关闭——`try` 里 `raise` 了，`finally` 也执行，文件不泄漏
3. 可读性，缩进就是「文件的寿命」，出缩进 = 已关闭

**最小例子 + 验证**：

```python
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("x")
    raise RuntimeError("故意炸")   # 异常也会走到 __exit__
# 程序到不了这里，但文件已经关了——用下面的写法验证
```

```python
try:
    with open("a.txt", "w", encoding="utf-8") as f:
        f.write("x")
        raise RuntimeError("炸")
except RuntimeError:
    print(f.closed)   # True ← with 在异常时也关
```

**扩展（自定义上下文管理器）**：

```python
class Timer:
    def __enter__(self):
        import time; self.t = time.time(); return self
    def __exit__(self, exc_type, exc, tb):
        import time
        print(f"耗时 {time.time() - self.t:.3f}s")

with Timer():
    sum(range(10_000_000))
# 出 with 自动打印耗时
```

**边界与反例**：
- `with` 只管「离开时清理」，**不管 `w` 模式会清空文件**——两个概念别混。
- `with` 不保证数据已落盘：`close` 会 flush，但进程被 kill 时还没走到 `__exit__`。
- `as f` 拿到的是 `__enter__` 的返回值，不一定是文件本身。

**关系**：K1 的资源账在这里还清。K3 的所有读法都套 `with` 写。

### 1.3 K3 三种读法　`★★★ 45 分钟`

**是什么**　把文件内容拿出来的五条路：

| 写法 | 返回 | 内存 | 什么时候用 |
| --- | --- | --- | --- |
| `f.read()` | 整个 str | 整个文件 | 小文件、要整体处理 |
| `f.read(n)` | 最多 n 个字符 | n | 逐块读大文件 |
| `f.readline()` | 一行（含 `\n`） | 一行 | 只取前几行 |
| `f.readlines()` | 所有行组成的 list | 全部行 | 小文件要列表 |
| `for line in f:` | 一行一行 | 一行 | **默认选它** |

**为什么 `for line in f` 是默认**：文件对象是迭代器，惰性一行一行产，1GB 日志也只占一行内存。`readlines()` 会把 1GB 全塞进 list——同样的代码，数据一大就 OOM。

**位置指针**：读完一次，指针在末尾，再读就是空串：

```python
with open("a.txt", encoding="utf-8") as f:
    print(f.read())   # 全部
    print(f.read())   # "" ← 指针在末尾了
    f.seek(0)         # 指针拨回开头
    print(f.read(3))  # 前 3 个字符
```

**行尾怎么处理**：读到的行带 `\n`（最后一行可能没有）。去掉用 `line.rstrip("\n")`，**不要用 `strip()`**——`strip()` 连行首尾的有意义空格一起剥，CSV 字段会坏。Windows 文件行尾是 `\r\n`，稳妥写法 `line.rstrip("\r\n")`。

**最小闭环（今天就能交的东西）**：

```python
from pathlib import Path
src = Path("log.txt")
with open(src, encoding="utf-8") as f:
    lines = [line.rstrip("\r\n") for line in f]
longest = max(lines, key=len)
Path("report.txt").write_text(
    f"行数：{len(lines)}\n最长：{len(longest)} 字\n", encoding="utf-8")
```

**边界与反例**：
- 大文件用 `readlines()` → OOM
- `strip()` 误删字段空格 → 用 `rstrip("\n")`
- 最后一行没换行，`split("\n")` 末尾会多个空串 → 用 `for line in f` 最稳
- `read(n)` 按字符不是按字节，中文一个字符算 1

**关系**：K1 开窗、K2 保证关窗、K3 把东西拿出来。三个 K 合起来就是「读文件 → 处理 → 写文件」的前半步；K4（写入）是后半步，明天学。

## 4 · 常见报错（病例库）

| 报错 | 原因 | 修法 |
| --- | --- | --- |
| `FileNotFoundError: [Errno 2]` | `r` 打开不存在的文件 / 路径拼错 | `ls` 确认 + `Path(p).exists()` |
| `UnicodeDecodeError` | 编码与文件不符（常见 GBK/BOM） | 试 `gbk`、`utf-8-sig` |
| `IsADirectoryError` | 把目录当文件打开 | 路径补上文件名 |
| `PermissionError: [Errno 13]` | 无权限 / 文件被占用 | 换目录；别 sudo 硬来 |
| `FileExistsError` | `x` 模式文件已存在 | 捕获它，或改 `w`（会清空） |
| `Too many open files` | 循环里 open 不 close | 全换成 `with` |
