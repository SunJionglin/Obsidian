## 2. 正文

### 2.1 Python 语法：列表与切片

> 细节版（完整方法表、越界规则、报错库、速查表）：[[05-序列]]

#### 2.1.1 增删改查

```python
a = [1, 2, 3]
a.append(4)          # [1,2,3,4]        尾部加一个
a.extend([5, 6])     # [1,2,3,4,5,6]    尾部加多个（把可迭代对象拆开）
a.insert(1, 9)       # [1,9,2,3,4,5,6]  指定位置插

a.pop()              # 弹尾部，返回被删的值；pop(0) 弹头部
a.remove(2)          # 按值删第一个 2，找不到报 ValueError
del a[0]             # 按索引删

a[0] = 100           # 改
a.index(3)           # 查下标，找不到报 ValueError
3 in a               # 成员判断 → True
a.count(3)           # 出现次数
len(a)               # 长度
```

**区别记忆**：

| 操作 | 参数是什么 | 找不到时 |
| --- | --- | --- |
| `remove(x)` | **值** | `ValueError` |
| `pop(i)` | **索引**（默认末尾） | `IndexError` |
| `del a[i]` | 索引 | `IndexError` |

`append` vs `extend`：前者把参数当一个整体塞进去，后者把它拆开逐个加。

```python
a = [1]
a.append([2, 3])   # [1, [2, 3]]   多了一个列表元素
a = [1]
a.extend([2, 3])   # [1, 2, 3]     元素被拆开
```

#### 2.1.2 切片

```python
a = [0, 1, 2, 3, 4, 5]
a[1:4]     # [1, 2, 3]        左闭右开
a[:3]      # [0, 1, 2]        省略起点 = 从头
a[3:]      # [3, 4, 5]        省略终点 = 到尾
a[::2]     # [0, 2, 4]        步长 2
a[::-1]    # [5, 4, 3, 2, 1]  步长 -1 = 反转
a[10:]     # []               越界不报错，返回空
a[0:100]   # [0,1,2,3,4,5]    越界不报错，自动截断
```

**三条规则**：左闭右开；越界不抛异常（这点和 `a[10]` 不一样）；负数下标从右往左数（`a[-1]` 是最后一个）。

#### 2.1.3 切片赋值

```python
a = [0, 1, 2, 3, 4]
a[1:3] = [9]          # [0, 9, 3, 4]    删了 2 个、插了 1 个
a[1:3] = [7, 8, 9]    # 长度可变
a[::2] = [0, 0, 0]    # 带步长的切片赋值：两边长度必须一致
```

普通切片赋值能改变列表长度；**带步长的切片赋值要求长度相同**，否则报错。

#### 2.1.4 排序

```python
a = [3, 1, 2]
a.sort()                 # 原地排序，返回 None
b = sorted(a)            # 返回新列表，a 不变

words = ["bb", "a", "ccc"]
words.sort(key=len)                    # 按长度排
words.sort(key=len, reverse=True)      # 降序
pairs = [("b", 2), ("a", 3), ("c", 1)]
pairs.sort(key=lambda p: p[1])         # 按第二项排
pairs.sort(key=lambda p: (-p[1], p[0]))# 先按第二项降，再按第一项升
```

| 写法 | 改原列表？ | 返回值 |
| --- | --- | --- |
| `a.sort()` | 是 | None |
| `sorted(a)` | 否 | 新列表 |

#### 2.1.5 列表推导式

```python
nums = [1, -2, 3, -4, 5]

neg_out  = [x for x in nums if x > 0]        # 去负：[1,3,5]
squares  = [x*x for x in nums]               # 平方
result   = sorted([x*x for x in nums if x > 0], reverse=True)  # 去负+平方+降序

pairs = [(i, j) for i in range(2) for j in range(2)]  # 嵌套：[(0,0),(0,1),(1,0),(1,1)]
```

等价写法：`[f(x) for x in a if cond(x)]` ==

```python
out = []
for x in a:
    if cond(x):
        out.append(f(x))
```

#### 2.1.6 二维表陷阱

```python
bad = [[0] * 3] * 2       # 两个元素指向同一个内层列表！
bad[0][0] = 1
print(bad)                # [[1,0,0], [1,0,0]]  ← 两行都变了

good = [[0] * 3 for _ in range(2)]   # 每行独立创建
good[0][0] = 1
print(good)               # [[1,0,0], [0,0,0]]  ✓
```

原因：`*` 复制的是**引用**。这个坑在生成矩阵、建 DP 表时会直接毁掉结果。

### 2.2 算法：原地数组操作

#### 2.2.1 什么算「原地」

题目说「不许新建数组」= 只能在原列表上搬元素，通常用**双指针**：一个慢指针记住「已处理好的位置」，一个快指针遍历。

额外空间只能是 O(1)。

#### 2.2.2 移除元素（27）与移动零（283）

```python
def remove_element(nums, val):        # 27
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != val:
            nums[slow] = nums[fast]
            slow += 1
    return slow                       # 前 slow 个是答案

def move_zeroes(nums):                # 283
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow += 1
```

思路：快指针找「要保留的元素」，慢指针把它们依次写到前面；283 用交换而不是覆盖，才能保证 0 被移到末尾。

#### 2.2.3 多数元素（169）与加一（66）

```python
def majority_element(nums):           # 169 摩尔投票
    cand, count = None, 0
    for x in nums:
        if count == 0:
            cand, count = x, 1
        elif x == cand:
            count += 1
        else:
            count -= 1
    return cand                       # 不同元素两两抵消，剩下的就是多数

def plus_one(digits):                 # 66
    for i in range(len(digits) - 1, -1, -1):
        if digits[i] < 9:
            digits[i] += 1
            return digits
        digits[i] = 0
    return [1] + digits               # 全是 9 的情况：99 → 100
```

多数元素为什么成立：多数元素出现次数 > n/2，其它元素加起来也没它多，两两抵消后一定剩它。

## 5. 常见报错（病例库）

| 报错 | 原因 | 解法 |
| --- | --- | --- |
| `ValueError: list.remove(x): x not in list` | `remove` 找不到该值 | 先 `if x in a` 或改用 `discard` 思路 |
| `IndexError: pop from empty list` | 空列表 `pop` | 先判空 |
| `IndexError: list index out of range` | 下标越界（不是切片） | 检查 `len` 与循环条件 |
| `ValueError: attempt to assign sequence of size 3 to extended slice of size 2` | 带步长切片赋值长度不一致 | 两边长度必须相同 |
| 改一行二维表全变 | `*` 复制的是引用 | 用 `[[0]*3 for _ in range(2)]` |

## 7. 自测

<details>
<summary>Q1：`a = [1,2,3]; b = a[:]; b.append(4)`，a 是几？</summary>

`a` 仍是 `[1,2,3]`。`a[:]` 是浅拷贝，新列表；`b = a` 才是共享。
</details>

<details>
<summary>Q2：`a[1:3] = [9]` 之后长度怎么变？</summary>

删掉 2 个、插入 1 个，长度 −1。切片赋值不要求等长（不带步长时）。
</details>

<details>
<summary>Q3：为什么 `sort()` 返回 None？</summary>

它原地改列表，返回值是 None。写成 `a = a.sort()` 会让 `a` 变成 None，这是常见错误。
</details>

<details>
<summary>Q4：283 为什么用交换而不是覆盖？</summary>

覆盖会把 0 丢掉；交换能把 0 挤到后面，同时保持非零元素的相对顺序。
</details>

<details>
<summary>Q5：摩尔投票为什么空间是 O(1)？</summary>

只用了 `cand` 和 `count` 两个变量，扫一遍就出结果，不需要额外数组。
</details>
