## 2. 正文

### 2.1 Python 语法：变量、字符串与布尔

#### 2.1.1 变量是「名字绑定对象」

```python
a = [1, 2]
b = a              # 两个名字指向同一个列表
b.append(3)
print(a)           # [1, 2, 3]

id(a) == id(b)     # True
a = [9]            # 重新绑定：a 指向新对象，b 还指旧的
print(b)           # [1, 2, 3]
```

要点：

1. **变量没有类型，对象才有类型**。`x = 1` 之后 `x = "a"` 完全合法。
2. **赋值是绑定，不是复制**。想复制列表要 `b = a[:]` 或 `list(a)`。
3. `a = b = []` 两个名字指向**同一个**列表，改一个另一个也变。

```python
def f(lst=[]):     # 默认参数只在定义时求值一次，是同一个列表
    lst.append(1)
    return lst
f(); f()           # [1, 1]  ← 经典坑
```

#### 2.1.2 数字、除法与类型判断

```python
7 / 2        # 3.5      真除法，结果永远是 float
7 // 2       # 3        向下取整（floor）
-7 // 2      # -4       不是 -3
-7 % 2       # 1        结果符号跟除数一致
divmod(7, 2) # (3, 1)   商与余一次拿到

int("12")    # 12       字符串转整数
int("3.5")   # ValueError！要先 float 再 int
float("1.5") # 1.5
str(12)      # '12'
```

```python
type(True)                # <class 'bool'>
isinstance(True, int)     # True  ← bool 是 int 的子类
type(1) == int            # True
isinstance(True, int)     # True（推荐用 isinstance，能认子类）
```

判断类型一律用 `isinstance`，`type(x) == T` 只在「必须精确等于」时用。

#### 2.1.3 字符串的定义、下标与切片

```python
s1 = 'abc'
s2 = "abc"
s3 = """第一行
第二行"""        # 三引号可跨行，常用于文档字符串或长文本

s = "abcdef"
s[0]        # 'a'
s[-1]       # 'f'
s[1:4]      # 'bcd'   左闭右开
s[::2]      # 'ace'   步长 2
s[::-1]     # 'fedcba' 反转
len(s)      # 6
for ch in s: ...        # 逐字符遍历
```

转义：`\n` 换行、`\t` 制表、`\\` 反斜杠、`r"\d"` 原生字符串（正则必用）。

**字符串不可变**：`s.upper()` 不改 `s`，要用返回值重新绑定。

#### 2.1.4 方法表（五类）

| 类别 | 方法 | 例子 → 结果 |
| --- | --- | --- |
| 查找 | `find` / `index` | `"abc".find("b")` → 1（`index` 找不到抛异常） |
| 查找 | `count` | `"aaa".count("a")` → 3 |
| 判断 | `startswith` / `endswith` | `"a.txt".endswith(".txt")` → True |
| 判断 | `isdigit` / `isalpha` / `isspace` | `"123".isdigit()` → True |
| 修改 | `upper` / `lower` | `"Ab".lower()` → 'ab' |
| 修改 | `strip` / `lstrip` / `rstrip` | `"  a  ".strip()` → 'a' |
| 修改 | `replace` | `"a-b".replace("-", "_")` → 'a_b' |
| 拆分 | `split` | `"a,b".split(",")` → ['a','b'] |
| 拼接 | `join` | `",".join(["a","b"])` → 'a,b' |
| 对齐 | `zfill` / `center` / `ljust` | `"7".zfill(3)` → '007' |

```python
s = "  Hello World  "
s.strip()                  # 'Hello World'（原字符串不变）
words = s.split()          # ['Hello', 'World']  按任意空白切，丢掉空串
" ".join(words)            # 'Hello World'
"a  b".split(" ")          # ['a', '', 'b']  按单个空格切，会留空串
```

#### 2.1.5 格式化三件套

```python
name, age = "小菜", 2
f"{name} 今年 {age} 岁"           # 推荐，3.6+
"{} 今年 {} 岁".format(name, age)
"%s 今年 %d 岁" % (name, age)     # 老写法

f"{3.14159:.2f}"    # '3.14'
f"{255:x}"          # 'ff'
f"{1234567:,}"      # '1,234,567'
f"{0.25:.0%}"       # '25%'
```

格式说明符：`.2f` 小数位、`,` 千分位、`x/X/o/b` 进制、`%` 百分比、`0>5` 填充。

#### 2.1.6 布尔与真值

```python
1 == 1.0        # True      值相等
1 is 1.0        # False     不是同一对象
x is None       # 判 None 只用 is

"" or "默认值"   # '默认值'   返回的是操作数，不是 True/False
0 and 1         # 0
not ""          # True
```

| 值 | 真假 |
| --- | --- |
| `0` `0.0` `0j` | 假 |
| `""` `b""` | 假 |
| `[]` `()` `{}` `set()` | 假 |
| `None` `False` | 假 |
| 其他（`"0"`、`[0]`、`-1`） | 真 |

`"0"` 和 `[0]` 都是真，这是最常翻车的一处。

### 2.2 算法：字符计数

#### 2.2.1 三种写法对比

```python
# ① dict 手写
def count_dict(s):
    d = {}
    for ch in s:
        d[ch] = d.get(ch, 0) + 1
    return d

# ② Counter（最省事）
from collections import Counter
def count_counter(s):
    return Counter(s)

# ③ 数组桶（值域已知时最快）
def count_array(s):
    cnt = [0] * 26
    for ch in s:
        cnt[ord(ch) - 97] += 1
    return cnt
```

| 写法 | 时间 | 特点 | 什么时候用 |
| --- | --- | --- | --- |
| dict | O(n) | 通用，键可以是任意字符 | 字符集不确定 |
| Counter | O(n) | 一行搞定，还能 `most_common` | 直接用，别手写 |
| 数组桶 | O(n) | 常数最小，内存固定 26 | 只含小写字母时 |

#### 2.2.2 为什么用 26 长度数组

哈希表每次要算哈希、查表、处理冲突；26 个桶直接用 `ord(ch) - ord('a')` 当下标，是纯数组随机访问。差值固定、空间固定，面试里写这个能省一半时间。

前提：题目保证只有小写字母。有其他字符就用 `Counter`。

#### 2.2.3 242 有效的字母异位词：一遍扫描

```python
def is_anagram(s, t):
    if len(s) != len(t):
        return False
    diff = [0] * 26
    for a, b in zip(s, t):
        diff[ord(a) - 97] += 1
        diff[ord(b) - 97] -= 1
    return all(x == 0 for x in diff)
```

思路：s 里出现就 +1，t 里出现就 -1，最后全 0 即异位词。比两次计数再比较省一遍遍历。

#### 2.2.4 387 第一个唯一字符

```python
def first_uniq_char(s):
    cnt = [0] * 26
    for ch in s:
        cnt[ord(ch) - 97] += 1
    for i, ch in enumerate(s):
        if cnt[ord(ch) - 97] == 1:
            return i
    return -1
```

两次遍历：第一次计数，第二次按**原顺序**找第一个计数为 1 的字符。顺序不能反，反了就不是「第一个」了。

#### 2.2.5 350 两个数组的交集 II：计短的那一边

```python
from collections import Counter

def intersect(nums1, nums2):
    if len(nums1) > len(nums2):      # 计短的，省空间
        nums1, nums2 = nums2, nums1
    cnt = Counter(nums1)
    res = []
    for x in nums2:
        if cnt[x] > 0:               # 缺键时 Counter 返回 0，不会 KeyError
            res.append(x)
            cnt[x] -= 1              # 减一，处理重复元素
    return res
```

`[1,2,2,1]` 与 `[2,2]` → `[2,2]`。每个 `2` 命中后减一，第二个 `2` 还能命中，第三个就不行了。若数组已排序，跟进解法是双指针、额外空间 O(1)；今天先掌握计数版。

### 2.3 Linux 权限：`ls -l` 那串字母与 `chmod`

`ls -l` 的一行拆开看：

```text
-rwxr-xr-x@ 1 jionglin  staff  15286 Nov  3 21:41 str_demo.py
drwxr-xr-x  3 jionglin  staff     96 Nov  3 21:40 demo
```

| 段 | 例子 | 含义 |
| --- | --- | --- |
| 第 1 位 | `-` / `d` / `l` | 类型：普通文件 / 目录 / 符号链接 |
| 第 2–4 位 | `rwx` | 所有者（u）的权限 |
| 第 5–7 位 | `r-x` | 所属组（g）的权限 |
| 第 8–10 位 | `r-x` | 其他人（o）的权限 |
| 9 位权限之后 | `@` / `+` | macOS 扩展属性 / ACL，**不是**权限位 |

后面几列依次是：硬链接数、所有者、所属组、大小（字节）、最后修改时间、名字。

**9 位权限 = 三组 `rwx`**：

| 位 | 对文件 | 对目录 |
| --- | --- | --- |
| `r` | 读内容 | 列出里面有哪些名字（`ls`） |
| `w` | 改内容 | 在里面新建 / 删除 / 改名 |
| `x` | 可执行 | 能进去（`cd`）、按名字访问里面的文件 |
| `-` | 没有这个权限 | 没有这个权限 |

**数字怎么来**：`r=4`、`w=2`、`x=1`，每组三个数相加。

| 数字 | 字母 | 给谁 | 典型用途 |
| --- | --- | --- | --- |
| 7 | `rwx` | 所有者 | 自己的脚本 / 目录 |
| 5 | `r-x` | 组 / 其他人 | 能读能进，不能改 |
| 4 | `r--` | 组 / 其他人 | 只读 |
| 6 | `rw-` | 所有者 | 普通文件 |

- `755` = `rwxr-xr-x`：所有者全权，组和其他人能读能进；**目录**和要执行的脚本用它。
- `644` = `rw-r--r--`：所有者读写，组和其他人只读；**普通文本 / 代码文件**用它，不给执行位。
- `777` = `rwxrwxrwx`：谁都能改，等于把门敞开，不要用。

`python3 str_demo.py` 只需要 `r`，644 就够；只有 `./str_demo.py` 这种直接执行才需要 `x`（755），而且第一行要有 `#!/usr/bin/env python3`。省事就用 `uv run str_demo.py`。

```bash
touch note.txt
ls -l note.txt          # -rw-r--r-- ... note.txt   ← 644
chmod 755 note.txt
ls -l note.txt          # -rwxr-xr-x ... note.txt   ← 755
chmod 644 note.txt

mkdir -p demo
ls -ld demo             # drwxr-xr-x ... demo        ← 看目录本身要 -d
chmod 750 demo          # drwxr-x--- ... demo
chmod u+x note.txt      # 只给所有者加执行位
```

两个边界：

1. **新建文件的默认权限不是写死的**：文件从 `666` 减去 `umask`，目录从 `777` 减去 `umask`；`umask` 是 `022` 时就得到 `644` / `755`。`umask` 命令能看当前值。
2. **macOS 的 `@` 和 `+` 不是权限位**：`-rw-r--r--@` 里的 `@` 表示有扩展属性（比如浏览器下载的隔离标记），`+` 表示有 ACL；它们接在 9 位之后，别数进去。

`chmod -R 755 dir` 会把目录里所有文件也变成可执行；目录和文件要分开设时，用 `find dir -type d -exec chmod 755 {} +` 与 `find dir -type f -exec chmod 644 {} +`。

### 2.4 今日交付：`str_demo.py` 词频前 3

「词频」数的是**单词**，不是字符。先把文本按空白切成词，统一小写，去掉挂在词上的标点，再计数：

```python
from collections import Counter

text = """The quick brown fox jumps over the lazy dog.
The dog barks, and the fox runs."""

words = []
for token in text.split():
    word = token.strip(".,!?;:\"'()[]").lower()
    if word:
        words.append(word)

for word, count in Counter(words).most_common(3):
    print(f"{word}: {count}")
```

输出：

```text
the: 4
fox: 2
dog: 2
```

`most_common(3)` 返回 `[(单词, 次数), ...]`，最多 3 项；不同单词不足 3 个时就少于 3 项。次数并列时按首次出现顺序排，别把并列顺序当业务规则。

**最容易错的一步**：`Counter(text)` 数的是字符（连空格都算），`Counter(text.split())` 才是词。对比：

```python
Counter("the cat")          # {'t': 2, 'h': 1, 'e': 1, ' ': 1, 'c': 1, 'a': 1}
Counter("the cat".split())  # {'the': 1, 'cat': 1}
```

三个边界：

1. **大小写**：`The` 和 `the` 是同一个词，先 `.lower()`。
2. **标点**：`dog.` 和 `dog` 要先用 `strip(".,!?;:")` 剥掉；更复杂的文本用正则 `re.findall(r"[A-Za-z']+", text.lower())`，但正则在 W2 才系统学，今天先用 `strip`。

## 7. 自测

<details>
<summary>Q1：`s = "abc"; s.upper(); print(s)` 输出什么？</summary>

还是 `abc`。字符串不可变，`upper()` 返回新串，没有重新绑定就没有变化。

<details>
<summary>Q2：`"a  b".split()` 与 `"a  b".split(" ")` 结果差在哪？</summary>

`split()` 按任意空白切并丢掉空串 → `['a', 'b']`；`split(" ")` 按单个空格切 → `['a', '', 'b']`。
</details>

<details>
<summary>Q3：为什么 `-7 // 2` 是 -4？</summary>

`//` 是向下取整（floor），不是向零截断；`-7/2 = -3.5`，向下取整得 -4。用 `int(-7/2)` 才是 -3。
</details>

<details>
<summary>Q4：`if []` 会进哪个分支？为什么？</summary>

进 else。空列表的真值为 False；`bool([])` 是 False。
</details>

<details>
<summary>Q5：242 里为什么可以只用一个 diff 数组？</summary>

两个字符串长度相同时，s 的字符各 +1、t 的字符各 -1，只要最终全为 0，说明每个字符出现次数相等，就是异位词。
</details>

<details>
<summary>Q6：`-rw-r--r--` 是几？谁能写？</summary>

644。所有者 `rw-` 可读写，组和其他人 `r--` 只读；普通文本文件的标准权限。
</details>

<details>
<summary>Q7：为什么 `Counter(text)` 不能直接当词频？</summary>

它按字符计数，空格和标点也算；词频要先 `text.split()` 切成词，再 `Counter(words)`。

### 8.1 碎片 20 分钟：权限的「匹配顺序」与「三个动作」

2.3 讲的是 9 位怎么读、755/644 怎么算；碎片时间要练的是**看到一条 `ls -l`，10 秒内判断「谁能干什么」**。先补几个 2.3 没展开的机制。

**权限判定顺序：只取第一个匹配，不叠加**

Linux 判断一个进程能不能读文件，按 `所有者 → 所属组 → 其他人` 顺序找，**命中第一组就停**，不会把三组权限加起来。例：

```text
-rw-r----- 1 alice dev 100 Nov 3 10:00 config.txt
```

- alice（所有者）→ `rw-`，能读写，**不再看组**。
- bob 在 dev 组 → `r--`，只读。
- carol 不在 dev 组 → `---`，什么都做不了。

所以「给组加了 r，但所有者是 rw-」时，所有者不会因为组有 r 就多出什么；反过来，所有者为 `---` 而组为 `rwx`，所有者本人也进不去（但所有者仍可 chmod 改回来）。这是「为什么我 chmod 了还是不行」的头号原因。

**目录的 x 是「穿过」，不是「执行」**：

| 目录权限 | 能做什么 | 不能做什么 |
| --- | --- | --- |
| `r--` | `ls` 看到名字 | 不能 `cd`、不能读文件内容（没有 x 穿不过去） |
| `r-x` | 列目录 + 进入 + 按名访问 | 不能新建 / 删除 / 改名（没有 w） |
| `-wx` | 能进、能建 / 删，但 `ls` 看不到名字 | 不能列目录 |
| `rwx` | 全权 | — |

**三个动作，别混**：

| 动作 | 改什么 | 例子 | 什么时候用 |
| --- | --- | --- | --- |
| `chmod` | 权限位（rwx） | `chmod 644 f` | 文件能不能读 / 写 / 执行 |
| `chown` | 所有者 / 组 | `sudo chown alice:dev f` | 文件归错人 |
| `umask` | 新建文件的默认权限 | `umask 022` | 改「默认给多少」，不是改已有文件 |

`chmod` 改不了「文件属于谁」；`chown` 改的是归属，不直接改 rwx 位——但归属变了，同一组 rwx 对谁生效也会变。报 `Operation not permitted` 时先看 owner，不是先 `chmod 777`。

**umask 怎么算**：文件从 `666` 减、目录从 `777` 减，按位「去掉」而不是算术减：

```text
umask 022 → 文件 666 & ~022 = 644；目录 777 & ~022 = 755
umask 027 → 文件 666 & ~027 = 640；目录 777 & ~027 = 750
```

`umask` 只影响**新建**文件；已经建好的文件要 `chmod`。`umask` 是 shell 级设置，换终端 / 换用户会变。

**符号模式比数字更适合「只改一位」**：

```bash
chmod u+x run.sh      # 只给所有者加执行
chmod g-w,o=r f       # 组去掉写，其他人设为只读
chmod a+r f           # 所有人可读（a = u+g+o）
chmod -R u+rwX dir    # 递归：文件不加 x，目录加 x（X 是大写）
```

`chmod -R 755 dir` 会把目录里所有普通文件也变成可执行，通常不是你想要的；要分开设：

```bash
find dir -type d -exec chmod 755 {} +
find dir -type f -exec chmod 644 {} +
```

**/tmp 的 1777 是什么**：第一位 `1` 是 sticky bit，表示「目录里谁都能建文件，但只有文件主人 / root 能删」。`/tmp` 就是 `drwxrwxrwt`，最后的 `t` 是 sticky + x。看到 `t` 不要当成权限位读错。

**默写检查**（遮右列）：

| 写法 | 读法 |
| --- | --- |
| `-rw-r--r--` | 644，所有者读写，组 / 其他人只读 |
| `drwxr-xr-x` | 755，目录，所有者全权，其他人能进能列 |
| `drwxrwxrwt` | 1777，/tmp，所有人可建，只有主人能删 |
| `chmod u+x f` | 只给所有者加执行位 |
| `umask 027` | 新建文件 640、目录 750 |

**20 分钟怎么切**：

### 8.4 卡住怎么办：语法错误先分类，再动手

通用时间闸门（20/30/40 分钟）和五样求助见 [[D1-环境与第一个仓库]] §8.4；今天卡住的多半是「语法 / 类型」，按下面顺序排。

**第一步：给错误分类**（30 秒）：

| 异常 | 典型长相 | 先查什么 |
| --- | --- | --- |
| `TypeError` | `"a" + 1`、`None.strip()` | 两边类型、变量是不是 None |
| `ValueError` | `int("3.5")` | 值的格式，不是类型 |

| `IndexError` | `s[10]` | 长度和下标 |

**第二步：最小复现**（2 分钟）：

**第四步：二分打印**（5 分钟）：
