# 12 · 纲要 · 实习（G2）

> 这一份回答：**要具备什么能力、学哪些内容、什么时候投、什么时候入职**。
> 素材：`学习/EWP/P0`–`P6`（36 周路线）｜项目 A/B/C 在这五段里各有里程碑｜八股在 P4。

---

## 一 · 要具备到什么程度

| 能力 | 判据（可演示） | 在哪个 P 段完成 |
| --- | --- | --- |
| Python 工程 | 200 行以上项目、有 README、别人 clone 能跑 | P0–P1 |
| 后端服务 | FastAPI + 数据库 + 部署上线、有接口文档 | P2 |
| AI 应用 | 一个 RAG/Agent 项目，**带评估数据**（不只是 demo） | P2–P3 |
| 算法笔试 | 力扣 140 题打底，Easy 30 秒、Medium 25 分钟 | P0–P4 |
| 面试八股 | 六块各一页：Python / 数据库 / 网络 / OS / 后端设计 / AI 应用 | P4 |
| 简历 | 一页、三个项目、能讲清每个技术选择的理由 | P1 末（v0）、P4 末（定稿） |

**什么叫「对得起评价」**：实习期结束时有 3 条「能写进简历的产出」，不是「参与了某项目」。

## 二 · 学哪些内容

### 工程与工具（P0–P1）
uv/venv、Git 分支与回滚、Linux 终端、VS Code 调试、pytest 与日志、类型注解、模块与包、容器化基础。

### 后端（P2）
HTTP/REST、FastAPI（路由/依赖注入/中间件）、SQL 与 ORM、索引与事务、Redis 缓存、鉴权、部署（Nginx/云主机）、压测与日志。

### AI 应用（P2–P3）
embedding 与向量检索、chunk 与召回、prompt 工程、工具调用、评估（金标集 + 指标）、成本与延迟、失败模式。

### 项目三件套（P1–P3）
- **项目 A**：AI 命令行助手（CLI、参数解析、异常、测试）
- **项目 B**：文档问答 Web 应用（上传→切分→检索→生成→部署）
- **项目 C**：旗舰项目（选「后端研发助手」或「行业 RAG」，要有评估报告）

### 面试（P4）
项目追问 20 问、八股六块、手撕算法二刷、模拟面试每周 1 次。
