# 11 · 纲要 · 蓝桥杯（G1）

> 这一份回答三个问题：**要学到什么程度、学哪些内容、什么时候学完**。往下的章节与题单在 `P`，知识点在 `W`，正文在 `While Back`。

## 一 · 要学到什么程度（四级熟练度）

| 级 | 判定动作 | 谁必须到这一级 |
| --- | --- | --- |
| ① 看懂 | 合上题解，能把「关键观察」讲 1 分钟 | A 层深水点（只求会写暴力档） |
| ② 默写 | 不看模板，敲出可交代码（含边界） | 全部变形题 |
| ③ 限时 | 同分值时限内 AC（10 分 25 分钟 / 15 分 40 / 20 分 50） | **全部 ★ 模板题** |
| ④ 变式 | 改一个条件仍能说清怎么改 | B 层核心（选做 20%） |

**总门槛**：C 层全部到 ②、B 层 ★ 到 ③、A 层 4 点做到 ① + 会写暴力档。

## 二 · 学哪些内容（按大纲三层）

### 第 0 层 · 竞赛工程（不是知识点，是习惯）

单文件提交模板、快读与解绑、`long long` 与溢出、数组/递归深度、复杂度估时（1s ≈ 1e8）、对拍脚本、部分分分档。

### C 层 · 地基 11 点（A 组也考）

枚举、模拟、排序（`cmp` 严格弱序）、二分（四种边界）、前缀和与差分、贪心、搜索（DFS/BFS）、一维 DP、高精度、栈/队列/单调结构、初等数论。

### B 层 · 国奖真正的地基 36 点（分 7 组）

| 组 | 点 | 大纲难度 |
| --- | --- | --- |
| 搜索 | 剪枝、双向 BFS、记忆化、迭代加深、IDA* | 4–7 |
| DP | 背包、树形、区间、状压、数位、DP 优化 | 4–7 |
| 字符串 | 哈希、KMP、Manacher | 4–6 |
| 图论 | 存图、最短路、差分约束、MST、拓扑、连通性（割点/桥/SCC）、DFS 序、LCA、二分图匹配 | 5–7 |
| 数学 | 排列组合、二项式、容斥、逆元、矩阵、高斯消元 | 5–7 |
| 结构 | 堆、树状数组、线段树、ST 表、Trie、并查集、平衡树（库） | 5–7 |
| 其他 | 计算几何基础、概率期望、博弈论（SG） | 6–7+ |

### A 层 · 压轴深水 16 点（**只挑 4–5 个**）

必选：AC 自动机、树链剖分、可持久化线段树、网络流、线性基。
明确放弃：后缀数组/SAM/PAM/FFT/树套树/LCT/生成函数/莫比乌斯/一般图匹配（只要求读懂题解 + 会写暴力档）。
