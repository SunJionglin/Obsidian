# 01 内核、发行版与命令行

## 1. 本篇知识点清单

- **内核 vs 发行版**：知道为什么「装的是 Ubuntu 不是 Linux」
- **发行版差异四维**：包管理器、预装软件、更新方式、用途
- **命令行与 shell**：明白敲的命令由谁解析、由谁执行
- **提示符解剖**：读懂 `用户@主机:目录$` 每一段
- **命令结构**：命令名 + 参数，大小写敏感、空格分隔
- **参数五种形式**：短/长、带值/不带值、位置参数，以及三种等价变体
- **中断与耗时命令**：`sleep` 占前台、`Ctrl+C` 发中断、`^C` 是什么意思
- **高效键入**：历史、TAB 补全、光标跳转、复制粘贴、清屏
- **查文档**：`--help` 与 `man` 的正确用法

## 2. 正文·知识块

### 2.1 内核 vs 发行版

**是什么**：Linux 严格说只是**内核**（kernel），由 Linus Torvalds 发起、全球开发者维护，负责管进程、内存、文件、设备。内核本身不能直接当系统用，要配上包管理器、shell、系统工具、默认配置，打包出来才叫**发行版**（distribution）。

**类比**：内核像 AOSP 底层，发行版像 MIUI、OriginOS、ColorOS——底层同一套，外面各不相同。

**内核版本**：有主线版、稳定版、长期支持版（LTS）之分，差异在硬件支持、驱动、调度、安全机制。入门阶段用发行版自带的内核即可，不必研究分支。

**发行版差异四个维度**：

| 维度 | 说明 | 例子 |
| --- | --- | --- |
| 包管理器 | 装软件的渠道 | Ubuntu/Debian → `apt`；Fedora/RHEL → `dnf`；Arch → `pacman`；OpenWrt → `opkg` |
| 预装软件 | 默认带哪些工具与服务 | 服务器版不带桌面；Alpine 连常用工具都精简 |
| 更新方式 | 固定版本 / LTS / 滚动更新 | Ubuntu 有 LTS；Arch 滚动更新 |
| 目标用途 | 通用服务器 / 容器 / 路由器 / 企业 | Alpine 面向容器，OpenWrt 面向路由器 |

**为什么本课用 Ubuntu 24.04 LTS**：用户最多、资料最全、排错方便。知识点和常用软件在各发行版之间通用，换发行版的学习成本不高。

```bash
cat /etc/os-release     # 看发行版信息
uname -r                # 看内核版本
```

**坑**：把「内核版本」当成「系统版本」。`uname -r` 是内核，`/etc/os-release` 才是发行版。

### 2.2 Shell：命令由谁执行

**是什么**：shell 是一个**程序**，负责读你输入的一行、解析成「命令名 + 参数」、执行（自己执行或调用别的程序），再把结果与新的提示符交回来。Ubuntu 默认是 **bash**（Bourne Again SHell）。

**两条使用路径**：图形界面（GUI，点按钮）与命令行界面（CLI，打命令）。Linux 最原汁原味的用法是 CLI，服务器上通常没有图形界面可选。

```bash
echo $SHELL     # 当前登录 shell：/bin/bash（Ubuntu）、/bin/zsh（macOS）
```

**坑**：`$SHELL` 显示的是登录时的 shell；如果你手动敲 `bash` 进了子 shell，它不会变。

### 2.3 提示符：读懂那行字

Ubuntu 默认提示符的结构：

```
ChrisKim@HOSHINO:/usr/local/etc$
└──┬───┘ └──┬─┘ └─────┬─────┘└┬┘
 用户名   主机名   当前工作目录 结束符
```

- **用户名**：装系统时自己填的；
- **主机名**：多台机器/服务器时靠它分辨「我现在在哪台机器上」；
- **当前工作目录**：你现在站在目录树的哪个位置（1.3 节讲路径）；
- **`$`**：普通用户；如果是 `#`，说明是 root。

**核心作用**：提示符出现 = shell 空了、能接受下一条命令；它迟迟不出现 = 上一条命令还占着前台。

**格式可改**（`PS1`），不同发行版默认样式不同，第 08 篇 `.bashrc` 里再讲。

### 2.4 命令的基本结构

```
命令名称 [命令参数]...
```

- 命令名**大小写敏感**：`ls` 和 `LS` 是两个东西；
- 命令名与每个参数之间用**空格**隔开，空格数量不限；
- 参数控制行为或提供数据，可以有多组。

### 2.5 参数的五种形式与三种变体

先看一张「每个参数都有真命令」的表，最后一列写清楚这句命令到底干了什么：

| 类型 | 作用 | 语法 | 真实例子 | 这句在干什么 |
| --- | --- | --- | --- | --- |
| 不带值短参数 | 开关，只切换行为 | `-x` | `ls -a` | 连隐藏文件一起列出来 |
| 带值短参数 | 开关后面紧跟一个值 | `-x 值` | `head -n 5 a.txt` | 只看文件的前 5 行 |
| 不带值长参数 | 和短参数等价，写全名 | `--xxx` | `ls --all` | 同 `ls -a`，给人读的版本 |
| 带值长参数 | 用 `=` 给值 | `--xxx=值` | `ls --block-size=KB` | 文件大小按 KB 显示，不按字节 |
| 位置参数 | 没有名字，位置决定含义 | `对象` | `ls /etc` | 列 /etc 这个目录，而不是当前目录 |

三种常见变体，同样每行给真命令：

| 变体 | 写法 | 真实例子 | 效果 |
| --- | --- | --- | --- |
| 短参数合并 | `-abc` | `ls -al` | 等于 `-a`（隐藏文件）+ `-l`（详细列表），两个开关一次写完 |
| 短参数与值不隔开 | `-x值` | `make -j8` | 用 8 个线程编译，等价于 `make -j 8` |
| 长参数用空格给值 | `--xxx 值` | `ls --block-size KB` | 等价于 `--block-size=KB` |

完整拆一条命令：

```bash
ls -a -l --block-size=KB /home/chriskim
```

| 片段 | 属于哪类 | 含义 |
| --- | --- | --- |
| `ls` | 命令名 | 列目录（list） |
| `-a` | 不带值短参数 | 显示以 `.` 开头的隐藏文件 |
| `-l` | 不带值短参数 | 用详细列表输出（权限、属主、大小、时间） |
| `--block-size=KB` | 带值长参数 | 大小以 KB 为单位，而不是字节 |
| `/home/chriskim` | 位置参数 | 要列的是这个目录；不写就列当前目录 |

它的等价写法：

```bash
ls -al --block-size KB /home/chriskim
```

**怎么判断某个参数要不要给值**：看 `--help` 里的写法，写成 `-n <num>` 或 `--size=<size>` 的就是「要值」；只写 `-a` 的是开关。

**坑**：`-al` 不是某个叫「al」的参数，而是 `-a` 和 `-l` 两个开关合并；长参数不能这样合，`--all` 只能单独写。

### 2.6 耗时命令与中断

```bash
sleep 3      # 干等 3 秒，什么也不做
sleep 60     # 等 60 秒；这期间提示符不会出现
```

默认一条命令在**前台**运行，shell 要等它结束才接受下一条输入——这就是「好像卡住了」的真相。

提前结束：按 `Ctrl+C` 发中断信号，程序通常就此终止，屏幕回显 `^C`（`^` 代表 Ctrl 键）。

**补充**：被 `Ctrl+C` 打断的进程退出码是 130，正常结束是 0；退出码在后面的 shell 脚本里会用上。

### 2.7 高效键入五个技巧

| 技巧 | 按键 | 说明 |
| --- | --- | --- |
| 历史记录 | `↑` / `↓` | 反复按 `↑` 找更早的命令 |
| 补全 | `Tab` | 补命令名、路径；有的系统连参数也能补 |
| 列候选 | `Tab` 连按两次 | 有歧义时列出所有候选 |
| 光标跳转 | `Home` / `End` | 跳行首 / 行尾 |
| 按词跳转 | `Ctrl+←` / `Ctrl+→` | 一次跳一个单词（看终端支持） |
| 复制 / 粘贴 | `Ctrl+Insert` / `Shift+Insert` | 各终端不同，macOS 是 `Cmd+C / Cmd+V` |
| 清屏 | `Ctrl+L` 或 `clear` | 只清屏，历史仍在 |

```bash
/usr/lo<Tab>        # 补成 /usr/local/
echo hel<Tab>       # 有多个候选时再按一次 Tab 列出来
```

### 2.8 查文档：--help 与 man

```bash
ls --help      # 简版用法，先看它
man ls         # 完整手册：q 退出、/ 搜索、n 跳下一个匹配
```

前提是命令自己提供了文档；不是所有命令都有，也不是所有系统都装了 `man`（精简容器里常常没有）。

**补充**：`man` 分章节，`man 1 ls` 是用户命令、`man 5 passwd` 是配置文件格式、`man 7 signal` 是概念说明——查不到时换个章节号试试。

## 3. 命令速查表

| 命令 / 按键 | 作用 | 常用参数 | 坑 |
| --- | --- | --- | --- |
| `cat /etc/os-release` | 看发行版信息 | — | 不是内核版本 |
| `uname -r` | 看内核版本 | `-a` 全部信息 | 别和发行版版本混淆 |
| `echo 内容` | 原样输出 | — | 多个空格要用引号保真 |
| `sleep 秒` | 等待 | — | 前台阻塞，提示符不回来 |
| `Ctrl+C` | 中断前台命令 | — | 回显 `^C`，不是复制 |
| `命令 --help` | 简版帮助 | — | 命令得支持才有 |
| `man 命令` | 完整手册 | `q` 退出、`/` 搜、`n` 下一个 | 精简系统可能没装 man |
| `↑` / `↓` | 历史命令 | — | 每个终端各自记录 |
| `Tab` | 补全 | 连按两次列候选 | 有歧义时只补一段 |
| `Home` / `End` | 行首 / 行尾 | — | 笔记本可能要按 `Fn` |
| `Ctrl+←` / `Ctrl+→` | 按词跳 | — | 取决于终端 |
| `Ctrl+Insert` / `Shift+Insert` | 复制 / 粘贴 | — | macOS 用 `Cmd` |
| `Ctrl+L` / `clear` | 清屏 | — | 历史不清 |

## 4. 动手练

**① 把提示符拆开对上号**
```bash
echo $USER      # 对应提示符第一段
hostname        # 对应第二段
pwd             # 对应第三段（1.3 节细讲）
```

**② 体会「前台阻塞」**
```bash
sleep 3        # 三秒内敲什么都不执行
sleep 60       # 然后按 Ctrl+C，看屏幕上出现的 ^C
```
预期：`sleep 60` 被 `Ctrl+C` 立刻打断，提示符马上回来。

**③ 参数合并与拆分**
```bash
ls -a -l       # 分开写
ls -al         # 合并写，输出一样
```

**④ 用补全少打字**
```bash
/usr/lo<Tab>        # 期望补成 /usr/local/
cat /etc/os<Tab>    # 期望补成 /etc/os-release
```

**⑤ 查一条命令的手册**
```bash
man ls
# 在手册里按 / 输入 recursive 回车搜索，n 跳下一个，q 退出
```

## 5. 常见报错

**① 把提示符一起敲进去**
```
$ $ ls
$: command not found
```
`$` 是 shell 打印的，不是命令的一部分。

**② 大小写写错**
`LS`、`Ls` 都会 `command not found`——Linux 命令和路径通常区分大小写。

**③ 想复制却中断了命令**
终端里 `Ctrl+C` 是「中断」不是「复制」。复制用 `Ctrl+Insert` 或终端菜单，粘贴用 `Shift+Insert`。

**④ `man: command not found` 或手册空白**
精简系统没装 man（`apt install man-db`），或者这条命令本身没提供手册——先试 `--help`。

## 6. 平台差异

| 项 | Linux（Ubuntu） | macOS |
| --- | --- | --- |
| 默认 shell | bash | zsh（Catalina 起） |
| 提示符样式 | `用户@主机:目录$` | `主机 目录 %` |
| 复制 / 粘贴 | `Ctrl+Insert` / `Shift+Insert` | `Cmd+C` / `Cmd+V` |
| `uname -r` | Linux 内核版本 | Darwin 版本 |
| `man` 章节 | 齐全（1/5/7…） | 有，但没有 `info` |

## 7. 自测

<details>
<summary>Q1：为什么说「我装的是 Ubuntu，不是 Linux」？</summary>

Linux 只是内核；Ubuntu 是把它和包管理器（apt）、用户空间工具、默认配置打包成的发行版。严格讲你装的是发行版。
</details>

<details>
<summary>Q2：`ls -al` 和 `ls -a -l` 为什么等价？</summary>

短参数可以合并写：`-al` = `-a` + `-l`。长参数不能这样合，`--all` 只能单独写。
</details>

<details>
<summary>Q3：敲完 `sleep 60` 后为什么提示符不出现？</summary>

命令在前台运行，shell 要等它结束才接受下一条输入。提示符不出现本身就是「还在跑」的信号；想提前结束用 `Ctrl+C`。
</details>

<details>
<summary>Q4：`^C` 是什么？</summary>

是终端对你按 `Ctrl+C` 的回显，`^` 代表 Ctrl 键。它表示发送了中断信号，通常会让前台程序终止。
</details>

<details>
<summary>Q5：`--help` 和 `man` 有什么区别，什么时候用哪个？</summary>

`--help` 是命令自带的简短用法（快、常在）；`man` 是系统手册（完整、能搜索）。先用 `--help` 找方向，需要细节再 `man`。
</details>
