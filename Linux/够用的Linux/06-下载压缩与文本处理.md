# 06 下载、压缩与文本处理

## 1. 本篇知识点清单

- **下载**：`wget`、`curl`、`aria2c` 各自的主场
- **打包压缩**：`tar` 的四个参数组合、`zip/unzip`、`7z`
- **数一数**：`wc -l/-w/-c`
- **筛内容**：`grep` 的 `-i -r -n -v -E`
- **改文本**：`sed` 的替换与原地修改（含 macOS 坑）

## 2. 正文·知识块

### 2.1 三种下载工具

```bash
wget https://example.com/file.zip              # 直接下到当前目录
wget -O app.zip https://example.com/file.zip   # 存成指定名字
wget -c https://example.com/big.iso            # 断点续传
```

```bash
curl -LO https://example.com/file.zip          # -L 跟随跳转，-O 用远程名
curl -o app.zip https://example.com/dl/1       # 重命名
curl -I https://example.com                    # 只看响应头（调试接口）
curl -X POST -d '{"q":1}' -H 'Content-Type: application/json' https://api/x
```

```bash
aria2c -x16 -s16 https://example.com/big.iso   # 16 线程下载，大文件快
```

| 工具 | 适合 | 特点 |
| --- | --- | --- |
| `wget` | 下载文件、整站抓取 | 简单，支持断点续传 |
| `curl` | 调接口、看响应头、上传 | 灵活，能发任意请求 |
| `aria2c` | 大文件、多线程 | 快，需要单独装 |

**坑**：`curl URL` 不写 `-O` 会把内容打到屏幕上（二进制就是一片乱码）。

### 2.2 tar：打包与解包

```bash
tar -czvf site.tar.gz ./site      # 打包并压缩（c 创建 z gzip v 过程 f 文件名）
tar -xzvf site.tar.gz             # 解包（x 解压）
tar -tzvf site.tar.gz             # 只看里面有什么，不解（t 列表）
tar -czvf logs.tar.gz --exclude='*.log' ./data   # 排除某些文件
```

记忆法：**c 打包、x 解开、t 看内容；z 用 gzip、j 用 bzip2、J 用 xz；v 显示过程；f 后面紧跟文件名**。

**坑**：`f` 必须放在最后、紧跟文件名；写成 `tar -cfz` 会报错。

### 2.3 zip / unzip / 7z

```bash
zip -r site.zip ./site        # 压目录要 -r
unzip site.zip                # 解到当前目录
unzip site.zip -d ./out       # 解到指定目录
7z a site.7z ./site           # 7z 压缩（需装 p7zip）
7z x site.7z                  # 7z 解压
```

**跨平台习惯**：给 Windows/macOS 传文件用 `zip`（对方免装软件）；Linux 之间用 `tar.gz`。

### 2.4 wc：数行数字节

```bash
wc -l app.log       # 行数
wc -w note.txt      # 词数
wc -c note.txt      # 字节数
ls | wc -l          # 当前目录有多少项（管道经典用法）
```

### 2.5 grep：筛内容

```bash
grep "404" access.log              # 含 404 的行
grep -i "error" app.log            # 忽略大小写
grep -n "timeout" app.log          # 带行号
grep -v "200" access.log           # 反选：不含 200 的行
grep -r "TODO" ./src               # 递归搜目录
grep -E "50[0-9]" access.log       # 扩展正则：500~509
ps aux | grep python               # 找进程
```

**坑**：`grep` 遇到二进制文件会提示 `Binary file matches`，加 `-a` 或改搜文本。

### 2.6 sed：改文本

```bash
sed 's/old/new/' file.txt               # 每行第一个 old 换成 new（不写文件）
sed 's/old/new/g' file.txt              # 每行全部替换
sed -n '10,20p' file.txt                # 只看 10~20 行
sed -i 's/8080/8000/' conf.ini          # 原地修改（Linux）
sed -i '' 's/8080/8000/' conf.ini       # 原地修改（macOS 必须多给空串）
```

**坑**：`sed -i` 在 macOS 和 Linux 上写法不同；`sed` 默认不改文件，要 `-i` 才落地，改错前先 `cp` 备份。

## 3. 命令速查表

| 命令 | 作用 | 真实例子 → 干什么 |
| --- | --- | --- |
| `wget -c` | 断点续传下载 | `wget -c big.iso` → 传了一半还能接着下 |
| `curl -LO` | 下载并保留原名 | `curl -LO .../a.zip` |
| `curl -I` | 看响应头 | `curl -I https://x.com` → 状态码与服务器信息 |
| `tar -czvf` | 打包压缩 | `tar -czvf s.tar.gz ./site` |
| `tar -xzvf` | 解包 | `tar -xzvf s.tar.gz` |
| `wc -l` | 数行 | `wc -l app.log` |
| `grep -rn` | 递归搜带行号 | `grep -rn TODO ./src` |
| `sed -i` | 原地替换 | `sed -i 's/a/b/g' f` |

## 4. 动手练

**① 造文件并压缩解压**
```bash
mkdir -p ~/lab/site && echo hello > ~/lab/site/index.html
cd ~/lab && tar -czvf site.tar.gz ./site
mkdir out && tar -xzvf site.tar.gz -C out
ls out/site
```

**② 用 grep 从日志里找东西**
```bash
seq 1 1000 > ~/lab/log.txt
grep -n "50" ~/lab/log.txt | head -5      # 行号 + 内容
grep -c "50" ~/lab/log.txt                # 出现次数
```

**③ 管道组合：统计有多少行含某个词**
```bash
grep "50" ~/lab/log.txt | wc -l
```

**④ sed 替换并验证**
```bash
cp ~/lab/log.txt ~/lab/log.bak
sed -i 's/^1/ONE-/' ~/lab/log.txt      # Linux 语法
head -3 ~/lab/log.txt
```

**⑤ zip 与 unzip**
```bash
cd ~/lab && zip -r site.zip site && unzip -l site.zip
```

## 5. 常见报错

**① `tar: Refusing to read archive contents from terminal`**
忘了给文件名，`f` 后面空着。

**② `sed: -e expression #1, char 1: unknown command`**
表达式里的引号被 shell 吃掉。用单引号包住 `'s/a/b/'`。

**③ macOS 上 `sed -i` 报 `invalid command code`**
macOS 要求 `sed -i '' 's/a/b/'`（多一个空串参数）。

**④ `zip` 出来解压后多一层目录**
要用 `zip -r site.zip ./site`，解压自然带目录；只要内容就进目录里再压。

## 6. 平台差异

| 项 | Linux | macOS |
| --- | --- | --- |
| `sed -i` | `sed -i 's/a/b/' f` | `sed -i '' 's/a/b/' f` |
| `grep -P` | 支持 | 不支持，用 `-E` |
| `tar` | GNU tar | bsdtar（参数基本兼容） |
| `wget` | 一般自带 | 默认没有，用 `curl` 或 `brew install wget` |
| `7z` | `apt install p7zip-full` | `brew install p7zip` |

## 7. 自测

<details>
<summary>Q1：`tar -czvf` 里四个字母各是什么意思？</summary>

c 创建归档、z 用 gzip 压缩、v 显示处理过程、f 指定文件名（后面必须紧跟文件名）。
</details>

<details>
<summary>Q2：`wget` 和 `curl` 该选哪个？</summary>

单纯下文件用 `wget`（能续传、整站抓取）；调接口、看响应头、发 POST 用 `curl`。两者功能有重叠，看习惯。
</details>

<details>
<summary>Q3：`grep -v` 是干什么的？</summary>

反选：输出**不包含**匹配模式的行。排查日志时经常用它排除掉正常请求。
</details>

<details>
<summary>Q4：`sed` 不加 `-i` 会改文件吗？</summary>

不会。不加 `-i` 只把结果打印到标准输出，原文件不动；要落盘必须 `-i`。
</details>

<details>
<summary>Q5：为什么 macOS 上 `sed -i` 要写两个单引号？</summary>

BSD sed 的 `-i` 必须带一个备份后缀参数，给空串表示不备份；Linux 的 GNU sed 不需要。
</details>
