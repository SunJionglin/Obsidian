## 学完的标准

作者给的目标是「能独立使用 Linux」。翻译成可验收的：

- [ ] 能在纯命令行里完成：建目录、建文件、复制、移动、删除、查看、编辑
- [ ] 能用管道和重定向把两个命令拼起来（`grep` + `sort` + `>`）
- [ ] 能解释 `chmod 755` 里每个数字是什么
- [ ] 能用 `apt` 装、卸、更新软件
- [ ] 能用 `ssh` 登录一台服务器、用 `scp` 传文件
- [ ] 能读懂 `top` 里 CPU 和内存那一行
- [ ] 能把环境变量写进 `~/.bashrc` 并让它生效
- [ ] 后台任务卡住时，知道用 `jobs` / `fg` / `kill` 处理
