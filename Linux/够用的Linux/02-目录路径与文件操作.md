# 02 目录、路径与文件操作

## 1. 本篇知识点清单

- **Linux 目录树**：单根 `/`、大小写敏感、家目录在 `/home/用户名`
- **绝对路径与相对路径**：`.`、`..`、`~` 三种简写
- **走目录**：`cd`、`cd -` 的用法
- **看目录**：`ls` 的四个常用参数、`ll` 别名、长列表每一列是什么
- **读文件**：`cat` 的正确用法与禁区
- **建东西**：`mkdir -p`、`touch`
- **找东西**：`find` 的四个查找条件
- **跑东西**：`./程序` 与带参数执行

## 2. 正文·知识块

### 2.1 Linux 目录树长什么样

和 Windows 的三点不同：

| 项 | Linux | Windows |
| --- | --- | --- |
| 分隔符 | 正斜杠 `/` | 反斜杠 `\` |
| 根 | 全系统只有一个 `/` | 每个盘符一个根 `C:\ D:\` |
| 大小写 | 区分，`File.txt` 与 `file.txt` 是两个文件 | 通常不区分 |

用户自己的目录在 `/home/用户名`（root 在 `/root`），**在家目录里折腾一般不会弄坏系统**——新手先在家目录练。

```bash
echo $HOME        # /home/chriskim
cd ~              # 回到家目录，~ 就是 $HOME 的简写
```

### 2.2 绝对路径与相对路径

- **绝对路径**：从 `/` 写起，任何时候指的都是同一个位置，必须以 `/` 开头。
- **相对路径**：相对「当前工作目录」，不以 `/` 开头；`.` 是当前目录，`..` 是上一层。

假设当前在 `/home/chriskim`：

| 写法 | 实际指向 | 为什么 |
| --- | --- | --- |
| `/home/chriskim/movies` | 同一个 | 绝对路径，与当前位置无关 |
| `movies/` | `/home/chriskim/movies` | 相对当前目录 |
| `../` | `/home/` | 上一层 |
| `../../data/llm/config.json` | `/data/llm/config.json` | 上两层再下去 |
| `./././run.sh` | `/home/chriskim/run.sh` | 多个 `.` 都指当前目录 |
| `~/main.cpp` | `/home/chriskim/main.cpp` | `~` = 家目录 |

**坑**：`..` 在根目录 `/` 时还是 `/`，不会报错也不会卡死，但会让你误以为「退出去了一层」。

### 2.3 切换与查看目录

```bash
cd /usr/local            # 绝对路径
cd movies                # 相对路径
cd                       # 不写参数 = 回家目录
cd -                     # 回到上一次待过的目录（只记一个）
pwd                      # 打印当前工作目录的绝对路径
```

`cd -` 相当于资源管理器的「后退」，但**只有一步**：连按两次会在两个目录之间来回跳。

```bash
ls                       # 列当前目录
ls /etc                  # 列指定目录
ls -a                    # 连隐藏文件（. 开头）一起列
ls -l                    # 详细列表
ls -h                    # 大小带单位（K/M/G），常和 -l 一起用
ls -F                    # 名字后缀加类型标记：/ 目录 * 可执行 @ 符号链接
ll                       # Ubuntu 预置别名，等于 ls -alF
```

详细列表每一列是什么（`ll` 的输出）：

```
drwxr-xr-x  2 user user 4096 Aug  2 21:20 Documents/
│           │ │    │    │    │            └─ 名字
│           │ │    │    │    └─ 最后修改时间
│           │ │    │    └─ 大小（字节）
│           │ │    └─ 所属组
│           │ └─ 所有者
│           └─ 硬链接数
└─ 文件类型与权限
```

第一列的 `d` 表示目录，`-` 表示普通文件；后面九位权限第 04 篇细讲。

### 2.4 读文件：cat

```bash
cat a.txt               # 输出整个文件
cat a.txt b.txt         # 依次输出两个文件（拼接）
cat a.txt | wc -l       # 数行数（管道第 03 篇讲）
```

**禁区**：别拿 `cat` 开大文件（刷满屏幕、卡住，救急按 `Ctrl+C`），也别开二进制/图片/压缩包（会喷乱码）。看大文件用 `less`、`head`、`tail`（第 03 篇）。

### 2.5 运行文件

有执行权限的程序或脚本，直接写路径就能跑：

```bash
./main --port 8000
/opt/my-script.sh
/data/main --config /data/config.json
```

**坑**：只写 `main` 会 `command not found`——当前目录不在 `PATH` 里，必须带 `./`。

### 2.6 新建：mkdir 与 touch

```bash
mkdir test              # 建一个目录
mkdir a b c             # 一次建三个
mkdir -p x/y/z          # 父目录不存在时一并创建
touch note.txt          # 建空文件（已存在则更新时间戳）
touch a.txt b.txt       # 一次建多个
```

**坑**：`mkdir x/y/z` 在 `x` 不存在时会报 `No such file or directory`，加 `-p` 才行。

### 2.7 查找：find

```bash
find [起始目录] [查找条件]

find . -name "config.json"          # 从当前目录往下找
find ~ -name "*.txt"                # 家目录里所有 txt
find /data -type d -name "ckpt"     # 只要目录
find /data -type f -name "*.pt"     # 只要普通文件
find . -iname "readme*"             # 忽略大小写
find . -maxdepth 1 -name "*.txt"    # 只看这一层
```

**坑**：条件里带 `*` 要用引号包住（`"*.txt"`），否则 shell 会先把通配符展开成当前目录的文件名，`find` 收到的就是一堆具体名字（第 03 篇讲通配符）。

## 3. 命令速查表

| 命令 | 作用 | 常用参数 | 真实例子 → 干什么 |
| --- | --- | --- | --- |
| `cd` | 切目录 | 无参=回家；`-`=上一次 | `cd -` → 回到刚才那个目录 |
| `pwd` | 打印当前目录 | — | `pwd` → `/home/chriskim` |
| `ls` | 列目录 | `-a -l -h -F` | `ls -alh` → 隐藏文件+详情+带单位 |
| `cat` | 看/拼文件 | — | `cat a.txt b.txt` → 两个文件依次输出 |
| `mkdir` | 建目录 | `-p` | `mkdir -p x/y/z` → 连父目录一起建 |
| `touch` | 建空文件 | — | `touch note.txt` → 建一个空文件 |
| `find` | 找文件 | `-name -iname -type -maxdepth` | `find . -name "*.md"` → 当前目录下所有 md |
| `./程序` | 运行 | — | `./main --port 8000` → 跑当前目录的可执行文件 |

## 4. 动手练

**① 走一遍目录树**
```bash
cd / && pwd          # 到根目录
cd ~ && pwd          # 回家
cd /etc && cd -      # 前进后退一次
```

**② 建一套嵌套目录并验证**
```bash
mkdir -p ~/lab/a/b/c
find ~/lab -type d
```
预期：列出 `~/lab`、`a`、`a/b`、`a/b/c` 四层。

**③ 看懂长列表**
```bash
mkdir -p ~/lab/demo && touch ~/lab/demo/{a.txt,b.txt}
ll ~/lab/demo
```
预期：两行文件，`-rw-r--r--` 开头，大小 0。

**④ 用相对路径进目录**
```bash
cd ~/lab/demo
cd ../..            # 回到 ~/lab
pwd                 # 应该是 /home/用户名/lab
```

**⑤ 找某个文件**
```bash
find ~ -maxdepth 2 -name "*.txt"
```

## 5. 常见报错

**① `mkdir: cannot create directory 'x/y/z': No such file or directory`**
上一级不存在。用 `mkdir -p x/y/z`。

**② `bash: main: command not found`**
当前目录不在 `PATH`。写 `./main`，或加可执行权限（第 04 篇）。

**③ `find . -name *.txt` 结果不对**
没加引号，`*.txt` 被 shell 先展开。改成 `find . -name "*.txt"`。

**④ `cat` 之后终端卡住**
文件太大或不是文本。`Ctrl+C` 中断，改用 `less`。

## 6. 平台差异

| 项 | Linux | macOS |
| --- | --- | --- |
| 家目录 | `/home/用户名` | `/Users/用户名`（`~` 同样有效） |
| 大小写 | 区分 | 默认不区分（APFS 可配置） |
| `ls` 颜色 | `--color=auto` | `-G` |
| `ll` 别名 | Ubuntu 预置 | 默认没有，要自己在 `~/.zshrc` 加 |
| `find -maxdepth` | 支持 | 支持 |

## 7. 自测

<details>
<summary>Q1：当前在 `/home/chriskim/lab`，`cd ../../data` 之后在哪？</summary>

`/data`。`..` 一次到 `/home`，再 `..` 到 `/`，然后进 `data`。
</details>

<details>
<summary>Q2：`/etc/passwd` 和 `passwd` 有什么区别？</summary>

前者是文件路径（绝对路径，指向 /etc 目录下的 passwd 文件），后者是命令名（改密码）。命令行里有没有 `/` 决定它是路径还是命令。
</details>

<details>
<summary>Q3：`ll` 输出第一列的 `drwxr-xr-x` 里，`d` 表示什么？</summary>

表示这是目录（directory）。普通文件是 `-`，符号链接是 `l`，后面九位是权限，第 04 篇细讲。
</details>

<details>
<summary>Q4：为什么 `find . -name *.txt` 和 `find . -name "*.txt"` 结果不同？</summary>

不加引号时 shell 先把 `*.txt` 展开成当前目录下匹配的文件名，`find` 收到的是具体清单；加引号才是把「通配符」交给 `find` 自己匹配。
</details>

<details>
<summary>Q5：`mkdir x/y/z` 为什么报错，加 `-p` 为什么就好了？</summary>

`mkdir` 默认只会建最后一层，父目录不存在就报错；`-p`（parents）会把缺的上级目录一并建出来，已存在也不报错。
</details>
