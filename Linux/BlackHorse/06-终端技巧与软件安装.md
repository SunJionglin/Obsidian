# 06 终端技巧与软件安装

## 6.1 快捷键与效率

| 按键 | 作用 |
| --- | --- |
| `Tab` | 补全（连按两次列候选） |
| `↑` / `↓` | 历史命令 |
| `Ctrl+R` | 搜索历史 |
| `Ctrl+C` | 中断当前命令 |
| `Ctrl+Z` | 挂起（`fg` 恢复） |
| `Ctrl+D` | 输入结束 / 退出 shell |
| `Ctrl+L` | 清屏 |
| `Ctrl+A` / `Ctrl+E` | 行首 / 行尾 |
| `Ctrl+U` / `Ctrl+K` | 删到行首 / 行尾 |
| `Ctrl+W` | 删前一个词 |
| `Ctrl+S` / `Ctrl+Q` | 暂停输出 / 恢复（误按会以为卡死） |

```bash
history | tail -20        # 最近 20 条历史
!编号                     # 重新执行某条历史
!!                        # 上一条命令（配 sudo 常用：sudo !!）
alias ll='ls -alF'        # 别名，写进 ~/.bashrc 永久生效
```

## 6.2 装软件：yum 与 apt

```bash
# CentOS / RHEL 系
sudo yum install -y nginx
sudo yum remove nginx
sudo yum search nginx
sudo yum update
sudo yum repolist

# Ubuntu / Debian 系
sudo apt update
sudo apt install -y nginx
sudo apt remove nginx
sudo apt search nginx
```

| 项 | yum（CentOS） | apt（Ubuntu） |
| --- | --- | --- |
| 刷新索引 | `yum makecache` / 自动 | `apt update`（必须先跑） |
| 装包 | `yum install -y pkg` | `apt install -y pkg` |
| 卸载 | `yum remove pkg` | `apt remove` / `apt purge` |
| 搜索 | `yum search` | `apt search` |
| 源配置 | `/etc/yum.repos.d/*.repo` | `/etc/apt/sources.list` |

**换源**：国内把源换成阿里/清华镜像，装包速度差好几倍。换完跑一次 `yum makecache` 或 `apt update`。

```bash
# 离线包
sudo rpm -ivh xxx.rpm        # CentOS
sudo dpkg -i xxx.deb         # Ubuntu
```

坑：`yum install` 忘了 `-y` 会停在确认；`apt` 不用 `update` 会报 `Unable to locate package`。

## 6.3 systemctl 管服务

```bash
systemctl start nginx         # 启动
systemctl stop nginx          # 停止
systemctl restart nginx       # 重启
systemctl reload nginx        # 重载配置（不断连接）
systemctl status nginx        # 状态（看是否 active、最近日志）
systemctl enable nginx        # 开机自启
systemctl disable nginx       # 取消自启
systemctl is-enabled nginx    # 查是否自启
systemctl list-units --type=service --state=running   # 正在跑的服务
```

CentOS7 之前用 `service nginx start`、`chkconfig`；现在统一 `systemctl`。

坑：`enable` 不等于 `start`——`enable` 只是开机自启，服务本身还得 `start`。

## 6.4 软链接

```bash
ln -s /opt/app/conf/config.yml /etc/app/config.yml    # 建软链接
ln -s /data/app/v2 /opt/app/current                   # 版本切换常用
ls -l /etc/app/config.yml       # 看到 -> 目标路径
readlink -f path                # 解析真实路径
```

| | 软链接（`ln -s`） | 硬链接（`ln`） |
| --- | --- | --- |
| 本质 | 一个指向路径的小文件 | 指向同一个 inode |
| 删原文件 | 断链，报 `No such file` | 数据还在 |
| 能否跨分区 | 能 | 不能 |
| 能否指目录 | 能 | 不能 |

典型用途：`/usr/local/bin` 里放软链接指向实际程序；Nginx 的 `sites-enabled` 指向 `sites-available` 里的配置。

坑：软链接用**绝对路径**最稳；用相对路径时相对的是链接所在目录，容易断。

## 6.5 常见坑

1. `alias` 写在命令行只在当前会话有效，要写进 `~/.bashrc` 再 `source`。
2. `systemctl status` 显示 `failed` 时看下面几行日志，或者 `journalctl -u nginx -n 50`。
3. 装完软件命令找不到：不在 `PATH`（`/usr/local/bin` 常见），或装成了别的名字。
4. 服务起不来先看端口占用（见 [[07-时间网络与主机]]）和配置文件语法（`nginx -t`）。
