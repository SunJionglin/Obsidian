# 08 进程、监控与环境

## 8.1 进程管理

```bash
ps aux                       # 所有进程（BSD 风格）
ps -ef                       # 所有进程（System V 风格，能看 PPID）
ps aux | grep nginx          # 找进程
ps -eo pid,ppid,pcpu,pmem,cmd --sort=-pcpu | head   # 按 CPU 排序前几名
```

| 列 | 含义 |
| --- | --- |
| `PID` | 进程号 |
| `PPID` | 父进程号 |
| `%CPU` / `%MEM` | CPU / 内存占用 |
| `STAT` | 状态：`R` 运行、`S` 睡眠、`Z` 僵尸、`D` 不可中断 |
| `COMMAND` | 启动命令 |

```bash
kill 1234                    # 发 SIGTERM（15），让程序自己收尾
kill -9 1234                 # SIGKILL，强杀
pkill -f "python3 job.py"    # 按命令行匹配批量杀
killall nginx                # 按进程名杀
```

优先级：先 TERM，不行再 `-9`；上来就 `-9` 会留锁和半截文件。

## 8.2 主机状态监控

```bash
top            # 动态看 CPU/内存/进程（M 按内存排，P 按 CPU 排，q 退出）
htop           # 更好看，需装
free -h        # 内存使用
df -h          # 磁盘各分区用量
du -sh /var/log    # 目录占用
uptime         # 负载（load average）
```

`top` 顶部的 load average 是 1/5/15 分钟平均负载，**超过核数（`nproc`）说明排队**；`wa` 高说明卡在磁盘 IO。

## 8.3 环境变量

```bash
echo $PATH                   # 命令搜索路径
export MYVAR=hello           # 当前会话有效
env | grep MYVAR
unset MYVAR
```

永久生效写进 `~/.bashrc`（用户级）或 `/etc/profile`（全局），再 `source ~/.bashrc`。

```bash
export PATH=$PATH:/opt/app/bin    # 追加路径（注意保留原 PATH）
```

坑：写成 `PATH=/opt/app/bin` 会把系统路径全覆盖，命令全找不到；恢复要 `/usr/bin/vi` 这种绝对路径改回来。

## 8.4 文件上传与下载

```bash
# scp（服务器之间/本地与服务器）
scp local.tar.gz user@host:/tmp/
scp -r user@host:/data/logs ./logs/
scp -P 2222 file user@host:/tmp/     # 端口是大写 P

# 本地与 Windows（需装 lrzsz）
rz            # 上传（在终端里执行，弹选择框）
sz file.txt   # 下载
```

大文件优先 `rsync -avz`：增量、断点续、可排除。

## 8.5 压缩与解压

```bash
tar -czvf site.tar.gz ./site       # 打包 gzip（c 打包 z gzip v 过程 f 文件名）
tar -xzvf site.tar.gz              # 解压
tar -tzvf site.tar.gz              # 只看内容
tar -czvf logs.tar.gz --exclude="*.log" ./data

zip -r site.zip ./site             # zip 压目录要 -r
unzip site.zip -d ./out            # 解到指定目录

gzip big.log                       # 单文件压缩（生成 big.log.gz）
gunzip big.log.gz
```

记忆：**c 打包、x 解开、t 列表；z gzip、j bzip2、J xz；v 显示过程；f 后面紧跟文件名**。

坑：`tar -czvf` 的 `f` 必须最后；`zip` 不加 `-r` 只压目录本身不压内容。

## 8.6 常见坑

1. `ps aux | grep xxx` 会把自己的 grep 也匹配进去，加 `| grep -v grep`。
2. `kill -9` 后端口还占着：进程可能已被 init 接管，`ss -tulnp` 确认 PID 再处理。
3. 磁盘满导致服务起不来：`df -h` 先看，`du -sh /*` 找大头，日志在 `/var/log`。
4. 环境变量改了不生效：没 `source`，或者改的是 `.bash_profile` 而当前是非登录 shell，改 `~/.bashrc`。
5. `free` 里 `buff/cache` 高不是问题，看 `available`。
