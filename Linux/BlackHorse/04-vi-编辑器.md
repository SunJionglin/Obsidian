# 04 vi 编辑器

## 4.1 为什么要会 vi

服务器上不一定有图形界面，但一定装了 vi/vim；改配置、写脚本、切日志都靠它。`vim` 是 `vi` 的增强版（语法高亮、插件）。

```bash
vi /etc/hosts          # 打开文件（不存在则新建）
vim /etc/hosts         # 增强版
vim +10 file           # 定位到第 10 行
vim + file             # 定位到最后一行
```

## 4.2 三种模式

| 模式 | 进入方式 | 能做什么 |
| --- | --- | --- |
| 普通模式（命令模式） | 打开即在；`Esc` 随时回来 | 移动、删除、复制、粘贴、撤销 |
| 插入模式 | `i` `a` `o` `I` `A` `O` | 打字 |
| 末行模式 | 普通模式按 `:` | 保存、退出、查找替换、设置 |

最容易踩的坑：打开文件直接敲字 → 进的是普通模式，字母被当成命令。**先按 `i` 再打字。**

## 4.3 进入插入模式

| 按键 | 效果 |
| --- | --- |
| `i` | 光标前插入 |
| `a` | 光标后插入 |
| `I` | 行首插入 |
| `A` | 行尾插入 |
| `o` | 下方新开一行 |
| `O` | 上方新开一行 |

## 4.4 移动光标（普通模式）

| 按键 | 效果 |
| --- | --- |
| `h` `j` `k` `l` | 左 下 上 右 |
| `0` / `^` | 行首 |
| `$` | 行尾 |
| `w` / `b` | 下一个 / 上一个单词 |
| `gg` / `G` | 文件首 / 文件尾 |
| `数字 + G` | 跳到第 n 行（如 `50G`） |
| `Ctrl+f` / `Ctrl+b` | 下翻页 / 上翻页 |

## 4.5 编辑（普通模式）

| 按键 | 效果 |
| --- | --- |
| `x` | 删一个字符 |
| `dd` | 删整行 |
| `数字 + dd` | 删 n 行（`3dd`） |
| `dw` | 删一个单词 |
| `d$` | 删到行尾 |
| `yy` | 复制整行 |
| `数字 + yy` | 复制 n 行 |
| `p` | 粘贴到下一行 |
| `P` | 粘贴到上一行 |
| `u` | 撤销 |
| `Ctrl+r` | 重做 |
| `r` | 替换一个字符 |
| `R` | 进入替换模式（连续覆盖） |

## 4.6 末行模式命令

```
:w            保存
:w newfile    另存为
:q            退出（没改过）
:q!           不保存强行退出
:wq           保存并退出
:x            保存并退出（等价）
ZZ            普通模式下保存退出
:set nu       显示行号
:set nonu     取消行号
:noh          取消搜索高亮
```

## 4.7 查找与替换

```
/关键词        向下搜索，n 下一个，N 上一个
?关键词        向上搜索
nohl           取消高亮

:s/old/new          当前行第一个替换
:s/old/new/g        当前行全部替换
:%s/old/new/g       全文替换
:%s/old/new/gc      全文替换，逐个确认
:10,20s/old/new/g   只替换 10–20 行
```

坑：`%` 表示整个文件；替换前先 `:set nu` + `/关键词` 确认范围，别一把梭。

## 4.8 一个完整的改配置流程

```bash
vi /etc/hosts
# 1. 按 i 进入插入
# 2. 改内容
# 3. 按 Esc 回普通模式
# 4. 敲 :wq 回车保存退出
# 5. cat /etc/hosts 确认改对了
```

## 4.9 常见坑

1. 进了 vi 出不来：`Esc` 连按两下，然后 `:q!`。
2. 保存时提示 `E45: 'readonly' option is set`：文件只读，`sudo vi` 或 `:w !sudo tee %`。
3. 改了文件但 `:q` 退不出去，会提示 `E37: No write since last change`，用 `:wq` 或 `:q!`。
4. 终端断线导致 `.swp` 残留，下次打开提示 swap 文件：确认没别人在改后删掉 `.文件名.swp`。
5. 中文乱码多半是终端编码问题，不是 vim 的错。
