# 11 命令与参数词根表

> 参数不是乱码，基本都是英文单词的首字母。记住单词，参数就不用背。
> 用法：查表 → 记单词 → 回到命令里对照着看。

## 11.1 按字母查（短参数）

| 字母 | 来自 | 常见命令 | 含义 |
| --- | --- | --- | --- |
| `-a` | **a**ll | `ls -a`、`ps aux` | 全部（含隐藏文件 / 所有进程） |
| `-A` | **a**lmost all | `ls -A` | 几乎全部（不含 `.` 与 `..`） |
| `-b` | **b**ytes / **b**lock | `du -b`、`tar -b` | 以字节/块计 |
| `-c` | **c**reate / **c**ount / **c**ontinue | `tar -c`、`grep -c`、`wget -c` | 创建 / 计数 / 续传 |
| `-C` | **C**hange directory | `tar -C dir` | 切换目录后再操作 |
| `-d` | **d**irectory | `ls -d`、`ss -d` | 目录本身 / 显示详情 |
| `-e` | **e**xtended / **e**very | `grep -E`、`ps -e` | 扩展正则 / 所有进程 |
| `-f` | **f**orce / **f**ile / **f**ollow / **f**ull | `rm -f`、`tar -f`、`tail -f`、`ps -f` | 强制 / 文件名 / 跟随 / 完整格式 |
| `-g` | **g**roup | `chmod g+w`、`ls -g` | 属组 |
| `-h` | **h**uman-readable | `ls -h`、`df -h`、`du -h`、`free -h` | 人性化单位（K/M/G） |
| `-i` | **i**nteractive / **i**gnore-case / **i**node | `cp -i`、`grep -i`、`ls -i` | 交互确认 / 忽略大小写 / inode 号 |
| `-I` | **I**nfo / **I**nclude | `curl -I`、`tar -I` | 只看响应头 / 指定压缩程序 |
| `-j` | bzip**j**（bzip2） | `tar -j` | bzip2 压缩 |
| `-k` | **k**ey / **k**ilobytes | `sort -k 2`、`du -k` | 排序键 / 以 KB 计 |
| `-l` | **l**ong / **l**ines / **l**istening | `ls -l`、`wc -l`、`ss -l` | 长格式 / 行数 / 监听 |
| `-L` | **L**ocation / dereference | `curl -L`、`find -L` | 跟随跳转 / 跟随软链接 |
| `-m` | **m**ake / **m**odify | `useradd -m`、`chmod` | 建家目录 / 修改 |
| `-n` | **n**umber / **n**umeric | `head -n 20`、`grep -n`、`sort -n`、`ss -n` | 行号 / 数值 / 不解析地址 |
| `-o` | **o**utput / **o**thers | `curl -o f`、`chmod o+r` | 输出文件 / 其他人 |
| `-O` | **O**utput (remote name) | `curl -O`、`wget -O` | 用远端原名保存 |
| `-p` | **p**arents / **p**ort / **p**reserve / **p**rocess | `mkdir -p`、`ssh -p`、`cp -p`、`ss -p` | 建父目录 / 端口 / 保留属性 / 进程 |
| `-P` | **P**ort | `scp -P` | 端口（scp 用大写） |
| `-q` | **q**uiet | `grep -q`、`tar -q` | 安静模式，不输出 |
| `-r` | **r**ecursive / **r**everse | `cp -r`、`grep -r`、`ls -r`、`sort -r` | 递归 / 反序 |
| `-R` | **R**ecursive | `ls -R`、`chmod -R`、`chown -R` | 递归 |
| `-s` | **s**ummary / **s**ymbolic / **s**ilent / **s**ize | `du -s`、`ln -s`、`curl -s`、`ls -s` | 汇总 / 符号 / 静默 / 大小 |
| `-t` | **t**ime / **t**ype / **t**cp | `ls -t`、`find -type`、`ss -t` | 时间排序 / 类型 / TCP |
| `-u` | **u**dp / **u**pdate / **u**nique | `ss -u`、`apt update`、`sort -u` | UDP / 更新 / 去重 |
| `-U` | **U**ser | `ps -U` | 按用户筛 |
| `-v` | **v**erbose / in**v**ert | `tar -v`、`grep -v` | 显示过程 / 反选（两义！） |
| `-V` | **V**ersion | `tar -V`、`grep -V` | 版本 |
| `-w` | **w**ords / **w**ide | `wc -w`、`ps w` | 词数 / 宽格式 |
| `-x` | e**x**tract / e**x**ecute | `tar -x`、`chmod +x` | 解包 / 可执行 |
| `-y` | **y**es | `yum -y`、`apt -y` | 自动回答「是」 |
| `-z` | g**z**ip / **z**ero | `tar -z` | gzip 压缩 |

**同名不同义的坑**：`grep -v` 是「反选」不是「显示过程」；`ls -i` 是 inode 不是「交互」；`scp -P` 是大写端口，`ssh -p` 是小写。

## 11.2 长参数就是完整单词

| 长参数 | 单词 | 命令 |
| --- | --- | --- |
| `--all` | all | `ls --all` |
| `--human-readable` | human readable | `ls`、`df` |
| `--recursive` | recursive | `cp`、`grep` |
| `--force` | force | `rm` |
| `--verbose` | verbose | `tar`、`cp` |
| `--exclude` | exclude | `tar`、`rsync` |
| `--maxdepth` | max depth | `find` |
| `--name` | name | `find` |
| `--type` | type | `find` |
| `--help` | help | 几乎所有命令 |
| `--version` | version | 几乎所有命令 |

## 11.4 三个高频组合的拆解

```bash
ls -lha /etc
#  -l long 长格式
#  -h human-readable 带单位
#  -a all 含隐藏文件

tar -czvf site.tar.gz ./site
#  -c create 创建
#  -z gzip 压缩
#  -v verbose 显示过程
#  -f file 指定文件名（必须最后）

ss -tulnp
#  -t tcp
#  -u udp
#  -l listening 只看监听
#  -n numeric 不解析服务名
#  -p process 显示进程
```
