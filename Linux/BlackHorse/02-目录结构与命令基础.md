# 02 目录结构与命令基础

## 2.1 Linux 目录结构（FHS）

| 目录 | 放什么 | 例子 |
| --- | --- | --- |
| `/` | 根，一切从这里开始 | — |
| `/bin`、`/usr/bin` | 普通用户命令 | `ls`、`cp`、`grep` |
| `/sbin`、`/usr/sbin` | 管理命令（多需 root） | `fdisk`、`iptables` |
| `/etc` | 配置文件 | `nginx/`、`passwd`、`hosts` |
| `/home/用户名` | 普通用户家目录 | 你的代码 |
| `/root` | root 家目录 | 只有 root 能进 |
| `/var` | 会变大的数据：日志、缓存、数据库 | `/var/log` |
| `/tmp` | 临时文件，可能被清理 | 脚本中间产物 |
| `/opt` | 第三方大型软件 | `/opt/google` |
| `/usr/local` | 自己编译安装的软件 | 源码装的东西 |
| `/dev` | 设备文件 | `/dev/sda`、`/dev/null` |
| `/proc` | 内核与进程的虚拟文件系统 | `/proc/cpuinfo` |
| `/mnt`、`/media` | 挂载点 | U 盘、数据盘 |

一句话：**配置在 `/etc`，日志在 `/var/log`，程序在 `/usr`，自己的东西在 `/home`。**

## 2.2 命令的通用格式

```
命令 [选项] [参数]
ls    -l      /etc
```

| 形式 | 例子 | 说明 |
| --- | --- | --- |
| 短选项 | `ls -l` | 单横线 + 单字母，可合并 `-lh` |
| 长选项 | `ls --all` | 双横线 + 单词 |
| 带值 | `head -n 20 f` | 选项后跟值 |
| 参数 | `ls /etc` | 操作对象 |

命令本身也是文件，`which` 能查它在哪；提示符 `$` 是普通用户、`#` 是 root。

## 2.3 ls：看目录

```bash
ls                  # 简单列
ls -l               # 长格式：权限/链接数/属主/属组/大小/时间/名字
ls -a               # 含隐藏文件（. 开头）
ls -lh              # 大小带单位
ls -lha             # 三个合并
ls -R               # 递归列子目录
ls -lt               # 按时间排序（新→旧）
ls -ltr              # 按时间反序（旧→新，看最新日志用）
```

长格式第一列 `drwxr-xr-x`：第 1 位 `d` 是目录（`-` 文件、`l` 链接），后 9 位是权限，见 [[05-用户组与权限]]。

## 2.4 cd 与 pwd

```bash
pwd                 # 当前所在目录的绝对路径
cd /etc             # 绝对路径
cd nginx            # 相对路径
cd ..               # 上一层
cd ~                # 回家目录
cd -                # 回上一次的目录
cd                  # 不带参数也回家
```

## 2.5 相对路径、绝对路径与特殊符号

| 写法 | 含义 |
| --- | --- |
| `/etc/nginx` | 绝对路径，从根开始 |
| `nginx/conf` | 相对当前目录 |
| `.` | 当前目录 |
| `..` | 上一级 |
| `~` | 家目录（`~user` 是别人家目录） |
| `-` | 上一次的目录（cd 专用） |

```bash
# 假设当前在 /home/user
cd ../etc            # → /home/etc（不是 /etc！）
cd /etc              # → /etc
```

坑：`cd ..` 从 `/` 出发还是 `/`，不会报错；写相对路径前先 `pwd` 看一眼。

## 2.6 命令补全与历史

| 按键 | 作用 |
| --- | --- |
| `Tab` | 补全命令/路径，连按两次列候选 |
| `↑` / `↓` | 翻历史命令 |
| `Ctrl+R` | 搜索历史（输入关键词） |
| `Ctrl+C` | 中断当前命令 |
| `Ctrl+L` | 清屏 |
| `Ctrl+A` / `Ctrl+E` | 行首 / 行尾 |

## 2.7 常见坑

1. Linux 区分大小写：`File.txt` 与 `file.txt` 是两个文件。
2. 路径里有空格要转义或加引号：`cd "my dir"`。
3. `ls -l` 的大小是「字节」，人类可读要 `-h`。
4. `/` 与 `~` 别混：`cd /home` 和 `cd ~` 在普通用户下不同。
