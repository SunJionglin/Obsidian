# 01 系统与虚拟机

## 1.1 操作系统、内核、发行版

| 概念 | 含义 | 一句话区分 |
| --- | --- | --- |
| 操作系统 | 管理硬件 + 提供接口的软件集合 | 内核 + 外壳 + 工具 |
| 内核（kernel） | 管进程、内存、文件、设备 | Linux 就是内核 |
| 发行版 | 内核 + 包管理器 + 工具 + 默认配置 | CentOS / Ubuntu / Debian |

课程选 CentOS7：企业服务器市场占比高、资料多；但它已停止维护（2024-06 EOL），实际生产更常见 Rocky/Alma/Ubuntu LTS。

```bash
cat /etc/centos-release      # CentOS Linux release 7.9.2009 (Core)
uname -r                     # 3.10.0-1160.el7.x86_64（内核版本）
```

## 1.2 为什么要用虚拟机

直接在物理机上装 Linux 意味着不能同时用 Windows；虚拟机能在一台机器上并存多个系统，随时快照回滚，踩坏了重开。

| 方案 | 说明 | 适合 |
| --- | --- | --- |
| 虚拟机（VMware/Fusion/VirtualBox） | 完整 Linux 环境，独立 IP | 学习、模拟服务器 |
| 双系统 | 独占硬件，性能好 | 长期主力使用 |
| WSL2 | Windows 里的轻量 Linux | Windows 上要 Linux 工具链 |
| 云服务器 | 现成的远程机器 | 练部署、随时随地 |

## 1.3 装 CentOS7（课程流程）

1. 装 VMware Workstation（Windows）/ VMware Fusion（macOS）。
2. 新建虚拟机 → 选 CentOS7 镜像（`.iso`）→ 内存 2G、磁盘 20G 起。
3. 安装时选「最小安装」或「带 GUI」，分区默认即可。
4. 装完设置 root 密码，创建普通用户。
5. `ip addr` 看 IP，主机上用 SSH 连。

```bash
# 在虚拟机里确认 SSH 服务开着
systemctl status sshd
ip addr | grep "inet "
```

**虚拟机网络三模式**：

| 模式 | 效果 | 用途 |
| --- | --- | --- |
| NAT | 虚拟机共享主机 IP 上网，主机能连它 | 默认，最省事 |
| 桥接 | 虚拟机像局域网里独立一台机器 | 要独立 IP 做服务器 |
| 仅主机 | 只能与主机通信 | 隔离实验 |

## 1.4 远程连接

```bash
ssh root@192.168.10.128            # 密码登录
ssh -p 2222 user@host              # 改过端口
ssh-keygen -t ed25519              # 生成密钥
ssh-copy-id user@host              # 免密
```

图形/终端工具：Xshell、FinalShell、iTerm2、VS Code Remote-SSH（推荐，能直接编辑远端文件）。

坑：连不上先查三件事——虚拟机 IP 对不对、`sshd` 起没起、防火墙/端口是否放行。

## 1.5 WSL（Windows 用户跳过虚拟机）

```powershell
wsl --install -d Ubuntu
wsl -l -v
```

Windows 下 Linux 文件在 `\\wsl$\Ubuntu\home\...`；WSL 的文件系统跨盘访问慢，项目放 WSL 内部目录。

## 1.6 快照

装完系统、配好网络后立刻打一个快照；之后每次做危险操作（改配置、装数据库）前再打一个。踩坏了直接回滚，不用重装。

VMware：虚拟机 → 快照 → 拍摄快照；恢复时选对应快照。

## 1.7 常见坑

1. 装完忘记开网络（NAT 服务没起），`ping baidu.com` 不通。
2. CentOS7 默认防火墙 `firewalld` 开着，外部连 SSH 前确认 22 端口放行：`firewall-cmd --list-ports`。
3. 用 root 直接登录生产服务器有风险，练习环境无所谓，正式环境用普通用户 + `sudo`。
4. 快照不是备份：同一块盘坏了快照一起没，重要数据另存。
