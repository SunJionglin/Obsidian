# 05 用户、组与权限

## 5.1 root 与提权

- `root` 是超级用户（uid 0），能改任何东西，也能删掉系统。
- `su -` 切到 root 并加载 root 环境（要 root 密码）。
- `sudo 命令` 用你自己的密码临时获得 root 权限，且有日志。

```bash
whoami              # 当前用户名
id                  # uid / gid / groups
sudo -i             # 进入 root 的交互 shell
sudo journalctl -xe # 用 root 权限看日志
```

为什么推荐 sudo：不用知道 root 密码、每条命令有记录、权限只在单条命令内有效。

## 5.2 用户管理

```bash
useradd -m -s /bin/bash tom      # 建用户并建家目录，指定 shell
passwd tom                        # 设置/修改密码
usermod -aG developers tom        # 追加到附加组（-a 必须有，否则覆盖）
userdel -r tom                    # 删用户并删家目录
id tom                            # 查 uid/gid/组
```

| 文件 | 内容 |
| --- | --- |
| `/etc/passwd` | 用户名:密码占位:uid:gid:描述:家目录:shell |
| `/etc/shadow` | 密码哈希（只有 root 可读） |
| `/etc/group` | 组名:密码占位:gid:成员列表 |

## 5.3 组管理

```bash
groupadd developers
groupmod -n devs developers       # 改名
gpasswd -a tom developers         # 加入组
gpasswd -d tom developers         # 移出组
groups tom                        # 看某用户属于哪些组
```

一个用户有一个**主组**（建用户时自动建的组）和若干**附加组**。

## 5.4 权限的九位

`ls -l` 第一列 `-rwxr-xr--` 拆开：

```
-  rwx  r-x  r--
│  │    │    └─ 其他人（other）
│  │    └─ 属组（group）
│  └─ 属主（user）
└─ 类型：- 普通文件，d 目录，l 链接
```

数值：**r=4，w=2，x=1**，三位一组相加。

| 数字 | 权限 | 典型用途 |
| --- | --- | --- |
| 644 | rw-r--r-- | 普通文件、配置 |
| 600 | rw------- | 私钥、`.env` |
| 755 | rwxr-xr-x | 目录、可执行脚本 |
| 700 | rwx------ | 只自己能进的目录（`~/.ssh`） |
| 666 | rw-rw-rw- | 协作写权限，慎用 |
| 777 | rwxrwxrwx | **别用**，任何用户都能改 |

## 5.5 chmod：改权限

```bash
# 数字法
chmod 755 run.sh          # rwxr-xr-x
chmod 644 conf.ini
chmod -R 755 public/      # 递归

# 符号法：u 属主 / g 属组 / o 其他人 / a 全部；+ - =
chmod u+x run.sh
chmod go-w note.txt
chmod a+r README.md
```

**目录的 x 位不是「执行」，而是「能不能进去」**：目录没有 x，里面文件权限再大也访问不了。

## 5.6 chown 与 chgrp

```bash
chown tom note.txt             # 改属主
chown tom:devs app/            # 同时改属组
chgrp devs note.txt            # 只改属组
chown -R tom:tom /data/www     # 递归
```

坑：`chown` 把别人的文件给自己要 root 权限；自己文件给别人不需要。

## 5.7 特殊权限位与 umask

| 位 | 显示 | 含义 | 例子 |
| --- | --- | --- | --- |
| SUID | `s` 在属主 x 位 | 执行时临时获得属主权限 | `/usr/bin/passwd` |
| SGID | `s` 在属组 x 位 | 以属组身份执行；目录里新建文件继承组 | 共享目录 |
| Sticky | `t` 在其他人 x 位 | 目录里只有文件主人能删 | `/tmp` |

```bash
chmod 4755 file      # SUID
chmod 2755 dir       # SGID
chmod 1777 /tmp      # Sticky
stat file            # 看完整权限与特殊位
```

`umask` 决定新建文件的默认权限：默认 022 → 文件 644、目录 755。

```bash
umask           # 0022
umask 077       # 之后新建的只有自己能访问
```

## 5.8 常见坑

1. `chmod 777` 一把梭：安全风险，能 755 就别 777，配置文件用 644。
2. 目录有 `w` 没有 `x`：能在里面建文件但进不去，行为很怪。
3. 改完权限发现脚本还是不能跑：文件系统可能挂了 `noexec`；或 shebang 写错。
4. `usermod -G` 忘了 `-a`：把用户从其他附加组里踢出去。
5. 私钥权限过松，`ssh` 会直接拒绝使用（报 `Bad permissions`），`chmod 600` 解决。
