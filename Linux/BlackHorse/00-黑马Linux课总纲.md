## 三、学完能做什么

- 在虚拟机里装好 CentOS7，用 SSH 连上去，不用图形界面也能干活
- 用命令完成：建目录、找文件、改权限、装软件、看进程、查端口、传文件
- 会用 `systemctl` 管服务、用 `yum/apt` 装包、看 `top`/`ps`/`ss` 定位问题
- 能照着文档把 MySQL、Nginx、Redis 装起来并起服务
- 知道集群部署前要准备什么（免密、主机名、时间同步、防火墙）

## 五、学习顺序

1. **先能登进去**：01（装虚拟机 + SSH）
2. **再能走路**：02 → 03 → 04（目录、文件、vi）
3. **再能管**：05 → 06 → 07 → 08（权限、装软件、网络、进程）
4. **最后能部署**：09 → 10（单机 → 集群）

赶时间只做 01–04 + 09 的 Nginx/Redis 两节，足够应付课程作业和第一次上服务器。

## 六、约定

- 命令默认在 CentOS7 环境（课程主环境），Ubuntu 差异会单独标出。
- 每条命令给「干什么 + 参数 + 坑」，不给光秃秃的符号。
- 危险命令（`rm -rf`、`chmod 777`）标红提示。
- 部署篇给「命令序列 + 验证方式」，因为环境不同，照抄前先看目录与版本。
