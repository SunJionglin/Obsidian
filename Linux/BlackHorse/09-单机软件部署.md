# 09 单机软件部署

> 部署没有唯一答案：路径、版本、账号都会变。这里给「命令序列 + 验证方式 + 常见报错」，照抄前先确认系统和版本。

## 9.1 通用步骤（所有软件都适用）

1. 看系统版本：`cat /etc/centos-release` 或 `cat /etc/os-release`
2. 装依赖：`yum install -y gcc gcc-c++ make` / `apt install -y build-essential`
3. 装包（yum/apt 或官方仓库/二进制包）
4. 起服务：`systemctl start xxx`
5. 验证：`systemctl status`、`ss -tulnp | grep 端口`、本地 `curl 127.0.0.1:端口`
6. 放行：`firewall-cmd --add-port=端口/tcp --permanent && firewall-cmd --reload`
7. 设自启：`systemctl enable xxx`

## 9.2 MySQL

```bash
# CentOS7 装 5.7（官方 yum 源）
sudo yum install -y https://dev.mysql.com/get/mysql57-community-release-el7-11.noarch.rpm
sudo yum install -y mysql-community-server
sudo systemctl start mysqld && sudo systemctl enable mysqld
sudo grep "temporary password" /var/log/mysqld.log     # 初始密码
mysql -uroot -p                                         # 登录后改密码
```

```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY 'NewPass123!';
CREATE USER 'app'@'%' IDENTIFIED BY 'AppPass123!';
GRANT ALL PRIVILEGES ON appdb.* TO 'app'@'%';
FLUSH PRIVILEGES;
```

```bash
# Ubuntu 装 8.0
sudo apt install -y mysql-server
sudo systemctl status mysql
sudo mysql_secure_installation
sudo mysql -uroot -p
```

| 项 | 路径 / 说明 |
| --- | --- |
| 配置文件 | `/etc/my.cnf`（CentOS）/ `/etc/mysql/mysql.conf.d/mysqld.cnf`（Ubuntu） |
| 数据目录 | `/var/lib/mysql` |
| 默认端口 | 3306 |
| 远程访问 | 用户表的 `host` 要允许 `%`，且防火墙放行 |

坑：8.0 默认认证插件 `caching_sha2_password`，老客户端连不上，可 `ALTER USER ... IDENTIFIED WITH mysql_native_password BY '...'`。

## 9.3 Nginx

```bash
sudo yum install -y nginx
sudo systemctl start nginx && sudo systemctl enable nginx
nginx -t                       # 校验配置
curl -I 127.0.0.1              # 应返回 200
```

| 项 | 位置 |
| --- | --- |
| 主配置 | `/etc/nginx/nginx.conf` |
| 站点配置 | `/etc/nginx/conf.d/*.conf` |
| 默认站点根 | `/usr/share/nginx/html` |
| 日志 | `/var/log/nginx/access.log`、`error.log` |

```nginx
server {
    listen 80;
    server_name _;
    root /data/www;
    index index.html;
    location /api/ {
        proxy_pass http://127.0.0.1:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

改完 `nginx -t && systemctl reload nginx`。

## 9.4 Tomcat（跑 Java Web）

```bash
sudo yum install -y java-1.8.0-openjdk-devel
tar -xzvf apache-tomcat-9.0.x.tar.gz -C /opt
/opt/apache-tomcat-9.0.x/bin/startup.sh
ss -tulnp | grep 8080
```

部署 war：把 `app.war` 放进 `webapps/`，Tomcat 会自动解压；日志在 `logs/catalina.out`。

坑：`JAVA_HOME` 没配会报 `Neither the JAVA_HOME nor the JRE_HOME environment variable is defined`。

## 9.5 Redis

```bash
sudo yum install -y epel-release
sudo yum install -y redis
sudo vi /etc/redis.conf          # 改 bind 0.0.0.0（内网）与 requirepass
sudo systemctl start redis && sudo systemctl enable redis
redis-cli ping                   # PONG
redis-cli -a 密码 info
```

坑：默认只监听 127.0.0.1；开放公网必须设密码 + 防火墙白名单，否则会被挖矿。

## 9.6 RabbitMQ

```bash
sudo yum install -y erlang
sudo yum install -y rabbitmq-server
sudo systemctl start rabbitmq-server
sudo rabbitmq-plugins enable rabbitmq_management    # 开管理台 15672
sudo rabbitmqctl add_user admin Admin123!
sudo rabbitmqctl set_user_tags admin administrator
sudo rabbitmqctl set_permissions -p / admin ".*" ".*" ".*"
```

默认端口：5672（协议）、15672（管理台）。坑：Erlang 版本要与 RabbitMQ 匹配，装错版本起不来。

## 9.7 Elasticsearch

```bash
# 不能以 root 运行！先建用户
sudo useradd es && sudo passwd es
sudo tar -xzvf elasticsearch-7.x.tar.gz -C /opt && sudo chown -R es:es /opt/elasticsearch-7.x
sudo -u es /opt/elasticsearch-7.x/bin/elasticsearch -d
curl 127.0.0.1:9200
```

```yaml
# config/elasticsearch.yml
network.host: 0.0.0.0
http.port: 9200
cluster.name: my-es
node.name: node-1
discovery.seed_hosts: ["127.0.0.1"]
cluster.initial_master_nodes: ["node-1"]
```

坑：内存不够会直接退出，改 `config/jvm.options` 的 `-Xms/-Xmx`（如 512m）；系统参数要 `vm.max_map_count`、文件句柄数；root 启动直接报错。

## 9.8 部署验收清单

- [ ] `systemctl status` 是 active (running)
- [ ] `ss -tulnp` 能看到端口
- [ ] 本机 `curl`/`redis-cli`/`mysql` 能连
- [ ] 外部能连（防火墙 + 云安全组都放行）
- [ ] `systemctl enable` 已设开机自启
- [ ] 日志里没有明显的 ERROR / OOM
