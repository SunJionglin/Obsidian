# 03 文件与内容操作

## 3.1 新建：mkdir、touch

```bash
mkdir demo                 # 建一级目录
mkdir -p a/b/c             # 父目录不存在时一并创建
mkdir dir1 dir2            # 一次建多个
touch note.txt             # 建空文件（已存在则更新时间戳）
touch a.txt b.txt          # 一次建多个
```

坑：`mkdir a/b/c` 在 `a` 不存在时报 `No such file or directory`，加 `-p`。

## 3.2 看内容：cat、more、less、head、tail

```bash
cat a.txt                  # 全部输出（小文件）
cat a.txt b.txt            # 依次输出两个文件
more big.log               # 分页看，只能往下
less big.log               # 分页看，可上下翻、可搜索（推荐）
head -n 20 app.log         # 前 20 行
tail -n 20 app.log         # 后 20 行
tail -f app.log            # 持续跟新内容（排查必备），Ctrl+C 退出
```

`less` 里：空格下一页、`b` 上一页、`/关键词` 搜索、`n` 下一个、`q` 退出。

坑：别用 `cat` 打开大文件或二进制文件（会刷屏/乱码），用 `less`。

## 3.3 复制、移动、删除

```bash
cp a.txt b.txt             # 复制文件
cp -r src/ dst/            # 复制目录（必须 -r）
cp -i a.txt b.txt          # 覆盖前询问

mv a.txt b.txt             # 重命名
mv a.txt /tmp/             # 移动到目录
mv dir1 dir2               # 目录移动/改名

rm a.txt                   # 删文件
rm -r dir/                 # 递归删目录
rm -f a.txt                # 强制，不提示
rm -rf dir/                # 强制递归（危险！）
```

**红线**：`rm -rf` 不回收站，删了就是删了。执行前 `pwd` + `ls` 确认路径，别在通配符旁边手滑（`rm -rf *` 后面多个空格就是灾难）。

## 3.4 查找：which、find

```bash
which python3              # 命令的完整路径（从 PATH 里找）
which -a python3           # 所有同名命令
find . -name "*.py"        # 当前目录递归找
find /var/log -name "*.log" -size +10M     # 大于 10M 的日志
find . -type d -name build # 只找目录
find . -maxdepth 1 -name "*.txt"           # 只看这一层
```

坑：`-name` 的模式带 `*` 要加引号，否则 shell 先展开。

## 3.5 筛内容：grep、wc、管道

```bash
grep "ERROR" app.log            # 含关键字的行
grep -i "error" app.log         # 忽略大小写
grep -n "timeout" app.log       # 带行号
grep -v "200" access.log        # 反选
grep -r "TODO" ./src            # 递归搜目录
grep -c "404" access.log        # 计数

wc -l app.log                   # 行数
wc -w note.txt                  # 词数
wc -c note.txt                  # 字节数
```

**管道 `|`**：把前一个命令的输出当后一个的输入。

```bash
ls -l | wc -l                   # 当前目录有多少项
ps aux | grep nginx             # 找进程
grep "ERROR" app.log | sort | uniq -c | sort -rn | head    # 错误类型 TopN
```

## 3.6 输出：echo、tail、重定向

```bash
echo "hello"                    # 输出
echo $HOME                      # 环境变量
echo "a" > f.txt                # 覆盖写
echo "b" >> f.txt               # 追加写
ls /etc > list.txt              # 命令结果写文件
ls /nope 2> err.txt             # 错误单独写
cmd > all.log 2>&1              # 正确与错误都写同一个文件
```

| 写法 | 作用 |
| --- | --- |
| `>` | 覆盖，**先清空再写** |
| `>>` | 追加 |
| `2>` | 标准错误 |
| `2>&1` | 错误并入标准输出 |
| `<` | 从文件读输入 |

坑：`>` 会清空文件，想留日志用 `>>` 或 `tee`（见 [[08-进程监控与环境]]）。

## 3.7 常用组合套路

```bash
# 看最新日志的尾部并持续跟
tail -f /var/log/messages

# 统计 nginx 访问日志里 top10 IP
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head

# 找大文件
find / -type f -size +500M 2>/dev/null

# 批量改后缀
for f in *.txt; do mv "$f" "${f%.txt}.md"; done
```

## 3.8 常见坑

1. `cp -r src dst` 时 `dst` 存在会变成 `dst/src`，先确认目标是否已存在。
2. `rm -rf dir/` 与 `rm -rf dir/*` 不同：后者不删隐藏文件。
3. `grep` 递归忘了 `-r`，只搜当前文件。
4. 管道里前一个命令报错不影响后一个（它们只传 stdout）。
5. 重定向 `>` 的权限不对时先报 `Permission denied`，别误以为命令本身有问题。
