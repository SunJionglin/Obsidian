# 10 集群部署

> 集群 = 多台机器协同。所有集群软件都建立在同一套前置条件上：主机名互认、免密登录、时间同步、JDK 就绪、防火墙与 SELinux 处理完。

## 10.1 前置准备（P53 的核心）

假设三台机器：`node01`、`node02`、`node03`。

```bash
# 1) 主机名
hostnamectl set-hostname node01        # 每台各自设置

# 2) hosts 互认（三台都要写）
sudo vi /etc/hosts
192.168.10.11 node01
192.168.10.12 node02
192.168.10.13 node03

# 3) 免密登录（在 node01 上生成密钥，分发到三台）
ssh-keygen -t rsa -N "" -f ~/.ssh/id_rsa
for h in node01 node02 node03; do ssh-copy-id $h; done
ssh node02 date                        # 不输密码即为成功

# 4) 时间同步
sudo yum install -y ntp
sudo systemctl enable --now ntpd
chronyc sources                        # 或 ntpq -p

# 5) 关防火墙与 SELinux（实验环境；生产按需放行端口）
sudo systemctl stop firewalld && sudo systemctl disable firewalld
sudo setenforce 0
sudo sed -i 's/^SELINUX=enforcing/SELINUX=disabled/' /etc/selinux/config

# 6) JDK（Hadoop/Spark/Flink 都要）
sudo yum install -y java-1.8.0-openjdk-devel
echo 'export JAVA_HOME=/usr/lib/jvm/java-1.8.0-openjdk' >> ~/.bashrc
source ~/.bashrc && java -version
```

## 10.2 scp：把文件铺到各节点

```bash
scp -r /opt/soft node02:/opt/
scp -r /opt/soft node03:/opt/
scp install.sh node02:/tmp/
```

批量分发用循环：`for h in node02 node03; do scp -r /opt/soft $h:/opt/; done`。

## 10.3 Zookeeper

```bash
tar -xzvf zookeeper-3.5.x.tar.gz -C /opt
cd /opt/zookeeper-3.5.x/conf
cp zoo_sample.cfg zoo.cfg
```

```properties
dataDir=/opt/zookeeper-3.5.x/data
server.1=node01:2888:3888
server.2=node02:2888:3888
server.3=node03:2888:3888
```

```bash
mkdir -p /opt/zookeeper-3.5.x/data
echo 1 > /opt/zookeeper-3.5.x/data/myid    # 每台写自己的编号 1/2/3
bin/zkServer.sh start
bin/zkServer.sh status                      # 一个 leader，两个 follower
```

坑：`myid` 与 `server.N` 必须对应；三台时间差太大会选主失败。

## 10.4 Kafka

```bash
tar -xzvf kafka_2.12-3.x.tgz -C /opt
# config/server.properties
broker.id=0                                  # 每台不同
listeners=PLAINTEXT://node01:9092
zookeeper.connect=node01:2181,node02:2181,node03:2181
log.dirs=/opt/kafka/logs
```

```bash
bin/kafka-server-start.sh -daemon config/server.properties
bin/kafka-topics.sh --bootstrap-server node01:9092 --list
```

## 10.5 Hadoop

```bash
tar -xzvf hadoop-3.x.tar.gz -C /opt
```

`etc/hadoop/core-site.xml`：

```xml
<property><name>fs.defaultFS</name><value>hdfs://node01:8020</value></property>
```

`hdfs-site.xml`：副本数 `dfs.replication=2`。

`workers`（3.x）或 `slaves`（2.x）写 `node02 node03`，`node01` 作 NameNode。

```bash
hdfs namenode -format        # 只执行一次！
start-dfs.sh
jps                          # 看 NameNode / DataNode / SecondaryNameNode
hdfs dfs -mkdir -p /data && hdfs dfs -ls /
```

坑：多次 `format` 会导致集群 ID 不一致，DataNode 起不来；格式化前先确认 `dfs.namenode.name.dir` 为空。

## 10.6 HBase

```bash
tar -xzvf hbase-2.x-bin.tar.gz -C /opt
# conf/hbase-site.xml
<property><name>hbase.rootdir</name><value>hdfs://node01:8020/hbase</value></property>
<property><name>hbase.cluster.distributed</name><value>true</value></property>
<property><name>hbase.zookeeper.quorum</name><value>node01,node02,node03</value></property>
```

```bash
start-hbase.sh
hbase shell      # create 'test','cf' / put / scan
```

坑：HBase 依赖 HDFS 与 ZK，两个先起；`hbase.rootdir` 指向 HDFS 才能分布式。

## 10.7 Spark

```bash
tar -xzvf spark-3.x-bin-hadoop3.tgz -C /opt
# conf/spark-env.sh
export JAVA_HOME=/usr/lib/jvm/java-1.8.0-openjdk
export SPARK_MASTER_HOST=node01
# conf/workers
node02
node03
```

```bash
sbin/start-all.sh
jps                    # Master / Worker
spark-shell --master spark://node01:7077
```

## 10.8 Flink

```bash
tar -xzvf flink-1.x-bin-scala_2.12.tgz -C /opt
# conf/flink-conf.yaml
jobmanager.rpc.address: node01
taskmanager.numberOfTaskSlots: 2
# conf/workers
node02
node03
```

```bash
bin/start-cluster.sh
jps                    # JobManager / TaskManager
curl 127.0.0.1:8081    # Web UI
```

## 10.9 集群部署检查清单

- [ ] 三台 `hostname` 与 `/etc/hosts` 一致，`ping node02` 通
- [ ] `ssh node02 date` 不要密码
- [ ] `date` 三台时间差 < 1 秒
- [ ] `java -version` 都有输出且版本一致
- [ ] 防火墙/SELinux 已关（实验环境）
- [ ] 每个组件的配置文件里 `broker.id`/`myid`/`node.name` **各不相同**
- [ ] 启动顺序：ZK → HDFS → YARN/Spark/HBase → Kafka
- [ ] `jps` 逐台检查进程齐不齐
- [ ] 关集群顺序与启动相反

## 10.10 常见坑

1. `jps` 里少了某个进程 → 去对应 `logs/` 看第一个 ERROR，九成是配置项拼错或端口被占。
2. 集群只有一台能起 → 检查 `myid`/`broker.id` 是否重复。
3. `Connection refused` 连 ZK：`zookeeper.connect` 写了 `localhost`，其他机器连不上。
4. 内存不足：单机跑 5 个组件，每个 JVM 给 512M～1G，8G 内存起步。
5. 时间不同步导致选主失败、Token 过期，装完系统先校时再装集群。
