# 07 时间、网络与主机

## 7.1 日期与时区

```bash
date                          # 2026年 11月 02日 星期一 22:40:00 CST
date +"%Y-%m-%d %H:%M:%S"     # 自定义格式
date -d "yesterday" +%F       # 昨天
timedatectl                   # 时间、时区、NTP 同步状态
timedatectl set-timezone Asia/Shanghai
```

| 格式符 | 含义 |
| --- | --- |
| `%Y` `%m` `%d` | 年 月 日 |
| `%H` `%M` `%S` | 时 分 秒 |
| `%F` | 等价 `%Y-%m-%d` |
| `%T` | 等价 `%H:%M:%S` |
| `%s` | 时间戳（秒） |

服务器时间错会导致证书校验失败、日志对不上、定时任务乱跑；装完系统先 `timedatectl` 看一眼。

## 7.2 IP 与主机名

```bash
ip addr                       # 所有网卡与 IP（CentOS7+ 用 ip，不再用 ifconfig）
ip a | grep "inet "
hostname                      # 当前主机名
hostnamectl set-hostname web01
cat /etc/hostname
ping -c 4 www.baidu.com       # 测连通
cat /etc/hosts                # 本地域名映射
```

`/etc/hosts` 用来做本地解析（集群里常写各节点 IP 与主机名），优先于 DNS。

## 7.3 配置固定 IP（虚拟机必备）

临时改（重启失效）：

```bash
sudo ip addr add 192.168.10.128/24 dev ens33
sudo ip route add default via 192.168.10.2
```

永久改（CentOS7，改网卡配置文件）：

```bash
sudo vi /etc/sysconfig/network-scripts/ifcfg-ens33
```

```ini
BOOTPROTO=static
ONBOOT=yes
IPADDR=192.168.10.128
NETMASK=255.255.255.0
PREFIX=24
GATEWAY=192.168.10.2
DNS1=114.114.114.114
```

```bash
sudo systemctl restart network     # 生效
ip addr show ens33
```

Ubuntu 用 netplan（`/etc/netplan/*.yaml`）+ `sudo netplan apply`。

坑：虚拟机用 DHCP 时 IP 会变，SSH 连接就断了，所以要配静态 IP。

## 7.4 下载：wget 与 curl

```bash
wget https://example.com/file.tar.gz
wget -O app.tar.gz https://example.com/file.tar.gz   # 改名
wget -c https://example.com/big.iso                  # 断点续传
wget -r -np https://example.com/docs/                # 整站抓取（慎用）

curl -LO https://example.com/file.tar.gz             # -L 跟随跳转，-O 用远程名
curl -o app.tar.gz https://example.com/dl/1
curl -I https://example.com                          # 只看响应头
curl -X POST -d '{"q":1}' -H "Content-Type: application/json" https://api/x
```

| 工具 | 适合 |
| --- | --- |
| `wget` | 下文件、续传、整站 |
| `curl` | 调接口、看响应头、发 POST |

## 7.5 端口

```bash
ss -tulnp                    # 所有监听端口与进程（推荐）
netstat -tulnp               # 老写法，需装 net-tools
ss -tulnp | grep 3306        # 看 MySQL 端口
lsof -i :8080                # 谁占了 8080
```

| 参数 | 含义 |
| --- | --- |
| `-t` | TCP |
| `-u` | UDP |
| `-l` | 只看监听 |
| `-n` | 数字显示（不解析服务名） |
| `-p` | 显示进程 |

防火墙（CentOS7 用 firewalld）：

```bash
firewall-cmd --list-ports
sudo firewall-cmd --add-port=8080/tcp --permanent
sudo firewall-cmd --reload
```

坑：服务本地能访问、外面连不上，九成是防火墙或云厂商安全组没放行端口。

## 7.6 常见坑

1. `ifconfig` 在新系统里可能没装，用 `ip addr`。
2. 改完 IP 忘了 `systemctl restart network`，白改。
3. `ss -tulnp` 看不到进程名是权限不够，加 `sudo`。
4. 时间不同步会让 `yum` 校验失败（证书时间错），先校时。
5. `/etc/hosts` 写错会导致本机域名解析异常，改完 `ping 主机名` 验证。
