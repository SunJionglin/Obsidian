## 3 · 二分左边界

```cpp
int lower_bound_idx(int a[], int l, int r, int x) {
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] < x) l = mid + 1;
        else r = mid;
    }
    return l;
}
```

## 4 · 二分答案

```cpp
int lo = 下界, hi = 上界;              // 保证 lo 可行 / hi 不可行按题意定
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (check(mid)) hi = mid;          // 求最小可行
    else lo = mid + 1;
}
// 求最大可行：check 成立则 lo = mid，mid 用 (lo+hi+1)/2
```

## 7 · BFS（网格）

```cpp
int dx[4] = {1,-1,0,0}, dy[4] = {0,0,1,-1};
queue<pair<int,int>> q;
dist[sx][sy] = 0; q.push({sx, sy});
while (!q.empty()) {
    auto [x, y] = q.front(); q.pop();
    for (int k = 0; k < 4; ++k) {
        int nx = x + dx[k], ny = y + dy[k];
        if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
        if (dist[nx][ny] != -1 || g[nx][ny] == 障碍) continue;
        dist[nx][ny] = dist[x][y] + 1;
        q.push({nx, ny});
    }
}
```

## 9 · 考前检查清单（每次提交前扫一眼）

- [ ] 数组开够了吗？（`n+2`，不是 `n`）
- [ ] 会溢出的地方用 `long long` 了吗？（乘法、累加）
- [ ] 多组数据：每组都要清空数组 / 队列
- [ ] 边界：`n=1`、全相同、全逆序、空输入
- [ ] 输出格式：换行、空格、小数位
- [ ] 递归深度：>1e5 改迭代
