# 09 迭代协议与生成器

> 对应分P：P40–P42

## 一、这一篇要掌握什么

- 可迭代对象 vs 迭代器（有 `__iter__` 不一定有 `__next__`）
- `for` 循环背后发生了什么
- 生成器函数（`yield`）与生成器表达式
- 为什么生成器省内存
- 生成器的双向通信：`send` / `throw` / `close` / `yield from`
- `itertools` 常用工具

## 二、三个概念

```python
lst = [1, 2, 3]
it = iter(lst)          # 拿到迭代器
next(it)                # 1
next(it)                # 2
next(it)                # 3
next(it)                # StopIteration
```

| 概念 | 要求 | 例子 |
| --- | --- | --- |
| 可迭代对象 | 实现了 `__iter__` | list、dict、str、文件对象 |
| 迭代器 | 实现 `__iter__` + `__next__` | `iter(list)` 返回的那个 |
| 生成器 | 用 `yield` 的函数 / 生成器表达式 | `(x*x for x in range(3))` |

`for x in obj` 等价于：`it = iter(obj)` → 反复 `next(it)` → 捕获 `StopIteration` 结束。

## 三、生成器函数

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        yield a              # 每次产出后挂起，下次从这继续
        a, b = b, a + b

list(fib(5))    # [0, 1, 1, 2, 3]
```

生成器是**惰性**的：不调用 `next` 就不算；算过的不会保存，所以只能遍历一次。

## 四、生成器表达式

```python
gen = (x * x for x in range(10**6))   # 立即返回，不占内存
sum(gen)                              # 边算边加

# 对比列表推导：一次性算完并占内存
lst = [x * x for x in range(10**6)]
```

| 写法 | 内存 | 能否重复遍历 |
| --- | --- | --- |
| 列表推导 `[...]` | 全量 | 能 |
| 生成器 `(...)` | 一个元素 | 不能 |
| `yield` 函数 | 一个元素 | 不能 |

## 五、生成器的双向通信：send / throw / close / yield from

`yield` 不只能往外吐值，它还是个**表达式**，能把外面的值收进来：

```python
def averager():
    total, count, avg = 0.0, 0, None
    while True:
        x = yield avg          # 挂起时把 avg 交给调用方；恢复时把 send 的值给 x
        if x is None:
            break
        total += x
        count += 1
        avg = total / count
    return avg                 # 返回值进 StopIteration.value

g = averager()
next(g)          # None：先跑到第一个 yield（叫「预热」）
g.send(10)       # 10.0
g.send(20)       # 15.0
try:
    g.send(None) # 结束
except StopIteration as e:
    e.value      # 15.0
```

- 第一次必须 `next(g)` 或 `g.send(None)`，否则报 `TypeError: can't send non-None value to a just-started generator`。
- `send(None)` 等价于 `next(g)`。
- 生成器函数里的 `return x` 不会把 x 返回给调用方，而是塞进 `StopIteration.value`；普通 `for` 拿不到。

`throw` 和 `close`：

```python
g.throw(ValueError("boom"))   # 二选一：在挂起点抛异常，生成器内部可以 try/except
# g.close()                   # 二选一：在挂起点抛 GeneratorExit，生成器必须退出
```

```python
def gen():
    try:
        yield 1
    except GeneratorExit:
        print("清理")
        raise                 # 不要在这里 yield
```

`yield from`：把迭代委托给另一个可迭代对象，顺带转发 `send` / `throw` / `close`，并拿到子生成器的返回值：

```python
def sub():
    yield 1
    yield 2
    return "done"

def outer():
    r = yield from sub()
    print(r)          # 'done'
    yield 3

list(outer())         # [1, 2, 3]
```

等价于手写 `for x in sub(): yield x`，但 `yield from` 还会把 `send` 送进子生成器、把异常透传过去，并保存返回值。用它把生成器串成管道：

```python
def chain(*iterables):
    for it in iterables:
        yield from it
```

**PEP 479**：生成器里显式 `raise StopIteration` 会被转成 `RuntimeError`，避免和「正常结束」混淆；要结束就 `return`。

状态查看：

```python
import inspect
inspect.getgeneratorstate(g)   # 'GEN_CREATED' / 'GEN_SUSPENDED' / 'GEN_CLOSED'
```

## 六、常见用法

```python
# 读大文件
def read_lines(path):
    with open(path, encoding="utf-8") as f:
        for line in f:
            yield line.strip()

# 管道式处理
nums = (int(x) for x in open("nums.txt"))
total = sum(n for n in nums if n > 0)
```

## 七、itertools：生成器的常用零件

| 工具 | 作用 | 例子 |
| --- | --- | --- |
| `count(start, step)` | 无限等差 | `islice(count(10, 2), 3)` → 10,12,14 |
| `cycle(it)` | 无限循环 | `cycle("AB")` → A,B,A,B… |
| `repeat(x, n)` | 重复 n 次 | `repeat("x", 3)` |
| `chain(*its)` | 首尾相接 | `chain([1,2], "ab")` |
| `islice(it, start, stop, step)` | 切迭代器 | `islice(it, 5)` 取前 5 个 |
| `groupby(it, key)` | 按 key 分组（**只合并相邻**） | 先 `sorted` 再分组 |
| `product(a, b)` | 笛卡尔积 | `product("AB", repeat=2)` |
| `permutations` / `combinations` | 排列 / 组合 | `permutations("ABC", 2)` |
| `accumulate` | 累加 / 累乘 | `accumulate([1,2,3])` → 1,3,6 |
| `pairwise` | 相邻两两配对（3.10+） | `pairwise([1,2,3])` → (1,2),(2,3) |
| `tee(it, n)` | 把一个迭代器复制成 n 份 | 两份都要遍历时 |
| `zip_longest` | 按最长补齐 | `fillvalue="-"` |

```python
from itertools import count, islice, chain, accumulate, pairwise, groupby, product

list(islice(count(10, 2), 3))          # [10, 12, 14]
list(chain([1, 2], "ab"))              # [1, 2, 'a', 'b']
list(accumulate([1, 2, 3]))            # [1, 3, 6]
list(pairwise([1, 2, 3]))              # [(1, 2), (2, 3)]

words = ["bb", "a", "ccc", "dd"]
[(k, list(g)) for k, g in groupby(sorted(words, key=len), key=len)]
# [(1, ['a']), (2, ['bb', 'dd']), (3, ['ccc'])]
```

**坑**：

- `groupby` 只合并**相邻**的相同 key，不排序会得到多段。
- `islice` 不支持负索引，也不能倒着取。
- 所有 itertools 返回的都是迭代器，**只能消费一次**。
- `tee` 不是免费的：一份被消费得多，另一份的缓冲就跟着涨。

## 八、常见坑

1. 生成器只能遍历一次，遍历完再 `for` 就是空的。
2. `len(gen)` 报错——生成器没有长度。
3. 生成器里的 `return` 会触发 `StopIteration`，值可以通过 `StopIteration.value` 拿（少用）。
4. 调试时生成器“不执行”，因为惰性；加个 `list()` 才能看到内容。
5. `send` 之前忘了预热（`next` / `send(None)`），直接 `TypeError`。
6. `close()` 之后再 `next` 只会得到 `StopIteration`，不会复活。
7. 生成器里写 `raise StopIteration` 会变成 `RuntimeError`（PEP 479），要结束用 `return`。
8. 把同一个生成器传给两个消费者，后一个只能拿到剩下的元素。
