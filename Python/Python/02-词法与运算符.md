# 02 词法与运算符

## 2.1 标识符与命名

```python
name = "a"
_name = 1          # 约定：内部使用
__private = 2      # 类里会触发名字改写（见 13 篇）
名字 = "中文变量"   # 合法（PEP 3131），但不推荐
```

规则：字母/下划线开头，后接字母、数字、下划线；大小写敏感；不能用关键字。

| 命名 | 约定 |
| --- | --- |
| `lower_snake` | 变量、函数、模块 |
| `UpperCamel` | 类 |
| `UPPER_SNAKE` | 常量 |
| `_x` | 内部用 |
| `__x` | 类内私有（名字改写） |
| `__x__` | 魔术方法/特殊属性，别自创 |

## 2.2 关键字表（35 个）

```
False None True and as assert async await break class continue def del
elif else except finally for from global if import in is lambda nonlocal
not or pass raise return try while with yield
```

**软关键字**（只在特定位置有意义，可当变量名）：`match`、`case`、`type`、`_`。

## 2.3 字面量

| 类型 | 写法 | 说明 |
| --- | --- | --- |
| 整数 | `42`、`1_000_000`、`0b1010`、`0o17`、`0xFF` | 下划线是分隔符，不进值 |
| 浮点 | `3.14`、`1e-3`、`.5`、`5.` | 科学计数、省略整数/小数部分都合法 |
| 复数 | `1+2j`、`3j` | `j` 是虚部单位 |
| 字符串 | `'a'`、`"a"`、三引号、`r"\d"`、`b"a"` | 三引号可跨行；`r` 不转义；`b` 是 bytes |
| 布尔 | `True` / `False` | 首字母大写 |
| 空值 | `None` | 全局只有一个 None 对象 |
| 序列 | `[1,2]`、`(1,2)`、`{1,2}`、`{"a":1}` | 列表 / 元组 / 集合 / 字典 |
| 省略号 | `...` | `Ellipsis`，类型注解里常见 |

**f-string**（3.6+）：`f"{x:.2f}"`，可嵌表达式；`f"{x=}"` 调试时直接打印 `x=值`。

## 2.4 注释与文档字符串

```python
# 单行注释，到行尾
x = 1  # 行尾注释

def f():
    """文档字符串：函数体第一行的字符串，help() 能看到"""
    ...
```

注释写「为什么」，代码表达「做什么」；文档字符串写参数、返回值、异常。

## 2.5 语句、缩进与续行

```python
a = 1; b = 2          # 一行多句（不推荐）

total = 1 + \
        2             # 显式续行

total = (1 +          # 括号内隐式续行（推荐）
         2)
```

规则：缩进一律 4 个空格，同一文件内必须一致；**混用 Tab 与空格会 `TabError`**；复合语句以冒号结尾，下一行必须缩进。

## 2.6 运算符优先级（高 → 低）

| 级别 | 运算符 | 说明 |
| --- | --- | --- |
| 1 | `( )` `[ ]` `{ }` | 括号、字面量 |
| 2 | `x[k]` `x(args)` `x.attr` | 下标 / 调用 / 属性 |
| 3 | `**` | 幂（右结合） |
| 4 | `+x` `-x` `~x` | 一元 |
| 5 | `*` `/` `//` `%` `@` | 乘、除、整除、取模、矩阵乘 |
| 6 | `+` `-` | 加减 |
| 7 | `<<` `>>` | 移位 |
| 8 | `&` | 按位与 |
| 9 | `^` | 按位异或 |
| 10 | `\|` | 按位或 |
| 11 | `in` `not in` `is` `is not` `<` `<=` `>` `>=` `!=` `==` | 比较、成员、身份（可链式） |
| 12 | `not x` | 逻辑非 |
| 13 | `and` | 逻辑与（短路） |
| 14 | `or` | 逻辑或（短路） |
| 15 | `if ... else ...` | 条件表达式 |
| 16 | `lambda` | 匿名函数 |
| 17 | `:=` | 海象赋值 |
| 18 | `,` | 表达式分隔 |
| 19 | `+=` `-=` `*=` `/=` `//=` `%=` `**=` `&=` `\|=` `^=` `>>=` `<<=` `=` | 赋值（右结合） |

记忆要点：**`not` 比 `and` 低、`and` 比 `or` 低**（`a or b and c` 是 `a or (b and c)`）；**比较可链式**：`0 < x < 10` 等价于 `0 < x and x < 10`，且 `x` 只求值一次。

## 2.7 特殊运算与语义

```python
# 短路求值：返回「决定结果的那个操作数」，不是布尔值
"" or "默认值"        # '默认值'
0 and 1              # 0
x = [] or [1]        # [1]

# 海象运算符（3.8+）
if (n := len(data)) > 10:
    print(n)

# 解包
a, *rest = [1, 2, 3]
merged = {**d1, **d2}
nums = [*a, *b]

# 身份与成员
x is None            # 判 None 只用 is
"a" in "cat"         # 成员判断
```

## 2.8 真值规则

| 值 | 真假 |
| --- | --- |
| `0`、`0.0`、`0j`、`Decimal("0")` | 假 |
| `""`、`b""` | 假 |
| `[]`、`()`、`{}`、`set()` | 假 |
| `None`、`False` | 假 |
| 其他（含 `"0"`、`[0]`、`-1`） | 真 |

`"0"` 和 `[0]` 都是真，这是新手最常翻车的地方。

## 2.9 常见陷阱

1. `is` 比较身份、`==` 比较值：`[] is []` 为 False，`1 is 1` 为 True 只是小整数缓存。
2. Python 没有隐式类型转换：`"1" + 1` 直接 `TypeError`。
3. 链式比较不是「两两独立」：`x < 10 > y` 是 `x < 10 and 10 > y`。
4. `a += b` 对 list 是原地扩展（`a` 变），对 tuple/str 是重新绑定。
5. `if x = 1` 是语法错，赋值不能出现在表达式里（除 `:=`）。
6. `*` 对 str/list 是重复、对数字是乘法，语义随类型走。
