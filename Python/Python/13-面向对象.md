## 二、类与对象

```python
class Dog:
    species = "犬科"                 # 类属性，所有实例共享

    def __init__(self, name, age):   # 构造函数
        self.name = name             # 实例属性
        self.age = age

    def bark(self):                  # 实例方法，第一个参数是 self
        return f"{self.name} 汪汪"

d = Dog("豆豆", 3)
d.bark()          # '豆豆 汪汪'
d.age = 4         # 改实例属性
```

- `self` 就是「这个对象自己」，不用传，Python 自动给。
- 类属性改了对所有实例可见；实例属性只属于那个对象。
- `__del__` 是析构，别依赖它做清理（执行时机不确定），用 `with` 或 `try/finally`。

## 三、封装

```python
class Account:
    def __init__(self):
        self.__balance = 0            # 双下划线：名字被改写为 _Account__balance

    def deposit(self, n):
        if n <= 0:
            raise ValueError("金额必须为正")
        self.__balance += n

    @property
    def balance(self):                # 只读属性
        return self.__balance
```

Python 没有真正的私有，靠约定：`_x` 表示「别碰」，`__x` 会名字改写。

## 四、继承与多态

```python
class Animal:
    def speak(self):
        return "..."

class Cat(Animal):
    def speak(self):                  # 重写
        return "喵"

class Kitten(Cat):
    def __init__(self, name):
        super().__init__()            # 调父类
        self.name = name

for a in (Animal(), Cat(), Kitten("小")):
    print(a.speak())                  # 多态：各调各的
```

`isinstance(x, Animal)` 认子类；`type(x) is Animal` 不认。判断类型优先用 `isinstance`。

### 4.1 MRO：多继承时到底调谁

**规则**　Python 用 **C3 线性化**把继承图压成一个有序列表 `Cls.__mro__`（含自己和 `object`）。查找属性/方法时沿这个列表从左到右找第一个。

C3 的合并算法：`L[C] = [C] + merge(L[父1], L[父2], ..., [父1, 父2, ...])`。`merge` 每次取第一个列表的表头，若它没出现在**其它任何列表的尾部**就取出，否则跳过这个列表看下一个。

```python
class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass

[c.__name__ for c in D.__mro__]   # ['D', 'B', 'C', 'A', 'object']
```

推导：`L[D] = D + merge([B,A,object], [C,A,object], [B,C])` → 取 `B`（不在任何尾部）→ 取 `C` → 取 `A` → `object`。

**`super()` 不是「父类」，是「MRO 里的下一个」**：

```python
class A:
    def hi(self): return "A"
class B(A):
    def hi(self): return "B" + super().hi()
class C(A):
    def hi(self): return "C" + super().hi()
class D(B, C):
    def hi(self): return "D" + super().hi()

D().hi()          # 'DBCA'：B 里的 super() 跳到 C，不是跳到 A
```

**协作式多继承**：每个 `__init__` 都收 `**kwargs` 并继续往上交，保证一条链上每个类只初始化一次：

```python
class A:
    def __init__(self, **kw):
        print("A", kw)
        super().__init__(**kw)        # 最后到 object，kw 必须已经清空

class B(A):
    def __init__(self, x, **kw):
        print("B", x)
        super().__init__(**kw)

class C(A):
    def __init__(self, y, **kw):
        print("C", y)
        super().__init__(**kw)

class D(B, C):
    pass

D(x=1, y=2)       # B 1 → C 2 → A {}
```

坑：谁都不 `pop` 参数，`object.__init__` 收到多余关键字会 `TypeError`。正确做法是「谁声明谁消费」：把用掉的参数从 `kw` 里去掉，再 `super().__init__(**kw)`。

**MRO 冲突**：父类顺序写反会直接建类失败：

```python
class A: pass
class B(A): pass
class D(A, B): pass   # TypeError: Cannot create a consistent MRO for bases A, B
```

**Mixin**：小功能类放前面、主类放最后，例如 `class User(JsonMixin, LogMixin, Base)`；Mixin 通常不写 `__init__`，只提供方法。

## 五、抽象基类 ABC

**解决什么问题**　接口约定靠口头说「子类必须实现 area」，漏写要等运行时才炸。ABC 把这条约定写进类里，**实例化时**就检查。

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self) -> float: ...

    @property
    @abstractmethod
    def name(self) -> str: ...       # 抽象属性：@property 在外，@abstractmethod 在内

class Circle(Shape):
    def __init__(self, r): self.r = r
    def area(self): return 3.14159 * self.r ** 2
    @property
    def name(self): return "circle"

Shape()          # TypeError: Can't instantiate abstract class Shape
Circle(2).area() # 12.56636
```

- 只要还有一个抽象方法没实现，子类也不能实例化；全实现了才能建对象。
- ABC 可以有普通方法、类属性、`__init__`，子类照常 `super().__init__()`。
- `Shape.register(Triangle)` 能把不相关的类登记为「虚拟子类」，`isinstance` 会认，但不继承任何实现——框架里常见，自己写代码少用。
- 标准库的 `collections.abc.Sequence` / `Mapping` 就是 ABC；自定义容器继承它们，能免费拿到 `__contains__`、`index` 等混入方法。

**ABC vs Protocol**：ABC 要求**显式继承**（nominal），Protocol 只看「有没有这几个方法」（structural）。要运行时报错用 ABC，要静态检查鸭子类型用 Protocol（写法见 [[08-函数与作用域]] 的类型注解一节）。

## 六、dataclass：少写样板代码

**解决什么问题**　只有数据的类，`__init__` / `__repr__` / `__eq__` 全是重复劳动。`@dataclass` 读类里的**类型注解**，自动生成这些方法。

```python
from dataclasses import dataclass, field, asdict, replace

@dataclass
class User:
    name: str
    age: int = 0
    tags: list[str] = field(default_factory=list)   # 可变默认值必须用工厂

u = User("小明")
u == User("小明")          # True，自动生成 __eq__
print(u)                  # User(name='小明', age=0, tags=[])
asdict(u)                 # {'name': '小明', 'age': 0, 'tags': []}
replace(u, age=18)        # 新对象，age=18
```

| 参数 | 作用 |
| --- | --- |
| `frozen=True` | 不可变；自动生成 `__hash__`，能进 set / 当 dict 键 |
| `order=True` | 生成 `< <= > >=`，按字段声明顺序比较 |
| `slots=True` | 3.10+，生成 `__slots__`，省内存、禁止动态加属性 |
| `kw_only=True` | 3.10+，字段只能关键字传参，继承时不怕默认值顺序 |
| `eq=False` | 不生成 `__eq__`，按 `id` 比较 |

```python
@dataclass(frozen=True)
class Point:
    x: int
    y: int

p = Point(1, 2)
p.x = 3          # FrozenInstanceError
hash(p)          # 可哈希
```

**坑**：

1. `tags: list = []` 直接报 `ValueError: mutable default ... use default_factory`；写 `field(default_factory=list)`。
2. dataclass **不做类型校验**，`User(123)` 照样能建；要校验得自己写 `__post_init__`，或用 pydantic。
3. 继承时「父类有默认值、子类加无默认值字段」会报 `non-default argument follows default argument`；给子类加 `kw_only=True`，或给所有字段都加默认值。
4. `frozen=True` 是**浅冻结**：字段指向的 list 仍然能 `append`。
5. 字段要靠 `__post_init__` 做派生计算；`InitVar` 用于「只传、不进字段」的初始化参数。

## 七、Enum：给常量起名字

**解决什么问题**　`status = 1` 这种魔法数字，读代码的人不知道 1 是什么，还容易传错。Enum 把「一组固定取值」变成一个类型。

```python
from enum import Enum, IntEnum, auto, unique

@unique                       # 有重复值直接报错
class Color(Enum):
    RED = 1
    GREEN = 2
    BLUE = auto()             # 自动编号 3

Color.RED.name                # 'RED'
Color.RED.value               # 1
Color(1) is Color.RED         # True，成员是单例
list(Color)                   # [Color.RED, Color.GREEN, Color.BLUE]
Color.RED == 1                # False：Enum 不跟裸值相等
Color["RED"]                  # 按名字取
```

| 变体 | 区别 | 什么时候用 |
| --- | --- | --- |
| `Enum` | 成员不是 int，不能直接当数字算 | 纯枚举、状态机 |
| `IntEnum` | 是 int 子类，能比较、能当索引 | 要跟 C 接口/旧代码互操作 |
| `StrEnum` | 3.11+，是 str 子类 | 要直接当字符串用 |
| `Flag` / `IntFlag` | 支持按位或、按位与组合 | 权限位、选项位 |

**坑**：

- 同值不同名是**别名**，遍历只出现第一个；不想要别名就加 `@unique`。同一个类里不能出现两个同名成员（后一个会覆盖前一个）。
- 枚举成员不能比大小（`Color.RED < Color.GREEN` 报错）；要排序用 `IntEnum`，或按 `.value` 排。
- JSON 不认识 Enum，序列化要写 `.value`；反序列化用 `Color(data["color"])`。
- 已经带成员的 Enum 不能再被继承。

## 八、静态方法与类方法

```python
class Math:
    @staticmethod
    def add(a, b):        # 不需要 self / cls
        return a + b

    @classmethod
    def name(cls):        # 第一个参数是类，常用于备用构造
        return cls.__name__
```

| 方法 | 第一个参数 | 什么时候用 |
| --- | --- | --- |
| 实例方法 | `self` | 要操作对象状态 |
| 类方法 | `cls` | 操作类本身、写工厂方法 |
| 静态方法 | 无 | 纯工具函数，放类里只是归类 |

## 九、单例与魔法方法

```python
class Config:
    _inst = None
    def __new__(cls, *a, **kw):
        if cls._inst is None:
            cls._inst = super().__new__(cls)
        return cls._inst

class Point:
    def __init__(self, x, y): self.x, self.y = x, y
    def __str__(self):  return f"({self.x},{self.y})"     # print 时用
    def __repr__(self): return f"Point({self.x},{self.y})" # 调试时用
    def __eq__(self, o): return (self.x, self.y) == (o.x, o.y)
    def __len__(self): return 2
```

## 十、常见坑

1. 类属性若是可变对象（`lst = []`），所有实例共享，容易踩。
2. `super().__init__()` 忘了调用 → 父类初始化没跑。
3. `__eq__` 写了最好一起写 `__hash__`，否则对象不能进 set/dict。
4. `isinstance` 比 `type(x) == T` 更合适（能认子类）。
5. 多继承里 `super()` 指 MRO 的下一个，不是「父类」；协作式 `__init__` 要把 `**kwargs` 一路交干净。
6. `frozen=True` 只冻结字段绑定，字段里的 list/dict 还能改；要真正只读得用 tuple/frozenset 或自定义。
7. `Enum` 成员不等于它的值，比较/入库/发 JSON 前先想清楚用成员还是 `.value`。
