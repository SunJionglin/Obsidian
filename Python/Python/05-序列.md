# 05 序列：list、tuple、range

> 在知识树里的位置：内置类型 → 序列。[[04-字符串]] 讲「不可变的字符序列」，
> 这篇讲 list（可变）、tuple（不可变）、range（惰性等差数列）三种序列；
> dict / set 见 [[06-映射与集合]]。学完要闭卷自测，用 [[Day 3]] 的 12 问。

## 一、list 到底是什么：动态数组

**规则**　list 是**可变、有序、可重复**的序列，底层是**连续内存上的指针数组**（动态数组），元素本身不放在列表里，列表存的是指向元素的引用。

**为什么需要它**　字符串存不了会变的集合、dict 无序，list 是「按位置访问 + 随时增删 + 什么都能装」的唯一解，接口返回值几乎都是它。

**代价**（决定了后面所有复杂度结论）：

| 操作 | 复杂度 | 原因 |
| --- | --- | --- |
| `a[i]` 读/写 | $O(1)$ | 起点地址 + i × 指针宽度，一步算出来 |
| `append` / `pop()` | 均摊 $O(1)$ | 尾部追加；容量不够时整体搬家，但按倍数扩容，均摊下来是常数 |
| `insert(i, x)` / `pop(0)` | $O(n)$ | 插入点之后的元素要整体后移/前移 |
| `x in a` / `a.index(x)` / `a.remove(x)` | $O(n)$ | 没有索引，只能从头逐个比 |
| 切片 `a[i:j]` | $O(k)$ | $k$ 是结果长度，要复制 $k$ 个引用 |

> 一句话：**尾部快、头部慢、按值找慢、按下标快**。所有「list 当查找表用导致上线变慢」的事故，都是忘了最后一条。

## 二、增：append / insert / extend

```python
a = [1, 2, 3]
a.append(4)          # [1,2,3,4]      尾部加「一个」元素
a.insert(1, 9)       # [1,9,2,3,4]    在下标 1 前插入，后面整体后移
a.extend([5, 6])     # [1,9,2,3,4,5,6] 把可迭代对象「拆开」逐个加到尾部
a += [7, 8]          # 等价于 extend（注意不是 append）
```

**append 与 extend 的区别（必考）**：`a.append([2,3])` → `[1,[2,3]]`，参数被当成一个整体；`a.extend([2,3])` → `[1,2,3]`，参数被拆开逐个加。`insert` 下标超长等价于 append，`insert(-1, x)` 插在最后一个元素**之前**。

> **坑**　`a += b` 对 list 是原地 extend（`id` 不变），`a = a + b` 才新建列表；前者在函数里改到了外部，见 [[08-函数与作用域]]。

## 三、删：pop / remove / del / clear

| 写法 | 参数 | 删什么 | 返回值 | 找不到时 |
| --- | --- | --- | --- | --- |
| `a.pop()` | 无 | 最后一个 | 被删的元素 | 空列表时 `IndexError` |
| `a.pop(i)` | 索引 | 下标 i | 被删的元素 | `IndexError` |
| `a.remove(x)` | **值** | 第一个等于 x 的元素 | `None` | `ValueError` |
| `del a[i]` | 索引 | 下标 i | 无 | `IndexError` |
| `del a[i:j]` | 切片 | 一段 | 无 | 不报错（越界自动截断） |
| `a.clear()` | 无 | 全部 | `None` | — |

```python
a = [10, 20, 30, 20]
a.remove(20)     # [10, 30, 20]  只删第一个
a.pop(0)         # 返回 10，a 变 [30, 20]
del a[0]         # [20]
```

**三条边界**：

1. `remove` 按值找（找不到 `ValueError`），`pop`/`del` 按下标（越界 `IndexError`）——报错类型就是「值 vs 下标」的体现。
2. 在 `for` 循环里删元素会**跳过元素**：删掉下标 i 后后面整体前移，下一轮 i+1 就跳过了原 i+1。要删多个，用推导式重建或倒序遍历。
3. `del a` 删的是**变量名**（解除绑定），`a.clear()` 才清空内容；还有别的变量指向同一列表时结果完全不同。

## 四、查：index / in / count / len

```python
a = [1, 2, 3, 2]
a.index(2)        # 1        第一个 2 的下标；找不到 ValueError
a.index(2, 2)     # 3        从下标 2 开始找
a.count(2)        # 2        出现次数
2 in a            # True     成员判断，O(n)
len(a)            # 4
```

- `in` 和 `index` 都是 $O(n)$ 线性扫描；判断「在不在」高频发生时，换 `set`（$O(1)$），见 [[02-哈希与集合]]。
- `count` 也是 $O(n)$，要统计全部元素的频次，用 `collections.Counter(a)` 一次扫描搞定。
- `index` 只返回**第一个**匹配位置，要找全部位置得自己循环 + `enumerate`。

## 五、改：下标赋值与切片赋值

```python
a = [0, 1, 2, 3, 4]
a[0] = 9              # [9,1,2,3,4]        单点改，长度不变
a[1:3] = [7, 8]       # 等长替换
a[1:3] = [7]          # [9,7,3,4]          删 2 个插 1 个 → 长度变短
a[1:3] = [7, 8, 9]    # 长度变长
a[2:2] = [5, 5]       # 在 2 号位前插入（空切片 = 纯插入）
a[1:3] = []           # 等价于 del a[1:3]
```

**规则**　不带步长的切片赋值 = 「先把这段删掉，再把右边的可迭代对象拆开插进去」，所以**长度可以任意变**。

**带步长的切片赋值必须等长**：

```python
a = [0, 1, 2, 3, 4]
a[::2] = [9, 9, 9]    # [9,1,9,3,9]   左边 3 个位置，右边 3 个元素 ✓
a[::2] = [9]          # ValueError: attempt to assign sequence of size 1 to extended slice of size 3
```

原因：步长切片选中的是**离散的固定位置**，无法像连续区间那样「腾出空间」；Python 只能一对一替换，所以长度必须相等。

## 六、切片：a[1:4]、a[:3]、a[::2]、a[::-1]

**语法**　`a[start:stop:step]`，三个都可以省，规则只有一条：**左闭右开**，取 `start, start+step, ...`，直到不满足 `< stop`（step 为正）或 `> stop`（step 为负）。

```python
a = [0, 1, 2, 3, 4, 5]
a[1:4]      # [1, 2, 3]         含 1 不含 4
a[:3]       # [0, 1, 2]         省略 start = 从头
a[3:]       # [3, 4, 5]         省略 stop = 到尾
a[::2]      # [0, 2, 4]         步长 2
a[1::2]     # [1, 3, 5]         从 1 开始，隔一个取一个
a[::-1]     # [5, 4, 3, 2, 1, 0] 负步长 = 反转（注意包含下标 0）
a[-2:]      # [4, 5]            负数下标从右数
a[-1:-4:-1] # [5, 4, 3]         负步长时 start 在右、stop 在左
```

**越界会怎样（这是 list 切片最反直觉的一点）**：

| 写法 | 结果 | 说明 |
| --- | --- | --- |
| `a[10:]` | `[]` | 起点越界 → 空 |
| `a[0:100]` | `[0,1,2,3,4,5]` | 终点越界 → 自动截断到末尾，**不报错** |
| `a[-100:2]` | `[0,1]` | 负起点越界 → 夹到 0 |
| `a[3:1]` | `[]` | 起点 ≥ 终点 → 空，不报错 |
| `a[10]` | `IndexError` | **单点下标**越界一定要报错 |
| `a[::0]` | `ValueError` | 步长不能为 0 |

一句话记：**切片是「箝位」（clamp），下标是「精确」**。切片表示「一段范围」，范围超出边界就取交集，所以永远合法；单点下标表示「这一个位置」，不存在就必须报错。这也是为什么分页写 `data[offset:offset+limit]` 永远不用先判断越界——最后一部分不满一页时，切片自动给你剩下的。

**切片的另外三个用途**：`b = a[:]` 浅拷贝（新列表，改 b 不影响 a）；`a[:] = []` 清空但保留变量绑定；`a[1:4] = []` 删除一段（等价于 `del a[1:4]`）。

> **坑**　`a[:]` 只复制**第一层**。元素本身是列表时，新旧列表仍指向同一批内层对象，改内层两边都变——这直接引出第七节的二维表陷阱。要连内层一起复制，用 `copy.deepcopy(a)`。

## 七、排序：sort() 原地 vs sorted() 新表

| 写法 | 改原列表？ | 返回值 | 用在 |
| --- | --- | --- | --- |
| `a.sort()` | 是 | `None` | 只关心排好后的 a，省内存 |
| `sorted(a)` | 否 | 新列表 | 还要保留原顺序 / 对任意可迭代对象排序 |

```python
a = [3, 1, 2]
a.sort()              # a 变 [1,2,3]，返回 None
b = sorted(a)         # b 是新列表，a 不变
a = a.sort()          # ✗ a 变成 None —— 最常见的错误
```

`sorted()` 能接受任何可迭代对象（tuple、生成器），`sort()` 只有 list 有。**key= 与 reverse=**：

```python
words = ["bb", "a", "ccc"]
words.sort(key=len)                  # ['a', 'bb', 'ccc']   按长度
words.sort(key=len, reverse=True)    # ['ccc', 'bb', 'a']   按长度降序

pairs = [("b", 2), ("a", 3), ("c", 1)]
pairs.sort(key=lambda p: p[1])              # 按第二项升序
pairs.sort(key=lambda p: (-p[1], p[0]))     # 第二项降序，同值时第一项升序

nums = ["10", "9", "2"]
sorted(nums)               # ['10', '2', '9']  按字符串字典序！
sorted(nums, key=int)      # ['2', '9', '10']  按数值
```

三条规则：

1. **`key` 收一个函数**，对每个元素调用一次，按返回值排序；不写 `key` 就按元素本身比。
2. **`reverse=True` 是在比较结果上取反**，不是「排完再反转」——对稳定性有影响。
3. **排序是稳定的**（Timsort）：`key` 相等的元素保持原来相对顺序。所以「多关键字排序」可以拆成多次稳定排序从次要关键字排到主要关键字，也可以像上面那样合成元组一次排完。

**边界**：数字和字符串混排会抛 `TypeError`，用 `key` 先统一类型；`a.reverse()` 原地反转、返回 `None`，`reversed(a)` 返回迭代器。

## 八、推导式：[x*2 for x in a if x > 0]

**展开式 → 推导式**（先记展开式，推导式只是它的缩写）：

```python
out = []
for x in a:              # ① for
    if x > 0:            # ② if
        out.append(x*2)  # ③ 表达式

out = [x * 2 for x in a if x > 0]   # 等价写法
```

语法三段：`[表达式 for x in 可迭代对象 if 过滤条件]`，执行顺序是「先 for、再 if、最后表达式」。

```python
nums = [1, -2, 3, -4, 5]
[x for x in nums if x > 0]                  # 去负 → [1,3,5]
[x*x for x in nums]                         # 平方
[x*x for x in nums if x > 0]                # 去负再平方
sorted([x*x for x in nums if x > 0], reverse=True)   # 去负+平方+降序

[(i, j) for i in range(2) for j in range(2)]  # 嵌套 → [(0,0),(0,1),(1,0),(1,1)]
```

边界与坑：

- **`if` 只能过滤，不能改写**；要「正数平方、负数取绝对值」用条件表达式：`[x*x if x > 0 else -x for x in nums]`（注意 `if/else` 在 `for` **前面**）。
- 推导式里别塞复杂逻辑；超过一个 `for` + 一个 `if` 就退回普通循环，可读性优先。
- 生成器表达式 `(x*2 for x in a)` 是惰性的，不建列表，大数据流用它省内存（迭代器在后续篇展开）。

## 九、二维表：[[0]*3 for _ in range(2)] 与 [[0]*3]*2

```python
bad = [[0] * 3] * 2
bad[0][0] = 1
print(bad)     # [[1, 0, 0], [1, 0, 0]]   ← 两行都变了

good = [[0] * 3 for _ in range(2)]
good[0][0] = 1
print(good)    # [[1, 0, 0], [0, 0, 0]]   ✓
```

**原因**　`*` 复制的是**引用**，不是对象。`[[0]*3] * 2` 先建了一个内层列表，再把这个内层列表的**同一个引用**放了两遍；`bad[0]` 和 `bad[1]` 指向同一块内存。而推导式每一轮都执行一次 `[0]*3`，创建的是两个独立的内层列表。

**验证方法**（比背结论可靠）：

```python
bad[0] is bad[1]     # True  ← 同一对象
good[0] is good[1]   # False ← 不同对象
```

**什么时候会踩**　建矩阵、建 DP 表、建「每个桶一个列表」的桶排序、按行分组。一旦踩了，改一格全变，而且不报错，是最难查的一类 bug。

**正确写法汇总**：

```python
[[0] * 3 for _ in range(2)]                 # 2 行 3 列
[[0] * cols for _ in range(rows)]           # 通用
[[] for _ in range(n)]                      # n 个独立的空桶
```

> 顺带：`[0] * 3` 本身没问题——0 是不可变对象，复制引用无副作用。**只有元素是可变对象（list/dict/set）时，`*` 才会出问题**。`[[]] * 3` 同样会三行共享。

## 十、速查表

```
增  append(x)  insert(i,x)  extend(iter)  a += iter
删  pop() pop(i)  remove(x)  del a[i]  del a[i:j]  clear()
查  index(x[,start])  count(x)  x in a  len(a)
改  a[i]=x   a[i:j]=iter   a[i:j:k]=iter（必须等长）
切  a[1:4] a[:3] a[3:] a[::2] a[::-1] a[-2:] a[10:]→[]
排  a.sort(key=..., reverse=...) → None；sorted(a, ...) → 新表
推  [f(x) for x in a if cond(x)]
二维 [[0]*m for _ in range(n)]   ✗ [[0]*m]*n
```

## 十一、常见报错（病例库）

| 报错 | 原因 | 解法 |
| --- | --- | --- |
| `ValueError: list.remove(x): x not in list` | `remove` 找不到该值 | 先 `if x in a`，或改用按值过滤重建 |
| `IndexError: pop from empty list` | 空列表 `pop()` | 先判空 |
| `ValueError: attempt to assign sequence of size ... to extended slice of size ...` | 带步长切片赋值长度不一致 | 两边长度必须相等 |
| 改一行二维表全变 | `*` 复制的是引用 | 用 `[[...] for _ in range(n)]` |

## 十二、tuple 与 range：另外两种序列

### 12.1 tuple：不可变的序列

**规则**　tuple 和 list 一样按位置索引、可切片、可遍历，但**创建后不能增删改元素**。不可变带来两个直接好处：可哈希（元素都可哈希时）、可以放心共享。

```python
t = (1, 2, 3)
t[0]            # 1
t[1:]           # (2, 3)
a, b, c = t     # 解包
x, *rest = (1, 2, 3)     # x=1, rest=[2, 3]
t + (4,)        # (1, 2, 3, 4)，新建对象，不是原地改
t * 2           # (1, 2, 3, 1, 2, 3)
```

- 函数 `return a, b` 返回的就是 tuple；多返回值、多变量赋值都靠它。
- `(1, 2)` 能当 dict 的键、能放进 set；`[1, 2]` 不行。
- 单元素元组必须写 `(1,)`；`(1)` 只是加了括号的整数。
- 「不可变」指**不能换元素**，元素本身可变时内容仍可变：`t = ([1],); t[0].append(2)` 合法。

```python
from collections import namedtuple
Point = namedtuple("Point", "x y")
p = Point(1, 2)
p.x, p.y        # 1 2，比下标可读
```

### 12.2 range：等差数列，惰性序列

**规则**　`range(start, stop, step)` 生成左闭右开区间 `[start, stop)` 的等差整数序列；只存 start/stop/step 三个数，**不占 $O(n)$ 内存**。

```python
range(5)            # 0..4
range(2, 6)         # 2..5
range(0, 10, 3)     # 0,3,6,9
range(5, 0, -1)     # 5,4,3,2,1
len(range(0, 10, 3))    # 4
range(10)[2:5]          # range(2, 5)，切片仍返回 range
```

- 支持 `len()`、下标、切片、整数 `in`（等差数列可 $O(1)$ 判断），但**不支持** `append`。
- `print(range(3))` 输出 `range(0, 3)`，不是 `[0, 1, 2]`；要看内容用 `list(range(3))`。
- 坑：`range(10, 0)` 是空的（默认 step=+1）；想倒序必须写 `range(10, 0, -1)`；右端永远取不到。

### 12.3 三种序列怎么选

| 序列 | 可变 | 内存 | 适合 |
| --- | --- | --- | --- |
| `list` | 是 | 存指针数组 | 需要增删改、当工作区 |
| `tuple` | 否 | 同 list，但可共享 | 固定记录、当键、函数返回多值 |
| `range` | 否 | 只存 3 个数 | 循环计数、生成连续整数，别先 `list()` |

> 判断标准：**要改 → list；要当键/要保护 → tuple；只是数数 → range。** dict / set 的取舍见 [[06-映射与集合]]。
