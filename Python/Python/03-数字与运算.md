# 03 数字与运算

## 3.1 四种内置数值类型

| 类型 | 例子 | 精度 | 用途 |
| --- | --- | --- | --- |
| `int` | `10**100` | 任意精度，无上限 | 计数、索引、大整数 |
| `float` | `3.14` | IEEE 754 双精度（约 15–17 位十进制有效数字） | 科学计算、一般小数 |
| `complex` | `1+2j` | 两个 float | 信号处理、数学 |
| `bool` | `True` / `False` | 就是 0 / 1 | 条件判断 |

另有标准库的 `decimal.Decimal`（十进制精确）与 `fractions.Fraction`（分数精确）。

## 3.2 int：任意精度

```python
2 ** 100                 # 1267650600228229401496703205376，不溢出
(10 ** 18).bit_length()  # 60
int("ff", 16)            # 255，按进制解析
int("0b1010", 0)         # 10，base=0 自动识别前缀
int(3.9)                 # 3，向零截断（不是四舍五入）
```

代价：大整数运算比机器整数慢；`10**10000` 能算，但别在循环里反复算。

## 3.3 除法、取整与取模（含负数）

```python
7 / 2        # 3.5    真除法，结果 float
7 // 2       # 3      向下取整（floor），不是截断
-7 // 2      # -4     注意！不是 -3
7 % 2        # 1
-7 % 2       # 1      结果的符号跟「除数」一致
7 % -2       # -1
divmod(7, 2) # (3, 1)
```

规律：`a == (a // b) * b + a % b` 恒成立，这是理解负数行为的钥匙。

```python
n % 2 == 0     # 判偶
n % 10         # 取末位
n // 10        # 去掉末位
```

## 3.4 float 的三件事

**① 二进制表示**：0.1、0.2、0.3 在二进制里都是无限循环小数。

```python
0.1 + 0.2             # 0.30000000000000004
0.1 + 0.2 == 0.3      # False
```

**② 比较要用容差**：

```python
import math
math.isclose(0.1 + 0.2, 0.3)     # True，默认相对容差 1e-9
abs(a - b) < 1e-9                # 手写版
```

**③ 特殊值**：

```python
float("inf"), float("-inf"), float("nan")
math.isnan(x); math.isinf(x)
x == x          # NaN 与任何值（含自己）都不相等
```

## 3.5 round 的银行家舍入

```python
round(2.5)       # 2   不是 3！
round(3.5)       # 4
round(0.5)       # 0
round(2.675, 2)  # 2.67（因为 2.675 实际是 2.674999...）

# 想要「四舍五入」：
from decimal import Decimal, ROUND_HALF_UP
Decimal("2.5").quantize(Decimal("1"), rounding=ROUND_HALF_UP)   # 3
```

`round` 采用「四舍六入五取偶」，带 ndigits 时还受二进制表示影响。

## 3.6 Decimal 与 Fraction

```python
from decimal import Decimal, getcontext
getcontext().prec = 28
Decimal("0.1") + Decimal("0.2")     # Decimal('0.3') 精确
Decimal("1") / Decimal("3")         # 0.3333333333333333333333333333

from fractions import Fraction
Fraction(1, 3) + Fraction(1, 6)     # Fraction(1, 2)
```

用 Decimal 的场景：金额、账单、任何「必须精确到分」的计算。**用字符串构造**，`Decimal(0.1)` 会把 float 误差带进来。

## 3.7 bool 是 int 的子类

```python
True + True              # 2
isinstance(True, int)    # True
sum([True, False, True]) # 2，统计 True 的个数
```

## 3.8 位运算

```python
5 & 3     # 1    与
5 | 3     # 7    或
5 ^ 3     # 6    异或
~5        # -6   取反（结果是 -(a+1)）
1 << 10   # 1024 左移 = 乘 2**n
16 >> 2   # 4    右移 = 整除 2**n
```

Python 整数是**无限位补码**：`~5 == -6`、`-1 & 0xFF == 255`。做位掩码时记得 `& 0xFF` 截断。

常用技巧：`n & (n-1)` 去掉最低位的 1、`n & -n` 取 lowbit、`n >> 1` 等价向下取整除以 2。

## 3.9 进制与格式化

```python
bin(10), oct(10), hex(10)   # ('0b1010', '0o12', '0xa')
f"{10:b}"                   # '1010'
f"{255:#x}"                 # '0xff'
f"{0.1:.2f}"                # '0.10'
f"{1234567:,}"              # '1,234,567'
f"{0.25:.0%}"               # '25%'
```

| 格式符 | 含义 |
| --- | --- |
| `.2f` | 保留 2 位小数 |
| `e` / `.2e` | 科学计数 |
| `d` | 整数 |
| `x` / `X` / `o` / `b` | 十六 / 大写十六 / 八 / 二进制 |
| `,` | 千分位 |
| `%` | 百分比 |
| `+` / 空格 | 强制显示正负号 |
| `0>5` / `<10` / `^10` | 填充字符与对齐 |

## 3.10 常见陷阱

1. `int(3.9)` 是 3，不是 4；要四舍五入用 `round`（且记得银行家舍入）。
2. `round(2.675, 2)` 得 2.67，因为 2.675 的二进制表示略小于 2.675。
3. `10**20 / 3` 会先转 float，精度丢失；要精确用 `//` 或 Decimal。
4. `nan != nan` 为 True，判断用 `math.isnan`。
5. `-7 // 2 == -4` 但 `int(-7/2) == -3`：前者向下取整，后者向零截断。
6. `1e1000` 变成 `inf`，不报错。
