# 06 映射与集合

> 在知识树里的位置：内置类型 → 映射与集合。按位置找元素看 [[05-序列]]，
> 按**键**找值、或只想知道「在不在」看这篇。两者共用一张哈希表，
> 所以「键必须可哈希」「查找 O(1)」「遍历顺序」这些结论是同一套机制推出来的。

## 一、dict：键值映射

**规则**　dict 是**可变、按键索引、键唯一**的映射；3.7 起**保证插入顺序**（3.6 是实现巧合，3.7 写进语言规范）。键必须是**可哈希**对象，值可以是任何对象。

**为什么需要它**　list 按位置找元素是 $O(n)$；只要你能给数据起个名字（学号、单词、配置项），dict 就能用一次哈希把查找压到 $O(1)$。

```python
d = {"a": 1, "b": 2}
d["c"] = 3                  # 增 / 改（键存在就是改）
d["a"]                      # 1，键不存在抛 KeyError
d.get("z")                  # None，不抛错、不插入
d.get("z", 0)               # 0
d.setdefault("z", [])       # 不存在才插入并返回，常用于分组
d.pop("a")                  # 删并返回值；d.pop("a", None) 不抛错
del d["b"]                  # 删，不存在抛 KeyError
"b" in d                    # 判断的是「键」，不是值
d.update({"d": 4})          # 批量更新
d | {"e": 5}                # 3.9+ 合并，返回新 dict（|= 原地）
{**d1, **d2}                # 合并，后者覆盖前者
```

遍历：

```python
for k in d: ...                 # 等价于 d.keys()
for k, v in d.items(): ...      # 最常用
for v in d.values(): ...
list(d)                         # 键的列表，保持插入序
```

**复杂度**：

| 操作 | 平均 | 最坏 | 说明 |
| --- | --- | --- | --- |
| `d[k]` 读 / 写 | $O(1)$ | $O(n)$ | 哈希冲突极端时退化 |
| `k in d` | $O(1)$ | $O(n)$ | 只算哈希，不比 value |
| `del d[k]` | $O(1)$ | $O(n)$ | |
| 遍历 | $O(n)$ | $O(n)$ | 按插入序 |

**坑**：

- `d["z"]` 不存在抛 `KeyError`，查询用 `get`。
- 遍历时增删键会抛 `RuntimeError: dictionary changed size during iteration`；先 `list(d.items())` 再改。
- `1`、`1.0`、`True` 哈希值相同且相等，在 dict 里是**同一个键**。
- `d.get(k, [])` 每次都给一个新的空列表，拿它 `append` 不会存回 dict；要存回用 `setdefault`。

## 二、哈希表与「可哈希」

dict / set 的底层都是**哈希表**：先算 `hash(key)` 得到一个整数，用它定位桶；桶里再用 `==` 确认是不是同一个键。

```python
hash("abc")          # 每次进程启动可能不同（字符串哈希随机化，防哈希洪水）
hash((1, 2))         # 元组可哈希，前提是元素都可哈希
hash([1, 2])         # TypeError: unhashable type: 'list'
```

**可哈希的三个条件**（口语版）：

1. 生命周期内哈希值不变（所以可变对象不行）；
2. 可比较相等（`__eq__`）；
3. 相等对象的哈希值必须相同。

| 类型 | 可哈希 | 原因 |
| --- | --- | --- |
| `int` / `float` / `str` / `bytes` | 是 | 不可变 |
| `tuple` | 是（元素都可哈希时） | 不可变容器 |
| `frozenset` | 是 | 不可变集合 |
| `list` / `dict` / `set` | 否 | 可变，改了就找不到原来的桶 |

**自定义对象**：默认按 `id()` 哈希；一旦你定义了 `__eq__` 而没定义 `__hash__`，Python 会把 `__hash__` 置为 `None`，对象立刻不可哈希——这是故意的，防止「相等但哈希不同」。

**冲突处理**：CPython 用开放寻址（探测下一个空槽），装载率到阈值（dict 约 2/3、set 约 3/5）就扩容重建。所以「最坏 $O(n)$」在正常数据下不会出现，但**别用精心构造的冲突键做攻击面**。

## 三、set 与 frozenset

**规则**　set 是**可变、无序、元素唯一**的哈希集合；`frozenset` 是它的不可变版本，可哈希、能当 dict 的键。

```python
s = {1, 2, 3}
s = set()                    # 空集合只能这么写，{} 是空 dict
s.add(4)
s.discard(2)                 # 不存在也不报错
s.remove(9)                  # 不存在抛 KeyError
s.pop()                      # 随机弹一个（无序，别依赖是哪个）
```

集合运算：

```python
a = {1, 2, 3}; b = {2, 3, 4}
a | b        # 并 {1,2,3,4}
a & b        # 交 {2,3}
a - b        # 差 {1}
a ^ b        # 对称差 {1,4}
a <= b       # 子集
a < b        # 真子集
a.isdisjoint(b)   # 有没有交集
```

**用途**：去重（`list(set(xs))` 会丢顺序，保序用 `dict.fromkeys(xs)`）、成员判断、两个集合的交并差、图遍历的 visited。

**坑**：

- `{}` 是空字典，不是空集合。
- set 无序，不能下标；`set` 的遍历顺序看起来稳定只是巧合。
- `list(set(xs))` 不保证原顺序；要保序去重：`list(dict.fromkeys(xs))`。
- set 里的元素同样必须可哈希，`{[]}` 直接 `TypeError`。

## 四、collections 里的专用字典

| 类型 | 一句话 | 例子 |
| --- | --- | --- |
| `defaultdict` | 键不存在时自动建默认值 | `dd = defaultdict(list); dd[k].append(v)` |
| `Counter` | 计数专用 dict | `Counter("abca")["a"] == 2`，`.most_common(3)` |
| `OrderedDict` | 显式记住顺序（3.7 后普通 dict 也有序） | 需要 `move_to_end` 时用 |
| `ChainMap` | 多个 dict 叠成一个视图 | 配置：命令行 > 环境变量 > 默认值 |

```python
from collections import defaultdict, Counter, ChainMap

dd = defaultdict(list)
for word, tag in [("apple", "n"), ("run", "v"), ("apple", "n")]:
    dd[word].append(tag)          # 不用先判断键在不在

cnt = Counter("abracadabra")
cnt.most_common(2)                # [('a', 5), ('b', 2)]

cfg = ChainMap({"debug": True}, {"debug": False, "port": 8000})
cfg["debug"]                      # True，前面的优先
```

## 五、四种容器怎么选

| 容器 | 有序 | 可重复 | 可变 | 查找 | 适合 |
| --- | --- | --- | --- | --- | --- |
| `list` | 是 | 是 | 是 | 按位置 $O(1)$，按值 $O(n)$ | 顺序存储、频繁尾部增删 |
| `tuple` | 是 | 是 | 否 | 同 list | 固定结构、当键、函数返回多值 |
| `dict` | 是（插入序） | 键唯一 | 是 | 按键 $O(1)$ | 键值映射、计数、缓存 |
| `set` | 否 | 否 | 是 | 按值 $O(1)$ | 去重、集合运算、判存在 |

一句话决策：**要顺序 → list/tuple；要名字 → dict；只要「有没有」→ set。**

## 六、可变、不可变与拷贝

```python
import copy
a = [1, [2, 3]]
b = a                 # 同一个对象，b is a
c = a[:]              # 浅拷贝：外层新，内层共享
d = copy.deepcopy(a)  # 深拷贝：完全独立

b.append(9)           # a 也变（同一对象）
c[1].append(4)        # a[1] 也变（内层共享）
d[1].append(5)        # a 不变
```

| 类型 | 可变？ | 赋值时发生什么 |
| --- | --- | --- |
| `int` / `float` / `str` / `tuple` / `frozenset` | 不可变 | 重新绑定名字，原对象不动 |
| `list` / `dict` / `set` | 可变 | 方法原地改，所有引用都看得到 |

**坑**：函数参数传的是对象引用，传 list/dict 进去改内容，外面也会变；不想改就传副本。默认参数写成 `def f(a=[])` 也会跨调用共享，见 [[08-函数与作用域]]。

## 七、常见报错（病例库）

| 报错 | 原因 | 解法 |
| --- | --- | --- |
| `KeyError: 'x'` | 用 `d["x"]` 取不存在的键 | 先 `in` 判断，或 `d.get("x", 默认值)` |
| `TypeError: unhashable type: 'list'` | 拿 list/dict/set 当键或塞进 set | 换成 tuple / frozenset，或序列化后当键 |
| `RuntimeError: dictionary changed size during iteration` | 遍历时增删键 | 先 `list(d.items())` 再改 |
| `TypeError: 'set' object is not subscriptable` | 对 set 用 `s[0]` | set 无序，先转 list 或改用 dict |
| `AttributeError: 'dict' object has no attribute 'append'` | 把 dict 当 list 用 | 用 `d[k] = v` / `setdefault` |
