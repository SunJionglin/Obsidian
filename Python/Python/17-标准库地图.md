## 二、os 与 sys

```python
import os, sys

os.getcwd()                       # 当前目录
os.listdir(".")                   # 列目录
os.makedirs("a/b", exist_ok=True) # 递归建目录
os.path.join("a", "b.txt")        # 拼路径
os.path.exists("a.txt")           # 是否存在
os.path.getsize("a.txt")          # 字节数
os.environ.get("HOME")            # 环境变量

sys.argv                          # 命令行参数（argv[0] 是脚本名）
sys.exit(0)                       # 退出码
sys.path                          # 模块搜索路径
sys.version                       # Python 版本
sys.platform                      # 'darwin' / 'linux' / 'win32'
sys.executable                    # 当前解释器路径
```

新代码优先 `pathlib.Path`，`os.path` 是老写法（见 [[14-文件与IO]]）。

## 三、time 与 datetime

```python
import time

time.time()                # 时间戳（秒，浮点）
time.sleep(1.5)            # 睡 1.5 秒
time.strftime("%Y-%m-%d %H:%M:%S")           # 格式化当前时间（本地时区）
time.strptime("2026-11-02", "%Y-%m-%d")      # 字符串 → 时间结构
time.perf_counter()        # 高精度计时，测性能用它
```

真正做日期计算用 `datetime`：

```python
from datetime import datetime, date, timedelta, timezone
from zoneinfo import ZoneInfo

now = datetime.now()                       # naive：本地时间，但不带时区
utc = datetime.now(timezone.utc)           # aware：明确 UTC
sh = datetime.now(ZoneInfo("Asia/Shanghai"))

now.strftime("%F %T")                      # 2026-11-05 23:30:00
datetime.strptime("2026-11-02 08:30", "%Y-%m-%d %H:%M")
datetime.fromisoformat("2026-11-02T08:30:00+08:00")   # 带时区偏移
datetime.fromisoformat("2026-11-02T08:30:00Z")        # 3.11+ 也认 Z

(now + timedelta(days=1)).date()           # 明天
(now - datetime(2026, 1, 1)).days          # 相差几天
int(now.timestamp())                       # naive 会按本地时区解释
datetime.fromtimestamp(0, timezone.utc)    # 1970-01-01 00:00:00+00:00

date.today()                               # 只要日期
date(2026, 11, 2).isoformat()              # '2026-11-02'
```

| 概念 | 含义 | 注意 |
| --- | --- | --- |
| naive | 不带 `tzinfo` 的 datetime | 只能当「墙上时间」，跨时区会错 |
| aware | 带 `tzinfo` 的 datetime | 能精确换算到 UTC 时间戳 |
| `timestamp()` | 距 1970-01-01 UTC 的秒数 | naive 会按**本地时区**解释 |
| `timedelta` | 时间差 | 只有天/秒/微秒，没有「月」「年」 |

**坑**：

- naive 和 aware 比较直接 `TypeError: can't compare offset-naive and offset-aware datetimes`。
- `datetime.utcnow()` 在 3.12 起弃用，用 `datetime.now(timezone.utc)`。
- 存数据库统一存 UTC，展示时再转本地时区；别存「本地时间字符串」。
- `timedelta(days=30)` 不是一个月；要按日历加月用 `dateutil.relativedelta`（第三方）。

`calendar` 处理月历：

```python
import calendar

calendar.isleap(2024)              # True
calendar.monthrange(2026, 11)      # (6, 30)：11 月 1 日是周日（0=周一），共 30 天
calendar.monthcalendar(2026, 11)   # 按周分组的二维列表，0 表示不在本月
```

## 四、shutil：文件与目录的高级操作

```python
import shutil

shutil.copy("a.txt", "b.txt")        # 内容 + 权限位
shutil.copy2("a.txt", "b.txt")       # 再保留 mtime 等元数据
shutil.copytree("src", "dst", dirs_exist_ok=True)   # 整棵树
shutil.move("a.txt", "dir/a.txt")    # 移动 / 重命名
shutil.rmtree("build", ignore_errors=True)          # 递归删除，慎用
shutil.disk_usage("/")               # (total, used, free) 字节
shutil.which("python3")              # 找可执行文件路径
shutil.make_archive("backup", "zip", "data")        # 打包
shutil.unpack_archive("backup.zip", "out")          # 解包
```

**坑**：

- `rmtree` 不校验路径，变量拼错就是灾难；删之前先 `print(path)` 并确认绝对路径。
- `copytree` 默认要求目标目录不存在；要覆盖加 `dirs_exist_ok=True`。
- `copy` 不保留 mtime，`copy2` 才保留；备份脚本通常用 `copy2`。
- 跨磁盘 `move` 是「复制 + 删除」，大文件会慢，中途失败可能留下半个文件。

## 五、logging

```python
import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(message)s",
    filename="app.log",
    encoding="utf-8",
)
logging.debug("调试信息")      # 默认不输出
logging.info("正常")
logging.warning("注意")
logging.error("出错")
```

| 级别 | 数值 | 用途 |
| --- | --- | --- |
| DEBUG | 10 | 开发期细节 |
| INFO | 20 | 正常运行 |
| WARNING | 30 | 可恢复的异常 |
| ERROR | 40 | 出错了 |
| CRITICAL | 50 | 要命了 |

坑：`basicConfig` 只在**第一次调用**生效（3.8+ 可 `force=True` 重配）；要按模块区分用 `logging.getLogger(__name__)`；异常日志用 `logger.exception("...")` 会自动带 traceback。

## 六、random

```python
import random
random.random()               # [0,1)
random.randint(1, 10)         # [1,10] 含两端
random.choice(["a","b"])      # 随机一个
random.sample(range(10), 3)   # 不重复抽样
random.shuffle(lst)           # 原地打乱

random.seed(42)               # 固定种子，结果可复现
```

`random` 是伪随机，**不能用于密码/令牌**；安全场景用 `secrets.token_hex()`。

## 七、collections / itertools / functools

### 7.1 collections：容器补丁包

| 类型 | 一句话 | 例子 |
| --- | --- | --- |
| `deque` | 双端队列，两头增删都是 $O(1)$ | `dq.appendleft(x)`、`dq.popleft()` |
| `namedtuple` | 带字段名的轻量元组 | `Point(x=1, y=2)` |
| `defaultdict` | 键不存在时自动建默认值 | `defaultdict(list)` |
| `Counter` | 计数专用 dict | `Counter("abca").most_common(2)` |
| `OrderedDict` | 显式记住顺序 | 需要 `move_to_end` 时 |
| `ChainMap` | 多个 dict 叠成一个视图 | 配置分层 |

```python
from collections import deque, namedtuple

dq = deque([1, 2, 3], maxlen=3)
dq.appendleft(0)        # [0,1,2]，挤掉右边的 3
dq.pop()                # 2
dq.rotate(1)            # 右旋一位

Point = namedtuple("Point", "x y", defaults=[0])
p = Point(1, 2)
p.x, p.y                # 1 2
p._asdict()             # {'x': 1, 'y': 2}
```

`list.pop(0)` 是 $O(n)$，频繁从头部删就用 `deque.popleft()`。`deque` 的 `append`/`popleft` 是线程安全的，但「先判断再操作」这种组合不是，别拿它当锁用。

`defaultdict` / `Counter` / `ChainMap` 的细节见 [[06-映射与集合]]。

### 7.2 itertools：迭代器流水线

| 工具 | 作用 | 例子 |
| --- | --- | --- |
| `count(start, step)` | 无限等差 | `islice(count(10, 2), 3)` → 10,12,14 |
| `cycle(iterable)` | 无限循环 | `cycle("AB")` → A,B,A,B… |
| `repeat(x, n)` | 重复 n 次 | `repeat("x", 3)` |
| `chain(*its)` | 首尾相接 | `chain([1,2], "ab")` |
| `islice(it, start, stop, step)` | 切片迭代器 | `islice(it, 2, 8, 2)` |
| `groupby(it, key)` | 按 key 分组（**相邻**） | 先 `sorted` 再分组 |
| `product(a, b)` | 笛卡尔积 | `product("AB", repeat=2)` |
| `permutations` / `combinations` | 排列 / 组合 | `permutations("ABC", 2)` |
| `accumulate` | 累加/累乘 | `accumulate([1,2,3])` → 1,3,6 |
| `pairwise` | 相邻两两配对（3.10+） | `pairwise([1,2,3])` → (1,2),(2,3) |
| `zip_longest` | 按最长补齐 | `fillvalue="-"` |
| `batched` | 按批切块（3.12+） | `batched(it, 2)` |

```python
from itertools import count, islice, chain, accumulate, pairwise, groupby, product

list(islice(count(10, 2), 3))          # [10, 12, 14]
list(chain([1, 2], "ab"))              # [1, 2, 'a', 'b']
list(accumulate([1, 2, 3]))            # [1, 3, 6]
list(pairwise([1, 2, 3]))              # [(1, 2), (2, 3)]

words = ["bb", "a", "ccc", "dd"]
[(k, list(g)) for k, g in groupby(sorted(words, key=len), key=len)]
# [(1, ['a']), (2, ['bb', 'dd']), (3, ['ccc'])]
```

**坑**：`groupby` 只合并**相邻**的相同 key，不排序会得到多段；`islice` 不支持负索引；所有 itertools 返回的都是迭代器，**只能消费一次**。

### 7.3 functools：函数工具

```python
from functools import lru_cache, cache, partial, reduce, wraps, cmp_to_key

int2 = partial(int, base=2)       # 预绑定参数
int2("1011")                      # 11

reduce(lambda a, b: a * b, [1, 2, 3, 4])   # 24

@lru_cache(maxsize=128)           # 缓存，参数必须可哈希
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

| 工具 | 用途 |
| --- | --- |
| `lru_cache` / `cache` | 记忆化；`cache` 是无上限版（3.9+） |
| `partial` | 冻结部分参数，生成新函数 |
| `reduce` | 把序列压成一个值 |
| `wraps` | 装饰器里保留原函数元信息 |
| `cmp_to_key` | 把老式 `cmp(a,b)` 转成 `key` |
| `cached_property` | 首次计算后缓存成实例属性 |

`singledispatch` 按第一个参数的类型分派，比一长串 `isinstance` 干净：

```python
from functools import singledispatch

@singledispatch
def show(x):
    return f"object: {x}"

@show.register
def _(x: int):
    return f"int: {x}"

show(1)        # 'int: 1'
show("a")      # 'object: a'
```

## 八、subprocess 与 argparse

### 8.1 subprocess：调外部命令

```python
import subprocess

r = subprocess.run(["ls", "-l"], capture_output=True, text=True, timeout=10)
r.returncode      # 0 成功
r.stdout          # 标准输出字符串
r.stderr          # 标准错误字符串

subprocess.run(["git", "status"], check=True)      # 非 0 退出码抛 CalledProcessError
out = subprocess.check_output(["python3", "--version"], text=True)
```

| 参数 | 作用 |
| --- | --- |
| `capture_output=True` | 收 stdout/stderr（等价 `PIPE`） |
| `text=True` | 按文本解码，否则是 bytes |
| `check=True` | 退出码非 0 抛异常 |
| `timeout=10` | 超时抛 `TimeoutExpired` |
| `cwd=` / `env=` | 指定工作目录 / 环境变量 |

**坑**：`shell=True` 把字符串交给 shell，用户输入拼进去就是命令注入；能用列表就别用 shell。要边跑边读输出用 `Popen` + `communicate()`，别用 `run` 等大输出撑爆内存。

### 8.2 argparse：写命令行工具

```python
import argparse
from pathlib import Path

def main():
    p = argparse.ArgumentParser(description="统计文件行数")
    p.add_argument("paths", nargs="+", type=Path)      # 一个或多个位置参数
    p.add_argument("-n", "--top", type=int, default=10)
    p.add_argument("--verbose", action="store_true")   # 开关，默认 False
    p.add_argument("--mode", choices=["line", "word"], default="line")
    args = p.parse_args()

    for path in args.paths:
        text = path.read_text(encoding="utf-8")
        n = len(text.splitlines()) if args.mode == "line" else len(text.split())
        print(path, n)

if __name__ == "__main__":
    main()
```

```bash
python count.py a.txt b.txt -n 5 --verbose --mode word
```

子命令（`git add` / `git commit` 那种）：

```python
sub = p.add_subparsers(dest="cmd", required=True)
add = sub.add_parser("add")
add.add_argument("name")
commit = sub.add_parser("commit")
commit.add_argument("-m", "--message", required=True)
```

**坑**：`parse_args` 遇到错误会直接 `SystemExit(2)`，库函数里别调它；`nargs="?"` 才是「可选的单个位置参数」；`type=Path` 比手动 `Path(args.path)` 省事。

## 九、序列化：json / csv / pickle

| 格式 | 适合 | 注意 |
| --- | --- | --- |
| `json` | 跨语言、配置、API | 只支持基本类型；不能写注释；中文要 `ensure_ascii=False` |
| `csv` | 表格、Excel 可打开 | 必须 `newline=""`；编码显式写 `utf-8` |
| `pickle` | Python 对象原样存取 | 只能 Python 读；**反序列化不可信数据 = 执行任意代码** |

```python
import json, csv, pickle

with open("d.json", "w", encoding="utf-8") as f:
    json.dump({"name": "小明", "age": 18}, f, ensure_ascii=False, indent=2)

with open("t.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.DictWriter(f, fieldnames=["name", "age"])
    w.writeheader()
    w.writerows([{"name": "小明", "age": 18}])

with open("obj.pkl", "wb") as f:
    pickle.dump({"a": 1}, f)
```

`json`/`csv` 的完整读写、`newline` 细节见 [[14-文件与IO]]；`pickle` 只在自己人之间传，别收外部文件。

## 十、第三方库的定位

| 库 | 定位 | 最小例子 |
| --- | --- | --- |
| `requests` | HTTP 客户端，比 `urllib` 好用 | `requests.get(url, timeout=10).json()` |
| `numpy` | 多维数组 + 向量化计算 | `np.array([1,2,3]) * 2` |
| `pandas` | 表格数据分析（建在 numpy 上） | `pd.read_csv("t.csv").groupby("city")["age"].mean()` |

```python
import numpy as np
a = np.array([1, 2, 3])
a * 2          # array([2, 4, 6])，不用写循环
a.sum()        # 6

import pandas as pd
df = pd.read_csv("t.csv")
df.head()
df.groupby("city")["age"].mean()
```

安装：`pip install requests numpy pandas`。判断标准很简单：**标准库能干净解决的别装库；要做数值/表格/HTTP，就用成熟库，别自己造。**
