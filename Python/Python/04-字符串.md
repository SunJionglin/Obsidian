# 04 字符串

> 对应分P：P12–P13

## 一、这一篇要掌握什么

- 三种定义方式与转义字符
- 下标、切片、`len()`、遍历
- 查找、判断、修改三类方法（字符串**不可变**，方法都返回新串）
- 格式化：f-string、`format()`、`%`
- 编码：`encode` / `decode`、乱码是怎么来的

## 二、定义与转义

```python
a = 'abc'
b = "abc"
c = """多行
字符串"""
s = "他说：\"好\"\n换行\t制表"
```

| 转义 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠 |
| `\'` `\"` | 引号 |
| `r"C:\new"` | 原生字符串，不转义（正则常用） |

## 三、下标、切片、遍历

```python
s = "abcdef"
s[0]      # 'a'
s[-1]     # 'f'
s[1:4]    # 'bcd'（左闭右开）
s[::2]    # 'ace'
s[::-1]   # 'fedcba'（反转）
len(s)    # 6
for ch in s: print(ch)
```

## 四、常用方法

| 分类 | 方法 | 例子 → 结果 |
| --- | --- | --- |
| 查找 | `find` / `index` | `"ab".find("b")` → 1；`index` 找不到会抛异常 |
| 查找 | `count` | `"aaa".count("a")` → 3 |
| 判断 | `startswith` / `endswith` | `"a.txt".endswith(".txt")` → True |
| 判断 | `isdigit` / `isalpha` / `isspace` | 逐字符判断，空串返回 False |
| 修改 | `upper` / `lower` | `"Ab".lower()` → 'ab' |
| 修改 | `strip` / `lstrip` / `rstrip` | 去首尾空白，常配 `input()` |
| 修改 | `replace` | `"a-b".replace("-", "_")` → 'a_b' |
| 拆分 | `split` | `"a,b".split(",")` → ['a','b'] |
| 拼接 | `join` | `",".join(["a","b"])` → 'a,b' |
| 对齐 | `center` / `ljust` / `rjust` / `zfill` | `"7".zfill(3)` → '007' |

**字符串不可变**：`s.upper()` 不会改 `s`，要 `s = s.upper()`。

## 五、格式化三兄弟

```python
name, age = "小菜", 3
f"{name} 今年 {age} 岁"              # 推荐，3.6+
"{} 今年 {} 岁".format(name, age)
"%s 今年 %d 岁" % (name, age)        # 老写法

f"{3.14159:.2f}"      # '3.14'
f"{255:x}"            # 'ff'
f"{1234567:,}"        # '1,234,567'
```

## 六、编码与乱码

```python
"中文".encode("utf-8")     # b'\xe4\xb8\xad\xe6\x96\x87'
b'\xe4\xb8\xad'.decode("utf-8")   # '中'
```

| 现象 | 原因 |
| --- | --- |
| `UnicodeDecodeError` | 用 UTF-8 解 GBK 的字节 |
| 读文件乱码 | `open(..., encoding="utf-8")` 没写，用了系统默认编码 |
| 终端中文变问号 | 终端编码不是 UTF-8 |

## 七、常见坑

1. 切片越界不报错，返回空串或截短结果——这是特性也是坑。
2. `split()` 不带参数会按任意空白切分并丢掉空串；`split(" ")` 会留下空串。
3. 循环里 `s += ch` 是 O(n²)，用 `"".join(parts)`。
4. `strip()` 去的是首尾字符集合，`strip("ab")` 会把 a、b 都去掉。

## 八、练习

1. 输入一句话，统计每个字符出现次数（不用 Counter，手写 dict）。
2. 判断回文（忽略大小写与标点）。
3. 把 `"2026-11-02"` 解析出年、月、日并打印成「2026 年 11 月 2 日」。
