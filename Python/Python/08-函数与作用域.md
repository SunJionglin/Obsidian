# 08 函数与作用域

> 对应分P：P19–P23

## 一、这一篇要掌握什么

- 定义、调用、返回值（没有 return 就是 None）
- 五种参数：位置、关键字、默认、可变位置 `*args`、可变关键字 `**kwargs`
- 作用域：局部 / 全局 / `global` / `nonlocal`
- lambda、内置高阶函数 `map/filter/sorted`、拆包
- 类型注解：容器泛型、`Optional`、`Protocol`、`TypedDict`

## 二、定义与返回

```python
def add(a, b):
    """返回两个数之和"""
    return a + b

print(add(1, 2))        # 3
```

- 没有 `return` 返回 `None`；`return a, b` 返回元组。
- 函数名是变量，可以赋给别的名字、可以当参数传。
- 文档字符串写在函数体第一行，`help(add)` 能看到。

## 三、参数五件套

```python
def f(a, b=2, *args, **kwargs):
    print(a, b, args, kwargs)

f(1)                      # 1 2 () {}
f(1, 3, 4, 5, k=6)        # 1 3 (4,5) {'k': 6}
f(a=1, b=3)               # 关键字传参
```

| 写法 | 名字 | 说明 |
| --- | --- | --- |
| `def f(a, b)` | 位置参数 | 按顺序传 |
| `def f(a=1)` | 默认参数 | 必须放在无默认值参数后面 |
| `def f(*args)` | 可变位置 | 收到的是元组 |
| `def f(**kwargs)` | 可变关键字 | 收到的是字典 |
| `def f(a, /, b, *, c)` | 仅位置 / 仅关键字 | 3.8+ 语法，限制传参方式 |

**默认参数是可变对象时的经典坑**：

```python
def bad(x, lst=[]):     # lst 只在定义时创建一次！
    lst.append(x)
    return lst

bad(1)   # [1]
bad(2)   # [1, 2]  ← 不是 [2]
```

要写 `def good(x, lst=None): lst = lst or []`。

## 四、作用域

```python
count = 0
def inc():
    global count      # 要改全局变量必须声明
    count += 1

def outer():
    n = 0
    def inner():
        nonlocal n    # 改外层函数的变量
        n += 1
    inner()
    return n
```

规则（LEGB）：局部 → 闭包外层 → 全局 → 内置。只读不用声明，**赋值就得声明**。

## 五、lambda 与高阶函数

```python
square = lambda x: x * x
square(5)              # 25

sorted(words, key=lambda w: len(w))
max(items, key=lambda x: x[1])
list(map(lambda x: x*2, [1,2,3]))        # [2,4,6]
list(filter(lambda x: x > 1, [1,2,3]))   # [2,3]
```

lambda 只能写一个表达式，不能写语句；复杂逻辑就写 def。

## 六、拆包与解包

```python
a, b = 1, 2
first, *mid, last = [1, 2, 3, 4]     # 1 [2,3] 4
def f(a, b): ...
args = (1, 2)
f(*args)          # 位置参数拆包
kwargs = {"a": 1, "b": 2}
f(**kwargs)       # 关键字拆包
```

## 七、类型注解：写给人和类型检查器看

Python 的注解**在运行时不做检查**：`greet(123)` 传错类型照样跑。它的价值是让 IDE 补全、让 mypy/pyright 静态检查、让 `dataclass`（见 [[13-面向对象]]）/ FastAPI 这类框架读到元数据。

### 7.1 基本写法

```python
def greet(name: str, times: int = 1) -> str:
    return f"你好，{name}" * times

age: int = 18
names: list[str] = []
scores: dict[str, float] = {}
point: tuple[float, float] = (1.0, 2.0)
```

- 3.9+ 可以直接用内置容器做泛型：`list[int]`、`dict[str, int]`、`tuple[int, ...]`；老代码里的 `List[int]` / `Dict[str, int]` 来自 `typing`，新代码不用。
- `tuple[int, ...]` 表示「任意长度的 int 元组」；`tuple[int, str]` 表示「固定两个元素」。
- `-> None` 表示「不返回有意义的值」；不写注解和写 `-> None` 不是一回事（前者是「没标」，后者是「明确不返回」）。

### 7.2 联合类型与可选

```python
from typing import Optional, Union

def find(name: str) -> Optional[int]: ...      # 可能是 int，也可能是 None
def find2(name: str) -> int | None: ...        # 3.10+ 的写法，等价

x: Union[int, str] = 1
y: int | str = "a"                             # 3.10+
```

坑：`Optional[int]` **不等于「可以不传」**，它只表示「值可以是 None」。参数要可省略仍得写默认值：`def f(x: int | None = None)`。

### 7.3 容器、可调用、字面量

```python
from collections.abc import Iterable, Iterator, Mapping, Sequence
from typing import Callable, Literal, Any

def total(xs: Iterable[int]) -> int:
    return sum(xs)

def apply(f: Callable[[int, int], int], a: int, b: int) -> int:
    return f(a, b)

Mode = Literal["r", "w", "a"]        # 只允许这三个字符串

def open_file(path: str, mode: Mode = "r") -> None: ...
```

- 参数尽量标 `Iterable` / `Sequence` / `Mapping`（只读接口），返回具体类型（`list` / `dict`）。
- `Any` 等于「放弃检查」，能不用就不用；`object` 才是「什么都能接，但用之前要收窄」。

### 7.4 类型别名、泛型与 TypedDict

```python
from typing import TypedDict, TypeVar

Vector = list[float]                 # 类型别名
type Vector2 = list[float]           # 3.12+ 的新语法

T = TypeVar("T")
def first(xs: list[T]) -> T:         # 输入什么元素类型，就返回什么类型
    return xs[0]

class Movie(TypedDict):              # 描述「有这些键的 dict」
    title: str
    year: int

m: Movie = {"title": "让子弹飞", "year": 2010}
```

`TypedDict` 运行时就是普通 dict，只是给类型检查器看；`m["director"]` 静态报错，但运行时仍是 `KeyError`。

### 7.5 Protocol：结构化鸭子类型

ABC 要求显式继承；Protocol 只看「有没有这几个方法」，适合描述第三方对象或函数参数：

```python
from typing import Protocol, runtime_checkable

class SupportsClose(Protocol):
    def close(self) -> None: ...

def shutdown(x: SupportsClose) -> None:
    x.close()

@runtime_checkable
class Sized(Protocol):
    def __len__(self) -> int: ...

isinstance([], Sized)      # True（只查方法在不在，不查签名）
```

`@runtime_checkable` 只支持 `isinstance`，且只检查方法名是否存在，不检查参数和返回值。

### 7.6 注解在运行时到底在哪

```python
def f(x: int) -> str: ...
f.__annotations__        # {'x': <class 'int'>, 'return': <class 'str'>}

from typing import get_type_hints
get_type_hints(f)        # 解析字符串注解（前向引用）后的结果
```

- 注解默认在函数定义时求值，所以写 `def f(x: Node)` 而 `Node` 还没定义会 `NameError`；用字符串 `"Node"` 或文件头 `from __future__ import annotations` 延迟求值。
- `from __future__ import annotations` 让所有注解变成字符串，3.9 也能写 `int | None`；但 `dataclass` 等靠注解的库仍能通过 `get_type_hints` 解析。
- 3.12+ 有 `type X = ...` 和 `class Box[T]:` 的新泛型语法，旧写法仍然有效。

### 7.7 怎么用起来

1. 编辑器开 Pylance / mypy 插件，写完就看波浪线；
2. 命令行 `pip install mypy`，`mypy app.py --ignore-missing-imports`；
3. 公共函数、数据模型、API 边界必须标；三行以内的局部变量可以不标；
4. 注解不是文档的替代品，复杂约束（范围、格式）仍要写进 docstring 或校验代码。

## 八、常见坑

1. 默认参数别用 `[]`、`{}`。
2. 函数里改了可变参数（list/dict）会影响调用方——这是特性，但要清楚。
3. `global` 只在需要**赋值**时用；读全局变量不需要。
4. 同名函数后定义会覆盖前一个（没有重载）。
5. 注解不强制，别以为标了 `int` 就安全；运行时校验仍要自己写。
6. `Optional[X]` 不等于有默认值，参数可省略要写 `= None`。
7. `list[int]` 在 3.8 上运行会 `TypeError`；要么用 3.9+，要么加 `from __future__ import annotations`。
8. `bool` 是 `int` 的子类（`isinstance(True, int)` 为 True），类型收窄时别把 True 当普通整数漏过去。

## 九、练习

1. 写 `def stats(nums)` 返回 (最小值, 最大值, 平均值)。
2. 用 `*args` 写一个可传任意个数的求和函数。
3. 用 `sorted(key=lambda)` 给一组 (姓名, 分数) 按分数降序、同分按姓名升序。
4. 给上面三个函数补全类型注解，再用 mypy 跑一遍，做到 0 error。
5. 写一个 `SupportsRead` Protocol（只有 `read() -> str`），让「文件对象」和「自定义的假对象」都能传进去。
