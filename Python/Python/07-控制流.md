# 07 控制流

> 对应分P：P8–P11

## 一、这一篇要掌握什么

- `if / elif / else` 与三元表达式
- `match / case` 的结构化分支（3.10+）
- `while`、`for ... in ...`、`range()` 的用法
- `break` / `continue` / `else`（循环的 else）
- 嵌套循环与常见套路（九九乘法表、找素数、累加）

## 二、条件分支

```python
score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

```python
# 三元表达式
level = "及格" if score >= 60 else "不及格"
```

坑：`elif` 顺序从上往下判，写反了后面的分支永远进不去；Python 没有 `switch`，3.10+ 用 `match` 代替。

## 三、match / case（3.10+）

`match` 不是 `switch`：它匹配的是**结构**，不是「等于某个值」。第一个匹配的 `case` 执行完就结束，**没有 fallthrough**。

```python
def handle(cmd: str) -> str:
    match cmd.split():
        case ["go", direction]:
            return f"向 {direction} 走"
        case ["look"]:
            return "观察四周"
        case ["take", item, *rest]:
            return f"拿起 {item}，忽略 {rest}"
        case _:
            return "无法识别"
```

常见模式：

```python
match point:
    case (0, 0):                 # 字面量/序列模式
        print("原点")
    case (x, 0):
        print("在 x 轴上", x)
    case (0, y):
        print("在 y 轴上", y)
    case {"type": "circle", "r": r} if r > 0:   # 映射模式 + 守卫
        print("圆", r)
    case Point(x=0, y=0):        # 类模式，按属性匹配
        print("原点")
    case _:
        print("其他")
```

- `case [a, b]` 里的 `a`、`b` 是**绑定**，会把匹配到的值赋给同名变量（注意别和外部变量重名）。
- OR 模式用 `|`，但两侧必须绑定同一组名字：`case "yes" | "y":` 合法，`case (x, 0) | (0, y):` 会语法错（两边绑定名不同）。
- `case _` 是兜底，等价于「其他」；没有它且全不匹配时，什么都不做。
- 区间、大小比较、复杂布尔条件仍用 `if`；`match` 适合「按形状分派」。

**坑**：`case` 里的裸名字是捕获变量，不是常量。想匹配常量要用 `case Color.RED` 或加守卫。

## 四、while 与 for

```python
i = 0
while i < 5:
    print(i)
    i += 1          # 忘了自增就是死循环

for i in range(5):          # 0..4
    print(i)

for i in range(1, 10, 2):   # 1,3,5,7,9
    print(i)

for ch in "abc":            # 遍历字符串
    print(ch)

for i, x in enumerate(["a", "b"]):   # 同时拿下标
    print(i, x)
```

| 写法 | 说明 |
| --- | --- |
| `range(n)` | 0 到 n-1 |
| `range(a, b)` | a 到 b-1 |
| `range(a, b, step)` | 带步长，可为负 |
| `enumerate(seq)` | 下标 + 值 |
| `zip(a, b)` | 并行遍历，长度取短的那个 |

## 五、break / continue / else

```python
for i in range(10):
    if i == 3:
        continue      # 跳过本次
    if i == 7:
        break         # 跳出整个循环
    print(i)

# 循环的 else：只有「没被 break」才执行
for n in range(2, 10):
    for d in range(2, n):
        if n % d == 0:
            break
    else:
        print(n, "是质数")
```

## 六、嵌套与套路

```python
# 九九乘法表
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}*{i}={i*j}", end="\t")
    print()
```

- 找素数：外层枚举、内层试除到 √n。
- 累加/累乘：初始化 `sum = 0` / `prod = 1`。
- 图形打印：外层行、内层列，注意 `end=""` 与换行位置。

## 七、常见坑

1. `while` 忘了改条件变量 → 死循环，`Ctrl+C` 停。
2. 循环里修改列表长度（`for x in lst: lst.remove(x)`）会跳元素，改用 while 或列表推导。
3. `range(len(lst))` 能写但不如 `enumerate(lst)`。
4. 嵌套循环里 `break` 只跳出**一层**。

## 八、练习

1. 猜数字：`while` + `break`，最多 5 次机会。
2. 打印 1–100 里所有能被 3 整除但不能被 5 整除的数。
3. 用 for 循环求 1!+2!+…+10!。
