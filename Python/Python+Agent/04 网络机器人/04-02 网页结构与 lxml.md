## 0. 速记

> [!tip] 五句话
> - 网页 = HTML（结构）+ CSS（样式）+ JS（行为），爬虫只关心 HTML
> - HTML 是一棵树：标签、属性、文本
> - `lxml.html.fromstring()` 把 HTML 字符串变成可查询的树
> - 它容错很强，不闭合的标签会自动补全
> - `xpath()` 返回的永远是列表，空列表代表没匹配到

## 1. 语法速查

### 1.1 HTML 的最小结构

```html
<html>
  <head><title>标题</title></head>
  <body>
    <div class="card">
      <a href="/movie/1">电影名</a>
    </div>
  </body>
</html>
```

- 标签：`div`、`a`
- 属性：`class="card"`、`href="/movie/1"`
- 文本：`电影名`

### 1.2 解析与提取

```python
from lxml import html

doc = html.fromstring(html_text)
titles = doc.xpath("//a/text()")        # ['电影名']
links = doc.xpath("//a/@href")          # ['/movie/1']
cards = doc.xpath("//div[@class='card']")
```

### 1.3 节点对象常用操作

```python
from lxml import etree

etree.tostring(node, encoding="unicode")   # 节点转回 HTML 字符串
node.xpath("./a/@href")                    # 相对当前节点查
node.text                                  # 第一个文本节点
```

### 1.4 一次完整解析

```python
resp = requests.get(url, timeout=10)
doc = html.fromstring(resp.text)               # 1. 字符串变树
cards = doc.xpath("//div[@class='card']")      # 2. 定位节点
for card in cards:
    title = card.xpath("./a/text()")           # 3. 相对提取
```

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| HTML 解析 | libxml2 / gumbo，需编译链接 | `lxml`，pip 安装 |
| 查询方式 | XPath C API，代码量大 | `xpath()` 一行 |
| 容错 | 弱，坏标签可能解析失败 | 强，自动补全 |
| 编码 | 自己转 UTF-8 | 传 `str` 即可 |
| 遍历 | 指针 + 递归 | 列表 + for |
| XPath 支持 | 需额外库或手写遍历 | 内置 `xpath()` |

## 3. 易漏点

- **浏览器会补 `tbody`**：源码里可能没有，XPath 写 `//table/tbody/tr` 可能空。
- **`//` 是全文档，`./` 是当前节点**：循环里取子元素必须用 `./`。
- **`.text` 只取第一个文本节点**：混合内容要用 `text_content()`。
- **属性用 `@href`**：不是 `.href`。
- **实体会被解码**：`&amp;` 变成 `&`，写 XPath 时注意。
- **空列表不是 None**：`[0]` 之前先判空。
- **相对链接不是完整 URL**：要拼 `https://site.com`。

## 4. 易错点

> [!warning] 用正则解析 HTML
> 嵌套标签、属性顺序、换行都会让正则失效。用解析器。

> [!warning] 直接 print 解析结果
> 打印出的是 `<Element html at 0x...>`，要 `.xpath()` 或 `tostring()`。

> [!warning] 循环里用 `//` 查子元素
> 会跳出当前节点，查到全文档。改成 `./`。

> [!warning] 编码传错
> `fromstring` 收到错误编码的字节会乱码。先把响应正确解码成 `str`。

> [!warning] 把列表当字符串用
> `titles.lower()` → `AttributeError`。先 `titles[0]`。

> [!warning] 忽略 base URL
> 拿到的 `href` 是 `/movie/1`，直接请求会失败。

## 5. 自测

> [!question]- HTML、CSS、JS 各负责什么？
> **答案**：HTML 结构（内容），CSS 样式（外观），JS 行为（交互）。

> [!question]- `doc.xpath("//a/@href")` 返回什么类型？
> **答案**：列表，元素是字符串；没匹配到就是空列表 `[]`。

> [!question]- 在循环里处理每个 `tr`，为什么用 `./td` 而不是 `//td`？
> **答案**：`//` 会从整个文档重新搜索，`./` 才限定在当前节点下。
