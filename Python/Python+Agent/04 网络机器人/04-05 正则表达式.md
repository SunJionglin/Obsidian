## 0. 速记

> [!tip] 五句话
> - 正则描述字符串的组成规则，用来匹配、提取、替换
> - 永远写 `r""` 原始字符串，别让 `\d` 被 Python 先转义
> - `match` 从开头，`search` 任意位置找第一个，`findall` 找全部
> - 量词默认贪婪，加 `?` 变非贪婪
> - `findall` 有分组时，返回的是分组内容，不是整个匹配

## 1. 语法速查

### 1.1 元字符

| 符号 | 含义 |
|---|---|
| `.` | 任意字符（默认不含换行） |
| `\d` / `\D` | 数字 / 非数字 |
| `\w` / `\W` | 字母数字下划线 / 非 |
| `\s` / `\S` | 空白 / 非空白 |
| `*` / `+` / `?` | 0+ / 1+ / 0 或 1 |
| `{m}` / `{m,}` / `{m,n}` | 恰好 m / 至少 m / m 到 n |
| `[]` | 字符集，`[3-9]` 表示 3 到 9 |
| `|` | 或 |
| `()` | 分组 |
| `^` / `$` | 开头 / 结尾 |

### 1.2 四个函数

```python
import re

re.match(r"\d+", "123abc")      # 从开头匹配，返回 Match 或 None
re.search(r"\d+", "abc123")     # 任意位置找第一个
re.findall(r"\d+", "a1b22c333") # ['1', '22', '333']
re.sub(r"\d+", "#", "a1b22")    # 'a#b#'
```

### 1.3 常用例子

```python
# 手机号
re.findall(r"1[3-9]\d{9}", text)

# 日期
re.search(r"\d{4}-\d{2}-\d{2}", "1957-04-10 (US)").group()

# 时长：2h 20m → 140
h = re.search(r"(\d+)h", "2h 20m")
m = re.search(r"(\d+)m", "2h 20m")
```

### 1.4 Match 对象

```python
m = re.search(r"\d+", "abc123")
m.group()      # '123'
m.group(1)     # 第一个分组
m.span()       # (3, 6)
m.start()      # 3
m.end()        # 6
```

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 标准库 | `std::regex` | `re` |
| 默认语法 | ECMAScript | PCRE 风格 |
| 原始字符串 | `R"(...)"` | `r"..."` |
| 返回 | `smatch` | `Match` / `list` |
| 分组 | `match[1]` | `group(1)` |
| 性能 | 编译一次复用 | 模块内部缓存 |
| 中文 | 需宽字符 | `\w` 默认可匹配中文 |

## 3. 易漏点

- **`match` 只从开头**：字符串开头不是数字就直接 `None`。
- **`findall` 和分组**：`re.findall(r"(\d+)", s)` 返回分组内容；多个分组返回元组列表。
- **`r""` 不是可选项**：`"\d"` 是无效转义，行为不稳定。
- **贪婪 vs 非贪婪**：`.*` 会吞到最后一个；`.*?` 才停在第一个。
- **`^`/`$` 默认整段**：多行匹配要 `re.M`。
- **`.` 不匹配换行**：跨行要 `re.S`。
- **特殊字符要转义**：`.`、`*`、`(`、`[` 想匹配本身，前面加 `\`。

## 4. 易错点

> [!warning] 忘写 r 前缀
> `"\d"` 在某些版本会触发 `DeprecationWarning`，逻辑也可能错。统一 `r"\d"`。

> [!warning] 用 match 找中间的内容
> `re.match(r"\d+", "abc123")` 返回 `None`。找任意位置用 `search`。

> [!warning] 贪婪匹配吞太多
> `r"<div>.*</div>"` 会匹配到最后一个 `</div>`。用 `.*?` 或排除字符集。

> [!warning] findall 结果和预期不一样
> 有分组时只返回分组内容。不想要分组就写 `(?:...)`。

> [!warning] 把 `\w` 当成只匹配英文
> Python 3 的 `\w` 默认可匹配中文，做英文校验要 `re.ASCII`。

> [!warning] 用 `$` 匹配每行结尾
> 默认只匹配整段末尾，多行要 `re.M`。

## 5. 自测

> [!question]- `match`、`search`、`findall` 的区别？
> **答案**：`match` 从开头匹配一次；`search` 任意位置找第一个；`findall` 找全部并返回列表。

> [!question]- `re.findall(r"(\d+)", "a1b22")` 返回什么？
> **答案**：`['1', '22']`，有分组时返回分组内容。

> [!question]- 把 `"2h 20m"` 转成 140 分钟，怎么写？
> **答案**：
> ```python
> h = int(re.search(r"(\d+)h", t).group(1)) if "h" in t else 0
> m = int(re.search(r"(\d+)m", t).group(1)) if "m" in t else 0
> total = h * 60 + m
> ```
