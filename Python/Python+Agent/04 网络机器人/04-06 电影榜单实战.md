## 0. 速记

> [!tip] 五句话
> - 流程：榜单页 → 详情页 → 清洗 → CSV
> - 第 1 页用 GET，第 2 页起改为 POST 表单
> - 详情页每个字段一条 XPath，取不到就兜底空串
> - 原始数据要清洗：年份去括号、日期取 `yyyy-mm-dd`、时长转分钟
> - 分页、延时、异常，一个都不能少

## 1. 语法速查

### 1.1 常量与入口

```python
import csv
import re
import requests
from lxml import html

BASE = "https://www.themoviedb.org"
TOP_URL = f"{BASE}/movie/top-rated"
```

### 1.2 列表页与详情链接

```python
resp = requests.get(TOP_URL, timeout=60)
doc = html.fromstring(resp.text)

cards = doc.xpath("//*[@id='page_1']/div[@class='card style_1']")
for card in cards:
    href = card.xpath("./div/div/a/@href")
    if href:
        detail_url = BASE + href[0]
```

### 1.3 详情页取字段

```python
detail = html.fromstring(requests.get(detail_url, timeout=60).text)
```

## 3. 易漏点

- **第 2 页起是 POST**：只 GET 第一页会漏掉 90% 数据。
- **页码藏在 id 里**：`page_1`、`page_2`，XPath 要跟着变。
- **空列表兜底**：`values[0] if values else ""`。
- **详情页要延时**：连续请求容易被封，`time.sleep(0.5)`。
- **相对链接拼 BASE**：`href` 是 `/movie/123`。
- **CSV 用 `utf-8-sig`**：Excel 打开不乱码。
- **字段可能缺失**：新片、冷门片没有宣传语、语言。

## 4. 易错点

> [!warning] 只抓第一页
> 榜单 100 条分 5 页，只请求首页只能拿到 20 条。

> [!warning] 空列表直接取下标
> `names[0]` → `IndexError`，整部电影数据丢失。先判空。

> [!warning] 页数硬编码
> 站点改版或多一页就漏数据。先解析总页数，或循环到空列表为止。

> [!warning] 不设 timeout
> 某一部电影卡住，整个脚本挂死。`timeout=60` + `try/except`。

> [!warning] 一部失败全崩
> 详情页请求要包 `try/except`，失败就跳过这一部。

> [!warning] 中文在 Excel 乱码
> 写 CSV 用 `encoding="utf-8-sig"`。

## 5. 自测

> [!question]- 为什么第 2 页开始要用 POST？
> **答案**：站点把翻页做成了表单提交，GET 只适用于第一页。

> [!question]- 时长 `2h 20m` 怎么转成分钟？
> **答案**：分别正则取小时和分钟，`h * 60 + m`；只有 `40m` 时小时按 0 算。

> [!question]- 详情页字段取不到时怎么处理？
> **答案**：用 `x[0].strip() if x else ""` 兜底，不能直接下标。
