## 0. 速记

> [!tip] 五句话
> - CSV 是逗号分隔的纯文本表格，Excel 能直接打开
> - 用 `csv` 模块，不要手写 `split(",")`
> - 写文件加 `newline=""`，否则 Windows 会多空行
> - 给 Excel 看的中文 CSV 用 `utf-8-sig`
> - `DictWriter` 按列名写，`DictReader` 按列名读

## 1. 语法速查

### 1.1 写 CSV

```python
import csv

rows = [
    {"电影名": "肖申克的救赎", "评分": 9.3},
    {"电影名": "霸王别姬", "评分": 9.6},
]

with open("movies.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["电影名", "评分"])
    writer.writeheader()
    writer.writerows(rows)
```

### 1.2 读 CSV

```python
with open("movies.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["电影名"], row["评分"])   # 值都是 str
```

### 1.3 基础读写

```python
with open("a.csv", "w", encoding="utf-8", newline="") as f:
    csv.writer(f).writerow(["姓名", "年龄"])
    csv.writer(f).writerow(["小王", 18])

with open("a.csv", encoding="utf-8") as f:
    for row in csv.reader(f):
        print(row)      # ['姓名', '年龄'] / ['小王', '18']
```

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 写表格 | `fstream` + 手动拼逗号 | `csv.writer` |
| 转义 | 自己处理引号、逗号 | 模块自动加引号 |
| 表头 | 自己记列顺序 | `DictWriter` |
| 读 | `getline` + `split` | `csv.reader` |
| 编码 | 字节流 | `encoding` 参数 |
| Excel 兼容 | 自己加 BOM | `utf-8-sig` |

## 3. 易漏点

- **`newline=""`**：不写会在 Windows 上每行之间多一个空行。
- **`utf-8-sig`**：带 BOM，Excel 打开中文才不乱码。
- **读出来都是字符串**：`"18"` 不是 `18`，要自己 `int()`。
- **字段含逗号会自动加引号**：`"football,Java"` 被包成 `"football,Java"`。
- **`writerows` 接收可迭代对象**：`DictWriter` 要字典列表。
- **追加会重复表头**：`a` 模式写入前先判断文件是否存在。
- **空文件读不到表头**：`DictReader` 直接迭代为空。

## 4. 易错点

> [!warning] 忘了 `newline=""`
> 写出来的文件每隔一行一个空行。

> [!warning] 用 `split(",")` 解析
> 字段里本身带逗号（如 `"football,Java"`）就切坏了。用 `csv.reader`。

> [!warning] 中文在 Excel 里乱码
> 用 `encoding="utf-8-sig"` 写，别用 `utf-8`。

> [!warning] 忘了 `writeheader()`
> 文件只有数据没有列名，`DictReader` 会把第一行数据当表头。

> [!warning] 想追加却用了 `w`
> 原文件被覆盖。追加用 `a`，并且别重复写表头。

> [!warning] 读出来当数字算
> `row["评分"] + 1` → `TypeError`。先 `float(row["评分"])`。

## 5. 自测

> [!question]- 写 CSV 时为什么要加 `newline=""`？
> **答案**：避免 `csv` 模块写入的换行和文件系统换行叠加，产生空行。

> [!question]- `DictReader` 读出来的值是什么类型？
> **答案**：全是字符串，数字需要自己转换。

> [!question]- 中文 CSV 给 Excel 打开，编码用什么？
> **答案**：`utf-8-sig`，带 BOM 才能被 Excel 正确识别。
