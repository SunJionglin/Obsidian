## 0. 速记

> [!tip] 五句话
> - 没写 `return` 返回 `None`；`return a, b` 返回的是元组
> - 默认参数只在定义时求值一次 → 别用 `[]`、`{}` 当默认值
> - 参数是对象引用传递：重新赋值不影响外部，改可变对象会影响
> - `*args` 收成 tuple，`**kwargs` 收成 dict
> - lambda 只能写一个表达式，不能有语句

## 1. 语法速查

### 1.1 定义、调用、返回

```python
def add(a, b):
    """返回两数之和"""
    return a + b

def no_return():
    pass                # 没有 return → 返回 None

def multi():
    return 1, 2         # 返回元组 (1, 2)
```

### 1.2 参数的五种形态

```python
def f(a, b=2, *args, c=3, **kwargs):
    print(a, b, args, c, kwargs)

f(1, 2, 3, 4, c=5, d=6)
# 1 2 (3, 4) 5 {'d': 6}
```

顺序固定：位置参数 → 默认参数 → `*args` → 仅关键字参数 → `**kwargs`。

```python
f(1, 2)              # 位置
f(a=1, b=2)          # 关键字
f(*[1, 2])           # 解包列表
f(**{"a": 1})        # 解包字典
```

### 1.3 作用域

```python
x = 1

def change():
    global x
    x = 2

change()
print(x)    # 2
```

LEGB：局部 → 外层函数 → 全局 → 内置。函数内第一次赋值就把它变成局部变量，除非声明 `global` / `nonlocal`。

### 1.4 函数作为参数 / lambda

```python
def apply(fn, x):
    return fn(x)

apply(lambda n: n * 2, 3)             # 6
sorted(data, key=lambda x: x[1])      # 按第二个元素排序
```

### 1.5 递归

```python
def fact(n):
    return 1 if n <= 1 else n * fact(n - 1)
```

必须有终止条件；Python 默认递归深度约 1000。

### 1.6 类型注解

```python
def greet(name: str, age: int = 18) -> str:
    return f"{name} {age}"
```

注解不强制、运行时不检查，只给人看和给 IDE 用。

### 1.7 列表推导式 vs 生成器表达式

```python
[x * x for x in range(10)]       # 立即生成列表
(x * x for x in range(10))       # 生成器，惰性求值
sum(x * x for x in range(10))    # 不建中间列表
```

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 返回类型 | 必须声明 | 不声明，可返回多值 |
| 函数重载 | 支持 | 不支持，同名后定义覆盖 |
| 默认参数 | 编译期展开 | 定义时求值一次 |
| 参数传递 | 值 / 引用 / 指针 | 对象引用传递 |
| 函数作为值 | 函数指针 / `std::function` | 直接赋值、传参 |
| 关键字参数 | 无 | 有 |
| 变长参数 | `va_list` / 模板 | `*args` / `**kwargs` |
| lambda | 有捕获列表 | 无捕获，只能单表达式 |
| 作用域 | 块作用域 | LEGB，无块作用域 |
| 递归深度 | 栈溢出 | 约 1000 抛 `RecursionError` |

## 3. 易漏点

- **默认参数只求值一次**：`def f(a, b=[])` 的 `b` 跨调用共享，越调越长。
- **多返回值是元组**：`a, b = f()` 是解包，`x = f()` 得到的是元组。
- **UnboundLocalError**：函数里只要出现过赋值，整个函数内它都是局部变量。
- **`*args` 是 tuple，`**kwargs` 是 dict**，名字可以换，星号不能少。
- **`*` 后的参数只能按关键字传**：`def f(*, a)` 必须 `f(a=1)`。
- **lambda 不能写语句**：不能 `return`、不能赋值，只能一个表达式。
- **生成器只能遍历一次**，第二次为空。
- **函数是对象**：可以放进列表、当返回值、当参数。

## 4. 易错点

> [!warning] 可变默认参数
> ```python
> def f(a, b=[]):
>     b.append(a)
>     return b
> ```
> `f(1)` → `[1]`，`f(2)` → `[1, 2]`。默认值只创建一次。改成 `b=None` 再判断。

> [!warning] 忘写 return
> 函数体只有计算没有 `return`，调用结果一律是 `None`。

> [!warning] 位置参数跟在关键字后面
> `f(a=1, 2)` → `SyntaxError`。位置参数必须在前。

> [!warning] 改全局变量忘写 global
> 函数内 `x = 2` 只是新建局部变量；要改全局必须 `global x`。

> [!warning] 递归没有终止条件
> `RecursionError: maximum recursion depth exceeded`。

> [!warning] 函数名覆盖内置
> `list = [...]` 之后 `list()` 就不能用了，别用内置名当函数名。

## 5. 自测

> [!question]- 输出什么？
> ```python
> def f(a, b=[]):
>     b.append(a)
>     return b
>
> print(f(1))
> print(f(2))
> ```
> **答案**：`[1]` 和 `[1, 2]`。默认列表只创建一次，被两次调用共享。

> [!question]- 输出什么？
> ```python
> def f(*args, **kwargs):
>     print(args, kwargs)
>
> f(1, 2, x=3)
> ```
> **答案**：`(1, 2) {'x': 3}`。`args` 是元组，`kwargs` 是字典。

> [!question]- 写函数：接收一个列表，返回其中偶数的平方组成的新列表。
> **答案**：
> ```python
> def even_squares(nums):
>     return [n * n for n in nums if n % 2 == 0]
>
> print(even_squares([1, 2, 3, 4]))   # [4, 16]
> ```
