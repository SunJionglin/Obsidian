## 0. 速记

> [!tip] 五句话
> - 条件不写括号，但必须冒号 + 缩进；`else if` 写作 `elif`
> - `for` 是遍历，`for i in range(n)` 才是计数循环，range 左闭右开
> - `break` / `continue` 只作用于当前这一层循环
> - `match-case` 是 switch 的替代，没有穿透，`case _` 兜底
> - `for/while ... else`：循环没被 break 才执行 else

## 1. 语法速查

### 1.1 if / elif / else

```python
if score >= 90:
    print("A")
elif score >= 60:
    print("B")
else:
    print("C")
```

- 条件可以是任意对象，按真值判断：`0`、`""`、`None`、空容器为假。
- `elif` 可以多个，从上往下匹配，命中一个就跳过其余。

### 1.2 match-case（3.10+）

```python
match command:
    case "start":
        print("开始")
    case "stop" | "quit":
        print("结束")
    case [x, y]:
        print(f"坐标 {x},{y}")
    case {"name": name}:
        print(f"名字 {name}")
    case n if n > 0:
        print("正数")
    case _:
        print("未知")
```

- 没有 fallthrough，每个 case 独立，不用写 break。
- `|` 是或模式，`_` 是通配符，`if` 是守卫条件。

### 1.3 while

```python
while 条件:
    ...
```

- 次数未知、靠条件退出时用。
- 没有 do-while，用 `while True` + `break` 模拟。

### 1.4 for 与 range

```python
for i in range(5):          # 0 1 2 3 4
    ...
for i in range(1, 10, 2):   # 1 3 5 7 9
    ...
for i in range(5, 0, -1):   # 5 4 3 2 1
    ...
for ch in "abc":            # 遍历字符串
    ...
for k in {"a": 1}:          # 遍历 dict 的 key
    ...

for i, ch in enumerate("abc"):
    print(i, ch)            # 0 a / 1 b / 2 c
```

- `range(start, end, step)`：左闭右开，step 可为负。
- 需要下标时用 `enumerate`，别写 `for i in range(len(lst))`。

### 1.5 嵌套、break、continue

```python
for i in range(3):
    for j in range(3):
        if j == 1:
            continue    # 跳过内层本次
        if i == 2:
            break       # 只跳出内层
```

- `break` 跳出当前循环，`continue` 跳过本次进入下一次。
- 双层跳出：用标志变量，或把循环封装成函数后 `return`。

### 1.6 pass

```python
if ready:
    pass    # 占位，什么都不做
```

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 条件括号 | `if (x > 0)` | `if x > 0:` |
| 分支关键字 | `else if` | `elif` |
| 多分支 | `switch` + `break` | `match-case`，无穿透 |
| 计数循环 | `for (int i = 0; i < n; i++)` | `for i in range(n)` |
| 循环变量作用域 | 块作用域 | 函数/模块作用域，循环后仍存在 |
| do-while | 有 | 无，`while True` + `break` |
| 自增 | `i++` | `i += 1` |
| 真值判断 | 基本类型隐式转换 | 任意对象按 truthiness |
| goto | 有 | 无 |
| 循环 else | 无 | `for/while ... else` |

## 3. 易漏点

- **range 左闭右开**：`range(1, 5)` 是 1、2、3、4。
- **循环 else**：`for ... else` 的 else 在「循环正常结束、没被 break」时执行。
- **循环变量不隔离**：`for i in ...` 结束后 `i` 仍然存在。
- **while 用真值**：`while []:` 一次都不进。
- **continue 会跳回条件判断**：while 里更新变量的语句别放在 continue 之后。
- **match 需要 3.10+**，无匹配且没有 `_` 时静默跳过，不报错。
- **`range(5, 1)` 是空序列**，step 默认为正。
- **只需要元素时直接 `for ch in s`**，别用 `range(len(s))`。

## 4. 易错点

> [!warning] 忘写冒号
> `if x > 0` 换行 → `SyntaxError`。冒号是语法的一部分。

> [!warning] 缩进不一致
> 空格和 Tab 混用 → `IndentationError`。统一 4 个空格。

> [!warning] 把赋值当比较
> 写 `if x = 1`（一个等号）会报 `SyntaxError`，判断相等要用双等号。

> [!warning] while 忘记更新条件
> 循环体里没有改变条件变量 → 死循环，用 `Ctrl+C` 中断。

> [!warning] `for i in 5`
> `TypeError: 'int' object is not iterable`。整数不可迭代，用 `range(5)`。

> [!warning] `else if`
> Python 没有 `else if`，只有 `elif`。

> [!warning] match 漏兜底
> 所有 case 都不匹配时什么都不做，且不报错，容易掩盖问题。

## 5. 自测

> [!question]- 输出什么？
> ```python
> for i in range(1, 10, 3):
>     print(i, end=" ")
> ```
> **答案**：`1 4 7`。

> [!question]- 输出什么？
> ```python
> for i in range(3):
>     if i == 1:
>         break
> else:
>     print("done")
> print("end")
> ```
> **答案**：只输出 `end`。循环被 `break` 打断，else 不执行。

> [!question]- 用 for 求 1~100 的偶数和。
> **答案**：
> ```python
> total = 0
> for i in range(2, 101, 2):
>     total += i
> print(total)   # 2550
> ```
