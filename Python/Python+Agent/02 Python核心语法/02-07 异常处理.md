## 0. 速记

> [!tip] 五句话
> - `try / except / else / finally`：else 无异常时执行，finally 一定执行
> - 捕获要具体，别用裸 `except:`
> - 异常不处理会沿调用栈向上抛，直到程序崩溃
> - `raise` 主动抛出，`raise X from e` 保留原因
> - 自定义异常继承 `Exception`

## 1. 语法速查

### 1.1 完整结构

```python
try:
    n = int(input("数字："))
    print(10 / n)
except ValueError:
    print("不是数字")
except ZeroDivisionError as e:
    print("不能为 0：", e)
except (TypeError, KeyError):
    print("类型或键错误")
else:
    print("没有异常")
finally:
    print("一定执行")
```

- 多个 `except` 从上往下匹配，命中一个就结束。
- `as e` 拿到异常对象，`str(e)` 是错误信息。

### 1.2 主动抛出

```python
def set_age(age):
    if age < 0:
        raise ValueError("年龄不能为负")
    return age
```

### 1.3 自定义异常

```python
class AgeError(Exception):
    pass

raise AgeError("年龄非法")
```

### 1.4 异常传递

```python
def a():
    b()

def b():
    1 / 0

a()    # ZeroDivisionError 一路抛到最外层
```

不捕获就继续往上抛，直到有人处理或程序终止。

### 1.5 常见异常

| 异常 | 触发场景 |
|---|---|
| `NameError` | 变量没定义 |
| `TypeError` | 类型不匹配 |
| `ValueError` | 类型对但值不对，如 `int("abc")` |
| `IndexError` | 列表下标越界 |
| `KeyError` | 字典键不存在 |
| `ZeroDivisionError` | 除以 0 |
| `FileNotFoundError` | 文件不存在 |
| `AttributeError` | 对象没有这个属性 |

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 语法 | `try / catch` | `try / except` |
| 匹配方式 | 按类型 | 按类型或类型元组 |
| 清理 | 析构 / RAII | `finally` |
| 抛出 | `throw` | `raise` |
| 异常声明 | `throw()` 规格 | 无 |
| 异常基类 | `std::exception` | `BaseException` |
| 全捕获 | `catch (...)` | `except Exception` |
| 错误处理风格 | 错误码 + 异常并存 | EAFP：先做，出错再处理 |

## 3. 易漏点

- **else 的位置**：在 `except` 之后、`finally` 之前，只有 try 没异常才执行。
- **finally 一定执行**：即使 try 里有 `return`；finally 里的 `return` 会覆盖前面的返回值。
- **except 顺序**：子类必须写在父类前面，否则永远命中父类。
- **`except Exception` 抓不到全部**：`KeyboardInterrupt`、`SystemExit` 直接继承 `BaseException`。
- **`as e` 的作用域**：except 块结束后 `e` 会被删除，块外再用会 `NameError`。
- **裸 `except:`** 等价于 `except BaseException:`，连 Ctrl+C 都吞掉。
- **异常链**：`raise NewError(...) from e` 保留原始异常。

## 4. 易错点

> [!warning] 裸 except 吞掉所有错误
> `except:` 会把拼写错误、键盘中断一起吞了，排查困难。写具体类型。

> [!warning] 捕获后什么都不做
> `except ValueError: pass` 等于隐藏 bug。至少记日志或给出提示。

> [!warning] finally 里 return
> 会覆盖 try 里的返回值，函数正常结果被丢掉。

> [!warning] except 顺序写反
> `except Exception` 写在 `except ValueError` 前面，后者永远不执行。

> [!warning] 用异常做正常流程
> 能 `if` 判断的别用 `try`，异常只处理「意外」。

> [!warning] 在 except 块外使用 e
> Python 3 会在块结束时删除 `e`，需要的话先赋给别的变量。

## 5. 自测

> [!question]- 输出顺序是什么？
> ```python
> try:
>     print("A")
>     1 / 0
> except ZeroDivisionError:
>     print("B")
> else:
>     print("C")
> finally:
>     print("D")
> ```
> **答案**：`A B D`。发生异常，else 不执行，finally 一定执行。

> [!question]- 哪个分支命中？
> ```python
> try:
>     int("abc")
> except ValueError:
>     print("V")
> except Exception:
>     print("E")
> ```
> **答案**：`V`。`ValueError` 是 `Exception` 的子类，写在前面的先匹配。

> [!question]- 自定义 `AgeError`，年龄小于 0 时抛出。
> **答案**：
> ```python
> class AgeError(Exception):
>     pass
>
> def check(age):
>     if age < 0:
>         raise AgeError("年龄不能为负")
>     return age
> ```
