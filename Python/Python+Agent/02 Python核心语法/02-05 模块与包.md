## 0. 速记

> [!tip] 五句话
> - 一个 `.py` 就是一个模块；目录 + `__init__.py` 就是包
> - `import x` 用 `x.f()`；`from x import f` 直接 `f()`
> - 模块只在第一次 import 时执行顶层代码，之后走缓存
> - `if __name__ == "__main__":` 区分「直接运行」和「被导入」
> - `__all__` 只控制 `from x import *` 导入哪些名字

## 1. 语法速查

### 1.1 四种导入写法

```python
import math                  # math.sqrt()
import numpy as np           # np.array()
from math import sqrt, pi    # 直接用 sqrt
from math import *           # 不推荐，污染命名空间
```

### 1.2 自定义模块

```python
# my_module.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    print(add(1, 2))         # 只有直接运行时才执行
```

### 1.3 `__all__`

```python
# my_module.py
__all__ = ["add"]

def add(a, b): ...
def sub(a, b): ...
```

`from my_module import *` 只会导入 `add`。

### 1.4 包

```
pkg/
├── __init__.py      # 包标识，可为空
├── a.py
└── b.py
```

```python
from pkg import a          # 导入模块
from pkg.a import f        # 导入函数
from . import b            # 包内相对导入
```

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 引入方式 | `#include` 文本展开 | `import` 加载模块对象 |
| 组织单位 | 头文件 + 源文件 | 一个 `.py` |
| 命名空间 | `namespace` | 模块名 |
| 重复引入 | include guard | 自动缓存，只执行一次 |
| 程序入口 | `main()` | `if __name__ == "__main__"` |
| 包 | 目录 + 构建配置 | 目录 + `__init__.py` |
| 符号导出 | 头文件声明 | `__all__` 控制 `*` |
| 依赖解析 | 编译期链接 | 运行时 import |

## 3. 易漏点

- **import 只执行一次**：放在 `sys.modules` 里，改代码要重启解释器。
- **`__name__` 的值**：直接运行是 `"__main__"`，被导入时是模块名。
- **`__all__` 只影响 `*`**：`from m import sub` 照样能导入没写进 `__all__` 的名字。
- **相对导入只能在包内用**：直接 `python pkg/a.py` 会报 `ImportError`。
- **模块名别撞标准库**：自己的 `random.py` 会遮蔽标准库 `random`。
- **`__init__.py` 可为空**，但课程要求有；没有它就不是常规包。
- **`import a.b` 绑定的是 `a`**，不是 `b`，用的时候写 `a.b.f()`。

## 4. 易错点

> [!warning] 循环导入
> `a.py` 导入 `b`，`b.py` 又导入 `a` → `ImportError` 或 `AttributeError`。把公共部分抽到第三方模块。

> [!warning] 忘了 `__init__.py`
> `ModuleNotFoundError: No module named 'pkg'`。包目录下必须有它。

> [!warning] 直接运行包内模块
> 文件里的 `from . import x` 会报「attempted relative import with no known parent package」。用 `python -m pkg.a` 运行。

> [!warning] `import *` 覆盖同名变量
> 两个模块都有 `f`，后导入的会覆盖先导入的。显式导入具体名字。

> [!warning] 改了模块不生效
> 解释器有缓存。重启，或 `importlib.reload(mod)`。

> [!warning] 模块名和标准库重名
> 新建 `json.py` 后 `import json` 导入的是你自己的文件。

## 5. 自测

> [!question]- `print(__name__)` 在「直接运行」和「被导入」时分别输出什么？
> **答案**：直接运行输出 `__main__`；被导入输出模块名，如 `my_module`。

> [!question]- `m.py` 里写了 `__all__ = ["a"]`，`from m import *` 会导入什么？
> **答案**：只导入 `a`。没写进 `__all__` 的 `b` 不会被导入，但 `from m import b` 仍可用。

> [!question]- 目录 `pkg/` 下有 `__init__.py` 和 `tool.py`，怎么导入 `tool.py` 里的 `run()`？
> **答案**：
> ```python
> from pkg.tool import run
> # 或
> from pkg import tool
> tool.run()
> ```
