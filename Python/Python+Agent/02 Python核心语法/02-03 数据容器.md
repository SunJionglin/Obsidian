## 0. 速记

> [!tip] 五句话
> - `list` ≈ vector，`str` 不可变，`tuple` ≈ const，`set` 无序去重，`dict` ≈ unordered_map
> - 切片 `s[start:end:step]` 左闭右开，负索引从 -1 开始
> - `sort()` 原地排序返回 `None`，`sorted()` 返回新列表
> - 容器赋值是引用：`b = a` 不拷贝
> - 推导式就是一行 for：`[expr for x in it if cond]`

## 1. 语法速查

### 1.1 list

```python
nums = [3, 1, 2]
nums[0], nums[-1]      # 3, 2
nums[0:2]              # [3, 1]
nums[::2]              # [3, 2]
nums[1:] = [9]         # 切片赋值
```

| 方法 | 作用 | 返回 |
|---|---|---|
| `append(x)` | 尾部追加 | `None` |
| `insert(i, x)` | 指定位置插入 | `None` |
| `remove(x)` | 删除第一个 x，不存在报错 | `None` |
| `pop(i=-1)` | 删除并返回 | 元素 |
| `sort(reverse=False)` | 原地排序 | `None` |
| `reverse()` | 原地反转 | `None` |
| `index(x)` | 查找下标 | `int` |
| `count(x)` | 计数 | `int` |
| `extend(it)` | 追加多个 | `None` |
| `clear()` / `copy()` | 清空 / 浅拷贝 | `None` / `list` |

```python
len(nums), sum(nums), min(nums), max(nums)
[1, 2] + [3]                    # 合并
[x * x for x in range(1, 6)]    # 推导式
[x for x in nums if x % 2 == 0] # 带条件
```

### 1.2 str

```python
s = "Hello"
s[0], s[-1], s[1:4]        # H, o, ell
s.upper(), s.lower()
s.strip(), s.split(","), "-".join(["a", "b"])
s.replace("l", "L")
s.find("l"), s.count("l")
s.startswith("He"), "ell" in s
```

不可变：所有方法都返回新串，原串不动。

### 1.3 tuple

```python
t = (1, 2, 3)
t[0], t[1:]
t.count(2), t.index(2)
a, b, c = t                 # 解包
a, *rest = (1, 2, 3)        # a=1, rest=[2, 3]
one = (1,)                  # 单元素必须有逗号
```

### 1.4 set

```python
s = {1, 2, 2, 3}            # {1, 2, 3} 自动去重
s.add(4)
s.remove(1)                 # 不存在报 KeyError
s.discard(99)               # 不存在不报错
a & b, a | b, a - b         # 交、并、差
a.intersection(b), a.union(b), a.difference(b)
```

空集合写 `set()`；`{}` 是空字典。

### 1.5 dict

```python
d = {"王林": 670, "韩立": 556}
d["王林"]                   # 670
d.get("李慕婉")             # None，不报错
d["李慕婉"] = 582           # 新增
d["王林"] = 680             # 修改
del d["韩立"]               # 删除
d.pop("韩立", None)
d.keys(), d.values(), d.items()
for k, v in d.items():
    print(k, v)
```

key 必须可哈希，value 任意；key 重复时后者覆盖前者。

### 1.6 五种容器对比

| 容器 | 有序 | 可变 | 可重复 | 索引 | 典型用途 |
|---|---|---|---|---|---|
| `list` | 是 | 是 | 是 | 是 | 序列、栈、队列 |
| `str` | 是 | 否 | 是 | 是 | 文本 |
| `tuple` | 是 | 否 | 是 | 是 | 固定记录、多返回值 |
| `set` | 否 | 是 | 否 | 否 | 去重、集合运算 |
| `dict` | 是* | 是 | key 唯一 | 键访问 | 映射、计数 |

\* 3.7+ 保持插入顺序。

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 动态数组 | `std::vector` | `list` |
| 字符串 | `std::string` 可变 | `str` 不可变 |
| 定长组合 | `std::pair` / `std::tuple` | `tuple` |
| 有序集合 | `std::set`（红黑树） | `set`（哈希，无序） |
| 映射 | `std::unordered_map` | `dict` |
| 切片 | 无 | `s[a:b:c]` |
| 负索引 | 无 | `s[-1]` |
| 赋值 | 拷贝 | 引用（换绑） |
| 越界 | UB | 索引越界 `IndexError`，切片越界不报错 |
| 推导式 | 无 | `[x for x in ...]` |

## 3. 易漏点

- **单元素元组**：`(1)` 是 int，`(1,)` 才是 tuple。
- **空容器**：`{}` 是空 dict，空 set 要写 `set()`。
- **`sort()` 返回 None**：`nums = nums.sort()` 会把列表弄丢，用 `sorted(nums)`。
- **切片越界不报错**：`[1, 2][0:99]` 返回 `[1, 2]`。
- **`[[0] * 3] * 3`**：三个子列表是同一个对象，改一个全变。
- **dict 的 key 必须可哈希**：list、set、dict 都不能当 key。
- **set 无序**：打印顺序不保证，不能靠顺序做题。
- **`b = a` 是引用**：要拷贝用 `a.copy()`、`a[:]`、`list(a)`。
- **遍历 dict 时增删 key**：会抛 `RuntimeError`。

## 4. 易错点

> [!warning] 索引越界
> `[1, 2, 3][3]` → `IndexError: list index out of range`。合法下标是 `-3 ~ 2`。

> [!warning] 直接取不存在的 key
> `d["不存在"]` → `KeyError`。不确定就用 `d.get(key, 默认值)`。

> [!warning] 把 sort 的返回值当列表
> `nums = nums.sort()` → `None`。`sort()` 原地改，不返回新列表。

> [!warning] 修改字符串的某个字符
> `s[0] = "H"` → `TypeError`。字符串不可变，用切片拼新串。

> [!warning] 以为赋值是拷贝
> `b = a; b.append(1)` 会让 `a` 也变。要独立副本用 `a.copy()`。

> [!warning] remove 不存在的元素
> `nums.remove(99)` → `ValueError`。先 `in` 判断，或用 `discard`（set）。

> [!warning] 把 list 放进 set
> `{ [1, 2] }` → `TypeError: unhashable type: 'list'`。set 元素必须可哈希。

## 5. 自测

> [!question]- 输出什么？
> ```python
> s = [0, 1, 2, 3, 4, 5]
> print(s[1:4], s[::2], s[::-1])
> ```
> **答案**：`[1, 2, 3] [0, 2, 4] [5, 4, 3, 2, 1, 0]`。

> [!question]- 用 set 求两个列表的交集、并集、差集。
> ```python
> a, b = [1, 2, 3], [2, 3, 4]
> ```
> **答案**：
> ```python
> sa, sb = set(a), set(b)
> print(sa & sb, sa | sb, sa - sb)
> # {2, 3} {1, 2, 3, 4} {1}
> ```

> [!question]- 统计字符串中每个字符出现的次数。
> **答案**：
> ```python
> s = "hello"
> count = {}
> for ch in s:
>     count[ch] = count.get(ch, 0) + 1
> print(count)   # {'h': 1, 'e': 1, 'l': 2, 'o': 1}
> ```
