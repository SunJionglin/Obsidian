## 0. 速记

> [!tip] 五句话
> - 类 = 模板，对象 = 实例；`__init__` 在对象创建后自动调用
> - 实例方法第一个参数是 `self`，调用时不用传
> - 实例属性属于对象，类属性属于类、被所有实例共享
> - 魔法方法由 Python 在特定时机自动调用，不用手动调
> - 没有真正的 private，只有约定：`_` 保护、`__` 名字改写

## 1. 语法速查

### 1.1 类与对象

```python
class Student:
    school = "黑马"                   # 类属性

    def __init__(self, name, score):
        self.name = name              # 实例属性
        self.score = score

    def show(self):                   # 实例方法
        print(f"{self.name}: {self.score}")
```

```python
s = Student("王林", 670)
s.show()          # 王林: 670
```

- 类名用大驼峰：`Student`、`UserInfo`。
- `__init__` 负责初始化，不是「创建对象」本身。

### 1.2 实例属性 vs 类属性

```python
class Dog:
    kind = "犬科"          # 类属性，所有实例共享

d1, d2 = Dog(), Dog()
d1.kind = "哈士奇"        # 给 d1 新建实例属性，不影响类
print(Dog.kind, d1.kind, d2.kind)   # 犬科 哈士奇 犬科
```

### 1.3 魔法方法

```python
class Student:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"Student({self.name})"

    def __eq__(self, other):
        return self.name == other.name

    def __lt__(self, other):
        return self.name < other.name
```

| 魔法方法 | 触发时机 |
|---|---|
| `__init__` | 创建对象后初始化 |
| `__str__` | `print(obj)` / `str(obj)` |
| `__repr__` | 交互式环境直接显示 |
| `__eq__` | `==` |
| `__lt__` / `__le__` / `__gt__` / `__ge__` | `<` `<=` `>` `>=` |

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 类定义结尾 | `};` | 无分号 |
| 构造函数 | `ClassName(...)` | `__init__(self, ...)` |
| this | 隐式 | `self` 显式写在参数第一位 |
| 访问控制 | `public` / `private` / `protected` | 无，靠 `_` / `__` 约定 |
| 成员声明 | 类内声明 | 在 `__init__` 里动态创建 |
| 静态成员 | `static` | 类属性 |
| 运算符重载 | `operator+` | `__add__` 等魔法方法 |
| 对象比较 | 默认按值 / 自定义 | 默认按身份，需 `__eq__` |
| 打印对象 | 重载 `<<` | `__str__` |
| 析构 | 确定性析构 | 引用计数 + GC，`__del__` 时机不定 |

## 3. 易漏点

- **`__init__` 拼错不报错**：写成 `__int__` 只是永远不会被调用。
- **self 不是关键字**：只是约定，但别改成别的名字。
- **实例赋值会遮蔽类属性**：`d1.kind = ...` 创建的是实例属性，类属性没变。
- **可变类属性共享**：`class A: items = []`，所有实例共用同一个列表。
- **没有 `__str__`**：`print(obj)` 输出 `<__main__.Student object at 0x...>`。
- **定义 `__eq__` 后对象不可哈希**：`__hash__` 自动变成 `None`，不能放进 set。
- **`__del__` 时机不确定**：靠引用计数和 GC，不要依赖它释放资源。
- **只读属性会向上找**：实例上没有，就去类属性里找。

## 4. 易错点

> [!warning] 方法忘写 self
> `def show():` → 调用时 `TypeError: show() takes 0 positional arguments but 1 was given`。

> [!warning] 用类名直接调实例方法
> `Student.show()` 少传 `self`，报 `TypeError`。要传实例：`Student.show(s)`。

> [!warning] `__init__` 参数对不上
> `Student()` 少传参数 → `TypeError: __init__() missing 1 required positional argument`。

> [!warning] 把类属性当实例属性改
> `d1.kind = ...` 只影响 `d1`；想改所有实例要 `Dog.kind = ...`。

> [!warning] 打印对象不是想要的内容
> 缺 `__str__`，只看到内存地址。加 `__str__` 返回字符串。

> [!warning] 用 is 比较对象内容
> `is` 比的是身份（内存地址），内容相等要用 `==`（并定义 `__eq__`）。

## 5. 自测

> [!question]- 输出什么？
> ```python
> class A:
>     x = 1
>
> a = A()
> a.x = 2
> print(A.x, a.x)
> ```
> **答案**：`1 2`。`a.x = 2` 给实例新建了属性，类的 `x` 没变。

> [!question]- 想让 `print(obj)` 输出 `Student(王林)`，要定义哪个方法？
> **答案**：
> ```python
> def __str__(self):
>     return f"Student({self.name})"
> ```

> [!question]- 补全类：`BankAccount`，有 `owner`、`balance`，支持存钱和取钱，余额不足抛异常。
> **答案**：
> ```python
> class BankAccount:
>     def __init__(self, owner, balance=0):
>         self.owner = owner
>         self.balance = balance
>
>     def deposit(self, amount):
>         self.balance += amount
>
>     def withdraw(self, amount):
>         if amount > self.balance:
>             raise ValueError("余额不足")
>         self.balance -= amount
> ```
