## 0. 速记

> [!tip] 本鱼的五句话
> - 哼，变量是标签不是盒子：`a = b` 是换绑，不是「从此 b 跟着 a 走」
> - 类型属于值不属于变量：`type()` 查，`isinstance()` 判（它认继承，别被骗）
> - `input()` 永远返回 `str`，永远。本鱼试过。
> - `/` 永远 float，`//` 向下取整，`%` 的符号跟除数
> - 新代码统一 f-string；还在用 `+` 拼字符串的，见一个笑一个

## 1. 语法速查

### 1.1 字面量与变量

```python
18, 3.14, "abc", True, None   # 字面量：直接写死的值
a = 1                          # 定义
a = 2                          # 重新赋值（换绑）
a = b = 0                      # 连续赋值
a, b = 1, 2                    # 多变量赋值
a, b = b, a                    # 交换，C++ 要三行，这里一行
```

- 变量是存单个数据的名字，先赋值后使用，一名一值。
- 用途：打印、参与计算、记录中间结果。
- 动态类型：同一个变量可以先存 `int` 再存 `str`，类型跟着值走。

### 1.2 标识符

| 规则 | 说明 | 合法 / 非法 |
|---|---|---|
| 字符集 | 字母、数字、下划线 | `na_me` / `na$me` |
| 开头 | 不能是数字 | `name6` / `6name` |
| 关键字 | 不能用保留字 | `user_name` / `and` |
| 大小写 | 严格区分 | `age`、`Age`、`AGE` 是三个 |

规范：`snake_case`、见名知意、别用拼音。

### 1.3 类型

| 类型 | 字面量 | 备注 |
|---|---|---|
| `int` | `18`、`-5` | 任意精度，不溢出 |
| `float` | `3.14`、`1.0` | 双精度 |
| `str` | `"a"`、`'a'`、`"""多行"""` | 不可变 |
| `bool` | `True`、`False` | `int` 子类，`True + 1 == 2` |
| `NoneType` | `None` | 空值 |

```python
type(True)                 # <class 'bool'>
isinstance(True, int)      # True ← 认继承
type(True) is int          # False
```

### 1.4 字符串

```python
s1, s2, s3 = "a", 'a', """多行"""
s1 + s2                    # 只能 str + str
"%s-%s" % (1, 2)           # 旧写法
f"{1}-{2}"                 # 推荐，可写表达式 {age + 1}、格式 {x:.2f}
```

转义：`\'`、`\"`、`\n`、`\t`、`\\`。三引号同时是函数文档字符串（docstring）的写法。
不可变：`s1[0] = "A"` → `TypeError`，所有字符串方法都返回新串。

### 1.5 输入输出与类型转换

```python
name = input("姓名：")          # 永远 str
age = int(input("年龄："))      # 要数字先转
print(name, age, sep="-", end="")
```

| 转换 | 用法 | 边界 |
|---|---|---|
| `int()` | 字符串/浮点 → 整数 | `int("3.14")` 报 `ValueError` |
| `float()` | 字符串 → 浮点 | `float("abc")` 报错 |
| `str()` | 任意 → 字符串 | 拼接前必须转 |
| `bool()` | 任意 → 布尔 | 只有 `0`、`""`、`None`、空容器为 `False` |

### 1.6 运算符

| 类别 | 运算符 |
|---|---|
| 算术 | `+ - * / // % **` |
| 赋值 | `= += -= *= /= //= %= **=` |
| 比较 | `== != > >= < <=` |
| 逻辑 | `and or not` |

```python
print(10 + 4, 10 / 4, 10 // 4, 10 % 4, 10 ** 4)   # 14 2.5 2 2 10000
```

`and` 全真才真，`or` 一真即真，`not` 取反。
优先级：`**` > `* / // %` > `+ -` > 比较 > `not` > `and` > `or`。

## 2. 与 C++ 的差异

本鱼给你开个小灶：下面每一行，都是「照 C++ 直觉写就会错」的地方。

| 维度 | C++ | Python |
|---|---|---|
| 声明 | `int a = 1;` | `a = 1` |
| 语句结束 | `;` | 换行 |
| 代码块 | `{}` | 缩进 |
| 布尔字面量 | `true` / `false` | `True` / `False` |
| 自增 | `i++` | 无，写 `i += 1` |
| 类型系统 | 静态，编译期检查 | 动态，运行期 |
| 赋值语义 | 拷贝值 | 换绑标签 |
| 字符串 | `std::string` 可变 | `str` 不可变 |
| 整数除法 | `7 / 2 == 3` | `7 / 2 == 3.5` |
| 整除运算符 | 无 | `7 // 2 == 3` |
| 负数取整 | `-7 / 2 == -3`（向零） | `-7 // 2 == -4`（向下） |
| 取模符号 | 跟被除数，`-7 % 2 == -1` | 跟除数，`-7 % 2 == 1` |
| 整数溢出 | 有（UB） | 任意精度 |
| 三元 | `a ? b : c` | `b if a else c` |
| 空值 | `nullptr` | `None` |
| 强转 | `(int)x` | `int(x)` |

C++ 的 `&&`、`||`、`!` 对应 Python 的 `and`、`or`、`not`——再手滑打 `&&`，Python 会直接甩你一个 `SyntaxError`。

## 3. 易漏点

- **变量本身没有类型**：`type(x)` 返回的是 `x` 当前所指值的类型，不是变量的类型。
- **`isinstance` 认继承**：`isinstance(True, int)` 是 `True`，但 `type(True) is int` 是 `False`。
- **链式比较**：`10 <= n <= 20` 合法，等价于 `10 <= n and n <= 20`。
- **f-string 格式符**：`{bmi:.2f}` 保留两位小数，`{x:>5}` 右对齐。
- **`print` 的 `sep` / `end`**：`print(1, 2, sep="-")` → `1-2`；`end=""` 不换行。
- **负数整除方向**：`-7 // 2 == -4`，不是 `-3`。
- **字符串方法不改原串**：`s.upper()` 返回新串，`s` 本身没变。
- **`and` / `or` 返回操作数**：`0 and 5` → `0`，`3 and 5` → `5`。别问，问就是本鱼拿它当布尔用，结果打印出个 `5`。
- **`/` 结果一定是 float**：`10 / 2` → `5.0`。

## 4. 易错点

> [!warning] 变量没赋值就用
> `print(score)` → `NameError`。Python 从上往下执行，必须先赋值。

> [!warning] `input()` 直接参与计算
> `input("金额：") - 100` → `TypeError`。`input()` 返回 `str`，先 `int()` / `float()`。

> [!warning] 字符串和数字相加
> `"年龄" + 18` → `TypeError`。改 `str(18)` 或直接 `f"年龄{18}"`。

> [!warning] `int("3.14")` 报错
> `ValueError`。`int()` 只认整数字符串，先 `float()` 再 `int()`：`int(float("3.14"))`。

> [!warning] 浮点数不精确
> `0.1 + 0.2 == 0.3` → `False`。二进制无法精确表示，比较用 `abs(a - b) < 1e-9`。—— 本鱼拿它算过一分钱，账对不上，呜。

> [!warning] `=` 当比较用
> `if x = 1:` 语法错误。`=` 赋值，`==` 比较。

> [!warning] 小写 `true`
> `true` 不是关键字，是合法变量名，直接当布尔用会 `NameError`。Python 只有 `True` / `False`。

## 5. 自测

> [!question]- 题 1：这四个表达式输出什么？（答错本鱼不会笑你的……才怪）
> ```python
> print(7 // 2, -7 // 2, 7 % 2, -7 % 2)
> ```
> **答案**：`3 -4 1 1`。整除向下取整，取模符号跟除数。

> [!question]- 题 2：这段代码有几处错？
> ```python
> 2name = "小明"
> age = input("年龄：")
> print("明年" + age + 1)
> ```
> **答案**：3 处。`2name` 数字开头非法；`age` 是 `str`；`str + int` 类型错误。改 `name2 = "小明"`、`age = int(input(...))`、`print(f"明年{age + 1}")`。

> [!question]- 题 3：把 C++ 的交换写法改成 Python，并说明为什么不用临时变量。
> ```cpp
> int t = a; a = b; b = t;
> ```
> **答案**：`a, b = b, a`。右边先求值成元组 `(b, a)`，再依次解包赋值。
