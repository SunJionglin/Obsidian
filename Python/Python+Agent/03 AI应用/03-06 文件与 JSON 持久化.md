## 0. 速记

> [!tip] 五句话
> - 三步：`open` → 读/写 → 关闭，最佳实践是用 `with`
> - 模式：`r` 读、`w` 覆盖写、`a` 追加、`b` 二进制
> - 文本文件必须写 `encoding="utf-8"`，否则 Windows 可能乱码
> - 存 JSON 用 `json.dump`，读用 `json.load`
> - `ensure_ascii=False` 才能让中文正常显示

## 1. 语法速查

### 1.1 打开模式

| 模式 | 含义 | 文件不存在时 |
|---|---|---|
| `r` | 只读（默认） | 报 `FileNotFoundError` |
| `w` | 覆盖写 | 创建新文件 |
| `a` | 追加 | 创建新文件 |
| `r+` | 读写 | 报错 |
| `b` | 二进制（配合上面） | — |

### 1.2 文本读写

```python
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")

with open("a.txt", "r", encoding="utf-8") as f:
    text = f.read()          # 一次读完
    # lines = f.readlines()  # 按行读成列表
```

### 1.3 JSON 文件

```python
import json

data = {"name": "涛哥", "age": 18, "hobbies": ["reading"]}

with open("user.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

with open("user.json", "r", encoding="utf-8") as f:
    data = json.load(f)
```

### 1.4 目录与路径

```python
import os

os.path.exists("sessions")     # 判断是否存在
os.mkdir("sessions")           # 创建目录
os.listdir("sessions")         # 列出内容
os.remove("a.txt")             # 删除文件（不是目录）
```

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 文件流 | `std::fstream` | `open()` |
| 关闭 | 析构自动关 | `with` 自动关 |
| 编码 | 字节流，自己处理 | `encoding` 参数 |
| 目录操作 | `std::filesystem` | `os` / `pathlib` |
| 错误 | 流状态位 | 抛异常 |
| 文本/二进制 | `ios::binary` | 模式加 `b` |
| JSON | 第三方库 | 内置 `json` |

## 3. 易漏点

- **`w` 会清空原文件**：想保留内容用 `a`。
- **不写 `encoding` 有风险**：Windows 默认 GBK，中文可能乱码或报 `UnicodeDecodeError`。
- **`with` 在异常时也会关闭文件**：比手写 `try/finally` 干净。
- **`json.dump` 的第一个参数是对象，第二个才是文件**：顺序别反。
- **`ensure_ascii` 默认 True**：中文会变成 `\u6d9b` 这样的转义。
- **`read()` 后指针在末尾**：再 `read()` 得到空字符串。
- **相对路径相对运行目录**：不是脚本文件所在目录。

## 4. 易错点

> [!warning] 忘记关闭文件
> 不写 `with` 也不 `close()`，内容可能没刷到磁盘。统一用 `with`。

> [!warning] 想追加却用了 `w`
> 原文件被清空。追加用 `a`。

> [!warning] 中文乱码
> 读写都加 `encoding="utf-8"`，存 JSON 再加 `ensure_ascii=False`。

> [!warning] `json.load` 空文件
> 抛 `JSONDecodeError`。读之前判断文件是否为空，或 `try/except`。

> [!warning] 路径不存在
> `FileNotFoundError`。写之前先 `os.makedirs(dir, exist_ok=True)`。

> [!warning] 把 dict 直接 write 进文件
> `f.write(dict)` → `TypeError`。先 `json.dumps` 或 `str()`。

## 5. 自测

> [!question]- `w` 和 `a` 的区别？
> **答案**：`w` 清空后写，`a` 在末尾追加；文件不存在时两者都会创建。

> [!question]- 用 `with` 的好处？
> **答案**：离开代码块自动关闭文件，即使中途抛异常也会关，等价于 `try/finally`。

> [!question]- 怎么让 JSON 文件里的中文可读？
> **答案**：`json.dump(data, f, ensure_ascii=False, indent=2)`，并且 `open` 时指定 `encoding="utf-8"`。
