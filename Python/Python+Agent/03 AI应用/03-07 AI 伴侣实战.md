## 0. 速记

> [!tip] 五句话
> - 会话记忆 = 每次把历史 `messages` 全部带上（滚雪球）
> - `st.session_state` 管当前会话，JSON 文件管历史会话
> - 会话标识用时间戳，天生唯一且可排序
> - 侧边栏负责新建、加载、删除
> - 流式输出用 `stream=True` 逐块拼接

## 1. 语法速查

### 1.1 项目结构

```
ai_partner/
```

### 1.2 会话数据结构

```json
{
  "nick_name": "小甜甜",
  "nature": "温柔",
  "current_session": "2026-10-22_12-00-00",
  "messages": [

    {"role": "assistant", "content": "你好呀～"}
  ]

```

### 1.3 滚雪球：带上全部历史

```python
messages = [{"role": "system", "content": system_prompt}]
messages += st.session_state.messages

resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=messages,

```

### 1.4 会话标识与存取

```python
from datetime import datetime

def new_session_name():
    return datetime.now().strftime("%Y-%m-%d_%H-%M-%S")

def save_session():
    path = f"sessions/{st.session_state.current_session}.json"
    with open(path, "w", encoding="utf-8") as f:
        json.dump({
            "messages": st.session_state.messages,
            "nick_name": st.session_state.nick_name,
        }, f, ensure_ascii=False, indent=2)
```

### 1.5 三元运算符

```python
label = "有消息" if st.session_state.messages else "暂无消息"
```

语法：`<真值> if <条件> else <假值>`，等价于 C++ 的 `cond ? a : b`。

## 2. 与 C++ 的差异

| 维度 | C++ | Python + Streamlit |
|---|---|---|
| 项目组织 | CMake + 多文件 | 单脚本 + 模块 |
| 界面状态 | 成员变量 | `st.session_state` |
| 持久化 | 数据库 / 二进制文件 | JSON 文件 |
| 热更新 | 重新编译 | 保存后 Rerun |
| 并发 | 线程 / 进程 | Streamlit 单线程模型 |
| 错误处理 | 异常 / 错误码 | `st.error` + `try/except` |

## 3. 易漏点

- **会话名用时间戳**：`%Y-%m-%d_%H-%M-%S`，避免重名覆盖。
- **保存前判空**：`current_session` 为空时不要写文件。
- **删除当前会话要清空**：同时重置 `messages` 和 `current_session`。
- **`messages` 会越来越长**：注意上下文上限，必要时截断旧消息。
- **目录不存在先建**：`os.makedirs("sessions", exist_ok=True)`。
- **三元表达式顺序**：值在前，条件在中间，别写成 `a if b`。
- **流的 chunk 可能为空**：`delta.content` 为 `None` 时跳过。

## 4. 易错点

> [!warning] 只传当前问题
> AI 完全失忆，因为历史没带上。每次请求都要拼完整 `messages`。

> [!warning] 会话名重复
> 同一秒内新建两次会覆盖。加毫秒或 UUID。

> [!warning] 删除文件后界面没更新
> 先 `os.remove`，再更新 `session_state`，最后 `st.rerun()`。

> [!warning] 路径写死绝对路径
> 换台机器就跑不起来。用相对路径，并在项目根目录启动。

> [!warning] 流式输出没拼接
> 每块单独 `print` 会断行；用 `end=""` 或先累加再一次性写入。

> [!warning] JSON 存中文变乱码
> 忘了 `ensure_ascii=False`。

## 5. 自测

> [!question]- 会话记忆是怎么实现的？
> **答案**：每次请求把 `system` + 历史 `user/assistant` 消息一起放进 `messages`，模型据此理解上下文。

> [!question]- `"a" if cond else "b"` 等价于 C++ 的什么？
> **答案**：`cond ? "a" : "b"`。

> [!question]- 新建会话要改哪些状态？
> **答案**：生成新的 `current_session`，清空 `messages`，必要时保存旧会话。
