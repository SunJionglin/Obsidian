## 0. 速记

> [!tip] 五句话
> - 排序用 `sort_values`，多列排序的 `ascending` 传列表
> - 分组用 `groupby`，本质是「split → apply → combine」
> - 分组后必须接聚合：`sum/count/max/min/mean`
> - 一次要多个指标用 `agg([...])`
> - 分组结果的索引是分组键，需要平铺就 `reset_index()`

## 1. 语法速查

### 1.1 排序

```python
df.sort_values("销售数量")                          # 升序
df.sort_values("销售数量", ascending=False)         # 降序
df.sort_values(["销售数量", "订单日期"],
               ascending=[True, False])              # 多列，一升一降
df.sort_values("评分", inplace=True)                # 原地排序
```

### 1.2 分组聚合

```python
df.groupby("产品类别")["销售额"].sum()
df.groupby("产品类别")["销售额"].count()
df.groupby("产品类别")["销售额"].mean()
df.groupby("产品类别")["销售额"].max()

df.groupby("产品类别")["销售额"].agg(["sum", "count", "max", "min", "mean"])
```

### 1.3 多列分组与平铺

```python
df.groupby(["城市", "产品类别"])["销售额"].sum()

result = df.groupby("产品类别")["销售额"].sum().reset_index()
# 变成普通两列表格：产品类别 / 销售额
```

### 1.4 不同列不同聚合

```python
df.groupby("产品类别").agg({
    "销售数量": "sum",
    "销售额": "sum",
    "单价": "mean",
})
```

## 2. 与 C++ 的差异

| 维度 | C++ | Pandas |
|---|---|---|
| 排序 | `std::sort` + 比较器 | `sort_values` |
| 多列排序 | 手写比较器 | `ascending=[True, False]` |
| 分组 | `map<key, vector>` | `groupby` |
| 聚合 | 遍历手算 | `sum/count/mean` |
| 结果结构 | 自定义 | 索引为分组键的 Series/DataFrame |
| 稳定性 | 可指定 | 默认稳定排序 |

## 3. 易漏点

- **`ascending` 多列要传列表**：长度必须和 `by` 一致。
- **`sort_values` 默认返回新表**：不赋值等于没排。
- **`groupby` 后不聚合没有意义**：得到的是 GroupBy 对象。
- **分组键会变成索引**：画图或写 CSV 前先 `reset_index()`。
- **`count` 不统计 NaN**：要统计行数用 `size()`。
- **多列分组结果是 MultiIndex**：`reset_index()` 后变普通列。
- **`groupby` 默认丢弃分组键为 NaN 的行**：需要时加 `dropna=False`。

## 4. 易错点

> [!warning] 排序后没赋值
> `df.sort_values("评分")` 只是返回新表，原表顺序没变。加 `inplace=True` 或重新赋值。

> [!warning] 多列排序 `ascending` 传了单个布尔
> 会作用到所有列，和预期不符。传列表。

> [!warning] 分组后直接画图报错
> 索引是分组键，列名对不上。先 `reset_index()`。

> [!warning] 用 `count` 当行数
> 它跳过 NaN。要总行数用 `size()`。

> [!warning] 分组列名带空格
> `df.groupby("产品 类别")` 找不到列，检查列名是否有多余空格。

## 5. 自测

> [!question]- 按「销售数量」降序、同数量按「订单日期」升序，怎么写？
> **答案**：
> ```python
> df.sort_values(["销售数量", "订单日期"], ascending=[False, True])
> ```

> [!question]- 统计每个产品类别的销售额总和、平均值，怎么写？
> **答案**：
> ```python
> df.groupby("产品类别")["销售额"].agg(["sum", "mean"])
> ```

> [!question]- 分组结果怎么变回普通表格？
> **答案**：`reset_index()`，分组键会从索引变回列。
