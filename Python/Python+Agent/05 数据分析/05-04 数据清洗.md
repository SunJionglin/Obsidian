## 0. 速记

> [!tip] 五句话
> - 清洗四件事：缺失值、重复值、异常值、格式不一致
> - 缺失值：`isnull` 看、`dropna` 删、`fillna` 补、`ffill/bfill` 前后填
> - 重复值：`duplicated` 看、`drop_duplicates` 删
> - 格式问题用 `str.replace` / `str.strip` / `astype` 统一
> - Pandas 的方法大多返回新对象，不改原表（除非 `inplace=True`）

## 1. 语法速查

### 1.1 缺失值

```python
df.isnull()                     # 布尔表，True 表示缺失
df.isnull().sum()               # 每列缺失数量
df.dropna()                     # 删掉含缺失的行
df.dropna(how="all")            # 只删全为空的行
df.dropna(subset=["评分"])      # 只看评分列
df.fillna(0)                    # 用 0 填
df.fillna({"评分": 0, "语言": "未知"})
df["年份"].ffill()              # 用前一个值填
df["年份"].bfill()              # 用后一个值填
```

### 1.2 重复值

```python
df.duplicated()                       # 布尔序列，True 表示重复
df.duplicated(subset=["电影名"])       # 按某几列判断
df.drop_duplicates()                  # 删重复，保留第一条
df.drop_duplicates(subset=["电影名"], keep="last")
```

### 1.3 异常值与格式

```python
df["温度"] = df["温度"].abs()                 # 负数取绝对值
df["日期"] = df["日期"].str.replace("/", "-")  # 统一分隔符
df["名称"] = df["名称"].str.strip()            # 去首尾空格
df["年份"] = df["年份"].astype("Int64")        # 类型转换
df["日期"] = pd.to_datetime(df["日期"])        # 转日期类型
```

## 2. 与 C++ 的差异

| 维度 | C++ | Pandas |
|---|---|---|
| 缺失值 | 哨兵值 / `optional` | `NaN` / `NaT` |
| 判断缺失 | 自己写比较 | `isnull()` |
| 删除行 | 重建 vector | `dropna()` |
| 填充 | 手写循环 | `fillna` / `ffill` |
| 去重 | `set` + 自定义哈希 | `drop_duplicates` |
| 字符串处理 | 手写遍历 | `.str` 向量化 |

## 3. 易漏点

- **`NaN != NaN`**：判断缺失只能用 `isnull()`，不能写 `== None`。
- **`inplace=True` 才改原表**：否则必须 `df = df.dropna()`。
- **`dropna` 默认删任意缺失**：可能删太狠，先看 `isnull().sum()`。
- **`ffill` 适合时间序列**：没有前值时仍为空。
- **`drop_duplicates` 默认保留第一条**：要保留最后一条用 `keep="last"`。
- **`astype` 遇到空值会失败**：先用 `Int64` 可空类型。
- **`.str` 只对字符串列有效**：数值列先转 `str`。

## 4. 易错点

> [!warning] 用 `== None` 判断缺失
> 永远为 `False`。用 `df["列"].isnull()`。

> [!warning] 以为方法改了原表
> `df.dropna()` 返回新表，原表没变。要么赋值，要么 `inplace=True`。

> [!warning] `astype(int)` 遇到空值报错
> `ValueError: cannot convert NaN to integer`，用 `"Int64"`。

> [!warning] 去重没指定 subset
> 整行完全一样才算重复，业务上通常按 ID / 名称去重。

> [!warning] 字符串替换没生效
> 列不是字符串类型，先 `astype(str)`。

> [!warning] 清洗后没检查
> 清洗完再看一眼 `isnull().sum()` 和 `shape`，确认没误删。

## 5. 自测

> [!question]- `dropna()` 和 `fillna()` 的区别？
> **答案**：`dropna` 删除含缺失的行/列，`fillna` 用指定值或方法填充。

> [!question]- 怎么找出每列缺失值的数量？
> **答案**：`df.isnull().sum()`。

> [!question]- 按「电影名」去重，保留最后一条，怎么写？
> **答案**：`df.drop_duplicates(subset=["电影名"], keep="last")`。
