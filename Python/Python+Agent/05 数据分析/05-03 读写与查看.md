## 0. 速记

> [!tip] 五句话
> - 读 `read_csv` / `read_excel`，写 `to_csv` / `to_excel`
> - `head/tail/describe/info` 是打开数据集后的四连看
> - 选列 `df['x']`，选多列 `df[['x','y']]`
> - `loc` 按标签、`iloc` 按位置，前者区间闭合、后者左闭右开
> - 过滤就是布尔索引：`df[df['单价'] >= 100]`

## 1. 语法速查

### 1.1 读写

```python
import pandas as pd

df = pd.read_csv("movies.csv", encoding="utf-8")
df = pd.read_csv("movies.csv", usecols=["电影名", "评分"], nrows=100)
df = pd.read_csv("movies.csv", dtype={"年份": "Int64"})

df.to_csv("out.csv", index=False, encoding="utf-8-sig")
```

| 参数 | 作用 |
|---|---|
| `usecols` | 只读需要的列 |
| `dtype` | 指定列类型，避免年份变 float |
| `nrows` | 只读前 n 行，调试用 |
| `index=False` | 写文件时不带行索引 |
| `encoding` | 中文用 `utf-8` 或 `utf-8-sig` |

### 1.2 四连看

```python
df.head()        # 前 5 行
df.tail(3)       # 后 3 行
df.info()        # 列名、非空数量、类型
df.describe()    # 数值列统计：count/mean/std/min/25%/50%/75%/max
df.shape         # (行数, 列数)
```

### 1.3 选行列

```python
df["电影名"]              # Series
df[["电影名", "评分"]]     # DataFrame

df.loc[0]                 # 标签为 0 的行
df.loc[0:2, ["电影名"]]    # 标签 0~2（含 2）
df.iloc[0:2]              # 位置 0、1（不含 2）
df.iloc[:5, :3]           # 前 5 行、前 3 列
```

### 1.4 过滤

```python
df[df["评分"] >= 9]
df[df["类型"].isin(["剧情", "喜剧"])]
df[(df["评分"] >= 9) & (df["时长"] > 120)]
df[~df["语言"].isin(["en"])]
```

## 2. 与 C++ 的差异

| 维度 | C++ | Pandas |
|---|---|---|
| 读 CSV | `getline` + `split` | `read_csv` |
| 选列 | 手工记录下标 | 按列名 |
| 过滤 | `for` + `if` 建新容器 | 布尔索引 |
| 统计 | 手写循环 | `describe()` |
| 缺失值 | 哨兵值 | `NaN` |
| 类型 | 编译期固定 | 运行期按列推断 |

## 3. 易漏点

- **`loc` 区间闭合**：`loc[0:2]` 包含 2；`iloc[0:2]` 不包含。
- **`to_csv` 默认带索引**：多出一列 `Unnamed: 0`，加 `index=False`。
- **`describe()` 只统计数值列**：字符串列要看 `info()`。
- **年份读成 float**：有空值就是 `1994.0`，用 `dtype={"年份": "Int64"}`。
- **`&`/`|` 要加括号**：优先级比比较运算符高，不加括号会报错。
- **链式索引有警告**：`df[df.a > 1]["b"] = 0` 可能改不到原表，用 `.loc`。

## 4. 易错点

> [!warning] 过滤条件用 `and`
> `df[(df.a > 1) and (df.b < 2)]` → `ValueError`。用 `&`，且每个条件加括号。

> [!warning] `to_csv` 多出一列索引
> 打开文件第一列是 `Unnamed: 0`，加 `index=False`。

> [!warning] `loc` 和 `iloc` 混用
> `df.loc[0:2]` 是标签 0、1、2；`df.iloc[0:2]` 只有 0、1。

> [!warning] 中文路径 / 编码报错
> 指定 `encoding="utf-8"`；Excel 导出可能是 `gbk`。

> [!warning] 直接改切片
> 触发 `SettingWithCopyWarning`，用 `df.loc[条件, "列"] = 值`。

## 5. 自测

> [!question]- 只想读 CSV 的前 100 行和前 3 列，怎么写？
> **答案**：
> ```python
> pd.read_csv("a.csv", nrows=100, usecols=[0, 1, 2])
> ```

> [!question]- `loc[0:2]` 和 `iloc[0:2]` 结果一样吗？
> **答案**：不一定。`loc` 含右端点，选 0、1、2；`iloc` 不含，选 0、1。

> [!question]- 过滤「评分 ≥ 9 且时长 > 120」怎么写？
> **答案**：`df[(df["评分"] >= 9) & (df["时长"] > 120)]`。
