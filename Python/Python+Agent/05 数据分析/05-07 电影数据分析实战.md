## 0. 速记

> [!tip] 五句话
> - 四张图：年份折线、语言柱状、类型柱状、评分饼图
> - 只读需要的列，`usecols` + `dtype` 能省内存、防类型错
> - 年份缺失用「上映时间」前四位补
> - 类型是逗号分隔的字符串，要拆开逐个计数
> - 饼图小比例合并成「其他」，否则图例挤成一团

## 1. 语法速查

### 1.1 加载

```python
df = pd.read_csv(
    "data/movies.csv",
    usecols=["电影名", "年份", "上映时间", "类型", "时长", "评分", "语言"],
    dtype={"年份": "Int64"},
)
```

### 1.2 布局

```python
fig, axes = plt.subplots(2, 2, figsize=(20, 12), dpi=100)
fig.suptitle("TMDB-TOP300 电影榜单统计", fontsize=23)
fig.subplots_adjust(hspace=0.5, wspace=0.2)
```

### 1.3 年份趋势

```python
df["年份"] = df["年份"].fillna(df["上映时间"].str[:4])

count = df.groupby("年份")["年份"].count()
x = range(int(count.index.min()), int(count.index.max()) + 1)
y = [int(count.get(i, 0)) for i in x]

axes[0][0].plot(x, y, color="green")
axes[0][0].set_title("每年电影数量变化")
```

### 1.4 语言与类型

```python
lang = df.groupby("语言")["语言"].count().sort_values(ascending=False)
axes[0][1].bar(lang.index, lang.values)

counter = {}
for types in df["类型"].str.split(","):
    for t in types:
        counter[t] = counter.get(t, 0) + 1
axes[1][0].bar(counter.keys(), counter.values())
```

### 1.5 评分饼图

```python
score = df.groupby("评分")["评分"].count()
total = score.sum()

large = score[score >= total * 0.02]
small = score[score < total * 0.02]
if len(small):
    large["其他"] = small.sum()

axes[1][1].pie(large.values, labels=large.index, autopct="%1.1f%%")
```

### 1.6 保存

```python
plt.savefig("data/top300.png", dpi=150)   # 必须在 show 之前
plt.show()
```

## 3. 易漏点

- **年份是 float**：有空值就变 `1994.0`，用 `dtype={"年份": "Int64"}`。
- **缺失值填充**：`df["年份"].fillna(..., inplace=True)` 或重新赋值。
- **`range` 要 int**：`count.index.min()` 可能是 numpy 类型，包一层 `int()`。
- **类型字段拆分**：`str.split(",")` 得到的是列表，要再遍历。
- **小比例合并**：先算 total，再按 2% 切分，否则饼图几十个扇区。
- **`savefig` 在 `show` 前**：否则保存的是空白图。

## 4. 易错点

> [!warning] 只读部分列却引用了没读的列
> `KeyError`。`usecols` 里没写的列不存在。

> [!warning] 年份分组出现 `1994.0`
> 浮点索引，画图刻度会变成小数。转 `Int64` 或 `astype(int)`。

> [!warning] 类型统计重复计数
> 一部电影有多个类型，按行 `value_counts` 会把 `"剧情,喜剧"` 当一个整体。

> [!warning] 饼图扇区太多
> 几十个评分值全画出来，图例盖住图。合并小比例。

> [!warning] 保存的图是空白
> `savefig` 写在 `show()` 之后，画布已清空。

> [!warning] 中文变方框
> 忘了设置 `font.sans-serif`。

## 5. 自测

> [!question]- 为什么读取时只选 7 列？
> **答案**：减少内存、加快速度，也避免无关列的类型问题。

> [!question]- 年份缺失怎么补？
> **答案**：用上映时间的前四位：`df["年份"].fillna(df["上映时间"].str[:4])`。

> [!question]- 饼图为什么要合并「其他」？
> **答案**：小比例扇区太多会导致标签重叠、图例遮挡，合并后更可读。
