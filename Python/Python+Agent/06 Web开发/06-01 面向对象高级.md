## 0. 速记

> [!tip] 五句话
> - 封装靠 `__` 前缀，但 Python 只是「改名」，不是真私有
> - 继承 `class Sub(Base)`，子类拿到父类非私有成员
> - 重写就是子类定义同名方法，想调父类用 `super()`
> - 多继承按 MRO 顺序查找，`类.__mro__` 能看顺序
> - 多态看行为不看类型，鸭子类型连继承都不需要

## 1. 语法速查

### 1.1 封装

```python
class Car:
    def __init__(self, owner):
        self.__owner = owner          # 私有属性

    def __control_fuel(self):         # 私有方法
        print("控制油门")

    def get_owner(self):              # 公开接口
        return self.__owner[0:1] + "**"
```

- 外面访问 `car.__owner` → `AttributeError`。
- 但 `car._Car__owner` 能访问——名字被改写成 `_类名__属性`，所以不是真私有。

### 1.2 继承与重写

```python
class Car:
    def __init__(self, brand):
        self.brand = brand

    def start(self):
        print(f"{self.brand} 启动")

class ElectricCar(Car):
    def __init__(self, brand, battery):
        super().__init__(brand)       # 调父类构造
        self.battery = battery

    def start(self):                  # 重写
        super().start()
        print("电动模式")
```

### 1.3 多继承与 MRO

```python
class A: ...
class B: ...
class C(A, B): ...

print(C.__mro__)   # C -> A -> B -> object
```

同名方法按 MRO 从左到右找第一个。

### 1.4 多态与鸭子类型

```python
def drive(car):
    car.start()      # 不关心类型，只要求有 start()

drive(Car("Audi"))
drive(ElectricCar("Tesla", 90))
```

鸭子类型：只要「会叫、会走」，就当鸭子用，不需要共同父类。

### 1.5 抽象类

```python
from abc import ABC, abstractmethod

class Member(ABC):
    @abstractmethod
    def get_max_books(self) -> int:
        ...

# Member()  # TypeError，抽象类不能实例化
```

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 私有 | `private` 编译期限制 | `__` 改名，运行期仍可绕过 |
| 继承声明 | `class Sub : public Base` | `class Sub(Base)` |
| 父类构造 | 初始化列表 | `super().__init__()` |
| 虚函数 | `virtual` + 动态绑定 | 方法默认就是动态查找 |
| 多继承 | 有，菱形需虚继承 | 有，MRO 解决 |
| 抽象类 | 纯虚函数 | `ABC` + `@abstractmethod` |
| 接口 | 纯虚类 | 鸭子类型 / 协议 |
| 类型检查 | 编译期 | 运行期 |

## 3. 易漏点

- **`_Car__owner` 能访问**：`__` 只是改名，不是安全机制。
- **子类拿不到私有成员**：`__owner` 在子类里叫 `_Car__owner`，直接用 `__owner` 会 `AttributeError`。
- **`super()` 在多重继承里按 MRO 走**：不是「父类」，是「下一个」。
- **重写后想复用父类逻辑**：必须显式 `super().method()`。
- **抽象方法必须全部实现**：少一个，实例化就 `TypeError`。
- **鸭子类型不检查继承**：只看有没有方法，写错方法名运行时才炸。

## 4. 易错点

> [!warning] 忘写 `super().__init__()`
> 父类属性没初始化，子类方法里访问就 `AttributeError`。

> [!warning] 以为 `__` 是真私有
> 外部仍能用 `_类名__属性` 访问或修改。要真正防护得用 `@property` 或重构。

> [!warning] 多继承顺序写反
> `class C(A, B)` 和 `class C(B, A)` 的 MRO 不同，同名方法结果可能相反。

> [!warning] 重写时改了方法签名
> 父类 `start(self)`，子类 `start(self, mode)`，多态调用就会 `TypeError`。

> [!warning] 抽象类直接实例化
> `Member()` → `TypeError: Can't instantiate abstract class`。

## 5. 自测

> [!question]- Python 的私有属性能被外部访问吗？
> **答案**：能。`__x` 被改名为 `_类名__x`，用这个名字仍可访问，只是不推荐。

> [!question]- `super()` 在多继承里指的是谁？
> **答案**：MRO 里的下一个类，不一定是直接父类。

> [!question]- 什么是鸭子类型？
> **答案**：不关心对象是什么类，只关心它有没有需要的方法；有就可以当这个接口用。
