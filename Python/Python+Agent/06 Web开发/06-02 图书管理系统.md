## 0. 速记

> [!tip] 五句话
> - 三个核心类：`Book`、`Member`（抽象）、`Library`
> - `Book` 的「可用数量」私有，只能通过借/还方法改
> - `Member` 定义借还逻辑，借阅上限交给子类实现
> - 普通会员 3 本，VIP 是 `6 + 等级`
> - 多态体现在：`Library` 只认 `Member`，不关心普通还是 VIP

## 1. 语法速查

### 1.1 书籍类

```python
class Book:
    def __init__(self, book_id, title, author, total):
        self.book_id = book_id
        self.title = title
        self.total = total
        self.__available = total      # 私有：可用数量

    def borrow(self):
        if self.__available > 0:
            self.__available -= 1
            return True
        return False

    def give_back(self):
        self.__available += 1

    def available(self):
        return self.__available
```

### 1.2 会员抽象类

```python
from abc import ABC, abstractmethod

class Member(ABC):
    def __init__(self, member_id, name, password):
        self.member_id = member_id
        self.name = name
        self.__password = password
        self.__borrowed = []

    def borrow(self, book: Book):
        if len(self.__borrowed) >= self.max_books():
            print("已达借阅上限")
            return False
        if book.borrow():
            self.__borrowed.append(book)
            return True
        return False

    def give_back(self, book: Book):
        if book in self.__borrowed:
            book.give_back()
            self.__borrowed.remove(book)

    @abstractmethod
    def max_books(self) -> int:
        ...
```

### 1.3 子类

```python
class NormalMember(Member):
    def max_books(self):
        return 3

class VipMember(Member):
    def __init__(self, member_id, name, password, level=1):
        super().__init__(member_id, name, password)
        self.level = level

    def max_books(self):
        return 6 + self.level
```

### 1.4 系统入口

```python
class Library:
    def __init__(self):
        self.books = []
        self.members = []
        self.current = None

    def login(self, member_id, password):
        for m in self.members:
            if m.member_id == member_id and m.check_password(password):
                self.current = m
                return True
        return False
```

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 抽象类 | 纯虚函数 | `ABC` + `@abstractmethod` |
| 接口约束 | 编译期检查 | 运行期检查 |
| 对象集合 | `vector<Member*>` | `list`，直接放对象 |
| 密码保护 | private | `__` 改名 + getter |
| 多态 | 虚函数 | 同名方法动态查找 |
| 项目组织 | 多文件 + 头文件 | 单文件多类 |

## 3. 易漏点

- **借书要判两次**：会员上限 + 书籍库存。
- **还书要校验**：只能还自己借过的书。
- **可用数量不能公开改**：否则库存会乱。
- **VIP 等级默认 1**：`6 + level`，不是固定 6。
- **抽象方法必须实现**：`NormalMember` / `VipMember` 都要写 `max_books`。
- **登录要校验密码**：密码私有，通过方法比较。
- **同一本书可借多本**：列表里会出现重复对象。

## 4. 易错点

> [!warning] 先减库存再判上限
> 会员已达上限却先把书扣了，数据不一致。先判上限，再扣库存。

> [!warning] 还书不校验归属
> 没借过的书也能「还」，库存虚增。

> [!warning] 直接改 `book.available`
> 私有属性改不动，或绕过封装导致负数。

> [!warning] VIP 上限写成固定值
> 忽略 `level`，VIP 等级形同虚设。

> [!warning] 用 `==` 比较两个 Book
> 默认比身份，内容相同也不同。需要时重写 `__eq__`。

## 5. 自测

> [!question]- 为什么 `Member` 要定义成抽象类？
> **答案**：强制子类实现 `max_books`，避免漏写导致借阅规则失效。

> [!question]- 借书方法里两个判断的顺序为什么重要？
> **答案**：先判会员上限，再扣库存；反了会出现「没借到书但库存少了」。

> [!question]- 普通会员和 VIP 的差别体现在哪？
> **答案**：只体现在 `max_books` 的返回值，其余借还逻辑复用父类——这就是多态。
