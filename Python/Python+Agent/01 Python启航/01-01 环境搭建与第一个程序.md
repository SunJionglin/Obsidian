## 0. 速记

> [!tip] 五句话
> - Python 是解释型语言：不用编译，解释器逐行执行
> - 装完必须配 PATH，否则命令行找不到 `python`
> - 一个 `.py` 文件就是一个程序，用 `python hello.py` 运行
> - 注释用 `#`；三引号本质是字符串，只是常被当多行注释
> - 代码里所有符号必须是英文半角

## 1. 语法速查

### 1.1 第一个程序

```python
print("Hello Python")
```

保存为 `hello.py`，在文件所在目录执行：

```bash
python hello.py
# Hello Python
```

### 1.2 注释

```python
# 单行注释，从 # 到行尾

"""
三引号是多行字符串，
放在函数/类开头时叫文档字符串（docstring），
并不是真正的注释。
"""
```

快捷键：PyCharm 里 `Ctrl + /`（macOS 是 `Cmd + /`）批量注释。

### 1.3 环境与工具

| 工具 | 作用 |
|---|---|
| Python 解释器 | 执行 `.py` 文件 |
| PATH 环境变量 | 告诉系统去哪些目录找 `python.exe` |
| PyCharm | IDE：编辑、运行、调试 |
| 终端 / CMD | 直接执行 `python xxx.py` |

### 1.4 运行方式

| 方式 | 操作 | 适合 |
|---|---|---|
| 交互式 | 终端输入 `python`，逐行敲 | 试验一行代码 |
| 脚本 | `python hello.py` | 正式程序 |
| IDE | 右键 Run | 日常开发 |

## 2. 与 C++ 的差异

| 维度 | C++ | Python |
|---|---|---|
| 执行方式 | 编译成机器码再运行 | 解释器逐行执行 |
| 程序入口 | `int main()` | 顶层代码直接执行 |
| 语句结束 | `;` | 换行 |
| 代码块 | `{}` | 缩进 |
| 打印 | `std::cout <<` | `print()` |
| 类型 | 必须声明 | 动态类型 |
| 文件 | `.cpp` + `.h` | 单个 `.py` |
| 环境 | 编译器 + 链接器 | 解释器 + 包管理器 pip |

## 3. 易漏点

- **PATH 的作用**：不配置就只能进安装目录敲 `python`。
- **`python` 还是 `python3`**：Windows 一般是 `python`，macOS/Linux 可能是 `python3`。
- **文件名**：不要中文、空格、特殊符号；后缀必须是 `.py`。
- **编码**：文件保存为 UTF-8，否则中文可能报 `SyntaxError`。
- **缩进是语法**：不是排版，缩进错了程序就错。
- **三引号不是注释**：它只是字符串，解释器仍会创建对象。
- **交互式不保存**：终端里敲的代码关掉就没了。

## 4. 易错点

> [!warning] 用了中文标点
> `print（"你好"）` 里的全角括号 → `SyntaxError: invalid character`。全部换成英文半角。

> [!warning] 忘了保存
> 改了代码没保存就运行，跑的还是旧文件。

> [!warning] 在错误目录运行
> `python hello.py` 找不到文件 → `can't open file`。先 `cd` 到文件所在目录。

> [!warning] 函数名大小写
> `Print("x")` → `NameError`。Python 区分大小写。

> [!warning] 路径里有空格
> 安装到 `C:\Program Files` 容易出问题，开发工具尽量装无空格无中文的目录。

> [!warning] 缩进混用 Tab 和空格
> `IndentationError`。统一用 4 个空格。

## 5. 自测

> [!question]- 为什么安装时要勾选「Add Python to PATH」？
> **答案**：把 Python 安装目录写进 PATH，命令行才能在任意位置找到 `python` 命令。

> [!question]- `#` 和三引号有什么区别？
> **答案**：`#` 是真正的注释，解释器直接忽略；三引号是字符串对象，只是没赋值时看起来像注释。

> [!question]- 写出输出 `Hello` 并加一行注释的代码。
> **答案**：
> ```python
> # 输出问候
> print("Hello")
> ```
