# 02 哈希与集合

## 一、什么时候想到它

- 要**快速判断存在**、计数、找配对 → `set` / `dict`
- 「同一元素不能用两次」→ 边遍历边查边插
- 值域小（26 个字母、0–9）→ 直接用数组当哈希表，比 dict 快

## 二、三个模板

### 2.1 边遍历边查（两数之和）

```python
def two_sum(nums, target):
    idx = {}
    for i, x in enumerate(nums):
        if target - x in idx:
            return [idx[target - x], i]
        idx[x] = i
    return []
```

### 2.2 计数（Counter）

```python
from collections import Counter

Counter("anagram")             # Counter({'a': 3, 'n': 1, ...})
Counter([1,1,2]).most_common(1)  # [(1, 2)]  前 K 高频

def is_anagram(s, t):          # 242
    return Counter(s) == Counter(t)
```

### 2.3 用数组当桶（值域已知）

```python
def first_uniq_char(s):        # 387
    cnt = [0] * 26
    for ch in s: cnt[ord(ch) - 97] += 1
    for i, ch in enumerate(s):
        if cnt[ord(ch) - 97] == 1: return i
    return -1
```

## 四、易错点

1. `dict[k]` 查询会**插入**键；只查不改用 `get` / `in`。
2. Python 3.7+ dict 保持插入顺序，但别依赖它做「有序输出」，要排序就 `sorted()`。
3. 计数用 `Counter` 比手写 dict 稳，`Counter.most_common(k)` 直接给 top-k。
4. 原地标记（448）改完要能还原，或者题面允许破坏数组。

## 五、一句话套路

**「这个数我见过吗」用哈希；「这个值出现几次」用 Counter；值域小时用数组当桶。**
