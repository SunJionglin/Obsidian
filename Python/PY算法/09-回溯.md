# 09 回溯

## 一、什么时候想到它

- 要列举**所有**方案（排列、组合、子集、括号、棋盘）
- 决策树深度有限（n ≤ 10～20），可以「选 / 不选」穷举
- 需要剪枝的搜索（组合和、数独）

## 二、模板

### 2.1 通用骨架

```python
def backtrack(path, choices, res):
    if 满足结束条件:
        res.append(path[:])              # 记住要拷贝
        return
    for c in choices:
        if 剪枝条件: continue
        path.append(c)                   # 做选择
        backtrack(path, 下一步的选择, res)
        path.pop()                       # 撤销
```

### 2.2 子集（不含重复）

```python
def subsets(nums):                       # 78
    res = []
    def dfs(i, path):
        res.append(path[:])
        for j in range(i, len(nums)):
            path.append(nums[j])
            dfs(j + 1, path)
            path.pop()
    dfs(0, [])
    return res
```

### 2.3 排列（含重复要排序后跳同层重复）

```python
def permute_unique(nums):                # 47
    nums.sort()
    res, used = [], [False] * len(nums)
    def dfs(path):
        if len(path) == len(nums):
            res.append(path[:]); return
        for i, x in enumerate(nums):
            if used[i]: continue
            if i and nums[i] == nums[i-1] and not used[i-1]: continue
            used[i] = True; path.append(x)
            dfs(path)
            path.pop(); used[i] = False
    dfs([])
    return res
```

### 2.4 组合和（可重复选 + 剪枝）

```python
def combination_sum(candidates, target): # 39
    candidates.sort()
    res = []
    def dfs(start, path, rest):
        if rest == 0: res.append(path[:]); return
        for i in range(start, len(candidates)):
            if candidates[i] > rest: break        # 剪枝
            path.append(candidates[i])
            dfs(i, path, rest - candidates[i])    # i 而不是 i+1：可重复
            path.pop()
    dfs(0, [], target)
    return res
```

### 2.5 棋盘类（N 皇后）

```python
def solve_n_queens(n):                   # 51
    res = []
    cols, d1, d2 = set(), set(), set()
    def dfs(r, path):
        if r == n: res.append(path[:]); return
        for c in range(n):
            if c in cols or r + c in d1 or r - c in d2: continue
            cols.add(c); d1.add(r + c); d2.add(r - c)
            dfs(r + 1, path + [c])
            cols.remove(c); d1.remove(r + c); d2.remove(r - c)
    dfs(0, [])
    return res
```

## 四、易错点

1. `res.append(path)` 存的是引用，必须 `path[:]` 拷贝。
2. 去重的标准写法：**排序 + `used[i-1]` 判断**，只在同层去重，不跨层。
3. 剪枝要放在递归前（`if sum > target: break`），放后面等于没剪。
4. 递归返回后一定要**撤销选择**，否则状态泄漏。

## 五、一句话套路

**回溯 = 递归 + 选择 + 撤销；先在纸上画一遍决策树，再决定「层」是什么、「选择」是什么。**
