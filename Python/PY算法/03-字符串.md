# 03 字符串

## 一、什么时候想到它

- 判断回文、反转、大小写、去空格 → 双指针 + 内置方法
- 找子串出现位置 → `in` / `find`，要线性就 KMP
- 两个字符串相加/相乘 → 竖式模拟
- 括号/无效字符清洗 → 栈或正则

## 二、模板

### 2.1 双指针判回文

```python
def is_palindrome(s):                    # 125
    i, j = 0, len(s) - 1
    while i < j:
        while i < j and not s[i].isalnum(): i += 1
        while i < j and not s[j].isalnum(): j -= 1
        if s[i].lower() != s[j].lower(): return False
        i += 1; j -= 1
    return True
```

### 2.2 字符串相加（竖式）

```python
def add_strings(a, b):                   # 415
    i, j, carry, out = len(a)-1, len(b)-1, 0, []
    while i >= 0 or j >= 0 or carry:
        x = ord(a[i]) - 48 if i >= 0 else 0
        y = ord(b[j]) - 48 if j >= 0 else 0
        carry, d = divmod(x + y + carry, 10)
        out.append(str(d)); i -= 1; j -= 1
    return "".join(reversed(out))
```

### 2.3 KMP（找子串下标，O(n+m)）

```python
def str_str(s, p):                       # 28
    if not p: return 0
    nxt = [0] * len(p)
    j = 0
    for i in range(1, len(p)):
        while j and p[i] != p[j]: j = nxt[j-1]
        if p[i] == p[j]: j += 1
        nxt[i] = j
    j = 0
    for i in range(len(s)):
        while j and s[i] != p[j]: j = nxt[j-1]
        if s[i] == p[j]: j += 1
        if j == len(p): return i - len(p) + 1
    return -1
```

平常用 `s.find(p)` 就够；面试要 O(n) 再写 KMP，或用 Python 的 `in`（实际是两路匹配，接近线性）。

### 2.4 中心扩展求最长回文

```python
def longest_palindrome(s):               # 5
    best = ""
    def expand(l, r):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1; r += 1
        return s[l+1:r]
    for i in range(len(s)):
        for cand in (expand(i, i), expand(i, i+1)):
            if len(cand) > len(best): best = cand
    return best
```

## 四、易错点

1. `s.split()` 会自动处理多个空格；`s.split(" ")` 会留下空串，151 要小心。
2. 回文中心扩展时边界写成 `l+1:r`，Python 切片右端不含。
3. 字符转数字用 `ord(c) - 48`，别写 `int(c)`（慢一个数量级）。
4. Python 字符串不可变，循环拼接要用 `list + join`，别 `+=`（O(n²)）。

## 五、一句话套路

**能 `join` 别 `+=`，能 `split` 别手写分词，要 O(n) 才上 KMP。**
