# 08 图与搜索

## 一、什么时候想到它

- 网格里连成一片（岛屿、填色、腐烂） → DFS/BFS 染色
- 最短步数、层数 → **BFS**（边权相同时唯一正确解）
- 依赖关系、能不能排完 → 拓扑排序
- 「连不连通」「有没有环」→ 并查集
- 带权最短路径 → Dijkstra（堆）

## 二、模板

### 2.1 网格 DFS（岛屿）

```python
def num_islands(grid):                   # 200
    if not grid: return 0
    m, n = len(grid), len(grid[0])
    def sink(i, j):
        if not (0 <= i < m and 0 <= j < n) or grid[i][j] != "1": return
        grid[i][j] = "0"                 # 标记访问，省 visited
        sink(i+1, j); sink(i-1, j); sink(i, j+1); sink(i, j-1)
    cnt = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == "1":
                cnt += 1; sink(i, j)
    return cnt
```

### 2.2 BFS 求最短步数

```python
from collections import deque

def min_steps(grid, start, target):      # 1091 / 994 同构
    m, n = len(grid), len(grid[0])
    q = deque([(start, 0)])
    seen = {start}
    while q:
        (i, j), d = q.popleft()
        if (i, j) == target: return d
        for di, dj in ((1,0), (-1,0), (0,1), (0,-1)):
            ni, nj = i + di, j + dj
            if 0 <= ni < m and 0 <= nj < n and (ni, nj) not in seen and grid[ni][nj] == 0:
                seen.add((ni, nj)); q.append(((ni, nj), d + 1))
    return -1
```

多源 BFS（994 腐烂橘子）：开局把所有源头一起入队，层数就是「同时扩散」的时间。

### 2.3 拓扑排序（课程表）

```python
def can_finish(n, edges):                # 207
    from collections import deque
    g = [[] for _ in range(n)]
    indeg = [0] * n
    for a, b in edges:                   # b -> a
        g[b].append(a); indeg[a] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    seen = 0
    while q:
        u = q.popleft(); seen += 1
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return seen == n
```

要输出顺序（210）就把出队元素记下来。

### 2.4 并查集

```python
class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1] * n
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]   # 路径压缩
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        if self.sz[ra] < self.sz[rb]: ra, rb = rb, ra
        self.p[rb] = ra; self.sz[ra] += self.sz[rb]
        return True
```

### 2.5 Dijkstra（带权最短路）

```python
import heapq

def dijkstra(g, src, n):                 # 743
    dist = [float("inf")] * n
    dist[src] = 0
    pq = [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue
        for v, w in g[u]:
            if d + w < dist[v]:
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

## 四、易错点

1. 网格题一律先判越界再取值，顺序反了会 IndexError。
2. BFS 入队时就标记 `seen`，出队才标记会重复入队、超时/爆内存。
3. 拓扑排序的「边方向」最容易写反：`a 依赖 b` 应建 `b -> a`。
4. 并查集忘了路径压缩 → 退化成链，1e5 数据就慢。

## 五、一句话套路

**连通性用 DFS/并查集，最少步数用 BFS，依赖关系用拓扑，带权用 Dijkstra。**
