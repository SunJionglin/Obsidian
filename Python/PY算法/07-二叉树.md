# 07 二叉树

## 一、什么时候想到它

- 遍历顺序（前中后/层） → 递归或队列
- 「深度/路径/左右子树比较」 → 递归函数返回一个值
- BST（有序）→ 中序遍历是升序，可以剪枝
- 「最近公共祖先 / 构造 / 序列化」→ 递归分治

## 二、模板

### 2.1 递归遍历

```python
def inorder(root):
    res = []
    def dfs(node):
        if not node: return
        dfs(node.left); res.append(node.val); dfs(node.right)
    dfs(root)
    return res
```

### 2.2 层序遍历（BFS）

```python
from collections import deque

def level_order(root):                   # 102
    if not root: return []
    res, q = [], deque([root])
    while q:
        cur = []
        for _ in range(len(q)):          # 关键：先记长度
            node = q.popleft()
            cur.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        res.append(cur)
    return res
```

### 2.3 递归返回信息（深度 / 直径）

```python
def max_depth(root):                     # 104
    if not root: return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))

def diameter(root):                       # 543
    best = 0
    def dfs(node):
        nonlocal best
        if not node: return 0
        l, r = dfs(node.left), dfs(node.right)
        best = max(best, l + r)
        return 1 + max(l, r)
    dfs(root)
    return best
```

### 2.4 验证 BST（中序 + 单调）

```python
def is_valid_bst(root):                   # 98
    pre = [None]
    def dfs(node):
        if not node: return True
        if not dfs(node.left): return False
        if pre[0] is not None and node.val <= pre[0]: return False
        pre[0] = node.val
        return dfs(node.right)
    return dfs(root)
```

### 2.5 最近公共祖先

```python
def lowest_common_ancestor(root, p, q):   # 236
    if not root or root is p or root is q: return root
    l = lowest_common_ancestor(root.left, p, q)
    r = lowest_common_ancestor(root.right, p, q)
    if l and r: return root
    return l or r
```

## 四、易错点

1. 层序每层开始前要 `len(q)`，否则新入队的孩子会被算进当前层。
2. 递归函数「要返回值」和「用全局变量收集」是两种写法，混着写最容易错。
3. BST 验证不能只比父子，要比**区间**（或中序单调）。
4. 递归深度：链状树 1e4 结点会触发 Python 递归上限，必要时 `sys.setrecursionlimit`。

## 五、一句话套路

**树题先问自己：答案要「自顶向下传参」还是「自底向上返回」，二者选一种写到底。**
