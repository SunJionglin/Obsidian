# 01 数组与双指针

## 一、什么时候想到它

- 要在**原地**删/移/换元素 → 快慢指针
- 有序数组里找一对数、判断回文、装水 → 对撞指针
- 求**连续子数组**满足某条件（最长/最短/和） → 滑动窗口
- 反复求区间和 → 前缀和

## 二、四个模板

### 2.1 快慢指针（原地删除/移动）

```python
def remove_element(nums, val):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != val:
            nums[slow] = nums[fast]
            slow += 1
    return slow          # 前 slow 个是答案，别切片复制
```

用在：27 移除元素、26 去重、283 移动零、905 按奇偶排序。

### 2.2 对撞指针（有序/两端）

```python
def two_sum_sorted(nums, target):        # 167
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s == target: return [l + 1, r + 1]
        if s < target: l += 1
        else: r -= 1
    return []

def max_area(h):                          # 11 盛水
    l, r, best = 0, len(h) - 1, 0
    while l < r:
        best = max(best, min(h[l], h[r]) * (r - l))
        if h[l] < h[r]: l += 1
        else: r -= 1
    return best
```

### 2.3 滑动窗口（可变长）

```python
def longest_unique(s):                    # 3 无重复最长子串
    seen, l, best = {}, 0, 0
    for r, ch in enumerate(s):
        if ch in seen and seen[ch] >= l:
            l = seen[ch] + 1              # 左边界跳到重复字符后
        seen[ch] = r
        best = max(best, r - l + 1)
    return best

def min_window(s, t):                     # 76 最小覆盖子串
    need = Counter(t); missing = len(t)
    l = 0; best = (0, float("inf"))
    for r, ch in enumerate(s):
        if need[ch] > 0: missing -= 1
        need[ch] -= 1
        while missing == 0:               # 收缩
            if r - l + 1 < best[1] - best[0]:
                best = (l, r + 1)
            need[s[l]] += 1
            if need[s[l]] > 0: missing += 1
            l += 1
    return "" if best[1] == float("inf") else s[best[0]:best[1]]
```

定长窗口（如 438 找所有异位词）：用 `Counter` 固定长度比较。

### 2.4 前缀和

```python
def subarray_sum(nums, k):                # 560 和为 K 的子数组
    cnt = {0: 1}                          # 前缀和 -> 出现次数
    pre = ans = 0
    for x in nums:
        pre += x
        ans += cnt.get(pre - k, 0)
        cnt[pre] = cnt.get(pre, 0) + 1
    return ans
```

一维前缀和、二维前缀和（304）都是同一思路：把「区间求和」变成两次相减。

## 四、易错点

1. 快慢指针返回**长度**还是**数组**要看题：26/27 返回长度，剩下部分不要求。
2. 滑动窗口更新 `l` 时用 `max(l, seen[ch]+1)`，否则会把窗口拉回去。
3. 前缀和哈希表要先放 `{0: 1}`，否则从下标 0 开始的子数组会被漏掉。
4. 双指针的前提通常是**有序**；无序要先排序（会丢原下标）。

## 五、一句话套路

**能原地就别开新数组，能两端就别两层循环，能记前缀就别重复求和。**
