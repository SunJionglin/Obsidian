# 12 堆与设计题

## 一、什么时候想到它

- 只要「前 K / 第 K / 动态最值」→ 小根堆（或大根堆）
- 数据流中位数 → 对顶堆
- 「按前缀查词」→ Trie
- 「容量满就淘汰最久未用」→ LRU（哈希 + 双向链表 / `OrderedDict`）

## 二、模板

### 2.1 堆的基本用法

```python
import heapq

h = []
heapq.heappush(h, x)
heapq.heappop(h)              # 弹出最小值
heapq.heapify(h)              # 原地建堆 O(n)
heapq.heapreplace(h, x)       # 弹最小再压入，比 pop+push 快
# 大根堆：压 -x
```

### 2.2 前 K 大 / 前 K 高频

```python
def top_k_frequent(nums, k):             # 347
    from collections import Counter
    return [x for x, _ in Counter(nums).most_common(k)]

# 不用 most_common 的堆写法
def top_k_frequent_heap(nums, k):
    from collections import Counter
    import heapq
    cnt = Counter(nums)
    return heapq.nlargest(k, cnt.keys(), key=cnt.get)
```

### 2.3 对顶堆求中位数

```python
class MedianFinder:                      # 295
    def __init__(self):
        self.small = []                  # 大根堆（存负数）
        self.large = []                  # 小根堆
    def addNum(self, x):
        import heapq
        heapq.heappush(self.small, -x)
        heapq.heappush(self.large, -heapq.heappop(self.small))
        if len(self.large) > len(self.small):
            heapq.heappush(self.small, -heapq.heappop(self.large))
    def findMedian(self):
        if len(self.small) > len(self.large): return -self.small[0]
        return (-self.small[0] + self.large[0]) / 2
```

### 2.4 LRU（OrderedDict 版，最短）

```python
from collections import OrderedDict

class LRUCache:                          # 146
    def __init__(self, capacity: int):
        self.cap = capacity
        self.d = OrderedDict()
    def get(self, key: int) -> int:
        if key not in self.d: return -1
        self.d.move_to_end(key)
        return self.d[key]
    def put(self, key: int, value: int) -> None:
        if key in self.d: self.d.move_to_end(key)
        self.d[key] = value
        if len(self.d) > self.cap: self.d.popitem(last=False)
```

### 2.5 Trie（前缀树）

```python
class Trie:                              # 208
    def __init__(self):
        self.child = {}
        self.end = False
    def insert(self, word):
        node = self
        for ch in word:
            node = node.child.setdefault(ch, Trie())
        node.end = True
    def search(self, word):
        node = self
        for ch in word:
            if ch not in node.child: return False
            node = node.child[ch]
        return node.end
    def startsWith(self, prefix):
        node = self
        for ch in prefix:
            if ch not in node.child: return False
            node = node.child[ch]
        return True
```

## 四、易错点

1. 求「第 K 大」用小根堆，求「第 K 小」用大根堆（堆里存 `-x`）——反了结果全错。
2. `heapq` 只能堆可比较元素；要把 `(优先级, 内容)` 打包成元组、或给 `key`。
3. `most_common(k)` 内部就是堆，直接用它比手写快。
4. LRU 的两个动作顺序别错：先看有没有，再更新位置，最后判容量。

## 五、一句话套路

**「只要最近 K 个」就用堆，别全排序；「前缀」用 Trie；「最近使用」用哈希 + 有序结构。**
