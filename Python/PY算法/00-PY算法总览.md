## 三、Python 刷题环境

```python
from typing import List, Optional
from collections import Counter, defaultdict, deque
import heapq, bisect, functools, math, re
```

力扣上写 `class Solution:`，函数签名照题目给的抄；本地测可以：

```python
if __name__ == "__main__":
    print(Solution().twoSum([2, 7, 11, 15], 9))   # [0, 1]
```

## 四、写题解时的三条规矩

1. 先写**暴力**并说清复杂度，再写优化——面试要的是推导过程。
2. 模板背下来，但每道题都说清「为什么这个模板适用」。
3. 易错点要带具体输入（例：`[3,3], target=6`），空话不算数。
