# 05 栈、队列与单调栈

## 一、什么时候想到它

- 括号、嵌套结构、「最近的匹配」→ 栈
- 先进先出、层序、BFS → 队列（`deque`）
- 「下一个更大/更小的元素」「柱状图最大矩形」→ 单调栈
- 「滑动窗口里的最值」→ 单调队列

## 二、模板

### 2.1 括号匹配

```python
def is_valid(s):                         # 20
    pairs = {")": "(", "]": "[", "}": "{"}
    st = []
    for ch in s:
        if ch in "([{": st.append(ch)
        elif not st or st[-1] != pairs[ch]: return False
        else: st.pop()
    return not st
```

### 2.2 最小栈（辅助栈同步）

```python
class MinStack:
    def __init__(self):
        self.s, self.m = [], []
    def push(self, x):
        self.s.append(x)
        self.m.append(x if not self.m else min(x, self.m[-1]))
    def pop(self):
        self.s.pop(); self.m.pop()
    def top(self): return self.s[-1]
    def getMin(self): return self.m[-1]
```

### 2.3 单调栈（下一个更大元素）

```python
def daily_temperatures(t):               # 739
    res, st = [0] * len(t), []
    for i, x in enumerate(t):
        while st and t[st[-1]] < x:
            j = st.pop()
            res[j] = i - j
        st.append(i)
    return res

def largest_rectangle(h):                # 84 两侧加哨兵
    h = [0] + h + [0]
    st, best = [], 0
    for i, x in enumerate(h):
        while st and h[st[-1]] > x:
            idx = st.pop()
            best = max(best, h[idx] * (i - st[-1] - 1))
        st.append(i)
    return best
```

### 2.4 单调队列（窗口最值）

```python
def max_sliding_window(nums, k):         # 239
    from collections import deque
    dq, out = deque(), []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x: dq.pop()
        dq.append(i)
        if dq[0] <= i - k: dq.popleft()
        if i >= k - 1: out.append(nums[dq[0]])
    return out
```

## 四、易错点

1. 单调栈里存**下标**而不是值，才能算宽度/距离。
2. 84 题两侧加 `0` 哨兵，省掉「栈里还有剩余」的收尾。
3. `deque` 的 `pop()` 是右边，`popleft()` 才是队头出。
4. 用 `list` 模拟队列要 `pop(0)`，是 O(n)；一律用 `deque`。

## 五、一句话套路

**栈解决「最近的未匹配」，单调栈解决「下一个更大」，单调队列解决「窗口最值」。**
