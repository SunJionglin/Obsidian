# 04 链表

## 一、什么时候想到它

- 「不准改值，只准改指针」→ 链表操作题
- 要删头结点、要合并/拆分 → 先上 **dummy 哨兵**
- 找中点、判环、找倒数第 N → **快慢指针**
- 要按 key 快速取 → 哈希 + 双向链表（LRU）

## 二、模板

### 2.1 翻转链表（迭代 / 递归）

```python
def reverse_list(head):                  # 206
    pre, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = pre
        pre, cur = cur, nxt
    return pre

def reverse_rec(head):                   # 递归版，注意栈深
    if not head or not head.next: return head
    new = reverse_rec(head.next)
    head.next.next = head
    head.next = None
    return new
```

### 2.2 dummy 哨兵

```python
def merge_two(a, b):                     # 21
    dummy = cur = ListNode()
    while a and b:
        if a.val <= b.val: cur.next, a = a, a.next
        else: cur.next, b = b, b.next
        cur = cur.next
    cur.next = a or b
    return dummy.next

def remove_nth(head, n):                 # 19 快慢 + dummy
    dummy = fast = slow = ListNode(0)
    dummy.next = head
    for _ in range(n): fast = fast.next
    while fast.next:
        fast, slow = fast.next, slow.next
    slow.next = slow.next.next
    return dummy.next
```

### 2.3 快慢指针

```python
def middle(head):                        # 876
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    return slow

def has_cycle(head):                     # 141
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast: return True
    return False
```

### 2.4 LRU（哈希 + 双向链表）

```python
class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}                  # key -> node（用 dict 的插入序也能实现，这里给链表版思路）
        self.head, self.tail = Node(0, 0), Node(0, 0)
        self.head.next, self.tail.prev = self.tail, self.head
```

Python 最省事的写法是 `OrderedDict`：`move_to_end(k)` + `popitem(last=False)`，面试写它也没问题。

## 四、易错点

1. 改指针前**先存 `nxt`**，否则后面接不上。
2. 用 dummy 时返回 `dummy.next`，别返回 `dummy`。
3. 循环条件 `while fast and fast.next`：少一个 `fast` 判断就会对空指针取 `.next`。
4. 链表题写完用 2–3 个结点的例子手动走一遍。

## 五、一句话套路

**先 dummy、再画图、改指向前存 nxt；删结点靠「前一个」，所以永远从 dummy 开始。**
