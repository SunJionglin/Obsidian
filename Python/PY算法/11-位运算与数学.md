# 11 位运算与数学

## 一、什么时候想到它

- 「其它都出现两次，只有一个一次」→ 异或
- 判断奇偶、能不能被 2 整除、数 1 的个数 → 位运算
- 不进位加法、子集枚举 → 位掩码
- 快速幂、最大公约数、质数筛 → 数学模板

## 二、模板

### 2.1 核心位运算

```python
x & 1              # 奇偶：1 是奇数
x >> 1             # 除以 2
x & (x - 1)        # 去掉最低位的 1
x & -x             # lowbit，取最低位的 1
x ^ x              # 0
```

Python 的整数没有溢出、也没有固定位宽，所以「int 溢出」类题目要手动取模或 `& 0xFFFFFFFF`。

### 2.2 只出现一次的数字

```python
def single_number(nums):                 # 136
    ans = 0
    for x in nums: ans ^= x
    return ans

def single_number_ii(nums):              # 137 其余出现三次
    once = twice = 0
    for x in nums:
        once = (once ^ x) & ~twice
        twice = (twice ^ x) & ~once
    return once
```

### 2.3 数 1 的个数 / 2 的幂

```python
def hamming_weight(n):                   # 191
    cnt = 0
    while n:
        n &= n - 1
        cnt += 1
    return cnt

def is_power_of_two(n):                  # 231
    return n > 0 and n & (n - 1) == 0
```

`bin(n).count("1")` 在 Python 里更省事（面试可以这么写）。

### 2.4 位掩码枚举子集

```python
def subsets_bitmask(nums):               # 78 的另一种写法
    n = len(nums)
    return [[nums[i] for i in range(n) if mask >> i & 1] for mask in range(1 << n)]
```

### 2.5 快速幂 / gcd / 质数筛

```python
def qpow(a, b, mod):
    r = 1 % mod; a %= mod
    while b:
        if b & 1: r = r * a % mod
        a = a * a % mod; b >>= 1
    return r

import math
math.gcd(a, b)                            # 最大公约数（Python 3.5+）

def primes(n):                            # 埃氏筛
    ok = [True] * (n + 1); ok[0] = ok[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if ok[i]:
            for j in range(i * i, n + 1, i): ok[j] = False
    return [i for i, v in enumerate(ok) if v]
```

## 四、易错点

1. Python 负数按无限位补码处理，`-1 & 0xFF` 得 255；位移前想清楚要不要掩码。
2. `1 << 31` 在 Python 是正数（没有溢出），别照抄 C++ 的写法。
3. 异或只对「成对出现」有用；出现三次要用双掩码或每位求和取模。
4. 质数筛的 `range(i*i, n+1, i)` 从 i² 开始，别从 2i 开始（慢一倍）。

## 五、一句话套路

**成对消掉用异或，判 2 的幂用 `n&(n-1)`，子集枚举用 `1<<n`。**
