# 10 动态规划

## 一、什么时候想到它

- 求「最值 / 方案数 / 可行性」并且**有重叠子问题**
- 当前位置的答案只依赖前几个状态（线性 DP）
- 决策是「选或不选」且容量有限（背包）
- 两个序列做对齐/编辑（区间 DP、序列 DP）

## 二、模板

### 2.1 线性 DP（打家劫舍）

```python
def rob(nums):                            # 198
    take, skip = 0, 0                     # take=抢当前，skip=不抢
    for x in nums:
        take, skip = skip + x, max(skip, take)
    return max(take, skip)
```

### 2.2 0/1 背包（一维压空间，容量倒序）

```python
def can_partition(nums):                  # 416
    total = sum(nums)
    if total % 2: return False
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    for x in nums:
        for j in range(target, x - 1, -1):    # 倒序：每件只用一次
            dp[j] = dp[j] or dp[j - x]
    return dp[target]
```

完全背包（零钱兑换、平方数）：内层**正序**。

### 2.3 二序列 DP（编辑距离 / LCS）

```python
def edit_distance(a, b):                  # 72
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1): dp[i][0] = i
    for j in range(n + 1): dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i-1] == b[j-1]: dp[i][j] = dp[i-1][j-1]
            else: dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
    return dp[m][n]
```

### 2.4 序列 LIS（O(n log n)）

```python
import bisect

def length_of_lis(nums):                  # 300
    tails = []
    for x in nums:
        i = bisect.bisect_left(tails, x)
        if i == len(tails): tails.append(x)
        else: tails[i] = x
    return len(tails)
```

### 2.5 区间 DP（戳气球）

```python
def max_coins(nums):                      # 312
    a = [1] + nums + [1]
    n = len(a)
    dp = [[0] * n for _ in range(n)]
    for length in range(2, n):            # 区间长度
        for i in range(n - length):
            j = i + length
            for k in range(i + 1, j):     # 最后戳破 k
                dp[i][j] = max(dp[i][j], dp[i][k] + a[i]*a[k]*a[j] + dp[k][j])
    return dp[0][n-1]
```

### 2.6 状态机 DP（股票系列）

```python
def max_profit_k(k, prices):              # 188 通用式
    if not prices: return 0
    buy = [-prices[0]] * (k + 1)
    sell = [0] * (k + 1)
    for p in prices[1:]:
        for t in range(1, k + 1):
            buy[t] = max(buy[t], sell[t-1] - p)
            sell[t] = max(sell[t], buy[t] + p)
    return sell[k]
```

## 四、易错点

1. 0/1 背包一维必须**倒序**容量，正序会变成完全背包。
2. 二维 DP 先想清楚 `dp[i][j]` 的定义，再写转移；定义写错，转移一定错。
3. 边界初始化最容易漏：`dp[0][*]`、`dp[*][0]` 单独处理。
4. 结果取 `dp[m][n]` 还是 `max(dp[-1])`，取决于定义是「以 i 结尾」还是「前 i 个」。

## 五、一句话套路

**先写暴力递归 → 找重复子问题 → 加记忆化 → 再滚成表（能压成一维就压）。**
