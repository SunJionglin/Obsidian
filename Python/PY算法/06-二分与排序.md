# 06 二分与排序

## 一、什么时候想到它

- 有序数组里找位置 → 二分
- 「最小的最大值 / 最大的最小值 / 能不能在 k 次内完成」→ 二分答案
- 找第 K 大 / 前 K 个 → 堆或快速选择
- 区间合并、自定义排序 → `sort(key=...)`

## 二、模板

### 2.1 二分三件套（左闭右开）

```python
def lower_bound(nums, x):                # 第一个 >= x，没有返回 len
    l, r = 0, len(nums)
    while l < r:
        m = (l + r) // 2
        if nums[m] >= x: r = m
        else: l = m + 1
    return l

def upper_bound(nums, x):                # 第一个 > x
    l, r = 0, len(nums)
    while l < r:
        m = (l + r) // 2
        if nums[m] > x: r = m
        else: l = m + 1
    return l
```

Python 现成：`bisect.bisect_left(nums, x)` / `bisect_right`。

### 2.2 二分答案

```python
def split_array(nums, m):                # 410 分割数组的最大值
    def ok(limit):
        cnt, cur = 1, 0
        for x in nums:
            if x > limit: return False
            if cur + x > limit: cnt, cur = cnt + 1, x
            else: cur += x
        return cnt <= m
    l, r = max(nums), sum(nums)
    while l < r:
        mid = (l + r) // 2
        if ok(mid): r = mid
        else: l = mid + 1
    return l
```

### 2.3 旋转数组二分

```python
def search_rotated(nums, target):        # 33
    l, r = 0, len(nums) - 1
    while l <= r:
        m = (l + r) // 2
        if nums[m] == target: return m
        if nums[l] <= nums[m]:           # 左半有序
            if nums[l] <= target < nums[m]: r = m - 1
            else: l = m + 1
        else:                            # 右半有序
            if nums[m] < target <= nums[r]: l = m + 1
            else: r = m - 1
    return -1
```

### 2.4 前 K 大 / 第 K 大

```python
import heapq

heapq.nlargest(k, nums)                  # 前 K 大
heapq.nsmallest(k, nums)                 # 前 K 小

def find_kth_largest(nums, k):           # 215：小根堆维护 K 个
    h = nums[:k]
    heapq.heapify(h)
    for x in nums[k:]:
        if x > h[0]: heapq.heapreplace(h, x)
    return h[0]
```

快速选择（平均 O(n)）：`random` 选主元分区，只递归目标那一侧。

## 四、易错点

1. `while l < r` 与 `while l <= r` 配套的边界不同，别混用；统一用**左闭右开**最省心。
2. 二分答案的 `l` 要从「不可能的下界」开始（如 `max(nums)`），否则漏解。
3. `mid = (l + r) // 2` 在 Python 不会溢出，但换成 C++ 要写 `l + (r-l)/2`。
4. 排序比较器里 `return a - b` 在 Python 不合法（要用 `key=` 或 `cmp_to_key`）。

## 五、一句话套路

**有序就二分；问「最小/最大可行值」就二分答案；问「第 K」就堆或快速选择。**
