# 4.1 串的定义和基本操作

## 1. 本节定位

- **对应王道书**：第 4 章「串」4.1 节「串的定义和基本操作」。
- **408 大纲对应**：串的基本概念、串的基本操作（存储结构下一节展开）。
- **先修知识**：线性表的逻辑结构（第 2 章）、位序从 1 开始的概念、ASCII 编码常识。
- **本章位置**：本章开篇。本节只讲**逻辑结构 + 基本运算**（数据结构三要素中的两个），下一节讲**存储结构**，之后整章重心是**模式匹配（定位操作）算法**——朴素算法与 KMP。

## 2. 一句话结论

串是**数据元素限定为字符**的特殊线性表，其基本操作**以子串为操作对象**；串的比较本质是**逐字符比较其编码（二进制数）**，先出现更大字符者更大，前缀全同则**长者更大**。

## 3. 知识地图

│   ├── 相同：逻辑上都是线性序列
│   └── 不同：①元素类型限定为字符 ②操作对象是子串而非单个元素

## 4. 核心内容

### 1. 定义

串（string）是由**零个或多个字符**组成的**有限序列**，记作 $S = "a_1a_2\cdots a_n"$（$n\ge 0$）。

- **串名**：串变量名，如 `s`、`t`。
- **串长**：字符个数 $n$。**引号只是边界符，不计入长度**。例：`"hello world"` 长度为 11（含中间 1 个空格）。
- **空串**：长度为 0 的串，记 `""` 或 `''`。
- **空格串**：由若干空格字符组成的串，长度 = 空格个数，**不是空串**。空格字符在 ASCII 中编码为 `0010 0000`，占 1 字节。

> 王道书用单引号括字符序列；C/Java 用双引号、Python 用单引号，**引号本身不是串的内容**。

### 2. 术语（位序从 1 开始，与线性表一致）

| 术语 | 定义 | 例（设 `t = "hello world"`） |
|---|---|---|
| 子串 | 主串中**任意连续**字符组成的子序列（可为空串） | `"world"`、`"lo w"`、`""` |
| 主串 | 包含子串的那个串 | `t` 本身 |
| 字符在主串中的位置 | 该字符的**位序**（从 1 数），默认指**第一次出现** | `'w'` 在 `t` 中位置为 7 |
| 子串在主串中的位置 | 子串**第一个字符**的位序 | `"world"` 在 `t` 中位置为 7 |

**注意**：子串必须连续；`"hl"` 不是 `"hello"` 的子串（不连续）。

### 3. 串与线性表的区别（408 常考辨析）

| | 线性表 | 串 |
|---|---|---|
| 逻辑结构 | 线性序列 | 线性序列（相同） |
| 数据元素类型 | 任意（`ElemType`） | **限定为字符** |
| 基本操作对象 | 单个数据元素（增删改查一个元素） | **子串**（一段连续字符） |

直观理解：搜索引擎输入的是**一个子串**去匹配海量长字符串，而不是单个字符。

### 4. 基本操作（王道书 9 个，函数原型按王道风格）

```c
StrAssign(&T, chars);          // 赋值：把字符串常量 chars 赋给 T
StrCopy(&T, S);                // 复制：T = S
StrEmpty(S);                   // 判空：空串返回 true，否则 false
StrLength(S);                  // 求串长：返回字符个数
ClearString(&S);               // 清空：S 变为空串，存储空间【不释放】
DestroyString(&S);             // 销毁：释放 S 占用的存储空间
Concat(&T, S1, S2);            // 连接：T = S1 拼接 S2
SubString(&Sub, S, pos, len);  // 求子串：取 S 中从第 pos 个字符起 len 个字符赋给 Sub
Index(S, T);                   // 定位：返回 T 在 S 中第一次出现的位置，找不到返回 0
StrCompare(S, T);              // 比较：S>T 返回正数，S==T 返回 0，S<T 返回负数
```

**清空 vs 销毁**（易混）：
- 清空：逻辑上置为空串，**那片内存仍归你**，可继续写入。
- 销毁：**内存归还系统**，之后不能再使用。

**连接操作的隐含问题**：拼接后长度可能超过原分配空间，故设计存储结构时要考虑**可扩展性**（为下一节顺序/链式存储埋下伏笔）。

### 5. 串的比较规则（本节重点，跨考必看）

**规则**：从第一个字符起逐位比较，**先出现更大字符的串更大**；若一个串是另一个串的**前缀**，则**更长的串更大**；两串完全相同（字符与长度均相同）才相等。

例（字典序）：
- `"abandon" < "aboard"`：前两位 `ab` 相同，第 3 位 `a < o`。
- `"academic" > "abuse"`：第 1 位 `a` 相同，第 2 位 `c > b`。
- `"abstract" < "abstraction"`：前者是后者前缀，后者更长。

**底层原理**：字符在计算机中存为二进制数（编码），比较字符大小 = 比较其编码值。ASCII 中 `'a'` = `0110 0001`，`'c'` = `0110 0011`，故 `'c' > 'a'`。计算机**不查字母表，直接比二进制数**。

### 6. 字符集与编码（了解即可，王道书扩展）

- **字符集**：字符的集合（ASCII 含英文字母、数字、标点；Unicode 含中文等多语言字符）。
- **编码**：字符集 → 二进制数的映射规则。同一字符集可有多种编码（UTF-8、UTF-16 等）。
- 8 位二进制只能表示 $2^8=256$ 个状态，不够表示数万汉字，故需 Unicode 等更大字符集。
- **不同编码下字符占用空间不同**：ASCII 每字符 1 字节；UTF-8 下一个汉字常占 3 字节。**408 考研中只考虑英文字符，每字符 1 字节**。
- **乱码成因**：存储时用编码 $f$，读取时误用另一编码 $g$ 的反函数解码，即用 $g^{-1}(y)$ 去还原本应 $f^{-1}(y)$ 的字符，映射错位 → 乱码。

## 5. 复杂度分析

本节为**概念与操作定义**，不涉及具体算法实现，故无严格复杂度。仅对操作语义作说明：

- `StrLength`、`StrEmpty`：若串的存储结构**额外记录长度**，则 $O(1)$；若需遍历数到结尾（如 C 风格 `'\0'` 结尾），则 $O(n)$。**取决于存储结构，下一节展开**。
- `Concat`：需复制两串全部字符，$O(|S_1|+|S_2|)$，且可能触发扩容。
- `SubString`：复制 `len` 个字符，$O(\text{len})$。
- `Index`（定位）：本节只给语义，**具体算法（朴素 $O(nm)$、KMP $O(n+m)$）在后续小节**，此处不展开推导。
- `StrCompare`：最坏需比较 $\min(|S|,|T|)$ 个字符，$O(\min(|S|,|T|))$；最好第 1 个字符即分出大小，$O(1)$。

> 平均情况本节不涉及概率模型，不强行给结论；定位算法的平均分析留到模式匹配小节。

## 6. 易错点与考试写法

1. **引号不计入串长**：`"hello world"` 长 11，不是 13。
2. **空串 ≠ 空格串**：`""` 长 0；`"   "`（3 个空格）长 3。判空只看长度是否为 0。
3. **位序从 1 开始**：字符位置、子串位置都从 1 数，与数组下标（从 0）差 1，答题时务必写清。
4. **子串必须连续**：不连续的不叫子串。
5. **子串位置取首字符位序**，不是末字符。
6. **空串是任何串的子串**（长度 0 的连续子序列）。
7. **比较时前缀关系**：`"ab" < "abc"`，不能因前两位相同就判相等。
8. **清空与销毁不可混用**：清空后空间还在，销毁后不可再用。
9. **答题程度**：概念题写清「定义 + 与线性表的异同（元素类型、操作对象两点）」即可满分；比较题必须写出「逐位比较 + 前缀长者大」两条规则；操作题按函数原型写语义，不必写实现（实现属下一节存储结构）。

## 7. 408 题型与解题套路

- **选择题高频点**：
  - 给一个串，问子串个数 / 某子串位置 / 串长（含空格陷阱）。
  - 空串与空格串辨析。
  - 串与线性表的区别（元素类型、操作对象）。
  - 两串比较大小（给几个字符串排序）。
  - 字符编码占字节数（考研默认英文字符 1 字节）。
- **解题套路**：
  - 数长度：逐字符数，**跳过引号，空格算 1 个**。
  - 定位：从左往右找子串首字符第一次匹配处，报其位序（从 1）。
  - 比较：逐位对齐比编码，前缀相同看长度。
- **常见陷阱**：把引号算进长度；把空格串当空串；位序与下标混用；子串不连续也当子串。

## 9. 背诵卡

1. 串 = 字符的有限序列；**引号是边界符，不计长度**；空串长 0，空格串长 = 空格数，二者不同。
2. 子串 = **连续**子序列（含空串）；子串位置 = **首字符位序**；位序**从 1 开始**。
3. 串是特殊线性表：**元素限定为字符**、**操作以子串为对象**。
4. 比较规则：逐位比编码，**先出现大字符者大**；前缀全同则**长者大**；全同才相等。
5. 清空 = 逻辑置空、空间保留；销毁 = 空间归还系统。考研默认英文字符 1 字节。
