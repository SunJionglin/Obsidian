# 8.1 排序的基本概念

## 1. 本节定位

- **对应王道书**：第 8 章「排序」开篇 8.1 排序的基本概念（全章总纲小节）。
- **408 大纲对应**：排序的基本概念（排序的定义、稳定性、内部排序与外部排序的分类）——属「排序」考查范围的总起条目。
- **先修知识**：数据元素与关键字的概念（第 1 章）、时间复杂度与空间复杂度的分析方法（第 1、2 章）。
- **本节位置**：整章的第一节，只建立术语框架，不涉及任何具体排序算法的实现；后续各小节（插入、交换、选择、归并、基数排序及外部排序）都将在本节给出的「时间复杂度 / 空间复杂度 / 稳定性」三把尺子下逐一分析。

## 2. 一句话结论

排序是把数据元素按关键字递增或递减重排；评价一个排序算法看**时间复杂度、空间复杂度、稳定性**三项指标，算法按数据能否全部装入内存分为**内部排序**与**外部排序**。

## 3. 知识地图

```
排序
├── 定义：按关键字递增/递减重排数据元素
│     └── 关键字可重复（与前面章节"关键字唯一"不同）
├── 评价指标（三把尺子）
│     ├── 时间复杂度
│     ├── 空间复杂度
│     └── 稳定性
│           ├── 稳定：排序后关键字相同元素的相对位置不变
│           └── 不稳定：相对位置可能改变
├── 分类
│     ├── 内部排序：数据全部在内存中 → 重点关注时间/空间复杂度
│     └── 外部排序：数据量过大，需借助外存 → 额外关注读写磁盘次数
└── 稳定 ≠ 更优：取决于应用需求与关键字是否可能重复
```

## 4. 核心内容

### 4.1 排序的定义

将一组数据元素按**关键字**递增或递减的顺序重新排列，使处理后关键字整体有序。

- 前面章节（如查找）中默认关键字唯一；**排序中关键字允许相同**（如游戏排行榜按战力排名、财富榜按财富值排名，都可能出现并列）。这是本节第一个需要扭转的认知。

### 4.2 稳定性（本节最核心概念，408 必考）

设序列中有两个关键字相同的元素 $a$、$b$，且排序前 $a$ 在 $b$ 之前：

- 若排序后 $a$ 仍在 $b$ 之前（相对位置不变）→ 该算法**稳定**；
- 若排序后可能出现 $b$ 在 $a$ 之前（相对位置改变）→ 该算法**不稳定**。

注意：稳定性是**算法本身的属性**，不是某一次排序结果的属性。判断不稳定，只需能构造出一组使相同关键字元素换位的输入即可。

### 4.3 稳定性是否等于更优？

不能一概而论：

- 若应用场景对稳定性无要求，用不稳定算法完全可以；
- 若所有元素关键字**互不相同**，则稳定与不稳定算法排出的结果必然相同，稳定性无实际意义。

### 4.4 内部排序与外部排序

| 类别 | 数据存放 | 设计时重点关注 |
|---|---|---|
| 内部排序 | 全部数据可放入内存 | 时间复杂度、空间复杂度 |
| 外部排序 | 数据量过大，无法一次全部读入内存，需分批处理并借助外存 | 除时间/空间外，还要追求**更少的磁盘读写次数** |

原因（数量级对比，用于理解，非精确考点）：机械硬盘读写速度约 100 MB/s 量级，内存读写速度约 60 GB/s 量级，相差数百倍；外部排序中数据要在磁盘与内存间反复读写，磁盘 I/O 成为瓶颈，故减少 I/O 次数是关键优化目标。具体外部排序方法在后续小节展开。

### 4.5 学习工具（了解即可）

旧金山大学的算法可视化网站，可逐步演示冒泡排序等各排序算法的执行过程，并可调节速度、单步执行；也含 BFS/DFS、哈希表、Dijkstra、Prim、拓扑排序、Floyd、Kruskal 等演示。**注意**：该网站部分非排序算法的变量定义与细节可能与 408 大纲要求有出入，但排序部分与考研教材一致。

## 5. 复杂度分析

本节为概念课，**不涉及具体算法，无复杂度可分析**。需要记住的是方法论：

- 内部排序：分析最好 / 最坏 / 平均时间复杂度与空间复杂度（后续每个算法逐一给出，平均情况需说明概率假设，如「待排序列等概率随机排列」）；
- 外部排序：在时间/空间之外，以「磁盘读写次数（I/O 次数）」作为核心代价度量。

## 6. 易错点与考试写法

1. **「关键字唯一」的惯性错误**：前面章节关键字唯一，排序章节必须允许关键字相同，否则稳定性概念无从谈起。
2. **稳定性定义的方向**：是「排序前后，关键字相同元素的**相对次序**是否保持」，不是「关键字值是否改变」，也不是「元素是否移动」。
3. **「稳定算法一定更好」是错的**：选择题常设此陷阱，正确表述是「取决于具体应用需求；关键字均不重复时两者结果相同」。
4. **内部/外部排序的划分依据**：是「数据能否全部装入内存」，不是「算法写在哪」或「数据量绝对大小」。
5. **答题程度**：概念题答到「按关键字递增/递减重排」「稳定性指相同关键字元素相对位置不变」「按数据是否全在内存分为内部/外部排序」即算完整，无需展开具体算法。

## 7. 408 题型与解题套路

- **选择题（主要考法）**：
  - 给出某算法对一组含重复关键字数据的排序前后序列，判断该算法是否稳定（后续各节学完具体算法后，直接背每个算法的稳定性结论）；
  - 概念辨析：「稳定的排序算法是否一定优于不稳定的」「内部排序与外部排序的区别」。
- **算法题**：本节不直接出算法题，但后续若要求「设计稳定/不稳定的排序方案」，稳定性判断是评分点。
- **常见陷阱**：把「一趟排序后相同关键字元素没换位」当作算法稳定的证明——单次结果不能证明稳定性，必须看算法对所有输入的行为。

## 8. 自测题

**1.** 排序算法稳定性的准确定义是什么？

**2.** 判断：稳定的排序算法一定比不稳定的排序算法好。

**3.** 若待排序序列中所有关键字互不相同，稳定算法与不稳定算法的排序结果是否一定相同？为什么？

## 9. 背诵卡

1. 排序 = 按关键字递增/递减重排；排序中关键字**可重复**。
2. 评价排序算法三指标：**时间、空间、稳定性**。
3. 稳定：排序前后关键字相同元素的**相对位置不变**；可能改变则不稳定。
4. 稳定不一定更优；关键字全不重复时稳定与不稳定结果相同。
5. 内部排序看时间/空间；外部排序额外看**磁盘读写次数**。
