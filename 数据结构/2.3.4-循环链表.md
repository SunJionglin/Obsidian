# 2.3.4 循环链表

## 1. 本节定位

- **对应王道书**：第 2 章 2.3.4 循环链表（循环单链表、循环双链表）。
- **408 大纲对应**：线性表的链式存储结构——单链表、双链表、循环链表的基本操作与实现。
- **先修知识**：单链表（带头结点）的插入、删除、遍历；双链表结点的 `prior`/`next` 双指针结构；头结点作用。
- **本节位置**：2.3 线性表链式表示的收尾小节，学完本节即完成“指针实现的全部链表”（单链表、双链表、循环单链表、循环双链表），为 2.4 顺序表与链表对比、后续栈/队列的链式实现打基础。

## 2. 一句话结论

循环链表就是把单/双链表“首尾相接”：**循环单链表尾结点 `next` 指回头结点，循环双链表再加头结点 `prior` 指向尾结点**；由此判空、判表尾、找前驱的写法全部改变，且“给一个结点指针即可遍历全表”。

## 3. 知识地图

```
循环链表
├── 循环单链表
│   ├── 结构：尾结点 next → 头结点（闭环）
│   ├── 初始化：head->next = head
│   ├── 判空：head->next == head
│   ├── 判表尾：p->next == head
│   ├── 遍历终止条件：p->next == head（而非 p != NULL）
│   └── 应用：仅给 p 可找全表任意结点（可删 p 本身）；L 指向尾结点时头/尾操作 O(1)
└── 循环双链表
    ├── 结构：尾 next → 头，头 prior → 尾（两个方向各成闭环）
    ├── 初始化：head->next = head 且 head->prior = head
    ├── 判空：head->next == head
    ├── 判表尾：p->next == head
    └── 应用：课本双链表“p 后插 s”“删 q”代码在表尾不再出错
```

## 4. 核心内容

### 1. 循环单链表

**定义**：在单链表基础上，令最后一个结点的 `next` 指针指向头结点（而非 `NULL`），整条链形成闭环。

**初始化（带头结点，空表）**：

```c
// 初始化一个空的循环单链表
bool InitList(LinkList *L) {
    *L = (LNode *)malloc(sizeof(LNode));  // 分配头结点
    if (*L == NULL) return false;         // 内存不足
    (*L)->next = *L;                      // 头结点 next 指向自己
    return true;
}
```

**判空**：

```c
// 空表：头结点的 next 指向自己
bool Empty(LinkList L) {
    return (L->next == L);
}
```

**判表尾**：结点 `p` 是表尾 ⇔ `p->next == L`（`L` 为头指针）。

**遍历**：扫描指针从首元结点出发，终止条件为 `p != L`（回到头结点即停），**不能写 `p != NULL`**，否则死循环。

```c
// 遍历循环单链表（带头结点）
LNode *p = L->next;          // 从首元结点开始
while (p != L) {             // 回到头结点即遍历结束
    visit(p);                // 访问 p
    p = p->next;
}
```

**关键性质（本节重点）**：普通单链表只给结点 `p`，只能访问 `p` 及其后继，**无法找前驱**；循环单链表只给 `p`，沿 `next` 绕一圈可到达表中任意结点，因此**可以找到 `p` 的前驱，从而删除 `p` 本身**（代价是 $O(n)$ 扫描）。

**工程技巧**：若 `L` 不指向头结点而**指向尾结点**，则找尾结点 $O(1)$、找头结点（`L->next`）也 $O(1)$，适合频繁在表头/表尾操作；代价是表尾插入/删除后要维护 `L` 的指向。

### 2. 循环双链表

**定义**：尾结点 `next` 指向头结点，头结点 `prior` 指向尾结点；`next` 链与 `prior` 链各自形成闭环。

**初始化（空表）**：

```c
// 初始化一个空的循环双链表
bool InitDLinkList(DLinkList *L) {
    *L = (DNode *)malloc(sizeof(DNode));  // 分配头结点
    if (*L == NULL) return false;
    (*L)->next = *L;                      // 后向指针指向自己
    (*L)->prior = *L;                     // 前向指针指向自己
    return true;
}
```

**判空**：`L->next == L`（等价地 `L->prior == L`）。

**判表尾**：`p->next == L`。空表时头结点既是“第一个”也是“最后一个”，该判断仍成立。

**课本双链表代码在循环双链表下“自动正确”**：

```c
// 在结点 p 之后插入结点 s（循环双链表下表尾也成立）
bool InsertNextDNode(DNode *p, DNode *s) {
    s->next = p->next;        // ① s 的后继 = p 原来的后继
    p->next->prior = s;       // ② 原后继的 prior 指向 s（普通双链表表尾时 p->next 为 NULL，此处出错）
    s->prior = p;             // ③ s 的前驱 = p
    p->next = s;              // ④ p 的后继 = s
    return true;
}
```

```c
// 删除结点 p 的后继结点 q（循环双链表下表尾也成立）
bool DeleteNextDNode(DNode *p) {
    DNode *q = p->next;       // q 为被删结点
    if (q == NULL) return false;
    p->next = q->next;        // ① p 的后继越过 q
    q->next->prior = p;       // ② q 的后继的 prior 指向 p（普通双链表 q 为表尾时 q->next 为 NULL，此处出错）
    free(q);                  // ③ 释放 q
    return true;
}
```

> 说明：上面两段代码在**普通双链表**中，当 `p` 是表尾（插入）或 `q` 是表尾（删除）时，`p->next`/`q->next` 为 `NULL`，第 ② 句解引用空指针出错；循环双链表因尾结点 `next` 指向头结点而**始终非空**，故逻辑正确。这是本节最典型的“代码复用”考点。

## 5. 复杂度分析

设表长 $n$（不含头结点）。

| 操作 | 循环单链表 | 循环双链表 |
|---|---|---|
| 判空 | $O(1)$ | $O(1)$ |
| 判表尾 | $O(1)$ | $O(1)$ |
| 找首元结点 | $O(1)$（`L->next`） | $O(1)$ |
| 找表尾结点 | $O(n)$（从头扫）；`L` 指尾时 $O(1)$ | $O(n)$（从头扫）；`L` 指尾时 $O(1)$ |
| 删除给定结点 `p` | $O(n)$（需先找前驱） | $O(1)$（`p->prior` 直接可得） |
| 在 `p` 后插入 `s` | $O(1)$ | $O(1)$ |

**平均情况推导**：以“循环单链表删除给定结点 `p`”为例，需从 `L->next` 起沿 `next` 扫描找 `p` 的前驱。设 `p` 等概率位于第 $i$ 个位置（$1 \le i \le n$），则扫描次数为 $i$（走到第 $i-1$ 个结点），平均比较次数

$$\frac{1}{n}\sum_{i=1}^{n} i = \frac{n+1}{2} = O(n).$$

最坏 $O(n)$（`p` 为表尾），最好 $O(1)$（`p` 为首元结点，前驱即头结点）。循环双链表删除 `p` 无需扫描，三种情况均为 $O(1)$。

## 6. 易错点与考试写法

1. **判空条件写错**：循环单链表空表是 `head->next == head`，不是 `head->next == NULL`；循环双链表还要 `head->prior == head`。
2. **遍历终止条件写错**：循环链表遍历用 `p != L`（回到头结点），写成 `p != NULL` 会死循环——这是选择题高频陷阱。
3. **判表尾条件**：`p->next == L`，不是 `p->next == NULL`。
4. **“给 p 能删 p”只对循环单链表成立**：普通单链表给 `p` 无法找前驱，不能直接删 `p`；循环单链表可以但需 $O(n)$ 扫描。**循环双链表**给 `p` 删 `p` 才是 $O(1)$。
5. **`L` 指向尾结点的代价**：表尾插入/删除后必须更新 `L` 的指向，否则 `L` 失效；答题时要写出这一维护动作。
6. **答题标准**：408 算法题写循环链表操作，必须体现“初始化/判空/判表尾/遍历终止”四类边界条件；插入删除要分“表头、表中、表尾”三种位置讨论是否需特殊处理，代码能处理表尾空指针即得分点。

## 7. 408 题型与解题套路

- **选择题**：常考判空/判表尾/遍历终止条件的辨析；给一段在普通双链表表尾出错的代码，问换成循环双链表是否仍正确；问“仅知结点 p 能否删除 p”在四种链表中的可行性。
- **算法题**：循环单链表常与“找前驱”“约瑟夫环”“尾指针优化”结合；循环双链表常考“在表尾插入/删除”的边界正确性。套路：先画闭环图 → 确定终止条件 → 分表头/表中/表尾讨论 → 检查 `next`/`prior` 是否可能为 `NULL`（循环链表下永不为 `NULL`，这是简化代码的关键）。
- **常见陷阱**：把循环链表当普通链表写 `while (p != NULL)`；忘记循环双链表初始化时 `prior` 也要指向自己；`L` 指尾时忘记维护 `L`。

## 8. 自测题

**1.** 带头结点的循环单链表 `L` 为空表的判断条件是（ ）。
A. `L == NULL` B. `L->next == NULL` C. `L->next == L` D. `L->prior == L`

**2.** 仅给出指向某结点的指针 `p`，在下列哪种链表中可以 $O(1)$ 删除 `p` 本身？
A. 单链表 B. 循环单链表 C. 双链表 D. 循环双链表

**3.** 循环单链表遍历的循环终止条件应写为（设头指针为 `L`，扫描指针 `p` 从首元结点出发）________。

**4.** 课本“在 `p` 后插入 `s`”的双链表代码 `p->next->prior = s;` 在普通双链表表尾会出错，在循环双链表中为什么正确？

**5.** 循环单链表 `L` 指向尾结点时，找表头结点和表尾结点的时间复杂度分别是多少？表尾插入后需要做什么维护？

<details>
<summary>答案</summary>

1. **C**。空表时头结点 `next` 指向自己。
2. **D**。循环双链表有 `prior` 可直接找前驱，$O(1)$；循环单链表需 $O(n)$ 扫描找前驱；普通单链表/双链表给 `p` 无法（或不能直接）删 `p`。
3. `p != L`（回到头结点即停），不能写 `p != NULL`。
4. 循环双链表尾结点的 `next` 指向头结点而非 `NULL`，故 `p->next` 始终非空，`p->next->prior = s` 合法，把头结点的 `prior` 改为 `s` 即可。
5. 找表头 `L->next` 为 $O(1)$，找表尾即 `L` 本身为 $O(1)$；表尾插入后需把 `L` 更新为新的尾结点。

## 9. 背诵卡

1. 循环单链表：尾 `next` → 头；初始化 `head->next = head`；判空 `head->next == head`；判尾 `p->next == head`；遍历停 `p == head`。
2. 循环双链表：尾 `next` → 头，头 `prior` → 尾；初始化 `head->next = head->prior = head`；判空 `head->next == head`。
3. 给 `p` 删 `p`：普通单链表不行；循环单链表 $O(n)$（找前驱）；循环双链表 $O(1)$。
4. 循环双链表下课本双链表插入/删除代码在表尾不再空指针出错——因为尾结点 `next` 指向头结点，永不为 `NULL`。
5. `L` 指尾结点：头/尾操作均 $O(1)$，但表尾插入/删除后要维护 `L`。
