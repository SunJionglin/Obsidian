# 7.4.1_2 B树的插入与删除

## 1. 本节定位

- **王道书**：第 7 章「查找」→ 7.4 B 树与 B+ 树 → 7.4.1 B 树 → 插入与删除操作。
- **408 大纲**：查找 → B 树（含 B+ 树）的基本概念、插入与删除。属于「408 必考」范围，选择题高频，偶尔与查找结合出综合题。
- **先修知识**：B 树的定义与阶（$m$ 阶 B 树的关键字个数范围）、B 树的查找过程（本节插入位置完全依赖查找规则）。
- **本章位置**：上一小节讲 B 树性质与查找，本节讲「动态维护」——插入靠分裂、删除靠借位/合并，本质是**始终维持 B 树定义中的关键字个数上下界与有序性**。

## 2. 一句话结论

B 树插入一律发生在终端节点，超上限就**从 $\lceil m/2 \rceil$ 位置分裂、中间关键字上提**，可能连锁到根使树高 +1；删除非终端关键字先**用直接前驱/后继顶替**转化为终端删除，终端删除后低于下限则**先向兄弟借（经父节点周转）、借不到就与兄弟连同父节点中夹着的关键字合并**，可能连锁到根使树高 −1。

## 3. 知识地图

```
B树的动态维护（m 阶，关键字数 ∈ [⌈m/2⌉−1, m−1]）
├── 插入
│   ├── 定位：按查找规则，一定插入到最底层终端节点
│   ├── 合法：关键字数 ≤ m−1，结束
│   └── 溢出（= m 个）：分裂
│       ├── 取第 ⌈m/2⌉ 个关键字上提到父节点
│       ├── 左右两半各自成节点，指针按大小关系重新挂接
│       └── 父节点可能继续溢出 → 逐层上分裂 → 根分裂则树高 +1
└── 删除
    ├── 非终端节点：用直接前驱（左子树最右下）或直接后继（右子树最左下）顶替
    │   └── 转化为终端节点删除
    └── 终端节点删除后
        ├── 关键字数 ≥ ⌈m/2⌉−1：直接删，结束
        ├── 低于下限且兄弟够借：借位（父节点关键字下移、兄弟关键字上移）
        │   ├── 借右兄弟：当前节点后继 + 后继的后继填补
        │   └── 借左兄弟：当前节点前驱 + 前驱的前驱填补
        └── 兄弟不够借：合并
            ├── 当前节点 + 兄弟 + 父节点中夹着的那个关键字 → 合成一个节点
            ├── 父节点关键字数 −1，可能低于下限 → 父节点继续借/合并
            └── 合并到根、根关键字数变 0 → 删根，树高 −1
```

## 4. 核心内容

### 一、前提：$m$ 阶 B 树的关键字个数范围

每个节点（除根）关键字个数 $n$ 满足

$$\lceil m/2\rceil - 1 \le n \le m-1$$

根节点特殊：$1 \le n \le m-1$（树非空时至少 1 个关键字）。

本节例子取 $m=5$：$2 \le n \le 4$，即**最少 2 个、最多 4 个**关键字。视频明确指出「考试不会出现比五阶更高阶的情况」，五阶例子已是难度上限。

### 二、插入

**规则 1（定位）**：新关键字一定插入到**最底层终端节点**，位置由 B 树查找规则确定。若插到非终端节点，会导致各失败节点不在同一层，破坏 B 树特性。

**规则 2（溢出处理）**：插入后若该节点关键字数达到 $m$（超过上限 $m-1$），分裂：

1. 取第 $\lceil m/2\rceil$ 个关键字（$m=5$ 时即第 3 个）作为分裂点；
2. 该关键字**上提到父节点**；
3. 其左的关键字留在原节点，其右的关键字放入新节点；
4. 新节点挂在分裂关键字右侧的指针上（保证左小右大）。

**规则 3（上提位置）**：上提的关键字放到父节点中「指向被分裂节点的那个指针」所对应关键字的**右边**，以维持父节点内关键字有序。

**规则 4（连锁）**：父节点因此也可能溢出，继续向上分裂；若分裂到根，则新建根节点，**树高 +1**——这是 B 树长高的唯一方式。

**插入过程示意（$m=5$，按视频顺序）**：

```
插 25,38,49,60 → 根节点 [25|38|49|60]（已满 4 个）
插 80 → 溢出，第3个 49 上提：
        根 [49]
          ├─ [25|38]
          └─ [60|80]
插 90 → 终端 [60|80|90]
插 88 → [60|80|88|90] 满
插 83 → 溢出，第3个 88 上提：
        根 [49|88]
          ├─ [25|38]
          ├─ [60|80]
          └─ [83|90]
插 87 → [83|87|90]
插 70 → [60|70|80] 溢出，80 上提至 49 与 88 之间：
        根 [49|80|88]
          ├─ [25|38]
          ├─ [60|70]
          ├─ [83|87]
          └─ [90]
插 92,93,94 → [90|92|93|94] 溢出，93 上提至 88 右侧：
        根 [49|80|88|93]
          ├─ [25|38]
          ├─ [60|70]
          ├─ [83|87]
          ├─ [90|92]
          └─ [94]
再插 73 等使 [60|70|73|…] 溢出，73 上提 → 根 [49|73|80|88|93] 溢出（5 个）
→ 根分裂，80 上提为新根，树高 +1：
        新根 [80]
          ├─ [49|73]
          └─ [88|93]
```

**要点**：分裂只改变节点划分与指针挂接，**不改变关键字之间的中序次序**，故 B 树有序性自动保持。

### 三、删除

**第一步：非终端节点关键字的删除 → 转化为终端删除**

删除非终端节点中的关键字 $k$ 时，用其**直接前驱**或**直接后继**顶替：

- 直接前驱：$k$ 左侧指针所指子树中**最右下**的关键字；
- 直接后继：$k$ 右侧指针所指子树中**最左下**的关键字。

顶替后问题变为删除终端节点中的那个前驱/后继，因为最右下/最左下一定落在终端节点。视频强调：这与二叉排序树找前驱/后继的思想一致。

**第二步：终端节点删除后的三种情况**

设删除后该节点关键字数为 $n$，下限 $L=\lceil m/2\rceil-1$（$m=5$ 时 $L=2$）。

| 情况 | 条件 | 处理 |
|---|---|---|
| ① 直接删 | $n \ge L$ | 删除后仍合法，结束 |
| ② 借位 | $n < L$ 且某相邻兄弟关键字数 $> L$ | 经父节点周转：父节点中夹在两节点间的关键字下移到当前节点，兄弟的一个关键字上移到父节点 |
| ③ 合并 | $n < L$ 且左右兄弟都只有 $L$ 个 | 当前节点 + 一个兄弟 + 父节点中夹着的关键字，三者合成一个节点 |

**借位细节（$m=5$）**：

- **借右兄弟**：当前节点缺位，父节点关键字 $p$ 下移补入当前节点，右兄弟最小关键字上移替换 $p$。视频的记忆口诀：「用当前节点的后继、后继的后继填补」——后继即父节点中的 $p$，后继的后继即右兄弟中最小者。
- **借左兄弟**：对称，父节点关键字 $p$ 下移，左兄弟最大关键字上移替换 $p$。口诀：「用当前节点的前驱、前驱的前驱填补」。

> 注意：**不能直接把兄弟的关键字搬过来**。例如删 38 后若直接把右兄弟的 70 拿过来，会破坏「49 左侧子树全部小于 49」的性质，必须先让 49 下移、70 上移。

**合并细节**：合并时**必须把父节点中夹在这两个节点之间的那个关键字一起并入**，否则该关键字失去归属，B 树性质被破坏。合并使父节点关键字数减 1，父节点可能低于下限，于是对父节点重复「借位/合并」，**逐层向上**；若合并进行到根、根的关键字被全部取走变为 0 个，则**删除根节点，其唯一孩子成为新根，树高 −1**——这是 B 树变矮的唯一方式。

**删除过程示意（$m=5$，按视频顺序）**：

```
删 60（终端，删后 3 个 ≥ 2）→ 直接删
删 80（非终端）→ 用直接前驱 77 顶替，转化为删终端 77
删 77（非终端）→ 用直接后继 82 顶替，转化为删终端 82 → 直接删
删 38 → 节点 [25] 只剩 1 个 < 2，右兄弟 [60|70] 有 2 个不够借？
        实际例中右兄弟宽裕：父 49 下移、70 上移 → [25|49] 与 [60|70] 调整
删 90 → 右兄弟不宽裕、左兄弟宽裕：借左兄弟
        父 88 下移、左兄弟最大 87 上移
删 49 → 左右兄弟都只有下限，合并：
        当前节点 + 右兄弟 + 父节点中夹着的 82 合并
        → 父节点关键字数减 1 低于下限 → 父节点与其兄弟再合并
        → 根被取空 → 删根，孩子成为新根，树高 −1
```

### 四、核心不变式（贯穿全节）

任何调整后必须检查：对每个关键字 $k$，其**左子树所有关键字 $< k$**，**右子树所有关键字 $> k$**；且每个非根节点关键字数在 $[L, m-1]$ 内，所有失败节点在同一层。视频反复强调「永远保证 B 树的特性」，这是所有操作的唯一判据。

## 5. 复杂度分析

设 B 树高为 $h$（失败节点层数为 $h+1$），节点关键字数上限 $m-1$。

- **查找定位（插入/删除的第一步）**：每层节点内做顺序查找，最多比较 $m$ 次；共 $h$ 层，故 $O(mh)$。若节点内改用折半查找则为 $O(h\log m)$（王道扩展，非本节重点）。
- **插入**：定位 $O(mh)$ + 分裂。分裂沿路径向上，最坏从终端一路裂到根，共 $h$ 次分裂，每次分裂搬移 $O(m)$ 个关键字，故分裂总代价 $O(mh)$。**最好** $O(mh)$（定位后不分裂，只多常数）；**最坏** $O(mh)$（裂到根，树高 +1）；**平均**：假设插入位置等概率落在各层终端节点、且节点平均半满，则期望分裂次数为常数级（几何级数 $\sum_{i\ge0}(1/2)^i$ 收敛），平均仍为 $O(mh)$，主导项是定位。由于 $m$ 视为常数，常写作 $O(h)$。
- **删除**：定位 $O(mh)$ + 借位/合并。借位只涉及常数个节点，$O(m)$；合并最坏沿路径逐层合并到根，$h$ 次合并、每次 $O(m)$，故 $O(mh)$。**最好** $O(mh)$（直接删）；**最坏** $O(mh)$（合并到根，树高 −1）；**平均**：与插入对称，期望合并次数常数级，平均 $O(mh)$。
- **树高范围**（补充，用于选择题估算）：含 $N$ 个关键字的 $m$ 阶 B 树，$h$ 满足 $\log_m(N+1) \le h \le \log_{\lceil m/2\rceil}\big((N+1)/2\big)+1$，故插入删除均为 $O(\log N)$ 量级。

## 6. 易错点与考试写法

1. **插入位置**：新关键字只能进终端节点。若答成「插到根节点/中间节点」，直接错——会破坏失败节点同层性。
2. **分裂点位置**：是第 $\lceil m/2\rceil$ 个关键字（$m=5$ 取第 3 个），不是第 $\lfloor m/2\rfloor$ 个，也不是「正中间偏左」。$m$ 为偶数时尤其要记牢向上取整。
3. **上提关键字在父节点中的位置**：放在「指向被分裂节点的指针」对应关键字的右边，不是随便插，否则父节点内无序。
4. **删除非终端关键字**：必须用直接前驱或直接后继顶替，不能直接删；顶替后要说明「转化为终端节点删除」。
5. **借位不能直接搬兄弟关键字**：必须经父节点周转（父下移、兄弟上移），否则破坏有序性。这是最常考的判断点。
6. **合并必须带上父节点中夹着的关键字**：漏掉它是最典型错误，合并后节点关键字数应为「左 + 1 + 右」。
7. **连锁方向**：插入向上分裂、删除向上合并，两者都可能波及根；插入使树高 +1，删除使树高 −1，且**只有这两种途径**改变树高。
8. **答题程度**：408 考 B 树插入删除以**画图/判断选择题**为主，不要求写代码。答题时每一步画出节点关键字序列与指针挂接即可；若考「是否合法」，逐节点核对关键字数范围和有序性两条即可给满分。

## 7. 408 题型与解题套路

- **选择题（高频）**：
  - 给 $m$ 阶 B 树与一个插入序列，问某次插入后根节点关键字 / 树高 / 某节点内容 → 按「定位终端 → 满则第 $\lceil m/2\rceil$ 个上提 → 连锁」逐步画。
  - 给删除操作，问「采用借位还是合并」「合并后该节点关键字数」「树高是否变化」→ 先看兄弟关键字数是否 $> L$，再看是否连锁到根。
  - 判断「某操作后仍是 B 树吗」→ 查两条：关键字数范围、有序性（左小右大）。
- **综合题（偶见）**：与 B 树查找、B+ 树对比结合，问「插入/删除对树高的影响」「与二叉排序树、平衡树的异同」。答题套路：先写 $m$ 阶范围公式，再按操作步骤描述，最后点明「分裂/合并是维持平衡的唯一手段」。
- **常见陷阱**：
  - 把 $m$ 阶的关键字上限记成 $m$（应为 $m-1$），下限记成 $\lceil m/2\rceil$（应为 $\lceil m/2\rceil-1$）。
  - 根节点特殊性：根可以只有 1 个关键字，删除合并到根为空时要删根降高。
  - 借位时搞反「谁下移谁上移」。
  - 合并后忘记父节点关键字数减 1，漏判连锁。

## 8. 自测题

**1.** 5 阶 B 树中，某终端节点已有 4 个关键字，再插入一个关键字后应如何分裂？分裂出的中间关键字放在父节点的什么位置？

**2.** 5 阶 B 树中删除某终端节点的一个关键字后，该节点剩 1 个关键字，其右兄弟有 3 个关键字，应执行什么操作？能否直接把右兄弟的一个关键字移到当前节点？

**3.** 承上，若左右兄弟都只有 2 个关键字，应如何操作？合并后的节点含几个关键字？对父节点有何影响？

**4.** 删除非终端节点中的关键字时，为什么一定能转化为终端节点的删除？

**5.** 判断：B 树插入操作可能使树高减 1，删除操作可能使树高加 1。

<summary>答案</summary>

1. 取第 $\lceil 5/2\rceil=3$ 个关键字上提；其左关键字留原节点，其右关键字放入新节点；上提关键字放在父节点中「指向被分裂节点的指针」所对应关键字的右边，新节点挂在该关键字右侧指针上。
2. 执行**借位**（向右兄弟借）。不能直接搬：必须父节点中夹在两节点间的关键字下移补入当前节点，右兄弟最小关键字上移替换父节点该位置，否则破坏「左小右大」有序性。
3. 执行**合并**：当前节点 + 一个兄弟 + 父节点中夹着的那个关键字合成一个节点，共 $1+1+2=4$ 个关键字（$m=5$ 上限 4，合法）。父节点关键字数减 1，可能低于下限，需对父节点继续借位/合并，可能连锁到根。
4. 因为直接前驱是左子树最右下关键字、直接后继是右子树最左下关键字，二者必落在终端节点；用其顶替后，问题等价于删除终端节点中的该关键字。
5. 错。插入只会使树高 +1（根分裂），删除只会使树高 −1（根被取空删除），方向相反。

## 9. 背诵卡

1. $m$ 阶 B 树非根节点关键字数 $\in [\lceil m/2\rceil-1,\ m-1]$；$m=5$ 即 $[2,4]$。
2. 插入必进终端节点；溢出取第 $\lceil m/2\rceil$ 个上提，左右分家，上提关键字放父节点对应指针的右边；裂到根则树高 +1。
3. 删非终端关键字 → 用直接前驱（左子树最右下）或直接后继（右子树最左下）顶替，转为终端删除。
4. 终端删除低于下限：兄弟 $>L$ 则借位（父下移、兄弟上移，不可直接搬）；兄弟都 $=L$ 则合并（当前 + 兄弟 + 父中夹着的关键字），父节点减 1 可能连锁。
5. 合并到根、根空则删根，树高 −1；一切操作后必查「左小右大 + 关键字数在范围内」。
