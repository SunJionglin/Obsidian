# 8.4.2 堆排序

## 1. 本节定位

- **对应王道书**：第 8 章 排序，8.4 选择排序，8.4.2 堆排序（本节为堆排序第一课时：堆的定义、建堆、排序过程与代码）。
- **408 大纲对应**：排序——堆排序（大根堆/小根堆的建立、调整、排序过程、复杂度、稳定性）。
- **先修知识**：完全二叉树的顺序存储（节点 $i$ 的左孩子 $2i$、右孩子 $2i+1$、父节点 $\lfloor i/2 \rfloor$；$i \le \lfloor n/2 \rfloor$ 为分支节点，否则为叶子）；树高 $h=\lfloor \log_2 n \rfloor + 1$；简单选择排序思想。
- **本章位置**：属于「选择排序」大类。前面是简单选择排序，本节是选择排序的高效实现；后续是归并排序、基数排序。堆排序是本章综合度最高、考频最高的算法之一（考堆排序顺带考完全二叉树性质）。

## 2. 一句话结论

堆排序 = **建堆（$O(n)$）+ $n-1$ 趟「堆顶与堆底交换 + 堆顶元素下坠调整」（每趟 $O(\log n)$）**，总时间 $O(n\log n)$、空间 $O(1)$、**不稳定**；基于大根堆得递增序列，基于小根堆得递减序列。

## 3. 知识地图

```
堆排序
├── 堆（逻辑上是顺序存储的完全二叉树）
│   ├── 大根堆：每个节点 ≥ 其左右子树所有节点（根最大）
│   └── 小根堆：每个节点 ≤ 其左右子树所有节点（根最小）
├── 下标关系（数组从 1 开始存）
│   ├── 左孩子 2i，右孩子 2i+1，父节点 ⌊i/2⌋
│   ├── i ≤ ⌊n/2⌋ → 分支节点；i > ⌊n/2⌋ → 叶子
│   └── 树高 h = ⌊log₂n⌋ + 1
├── 建堆（以大根堆为例）
│   └── 从 i = ⌊n/2⌋ 递减到 1，对每个分支节点执行「下坠调整」
├── 下坠调整（核心基本操作）
│   └── 小元素逐层与「更大的孩子」交换，直到满足堆性质或到叶子
├── 排序
│   └── n-1 趟：堆顶 ↔ 当前堆底交换，堆长度减 1，对新堆顶下坠调整
└── 复杂度与稳定性
    ├── 建堆 O(n)
    ├── 排序 O(n log n)
    ├── 空间 O(1)
    └── 不稳定
```

## 4. 核心内容

### 4.1 堆的定义

**物理视角**：一个连续存放的数组。**逻辑视角**：一棵顺序存储的完全二叉树。

- **大根堆（大顶堆）**：完全二叉树中，任一节点 $i$ 的值 $\ge$ 其左右孩子（进而 $\ge$ 左右子树所有节点），即 $a_i \ge a_{2i}$ 且 $a_i \ge a_{2i+1}$。根节点（数组首元素）为全局最大。
- **小根堆**：任一节点 $i$ 的值 $\le$ 其左右孩子，根节点为全局最小。

> 对比：二叉排序树是「左子树 $\le$ 根 $\le$ 右子树」；大根堆是「根 $\ge$ 左子树且根 $\ge$ 右子树」，**左右子树之间无大小关系**。

**下标约定（务必说清）**：王道代码中数组 **从下标 1 开始存元素**（`a[0]` 作哨兵/暂存），故左孩子 $2i$、右孩子 $2i+1$、父节点 $\lfloor i/2 \rfloor$。若从 0 开始存，则左孩子 $2i+1$、右孩子 $2i+2$，公式不同，考试按题目约定。

**分支节点与叶子**：$n$ 个节点的完全二叉树，$i \le \lfloor n/2 \rfloor$ 为分支节点（非终端节点），$i > \lfloor n/2 \rfloor$ 为叶子节点。建堆只需检查所有分支节点。

### 4.2 建堆（以大根堆为例）

**手算流程**（初始序列共 $n=8$ 个元素，编号 1~8）：

1. 从编号最大的分支节点 $i=\lfloor n/2 \rfloor = 4$ 开始，**从后往前**依次处理 $i=4,3,2,1$。
2. 对每个节点 $i$：比较其左右孩子，若孩子中有比它大的，则与**更大的那个孩子**交换（下坠一层）；交换后若新位置仍不满足堆性质，**继续下坠**，直到满足或落到叶子。
3. 处理完 1 号节点后整棵树即为大根堆。

**为什么必须和「更大的孩子」换**：若和较小的孩子换，换上去的值仍小于另一个孩子，根仍不满足「≥ 左右孩子」，白换。所以选更大的孩子上浮。

**「小元素下坠」**：被换下来的小元素沿路径逐层下沉，每层都与更大的孩子交换，直到不能再沉。这是堆排序最核心的基本操作。

### 4.3 下坠调整代码（核心，能默写）

前提：以 `k` 为根的子树，其左右子树**已经是堆**，仅 `k` 处可能不满足堆性质。`len` 为当前堆中元素个数。

```c
// 将以 k 为根的子树调整为大根堆（元素存于 a[1..len]，a[0] 作暂存）
void HeadAdjust(int a[], int k, int len) {
    a[0] = a[k];                       // a[0] 暂存待调整的根节点，防止被覆盖
    for (int i = 2 * k; i <= len; i = 2 * i) {   // i 指向 k 的左孩子
        if (i < len && a[i] < a[i + 1]) // 有右孩子且右孩子更大
            i++;                        // i 指向更大的那个孩子
        if (a[0] >= a[i])               // 根 ≥ 更大的孩子，已满足堆性质
            break;                      // 无需再调整
        else {
            a[k] = a[i];                // 更大的孩子上移到父节点位置
            k = i;                      // k 记录待插入位置，继续向下比较
        }
    }
    a[k] = a[0];                        // 待调整元素放入最终位置
}
```

**逐行要点**：
- `a[0]` 暂存是**关键**：下坠过程中父节点位置会被孩子覆盖，必须先保存原值。
- `i < len` 判断保证 `i+1` 存在（有右兄弟）才能比较左右孩子；否则只有左孩子，直接与左孩子比。
- `i = 2 * i` 实现逐层下坠。
- 循环结束把 `a[0]` 放到 `k` 所指的最终位置。

### 4.4 建堆代码

```c
// 建立大根堆
void BuildMaxHeap(int a[], int len) {
    for (int i = len / 2; i > 0; i--)   // 从最后一个分支节点往前
        HeadAdjust(a, i, len);          // 逐个分支节点下坠调整
}
```

### 4.5 堆排序代码

```c
void HeapSort(int a[], int len) {
    BuildMaxHeap(a, len);               // 第一步：建初始大根堆
    for (int i = len; i > 1; i--) {     // n-1 趟
        // 堆顶（最大）与当前堆底交换，最大值归位到 i
        int temp = a[i];
        a[i] = a[1];
        a[1] = temp;
        HeadAdjust(a, 1, i - 1);        // 对剩余 i-1 个元素的新堆顶下坠调整
    }
}
```

**排序过程（大根堆）**：每趟把堆顶（当前最大）与堆底交换 → 最大值落到数组末尾并「移出堆」→ 对新堆顶下坠调整恢复堆性质。经 $n-1$ 趟得到**递增**序列。基于小根堆则得**递减**序列。

## 5. 复杂度分析

### 5.1 下坠调整 `HeadAdjust` 的代价

- 每下坠一层：先比较左右孩子（1 次关键字比较），再比较根与更大孩子（1 次），**最多 2 次比较**。
- 若节点只有左孩子（无右兄弟），只需 1 次比较。
- 树高 $h$，第 $i$ 层节点最多下坠 $h-i$ 层，比较次数 $\le 2(h-i)$。

### 5.2 建堆：$O(n)$（推导）

第 $i$ 层最多 $2^{i-1}$ 个节点，每个最多比较 $2(h-i)$ 次，只调整 $1 \sim h-1$ 层：

$$
\sum_{i=1}^{h-1} 2^{i-1}\cdot 2(h-i) = \sum_{j=1}^{h-1} 2^{h-j}\cdot j \quad (j=h-i)
= 2^h \sum_{j=1}^{h-1} \frac{j}{2^j}
$$

其中 $\sum_{j\ge1} j/2^j < 2$（差比数列，错位相减法），且 $2^h \le 2n$（因 $h=\lfloor\log_2 n\rfloor+1$，$2^{h-1}\le n$），故总比较次数 $\le 4n$，即**建堆 $O(n)$**。

> 直觉：越靠下的节点越多，但下坠层数越少，加权求和收敛到线性。

### 5.3 排序阶段：$O(n\log n)$

共 $n-1$ 趟，每趟对堆顶下坠，最多 $h-1$ 层、每层常数次比较，单趟 $O(h)=O(\log n)$，总计 $O(n\log n)$。

### 5.4 总复杂度

| 情况 | 时间复杂度 | 说明 |
|---|---|---|
| 最好 | $O(n\log n)$ | 建堆 $O(n)$ + 排序 $O(n\log n)$，与初始序列无关 |
| 最坏 | $O(n\log n)$ | 同上，堆排序对初始状态不敏感 |
| 平均 | $O(n\log n)$ | 建堆 $O(n)$ 与排序 $O(n\log n)$ 相加取高阶项；排序阶段每趟下坠期望层数仍为 $\Theta(\log n)$（堆近似满二叉树，路径长度 $\Theta(\log n)$），故平均即 $O(n\log n)$ |

- **空间**：$O(1)$，只用常数个辅助变量（`a[0]` 暂存、`i`、`k`、`temp`），原地排序。
- **稳定性**：**不稳定**。反例：初始 `1, 2, 2`（两个 2 有先后），建堆时左右孩子相等，代码 `a[i] < a[i+1]` 不成立故优先换左孩子，带下划线的 2 被换到根；排序后两个 2 的相对次序颠倒。

## 6. 易错点与考试写法

1. **下标基准**：王道代码数组从 1 开始，左孩子 $2i$、右孩子 $2i+1$；若题目从 0 开始，公式变为 $2i+1$、$2i+2$。答题先声明下标约定。
2. **建堆起点**：是 $\lfloor n/2 \rfloor$（最后一个分支节点），不是 $n$，也不是 1；方向是**从后往前**。
3. **必须与更大的孩子交换**：与较小孩子交换会破坏堆性质，这是手算题最常见的错。
4. **下坠要「一路到底」**：交换一次后新位置可能仍不满足，必须继续下坠，不能只换一层。
5. **排序时堆长度递减**：交换后堆顶下坠的范围是 $i-1$（已归位元素不再参与），写成 $n$ 是错的。
6. **大根堆得递增、小根堆得递减**：别记反。
7. **稳定性**：堆排序不稳定，选择题常考；反例用「两个相等关键字」构造。
8. **答题程度**：手算题要画出每步交换后的完全二叉树（或数组），标出被调整的节点；代码题写出 `HeadAdjust` + `BuildMaxHeap` + `HeapSort` 三段，注释写清 `a[0]` 暂存、`i<len` 判右兄弟、`i=2*i` 下坠；复杂度题要写出建堆 $O(n)$ 的求和推导思路（能写 $\sum 2^{i-1}\cdot 2(h-i)$ 即可）。

## 7. 408 题型与解题套路

- **选择题**：
  - 给初始序列问「建堆后数组/树的形态」——按从 $\lfloor n/2\rfloor$ 往前逐点下坠手算。
  - 问「堆排序第 $k$ 趟后的序列」——每趟堆顶与堆底交换再调整。
  - 问复杂度：建堆 $O(n)$、排序 $O(n\log n)$、空间 $O(1)$、稳定性（不稳定）。
  - 判断某序列是否为大/小根堆——逐节点检查 $a_i$ 与 $a_{2i},a_{2i+1}$。
  - 堆的插入/删除（补充，王道书扩展）：插入放末尾再上浮；删除堆顶用堆底替换再下坠。
- **算法题套路**：题目要求「找前 $k$ 大/小」「维护动态最值」时可用堆；408 算法题一般不直接考写完整堆排序，但可能考「调整为大根堆」的子过程。
- **常见陷阱**：把「建堆」和「排序」的复杂度混为一谈（建堆是 $O(n)$ 不是 $O(n\log n)$）；误认为堆排序最好情况是 $O(n)$；把堆与二叉排序树的性质混淆。

## 8. 自测题

**1.** 序列 `{53, 17, 78, 9, 45, 65, 87, 32}`（下标 1~8），建大根堆后数组首元素（堆顶）是什么？建堆过程中 53 最终落到哪个下标？

**2.** 对含 $n$ 个元素的序列建大根堆，关键字比较次数上界是多少？据此说明建堆时间复杂度。

**3.** 堆排序基于大根堆，经过 $n-1$ 趟后得到什么序列？基于小根堆呢？

**4.** 判断：堆排序的最好时间复杂度为 $O(n)$，因为初始有序时建堆很快。

**5.** 为什么 `HeadAdjust` 中要先执行 `a[0] = a[k]`？不暂存会出什么问题？

<details>
<summary>答案</summary>

1. 堆顶为 87。建堆从 $i=4$ 起：4 号 9 与左孩子 32 换；3 号 78 与右孩子 87 换；2 号 17 与更大孩子 45 换；1 号 53 与右孩子 87 换后 53 下坠到 3 号位，再与更大孩子 78 换，最终 **53 落到下标 7**（叶子）。建堆结果 `{87,45,78,32,17,65,53,9}`。
2. 上界 $4n$（推导见 5.2），故建堆 $O(n)$。

5. 下坠时父节点位置会被更大的孩子覆盖，若不先暂存原值，待调整元素就丢失了；`a[0]` 保存原值，循环结束后再放回最终位置 `a[k]`。

## 9. 背诵卡

1. 堆 = 顺序存储的完全二叉树；大根堆：$a_i \ge a_{2i}, a_i \ge a_{2i+1}$；小根堆反之。
2. 下标（从 1 起）：左 $2i$、右 $2i+1$、父 $\lfloor i/2\rfloor$；$i\le\lfloor n/2\rfloor$ 为分支节点。
3. 建堆：从 $i=\lfloor n/2\rfloor$ 递减到 1，逐个下坠；下坠 = 与**更大的孩子**交换，一路到底。
4. 排序：$n-1$ 趟「堆顶↔堆底，堆长减 1，新堆顶下坠」；大根堆→递增，小根堆→递减。
5. 复杂度：建堆 $O(n)$、排序 $O(n\log n)$、总 $O(n\log n)$、空间 $O(1)$、**不稳定**。

## 10. 关联与下一节

- **向前关联**：完全二叉树顺序存储（节点下标关系、树高公式）是理解堆的前提；简单选择排序的「每趟选最值」是堆排序的思想来源，堆排序只是把「选最值」从 $O(n)$ 优化到 $O(\log n)$。
- **向后关联**：下一节（8.4.2 第 2 课时）通常讲堆的插入与删除、堆排序的进一步应用与习题；再往后是归并排序、基数排序，可与堆排序对比复杂度与稳定性。
- **横向对比**：与快速排序同为 $O(n\log n)$ 且不稳定，但堆排序最坏也是 $O(n\log n)$、空间 $O(1)$；与直接插入排序对比「初始有序」时的表现（堆排序不因初始有序而变快）。
