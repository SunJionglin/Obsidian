# 1.2_3 算法的空间复杂度

## 1. 本节定位

- **对应王道书**：第 1 章「绪论」→ 1.2「算法和算法评价」→ 1.2.3「算法的空间复杂度」（承接 1.2.2 时间复杂度）。
- **408 大纲对应条目**：算法的时间复杂度与空间复杂度的分析与计算（属「算法与算法评价」）。
- **先修知识**：大 $O$ 表示法、时间复杂度分析、加法/乘法规则（多个大 $O$ 相加取最高阶）、函数调用栈的基本概念。
- **本节位置**：算法效率度量的第二部分。上一节用 $T(n)$ 度量时间开销，本节用 $S(n)$ 度量内存开销；后续所有算法（顺序表、链表、递归算法等）的空间分析都复用本节方法。

## 2. 一句话结论

空间复杂度 $S(n)$ 只统计**与问题规模 $n$ 相关的存储空间**的数量级；普通程序找与 $n$ 相关的变量，递归程序一般看**递归调用深度**（每层开销为常数时）。

## 3. 知识地图

```
算法的空间复杂度 S(n)
├── 程序运行所需内存
│   ├── 程序代码区：编译后机器指令，大小固定，与 n 无关
│   └── 数据区：局部变量、参数等
│       ├── 与 n 无关的变量 → 只贡献常数项 → 大 O 下忽略
│       └── 与 n 相关的变量（如长度 n 的数组）→ 决定阶数
├── 普通程序分析步骤
│   ├── 找出与 n 相关的变量/数组
│   ├── 写出空间表达式（如 4n+8、4n²）
│   └── 取数量级 → O(n)、O(n²)
├── 递归程序分析
│   ├── 每层开销为常数 k → S(n) = O(递归深度)
│   └── 每层开销随 n 变化（如每层开长度 n 的数组）→ 求和后取阶（如 O(n²)）
└── 术语：原地工作（in-place）——S(n) = O(1)
```

## 4. 核心内容

### 1. 空间复杂度的定义

$S(n)$ 衡量算法**所需内存空间与问题规模 $n$ 之间的关系**，$S$ 取自 space。与时间复杂度一样，只关心**数量级**，用大 $O$ 表示法，系数与低阶项全部舍去。

### 2. 程序运行需要的内存（跨考补充）

- **程序代码区**：程序编译后的机器指令，占多大空间在编译后即确定，**与 $n$ 无关**，是常数。
- **数据区**：存放参数、局部变量等。若某变量大小与 $n$ 无关，它最多给表达式加一个常数项，取大 $O$ 后被舍去，**分析时可完全不看它**。

> 结论：分析空间复杂度时，**只需盯住与 $n$ 相关的变量**（典型是长度为 $n$、$n\times n$ 的数组）。

### 3. 普通程序示例

**例 1：常数阶**

```c
void loveYou(int n) {   // 参数 n
    int i = 1;          // 局部变量 i
    while (i <= n) {
        i++;
    }
}
```

`n`、`i` 均为 int，各占固定字节，与 $n$ 无关。设 int 占 4 字节，总空间为常数（如 8 字节，加代码区假设 100 字节共 108 字节），与 $n$ 无关：

$$S(n) = O(1)$$

这种算法称为**原地工作**（in-place），该术语可能出现在选择题中。

**例 2：一维数组**

```c
void test(int n) {
    int flag[n];        // 长度与 n 相关的数组
    int i;
}
```

空间约为 $4n + 8$ 字节，取数量级：

$$S(n) = O(n)$$

**例 3：二维数组**

```c
void test(int n) {
    int flag[n][n];     // n×n 数组
    int i;
}
```

空间约为 $4n^2 + \text{常数}$：

$$S(n) = O(n^2)$$

**例 4：多个数组相加**

```c
void test(int n) {
    int flag[n][n];     // O(n²)
    int other[n];       // O(n)
    int i;              // O(1)
}
```

$$S(n) = O(n^2) + O(n) + O(1) = O(n^2)$$

多个大 $O$ 相加只保留最高阶（与时间复杂度同一规则）。

### 4. 递归程序：函数调用栈

递归调用时，**每一层调用都要单独开辟一片内存**存放该层的参数与局部变量；函数返回后该层空间才释放。因此递归的空间开销与**调用深度**有关。

**例 5：每层开销为常数**

```c
void loveYou(int n) {
    int a, b, c;        // 每层固定 3 个 int
    if (n > 1)
        loveYou(n - 1); // 递归，深度随 n 增长
    printf("%d\n", n);
}
// main 中调用 loveYou(5)，依次打印 1 2 3 4 5
```

设每层参数与局部变量共 $k$ 字节（$k$ 为常数）。调用 `loveYou(5)` 时深度为 5，问题规模为 $n$ 时深度为 $n$：

$$S(n) = k\cdot n = O(n)$$

> **考研主流结论**：每层递归开销为常数时，$S(n) = O(\text{递归深度})$。

**例 6：每层开销随 $n$ 变化（了解即可）**

```c
void loveYou(int n) {
    int flag[n];        // 本层数组长度 = 本层参数 n
    if (n > 1)
        loveYou(n - 1);
    printf("%d\n", n);
}
```

第 1 层数组长 $n$，第 2 层长 $n-1$，……，第 $n$ 层长 1。总空间为等差数列求和：

$$4\cdot(1+2+\cdots+n) + \text{常数} = 4\cdot\frac{n(n+1)}{2} + \text{常数}$$

$$S(n) = O(n^2)$$

此类题在 408 中极少出现，绝大多数递归题按例 5 处理。

## 5. 复杂度分析

本节讨论的是「如何求空间复杂度」，本身不存在最好/最坏/平均之分；但被分析算法存在不同情形，需说明：

- **普通程序**：空间开销由变量声明决定，与输入取值无关，**无最好/最坏之分**，直接按声明求 $S(n)$。
- **递归程序**：空间开销取决于**递归深度**。
  - 最好情况：递归深度最小（如某些分治在特定输入下提前终止），$S(n)$ 取对应深度。
  - 最坏情况：递归深度最大（如链式递归退化为 $n$ 层），$S(n) = O(n)$。
  - 平均情况：需对输入分布作概率假设。以「每层开销为常数 $k$、深度为 $d$」为例，若深度 $d$ 的取值为 $1,2,\dots,n$ 且等概率（假设 $P(d=i)=1/n$），则平均空间为
    $$\bar{S} = \sum_{i=1}^{n} \frac{1}{n}\cdot k i = \frac{k}{n}\cdot\frac{n(n+1)}{2} = \frac{k(n+1)}{2}$$
    取数量级仍为 $O(n)$。**注意**：408 中递归空间题几乎只考最坏（最大深度）情形，平均分析仅作理解。

## 6. 易错点与考试写法

1. **把代码区算进 $S(n)$**：程序代码大小固定、与 $n$ 无关，取大 $O$ 后消失，不必计入。
2. **纠结 int 占几字节**：最终取数量级，系数必被舍去，**分析时不需要知道具体字节数**，只需判断「与 $n$ 是否相关」。
3. **递归只看深度，不看调用总次数**：如斐波那契递归调用次数指数级，但空间只与最大深度有关（每层返回即释放）。本节例 5 的深度为 $n$，故 $O(n)$，不要误写成 $O(2^n)$。
4. **每层开销非常数时不能直接写 $O(\text{深度})$**：要先对每层空间求和再取阶（例 6 得 $O(n^2)$）。
5. **「原地工作」的判断**：$S(n)=O(1)$ 才叫原地工作；$O(n)$ 不是。
6. **答题写到什么程度算对**：写出空间表达式（如 $4n+8$）→ 说明只保留最高阶 → 给出 $S(n)=O(n)$；递归题写出「每层 $k$ 字节，深度为 $n$，故 $S(n)=O(n)$」即可，无需画栈图。

## 7. 408 题型与解题套路

- **选择题（主要考法）**：
  - 给一段含数组/递归的代码，问空间复杂度 → 套路：找与 $n$ 相关的变量 → 写表达式 → 取阶。
  - 概念题：「空间复杂度为 $O(1)$ 的算法称为____」→ 原地工作。
  - 陷阱：代码中变量很多但都与 $n$ 无关（答案 $O(1)$）；递归调用次数多但深度小（答案按深度）；二维数组误算成 $O(n)$。
- **算法题（应用题）**：题目要求「空间复杂度为 $O(1)$」即要求**原地**算法，常见于数组原地逆置、原地删除等；此时不得开与 $n$ 同阶的辅助数组，只能用常数个辅助变量。
- **常见陷阱**：把「辅助空间」与「总空间」混淆——408 通常默认考察**辅助空间**（不含输入本身占用的空间），题目若给输入数组，不要把它算进 $S(n)$。

## 8. 自测题

**1.** 下列算法空间复杂度为（ ）。
```c
void f(int n) {
    int i, j, sum = 0;
    for (i = 1; i <= n; i++)
        for (j = 1; j <= n; j++)
            sum += i * j;
}
```
A. $O(1)$　B. $O(n)$　C. $O(n^2)$　D. $O(n\log n)$

**2.** 若递归算法每层调用的空间开销为常数 $k$，最大递归深度为 $n$，则其空间复杂度为____。

**3.** 算法中定义了 `int a[n][n]` 与 `int b[n]`，其余为常数个变量，空间复杂度为____。

**4.** 判断：递归算法的空间复杂度一定等于递归调用的总次数。

**5.** 某递归函数每层都定义一个长度为当前参数 $n$ 的 int 数组，然后以 $n-1$ 递归，直到 $n=1$。求其空间复杂度。

<details>
<summary>答案与解析</summary>

1. **A**。`i, j, sum` 均为固定大小变量，与 $n$ 无关；循环次数多只影响时间，不影响空间。
2. $O(n)$。每层常数开销 × 深度 $n$。
3. $O(n^2)$。$O(n^2)+O(n)+O(1)$ 取最高阶。
4. **错**。空间取决于**最大递归深度**（每层返回即释放），与总调用次数无关；如斐波那契递归调用次数指数级，空间仅 $O(n)$。
5. 各层数组长度依次为 $n, n-1, \dots, 1$，总空间 $\propto \frac{n(n+1)}{2}$，故 $S(n)=O(n^2)$。

</details>

## 9. 背诵卡

1. $S(n)$ 衡量内存开销与问题规模 $n$ 的关系，只取数量级，用大 $O$。
2. 只统计与 $n$ 相关的变量；与 $n$ 无关的变量取大 $O$ 后消失，不必纠结字节数。
3. 数组长度 $n$ → $O(n)$；$n\times n$ → $O(n^2)$；多个大 $O$ 相加取最高阶。
4. $S(n)=O(1)$ 的算法称为**原地工作**（in-place）。
5. 递归程序：每层常数开销时 $S(n)=O(\text{递归深度})$；每层开销随 $n$ 变时先求和再取阶。
