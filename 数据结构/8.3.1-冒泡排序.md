# 8.3.1 冒泡排序（Bubble Sort）

## 1. 本节定位

- **王道书章节**：第 8 章 排序 → 8.3 交换排序 → 8.3.1 冒泡排序。
- **408 大纲对应**：排序 → 交换排序（冒泡排序、快速排序）。要求掌握冒泡排序的基本思想、执行过程、代码实现、复杂度与稳定性。
- **先修知识**：数组下标从 0 开始、相邻元素比较与交换、循环嵌套、`swap` 函数、稳定性定义（关键字相等的记录排序前后相对次序不变）。
- **在整章中的位置**：交换排序的第一节，是快速排序的基础铺垫。冒泡排序思想简单、代码短，是理解“一趟排序确定一个元素最终位置”这一排序范式的入门算法。

## 2. 一句话结论

冒泡排序每一趟从后往前（或从前往后）两两比较相邻元素，逆序则交换，每趟把当前剩余元素中的最小（或最大）者“冒”到最终位置；若某趟未发生任何交换则可提前结束，算法稳定，空间 $O(1)$，时间最好 $O(n)$、最坏与平均 $O(n^2)$。

## 4. 核心内容

### 4.1 定义与基本思想

**交换排序**：比较两个元素的关键字，根据大小关系决定是否交换这两个记录的位置。冒泡排序和快速排序都属于交换排序。

**冒泡排序**：从后往前（或从前往后）依次比较相邻的两个元素，若为逆序（即左边比右边大，而目标是递增序列）则交换，直到序列比较完。这一过程称为**一趟冒泡排序**。

- 每趟冒泡结束，当前剩余元素中的最小者被“冒”到最前面（从后往前冒时），其最终位置确定，后续趟不再参与比较。
- 若某一趟中**没有发生任何交换**，说明整个表已有序，可提前结束。

### 4.2 执行过程（以递增排序、从后往前冒为例）

设序列（下标 0~7）：`49, 38, 65, 97, 76, 13, 27, 49`（王道书经典例子，n = 8）。

- **第 1 趟**：从最后一个元素开始，依次比较相邻两元素，逆序则交换。13 一路向前冒，最终 13 到达下标 0。第 1 趟结束，最小元素 13 位置确定。
- **第 2 趟**：对下标 1~7 的剩余元素重复，27 向前冒到下标 1。前两个元素位置确定。
- **第 3 趟**：对下标 2~7 重复，38 冒到下标 2。前三个元素位置确定。
- **第 4 趟**：对下标 3~7 重复，49 冒到下标 3。前四个元素位置确定。
- **第 5 趟**：对下标 4~7 重复，比较过程中**未发生任何交换**，说明整体已有序，算法提前结束，不再进行第 6 趟。

> 关键：每趟比较范围逐趟缩小，已确定最终位置的元素不再参与比较。

### 4.3 代码实现（C 语言，王道风格）

```c
// 交换两个元素
void swap(int &a, int &b) {   // 王道书用 C++ 引用；纯 C 可用指针
    int temp = a;             // 第 1 次移动：a → temp
    a = b;                    // 第 2 次移动：b → a
    b = temp;                 // 第 3 次移动：temp → b
}

// 冒泡排序（从后往前冒，递增）
void BubbleSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {        // i 之前（下标 < i）已排好序
        bool flag = false;                    // 本趟是否发生交换的标记
        for (int j = n - 1; j > i; j--) {     // 从后往前，两两比较相邻元素
            if (A[j - 1] > A[j]) {            // 逆序（左 > 右）才交换
                swap(A[j - 1], A[j]);
                flag = true;                  // 发生交换，置标记
            }
        }
        if (flag == false)                    // 本趟无交换 → 已整体有序
            return;                           // 提前结束
    }
}
```

**代码要点**：

- 外层 `i` 表示已确定最终位置的元素个数，`i` 之前的元素不再参与比较。
- 内层 `j` 从 `n-1` 递减到 `i+1`，比较 `A[j-1]` 与 `A[j]`。
- 判断条件为 `A[j-1] > A[j]`，**相等时不交换**，这是稳定性的来源。
- `flag` 用于提前结束：某趟无交换即整体有序。

**从前往后冒的等价写法**（把大的往后冒，与链表例子一致）：内层改为 `for (j = 0; j < n - 1 - i; j++)`，比较 `A[j] > A[j+1]` 则交换。两种方向等价，代码类似。

### 4.4 链表上的冒泡（王道书扩展，了解即可）

冒泡思想可用于链表：从链头开始，当前元素与后继比较，若当前更大则交换（或交换结点），扫描指针后移，一趟把最大元素“冒”到链尾；下一趟处理剩余部分。具体代码留作练习，408 算法题若要求链表排序，可考虑此思路，但更常见的是直接插入排序。

## 5. 复杂度分析

### 5.1 空间复杂度

只需 `temp`、`i`、`j`、`flag` 等常数个辅助变量，$S(n) = O(1)$。

### 5.2 时间复杂度

**最好情况**：初始序列已有序（如 `1,2,…,n`）。第 1 趟从后往前比较 $n-1$ 次，均不交换，`flag` 保持 `false`，算法结束。

- 比较次数 $= n-1$，交换次数 $= 0$。
- $T_{\text{best}}(n) = O(n)$。

**最坏情况**：初始序列完全逆序（如 `n,n-1,…,1`）。

- 第 1 趟：最小元素 1 需与前面 $n-1$ 个元素逐一比较并交换，比较 $n-1$ 次、交换 $n-1$ 次。
- 第 2 趟：次小元素需比较 $n-2$ 次、交换 $n-2$ 次。
- ……
- 第 $n-1$ 趟：比较 1 次、交换 1 次。
- 总比较次数 $= \sum_{k=1}^{n-1} k = \frac{n(n-1)}{2}$，交换次数相同。
- $T_{\text{worst}}(n) = O(n^2)$。

**平均情况**：假设待排序列的 $n!$ 种排列等概率出现。对任意一对元素 $(A[i], A[j])$（$i<j$），在排序过程中它们必被比较一次，且逆序（前大后小）的概率为 $\frac{1}{2}$。因此平均比较次数为

$$\frac{1}{2}\binom{n}{2} = \frac{n(n-1)}{4} = O(n^2)$$

平均交换次数同阶，故 $T_{\text{avg}}(n) = O(n^2)$。

> 注意区分**交换次数**与**移动次数**：每次 `swap` 执行 3 次元素移动。若题目问“移动次数”，最坏为 $3 \times \frac{n(n-1)}{2}$；若问“交换次数”，最坏为 $\frac{n(n-1)}{2}$。这是 408 选择题的常见陷阱。

### 5.3 稳定性

判断条件为严格大于（`A[j-1] > A[j]`）才交换，关键字相等的元素不会交换，相对次序不变，**冒泡排序是稳定的**。

## 6. 易错点与考试写法

1. **提前结束条件**：某趟无交换即可结束，这是冒泡排序最易遗忘的点。选择题常问“最好情况比较次数”“能否提前终止”。
2. **交换次数 ≠ 移动次数**：一次 `swap` 是 3 次移动。题目问“移动次数”要乘 3。
3. **每趟比较范围**：第 $i$ 趟（从 1 计）只需比较 $n-i$ 次，已确定位置的元素不再比较。写代码时内层边界别写错。
4. **稳定性判断**：条件必须是严格大于（或严格小于），写成 `>=` 会破坏稳定性。
5. **方向等价**：从后往前冒小的、从前往后冒大的，结果都是递增，别被题目方向绕晕。
6. **答题程度**：408 算法题若要求写冒泡排序，需写出完整可运行代码（含 `swap` 或内联交换）、循环边界正确、有 `flag` 优化更佳；复杂度分析要写出比较次数求和过程，不能只写 $O(n^2)$。

## 7. 408 题型与解题套路

- **选择题**：
  - 给一个序列，问某趟冒泡后的结果（按方向逐趟模拟，注意比较范围）。
  - 问最好/最坏情况的比较次数、交换次数、移动次数。
  - 问稳定性、时间复杂度、空间复杂度。
  - 问“某趟无交换说明什么”（整体有序，可提前结束）。
- **算法题**：直接要求实现冒泡排序，或作为“稳定排序”的候选出现在排序算法比较题中。写代码时注意边界与 `flag`。
- **常见陷阱**：
  - 把交换次数当移动次数（漏乘 3）。
  - 忘记每趟缩小范围，导致比较次数算多。
  - 认为冒泡排序最好情况也是 $O(n^2)$（忽略提前结束）。
  - 把“一趟”与“一次比较”混淆。

## 8. 自测题

**题 1** 对序列 `49, 38, 65, 97, 76, 13, 27, 49` 进行从后往前的冒泡排序（递增），第 1 趟结束后的序列是什么？

**题 2** 冒泡排序在最好情况下的比较次数和交换次数分别是多少？时间复杂度是多少？

**题 3** 冒泡排序最坏情况下交换次数为 $\frac{n(n-1)}{2}$，则移动元素次数为多少？

**题 4** 冒泡排序是否稳定？为什么？

**题 5** 若某趟冒泡排序中没有发生任何交换，说明什么？算法应如何处理？

<details>
<summary>参考答案</summary>

**题 1**：`13, 49, 38, 65, 97, 76, 27, 49`。13 一路向前冒到下标 0，其余元素相对次序在交换中相应后移。

**题 2**：最好情况（初始有序）比较 $n-1$ 次，交换 0 次，时间复杂度 $O(n)$。

**题 3**：每次交换 3 次移动，移动次数 $= 3 \times \frac{n(n-1)}{2} = \frac{3n(n-1)}{2}$。

**题 4**：稳定。因为只有 `A[j-1] > A[j]`（严格大于）时才交换，关键字相等的元素不交换，相对次序不变。

**题 5**：说明整个序列已经有序，算法可以提前结束，不再进行后续趟。

## 9. 背诵卡

1. 冒泡排序属**交换排序**，每趟两两比较相邻元素，逆序则交换，每趟确定一个元素最终位置。
2. 代码核心：双层循环 + `if (A[j-1] > A[j]) swap(...)` + `flag` 提前结束。
3. 空间 $O(1)$；时间最好 $O(n)$（有序，比较 $n-1$ 次）、最坏 $O(n^2)$（逆序，比较 $\frac{n(n-1)}{2}$ 次）、平均 $O(n^2)$。
4. **稳定**：相等不交换。
5. 交换次数 ≠ 移动次数：一次 `swap` = 3 次移动。
