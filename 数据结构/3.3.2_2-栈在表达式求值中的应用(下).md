# 3.3.2 栈在表达式求值中的应用（下）

## 1. 本节定位

- **对应章节**：王道《数据结构》第 3 章 栈、队列和数组，3.3 节 栈的应用——表达式求值（下）。
- **408 大纲条目**：栈和队列的应用（表达式求值、中缀转后缀）。
- **先修知识**：栈的基本操作（入栈/出栈/取栈顶）；运算符优先级（乘除高于加减，同级相等）；上一小节“左优先原则”与“后缀表达式求值”的算法。
- **本节位置**：承接上一小节“后缀表达式求值”，本节完成“中缀转后缀”的算法化，并把两个算法合并成“用栈直接求中缀表达式的值”，是栈应用的收口内容。

## 2. 一句话结论

中缀转后缀用**一个运算符栈**：操作数直接输出，运算符按“弹出栈顶所有优先级 $\ge$ 当前运算符的运算符后再入栈”处理，遇左括号直接入栈、遇右括号弹到左括号为止；中缀求值则是**运算符栈 + 操作数栈**两个栈，把“中缀转后缀”和“后缀求值”两个过程同步进行。

## 3. 知识地图

```
栈在表达式求值中的应用（下）
├── 中缀 → 后缀（一个运算符栈）
│   ├── 前提：左优先原则确定运算符生效次序
│   ├── 操作数：直接输出（相对顺序不变）
│   ├── 运算符：弹出栈顶优先级 ≥ 当前的所有运算符，再入栈
│   ├── 左括号 '('：直接入栈
│   ├── 右括号 ')'：依次弹出到 '(' 为止，'(' 不输出
│   └── 扫描结束：弹出栈中剩余全部运算符
├── 中缀表达式求值（两个栈）
│   ├── 运算符栈：逻辑同“中缀转后缀”
│   ├── 操作数栈：操作数直接入栈
│   └── 每弹出一个运算符 → 立即弹两个操作数运算 → 结果压回操作数栈
└── 意义：把复杂表达式拆成“一次一个基本运算”，对应编译原理中生成机器指令
```

## 4. 核心内容

### 4.1 中缀转后缀的算法规则（408 必考）

从左往右扫描中缀表达式，对每个元素：

1. **操作数**：直接加入后缀表达式（操作数之间的相对顺序不变）。
2. **运算符**：若栈非空，依次弹出栈顶中**优先级高于或等于**当前运算符的所有运算符并输出；然后当前运算符入栈。
3. **左括号 `(`**：直接入栈。
4. **右括号 `)`**：依次弹出栈中运算符并输出，直到弹出 `(` 为止；`(` 只弹出、不输出（后缀表达式无界限符）。
5. **扫描结束**：把栈中剩余运算符依次弹出输出。

**规则背后的逻辑（理解即可，帮助记忆）**：

- 扫描到运算符时，栈顶运算符对应的左操作数区间已经确定；若栈顶优先级 $\ge$ 当前，按左优先原则栈顶运算可以先生效，故弹出。
- 栈顶优先级 $<$ 当前（如栈顶 `-`、当前 `*`），不能先算栈顶，当前运算符也不能确定能否立即生效（后面可能跟括号），故当前运算符先入栈等待。
- 遇 `(` 时栈顶为 `(`，说明当前运算符左侧紧邻括号，括号内运算优先但当前运算符能否立即生效仍不确定，故不弹任何元素，直接入栈。
- 遇 `)` 时括号范围已确定，括号内运算全部可先生效，故弹到 `(` 为止。

**手算示例（无括号）**：中缀 `A+B-C*D/E+F`

| 扫描 | 动作 | 后缀输出 | 运算符栈（底→顶） |
|---|---|---|---|
| A | 输出 | A | 空 |
| + | 入栈 | A | + |
| B | 输出 | A B | + |
| - | 弹出 `+`（同级），`-` 入栈 | A B + | - |
| C | 输出 | A B + C | - |
| * | 栈顶 `-` 优先级低，不弹，`*` 入栈 | A B + C | - * |
| D | 输出 | A B + C D | - * |
| / | 弹出 `*`（同级），`/` 入栈 | A B + C D * | - / |
| E | 输出 | A B + C D * E | - / |
| + | 弹出 `/`、`-`（均 $\ge$），`+` 入栈 | A B + C D * E / - | + |
| F | 输出 | A B + C D * E / - F | + |
| 结束 | 弹出 `+` | A B + C D * E / - F + | 空 |

**手算示例（带括号）**：中缀 `A+B*(C-D)-E/F`（按讲解顺序模拟）

- 扫到 `(` 直接入栈；扫到 `-` 时栈顶为 `(`，不弹任何元素，`-` 入栈；扫到 `)` 时弹出 `-`，再弹出 `(`（不输出）。
- 其余按规则处理，最终后缀为 `A B C D - * + E F / -`。

### 4.2 中缀表达式求值（两个栈，王道书扩展/了解即可）

**核心思想**：把“中缀转后缀”与“后缀表达式求值”两个算法合并，边转换边计算。

- 设两个栈：`OPTR`（运算符栈）、`OPND`（操作数栈）。
- 扫描中缀表达式：
  - **操作数**：压入 `OPND`。
  - **运算符/界限符**：按 4.1 的规则决定入栈或弹出。
  - **每当从 `OPTR` 弹出一个运算符**：立即从 `OPND` 弹出两个操作数（先弹出的是右操作数，后弹出的是左操作数），执行该运算，结果压回 `OPND`。
- 扫描结束后，继续弹出 `OPTR` 中剩余运算符并同样执行运算；最终 `OPND` 栈顶即表达式的值（表达式合法时 `OPND` 中只剩一个元素）。

**关键顺序**：先弹出的是**右操作数**，后弹出的是**左操作数**——减法、除法不可交换，顺序写反必错。

**伪代码（王道风格，前提：表达式合法、只含加减乘除与括号）**：

```c
// 假设已实现栈的基本操作：InitStack、Push、Pop、GetTop、StackEmpty
// OPND 存操作数（float/int），OPTR 存运算符（char）
float EvaluateInfix(char expr[]) {
    InitStack(OPTR);  InitStack(OPND);
    int i = 0;
    while (expr[i] != '\0') {
        char ch = expr[i];
        if (ch 是操作数) {                 // 操作数直接入操作数栈
            Push(OPND, ch - '0');          // 简化：单字符数字
        } else if (ch == '(') {
            Push(OPTR, ch);                // 左括号直接入栈
        } else if (ch == ')') {
            while (GetTop(OPTR) != '(') {  // 弹到左括号为止
                char op = Pop(OPTR);
                float r = Pop(OPND), l = Pop(OPND);  // 先右后左！
                Push(OPND, Apply(op, l, r));
            }
            Pop(OPTR);                     // 弹出 '('，不参与运算
        } else {                           // 运算符
            while (!StackEmpty(OPTR) && GetTop(OPTR) != '('
                   && Priority(GetTop(OPTR)) >= Priority(ch)) {
                char op = Pop(OPTR);       // 栈顶优先级 ≥ 当前，先生效
                float r = Pop(OPND), l = Pop(OPND);  // 先右后左！
                Push(OPND, Apply(op, l, r));
            }
            Push(OPTR, ch);                // 当前运算符入栈
        }
        i++;
    }
    while (!StackEmpty(OPTR)) {            // 处理剩余运算符
        char op = Pop(OPTR);
        float r = Pop(OPND), l = Pop(OPND);
        Push(OPND, Apply(op, l, r));
    }
    return GetTop(OPND);                   // 栈顶即结果
}
```

> 注：`Apply(op, l, r)` 表示对左右操作数执行 `op` 运算；`Priority` 中乘除返回 2、加减返回 1。真实实现需处理多位数与小数，考试手算时按单字符操作数模拟即可。

### 4.3 为什么值得这么“复杂”（理解，非考点）

CPU 一次只能执行一个最基本的加减乘除指令，编译器必须把复杂表达式拆成一条条基本指令，本节算法正是这种拆解思想的体现。**408 不直接考这段论述**，但理解它有助于记住“每次弹出一个运算符就立即算一次”的设计动机。

## 5. 复杂度分析

设中缀表达式长度为 $n$（操作数 + 运算符 + 括号总数）。

- **最好情况**：$O(n)$。每个字符至多入栈一次、出栈一次，栈操作均 $O(1)$。
- **最坏情况**：$O(n)$。如全为同级运算符 `a+b-c-d-...`，每个运算符入栈后立即被下一个弹出，总操作数仍与 $n$ 成正比。
- **平均情况**：$O(n)$。推导：扫描 $n$ 个字符，每个字符触发常数次栈操作（入栈 1 次，出栈至多 1 次）；总出栈次数不超过总入栈次数 $\le n$，故总操作次数 $\le 2n$ 次常数时间操作，即 $O(n)$。空间上运算符栈深度不超过运算符个数，最坏 $O(n)$（如 `((((...))))` 或严格递增优先级的嵌套）。
- **补充**：中缀求值用两个栈，时间同为 $O(n)$，空间 $O(n)$（操作数栈最坏存 $O(n)$ 个中间结果）。

## 6. 易错点与考试写法

1. **“优先级 ≥ 当前”中的“等于”不能漏**：同级运算符（如 `+` 遇 `-`、`*` 遇 `/`）必须弹出栈顶，这是左优先原则的体现；漏掉等号会得到错误的结合顺序。
2. **右括号只弹到左括号，左括号不输出**：后缀表达式没有界限符，`(` 弹出后丢弃，不要写进结果。
3. **遇左括号时不弹任何运算符**：即使栈顶是同级或更高优先级的运算符，只要栈顶是 `(` 就停止弹出（`(` 优先级视为最低，但更准确的理解是“括号内运算尚未确定结束”）。
4. **扫描结束后必须清空运算符栈**：很多同学漏掉最后一步，导致后缀表达式缺尾部运算符。
5. **求值时先弹出的是右操作数**：`a-b` 弹出顺序是先 `b` 后 `a`，写成 `b-a` 直接错；除法同理。
6. **操作数相对顺序不变**：中缀与后缀中操作数出现次序完全一致，可用此快速校验手算结果。
7. **答题程度**：408 选择题常问“转换到某一步时栈中内容是什么”，答题时按“当前已扫描字符 → 输出串 → 栈（底到顶）”三栏列表模拟即可；算法题若要求写转换/求值，写出 4.2 的循环框架 + 三条分支（操作数/左括号/右括号/运算符）+ 收尾清栈即算完整，不必处理多位数。

## 7. 408 题型与解题套路

- **选择题（高频）**：
  - 给中缀表达式，问后缀表达式是什么 → 按 4.1 逐字符模拟，用三栏表。
  - 问“扫描到某字符时运算符栈的内容” → 只模拟到该字符，注意栈底到栈顶的顺序。
  - 给后缀表达式反推中缀，或判断某后缀是否合法 → 用后缀求值栈模拟，操作数不够即非法。
- **算法题（低频，多为扩展）**：要求实现中缀转后缀或中缀求值，套 4.2 框架；注意栈的判空与括号匹配检查。
- **常见陷阱**：
  - 同级运算符不弹出（违反左优先）。
  - 把 `(` 写进后缀输出。
  - 求值时左右操作数颠倒。
  - 忘记最后清空运算符栈。
  - 栈容量不足（视频提到用 5 个容量的栈模拟长表达式会溢出，考试手算时注意栈深）。

## 8. 自测题

**题 1**：中缀表达式 `A+B*C-D/E` 对应的后缀表达式是？

**题 2**：将 `A-(B+C/D)*E` 转为后缀表达式，扫描到 `)` 时，运算符栈（底→顶）的内容是什么（不含已弹出的）？

**题 3**：用两个栈求中缀表达式值时，从运算符栈弹出 `-` 后，操作数栈依次弹出 `x`、`y`，应计算的是？

**题 4**：判断：中缀转后缀过程中，遇到右括号时应把栈中所有运算符弹出并输出。这句话错在哪？

**题 5**：后缀表达式 `A B + C D * -` 对应的中缀表达式（不加多余括号）是？

<summary>答案与解析</summary>

**题 1**：`A B C * + D E / -`。
解析：`+` 入栈；`*` 优先级高于 `+`，入栈；扫 `-` 时弹出 `*`、`+`，`-` 入栈；扫 `/` 时栈顶 `-` 优先级低，`/` 入栈；结束弹出 `/`、`-`。

**题 2**：栈中只剩 `(`（底→顶为 `(`）。
解析：扫到 `)` 时依次弹出 `-`、`+`（括号内运算符），直到弹出 `(` 为止；`(` 弹出后不输出，栈中此时为空——若问“弹出过程中栈内容”，弹出前栈为 `( - +`（底→顶），弹出后为空。按题意“扫描到 `)` 时”指处理前，栈为 `( - +`。

**题 3**：计算 `y - x`。
解析：先弹出的是右操作数 `x`，后弹出的是左操作数 `y`，故为 `y - x`。

**题 4**：错。应“依次弹出运算符直到弹出左括号为止”，左括号本身弹出但不输出；不是弹出所有运算符（左括号以下的运算符不能弹）。

**题 5**：`(A+B) - C*D`。
解析：`A B +` → `A+B`；`C D *` → `C*D`；`-` 作用于两者，得 `(A+B) - C*D`。

## 9. 背诵卡

1. 中缀转后缀：操作数直出；运算符“弹出栈顶优先级 $\ge$ 当前的，再入栈”；`(` 直入；`)` 弹到 `(` 为止且 `(` 不输出；结束清栈。
2. 左优先原则：同级运算符先算左边，所以“$\ge$”里的等号必须弹。
3. 中缀求值 = 运算符栈 + 操作数栈；每弹一个运算符，立刻弹两操作数算一次，结果压回。
4. 求值时先弹出的是右操作数，后弹出的是左操作数（减法除法不可交换）。
5. 操作数在中缀与后缀中相对顺序完全不变，可用来快速校验手算结果。
