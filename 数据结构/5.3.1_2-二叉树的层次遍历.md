# 5.3.1_2 二叉树的层次遍历

## 1. 本节定位

- **王道书对应**：第 5 章「树与二叉树」→ 5.3「二叉树的遍历」→ 层次遍历（层序遍历）。
- **408 大纲对应**：二叉树遍历（先序、中序、后序、层次）——层次遍历是四种遍历之一，属于「408 必考」基础考点。
- **先修知识**：二叉树链式存储结构（`BiTNode`/`BiTree`）、队列（链队列的初始化、入队、出队、判空，见第 3 章）。
- **本节位置**：在三种深度优先遍历（先/中/后序）之后，是遍历方式中唯一「按层」推进的一种，也是后续求树高、求宽度、判断完全二叉树等算法题的基础工具。

## 2. 一句话结论

**层次遍历 = 一个辅助队列 + 循环「出队访问、左右孩子依次入队」，直到队列为空。**

## 3. 知识地图

```
二叉树的遍历
├── 深度优先（递归/栈）
│   ├── 先序 N-L-R
│   ├── 中序 L-N-R
│   └── 后序 L-R-N
└── 广度优先（队列）—— 层次遍历
    ├── 辅助结构：链队列（存的是节点指针，不是节点本身）
    ├── 初始：根节点入队
    ├── 循环体：判空 → 队头出队并访问 → 左孩子入队（若有）→ 右孩子入队（若有）
    └── 终止：队列为空
```

## 4. 核心内容

### 4.1 定义

**层次遍历（level-order traversal）**：从根节点开始，按「层」自上而下、每层内自左向右，依次访问每个节点，每个节点恰好访问一次。

例（视频中的树）：遍历序列为 `a b c d e f g h i j k l`。

### 4.2 算法思想（手工模拟）

1. 初始化一个辅助队列，**根节点入队**。
2. 循环：若队列非空 →
   - 队头元素出队，**访问**该节点；
   - 若该节点有左孩子，左孩子入队；
   - 若该节点有右孩子，右孩子入队。
3. 队列为空时结束。

关键顺序：**先左后右**入队，保证同层内自左向右访问；**先出队访问、再入孩子**，保证父节点先于孩子被访问。

### 4.3 代码实现（C，王道风格）

前提：链队列已定义好 `InitQueue`、`EnQueue`、`DeQueue`、`QueueEmpty`（第 3 章内容）。队列元素类型为 `BiTNode *`（节点指针）。

```c
// 二叉树节点（链式存储）
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

// 链队列结点：存的是二叉树节点的指针，不是节点本身
typedef struct LinkNode {
    BiTNode *data;          // 队列中保存节点指针，节省空间
    struct LinkNode *next;
} LinkNode;
typedef struct {
    LinkNode *front, *rear;
} LinkQueue;

// 层次遍历
void LevelOrder(BiTree T) {
    LinkQueue Q;
    InitQueue(Q);           // 初始化辅助队列
    BiTree p;
    if (T != NULL)
        EnQueue(Q, T);      // 根节点入队（入队的是指针）
    while (!QueueEmpty(Q)) {        // 队列不空则循环
        DeQueue(Q, p);              // 队头出队，p 指向该节点
        visit(p);                   // 访问：如打印 p->data
        if (p->lchild != NULL)
            EnQueue(Q, p->lchild);  // 左孩子入队
        if (p->rchild != NULL)
            EnQueue(Q, p->rchild);  // 右孩子入队
    }
}
```

要点：
- 用**链队列**而非顺序队列：树的节点数难以预估，链队列便于扩展（视频明确说明）。
- 队列里存**节点指针**，不存整个节点，节省空间。
- `visit(p)` 由使用者定义（打印、计数、判条件等）。

### 4.4 图解（视频中的树，按讲解顺序）

| 步骤 | 出队并访问 | 入队（先左后右） | 队列内容（队头→队尾） |
|---|---|---|---|
| 初始 | — | a | a |
| 1 | a | b, c | b c |
| 2 | b | d, e | c d e |
| 3 | c | f, g | d e f g |
| 4 | d | h, i | e f g h i |
| 5 | e | （无孩子） | f g h i |
| 6 | f | j, k | g h i j k |
| 7 | g | l | h i j k l |
| 8~12 | h, i, j, k, l | 均无孩子 | 逐次变空 |

访问序列：`a b c d e f g h i j k l`，与定义一致。

## 5. 复杂度分析

设树有 $n$ 个节点。

- **时间**：每个节点恰好入队一次、出队一次、访问一次，入队/出队为 $O(1)$，故总时间 $O(n)$。最好、最坏、平均均为 $O(n)$——遍历必须触及每个节点，不存在更优情况。
- **空间**：取决于队列中同时存在的最大元素数，即**树的最大宽度** $w$（同一层最多节点数）。
  - 最好：单支树（每层 1 个节点），$w=1$，空间 $O(1)$。
  - 最坏：完全二叉树最底层约 $\lceil n/2 \rceil$ 个节点，$w=O(n)$，空间 $O(n)$。
  - 平均：若在「所有含 $n$ 个节点的二叉树等可能」的假设下，平均宽度为 $\Theta(\sqrt{n})$ 量级（推断，教材不要求严格证明），工程上按最坏 $O(n)$ 记。
  - 结论：**空间 $O(n)$（最坏），最好 $O(1)$**。

## 6. 易错点与考试写法

1. **入队顺序写反**：必须先左孩子后右孩子，否则同层变成自右向左，序列错。
2. **先入孩子再访问**：必须先出队访问、再让孩子入队；顺序颠倒会改变层内次序甚至死循环式错误。
3. **空树处理**：`T == NULL` 时直接返回，不能对空指针取 `lchild`。
4. **队列存什么**：存 `BiTNode *` 指针，不是 `BiTNode` 结构体本身；写 `EnQueue(Q, T)` 而非 `EnQueue(Q, *T)`。
5. **判空位置**：`while (!QueueEmpty(Q))`，循环体内不再重复判空。
6. **答题标准**：408 算法题写层次遍历，需写出「初始化队列 → 根入队 → while 非空 { 出队访问；左入队；右入队 }」完整骨架，并说明队列元素类型为节点指针；只写文字描述不给满分。

## 7. 408 题型与解题套路

- **选择题**：给一棵树求层序序列；或给层序 + 中序还原二叉树（层序第一个必是根）。也可能问「层次遍历需要什么辅助结构」——答队列。
- **算法题套路**：层次遍历是「按层处理」类题目的模板：
  - 求树高/每层节点数：在 while 内用「当前队列长度」控制一层循环（王道书扩展，本节未展开，标注「王道书扩展」）。
  - 判断完全二叉树：层序遍历中一旦遇到空孩子后仍出现非空节点则非完全二叉树（王道书扩展）。
  - 求树的宽度：层序遍历统计每层节点数取最大。
- **常见陷阱**：把层序与先序混淆（层序不是递归定义）；忘记空树判断；队列用顺序队列导致溢出。

## 9. 背诵卡

1. 层次遍历 = **队列** + 「出队访问、左入队、右入队」循环到空。
2. 初始：**根节点入队**；空树直接返回。
3. 入队顺序：**先左后右**；出队即访问。
4. 队列存 **`BiTNode *` 指针**，用**链队列**便于扩展。
5. 时间 $O(n)$；空间最坏 $O(n)$（最大宽度），最好 $O(1)$（单支树）。

## 10. 关联与下一节

- **前向关联**：先/中/后序遍历（递归 + 栈）→ 本节层次遍历（队列），四种遍历构成完整遍历体系；队列操作依赖第 3 章链队列知识。
- **后向关联**：层次遍历是求树高、树宽、判断完全二叉树、按层输出等算法题的通用骨架；下一节进入「由遍历序列构造二叉树」（如先序 + 中序、层序 + 中序还原），本节层序序列常作为构造条件出现。
