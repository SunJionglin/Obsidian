# 6.4.2_1 最短路径问题：BFS 算法

## 1. 本节定位

- **对应王道书**：第 6 章「图」→ 6.4 图的应用 → 6.4.2 最短路径（第一小节：BFS 求无权图单源最短路径）。
- **408 大纲对应**：图的应用——最短路径（单源最短路径、每对顶点间最短路径）。
- **先修知识**：图的邻接表/邻接矩阵存储、广度优先搜索（BFS）及其队列实现、辅助数组 `visited[]`。
- **本节位置**：最短路径问题的开篇。先解决「无权图 + 单源」这一最简情形，为后续 Dijkstra（带权单源）与 Floyd（各顶点对）做铺垫。

## 2. 一句话结论

**对无权图从源点 $u$ 做一次 BFS，按层扩展即得 $u$ 到其余各顶点的最短路径长度（层数）与路径本身（前驱数组 `path[]` 回溯）。**

├── 两个辅助数组

## 4. 核心内容

### 4.1 问题定义

- **单源最短路径**：给定源点 $u$，求 $u$ 到图中其余每个顶点的最短路径（长度 + 路径）。
- **无权图**：每条边权值相同，可视为边权恒为 $1$ 的带权图。因此「路径长度」= 路径上边的条数。
- BFS 按「距源点由近及远」逐层扩展，第一次访问到某顶点时经过的边数必为最少——这就是 BFS 能求无权图最短路径的根本原因。

### 4.2 手工过程（以源点 2 为例，按讲解顺序）

设图为 8 个顶点，源点 $u=2$。BFS 分层：

| 层（距离） | 顶点 |
|---|---|
| 0 | 2 |
| 1 | 1, 6 |
| 2 | 5, 3, 7 |
| 3 | 4, 8 |

- 初始：`d[]` 全置 $\infty$，`path[]` 全置 $-1$，`d[2]=0`。
- 出队 2：邻接点 1、6 未访问 → `d[1]=d[2]+1=1`，`path[1]=2`；`d[6]=1`，`path[6]=2`。
- 出队 1：邻接点 2 已访问跳过；5 未访问 → `d[5]=d[1]+1=2`，`path[5]=1`。
- 出队 6：邻接点 3、7 未访问 → `d[3]=d[6]+1=2`，`path[3]=6`；`d[7]=2`，`path[7]=6`。
- 出队 5：邻接点均已访问，无操作。
- 出队 3：邻接点 4 未访问 → `d[4]=d[3]+1=3`，`path[4]=3`。
- 出队 7：邻接点 8 未访问 → `d[8]=d[7]+1=3`，`path[8]=7`。
- 出队 4、8：邻接点均已访问，结束。

最终：`d = [1, 0, 2, 3, 2, 1, 2, 3]`（下标 1~8），`path = [2, -1, 6, 3, 1, 2, 6, 7]`。

### 4.3 结果的使用

- **求长度**：直接读 `d[v]`。如 $2\to8$：`d[8]=3`。
- **求路径**：从 `path[v]` 逆向回溯至源点。如 $v=8$：`path[8]=7 → path[7]=6 → path[6]=2`（源点），逆序得路径 $2\to6\to7\to8$。

### 4.4 代码实现（王道风格，基于 BFS 改造）

前提：图用邻接表存储，`G.vertices` 为顶点数组，`FirstNeighbor/NextNeighbor` 为取邻接点的基本操作；队列 `Q` 已实现 `InitQueue/EnQueue/DeQueue/QueueEmpty`。

```c
// 求无权图 G 中从顶点 u 到其余各顶点的最短路径
// d[]: 记录最短路径长度; path[]: 记录最短路径上的直接前驱
void BFS_MIN_Distance(Graph G, int u) {
    int i;
    for (i = 0; i < G.vexnum; ++i) {
        d[i]    = INT_MAX;   // 初始化最短路径长度为无穷
        path[i] = -1;        // 初始化前驱为 -1
    }
    d[u] = 0;                // 源点到自身距离为 0
    visited[u] = true;       // 标记源点已访问
    EnQueue(Q, u);           // 源点入队

    while (!QueueEmpty(Q)) {
        DeQueue(Q, u);                       // 队头出队
        for (int w = FirstNeighbor(G, u);
             w >= 0;
             w = NextNeighbor(G, u, w)) {    // 遍历 u 的所有邻接点
            if (!visited[w]) {               // 未访问过才处理
                d[w]    = d[u] + 1;          // 关键：距离 = 前驱距离 + 1
                path[w] = u;                 // 关键：记录直接前驱
                visited[w] = true;           // 标记已访问
                EnQueue(Q, w);               // 入队
            }
        }
    }
}
```

**与普通 BFS 的唯一区别**：在「访问」处增加 `d[w] = d[u] + 1` 与 `path[w] = u` 两行赋值。其余逻辑（`visited` 标记、入队出队）完全一致。

### 4.5 与广度优先生成树的联系

- 以源点 $u$ 为根做 BFS，得到广度优先生成树；`path[]` 恰好刻画了树中的父子关系。
- 顶点在生成树中的**层数** = 源点到该顶点的最短距离。
- 因此 BFS 生成树是**高度最小**的生成树（相对于以 $u$ 为根而言）。

## 5. 复杂度分析

设图有 $n$ 个顶点、$e$ 条边。

- **时间复杂度**：每个顶点至多入队、出队一次，共 $O(n)$；每条边在邻接表中被扫描常数次（无向图 2 次，有向图 1 次），共 $O(e)$。合计 $O(n+e)$。
  - 若用邻接矩阵存储，每个顶点出队时需扫描整行 $n$ 个元素，合计 $O(n^2)$。
- **空间复杂度**：队列最多存 $O(n)$ 个顶点，`visited/d/path` 各 $O(n)$，合计 $O(n)$。
- **最好/最坏/平均**：BFS 的代价与图的形状无关，只与 $n,e$ 有关，故最好 = 最坏 = 平均 = $O(n+e)$（邻接表）。不存在需要按概率假设求平均的情形。

## 6. 易错点与考试写法

1. **BFS 只能求无权图（或边权全相等）的单源最短路径**。带权图必须用 Dijkstra，这是选择题高频陷阱。
2. **`d[w] = d[u] + 1` 中的 `u` 是刚出队的顶点**，不是源点；写错会得到错误距离。
3. **`path[]` 记录的是「直接前驱」，不是完整路径**。求路径必须逆向回溯，输出时需逆序。
4. **`visited` 判断必须在赋值之前**：只有未访问顶点才更新 `d` 与 `path`，否则会覆盖已确定的最短距离。
5. **源点自身**：`d[u]=0`、`path[u]=-1`，不要漏初始化。
6. **答题程度**：408 算法题若要求「求无权图单源最短路径」，写出上述改造版 BFS 并说明 `d`、`path` 含义即可；若只考选择题，掌握「层数 = 距离」「`path` 回溯」即可。

## 7. 408 题型与解题套路

- **选择题**：
  - 给出无权图与源点，问某顶点的最短路径长度 → 数 BFS 层数。
  - 问 BFS 能否求带权图最短路径 → 不能。
  - 给出 `d[]`、`path[]` 结果，反推图或路径。
- **算法题**：
  - 直接套用改造版 BFS，注意邻接表存储与队列基本操作。
  - 若要求输出路径，写回溯循环：`while (v != -1) { 输出 v; v = path[v]; }` 后逆序。
- **常见陷阱**：
  - 把 BFS 与 DFS 混淆（DFS 不能保证最短）。
  - 忘记初始化 `d` 为 $\infty$、`path` 为 $-1$。
  - 有向图与无向图边扫描次数不同，影响复杂度常数但不影响阶。

## 8. 自测题

**题 1** 无权图中，从源点 $u$ 做 BFS，顶点 $v$ 第一次被访问时所在的层数等于什么？

**题 2** BFS 求单源最短路径时，`path[]` 数组存储的是什么？如何据此得到完整路径？

**题 3** 为什么 BFS 不能直接用于带权图的最短路径？应改用哪种算法？

**题 4** 邻接表存储的无权图有 $n$ 个顶点、$e$ 条边，BFS 求单源最短路径的时间复杂度是多少？若改为邻接矩阵呢？

**题 5** 源点 2 的 `path` 数组为 `path[6]=2, path[7]=6, path[8]=7`，写出 2 到 8 的最短路径。

<details>
<summary>参考答案</summary>

1. 等于源点 $u$ 到 $v$ 的最短路径长度（边数）。
2. 存储最短路径上该顶点的**直接前驱**；从目标顶点出发反复取 `path` 直到源点，再逆序即得完整路径。
3. 因为带权图各边权值不同，BFS 按边数分层不能保证权值和最小；应使用 Dijkstra 算法。
4. 邻接表 $O(n+e)$；邻接矩阵 $O(n^2)$。
5. $2\to6\to7\to8$。

</details>

## 9. 背诵卡

1. BFS 求**无权图**单源最短路径；带权图用 Dijkstra。
2. 核心改造：访问时 `d[w]=d[u]+1`，`path[w]=u`。
3. `d[]` 存距离，`path[]` 存直接前驱，路径需逆向回溯。
4. 初始化：`d` 全 $\infty$、`path` 全 $-1$、`d[u]=0`。
5. 复杂度：邻接表 $O(n+e)$，邻接矩阵 $O(n^2)$，空间 $O(n)$。

## 10. 关联与下一节

- **向前关联**：BFS 基本算法、`visited[]` 数组、队列实现、广度优先生成树。
- **向后关联**：下一节 Dijkstra 算法——把「按层扩展」推广到「按当前最短距离贪心扩展」，从而支持带权图；再往后 Floyd 算法解决各顶点对最短路径。
