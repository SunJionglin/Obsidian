# 6.3.1 图的广度优先遍历（BFS）

## 1. 本节定位

- **王道书对应**：第 6 章「图」→ 6.3 图的遍历 → 6.3.1 广度优先遍历（BFS, Breadth-First Search）。
- **408 大纲对应**：图的遍历（广度优先搜索）。
- **先修知识**：图的存储结构（邻接矩阵、邻接表）、图的基本操作（`FirstNeighbor(G,x)`、`NextNeighbor(G,x,y)`）、树的层序遍历、队列。
- **位置**：紧接 6.2 图的存储与基本操作，是图遍历的第一个算法；后续 6.3.2 深度优先遍历（DFS）、6.4 图的应用（最小生成树、最短路径、拓扑排序）都以 BFS/DFS 为工具。

## 2. 一句话结论

BFS 从某顶点出发，借助**辅助队列**和 **`visited[]` 标记数组**，按“由近及远、逐层扩展”的顺序访问所有可达顶点；对非连通图需在外层用 for 循环扫描 `visited[]`，对每个未访问顶点再调用一次 BFS，调用次数等于连通分量个数。

## 3. 知识地图

```
图的广度优先遍历 BFS
├── 思想来源：树的层序遍历（树是特殊图）
│     └── 逐层：根 → 与根相邻 → 再下一层 …
├── 与树的区别
│     ├── 树：找相邻点 = 找孩子；无回路，不会重复访问
│     └── 图：用 FirstNeighbor / NextNeighbor 找邻接点；有回路、无向边双向可达 → 必须用 visited[] 防重复
├── 实现要素
│     ├── 辅助队列（保存“已访问但邻接点未处理完”的顶点）
│     ├── visited[] 布尔数组（初值全 false）
│     └── 两个基本操作：FirstNeighbor、NextNeighbor
├── 代码
│     ├── BFS(G, v)：处理单个连通分量
│     └── BFSTraverse(G)：外层 for 扫描 visited[]，处理非连通图
├── 遍历序列
│     ├── 邻接矩阵存储 → 序列唯一
│     └── 邻接表存储 → 序列不唯一（取决于边结点次序）
├── 复杂度
│     ├── 空间：O(V)（队列最坏存 V 个顶点）
│     ├── 时间（邻接矩阵）：O(V²)
│     └── 时间（邻接表）：O(V+E)
└── 生成树 / 生成森林
      ├── 连通图 → 广度优先生成树（n 个顶点、n-1 条红边）
      └── 非连通图 → 广度优先生成森林（每个连通分量一棵树）
```

## 4. 核心内容

### 4.1 基本思想

从起始顶点 $v$ 出发：先访问 $v$；再依次访问 $v$ 的所有**未被访问过**的邻接点；然后按这些邻接点被访问的先后次序，逐个访问它们的未被访问的邻接点……即“由近及远、逐层扩展”，横向优先，故称广度优先。

**与树层序遍历的对应**：树中“找相邻点”就是找孩子；图中则通过 `FirstNeighbor` / `NextNeighbor` 枚举邻接点。

**与树的关键区别**：图可能有回路，无向边可双向走，因此从某点出发可能搜到**已访问过**的顶点，必须用 `visited[]` 标记并跳过，保证每个顶点只访问一次。

### 4.2 两个基本操作（前提）

```c
// 求图 G 中顶点 x 的第一个邻接点；若 x 无邻接点或图空，返回 -1
int FirstNeighbor(Graph G, int x);
// 求图 G 中顶点 x 的邻接点 y 之后的下一个邻接点；若 y 是最后一个邻接点，返回 -1
int NextNeighbor(Graph G, int x, int y);
```

邻接矩阵与邻接表下实现不同，但都简单：矩阵按行扫描，邻接表沿边链表走。

### 4.3 BFS 核心代码（王道风格，C 语言）

前提：`visited[]` 为全局布尔数组，初值全 `false`；`Q` 为辅助队列；顶点编号从 0 开始（王道书代码），本节例子中顶点编号从 1 开始，原理相同。

```c
bool visited[MAX_VERTEX_NUM];   // 访问标记数组，初值全 false

// 从顶点 v 出发，广度优先遍历图 G 的一个连通分量
void BFS(Graph G, int v) {
    visit(v);                   // 访问初始顶点 v
    visited[v] = true;          // 打上已访问标记
    InitQueue(Q);               // 初始化辅助队列（若在外层已初始化可省略）
    EnQueue(Q, v);              // v 入队
    while (!isEmpty(Q)) {       // 队列不空则循环
        DeQueue(Q, v);          // 队头顶点出队，用 v 接住
        // 枚举 v 的所有邻接点 w
        for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w)) {
            if (!visited[w]) {  // w 尚未被访问
                visit(w);       // 访问 w
                visited[w] = true;
                EnQueue(Q, w);  // w 入队，等待以后处理它的邻接点
            }
        }
    }
}
```

**执行要点**：入队时机 = 第一次被访问时；出队后才枚举其邻接点；`if (!visited[w])` 是防重复访问的唯一关口。

### 4.4 非连通图的处理（易错重点）

上面的 `BFS(G, v)` 只能遍历 $v$ 所在的连通分量。对非连通图，需在外层扫描 `visited[]`：

```c
void BFSTraverse(Graph G) {
    for (int i = 0; i < G.vexnum; ++i)
        visited[i] = false;     // 初始化标记数组
    InitQueue(Q);               // 初始化辅助队列
    for (int i = 0; i < G.vexnum; ++i)
        if (!visited[i])        // 找到一个尚未访问的顶点
            BFS(G, i);          // 从它出发遍历其所在连通分量
}
```

**结论**：对无向图，`BFS` 被调用的次数 = 连通分量个数；对有向图，调用次数 = 强连通分量个数（若按“可达性”划分，则等于该有向图弱连通意义下各部分的个数，考试按连通分量/强连通分量理解）。

### 4.5 遍历序列与唯一性

- **邻接矩阵**：表示唯一 → 从固定起点出发，枚举邻接点顺序固定（按顶点编号递增）→ **BFS 序列唯一**，生成树唯一。
- **邻接表**：边结点次序取决于建表顺序 → 枚举邻接点顺序可变 → **BFS 序列不唯一**，生成树也可能不唯一。

例（无向图，从顶点 2 出发）：若 2 的邻接表次序为 1、6，则序列为 2,1,6,5,3,7,4,8；若次序为 6、1，则序列变为 2,6,1,3,7,5,4,8（推断：后续层随之改变）。

### 4.6 广度优先生成树 / 生成森林

- 遍历过程中，每个顶点**第一次被访问时经过的那条边**（讲解中标红的边）保留，其余边删去，得到 $n$ 个顶点、$n-1$ 条边的树 → **广度优先生成树**（仅对连通图）。
- 非连通图：每个连通分量各得一棵生成树，合起来为**广度优先生成森林**。
- 邻接矩阵存储 → 生成树唯一；邻接表存储 → 生成树可能不唯一。

### 4.7 有向图上的表现（了解即可）

有向图从某顶点出发不一定能到达全部顶点，需多次调用 BFS。例如某有向图中从顶点 1 出发只能到 5，必须多次调用；而从 7 或 8 出发可一次遍历全部顶点（推断：取决于该顶点到其余顶点的可达性）。

## 5. 复杂度分析

设顶点数 $V$、边数 $E$。

**空间复杂度**：辅助队列最坏情况——某顶点与其余所有顶点相邻（星形图），访问它时要把其余 $V-1$ 个顶点全部入队，故队列最大长度 $O(V)$；`visited[]` 为 $O(V)$。合计 $O(V)$。

**时间复杂度**：总开销 = 访问各顶点的时间 + 枚举各边（邻接点）的时间。

- **邻接矩阵**：
  - 访问 $V$ 个顶点：$O(V)$。
  - 每个顶点出队后要扫描其整行（$V$ 个元素）找邻接点，共 $V$ 行：$O(V^2)$。
  - 合计 $O(V^2 + V) = O(V^2)$。
- **邻接表**：
  - 访问 $V$ 个顶点：$O(V)$。
  - 每个顶点的边结点只被扫描一次；无向图边结点总数 $2E$，有向图 $E$，均为 $O(E)$。
  - 合计 $O(V + E)$。

**最好 / 最坏 / 平均**：BFS 的时间复杂度由存储结构决定，与具体图形态无关，故不区分三种情况；空间上最好为 $O(1)$ 量级队列（链状图，队列长度恒为 1，但 `visited[]` 仍 $O(V)$，故整体仍 $O(V)$），最坏 $O(V)$（星形图）。平均情况无概率模型，不作平均分析。

**注意**：不能像普通循环那样只数最内层 for 的执行次数——若图无边且用邻接表，内层 for 一次都不执行，但每个顶点仍需一次 `visit`，故必须“顶点 + 边”分开算。

## 6. 易错点与考试写法

1. **忘记外层 for 循环**：只写 `BFS(G, v)` 处理不了非连通图，这是最常考的代码填空/改错点。
2. **`visited[]` 置 true 的时机**：必须在**入队时**（即第一次访问时）置 true，不能在出队时置，否则同一顶点可能被多次入队。
3. **入队与访问的顺序**：先 `visit`、置标记，再 `EnQueue`；出队后才枚举邻接点。
4. **序列唯一性判断**：邻接矩阵 → 唯一；邻接表 → 不唯一。选择题常给两种存储问“序列是否唯一”。
5. **调用次数**：无向图 BFS 调用次数 = 连通分量数；不要与“生成树棵数”混淆，二者数值相同但概念不同。
6. **答题程度**：代码题写全 `BFS` + `BFSTraverse` 两个函数、`visited` 初始化、队列操作即可；复杂度题必须写出“顶点 $O(V)$ + 边 $O(E)$ 或 $O(V^2)$”的拆分过程，只写结论会扣分。

## 7. 408 题型与解题套路

- **选择题**：
  - 给图与存储结构，问 BFS 序列（按编号递增枚举邻接点；邻接表按给定链表次序）。
  - 问序列/生成树是否唯一（看存储结构）。
  - 问 BFS 调用次数（数连通分量）。
  - 问复杂度（先看存储结构，再套 $O(V^2)$ 或 $O(V+E)$）。
- **算法题**：BFS 常作为工具出现——求无权图单源最短路径（本节未讲，放到最短路径小节）、判断连通性、求连通分量数、层次相关统计。套模板：初始化 `visited` + 队列 → 起点入队 → while 出队枚举邻接点 → 未访问则访问、标记、入队。
- **陷阱**：非连通图漏外层循环；有向图误用无向图结论；把“访问”和“入队”顺序写反；复杂度只写结论不写拆分。

## 8. 自测题

**1.** 对含 $V$ 个顶点、$E$ 条边的图做 BFS，采用邻接表存储，时间复杂度是（ ）。
A. $O(V)$ B. $O(E)$ C. $O(V+E)$ D. $O(V^2)$

**2.** 无向图有 3 个连通分量，对其做 `BFSTraverse`，`BFS` 函数被调用几次？广度优先生成森林有几棵树？

**3.** 同一张图分别用邻接矩阵和邻接表存储，从同一顶点出发的 BFS 序列是否都唯一？说明理由。

**4.** 补全 BFS 中防止重复访问的关键语句，并说明 `visited[w] = true` 应放在入队前还是出队后，为什么。

**5.** 为什么 BFS 的空间复杂度是 $O(V)$？举出使队列达到最大长度的图形态。

<details>
<summary>答案</summary>

1. **C**。访问顶点 $O(V)$，邻接表扫描全部边结点 $O(E)$，合计 $O(V+E)$。
2. 调用 **3** 次（每次处理一个连通分量）；生成森林有 **3** 棵树。
3. 邻接矩阵存储时序列**唯一**（矩阵表示唯一，枚举邻接点按编号递增）；邻接表存储时序列**不唯一**（边结点次序可变，枚举顺序随之改变）。
4. 关键语句：`if (!visited[w]) { visit(w); visited[w] = true; EnQueue(Q, w); }`。置 true 必须在**入队前**（即首次访问时），否则同一顶点会被多个前驱重复入队，导致重复访问。
5. 队列保存“已访问但邻接点尚未处理完”的顶点；星形图（一个中心顶点与其余 $V-1$ 个顶点相邻）中，访问中心顶点时其余 $V-1$ 个顶点全部入队，队列长度达 $O(V)$。

</details>

## 9. 背诵卡

1. BFS = 树的层序遍历 + `visited[]` 防环 + 队列；由近及远、逐层扩展。
2. 模板：访问起点 → 标记 → 入队；while 队不空：出队 → for 枚举邻接点 → 未访问则访问、标记、入队。
3. 非连通图：外层 for 扫描 `visited[]`，对每个 false 顶点调用 BFS；调用次数 = 连通分量数。
4. 复杂度：空间 $O(V)$；时间邻接矩阵 $O(V^2)$、邻接表 $O(V+E)$（顶点 + 边分开算）。
5. 唯一性：邻接矩阵 → 序列与生成树唯一；邻接表 → 均可能不唯一。
