# 2.3.2_3 单链表的建立（尾插法 / 头插法）

## 1. 本节定位

- **王道书对应**：第 2 章 线性表 → 2.3 线性表的链式表示 → 2.3.2 单链表 → **单链表的建立**（尾插法、头插法）。
- **408 大纲对应**：线性表的链式存储结构——单链表的建立（插入操作的组合应用）。
- **先修知识**：单链表的定义与初始化（带头结点）、按位序插入、**指定结点的后插操作**（`InsertNextNode`）。
- **本章位置**：属于"单链表基本操作"的收尾与综合应用。前面学的是"单个结点怎么插"，本节学的是"**一批数据怎么一次性建成表**"，是后续链表逆置、链表合并、链表排序等算法题的**代码骨架来源**。

## 2. 一句话结论

**单链表的建立 = 初始化空表 + 循环"取一个元素、插一个结点"；尾插法用尾指针 `r` 保证 $O(n)$ 且保持输入顺序，头插法每次对头结点后插，得到输入序列的逆序，是链表逆置的核心手段。**

## 3. 知识地图

```
单链表的建立（带头结点）
├── 问题：给定 n 个数据元素，如何存入单链表
├── 通用框架
│   ├── ① 初始化空表（malloc 头结点，head->next = NULL）
│   └── ② 循环：取一个元素 → 申请结点 → 插入
├── 尾插法（Tail Insertion）
│   ├── 朴素实现：每次调用按位序插入 InsertList(L, length+1, e)
│   │   └── 每次从头找表尾 → 总时间 O(n²)
│   └── 优化实现：设尾指针 r 指向表尾数据结点
│       ├── 对 r 做后插（r->next = s）
│       ├── r 后移（r = s）
│       └── 总时间 O(n)，结果与输入顺序一致
└── 头插法（Head Insertion）
    ├── 每次对头结点做后插（s->next = L->next; L->next = s）
    ├── 总时间 O(n)
    └── 结果 = 输入序列的逆序 → 用于链表逆置
```

## 4. 核心内容

### 4.1 问题抽象

给定若干数据元素（`ElemType`），要求把它们存进一个**带头结点**的单链表。做法固定为两步：

1. **从无到有**：初始化一个空单链表（申请头结点，`L->next = NULL`）。
2. **逐个插入**：每取一个元素，申请一个新结点存入该元素，再插入表中。插到表尾 → 尾插法；插到表头 → 头插法。

> 两种方法的核心都是已学过的两个基本操作：**初始化** + **指定结点的后插**。区别只在"对谁做后插"以及"是否维护尾指针"。

### 4.2 尾插法：朴素实现（用按位序插入）

设 `length` 记录当前表长，每取一个元素 `e`，调用按位序插入，插到第 `length+1` 个位置（即表尾）：

```c
// 伪代码：借助按位序插入实现尾插法
LinkList TailInsert_Naive() {
    InitList(L);                 // 初始化带头结点的空表
    int length = 0;              // 当前表长
    ElemType e;
    while (scanf("%d", &e) != EOF) {
        ListInsert(L, length + 1, e);  // 插到表尾（第 length+1 位）
        length++;                      // 表长加一
    }
    return L;
}
```

**为什么慢**：`ListInsert` 内部要从头结点开始 `while` 循环走到第 `length` 个结点，才能在其后插入。

- 插入第 1 个元素：循环 0 次（只有头结点）；
- 插入第 2 个元素：循环 1 次；
- …
- 插入第 $n$ 个元素：循环 $n-1$ 次。

总循环次数 $0+1+2+\cdots+(n-1)=\dfrac{n(n-1)}{2}=O(n^2)$。

### 4.3 尾插法：优化实现（尾指针 `r`）

**关键思想**：没必要每次都从头找表尾。设指针 `r` **始终指向表尾数据结点**，新结点直接后插到 `r` 之后，再把 `r` 后移。

```c
// 尾插法建立带头结点的单链表（王道课本风格）
LinkList List_TailInsert(LinkList *L) {
    int x;                                   // 设 ElemType 为 int
    L = (LinkList)malloc(sizeof(LNode));     // ① 建立头结点
    L->next = NULL;                          //    头结点 next 置空（好习惯，必写）
    LNode *s, *r = L;                        // ② r 为表尾指针，初始指向头结点
    scanf("%d", &x);                         // ③ 读入第一个元素
    while (x != 9999) {                      //    9999 为约定的结束标志（可换）
        s = (LNode *)malloc(sizeof(LNode));  // ④ 申请新结点
        s->data = x;                         //    存入数据
        r->next = s;                         // ⑤ 新结点接到表尾之后（对 r 后插）
        r = s;                               // ⑥ 尾指针后移，仍指向表尾
        scanf("%d", &x);                     // ⑦ 读下一个元素
    }
    r->next = NULL;                          // ⑧ 表尾置空，收尾
    return L;                                //    返回头指针
}
```

**执行过程（输入 10、16、27、9999）**：

| 步骤 | 操作 | 链表状态（头结点记作 H） |
|---|---|---|
| 初始 | `r = L` | `H -> NULL` |
| 输入 10 | 建结点 s，`r->next = s`，`r = s` | `H -> 10 -> NULL` |
| 输入 16 | 建结点 s，`r->next = s`，`r = s` | `H -> 10 -> 16 -> NULL` |
| 输入 27 | 同上 | `H -> 10 -> 16 -> 27 -> NULL` |
| 输入 9999 | 退出循环，`r->next = NULL` | `H -> 10 -> 16 -> 27 -> NULL` |

**结果与输入顺序一致**。

> **注意**：课本代码中 `r` 初始指向头结点，第一次插入时 `r->next = s` 恰好把新结点接在头结点之后，逻辑统一，无需特判空表。

### 4.4 头插法

**关键思想**：每取一个元素，都插到**头结点之后**（即表头位置），等价于对头结点做一次后插。

```c
// 头插法建立带头结点的单链表
LinkList List_HeadInsert(LinkList *L) {
    LNode *s;
    int x;
    L = (LinkList)malloc(sizeof(LNode));     // ① 建立头结点
    L->next = NULL;                          // ② 必须置空！否则尾结点 next 指向脏数据
    scanf("%d", &x);
    while (x != 9999) {
        s = (LNode *)malloc(sizeof(LNode));  // ③ 申请新结点
        s->data = x;
        s->next = L->next;                   // ④ 新结点 next 指向原第一个结点
        L->next = s;                         // ⑤ 头结点指向新结点（对头结点后插）
        scanf("%d", &x);
    }
    return L;
}
```

**执行过程（输入 10、16、27、9999）**：

| 步骤 | 链表状态 |
|---|---|
| 输入 10 | `H -> 10 -> NULL` |
| 输入 16 | `H -> 16 -> 10 -> NULL` |
| 输入 27 | `H -> 27 -> 16 -> 10 -> NULL` |

**结果 = 输入序列的逆序**。

### 4.5 为什么头插法必须写 `L->next = NULL`

`malloc` 申请到的内存可能残留**脏数据**（之前用过的内容）。若不置空：

- 第一个结点 `s->next = L->next` 会指向一片**不可知的内存区域**；
- 后续所有结点都接在这条"野链"前面，最后一个结点的 `next` 最终指向未知地址；
- 遍历链表时可能越界、死循环或崩溃。

**结论**：无论头插法还是尾插法，初始化头结点后**一律写 `L->next = NULL`**，这是必须养成的编码习惯。

### 4.6 头插法与链表逆置（408 高频考点）

头插法的本质是"**边取边逆序**"。因此：

- **建新表逆置**：用一个指针 `p` 顺序扫描原链表 `L`，每取一个结点数据，用头插法插入新表 `L2`，则 `L2` 是 `L` 的逆序。
- **原地逆置**：从原链表依次摘下结点，重新头插回头结点之后，不额外申请空间。

```c
// 原地逆置带头结点单链表（头插法思想）
void Reverse(LinkList L) {
    LNode *p = L->next, *q;   // p 指向第一个数据结点
    L->next = NULL;           // 断开，头结点成为新空表
    while (p != NULL) {
        q = p->next;          // 暂存后继，防止断链
        p->next = L->next;    // 头插：新结点 next 指向原首结点
        L->next = p;          // 头结点指向新结点
        p = q;                // p 后移
    }
}
```

> 这段代码是 408 算法题的**标准模板**，务必能默写。核心三行：`q = p->next; p->next = L->next; L->next = p;`。

## 5. 复杂度分析

设插入元素个数为 $n$。

### 5.1 尾插法（朴素，调用按位序插入）

- **最好**：$n=0$ 或 $n=1$，循环 0 次，$O(1)$。
- **最坏**：$n$ 个元素，总循环次数 $\sum_{i=1}^{n}(i-1)=\dfrac{n(n-1)}{2}$，$O(n^2)$。
- **平均**：每个元素插入位置固定为表尾，无概率选择，平均即 $\dfrac{1}{n}\sum_{i=1}^{n}(i-1)=\dfrac{n-1}{2}=O(n)$ 次/元素，总计 $O(n^2)$。
- **空间**：$O(n)$（$n$ 个结点）。

### 5.2 尾插法（优化，尾指针 `r`）

- **最好 / 最坏 / 平均**：每个元素只做常数次操作（申请、赋值、指针修改、`r` 后移），循环 $n$ 次，**均为 $O(n)$**。
- **空间**：$O(n)$。

### 5.3 头插法

- **最好 / 最坏 / 平均**：每个元素常数次操作，循环 $n$ 次，**均为 $O(n)$**。
- **空间**：$O(n)$。

> **对比记忆**：朴素尾插 $O(n^2)$ 的根源是"每次都要从头找表尾"；引入尾指针 `r` 后降为 $O(n)$。这是"**用空间（一个指针）换时间**"的典型例子。

## 6. 易错点与考试写法

1. **忘记 `L->next = NULL`**：头插法中尤其致命（尾结点指向脏数据）；尾插法中虽最后会 `r->next = NULL` 收尾，但初始化时仍应写上，养成习惯。
2. **尾插法忘记 `r = s`**：只写 `r->next = s` 而不后移 `r`，则所有新结点都接在同一个位置，链表断裂/覆盖。
3. **头插法指针顺序写反**：必须先 `s->next = L->next`，再 `L->next = s`；顺序颠倒会丢失原链表。
4. **混淆两种方法的输出顺序**：尾插 → 与输入同序；头插 → 与输入逆序。选择题常直接问"输入 1,2,3，输出是什么"。
5. **不带头结点的实现差异**（视频要求思考）：
   - 尾插法：空表时第一个结点要同时让 `L` 和 `r` 指向它，需特判 `if (L == NULL)`；
   - 头插法：每次插入后要更新头指针 `L = s`，因为表头变了。
   - **408 答题默认带头结点**，除非题目明确说不带头结点。
6. **答题标准**：
   - 算法题写建立/逆置链表，**必须**：① 声明结构体；② 写出完整可运行函数（含 `malloc`、返回值）；③ 关键行注释；④ 说明时间/空间复杂度。
   - 只写"思路"不写代码，通常只得部分分。

## 7. 408 题型与解题套路

### 选择题常见考法

- **顺序判断**：给输入序列，问头插法/尾插法建成的链表遍历结果。→ 尾插同序，头插逆序。
- **指针修改顺序**：给一段头插代码挖空，问哪句在前。→ `s->next = L->next` 必须在 `L->next = s` 之前。
- **复杂度判断**：问"用按位序插入实现尾插法"的时间复杂度。→ $O(n^2)$。
- **`L->next = NULL` 的作用**：问不写会怎样。→ 尾结点指向脏数据/野指针。

### 算法题套路

- **看到"逆置 / 反转链表"** → 立刻想到头插法，用"摘结点 + 头插"三行模板。
- **看到"按输入顺序建表"** → 尾插法 + 尾指针。
- **看到"将链表分成两半 / 重排"** → 常结合头插法做后半段逆置。
- **常见陷阱**：题目给的是**不带头结点**的链表，代码需相应调整头指针更新逻辑；逆置时忘记暂存 `p->next` 导致断链。

## 8. 自测题

**Q1** 依次输入 1、2、3、4，用**头插法**建立带头结点的单链表，从头到尾遍历的输出是？

<details>
<summary>答案</summary>
4、3、2、1。头插法每次插在头结点之后，后插入的在前，结果为输入序列的逆序。
</details>

**Q2** 用"按位序插入"实现尾插法建立含 $n$ 个结点的单链表，总比较/循环次数是多少？时间复杂度？

<details>
<summary>答案</summary>
插入第 $i$ 个元素需从头走 $i-1$ 步，总次数 $0+1+\cdots+(n-1)=\dfrac{n(n-1)}{2}$，时间复杂度 $O(n^2)$。
</details>

**Q3** 尾插法优化代码中，若漏写 `r = s;` 会发生什么？

<details>
<summary>答案</summary>
`r` 始终指向同一个结点，后续新结点不断覆盖 `r->next`，前面的结点丢失，链表无法正确建立（每次只保留最后一个新结点）。
</details>

**Q4** 头插法中 `L->next = NULL` 能否省略？为什么？

<details>
<summary>答案</summary>
不能。`malloc` 得到的内存可能含脏数据，若不置空，第一个结点的 `next` 会指向未知区域，最终尾结点 `next` 为野指针，遍历时可能崩溃或死循环。
</details>

**Q5** 写出原地逆置带头结点单链表的核心三行代码，并说明为何要先暂存后继。

<details>
<summary>答案</summary>
`q = p->next; p->next = L->next; L->next = p;`（随后 `p = q;`）。先暂存 `p->next` 是因为执行 `p->next = L->next` 后 `p` 与原后继的链被切断，不暂存就找不到下一个结点了。
</details>

## 9. 背诵卡

1. **建表两步**：初始化空表（`malloc` 头结点 + `L->next = NULL`）→ 循环"取元素、建结点、插入"。
2. **尾插法**：设尾指针 `r`，`r->next = s; r = s;`，结果**同序**，时间 $O(n)$；不设 `r` 用按位序插入则 $O(n^2)$。
3. **头插法**：`s->next = L->next; L->next = s;`，结果**逆序**，时间 $O(n)$。
4. **`L->next = NULL` 必写**：防止尾结点指向脏数据/野指针。
5. **逆置模板**：`q = p->next; p->next = L->next; L->next = p; p = q;` —— 头插法思想的直接应用，408 高频。
