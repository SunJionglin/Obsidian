# 8.4.2 堆的插入与删除

## 1. 本节定位

- **对应王道书**：第 8 章 排序 → 8.4 选择排序 → 8.4.2 堆排序（堆的插入、删除操作）
- **408 大纲对应**：内部排序中的“堆排序”，重点在堆这种数据结构的调整操作（插入、删除）及其关键字比较次数
- **先修知识**：完全二叉树的顺序存储（数组下标从 1 开始，父结点 $\lfloor i/2 \rfloor$，左孩子 $2i$，右孩子 $2i+1$）；大根堆/小根堆的定义；上节“建堆”与“下坠（sift-down）”操作
- **本节位置**：上一节讲堆排序整体流程（建堆 + 反复输出堆顶），本节单独抽出“堆的插入、删除”两个基本操作，是堆排序的底层动作，也是 408 选择题高频考点

## 2. 一句话结论

**插入 = 新元素放表尾后不断“上升”直到无法上升；删除 = 用堆底元素顶替被删元素后不断“下坠”直到无法下坠；两种调整都要数清关键字比较次数。**

## 3. 知识地图

```
堆的插入与删除
├── 插入（以小根堆为例）
│   ├── 步骤1：新元素放到表尾（数组末尾 / 逻辑上的堆底）
│   ├── 步骤2：与父结点比较，比父结点小则交换（上升）
│   └── 步骤3：重复上升，直到无法上升为止
├── 删除（删除堆顶元素）
│   ├── 步骤1：用堆底（表尾）元素顶替被删元素的位置
│   ├── 步骤2：与左右孩子中较小者比较，比它大则交换（下坠）
│   └── 步骤3：重复下坠，直到无法下坠为止
└── 关键字比较次数（考试重点）
    ├── 上升：每层只与父结点比 1 次
    └── 下坠：有 2 个孩子 → 比 2 次；只有 1 个孩子 → 比 1 次
```

## 4. 核心内容

### 4.1 堆的数组表示（前提）

堆是**完全二叉树**，用数组顺序存储，**下标从 1 开始**（王道约定）：

- 结点 $i$ 的父结点：$\lfloor i/2 \rfloor$
- 结点 $i$ 的左孩子：$2i$，右孩子：$2i+1$

> 位序说明：本节所有下标均指数组下标（从 1 开始），与逻辑上的“第几个结点”一致。

### 4.2 插入操作（以小根堆为例）

**算法思想**：新元素先放到表尾，然后沿父结点路径“上升”，直到满足堆序。

```c
// 小根堆插入，A[1..n] 为堆，len 为当前元素个数
void Insert(int A[], int &len, int key) {
    len = len + 1;          // 堆元素个数加 1
    A[len] = key;           // 新元素放到表尾
    int i = len;
    while (i > 1 && A[i] < A[i/2]) {  // 比父结点小则上升
        swap(A[i], A[i/2]);
        i = i / 2;          // 上升到父结点位置
    }
}
```

**讲解中的具体例子（小根堆）**：

- 插入 13：放到下标 9，父结点为 $\lfloor 9/2 \rfloor = 4$，值为 32；$13<32$ 交换 → 再与 17 比，$13<17$ 交换 → 再与 9 比，$13>9$ 停止。共 **3 次**关键字比较。
- 插入 46：放到表尾，父结点 45 比它小，无法上升，**1 次**比较。

**要点**：上升过程每层只与**一个**父结点比较，比较次数 = 上升的层数（含最后一次“比不过”的那次）。

### 4.3 删除操作（删除堆顶元素）

**算法思想**：删除堆顶后，用**堆底（表尾）元素**填补空位，再让它“下坠”恢复堆序。

```c
// 小根堆删除堆顶，返回被删元素
int DeleteMin(int A[], int &len) {
    int minVal = A[1];          // 保存堆顶
    A[1] = A[len];              // 堆底元素顶替堆顶
    len = len - 1;              // 元素个数减 1
    int i = 1;
    while (2*i <= len) {        // 存在孩子
        int child = 2*i;        // 先假设左孩子较小
        if (child + 1 <= len && A[child+1] < A[child])
            child = child + 1;  // 右孩子更小则选右孩子（第 1 次比较）
        if (A[i] <= A[child]) break;  // 已满足堆序（第 2 次比较）
        swap(A[i], A[child]);
        i = child;              // 继续下坠
    }
    return minVal;
}
```

**讲解中的具体例子（小根堆）**：

- 删除 13：46 顶替到堆顶 → 与孩子 17、45 比较，选较小者 17（第 1 次比较），46 与 17 比（第 2 次比较）交换 → 再与 32、…… 比较，选 32（第 3 次），46 与 32 比（第 4 次）交换 → 到最底层停止。共 **4 次**比较。
- 删除 65：46 顶替 → 与 78、87 比较选 78（第 1 次），46 与 78 比（第 2 次），46 更小无需交换，停止。共 **2 次**比较。

### 4.4 关键字比较次数规则（考试重点）

| 调整方向 | 情形 | 比较次数 |
|---|---|---|
| 上升 | 每层与父结点比 | 1 次/层 |
| 下坠 | 结点有 2 个孩子 | 2 次（孩子间选小 + 与选中孩子比） |
| 下坠 | 结点只有 1 个孩子（左孩子） | 1 次（直接与唯一孩子比） |

> 注意：下坠时“两个孩子先比一次选出较小者”这一次也算关键字比较，很多同学漏数。

## 5. 复杂度分析

设堆中有 $n$ 个元素，堆高 $h = \lfloor \log_2 n \rfloor + 1$。

- **插入**：新元素从表尾上升，最多走 $h-1$ 层，每层 1 次比较。
  - 最好：$O(1)$（新元素已满足堆序，1 次比较即停）
  - 最坏：$O(\log n)$（一路上升到根）
  - 平均：新元素等概率落在各层，期望上升层数约为 $O(1)$（大部分结点在底层附近），但**408 通常按最坏 $O(\log n)$ 记**；平均推导：完全二叉树中第 $k$ 层有 $2^{k-1}$ 个结点，上升距离期望 $\sum_{k} \frac{2^{k-1}}{n}\cdot(k-1) \approx O(1)$，故平均比较次数为常数级。
- **删除**：堆底元素顶到堆顶后下坠，最多走 $h-1$ 层，每层最多 2 次比较。
  - 最好：$O(1)$（顶替元素已满足堆序，只比 2 次）
  - 最坏：$O(\log n)$（一路下坠到底层，约 $2\log n$ 次比较）
  - 平均：同理，期望下坠距离 $O(1)$，平均比较次数为常数级；考试按最坏 $O(\log n)$ 计。

> 补充：插入/删除本身是 $O(\log n)$，但**建堆**是 $O(n)$（上节结论），不要混淆。

## 6. 易错点与考试写法

1. **下标从 1 开始**：父结点是 $\lfloor i/2 \rfloor$，不是 $(i-1)/2$（那是下标从 0 开始的写法）。408 王道代码统一从 1 开始，答题时写清约定。
2. **删除的是堆顶**：堆的删除操作特指删除堆顶（最值），不是任意位置删除。删除任意元素需先定位再调整，408 不考。
3. **下坠选“较小/较大”孩子**：小根堆选较小孩子上浮，大根堆选较大孩子上浮，方向别搞反。
4. **比较次数漏数**：下坠时“两孩子比较选小”也算一次；上升时最后一次“比不过”的那次也要算。
5. **删除后元素个数先减再调整**：代码中 `len--` 要在下坠循环前完成，否则会把已删元素当孩子比较。
6. **答题程度**：408 选择题要求能**手算比较次数**并选出答案；算法题若要求写插入/删除，写出上述循环结构 + 注释即可，不要求完整可运行程序，但循环条件和交换逻辑必须正确。

## 7. 408 题型与解题套路

- **选择题（高频）**：
  - 给一个堆和插入/删除的元素，问调整后的堆序列 → 按“放表尾上升 / 堆底顶替下坠”逐步画。
  - 问关键字比较次数 → 按 4.4 表格逐层数，注意下坠双孩子算 2 次。
  - 问插入/删除的时间复杂度 → $O(\log n)$。
- **算法题（低频，了解即可）**：可能要求补全 `Insert` 或 `DeleteMin` 的循环体，套 4.2/4.3 模板。
- **常见陷阱**：
  - 大根堆与小根堆混用（题目给大根堆，你按小根堆调）；
  - 下坠时只与左孩子比，忘了先选较小孩子；
  - 把“建堆 $O(n)$”与“插入 $O(\log n)$”混淆。

## 8. 自测题

**题 1** 小根堆插入新元素时，新元素首先放在哪里？
<details><summary>答案</summary>放在表尾（数组末尾 / 逻辑上的堆底），然后与父结点比较并上升。</details>

**题 2** 小根堆删除堆顶元素后，用哪个元素顶替？
<details><summary>答案</summary>用堆底（表尾）元素顶替被删的堆顶元素，然后让其下坠调整。</details>

**题 3** 下坠调整中，某结点有左右两个孩子，本次下坠共需几次关键字比较？只有左孩子时呢？
<details><summary>答案</summary>有 2 个孩子：2 次（孩子间选较小者 1 次 + 与选中孩子比较 1 次）；只有 1 个孩子：1 次。</details>

**题 4** 含 $n$ 个元素的堆，插入一个元素的最坏时间复杂度是多少？为什么？
<details><summary>答案</summary>$O(\log n)$。新元素最坏从堆底一路上升到根，堆高为 $\lfloor \log_2 n \rfloor + 1$，每层 1 次比较，共 $O(\log n)$ 次。</details>

**题 5** 小根堆中依次插入 13、46（原堆为讲解中的蓝色部分），分别发生几次关键字比较？
<details><summary>答案</summary>插入 13：3 次（与 32、17、9 各比一次）；插入 46：1 次（与 45 比，无法上升）。</details>

## 9. 背诵卡

1. **插入**：放表尾 → 与父结点比 → 小（大根堆则大）则上升 → 直到无法上升。
2. **删除**：堆底元素顶替堆顶 → 与较小（大根堆则较大）孩子比 → 下坠 → 直到无法下坠。
3. **下标从 1 开始**：父 $\lfloor i/2 \rfloor$，左 $2i$，右 $2i+1$。
4. **比较次数**：上升 1 次/层；下坠有 2 孩子算 2 次、1 孩子算 1 次。
5. **复杂度**：插入、删除最坏均 $O(\log n)$；建堆 $O(n)$。
