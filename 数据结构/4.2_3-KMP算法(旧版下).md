# 4.2_3 KMP 算法（旧版下）：手算 next 数组与复杂度

## 1. 本节定位

- **对应王道书**：第 4 章 串 → 4.2 串的模式匹配 → KMP 算法（next 数组的求法）。
- **408 大纲对应**：串的模式匹配（KMP 算法思想、next 数组）。
- **先修知识**：朴素模式匹配（BF）算法、上一小节 KMP 的匹配思想（失配时主串指针 $i$ 不回溯，模式串指针 $j$ 跳到 $next[j]$）。
- **本节位置**：上一小节给出 KMP 的“匹配过程 + next 数组的用法”，本节解决“**next 数组怎么手算**”这一考研高频考点，并给出 KMP 的时间复杂度结论。下一节（旧版下之后）才展开 next 数组的代码实现细节。

## 2. 一句话结论

**当模式串第 $j$ 个字符失配时，把前 $j-1$ 个字符组成的串 $S$ 拿出来，求 $S$ 的“最长相等前后缀长度”，再加 1，就是 $next[j]$；且恒有 $next[1]=0$、$next[2]=1$。**

## 4. 核心内容

### 4.1 前缀与后缀的定义（本节新引入的概念）

设有一个串 $S$：

- **前缀**：包含 $S$ 的第一个字符、**不包含** $S$ 的最后一个字符的子串。
- **后缀**：包含 $S$ 的最后一个字符、**不包含** $S$ 的第一个字符的子串。

> 注意：长度为 1 的串，其唯一字符既是第一个也是最后一个，因此它**既没有前缀也没有后缀**，最长相等前后缀长度为 0。

### 4.2 next 数组的求法（手算核心）

设模式串为 $T$，位序从 1 开始（王道书习惯）。

**当 $j$ 位置失配时**：

1. 取 $T$ 的前 $j-1$ 个字符组成串 $S$（即 $T[1..j-1]$）。
2. 求 $S$ 的**最长相等前后缀长度**，记为 $L$。
3. 则 $next[j] = L + 1$。

**两个固定值**：

- $next[1] = 0$：第一个字符就失配，说明主串当前字符不可能与模式串任何位置匹配，需让 $i$ 后移。代码中令 $j=0$，下一轮循环执行 `i++; j++;`，即主串与模式串同时后移一位。
- $next[2] = 1$：前 1 个字符组成的串长度为 1，无前后缀，$L=0$，故 $next[2]=0+1=1$。对任何模式串都成立。

**为什么取“最长”**：若存在多组可对齐的前后缀，取最长的那组，可保证不漏掉任何可能的匹配位置（视频中用反例说明：若取较短对齐，后续字符可能对不上；取最长对齐则后续仍可继续比较）。

### 4.3 手算示例

**例 1**：模式串 `A B A B A`（长度 5）

| $j$ | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| $T[j]$ | A | B | A | B | A |
| $S=T[1..j-1]$ | — | A | AB | ABA | ABAB |
| 最长相等前后缀长度 $L$ | — | 0 | 0 | 1 | 2 |
| $next[j]$ | 0 | 1 | 1 | 2 | 3 |

**例 2**：模式串 `A A A A B`（长度 5）

| $j$ | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| $T[j]$ | A | A | A | A | B |
| $S=T[1..j-1]$ | — | A | AA | AAA | AAAA |
| $L$ | — | 0 | 1 | 2 | 3 |
| $next[j]$ | 0 | 1 | 2 | 3 | 4 |

### 4.4 王道书上的等价描述

王道书用 $k$ 表示“前缀的末字符下标”，描述为：

- $next[1] = 0$；
- 当 $S$（前 $j-1$ 个字符）存在相等前后缀时，$next[j] = \max\{k \mid 1<k<j \text{ 且 } T[1..k-1] = T[j-k+1..j-1]\}$；
- 其他情况 $next[j] = 1$。

这与“最长相等前后缀长度 + 1”完全等价：$k-1$ 就是最长相等前后缀长度，$k$ 就是 $next[j]$。

### 4.5 KMP 匹配代码（结合 next 使用）

```c
// 王道风格：串下标从 1 开始，T[0] 可存长度或不用
int Index_KMP(SString S, SString T, int next[]) {
    int i = 1, j = 1;
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) {
            i++; j++;          // 字符匹配，或 j=0 的特殊情况：主串、模式串同时后移
        } else {
            j = next[j];       // 失配：i 不动，j 跳到 next[j]
        }
    }
    if (j > T.length) return i - T.length;  // 匹配成功，返回起始位置
    else return 0;
}
```

> 关键：`j == 0` 分支对应 $next[1]=0$ 的特殊处理——第一个字符就失配时，让 $i$ 和 $j$ 同时加 1，即主串后移一位重新开始。

### 4.6 求 next 数组的代码（本节仅提及，未展开）

视频明确说明：求 next 数组的代码实现“先往后留一留，本节不展开”，只用于分析复杂度。其外层循环变量 $i$ 从 1 递增到 $m$（模式串长度），故时间复杂度为 $O(m)$。

## 5. 复杂度分析

### 5.1 求 next 数组：$O(m)$

求 next 的函数中，循环变量 $i$ 从 1 递增到 $m$（$m$ 为模式串长度），$i$ 单调不减，循环次数与 $m$ 同阶，故为 $O(m)$。

### 5.2 KMP 匹配：$O(n+m)$

- 主串指针 $i$ 从 1 到 $n$，**永不回溯**，最多移动 $n$ 次；
- 模式串指针 $j$ 虽然会回跳，但每次回跳后 $j$ 减小，而 $j$ 的总增量不超过 $n$（因为 $j$ 每次加 1 都伴随 $i$ 加 1），故 $j$ 的总移动次数也是 $O(n)$ 量级；
- 加上求 next 的 $O(m)$，总时间为 $O(n+m)$。

> 视频原话：这个分析“很粗略”，但考研只需记住结论 $O(n+m)$。严格证明需用势能分析（$j$ 的增减次数配平），408 不要求。

### 5.3 与朴素算法对比

| 算法 | 最好 | 最坏 | 平均 |
|---|---|---|---|
| 朴素 BF | $O(n)$ | $O(nm)$ | $O(nm)$（一般情况） |
| KMP | $O(n+m)$ | $O(n+m)$ | $O(n+m)$ |

> 视频补充：KMP 只有在“主串与模式串经常能匹配一小部分”的情况下才明显优于朴素算法；否则两者差距不大，故朴素算法至今仍被广泛使用。

## 6. 易错点与考试写法

1. **下标从 0 还是从 1 开始**：王道书和 408 真题默认**位序从 1 开始**，$next[1]=0$。若题目给出从 0 开始的数组，需整体平移（$next$ 值减 1），务必看清题目约定。
2. **$next[2]=1$ 是固定值**：任何模式串都成立，做题时先填 $next[1]=0$、$next[2]=1$，可节省时间并防止算错。
3. **“前 $j-1$ 个字符”不是“前 $j$ 个字符”**：求 $next[j]$ 时，取的是失配位置**之前**的串，不含失配字符本身。
4. **最长相等前后缀不能取整个串**：前缀不含最后一个字符、后缀不含第一个字符，所以长度最多为 $j-2$。
5. **$next[1]=0$ 的含义**：不是“跳到 0 号位置比较”，而是触发 `i++; j++;` 的特殊分支，表示主串当前字符与模式串首字符也无法匹配，主串后移。
6. **答题写到什么程度算对**：手算题只需列出每个 $j$ 对应的 $S$、最长相等前后缀长度、$next[j]$ 值；若题目要求“说明理由”，写“$next[j]$ = 前 $j-1$ 个字符组成串的最长相等前后缀长度 + 1”即可。

## 7. 408 题型与解题套路

**选择题常见考法**：

- 给一个模式串，求其 next 数组（最常考，几乎每年变形出现）。
- 给 next 数组，反推模式串（较少见，但可考）。
- 问 $next[j]$ 的含义：失配时模式串指针应跳到的位置。
- 问 $next[1]$、$next[2]$ 的值（送分题）。

**手算套路（三步法）**：

1. 先写 $next[1]=0$、$next[2]=1$；
2. 对每个 $j \ge 3$，取前 $j-1$ 个字符，从长到短试前后缀是否相等，找到最长相等长度 $L$；
3. $next[j] = L+1$。

**常见陷阱**：

- 题目模式串含重复字符（如 `AAAA`），前后缀可重叠，容易漏算最长长度；
- 题目要求“从 0 开始存储”的 next 数组，需与从 1 开始的版本区分；
- 混淆 next 数组与 nextval 数组（后者是优化版，本节未讲，属后续内容）。

## 8. 自测题

**题 1**：模式串 `ababaa`，求其 next 数组（位序从 1 开始）。

**题 2**：模式串 `aaaab`，$next[4]$ 等于多少？

**题 3**：为什么任何模式串都有 $next[2]=1$？

**题 4**：KMP 算法的时间复杂度是多少？请说明 $O(m)$ 和 $O(n)$ 分别来自哪里。

**题 5**：判断：求 $next[j]$ 时，取的是模式串前 $j$ 个字符组成串的最长相等前后缀长度加 1。

<details>
<summary>答案</summary>

**题 1**：
- $next[1]=0$，$next[2]=1$；
- $j=3$：$S=$`ab`，前后缀 `a` vs `b` 不等，$L=0$，$next[3]=1$；
- $j=4$：$S=$`aba`，前缀 `a` = 后缀 `a`，$L=1$，$next[4]=2$；
- $j=5$：$S=$`abab`，前缀 `ab` = 后缀 `ab`，$L=2$，$next[5]=3$；
- $j=6$：$S=$`ababa`，前缀 `aba` = 后缀 `aba`，$L=3$，$next[6]=4$。
- 结果：`0 1 1 2 3 4`。

**题 2**：$j=4$ 时取前 3 个字符 `aaa`，最长相等前后缀为 `aa`（长度 2），故 $next[4]=3$。

**题 3**：$j=2$ 时前 1 个字符组成的串长度为 1，该字符既是首也是尾，不存在前缀和后缀，最长相等前后缀长度为 0，故 $next[2]=0+1=1$，与模式串内容无关。

**题 4**：$O(n+m)$。$O(m)$ 来自求 next 数组（循环变量从 1 到 $m$）；$O(n)$ 来自 KMP 匹配主循环（主串指针 $i$ 不回溯，最多移动 $n$ 次）。

**题 5**：错误。取的是前 $j-1$ 个字符（不含失配字符本身）。

## 9. 背诵卡

1. **$next[j]$ = 前 $j-1$ 个字符组成串的最长相等前后缀长度 + 1**。
2. **$next[1]=0$，$next[2]=1$，任何模式串都成立**。
3. **前缀不含末字符，后缀不含首字符；长度 1 的串无前后缀**。
4. **失配时 $i$ 不动、$j \leftarrow next[j]$；$j=0$ 时 $i$、$j$ 同时加 1**。
5. **KMP 时间复杂度 $O(n+m)$：求 next 为 $O(m)$，匹配为 $O(n)$**。

## 10. 关联与下一节

- **向前关联**：朴素模式匹配算法中主串指针 $i$ 频繁回溯，最坏 $O(nm)$；KMP 的核心优化就是让 $i$ 不回溯，只让 $j$ 按 next 数组回跳。
- **向后关联**：下一节将展开**求 next 数组的代码实现**（即本节“先留一留”的部分），以及可能的 **nextval 数组（KMP 优化）**——当模式串中出现连续相同字符时，next 数组会产生无效回跳，nextval 可进一步优化。
- **考试地位**：手算 next 数组是 **408 必考**内容，选择题高频；nextval 数组也需掌握（后续小节）。
