# 7.3.2 平衡二叉树的删除

## 1. 本节定位

- **对应王道书**：第 7 章「查找」→ 7.3 树型查找 → 7.3.2 平衡二叉树（AVL 树），本节为「AVL 树的删除」。
- **408 大纲对应条目**：平衡二叉树（AVL 树）的插入、删除与查找。
- **先修知识**：
  - 二叉排序树（BST）的删除规则（叶子 / 单子树 / 双子树三种情况）；
  - AVL 树的定义（$|BF| \le 1$，$BF = h_L - h_R$）；
  - AVL 树的四种旋转：LL、RR、LR、RL（上一小节 7.3.2_1 插入调整）。
- **本节位置**：AVL 树「插入 → 删除 → 查找效率」链条中的第二环。删除 = BST 删除 + 插入式再平衡 + 可能的不平衡向上传导，是插入知识的直接迁移与扩展。

## 2. 一句话结论

**AVL 删除 = 先按 BST 规则删结点，再从删除位置「一路向北」找最小不平衡子树，用与插入完全相同的四种旋转（LL/RR/LR/RL）调整；若调整后子树高度变矮，则不平衡可能向上传导，需回到「找最小不平衡子树」一步循环，直到根结点。**

## 3. 知识地图

```
AVL 删除
├── 前提：删除后仍须满足
│   ├── 排序性：左 < 中 < 右（BST 性质不变）
│   └── 平衡性：每个结点 |BF| ≤ 1
├── 五步流程
│   ├── ① 按 BST 规则删除结点（三种情况）
│   ├── ② 从删除位置一路向北，找最小不平衡子树
│   │      └── 找不到 → 算法结束
│   ├── ③ 找最小不平衡子树中「最高的儿子 + 最高的孙子」
│   ├── ④ 按孙子位置判型：LL / RR / LR / RL，用插入的旋转法调整
│   └── ⑤ 检查不平衡是否向上传导 → 是则回到 ②
├── 四种失衡型（与插入同）
│   ├── LL → 右单旋
│   ├── RR → 左单旋
│   ├── LR → 先左旋后右旋
│   └── RL → 先右旋后左旋
└── 复杂度：$O(\log_2 n)$
```

## 4. 核心内容

### 4.1 删除与插入的异同（理解框架）

| 对比项 | 插入 | 删除 |
|---|---|---|
| 排序性 | 插入后仍须左<中<右 | 删除后仍须左<中<右 |
| 失衡型 | LL / RR / LR / RL | 同样四种 |
| 旋转方法 | 四种旋转 | **完全相同** |
| 失衡传播 | 只需调整**最低**不平衡子树，一次即可 | 调整后子树可能**变矮**，失衡可能**向上传导**，需循环 |

> 关键差异只有一条：**删除可能引起连锁失衡，插入不会**（插入使子树变高，调整后高度复原，不再向上影响）。

### 4.2 五步流程（背诵版）

1. **按 BST 规则删除**被删结点（叶子直接删；单子树用子树顶替；双子树用前驱或后继顶替，转为删前驱/后继）。
2. **一路向北**：从删除位置向上，找到**第一个**（最低的）不平衡祖先，即**最小不平衡子树**根。若一路到根都平衡，直接结束。
3. 在该子树中找**高度最高的儿子**，再找**高度最高的孙子**（若并列，任选其一，结果均合法）。
4. 按孙子相对最小不平衡子树根的位置判型（LL/RR/LR/RL），套用插入的旋转：
   - LL：对儿子**右单旋**；
   - RR：对儿子**左单旋**；
   - LR：先对孙子**左旋**，再对孙子**右旋**；
   - RL：先对孙子**右旋**，再对孙子**左旋**。
5. **检查传导**：若调整后该子树高度变矮，回到第 2 步继续向上找；否则结束。

### 4.3 典型例子（按讲解顺序）

**例 1（删叶子，无需调整）**：删 9（叶子）→ 向上检查各祖先均平衡 → 直接结束。

**例 2（RR 型，单旋）**：删 55（叶子）→ 祖先 75 失衡（左高 1、右高 3）→ 最小不平衡子树根 75 → 最高儿子 80、最高孙子 90（RR 型）→ 对 80 **左单旋** → 恢复平衡，高度由 4 变 3，但上层无失衡，结束。

**例 3（RL 型，双旋）**：删 32（叶子）→ 44 失衡 → 最高儿子 78、最高孙子 50（RL 型）→ 先对 50 **右旋**，再对 50 **左旋** → 恢复平衡，结束。

**例 4（不平衡向上传导）**：在例 3 基础上，调整后子树高度由 4 变 3，导致上层 33 失衡（左高 5、右高 3）→ 回到第 2 步 → 最小不平衡子树根 33 → 最高儿子 10、最高孙子 20（LR 型）→ 先对 20 **左旋**，再对 20 **右旋** → 恢复平衡，结束。**这是「传导」的标准演示，务必掌握。**

**例 5（删双子树结点，用前驱顶替）**：删 75（有左右子树）→ 前驱 = 左子树一路向右到底 = 60 → 用 60 数据覆盖 75，转为删原 60 结点（仅左子树 55）→ 用 55 顶替 → 60 处失衡（RR 型）→ 对 80 **左单旋** → 结束。

**例 6（删双子树结点，用后继顶替；孙子并列）**：删 75 → 后继 = 右子树一路向左到底 = 77 → 覆盖后转为删 77（叶子）→ 80 失衡 → 最高儿子 90，最高孙子有 85、95 两个并列 → **选 95（RR 型）**：对 90 左单旋；**选 85（RL 型）**：先右旋后左旋。两种结果均平衡，均合法。

### 4.4 旋转代码（王道风格，与插入共用）

前提：`T` 为最小不平衡子树根指针，结点含 `bf`（平衡因子）、`lchild`、`rchild`。

```c
typedef struct AVLNode {
    int data;
    int bf;                    // 平衡因子 = 左子树高 - 右子树高
    struct AVLNode *lchild, *rchild;
} AVLNode, *AVLTree;

/* 右单旋：处理 LL 型，A 为最小不平衡子树根 */
void RotateRight(AVLTree *A) {
    AVLNode *B = (*A)->lchild;         // B 为 A 的左孩子（最高儿子）
    (*A)->lchild = B->rchild;          // B 的右子树挂到 A 的左子树
    B->rchild = *A;                    // A 成为 B 的右孩子
    *A = B;                            // B 上位为子树新根
    /* 旋转后需按子树高度重算 A、B 的 bf（王道书按具体型别公式更新） */
}

/* 左单旋：处理 RR 型，A 为最小不平衡子树根 */
void RotateLeft(AVLTree *A) {
    AVLNode *B = (*A)->rchild;         // B 为 A 的右孩子（最高儿子）
    (*A)->rchild = B->lchild;          // B 的左子树挂到 A 的右子树
    B->lchild = *A;                    // A 成为 B 的左孩子
    *A = B;                            // B 上位为子树新根
}

/* LR 型：先对左孩子左旋，再对根右旋 */
void RotateLR(AVLTree *A) {
    RotateLeft(&(*A)->lchild);
    RotateRight(A);
}

/* RL 型：先对右孩子右旋，再对根左旋 */
void RotateRL(AVLTree *A) {
    RotateRight(&(*A)->rchild);
    RotateLeft(A);
}
```

> 说明：删除流程的「找最小不平衡子树 → 判型 → 调旋转 → 检查传导」属于**算法思想**，408 不要求默写完整删除代码，但要求能按流程手工模拟（见第 7 节）。

## 5. 复杂度分析

- **最好情况**：删除的是叶子且祖先全平衡（例 1），只需沿路径向上检查一次，$O(\log_2 n)$。
- **最坏情况**：删除后失衡一路传导到根，每层都可能旋转一次，路径长 $O(\log_2 n)$，每层旋转 $O(1)$，总计 $O(\log_2 n)$。
- **平均情况**：AVL 树高 $h$ 满足 $n \ge N(h)$，其中 $N(h)$ 为高度 $h$ 的 AVL 树最少结点数，递推 $N(h) = N(h-1) + N(h-2) + 1$，$N(1)=1, N(2)=2$，解得 $N(h) \approx \frac{\phi^{h+2}}{\sqrt{5}} - 1$（$\phi = \frac{1+\sqrt{5}}{2}$），故 $h = O(\log_2 n)$。删除需沿一条根到叶的路径操作，平均代价 $O(\log_2 n)$。
- **结论**：删除时间复杂度为 $O(\log_2 n)$，与插入、查找同阶。

## 6. 易错点与考试写法

1. **「一路向北」找的是最低的不平衡祖先**，不是根，也不是最高不平衡结点。找到第一个即停。
2. **删除后失衡型判定看「孙子」位置**，不是看儿子位置。RR 型是「右孩子的右孩子高」，对应**左单旋**——方向容易记反。
3. **双旋顺序**：LR 是「先左后右」，RL 是「先右后左」，旋转对象是**孙子结点**，不是儿子。
4. **不平衡向上传导只在删除时出现**，插入不会。答题时若题目要求「继续检查」，必须写出回到第 2 步的循环。
5. **双子树结点删除**：前驱 = 左子树最右结点，后继 = 右子树最左结点；顶替只复制数据，实际删除的是前驱/后继结点，后续失衡检查从**该前驱/后继的原位置**开始。
6. **并列最高孙子**：选哪个都合法，但考试中若出现并列，说明题目本身有歧义，408 统考一般回避；若遇到，任选一种并说明「另一种选择同样合法」即可。
7. **答题程度**：408 对本节以**选择题 + 手工模拟**为主，要求写出「删除 → 找最小不平衡子树 → 判型 → 旋转 → 检查传导」的完整过程，不必默写删除代码；旋转代码能读懂、能默写单旋即可。

## 7. 408 题型与解题套路

- **选择题常见考法**：
  - 给出 AVL 树，删除某结点后问「最小不平衡子树的根是哪个」；
  - 问「应进行何种旋转」（LL/RR/LR/RL 或左单旋/右单旋/先左后右等）；
  - 问「调整后树的高度 / 某结点的平衡因子」；
  - 问「删除操作最多需要旋转几次」（答：$O(\log_2 n)$ 次，最坏沿路径每层一次）。
- **解题套路（手工模拟四步）**：
  1. 按 BST 规则删（双子树先定前驱/后继顶替）；
  2. 从删除位置向上标高度/平衡因子，找第一个 $|BF|=2$ 的结点；
  3. 看该结点较高子树的孩子、孙子走向，定 LL/RR/LR/RL；
  4. 套旋转，重画子树，再向上检查是否传导。
- **常见陷阱**：
  - 把「最高儿子」当成「被删结点的兄弟」；
  - 双旋时先转儿子而非孙子；
  - 忘记传导，只调一次就收笔；
  - 双子树删除后从错误位置开始向上检查。

## 8. 自测题

**题 1**：AVL 树删除结点后，若删除位置到根的所有祖先都平衡，算法是否结束？为什么？

**题 2**：删除后最小不平衡子树根为 A，A 的左孩子高、左孩子的右孩子更高，应进行什么旋转？旋转对象是谁？

**题 3**：为什么 AVL 删除可能出现「不平衡向上传导」，而插入不会？

**题 4**：删除一个有左右子树的结点，用前驱顶替后，后续失衡检查应从哪个位置开始？

**题 5**：AVL 树删除操作的时间复杂度是多少？最坏情况下沿路径最多旋转多少次？

<details>
<summary>参考答案</summary>

**题 1**：结束。因为没有任何祖先失衡，无需调整；且删除只可能使子树变矮，若所有祖先仍平衡，则不会再有新的失衡产生。

**题 2**：LR 型，先对孙子（左孩子的右孩子）左旋，再对孙子右旋（等价于先对左孩子左旋、再对 A 右旋）。

**题 3**：插入使子树变高，调整后子树高度恢复原值，不影响上层；删除使子树变矮，调整后子树高度可能比删除前更矮，导致上层祖先的平衡因子变化而失衡，故需循环向上检查。

**题 4**：从被删结点前驱的**原位置**（即前驱结点原来所在处，通常是左子树最右端）开始向上检查，而不是从被覆盖的结点位置开始。

**题 5**：$O(\log_2 n)$；最坏沿路径每层旋转一次，共 $O(\log_2 n)$ 次。

## 9. 背诵卡

1. **AVL 删除五步**：BST 删 → 一路向北找最小不平衡子树 → 找最高儿子和最高孙子 → 按孙子位置判型旋转 → 检查传导，传导则回到第二步。
2. **四种型与旋转**：LL 右单旋；RR 左单旋；LR 先左后右；RL 先右后左。旋转对象是孙子（双旋）或儿子（单旋）。
3. **传导只在删除出现**：调整后子树变矮 → 上层可能失衡 → 循环向上，直到根。
4. **双子树删除**：前驱 = 左子树最右，后继 = 右子树最左；数据顶替，实体删除前驱/后继，检查从其原位置开始。
5. **复杂度**：删除 $O(\log_2 n)$，最坏旋转 $O(\log_2 n)$ 次；408 以手工模拟为主，例 1–例 4 必须掌握。
