# 7.3.3 红黑树的删除

## 1. 本节定位

- **对应王道书**：第 7 章「查找」→ 7.3 树型查找 → 7.3.3 红黑树（删除部分）。
- **408 大纲对应**：红黑树的定义、性质、插入、删除（删除为大纲列出但极低频的考点）。
- **先修知识**：二叉排序树（BST）的删除、平衡二叉树（AVL）的删除、红黑树定义与五大性质（左根右、根叶黑、不红红、黑路同）、红黑树插入。
- **本节位置**：红黑树一节的收尾。插入是「了解/尽量掌握」，删除是「了解即可、不要求掌握」——本节的核心价值在于**划定复习边界**，而不是掌握删除算法本身。

## 2. 一句话结论

红黑树删除 = **先按二叉排序树规则删结点，若破坏红黑性质再做调整**，时间复杂度 $O(\log_2 n)$；但该操作极其复杂，408 近年几乎不可能考，**只需记住三条结论性考点，不必掌握具体调整过程**。

## 3. 知识地图

## 4. 核心内容

### 4.1 删除的两步框架（本节唯一实质内容）

**第一步：按二叉排序树的删除规则删除目标结点。**

BST 删除的三种情形（先修知识，本节默认已会）：

| 情形 | 处理方式 |
|---|---|
| 被删结点是叶子 | 直接摘除 |
| 被删结点只有一个孩子 | 用该孩子顶替其位置 |
| 被删结点有两个孩子 | 用中序前驱（或后继）的值替换，再删除前驱/后继结点（转化为前两种情形） |

**第二步：检查并恢复红黑性质。**

删除一个结点后，可能破坏的性质包括：

- **不红红**：删掉黑结点后，其父/子可能出现连续红结点；
- **黑路同**：删掉黑结点会使经过该位置的路径黑结点数减 1，各路径黑高不再相等；
- 根结点被删时还可能影响「根叶黑」。

若性质被破坏，则通过**调整结点颜色与位置**（本质是「借黑 / 染色 / 旋转」一类操作）恢复红黑树性质。**具体调整分支本节未展开，408 不要求掌握。**

> 与 AVL 删除的类比：AVL 删除也是先按 BST 规则删，再沿路径回溯做旋转恢复平衡；红黑树删除是同一思路，只是恢复手段换成染色 + 旋转。这一「先 BST 删除、后修复」的框架是本节要求记住的关键。

### 4.2 三条结论性考点（选择题可能作为选项）

1. 红黑树删除的时间复杂度为 $O(\log_2 n)$。
2. 红黑树删除的**初始处理方式与二叉排序树删除相同**。
3. 删除后若破坏红黑性质，需通过调整结点颜色和位置恢复；调整后仍是一棵合法红黑树。

### 4.3 复习定位（本节强调的应试策略）

- 红黑树 2022 年才进入 408 新大纲，此前从未考过红黑树题目。
- 新考点通常「一档起步」：先考**定义与性质**（选择题为主），插入操作概率次之，**删除操作几乎不可能在最初几年出现**。
- 因此删除部分**性价比低**，不建议投入大量时间学习具体调整过程；能答出 4.2 的三条结论即可。

> 说明：以上「不考」判断是讲课老师基于 2022 年大纲新增、历年未考所做的**应试预测**，不是大纲原文；大纲本身列有删除，故按「了解即可」对待，不可当作「大纲删除」。

## 5. 复杂度分析

- **最坏情况**：红黑树高度为 $O(\log_2 n)$（由「黑路同 + 不红红」保证：设黑高为 $bh$，则内部结点数 $n \ge 2^{bh}-1$，且根到叶最长路径不超过最短路径的 2 倍，故 $h \le 2\log_2(n+1)$）。BST 删除需先查找目标结点，查找代价 $O(\log_2 n)$；删除后沿回溯路径调整，路径长度不超过树高，调整代价 $O(\log_2 n)$。合计 $O(\log_2 n)$。
- **最好情况**：目标结点就在根附近且删除不破坏性质，查找与调整均为常数级，$\Omega(1)$。
- **平均情况**：在「关键字等概率随机分布、红黑树由随机插入序列生成」的假设下，树高期望为 $\Theta(\log_2 n)$，查找与调整的期望代价均为 $\Theta(\log_2 n)$，故平均复杂度为 $\Theta(\log_2 n)$。推导要点：随机红黑树的期望高度与随机 BST 同阶（常数因子更小），而删除的调整只沿一条根到叶的路径进行，故总代价由树高决定。

## 6. 易错点与考试写法

- **易错 1**：误以为红黑树删除要「先调整颜色再删结点」。正确顺序是**先按 BST 规则删，再修复性质**。
- **易错 2**：把红黑树删除与 AVL 删除的修复手段混淆。两者框架相同，但 AVL 靠**旋转恢复平衡因子**，红黑树靠**染色 + 旋转恢复颜色性质**。
- **易错 3**：删除黑结点与删除红结点的后果不同——删红结点一般不破坏「黑路同」，删黑结点必然使某条路径黑结点数减 1，是破坏性质的主因（推断，由「黑路同」定义直接得出）。
- **易错 4**：把「不考删除」当成「红黑树整节不考」。定义、性质（尤其「黑路同」的判定、红黑树高度上界）仍是选择题重点。
- **答题程度**：本节内容在考研中**只需答到**「先按 BST 规则删除，再检查并调整以恢复红黑性质，时间 $O(\log_2 n)$」这一层；不需要写出任何调整分支的伪代码。

## 7. 408 题型与解题套路

- **选择题（主要形式）**：
  - 直接考复杂度：「红黑树插入/删除的时间复杂度是？」→ $O(\log_2 n)$。
  - 考框架：「红黑树删除结点时，首先应？」→ 按二叉排序树规则删除。
  - 考性质判定：给出一棵删除了某结点后的树，判断是否仍是红黑树（检查根叶黑、不红红、黑路同）。
- **算法题**：本节不涉及，红黑树删除不会出算法设计题。
- **常见陷阱**：选项中出现「删除后无需调整」「删除一定需要旋转」「删除时间复杂度 $O(n)$」等表述，均为错误项。

A. 调整结点颜色　B. 旋转恢复平衡　C. 按二叉排序树规则删除　D. 将结点染红

**4.** 删除红黑树中一个**黑**叶结点后，最可能被破坏的性质是哪一条？为什么？

**5.** 简述红黑树删除与 AVL 树删除在处理框架上的共同点。

**1. B。** 查找目标结点与沿路径调整均为 $O(\log_2 n)$，树高为 $O(\log_2 n)$。

**5. 都是「先按二叉排序树规则删除结点，再沿回溯路径修复结构性质」**：AVL 修复平衡因子（旋转），红黑树修复颜色性质（染色 + 旋转）。

## 9. 背诵卡

1. 红黑树删除 = **先 BST 规则删，再修复红黑性质**。
2. 删除时间复杂度 $O(\log_2 n)$（树高 $O(\log_2 n)$）。
3. 删除可能破坏「不红红」「黑路同」，需调整颜色与位置。
4. 删黑结点是破坏「黑路同」的主因（推断）。
5. 408 定位：定义性质必背，插入尽量会，**删除了解即可**。
