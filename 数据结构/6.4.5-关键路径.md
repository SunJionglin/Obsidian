# 6.4.5 关键路径

## 1. 本节定位

- **对应王道书**：第 6 章「图」→ 6.4 图的应用 → 6.4.5 关键路径（AOE 网与关键路径）。
- **408 大纲对应条目**：图的应用——最小生成树、最短路径、拓扑排序、关键路径（关键路径属于「图的应用」必考范围）。
- **先修知识**：有向无环图（DAG）、拓扑排序与逆拓扑排序（6.4.4 AOV 网）、带权有向图、路径长度概念。
- **本章位置**：图应用的收尾小节，与 AOV 网（顶点表示活动）成对出现，是「拓扑排序」的直接延伸——先拓扑排序才能算最早发生时间，先逆拓扑排序才能算最迟发生时间。

## 2. 一句话结论

**关键路径 = 从源点到汇点的最长路径；路径长度即整个工程的最短完成时间；关键活动 = 时间余量 $l(e)-e(e)=0$ 的活动，其耗时拖延必然拖延整个工期。**

## 3. 知识地图

```
AOE 网（Activity On Edge，边表示活动）
├── 基本概念
│   ├── 顶点 = 事件（一瞬间发生）
│   ├── 有向边 = 活动，权值 = 活动持续时间
│   ├── 源点（开始顶点）：唯一入度为 0
│   └── 汇点（结束顶点）：唯一出度为 0
├── 两条性质
│   ├── 顶点事件发生后，其出边活动才能开始
│   └── 顶点所有入边活动都结束后，该事件才发生
├── 四个参量
│   ├── ve(k)：事件 k 最早发生时间（正向拓扑序，取 max）
│   ├── vl(k)：事件 k 最迟发生时间（逆向逆拓扑序，取 min）
│   ├── e(i)：活动 i 最早开始时间 = 弧尾顶点的 ve
│   └── l(i)：活动 i 最迟开始时间 = 弧头顶点的 vl − 权值
├── 时间余量 d(i) = l(i) − e(i)
│   └── d(i)=0 的活动 = 关键活动
└── 关键路径 = 由关键活动构成的源点到汇点路径（可能不唯一）
```

## 4. 核心内容

### 1. AOE 网与 AOV 网的区别（408 必考辨析）

| | AOV 网 | AOE 网 |
|---|---|---|
| 字母含义 | Vertex，顶点表示活动 | Edge，边表示活动 |
| 顶点 | 活动 | 事件 |
| 边 | 表示活动间先后约束，无权 | 表示活动，权值为持续时间 |
| 用途 | 拓扑排序判环 | 求关键路径、估算工期 |

AOE 网的两条性质（务必背）：

1. 某顶点代表的事件发生后，从该顶点出发的各条边代表的活动**才能开始**；
2. 进入某顶点的各条边代表的活动**全部结束**后，该顶点代表的事件**才发生**。

由此可知：AOE 网中活动可并行（如「打鸡蛋」与「洗番茄」），也可串行（「洗番茄」必须先于「切番茄」）。

### 2. 关键路径的定义

- 源点到汇点可能有多条路径，**长度最大**的那条称为**关键路径**，其上的活动称为**关键活动**。
- 关键路径长度 = 完成整个工程的**最短时间**（因为最长的那条链决定了工期下界，其余活动都可塞进这段时间内并行完成）。
- 例（番茄炒蛋）：路径 $v_1\to v_3\to v_4$ 长度 $1+3+2=6$；路径 $v_1\to v_2\to v_3\to v_4$ 长度 $2+2+2=6$（原例中为 4，取讲解中「打鸡蛋 2 分钟」的原始数据时上路径为 4，下路径为 6，故下路径为关键路径）。**关键路径长度 6 即最短工期 6 分钟。**

### 3. 四个参量的计算（核心算法，必须会手算）

**前提**：AOE 网为 DAG，源点唯一、汇点唯一。

**Step 1：求 ve（事件最早发生时间）——按拓扑序正向递推**

$$
ve(\text{源点})=0,\qquad ve(k)=\max_{\langle j,k\rangle \in E}\{\,ve(j)+w(j,k)\,\}
$$

即：所有前驱「最早发生时间 + 边权」中取**最大**（必须等最慢的那条入边完成）。

**Step 2：求 vl（事件最迟发生时间）——按逆拓扑序逆向递推**

$$
vl(\text{汇点})=ve(\text{汇点}),\qquad vl(k)=\min_{\langle k,j\rangle \in E}\{\,vl(j)-w(k,j)\,\}
$$

即：所有后继「最迟发生时间 − 边权」中取**最小**（不能拖累任何一个后继）。

**Step 3：求活动的最早开始时间 $e(i)$**

$$
e(i)=ve(\text{弧尾顶点})
$$

**Step 4：求活动的最迟开始时间 $l(i)$**

$$
l(i)=vl(\text{弧头顶点})-w(i)
$$

**Step 5：求时间余量并判定**

$$
d(i)=l(i)-e(i)
$$

$d(i)=0$ 的活动即关键活动；由关键活动连成的源点到汇点路径即关键路径。

### 4. 手算示例（以讲解中的 6 顶点网为例）

顶点：$v_1$（源）、$v_2,v_3,v_4,v_5$、$v_6$（汇）。边权：$a_1(v_1\to v_3)=2$，$a_2(v_1\to v_2)=3$，$a_3(v_2\to v_4)=2$，$a_4(v_2\to v_5)=3$，$a_5(v_3\to v_4)=4$，$a_6(v_3\to v_6)=3$，$a_7(v_4\to v_6)=2$，$a_8(v_5\to v_6)=1$。

**拓扑序**：$v_1,v_3,v_2,v_5,v_4,v_6$（一种合法序）

| 顶点 | ve | vl |
|---|---|---|
| $v_1$ | 0 | 0 |
| $v_2$ | 3 | 4 |
| $v_3$ | 2 | 2 |
| $v_4$ | 6 | 6 |
| $v_5$ | 6 | 7 |
| $v_6$ | 8 | 8 |

计算过程要点：
- $ve(v_4)=\max\{ve(v_2)+2,\ ve(v_3)+4\}=\max\{5,6\}=6$（取大）
- $ve(v_6)=\max\{ve(v_3)+3,\ ve(v_4)+2,\ ve(v_5)+1\}=\max\{5,8,7\}=8$
- $vl(v_2)=\min\{vl(v_4)-2,\ vl(v_5)-3\}=\min\{4,4\}=4$（取小）
- $vl(v_3)=\min\{vl(v_4)-4,\ vl(v_6)-3\}=\min\{2,5\}=2$

**活动表**：

| 活动 | 边 | $e=l$ 前 | $e(i)$ | $l(i)$ | $d(i)$ | 关键？ |
|---|---|---|---|---|---|---|
| $a_1$ | $v_1\to v_3$ | | 0 | 0 | 0 | ✔ |
| $a_2$ | $v_1\to v_2$ | | 0 | 1 | 1 | ✘ |
| $a_3$ | $v_2\to v_4$ | | 3 | 4 | 1 | ✘ |
| $a_4$ | $v_2\to v_5$ | | 3 | 4 | 1 | ✘ |
| $a_5$ | $v_3\to v_4$ | | 2 | 2 | 0 | ✔ |
| $a_6$ | $v_3\to v_6$ | | 2 | 5 | 3 | ✘ |
| $a_7$ | $v_4\to v_6$ | | 6 | 6 | 0 | ✔ |
| $a_8$ | $v_5\to v_6$ | | 6 | 7 | 1 | ✘ |

**关键活动**：$a_1,a_5,a_7$ → **关键路径** $v_1\to v_3\to v_4\to v_6$，长度 $2+4+2=8$。

### 5. 关键活动与关键路径的性质（选择题高频）

1. 关键活动耗时**增加** → 整个工程工期**延长**。
2. 缩短关键活动时间 → 工期**可能**缩短（注意是「可以」，不是「一定」）。
3. 关键活动缩短到一定程度后，**可能变成非关键活动**，关键路径随之改变。例：把「切番茄」从 3 分钟压到 1 分钟，则下路径长度变为 4，上路径（打鸡蛋 2 + 炒菜 2 = 4）成为新的关键路径；此时再压缩切番茄已无意义，必须压缩打鸡蛋或炒菜。
4. AOE 网**可能存在多条关键路径**。此时只缩短一条关键路径上的活动，工期**不会缩短**（另一条仍卡着）；必须同时缩短所有关键路径上的活动，或缩短公共关键活动（如「炒菜」）。

### 6. 算法框架（王道风格伪代码，理解即可，408 不要求默写完整代码）

```c
// 前提：图已用邻接表存储，且已求得拓扑序列 topo[]
// 求 ve：按拓扑序正向
for (k = 0; k < n; k++) ve[k] = 0;          // 初始化
for (i = 0; i < n; i++) {                    // 按拓扑序
    v = topo[i];
    for (p = G.vertices[v].firstarc; p; p = p->nextarc) {
        w = p->adjvex;
        if (ve[v] + p->weight > ve[w])       // 取 max
            ve[w] = ve[v] + p->weight;
    }
}
// 求 vl：按逆拓扑序逆向
for (k = 0; k < n; k++) vl[k] = ve[n-1];     // 汇点 vl = ve
for (i = n-1; i >= 0; i--) {                 // 逆拓扑序
    v = topo[i];
    for (p = G.vertices[v].firstarc; p; p = p->nextarc) {
        w = p->adjvex;
        if (vl[w] - p->weight < vl[v])       // 取 min
            vl[v] = vl[w] - p->weight;
    }
}
// 判定关键活动
for (每条边 e = <u,v>, 权 w) {
    e_early = ve[u];
    l_late  = vl[v] - w;
    if (e_early == l_late) 输出 e;           // 时间余量为 0
}
```

## 5. 复杂度分析

设顶点数 $n$、边数 $m$。

- **拓扑排序**：$O(n+m)$（邻接表，每个顶点入队一次、每条边被扫描一次）。
- **求 ve**：外层遍历 $n$ 个顶点，内层遍历每个顶点的出边，总边数 $m$，故 $O(n+m)$。
- **求 vl**：同理 $O(n+m)$。
- **判定关键活动**：扫描全部边，$O(m)$。
- **总复杂度**：$O(n+m)$，最好/最坏/平均均为 $O(n+m)$（与图的规模成线性，无概率假设，故无平均情况推导）。
- 若用邻接矩阵存储，扫描每个顶点的所有邻接点需 $O(n)$，总复杂度退化为 $O(n^2)$。

## 6. 易错点与考试写法

1. **ve 取 max、vl 取 min 不能反**。ve 是「等所有前驱都完成」，故取最大；vl 是「不能拖累任何后继」，故取最小。这是最高频失分点。
2. **汇点的 $vl$ 必须等于 $ve$**，不是 0，也不是无穷大。
3. **$e(i)$ 看弧尾，$l(i)$ 看弧头再减权**。记法：最早开始看「起点事件最早何时发生」；最迟开始看「终点事件最迟何时发生，倒推要留出活动时间」。
4. **关键路径可能不唯一**，答题时若题目问「关键路径」需写出全部，或说明「其中一条」。
5. **「缩短关键活动一定缩短工期」是错的**——存在多条关键路径时不一定；且缩短到一定程度关键路径会转移。
6. **答题规范**：408 计算题要求写出 ve/vl 表或逐点递推式（如 $ve(v_4)=\max\{5,6\}=6$），再列活动表求 $e,l,d$，最后指出关键活动与关键路径。只写最终路径不写过程会丢步骤分。

## 7. 408 题型与解题套路

**选择题常见考法**：
- 给 AOE 网求关键路径长度 / 关键活动个数 → 按四参量手算，注意取 max/min。
- 概念辨析：AOV 与 AOE 的区别、事件与活动的区别。
- 性质判断：「关键活动延长工期必延长」（对）；「缩短任一关键活动工期必缩短」（错）；「关键路径唯一」（错）；「关键活动一定是关键路径上的边」（对）。
- 给多条关键路径的情形，问缩短某活动是否有效。

**算法题考法**：408 大题中关键路径多作为「图的应用」综合题的一问，通常要求：写出拓扑序列 → 求 ve → 求 vl → 求关键路径。**不要求默写完整代码**，但要求会手工推演并写清递推依据。

**解题套路（手算五步）**：
1. 找源点、汇点，写出一个拓扑序列；
2. 正向按拓扑序算 ve（取 max）；
3. 逆向按逆拓扑序算 vl（取 min，汇点 vl=ve）；
4. 对每条边算 $e=ve(\text{尾})$、$l=vl(\text{头})-w$；
5. $e=l$ 的边连起来即关键路径，长度 = $ve(\text{汇点})$。

## 8. 自测题

**1.** AOE 网中，某顶点的所有入边活动都结束时，该顶点代表的事件（ ）。
A. 才能开始　B. 已经结束　C. 才能发生　D. 与活动无关

**2.** 求事件最迟发生时间 $vl$ 时，应按（ ）顺序进行，且对后继取（ ）。
A. 拓扑序，max　B. 逆拓扑序，min　C. 拓扑序，min　D. 逆拓扑序，max

**3.** 某 AOE 网有两条长度均为 10 的关键路径，若将其中一条关键路径上某关键活动缩短 1，则整个工期（ ）。
A. 缩短 1　B. 不变　C. 延长 1　D. 无法确定

**4.** 活动 $a=\langle u,v\rangle$ 的权为 3，$ve(u)=4$，$vl(v)=9$，则 $a$ 的时间余量为（ ）。
A. 0　B. 2　C. 3　D. 5

**5.**（简答）为什么关键路径的长度就是整个工程的最短完成时间？

<details>
<summary>答案与解析</summary>

**1. C**。AOE 网性质：进入某顶点的各活动全部结束后，该顶点事件才发生；事件发生后其出边活动才能开始。A 混淆了「事件发生」与「活动开始」。

**2. B**。$vl$ 从汇点逆向推，$vl(k)=\min\{vl(j)-w\}$，取 min。

**3. B**。两条关键路径并行卡工期，只缩短一条，另一条仍为 10，工期不变。必须同时缩短所有关键路径上的活动或缩短公共活动。

**4. B**。$e=ve(u)=4$，$l=vl(v)-w=9-3=6$，$d=l-e=2$。

**5.** 工程完成要求源点到汇点的每条路径上的活动全部完成，故工期 ≥ 任一路径长度，即 ≥ 最长路径长度；而把非关键活动安排在其时间余量内并行执行，可使全部活动在最长路径长度内完成，故最短工期恰等于最长路径（关键路径）长度。

</details>

## 9. 背诵卡

1. **AOE 边表活动、顶点表事件；AOV 顶点表活动。**
2. **ve 正向拓扑取 max，vl 逆向逆拓扑取 min，汇点 $vl=ve$。**
3. **$e=ve(\text{弧尾})$，$l=vl(\text{弧头})-w$，$d=l-e$，$d=0$ 为关键活动。**
4. **关键路径 = 源到汇最长路径，长度 = 最短工期；可能不唯一。**
5. **关键活动延长必延工期；缩短不一定缩工期（多关键路径 / 缩短过度会转移）。**
