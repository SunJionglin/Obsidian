## 2. 一句话结论

**线索化 = 在三种遍历框架上「边遍历边改指针」：用全局（或引用型）指针 `pre` 记录当前访问节点的前驱，访问节点 `q` 时把 `q` 的空左指针指向前驱、把 `pre` 的空右指针指向后继，最后单独处理最后一个节点的右指针。**

## 4. 核心内容

### 1. 线索二叉树结点定义（前提）

```c
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;   // 0 表示指向孩子，1 表示指向线索（前驱/后继）
} ThreadNode, *ThreadTree;
```

初始建树时 `ltag = rtag = 0`，表示指针都指向真实孩子，尚未线索化。

### 2. 中序线索化（模板，必须默写）

**核心逻辑**：本质就是一次中序遍历，只是把 `visit` 换成「线索化处理」。

```c
ThreadNode *pre = NULL;   // 全局变量，指向当前访问节点的前驱

// 处理当前结点 q 的线索化（相当于 visit）
void visit(ThreadNode *q) {
    if (q->lchild == NULL) {      // 左孩子为空 → 建立前驱线索
        q->lchild = pre;
        q->ltag = 1;
    }
    if (pre != NULL && pre->rchild == NULL) {  // 前驱的右孩子为空 → 建立后继线索
        pre->rchild = q;
        pre->rtag = 1;
    }
    pre = q;                      // 更新 pre 为当前结点，准备访问下一个
}

// 中序线索化（左根右）
void InThread(ThreadTree T) {
    if (T != NULL) {
        InThread(T->lchild);      // 左
        visit(T);                 // 根
        InThread(T->rchild);      // 右
    }
}

// 对整棵树进行中序线索化的入口
void CreateInThread(ThreadTree T) {
    pre = NULL;                   // 第一个被访问的结点无前驱
    if (T != NULL) {
        InThread(T);
        if (pre->rchild == NULL)  // 收尾：处理最后一个结点
            pre->rtag = 1;
    }
}
```

**执行要点（按讲解顺序）**：
- 第一个被访问的结点（中序第一个）无前驱，`pre` 初值为 `NULL`，其左指针线索化为 `NULL`。
- 访问结点 `q` 时，先看 `q` 的左指针是否为空（建前驱线索），再看 `pre` 的右指针是否为空（建后继线索），最后 `pre = q`。
- 遍历结束后，最后一个被访问的结点右指针仍为空，需在入口函数中补设 `rtag = 1`。

### 3. 先序线索化（有陷阱）

```c
void PreThread(ThreadTree T) {
    if (T != NULL) {
        visit(T);                        // 根
        if (T->ltag == 0)                // ★ 关键：只有 ltag==0 才是真左孩子
            PreThread(T->lchild);        // 左
        PreThread(T->rchild);            // 右
    }
}
```

**「转圈」问题（本节最易错点）**：先序访问根后，若根的左指针为空，`visit` 会把它线索化为指向 `pre`（前驱）。此时若不加判断直接递归 `T->lchild`，就会顺着前驱线索往回走，造成无限循环（讲解中戏称「爱的魔力转圈圈」）。**解决办法：递归左子树前判断 `T->ltag == 0`。**

### 4. 后序线索化（无转圈问题）

```c
void PostThread(ThreadTree T) {
    if (T != NULL) {
        PostThread(T->lchild);   // 左
        PostThread(T->rchild);   // 右
        visit(T);                // 根
    }
}
```

**为什么不会转圈**：访问结点 `q` 时，它的左、右子树都已处理完毕，之后不会再回头访问左孩子那条路，所以左指针被线索化也不会被再次递归进入。

### 5. 王道书风格（引用型参数）

王道书把 `pre` 作为**引用型参数** `ThreadNode *&pre` 在函数间传递，效果等价于全局变量（保证修改能传回上层）。收尾时王道书直接写 `pre->rchild = NULL; pre->rtag = 1;` 而不判空——因为**中序遍历最后一个被访问的结点一定没有右孩子**（若有右孩子，它就不是最后一个），所以直接置空是安全的。本节推荐写法是加判空，更稳妥。

## 5. 复杂度分析

设二叉树结点数为 $n$。

- **时间复杂度**：三种线索化都只对每个结点做常数次操作（判断指针、赋值、递归调用），递归调用总次数为 $O(n)$，故 **最好 = 最坏 = 平均 = $O(n)$**。
  - 推导：每个结点恰好被 `visit` 一次，`visit` 内部为 $O(1)$；递归遍历每条边恰好走一次，总代价 $O(n)$。
- **空间复杂度**：递归栈深度等于树高 $h$。
  - 最好：平衡树 $h = O(\log n)$；
  - 最坏：单支树 $h = O(n)$；
  - 平均：随机二叉树期望高度 $O(\log n)$（在随机插入的假设下），故平均 $O(\log n)$。
  - 若用全局 `pre`，不额外占堆空间；线索化本身不新建结点，原地修改。

## 6. 易错点与考试写法

1. **忘记收尾**：遍历结束后最后一个结点的右指针仍为空，必须补设 `rtag = 1`（中序/先序/后序都要）。这是代码题最常见的扣分点。
2. **先序线索化不判 `ltag`**：递归左子树前必须 `if (T->ltag == 0)`，否则死循环。中序、后序不需要此判断。
3. **`pre` 的传递方式**：全局变量或引用型参数 `*&pre`，二者等价；若写成普通值传递 `*pre`，修改无法传回，线索全部丢失。
4. **`visit` 中两个 if 的顺序**：先处理 `q` 的左线索，再处理 `pre` 的右线索，最后 `pre = q`。顺序颠倒会导致后继线索错位。
5. **考试写法要求**：408 算法题只需写出「遍历框架 + visit 内两条线索化语句 + 收尾」，并注明 `pre` 是全局变量或引用参数；不必写完整 `main`。选择题常考「先序线索化是否需要判 ltag」「最后一个结点 rtag 是否为 1」等细节。

## 7. 408 题型与解题套路

- **选择题**：
  - 给出二叉树，问线索化后某结点的 `lchild`/`rchild` 指向谁（本质是找中序/先序/后序前驱后继）。
  - 问「先序线索化中防止转圈的条件」→ 答 `ltag == 0`。
  - 问「哪种线索化需要判 ltag」→ 只有先序。
- **算法题**：
  - 直接考「编写中序线索化算法」→ 套模板：遍历框架 + `visit` + 收尾。
  - 变式：在线索二叉树上找某结点的前驱/后继（下一节内容），需先会建线索。
- **常见陷阱**：把「线索化」与「找前驱」混淆；忽略 `pre` 初值为 `NULL`；先序线索化漏判 `ltag`。

**2.** 先序线索化递归左子树前必须判断（ ）。
A. `T->rtag == 0`　B. `T->ltag == 0`　C. `T->lchild != NULL`　D. 无需判断

**3.** 为什么后序线索化不会出现「转圈」问题？

**4.** 写出中序线索化中 `visit` 函数的核心代码（含两条线索化语句与 `pre` 更新）。

**5.** 中序线索化结束后，最后一个被访问结点的 `rtag` 应设为多少？为什么可以直接把它的 `rchild` 置空？

<details>
<summary>答案</summary>

1. **B**。第一个被访问结点无前驱，`pre` 初值为 `NULL`。
2. **B**。左指针可能已被线索化为前驱，只有 `ltag == 0` 才是真左孩子。
3. 后序访问结点 `q` 时，其左、右子树均已处理完毕，之后不会再递归进入左孩子路径，故左指针被线索化也不会导致回头访问。
4.

5. 设为 **1**。中序遍历最后一个被访问的结点一定没有右孩子（否则它后面还会访问其右子树），故可直接置 `rchild = NULL` 并令 `rtag = 1`。

## 9. 背诵卡

1. **线索化 = 遍历框架 + 改空指针**，`pre` 记录前驱，全局变量或引用参数。
2. **visit 三步**：`q` 左空→指 `pre`、`ltag=1`；`pre` 右空→指 `q`、`rtag=1`；`pre=q`。
3. **先序线索化必判 `ltag==0`** 再递归左子树，否则转圈；中序、后序不用判。
4. **收尾不能忘**：最后一个结点 `rtag=1`（中序最后一个必无右孩子）。
5. 三种线索化时间均为 $O(n)$，空间为递归栈 $O(h)$。
