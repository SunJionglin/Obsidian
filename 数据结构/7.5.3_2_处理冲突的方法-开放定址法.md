# 7.5.3 处理冲突的方法——开放定址法

## 1. 本节定位

- **对应王道书**：第 7 章「查找」→ 7.5 散列表 → 7.5.3 处理冲突的方法（开放定址法部分）。
- **408 大纲对应**：散列表（Hash Table）——处理冲突的方法：开放定址法（线性探测、平方探测、双散列、伪随机序列）。
- **先修知识**：散列函数构造、装填因子、冲突概念、拉链法（上一节）。
- **本章位置**：散列查找是查找章的收尾重点；本节是「处理冲突」两大方法之一（另一为拉链法），是选择题高频区，也是删除操作「逻辑删除」这一经典陷阱的来源。

## 2. 一句话结论

开放定址法在冲突时按一个**探测序列 $D_i$** 在表内另找空位，公式为 $H_i=(H(key)+D_i)\bmod m$；四种探测序列（线性、平方、双散列、伪随机）只是 $D_i$ 不同，**删除必须逻辑删除**，否则探测链断裂导致查找失败。

## 3. 知识地图

```
开放定址法
├── 基本思想：冲突时按探测序列另寻空位；一个地址对同义词/非同义词都开放
├── 通式：H_i = (H(key) + D_i) mod m，i = 0,1,…,m-1，D_0 = 0
├── 四种探测序列
│   ├── 线性探测法：D_i = 0,1,2,…,m-1（循环后移）
│   ├── 平方探测法（二次探测）：D_i = 0, 1², -1², 2², -2², …
│   ├── 双散列法：D_i = i × H₂(key)
│   └── 伪随机序列法：D_i 为人为设计的伪随机序列
├── 三种操作
│   ├── 插入：算 H(key)，冲突则按 D_i 探测，遇空位插入
│   ├── 查找：按同一序列探测；关键字匹配→成功；遇空位→失败
│   └── 删除：先查找，成功后【逻辑删除】（打删除标记），不可物理清空
└── 拓展（了解）：探测序列覆盖率
    ├── 线性：必覆盖全表
    ├── 平方：m 为 4j+3 型素数时可覆盖全表
    ├── 双散列：H₂(key) 与 m 互质时可覆盖全表
    └── 伪随机：取决于序列设计
```

## 4. 核心内容

### 1. 基本思想与通式

插入元素时先用散列函数算出初始地址 $H(key)$；若该地址已被占用（冲突），则按**探测序列** $D_0,D_1,D_2,\dots$ 依次尝试新地址：

$$H_i=(H(key)+D_i)\bmod m,\quad i=0,1,\dots,m-1$$

- $m$ 为表长，取余保证地址不越界。
- $D_0=0$，即第一次探测的就是初始散列地址本身。
- 下标 $i$ 最大到 $m-1$：最多探测 $m$ 个地址。
- 之所以叫「开放」：一个散列地址既存同义词，也存非同义词，对所有关键字「开放」。

### 2. 四种探测序列

| 方法 | $D_i$ 序列 | 特点 |
|---|---|---|
| 线性探测法 | $0,1,2,\dots,m-1$ | 冲突就往后挪一格，循环 |
| 平方探测法（二次探测） | $0,1^2,-1^2,2^2,-2^2,\dots$ | 左右跳跃，避免聚集 |
| 双散列法 | $D_i=i\times H_2(key)$ | 第二个散列函数，不同关键字序列不同 |
| 伪随机序列法 | 人为设计的伪随机序列 | 序列由设计者决定 |

**线性探测插入示例**（$m=13$，$H(key)=key\bmod 13$，表内 1、2、3 已占）：插入 1 → $H=1$ 冲突 → 探测 2 冲突 → 探测 3 冲突 → 探测 4 空，插入 4。

**平方探测插入示例**：插入 1 → $H=1$ 冲突 → $1+1=2$ 冲突 → $1-1=0$ 冲突 → $1+4=5$ 空，插入 5。

**双散列插入示例**（$H_2(key)=13-key$，插入 1）：$H=1$ 冲突 → $D_1=1\times12=12$，$(1+12)\bmod13=0$ 冲突 → $D_2=2\times12=24$，$(1+24)\bmod13=12$ 冲突 → $D_3=3\times12=36$，$(1+36)\bmod13=11$ 空，插入 11。

**伪随机序列示例**（序列 5,3,…，插入 1）：$H=1$ 冲突 → $1+5=6$ 冲突 → $1+3=4$ 空，插入 4。

### 3. 查找

与插入同序列探测：
- 关键字匹配 → **查找成功**；
- 探测到**空位置** → **查找失败**（说明该关键字从未插入）。

例：查 27，$H=27\bmod13=1$，沿 1→2→3→4→5 探测，到 5 为空，查找失败。

### 4. 删除——逻辑删除（本节最大考点）

**错误做法**：直接把被删元素的位置清空。后果：探测链中间出现空位，后续元素（如元素 1 排在 15 之后）查找时提前遇到空位，被误判为查找失败。

**正确做法**：给该位置打「已删除」标记（如 `flag=1`），即**逻辑删除**，探测链不断。查找时遇到「已删除」标记要继续往后探测，遇到真正空位才判失败。

**副作用**：大量逻辑删除会让表「看起来很满、其实很空」，查找效率严重下降；解决办法是定期整理（把元素挪回初始散列地址、物理清空其余位置）。插入新元素时，**可以复用**逻辑删除的位置。

```c
/* 王道风格：开放定址法删除的核心思想（伪代码） */
#define EMPTY  0   /* 该位置从未使用 */
#define DELETED 1  /* 逻辑删除标记 */
#define OCCUPIED 2 /* 有效元素 */

typedef struct {
    int key;
    int state;   /* EMPTY / DELETED / OCCUPIED */
} HashSlot;

/* 查找：返回下标，失败返回 -1 */
int Search(HashSlot T[], int m, int key) {
    int h0 = key % m;              /* 初始散列地址 */
    for (int i = 0; i < m; i++) {  /* 最多探测 m 个位置 */
        int hi = (h0 + D(i, key)) % m;  /* D(i,key) 为探测序列第 i 项 */
        if (T[hi].state == EMPTY)       /* 真空位 → 查找失败 */
            return -1;
        if (T[hi].state == OCCUPIED && T[hi].key == key)
            return hi;                  /* 匹配成功 */
        /* state == DELETED 或关键字不等 → 继续探测 */
    }
    return -1;
}

/* 删除：先查找，成功后逻辑删除 */
int Delete(HashSlot T[], int m, int key) {
    int pos = Search(T, m, key);
    if (pos == -1) return 0;       /* 查找失败，删除失败 */
    T[pos].state = DELETED;        /* 只打标记，不清空 */
    return 1;
}
```

> 说明：`D(i,key)` 按所选方法展开——线性 `i`；平方 `±(i/2+1)²` 交替；双散列 `i*H2(key)`；伪随机查表。插入时遇到 `EMPTY` 或 `DELETED` 均可落位。

## 5. 复杂度分析

设装填因子 $\alpha=n/m$（$n$ 为表中元素数），假设散列函数均匀、各关键字等概率。

- **最好情况**：$O(1)$，首次探测即命中/落位（无冲突）。
- **最坏情况**：$O(m)$，线性探测下连续冲突，需探测整表；查找失败最坏也要扫 $m$ 个位置。
- **平均情况**（王道书结论，推导思路）：
  - 线性探测：查找成功约 $\frac{1}{2}\left(1+\frac{1}{1-\alpha}\right)$，失败约 $\frac{1}{2}\left(1+\frac{1}{(1-\alpha)^2}\right)$。
  - 推导直觉：冲突后探测的期望长度随 $\alpha$ 增大而急剧上升；$\alpha\to1$ 时线性探测退化为顺序查找，故实际要求 $\alpha<1$ 且通常控制在 0.5～0.75。
  - 平方探测、双散列的平均探测长度优于线性探测（聚集更少），但结论以王道书表格为准，考试一般只考「$\alpha$ 越大，平均查找长度越长」这一定性结论。

> 408 必考：ASL 计算题（给定表、给定序列，数比较次数求平均），按定义逐个数即可，不必套公式。

## 6. 易错点与考试写法

1. **删除必须逻辑删除**：写「直接清空」必错。答题要写出「打删除标记/墓碑标记，探测链不断」。
2. **查找失败的判定**：遇到**空位置**才失败；遇到**已删除标记**要继续探测。这是选择题最爱设的坑。
3. **$D_0=0$**：第一次探测就是初始地址，别漏算这一次比较。
4. **平方探测的符号交替**：$+1^2,-1^2,+2^2,-2^2$，顺序不能乱；负偏移要 $\bmod m$ 转正。
5. **双散列 $D_i=i\times H_2(key)$**：$i$ 从 1 开始乘（$D_0=0$ 时 $i=0$），别把 $H_2$ 的结果直接当 $D_1$ 之外的值用错。
6. **ASL 计算**：成功 ASL 只统计表中已有元素；失败 ASL 要覆盖所有可能的初始散列地址（$0\sim m-1$），分母是 $m$ 而非 $n$。
7. **覆盖率结论（了解即可）**：只有线性探测必覆盖全表；平方探测需 $m=4j+3$ 型素数；双散列需 $H_2(key)$ 与 $m$ 互质（常令 $m$ 为素数、$H_2(key)=m-(key\bmod m)$ 之类保证）。

**答题标准**：概念题写清「通式 + 四种 $D_i$ + 逻辑删除原因」；计算题列出每个关键字的探测地址序列，再数比较次数求平均，步骤分才拿满。

## 7. 408 题型与解题套路

- **选择题**：
  - 给表、给散列函数、给探测方法，问某关键字插入位置 / 查找成功比较次数 / 删除后某元素能否查到。
  - 套路：画表 → 按 $D_i$ 逐个填/查 → 数次数。删除题先想「逻辑删除」。
  - 常考陷阱：删除后查找失败误判、平方探测序列符号、双散列 $i$ 的起点。
- **算法题**：本节一般不单独出大题，但可作为「散列表设计」题的组成部分（定义结构体含 `state` 字段、写插入/查找/删除）。写代码时务必体现 `EMPTY/DELETED/OCCUPIED` 三态。
- **综合题**：与拉链法对比 ASL、装填因子影响，属简答/选择混合。

## 8. 自测题

**1.** 开放定址法通式中 $D_0$ 为什么等于 0？

**2.** 表长 $m=11$，$H(key)=key\bmod 11$，线性探测法，依次插入 11,22,33，各自落在哪个地址？

**3.** 承上，删除 22 后若不进行逻辑删除而直接清空，查找 33 会怎样？为什么？

**4.** 平方探测法在什么条件下能覆盖整个散列表？

**5.** 双散列法中，保证探测序列覆盖全表的条件是什么？

<details>
<summary>答案</summary>

1. $D_0=0$ 表示第 0 次探测就是初始散列地址 $H(key)$ 本身，即先检查原位是否冲突。
2. 11→地址 0；22→$H=0$ 冲突，探测 1，落 1；33→$H=0$ 冲突，探测 1 冲突，探测 2，落 2。
3. 查找 33：$H=0$，0 处已空（被物理清空），立即判查找失败——但 33 实际在地址 2，属误判。原因：物理删除在探测链中制造了空位，探测提前终止。故必须逻辑删除。
4. 当表长 $m$ 为形如 $4j+3$ 的素数（如 7, 11, 19）时，平方探测可覆盖全表。
5. 第二个散列函数值 $H_2(key)$ 与表长 $m$ 互质（最大公因子为 1）时，探测序列可覆盖所有地址；常用做法是令 $m$ 为素数且 $H_2(key)<m$。

</details>

## 9. 背诵卡

1. 通式：$H_i=(H(key)+D_i)\bmod m$，$D_0=0$，$i=0\sim m-1$。
2. 四序列：线性 $0,1,2,\dots$；平方 $0,\pm1^2,\pm2^2,\dots$；双散列 $i\cdot H_2(key)$；伪随机自定义。
3. 查找：匹配→成功；遇**空位**→失败；遇**删除标记**→继续。
4. 删除只能**逻辑删除**（打标记），否则探测链断裂、误判失败；可定期整理、插入可复用删除位。
5. 覆盖率：线性必全覆盖；平方需 $m=4j+3$ 素数；双散列需 $H_2$ 与 $m$ 互质（了解即可）。
