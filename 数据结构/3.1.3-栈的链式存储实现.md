# 3.1.3 栈的链式存储实现

## 1. 本节定位

- **对应王道书**：第 3 章 栈、队列和数组，3.1 栈，3.1.3 栈的链式存储结构（链栈）。
- **408 大纲对应**：栈和队列的基本概念、顺序存储结构与链式存储结构、基本操作（入栈、出栈、判空）。
- **先修知识**：单链表的定义、头插法建表、单链表在表头插入/删除结点、带头结点与不带头结点单链表的区别、栈的 LIFO（后进先出）特性。
- **本节位置**：紧接 3.1.2 栈的顺序存储（顺序栈），是“栈的两种存储实现”中的链式版本；后续 3.1.4 起进入栈的应用（括号匹配、表达式求值、递归），本节只解决“存储结构 + 基本操作”。

## 2. 一句话结论

**链栈本质上就是一个只能在表头一端插入和删除的单链表**：把链头当栈顶，入栈 = 头插法插入，出栈 = 删除首元结点；王道书推荐不带头结点的实现，但带头结点版本也必须会写。

## 3. 知识地图

```
栈的链式存储（链栈）
├── 本质：受限的单链表（只在一端插入/删除）
│   ├── 链头一端 = 栈顶（top 指针所指）
│   └── 链尾一端 = 栈底
├── 两种设计
│   ├── 不带头结点（王道书推荐）
│   │   ├── 空栈条件：top == NULL
│   │   └── 入栈/出栈都要改 top 本身
│   └── 带头结点
│       ├── 空栈条件：top->next == NULL
│       └── 入栈/出栈只改 top->next，头结点始终存在
├── 基本操作
│   ├── 初始化 InitStack
│   ├── 判空 StackEmpty
│   ├── 入栈 Push（对应单链表头插）
│   ├── 出栈 Pop（对应删除首元结点）
│   └── 取栈顶 GetTop（只读 top 所指结点）
└── 特点
    ├── 不存在“栈满上溢”（除非内存耗尽）
    └── 多栈共享不方便（与顺序栈共享栈对比）
```

## 4. 核心内容

### 4.1 定义

链栈结点与单链表结点完全相同，只是命名习惯上把指向栈顶的指针叫 `top`（等价于单链表的头指针 `L`）。

```c
// 王道风格：不带头结点的链栈
typedef struct LinkNode {
    ElemType data;          // 数据域
    struct LinkNode *next;  // 指针域，指向栈中下一个元素（更靠近栈底）
} LinkNode, *LiStack;       // LiStack 是指向栈顶结点的指针类型
```

要点：
- `LiStack top;` 中 `top` 直接指向**栈顶结点**（不带头结点时就是首元结点）。
- 栈底结点的 `next == NULL`。
- 与单链表一样，`LinkNode` 是结点类型，`LiStack` 是指针类型，二者不要混用。

### 4.2 不带头结点版本（王道书推荐，必须会默写）

```c
// 初始化：空栈
void InitStack(LiStack *S) {   // 传指针的指针，才能修改调用者的 top
    *S = NULL;
}

// 判空
bool StackEmpty(LiStack S) {
    return S == NULL;          // 不带头结点：top 为 NULL 即空栈
}

// 入栈：等价于单链表“头插法”
bool Push(LiStack *S, ElemType x) {
    LinkNode *p = (LinkNode *)malloc(sizeof(LinkNode));
    if (p == NULL) return false;   // 内存分配失败（链栈唯一的“满”）
    p->data = x;
    p->next = *S;              // 新结点指向原栈顶
    *S = p;                    // top 移到新结点，新结点成为栈顶
    return true;
}

// 出栈：删除首元结点，用 x 带回被删元素
bool Pop(LiStack *S, ElemType *x) {
    if (*S == NULL) return false;  // 栈空，出栈失败
    LinkNode *p = *S;              // p 指向栈顶结点
    *x = p->data;                  // 先保存数据
    *S = p->next;                  // top 下移到次栈顶
    free(p);                       // 释放原栈顶结点
    return true;
}

// 取栈顶（不出栈）
bool GetTop(LiStack S, ElemType *x) {
    if (S == NULL) return false;
    *x = S->data;
    return true;
}
```

关键行理解：
- `p->next = *S; *S = p;` 这两句就是头插法的核心，**顺序不能反**，否则丢失原栈顶。
- `Pop` 中必须先 `*x = p->data` 再 `free(p)`，否则释放后读数据是悬空访问。

### 4.3 带头结点版本（也必须会写）

```c
// 初始化：建立头结点，top 指向头结点
void InitStack(LiStack *S) {
    *S = (LinkNode *)malloc(sizeof(LinkNode));
    (*S)->next = NULL;         // 头结点 next 为空表示空栈
}

// 判空
bool StackEmpty(LiStack S) {
    return S->next == NULL;    // 带头结点：看头结点的 next
}

// 入栈：在头结点之后插入（头插）
bool Push(LiStack S, ElemType x) {   // 头结点不变，传一级指针即可
    LinkNode *p = (LinkNode *)malloc(sizeof(LinkNode));
    if (p == NULL) return false;
    p->data = x;
    p->next = S->next;         // 新结点接在头结点之后
    S->next = p;               // 头结点指向新栈顶
    return true;
}

// 出栈：删除头结点之后的第一个结点
bool Pop(LiStack S, ElemType *x) {
    if (S->next == NULL) return false;
    LinkNode *p = S->next;     // p 是栈顶结点
    *x = p->data;
    S->next = p->next;         // 头结点越过 p
    free(p);
    return true;
}
```

两种版本对比（考试常考判断）：

| 项目 | 不带头结点 | 带头结点 |
|---|---|---|
| 空栈条件 | `top == NULL` | `top->next == NULL` |
| 入栈是否改 `top` | 改（`*S = p`） | 不改（只改 `S->next`） |
| 出栈是否改 `top` | 改（`*S = p->next`） | 不改 |
| 函数参数 | 需 `LiStack *S` | 传 `LiStack S` 即可 |
| 王道书推荐 | ✔ | 也要求会写 |

### 4.4 图解（不带头结点，依次 Push a、b、c 再 Pop 一次）

```
Push(a):  top → [a|NULL]
Push(b):  top → [b|·] → [a|NULL]
Push(c):  top → [c|·] → [b|·] → [a|NULL]
                          ↑栈顶        ↑栈底
Pop():    top → [b|·] → [a|NULL]   （c 被 free，x = c）
```

栈顶在链头，插入/删除都在链头完成，时间复杂度与“表头操作”一致。

## 5. 复杂度分析

设栈中当前元素个数为 $n$。

- **入栈 Push**：只需修改常数个指针并 `malloc` 一个结点，与 $n$ 无关，最好/最坏/平均均为 $O(1)$。平均情况无需概率假设，因为操作步数与 $n$ 无关。
- **出栈 Pop**：常数个指针操作加一次 `free`，最好/最坏/平均均为 $O(1)$。
- **取栈顶 GetTop / 判空**：$O(1)$。
- **空间复杂度**：$n$ 个元素占 $n$ 个结点，$O(n)$；且随用随申请，**不存在顺序栈的“假溢出/上溢”问题**（仅受系统内存限制）。

对比记忆：顺序栈入栈/出栈也是 $O(1)$，但顺序栈容量固定、可能栈满；链栈无栈满（除内存耗尽），但每个结点多一个指针域的空间开销，且 `malloc/free` 有常数时间开销。

## 6. 易错点与考试写法

1. **空栈条件写错**：不带头结点是 `top == NULL`，带头结点是 `top->next == NULL`。这是选择题最高频陷阱。
2. **`top` 指向哪里**：链栈的 `top` 指向栈顶结点本身（不是栈顶的下一个位置），这与顺序栈 `top` 指向“栈顶元素下标”或“栈顶上一位置”的约定不同，不要混。
3. **入栈两句顺序**：`p->next = *S; *S = p;` 反了就断链。
4. **Pop 先取数据后 free**：`*x = p->data;` 必须在 `free(p);` 之前。
5. **参数传递**：不带头结点时 Push/Pop 要修改 `top` 本身，必须传 `LiStack *S`（二级指针）；若只传 `LiStack S`，函数内改的是副本，调用者栈不变。带头结点时头结点地址不变，传一级指针即可。
6. **判空与出栈的边界**：Pop 前必须判空，否则对 `NULL` 解引用。
7. **答题程度**：408 算法题/基本操作题要求写出完整可编译的 C 函数（含判空、`malloc` 失败处理可简写但结构要完整）；选择题要求能根据“空栈条件、top 移动方向、是否带头结点”快速判断。只写“头插法”三个字不给分。

## 7. 408 题型与解题套路

- **选择题**：
  - 给一段链栈 Push/Pop 代码，问执行后栈中元素或 `top` 指向 → 画图逐句模拟，注意头插顺序导致栈顶是最新元素。
  - 问“链栈的栈顶在链头还是链尾” → 链头（因为删除/插入都在链头才 $O(1)$；若栈顶在链尾，出栈需找前驱，变 $O(n)$）。
  - 问“链栈是否需要判满” → 不需要（除内存耗尽），对比顺序栈。
  - 问带头结点与不带头结点的空栈条件、参数类型差异。
- **算法题套路**：
  - 题目要求“用链栈实现某操作”时，先写结构体定义，再写 Init/Empty/Push/Pop 四件套，最后写主逻辑；判空一定写在 Pop 最前面。
  - 若题目只给“栈”的抽象操作，可先用链栈实现再调用，注意 `ElemType` 按题目要求替换。
- **常见陷阱**：
  - 把链栈的 `top` 当成“栈顶下一位置”（那是顺序栈的写法）。
  - 出栈后忘记 `free`，或 `free` 后还访问 `p->data`。
  - 带头结点版本误把 `top` 当成首元结点，导致空栈判断和 Pop 起点都错一位。

## 8. 自测题

**1.** 不带头结点的链栈，空栈条件是（ ）。
A. `top == NULL` B. `top->next == NULL` C. `top->next == top` D. `top != NULL`

**2.** 链栈的栈顶通常设在（ ）。
A. 链尾，便于插入 B. 链头，使入栈出栈均为 $O(1)$ C. 链中任意位置 D. 必须带头结点才能确定

**3.** 写出不带头结点链栈的入栈函数，并说明两行指针赋值的顺序为什么不能交换。

**4.** 带头结点链栈执行 `Push(a); Push(b); Pop(&x);` 后，`x` 的值和栈中剩余元素分别是什么？

**5.** 判断：链栈在入栈时可能发生“栈满上溢”，因此 Push 前必须判满。（ ）

<details>
<summary>答案与解析</summary>

**1. A**。不带头结点时 `top` 直接指向栈顶结点，空栈即 `top == NULL`；B 是带头结点版本的空栈条件。

**2. B**。栈顶放链头，入栈=头插、出栈=删首元结点，都是常数次指针操作，$O(1)$；若栈顶在链尾，出栈需找前驱，退化为 $O(n)$。

**3.**
```c
bool Push(LiStack *S, ElemType x) {
    LinkNode *p = (LinkNode *)malloc(sizeof(LinkNode));
    if (p == NULL) return false;
    p->data = x;
    p->next = *S;   // 先让新结点指向原栈顶
    *S = p;         // 再让 top 指向新结点
    return true;
}
```
若先执行 `*S = p;`，原栈顶地址就丢失了，`p->next` 无法正确接上，导致断链、原栈元素全部丢失。

**4.** `x = b`；栈中剩余元素为 `a`（`top` 指向 a 结点）。Push(a)、Push(b) 后栈顶到栈底为 b、a；Pop 弹出栈顶 b，剩 a。

**5. 错**。链栈结点动态申请，只有内存耗尽才失败，不存在顺序栈那种固定容量的“栈满”；Push 中判断的是 `malloc` 是否返回 `NULL`，不是判满。

## 9. 背诵卡

1. **链栈 = 只能在表头插入/删除的单链表**，链头即栈顶，栈底结点 `next == NULL`。
2. **不带头结点**：空栈 `top == NULL`；Push/Pop 改 `top` 本身，参数用 `LiStack *S`。
3. **带头结点**：空栈 `top->next == NULL`；Push/Pop 只改 `top->next`，参数用 `LiStack S`。
4. **入栈两句**：`p->next = *S; *S = p;` 顺序不可反；**出栈先存数据再 free**。
5. **链栈无栈满**（除内存耗尽），入栈/出栈/取栈顶均 $O(1)$；王道书推荐不带头结点，但两种都要会写。
