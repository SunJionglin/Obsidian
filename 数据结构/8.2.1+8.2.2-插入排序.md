# 8.2.1+8.2.2 插入排序

## 1. 本节定位

- **对应王道书**：第 8 章「排序」→ 8.2 插入排序 → 8.2.1 直接插入排序、8.2.2 折半插入排序。
- **408 大纲对应**：排序算法中的「插入排序」（直接插入排序、折半插入排序），要求掌握算法思想、执行过程、时间/空间复杂度与稳定性。
- **先修知识**：顺序表（数组）的存储与下标约定、折半查找（二分查找）的区间收缩过程、算法稳定性定义。
- **本节位置**：是第 8 章排序的第一个算法，后续的希尔排序、冒泡、快速、选择、堆、归并、基数排序都以「插入」这一基本思想为起点；折半插入排序又是「折半查找 + 移动」的组合，直接复用第 7 章折半查找。

## 2. 一句话结论

插入排序每一趟把当前元素插入到前面已排好序的子序列中，直接插入排序时间 $O(n^2)$、空间 $O(1)$、稳定；折半插入排序只把「找位置」的比较次数降到 $O(n\log n)$，移动次数不变，总时间仍是 $O(n^2)$。

## 3. 知识地图

```
插入排序
├── 基本思想：维护前缀有序区，逐个把待排元素插入有序区
├── 直接插入排序（顺序表）
│   ├── 无哨兵版：temp 暂存 + 从 i-1 向左顺序比较并后移
│   └── 带哨兵版：a[0] 作哨兵，数据存 a[1..n]
├── 折半插入排序（仅顺序表可实现）
│   ├── 折半查找确定插入位置 low
│   └── 统一后移 [low, i-1]，再放入 a[0] 副本
├── 链表插入排序（思想相同，改指针，不做折半）
└── 三要素
    ├── 时间：最好 O(n)、最坏/平均 O(n^2)
    ├── 空间：O(1)
    └── 稳定性：稳定（相等元素不后移、折半遇等值往右半区找）
```

## 4. 核心内容

### 4.1 直接插入排序的思想

把待排序序列看成「已排好序的前缀 + 未处理的后续」。从第 2 个元素开始，依次把当前元素 $a[i]$ 插入到前面有序区 $a[1..i-1]$ 的正确位置：

1. 若 $a[i] \ge a[i-1]$，说明它已在正确位置，本趟不移动；
2. 否则暂存 $a[i]$，把所有大于它的元素依次右移一位，腾出空位后放入。

**稳定性来源**：只把「严格大于」当前元素的记录后移，与它相等的元素不动，因此相等元素的相对次序不变，算法稳定。

### 4.2 直接插入排序代码（无哨兵版，王道风格）

```c
// 对 a[0..n-1] 做升序直接插入排序
void InsertSort(int a[], int n) {
    int i, j, temp;
    for (i = 1; i < n; i++) {          // 从第 2 个元素开始，共 n-1 趟
        if (a[i] < a[i - 1]) {         // 只有比前驱小才需要插入
            temp = a[i];               // 暂存，防止后移时被覆盖
            for (j = i - 1; j >= 0 && a[j] > temp; j--)
                a[j + 1] = a[j];       // 大于 temp 的元素依次右移
            a[j + 1] = temp;           // 放入空出的位置
        }
    }
}
```

要点：
- 内层循环条件 `j >= 0 && a[j] > temp` 中，**先判越界再比值**，两个判断都要做。
- 循环结束时 `j` 指向「最后一个不大于 temp 的元素」，所以插入位置是 `j+1`。
- 若 `a[i] >= a[i-1]`，整趟只做 1 次比较、0 次移动。

### 4.3 带哨兵的实现（王道书版本）

数据存放在 `a[1..n]`，`a[0]` 空出来作哨兵：

```c
// 数据在 a[1..n]，a[0] 作哨兵；升序
void InsertSort_Sentry(int a[], int n) {
    int i, j;
    for (i = 2; i <= n; i++) {         // 从第 2 个元素开始
        if (a[i] < a[i - 1]) {
            a[0] = a[i];               // 哨兵暂存当前元素
            for (j = i - 1; a[j] > a[0]; j--)
                a[j + 1] = a[j];       // 大于哨兵的元素右移
            a[j + 1] = a[0];           // 放入正确位置
        }
    }
}
```

**哨兵的作用**：内层循环省掉 `j >= 0` 的判断——当 `j` 减到 0 时，`a[0] > a[0]` 为假，循环自然终止，每轮少一次比较。但提升很小，考试写哪种都行，逻辑清晰即可。

### 4.4 折半插入排序

前提：**顺序存储**且前缀已有序，因此可用折半查找定位插入位置。

```c
// 数据在 a[1..n]，a[0] 暂存当前元素；升序
void BInsertSort(int a[], int n) {
    int i, j, low, high, mid;
    for (i = 2; i <= n; i++) {
        a[0] = a[i];                   // 暂存待插入元素
        low = 1; high = i - 1;         // 在 a[1..i-1] 中折半查找
        while (low <= high) {
            mid = (low + high) / 2;
            if (a[mid] > a[0])
                high = mid - 1;        // 插入点在左半区
            else
                low = mid + 1;         // 相等也往右半区找 → 保证稳定性
        }
        for (j = i - 1; j >= high + 1; j--)
            a[j + 1] = a[j];           // 统一后移 [high+1, i-1]
        a[high + 1] = a[0];            // 等价于 a[low] = a[0]
    }
}
```

两个必须记住的细节：

1. **稳定性处理**：`a[mid] == a[0]` 时走 `else` 分支（`low = mid + 1`），继续在右半区找，使相等元素插在后面，保持稳定。这与普通折半查找「找到即停」不同。
2. **插入位置**：循环因 `low > high` 结束，此时 `high + 1 == low`，插入位置就是 `low`（即 `high+1`），后移区间是 `[low, i-1]`（即 `[high+1, i-1]`）。

### 4.5 链表插入排序（了解即可）

- 思想相同：维护有序链表，逐个把结点按关键字插入。
- 移动元素只需改指针，**移动次数减少**；但只能顺序比较找位置，**比较次数仍是 $O(n^2)$**，总时间仍 $O(n^2)$。
- 链表无法随机访问，**折半插入排序不可实现**。

## 5. 复杂度分析

设表长 $n$，共 $n-1$ 趟。

**空间复杂度**：只用 `i, j, temp`（或 `a[0]` 哨兵）等常数个辅助单元，与 $n$ 无关，$O(1)$。

**时间复杂度**（以「比较次数 + 移动次数」计）：

- **最好情况**：原表已升序。每趟只比较 1 次、移动 0 次，总比较 $n-1$ 次，时间 $O(n)$。
- **最坏情况**：原表逆序。第 $i$ 趟（$i=2..n$）需比较 $i-1$ 次、移动 $i-1+1$ 次（含暂存与放回），
  $$\sum_{i=2}^{n}(i-1)=\frac{n(n-1)}{2}=O(n^2)$$
  比较与移动均为 $O(n^2)$。
- **平均情况**：假设待排序列的 $n!$ 种排列等概率出现（王道书取最好与最坏的平均，本质是等概率假设）。第 $i$ 趟平均比较约 $i/2$ 次、平均移动约 $i/2$ 次，
  $$\sum_{i=2}^{n}\frac{i}{2}\approx \frac{n^2}{4}=O(n^2)$$
  故平均时间 $O(n^2)$。

**折半插入排序**：

- 比较次数：第 $i$ 趟折半查找约 $\lceil \log_2 i\rceil$ 次，总比较 $O(n\log n)$；
- 移动次数：与直接插入相同，最坏仍 $\sum(i-1)=O(n^2)$；
- 总时间由移动主导，**仍为 $O(n^2)$**，相对直接插入只是常数因子减小，无质的飞跃。

**稳定性**：直接插入与折半插入均**稳定**。

## 6. 易错点与考试写法

1. **下标约定**：无哨兵版数据在 `a[0..n-1]`，带哨兵版数据在 `a[1..n]`、`a[0]` 作哨兵。答题时先声明约定，别混用。
2. **插入位置写错**：无哨兵版是 `a[j+1] = temp`；带哨兵/折半版是 `a[high+1] = a[0]`（即 `a[low]`）。写成 `a[j]` 或 `a[high]` 都错。
3. **折半遇等值不能停**：必须走 `else`（`low = mid+1`）往右半区继续找，否则不稳定。这是折半插入排序与普通折半查找最大的区别，也是选择题高频陷阱。
4. **后移区间**：折半插入排序是 `[low, i-1]`（即 `[high+1, i-1]`）整体右移，不是只移一个。
5. **「折半插入排序更快」是错的**：只减少比较次数，移动次数不变，总时间仍 $O(n^2)$。
6. **链表不能折半插入**：折半查找依赖随机访问，链表只能顺序比较。
7. **答题程度**：408 算法题写直接插入排序，给出完整可运行函数、注明下标约定、内层循环条件写全（`j >= 0 && a[j] > temp`）即可满分；折半插入排序要写出 `while (low <= high)` 的折半过程、`else` 分支的稳定性处理和后移循环。

## 7. 408 题型与解题套路

- **选择题**：
  - 给一个序列，问第 $k$ 趟插入排序后的结果（数清「已处理到第几个元素」）。
  - 问比较次数/移动次数（最好 $n-1$ 次比较、0 次移动；逆序时 $\frac{n(n-1)}{2}$）。
  - 问稳定性、时间复杂度、空间复杂度。
  - 折半插入排序中「遇等值元素如何处理」「最终插入位置是 low 还是 high」。
- **算法题套路**：
  1. 明确存储结构（顺序表/链表）与下标约定；
  2. 外层 `for (i = 2; i <= n; i++)`（或 `i = 1` 起，视约定）；
  3. 暂存当前元素 → 找位置（顺序比较或折半）→ 后移 → 放回；
  4. 说明稳定性与复杂度。
- **常见陷阱**：把折半插入排序说成 $O(n\log n)$；把哨兵说成能降低时间复杂度（只省一次越界判断）；把插入排序说成不稳定。

## 8. 自测题

**1.** 对序列 `{49, 38, 65, 97, 76, 13, 27, 49*}` 做直接插入排序，第 5 趟（处理完 76）后的序列是什么？

**2.** 直接插入排序在最好、最坏情况下的比较次数分别是多少？

**3.** 折半插入排序相比直接插入排序，改进的是哪一部分？时间复杂度是否降低？

**4.** 折半插入排序中，当 `a[mid] == a[0]` 时应如何操作？为什么？

**5.** 为什么链表可以实现插入排序，却不能实现折半插入排序？

<details>
<summary>答案</summary>

1. `{13, 27, 38, 49, 65, 76, 97, 49*}`（处理到 76 时，前 5 个元素 49,38,65,97,76 已排好，13、27、49* 尚未处理；按趟数口径以「已处理元素个数」为准，答题时注明口径）。
2. 最好 $n-1$ 次（已有序，每趟比较 1 次）；最坏 $\frac{n(n-1)}{2}$ 次（逆序）。
3. 改进的是「查找插入位置」的比较次数，从 $O(n^2)$ 降到 $O(n\log n)$；移动次数不变，总时间仍 $O(n^2)$。
4. 走 `else` 分支令 `low = mid + 1`，继续在右半区查找。这样相等元素插在后面，保证稳定性。
5. 插入排序只需顺序比较和改指针，链表可做；折半查找需要随机访问中间元素，链表只能顺序访问，故折半插入排序不可实现。

</details>

## 9. 背诵卡

1. 插入排序：前缀有序，逐个插入；从第 2 个元素起共 $n-1$ 趟。
2. 直接插入：最好 $O(n)$（已有序，比较 $n-1$ 次），最坏/平均 $O(n^2)$，空间 $O(1)$，**稳定**。
3. 哨兵 `a[0]`：省去内层 `j >= 0` 判断，只提效率常数，不改复杂度。
4. 折半插入：比较 $O(n\log n)$、移动 $O(n^2)$，总时间仍 $O(n^2)$；遇等值走右半区保稳定；插入位置 `low = high+1`。
5. 链表可插入排序（改指针、比较仍 $O(n^2)$），不可折半插入（无随机访问）。
