# 3.4.1–3.4.4 特殊矩阵的压缩存储

## 1. 本节定位

- **对应王道书**：第 3 章「栈、队列和数组」中数组与特殊矩阵一节（3.4 数组和特殊矩阵）。
- **408 大纲对应**：数据结构部分「数组和特殊矩阵」——多维数组的存储（行优先/列优先）、特殊矩阵（对称矩阵、三角矩阵、三对角矩阵、稀疏矩阵）的压缩存储与下标映射。
- **先修知识**：一维/二维数组的内存连续存放、C 语言数组定义、等差数列求和、矩阵的行列号约定。
- **本章位置**：数组是线性结构的推广；本节是「数组」这一节的落点，也是后续查找、排序中「存储结构决定访问方式」思想的直接体现。属于**408 必考**（选择题高频，偶有算法题背景）。

## 2. 一句话结论

特殊矩阵压缩存储的全部考点，归结为一件事：**把矩阵元素的行号 $i$、列号 $j$ 映射为一维数组下标 $k$**——先数出该元素前面有多少个元素，再按「数组下标从 0 还是从 1 开始」决定减不减 1。

## 3. 知识地图

```
数组基础
├── 一维数组：连续存放、等长元素 → 随机存取
│     LOC(a[i]) = LOC(a[0]) + i × sizeof(ElemType)
└── 二维数组：逻辑二维 → 内存一维
      ├── 行优先（先存完一行再存下一行）
      └── 列优先（先存完一列再存下一列）
特殊矩阵压缩存储
├── 对称矩阵：a[i][j] = a[j][i]，只存主对角线 + 下三角（或上三角）
├── 三角矩阵
│     ├── 下三角矩阵：上三角区全为常量 c
│     └── 上三角矩阵：下三角区全为常量 c
├── 三对角矩阵（带状矩阵）：|i − j| > 1 时元素为 0
└── 稀疏矩阵：非零元素远少于总元素
      ├── 三元组顺序表（行号、列号、值）
      └── 十字链表（行链 + 列链，各设头指针数组）
```

## 4. 核心内容

### 4.1 一维数组的地址计算

数组元素类型相同、大小相等、内存连续，故只需起始地址即可算出任意元素地址：

$$
LOC(a[i]) = LOC(a[0]) + i \times L
$$

其中 $L$ 为每个元素所占字节数。**若下标从 1 开始**，则

$$
LOC(a[i]) = LOC(a[1]) + (i-1)\times L
$$

> 题目未特别说明时，默认数组下标从 0 开始；矩阵的行号列号默认从 1 开始。这是本节最大的坑，见第 6 节。

### 4.2 二维数组的行优先 / 列优先存储

设二维数组 $b[m][n]$（$m$ 行 $n$ 列），元素大小 $L$，起始地址 $LOC$。

**行优先**（先第一行，再第二行……）：

$$
LOC(b[i][j]) = LOC + \big(i \times n + j\big)\times L
$$

**列优先**（先第一列，再第二列……）：

$$
LOC(b[i][j]) = LOC + \big(j \times m + i\big)\times L
$$

理解方式：括号内就是「目标元素前面有多少个元素」。行优先时前面有 $i$ 整行（每行 $n$ 个）再加本行前 $j$ 个；列优先时前面有 $j$ 整列（每列 $m$ 个）再加本列前 $i$ 个。**二维数组同样具有随机存取特性**。

### 4.3 对称矩阵

**定义**：$n$ 阶方阵，满足 $a_{ij}=a_{ji}$（$1\le i,j\le n$）。主对角线 $i=j$；上三角区 $i<j$；下三角区 $i>j$。

**压缩策略**：只存主对角线 + 下三角区（共 $\frac{n(n+1)}{2}$ 个元素），按行优先放入一维数组 `sa[0..n(n+1)/2-1]`。

**一维数组长度**：$1+2+\cdots+n=\dfrac{n(n+1)}{2}$，最后一个元素下标为 $\dfrac{n(n+1)}{2}-1$。

**下标映射（行优先、存下三角、数组下标从 0 起）**：

- 当 $i \ge j$（下三角 + 主对角线，实际存储区）：
  $$
  k = \frac{(i-1)i}{2} + (j-1)
  $$
  推导：$a_{ij}$ 前面有第 1 行到第 $i-1$ 行，共 $1+2+\cdots+(i-1)=\frac{(i-1)i}{2}$ 个元素；本行中它前面还有 $j-1$ 个。因数组下标从 0 起，故不再减 1（「第几个」减 1 恰好等于上式）。
- 当 $i < j$（上三角区，未存储）：利用对称性 $a_{ij}=a_{ji}$，代入上式把 $i,j$ 互换即可。

**变式（列优先存下三角）**：$a_{ij}$ 前面有第 1 列到第 $j-1$ 列，元素数为 $n+(n-1)+\cdots+(n-j+2)$，本列中它前面还有 $i-j$ 个，故它是第
$$
\big[n+(n-1)+\cdots+(n-j+2)\big] + (i-j) + 1
$$
个元素，再按数组下标起点调整。

> 这些公式**不要背**，考场上现推：数「前面有多少个元素」→ 得「第几个」→ 按起点减 1 或减 0。

### 4.4 三角矩阵

**下三角矩阵**：上三角区（不含主对角线）全为常量 $c$；**上三角矩阵**：下三角区全为常量 $c$。

**压缩策略**：非常量区按行优先（或列优先）存入一维数组，**再在数组末尾多留一个单元存常量 $c$**。

- 下三角矩阵：数组长度 $\dfrac{n(n+1)}{2}+1$。
- 上三角矩阵：非常量区元素个数也是 $\dfrac{n(n+1)}{2}$，数组长度同为 $\dfrac{n(n+1)}{2}+1$。

**下三角矩阵映射**（行优先、下标从 0 起）：

- $i \ge j$：$k=\dfrac{(i-1)i}{2}+(j-1)$（与对称矩阵完全相同）。
- $i < j$：$k=\dfrac{n(n+1)}{2}$（常量 $c$ 所在位置）。

**上三角矩阵映射**（行优先、下标从 0 起）：

- $i \le j$：前面 $i-1$ 行元素数为 $n+(n-1)+\cdots+(n-i+2)$，本行前面还有 $j-i$ 个，故
  $$
  k=\frac{(i-1)(2n-i+2)}{2}+(j-i)
  $$
- $i > j$：$k=\dfrac{n(n+1)}{2}$（常量 $c$ 所在位置）。

### 4.5 三对角矩阵（带状矩阵）

**定义**：$|i-j|>1$ 时 $a_{ij}=0$；只有主对角线及其上下相邻一条对角线上的元素可能非零。

**压缩策略**：按行优先只存非零带内元素。第 1 行与第 $n$ 行各 2 个，其余每行 3 个，共 $3n-2$ 个，一维数组长度 $3n-2$，末元素下标 $3n-3$。

**$k$ 的映射**（行优先、下标从 0 起，$|i-j|\le 1$）：

$$
k = 2i + j - 3
$$

推导：前 $i-1$ 行共 $3(i-1)-1=3i-4$ 个元素（第 1 行少 1 个）；第 $i$ 行中 $a_{ij}$ 是本行第 $j-i+2$ 个；故它是第 $(3i-4)+(j-i+2)+1=2i+j-2$ 个，下标从 0 起再减 1，得 $k=2i+j-3$。

**由 $k$ 反求 $i,j$**（王道书扩展，408 选择题偶考）：

由 $k+1$ 是第 $k+1$ 个元素，满足
$$
3i-4 < k+1 \le 3i-1
$$
解得 $i \ge \left\lceil \dfrac{k+2}{3}\right\rceil$，即
$$
i=\left\lceil \frac{k+2}{3}\right\rceil \quad(\text{等价于王道书写法 } i=\left\lfloor \frac{k+1}{3}\right\rfloor+1)
$$
再由 $k=2i+j-3$ 得 $j=k-2i+3$。

### 4.6 稀疏矩阵

**定义**：非零元素个数远少于矩阵元素总数（无固定阈值）。

**方法一：三元组顺序表**（408 必考）

```c
#define MaxSize 100          // 非零元素个数上限
typedef struct {
    int i, j;                // 行号、列号（一般从 1 开始）
    ElemType value;          // 非零元素值
} Triple;

typedef struct {
    Triple data[MaxSize];    // 三元组表，按行优先（或列优先）有序存放
    int mu, nu, tu;          // 行数、列数、非零元素个数
} TSMatrix;
```

特点：节省空间，但**失去随机存取特性**，按行列访问需顺序扫描三元组表。

**方法二：十字链表**（王道书扩展，了解即可）

每个非零元素对应一个结点，含行号、列号、值、`right` 指针（指向同行下一非零元素）、`down` 指针（指向同列下一非零元素）；另设行头指针数组与列头指针数组。适合非零元素动态变化、需按行又按列访问的场合。

## 5. 复杂度分析

本节操作本质是**地址/下标计算**，不是查找算法，故复杂度分析针对「映射计算」与「访问方式」：

- **映射计算（由 $i,j$ 求 $k$）**：只含四则运算与取整，最好/最坏/平均均为 $O(1)$。无概率假设，因为公式是确定性的。
- **三元组顺序表按行列访问某元素**：最好 $O(1)$（恰为第一个三元组），最坏 $O(t)$（$t$ 为非零元素个数，扫到末尾或不存在），平均 $O(t)$。若假设目标元素等概率落在 $t$ 个三元组位置上，平均比较次数为 $\dfrac{t+1}{2}$，即 $O(t)$。
- **空间**：对称矩阵/三角矩阵由 $n^2$ 降为 $O(n^2/2)$（常数因子减半）；三对角矩阵由 $n^2$ 降为 $O(n)$；稀疏矩阵由 $O(mn)$ 降为 $O(t)$。

## 6. 易错点与考试写法

1. **数组下标从 0 还是从 1 开始**：题目未说明默认从 0；但矩阵行号列号默认从 1。求 $k$ 时先算「第几个」，再按起点决定减 1 还是不减。这是本节最高频失分点。
2. **对称矩阵只存一半**：上三角区元素不存，访问时用 $a_{ij}=a_{ji}$ 换成 $a_{ji}$ 再套公式，不要另编公式。
3. **三角矩阵数组长度要 +1**：常量 $c$ 单独占一个单元，长度是 $\frac{n(n+1)}{2}+1$ 而非 $\frac{n(n+1)}{2}$；常量位置下标为 $\frac{n(n+1)}{2}$。
4. **三对角矩阵首末行只有 2 个元素**：长度 $3n-2$，不是 $3n$；推导时「前 $i-1$ 行」要减掉第 1 行少的那个 1。
5. **行优先 / 列优先看题目**：同一矩阵换存储顺序，公式全变，必须现推，不能套记忆中的式子。
6. **答题程度**：选择题只需选出正确 $k$；若考推导（如「写出 $k$ 与 $i,j$ 的关系」），要写出「前面有多少个元素 + 本行/列前面有几个 + 起点修正」三步，并注明数组下标起点假设，结论正确即给分。

## 7. 408 题型与解题套路

- **选择题（主流）**：给出 $n$、存储策略（行/列优先、存哪一半）、数组下标起点，求某元素的 $k$，或给出 $k$ 反求 $i,j$。
  - 套路：① 确认存的是哪块区域；② 数前面整行/整列元素数（等差数列）；③ 加本行/列前面个数得「第几个」；④ 按起点修正。
- **选择题（三对角反求）**：给 $k$ 求 $i,j$，用 $i=\lceil (k+2)/3\rceil$，$j=k-2i+3$；注意 $k$ 从 0 起。
- **算法题背景**：稀疏矩阵三元组表可能作为「矩阵转置/相加」题的存储结构出现，需会写三元组结构体并遍历。
- **常见陷阱**：把「第几个」直接当数组下标（忘减 1）；三角矩阵忘加常量单元；三对角矩阵按 $3n$ 算长度；行列优先混用。

## 8. 自测题

**1.** 将 $n$ 阶对称矩阵 $A$ 的下三角（含主对角线）按行优先存入一维数组 `sa`（下标从 0 开始），则 $a_{53}$（$i=5,j=3$）在 `sa` 中的下标为多少？

**2.** 上题若改为按**列优先**存下三角，$a_{53}$ 的下标为多少？（$n$ 阶，下标从 0 起）

**3.** $n$ 阶下三角矩阵（上三角区全为常量）压缩存储，一维数组至少需要多少个单元？常量存放在哪个下标？

**4.** 三对角矩阵 $A$（$|i-j|>1$ 时 $a_{ij}=0$）按行优先压缩存储，一维数组下标从 0 开始。已知某非零元素在数组中的下标 $k=8$，求其行号 $i$ 与列号 $j$。

**5.** 稀疏矩阵采用三元组顺序表存储，相比二维数组，主要得与失各是什么？

<details>
<summary>答案</summary>

1. $i\ge j$，$k=\frac{(5-1)\times5}{2}+(3-1)=10+2=12$。
2. 列优先存下三角：$a_{53}$ 前有第 1 列到第 2 列，元素数 $n+(n-1)=2n-1$；第 3 列中它前面有 $5-3=2$ 个；故它是第 $(2n-1)+2+1=2n+2$ 个，下标 $k=2n+1$。
3. 需 $\frac{n(n+1)}{2}+1$ 个单元；常量存放在下标 $\frac{n(n+1)}{2}$ 处（下标从 0 起）。
4. $i=\lceil (8+2)/3\rceil=\lceil 10/3\rceil=4$；$j=k-2i+3=8-8+3=3$。验证 $|4-3|=1\le1$，成立。
5. 得：空间由 $O(mn)$ 降为 $O(t)$（$t$ 为非零元素个数），适合稀疏矩阵；失：失去随机存取特性，按行列访问需顺序扫描三元组表，最坏 $O(t)$。

## 9. 背诵卡

1. 一维：$LOC(a[i])=LOC(a[0])+i\times L$；下标从 1 起则用 $(i-1)$。
2. 二维行优先：$LOC(b[i][j])=LOC+(i\times n+j)L$；列优先：$LOC+(j\times m+i)L$。
3. 对称矩阵存下三角（行优先、下标 0 起）：$k=\frac{(i-1)i}{2}+(j-1)$，$i<j$ 时换成 $a_{ji}$；长度 $\frac{n(n+1)}{2}$。
4. 三角矩阵长度 $\frac{n(n+1)}{2}+1$，常量在下标 $\frac{n(n+1)}{2}$；三对角矩阵长度 $3n-2$，$k=2i+j-3$，反求 $i=\lceil (k+2)/3\rceil$。
5. 所有公式现推三步：数前面整行/列 → 加本行/列前面个数 → 按数组下标起点修正；先看清行优先还是列优先。
