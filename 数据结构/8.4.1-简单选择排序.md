# 8.4.1 简单选择排序

## 1. 本节定位

- **王道书对应**：第 8 章「排序」→ 8.4 选择排序 → 8.4.1 简单选择排序。
- **408 大纲对应**：内部排序中的「选择排序（简单选择排序）」，要求掌握算法思想、执行过程、复杂度与稳定性。
- **先修知识**：顺序表的基本操作（交换元素）、「有序序列 / 无序序列」的划分思想、时间复杂度的基本推导。
- **本章位置**：选择排序大类的入门算法；下一节「堆排序」同属选择排序思想，是高频考点，本节是理解「每趟选最值」这一共性的基础。

## 2. 一句话结论

简单选择排序每趟从无序区选出关键字最小（或最大）的元素换到无序区首部，**n 个元素只需 n−1 趟**，时间恒为 $O(n^2)$、空间 $O(1)$、**不稳定**，且复杂度**不随初始序列状态改变**。

## 3. 知识地图

```
选择排序（大类思想：每趟在待排序元素中选关键字最小/最大的元素，加入有序序列）
├── 简单选择排序（本节）
│   ├── 执行过程：n−1 趟，每趟扫描无序区找最小，与无序区首元素交换
│   ├── 代码实现（基于顺序表）
│   ├── 性能：时间 O(n²)（与初始状态无关）、空间 O(1)
│   └── 稳定性：不稳定（交换会跨越相等元素）
└── 堆排序（下一节，高频考点，同属选择排序思想）
```

## 4. 核心内容

### 4.1 算法思想（定义）

将序列分为**有序区**（前部，已排好）与**无序区**（后部）。每一趟在无序区中扫描，选出关键字最小的元素，与无序区的第一个元素交换，使有序区长度 +1。重复至无序区只剩 1 个元素。

- 第 $i$ 趟（$i=1,2,\dots,n-1$）：在 $A[i..n]$ 中找最小元素，与 $A[i]$ 交换。
- 共进行 **$n-1$ 趟**；最后一趟结束后只剩 1 个元素，它必然是最大者，无需再处理。

### 4.2 执行过程（以讲解中的例子说明）

初始序列（无序）：`49, 38, 65, 97, 76, 13, 27, 49`

| 趟次 | 无序区 | 选出的最小元素 | 交换后结果（有序区加粗） |
|---|---|---|---|
| 第 1 趟 | 全部 | 13 | **13**, 38, 65, 97, 76, 49, 27, 49 |
| 第 2 趟 | 38 起 | 27 | **13, 27**, 65, 97, 76, 49, 38, 49 |
| 第 3 趟 | 65 起 | 38 | **13, 27, 38**, 97, 76, 49, 65, 49 |
| 第 4 趟 | 97 起 | 49（靠左的那个） | **13, 27, 38, 49**, 76, 97, 65, 49 |
| 第 5 趟 | 76 起 | 49（另一个） | **13, 27, 38, 49, 49**, 97, 65, 76 |
| 第 6 趟 | 97 起 | 65 | **13, 27, 38, 49, 49, 65**, 97, 76 |
| 第 7 趟 | 97 起 | 76 | **13, 27, 38, 49, 49, 65, 76**, 97 |

要点：
- 存在两个相等关键字（两个 49）时，**优先选先扫描到的（靠左的）**，这是「选最小」时的取法约定。
- 第 7 趟后只剩 97，必为最大，结束。故 $n=8$ 时只需 7 趟。

### 4.3 代码实现（C，王道风格，基于顺序表）

```c
// 对顺序表 A[0..n-1] 做简单选择排序（升序）
void SelectSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {      // 共 n-1 趟，i 指向无序区首位置
        int min = i;                        // 记录本趟最小元素的下标
        for (int j = i + 1; j < n; j++) {   // 在无序区 A[i+1..n-1] 中扫描
            if (A[j] < A[min])              // 严格小于才更新 → 相等时保留靠左者
                min = j;
        }
        if (min != i) {                     // 最小元素不在原位才交换
            int temp = A[i];
            A[i] = A[min];
            A[min] = temp;
        }
    }
}
```

- 外层循环 $i$ 从 $0$ 到 $n-2$，共 $n-1$ 趟；内层从 $i+1$ 扫到 $n-1$。
- 比较用 `<` 而非 `<=`：相等时不更新 `min`，保证选到靠左的相等元素（与讲解一致）。
- `if (min != i)` 只是减少无谓交换，不影响复杂度。

### 4.4 基于链表的适用性（王道书扩展 / 了解即可）

简单选择排序的思想对链表同样适用：每趟从头到尾扫描链表各结点关键字，挑出最小者，摘链后插入到结果链表的表头（或表尾）。实现细节为课后练习，408 一般不要求写链表版代码，但可能考「是否适用于链表」的判断。

## 5. 复杂度分析

### 5.1 空间复杂度

只需 `i, j, min, temp` 等常数个辅助变量，$S(n)=O(1)$。

### 5.2 时间复杂度

**比较次数**：第 $i$ 趟（$i$ 从 1 计）在无序区 $n-i+1$ 个元素中找最小，需比较 $n-i$ 次。总比较次数

$$
\sum_{i=1}^{n-1}(n-i)=(n-1)+(n-2)+\cdots+1=\frac{n(n-1)}{2}
$$

**交换次数**：每趟至多 1 次交换，共至多 $n-1$ 次，每次 $O(1)$。

因此总时间 $T(n)=\dfrac{n(n-1)}{2}+O(n)=O(n^2)$。

**关键结论：无论初始序列有序、逆序还是乱序，比较次数恒为 $\frac{n(n-1)}{2}$，交换次数只在常数范围内变化，故最好、最坏、平均时间复杂度均为 $O(n^2)$。**

- 最好情况（初始已有序）：仍需 $\frac{n(n-1)}{2}$ 次比较，交换 0 次，$O(n^2)$。
- 最坏情况（逆序）：比较 $\frac{n(n-1)}{2}$ 次，交换 $n-1$ 次，$O(n^2)$。
- 平均情况：由于比较次数与数据分布无关（是确定值），平均即 $O(n^2)$，无需概率假设。

> 对比提醒：直接插入排序、冒泡排序在初始有序时可降到 $O(n)$；简单选择排序**没有**这种「自适应」性质，这是它与前两者的本质区别，也是选择题常考点。

### 5.3 稳定性

**不稳定**。反例（讲解中给出）：序列 `2, 2, 1`（第一个 2 记为 $2_a$，第二个记为 $2_b$）。

- 第 1 趟：选出最小 1，与首元素 $2_a$ 交换 → `1, 2_b, 2_a`。
- 原本 $2_a$ 在 $2_b$ 左边，排序后 $2_a$ 跑到 $2_b$ 右边，相等元素的相对次序被破坏。

原因：交换是「远距离」的，会把无序区首部的元素直接甩到后面，跨过相等元素。

## 6. 易错点与考试写法

1. **趟数**：$n$ 个元素是 **$n-1$ 趟**，不是 $n$ 趟。最后一趟只剩一个元素，必为最大，不必处理。
2. **比较次数公式**：$\frac{n(n-1)}{2}$，与初始状态无关；不要与冒泡「最好 $n-1$ 次比较」混淆。
3. **稳定性判断**：简单选择排序**不稳定**；不要因为「名字简单」就默认稳定。反例用 `2, 2, 1` 最快。
4. **相等元素的选取**：代码用 `A[j] < A[min]`（严格小于），相等不更新，保证选靠左者；若写成 `<=` 会选靠右者，虽不影响排序结果正确性，但影响稳定性分析时的具体过程。
5. **「与初始状态无关」的准确表述**：指**比较次数**与**时间复杂度量级**不变；交换次数会随初始状态变化（有序时 0 次，逆序时 $n-1$ 次），不要绝对化。
6. **答题程度**：408 算法题若要求写简单选择排序，写出上述双层循环 + 交换即可；复杂度分析写「比较次数 $\frac{n(n-1)}{2}$，故 $O(n^2)$，与初始序列无关；空间 $O(1)$；不稳定，反例……」即满分。

## 7. 408 题型与解题套路

- **选择题（408 必考）**：
  - 给一个序列，问第 $k$ 趟排序后的结果 → 按「每趟选最小换到无序区首部」逐趟模拟，注意相等元素取靠左者。
  - 问比较次数 / 交换次数 → 比较恒为 $\frac{n(n-1)}{2}$；交换次数看具体序列（有序 0 次，逆序 $n-1$ 次）。
  - 问「时间复杂度是否受初始状态影响」→ 不受，恒 $O(n^2)$。
  - 问稳定性 → 不稳定，能举反例。
  - 与插入、冒泡、堆排序对比：谁稳定、谁自适应、谁比较次数固定。
- **算法题套路**：若题目要求「不稳定的 $O(n^2)$ 原地排序」或作为对照算法出现，直接默写 4.3 的代码；注意下标从 0 开始、循环边界 `i < n-1`、`j = i+1`。
- **常见陷阱**：
  - 把「$n-1$ 趟」写成「$n$ 趟」。
  - 认为有序时复杂度降为 $O(n)$（错，那是插入/冒泡）。
  - 认为简单选择排序稳定（错）。
  - 混淆「选择排序大类」与「简单选择排序」：堆排序也属选择排序思想，但实现与复杂度不同。

## 8. 自测题

**题 1** 对含 $n$ 个元素的序列做简单选择排序，共需多少趟？每趟做什么？

**题 2** 序列 `49, 38, 65, 97, 76, 13, 27, 49` 做简单选择排序，写出第 1 趟和第 2 趟结束后的序列。

**题 3** 简单选择排序的比较次数与初始序列有关吗？给出 $n$ 个元素时的总比较次数。

**题 4** 判断：简单选择排序是稳定的；初始序列有序时其时间复杂度为 $O(n)$。并说明理由。

**题 5** 简单选择排序与直接插入排序在「初始有序」情形下的时间复杂度分别是多少？这体现了什么区别？

<details>
<summary>参考答案</summary>

**题 1**：共 $n-1$ 趟。第 $i$ 趟在无序区 $A[i..n]$ 中扫描选出关键字最小的元素，与 $A[i]$ 交换，使有序区长度 +1。

**题 2**：第 1 趟选出 13 与首元素 49 交换 → `13, 38, 65, 97, 76, 49, 27, 49`；第 2 趟在剩余部分选出 27 与 38 交换 → `13, 27, 65, 97, 76, 49, 38, 49`。

**题 3**：无关。无论初始状态如何，第 $i$ 趟比较 $n-i$ 次，总比较次数 $\sum_{i=1}^{n-1}(n-i)=\frac{n(n-1)}{2}$。

**题 4**：两句都错。不稳定，反例 `2, 2, 1`：第 1 趟 1 与第一个 2 交换后，两个 2 的相对次序颠倒。初始有序时比较次数仍为 $\frac{n(n-1)}{2}$，时间复杂度仍为 $O(n^2)$，只是交换 0 次。

**题 5**：简单选择排序恒为 $O(n^2)$；直接插入排序在初始有序时为 $O(n)$（每趟只比较 1 次、不移动）。区别：插入排序具有「自适应」性，简单选择排序没有。

## 9. 背诵卡

1. 简单选择排序：每趟在无序区选最小，换到无序区首部；**$n$ 个元素 $n-1$ 趟**。
2. 比较次数恒为 $\frac{n(n-1)}{2}$，时间 **最好 = 最坏 = 平均 = $O(n^2)$**，**与初始状态无关**。
3. 空间 $O(1)$；交换至多 $n-1$ 次。
4. **不稳定**，反例 `2, 2, 1`（交换跨越相等元素）。
5. 代码：`for i=0..n-2`，内层 `j=i+1..n-1` 找最小下标 `min`，`A[i]` 与 `A[min]` 交换；比较用 `<` 取靠左相等元素。

## 10. 关联与下一节

- **向前关联**：与直接插入排序、冒泡排序对比——后两者初始有序时可降到 $O(n)$，简单选择排序不能；三者同为 $O(n^2)$ 量级，但稳定性不同（插入、冒泡稳定，简单选择不稳定）。
- **向后关联**：下一节 **堆排序** 同属「选择排序」大类，但用堆结构把「每趟选最值」从 $O(n)$ 降到 $O(\log n)$，总时间 $O(n\log n)$，是 408 高频考点；本节「每趟选最值」的思想是理解堆排序的起点。
- **扩展**：简单选择排序思想可推广到链表存储（每趟扫描链表选最小结点，摘链插入结果链），为课后练习，408 了解即可。
