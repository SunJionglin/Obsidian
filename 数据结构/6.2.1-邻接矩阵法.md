# 6.2.1 邻接矩阵法

## 1. 本节定位

- **对应王道书**：第 6 章「图」→ 6.2「图的存储及基本操作」→ 6.2.1 邻接矩阵法。
- **408 大纲对应**：图的存储结构（邻接矩阵法），属「图」这一章的基础存储结构条目。
- **先修知识**：图的定义（顶点集 $V$、边集 $E$）、无向图/有向图/网（带权图）的概念、二维数组、对称矩阵的压缩存储。
- **本节位置**：本章四种存储结构的**第一种**（邻接矩阵法、邻接表法、十字链表、邻接多重表）。后续所有图算法（BFS/DFS、Prim、Kruskal、Dijkstra、拓扑排序等）都建立在存储结构之上，本节是整章的起点。

## 2. 一句话结论

邻接矩阵用一个 $n\times n$ 的二维数组存边：$A[i][j]=1$ 表示顶点 $i$ 到 $j$ 有边（无权图），带权图则存权值、无边存 $\infty$；无向图矩阵对称，空间复杂度 $O(n^2)$，适合稠密图。

## 3. 知识地图

```
邻接矩阵法
├── 存储结构
│   ├── 顶点表：一维数组 vex[]，存顶点信息（下标 i 对应矩阵第 i 行/列）
│   └── 边表：二维数组 edge[n][n]
├── 元素含义
│   ├── 无权图：1 = 有边/有弧，0 = 无边
│   ├── 带权图（网）：权值 = 有边，∞ = 无边（可用 int 最大值宏定义）
│   └── 补充约定：对角线有时置 0 或 ∞，均表示「无自环边」
├── 图类型差异
│   ├── 无向图：矩阵对称，一条边对应两个 1
│   └── 有向图：一般不对称，一条弧对应一个 1
├── 度的计算
│   ├── 无向图：度 = 第 i 行（或第 i 列）非零元个数
│   └── 有向图：出度 = 第 i 行非零元个数；入度 = 第 i 列非零元个数；度 = 出度 + 入度
├── 性能
│   ├── 空间复杂度 O(n²)（顶点表 O(n) 被支配）
│   └── 适合稠密图；无向图可只存上/下三角压缩
└── 性质（无权图）
    └── A^k 的 A^k[i][j] = 顶点 i 到 j 长度为 k 的路径条数
```

## 4. 核心内容

### 4.1 定义与元素含义

设图 $G=(V,E)$，$|V|=n$。邻接矩阵 $A$ 是 $n\times n$ 矩阵：

- **无权图**：
  $$A[i][j]=\begin{cases}1, & (v_i,v_j)\in E \text{ 或 } \langle v_i,v_j\rangle\in E\\ 0, & \text{否则}\end{cases}$$
- **带权图（网）**：$A[i][j]=w_{ij}$（边权），无边时 $A[i][j]=\infty$。

**关键对应关系**：顶点在顶点表数组中的**下标** $i$，就是它在邻接矩阵中的**行号/列号**。判断 $a$ 与 $b$ 是否有边，就是查 $A[a的下标][b的下标]$。这是本节所有操作的根基，务必记牢「下标 ↔ 行列」一一对应。

**无向图 vs 有向图**：
- 无向图每条边 $(v_i,v_j)$ 无方向，故 $A[i][j]=A[j][i]=1$，矩阵**对称**，一条边贡献**两个 1**。
- 有向图每条弧 $\langle v_i,v_j\rangle$ 有方向，只置 $A[i][j]=1$，$A[j][i]$ 未必为 1，矩阵**一般不对称**，一条弧贡献**一个 1**。

### 4.2 存储结构定义（C 语言，王道风格）

```c
#define MaxVertexNum 100        // 顶点数目的最大值
#define INF 0x3f3f3f3f          // 宏定义"无穷"，表示带权图中两顶点无边

typedef char VertexType;        // 顶点数据类型（可换成更复杂的结构体）

typedef struct {
    VertexType vex[MaxVertexNum];          // 顶点表：存顶点信息
    int edge[MaxVertexNum][MaxVertexNum];  // 邻接矩阵：存边/弧信息
    int vexnum, arcnum;                    // 图的当前顶点数和边（弧）数
} MGraph;
```

**说明**：
- 顶点表 `vex[]` 的下标 $i$ 与矩阵第 $i$ 行、第 $i$ 列对应。
- 矩阵元素类型：无权图只需 0/1 两种状态，可把 `int` 换成 `bool` 或枚举类型以省空间（`int` 常占 4 字节，`bool` 占 1 字节）；带权图则用 `int` 或 `float` 存权值。
- 「无穷」用宏定义常量实现，如取 `int` 上限；不要用 `INT_MAX` 直接参与加法运算（易溢出），考试写 `INF` 宏即可。

### 4.3 度的计算（重点，选择题高频）

| 图类型 | 求什么 | 做法 |
|---|---|---|
| 无向图 | 顶点 $v_i$ 的度 | 数第 $i$ **行**（或第 $i$ 列）非零元个数 |
| 有向图 | 顶点 $v_i$ 的出度 | 数第 $i$ **行**非零元个数 |
| 有向图 | 顶点 $v_i$ 的入度 | 数第 $i$ **列**非零元个数 |
| 有向图 | 顶点 $v_i$ 的度 | 出度 + 入度 = 第 $i$ 行非零元数 + 第 $i$ 列非零元数 |

**记忆口诀**：**行出列入**（有向图），无向图行列等价。每次都要扫一整行/列，故单次求度为 $O(n)$。

### 4.4 邻接矩阵的幂与路径条数（性质，408 必考）

设 $A$ 为**无权图**的邻接矩阵，则 $A^k$ 中元素
$$(A^k)[i][j] = \text{顶点 } i \text{ 到顶点 } j \text{ 长度为 } k \text{ 的路径条数}$$

**推导思路（矩阵乘法展开）**：以 $k=2$ 为例，
$$(A^2)[i][j]=\sum_{m=1}^{n}A[i][m]\cdot A[m][j]$$
每一项 $A[i][m]\cdot A[m][j]$ 为 1 当且仅当「$i\to m$ 有边」且「$m\to j$ 有边」，即存在一条 $i\to m\to j$ 的长度 2 路径；对所有中间点 $m$ 求和，正是长度为 2 的路径条数。$k$ 次方同理，用归纳法可证。

**例子（视频原图，无向图，顶点 a,b,c,d,e 下标 0~4）**：
- $(A^2)[a][d]=1$：a 到 d 长度为 2 的路径只有 $a\to b\to d$ 一条。
- $(A^2)[b][b]=3$：b 到 b 长度为 2 的路径有 $b\to a\to b$、$b\to c\to b$、$b\to d\to b$ 三条（简单图无自环，$b\to b\to b$ 不计）。
- $(A^3)[a][d]=1$：a 到 d 长度为 3 的路径只有 $a\to c\to b\to d$ 一类（拼接「长度 2 段 + 长度 1 段」）。

**注意**：该性质只对**无权图（0/1 矩阵）**成立；带权图矩阵的幂没有「路径条数」含义。

### 4.5 带权图的特殊约定

- 对角线元素：有的实现把顶点到自身的距离置 0（如最短路算法初始化），有的置 $\infty$。做题时若见「0 或 ∞ 都表示无边」，按题目约定理解即可（视频提到此点，属了解即可）。
- 带权图求「度」不再数非零元，而是看与顶点相连的边数（权值非 $\infty$ 即相连），考试一般不在此设陷阱。

## 5. 复杂度分析

**空间复杂度**：
- 顶点表一维数组：$O(n)$。
- 邻接矩阵二维数组：$n\times n$ 个元素，$O(n^2)$。
- 取高阶：$O(n^2)$。**与边数 $e$ 无关**，这是邻接矩阵与邻接表的本质区别。

**求某顶点度/出度/入度的时间复杂度**：
- 最好/最坏/平均均为 $O(n)$：必须扫描整行或整列共 $n$ 个元素，与数据分布无关，无平均情况之分。
- 若求所有顶点的度：$O(n^2)$（扫整个矩阵）。

**判断两顶点是否相邻**：$O(1)$，直接取 $A[i][j]$，这是邻接矩阵相对邻接表的优势。

**适用性**：适合**稠密图**（$e$ 接近 $n^2$）；稀疏图（$e\ll n^2$）会浪费大量 0 元素空间。无向图矩阵对称，可只存上三角或下三角，空间降为约 $n(n+1)/2$，即 $O(n^2)$ 常数减半（王道书扩展，408 一般不深究压缩后的下标公式，但要知道「可利用对称性压缩」）。

## 6. 易错点与考试写法

1. **下标从 0 还是 1 开始**：C 语言数组下标从 0 开始，顶点 $v_1$ 存在 `vex[0]`，对应矩阵第 0 行/列。题目若用「$v_1,v_2,\dots$」编号，务必换算：$v_i$ 对应下标 $i-1$。这是最高频失分点。
2. **无向图一条边两个 1，有向图一条弧一个 1**：数非零元总数时，无向图非零元个数 $=2e$，有向图 $=e$（不含对角线）。选择题常在此设「矩阵中 1 的个数」陷阱。
3. **有向图求度别只数一行**：度 = 出度 + 入度 = 行非零元 + 列非零元，漏掉列就错。
4. **$A^k$ 性质只对无权图**：带权图不适用；且 $k$ 是路径**长度（边数）**，不是顶点数。
5. **「无穷」的表示**：答题写「用宏定义常量 `INF` 表示无穷，如取 `int` 最大值」，不要写具体魔数；也不要用 `INT_MAX` 做加法。
6. **答题写到什么程度算对**：408 中本节以选择题为主，答「空间复杂度 $O(n^2)$、适合稠密图、无向图对称、行出列入、$A^k$ 数路径条数」这些结论性语句即可；若考代码填空，结构体定义中顶点表 + 二维数组 + `vexnum/arcnum` 三要素齐全即得分。

## 7. 408 题型与解题套路

- **选择题（主流）**：
  - 给一个图，问邻接矩阵中 1 的个数 → 无向图 $2e$，有向图 $e$。
  - 给矩阵，问某顶点度/出度/入度 → 行出列入，注意下标换算。
  - 问空间复杂度、适合稠密还是稀疏图 → $O(n^2)$、稠密图。
  - 给 $A^k$ 某元素值，问路径条数 → 直接读值，注意是无权图。
  - 判断矩阵对称性 → 无向图必对称，有向图未必。
- **算法题（间接考）**：邻接矩阵常作为 BFS/DFS、Prim、Dijkstra 的输入结构出现，需会写「遍历第 $i$ 行找邻接点」的循环：
  ```c
  for (int j = 0; j < G.vexnum; j++)
      if (G.edge[i][j] != 0 && G.edge[i][j] != INF) { /* j 是 i 的邻接点 */ }
  ```
- **常见陷阱**：把「矩阵元素个数 $n^2$」与「非零元个数」混淆；带权图把 $\infty$ 当成 0 处理；$A^2$ 的对角元误以为一定是 0（简单图无自环时 $A[i][i]=0$，但 $A^2[i][i]$ 可非零，表示绕一圈回来的路径数）。

## 8. 自测题

**题 1** 无向图有 $n$ 个顶点、$e$ 条边，其邻接矩阵中 1 的个数是多少？若为有向图呢？

**题 2** 有向图邻接矩阵第 $i$ 行有 3 个 1、第 $i$ 列有 2 个 1，顶点 $v_i$ 的出度、入度、度各是多少？

**题 3** 某无权图邻接矩阵 $A$ 满足 $(A^2)[2][5]=4$，说明什么？

**题 4** 为什么邻接矩阵适合稠密图而不适合稀疏图？空间复杂度是多少，如何推导？

**题 5** 无向图邻接矩阵一定是对称矩阵吗？有向图呢？利用对称性可做什么优化？

<details>
<summary>参考答案</summary>

**题 1** 无向图每条边贡献两个 1，共 $2e$ 个；有向图每条弧贡献一个 1，共 $e$ 个（均不计对角线自环）。

**题 2** 出度 = 行非零元数 = 3；入度 = 列非零元数 = 2；度 = 3 + 2 = 5。

**题 3** 顶点 $v_2$（下标 2）到 $v_5$（下标 5）长度为 2 的路径共有 4 条。

**题 4** 空间复杂度 $O(n^2)$：顶点表 $O(n)$，矩阵 $n\times n$ 个元素 $O(n^2)$，取高阶得 $O(n^2)$，与边数无关。稀疏图 $e\ll n^2$ 时矩阵中大量 0 被浪费；稠密图 $e$ 接近 $n^2$ 时空间利用率高，且判邻接 $O(1)$。

**题 5** 无向图邻接矩阵一定对称（$A[i][j]=A[j][i]$）；有向图一般不对称。可利用对称性只存上三角或下三角，空间约降为 $n(n+1)/2$。

</details>

## 9. 背诵卡

1. 邻接矩阵 = 顶点表（一维）+ 边表（$n\times n$ 二维），**下标 ↔ 行列**一一对应。
2. 无权图 1/0 表有无边；带权图存权值、无边存 $\infty$（宏定义 `INF`）。
3. 无向图对称、一边两个 1；有向图不对称、一弧一个 1。
4. **行出列入**：有向图出度数行、入度数列入；无向图度 = 行（列）非零元数。
5. 空间 $O(n^2)$、适合稠密图；无权图 $A^k[i][j]$ = $i$ 到 $j$ 长度为 $k$ 的路径条数。
