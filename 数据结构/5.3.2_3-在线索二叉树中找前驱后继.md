# 5.3.2_3 在线索二叉树中找前驱后继

## 1. 本节定位

- **对应王道书**：第 5 章「树与二叉树」→ 5.3「二叉树的遍历与线索二叉树」→ 5.3.2 线索二叉树（找前驱/后继部分）。
- **408 大纲对应**：二叉树的遍历、线索二叉树的基本概念与构造（找前驱后继属于线索化的目的与使用）。
- **先修知识**：二叉树链式存储结构（`lchild`、`rchild`、`ltag`、`rtag`）、三种遍历顺序（先序根左右、中序左根右、后序左右根）、线索化的含义（`tag=1` 表示指针为线索，`tag=0` 表示指向孩子）。
- **本节位置**：上一节讲「如何线索化」，本节讲「线索化之后怎么用」——即给定结点 `p`，如何找它的前驱/后继。这是线索二叉树存在的**唯一目的**，也是选择题高频考点。

## 2. 一句话结论

**中序线索二叉树找前驱、后继都方便；先序线索二叉树只能方便找后继（找前驱需三叉链表或从头遍历）；后序线索二叉树只能方便找前驱（找后继需三叉链表或从头遍历）。**

## 4. 核心内容

### 4.1 线索二叉树结点结构（复习）

```c
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;   // 1 表示线索，0 表示孩子
} ThreadNode, *ThreadTree;
```

- `ltag == 1`：`lchild` 指向**前驱**；`ltag == 0`：`lchild` 指向左孩子。
- `rtag == 1`：`rchild` 指向**后继**；`rtag == 0`：`rchild` 指向右孩子。

### 4.2 中序线索二叉树

#### （1）找中序后继 `NextNode(p)`

- 若 `p->rtag == 1`：`rchild` 就是后继，直接返回。
- 若 `p->rtag == 0`：`p` 必有右子树，中序后继是**右子树中最左下的结点**（右子树中第一个被中序访问的结点）。

```c
// 求以 p 为根的子树中，中序遍历第一个被访问的结点（最左下）
ThreadNode *FirstNode(ThreadNode *p) {
    while (p->ltag == 0)   // 有左孩子就一路向左
        p = p->lchild;
    return p;
}

// 找 p 的中序后继
ThreadNode *NextNode(ThreadNode *p) {
    if (p->rtag == 1)      // 已是线索，直接返回
        return p->rchild;
    else                   // 有右子树，取右子树最左下
        return FirstNode(p->rchild);
}
```

#### （2）利用 `NextNode` 实现非递归中序遍历（空间 $O(1)$）

```c
void InOrder(ThreadTree T) {
    for (ThreadNode *p = FirstNode(T); p != NULL; p = NextNode(p))
        visit(p);
}
```

> 关键：不需要栈，空间复杂度 $O(1)$，这是线索二叉树相对普通二叉树的优势。

#### （3）找中序前驱 `PreNode(p)`

- 若 `p->ltag == 1`：`lchild` 就是前驱。
- 若 `p->ltag == 0`：`p` 必有左子树，中序前驱是**左子树中最右下的结点**（左子树中最后一个被中序访问的结点）。

```c
// 求以 p 为根的子树中，中序遍历最后一个被访问的结点（最右下）
ThreadNode *LastNode(ThreadNode *p) {
    while (p->rtag == 0)   // 有右孩子就一路向右
        p = p->rchild;
    return p;
}

ThreadNode *PreNode(ThreadNode *p) {
    if (p->ltag == 1)
        return p->lchild;
    else
        return LastNode(p->lchild);
}
```

> 同理可实现**逆向中序遍历**（从最后一个结点出发反复取前驱）。

### 4.3 先序线索二叉树

#### （1）找先序后继 `NextNode(p)`

- 若 `p->rtag == 1`：直接返回 `rchild`。
- 若 `p->rtag == 0`：`p` 有右子树，但**是否有左孩子不确定**，分两种：
  - 有左孩子（`ltag == 0`）：先序为「根左右」，后继是**左孩子**。
  - 无左孩子（`ltag == 1`）：先序为「根右」，后继是**右孩子**。

```c
ThreadNode *NextNode_Pre(ThreadNode *p) {
    if (p->rtag == 1)
        return p->rchild;
    if (p->ltag == 0)      // 有左孩子
        return p->lchild;
    else                   // 无左孩子，必有右孩子
        return p->rchild;
}
```

#### （2）找先序前驱——**难点**

- 若 `p->ltag == 1`：直接返回 `lchild`。
- 若 `p->ltag == 0`：`p` 有左孩子。先序为「根左右」，`p` 的左、右子树中所有结点都是 `p` 的**后继**，不可能是前驱；而线索二叉树只有指向孩子的指针，无法回溯。**结论：在先序线索二叉树中，`ltag == 0` 时找不到先序前驱。**

**补救方案一：三叉链表（带 `parent` 指针）**（王道书扩展）

设 `p` 有父结点 `parent`：

| 情形 | 先序前驱 |
|---|---|
| `p` 是根 | 无前驱 |
| `p` 是父的左孩子 | `parent` |
| `p` 是父的右孩子且父无左孩子 | `parent` |
| `p` 是父的右孩子且父有左孩子 | 父的左子树中**先序遍历最后一个结点** |

> 左子树中先序最后访问的结点：从该子树根出发，**优先向右走，右走不通再向左走**，到达的最底层结点。

**补救方案二**：从头做一次完整先序遍历，用 `pre` 指针记录前驱，找到 `p` 时输出 `pre`。时间 $O(n)$。

### 4.4 后序线索二叉树

#### （1）找后序前驱 `PreNode(p)`

- 若 `p->ltag == 1`：直接返回 `lchild`。
- 若 `p->ltag == 0`：`p` 有左子树，但**是否有右孩子不确定**：
  - 有右孩子（`rtag == 0`）：后序为「左右根」，前驱是**右孩子**。
  - 无右孩子（`rtag == 1`）：后序为「左根」，前驱是**左孩子**。

```c
ThreadNode *PreNode_Post(ThreadNode *p) {
    if (p->ltag == 1)
        return p->lchild;
    if (p->rtag == 0)      // 有右孩子
        return p->rchild;
    else                   // 无右孩子，必有左孩子
        return p->lchild;
}
```

#### （2）找后序后继——**难点**

- 若 `p->rtag == 1`：直接返回 `rchild`。
- 若 `p->rtag == 0`：`p` 有右孩子。后序为「左右根」，`p` 的左右子树中所有结点都是 `p` 的**前驱**，不可能是后继；无法回溯。**结论：在后序线索二叉树中，`rtag == 0` 时找不到后序后继。**

**补救方案一：三叉链表**（王道书扩展）

| 情形 | 后序后继 |
|---|---|
| `p` 是根 | 无后继 |
| `p` 是父的右孩子 | `parent` |
| `p` 是父的左孩子且父无右孩子 | `parent` |
| `p` 是父的左孩子且父有右孩子 | 父的右子树中**后序遍历第一个结点** |

> 右子树中后序第一个访问的结点：从该子树根出发，**优先向左走，左走不通再向右走**，到达的最底层结点。

**补救方案二**：从头做一次完整后序遍历，记录 `pre`，找到 `p` 时输出 `pre`。时间 $O(n)$。

### 4.5 总表（背诵用）

| 线索类型 | 找前驱 | 找后继 |
|---|---|---|
| 中序 | ✅ 方便（`ltag==1` 直接取；否则左子树最右下） | ✅ 方便（`rtag==1` 直接取；否则右子树最左下） |
| 先序 | ❌ `ltag==0` 时不行（需三叉链表/从头遍历） | ✅ 方便（`rtag==1` 直接取；否则有左取左，无左取右） |
| 后序 | ✅ 方便（`ltag==1` 直接取；否则有右取右，无右取左） | ❌ `rtag==0` 时不行（需三叉链表/从头遍历） |

> 记忆口诀：**中序双向通；先序只向后；后序只向前。**

## 5. 复杂度分析

设树有 $n$ 个结点，树高 $h$。

- **`NextNode` / `PreNode` 单次调用**：
  - 最好：`tag == 1`，直接返回，$O(1)$。
  - 最坏：`tag == 0`，需沿左（或右）链走到最左下（最右下），走 $O(h)$ 步，即 $O(h)$；退化成单支树时 $h = n$，为 $O(n)$。
  - 平均：假设树**随机形态**、各结点等概率被查询，则平均路径长度与树的平均深度同阶，平衡树情形下 $O(\log n)$；一般二叉树平均 $O(\sqrt{n})$ 量级（随机 BST 结论，仅作参考，408 不要求推导）。**408 只要求会分析最好/最坏，平均一般不考。**
- **整棵中序线索树的中序遍历**：`FirstNode` 一次 $O(h)$，之后 $n-1$ 次 `NextNode`。每次 `NextNode` 沿右子树左链下行，但**每条边在整趟遍历中至多被下降一次**（摊还分析），总时间 $O(n)$；空间 $O(1)$（无栈）。
- **三叉链表补救**：找父 $O(1)$，再求「左子树先序最后结点」或「右子树后序第一结点」最坏 $O(h)$。
- **从头遍历补救**：$O(n)$ 时间，$O(h)$ 栈空间（递归）或 $O(1)$（Morris 类，408 不要求）。

## 6. 易错点与考试写法

1. **`tag` 的含义别记反**：`tag == 1` 是**线索**（指向前驱/后继），`tag == 0` 是**孩子**。选择题常把 0/1 对调设陷阱。
2. **中序后继是「右子树最左下」，不是「右孩子」**：只有右孩子本身无左孩子时才恰好是右孩子。
3. **先序找后继要判 `ltag`**：`rtag == 0` 只说明有右子树，**不能直接返回右孩子**，必须先看有没有左孩子。这是最高频错点。
4. **后序找前驱要判 `rtag`**：对称地，`ltag == 0` 只说明有左子树，必须先看有没有右孩子。
5. **「找不到」的准确表述**：不是「不存在前驱」，而是「在只有孩子指针的二叉链表线索树中，无法直接求得」；用三叉链表或从头遍历仍可求。答题时要写清前提。
6. **答题标准**：
   - 选择题：能根据 `tag` 值和有无左右孩子，快速判断走哪条分支。
   - 算法题：写出 `FirstNode`/`LastNode` + `NextNode`/`PreNode` 的完整 C 代码，注释标清 `tag` 判断；分析时空复杂度。**不要求默写三叉链表版本**，但要知道思路。
   - 简答题：能画出「先序/后序找不到」的反例图（如先序中 `p` 有左孩子时，其前驱无法由 `p` 直接得到）。

## 7. 408 题型与解题套路

- **选择题（高频）**：
  - 给一棵具体线索树（画出 `tag`），问某结点的前驱/后继是谁 → 按 `tag` 分支走。
  - 问「先序线索树中找前驱，最坏时间复杂度」→ 答 $O(n)$（从头遍历）。
  - 问「哪种线索树可双向遍历」→ 中序。
  - 陷阱：把「中序后继 = 右孩子」当结论；把 `tag` 值记反。
- **算法题（中频）**：
  - 写「中序线索二叉树非递归遍历」→ 套 `FirstNode` + `NextNode` 循环。
  - 写「求某结点在中序线索树中的后继」→ 套 `NextNode`。
  - 可能要求「不用栈、空间 $O(1)$」——正是线索树的卖点。
- **常见陷阱**：
  - 先序/后序「找不到」的情形，题目问「能否找到」时要答「`ltag==0`（或 `rtag==0`）时不能」。
  - 三叉链表版本中，判断 `p` 是左孩子还是右孩子、兄弟是否为空，四种情况要列全。

## 8. 自测题

**1.** 中序线索二叉树中，结点 `p` 的 `rtag == 0`，则 `p` 的中序后继是（ ）。
A. `p->rchild`　B. `p` 右子树中最左下结点　C. `p` 右子树中最右下结点　D. 不存在

**2.** 先序线索二叉树中，结点 `p` 的 `rtag == 0` 且 `ltag == 0`，则 `p` 的先序后继是（ ）。
A. `p->rchild`　B. `p->lchild`　C. `p` 右子树最左下　D. 找不到

**3.** 下列线索二叉树中，给定任一结点都能**直接**（不借助三叉链表、不重新遍历）找到前驱和后继的是（ ）。
A. 先序线索树　B. 中序线索树　C. 后序线索树　D. 都不行

**4.** 后序线索二叉树中，`p` 的 `rtag == 0`，能否直接找到 `p` 的后序后继？为什么？

**5.** 写出在中序线索二叉树中找结点 `p` 前驱的 C 函数（含辅助函数），并说明最坏时间复杂度。

<summary>答案</summary>

**1. B**。`rtag == 0` 表示有右子树，中序后继为右子树中最左下结点（右子树中第一个被中序访问的结点）。

**2. B**。`rtag == 0` 说明有右子树，`ltag == 0` 说明有左孩子；先序「根左右」，后继为左孩子。

**3. B**。中序线索树前驱后继都能直接求；先序树 `ltag==0` 时找不到前驱；后序树 `rtag==0` 时找不到后继。

**4. 不能直接找到。** `rtag == 0` 说明 `p` 有右子树，后序「左右根」中 `p` 的左右子树结点都是 `p` 的前驱，后继在 `p` 之上；而线索树只有指向孩子的指针，无法回溯到父结点，故无法直接求。需借助三叉链表的 `parent` 指针，或从头做一次后序遍历。

**5.**
```c
ThreadNode *LastNode(ThreadNode *p) {   // 子树中序最后一个结点（最右下）
    while (p->rtag == 0)
        p = p->rchild;
    return p;
}
ThreadNode *PreNode(ThreadNode *p) {
    if (p->ltag == 1)
        return p->lchild;               // 线索直接指向前驱
    else
        return LastNode(p->lchild);     // 左子树最右下
}
```
最坏时间复杂度 $O(h)$，$h$ 为树高；退化成单支树时 $O(n)$。

## 9. 背诵卡

1. **中序**：后继 = `rtag==1 ? rchild : 右子树最左下`；前驱 = `ltag==1 ? lchild : 左子树最右下`。双向可通。
2. **先序**：后继 = `rtag==1 ? rchild : (ltag==0 ? lchild : rchild)`；前驱在 `ltag==0` 时**求不出**（需三叉链表/从头遍历）。
3. **后序**：前驱 = `ltag==1 ? lchild : (rtag==0 ? rchild : lchild)`；后继在 `rtag==0` 时**求不出**（需三叉链表/从头遍历）。
4. **口诀**：中序双向通，先序只向后，后序只向前。
5. **三叉链表补救**：先序前驱看「是否父的左孩子 / 父有无左孩子」；后序后继看「是否父的右孩子 / 父有无右孩子」，共四种情况。
