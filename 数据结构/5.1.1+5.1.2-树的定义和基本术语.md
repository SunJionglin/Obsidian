# 5.1.1+5.1.2 树的定义和基本术语

## 1. 本节定位

- **对应王道书**：第 5 章「树与二叉树」5.1 节开头部分（树的定义、基本术语）。
- **408 大纲对应**：树与二叉树——树的基本概念（树的定义、基本术语）。
- **先修知识**：线性表中「前驱 / 后继」的概念（本节反复借用）。
- **本章位置**：全章总起。先建立「树」这种**分层、分支、一对多**的逻辑结构，再引出特殊形态——二叉树（后续小节重点）。本节术语是后面所有树/二叉树题目的语言基础。

## 2. 一句话结论

树是 $n(n\ge 0)$ 个节点的有限集合，**非空树有且仅有一个根节点，除根外每个节点有且仅有一个前驱（双亲），子树互不相交**——它是递归定义的数据结构。

## 3. 知识地图

```

│  ├─ 空树（n = 0）

│  ├─ 分层、分支、一对多
│  ├─ 根：无前驱
│  ├─ 其余节点：有且仅有一个前驱
│  ├─ 叶子节点：无后继（终端节点）
│  └─ 分支节点：有后继（非终端节点）
├─ 递归定义
│  └─ 树 = 根节点 + 若干棵互不相交的子树
├─ 节点关系术语

│  ├─ 兄弟 / 堂兄弟
```

## 4. 核心内容

### 1. 树的定义（递归定义）

- **树**：$n$ 个节点的有限集合。$n=0$ 时称为**空树**；$n>0$ 时为非空树，满足：
  1. 有且仅有一个特定的**根节点（root）**；
  2. 其余节点可分为若干**互不相交**的有限集合，每个集合本身又是一棵树，称为根的**子树（subtree）**。
- 因此「树 = 根 + 若干互不相交的子树」是**递归定义**，这是后面写递归算法的依据。

### 2. 逻辑结构特性（与线性表对比）

| 结构 | 前驱 | 后继 |
|---|---|---|
| 线性表 | 除首元素外各一个 | 除尾元素外各一个 |
| 树 | 除根外**各一个** | 可有**零个或多个** |

- 若某节点有**多个前驱**（如两节点间多连一条边），则**不是树**，而是**图 / 网**。这是判断题的高频陷阱。
- 根节点无前驱；叶子节点无后继。

### 3. 节点关系术语（结合「家谱」理解）

- **祖先**：从该节点向上走到根，路径上经过的所有节点（不含自身，按王道习惯）。
- **子孙**：以该节点为根的子树中所有节点。
- **双亲（父节点）**：该节点的**直接前驱**。
- **孩子**：该节点的**直接后继**。
- **兄弟**：同一双亲的孩子。
- **堂兄弟**：双亲在同一层的节点（即同一层的节点）。⚠️ 该术语使用频率低，题目出现时通常只想表达「两节点在同一层」。

### 4. 路径与路径长度

- 树中的边视为**有向边，只能自上而下**。
- **路径**：只能从祖先到子孙方向存在；反向（子孙→祖先）**不存在路径**。
- **路径长度**：路径上**边的条数**（不是节点数）。

### 5. 层次、高度、度

- **节点的层次（深度）**：从根往下数，根为第 1 层。⚠️ 部分教材从 0 开始，题目若声明「从 0 开始」按题目来；默认从 1。
- **节点的高度**：从下往上数，叶子高度为 1。
- **树的高度（深度）**：树中节点的最大层次 = 总层数。
- **节点的度**：该节点的**孩子个数**（分支数）。度为 0 ⇔ 叶子节点。
- **树的度**：树中所有节点度的**最大值**。

> 408 必考：节点的度、树的度是大量计数题的出题条件（如「度为 3 的树中，度为 0/1/2/3 的节点数关系」），下一小节展开。

### 6. 有序树与无序树

- **有序树**：各子树从左至右**有次序、不可互换**（如家谱按出生顺序）。
- **无序树**：子树次序可互换（如行政区划分）。
- 判定依据：是否需要**左右位置关系承载逻辑含义**。

### 7. 森林

- **森林**：$m$（$m\ge 0$）棵**互不相交**的树的集合；$m=0$ 为空森林。
- 森林 + 一个虚拟根 = 一棵树；树去掉根 = 森林。此转换是后续重要考点。

### 8. 典型应用（了解即可）

行政区划分、文件系统目录、思维导图、家谱——均为树形结构。

## 5. 复杂度分析

本节为**概念定义课，无算法、无代码**，不涉及时间复杂度。若强行对应：判断「是否为树」需检查每个非根节点前驱数是否为 1，遍历所有边即可，$O(n)$（$n$ 为节点数）——**补充**，非本节讲解内容，仅作理解。

## 6. 易错点与考试写法

1. **「每个节点只有一个前驱」≠「每个节点只有一个后继」**：树是「一前驱、多后继」，说成「一前驱一后继」即错（那是线性表）。
2. **多前驱 → 不是树**：出现节点有两个双亲，该结构是图/网。判断题常画一条「交叉边」设陷阱。
3. **路径单向**：从子孙到祖先**不存在路径**；路径长度数**边**不数节点。
4. **层次默认从 1 开始**：题目未说明按 1；若题目写「根为第 0 层」，则整棵树高度随之变化，务必看题干。
5. **树的度是最大值**，不是各节点度之和，也不是平均值。
6. **空树合法**：$n=0$ 是树；空森林也合法。不要因「没有根」判错。
7. **答题程度**：概念题答出「有且仅有一个根、其余节点有且仅有一个前驱、子树互不相交」三点即满分；术语题按定义一句话作答，不必展开。

## 7. 408 题型与解题套路

- **选择题（主力）**：
  - 给一张图判断「是否为树」→ 查是否有节点多前驱 / 是否有回路。
  - 给家谱式图问「某节点的祖先/兄弟/堂兄弟/度/层次」→ 按定义逐个数，注意祖先不含自身。
  - 问「树的度」→ 遍历所有节点取最大孩子数。
  - 问「路径长度」→ 数边。
- **判断题陷阱**：把「前驱」与「后继」对调；把「堂兄弟」说成「兄弟」；层次从 0 起算却不说明。
- **为后续铺垫**：本节术语是「节点数 = 总度数 + 1」「$n_0=n_2+1$」等计数公式的语言基础，下一小节直接用。

## 8. 自测题

**1.** 一棵非空树中，除根节点外，每个节点的前驱个数是（ ）。
A. 0 个　B. 1 个　C. 至少 1 个　D. 任意个

**2.** 判断：树中任意两个节点之间都存在路径。

**3.** 某树中节点 A 有 3 个孩子，节点 B 有 2 个孩子，其余节点均为叶子，则这棵树的度是多少？

**4.** 从根到某叶子的路径上共有 5 个节点，该路径长度是多少？该叶子的层次是多少？

**5.** 森林与树的关系是什么？如何由森林得到一棵树？

<details>
<summary>答案与解析</summary>

1. **B**。树中除根外每个节点有且仅有一个直接前驱（双亲）；多前驱则不是树。
2. **错**。树中边视为有向、只能自上而下，只有祖先—子孙方向存在路径；兄弟之间、子孙到祖先之间不存在路径。
3. **3**。树的度取所有节点度的最大值，A 的度为 3，故树的度为 3（B 的度 2 不影响）。
4. 路径长度 = 边数 = 节点数 − 1 = **4**；该叶子层次为 **5**（根为第 1 层）。
5. 森林是 $m$ 棵互不相交的树的集合（$m\ge 0$）。给森林中每棵树的根节点之上再加一个共同的根节点，即得到一棵树；反之，树删去根节点，其各子树构成森林。

</details>

## 9. 背诵卡

1. 树：$n\ge 0$ 个节点的有限集；非空树有且仅有一个根，其余节点**有且仅有一个前驱**，子树**互不相交**。
2. 树 = 根 + 若干互不相交的子树（**递归定义**）。
3. 路径**单向自上而下**，路径长度 = **边数**；层次默认从 **1** 起，树高 = 最大层次。
4. **节点的度 = 孩子数**；**树的度 = 所有节点度的最大值**；度为 0 即叶子（终端节点）。
5. 森林 = $m$ 棵互不相交的树（$m$ 可为 0）；森林加一个根即成树，树去根即成森林。

## 10. 关联与下一节

- **向前关联**：线性表的「前驱/后继」被推广为树的「双亲/孩子」；线性表是「一对一」，树是「一对多」。
- **向后关联**：下一小节用「节点的度 / 树的度」推导节点数计数公式（如 $n_0=n_2+1$ 的树版本），并引出**二叉树**这一特殊树——它是 408 全章重点，后续讲性质、存储结构、遍历。森林↔树的转换也是后续大题考点。
