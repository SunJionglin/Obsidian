# 3.3.2 栈在表达式求值中的应用（上）

## 1. 本节定位

- **对应王道书**：第 3 章「栈、队列和数组」→ 3.3 节「栈的应用」→ 表达式求值（上）。
- **408 大纲对应**：栈和队列的应用——表达式求值（中缀转后缀/前缀、后缀表达式求值）。
- **先修知识**：栈的 LIFO 特性、入栈/出栈操作；算术表达式的运算符优先级与括号规则。
- **本节位置**：栈的第二个经典应用。本节讲**手算**（三种表达式互转、后缀/前缀求值），下一节讲**用栈实现中缀转后缀的算法**（机算）。本节是下一节的直观基础。

## 2. 一句话结论

中缀表达式因运算符生效次序不唯一，需用**左优先原则**（转后缀）或**右优先原则**（转前缀）固定唯一结果；后缀表达式求值时**从左往右扫描**，遇操作数入栈、遇运算符弹两个栈顶元素运算后压回，**先弹出的是右操作数**。

## 3. 知识地图

```
算术表达式
├── 中缀表达式：运算符在两个操作数中间，必须用括号（界限符）表明运算次序
├── 后缀表达式（逆波兰表达式，Reverse Polish Notation）
│   ├── 运算符在两个操作数之后，操作数左右顺序不可颠倒
│   ├── 中缀→后缀：确定运算次序 → 按次序把「左操作数 右操作数 运算符」组合
│   └── 求值：从左往右扫描，操作数入栈；遇运算符弹两元素，先弹出者为右操作数
└── 前缀表达式（波兰表达式，Polish Notation）
    ├── 运算符在两个操作数之前
    ├── 中缀→前缀：右优先原则确定次序 → 按次序把「运算符 左操作数 右操作数」组合
    └── 求值：从右往左扫描，操作数入栈；遇运算符弹两元素，先弹出者为左操作数
```

## 4. 核心内容

### 4.1 三种表达式的定义

中缀表达式由三部分组成：**操作数**（1、2、3…）、**运算符**（+ − × ÷）、**界限符**（括号）。界限符的作用是表明各运算符生效的先后顺序；去掉括号后运算次序会改变，因此中缀表达式中括号是必需的。

1924 年波兰数学家提出不用括号也能无歧义表达运算次序的两种记法：

| 表达式 | 运算符位置 | 别名 |
|---|---|---|
| 中缀 | 两操作数**中间** | — |
| 后缀 | 两操作数**之后** | 逆波兰表达式 |
| 前缀 | 两操作数**之前** | 波兰表达式 |

**关键约束**：操作数的左右顺序不能颠倒。$a-b$ 的后缀是 `a b -`，不能写成 `b a -`；除法同理。

### 4.2 中缀 → 后缀（手算方法）

**步骤**：
1. 按「先乘除后加减、有括号先算括号内」确定各运算符的生效次序；
2. 从第一个生效的运算符开始，把「左操作数 右操作数 运算符」写成后缀形式；
3. 把这一步的结果视为一个**新的整体（新操作数）**，继续处理下一个生效的运算符，直到全部合并。

**例**：$a+b-c$

- 先算 $a+b$ → `a b +`，整体记为 $X$；
- 再算 $X-c$ → `a b + c -`。

若改为先算 $b-c$ → `b c -`，再算 $a+(b-c)$ → `a b c - +`。**同一中缀表达式可对应多个后缀表达式**，因为运算次序不唯一。

**左优先原则**：只要左边的运算符可以先计算，就优先让左边的先生效。这样运算次序唯一，结果与计算机算法输出一致。考试验证算法时**必须用左优先得到的那一种**。

**例**：$A+B\times C-D/E+F$（按左优先）

- 最左的加法可先生效（$A+B$）→ `A B +`；
- 乘除优先于加减，且乘法在除法左边 → 先乘后除；
- 依次得：`A B + C × D E / - F +`。

**规律**：按左优先确定次序后，后缀表达式中运算符**从左到右**的出现顺序，与中缀中运算符的生效次序**一一对应**。

### 4.3 后缀表达式求值（手算）

从左往右扫描后缀表达式，每遇到一个运算符，就让**紧挨在它前面的两个操作数**执行该运算，结果合并为一个新操作数，继续扫描，直到只剩一个数。

**例**：中缀 $15/(7-(1+1))-3\times(2+(1+1))$ 对应后缀（左优先）

```
1 1 + 7 - 15 / 3 2 1 1 + + × -
```

逐步合并：

| 步骤 | 扫描到的运算符 | 运算 | 结果 |
|---|---|---|---|
| 1 | + | 1+1 | 2 |
| 2 | − | 7−2 | 5 |
| 3 | / | 15/5 | 3 |
| 4 | + | 1+1 | 2 |
| 5 | + | 2+2 | 4 |
| 6 | × | 3×4 | 12 |
| 7 | − | 3−12 | −9 |

**注意**：除法/减法时，运算符**前面**的操作数是左操作数，**后面**的是右操作数，不能颠倒。

### 4.4 用栈计算后缀表达式（机算模拟）

**规则**：
- 从左往右扫描；
- 遇**操作数** → 入栈；
- 遇**运算符** → 弹出两个栈顶元素，执行运算，结果压回栈；
- 扫描结束后栈中只剩一个元素，即结果。

**关键**：**先弹出的是右操作数，后弹出的是左操作数**（因为右操作数后入栈，先出栈）。

```c
// 后缀表达式求值（伪代码，栈元素为操作数）
int EvalPostfix(char exp[], int n) {
    InitStack(S);
    for (int i = 0; i < n; i++) {
        if (exp[i] 是操作数) {
            Push(S, exp[i]);              // 操作数入栈
        } else {                          // 遇运算符
            Pop(S, right);                // 先弹出：右操作数
            Pop(S, left);                 // 后弹出：左操作数
            result = left  op  right;     // 注意左右顺序
            Push(S, result);              // 结果压回栈
        }
    }
    Pop(S, result);                       // 栈中唯一元素即结果
    return result;
}
```

**例**（王道经典）：后缀 `A B + C D × E / - F +`，模拟入栈出栈，最终栈中只剩一个元素即结果。

### 4.5 后缀 → 中缀

从左往右扫描，遇运算符就把其前面两个操作数用「左 运算符 右」组合并加括号，作为新整体继续。例：`1 1 + 7 - 15 /` → `(1+1)` → `(7-(1+1))` → `(15/(7-(1+1)))`。

### 4.6 中缀 → 前缀

方法对称：确定运算次序后，按「运算符 左操作数 右操作数」组合。

**右优先原则**：只要右边的运算符可以先计算，就优先让右边的先生效。按右优先确定次序后，前缀表达式中运算符**从右到左**的出现顺序与生效次序一一对应。

**例**：$A+B\times C-D/E+F$ 按右优先 → 前缀 `+ A - + B × C / D E F`（推断：按右优先次序组合，运算符从右到左依次为 +、−、+、×、/）。

### 4.7 用栈计算前缀表达式

- **从右往左**扫描；
- 遇操作数入栈；
- 遇运算符弹两个栈顶元素，**先弹出的是左操作数，后弹出的是右操作数**（与后缀相反）；
- 结果压回栈，最终栈中唯一元素为结果。

## 5. 复杂度分析

设表达式长度为 $n$（操作数与运算符总数）。

- **后缀/前缀求值（栈模拟）**：每个元素恰好扫描一次，每次操作数入栈 $O(1)$，每次运算符两次出栈 + 一次入栈 $O(1)$。
  - 最好情况：$n=1$（只有操作数），$O(1)$；
  - 最坏情况：$n$ 个元素全部处理，$O(n)$；
  - 平均情况：每个元素处理代价为常数，总代价 $\sum_{i=1}^{n} c = c\cdot n$，故平均 $O(n)$。**概率假设**：各元素等概率出现在任意位置，单次操作代价与位置无关。
- **空间**：栈的最大深度取决于表达式的嵌套结构，最坏 $O(n)$（如全为操作数时栈中积累 $n$ 个），平均 $O(\log n)$ 量级（推断：平衡表达式树深度）。
- **中缀转后缀/前缀（手算）**：本质是构造表达式树并后序/前序遍历，时间 $O(n)$。

## 6. 易错点与考试写法

1. **操作数左右顺序颠倒**：$a-b$ 后缀是 `a b -` 不是 `b a -`；求值时先弹出的是**右**操作数（后缀）或**左**操作数（前缀），减法除法搞反直接错。
2. **后缀表达式不唯一**：不规定左优先时，同一中缀可对应多个后缀。**考试验证算法必须用左优先那一种**，否则与标准答案不符。
3. **左优先 ≠ 优先级**：左优先是在满足「先乘除后加减、括号优先」的前提下，同级或可并行时选左边的。例 $A+B\times C$ 中加法虽在最左，但乘法优先级高，仍先算乘法。
4. **前缀求值扫描方向**：从右往左，且先弹出的是左操作数——与后缀完全对称，别记混。
5. **答题程度**：选择题要求能快速写出唯一后缀/前缀并求值；简答题写「按左优先原则确定运算次序，依次组合」即可，不必展开每一步合并（推断：王道书标准写法）。

## 7. 408 题型与解题套路

- **选择题（高频）**：
  - 给中缀选后缀/前缀 → 用左优先/右优先逐次合并，或直接按「运算符出现顺序与生效次序对应」验证；
  - 给后缀求值 → 从左往右扫描合并，注意减法除法方向；
  - 给后缀表达式问栈的**最大深度**或某步栈内容 → 模拟入栈出栈；
  - 判断某后缀是否合法 → 扫描过程中操作数个数始终 ≥ 运算符所需，结束时恰剩 1 个。
- **算法题（低频，下一节为主）**：用栈实现中缀转后缀，需处理运算符优先级与括号，本节只打手算基础。
- **常见陷阱**：把「左优先」误用于前缀；求值时先弹出元素当左操作数（后缀中应为右操作数）；忽略括号导致的次序变化。

## 8. 自测题

**题 1**：中缀 $A+B\times(C-D)-E/F$ 按左优先转后缀，结果是？

**题 2**：后缀表达式 `5 3 2 × + 8 4 / -` 的值是？

**题 3**：用栈计算后缀 `A B - C D + ×`，扫描到 `×` 时先弹出的是哪个操作数？它对应中缀中的左还是右操作数？

**题 4**：前缀表达式 `- × A B + C D` 的值（设 A=2,B=3,C=4,D=5）是？

**题 5**：判断：同一中缀表达式对应的后缀表达式一定唯一。（ ）

<details>
<summary>答案与解析</summary>

**题 1**：`A B C D - × + E F / -`。次序：$C-D$ → $B\times(C-D)$ → $A+[\ ]$ → $E/F$ → 相减。

**题 2**：$3\times2=6$，$5+6=11$，$8/4=2$，$11-2=9$。答案 9。

**题 3**：扫描到 `×` 时栈中自底向上为 $[A-B,\ C+D]$，先弹出 $C+D$，它是**右**操作数，运算为 $(A-B)\times(C+D)$。

**题 4**：从右往左：D、C 入栈，遇 `+` 得 $C+D=9$；B、A 入栈，遇 `×` 得 $A\times B=6$；遇 `-` 先弹出 6（左），后弹出 9（右），$6-9=-3$。

**题 5**：错。运算次序不唯一时后缀不唯一；引入左优先原则后才唯一。

## 9. 背诵卡

1. 后缀=逆波兰，前缀=波兰；运算符分别在操作数**后/前**，操作数顺序不可颠倒。
2. 中缀转后缀用**左优先**，转前缀用**右优先**；运算符在后缀中从左到右、在前缀中从右到左的出现顺序 = 生效次序。
3. 后缀求值：从左往右扫，操作数入栈，遇运算符弹两个，**先弹出=右操作数**。
4. 前缀求值：从右往左扫，遇运算符弹两个，**先弹出=左操作数**。
5. 扫描结束栈中恰剩 1 个元素即结果；减法除法方向错=全错。
