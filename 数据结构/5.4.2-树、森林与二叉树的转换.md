# 5.4.2 树、森林与二叉树的转换

## 1. 本节定位

- **对应王道书**：第 5 章「树与二叉树」→ 5.4「树、森林」→ 5.4.2「树、森林与二叉树的转换」。
- **408 大纲对应**：树与二叉树的应用之一——树、森林与二叉树的相互转换（属于「树与二叉树」基本内容，选择题高频、大题常作为中间步骤）。
- **先修知识**：树的定义与基本术语（双亲、孩子、兄弟、层次/层序）、二叉树的定义与链式存储结构（`lchild`、`rchild` 指针）、**孩子兄弟表示法**（左指针指向第一个孩子，右指针指向下一个兄弟）。
- **本节位置**：紧接 5.4.1「树的存储结构」（孩子兄弟表示法），是孩子兄弟表示法的直接应用；后续 5.5「哈夫曼树」与 5.6「并查集」不依赖本节，但本节是「树→二叉树」思想的核心落点，也是遍历（5.3）与存储（5.4.1）的综合运用。

## 2. 一句话结论

**树/森林与二叉树的转换，本质就是用孩子兄弟表示法存储树或森林：左指针连第一个孩子，右指针连下一个兄弟；森林中所有树的根视为平级兄弟，用右指针串成一串。**

## 3. 知识地图

```
树、森林与二叉树的转换
├── 原理：孩子兄弟表示法（左孩子、右兄弟）
├── 树 → 二叉树
│   ├── 画根节点
│   ├── 按树的层序处理每个节点
│   └── 处理规则：所有孩子用右指针串成"冰糖葫芦"，第一个孩子挂到当前节点左指针
├── 森林 → 二叉树
│   ├── 第一步：所有树的根用右指针串起来（视为兄弟）
│   └── 之后同"树 → 二叉树"，按整体层序处理
├── 二叉树 → 树
│   ├── 画根节点
│   ├── 按层序恢复每个节点的孩子
│   └── 恢复规则：左孩子及其右指针串（整串）拆下，挂到当前节点下方
└── 二叉树 → 森林
    ├── 第一步：根节点及其右指针串全部拆下，作为各棵树的根
    └── 之后同"二叉树 → 树"，按层序恢复
```

## 4. 核心内容

### 4.1 原理：孩子兄弟表示法

树的每个节点用二叉链表存储，两个指针含义固定：

- `lchild`（左指针）：指向该节点的**第一个孩子**；
- `rchild`（右指针）：指向该节点的**下一个兄弟**。

```c
// 孩子兄弟表示法的结点结构（王道风格）
typedef struct CSNode {
    ElemType data;                  // 数据域
    struct CSNode *firstchild;      // 左指针：第一个孩子
    struct CSNode *nextsibling;     // 右指针：下一个兄弟
} CSNode, *CSTree;
```

> 说明：本节讲解用「左指针/右指针」描述，与 `firstchild/nextsibling` 一一对应。存储形态与二叉树完全相同，因此「转换」就是「按孩子兄弟表示法画出来」。

### 4.2 树 → 二叉树（转换规则）

**操作步骤**（按树的层序处理，避免混乱）：

1. 在二叉树中画出该树的根节点；
2. 按树的**层序**（逐层、从左到右）依次处理每个节点；
3. 对当前节点：
   - 若**有孩子**：把所有孩子用**右指针**串成一条「冰糖葫芦」（第一个孩子 → 第二个孩子 → …，靠右指针相连）；
   - 把**第一个孩子**挂到当前节点的**左指针**下；
   - 若**无孩子**：不做任何处理。

**图解（以讲解中的例子抽象）**：

```
树：A 的孩子 B、C；B 的孩子 D、H、F；C 的孩子 E、J、K；H 的孩子 G、I、L

转换后二叉树：
        A
       /
      B
     / \
    D   H
       / \
      G   I
           \
            L
   （右指针链：A→(B→C)，B→(D→H→F)，C→(E→J→K)，H→(G→I→L)）
```

> 上面示意图只表达「左孩子 + 右兄弟」的连接关系，实际画图时每个节点的右指针链要完整画出（如 B 的右指针连 C，D 的右指针连 H，H 的右指针连 F 等）。**考试画图必须把右指针链画全**，这是得分点。

### 4.3 森林 → 二叉树

与「树 → 二叉树」唯一区别在**第一步**：

1. **把森林中每棵树的根节点用右指针串起来**（森林的根之间是平级的兄弟关系）；
2. 之后按**整个森林的层序**（把所有树看成一个整体，逐层从左到右）处理每个节点，规则同 4.2。

**关键理解**：森林的「第一层」是所有树的根；「第二层」是所有树根的孩子；依此类推。

### 4.4 二叉树 → 树（逆过程）

**操作步骤**：

1. 画出树的根节点（即二叉树的根）；
2. 按**层序**依次恢复每个节点的孩子；
3. 对当前节点：
   - 若其**左指针为空**：无孩子，不处理；
   - 若**左指针非空**：把「左孩子 + 沿右指针串起来的整串」**整体拆下**，依次挂到当前节点下方，作为它的孩子（第一个是左孩子，其余按右指针顺序为第 2、3…个孩子）。

**要点**：拆的是「一整串冰糖葫芦」，不是单个节点；拆下后这些节点在树中是**平级的兄弟**。

### 4.5 二叉树 → 森林（逆过程）

1. **第一步**：把二叉树的**根节点及其右指针串**全部拆下，它们分别是森林中各棵树的根（根之间是兄弟关系）；
2. 之后对每棵树按 4.4 的规则，按层序恢复各节点的孩子。

**判断技巧**：二叉树根节点的右指针链有多长，森林就有多少棵树。

### 4.6 转换的可逆性

树 ↔ 二叉树、森林 ↔ 二叉树都是**一一对应、可逆**的（在给定孩子兄弟表示法下）。因此「树转二叉树再转回树」应还原原树，可作为自检手段。

## 5. 复杂度分析

本节是**结构变换/画图题**，不涉及查找、插入等算法操作，复杂度按「处理节点数」计：

- 设树（或森林）共有 $n$ 个节点。
- 转换过程对每个节点**恰好处理一次**（层序访问一次，修改常数个指针），每次处理为 $O(1)$。
- 因此**最好、最坏、平均均为 $O(n)$**：最好情况是链状树（每节点至多一个孩子），最坏是每个节点都有大量孩子（右指针链很长），但总指针修改次数仍与节点数同阶；平均情况在「每个节点孩子数期望为常数」的假设下同样是 $O(n)$，因为总边数 = 节点数 − 1（树）或 节点数 − 树数（森林），均为 $O(n)$。
- **空间**：若原地修改指针则为 $O(1)$ 辅助空间；若新建二叉树节点则为 $O(n)$。

> 408 一般不单独考本节复杂度，此处仅作理解；重点是**转换规则的正确性**。

## 6. 易错点与考试写法

1. **森林转二叉树漏掉第一步**：忘记把各棵树的根用右指针串起来，直接按单棵树处理——这是最常见的失分点。**森林的根是兄弟**。
2. **「冰糖葫芦」串错方向**：孩子之间用**右指针**串（兄弟关系），第一个孩子才挂**左指针**；不要把孩子都挂在左指针上。
3. **逆转换时只拆一个节点**：二叉树 → 树时，要把「左孩子 + 右指针整串」一起拆下，漏拆右指针链会导致孩子丢失。
4. **层序处理顺序乱**：必须按层序（逐层从左到右）处理，否则容易漏节点或重复处理。讲解反复强调「按层序不容易乱」。
5. **森林层序的理解**：森林的层序是「所有树看成一个整体」的层序，不是一棵一棵树单独处理完再下一棵。
6. **答题标准**：408 画图题要求**指针连接完整、节点不重不漏**；文字题要写出「左指针指向第一个孩子，右指针指向下一个兄弟」这一核心句，并说明森林根节点视为兄弟。只画结果不写规则，可能扣分。

## 7. 408 题型与解题套路

- **选择题**：常考「某树/森林对应的二叉树中，某节点的左/右孩子是谁」「二叉树中某节点在树中的孩子个数」「森林有几棵树（看根右链长度）」。
  - 套路：先按孩子兄弟表示法在草稿上画连接，再逐题对照；注意「二叉树中某节点的右孩子 = 它在原树中的下一个兄弟」。
- **画图/综合题**：给出树或森林，要求画出对应二叉树；或反过来。常作为遍历题、存储结构题的中间步骤。
  - 套路：**先画根 → 按层序逐个处理 → 每个节点「串孩子、挂第一个」**；逆过程「拆整串、挂下方」。
- **常见陷阱**：
  - 把「森林」当「树」处理（漏串根）；
  - 混淆「左孩子」与「右兄弟」的语义；
  - 逆转换时把右指针链误当成孩子链（右链是兄弟，不是孩子）；
  - 树转二叉树后误以为「二叉树的中序 = 树的后序」等遍历对应关系（本节不展开，属 5.4 后续/遍历综合，**了解即可**）。

## 8. 自测题

**题 1**：树中节点 X 有 3 个孩子，转换为二叉树后，X 的左指针指向什么？X 的 3 个孩子在二叉树中如何连接？

**题 2**：森林有 4 棵树，转换为二叉树后，二叉树根节点的右指针链上有几个节点（不含根）？

**题 3**：二叉树中某节点 P 的左指针为空，说明 P 在原树（或原森林对应树）中是什么情况？

**题 4**：二叉树 → 森林时，第一步做什么？如何从二叉树判断森林有几棵树？

**题 5**：判断：树转成二叉树后，二叉树的根节点一定没有右孩子。（对/错，说明理由）

<details>
<summary>参考答案</summary>

**题 1**：X 的左指针指向它的**第一个孩子**；3 个孩子之间用**右指针**依次串成链（第一个孩子 → 第二个 → 第三个），即「冰糖葫芦」。

**题 2**：森林 4 棵树的根视为兄弟，用右指针串起来，根节点右链上有 **3 个**节点（第 2、3、4 棵树的根）。

**题 3**：P 没有孩子（左指针为空即无第一个孩子，也就无孩子）。

**题 4**：第一步把二叉树根节点及其右指针串全部拆下，作为森林中各棵树的根；根右链长度 + 1 = 森林的树数。

**题 5**：**对**。单棵树的根没有兄弟，转换后根节点的右指针为空；只有森林转换时根才有右链。

## 9. 背诵卡

1. **本质**：树/森林 ↔ 二叉树 = 孩子兄弟表示法；**左指针 = 第一个孩子，右指针 = 下一个兄弟**。
2. **树→二叉树**：画根 → 按层序 → 孩子用右指针串成串 → 第一个孩子挂左指针。
3. **森林→二叉树**：**先把所有树根用右指针串起来**（根是兄弟），再按整体层序同树处理。
4. **二叉树→树**：按层序，左孩子 + 右指针整串一起拆下，挂到当前节点下方当孩子。
5. **二叉树→森林**：先把根及其右链拆成各树根；根右链长度 + 1 = 树数。
