# 8.5.1 归并排序（Merge Sort）

## 1. 本节定位

- **对应王道书**：第 8 章「排序」→ 8.5 归并排序和基数排序 → 8.5.1 归并排序。
- **408 大纲对应**：内部排序中的「归并排序」（排序算法的时间/空间复杂度、稳定性、趟数分析）。
- **先修知识**：数组下标与区间表示、递归、双指针合并两个有序表、二叉树层数与结点数关系（第 $h$ 层最多 $2^{h-1}$ 个结点）。
- **在整章中的位置**：前面学了插入、交换（快排）、选择（堆排），本节是又一种 $O(n\log n)$ 的排序；其「多路归并」思想直接通向第 8 章后面的**外部排序**（多路归并、败者树）。

---

## 2. 一句话结论

归并排序 = **把两个相邻有序子序列合并成一个有序序列（Merge）** 的递归分治；二路归并排序时间恒为 $O(n\log_2 n)$（最好=最坏=平均），空间 $O(n)$，**稳定**。

---

## 3. 知识地图

```
归并排序
├── 核心操作：Merge（合并两个相邻有序表）
│   ├── 三指针 low / mid / high 划定两个子序列
│   ├── 辅助数组 B 暂存
│   └── 双指针 i、j 比较，小者先入 A；相等时取左边 → 稳定
├── 归并路数
│   ├── 二路归并：每次选最小只需比较 1 次关键字
│   ├── m 路归并：每次选最小至少比较 m−1 次
│   └── 内部排序用二路；外部排序用多路（后续章节）
├── 递归实现 MergeSort(A, low, high)
│   ├── low < high 才继续
│   ├── mid = (low+high)/2 向下取整
│   ├── 递归左半 [low, mid]、右半 [mid+1, high]
│   └── Merge(A, low, mid, high)
└── 效率
    ├── 时间：每趟 O(n)，共 ⌈log₂n⌉ 趟 → O(n log₂ n)
    ├── 空间：辅助数组 O(n) + 递归栈 O(log₂ n) → O(n)
    └── 稳定性：稳定
```

## 4. 核心内容

### 4.1 定义

**归并（Merge）**：把两个或两个以上**已经有序**的序列合并成一个有序序列的过程。

- **二路归并**：两个有序表合二为一。内部排序通常采用二路归并。
- **m 路归并**：m 个有序表合一。从 m 个候选元素中选出最小者，**至少需要比较 $m-1$ 次关键字**（两两比较、逐步更新最小值）。路数越多，每选一个元素比较次数越多。

### 4.2 核心操作 Merge 的图解

设数组 `A` 中 `[low..mid]` 与 `[mid+1..high]` 两段各自有序，要合并成 `[low..high]` 整体有序。

```
下标:   low ... mid | mid+1 ... high
        有序左段     |   有序右段
指针:    i →         |   j →
结果写回: k → 从 low 开始
```

规则：比较 `A[i]` 与 `A[j]`，**较小者**放入 `A[k]`，对应指针后移，`k` 后移；某一段耗尽后，把另一段剩余元素**直接整体搬过去**（不再比较）。

**相等时取左边（`A[i] <= A[j]` 取 i）**，这是稳定性的来源：左段元素在原序列中位置更靠前，先合并它，相等关键字的相对次序不变。

### 4.3 Merge 代码（王道风格，C 语言）

前提：`A[low..mid]`、`A[mid+1..high]` 已各自非降序；`B` 为长度 ≥ n 的辅助数组。

```c
// 将 A[low..mid] 与 A[mid+1..high] 归并为有序的 A[low..high]
void Merge(int A[], int B[], int low, int mid, int high) {
    int i, j, k;
    // 1) 把待归并区间复制到辅助数组 B（下标一一对应）
    for (k = low; k <= high; k++)
        B[k] = A[k];

    // 2) 双指针归并，结果写回 A
    for (i = low, j = mid + 1, k = low; i <= mid && j <= high; k++) {
        if (B[i] <= B[j])      // 相等取左边 → 保证稳定
            A[k] = B[i++];
        else
            A[k] = B[j++];
    }
    // 3) 把未耗尽的一段剩余元素直接搬过去
    while (i <= mid)  A[k++] = B[i++];
    while (j <= high) A[k++] = B[j++];
}
```

> 注意：比较的是 **B 数组**（副本），写回的是 **A 数组**；若直接比较 A 会覆盖未处理元素。

### 4.4 递归归并排序代码

```c
void MergeSort(int A[], int B[], int low, int high) {
    if (low < high) {                 // 区间长度 ≥ 2 才需排序
        int mid = (low + high) / 2;   // 向下取整，从中间切分
        MergeSort(A, B, low, mid);        // 递归排左半
        MergeSort(A, B, mid + 1, high);   // 递归排右半
        Merge(A, B, low, mid, high);      // 合并两个有序段
    }
}
// 调用：MergeSort(A, B, 0, n-1);  B 需预先分配长度 n
```

递归终止：`low == high` 时区间只有一个元素，天然有序，什么也不做——这就是「俄罗斯套娃」的最内层。

### 4.5 归并过程示例（讲解中的例子）

初始序列（每个元素视为长度 1 的有序段）：

```
[49] [38] [65] [97] [76] [13] [27]
```

- **第 1 趟**：相邻两两归并 → `[38 49] [65 97] [13 76] [27]`
- **第 2 趟**：相邻有序段两两归并 → `[38 49 65 97] [13 27 76]`
- **第 3 趟**：合并最后两段 → `[13 27 38 49 65 76 97]`

每趟都是「相邻的两个有序段」合并，段长依次为 1→2→4→…，直到覆盖整个表。

### 4.6 归并树（归并趟数的来源）

把上述过程画成倒立的二叉树：

- 叶子：n 个单元素（第 1 层为根，向下分层）；
- 每个内部结点：一次 Merge；
- **树高 $h$，归并趟数 = $h-1$**（叶子层不需要归并）。

第 $h$ 层最多 $2^{h-1}$ 个结点，n 个元素都要落在第 $h$ 层，故

$$n \le 2^{h-1} \;\Rightarrow\; h-1 \ge \lceil \log_2 n \rceil$$

即 **二路归并趟数 = $\lceil \log_2 n \rceil$**。

## 5. 复杂度分析

### 5.1 时间复杂度

**每趟 Merge 的代价**：两个有序段合并，每比较一次关键字就确定一个元素的最终位置，最多比较 $n-1$ 次；加上复制与搬移，整趟为 $O(n)$。

- 第一趟：$\frac{n}{2}$ 对元素各比较 1 次，约 $\frac{n}{2}$ 次比较，仍是 $O(n)$；
- 最后一趟：两段合并，比较次数 $\le n-1$，$O(n)$。

**总时间** = 每趟 $O(n)$ × 趟数 $\lceil \log_2 n \rceil$：

$$T(n) = O(n\log_2 n)$$

**三种情况**：归并排序的趟数只由 n 决定，与初始序列是否有序**无关**；每趟代价也只看长度。因此

- 最好：$O(n\log_2 n)$
- 最坏：$O(n\log_2 n)$
- 平均：$O(n\log_2 n)$

> 平均情况推导：归并树形态由 n 唯一确定（每次对半切），不存在「输入分布影响比较次数数量级」的问题；无论输入如何排列，比较次数都在 $\Theta(n\log n)$ 量级，故平均即等于最坏。

### 5.2 空间复杂度

- 辅助数组 `B`：长度 n → $O(n)$；
- 递归调用栈：深度不超过 $\lceil \log_2 n \rceil$ → $O(\log_2 n)$；
- 相加取高阶：$O(n) + O(\log_2 n) = O(n)$。

### 5.3 稳定性

Merge 中相等时优先取左段元素，相等关键字相对次序不变 → **稳定**。

### 5.4 横向对比（408 常考表格的一行）

| 算法 | 最好 | 最坏 | 平均 | 空间 | 稳定 |
|---|---|---|---|---|---|
| 归并排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | 稳定 |

## 6. 易错点与考试写法

1. **比较的是辅助数组 B，写回的是 A**。写成直接比较 A 会因覆盖出错，默写代码时务必先复制。
2. **`B[i] <= B[j]` 的等号不能丢**：丢了等号（写成 `<`）会破坏稳定性；408 选择题常拿「相等时取哪边」考稳定性。
3. **mid 的取法**：`mid = (low+high)/2` 向下取整，左段 `[low, mid]`、右段 `[mid+1, high]`，两段都非空，递归不会死循环。
4. **趟数不是 $\log_2 n$ 而是 $\lceil \log_2 n \rceil$**：n 不是 2 的幂时要向上取整（如 n=7 需 3 趟）。
5. **空间是 $O(n)$ 不是 $O(\log n)$**：递归栈只是 $O(\log n)$，被辅助数组的 $O(n)$ 盖过，别只答栈空间。
6. **「归并路数越多越快」是错的**：m 路归并每选一个元素至少比较 $m-1$ 次，内部排序选二路；多路用于外部排序是为减少**访存/读盘次数**（后续章节）。
7. **答题程度**：算法题写全 `MergeSort` + `Merge` 两个函数、注明 `B` 已分配、注释「相等取左保证稳定」即可满分；复杂度题必须写出「趟数 $\lceil\log_2 n\rceil$ × 每趟 $O(n)$」的推导，只写结论扣分。

## 7. 408 题型与解题套路

**选择题常见考法**

- 给初始序列，问第 k 趟归并后的结果 / 共需几趟 → 按段长 1,2,4,… 手工模拟，趟数 $=\lceil \log_2 n\rceil$。
- 问某趟的比较次数 → 每对有序段合并比较次数 ≤ 段长和 −1。
- 复杂度与稳定性判断 → 直接背表；注意「最好=最坏」这一特征只有归并（和堆排、简单选择）具备。
- m 路归并每次选最小比较次数 → $m-1$。

**算法题套路**

- 题目要求「合并两个有序数组/链表」→ 直接套 Merge 双指针骨架（链表版不需辅助数组，空间 $O(1)$，属王道扩展）。
- 题目要求「排序且要求稳定、$O(n\log n)$」→ 归并排序是首选（快排不稳定、堆排不稳定）。
- 求逆序对（王道扩展/真题变体）→ 在 Merge 的 `else` 分支（取右段元素）时累加 `mid - i + 1`，即该右段元素与左段剩余元素构成的逆序数。

**陷阱**

- 把「归并」与「插入」混淆：归并是两段**整体**合并，插入是逐个插入已排序区。
- 误认为初始有序时归并更快：趟数不变，仍 $O(n\log n)$。

## 8. 自测题

**1.** 对含 10 个元素的序列做二路归并排序，共需几趟？第 2 趟结束时每个有序段的长度是多少？

**2.** 归并排序的空间复杂度为什么是 $O(n)$ 而不是 $O(\log_2 n)$？

**3.** Merge 中若把 `B[i] <= B[j]` 改为 `B[i] < B[j]`，对算法有什么影响？

**4.** 对 4 个有序表做四路归并，每选出一个最小元素至少需要比较几次关键字？二路归并呢？

**5.** 序列 `[49, 38, 65, 97, 76, 13, 27]` 第一趟二路归并后的结果是什么？

<details>
<summary>参考答案</summary>

1. 趟数 $=\lceil \log_2 10 \rceil = 4$ 趟；第 2 趟结束时段长为 4（最后一段可能不足 4）。
2. 需要长度 n 的辅助数组 B 暂存待归并区间，$O(n)$；递归栈深度仅 $O(\log_2 n)$，相加取高阶仍为 $O(n)$。
3. 相等时改为取右段元素，相等关键字的相对次序被颠倒，**稳定性被破坏**；时间、空间复杂度不变。
4. 四路：至少 $4-1=3$ 次；二路：$2-1=1$ 次。
5. `[38, 49, 65, 97, 13, 76, 27]`（相邻两两归并，最后一个 27 单独成段）。

## 9. 背诵卡

1. 归并 = 两个**相邻有序段**合成一个有序段；内部排序用**二路**。
2. Merge 三要素：`B` 暂存 → 双指针 `i,j` 比较、**相等取左**（稳定）→ 剩余段整体搬移。
3. 趟数 $=\lceil \log_2 n \rceil$，每趟 $O(n)$，总时间 $O(n\log_2 n)$，**最好=最坏=平均**。
4. 空间 $O(n)$（辅助数组主导，递归栈 $O(\log n)$ 可忽略）；**稳定**。
5. m 路归并每选一个最小元素至少比较 $m-1$ 次；多路归并服务于外部排序。
