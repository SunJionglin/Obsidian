# 1.0 开篇：数据结构在学什么

## 1. 本节定位

- **对应王道书**：绪论章开篇导学（第 1 章前言部分），不涉及具体考点条目。
- **408 大纲**：本节不直接对应大纲任何一条，属于「学科认知 + 学习路线」导学内容，**408 不直接考**。
- **先修知识**：C 语言基础（变量、数组、结构体、指针的初步概念）。
- **本章位置**：整门课的第 0 节，作用是建立「数据结构 = 把现实问题信息化 + 高效处理信息」的总纲，为第 1 章绪论（数据、数据元素、逻辑结构、存储结构、算法与复杂度）做动机铺垫。

## 2. 一句话结论

数据结构这门课研究两件事：**如何用程序代码把现实世界的问题信息化（表示信息）**，以及**如何用计算机高效地处理这些信息（处理信息）**，二者合起来才能创造价值。

## 3. 知识地图

```
数据结构在学什么
├── 目标一：把现实问题「信息化」（表示）
│   ├── 例1 金钱 → 一个 float 变量
│   ├── 例2 排队叫号 → 数组（有更好方式，后续学）
│   └── 例3 微博互相关注 → C 语言基础无法直接表达（引出数据结构）
├── 目标二：用计算机「高效处理」信息（处理）
│   └── 高效 = 创造价值（省时间、省空间）
└── 四门课的分工（计算机专业的知识地图）
    ├── 计算机组成原理 → 底层硬件（CPU、内存、主板）如何工作
    ├── 操作系统 → 硬件之上的系统层（Windows/Android/iOS）如何管理机器
    ├── 数据结构（+C 语言）→ 上层应用软件如何表示并处理现实问题
    └── 计算机网络 → 多台计算机/手机之间如何互联互通、传递信息
```

## 4. 核心内容

### 1. 信息化的三个例子（本节主线）

| 现实问题 | 用已学 C 语言如何表示 | 结论 |
|---|---|---|
| 存款金额（六位数财富） | 定义一个 `float` 型变量即可 | 简单信息，基本类型就能表示 |
| 餐厅排队叫号（记录每桌要大桌/小桌） | 可以定义一个数组逐项记录 | 能表示，但**存在更好的方式**（后续学队列等结构） |
| 微博用户之间的「互相关注」关系 | 用 C 语言基础**毫无思路** | 复杂逻辑关系需要**数据结构**来刻画 |

要点：前两个例子说明「信息化」是可行的，第三个例子说明**仅靠 C 语言语法不足以表达信息之间的逻辑关系**，这正是数据结构要解决的问题。

### 2. 信息化的两步走（本节最重要的框架）

1. **表示**：把现实世界的问题转化为计算机内的数据表示（用代码描述信息及其关系）。
2. **处理**：研究如何用计算机**高效**地处理这些信息，从而创造价值（节省顾客时间、节省商家等位空间等）。

> 只完成第一步（信息化）不够，还要追求「高效」，这就是后续学算法与时间/空间复杂度的动机。

### 3. 四门课的分工（了解即可，408 不直接考）

- **计算机组成原理**：研究 CPU、内存、主板等底层硬件的工作原理。
- **操作系统**：研究架在硬件之上的系统软件（Windows、Android、iOS）如何管理计算机/手机。
- **数据结构（+ C 语言）**：面向上层应用软件开发，解决「如何把现实问题信息化并高效处理」。
- **计算机网络**：实现计算机与计算机、计算机与手机之间的互联互通（如微信消息如何到达对方手机）。

本节观点（推断，属作者个人建议）：即便考研不考其中某几门，有时间也应把四门课都学一遍，这是计算机专业学生与「只会写代码的人」的区别所在。

### 4. 引用的背景（了解即可）

- 未来学家托夫勒（Toffler）《第三次浪潮》：人类社会发展分三阶段——农业阶段（约 1 万年）、工业阶段（17 世纪末起，约 300 多年）、**信息化阶段（正在到来）**。
- 结尾引用其名言：「唯一可以确定的是，明天会让我们所有人大吃一惊。」

## 5. 复杂度分析

本节为导学课，**不涉及任何算法，无复杂度分析内容**。复杂度（最好/最坏/平均）将从第 1 章「算法与算法评价」开始系统学习，本节不展开、不编造。

## 6. 易错点与考试写法

本节不是考点章节，易错点只在于**认知层面**：

1. **不要把「数据结构」理解成「就是学几种存储结构」**。本节给出的定义是「表示 + 高效处理」两件事，后续所有章节（线性表、栈队列、树、图、查找、排序）都围绕这两件事展开。
2. **不要误以为「能用数组表示就万事大吉」**。排队例子中数组「能表示」，但本节明确说「还有更好的方式」——表示的正确性 ≠ 表示的合理性，这是后续选型思维的起点。
3. **考试写法**：本节内容 408 不直接命题，无需背诵；但「数据结构研究数据的逻辑结构、存储结构及其操作（运算）」这一表述会在第 1 章绪论中以正式定义出现，届时按王道书原文作答。

## 7. 408 题型与解题套路

**1.** ①如何用程序代码把现实世界的问题**信息化**（表示信息）；②如何用计算机**高效地处理**这些信息，从而创造价值（处理信息）。

## 9. 背诵卡

1. 数据结构 = **把现实问题信息化（表示）** + **用计算机高效处理信息（处理）**。
2. 信息化只是第一步，**高效**处理才能创造价值。
3. 简单信息用基本类型（如 `float`）表示；复杂逻辑关系（如互相关注）必须靠数据结构。
4. 四门课分层：组成原理（硬件）→ 操作系统（系统层）→ 数据结构（应用层表示与处理）→ 计算机网络（互联互通）。
5. 本节为导学，**408 不直接命题**；正式考点从第 1 章绪论开始。

## 10. 关联与下一节

- **向后关联**：本节提出的「表示 + 处理」总纲，将在第 1 章绪论中落为正式概念——数据、数据元素、数据项、逻辑结构（集合/线性/树/图）、存储结构（顺序/链式/索引/散列）、算法及其时间空间复杂度。本节三个例子分别对应后续的：基本类型 → 线性表元素类型；排队 → 队列（第 3 章）；互相关注 → 图（第 6 章）。
- **下一节**：进入第 1 章绪论，学习数据结构的基本概念（数据、数据元素、数据项）与逻辑结构、存储结构的分类，随后是算法的定义、特性与复杂度分析——从下一节起才是 408 的正式考点。
