# 6.2.2 邻接表法

## 1. 本节定位

- **对应王道书**：第 6 章「图」→ 6.2「图的存储及基本操作」→ 6.2.2「邻接表法」。
- **408 大纲对应条目**：图的存储结构（邻接矩阵法、邻接表法、十字链表、邻接多重表）——本节覆盖「邻接表法」。
- **先修知识**：图的顶点/边（弧）基本概念、邻接矩阵法（上一小节）、顺序存储与链式存储、孩子表示法（树）。
- **本章位置**：紧接邻接矩阵法之后，是图存储的第二种基本方式；后续十字链表、邻接多重表都是对邻接表「求入度不便」这一缺点的改进，因此本节是理解后续两种结构的前提。

## 2. 一句话结论

邻接表用「顶点数组 + 边链表」的顺序+链式混合存储，把空间从邻接矩阵的 $O(n^2)$ 降到 $O(n+e)$，适合稀疏图；代价是**有向图求入度必须遍历全部边链表**，且**同一张图的邻接表表示不唯一**。

## 3. 知识地图

```
邻接表法
├── 存储结构
│   ├── 顶点表：一维数组，每项 = 数据域 + 指向第一条边/弧的指针
│   └── 边表：链表结点，每项 = 邻接点编号(下标) + 指向下一条边的指针
│       └── 带权图：边结点再加权值域
├── 与树的孩子表示法的关系：实现方式相同
├── 空间复杂度
│   ├── 无向图：O(n + 2e)（每条边存两份，冗余）
│   └── 有向图：O(n + e)（每条弧存一份）
├── 基本操作
│   ├── 无向图：求度、找邻接边 → 遍历该顶点边链表，方便
│   └── 有向图：求出度、找射出弧 → 方便
│             求入度、找射入弧 → 必须遍历所有顶点边链表，麻烦
└── 表示唯一性：不唯一（边结点顺序任意）；对比邻接矩阵唯一
```

## 4. 核心内容

### 1. 结构定义（C 语言，王道风格）

```c
#define MaxVertexNum 100          // 顶点数目的最大值

// 边表结点
typedef struct ArcNode {
    int adjvex;                   // 该边/弧指向的顶点在顶点表中的下标
    struct ArcNode *next;         // 指向下一条边/弧的指针
    // InfoType info;             // 带权图时加权值域（网）
} ArcNode;

// 顶点表结点
typedef struct VNode {
    VertexType data;              // 顶点信息
    ArcNode *first;               // 指向第一条依附该顶点的边/弧
} VNode, AdjList[MaxVertexNum];

// 用邻接表存储的图
typedef struct {
    AdjList vertices;             // 顶点表（一维数组）
    int vexnum, arcnum;           // 图的当前顶点数和边/弧数
} ALGraph;
```

要点：
- 顶点表是**一维数组**（顺序存储），边表是**链表**（链式存储）——这就是「顺序 + 链式」的含义。
- 边结点里存的是**邻接点在顶点数组中的下标**，不是顶点值本身。
- 声明一个图，本质就是声明一个顶点结点数组，外加记录顶点数、边数。

### 2. 图解（无向图，顶点 a、b、c、d 编号 0、1、2、3，a 与 b、c、d 相邻）

```
顶点表 vertices[]            边表（链表）
[0] a ──► [1| ]──► [2| ]──► [3|^]      // a 的边链表：1,2,3
[1] b ──► [0| ]──► [2| ]──► [3|^]
[2] c ──► [0| ]──► [1| ]──► [3|^]
[3] d ──► [0| ]──► [1| ]──► [2|^]
```

- 无向图中每条边 $(i,j)$ 在边表里出现**两次**：i 的链表里有 j，j 的链表里有 i，二者对应同一条边，数据冗余。
- 有向图（弧 a→b、a→c、a→d）：a 的边链表存 1、2、3，表示从 0 号顶点射出的弧；每条弧只存一份。

### 3. 与孩子表示法的关系

邻接表的实现方式与树的**孩子表示法**相同：各结点顺序存储，再用链表指出与该结点相连的各边。可类比记忆。

### 4. 求度 / 入度 / 出度

| 图类型 | 操作 | 做法 | 代价 |
|---|---|---|---|
| 无向图 | 求顶点 v 的度 | 遍历 v 的边链表，数结点个数 | 与该顶点度相关，方便 |
| 无向图 | 找 v 的所有邻接边 | 遍历 v 的边链表 | 方便 |
| 有向图 | 求 v 的出度 | 遍历 v 的边链表数结点 | 方便 |
| 有向图 | 找 v 射出的弧 | 遍历 v 的边链表 | 方便 |
| 有向图 | 求 v 的入度 / 找射入 v 的弧 | **必须遍历所有顶点的边链表**逐个检查 | 麻烦，代价高 |

有向图：度 = 入度 + 出度，出度易求、入度难求，这是邻接表存有向图的主要缺点（后续用**逆邻接表**或**十字链表**改进，属王道书扩展）。

### 5. 表示的唯一性

- 邻接表：同一张图，各边结点在链表中的先后顺序**任意**，故表示**不唯一**。
- 邻接矩阵：顶点编号确定后，矩阵**唯一**。
- 这是选择题高频考点。

## 5. 复杂度分析

设顶点数 $n$、边（弧）数 $e$。

**空间复杂度**
- 无向图：顶点表 $n$ 项 + 边结点 $2e$ 个（每条边两份冗余），故 $O(n+2e)=O(n+e)$。
- 有向图：顶点表 $n$ 项 + 边结点 $e$ 个（每条弧一份），故 $O(n+e)$。
- 对比邻接矩阵 $O(n^2)$：稀疏图（$e \ll n^2$）时邻接表省空间；稠密图时两者同量级，邻接表仍可用。

**求度 / 出度**：遍历单个顶点的边链表，最好 $O(1)$（该顶点无邻接边），最坏 $O(n)$（该顶点与其余 $n-1$ 个顶点全相邻），平均按「每个顶点平均度 $\bar d = 2e/n$（无向）或 $e/n$（有向）」估计为 $O(\bar d)$。推导：无向图所有边结点总数为 $2e$，分摊到 $n$ 个顶点，平均每个链表长 $2e/n$。

**求入度（有向图）**：必须扫描全部 $n$ 个顶点的边链表，总边结点数 $e$，故最好/最坏/平均均为 $O(n+e)$——这是邻接表存有向图的固有代价。

**找某顶点的所有邻接点**：遍历该顶点边链表，代价同求度。

## 6. 易错点与考试写法

1. **边结点存的是下标不是值**：`adjvex` 是邻接点在顶点数组中的下标（位序从 0 开始），答题时写清「下标」。
2. **无向图边结点数是 $2e$ 不是 $e$**：空间 $O(n+2e)$，别写成 $O(n+e)$ 后又说「每条边存两份」自相矛盾；写 $O(n+e)$ 时说明常数因子。
3. **有向图入度难求**：必须遍历所有边链表，不能只查一个链表；这是与邻接矩阵（求入度查一列即可）的关键对比。
4. **唯一性**：邻接表不唯一、邻接矩阵唯一——选择题常设陷阱，务必记牢。
5. **带权图**：边结点加 `info` 权值域，结构体定义要体现。
6. **答题程度**：408 中本节以选择题为主，答题写到「结构定义 + 空间复杂度 + 度/入度/出度的求法 + 唯一性对比」即算完整；算法题若要求建邻接表，需写出顶点表与边表结点结构并正确插入（无向图插入两次）。

## 7. 408 题型与解题套路

- **选择题**：
  - 给图判断邻接表存储的边结点总数（无向 $2e$、有向 $e$）。
  - 判断「邻接表表示是否唯一」「邻接矩阵是否唯一」。
  - 比较邻接表与邻接矩阵求度、入度、出度、找邻接点的效率。
  - 给邻接表图判断某顶点度/入度/出度。
- **算法题套路**：建立邻接表时，无向图对每条边 $(i,j)$ 要执行两次插入（i 链表插 j、j 链表插 i）；有向图只插一次。插入用头插法即可，顺序不影响正确性（正因如此表示不唯一）。
- **常见陷阱**：把「出度易求」误记为「入度易求」；把无向图边结点数记成 $e$；忽略带权图的权值域。

## 8. 自测题

**1.** 含 $n$ 个顶点、$e$ 条边的无向图用邻接表存储，边表结点总数是多少？空间复杂度是多少？

**2.** 有向图用邻接表存储，求某顶点入度的最坏时间复杂度是多少？为什么？

**3.** 同一张图，邻接矩阵和邻接表的表示是否唯一？说明理由。

**4.** 邻接表与树的哪种表示法实现方式相同？

**5.** 带权图（网）用邻接表存储时，结构体需增加什么？

1. $2e$ 个（每条边在两个端点的链表中各出现一次）；空间复杂度 $O(n+2e)=O(n+e)$。

3. 邻接矩阵唯一（顶点编号确定后矩阵确定）；邻接表不唯一（各边结点在链表中的先后顺序任意）。

## 9. 背诵卡

1. 邻接表 = 顶点数组（顺序）+ 边链表（链式），空间 $O(n+e)$，适合稀疏图。
2. 无向图边结点 $2e$ 个（冗余），有向图 $e$ 个。
3. 无向图求度、有向图求出度：查一个链表，方便；有向图求入度：遍历全部链表，$O(n+e)$，麻烦。
4. 邻接表表示**不唯一**，邻接矩阵**唯一**。
5. 实现方式同树的孩子表示法；带权图边结点加权值域。

## 10. 关联与下一节

- **向前关联**：邻接矩阵空间 $O(n^2)$ 只适合稠密图，邻接表正是为稀疏图而生；两者在求度/入度/出度、唯一性上的对比是选择题核心。
- **向后关联**：邻接表存有向图「求入度难」，引出**逆邻接表**与**十字链表**（有向图专用）；无向图边结点冗余，引出**邻接多重表**（无向图专用）。下一节学习十字链表。
