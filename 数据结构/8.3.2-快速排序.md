# 8.3.2 快速排序

## 1. 本节定位

- **对应王道书**：第 8 章「排序」→ 8.3 交换排序 → 8.3.2 快速排序。
- **408 大纲对应**：内部排序中的交换排序（快速排序），要求掌握算法思想、执行过程、代码实现、时间/空间复杂度、稳定性及一趟排序与一次划分的区别。
- **先修知识**：递归与函数调用栈、数组下标与位序关系、冒泡排序（同为交换排序）、二叉树的层数与高度。
- **本章位置**：交换排序的第二种算法，是内部排序中平均性能最优、代码考察频率最高的算法；后续「选择排序」「归并排序」「基数排序」均需与本节比较复杂度与稳定性。

## 2. 一句话结论

快速排序以首元素为枢轴（基准），用 `low`、`high` 双指针交替向中间扫描完成一次划分，使枢轴归位、左小右大，再递归处理左右子表；其时间与空间复杂度都取决于递归深度，最好 $O(n\log_2 n)$、最坏 $O(n^2)$，平均接近最好，且**不稳定**。

## 4. 核心内容

### 4.1 算法思想

对含 $n$ 个元素的表，任选一个元素作**枢轴（pivot，又称基准）**，通过一次划分把表分成两部分：左部所有元素 $<$ 枢轴，右部所有元素 $\ge$ 枢轴，枢轴本身落到最终位置。再对左右子表递归重复，直至子表长度 $\le 1$。

- 与冒泡对比：冒泡每趟只确定一个最大/最小元素的最终位置；快排一次划分确定的是一个**中间元素**的最终位置，且把表一分为二。
- 关键字：**一次划分（partition）**、**枢轴/基准（pivot）**。

### 4.2 一次划分的过程（双指针法）

设当前区间为 `[low, high]`，取 `A[low]` 为枢轴存入 `pivot`，此时 `low` 位置视为“空位”。

1. `high` 从右向左移，跳过 $\ge pivot$ 的元素；遇到 $< pivot$ 的元素，将其填入 `low` 所指空位，`high` 位置变为空位。
2. `low` 从左向右移，跳过 $\le pivot$ 的元素；遇到 $> pivot$ 的元素，将其填入 `high` 所指空位，`low` 位置变为空位。
3. 重复 1、2，直到 `low == high`，把 `pivot` 放入该位置，返回 `low`。

**王道例题（初始序列 49, 38, 65, 97, 76, 13, 27, 49，下标 0~7）第一趟划分结果**：

```
初始:  49  38  65  97  76  13  27  49
划分后:27  38  13  [49] 76  97  65  49
                  ↑ 枢轴归位于下标 3
```

要点：扫描过程中 `low` 左侧恒 $< pivot$，`high` 右侧恒 $\ge pivot$；两指针相遇处即枢轴最终位置。

### 4.3 代码实现（C，王道风格）

```c
// 一次划分：将 A[low..high] 以 A[low] 为枢轴划分，返回枢轴最终位置
int Partition(int A[], int low, int high) {
    int pivot = A[low];              // 首元素作枢轴，low 位置视为空位
    while (low < high) {             // 两指针未相遇
        while (low < high && A[high] >= pivot)
            high--;                  // high 左移，跳过 >= pivot 的元素
        A[low] = A[high];            // 找到 < pivot 的元素，填入 low 空位
        while (low < high && A[low] <= pivot)
            low++;                   // low 右移，跳过 <= pivot 的元素
        A[high] = A[low];            // 找到 > pivot 的元素，填入 high 空位
    }
    A[low] = pivot;                  // 枢轴归位（此时 low == high）
    return low;                      // 返回枢轴最终位置
}

// 快速排序：对 A[low..high] 递归排序
void QuickSort(int A[], int low, int high) {
    if (low < high) {                        // 子表长度 > 1 才需排序
        int pivotpos = Partition(A, low, high);  // 一次划分
        QuickSort(A, low, pivotpos - 1);         // 递归左子表
        QuickSort(A, pivotpos + 1, high);        // 递归右子表
    }
}
```

**递归执行要点（函数调用栈视角）**：

- 初始调用 `QuickSort(A, 0, 7)`，`Partition` 返回 3 → 左子表 `[0,2]`、右子表 `[4,7]`。
- 先递归左子表 `[0,2]`，`Partition` 返回 1 → 子表 `[0,0]`、`[2,2]` 均因 `low == high` 直接返回。
- 再递归右子表 `[4,7]`，`Partition` 返回 6 → 左 `[4,5]` 返回 4 → 其左 `[4,3]`（`low > high`，空表）直接返回，右 `[5,5]` 直接返回；右 `[7,7]` 直接返回。
- 递归终止条件：`low >= high`（空表或单元素表无需处理）。

> 注意：`Partition` 中两个内层 `while` 的条件必须带 `low < high`，否则指针会越界或死循环。

### 4.4 递归过程与二叉树

每一层递归把当前待处理区间划分为左右两部分，整个递归过程可画成一棵**递归树（划分树）**：

- 树中每个结点对应一次 `Partition` 调用，结点值即该次划分选出的枢轴；
- 树的层数 = 递归深度 = 函数调用栈的最大深度；
- 树的形态取决于每次划分是否均匀。

## 5. 复杂度分析

### 5.1 时间复杂度的推导

- 一次 `Partition` 对长度为 $m$ 的区间，`low`、`high` 合计移动不超过 $m$ 次，故为 $O(m)$。
- 每一层递归中，所有 `Partition` 处理的区间互不重叠，处理的元素总数不超过 $n$，故**每一层时间为 $O(n)$**。
- 总时间 $= O(n) \times$ 递归层数。

递归层数即划分树高度：

- **最好情况**：每次枢轴都把区间均匀二分，树高 $\lceil \log_2(n+1) \rceil$，时间 $O(n\log_2 n)$。
- **最坏情况**：每次枢轴都是区间最大或最小元素（如初始序列已**有序或逆序**），划分成 0 个和 $m-1$ 个元素，树退化为单链，层数为 $n$，时间 $O(n^2)$。
- **平均情况**：假设枢轴在区间内各位置等概率出现（随机化假设），可证明平均比较次数为 $O(n\log_2 n)$，即平均时间 $O(n\log_2 n)$。直观理解：随机枢轴使划分“不太偏”的概率占多数，平均树高为 $O(\log_2 n)$ 量级。

### 5.2 空间复杂度

递归需要函数调用栈，每层保存常数个局部变量与返回地址，故空间 $= O(\text{递归层数})$：

- 最好：$O(\log_2 n)$；
- 最坏：$O(n)$；
- 平均：$O(\log_2 n)$。

### 5.3 汇总表

| 情况 | 触发条件 | 递归层数 | 时间复杂度 | 空间复杂度 |
|---|---|---|---|---|
| 最好 | 每次划分均匀 | $O(\log_2 n)$ | $O(n\log_2 n)$ | $O(\log_2 n)$ |
| 最坏 | 初始有序/逆序（未优化） | $O(n)$ | $O(n^2)$ | $O(n)$ |
| 平均 | 随机枢轴假设 | $O(\log_2 n)$ | $O(n\log_2 n)$ | $O(\log_2 n)$ |

- **稳定性**：不稳定。例：序列 `2, 2*, 1`（`2*` 为带下划线标记的 2），以首元素 2 为枢轴划分后，`2*` 被移到 2 的左边，相对次序改变。
- **适用性**：仅适用于**顺序存储**（需随机访问、双指针双向扫描），不适用于链表。

## 6. 易错点与考试写法

1. **一趟排序 ≠ 一次划分**（408 真题定义）：王道书把二者等同，但 408 原题中「一趟排序」指**对所有尚未确定最终位置的元素各处理一遍**，一趟可确定多个元素位置；「一次划分」只对一个连续区间调用一次 `Partition`，只确定一个元素位置。答题以 408 真题定义为准。
2. **枢轴最终位置是 `low == high` 处**，不是初始 `low` 处；初始 `low` 位置的值已被 `pivot` 保存，可被覆盖。
3. **内层 `while` 必须带 `low < high`**，漏写会越界/死循环。
4. **初始有序或逆序时最慢**（$O(n^2)$），这是反直觉的高频考点；不要误答“有序时最快”。
5. **快排不稳定**，举例时注意标出相同关键字的原始相对次序。
6. **快排不适用于链表**，因划分依赖双向随机访问。
7. 答题写到什么程度算对：算法题需写出 `Partition` 与 `QuickSort` 完整可运行代码并注释关键行；复杂度题需说明“时间 = 每层 $O(n)$ × 递归层数，层数由划分均匀程度决定”，只写结论不给推导会扣分。

## 7. 408 题型与解题套路

- **选择题**：
  - 给初始序列，问第一趟划分（或第一趟排序）后的结果 → 按双指针过程手动模拟，注意“一趟”按 408 定义可能含多次划分。
  - 问枢轴最终位置、比较/移动次数 → 模拟 `low`、`high` 移动。
  - 问最坏情况触发条件 → 初始有序/逆序。
  - 问复杂度、稳定性、适用存储结构 → 背表。
  - 与堆排序、归并排序比较：平均时间同量级，但快排常数小、最坏更差、不稳定。
- **算法题套路**：
  1. 写 `Partition`：存枢轴 → 外层 `while(low<high)` → 两个内层 `while` 交替填坑 → 枢轴归位 → 返回 `low`。
  2. 写 `QuickSort`：`if(low<high)` 内先划分、再递归左右。
  3. 若题目要求“找第 k 小”等变体，利用划分后枢轴位置与 k 比较，只递归一侧（此为快排思想的应用，王道书扩展）。
- **常见陷阱**：把“一趟”当“一次划分”；忘记 `low<high` 边界；把最坏情况答成最好；认为快排稳定。

## 9. 背诵卡

1. 快排 = 选枢轴 + 一次划分（左小右大、枢轴归位）+ 递归左右子表。
2. 划分口诀：存枢轴、high 左移填 low、low 右移填 high、相遇放枢轴、返回 low。
3. 时间 = $O(n)$ × 递归层数；最好 $O(n\log_2 n)$，最坏 $O(n^2)$（初始有序/逆序），平均 $O(n\log_2 n)$。
4. 空间 = $O(\text{递归层数})$：最好 $O(\log_2 n)$，最坏 $O(n)$。
5. 快排不稳定、只适用于顺序存储；408 中“一趟排序”可确定多个元素，“一次划分”只确定一个。
