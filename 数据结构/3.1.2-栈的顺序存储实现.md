# 3.1.2 栈的顺序存储实现

## 1. 本节定位

- **对应王道书**：第 3 章 栈、队列和数组，3.1 栈，3.1.2 栈的顺序存储结构（顺序栈）。
- **408 大纲对应**：栈和队列的基本概念、顺序存储结构及其基本操作（初始化、判空、判满、进栈、出栈、读栈顶）。
- **先修知识**：顺序表（3.1 之前的结构体定义、静态数组、`typedef`）、C 语言结构体与引用参数 `&`。
- **本节位置**：承接“栈的逻辑结构（LIFO）”，把逻辑结构落到**顺序存储**上；下一节是链栈，再往后是栈的应用（括号匹配、表达式求值、递归）。

## 2. 一句话结论

顺序栈 = 一个静态数组 `data[MaxSize]` + 一个栈顶指针 `top`；**`top` 的约定（指向栈顶元素 or 指向栈顶后一空位）决定了初始化、判空、判满、进栈、出栈的全部代码写法**，两种约定不能混用。

## 3. 知识地图

```
顺序栈
├── 存储结构定义
│   ├── 静态分配：ElemType data[MaxSize] + int top（王道本节主用）
│   └── 动态分配：ElemType *data + malloc（王道书扩展，本节未展开）
├── top 的两种约定（核心分歧点）
│   ├── 约定 A：top 指向栈顶元素
│   │   ├── 初始化 top = -1
│   │   ├── 判空 top == -1
│   │   ├── 判满 top == MaxSize-1
│   │   ├── 进栈 ++top; data[top]=x
│   │   └── 出栈 x=data[top]; --top
│   └── 约定 B：top 指向栈顶后一空位（下一个可插入位置）
│       ├── 初始化 top = 0
│       ├── 判空 top == 0
│       ├── 判满 top == MaxSize
│       ├── 进栈 data[top]=x; top++
│       └── 出栈 --top; x=data[top]
├── 基本操作（均在 O(1)）
│   ├── InitStack
│   ├── StackEmpty
│   ├── Push（进栈）
│   ├── Pop（出栈，带回 x）
│   ├── GetTop（读栈顶，不删）
│   └── DestroyStack（逻辑清空 + 回收）
└── 共享栈（王道书扩展）
    ├── top0 = -1（从低地址向上长）
    ├── top1 = MaxSize（从高地址向下长）
    └── 判满 top0 + 1 == top1
```

## 4. 核心内容

### 1. 存储结构定义（约定 A：top 指向栈顶元素）

```c
#define MaxSize 10            // 栈的最大容量
typedef struct {
    ElemType data[MaxSize];   // 静态数组存放栈中元素
    int top;                  // 栈顶指针（存的是数组下标，从 0 开始）
} SqStack;                    // Sq = sequence，顺序栈
```

- `SqStack S;` 声明后，系统在内存中分配 `MaxSize * sizeof(ElemType)` 的**连续空间**给 `data`，再分配 4 字节给 `top`。
- `top` 记录的是**数组下标**，不是元素个数；位序（第 1 个元素）与下标（0）差 1，答题时务必分清。

### 2. 初始化

```c
void InitStack(SqStack &S) {
    S.top = -1;               // 初始时栈空，top 指向 -1（无栈顶元素）
}
```

- 为什么不是 `top = 0`？因为 `data[0]` 此时还没有元素，若 `top = 0` 就“假装”有一个栈顶元素，判空逻辑会错。
- 判空：`S.top == -1`。

### 3. 进栈 Push（约定 A）

```c
bool Push(SqStack &S, ElemType x) {
    if (S.top == MaxSize - 1) // 栈满，上溢
        return false;
    S.top = S.top + 1;        // 先让 top 加 1
    S.data[S.top] = x;        // 再存入新元素
    return true;
}
```

王道书简洁写法（等价）：

```c
S.data[++S.top] = x;          // 先 ++top，再用 top 作下标
```

**`++top` 与 `top++` 的区别（本节最易错）**：设当前 `top = 1`（栈顶为 `data[1]`），要插入 `c`，正确位置是 `data[2]`。

- `data[++S.top] = x;` → 先 `top` 变 2，再写 `data[2]`，正确。
- `data[S.top++] = x;` → 先写 `data[1]`（**覆盖了原栈顶 b**），再 `top` 变 2，错误。

### 4. 出栈 Pop（约定 A）

```c
bool Pop(SqStack &S, ElemType &x) {
    if (S.top == -1)          // 栈空，下溢
        return false;
    x = S.data[S.top];        // 先取出栈顶元素
    S.top = S.top - 1;        // 再让 top 下移
    return true;
}
```

简洁写法：`x = S.data[S.top--];`（先取值，再 `top--`）。

- `x` 是**引用参数** `&x`：函数内改的就是调用者那个变量本身，不是副本，所以能把栈顶值带回。
- 出栈只是 `top` 下移，**被删元素的数据仍残留在数组中**，只是逻辑上不属于栈了。

**`top--` 与 `--top` 的区别**：设 `top = 2`（栈顶为 `data[2] = j`），应返回 `j`。

- `x = S.data[S.top--];` → 先取 `data[2]`（j），再 `top` 变 1，正确。
- `x = S.data[--S.top];` → 先 `top` 变 1，再取 `data[1]`（i），错误。

### 5. 读栈顶 GetTop（约定 A）

```c
bool GetTop(SqStack S, ElemType &x) {
    if (S.top == -1)          // 栈空
        return false;
    x = S.data[S.top];        // 只取值，top 不动
    return true;
}
```

与 Pop 的唯一区别：**不执行 `top--`**，栈内容不变。

### 6. 判空 / 判满 / 销毁

- 判空：`S.top == -1`。
- 判满：`S.top == MaxSize - 1`。
- 销毁：逻辑清空只需 `S.top = -1`；本节用变量声明方式分配空间（未用 `malloc`），函数结束后系统自动回收，无需手动 `free`。

### 7. 约定 B：top 指向栈顶后一空位（对比记忆）

| 操作 | 约定 A（top 指栈顶元素） | 约定 B（top 指栈顶后一空位） |
|---|---|---|
| 初始化 | `top = -1` | `top = 0` |
| 判空 | `top == -1` | `top == 0` |
| 判满 | `top == MaxSize - 1` | `top == MaxSize` |
| 进栈 | `data[++top] = x` | `data[top++] = x` |
| 出栈 | `x = data[top--]` | `x = data[--top]` |

**做题先审题**：题目说 `top` 指向栈顶元素，还是指向栈顶元素的下一个位置？两种约定代码完全相反。

### 8. 共享栈（王道书扩展，了解即可）

两个栈共享一片连续空间，提高内存利用率：

```c
typedef struct {
    ElemType data[MaxSize];
    int top0;                 // 0 号栈栈顶，初始 -1，从低地址向高地址长
    int top1;                 // 1 号栈栈顶，初始 MaxSize，从高地址向低地址长
} ShStack;
```

- 初始化：`top0 = -1; top1 = MaxSize;`
- 判满：`top0 + 1 == top1`（两栈顶相邻即满）。
- 逻辑上是两个栈，物理上共享同一片空间。

## 5. 复杂度分析

设栈中当前元素个数为 $n$，栈容量为 $MaxSize$。

- **进栈 Push**：只做一次判满比较 + 一次下标自增 + 一次赋值，与 $n$ 无关 → 最好 / 最坏 / 平均均为 $O(1)$。
- **出栈 Pop**：一次判空比较 + 一次取值 + 一次下标自减 → $O(1)$。
- **读栈顶 GetTop**：一次判空 + 一次取值 → $O(1)$。
- **判空 / 判满 / 初始化**：常数次比较或赋值 → $O(1)$。

**平均情况推导**：以上操作执行的语句条数都是常数（不随 $n$ 变化），不存在“按位置不同而代价不同”的分支，因此平均代价 = 最坏代价 = 最好代价 = $O(1)$，无需概率假设。这与顺序表按位查找 $O(1)$ 同理：**连续存储 + 元素等长 + 已知起始地址**，下标直接算出地址，一次访存即可定位。

## 6. 易错点与考试写法

1. **`++top` 与 `top++` 写反**：约定 A 进栈必须 `data[++top] = x`；写成 `data[top++] = x` 会覆盖原栈顶。出栈必须 `x = data[top--]`；写成 `x = data[--top]` 会返回次栈顶。**不要背代码，按“top 当前指向谁”现场推**。
2. **`top` 的约定与题目不一致**：题目若规定 `top` 指向栈顶后一位置，则初始化 `top = 0`、判满 `top == MaxSize`、进栈 `data[top++] = x`。答题前先圈出题目的约定。
3. **判空 / 判满条件写错**：约定 A 下判满是 `top == MaxSize - 1`，不是 `top == MaxSize`；判空是 `top == -1`，不是 `top == 0`。
4. **出栈参数漏写引用 `&`**：`bool Pop(SqStack &S, ElemType &x)`，`x` 必须是引用（C++）或指针（C），否则栈顶值带不回来。
5. **误以为出栈会清空数组元素**：出栈只移动 `top`，数据仍残留，逻辑删除 ≠ 物理清除。
6. **答题标准**：408 算法题/选择题中，写出结构体定义 + 初始化 + 进栈/出栈函数（含判空判满）即算完整；注释写清 `top` 的约定，避免阅卷歧义。

## 7. 408 题型与解题套路

- **选择题高频考法**：
  - 给 `top` 初值和一串进栈/出栈操作，问最终 `top` 值或栈内元素——按约定逐条模拟，注意 `top` 是下标不是个数。
  - 给 `top` 的约定，问判空/判满表达式——直接套上表。
  - 问 `data[++top]` 与 `data[top++]` 的区别——考自增运算符前置/后置。
  - 共享栈判满条件 `top0 + 1 == top1`。
- **算法题套路**：顺序栈常作为“辅助栈”出现在括号匹配、表达式求值、进制转换、递归非递归化中；此时只需会调用 `Push/Pop/GetTop/StackEmpty`，不必重写。
- **常见陷阱**：题目给的是“栈顶指针指向栈顶元素的下一个位置”，但考生按王道默认约定（指向栈顶元素）作答，导致判空判满全错。

## 8. 自测题

**1.** 约定 `top` 指向栈顶元素，`MaxSize = 10`，初始 `top = -1`。依次执行 Push(a)、Push(b)、Pop(x)、Push(c)，此时 `top` 的值和栈内元素分别是什么？

**2.** 下列进栈代码（约定 A）哪句正确？A. `S.data[S.top++] = x;` B. `S.data[++S.top] = x;`

**3.** 若约定 `top` 指向栈顶后一空位，写出判空、判满条件及出栈的核心语句。

**4.** 共享栈 `top0 = -1, top1 = MaxSize`，判断栈满的条件是什么？为什么？

**5.** 顺序栈的进栈、出栈、读栈顶时间复杂度为什么都是 $O(1)$？

<details>
<summary>参考答案</summary>

1. Push(a)：`top=0`，`data[0]=a`；Push(b)：`top=1`，`data[1]=b`；Pop(x)：`x=b`，`top=0`；Push(c)：`top=1`，`data[1]=c`。最终 `top = 1`，栈内元素为 a、c（`data[0]=a, data[1]=c`，b 残留但已逻辑删除）。
2. B。`++S.top` 先自增再作下标，写入新栈顶位置；A 会先写旧 `top` 位置，覆盖原栈顶。
3. 判空 `top == 0`；判满 `top == MaxSize`；出栈 `x = S.data[--S.top];`（先 `top` 减 1 再取值）。
4. `top0 + 1 == top1`。0 号栈从低地址向上长、1 号栈从高地址向下长，当两栈顶指针相邻（中间无空位）时整片空间已满。
5. 顺序栈用连续等长数组存储，`top` 直接是下标，进栈/出栈/读栈顶都只做常数次比较、下标加减和一次赋值/取值，执行语句条数与栈中元素个数 $n$ 无关，故最好、最坏、平均均为 $O(1)$。

</details>

## 9. 背诵卡

1. 顺序栈 = 静态数组 `data[MaxSize]` + `int top`；`Sq` 是 sequence 的缩写。
2. 约定 A（top 指栈顶元素）：初始化 `-1`，判空 `==-1`，判满 `==MaxSize-1`，进栈 `data[++top]=x`，出栈 `x=data[top--]`。
3. 约定 B（top 指栈顶后一空位）：初始化 `0`，判空 `==0`，判满 `==MaxSize`，进栈 `data[top++]=x`，出栈 `x=data[--top]`。
4. 出栈参数 `x` 必须加引用 `&`；出栈只移 `top`，数据残留，逻辑删除。
5. 共享栈判满：`top0 + 1 == top1`；所有基本操作 $O(1)$。
