# 6.4.2 最短路径问题：Dijkstra 算法

## 1. 本节定位

---

## 2. 一句话结论

Dijkstra 算法用「贪心 + 逐轮确定」的方式求**单源、带权、无负权边**图的最短路径，时间复杂度 $O(|V|^2)$，**不能处理负权边**。

---

## 3. 知识地图

```
最短路径问题
├── 单源最短路径（一个起点到其余各点）
│   ├── BFS（上一节）——仅限无权图
│   └── Dijkstra 算法（本节）——带权图，无负权边

└── 多源最短路径（各顶点之间）
    └── Floyd 算法（下一节）
```

## 4. 核心内容

### 4.1 为什么 BFS 不够用

BFS 求最短路径只适用于**无权图**（每条边代价相同）。在带权图中，边数最少的路径不一定权值之和最小。

例：从 v0 到 v2，直接边权为 7；经 v1 中转，两段权为 10 和 -5（负权例子见 4.5）。带权路径长度 = 路径上所有边权值之和，本节之后「路径长度」均指**带权路径长度**。

### 4.2 三个辅助数组（核心！）

设起点为 v0，顶点编号 0 ~ n-1：

| 数组 | 含义 | 初始化 |
|---|---|---|
| `final[i]` | 布尔值，是否已确定 v0→vi 的最短路径 | `final[0]=true`，其余 `false` |
| `dist[i]` | 当前已知的 v0→vi 最短路径长度（可能还会被改进） | `dist[i] = arcs[0][i]`（v0 到 vi 的弧长，无弧则为 ∞）；`dist[0]=0` |
| `path[i]` | vi 在最短路径上的**直接前驱**顶点编号 | 有弧 v0→vi 则 `path[i]=0`，否则 `path[i]=-1` |

> 注意：`dist` 是「当前最优」，不是「最终答案」；只有 `final[i]=true` 后 `dist[i]` 才是最终最短路径长度。

### 4.3 算法执行流程（手动模拟必须会）

```
1. 初始化 final / dist / path（见上表）
2. 重复 n-1 轮：
   a. 在 final[i]==false 的顶点中，选 dist 最小的顶点 vk
   b. final[k] = true          // vk 的最短路径已确定
   c. 松弛：对所有 final[j]==false 且存在弧 vk→vj 的顶点 j：
        若 dist[k] + arcs[k][j] < dist[j]：
            dist[j] = dist[k] + arcs[k][j]
            path[j] = k
3. 结束，dist[] 即各点最短路径长度，path[] 可回溯完整路径
```

### 4.4 王道例题手动模拟（有向带权图，起点 v0）

设边：v0→v1=10，v0→v4=5，v4→v1=3，v4→v2=9，v4→v3=2，v3→v2=6，v1→v2=1，v1→v4=…（按转写给出的权值）。

**初始**：

| 顶点 | v0 | v1 | v2 | v3 | v4 |
|---|---|---|---|---|---|
| final | T | F | F | F | F |
| dist | 0 | 10 | ∞ | ∞ | 5 |
| path | -1 | 0 | -1 | -1 | 0 |

**第 1 轮**：未确定中 dist 最小是 v4（5）→ `final[4]=T`。松弛 v4 的出边：
- v1：5+3=8 < 10 → dist[1]=8，path[1]=4
- v2：5+9=14 < ∞ → dist[2]=14，path[2]=4
- v3：5+2=7 < ∞ → dist[3]=7，path[3]=4

**第 2 轮**：未确定中最小是 v3（7）→ `final[3]=T`。松弛 v3 出边：
- v2：7+6=13 < 14 → dist[2]=13，path[2]=3

**第 3 轮**：未确定中最小是 v1（8）→ `final[1]=T`。松弛 v1 出边：
- v2：8+1=9 < 13 → dist[2]=9，path[2]=1

**第 4 轮**：只剩 v2（9）→ `final[2]=T`，无未确定顶点，结束。

**最终结果**：

| 顶点 | v0 | v1 | v2 | v3 | v4 |
|---|---|---|---|---|---|
| final | T | T | T | T | T |
| dist | 0 | 8 | 9 | 7 | 5 |
| path | -1 | 4 | 1 | 4 | 0 |

**回溯 v0→v2 路径**：path[2]=1 → path[1]=4 → path[4]=0 → path[0]=-1，得路径 v0→v4→v1→v2，长度 9。

### 4.5 负权边失效（必考坑）

反例：v0→v1=10，v0→v2=7，v1→v2=-5。

- 初始 dist[2]=7，第 1 轮选 v2（7），`final[2]=T`，认定 v0→v2 最短为 7。
- 但实际 v0→v1→v2 = 10+(-5) = 5 < 7，算法已无法修正。

**结论**：Dijkstra 算法**不适用于含负权边的图**。原因：算法假设「已确定顶点的最短路径不会再被改进」，负权边会破坏这一贪心前提。

### 4.6 与 Prim 算法的对比（408 常考对比）

| 对比项 | Prim | Dijkstra |
|---|---|---|
| 目标 | 最小生成树 | 单源最短路径 |
| 辅助数组 | `lowcost[]`：顶点到生成树的最小代价 | `dist[]`：起点到该顶点的最短路径长度 |
| 更新方式 | `lowcost[j] = min(lowcost[j], arcs[k][j])` | `dist[j] = min(dist[j], dist[k]+arcs[k][j])` |
| 时间复杂度 | $O(|V|^2)$ | $O(|V|^2)$ |
| 思想 | 贪心，逐点加入 | 贪心，逐点确定 |

> 关键区别：Prim 的 `lowcost` 只看「一条边」，Dijkstra 的 `dist` 是「路径累加」，所以 Dijkstra 多一个 `dist[k] +`。

### 4.7 代码实现（王道风格，邻接矩阵）

```c
#define INF 0x3f3f3f3f
#define MAXV 100

// 前提：图用邻接矩阵 arcs[MAXV][MAXV] 存储，arcs[i][j] 为弧 i→j 的权值
// 顶点编号 0 ~ n-1，起点为 v0
void Dijkstra(int n, int arcs[][MAXV], int v0,
              int dist[], int path[], bool final[]) {
    // 1. 初始化
    for (int i = 0; i < n; i++) {
        dist[i]  = arcs[v0][i];      // 起点到 i 的弧长，无弧为 INF
        final[i] = false;
        if (i != v0 && dist[i] < INF)
            path[i] = v0;            // 有直接弧，前驱为 v0
        else
            path[i] = -1;            // 无弧或起点自身
    }
    dist[v0]  = 0;
    final[v0] = true;                // 起点自身最短路径已确定

    // 2. 共 n-1 轮，每轮确定一个顶点
    for (int round = 1; round < n; round++) {
        int k = -1, minDist = INF;
        // 2a. 在未确定顶点中找 dist 最小者
        for (int i = 0; i < n; i++) {
            if (!final[i] && dist[i] < minDist) {
                minDist = dist[i];
                k = i;
            }
        }
        if (k == -1) break;          // 剩余顶点不可达，提前结束
        final[k] = true;             // 2b. 确定 vk 的最短路径

        // 2c. 松弛 vk 的所有出边
        for (int j = 0; j < n; j++) {
            if (!final[j] && arcs[k][j] < INF
                && dist[k] + arcs[k][j] < dist[j]) {
                dist[j] = dist[k] + arcs[k][j];
                path[j] = k;         // 记录前驱
            }
        }
    }
}
```

> 注意：`arcs[v0][v0]` 应初始化为 0 或 INF 均可，因为 `dist[v0]` 随后被强制置 0。

## 5. 复杂度分析

设顶点数 $n=|V|$，边数 $e=|E|$。

**每轮开销**：
- 找最小 `dist`：扫描整个 `dist` 数组，$O(n)$；
- 松弛出边：
  - 邻接矩阵：扫描 vk 对应的一整行，$O(n)$；
  - 邻接表：扫描 vk 的所有出边，$O(\deg^+(v_k))$，但找最小仍需 $O(n)$，故每轮仍为 $O(n)$（邻接表优势体现在稀疏图常数上，渐进阶不变）。

**总复杂度**：共 $n-1$ 轮，每轮 $O(n)$，故

$$T(n) = (n-1)\cdot O(n) = O(n^2) = O(|V|^2)$$

**最好 / 最坏 / 平均**：三种情况均为 $O(|V|^2)$，因为无论图稠密还是稀疏，每轮「找最小 dist」都必须扫描整个数组，与边数无关。**这是 Dijkstra 朴素实现的固有代价**。

> 补充（王道扩展，了解即可）：用优先队列（小根堆）优化「找最小」可降至 $O((|V|+|E|)\log|V|)$，但 408 初试只考朴素 $O(|V|^2)$ 版本。

## 6. 易错点与考试写法

1. **`dist` 不是最终答案**：只有 `final[i]=true` 后 `dist[i]` 才可信。模拟题中若问「第 k 轮后 dist 数组」，要严格按轮次写。
2. **松弛条件写错**：必须是 `dist[k] + arcs[k][j] < dist[j]`，不能写成 `arcs[k][j] < dist[j]`（那是 Prim）。
3. **只松弛未确定顶点**：`final[j]==true` 的顶点不再更新，否则会破坏已确定结果。
4. **负权边**：题目若给负权，Dijkstra 直接失效，必须指出「不适用」，不能硬算。
5. **无向图**：一条无向边等价于两条有向边，算法照常运行，初始化时 `arcs[i][j]=arcs[j][i]=w`。
6. **不可达顶点**：`dist` 保持 ∞，`path` 保持 -1，不要误标 `final`。
7. **答题程度**：408 初试只要求**手动模拟**——写出每轮的 final/dist/path 变化表，并能回溯路径。代码实现「能读懂、能补全关键行」即可，不要求完整默写。

## 7. 408 题型与解题套路

**选择题常见考法**：
- 给图，问第 k 轮后某顶点的 `dist` 值；
- 问最终 `path` 数组内容或某条最短路径经过的顶点序列；
- 问算法能否处理负权边（答案：不能）；
- 与 Prim 对比：辅助数组含义、更新公式、复杂度。

**算法题套路**：
- 若题目要求「求单源最短路径」且**无负权**，直接套 Dijkstra，写初始化 + n-1 轮循环 + 松弛三段；
- 若出现负权，改用 Bellman-Ford（408 不考，但要知道 Dijkstra 不适用）；
- 若要求「多源」，用 Floyd（下一节）。

**常见陷阱**：
- 把 `dist` 初值写成 0（应为弧长或 ∞）；
- 忘记 `final[v0]=true`；
- 轮数写成 n 轮（应为 n-1 轮）；
- 松弛时用了已确定顶点。

## 8. 自测题

**题 1**：Dijkstra 算法中，`dist[i]` 在 `final[i]=false` 时的含义是什么？

**题 2**：含负权边的图能否用 Dijkstra 求最短路径？说明原因。

**题 3**：n 个顶点的图，Dijkstra 算法共需几轮「选最小 + 松弛」？为什么？

**题 4**：Dijkstra 与 Prim 的辅助数组更新公式有何本质区别？

**题 5**：邻接矩阵存储时，Dijkstra 时间复杂度为什么是 $O(|V|^2)$？邻接表能否降低渐进阶？

<details>
<summary>参考答案</summary>

**题 1**：表示「当前已知的、从起点到 vi 的暂定最短路径长度」，可能还会被后续轮次改进，不是最终答案。

**题 2**：不能。Dijkstra 基于贪心，假设已确定顶点的最短路径不会再被改进；负权边可能使「绕路」路径更短，破坏该假设，导致结果错误。

**题 3**：n-1 轮。起点 v0 初始化即确定，剩余 n-1 个顶点每轮确定一个。

**题 4**：Prim 更新 `lowcost[j] = min(lowcost[j], arcs[k][j])`，只看单条边；Dijkstra 更新 `dist[j] = min(dist[j], dist[k]+arcs[k][j])`，是路径累加，多一个 `dist[k]+`。

**题 5**：每轮找最小 dist 需扫描 $O(n)$，松弛邻接矩阵一行也需 $O(n)$，共 n-1 轮，故 $O(n^2)$。邻接表松弛出边可降为 $O(\deg^+)$，但「找最小 dist」仍须 $O(n)$，渐进阶不变，仍为 $O(|V|^2)$。

</details>

## 9. 背诵卡

1. **三数组**：`final`（是否确定）、`dist`（暂定最短长度）、`path`（直接前驱）。
2. **初始化**：`final[v0]=true`，`dist[i]=arcs[v0][i]`，有弧 `path[i]=v0` 否则 -1。
3. **n-1 轮**：选未确定中 dist 最小者 → 标记 final → 松弛出边 `dist[k]+arcs[k][j] < dist[j]`。
4. **复杂度**：$O(|V|^2)$，与边数无关；邻接表不降阶。
5. **禁区**：负权边失效；与 Prim 区别在「路径累加」而非「单边代价」。
