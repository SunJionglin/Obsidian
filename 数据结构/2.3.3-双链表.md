# 2.3.3 双链表

## 1. 本节定位

- **对应王道书**：第 2 章线性表 2.3 节「线性表的链式表示」中的双链表部分（2.3.3）。
- **408 大纲对应**：线性表的链式存储结构——双向链表的基本操作（插入、删除、查找、遍历）。
- **先修知识**：单链表（2.3.1 定义、2.3.2 基本操作）——尤其是带头结点的单链表、`malloc` 申请结点、指针改序问题。
- **本章位置**：单链表 → **双链表** → 循环链表 → 静态链表。双链表是单链表的“加一个前驱指针”的扩展，是后续循环双链表的基础。

## 2. 一句话结论

双链表在单链表结点上增加 `prior` 前驱指针，使“找前驱”从 $O(n)$ 变为 $O(1)$；**插入/删除的核心是四句/三句指针修改，且必须处理“操作的是最后一个结点”的空指针边界**。

## 3. 知识地图

```
双链表
├── 定义
│   ├── 结点结构：prior | data | next
│   ├── 类型重命名：DNode（强调结点）/ DLinkList（强调链表）
│   └── 带头结点：头结点 prior 永远为 NULL
├── 基本操作
│   ├── 初始化 InitDLinkList
│   ├── 判空（头结点 next == NULL）
│   ├── 插入
│   │   ├── 后插（核心，四句指针）
│   │   ├── 前插（找前驱 → 对前驱后插）
│   │   └── 按位序插入（找第 i-1 个 → 后插）
│   ├── 删除
│   │   ├── 删除 p 的后继 q（三句指针 + 边界判断）
│   │   └── 销毁（循环删头结点后继，最后释放头结点）
│   └── 遍历

│       └── 前向遍历（prior 方向，可跳过/不跳过头结点）
└── 查找

    └── 按值查找：遍历 + 比较，O(n)
```

## 4. 核心内容

### 4.1 定义与结点结构

单链表每个结点只有指向后继的指针，给定结点 `p` 找其前驱很麻烦（要从头遍历）。双链表在单链表基础上**增加一个指针域 `prior` 指向前驱**。

```c
typedef struct DNode {        // 双链表结点
    ElemType data;            // 数据域
    struct DNode *prior;      // 前驱指针
    struct DNode *next;       // 后继指针
} DNode, *DLinkList;
```

- `DNode` 强调“这是一个结点”，`DLinkList` 强调“这是一个链表”，与单链表 `LNode / LinkList` 的命名习惯一致。
- 本节讨论**带头结点**的情况。

### 4.2 初始化与判空

```c
bool InitDLinkList(DLinkList *L) {
    *L = (DNode *)malloc(sizeof(DNode));  // 分配头结点
    if (*L == NULL) return false;         // 内存不足
    (*L)->prior = NULL;                   // 头结点无前驱，永远为 NULL
    (*L)->next  = NULL;                   // 初始为空表
    return true;
}

bool Empty(DLinkList L) {
    return (L->next == NULL);             // 头结点 next 为空即表空
}
```

**关键**：头结点的 `prior` 永远为 `NULL`（它前面不可能再有结点）。

### 4.3 插入——后插操作（核心，408 必考）

在结点 `p` 之后插入新结点 `s`，**四句指针**（王道书顺序）：

```c
// 前提：p 非空，s 已分配好
s->next = p->next;        // ① s 的后继指向 p 原来的后继
if (p->next != NULL)      // ② 若 p 有后继，其后继的 prior 指向 s
    p->next->prior = s;
s->prior = p;             // ③ s 的前驱指向 p
p->next = s;              // ④ p 的后继指向 s
```

**为什么第 ② 句要加 if**：若 `p` 是最后一个结点，`p->next == NULL`，直接写 `p->next->prior = s` 会**空指针访问**。这是王道书原代码的 bug，必须补上判断。

**改序陷阱**：若先执行 ④ 再执行 ①，则 ④ 已让 `p->next = s`，再执行 ① 时 `s->next = p->next = s`，**s 指向自己**，链表断裂。所以 ① 必须在 ④ 之前。

### 4.4 前插与按位序插入（都归约为后插）

- **前插**：在 `p` 之前插入 `s`。双链表能 $O(1)$ 找到 `p->prior`，于是对 `p->prior` 执行后插即可。
- **按位序插入**：从头结点出发找到第 $i-1$ 个结点（前驱），对其执行后插。

> 结论：**只要后插写对，前插、按位序插入都能复用**。

### 4.5 删除——删除 p 的后继 q（408 必考）

```c
bool DeleteNextDNode(DNode *p) {
    if (p == NULL) return false;
    DNode *q = p->next;          // q 为待删除结点
    if (q == NULL) return false; // p 无后继，删除失败
    p->next = q->next;           // ① p 的后继跨过 q
    if (q->next != NULL)         // ② 若 q 有后继，其后继的 prior 指向 p
        q->next->prior = p;
    free(q);                     // ③ 释放 q
    return true;
}
```

**边界**：若 `q` 是最后一个结点，`q->next == NULL`，第 ② 句必须跳过，否则空指针。

### 4.6 销毁双链表

```c
void DestroyList(DLinkList *L) {
    while ((*L)->next != NULL)       // 反复删除头结点的后继
        DeleteNextDNode(*L);
    free(*L);                        // 最后释放头结点
    *L = NULL;                       // 头指针置空
}
```

### 4.7 遍历

```c
// 后向遍历
void PrintNext(DNode *p) {
    while (p != NULL) {
        // 处理 p（如打印 p->data）
        p = p->next;
    }
}

// 前向遍历（不处理头结点）
void PrintPrior(DNode *p) {
    while (p->prior != NULL) {   // 条件保证不处理头结点
        // 处理 p
        p = p->prior;
    }
}
```

- 后向遍历从头结点开始会处理头结点；若只想处理数据结点，从 `L->next` 开始。
- 前向遍历用 `p->prior != NULL` 作条件，天然跳过 `prior` 为 `NULL` 的头结点。

### 4.8 查找

- **按位查找**：遍历 + 计数器，找到第 $i$ 个结点。
- **按值查找**：遍历 + 比较 `data`。
- 双链表**没有随机存取特性**，只能顺序找，均为 $O(n)$。

## 5. 复杂度分析

设表长为 $n$（数据结点数）。

| 操作 | 最好 | 最坏 | 平均 |
|---|---|---|---|
| 后插（已知 p） | $O(1)$ | $O(1)$ | $O(1)$ |
| 前插（已知 p） | $O(1)$ | $O(1)$ | $O(1)$ |
| 按位序插入 | $O(1)$（i=1） | $O(n)$（i=n+1） | $O(n)$ |
| 删除 p 的后继 | $O(1)$ | $O(1)$ | $O(1)$ |
| 按位查找 | $O(1)$（i=1） | $O(n)$（i=n） | $O(n)$ |
| 按值查找 | $O(1)$（首元素命中） | $O(n)$（末尾或不存在） | $O(n)$ |

**平均推导（按位查找）**：假设查找第 $i$ 个位置等概率，$P_i = 1/n$，比较次数为 $i$，则
$$ASL = \sum_{i=1}^{n} \frac{1}{n} \cdot i = \frac{1}{n}\cdot\frac{n(n+1)}{2} = \frac{n+1}{2} = O(n).$$

**平均推导（按值查找）**：假设目标值出现在每个位置等概率且一定存在，比较次数同上，$ASL = (n+1)/2 = O(n)$；若目标可能不存在，最坏需比较 $n$ 次，仍为 $O(n)$。

> 注意：后插/前插/删除后继之所以 $O(1)$，前提是**已给定结点指针 p**；若要先按位序找到 p，则整体退化为 $O(n)$。

## 6. 易错点与考试写法

1. **后插四句的顺序**：① `s->next = p->next` 必须在 ④ `p->next = s` 之前，否则 `s->next` 指向自己。答题时按王道顺序写，并注明“先接后、再改前”。
2. **边界判断不能漏**：`p->next != NULL`（后插）与 `q->next != NULL`（删除）是王道书原代码的缺陷，**408 算法题写完整版才拿满分**。
3. **头结点 `prior` 恒为 NULL**：初始化必须置 `NULL`，前向遍历靠它判断到头。
4. **判空只看 `L->next`**：不要用 `L->prior` 判空（它永远为 NULL，判不出空表）。
5. **`free` 后要置空/更新指针**：删除时先改指针再 `free(q)`，顺序反了会丢失后继。
6. **答题程度**：408 算法题要求写出完整可运行函数（含类型定义、边界判断、返回值），只写四句指针不给满分；选择题常考“某句写错会怎样”。

## 7. 408 题型与解题套路

- **选择题**：
  - 给一段双链表插入/删除代码，问“哪一句有错”或“执行后链表形态”。
  - 考“在 p 后插入 s 的正确语句顺序”。
  - 考“删除 p 的后继需要修改几个指针”。
  - 考双链表与单链表在“找前驱”上的复杂度差异。
- **算法题套路**：
  1. 先写结点类型定义；
  2. 写带头结点的初始化；
  3. 插入统一归约为“找前驱 → 后插”；
  4. 删除统一为“改前驱 next、改后继 prior、free”；
  5. **每个改指针处都检查是否为空**。
- **常见陷阱**：把 `p->next->prior = s` 写在 `if` 外；先改 `p->next` 再取 `p->next`；忘记释放结点；前向遍历把头结点也处理了。

## 8. 自测题

**1.** 在双链表结点 `p` 之后插入 `s`，下列语句顺序正确的是（ ）  
A. `p->next=s; s->prior=p; s->next=p->next;`  
B. `s->next=p->next; p->next->prior=s; s->prior=p; p->next=s;`  
C. `s->prior=p; s->next=p->next; p->next=s;`  
D. `p->next=s; s->next=p->next; s->prior=p;`

**2.** 双链表删除 `p` 的后继 `q`，若 `q` 是最后一个结点，需要修改几个指针？为什么？

**3.** 带头结点双链表判空的条件是什么？为什么不用 `L->prior == NULL`？

**4.** 双链表按值查找的平均比较次数是多少？写出推导。

**5.** 写出在双链表第 $i$ 个位置插入元素 `e` 的完整函数（带头结点，含边界判断）。

<details>
<summary>答案</summary>

**1. B。** 必须先让 `s->next` 接上 `p` 原来的后继，再改 `p->next`；且 `p->next->prior` 需在 `p->next` 被改前访问（严格版还应加 `if (p->next != NULL)`）。

**2. 只改 1 个指针**（`p->next = q->next`，即置 NULL），因为 `q` 无后继，`q->next->prior` 那句必须跳过，否则空指针。

**3. `L->next == NULL`。** 头结点的 `prior` 永远为 `NULL`，无论表空不空都成立，无法区分空表与非空表。

**4. $\frac{n+1}{2}$。** 设目标等概率出现在 $n$ 个位置，$P_i=1/n$，比较次数 $i$，$ASL=\sum_{i=1}^n \frac{i}{n}=\frac{n+1}{2}=O(n)$。

**5. 参考：**
```c
bool InsertDLinkList(DLinkList L, int i, ElemType e) {
    if (i < 1) return false;
    DNode *p = L;                 // 从头结点开始
    int j = 0;                    // 当前 p 是第 j 个结点（头结点为 0）
    while (p != NULL && j < i - 1) {  // 找第 i-1 个结点
        p = p->next; j++;
    }
    if (p == NULL) return false;  // i 越界
    DNode *s = (DNode *)malloc(sizeof(DNode));
    if (s == NULL) return false;
    s->data = e;
    s->next = p->next;
    if (p->next != NULL) p->next->prior = s;
    s->prior = p;
    p->next = s;
    return true;
}
```

## 9. 背诵卡

1. 双链表结点 = `prior | data | next`；头结点 `prior` 恒 NULL。
2. 后插四句：**接后 → 改后之前 → 接前 → 改前之后**；`p->next` 为空要跳过第二句。
3. 删除后继三句：**跨过 → 改后之前（判空）→ free**。
4. 前插、按位序插入都归约为“找前驱 → 后插”。
5. 双链表无随机存取，按位/按值查找均 $O(n)$，平均 $\frac{n+1}{2}$ 次比较。

## 10. 关联与下一节

- **向前关联**：单链表的头插/尾插、带头结点判空、`malloc/free`；双链表只是多维护一个 `prior`。
- **向后关联**：**循环双链表**——把尾结点 `next` 指向头结点、头结点 `prior` 指向尾结点，插入删除的边界判断会进一步简化（因为 `p->next` 永不为 NULL），是 408 高频对比考点。
