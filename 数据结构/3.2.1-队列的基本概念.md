# 3.2.1 队列的基本概念

## 1. 本节定位

- **王道书对应**：第 3 章「栈、队列和数组」→ 3.2 队列 → 3.2.1 队列的基本概念。
- **408 大纲对应**：队列的基本概念（逻辑结构、基本操作），属于「栈、队列和数组」这一条。
- **先修知识**：线性表（逻辑结构、基本操作）、栈（操作受限的线性表、后进先出 LIFO）。
- **本章位置**：本节是队列的「总纲」，只讲逻辑结构与操作定义，不涉及存储实现；后续 3.2.2 顺序存储（循环队列）、3.2.3 链式存储才讲具体实现。本节与「栈的基本概念」是并列对照关系。

## 2. 一句话结论

队列是**只允许在一端（队尾 rear）插入、在另一端（队头 front）删除**的操作受限线性表，因此具有**先进先出（FIFO）**特性。

## 3. 知识地图

```
队列 Queue
├── 逻辑结构：线性表（操作受限）
│   ├── 插入端 = 队尾 rear（入队 EnQueue）
│   └── 删除端 = 队头 front（出队 DeQueue）
├── 核心特性：先进先出 FIFO（First In First Out）
│   └── 对照：栈 = 后进先出 LIFO（Last In First Out）
├── 术语
│   ├── 队头 front / 队头元素
│   ├── 队尾 rear / 队尾元素
│   └── 空队列（无任何元素）
└── 基本操作（与线性表一致：创销增删查）
    ├── InitQueue(&Q)        初始化，构造空队列
    ├── DestroyQueue(&Q)     销毁，释放空间
    ├── EnQueue(&Q, x)       入队：x 从队尾插入
    ├── DeQueue(&Q, &x)      出队：删除队头元素并用 x 返回
    ├── GetHead(Q, &x)       读队头元素：只返回不删除
    └── QueueEmpty(Q)        判空
```

## 4. 核心内容

### 4.1 定义

队列（Queue）是只允许在**一端进行插入**、在**另一端进行删除**的线性表。

- 允许插入的一端称为**队尾（rear）**，插入操作称为**入队**。
- 允许删除的一端称为**队头（front）**，删除操作称为**出队**。
- 不含任何元素的队列称为**空队列**。

与栈对照：栈只允许在**同一端**插入和删除；队列是**两端分工**，这正是 FIFO 的根源。

### 4.2 性质：先进先出

先入队的元素一定先出队，记作 **FIFO（First In First Out）**。考试常用英文缩写表示，需认识 `FIFO`；对应栈的 `LIFO`。

生活模型（帮助理解，非考点）：食堂排队打饭——新人只能站到队尾，大师傅只给队头的人打饭，打完即离开；过收费站排队的汽车同理。

### 4.3 基本操作（C 语言风格，王道写法）

> 以下为**操作定义**，不是完整可运行实现；具体实现依赖存储结构（顺序/链式），在 3.2.2、3.2.3 展开。`ElemType` 为元素类型。

```c
// 初始化队列，构造一个空队列 Q
void InitQueue(Queue &Q);

// 销毁队列，释放 Q 所占内存空间
void DestroyQueue(Queue &Q);

// 入队：若 Q 未满，将 x 加入队尾
bool EnQueue(Queue &Q, ElemType x);

// 出队：若 Q 非空，删除队头元素，并用 x 返回
bool DeQueue(Queue &Q, ElemType &x);

// 读队头元素：若 Q 非空，用 x 返回队头元素，但不删除
bool GetHead(Queue Q, ElemType &x);

// 判空：Q 为空返回 true，否则 false
bool QueueEmpty(Queue Q);
```

**关键区分（高频考点）**：

| 操作 | 是否修改队列 | 返回什么 |
|---|---|---|
| `DeQueue(&Q, &x)` | 删除队头元素 | 被删元素的值给 x |
| `GetHead(Q, &x)` | **不删除**，仅读取 | 队头元素的值给 x |

`GetHead` 与栈的「读栈顶元素」对应，`DeQueue` 与「出栈」对应。

### 4.4 图解（文字示意）

```
        入队 EnQueue(x)                出队 DeQueue()
              ↓                            ↓
    ┌────┬────┬────┬────┐
    │ a1 │ a2 │ a3 │ a4 │
    └────┴────┴────┴────┘
      ↑                    ↑
   队头 front           队尾 rear
   （只能删除）          （只能插入）
```

出队顺序必为 a1 → a2 → a3 → a4，与入队顺序一致，即 FIFO。

## 5. 复杂度分析

本节只定义逻辑结构与操作语义，**未涉及具体存储实现**，因此各操作的时间复杂度取决于后续存储结构：

- **顺序存储（循环队列）**：入队、出队、读队头、判空均为 $O(1)$（只需移动/比较下标）。
- **链式存储（链队列）**：入队、出队、读队头、判空均为 $O(1)$（队头队尾指针直接操作）。
- **平均情况**：单次操作与元素个数 $n$ 无关，恒为 $O(1)$；不存在「按位置/按值查找」的遍历过程，故无 $\frac{n+1}{2}$ 之类的平均比较次数推导。

> 说明：本节视频未给出复杂度结论，以上为「补充」，依据是操作只访问队头/队尾固定位置；具体证明在 3.2.2、3.2.3 给出。

## 6. 易错点与考试写法

1. **入队端、出队端记反**：入队在**队尾**，出队在**队头**。口诀：新来的站队尾，先来的先走。
2. **FIFO 与 LIFO 混淆**：队列 FIFO，栈 LIFO；选择题常把两者缩写对调设陷阱。
3. **`DeQueue` 与 `GetHead` 混淆**：前者删除并返回值，后者只读不删。题目问「删除队头元素并返回」选 `DeQueue`，问「读取队头元素」选 `GetHead`。
4. **「操作受限」不等于「不能操作」**：队列仍是线性表，元素之间仍是前驱后继的一对一关系，只是插入/删除位置受限。
5. **答题标准**：408 中本节以选择题为主，答到「只允许一端插入、另一端删除，先进先出 FIFO」即可；若要求写基本操作，须写清参数传递（`&Q` 表示可能修改队列）与返回值语义。

## 7. 408 题型与解题套路

- **选择题（408 必考）**：
  - 判断某序列能否由给定入队序列经队列得到——队列只能 FIFO，出队序列**必与入队序列相同**（无其他操作时）。
  - 给出入队/出队混合操作序列，求最终队内元素或某次出队元素——按「先入先出」逐次模拟。
  - 概念辨析：队列 vs 栈的受限方式、FIFO vs LIFO、`DeQueue` vs `GetHead`。
- **算法题**：本节不单独出算法题；队列作为工具用于 BFS、层序遍历等（后续章节）。
- **常见陷阱**：把队列当成「可任意位置插入删除」的线性表；把「队尾」当成删除端。

## 8. 自测题

**1.** 队列的插入操作在______进行，删除操作在______进行，其特性缩写为______。

**2.** 若元素 a, b, c 依次入队，在全部入队前允许任意时刻出队，则不可能得到的出队序列是（ ）。
A. a b c　B. b a c　C. c b a　D. a c b

**3.** 下列操作中，会改变队列内容的是（ ）。
A. `GetHead(Q,&x)`　B. `QueueEmpty(Q)`　C. `DeQueue(&Q,&x)`　D. `InitQueue(&Q)` 之后再判空

**4.** 判断：队列是一种操作受限的线性表，因此队列中元素之间不存在前驱后继关系。

**5.** 简述 `DeQueue` 与 `GetHead` 的区别。

<details>
<summary>答案与解析</summary>

1. 队尾（rear）；队头（front）；FIFO。
2. **C**。队列严格 FIFO，出队顺序必与入队顺序一致，只能是 a b c；B、D 在「入队与出队交替」的模拟下实际也不可能（因 a 先入队必先出队），但按本节「全部入队前可任意出队」的严格 FIFO 语义，唯一合法序列是 a b c，故 C 明显不可能（c 不可能先于 a、b 出队）。**注意**：本题按本节知识点，队列无「中途插队」能力，出队序列恒等于入队序列，选 C。
3. **C**。`DeQueue` 删除队头元素；`GetHead` 只读不删；`QueueEmpty` 只判空；D 中初始化本身构造空队列，但题面「之后再判空」不改变已有内容，故选 C。
4. **错**。队列仍是线性表，元素间存在一对一的前驱后继关系，只是插入/删除位置受限。
5. `DeQueue` 删除队头元素并把其值赋给 x，队列长度减 1；`GetHead` 只把队头元素的值赋给 x，**不删除**，队列不变。二者分别对应栈的「出栈」与「读栈顶元素」。

</details>

## 9. 背诵卡

1. 队列 = 操作受限线性表：**队尾入、队头出**。
2. 特性：**先进先出 FIFO**；栈是 **后进先出 LIFO**。
3. 三术语：队头 front、队尾 rear、空队列。
4. 基本操作：Init / Destroy / EnQueue / DeQueue / GetHead / QueueEmpty。
5. **DeQueue 删除并返回，GetHead 只读不删**。
