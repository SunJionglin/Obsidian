# 4.2.2 求 next 数组

## 1. 本节定位

- **对应王道书**：第 4 章 串 → 4.2 串的模式匹配 → 4.2.2 KMP 算法 → **求 next 数组**（手算方法）。
- **408 大纲对应**：串的模式匹配（KMP 算法中 next 数组的求法）。408 明确要求掌握**手算 next 数组**。
- **先修知识**：KMP 匹配原理（主串指针 $i$ 不回溯、失配时 $j \leftarrow next[j]$、$j=0$ 时 $i,j$ 同时加加）。
- **本节位置**：上一小节讲清 KMP 原理与 next 数组的含义，本节专门训练**手算 next 数组**，是 KMP 整章的核心计算技能，直接对接选择题与算法题。

## 2. 一句话结论

**对任意模式串，$next[1]=0$、$next[2]=1$ 恒成立；求 $next[j]$ 就是在第 $j$ 个字符前画一条分界线，把模式串逐步右移，找到分界线左侧能完全匹配的最长前缀，此时 $j$ 指针所指位置（前缀长度 $+1$）就是 $next[j]$。**

## 4. 核心内容

### 1. next 数组的定义（复习）

设模式串为 $P_1P_2\cdots P_m$，$next[j]$ 表示：**当模式串第 $j$ 个字符与主串失配时，模式串指针 $j$ 应回退到的位置**（即用 $P_{next[j]}$ 继续与主串当前字符比较）。

> 位序说明：王道书与 408 中模式串下标**从 1 开始**，$next$ 数组下标也**从 1 开始**，$next[1]$ 对应第 1 个字符。做题时务必确认题目下标起点，若从 0 开始则整体减 1（推断：部分教材用 0 起始，408 真题以 1 起始为主）。

### 2. 两个恒定值（必背）

| 情形 | 结论 | 理由 |
|---|---|---|
| 第 1 个字符失配 | $next[1]=0$ | 前面已无字符可用，令 $j=0$，随后 $i,j$ 同时加加，从主串下一字符与模式串第 1 字符重新比 |
| 第 2 个字符失配 | $next[2]=1$ | 只能把模式串右滑一位，用第 1 个字符与主串当前字符比 |

**任何模式串都满足 $next[1]=0,\ next[2]=1$**，考试可直接写，节省时间。

### 3. 手算方法（本节核心，务必掌握）

**步骤**（求 $next[j]$，$j \ge 3$）：

1. 在模式串第 $j$ 个字符**前面画一条分界线**。
2. 分界线**左侧**的字符是失配前已确认与主串匹配的部分（已知）；右侧未知。
3. 把模式串**逐步右移**，每移一步检查分界线左侧部分能否与模式串自身前缀完全对上。
4. 找到**第一个**使左侧完全匹配的位置，此时 $j$ 指针落在模式串的某个下标 $k$ 上，则 $next[j]=k$。
5. 若移到整个模式串都跨过分界线仍不匹配，则 $next[j]=1$。

> 本质：$next[j] = $ 模式串前 $j-1$ 个字符中**最长相等前后缀的长度 $+1$**（王道书扩展表述，等价于上述右移法）。

### 4. 例 1：模式串 `google`（下标 1~6）

| $j$ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| $P_j$ | g | o | o | g | l | e |
| $next[j]$ | 0 | 1 | 1 | 1 | 2 | 1 |

**逐项说明**：

- $next[1]=0,\ next[2]=1$：恒定。
- $next[3]$：第 3 字符 `o` 前画线，左侧为 `go`。右移一位 `g` 对 `o` 不匹配；再移整个串跨过分界线 → $next[3]=1$。
- $next[4]$：第 4 字符 `g` 前画线，左侧 `goo`。右移均不匹配，跨过分界线 → $next[4]=1$。
- $next[5]$：第 5 字符 `l` 前画线，左侧 `goog`。右移后 `g` 与 `g` 对上（前缀 `g` 匹配）→ $j$ 指向第 2 个字符 → $next[5]=2$。
- $next[6]$：第 6 字符 `e` 前画线，左侧 `googl`。右移检查均不匹配，跨过分界线 → $next[6]=1$。

### 5. 例 2：模式串 `ababaa`（下标 1~6）

| $j$ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| $P_j$ | a | b | a | b | a | a |
| $next[j]$ | 0 | 1 | 1 | 2 | 3 | 4 |

**逐项说明**：

- $next[1]=0,\ next[2]=1$：恒定。
- $next[3]$：第 3 字符 `a` 前画线，左侧 `ab`。右移一位 `a` 对 `b` 不匹配，跨过分界线 → $next[3]=1$。
- $next[4]$：第 4 字符 `b` 前画线，左侧 `aba`。右移后前缀 `a` 与左侧末尾 `a` 对上 → $j$ 指向第 2 字符 → $next[4]=2$。
- $next[5]$：第 5 字符 `a` 前画线，左侧 `abab`。右移后前缀 `ab` 与左侧末尾 `ab` 对上 → $j$ 指向第 3 字符 → $next[5]=3$。
- $next[6]$：第 6 字符 `a` 前画线，左侧 `ababa`。右移后前缀 `aba` 与左侧末尾 `aba` 对上 → $j$ 指向第 4 字符 → $next[6]=4$。

### 6. next 数组的使用（配合例 1 演示）

主串 `googoogle`，模式串 `google`，$next=\{0,1,1,1,2,1\}$：

- 前 5 个字符匹配，第 6 个 `o` 与 `e` 失配（$j=6$）→ $j \leftarrow next[6]=1$，$i$ 不动。
- 此时 `o` 与 `g` 失配（$j=1$）→ $j \leftarrow next[1]=0$，触发特殊处理：$i,j$ 同时加加。
- 继续匹配，到 $j=5$ 时 `l` 失配 → $j \leftarrow next[5]=2$，$i$ 不动，从模式串第 2 字符继续。
- 后续全部匹配成功。

**关键操作**：失配时 $j \leftarrow next[j]$，$i$ **永不回溯**；$j=0$ 时 $i,j$ 同时加加。

### 7. 求 next 数组的代码（王道风格，408 必考，能读懂能默写）

```c
// 模式串 P 下标从 1 开始，长度 m；next 数组下标从 1 开始
void get_next(char P[], int next[], int m) {
    int i = 1, j = 0;          // i 扫描模式串，j 表示当前最长相等前后缀长度
    next[1] = 0;               // 第 1 个字符失配，j 回退到 0
    while (i < m) {
        if (j == 0 || P[i] == P[j]) {
            i++; j++;          // 前后缀匹配成功，长度 +1
            next[i] = j;       // next[i] = 最长相等前后缀长度 + 1
        } else {
            j = next[j];       // 失配，j 回退（利用已求出的 next 值）
        }
    }
}
```

> 说明：代码中 $next[i]=j$ 的 $j$ 恰为"前 $i-1$ 个字符的最长相等前后缀长度 $+1$"，与手算右移法结果一致。**手算与代码必须能互相验证**。

## 5. 复杂度分析

- **求 next 数组的时间复杂度**：
  - 最好情况：模式串所有字符相同（如 `aaaa`），每次 $P[i]==P[j]$ 直接前进，循环 $m-1$ 次，$O(m)$。
  - 最坏情况：$j$ 频繁回退，但 $j$ 每次回退至少减 1，而 $i$ 单调递增，$j$ 的总增量不超过 $m$，故总回退次数不超过 $m$，仍为 $O(m)$。
  - 平均情况：$O(m)$。推导：$i$ 只增不减，共增 $m$ 次；$j$ 每次失配回退至少减 1，而 $j$ 的总增量受 $i$ 增量约束（每次 $i$ 增时 $j$ 至多增 1），故 $j$ 回退总次数 $\le m$，总操作数 $O(m)$。
- **KMP 匹配总复杂度**：$O(m+n)$，$m$ 为模式串长、$n$ 为主串长（求 next $O(m)$ + 匹配 $O(n)$）。
- **空间复杂度**：$O(m)$，存 next 数组。

## 6. 易错点与考试写法

1. **下标起点搞错**：408 与王道书模式串下标从 **1** 开始，$next[1]=0$；若题目从 0 开始，则 $next[0]=-1$，整体错位。**答题前先看题目下标**。
2. **$next[2]=1$ 不是 0**：很多同学误写 $next[2]=0$。记住：第 2 字符失配只能右滑一位，$j$ 指向 1。
3. **右移法找的是"最长"相等前后缀**：右移时找到**第一个**能匹配的位置即停，不要继续移。
4. **$next[j]$ 是"长度 +1"不是"长度"**：手算时 $j$ 指针落在下标 $k$，则 $next[j]=k$，$k$ = 最长相等前后缀长度 $+1$。
5. **答题写到什么程度算对**：408 选择题只需填出 next 数组各值；算法题要求写出 `get_next` 代码并说明 $next[1]=0$ 的初始化与 $j=next[j]$ 的回退逻辑。手算题写清"分界线 + 右移 + 结果"即可得分。

## 7. 408 题型与解题套路

- **选择题（高频）**：给出模式串求 next 数组某几项，或给出 next 数组反推模式串。套路：先写 $next[1]=0,next[2]=1$，再逐项右移。
- **算法题（中频）**：要求写出 `get_next` 或 KMP 匹配代码。套路：默写上述代码，注意下标从 1 开始、$j=0$ 特殊处理。
- **常见陷阱**：
  - 题目下标从 0 开始（如 `next[0]=-1`），需整体平移。
  - 求 `nextval` 数组（优化版 next）：在 next 基础上，若 $P[j]==P[next[j]]$ 则 $nextval[j]=nextval[next[j]]$，否则 $nextval[j]=next[j]$（王道书扩展，408 偶考）。
  - 混淆"最长相等前后缀长度"与"$next$ 值"（差 1）。

## 8. 自测题

**1.** 模式串 `ababaa` 的 $next$ 数组（下标从 1 开始）是？

**2.** 模式串 `aaaab` 的 $next$ 数组是？

**3.** 为什么任何模式串都有 $next[1]=0,\ next[2]=1$？

**4.** 已知模式串 $next=\{0,1,1,2,3,4\}$，长度 6，求该模式串（写出一种可能）。

**5.** `get_next` 代码中 `j = next[j]` 的作用是什么？为什么不会导致死循环？

<details>
<summary>答案</summary>

**1.** $next=\{0,1,1,2,3,4\}$。逐项：$next[3]=1$（`ab` 无相等前后缀）；$next[4]=2$（`aba` 前缀 `a`=后缀 `a`）；$next[5]=3$（`abab` 前缀 `ab`=后缀 `ab`）；$next[6]=4$（`ababa` 前缀 `aba`=后缀 `aba`）。

**2.** $next=\{0,1,2,3,4\}$。$next[3]=2$（`aa` 前缀 `a`=后缀 `a`）；$next[4]=3$（`aaa` 前缀 `aa`=后缀 `aa`）；$next[5]=4$（`aaaa` 前缀 `aaa`=后缀 `aaa`）。

**3.** 第 1 字符失配时前面无字符可用，只能令 $j=0$ 后 $i,j$ 同时加加，从主串下一字符重新比，故 $next[1]=0$；第 2 字符失配时只能把模式串右滑一位，用第 1 字符与主串当前字符比，故 $next[2]=1$。与模式串内容无关。

**4.** 一种可能：`ababa` 类结构，如 `ababab`（长度 6，$next=\{0,1,1,2,3,4\}$）。验证：$next[4]=2$（`aba` 前后缀 `a`），$next[5]=3$（`abab` 前后缀 `ab`），$next[6]=4$（`ababa` 前后缀 `aba`）。

**5.** `j = next[j]` 是失配时利用已求出的 next 值让 $j$ 回退到更短的可能前缀位置，避免从头比较。不会死循环：每次回退 $j$ 严格减小（$next[j] < j$），且 $j$ 有下界 0，$j=0$ 时进入 `if` 分支使 $i,j$ 同时加加，$i$ 单调递增，循环必然终止。

## 9. 背诵卡

1. **$next[1]=0,\ next[2]=1$**，任何模式串恒定，先写再说。
2. 求 $next[j]$：**第 $j$ 字符前画线 → 模式串右移 → 左侧首次完全匹配处 $j$ 所指下标即 $next[j]$**。
3. $next[j]$ = 前 $j-1$ 个字符的**最长相等前后缀长度 $+1$**。
4. 失配时 **$j \leftarrow next[j]$，$i$ 不动**；$j=0$ 时 $i,j$ 同时加加。
5. 求 next 与 KMP 匹配均 **$O(m+n)$**，空间 $O(m)$。
