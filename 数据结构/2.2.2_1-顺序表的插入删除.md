# 2.2.2_1 顺序表的插入与删除

## 1. 本节定位

- **对应王道书**：第 2 章 线性表 · 2.2 顺序表 · 2.2.2 顺序表的基本操作（插入、删除）。
- **408 大纲对应**：线性表的顺序存储结构；顺序表上基本操作（插入、删除）的实现与效率分析。
- **先修知识**：顺序表的定义（静态分配 `SqList` 结构体：`ElemType data[MaxSize]` + `int length`）、初始化（`length = 0`）。
- **本节位置**：上一节完成“定义 + 初始化”，本节实现“插入、删除”两个基本操作并分析时间复杂度；后续 2.2.2_2 讲按位查找、按值查找，2.3 进入单链表。本节是“顺序表操作三件套（增、删、查）”的前两件，也是第一次系统训练**元素移动方向**与**参数引用**。

## 2. 一句话结论

顺序表插入要**从后往前**依次后移元素、删除要**从前往后**依次前移元素，二者平均时间复杂度均为 $O(n)$，且代码必须做**位序合法性 + 表满/表空**的健壮性判断。

## 3. 知识地图

```
顺序表基本操作（本节）
├── 插入 ListInsert(L, i, e)
│   ├── 语义：在位序 i（1 ≤ i ≤ length+1）处插入 e
│   ├── 移动方向：从后往前（j 从 length 递减到 i）
│   ├── 关键动作：data[j] = data[j-1]；data[i-1] = e；length++
│   └── 健壮性：i 越界 → false；length ≥ MaxSize → false
├── 删除 ListDelete(L, i, &e)
│   ├── 语义：删除位序 i（1 ≤ i ≤ length）的元素，用 e 带回
│   ├── 移动方向：从前往后（j 从 i 递增到 length-1）
│   ├── 关键动作：e = data[i-1]；data[j-1] = data[j]；length--
│   └── 健壮性：i 越界 → false
└── 复杂度（两者同构）
    ├── 最好：$O(1)$（插表尾 / 删表尾）
    ├── 最坏：$O(n)$（插表头 / 删表头）
    └── 平均：$O(n)$（等概率假设，平均移动约 $n/2$ 次）
```

## 4. 核心内容

### 4.1 插入操作 `ListInsert`

**语义**：在线性表 $L$ 的**第 $i$ 个位置（位序，从 1 开始）**插入元素 $e$。插入后，$e$ 成为原第 $i$ 个元素的前驱。

**为什么必须后移**：顺序表用“物理相邻”体现“逻辑相邻”，第 $i$ 个位置被占用，原第 $i$ 个及之后的元素必须整体后移一格，空出位置。

**移动方向**：必须**从后往前**移（先把最后一个元素挪到 `length` 位置，再挪倒数第二个……）。若从前往后移，会把后面的元素覆盖掉。

```c
#define MaxSize 10
typedef struct {
    int data[MaxSize];   // 静态分配，元素类型以 int 为例
    int length;          // 当前表长
} SqList;

// 在位序 i 处插入元素 e；i 从 1 开始
bool ListInsert(SqList &L, int i, int e) {
    if (i < 1 || i > L.length + 1)   // 位序合法性：1 ~ length+1
        return false;
    if (L.length >= MaxSize)         // 表满，不能再插
        return false;
    for (int j = L.length; j >= i; j--)  // 从后往前，把第 i..length 个元素后移
        L.data[j] = L.data[j - 1];       // 位序 j 的元素放到下标 j（即原下标 j-1 处）
    L.data[i - 1] = e;               // 位序 i 对应数组下标 i-1
    L.length++;                      // 表长加一
    return true;
}
```

**逐轮追踪（以 `data = {1,2,4,5,6}`、`length = 5`、在 $i=3$ 插入 3 为例）**：

| 轮次 | `j` | 执行语句 | 效果 |
|---|---|---|---|
| 1 | 5 | `data[5] = data[4]` | 6 移到下标 5 |
| 2 | 4 | `data[4] = data[3]` | 5 移到下标 4 |
| 3 | 3 | `data[3] = data[2]` | 4 移到下标 3 |
| 结束 | `j=2 < i` | 退出循环 | — |
| 收尾 | — | `data[2] = 3`，`length = 6` | 得 `{1,2,3,4,5,6}` |

**位序 vs 下标**：函数参数 $i$ 是位序（从 1 开始），数组下标从 0 开始，故写入位置是 `data[i-1]`。这是本节第一个高频失分点。

**健壮性（代码要“让别人用得爽”）**：
- 若不做 $i$ 的合法性判断，调用者传 $i=9$（表长 5）时，循环不执行，元素被写到 `data[8]`，中间 `data[5..7]` 留空，破坏“物理相邻”性质——代码不健壮。
- 表满（`length == MaxSize`）时必须拒绝插入，否则数组越界。
- 用 `bool` 返回值把成功/失败反馈给调用者，是工程习惯，也是 408 算法题“接口完整”的加分写法。

### 4.2 删除操作 `ListDelete`

**语义**：删除线性表 $L$ 中**位序 $i$** 的元素，并用引用参数 $e$ 把它带回给调用者。

**为什么必须前移**：删掉第 $i$ 个元素后，为保持物理相邻，原第 $i+1$ 到第 $n$ 个元素整体前移一格。

**移动方向**：必须**从前往后**移（先让第 $i+1$ 个覆盖第 $i$ 个，再让第 $i+2$ 个覆盖第 $i+1$ 个……）。若从后往前移，前面的空位补不上、后面的元素被重复覆盖。

```c
// 删除位序 i 的元素，用引用参数 e 带回；i 从 1 开始
bool ListDelete(SqList &L, int i, int &e) {
    if (i < 1 || i > L.length)       // 位序合法性：1 ~ length（只能删已存在的元素）
        return false;
    e = L.data[i - 1];               // 先保存被删元素（位序 i → 下标 i-1）
    for (int j = i; j < L.length; j++)   // 从前往后，把第 i+1..length 个元素前移
        L.data[j - 1] = L.data[j];       // 位序 j+1 的元素移到下标 j-1
    L.length--;                      // 表长减一
    return true;
}
```

**逐轮追踪（以 `data = {1,2,3,4,5,6}`、`length = 6`、删除 $i=3$ 为例）**：

| 步骤 | 执行语句 | 效果 |
|---|---|---|
| 保存 | `e = data[2]` | `e = 3` |
| 第 1 轮 `j=3` | `data[2] = data[3]` | 4 前移到下标 2 |
| 第 2 轮 `j=4` | `data[3] = data[4]` | 5 前移到下标 3 |
| 第 3 轮 `j=5` | `data[4] = data[5]` | 6 前移到下标 4 |
| 收尾 | `length = 5` | 得 `{1,2,4,5,6}`，`e = 3` |

**引用参数 `&e` 与 `&L` 的必要性（本节第二个高频失分点）**：
- `&e`：若去掉 `&`，函数内 `e` 只是 `main` 中 `e` 的**副本**，函数里赋值改的是副本，返回 `main` 后 `e` 仍是初值（如 -1），删除结果丢失。
- `&L`：若去掉 `&`，函数内操作的是整个顺序表的**副本**，移位与 `length--` 都作用在副本上，`main` 中的 `L` 原封不动。
- 结论：**要修改调用者的实参，就必须传引用（C++）或传指针（C）**。408 算法题默认 C 风格伪代码时，可用指针或直接说明“返回修改后的表”；王道书代码用 C++ 引用。

### 4.3 插入与删除的对称性（记忆抓手）

| 对比项 | 插入 | 删除 |
|---|---|---|
| 合法位序 | $1 \le i \le length+1$ | $1 \le i \le length$ |
| 移动方向 | 从后往前 | 从前往后 |
| 循环变量 | `j` 从 `length` 递减到 `i` | `j` 从 `i` 递增到 `length-1` |
| 循环次数 | `length - i + 1` | `length - i` |
| 表长变化 | `length++` | `length--` |
| 额外判断 | 表满 `length >= MaxSize` | 无（表空时 $i$ 必越界） |

## 5. 复杂度分析

问题规模 $n$ = 顺序表当前表长 `length`。核心语句是 for 循环中的移动语句，分析其执行次数。

### 5.1 插入

- **最好**：$i = n+1$（插在表尾），无需移动，循环 0 次，其余语句各执行一次 → $O(1)$。
- **最坏**：$i = 1$（插在表头），原 $n$ 个元素全部后移，循环 $n$ 次 → $O(n)$。
- **平均**：设新元素插入到 $n+1$ 个合法位置中任一位置的概率相等，即 $p = \frac{1}{n+1}$。位序 $i$ 对应移动次数 $n - i + 1$，故平均移动次数
  $$\sum_{i=1}^{n+1} p\,(n-i+1) = \frac{1}{n+1}\sum_{k=0}^{n} k = \frac{1}{n+1}\cdot\frac{n(n+1)}{2} = \frac{n}{2}$$
  即平均移动约 $n/2$ 次 → $O(n)$。

### 5.2 删除

- **最好**：$i = n$（删表尾），无需移动，循环 0 次 → $O(1)$。
- **最坏**：$i = 1$（删表头），后 $n-1$ 个元素全部前移，循环 $n-1$ 次 → $O(n)$。
- **平均**：设删除 $n$ 个元素中任一元素的概率相等，即 $p = \frac{1}{n}$。位序 $i$ 对应移动次数 $n - i$，故平均移动次数
  $$\sum_{i=1}^{n} p\,(n-i) = \frac{1}{n}\sum_{k=0}^{n-1} k = \frac{1}{n}\cdot\frac{(n-1)n}{2} = \frac{n-1}{2}$$
  即平均移动约 $(n-1)/2$ 次 → $O(n)$。

**记忆**：插入平均移 $n/2$，删除平均移 $(n-1)/2$，都是 $O(n)$；只有“表尾操作”是 $O(1)$。

## 6. 易错点与考试写法

1. **位序与下标混用**：参数 $i$ 是位序（1 起），数组下标 0 起。插入写 `data[i-1] = e`，删除写 `e = data[i-1]`。题目说“删除第 2 个元素”与“删除下标为 2 的元素”是两回事，审题必看。
2. **移动方向写反**：插入从后往前（`j--`），删除从前往后（`j++`）。写反后数据被覆盖，是手写代码最常见的错误。
3. **循环边界**：插入 `j >= i`（含 $i$，因为第 $i$ 个也要后移）；删除 `j < L.length`（不含 `length`，因为 `data[length]` 是空位）。边界差一即错。
4. **忘记改 `length`**：插入后 `length++`，删除后 `length--`，漏写则表长与实际元素数不符。
5. **漏判表满**：静态分配下 `length == MaxSize` 时插入会越界，必须 `return false`。
6. **引用参数**：删除的 `&e`、插入/删除的 `&L` 不能省；C 语言无引用，用指针或返回结构体。
7. **答题标准**：408 算法题写顺序表插入/删除，需给出：① 合法性判断（含表满）；② 正确的循环方向与边界；③ 元素写入/保存；④ `length` 更新；⑤ 返回值或 `e` 带回。缺任一项按步扣分。复杂度分析要写“最好/最坏/平均”三档，平均档必须给出等概率假设与求和式。

## 7. 408 题型与解题套路

- **选择题**：常考“在长度为 $n$ 的顺序表第 $i$ 个位置插入/删除需移动多少元素”（答案：插入 $n-i+1$，删除 $n-i$）；“平均移动次数”（插入 $n/2$，删除 $(n-1)/2$）；“插入/删除的时间复杂度”（$O(n)$）；“哪个位置操作最快”（表尾，$O(1)$）。
- **算法题**：作为更复杂算法（如顺序表去重、合并、逆置）的子过程出现。套路：先判合法性与容量，再定移动方向，最后更新 `length`。若题目要求“原地”操作，注意不要额外开数组。
- **常见陷阱**：
  - 题目给的是“数组下标 $i$”，代码里却按位序处理，导致差一。
  - 动态分配顺序表（`data` 为指针、`MaxSize` 可扩容）时，表满需 `realloc` 扩容再插入——本节代码基于静态分配，动态版需补扩容逻辑（王道书扩展，408 可能以选择题形式考扩容后地址变化）。
  - 删除时先移动后保存 `e`，会把被删元素覆盖掉，必须先 `e = data[i-1]`。

## 8. 自测题

**1.** 长度为 $n$ 的顺序表，在第 $i$ 个位置（$1 \le i \le n+1$）插入一个元素，需后移的元素个数是（ ）。
A. $n-i$  B. $n-i+1$  C. $n-i-1$  D. $i$

**2.** 顺序表插入操作中，for 循环若写成 `for (j = i; j <= L.length; j++) L.data[j] = L.data[j-1];`，会出现什么问题？

**3.** 删除操作中参数 `e` 若不加引用符号 `&`，调用后 `main` 中的 `e` 值如何？为什么？

**4.** 推导：在长度为 $n$ 的顺序表中等概率删除任一元素，平均移动次数是多少？时间复杂度是多少？

**5.** 判断：顺序表插入和删除的最好情况时间复杂度都是 $O(1)$，最坏情况都是 $O(n)$，因此二者平均时间复杂度也相同。（ ）

<details>
<summary>答案与解析</summary>

**1. B。** 位序 $i$ 到 $n$ 共 $n-i+1$ 个元素需后移（含第 $i$ 个本身）。

**2.** 从前往后移会把后面的元素覆盖：先把 `data[i]` 写到 `data[i-1]`，下一步 `data[i+1]` 写到 `data[i]` 时，`data[i]` 已是新值，原第 $i$ 个元素丢失。插入必须从后往前（`j--`）。

**3.** `e` 保持原值（如 -1）不变。因为非引用参数是实参的副本，函数内赋值只改副本，不影响 `main` 中的 `e`，删除结果无法带回。

**4.** 等概率假设 $p = 1/n$，位序 $i$ 需移动 $n-i$ 次，平均移动
$$\frac{1}{n}\sum_{i=1}^{n}(n-i) = \frac{1}{n}\cdot\frac{(n-1)n}{2} = \frac{n-1}{2}$$
时间复杂度 $O(n)$。

**5.** 正确（就结论而言）。两者最好 $O(1)$、最坏 $O(n)$、平均 $O(n)$；但注意平均移动次数不同：插入 $n/2$，删除 $(n-1)/2$。

</details>

## 9. 背诵卡

1. **插入**：判 $1 \le i \le length+1$ 与表未满 → **从后往前**移（`j` 从 `length` 到 `i`）→ `data[i-1]=e` → `length++`。
2. **删除**：判 $1 \le i \le length$ → 先 `e=data[i-1]` → **从前往后**移（`j` 从 `i` 到 `length-1`）→ `length--`。
3. **移动次数**：插入第 $i$ 位移 $n-i+1$ 个；删除第 $i$ 位移 $n-i$ 个。
4. **复杂度**：最好 $O(1)$（表尾），最坏 $O(n)$（表头），平均 $O(n)$；插入平均移 $n/2$，删除平均移 $(n-1)/2$。
5. **两个坑**：位序 1 起、下标 0 起（`data[i-1]`）；要改实参必须传引用 `&`。
