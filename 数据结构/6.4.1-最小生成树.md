# 6.4.1 最小生成树（MST）

## 1. 本节定位

- **对应王道书**：第 6 章「图」→ 6.4「图的应用」→ 6.4.1 最小生成树。
- **408 大纲对应**：图的应用——最小（代价）生成树的基本概念；Prim 算法与 Kruskal 算法的构造过程、复杂度与适用场景。
- **先修知识**：连通无向图、生成树（含 $n$ 个顶点、$n-1$ 条边、连通无环）、带权图、邻接矩阵/邻接表、并查集思想（仅需了解，408 不要求掌握实现）。
- **本节位置**：图的经典应用第一站。前面刚学完 BFS/DFS 生成树，本节把「生成树」加上「权值最小」的约束；后面接着是最短路径、拓扑排序、关键路径。

## 2. 一句话结论

**最小生成树 = 带权连通无向图中边权之和最小的生成树；Prim 每次「拉一个顶点进来」（$O(|V|^2)$，适合稠密图），Kruskal 每次「挑一条不成环的最小边」（$O(|E|\log|E|)$，适合稀疏图），两者结果权值和相同，但形态可能不唯一。**

## 3. 知识地图

```
最小生成树 MST（Minimum Spanning Tree，又称最小代价树）
├── 研究对象：带权连通无向图
├── 定义：该图所有生成树中，各边权值之和最小的那棵
├── 性质
│   ├── MST 可能不唯一（形态不同，权值和相同且最小）
│   ├── 图本身是树 ⇒ MST 就是它自身
│   ├── 所有边权相等 ⇒ 任意生成树都是 MST
│   └── 图不连通 ⇒ 无生成树，只有生成森林
├── Prim 算法（加点法）
│   ├── 从任一顶点出发，每次并入「代价最小的新顶点」
│   ├── 维护 lowcost[] 与 标记数组
│   └── 复杂度 O(|V|²)，适合稠密图
└── Kruskal 算法（加边法）
    ├── 边按权值递增排序，依次选边，两端已连通则跳过
    ├── 用并查集判连通（408 不要求实现）
    └── 复杂度 O(|E| log|E|)，适合稀疏图
```

## 4. 核心内容

### 4.1 定义与前提

- **生成树**：连通无向图的子图，含全部 $n$ 个顶点、恰好 $n-1$ 条边、保持连通（等价于连通且无环）。
- **最小生成树**：带权连通无向图中，边权之和最小的生成树。
- **前提必须是「带权 + 连通 + 无向」**：不连通图没有生成树，只能得到生成森林。

### 4.2 三条必背性质

1. **MST 不唯一**：同一图可有多棵 MST，形态不同但权值和相同且最小。
2. **图本身是树**（连通无环）⇒ 其 MST 就是自身。
3. **所有边权相等** ⇒ 任意一棵生成树都是 MST。

### 4.3 Prim 算法（加点法，408 必考构造过程）

**手算流程**：任选一个顶点作为初始树，之后每轮从「树外顶点」中选一个「连到当前树代价最小」的顶点并入，直到 $n$ 个顶点全部并入。

**机考/代码思想（王道风格，邻接矩阵存图）**：

```c
// 前提：图用邻接矩阵 M[n][n] 存储，不存在的边为 INF
// lowcost[i]：顶点 i 连入当前生成树的最小边权
// visited[i]：顶点 i 是否已并入生成树
void Prim(int M[][MAXV], int n, int start) {
    int lowcost[MAXV], visited[MAXV];
    for (int i = 0; i < n; i++) {          // 初始化：只把 start 并入
        lowcost[i] = M[start][i];
        visited[i] = 0;
    }
    visited[start] = 1;
    lowcost[start] = 0;

    for (int round = 1; round < n; round++) {   // 共 n-1 轮，每轮并入一个顶点
        int min = INF, k = -1;
        for (int i = 0; i < n; i++)             // 找树外 lowcost 最小的顶点
            if (!visited[i] && lowcost[i] < min) { min = lowcost[i]; k = i; }
        if (k == -1) return;                    // 图不连通，无法生成树
        visited[k] = 1;                         // 顶点 k 并入生成树
        for (int i = 0; i < n; i++)             // 用 k 更新其余顶点的 lowcost
            if (!visited[i] && M[k][i] < lowcost[i])
                lowcost[i] = M[k][i];
    }
}
```

> 关键点：每轮做两件事——① 选树外 `lowcost` 最小者并入；② 用新顶点刷新其余顶点的 `lowcost`（取较小值）。

### 4.4 Kruskal 算法（加边法，408 必考构造过程）

**手算流程**：把所有边按权值从小到大排序，依次考察每条边：若两端顶点当前**不连通**则选入，否则跳过；选够 $n-1$ 条边即结束。

**代码思想（伪代码，判连通用并查集）**：

```c
// 前提：边集已按权值升序排序；并查集 Find/Union 判连通
// 408 不要求实现并查集，只需理解「同集合 = 已连通」
Kruskal(Edge E[], int e, int n) {
    for (i = 0; i < n; i++) MakeSet(i);   // 每个顶点独立成集合
    count = 0;                            // 已选边数
    for (i = 0; i < e && count < n - 1; i++) {
        u = E[i].u; v = E[i].v;
        if (Find(u) != Find(v)) {         // 两端不在同一集合 ⇒ 不连通
            Union(u, v);                  // 合并集合
            count++;                      // 选中该边
        }
    }
}
```

### 4.5 两算法对比（必背表）

| 维度 | Prim | Kruskal |
|---|---|---|
| 每步操作 | 选一个**顶点**并入 | 选一条**边**加入 |
| 依赖 | 顶点数 $|V|$ | 边数 $|E|$ |
| 时间复杂度 | $O(|V|^2)$ | $O(|E|\log|E|)$ |
| 适用 | **稠密图**（$|E|$ 大） | **稀疏图**（$|E|$ 小） |
| 判环方式 | 天然无环（只连树外顶点） | 并查集判两端是否已连通 |

## 5. 复杂度分析

**Prim：$O(|V|^2)$**

- 共进行 $n-1$ 轮（每轮并入一个顶点）。
- 每轮两次线性扫描全部顶点：一次找最小 `lowcost`，一次更新 `lowcost`，各 $O(n)$。
- 总时间 $= (n-1)\cdot O(n) = O(n^2) = O(|V|^2)$。
- 与边数无关，故**稠密图**（$|E|$ 接近 $|V|^2$）效率更好；用邻接矩阵实现时最好/最坏/平均均为 $O(|V|^2)$（循环次数固定，与数据无关）。

**Kruskal：$O(|E|\log|E|)$**

- 排序所有边：$O(|E|\log|E|)$（主导项）。
- 依次检查 $|E|$ 条边，每条做一次并查集 Find（近似 $O(\log|E|)$，王道按 $\log$ 量级计），共 $O(|E|\log|E|)$。
- 总时间 $= O(|E|\log|E|)$，与顶点数关系不大，故**稀疏图**效率更好。
- 最好/最坏/平均：排序代价固定为 $O(|E|\log|E|)$，与边的权值分布无关，三种情况同阶。

> 补充（王道书扩展）：Prim 用二叉堆优化可降到 $O(|E|\log|V|)$，408 初试不要求，了解即可。

## 6. 易错点与考试写法

1. **研究对象说错**：MST 只针对**带权连通无向图**。不连通图只能求「最小生成森林」，这是选择题高频陷阱。
2. **「MST 唯一」是错的**：权值有相等边时 MST 可能不唯一；只有「所有边权互不相同」时才唯一（推断，可由 Kruskal 选择唯一性推出）。
3. **Prim 起点任意**：从不同顶点出发得到的 MST 形态可能不同，但**权值和一定相同**。答题时不要因为起点不同就判错。
4. **Kruskal 选边时「已连通就跳过」**：手算时务必先画出当前连通分量，再判断两端是否同属一个分量，否则容易多选成环。
5. **复杂度记反**：Prim 是 $O(|V|^2)$ 看**顶点**，Kruskal 是 $O(|E|\log|E|)$ 看**边**；适用场景与复杂度一一对应，稠密图用 Prim、稀疏图用 Kruskal。
6. **答题程度**：408 对本节**不考代码实现**，只考「手动模拟构造过程 + 复杂度 + 适用场景」。构造题要求：写出每步选中的边（或顶点）及当前生成树，最后给出权值和；选择题要求能判断「某棵生成树是否可能为 MST」。

## 7. 408 题型与解题套路

- **选择题**：
  - 给图问「MST 的权值和」→ 直接跑 Kruskal（排序选边最快）。
  - 问「MST 是否唯一」→ 看是否存在权值相等的边可互换。
  - 问「Prim/Kruskal 适用场景、复杂度」→ 背对比表。
  - 陷阱：把「生成树」与「最小生成树」混淆；把不连通图当连通图。
- **算法题**：本节极少单独出算法设计题；若出现，多为「证明某性质」或「判断边是否属于某 MST」（了解即可）。
- **综合题**：与最短路径（Dijkstra）对比出选择题——注意 **Prim 与 Dijkstra 代码结构极像**，区别在 `lowcost` 更新方式：Prim 取 `M[k][i]`，Dijkstra 取 `dist[k] + M[k][i]`。

## 9. 背诵卡

1. MST：带权**连通无向**图中边权和最小的生成树；不连通图只有生成森林。
2. MST 可能不唯一；图本身是树 ⇒ MST 是自身；边权全等 ⇒ 任意生成树都是 MST。
3. Prim：加点法，每轮并入代价最小的树外顶点，$O(|V|^2)$，适合**稠密图**。
4. Kruskal：加边法，边升序选、两端已连通则跳过，$O(|E|\log|E|)$，适合**稀疏图**。
5. 两算法结果权值和相同；Prim 与 Dijkstra 代码形似，区别在 `lowcost` 更新式。
