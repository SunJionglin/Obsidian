# 7.3.2 平衡二叉树（AVL 树）

## 1. 本节定位

- **王道书对应**：第 7 章「查找」→ 7.3 树型查找 → 7.3.2 平衡二叉树（AVL）。
- **408 大纲对应**：「查找」章中「平衡二叉树（AVL 树）」条目：定义、平衡因子、插入后调整（LL/RR/LR/RL 四种旋转）、查找效率分析。
- **先修知识**：二叉排序树（BST）的定义与插入、树的高度、结点平衡因子概念。
- **本章位置**：上一小节讲二叉排序树及其平均查找长度 ASL；本节解决「BST 退化成单支树导致查找退化」的问题，是 BST 的「平衡化补丁」；后续接 B 树/B+ 树（多路平衡查找）。

## 2. 一句话结论

**插入新结点后，从插入点向上找到第一个不平衡结点（最小不平衡子树的根），按 LL/RR/LR/RL 四种形态做一次（或两次）旋转，即可恢复整棵树平衡，且调整后子树高度回到插入前，故祖先自动恢复平衡；由此 AVL 树高为 $O(\log_2 n)$，查找为 $O(\log_2 n)$。**

## 3. 知识地图

```
平衡二叉树 AVL
├── 定义
│   ├── 任一结点左右子树高度差绝对值 ≤ 1
│   └── 平衡因子 BF = 左子树高 − 右子树高 ∈ {−1, 0, 1}
├── 名字来源：Adelson-Velsky & Landis（1962 论文），勿与 ASL 混淆
├── 插入后失衡的处理
│   ├── 找最小不平衡子树（离插入点最近的失衡祖先为根）
│   ├── 四种形态
│   │   ├── LL：a 的左孩子的左子树插入 → 对 a 的左孩子右旋
│   │   ├── RR：a 的右孩子的右子树插入 → 对 a 的右孩子左旋
│   │   ├── LR：a 的左孩子的右子树插入 → 先左旋再右旋
│   │   └── RL：a 的右孩子的左子树插入 → 先右旋再左旋
│   └── 基本操作：左旋、右旋（保持 BST 序）
├── 调整后性质：子树高度复原 ⇒ 祖先 BF 复原 ⇒ 只需调最小不平衡子树
└── 查找效率
    ├── 高度为 h 的 AVL 最少结点数 n_h 递推
    └── 树高 O(log₂ n) ⇒ 查找 O(log₂ n)
```

## 4. 核心内容

### 4.1 定义与平衡因子

- **平衡二叉树（AVL 树）**：树上任一结点，其左子树与右子树高度之差的绝对值不超过 1。
- **平衡因子（Balance Factor, BF）**：$\text{BF}(p) = h(\text{左子树}) - h(\text{右子树})$。
- 平衡树中每个结点 BF 只能取 $-1, 0, 1$；只要有一个结点 $|\text{BF}| > 1$，整棵树就不是 AVL 树。
- 实现上可在结点结构体中增加 `bf` 字段（王道书扩展，考试以手算为主，不考代码）。

### 4.2 最小不平衡子树

插入新结点后，只有插入点的**祖先**的 BF 可能改变。从插入点向上找，**第一个** $|\text{BF}|>1$ 的结点为根的子树，称为**最小不平衡子树**。只需调整它，其余祖先自动恢复平衡（原因见 4.4）。

### 4.3 四种形态与旋转（核心，408 必考）

设最小不平衡子树的根为 `a`，其孩子为 `b`，`b` 的孩子为 `c`（LR/RL 时）。抽象图中各子树高度均为 $h$（这是「a 为最小不平衡子树」所强制的，可自行推敲：若某侧高度不同，则失衡点会下移或原本就不平衡）。

**（1）LL：在 a 的左孩子的左子树插入 → 右旋**

```
      a                b
     / \              / \
    b   AR   →       BL  a
   / \                  / \
  BL  BR               BR  AR
```
操作：`b` 右上旋代替 `a` 成根；`a` 成 `b` 的右孩子；`BR` 挂到 `a` 的左子树。调整后 `b`、`a` 的 BF 均为 0。

**（2）RR：在 a 的右孩子的右子树插入 → 左旋**

```
    a                  b
   / \                / \
  AL  b      →       a   BR
     / \            / \
    BL  BR         AL  BL
```
操作：`b` 左上旋代替 `a` 成根；`a` 成 `b` 的左孩子；`BL` 挂到 `a` 的右子树。

**（3）LR：在 a 的左孩子的右子树插入 → 先左旋（对 b）再右旋（对 c）**

```
      a              a              c
     / \            / \            / \
    b   AR   →     c   AR   →     b   a
   / \            / \            / \ / \
  BL  c          b   CR         BL CL CR AR
     / \        / \
    CL  CR     BL  CL
```
两步后 `c` 成为子树根，`b`、`a` 分别为其左右孩子。

**（4）RL：在 a 的右孩子的左子树插入 → 先右旋（对 b）再左旋（对 c）**

```
    a              a                c
   / \            / \              / \
  AL  b    →     AL  c      →     a   b
     / \            / \          / \ / \
    c   BR         CL  b        AL CL CR BR
   / \                / \
  CL  CR             CR  BR
```

**记忆口诀**：只有左孩子才能右旋，只有右孩子才能左旋；每次旋转「孩子变爹、爹变孩子」。LL→右旋；RR→左旋；LR→先左后右；RL→先右后左。

### 4.4 为什么只调最小不平衡子树就够

四种形态调整前，该子树高度为 $h+2$；插入后变为 $h+3$（高度 +1 导致失衡）；旋转后高度**恢复为 $h+2$**。对上层祖先而言，子树高度未变，故其 BF 复原，无需再调。

### 4.5 左旋 / 右旋的代码思路（王道书扩展，了解即可）

设 `f` 指向 `a`，`p` 指向 `b`，`gf` 为 `a` 的父结点。

```c
/* 右旋：p 是 f 的左孩子，p 右上旋代替 f */
p = f->lchild;
f->lchild = p->rchild;   // p 的右子树挂到 f 左边（保持 BST 序）
p->rchild = f;           // f 成为 p 的右孩子
/* 再让 gf 的孩子指针指向 p（f 原为左孩子则 gf->lchild=p，否则 gf->rchild=p） */

/* 左旋：p 是 f 的右孩子，p 左上旋代替 f */
p = f->rchild;
f->rchild = p->lchild;   // p 的左子树挂到 f 右边
p->lchild = f;           // f 成为 p 的左孩子
/* 再修改 gf 的孩子指针指向 p */
```

> 408 以**手算旋转**为主，代码只需理解「三步：移子树、换父子、改祖父指针」。

### 4.6 手算例题（对应视频练习）

- 插入 90：66 为最小不平衡根，属 RR → 对 70 左旋。
- 插入 63：50 为根，属 RL → 对 66 先右旋再左旋。
- 插入 57：66 为根，属 LR → 对 60 先左旋再右旋（熟练后可直接把 60 提为根，左子树挂 50 右侧、右子树挂 66 左侧）。

**做完必验**：中序遍历是否仍递增（BST 序）。

## 5. 复杂度分析

**查找代价 = 树高 $h$**（最坏比较 $h$ 次）。

**高度为 $h$ 的 AVL 树最少结点数 $n_h$**（递推）：

$$n_0 = 0,\quad n_1 = 1,\quad n_h = n_{h-1} + n_{h-2} + 1\ (h \ge 2)$$

含义：根 1 个 + 一棵高 $h-1$ 的最少结点子树 + 一棵高 $h-2$ 的最少结点子树（高度差取 1 才最省结点）。

计算：$n_2=2,\ n_3=4,\ n_4=7,\ n_5=12,\ n_6=20,\dots$

**由递推得**（视频引 1962 年原论文结论，证明略）：$h < \frac{3}{2}\log_2(n+1)$，即 $h = O(\log_2 n)$。

- **最好**：完全平衡，$h=\lceil \log_2(n+1)\rceil$，查找 $O(\log_2 n)$。
- **最坏**：结点数取最少形态，$h \approx 1.44\log_2 n$，仍为 $O(\log_2 n)$。
- **平均**：在等概率查找假设下，ASL 与树高同阶，为 $O(\log_2 n)$；推导依据是「任意 $n$ 个结点的 AVL 树高被 $O(\log_2 n)$ 夹住」，故平均比较次数不超过常数倍 $\log_2 n$。

**应用结论**：$n=9$ 时 $n_4=7<9\le n_5=12$，故树高最大为 4，最坏比较 4 次。

## 6. 易错点与考试写法

1. **BF 符号方向**：王道定义为「左减右」，LL 型根 BF = +2，RR 型根 BF = −2。答题时写清定义，避免与「右减左」教材冲突。
2. **找错最小不平衡子树**：必须从插入点**向上第一个**失衡结点，不是整棵树的根。调整后要检查祖先 BF 是否复原。
3. **LR/RL 的旋转对象**：LR 是「先对 b 的左孩子 c 左旋，再对 c 右旋」，不是对 b 右旋两次。
4. **旋转后忘验 BST 序**：旋转只改结构不改中序序列，若中序不递增说明挂错子树。
5. **AVL 缩写**：来自 Adelson-Velsky 与 Landis，勿与平均查找长度 ASL 混淆（选择题常设此干扰）。
6. **答题程度**：选择题只需选出正确形态/旋转方向/调整后树形；简答或算法题要求画出调整前后两棵树并标注 BF，写出「最小不平衡子树根 + 形态 + 旋转步骤」三要素即算完整。

## 7. 408 题型与解题套路

- **选择题（高频）**：
  - 给插入序列，问调整后某结点的左/右孩子、树高、BF；
  - 给树形判断是否为 AVL、求某结点 BF；
  - 给 $n$ 求最大/最小树高（用 $n_h$ 递推表：0,1,2,4,7,12,20…）；
  - 判断「插入后一定需要调整吗」——不一定，只有出现 $|\text{BF}|>1$ 才调。
- **套路**：① 按 BST 规则插入 → ② 从插入点向上算 BF 找最小不平衡根 → ③ 判形态（看插入点在根的哪条「左左/右右/左右/右左」路径）→ ④ 旋转 → ⑤ 中序验证。
- **陷阱**：删除结点也可能引发调整（本节未展开，408 偶考概念）；插入多个结点时可能多次调整，每次只调当时的最小不平衡子树。

## 9. 背诵卡

1. AVL：任一结点 $|\text{BF}|=|\text{左高}-\text{右高}|\le 1$；名字来自 Adelson-Velsky & Landis，别混 ASL。
2. 插入后从下往上找**第一个**失衡结点 = 最小不平衡子树根，只调它。
3. LL→右旋；RR→左旋；LR→先左后右；RL→先右后左；口诀「左孩子才右旋，右孩子才左旋，孩子变爹」。
4. 旋转三步：移子树、换父子、改祖父指针；旋转后必验中序递增。
5. 最少结点递推 $n_h=n_{h-1}+n_{h-2}+1$：0,1,2,4,7,12,20…；树高 $O(\log_2 n)$，查找 $O(\log_2 n)$。

## 10. 关联与下一节

- **向上关联**：BST 的插入与 ASL——AVL 是把 BST 的「最坏 $O(n)$」压到「$O(\log_2 n)$」的结构保证。
- **向下关联**：下一节通常进入**平衡二叉树的删除**（同样找最小不平衡子树，但可能需向上回溯多次调整）或 **B 树/B+ 树**（多路平衡，降低树高以适应磁盘）。
- **真题连接**：AVL 插入调整几乎年年以选择题出现；$n_h$ 递推常与「求最大高度/最少结点」结合命题。
