- **408 大纲**：线性表的顺序存储结构及其基本操作。

## 2. 一句话结论

按位查找靠“起始地址 + 元素大小”直接算地址，$O(1)$；按值查找只能从头逐个比较，$O(n)$，等概率成功时平均比较 $\frac{n+1}{2}$ 次。

## 3. 知识地图

```text
顺序表的查找
├─ 按位查找 GetElem(L, i)
│  ├─ 静态分配：L.data[i - 1]
│  ├─ 动态分配：L.data 是指针，仍可下标访问
│  ├─ 合法性：1 ≤ i ≤ length
│  └─ O(1)：连续存放 + 同类型等长 + 知道起始地址
└─ 按值查找 LocateElem(L, e)
   ├─ 从下标 0 扫到 length - 1
   ├─ 命中返回位序 i + 1，失败返回 0
   ├─ 结构体不能直接 ==（C 语言）
   └─ O(n)：最好 1 次，最坏 n 次，平均 (n + 1) / 2 次
```

## 4. 核心内容

### 4.1 按位查找

**语义**：取线性表 $L$ 中第 $i$ 个元素（$1 \le i \le length$），返回该元素的值。这里的 $i$ 是**位序**，从 1 开始；数组下标从 0 开始。

#### 静态分配的实现

```c
#define MaxSize 10

typedef struct {
    ElemType data[MaxSize];  // 静态数组，容量固定
    int length;              // 当前元素个数
} SqList;

ElemType GetElem(SqList L, int i) {
    // 视频里的写法是直接返回；工程上建议先判断 i 是否合法
    return L.data[i - 1];    // 位序 i → 下标 i - 1
}
```

更健壮的写法（把“是否找到”和“元素值”分开）：

```c
#include <stdbool.h>

bool GetElem(SqList L, int i, ElemType *e) {
    if (i < 1 || i > L.length) return false;  // 越界或空表
    *e = L.data[i - 1];
    return true;
}
```

#### 动态分配的实现

```c
#include <stdlib.h>

#define InitSize 10

typedef struct {
    ElemType *data;  // 指向 malloc 申请的连续空间
    int MaxSize;     // 当前容量
    int length;      // 当前元素个数
} SeqList;

void InitList(SeqList *L) {
    L->data = (ElemType *)malloc(sizeof(ElemType) * InitSize);
    if (L->data == NULL) exit(1);  // 申请失败
    L->MaxSize = InitSize;
    L->length = 0;
}

ElemType GetElem(SeqList L, int i) {
    return L.data[i - 1];  // 指针也可以像数组一样下标访问
}
```

**为什么 `data` 是指针还能写 `data[i]`？**

`data` 保存的是整片连续内存的起始地址。`data[i]` 的实际地址是：

$$
\&data[i] = data + i \times \text{sizeof}(ElemType)
$$

计算机按**指针指向的类型大小**决定每次跨多少字节。

视频里的例子：假设 `data` 指向地址 2000，`ElemType` 占 6 个字节。

| 表达式 | 指针类型 | 起始地址 | 读取的字节 |
| --- | --- | --- | --- |
| `data[0]` | `ElemType *` | 2000 | 2000–2005（6 B） |
| `data[1]` | `ElemType *` | 2006 | 2006–2011（6 B） |
| `p[0]` | `int *` | 2000 | 2000–2003（4 B） |
| `p[1]` | `int *` | 2004 | 2004–2007（4 B） |

同样从 2000 开始，`ElemType *` 的 `[1]` 落在 2006，`int *` 的 `[1]` 落在 2004——**指针类型决定步长**。这也是为什么 `malloc` 返回的指针要强制转换成 `ElemType *`：类型错了，后面用下标访问就会按错误的字节数跳。

> C 里 `void *` 可以隐式转成其他指针，但显式写 `(ElemType *)` 更清楚；C++ 必须显式转换。

#### 为什么是 $O(1)$

代码里只有一次地址计算和一次内存访问，没有循环、没有递归。只要满足下面三个条件，就能“一步到位”：

1. 所有元素在内存中**连续存放**；
2. 每个元素的**类型相同、占用空间一样大**；
3. 知道**起始地址**。

这就是顺序表的**随机存取**特性。注意：随机存取指的是“按位置取元素是 $O(1)$”，不是“按值查找是 $O(1)$”。

### 4.2 按值查找

**语义**：在线性表 $L$ 中查找第一个值等于 $e$ 的元素；找到返回它的**位序**，找不到返回 0。

```c
int LocateElem(SqList L, ElemType e) {
    for (int i = 0; i < L.length; i++) {  // 下标从 0 到 length - 1
        if (L.data[i] == e) {
            return i + 1;                 // 下标 → 位序
        }
    }
    return 0;                             // 未找到；0 不是合法位序
}
```

这个写法对静态分配和动态分配都适用，因为二者都能用 `L.data[i]` 访问元素。

**例子**：`L = {4, 7, 9, 12, 15, 18}`，`length = 6`，查找 `e = 9`。

- `i = 0`，`4 != 9`；
- `i = 1`，`7 != 9`；
- `i = 2`，`9 == 9`，返回 `i + 1 = 3`。

#### 结构体为什么不能直接 `==`

如果 `ElemType` 是基本类型（`int`、`char`、`double`、`float` 等），可以直接用 `==` 比较。但如果是结构体：

```c
typedef struct {
    int id;
    char name[20];
} Customer;

Customer a = {1, "张三"};
Customer b = {1, "张三"};
// if (a == b) { ... }   // C 语言编译不过
```

C 语言没有为结构体自动生成“逐成员比较”的 `==`，必须自己写：

```c
#include <stdbool.h>
#include <string.h>

bool EqualCustomer(Customer a, Customer b) {
    return a.id == b.id && strcmp(a.name, b.name) == 0;
}
```

C++ 可以重载运算符，让 `a == b` 合法：

```cpp
#include <cstring>

bool operator==(const Customer &a, const Customer &b) {
    return a.id == b.id && strcmp(a.name, b.name) == 0;
}
```

**考试怎么写**：

- 科目叫「数据结构」：重点是算法思想，伪代码里用 `==` 比较结构体通常可以接受；
- 科目叫「C 语言程序设计」：语法会被严格检查，结构体要逐成员比较，或调用自己写的比较函数；
- 最稳的办法是看报考学校的历年真题和题目要求。

## 5. 复杂度分析

| 操作 | 最好 | 最坏 | 平均 | 结论 |
| --- | --- | --- | --- | --- |
| 按位查找 `GetElem` | $O(1)$ | $O(1)$ | $O(1)$ | 随机存取 |
| 按值查找 `LocateElem` | $O(1)$ | $O(n)$ | $O(n)$ | 顺序扫描 |

按值查找的三种情况：

- **最好**：目标就在第一个位置，比较 1 次，$O(1)$；
- **最坏**：目标在最后一个位置，或根本不存在，比较 $n$ 次，$O(n)$；
- **平均**（假设目标等概率出现在 $n$ 个位置中的任意一个）：

$$
ASL_{\text{成功}} = \frac{1}{n}(1 + 2 + \cdots + n) = \frac{n+1}{2}
$$

所以平均时间复杂度仍是 $O(n)$。

如果查找失败，$n$ 个元素都要比较一遍，$ASL_{\text{失败}} = n$。

> 注意：不能因为“最好情况是 $O(1)$”就说按值查找是 $O(1)$。没有特别说明时，复杂度看最坏 / 平均，答案是 $O(n)$。

## 6. 易错点与考试写法

1. **位序和下标混用**：题目说“第 $i$ 个元素”，代码写 `data[i - 1]`；返回位置时写 `i + 1`。
2. **循环边界写错**：`for (int i = 0; i < L.length; i++)`，不是 `<= L.length`；`length` 是元素个数，不是最大容量 `MaxSize`。
3. **动态分配的指针类型**：`data` 是 `ElemType *`，`data[i]` 的步长是 `sizeof(ElemType)`；不要把 `malloc` 的返回值随便转成别的指针类型。
4. **结构体直接用 `==`**：C 语言编译不过；要么逐成员比较，要么写比较函数；C++ 可以重载。
5. **找不到时返回 0**：位序从 1 开始，0 专门表示“没找到”，不要返回 -1 又混着用。
6. **空表**：`length = 0` 时循环一次都不进，直接返回 0；按位查找要先判断 `i` 是否在 `1..length`。
7. **随机存取 ≠ 随机查找**：按位置取是 $O(1)$；按值找还是得扫描。
8. **有序表不要硬套本节**：如果表是有序的，可以用折半查找做到 $O(\log n)$，但那是第 7 章的内容，而且要求能随机存取。

> 视频里反复强调的三件事：位序从 1 开始、下标从 0 开始；`malloc` 的返回值要强转成正确的元素指针；C 语言里结构体不能直接用 `==`。

## 7. 408 题型与解题套路

- **选择题**：按位查找为什么是 $O(1)$；随机存取需要哪些条件；按值查找的平均比较次数；位序与下标的换算；静态 / 动态分配的差异。
- **算法题**：顺序表的查找、删除、去重、合并、找最值、逆置。常用套路是双指针 + 一次扫描，注意时间复杂度和空间复杂度的说明。
- **综合题**：和插入 / 删除结合，考平均移动次数；和有序表结合，考折半查找与 ASL。
- **常见陷阱**：把 `length` 当容量；循环多走一位；结构体比较不写函数；把“最好情况”当成平均复杂度。

## 8. 自测题

**Q1**：顺序表按位查找能做到 $O(1)$，依赖哪三个条件？

<details>
<summary>答案</summary>

元素连续存放；每个元素类型相同、占用空间一样大；知道起始地址。这样第 $i$ 个元素的地址可以直接算：`base + (i - 1) * sizeof(ElemType)`。
</details>

**Q2**：动态分配的顺序表中，`ElemType` 占 8 个字节，`data` 指向地址 1000，`data[3]` 的起始地址是多少？

<details>
<summary>答案</summary>

$1000 + 3 \times 8 = 1024$。注意 `data[3]` 是第 4 个元素，位序是 4。
</details>

**Q3**：长度为 $n$ 的顺序表，按值查找在“目标等概率出现在任一位置”的假设下，成功平均比较多少次？失败呢？

<details>
<summary>答案</summary>

成功：$\frac{1}{n}(1+2+\cdots+n)=\frac{n+1}{2}$ 次；失败：$n$ 次。两种情况的时间复杂度都是 $O(n)$。
</details>

**Q4**：C 语言中两个结构体能不能直接用 `==` 比较？考研答题怎么处理？

<details>
<summary>答案</summary>

不能，C 不会自动逐成员比较。需要自己写函数，逐个成员比较（字符串用 `strcmp`）。C++ 可以重载 `operator==`。如果考「数据结构」，伪代码里用 `==` 通常可以；如果考「C 语言程序设计」，要按严格语法写。
</details>

**Q5**：有序顺序表用本节的 `LocateElem` 查找合适吗？更好的选择是什么？

<details>
<summary>答案</summary>

能用，但还是 $O(n)$ 的顺序扫描，浪费了“有序”这个条件。有序且支持随机存取时，可以用折半查找，把时间复杂度降到 $O(\log n)$，具体在第 7 章「查找」。
</details>

## 9. 背诵卡

- 位序 $i$ ↔ 下标 $i-1$；返回位置要 $+1$。
- `GetElem`：$O(1)$，靠“连续 + 等长 + 起始地址”随机存取。
- `LocateElem`：$O(n)$；最好 1 次，最坏 $n$ 次，平均 $\frac{n+1}{2}$ 次。
- 动态 `data` 是指针，`data[i]` 的步长是 `sizeof(ElemType)`，`malloc` 要强转。
- C 结构体比较要逐成员；C++ 可重载 `==`；考试按科目要求写。
