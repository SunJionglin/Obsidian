# 2.3.2 单链表的插入与删除

## 1. 本节定位

- **对应王道书**：第 2 章 线性表 · 2.3.2 单链表的插入删除（按位序插入、指定结点前插/后插、按位序删除、删除指定结点）。
- **408 大纲对应**：线性表的链式存储结构——单链表的插入、删除操作（算法设计题与选择题均常考）。
- **先修知识**：单链表结点结构 `LNode`、头指针 `L`、头结点概念、`malloc`/`free` 的作用、指针与 `next` 域的修改。
- **本章位置**：紧接 2.3.1 单链表的定义与按位查找，是单链表基本操作的“核心动作”，后续双链表、循环链表、静态链表的插入删除都以此为基础。

> 说明：本节只讨论**单链表**（只能单向向后检索）。静态分配/动态分配、按值查找的复杂度推导属于 2.2 顺序表与 2.3.1 的内容，本节不重复。

---

## 2. 一句话结论

**单链表插入/删除的本质是“找到前驱结点，改 `next` 指针”；带头结点可统一处理第 1 个位置，不带头结点必须对 `i=1` 特判；给定结点 p 的前插、删除可用“偷天换日”（复制数据域）做到 $O(1)$，但删除 p 为表尾结点时该技巧失效。**

---

## 3. 知识地图

```
单链表插入删除
├── 插入
│   ├── 按位序插入 InsertList(L, i, e)
│   │   ├── 带头结点：p 从头结点(第0个)出发，找第 i-1 个，后插
│   │   └── 不带头结点：i=1 特判（改头指针 L），i>1 同带头结点
│   ├── 后插操作 InsertNextNode(p, e)：给定 p，在 p 之后插入，O(1)
│   └── 前插操作 InsertPriorNode(p, e)
│       ├── 思路一：传头指针，找 p 的前驱，O(n)
│       └── 思路二：偷天换日，O(1)（王道书版传结点 s）
├── 删除
│   ├── 按位序删除 ListDelete(L, i, &e)
│   │   └── 带头结点：找第 i-1 个，q 指向第 i 个，摘链 + free，O(n)
│   └── 删除指定结点 DeleteNode(p)
│       ├── 偷天换日：复制后继数据到 p，删后继，O(1)
│       └── 缺陷：p 为表尾时 q=NULL，q->data 空指针错误 → 只能从头找前驱
└── 关键前提：单链表只能向后检索，不能向前
```

## 4. 核心内容

### 1. 结点定义（王道风格，前提）

```c
typedef struct LNode {
    ElemType data;      // 数据域
    struct LNode *next; // 指针域
} LNode, *LinkList;
```

### 2. 按位序插入（带头结点）

**目标**：在第 $i$ 个位置插入元素 $e$，即插到第 $i-1$ 个结点之后。头结点视为“第 0 个结点”。

```c
bool ListInsert(LinkList L, int i, ElemType e) {
    if (i < 1) return false;          // 位序从 1 开始，i<1 非法
    LNode *p = L;                     // p 指向头结点（第 0 个）
    int j = 0;                        // j 记录 p 当前指向第几个结点
    while (p != NULL && j < i - 1) {  // 找第 i-1 个结点
        p = p->next;
        j++;
    }
    if (p == NULL) return false;      // i 太大，第 i-1 个不存在
    LNode *s = (LNode *)malloc(sizeof(LNode));
    if (s == NULL) return false;      // 内存分配失败（可省略，但要知道）
    s->data = e;
    s->next = p->next;                // ① 先让新结点接上后继
    p->next = s;                      // ② 再让前驱指向新结点
    return true;
}
```

**关键点**：

- 循环结束时 `p` 指向第 $i-1$ 个结点，`j = i-1`。
- **①②两句不能颠倒**：若先 `p->next = s`，则 `p->next` 已丢失原后继，再执行 `s->next = p->next` 会让 `s->next` 指向自己，链表断裂、后续结点丢失。
- `i=1` 时循环不执行，`p` 就是头结点，逻辑统一——这就是带头结点的好处。

### 3. 按位序插入（不带头结点）

```c
bool ListInsert(LinkList L, int i, ElemType e) {
    if (i < 1) return false;
    if (i == 1) {                     // 特判：插入到表头，需改头指针 L
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = e;
        s->next = L;                  // 新结点指向原第一个结点
        L = s;                        // 头指针改指向新结点
        return true;
    }
    LNode *p = L;                     // p 指向第一个结点
    int j = 1;                        // j 从 1 开始
    while (p != NULL && j < i - 1) {  // 找第 i-1 个结点
        p = p->next;
        j++;
    }
    if (p == NULL) return false;
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;
    p->next = s;
    return true;
}
```

**对比记忆**：不带头结点时没有“第 0 个结点”，`i=1` 必须单独处理（改头指针 `L`）；`i>1` 的逻辑与带头结点完全一致，只是 `j` 初值从 1 开始。

### 4. 后插操作（给定结点 p，在 p 之后插入 e）

```c
bool InsertNextNode(LNode *p, ElemType e) {
    if (p == NULL) return false;
    LNode *s = (LNode *)malloc(sizeof(LNode));
    if (s == NULL) return false;      // 内存分配失败
    s->data = e;
    s->next = p->next;
    p->next = s;
    return true;
}
```

**封装价值**：按位序插入可写成“先找第 $i-1$ 个结点，再调用 `InsertNextNode`”，逻辑更清晰。

### 5. 前插操作（给定结点 p，在 p 之前插入 e）

**思路一（找前驱）**：传入头指针，从头遍历找 p 的前驱，再后插。时间 $O(n)$。

**思路二（偷天换日，$O(1)$）**：单链表看不到 p 的前驱，但可以“改数据不改位置”。

```c
// 王道书版：传入待插入结点 s
bool InsertPriorNode(LNode *p, LNode *s) {
    if (p == NULL || s == NULL) return false;
    s->next = p->next;        // s 先挂到 p 之后
    p->next = s;
    // 交换 p 与 s 的数据域，逻辑上等价于 s 插到了 p 之前
    ElemType temp = p->data;
    p->data = s->data;
    s->data = temp;
    return true;
}
```

**本质**：新结点物理上在 p 之后，但数据域交换后，逻辑顺序变为“e 在 p 原数据之前”。

### 6. 按位序删除（带头结点）

**目标**：删除第 $i$ 个结点，需先找第 $i-1$ 个结点（前驱），并带回被删元素。

```c
bool ListDelete(LinkList L, int i, ElemType *e) {
    if (i < 1) return false;
    LNode *p = L;                     // p 指向头结点（第 0 个）
    int j = 0;
    while (p != NULL && j < i - 1) {  // 找第 i-1 个结点
        p = p->next;
        j++;
    }
    if (p == NULL || p->next == NULL) return false; // 第 i 个不存在
    LNode *q = p->next;               // q 指向被删结点（第 i 个）
    *e = q->data;                     // 带回被删元素（e 为引用/指针）
    p->next = q->next;                // 摘链：前驱跳过 q
    free(q);                          // 释放结点
    return true;
}
```

**注意**：`p->next == NULL` 判断不可少——若 `i` 恰好等于表长 +1，`p` 指向表尾，`q = p->next = NULL`，直接 `q->data` 会空指针。

### 7. 删除指定结点 p（偷天换日）

```c
bool DeleteNode(LNode *p) {
    if (p == NULL) return false;
    LNode *q = p->next;               // q 指向 p 的后继
    p->data = q->data;                // 后继数据复制到 p
    p->next = q->next;                // p 跳过 q
    free(q);                          // 释放后继结点
    return true;
}
```

**缺陷（必考陷阱）**：若 p 是**表尾结点**，则 `q = NULL`，`q->data` 空指针错误。此时只能从头遍历找 p 的前驱，用常规摘链方式删除，时间 $O(n)$。

## 5. 复杂度分析

设表长为 $n$，插入/删除位置为 $i$（$1 \le i \le n+1$ 或 $1 \le i \le n$）。

| 操作 | 最好 | 最坏 | 平均 |
|---|---|---|---|
| 按位序插入（带头/不带头） | $O(1)$（$i=1$） | $O(n)$（$i=n+1$，插表尾） | $O(n)$ |
| 后插（给定 p） | $O(1)$ | $O(1)$ | $O(1)$ |
| 前插（偷天换日） | $O(1)$ | $O(1)$ | $O(1)$ |
| 前插（找前驱） | $O(1)$（p 为第一个） | $O(n)$（p 为表尾） | $O(n)$ |
| 按位序删除 | $O(1)$（$i=1$） | $O(n)$（$i=n$） | $O(n)$ |
| 删除指定结点（偷天换日） | $O(1)$ | $O(1)$（p 非表尾） | $O(1)$ |
| 删除指定结点（p 为表尾） | — | $O(n)$ | $O(n)$ |

**平均复杂度推导（按位序插入/删除）**：

假设插入位置 $i$ 在 $1 \sim n+1$ 中等概率取值，概率 $p = \frac{1}{n+1}$。查找第 $i-1$ 个结点需移动指针 $i-1$ 次，故平均移动次数

$$
\sum_{i=1}^{n+1} \frac{1}{n+1}(i-1) = \frac{1}{n+1}\cdot\frac{n(n+1)}{2} = \frac{n}{2}
$$

即平均 $O(n)$。删除同理（$i$ 在 $1\sim n$ 等概率，平均移动 $\frac{n-1}{2}$），仍为 $O(n)$。

## 6. 易错点与考试写法

1. **`s->next = p->next; p->next = s;` 顺序颠倒** → 链表自环、断链。默写时必须先接后继再改前驱。
2. **位序 vs 下标**：位序 $i$ 从 1 开始，头结点是“第 0 个”；数组下标从 0 开始。循环条件写 `j < i-1`，不是 `j < i`。
3. **不带头结点忘记特判 `i=1`**：必须改头指针 `L`，否则头插失败。
4. **删除时漏判 `p->next == NULL`**：`i` 超表长时 `q` 为空，`q->data` 崩溃。
5. **删除指定结点 p 为表尾**：偷天换日失效，必须说明“需从头找前驱”，这是王道书代码的已知 bug，答题时指出可加分。
6. **`free` 后不能再访问 q**：先取 `q->data` 再 `free(q)`，顺序不能反。
7. **`malloc` 返回值判空**：手写代码可不写，但要知道可能失败；答题写不写都不扣分（推断：按王道书风格，写了更严谨）。
8. **参数传递**：带回被删元素用 `ElemType *e`（C）或 `ElemType &e`（C++ 引用），408 答题用 C 指针即可。

**答题标准**：算法题写完整函数（含边界判断、指针修改、`free`），关键两句加注释说明“先接后继再改前驱”；复杂度注明最好/最坏/平均。

## 7. 408 题型与解题套路

- **选择题**：
  - 给一段插入/删除代码，问执行后链表形态或哪句写错（高频：两句顺序颠倒、`j` 初值、循环条件）。
  - 问“不带头结点插入第 1 个位置”与“带头结点”的代码差异。
  - 问删除指定结点 p 为表尾时的正确处理方式。
- **算法题**：
  - 按位序插入/删除是基础模板，常作为大题的一小步（如“删除所有值为 x 的结点”需先会删除）。
  - 偷天换日思想常用于“$O(1)$ 删除/前插”类设计题，答题时须说明表尾退化情况。
- **常见陷阱**：
  - 题目未说明是否带头结点 → 必须审题，两种代码都要会。
  - 要求“原地”“$O(1)$ 空间” → 用偷天换日或指针重排，不能新建数组。
  - 删除后要求“释放空间” → 必须 `free`。

**2.** 写出不带头结点单链表在第 1 个位置插入元素 e 的代码片段，并说明为什么必须特判。

**3.** 给定结点 p（非表尾），如何在 $O(1)$ 时间内删除它？若 p 是表尾结点，该做法为何失效？应如何补救？

**4.** 判断：单链表前插操作若只给结点 p、不给头指针，一定无法在 $O(1)$ 内完成。（说明理由）

**5.** 带头结点单链表删除第 $i$ 个结点，平均时间复杂度是多少？写出推导。

<details>
<summary>答案</summary>

1. `j < i-1` 保证循环结束时 p 指向第 $i-1$ 个结点（前驱），j 从 0（头结点）开始计数。若改成 `j < i`，p 会多走一步指向第 $i$ 个结点，插入位置错位（变成在第 $i+1$ 个位置前插入），且 i 较大时可能越界。
2. 
```c
LNode *s = (LNode *)malloc(sizeof(LNode));
s->data = e;
s->next = L;   // 新结点指向原第一个结点
L = s;         // 头指针改指向新结点
```
不带头结点时没有“第 0 个结点”，第 1 个位置的前驱不存在，无法用统一的“找前驱再后插”逻辑，必须直接修改头指针 L。
3. 令 `q = p->next`，把 `q->data` 复制到 `p->data`，再 `p->next = q->next`，最后 `free(q)`。若 p 为表尾，`q = NULL`，访问 `q->data` 空指针错误；补救：从头遍历找 p 的前驱，用常规摘链删除，时间 $O(n)$。
4. 错误。可用偷天换日：在 p 之后插入新结点 s，再交换 p 与 s 的数据域，逻辑上等价于在 p 之前插入，时间 $O(1)$（前提 p 非空）。
5. 平均 $O(n)$。设删除位置 $i$ 在 $1\sim n$ 等概率，概率 $1/n$，查找前驱移动 $i-1$ 次，平均移动 $\frac{1}{n}\sum_{i=1}^{n}(i-1)=\frac{n-1}{2}$，故 $O(n)$。

## 9. 背诵卡

1. **插入两句**：`s->next = p->next; p->next = s;` ——先接后继，再改前驱，顺序不可颠倒。
2. **带头结点**：头结点 = 第 0 个，`i=1` 与一般情况统一；**不带头结点**：`i=1` 必须特判改头指针。
3. **找前驱**：按位序插入/删除都要找第 $i-1$ 个，循环 `while(p && j<i-1){p=p->next; j++;}`，`j` 初值带头为 0、不带头为 1。
4. **偷天换日**：前插、删指定结点可 $O(1)$——复制数据域、删后继；**表尾失效**，只能从头找前驱。
5. **删除三步**：`q=p->next; *e=q->data; p->next=q->next; free(q);` ——先取值，再摘链，后释放。
