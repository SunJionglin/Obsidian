# 5.2.1 二叉树的性质

## 1. 本节定位

- **对应王道书**：第 5 章「树与二叉树」→ 5.2「二叉树」→ 5.2.1「二叉树的性质」。
- **408 大纲对应**：二叉树的性质（节点数与度、高度、完全二叉树编号关系）。
- **先修知识**：树的节点数 = 总度数 + 1；满二叉树、完全二叉树的定义；$m$ 叉树的层节点上限与高度节点上限（上一小节已推）。
- **本节位置**：紧接二叉树定义之后，是后续「顺序存储」「完全二叉树编号」「堆」「哈夫曼树」的计算基础，属于**纯计算型高频考点**。

## 2. 一句话结论

非空二叉树中**叶子数比双分支节点数多 1**（$n_0=n_2+1$），且完全二叉树只要给出节点总数 $n$，就能唯一确定 $n_0,n_1,n_2$ 与高度 $h$。

## 3. 知识地图

```
二叉树的性质
├─ 度与节点数关系
│   ├─ n = n0 + n1 + n2
│   ├─ n = 总度数 + 1 = n1 + 2n2 + 1
│   └─ 推出 n0 = n2 + 1
├─ 层/高度上限
│   ├─ 第 i 层最多 2^(i-1) 个节点
│   └─ 高度 h 最多 2^h - 1 个节点（满二叉树取到）
├─ 完全二叉树的高度
│   ├─ h = ⌈log2(n+1)⌉
│   └─ h = ⌊log2 n⌋ + 1
├─ 完全二叉树的 n0/n1/n2
│   ├─ n1 ∈ {0,1}
│   ├─ n 为偶数 → n1 = 1
│   └─ n 为奇数 → n1 = 0
└─ 编号与层次
    └─ 节点 i 所在层 = ⌊log2 i⌋ + 1
```

## 4. 核心内容

### 4.1 度与节点数的关系（408 必考）

设非空二叉树中度为 0、1、2 的节点数分别为 $n_0,n_1,n_2$，节点总数 $n$。

**式①（按节点分类计数）**：

$$n=n_0+n_1+n_2$$

**式②（按分支数计数）**：树中除根外每个节点恰有一条入分支，故

$$n=\text{总度数}+1=n_1+2n_2+1$$

**两式相减**：

$$n_0+n_1+n_2=n_1+2n_2+1\;\Longrightarrow\;\boxed{n_0=n_2+1}$$

> 直观理解：每个双分支节点“多出”一个分支，最终必然多出一个叶子来收尾。

### 4.2 层与高度的上限（408 必考）

- 第 $i$ 层（$i\ge1$）最多 $2^{i-1}$ 个节点。
- 高度为 $h$ 的二叉树最多 $2^{h}-1$ 个节点，取到当且仅当是**满二叉树**。
- 高度为 $h$ 的二叉树最少 $h$ 个节点（每层一个）。

### 4.3 完全二叉树的高度（408 必考）

设完全二叉树有 $n$ 个节点、高度为 $h$。

**下界**：前 $h-1$ 层是满的，共 $2^{h-1}-1$ 个节点；高度为 $h$ 要求第 $h$ 层至少 1 个节点：

$$n\ge 2^{h-1}$$

**上界**：高度为 $h$ 最多是满二叉树：

$$n\le 2^{h}-1$$

联立得 $2^{h-1}\le n<2^{h}$，取对数：

$$h-1\le \log_2 n<h\;\Longrightarrow\;h=\lfloor\log_2 n\rfloor+1$$

等价写法（由 $2^{h-1}\le n\Rightarrow h\le \log_2 n+1$，再结合 $n\le 2^h-1\Rightarrow h\ge\log_2(n+1)$）：

$$h=\lceil\log_2(n+1)\rceil$$

> 两种写法结果相同，考试任选其一，**不要背错成 $\lceil\log_2 n\rceil$**。

### 4.4 完全二叉树的 $n_0,n_1,n_2$（408 必考）

两个前提：

1. 完全二叉树中 $n_1\in\{0,1\}$（最多一个单分支节点）。
2. $n_0+n_2=2n_2+1$ 必为**奇数**。

于是：

| $n$ 的奇偶 | $n_1$ | $n_0$ | $n_2$ |
|---|---|---|---|
| $n$ 为偶数 | $1$ | $n/2$ | $n/2-1$ |
| $n$ 为奇数 | $0$ | $(n+1)/2$ | $(n-1)/2$ |

**推导（偶数情形）**：$n=n_0+n_1+n_2$ 为偶数，而 $n_0+n_2$ 为奇数，故 $n_1$ 必须为奇数，又 $n_1\in\{0,1\}$，所以 $n_1=1$。再由 $n_0=n_2+1$ 与 $n_0+n_2=n-1$ 解得 $n_0=n/2,\;n_2=n/2-1$。

**推导（奇数情形）**：$n$ 为奇数、$n_0+n_2$ 为奇数，故 $n_1$ 为偶数，只能 $n_1=0$。解得 $n_0=(n+1)/2,\;n_2=(n-1)/2$。

### 4.5 编号与层次

完全二叉树按层序从 1 开始编号，编号为 $i$ 的节点所在层次为

$$\lfloor\log_2 i\rfloor+1$$

（由 4.3 的结论把 $n$ 换成 $i$ 即得。）

## 5. 复杂度分析

本节为**纯公式推导**，不涉及算法执行，无时间/空间复杂度。若把「由 $n$ 求 $h$」视作一次计算：

- 最好/最坏/平均均为 $O(1)$：只需一次对数运算或位运算（求最高位位置）。
- 平均情况说明：$n$ 在 $[2^{h-1},2^h-1]$ 内均匀取值时，$\lfloor\log_2 n\rfloor$ 恒为 $h-1$，故结果确定，无随机性。

## 6. 易错点与考试写法

1. **$n_0=n_2+1$ 只对二叉树成立**，$m$ 叉树要重新推（$n_0=1+n_2+2n_3+\cdots+(m-1)n_m$）。
2. **高度公式混淆**：$h=\lfloor\log_2 n\rfloor+1$ 与 $h=\lceil\log_2(n+1)\rceil$ 都对；写成 $\lceil\log_2 n\rceil$ 在 $n=2^k$ 时会错（如 $n=8$，正确 $h=4$，$\lceil\log_2 8\rceil=3$ 错）。
3. **$n_1$ 的取值**：完全二叉树 $n_1$ 只能 0 或 1，普通二叉树不受此限。
4. **奇偶判断方向别反**：$n$ 偶 → $n_1=1$；$n$ 奇 → $n_1=0$。
5. **答题程度**：选择题直接套结论；若考推导（少见），写出式①式②并相减即可得分，不必长篇解释。

## 7. 408 题型与解题套路

- **选择题（主流）**：
  - 给 $n_0$ 求 $n_2$ 或总数 → 套 $n_0=n_2+1$。
  - 给完全二叉树 $n$ 求叶子数/高度 → 套 4.3、4.4 表格。
  - 给高度 $h$ 求最多/最少节点 → $2^h-1$ / $h$。
  - 给编号 $i$ 求层次 → $\lfloor\log_2 i\rfloor+1$。
- **常见陷阱**：
  - 题目说“二叉树”而非“完全二叉树”，此时 $n_1$ 不能限定，只能用 $n_0=n_2+1$ 一个方程，需结合其他条件。
  - 求“最多”时默认满二叉树，求“最少”时默认单链。
  - 高度从 1 开始计层，不要按 0 起算。

## 8. 自测题

**1.** 一棵二叉树有 20 个叶子节点，则双分支节点数为多少？

**2.** 一棵完全二叉树有 1000 个节点，求叶子节点数、单分支节点数、高度。

**3.** 高度为 5 的二叉树最多、最少各有多少个节点？

**4.** 完全二叉树中编号为 100 的节点位于第几层？

**5.** 判断：任何二叉树都满足 $n_0=n_2+1$，且 $n_1\le1$。

<details>
<summary>答案</summary>

1. $n_2=n_0-1=19$。
2. $n=1000$ 为偶数 → $n_1=1$，$n_0=500$，$n_2=499$；$h=\lfloor\log_2 1000\rfloor+1=9+1=10$。
3. 最多 $2^5-1=31$；最少 5。
4. $\lfloor\log_2 100\rfloor+1=6+1=7$ 层。
5. 错。$n_0=n_2+1$ 对任何二叉树成立，但 $n_1\le1$ 只对完全二叉树成立，普通二叉树 $n_1$ 可任意大。

</details>

## 9. 背诵卡

1. $n=n_0+n_1+n_2=n_1+2n_2+1\Rightarrow n_0=n_2+1$。
2. 第 $i$ 层最多 $2^{i-1}$；高 $h$ 最多 $2^h-1$，最少 $h$。
3. 完全二叉树：$h=\lfloor\log_2 n\rfloor+1=\lceil\log_2(n+1)\rceil$。
4. 完全二叉树 $n_1\in\{0,1\}$：$n$ 偶 → $n_1=1$；$n$ 奇 → $n_1=0$。
5. 编号 $i$ 所在层 = $\lfloor\log_2 i\rfloor+1$。
