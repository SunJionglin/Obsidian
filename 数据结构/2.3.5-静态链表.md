# 2.3.5 静态链表

## 1. 本节定位

- **王道书对应**：第 2 章线性表，2.3 线性表的链式表示，2.3.5 静态链表（单链表的一种“数组实现”变体）。
- **408 大纲对应**：线性表的实现（顺序存储、链式存储），静态链表属于链式存储的扩展实现方式。
- **先修知识**：单链表的结构（数据域 + 指针域）、头结点作用、`typedef` 与结构体数组、`sizeof` 运算符。
- **本节位置**：在单链表（2.3.1–2.3.4）之后，是“用数组模拟指针”的过渡内容，为后续双链表、循环链表打基础，同时为操作系统 FAT 表埋伏笔。

## 2. 一句话结论

静态链表 = **用一整片连续内存（结构体数组）存放节点，用数组下标（游标）代替指针表示逻辑先后关系**；逻辑相邻的元素物理上可以不相邻，插入删除只改游标不移动元素，但容量固定、不支持随机存取。

## 3. 知识地图

```
静态链表
├── 定义
│   ├── 存储：一片连续内存（结构体数组）
│   ├── 节点 = 数据域 data + 游标 next（int，存下一个节点的数组下标）
│   ├── 下标 0 节点 = 头结点（不存数据）
│   └── 表尾标志：next = -1（等价于 NULL）
├── 代码定义
│   ├── 写法一（易懂）：struct Node + struct Node a[MaxSize]
│   └── 写法二（王道书）：typedef struct { ElemType data; int next; } SLinkList[MaxSize]
├── 基本操作
│   ├── 初始化：头结点 next = -1；空闲节点 next = -2（标记空闲）
│   ├── 按位序查找：从头结点沿游标走，O(n)
│   ├── 插入：找空闲节点 → 改前驱游标 → 新节点游标指向后继
│   └── 删除：改前驱游标 → 被删节点 next = -2（回收标记）
└── 特点
    ├── 优点：插入删除不移动元素；无指针，适合不支持指针的语言
    └── 缺点：容量固定不可扩展；不能随机存取
```

## 4. 核心内容

### 1. 定义与基本原理（408 必考概念）

- 单链表节点**离散分布**在内存各处，指针存的是**真实内存地址**。
- 静态链表先分配**一整片连续内存**，节点放在其中某些位置；每个节点含 `data` 和 `next`，这里的 `next` 是**下一个节点的数组下标（游标）**，不是地址。
- **下标 0 的节点充当头结点**，不存实际数据；头结点游标指向第一个数据节点（位序 1）的数组下标。
- 表尾节点游标设为 `-1`，表示后面没有节点（相当于单链表的 `NULL`）。
- 游标 → 实际地址的映射：设每个节点占 $s$ 字节，起始地址为 $base$，则下标 $i$ 的节点地址为
  $$addr(i) = base + i \times s$$
  这就是“游标能代替指针”的根本原因（连续 + 等长）。

> 关键区分：**位序**是逻辑顺序（第几个元素），**数组下标**是物理位置。二者一般不相等。

### 2. 代码定义（能读懂、能默写）

**写法一：直观的结构体数组**

```c
#define MaxSize 10          // 静态链表最大长度
typedef struct {
    ElemType data;          // 数据域
    int next;               // 游标：下一个节点的数组下标
} SLinkList;                // 一个节点类型

SLinkList a[MaxSize];       // 声明静态链表：长度 10 的结构体数组
```

**写法二：王道书上的 typedef 数组写法（等价）**

```c
#define MaxSize 10
typedef struct {
    ElemType data;
    int next;
} SLinkList[MaxSize];       // 注意：SLinkList 是“长度为 MaxSize 的数组类型”

SLinkList a;                // a 就是一个长度 10 的结构体数组
```

- 两种写法**完全等价**：`SLinkList a;` 等价于 `struct Node a[MaxSize];`。
- 王道书用写法二，是为了让代码“一眼看出 `a` 是静态链表”，与单链表中 `LinkList` / `LNode *` 的命名风格保持一致。
- 验证：若 `data`、`next` 各占 4 字节，单节点 8 字节，则 `sizeof(a) = 80`，与普通结构体数组一致。

### 3. 基本操作思路（了解即可，408 极少考代码）

**初始化**

```c
void InitList(SLinkList a) {
    a[0].next = -1;                 // 头结点：链表为空
    for (int i = 1; i < MaxSize; i++)
        a[i].next = -2;             // -2 标记该节点空闲（可复用）
}
```

> 为什么要标记空闲？内存中任何位置都有“脏数据”，计算机无法靠“看起来没数据”判断空闲，必须用特殊值（如 `-2`）显式标记。

**按位序查找**：从头结点 `a[0]` 出发，沿 `next` 游标走 $i$ 步，找到位序 $i$ 的节点。时间复杂度 $O(n)$。

**插入（位序 $i$）**

1. 扫描数组找一个 `next == -2` 的空闲节点，记其下标为 $k$；
2. 找到位序 $i-1$ 的节点（前驱），设其下标为 $p$；
3. `a[k].next = a[p].next;`（新节点接管后继）
4. `a[p].next = k;`（前驱指向新节点）

**删除（位序 $i$）**

1. 找到位序 $i-1$ 的前驱 $p$ 和位序 $i$ 的节点 $q$；
2. `a[p].next = a[q].next;`（前驱跳过被删节点）
3. `a[q].next = -2;`（标记回收）

### 4. 静态链表 vs 单链表 vs 顺序表

| 对比项 | 顺序表 | 单链表 | 静态链表 |
|---|---|---|---|
| 存储 | 连续 | 离散 | 连续（整片分配） |
| 逻辑关系表示 | 物理相邻 | 指针 | 游标（数组下标） |
| 插入删除 | 移动元素 $O(n)$ | 改指针 $O(1)$（已知前驱） | 改游标 $O(1)$（已知前驱） |
| 随机存取 | 支持 $O(1)$ | 不支持 | 不支持 |
| 容量 | 固定（动态可扩） | 动态 | **固定不可扩** |

## 5. 复杂度分析

设静态链表长度为 $n$（数据节点数），容量为 $MaxSize$。

- **按位序查找**：
  - 最好：查位序 1，走 1 步，$O(1)$；
  - 最坏：查位序 $n$，走 $n$ 步，$O(n)$；
  - 平均：假设查每个位序等概率（概率 $1/n$），比较次数
    $$\frac{1}{n}\sum_{i=1}^{n} i = \frac{1}{n}\cdot\frac{n(n+1)}{2} = \frac{n+1}{2}$$
    故平均 $O(n)$。
- **插入 / 删除**：找空闲节点需扫描数组，最坏 $O(MaxSize)$；找前驱需 $O(n)$；改游标本身 $O(1)$。整体 $O(n)$（若维护空闲链表可优化找空闲节点，属王道书扩展，408 不要求）。
- **空间**：$O(MaxSize)$，且**固定不变**。

## 6. 易错点与考试写法

1. **位序 ≠ 数组下标**：位序是逻辑第几个，数组下标是物理位置。静态链表中二者一般不相等，题目常在此设陷阱。
2. **头结点在下标 0**：静态链表的“头指针”就是下标 0，不是另设变量。
3. **表尾是 `-1` 不是 `0`**：`0` 是头结点下标，若把表尾写成 `0` 会形成环。
4. **空闲标记 `-2`**：初始化必须把所有空闲节点标 `-2`，否则无法区分“空闲”与“脏数据”。这是王道书扩展细节，选择题可能考“如何判断节点空闲”。
5. **`typedef ... SLinkList[MaxSize]` 的含义**：`SLinkList` 是**数组类型**，`SLinkList a;` 声明的是数组，不是单个节点。若写 `SLinkList *p;` 则 `p` 是指向整个数组的指针，与单链表 `LinkList` 用法不同，别混。
6. **答题程度**：408 对静态链表以**选择题概念辨析**为主，代码实现极少考。答题时写清“连续存储 + 游标代替指针 + 头结点下标 0 + 表尾 -1 + 容量固定”即可拿分；算法题若要求实现，按上面插入删除四步写伪代码并注明“找空闲节点”步骤即可。

## 7. 408 题型与解题套路

- **选择题高频考法**：
  - 给一个静态链表图，问某位序节点的数组下标 / 某节点的后继下标；
  - 问“静态链表插入一个节点需要修改几个游标”（答：2 个，前驱和新节点）；
  - 问“静态链表是否支持随机存取”（否）；
  - 问“静态链表的容量能否扩展”（否）；
  - 问“哪种场景适合静态链表”（元素数量基本固定、不支持指针的语言）。
- **算法题套路**：若考静态链表实现，核心是“找空闲节点 → 改前驱游标 → 接后继游标”，与单链表插入删除逻辑一一对应，只是把 `p->next` 换成 `a[p].next`。
- **常见陷阱**：把游标当指针做地址运算；忘记初始化空闲标记；把表尾写成 0；混淆位序与下标。

## 8. 自测题

**1.** 静态链表中，数组下标 0 的节点作用是什么？表尾节点的 `next` 通常设为多少？

**2.** 设静态链表每个节点占 8 字节，起始地址为 1000，则数组下标为 3 的节点地址是多少？这说明了什么？

**3.** 静态链表按位序查找的平均时间复杂度是多少？请写出推导。

**4.** 在静态链表中删除位序为 $i$ 的节点，需要修改哪些游标？被删节点的 `next` 应设为多少？

**5.** 判断：静态链表逻辑上相邻的元素在物理上也一定相邻。（说明理由）

<details>
<summary>答案</summary>

1. 充当**头结点**，不存实际数据，其 `next` 指向第一个数据节点的下标；表尾节点 `next = -1`（表示无后继）。
2. $1000 + 3 \times 8 = 1024$。说明连续且等长的存储下，游标（下标）可线性映射为真实地址，因此游标能代替指针。
3. 平均 $O(n)$。等概率查各位序，比较次数 $\frac{1}{n}\sum_{i=1}^n i = \frac{n+1}{2}$，为 $n$ 的线性函数。
4. 修改前驱节点（位序 $i-1$）的 `next`，使其跳过被删节点、指向被删节点的后继；被删节点 `next` 设为 `-2` 表示回收空闲。
5. **错**。静态链表整片内存连续，但逻辑相邻元素通过游标连接，物理位置可以不相邻（游标可指向任意下标）。

</details>

## 9. 背诵卡

1. 静态链表 = 结构体数组 + 游标（数组下标）代替指针。
2. 下标 0 是头结点，表尾 `next = -1`，空闲节点 `next = -2`。
3. 两种定义等价：`struct Node a[MaxSize]` ≡ `SLinkList a`（`typedef ... SLinkList[MaxSize]`）。
4. 插入删除只改游标不移动元素；查找必须从头沿游标走，$O(n)$，不支持随机存取。
5. 容量固定不可扩；适合元素数量基本固定、不支持指针的场合（如 OS 的 FAT 表）。

## 10. 关联与下一节

- **向前关联**：单链表的头结点、插入删除改指针逻辑，在静态链表中一一对应（指针 → 游标）。
- **向后关联**：下一节进入**双链表**（2.3.6），在单链表基础上增加前驱指针，插入删除需改更多指针，是 408 算法题高频考点。
- **跨科关联（补充）**：操作系统文件管理中 FAT（文件分配表）本质就是静态链表，学文件管理时可回看本节。
