# 5.4.3 树和森林的遍历

## 1. 本节定位

- **对应王道书**：第 5 章「树与二叉树」→ 5.4「树、森林」→ 5.4.3「树和森林的遍历」。
- **408 大纲对应**：树与二叉树——树的遍历、森林的遍历、树/森林与二叉树的转换关系。
- **先修知识**：二叉树的先序/中序/后序遍历、树的递归定义、孩子兄弟表示法（左孩子右兄弟）、队列的基本操作。
- **本节位置**：紧接 5.4.2「树、森林与二叉树的转换」。本节把「遍历」这一操作从二叉树推广到树和森林，核心是**遍历序列的等价关系**，是选择题高频考点，也是算法题把树/森林问题转成二叉树问题的桥梁。

## 2. 一句话结论

树的先根遍历 = 对应二叉树的先序遍历，树的后根遍历 = 对应二叉树的中序遍历；森林的先序遍历 = 各树先根遍历依次拼接 = 对应二叉树先序，森林的中序遍历 = 各树后根遍历依次拼接 = 对应二叉树中序。

## 3. 知识地图

```
树和森林的遍历
├── 树的遍历
│   ├── 先根遍历（深度优先）── 等价于对应二叉树的先序遍历
│   ├── 后根遍历（深度优先）── 等价于对应二叉树的中序遍历
│   └── 层次遍历（广度优先）── 借助辅助队列
└── 森林的遍历
    ├── 先序遍历 ── 效果 = 依次对每棵树先根遍历 ── 等价于对应二叉树的先序遍历
    └── 中序遍历 ── 效果 = 依次对每棵树后根遍历 ── 等价于对应二叉树的中序遍历
```

## 4. 核心内容

### 4.1 树的先根遍历

**定义**：若树非空，先访问根结点，再依次对根的每棵子树执行先根遍历。

**伪代码**（王道风格，前提：树用孩子兄弟表示法或可枚举孩子的存储结构）：

```c
void PreOrder(Tree T) {
    if (T != NULL) {
        visit(T);                 // 先访问根结点
        // 依次对每棵子树做先根遍历
        for (每个孩子结点 p，从左到右)
            PreOrder(p);          // 递归
    }
}
```

> 说明：普通树一个结点可有多个孩子，故用循环枚举孩子；具体循环写法取决于存储结构（孩子兄弟表示法用 `firstchild` + `nextsibling` 遍历，孩子表示法用孩子链表遍历）。视频用 while 循环检查「是否还有未访问的子树」，本质相同。

**例（视频中的树）**：根 A，孩子 B、C、D；B 的孩子 E、F；E 的孩子 K；C 的孩子 G；D 的孩子 H、I、J。

先根遍历序列：**A B E K F C G D H I J**。

**关键等价**：把该树用孩子兄弟表示法转成二叉树后，其**先序遍历序列与树的先根遍历序列完全相同**。

### 4.2 树的后根遍历

**定义**：若树非空，先依次对根的每棵子树执行后根遍历，最后访问根结点。

**伪代码**：

```c
void PostOrder(Tree T) {
    if (T != NULL) {
        for (每个孩子结点 p，从左到右)
            PostOrder(p);         // 先递归处理所有子树
        visit(T);                 // 最后访问根
    }
}
```

**例（同一棵树）**：后根遍历序列：**K E F B G C H I J D A**。

**关键等价**：树的后根遍历序列 = 对应二叉树的**中序遍历**序列。

### 4.3 树的层次遍历（广度优先）

**思路**：与二叉树层次遍历一致，用辅助队列。

```c
void LevelOrder(Tree T) {
    InitQueue(Q);
    if (T != NULL) EnQueue(Q, T);
    while (!IsEmpty(Q)) {
        DeQueue(Q, p);
        visit(p);                       // 出队即访问
        for (每个孩子 c of p，从左到右)
            EnQueue(Q, c);              // 孩子依次入队
    }
}
```

**例**：层次遍历序列：**A B C D E F G H I J K**。

**概念对照**：先根、后根是**深度优先遍历**（尽量往深处走，走不通再回退）；层次遍历是**广度优先遍历**（尽量横向扩展）。

### 4.4 森林的先序遍历

**递归定义**：森林非空时，
1. 访问第一棵树的根结点；
2. 先序遍历第一棵树的**子树森林**（去掉根后其各子树构成的森林）；
3. 先序遍历**剩余树**构成的森林。

**做题捷径（推荐）**：不必钻递归，直接用下面两条等价之一：
- 效果上 = **依次对森林中每棵树做先根遍历**，序列首尾拼接；
- 或先把森林转成对应二叉树，求其**先序遍历**序列。

### 4.5 森林的中序遍历

**递归定义**：森林非空时，
1. 中序遍历第一棵树的**子树森林**；
2. 访问第一棵树的根结点；
3. 中序遍历剩余树构成的森林。

**做题捷径（推荐）**：
- 效果上 = **依次对森林中每棵树做后根遍历**，序列首尾拼接；
- 或转成对应二叉树，求其**中序遍历**序列。

> 注意：森林没有「后序遍历」这一说法（王道体系下森林只讲先序、中序），这是常见概念陷阱。

### 4.6 等价关系总表（本节最该背的表）

| 树 / 森林的遍历 | 等价的二叉树遍历 |
|---|---|
| 树的先根遍历 | 二叉树的先序遍历 |
| 树的后根遍历 | 二叉树的中序遍历 |
| 树的层次遍历 | （无直接二叉树对应，需队列） |
| 森林的先序遍历 | 二叉树的先序遍历 |
| 森林的中序遍历 | 二叉树的中序遍历 |

## 5. 复杂度分析

设树（森林）共 $n$ 个结点。

- **先根 / 后根 / 中序（森林）遍历**：每个结点恰好被 `visit` 一次，每条「父→子」边恰好被枚举一次，故时间 $T(n)=O(n)$。最好、最坏、平均均为 $O(n)$（与树的形态无关，因为都要访问全部结点）。
- **层次遍历**：每个结点入队、出队各一次，每次 $O(1)$，共 $O(n)$；队列最大长度不超过「结点数最多的那一层」的结点数 $w$，空间 $O(w)$，最坏 $O(n)$（单支树时 $w=1$，满多叉树时 $w$ 可达 $O(n)$）。
- **递归遍历的栈空间**：递归深度 = 树高 $h$，空间 $O(h)$；最坏 $O(n)$（退化成链），最好 $O(\log n)$ 量级（平衡时，多叉树取对数底为度数）。
- **平均情况说明**：上述均为「访问全部结点」的确定性代价，不存在依赖输入分布的平均量；若按随机树模型讨论栈深，期望高度为 $O(\log n)$（补充，非本节考点）。

## 6. 易错点与考试写法

1. **「后根」≠「后序」混用**：树叫**先根/后根**，二叉树叫**先序/中序/后序**，森林叫**先序/中序**。答题时名称写错可能被判错。
2. **森林没有后序遍历**：只有先序和中序，别自造「森林后序」。
3. **等价方向别记反**：树的后根 ↔ 二叉树**中序**（不是后序）；这是最高频失分点。
4. **森林中序 = 各树后根依次拼接**，不是各树中序（树本身没有「中序」概念）。
5. **层次遍历必须用队列**，不能用栈；用栈得到的是深度优先。
6. **答题程度**：选择题只需给出遍历序列或判断等价关系；若考算法题，标准写法是「用孩子兄弟表示法存储 → 转化为二叉树遍历」，写出二叉树先序/中序递归代码即可，不必强行写多叉树枚举孩子的复杂代码。

## 7. 408 题型与解题套路

- **选择题（高频）**：
  - 给一棵树/森林，求先根、后根、层次、森林先序/中序序列 → 用「转二叉树 + 先序/中序」最快，或用「各树先根/后根拼接」。
  - 判断等价关系（树后根 = 二叉树中序等）。
  - 给遍历序列反推树形（结合孩子兄弟表示法）。
- **算法题（低频，但可能）**：要求遍历森林/树 → 套路：声明孩子兄弟结构体 `typedef struct CSNode { ElemType data; struct CSNode *firstchild, *nextsibling; } CSNode, *CSTree;`，然后直接套二叉树先序/中序递归模板，把 `lchild` 换成 `firstchild`、`rchild` 换成 `nextsibling`。
- **常见陷阱**：把森林中序误当「各树中序拼接」；把树后根误等价为二叉树后序；层次遍历误用栈。

## 9. 背诵卡

1. 树：先根、后根、层次（前两者深度优先，层次为广度优先）。
2. 树先根 = 二叉树先序；树后根 = 二叉树中序。
3. 森林先序 = 各树先根拼接 = 二叉树先序；森林中序 = 各树后根拼接 = 二叉树中序。
4. 森林只有先序、中序，**没有后序**。
5. 层次遍历用队列；算法题用孩子兄弟表示法转二叉树再套模板。
