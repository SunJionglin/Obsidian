# 5.3.1 二叉树的先序、中序、后序遍历

## 1. 本节定位

- **对应王道书**：第 5 章「树与二叉树」→ 5.3 二叉树的遍历 → 5.3.1 先序/中序/后序遍历（递归实现）。
- **408 大纲对应**：二叉树的遍历（先序、中序、后序、层次），属于「树与二叉树」必考内容。
- **先修知识**：二叉树的定义（空树 / 根 + 左子树 + 右子树）、递归函数、函数调用栈。
- **本节位置**：是二叉树所有遍历与算法题的基础。本节只讲**递归的三种深度优先遍历**；层次遍历在下一小节；由遍历序列构造二叉树、线索二叉树等后续小节都建立在本节之上。

## 2. 一句话结论

**先序、中序、后序遍历的差别只在于「访问根节点」发生在递归左子树、递归右子树之间的哪个位置：根左右、左根右、左右根；三种递归代码结构完全相同，只挪动 `visit(T)` 一行。**

## 3. 知识地图

```
二叉树的遍历

├── 按分层特性 → 层次遍历（下一小节）
└── 按递归特性 → 深度优先遍历（本节）

    ├── 中序遍历 InOrder ：左 → 根 → 右（中根遍历）
    └── 后序遍历 PostOrder：左 → 右 → 根（后根遍历）

        └── 递归代码（C 语言，王道风格）
            ├── 空间复杂度 O(h)（h 为树高）
            └── 应用：求树高 = 后序遍历的变种
```

## 4. 核心内容

### 4.1 遍历的定义

遍历（traversal）：按照某种规定的次序，把二叉树中所有结点都访问一遍（每个结点恰好访问一次）。线性表只有「从头到尾 / 从尾到头」两种简单规则；树是分层结构，规则需要专门制定。

### 4.2 三种遍历的递归定义

对非空二叉树（空树则什么都不做）：

| 遍历 | 访问顺序 | 别名 |
|---|---|---|
| 先序 PreOrder | 根 → 左子树 → 右子树 | 先根遍历 |
| 中序 InOrder | 左子树 → 根 → 右子树 | 中根遍历 |
| 后序 PostOrder | 左子树 → 右子树 → 根 | 后根遍历 |

关键点：左、右子树本身也按同一规则**递归**遍历。叶子结点可视为带两个空子树的结点，因此对单个结点 d，三种序列都只有 `d`。

### 4.3 手算方法一：分支结点逐层展开法

规则：遇到**分支结点**（非叶子），就按当前遍历的「根/左/右」顺序把它展开成下一级；叶子结点直接写出。

例（视频中的树）：根 a，左子树根 b（b 的左 d、右 e），右子树根 c（c 的左 f、右 g）。

- 先序（根左右）：a → 展开 b 得 `b d e` → 展开 c 得 `c f g`，得 **a b d e c f g**。
- 中序（左根右）：b 子树展开为 `d b e`，c 子树展开为 `f c g`，得 **d b e a f c g**。
- 后序（左右根）：b 子树 `d e b`，c 子树 `f g c`，得 **d e b f g c a**。

再练一棵（视频练习树）：a 的左 b（b 左 d，d 右 g；b 右 e），右 c（c 左 f）。

- 先序：**a b d g e c f**
- 中序：**d g b e a f c**
- 后序：**g d e b f c a**

### 4.4 手算方法二：画路径法（从递归执行原理总结）

先脑补出所有空结点（每个叶子下挂两个空子树）。从根出发：**左边有路先走左，走不通（遇空结点）再回退，再走右**。每个结点在整条路径上会被**路过三次**：

- 先序：**第一次**路过该结点时访问；
- 中序：**第二次**路过时访问；
- 后序：**第三次**路过时访问。

视频中 a–b–d–g–e–c–f 这棵树：先序第一个访问 a，中序第一个访问的是 b（a 第一次路过不访问，进左子树后 b 第一次路过也不访问，直到从 d 的空左子树返回、第二次路过 b 才访问），后序第一个访问的是 g（g 的左右空子树都返回后第三次路过 g）。两种手算方法任选一种练熟即可，考场上要又快又准。

### 4.5 递归代码（C 语言，王道风格，可默写）

```c
// 二叉树结点（二叉链表）
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

// 先序遍历：根左右
void PreOrder(BiTree T) {
    if (T != NULL) {
        visit(T);              // 访问根结点
        PreOrder(T->lchild);   // 递归遍历左子树
        PreOrder(T->rchild);   // 递归遍历右子树
    }
}

// 中序遍历：左根右
void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild);    // 递归遍历左子树
        visit(T);              // 访问根结点
        InOrder(T->rchild);    // 递归遍历右子树
    }
}

// 后序遍历：左右根
void PostOrder(BiTree T) {
    if (T != NULL) {
        PostOrder(T->lchild);  // 递归遍历左子树
        PostOrder(T->rchild);  // 递归遍历右子树
        visit(T);              // 访问根结点
    }
}
```

`visit(T)` 是抽象操作（如 `printf("%c", T->data)`），三种算法只差这一行的位置。空树时 `if` 不成立，直接返回，什么都不做。

### 4.6 递归执行过程（以先序为例，理解调用栈）

以 a（左 b，b 左 d、d 右 g，b 右 e；右 c，c 左 f）为例：

1. 调用 `PreOrder(a)`：a 非空 → visit(a)，然后调用 `PreOrder(a->lchild)`，系统把「当前执行到递归左子树这一行」的信息压栈。
2. 进入 `PreOrder(b)`：visit(b)，再递归左孩子 d。
3. 进入 `PreOrder(d)`：visit(d)，递归 d 的左孩子——为空，该层函数什么都不做直接返回，弹栈，回到 d 这一层，接着执行「递归右子树」。
4. 进入 `PreOrder(g)`：visit(g)，g 的左右孩子都为空，两次递归调用都立即返回，g 这层结束，弹栈回 d；d 这层也已执行完最后一句，弹栈回 b。
5. b 这层继续执行「递归右子树」→ `PreOrder(e)`：visit(e)……后续同理。

得到先序序列 **a b d g e c f**。要点：**递归调用前系统保存现场（压栈），子调用返回后从断点继续执行**；空结点也会产生一次函数调用（压栈后立即返回）。

### 4.7 应用：求树高（后序遍历的变种）

```c
int treeDepth(BiTree T) {
    if (T == NULL) return 0;
    int l = treeDepth(T->lchild);   // 求左子树高度
    int r = treeDepth(T->rchild);   // 求右子树高度
    return (l > r ? l : r) + 1;     // 取较大者加 1（相当于"访问根"）
}
```

结构上是「左 → 右 → 根」，即后序遍历的变种。**408 必考**：本章算法题大多由这三种遍历变换而来。

### 4.8 与算术表达式的关系（王道书扩展，真题考过）

对算术表达式的语法分析树做遍历：

- 先序遍历 → 前缀表达式（波兰表达式）；
- 中序遍历 → 中缀表达式（**需自行加括号**，否则与原式不等价）；
- 后序遍历 → 后缀表达式（逆波兰表达式）。

## 5. 复杂度分析

设二叉树结点数为 $n$，高度为 $h$。

- **时间复杂度**：三种遍历都恰好访问每个结点一次，每个结点上的操作（visit + 两次判空/递归调用）为 $O(1)$，故 $T(n)=O(n)$。最好、最坏、平均均为 $O(n)$——因为无论树形如何，都必须走遍全部 $n$ 个结点，不存在「提前结束」的情况。
- **空间复杂度**：递归调用栈的最大深度等于树高（外加空结点那一层）。视频给出的量级为 $O(h+1)$，舍去常数即 $O(h)$。
  - 最好情况：树尽量平衡，$h=\lceil \log_2(n+1)\rceil$，空间 $O(\log n)$；
  - 最坏情况：单支树（每个结点只有一个孩子），$h=n$，空间 $O(n)$；
  - 平均情况：在「$n$ 个结点的二叉树等可能出现」的假设下，随机二叉树的平均高度为 $\Theta(\log n)$（补充：随机 BST/随机二叉树模型下期望高度为 $O(\log n)$），故平均空间 $O(\log n)$。408 选择题通常只考最好/最坏两个端点，答 $O(h)$ 即可。

## 6. 易错点与考试写法

1. **「先序/中序/后序」指的是根的位置，不是左、右子树的顺序**：左右子树永远是先左后右，别写成「右左根」。
2. **中序、后序的第一个结点不一定是根**：先序序列第一个必是根；中序第一个是「最左下的结点」；后序第一个是「最左下的叶子」。视频中后序第一个是 g 而非 d，就是因为 d 还有右孩子 g。
3. **空子树也要「走一遍」**：画路径法必须先脑补空结点，否则中序/后序的「第几次路过」会数错。
4. **三种代码只挪 `visit` 一行**，默写时不要多写/漏写 `if (T != NULL)` 判断，否则空指针解引用。
5. **空间复杂度是 $O(h)$ 不是 $O(n)$**：只有退化成单支树时才等于 $O(n)$；答「$O(n)$」在平衡树上会判错。
6. **中缀表达式要加括号**：直接中序遍历算术表达式树得到的中缀序列缺少界限符，与原始表达式不等价，这是真题陷阱。
7. **答题标准**：手算遍历序列题，写出完整序列即可；若要求过程，用「分支结点逐层展开」写出每层展开结果；代码题写递归三行结构 + 注释「根左右 / 左根右 / 左右根」即算对，不必写 `visit` 的具体实现。

## 7. 408 题型与解题套路

- **选择题（高频）**：
  - 给一棵树（或先序+中序序列）求另一种遍历序列 → 用逐层展开法或画路径法，先补空结点；
  - 判断「某序列是否可能是某遍历序列」→ 用先序定根、中序分左右递归验证；
  - 考空间复杂度、递归调用栈深度、叶子结点在三种序列中的相对位置。
- **算法题（高频）**：题目要求「统计叶子数 / 求树高 / 求某层结点数 / 判断相似」等，套路是**套用后序或先序框架，把 `visit` 换成统计或判断逻辑**。写代码时先写 `if (T == NULL) return ...;` 的递归出口，再写左右递归，最后写合并逻辑。
- **常见陷阱**：
  - 把「先序遍历序列 + 后序遍历序列」当作能唯一确定二叉树（不能，必须含中序）；
  - 单支树时把空间复杂度误答成 $O(\log n)$；
  - 算术表达式树中序输出忘加括号。

## 9. 背诵卡

1. 先序 = 根左右，中序 = 左根右，后序 = 左右根；左右子树永远先左后右。
2. 三种递归代码只差 `visit(T)` 一行：先序在最前、中序在中间、后序在最后。
3. 手算两法：分支结点逐层展开；画路径法——每个结点路过三次，先序取第 1 次、中序取第 2 次、后序取第 3 次。
4. 时间 $O(n)$；空间 $O(h)$，最好 $O(\log n)$（平衡），最坏 $O(n)$（单支）。
5. 求树高 = 后序遍历变种：`max(左高, 右高) + 1`；算术表达式树先/中/后序 = 前缀/中缀（要加括号）/后缀表达式。
