# 6.4.2 最短路径问题：Floyd 算法

## 1. 本节定位

- **对应王道书**：第 6 章「图」→ 6.4「图的应用」→ 6.4.2「最短路径」中的 Floyd 算法部分（与 Dijkstra 并列）。
- **408 大纲对应**：图的应用——最短路径（要求掌握求每对顶点间最短路径的算法）。
- **先修知识**：邻接矩阵存储、图的路径与带权路径长度、Dijkstra 算法（单源最短路径）、动态规划的基本思想。
- **本节位置**：Dijkstra 解决「单源」最短路径；Floyd 解决「各顶点对之间」的最短路径，是本章最短路径部分的收尾算法，也是 408 中唯一要求掌握的「多源」最短路径算法。

## 2. 一句话结论

Floyd 算法以「逐轮允许 $v_0,v_1,\dots,v_{n-1}$ 依次作为中转点」的方式做 $n$ 轮动态规划递推，用 $n\times n$ 的 `A` 矩阵（最短路径长度）和 `path` 矩阵（中转点）在 $O(n^3)$ 时间内求出任意两点间的最短路径，且能处理负权边、不能处理负权回路。

## 3. 知识地图

```
Floyd 算法（多源最短路径，动态规划）
├── 问题：求任意顶点对 (vi, vj) 的最短路径
├── 核心思想：分阶段递推
│   ├── 初始阶段：不允许任何中转点（只允许直达边）
│   ├── 第 k 阶段：允许以 v0..vk 作为中转点
│   └── 共 n 个阶段，第 n-1 阶段即最终解
├── 两个辅助矩阵（n×n）
│   ├── A（距离矩阵）：初值为邻接矩阵
│   └── path（中转点矩阵）：初值全为 -1
├── 递推公式（第 k 轮，对所有 i,j）
│   └── A[i][j] = min(A[i][j], A[i][k] + A[k][j])
│       若更新，则 path[i][j] = k
├── 代码：三重循环，6 行核心
├── 复杂度：时间 O(n³)，空间 O(n²)
├── 路径还原：查 path 递归展开
└── 适用性
    ├── 可处理负权边（Dijkstra 不行）
    └── 不可处理负权回路（无最短路径）
```

## 4. 核心内容

### 4.1 算法思想（动态规划）

对任意顶点对 $(v_i, v_j)$，把求解分成 $n$ 个阶段：

- **初始阶段**：不允许路径中间出现任何中转顶点，此时 $A[i][j]$ 就是邻接矩阵中的值（直达边权，无直达边则为 $\infty$）。
- **第 $k$ 阶段**：在上一阶段基础上，允许以 $v_k$ 作为中转点，检查「$v_i \to v_k \to v_j$」是否比已知路径更短。
- 经过 $n$ 轮（$k=0,1,\dots,n-1$）后，$A$ 中即为所有顶点对的最短路径长度。

> 关键理解：第 $k$ 轮是在「已经允许 $v_0..v_{k-1}$ 中转」的最优结果上，再叠加 $v_k$ 中转，因此每轮结果都是当前阶段的最优解（最优子结构）。

### 4.2 两个矩阵的含义

| 矩阵 | 含义 | 初值 |
|---|---|---|
| `A[i][j]` | 当前阶段 $v_i$ 到 $v_j$ 的最短路径长度 | 邻接矩阵（无边为 $\infty$，$i=j$ 为 0） |
| `path[i][j]` | 当前最短路径上 $v_i$ 到 $v_j$ 的**中转点编号** | 全部 `-1`（表示无中转点） |

注意：`path[i][j] = k` 只记录「这一层」的中转点，完整路径需递归展开（见 4.4）。

### 4.3 核心代码（C 语言，王道风格）

```c
// 前提：A 已初始化为图的邻接矩阵（无边为 INF，对角线为 0）
//       path 全部初始化为 -1
void Floyd(int A[][MAXV], int path[][MAXV], int n) {
    for (int k = 0; k < n; k++) {          // 第 k 轮：允许 vk 作中转点
        for (int i = 0; i < n; i++) {      // 遍历所有起点
            for (int j = 0; j < n; j++) {  // 遍历所有终点
                if (A[i][k] + A[k][j] < A[i][j]) {   // 经 vk 中转更短
                    A[i][j] = A[i][k] + A[k][j];     // 更新最短距离
                    path[i][j] = k;                  // 记录中转点
                }
            }
        }
    }
}
```

**默写要点**：
- 最外层循环变量是 **$k$（中转点）**，不是 $i$ 或 $j$——这是 Floyd 与普通三重循环最本质的区别，写错顺序结果就错。
- 判断条件用 `<`（严格小于），相等时不更新，保证结果稳定。
- 更新 `A` 与 `path` 必须同时进行。

### 4.4 路径还原（查 path 矩阵）

以 $v_0 \to v_4$ 为例（王道书 5 顶点例）：

1. 查 `A[0][4]` 得最短长度；查 `path[0][4]` 得中转点，如为 3，则路径拆为 $v_0 \to v_3$ 与 $v_3 \to v_4$。
2. 对每一段继续查 `path`：`path[0][3] = 2`，拆为 $v_0 \to v_2$、$v_2 \to v_3$；`path[3][4] = -1`，该段直达。
3. 递归展开直到所有 `path` 为 `-1`，得到完整路径 $v_0 \to v_2 \to v_1 \to v_3 \to v_4$（示例，具体以题给矩阵为准）。

> 递归还原伪代码（可自行实现）：
> ```
> printPath(i, j):
>     if path[i][j] == -1: 输出边 i→j
>     else:
>         k = path[i][j]
>         printPath(i, k); printPath(k, j)
> ```

### 4.5 手工模拟方法（考试核心）

以 3 顶点王道例（$v_0,v_1,v_2$，边权 $v_0\to v_1=6$，$v_0\to v_2=13$，$v_1\to v_2=4$，$v_2\to v_0=5$，$v_2\to v_1=\infty$ 等，以题给邻接矩阵为准）演示：

- **初始**：$A$ = 邻接矩阵，`path` 全 `-1`。
- **$k=0$（允许 $v_0$ 中转）**：检查 $A[2][1]$，原为 $\infty$，经 $v_0$ 得 $A[2][0]+A[0][1]=5+6=11<\infty$，更新 $A[2][1]=11$，`path[2][1]=0`。
- **$k=1$（允许 $v_1$ 中转）**：检查 $A[0][2]$，原为 13，经 $v_1$ 得 $A[0][1]+A[1][2]=6+4=10<13$，更新 $A[0][2]=10$，`path[0][2]=1`。
- **$k=2$（允许 $v_2$ 中转）**：检查 $A[1][0]$，原为 10，经 $v_2$ 得 $A[1][2]+A[2][0]=4+5=9<10$，更新 $A[1][0]=9$，`path[1][0]=2`。

**手算技巧**：第 $k$ 轮只需关注「第 $k$ 行、第 $k$ 列」参与的组合，即对每个 $i,j$ 比较 $A[i][k]+A[k][j]$ 与 $A[i][j]$；其余元素不变。

### 4.6 适用性

- **可处理负权边**：递推只做加法比较，负权边不影响正确性（王道例中带负权边的图可正常求解）。
- **不可处理负权回路**：若存在负权回路，绕圈越多路径越短，最短路径不存在，算法无法给出有意义的解。Dijkstra 同样不能处理负权边/负权回路。

## 5. 复杂度分析

- **时间复杂度**：三重循环，每层均执行 $n$ 次，共 $n \times n \times n = n^3$ 次基本操作（加法与比较），故 $T(n)=O(n^3)$。最好、最坏、平均均为 $O(n^3)$——循环次数与输入数据无关，是**确定性**的。
- **空间复杂度**：两个 $n\times n$ 辅助矩阵，$S(n)=O(n^2)$。
- **平均情况推导**：由于三重循环的迭代次数固定为 $n^3$，不依赖边的分布或权值，故不存在「平均」与「最坏」的差异，统一为 $O(n^3)$。

## 6. 易错点与考试写法

1. **循环顺序写错**：最外层必须是中转点 $k$，写成 $i$ 或 $j$ 在外层会得到错误结果。这是选择题和代码填空题的高频陷阱。
2. **`path` 初值**：必须全部初始化为 `-1`，不能初始化为 0（0 是合法顶点编号，会与「无中转点」混淆）。
3. **`path` 只记一层中转点**：`path[i][j]=k` 不代表路径就是 $i\to k\to j$，完整路径要递归查 `path[i][k]`、`path[k][j]`。
4. **无穷大的处理**：手算时 $\infty +$ 任何数仍视为 $\infty$，不要误算成有限值；代码中 `INF` 要足够大且防止溢出（如 `INF/2` 判断）。
5. **负权回路判断**：若最终 $A[i][i]<0$，说明存在负权回路，最短路径无意义（408 选择题可能考此结论）。
6. **答题程度**：408 对本节要求「会手工模拟 $A$ 矩阵的逐轮迭代 + 会写核心三重循环 + 会查 `path` 还原路径」，不要求证明动态规划正确性。

## 7. 408 题型与解题套路

- **选择题**：
  - 给图与邻接矩阵，问第 $k$ 轮后某元素的值 → 按 4.5 手算，只算第 $k$ 行/列相关组合。
  - 问 Floyd 与 Dijkstra 的区别：Floyd 多源、可负权边、$O(n^3)$；Dijkstra 单源、不可负权、$O(n^2)$（邻接矩阵）。
  - 问 `path` 矩阵某元素含义 → 中转点编号，非完整路径。
  - 问负权回路能否求最短路径 → 不能。
- **算法题**：直接默写 4.3 三重循环；若要求输出路径，补 4.4 递归还原。
- **常见陷阱**：把 Floyd 当成「对每个顶点跑一次 Dijkstra」——两者时间复杂度虽同为 $O(n^3)$，但 Floyd 代码更简洁、可处理负权边（无负权回路时），这是常考对比点。

<summary>参考答案</summary>

**题 1**：最外层是 $k$（中转点编号）。因为算法按「逐轮增加允许的中转点」递推，第 $k$ 轮必须基于前 $k-1$ 轮的最优结果，若 $i$ 或 $j$ 在外层，则中转点集合的递进关系被破坏，结果错误。

**题 2**：4 轮（$k=0,1,2,3$）；每轮检查 $4\times4=16$ 个元素，总计 $4^3=64$ 次检查。

**题 3**：表示 $v_2$ 到 $v_3$ 的最短路径以 $v_1$ 为中转点，路径拆为 $v_2\to v_1$ 与 $v_1\to v_3$；再分别查 `path[2][1]`、`path[1][3]`，递归展开至 `-1` 为止，拼接得到完整路径。

**题 4**：能处理负权边（递推只做加法比较，负权不影响最优子结构）；不能处理负权回路（绕回路越多路径越短，最短路径不存在，算法结果无意义，可由 $A[i][i]<0$ 发现）。

**题 5**：
```c
for (int k = 0; k < n; k++)
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (A[i][k] + A[k][j] < A[i][j]) {
                A[i][j] = A[i][k] + A[k][j];
                path[i][j] = k;
            }
```
时间复杂度 $O(n^3)$，空间 $O(n^2)$。

## 9. 背诵卡

1. **Floyd = 多源最短路径 + 动态规划**，$n$ 轮递推，第 $k$ 轮允许 $v_k$ 作中转点。
2. **核心递推**：`A[i][j] = min(A[i][j], A[i][k]+A[k][j])`，更新时 `path[i][j]=k`。
3. **循环顺序**：$k$ 在最外层，$i$、$j$ 在内层，共 $n^3$ 次。
4. **复杂度**：时间 $O(n^3)$，空间 $O(n^2)$（两个 $n\times n$ 矩阵）。
5. **适用性**：可负权边，不可负权回路；`path` 初值全 `-1`，路径需递归还原。
