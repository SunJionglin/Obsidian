# 5.3.3 由遍历序列构造二叉树

## 1. 本节定位

- **对应王道书**：第 5 章「树与二叉树」→ 5.3 二叉树的遍历 → 5.3.3 由遍历序列构造二叉树。
- **408 大纲对应**：二叉树遍历序列与二叉树形态的相互确定（遍历序列还原二叉树）。
- **先修知识**：先序（NLR）、中序（LNR）、后序（LRN）、层序（层次）四种遍历的执行过程与序列写法。
- **位置**：紧接四种遍历的定义之后，是遍历性质的应用，也是后续「树/森林与二叉树转换」「哈夫曼树」中反复用到的还原基本功。属于**408 必考**考点（选择题高频，偶尔出现在大题第一小问）。

## 2. 一句话结论

**只给一种遍历序列不能唯一确定二叉树；必须含中序序列的两种序列组合（前+中、后+中、层+中）才能唯一还原二叉树，前+后、前+层、后+层都不行。**

## 3. 知识地图

```
由遍历序列构造二叉树
├── 唯一性问题
│   ├── 单个序列 → 不唯一（前/中/后/层均如此）
│   └── 两个序列
│       ├── 含中序：前+中、后+中、层+中 → 唯一 ✔
│       └── 不含中序：前+后、前+层、后+层 → 不唯一 ✘
└── 还原方法（统一三步）
    ├── ① 定根：前序取首 / 后序取尾 / 层序取首
    ├── ② 用中序划分左右子树节点集合
    └── ③ 对左右子树递归执行 ①②（层序按层推进）
```

## 4. 核心内容

### 4.1 为什么单个序列不唯一

同一中序序列 `BDCAE` 可对应多棵形态不同的二叉树（如根为 A、左子树链状或右斜等不同挂法），前序序列 `BDCAE` 同样可对应多棵。**结论：任一单种遍历序列都无法唯一确定形态**（本节用三棵不同二叉树得到相同中序/前序序列的例子说明）。

### 4.2 前序 + 中序还原

**原理**：
- 前序序列第一个元素 = 根；
- 在中序序列中找到该根，其**左侧全部节点属于左子树，右侧全部节点属于右子树**；
- 由中序划分出的左子树节点个数 $k$，可从前序序列中截出「根后 $k$ 个」为左子树前序，其余为右子树前序；
- 递归。

**例**：中序 `B D C A E`，前序 `A B D C E`。

1. 前序首元素 `A` → 根；中序中 A 左侧 `B D C`（3 个）为左子树，右侧 `E` 为右子树。
2. 左子树：前序 `B D C`，中序 `B D C` → 根 `B`；中序中 B 左侧空、右侧 `D C` → 左空，右子树根为 `D`（前序 `D C` 首元素），中序 `D C` 中 D 左空、右为 `C`。
3. 右子树：仅 `E`。

结果：A 的左孩子 B，B 的右孩子 D，D 的右孩子 C；A 的右孩子 E。

### 4.3 后序 + 中序还原

**原理**：后序序列**最后一个**元素 = 根；其余步骤与前序+中序完全对称（用中序划分左右，再按节点个数切分后序序列：前 $k$ 个为左子树后序，接着为右子树后序，最后为根）。

**例**：中序 `B D C A E`，后序 `D C B E A`。

1. 后序末元素 `A` → 根；中序划分：左 `B D C`，右 `E`。
2. 左子树后序 = 前 3 个 `D C B`，末元素 `B` 为根；中序 `B D C` 中 B 左空、右 `D C`。
3. 右子树后序 = `E`，根 `E`。

### 4.4 层序 + 中序还原

**原理**：层序序列第一个元素 = 根；用中序划分左右子树后，**层序中按出现顺序，属于左子树集合的节点依次构成左子树层序，属于右子树集合的依次构成右子树层序**（不是简单按个数切，要按集合归属筛选）。

**例**：中序 `D B E A F C G`，层序 `A B C D E F G`。

1. 层序首元素 `A` → 根；中序划分：左 `D B E`，右 `F C G`。
2. 层序中属于左集合的节点依次为 `B D E` → 左子树层序；属于右集合的为 `C F G` → 右子树层序。
3. 左子树：层序首 `B` 为根，中序 `D B E` 中 D 在左、E 在右 → B 的左 D、右 E。
4. 右子树：层序首 `C` 为根，中序 `F C G` 中 F 在左、G 在右 → C 的左 F、右 G。

**特殊情况**：若中序中根左侧为空（如中序 `A B C D E`、层序 `A B C D E`），说明**左子树为空**，层序中根后的下一个节点是**右子树根**，不能机械地认为「根后面紧跟的是左孩子」。必须结合中序判断左右子树是否存在。

### 4.5 不含中序的组合为何不行

反例：两棵二叉树
- 树 1：A 为根，B 为 A 的左孩子；
- 树 2：A 为根，B 为 A 的右孩子。

二者前序均为 `AB`、后序均为 `BA`、层序均为 `AB`，但形态不同。故**前+后、前+层、后+层均不能唯一确定二叉树**。

### 4.6 还原算法框架（伪代码，递归思想，408 不要求写完整代码，但答题可写此框架）

```c
// 前提：pre[0..n-1] 前序，in[0..n-1] 中序，n 为节点数
// 返回构造出的二叉树根指针
BiTree BuildByPreIn(int pre[], int in[], int n) {
    if (n == 0) return NULL;              // 空子树
    BiTree root = (BiTree)malloc(sizeof(BiTNode));
    root->data = pre[0];                  // ① 前序首元素为根
    int k = 0;
    while (in[k] != pre[0]) k++;          // ② 在中序中定位根，k 即左子树节点数
    root->lchild = BuildByPreIn(pre + 1, in, k);              // 左子树：前序取根后 k 个，中序取前 k 个
    root->rchild = BuildByPreIn(pre + 1 + k, in + k + 1, n - k - 1); // 右子树
    return root;
}
// 后序+中序：根取 post[n-1]，左子树后序为 post[0..k-1]，右子树后序为 post[k..n-2]
```

## 5. 复杂度分析

设节点数为 $n$。

- **最好情况**：树为完全平衡二叉树，递归深度 $\lceil \log_2(n+1) \rceil$，每层定位根若用顺序扫描，总代价 $O(n\log n)$；若用哈希表预处理中序位置，则 $O(n)$。
- **最坏情况**：树退化为单支（链状），递归深度 $n$，每层扫描中序定位根，总代价 $O(n^2)$。
- **平均情况**：假设 $n$ 个节点等概率地作为根出现在中序任意位置（即随机二叉树的先验），第 $i$ 层平均需扫描约 $n/2^i$ 个元素，总代价 $\sum_{i=0}^{h} \frac{n}{2^i} \cdot 2^i = O(nh)$，其中 $h$ 为平均树高。随机二叉树平均高度为 $O(\log n)$（推导：随机 BST 的期望高度约为 $4.311\ln n$，即 $O(\log n)$），故平均复杂度为 $O(n\log n)$。若先建立「值→中序下标」的哈希表，则三种情况均为 $O(n)$（时间）与 $O(n)$（空间）。

> 408 选择题只考「能否唯一确定」，不考复杂度；复杂度属王道书扩展，了解即可。

## 6. 易错点与考试写法

1. **误以为「前序+后序」能唯一确定**——这是最高频陷阱，反例就是「A 左挂 B」与「A 右挂 B」。
2. **层序+中序时机械按个数切分层序序列**——层序必须按「节点属于左集合还是右集合」筛选，不能按前 $k$ 个切。
3. **层序+中序时忽略空子树**：中序中根左侧为空时，层序中根的下一个节点是右子树根，不是左孩子。
4. **前序/后序切分时节点个数算错**：左子树节点数 $k$ = 根在中序中的下标（相对当前子序列起点），前序左子树为「根后 $k$ 个」，后序左子树为「前 $k$ 个」。
5. **答题标准**：408 选择题只需判断「哪组序列能唯一确定」；若出还原题，写出「定根 → 中序划分 → 递归」的步骤并画出最终树形即可，不必写完整代码；画树时标清左右孩子，空子树用 `^` 或省略均可，但左右不能颠倒。

## 7. 408 题型与解题套路

- **选择题（高频）**：给出若干组遍历序列，问「哪组能唯一确定一棵二叉树」。套路：**看是否含中序**——含中序的两种组合必对，不含中序的必错（除非题目附加了「满二叉树」「完全二叉树」等形态条件，此时前+后也可唯一，属推断延伸，需看题干）。
- **选择题（中频）**：给出前序+中序（或后序+中序），问某节点的左/右孩子、某子树的后序序列、树的形态个数等。套路：按 4.2/4.3 逐步定根划分，画到叶子。
- **大题小问**：在树的应用题中先要求「由给定序列画出二叉树」，再继续求 WPL、转换森林等。套路：先画树，画完用三种遍历回验一遍序列是否与题给一致。
- **常见陷阱**：序列中有重复值（408 默认节点值互异，若重复则无法唯一还原，属超纲提醒）；把「后序末元素」误当「前序首元素」用。

**题 1**：D。含中序的组合才唯一；A、B、C 均不含中序，不能唯一确定。

**题 2**：前序首 `A` 为根；中序 `D B E | A | F C` → 左 `D B E`，右 `F C`。左子树前序 `B D E` → 根 `B`，中序 `D B E` 中 D 左、E 右。右子树前序 `C F` → 根 `C`，中序 `F C` 中 F 在左。树形：A 左 B（B 左 D、右 E），A 右 C（C 左 F）。后序：`D E B F C A`。

**题 3**：后序末 `A` 为根；中序 `B | A | C` → 左 B、右 C。根 A 的右孩子是 `C`。

**题 4**：层序首 `A` 为根；中序 `A | B C D` 中 A 左侧为空 → 左子树为空，层序中 A 后紧跟的 `B` 是右子树根。中序 `B C D` 中 B 左空、右 `C D`；层序 `C D` 首 `C` 为 B 的右孩子，中序 `C D` 中 C 左空、右 D → D 为 C 的右孩子。形态：A 只有右孩子 B，B 只有右孩子 C，C 只有右孩子 D（右单支）。

## 9. 背诵卡

1. 单序列不唯一；**必须含中序**的两种组合才唯一：前+中、后+中、层+中。
2. 前+后、前+层、后+层 → **不唯一**（反例：A 左挂 B vs A 右挂 B）。
3. 定根口诀：**前序取首、后序取尾、层序取首**。
4. 划分口诀：**中序定左右，个数切前/后序；层序按集合筛，不按个数切**。
5. 层序+中序特判：中序根左侧为空 → 层序下一个是右子树根，左子树为空。
