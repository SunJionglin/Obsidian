# 6.4.4 拓扑排序

## 1. 本节定位

- **对应王道书**：第 6 章「图」→ 6.4「图的应用」→ 6.4.4 拓扑排序（DAG 图的第二个应用，第一个是上一节的有向无环图判定/表达式相关应用）。
- **408 大纲对应**：图的应用——拓扑排序、关键路径（本节只讲拓扑排序与逆拓扑排序）。
- **先修知识**：有向图、入度/出度、邻接表与邻接矩阵存储、DFS（深度优先搜索）及其 `visited[]` 数组、栈/队列的基本操作。
- **本章位置**：位于「最短路径」之后、「关键路径」之前。拓扑排序是 AOV 网（Activity On Vertex Network）的核心算法，也是后面 AOE 网与关键路径的前置工具；同时它本身是「判断有向图是否有环」的经典手段。

## 2. 一句话结论

**拓扑排序 = 反复「输出一个入度为 0 的顶点，并逻辑删除它及其所有出边」，直到图为空（成功）或找不到入度为 0 的顶点（有环，失败）；DAG 才有拓扑序列，且序列一般不唯一。**

## 4. 核心内容

### 4.1 AOV 网（Activity On Vertex Network）

- **定义**：用顶点表示活动，用有向边 $\langle u,v\rangle$ 表示「活动 $u$ 必须在活动 $v$ 之前进行」的先后关系，这样的有向图称为 AOV 网。
- **关键性质**：AOV 网**一定是有向无环图（DAG）**。若存在回路，例如「切番茄 → 洗番茄 → 切番茄」，则工程无法推进，矛盾。
- **例子（番茄炒蛋）**：买菜 → 洗番茄 → 切番茄；买菜 → 打鸡蛋；准备厨具 → 切番茄；切番茄、打鸡蛋 → 下锅炒 → 吃。每条边都表示一个先后约束。

### 4.2 拓扑排序的定义

对有向图 $G=(V,E)$，若 $V$ 的一个线性序列满足：对任意边 $\langle u,v\rangle\in E$，$u$ 在序列中都排在 $v$ 之前，则称该序列为 $G$ 的一个**拓扑排序序列**。

- 一个 DAG 可能有**一个或多个**拓扑序列（起点可能不唯一，如「先准备厨具」或「先买菜」均可）。
- 有环图**不存在**拓扑序列。

### 4.3 手工算法（Kahn 算法思想）

1. 从图中选择一个**入度为 0** 的顶点并输出（入度为 0 表示它没有前驱活动，可以立即执行）。
2. 从图中**删除**该顶点及其所有出边（等价于把它的所有后继顶点的入度减 1）。
3. 重复 1、2，直到：
   - 图为空 → 排序成功，输出序列即拓扑序列；
   - 图中已无入度为 0 的顶点但仍有顶点剩余 → 原图存在回路，**拓扑排序失败**。

> 注意：第 2 步的「删除」是**逻辑删除**，只修改 `indegree[]` 数组，邻接表本身不变。

### 4.4 代码实现（王道风格，邻接表存储）

**前提**：图用邻接表存储；`indegree[]` 已预先统计好各顶点入度；用栈保存当前入度为 0 的顶点（也可用队列或数组，不影响正确性，只影响序列顺序）。

```c
#define MaxVertexNum 100

bool TopologicalSort(ALGraph G) {
    int indegree[MaxVertexNum];   // 各顶点当前入度（需事先统计好）
    int print[MaxVertexNum];      // 保存拓扑序列
    int count = 0;                // 已输出的顶点个数
    InitStack(S);                 // 栈，也可换队列

    // 第一轮：把所有入度为 0 的顶点入栈
    for (int i = 0; i < G.vexnum; i++)
        if (indegree[i] == 0)
            Push(S, i);

    while (!IsEmpty(S)) {
        Pop(S, i);                // 弹出一个入度为 0 的顶点
        print[count++] = i;       // 记入拓扑序列，count 加 1
        // 遍历 i 的所有邻接点（即 i 的所有后继）
        for (ArcNode *p = G.vertices[i].firstarc; p; p = p->nextarc) {
            int v = p->adjvex;
            indegree[v]--;        // 后继入度减 1（逻辑删除边 i→v）
            if (indegree[v] == 0) // 后继入度变为 0，可入栈
                Push(S, v);
        }
    }

    if (count < G.vexnum)
        return false;             // 有顶点未输出 → 图中有回路
    return true;                  // 拓扑排序成功
}
```

**执行过程（以讲解中的 5 顶点图为例）**：

| 步骤 | 栈内容 | 弹出 | print[] | 入度变化 |
|---|---|---|---|---|
| 初始 | 0, 2 | — | — | indegree = [0,1,0,2,2] |
| 1 | 0 | 2 | [2] | 3、4 入度各减 1 → 1、1 |
| 2 | — | 0 | [2,0] | 1 入度减 1 → 0，入栈 |
| 3 | — | 1 | [2,0,1] | 3 入度减 1 → 0，入栈 |
| 4 | — | 3 | [2,0,1,3] | 4 入度减 1 → 0，入栈 |
| 5 | — | 4 | [2,0,1,3,4] | 无后继 |

最终 `count = 5 = vexnum`，排序成功。若图中存在回路，则循环结束时 `count < vexnum`，返回 `false`。

### 4.5 逆拓扑排序

- **定义**：每次选择**出度为 0** 的顶点输出并删除（及其所有入边），得到的序列为逆拓扑序列（即拓扑序列的逆序）。
- **手工过程**：番茄炒蛋图中，出度为 0 的只有「吃」，先输出「吃」；再输出「下锅炒」；再「打鸡蛋」；最后「准备厨具」「买菜」等任选。
- **实现要点**：
  - 用**邻接矩阵**实现较方便：删除顶点后，找「指向它的边」只需扫描它对应的那一列。
  - 用**邻接表**实现低效：邻接表存的是出边，找入边需遍历整个邻接表；此时应改用**逆邻接表**（每个顶点挂的是指向它的边），找入边方便。
- **DFS 实现逆拓扑排序（王道书扩展，408 可能考）**：
  - 在 DFS 中，**当一个顶点访问完其所有邻接点、即将退出递归（退栈）时**，输出该顶点。
  - 这样输出的序列就是逆拓扑序列（因为 DFS 先深入后继，后继先退栈先输出）。
  - 若图中有环，需增加判环逻辑（DFS 中判断是否遇到「正在递归栈中」的顶点，即三色标记/栈内标记），否则算法会出错。

```c
// DFS 实现逆拓扑排序（王道书扩展）
bool visited[MaxVertexNum];

void DFS_ReverseTopo(ALGraph G, int v) {
    visited[v] = true;
    for (ArcNode *p = G.vertices[v].firstarc; p; p = p->nextarc) {
        int w = p->adjvex;
        if (!visited[w])
            DFS_ReverseTopo(G, w);
    }
    printf("%d ", v);   // 关键：退栈前输出 → 逆拓扑序列
}
```

> 用 DFS 实现**正**拓扑排序的方法在综合题中考察（本节不展开，留作练习）。

## 5. 复杂度分析

设顶点数 $n=|V|$，边数 $e=|E|$。

**邻接表存储**：

- 初始化入度 0 顶点入栈：$O(n)$。
- 每个顶点出栈一次，共 $O(n)$。
- 每条边在其起点出栈时被访问一次（`indegree[v]--`），共 $O(e)$。
- 总时间 $T(n,e)=O(n)+O(n)+O(e)=O(n+e)$。
- 空间：`indegree[]`、`print[]`、栈各 $O(n)$，故 $O(n)$。

**邻接矩阵存储**：

- 每个顶点出栈后，需扫描该顶点对应的整行（$n$ 个元素）来找后继，共 $n$ 个顶点 → $O(n^2)$。
- 总时间 $O(n^2)$。

**最好 / 最坏 / 平均**：

- 拓扑排序的时间复杂度**与图的形态无关**，只与存储结构有关：邻接表恒为 $O(n+e)$，邻接矩阵恒为 $O(n^2)$。因此最好 = 最坏 = 平均。
- 若按「平均每条边被处理一次」的概率假设推导：$n$ 个顶点各出栈一次（$O(n)$），$e$ 条边各被检查一次（$O(e)$），无随机性，故平均即 $O(n+e)$。

**逆拓扑排序**：

- 邻接矩阵：$O(n^2)$（扫描列方便）。
- 邻接表：需遍历全表找入边，最坏 $O(n\cdot e)$ 量级（低效）；用逆邻接表则回到 $O(n+e)$。
- DFS 实现：$O(n+e)$（邻接表）。

## 6. 易错点与考试写法

1. **「删除」是逻辑删除**：代码中只改 `indegree[]`，邻接表结构不变。答题时若写「删除顶点和边」，要注明是逻辑删除。
2. **入度为 0 的顶点可能同时有多个**：必须全部入栈（或队列），不能只取一个，否则会漏顶点导致误判有环。
3. **判环条件**：循环结束后 `count < vexnum` ⇔ 有环 ⇔ 拓扑排序失败。不要写成「栈空即有环」——栈空是正常结束条件。
4. **栈 vs 队列**：用栈和用队列得到的拓扑序列一般不同，但都合法；题目若要求「字典序最小」等特定序列，需按题意选择数据结构（通常用优先队列/每次选最小编号）。
5. **逆拓扑排序的存储选择**：邻接表找入边低效，逆拓扑要用逆邻接表或邻接矩阵；这是常考的选择题陷阱。
6. **DFS 逆拓扑排序的输出时机**：是「退栈时输出」，不是「访问时输出」；访问时输出得到的是 DFS 序列，不是逆拓扑序列。
7. **AOV 网 ≠ 一般有向图**：AOV 网必须无环；有环图不能进行拓扑排序。
8. **答题程度**：算法题写拓扑排序，需写出 `indegree[]` 初始化、入栈、while 循环、出边遍历、`count` 判定五部分，缺一扣分；复杂度要写「邻接表 $O(n+e)$，邻接矩阵 $O(n^2)$」。

## 7. 408 题型与解题套路

**选择题常见考法**：

- 给一个有向图，问「下列哪个序列不可能是拓扑序列」——逐个检查每条边是否满足先后约束。
- 问「拓扑序列的个数」——手工枚举，注意起点不唯一。
- 问「拓扑排序能否判断有环」——能，`count < n` 即有环。
- 问「逆拓扑排序用哪种存储最方便」——邻接矩阵或逆邻接表。
- 问「DFS 实现逆拓扑排序的输出时机」——退栈时。

**算法题套路**：

- 拓扑排序代码是模板，背熟 `indegree[] + 栈 + count` 三件套。
- 若题目要求「判断有向图是否有环」，直接套拓扑排序，返回 `count == n`。
- 若要求「输出所有拓扑序列」，需用回溯 DFS（本节不展开，属扩展）。
- 逆拓扑排序：邻接矩阵扫列，或逆邻接表扫出边。

**常见陷阱**：

- 把「出度为 0」当成拓扑排序条件（那是逆拓扑）。
- 忘记初始化 `indegree[]`（题目通常已给，但要检查）。
- 栈空后直接返回 true，忘记检查 `count`。

## 9. 背诵卡

1. **AOV 网**：顶点=活动，边=先后约束，必为 DAG；有环则工程无法推进。
2. **拓扑排序两步**：输出入度 0 顶点 → 删除其出边（后继入度 -1）→ 重复；图为空成功，无入度 0 顶点则有环失败。
3. **判环**：`count == vexnum` 成功；`count < vexnum` 有环。
4. **复杂度**：邻接表 $O(n+e)$，邻接矩阵 $O(n^2)$；与图形态无关，最好=最坏=平均。
5. **逆拓扑**：删出度 0 顶点；邻接矩阵/逆邻接表方便；DFS 实现时**退栈输出**。
