# 6.3.2 图的深度优先遍历（DFS）

## 1. 本节定位

- **对应王道书**：第 6 章「图」→ 6.3 图的遍历 → 6.3.2 图的深度优先遍历（DFS, Depth-First Search）。
- **408 大纲对应**：图的遍历——深度优先遍历的基本思想、算法实现、复杂度分析、生成树/生成森林、遍历与连通性的关系。
- **先修知识**：树的先根遍历（递归）、图的存储结构（邻接矩阵、邻接表）、6.3.1 广度优先遍历（BFS）的框架（visited 数组、非连通图处理）。
- **本节位置**：与 6.3.1 BFS 并列，是图遍历的第二种算法；后续 6.4 图的应用（最小生成树、拓扑排序、关键路径）大量复用 DFS 框架，本节是整章算法模板的来源之一。

## 2. 一句话结论

DFS 本质是「树的先根遍历 + visited 数组」：访问一个顶点后，沿其第一个未访问邻接点递归深入，无路可走再回溯；非连通图需在外层 for 循环中对每个未访问顶点再调用一次 DFS，调用次数 = 连通分量数。

## 3. 知识地图

```
图的深度优先遍历 DFS
├── 思想来源：树的先根遍历（递归）
├── 关键机制
│   ├── visited[] 数组：标记顶点是否被访问（图有环/有回边，必须防重复）
│   └── 递归 + 回溯：深入到底再退回上一层检查剩余邻接点
├── 算法框架
│   ├── DFS(G, v)：访问 v → visited[v]=true → 循环检查 v 的每个邻接点 w，未访问则 DFS(G, w)
│   └── DFSTraverse(G)：for 每个顶点，若未访问则 DFS（处理非连通图）
├── 复杂度
│   ├── 空间：递归工作栈，最坏 O(|V|)，最好 O(1)
│   └── 时间：邻接矩阵 O(|V|²)；邻接表 O(|V|+|E|)
├── 深度优先生成树 / 生成森林
│   ├── 保留「由未访问点发现的边」（红边），删去其余边 → 生成树
│   └── 非连通图 → 多棵树 → 生成森林
└── 遍历与连通性
    ├── 无向图：DFS 调用次数 = 连通分量数；连通图只需 1 次
    └── 有向图：起始点能到达所有顶点则 1 次；强连通图任意起点均 1 次
```

## 4. 核心内容

### 4.1 从树的先根遍历到图的 DFS

树的先根遍历（递归）：访问根 → 依次对每棵子树递归。由于树无环，新找到的结点必然未访问。

图不同：通过某顶点找到的邻接点**可能已被访问**（存在回路/回边），因此必须增设 `visited[]` 数组。除此之外，DFS 与树的先根遍历结构几乎一致：先访问，再用循环依次检查邻接点，对未访问者递归深入。

### 4.2 算法代码（王道风格，C 语言）

前提：图 `G` 采用邻接表或邻接矩阵存储；`visited[]` 为全局数组，初值 `false`。

```c
bool visited[MAX_VERTEX_NUM];          // 访问标记数组，全局，初值 false

// 从顶点 v 出发，深度优先遍历图 G（连通分量内部）
void DFS(Graph G, int v) {
    visit(v);                          // 访问顶点 v（输出/计数等）
    visited[v] = true;                 // 标记已访问，防止重复
    for (int w = FirstNeighbor(G, v);  // 取 v 的第一个邻接点
         w >= 0;                       // 还有邻接点（用 -1 表示无）
         w = NextNeighbor(G, v, w)) {  // 取 v 的下一个邻接点
        if (!visited[w])               // w 未被访问才深入
            DFS(G, w);                 // 递归：一条路走到黑
    }
}

// 对图 G 做深度优先遍历（处理非连通图）
void DFSTraverse(Graph G) {
    for (int v = 0; v < G.vexnum; ++v)
        visited[v] = false;            // 初始化标记数组
    for (int v = 0; v < G.vexnum; ++v)
        if (!visited[v])               // 每个连通分量挑一个未访问起点
            DFS(G, v);                 // 一次 DFS 遍历完一个连通分量
}
```

要点：
- `FirstNeighbor` / `NextNeighbor` 是基本操作，具体实现依赖存储结构（邻接矩阵扫一行，邻接表扫链表）。
- 外层 `for` 是处理**非连通图**的关键：一次 DFS 只能走完一个连通分量。
- 递归版是王道主线；非递归版（显式栈）属「王道书扩展」，408 选择题偶有涉及，但默写以递归版为准。

### 4.3 执行过程示例（从顶点 2 出发，邻接点按编号递增顺序）

设图含顶点 1~11，其中 1~8 为一个连通分量，9、10、11 为另一连通分量。从 2 出发：

```
访问 2 → 邻接点中 1 未访问 → 访问 1 → 1 的邻接点 2 已访问，5 未访问 → 访问 5
→ 5 的邻接点全已访问，回溯到 1 → 1 的邻接点检查完，回溯到 2
→ 2 的下一个未访问邻接点 6 → 访问 6 → 6 的邻接点 2 已访问，3 未访问 → 访问 3
→ 3 的邻接点中 4 未访问 → 访问 4 → 4 的邻接点 3 已访问，7 未访问 → 访问 7
→ 7 的邻接点中 8 未访问 → 访问 8 → 8 的邻接点全已访问，逐层回溯至 2
→ 2 的邻接点检查完，DFS(2) 结束
```

得到序列：**2, 1, 5, 6, 3, 4, 7, 8**。此时 `visited[9..11]` 仍为 false，外层 for 循环继续找到 9，再调用 DFS(9)，遍历 9、10、11。

### 4.4 深度优先生成树与生成森林

- 遍历中「通过某条边首次发现一个未访问顶点」时，把这条边保留（标红），删去其余边，得到无环连通结构 → **深度优先生成树**。
- 邻接表存储不唯一（边结点顺序可变）→ 同一图、同一起点可能得到不同 DFS 序列 → 生成树也可能不同；邻接矩阵存储唯一 → 生成树唯一。
- 非连通图需多次调用 DFS，每次生成一棵树，全体构成**深度优先生成森林**。

### 4.5 遍历与连通性（408 必考结论）

| 图的类型 | 结论 |
|---|---|
| 无向图 | DFS（或 BFS）调用次数 = 连通分量数；连通图只需 1 次 |
| 有向图 | 从某顶点出发能到达所有顶点，则从该点起 1 次即可；否则需多次 |
| 有向强连通图 | 任意顶点出发均只需 1 次 |

## 5. 复杂度分析

**空间复杂度**（主要来自递归工作栈）：

- **最坏** $O(|V|)$：图为一条链（如 1—2—3—…—n），递归深度等于顶点数。题目未特殊说明时按最坏情况答。
- **最好** $O(1)$：图为星形（一个中心连所有其余顶点），递归深度最多 2 层。
- **平均**：取决于图的形态分布，无统一概率模型；408 不考平均，只考最好/最坏。

**时间复杂度**：总开销 = 访问各顶点 + 探索各条边。

- **邻接矩阵**：访问顶点共 $O(|V|)$；对每个顶点需扫描其整行（$|V|$ 个元素）找邻接点，共 $|V| \times O(|V|) = O(|V|^2)$。故 $T = O(|V|^2)$。
- **邻接表**：访问顶点 $O(|V|)$；无向图每条边在边表中出现 2 次、有向图 1 次，探索边共 $O(|E|)$。故 $T = O(|V| + |E|)$。
- 与 BFS 完全一致：复杂度只由**存储结构**决定，与遍历方式无关。

## 6. 易错点与考试写法

1. **漏写 visited 判断**：图有回路，不判 `visited[w]` 会死递归。这是与树先根遍历的唯一本质差别。
2. **漏写外层 for 循环**：只写 `DFS(G, v)` 只能遍历一个连通分量；非连通图必须 `DFSTraverse` 外层扫描。
3. **混淆 DFS 与 BFS 的序列**：DFS 是「一条路走到黑再回溯」，BFS 是「一层一层扩散」。手算序列时 DFS 要严格按递归回溯顺序写，不能按编号顺序写。
4. **邻接表序列不唯一**：题目若说「邻接表边结点按编号递增排列」，则序列唯一；未说明时答案可能不唯一，选择题常在此设陷阱。
5. **生成树边数**：$n$ 个顶点的生成树恰有 $n-1$ 条边；生成森林边数 = $n - $（树的棵数）。
6. **答题程度**：算法题写递归版 `DFS` + `DFSTraverse` 两个函数、含 `visited` 初始化与判断，即算完整；复杂度答「邻接矩阵 $O(|V|^2)$，邻接表 $O(|V|+|E|)$，空间最坏 $O(|V|)$」即得分。

## 7. 408 题型与解题套路

- **选择题（高频）**：
  - 给定图和存储结构，求 DFS 序列 → 按「访问→找第一个未访问邻接点→深入→回溯」逐步写，邻接点顺序以题目给定为准。
  - 判断 DFS 调用次数 / 连通分量数 → 数连通分量。
  - 判断生成树是否唯一 → 看存储结构（矩阵唯一、邻接表不唯一）。
  - DFS 与 BFS 复杂度对比 → 同存储结构下二者相同。
- **算法题（中频）**：判断图是否连通、求连通分量数、判断有无回路（DFS 中遇到已访问且非父结点的邻接点）等，均以本节模板为骨架，改 `visit()` 与判断条件即可。
- **常见陷阱**：把「邻接点编号最小」误当默认规则；忽略非连通图；把生成森林当成生成树。

## 8. 自测题

**题 1** 无向图有 3 个连通分量，对其做 DFS，`DFS` 函数被调用几次？

**题 2** 图采用邻接矩阵存储，顶点数 $n$、边数 $e$，DFS 时间复杂度是多少？若改为邻接表呢？

**题 3** 从顶点 3 出发对 4.3 中 1~8 的连通分量做 DFS（邻接点按编号递增），写出遍历序列。

**题 4** 同一图、同一起点，用邻接表和邻接矩阵分别做 DFS，所得序列是否一定相同？为什么？

**题 5** 含 $n$ 个顶点、$k$ 个连通分量的无向图，其深度优先生成森林共有多少条边？

<details>
<summary>答案</summary>

1. 3 次。每次 DFS 遍历一个连通分量，调用次数 = 连通分量数。
2. 邻接矩阵 $O(n^2)$；邻接表 $O(n+e)$。推导见第 5 节。
3. 3, 4, 7, 6, 2, 1, 5, 8。过程：3→4→7→6→2→1→5，回溯至 7 后访问 8。
4. 不一定相同。邻接矩阵表示唯一，序列唯一；邻接表边结点顺序可变，序列可能不同。
5. $n-k$ 条边。森林中每棵树边数 = 顶点数 − 1，求和得 $n-k$。

## 9. 背诵卡

1. DFS = 树的先根遍历 + `visited[]` 数组；先访问、再循环邻接点、未访问则递归。
2. 非连通图必须外层 for 扫描，DFS 调用次数 = 连通分量数。
3. 时间：邻接矩阵 $O(|V|^2)$，邻接表 $O(|V|+|E|)$；空间最坏 $O(|V|)$（递归栈），最好 $O(1)$。
4. 邻接矩阵 → 序列与生成树唯一；邻接表 → 均不唯一。
5. 生成森林边数 = $n - $（树的棵数）= $n - $（连通分量数）。
