# 8.7.5 最佳归并树

## 1. 本节定位

- **对应王道书**：第 8 章「排序」→ 8.7 外部排序 → 8.7.5 最佳归并树（承接 8.7.3 多路平衡归并、8.7.4 置换-选择排序）。
- **408 大纲对应**：外部排序（多路归并、归并树、最佳归并树、哈夫曼树在外部排序中的应用）。
- **先修知识**：哈夫曼树与带权路径长度（WPL）、多路归并、置换-选择排序生成不等长初始归并段、磁盘 I/O 以块为单位。
- **本节位置**：外部排序的收尾优化环节——初始归并段长度不等时，如何安排归并顺序使磁盘读写次数最少。是「哈夫曼树」在外部排序中的直接应用，也是本章最后的知识点。

## 2. 一句话结论

**归并过程的磁盘 I/O 总次数 = 归并树 WPL × 2；使 WPL 最小的归并树就是最佳归并树，用（k 叉）哈夫曼树构造；k 路归并时若初始归并段数不能构成严格 k 叉树，需补若干长度为 0 的虚段。**

## 4. 核心内容

### 4.1 归并树与磁盘 I/O 的关系（408 必考）

设初始归并段 $r_i$ 的长度（占磁盘块数）为权值 $w_i$。把每个归并段看作叶子，每次归并产生一个内部结点（权值为两/多孩子之和），得到一棵**归并树**。

**关键结论**：归并过程中

$$\text{读磁盘次数} = \text{写磁盘次数} = \text{WPL} = \sum_{i} w_i \cdot l_i$$

其中 $l_i$ 为叶子 $r_i$ 到根的路径长度（即该段参与归并的次数）。

$$\boxed{\text{总磁盘 I/O 次数} = 2 \times \text{WPL}}$$

**推导**：每次归并需把参与归并的各段全部读入内存（读次数 = 参与段总块数），归并结果写回磁盘（写次数 = 结果块数）。对每个叶子，它每被归并一次就贡献一次读和一次写；它到根的路径长度恰是它被归并的次数。故读、写各等于 WPL。

> 例（二路归并，5 个段，权值 2,5,1,6,2）：按「先合并相邻短段」的朴素策略，读次数 = 6+8+14+16 = 44，WPL = 2×1 + (5+1+6+2)×3 = 2+42 = 44，二者相等，总 I/O = 88。

### 4.2 二路归并的最佳归并树

要 I/O 最少 ⇔ 要 WPL 最小 ⇔ **构造哈夫曼树**。

**构造步骤**（与哈夫曼树完全一致）：
1. 每个初始归并段作为一棵单结点树，权值为其长度；
2. 每次从森林中取**根权值最小的两棵**，作为兄弟合并，新根权值 = 两孩子权值之和；
3. 重复直到只剩一棵树。

**例**：权值 2,5,1,6,2
- 取 1、2 → 新结点 3
- 取 2、3 → 新结点 5
- 取 5、5 → 新结点 10
- 取 6、10 → 新结点 16
- WPL = 34，总 I/O = 68（优于朴素策略的 88）

**归并方案解读**：先归并 $r_1(2)$ 与 $r_3(1)$ 得长度 3；再与 $r_5(2)$ 归并得 5；再与 $r_2(5)$ 归并得 10；最后与 $r_4(6)$ 归并得 16。

### 4.3 k 路归并的最佳归并树

**构造规则**：每次取根权值最小的 **k 棵**树合并，新根权值 = k 个孩子之和。得到 k 叉哈夫曼树，即 k 路归并的最佳归并树。

**例**（三路归并，权值 2,3,6,9,17,18,24,30）：取 2,3,6 → 11；取 9,11,12 → 32；取 17,18,24 → 59；最后 30,32,59 → 121。WPL = 223，总 I/O = 446。

### 4.4 严格 k 叉树与虚段（408 高频）

**问题**：k 路归并的最佳归并树必须是**严格 k 叉树**（每个内部结点恰有 k 个孩子）。若初始归并段数 $n_0$ 不能构成严格 k 叉树，最后一次归并会退化为不足 k 路，此时构造出的树不是最优。

**判定与补段**：

设初始归并段数为 $n_0$，归并路数为 $k$。

- 若 $(n_0 - 1) \bmod (k - 1) = 0$：**不需补虚段**；
- 否则设余数 $u = (n_0 - 1) \bmod (k - 1)$，需补

$$\text{虚段数} = (k - 1) - u$$

**推导**（严格 k 叉树性质）：设度为 k 的结点数 $n_k$、叶子数 $n_0$、总结点数 $n$。则
$$n = n_0 + n_k, \qquad n - 1 = k \cdot n_k$$
联立得 $n_0 = (k-1)n_k + 1$，即 $n_0 - 1$ 必须被 $k-1$ 整除。补虚段后叶子总数 $n_0'$ 满足 $(n_0' - 1) \bmod (k-1) = 0$。

**例**：$n_0 = 8$，$k = 3$：$(8-1) \bmod 2 = 1 = u$，补 $(3-1)-1 = 1$ 个虚段，叶子变 9 个，$(9-1)/2 = 4$ 个内部结点，严格三叉树成立。补虚段后 WPL = 163，总 I/O = 326（不补时为 193，更差）。

**例**：$n_0 = 19$，$k = 8$：$(19-1) \bmod 7 = 4 = u$，补 $7 - 4 = 3$ 个虚段，叶子变 22，$(22-1)/7 = 3$ 个内部结点。

**虚段的物理含义**：k 路归并需 k 个输入缓冲区；虚段占一个缓冲区但其中无数据，等价于该路「已归并完毕」，不参与实际比较。

## 5. 复杂度分析

本节核心是**归并树 WPL 的计算与最小化**，不是算法时间复杂度的传统三情况分析，按考试口径给出：

- **构造最佳归并树（k 叉哈夫曼）**：设叶子数 $n_0$（含虚段），每次合并需选出最小 k 个根。用最小堆实现，每次取 k 个 + 插入 1 个，共约 $\frac{n_0-1}{k-1}$ 次合并，每次 $O(k \log n_0)$，总时间 $O(n_0 \log n_0)$（k 为常数时）。**最好/最坏/平均均为 $O(n_0 \log n_0)$**，因为堆操作次数由叶子数唯一决定，与权值分布无关。
- **WPL 计算**：遍历树一次，$O(n_0)$。
- **磁盘 I/O 次数**：等于 $2 \times \text{WPL}$，是**结果量**而非算法复杂度；其大小取决于权值分布与归并策略，最优策略下取到最小值。

> 说明：本节不涉及「平均情况概率假设」型复杂度，故不强行套用；上述为构造算法的确定性复杂度。

## 6. 易错点与考试写法

1. **I/O 次数 = 2 × WPL，不是 WPL**。读、写各等于 WPL，总次数翻倍。题目问「读写总次数」要乘 2，问「读次数」不乘。
2. **虚段数公式记反**：是 $(k-1) - u$，不是 $u$ 或 $k - u$。先算 $u = (n_0-1) \bmod (k-1)$。
3. **判定条件用 $n_0 - 1$ 而非 $n_0$**：$(n_0 - 1) \bmod (k-1)$，不是 $n_0 \bmod (k-1)$。
4. **k = 2 时 $k-1 = 1$，任何 $n_0$ 都整除**，故二路归并永远不需补虚段——这是二路与多路的本质区别。
5. **虚段权值为 0**，参与哈夫曼构造时会被最先合并，不能忽略它占一个叶子位置。
6. **答题写到什么程度算对**：写出「I/O = 2×WPL」结论 + 画出哈夫曼树（标出每次合并的新权值）+ 算出 WPL 数值 + 若 k>2 写出补虚段个数及判定式，即可满分。只写「用哈夫曼树」不画树、不算 WPL 会失分。

## 7. 408 题型与解题套路

**选择题常见考法**：
- 给一组初始归并段长度和路数 k，问最佳归并树的 WPL 或总 I/O 次数 → 画 k 叉哈夫曼树算 WPL，乘 2。
- 给 $n_0$ 和 k，问需补几个虚段 → 套 $(k-1) - ((n_0-1) \bmod (k-1))$。
- 判断「最佳归并树一定是哈夫曼树」→ 正确（k 叉意义下）。
- 比较两种归并方案的 I/O 次数 → 分别算 WPL。

**解题套路（四步）**：
1. 确定 k 与 $n_0$；
2. 若 k > 2，算虚段数并补 0 权叶子；
3. 反复取最小 k 个合并，画树、标新权值；
4. 算 WPL = Σ(叶子权 × 路径长)，总 I/O = 2 × WPL。

**陷阱**：忘记补虚段直接构造（导致最后一次不足 k 路，WPL 偏大）；把 WPL 当总 I/O；虚段权值误写成 1。

## 8. 自测题

**题 1**：5 个初始归并段长度 2,5,1,6,2，二路归并，最佳归并树的总磁盘 I/O 次数是多少？

**题 2**：8 个初始归并段做三路归并，需补几个虚段？补后叶子总数是多少？

**题 3**：19 个初始归并段做八路归并，需补几个虚段？

**题 4**：判断：二路归并时，若初始归并段数为奇数，必须补一个虚段。

**题 5**：某最佳归并树 WPL = 223，k = 3，则归并过程读磁盘多少次、写磁盘多少次、总 I/O 多少次？

<details>
<summary>答案</summary>

**题 1**：构造哈夫曼树：1+2=3，2+3=5，5+5=10，6+10=16。WPL = 2×1+(5+1+6+2)×3 = 2+42 = 44，总 I/O = 88 次。

**题 2**：$u = (8-1) \bmod (3-1) = 7 \bmod 2 = 1$，补 $(3-1)-1 = 1$ 个虚段，叶子总数 = 8+1 = 9，$(9-1)/2 = 4$ 个内部结点，严格三叉树成立。

**题 3**：$u = (19-1) \bmod (8-1) = 18 \bmod 7 = 4$，补 $7-4 = 3$ 个虚段，叶子总数 22。

**题 4**：错误。二路归并 $k-1 = 1$，$(n_0-1) \bmod 1 = 0$ 恒成立，任何 $n_0$ 都能构成严格二叉树，不需补虚段。

**题 5**：读 223 次，写 223 次，总 I/O = 446 次。

## 9. 背诵卡

1. **总 I/O = 2 × WPL**；读 = 写 = WPL。
2. 最佳归并树 = **k 叉哈夫曼树**：每次取权值最小的 k 棵合并。
3. 严格 k 叉树条件：$(n_0 - 1) \bmod (k-1) = 0$。
4. 补虚段数 = $(k-1) - ((n_0-1) \bmod (k-1))$，虚段权值为 **0**。
5. 二路归并 $k-1=1$，**永不补虚段**。
