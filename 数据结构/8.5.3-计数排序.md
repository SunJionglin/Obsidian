# 8.5.3 计数排序（Counting Sort）

## 1. 本节定位

- **对应章节**：王道《数据结构》第 8 章「排序」→ 8.5 基数排序与计数排序 → 8.5.3 计数排序。
- **408 大纲**：**不在大纲要求内**（大纲只列插入、交换、选择、归并、基数五类）。但 2013 年 41 题、2018 年 41 题均可用计数排序思想高效求解，故作为**补充考点**学习，属于「王道书扩展」。
- **先修知识**：数组下标与位序的对应、时间复杂度加法原则（第一章）、空间换时间思想。
- **位置**：本章最后一类排序算法，是「非比较排序」的代表，与基数排序同属「按关键字值直接定位」的思路。

## 2. 一句话结论

计数排序先统计每个值出现次数，再前缀和求出「小于等于 $i$ 的元素个数」，从后往前把元素放到对应位置；当取值范围 $K$ 与元素个数 $N$ 同数量级时，时间、空间均为 $O(N)$，且**稳定**。

## 3. 知识地图

```
计数排序
├── 适用条件
│   ├── 关键字为整数
│   ├── 取值范围 0 ~ K-1（K 为值域大小）
│   └── K 较小，最好 K 与 N 同数量级
├── 三步流程
│   ├── Step1 统计次数：C[A[i]]++
│   ├── Step2 前缀和：C[i] += C[i-1]  → C[i] = 小于等于 i 的元素个数
│   └── Step3 从后往前放置：B[--C[A[i]]] = A[i]
├── 性能
│   ├── 时间 O(N+K)
│   ├── 空间 O(N+K)（辅助数组 B、C）
│   └── 稳定（依赖从后往前扫描）
└── 考试应用
    ├── 2013-41 主元素（只用到 Step1）
    └── 2018-41 未出现的最小正整数（变通使用）
```

## 4. 核心内容

### 1. 算法思想（用「排名」理解）

要确定元素 $x$ 排第几，只需数出「值 $\le x$ 的元素共有几个」。设共有 $c$ 个，则 $x$ 应放在第 $c$ 个位置（位序从 1 起），对应数组下标 $c-1$。

> 位序 vs 下标：位序第 $c$ 个 ↔ 下标 $c-1$。代码里先 `C[A[i]]--` 再取该值作下标，正是把「位序」转成「下标」。

### 2. 三步流程（设 A 长度 N，值域 $0\sim K-1$）

**Step1 统计次数**：遍历 A，`C[A[i]]++`。此时 `C[i]` = 值等于 $i$ 的元素个数。

**Step2 前缀和**：`for i=1..K-1: C[i] += C[i-1]`。此时 `C[i]` = 值**小于等于** $i$ 的元素个数。

**Step3 从后往前放置**：对 $i=N-1$  downto $0$：
```
B[--C[A[i]]] = A[i];
```
先自减得到下标，再写入 B。**必须从后往前**，才能保证相同值的元素相对次序不变（稳定性）。

### 3. C 语言实现（王道风格，可默写）

```c
// A: 待排序数组，长度 n；值域 0 ~ k-1
// B: 输出数组，长度 n；C: 计数数组，长度 k
void CountingSort(int A[], int B[], int n, int k) {
    int *C = (int *)malloc(sizeof(int) * k);   // 辅助计数数组
    for (int i = 0; i < k; i++) C[i] = 0;      // 初始化，O(k)

    for (int i = 0; i < n; i++) C[A[i]]++;     // Step1 统计次数，O(n)

    for (int i = 1; i < k; i++) C[i] += C[i-1];// Step2 前缀和，O(k)

    for (int i = n - 1; i >= 0; i--) {         // Step3 从后往前，O(n)
        B[--C[A[i]]] = A[i];                   // 先减 1 得下标，再放入
    }
    free(C);
}
```

**关键行注释**：
- `C[A[i]]++`：值 $A[i]$ 出现一次，计数加一。
- `C[i] += C[i-1]`：累加，使 `C[i]` 变为「$\le i$ 的个数」。
- `B[--C[A[i]]] = A[i]`：`--C[A[i]]` 把「位序」转成「下标」，同时为下一个同值元素让位。

### 4. 图解（教材例子，值域 0~4，N=8）

A = `[2, 4, 3, 0, 2, 3, 0, 3]`

| 阶段 | C[0] | C[1] | C[2] | C[3] | C[4] |
|---|---|---|---|---|---|
| Step1 统计 | 2 | 0 | 2 | 3 | 1 |
| Step2 前缀和 | 2 | 2 | 4 | 7 | 8 |

Step3 从后往前：A[7]=3 → `--C[3]=6` → B[6]=3；A[6]=0 → `--C[0]=1` → B[1]=0；……最终 B = `[0,0,2,2,3,3,3,4]`。

**稳定性验证**：三个 3 按原相对次序落入 B[4]、B[5]、B[6]，次序不变。

## 5. 复杂度分析

设元素个数 $N$，值域大小 $K$。

**时间**：
- 初始化 C：$O(K)$
- Step1 遍历 A：$O(N)$
- Step2 前缀和：$O(K)$
- Step3 遍历 A：$O(N)$
- 合计 $O(N+K)$，去掉常数即 $O(N+K)$。

**空间**：辅助数组 B 长 $N$、C 长 $K$，共 $O(N+K)$。

**最好 / 最坏 / 平均**：三者均为 $O(N+K)$——算法执行路径与数据分布无关，只与 $N$、$K$ 有关，**不存在最好最坏之分**（这是非比较排序的特点）。

**关键推论**（考试常考）：
- 若 $K$ 与 $N$ 同数量级，则 $O(N+K)=O(N)$，**优于**快排/堆排的 $O(N\log N)$。
- 若 $K \ge N\log N$ 数量级，则 $O(N+K) \ge O(N\log N)$，**不如**快排/堆排。
- 故计数排序是典型的**空间换时间**：牺牲 $O(N+K)$ 空间换取线性时间。

## 6. 易错点与考试写法

1. **Step3 必须从后往前**。若从前往后，相同值元素次序反转，**稳定性被破坏**。这是最常考的判断点。
2. **`--C[A[i]]` 与 `C[A[i]]--` 的区别**：前者先减后用作下标（正确），后者先用原值作下标再减（会越界或错位）。默写时务必写对。
3. **位序与下标差 1**：`C[i]` 表示「个数」，个数 $c$ 对应下标 $c-1$，所以要先自减。
4. **Step2 从 i=1 开始**，`C[0]` 不变（$\le 0$ 的个数就是值 0 的个数）。
5. **适用条件必须写**：关键字为整数、值域 $K$ 较小。若值域很大（如含负数、大整数），直接套用会爆空间。
6. **答题程度**：408 算法题若用计数排序思想，需写出「辅助数组定义 + 统计 + 前缀和/查找」的完整逻辑，并给出 $O(N)$ 时间、$O(N)$ 空间的分析，即可得高分；不必写完整可编译代码，但关键循环要写清。

## 7. 408 题型与解题套路

**选择题考法**：
- 判断某序列经计数排序后是否稳定（看相同值相对次序）。
- 给定 A 和 K，问 Step2 后 `C[i]` 的含义（「$\le i$ 的个数」）。
- 比较计数排序与快排/堆排的适用场景（$K$ 与 $N$ 的数量级关系）。
- 问空间复杂度（易漏掉 B 数组，答成 $O(K)$ 是错的）。

**算法题套路**（2013-41、2018-41 为代表）：
- **信号**：题目给出「元素值范围 $< N$」或「只要求时间高效、不限空间」→ 考虑计数排序思想。
- **2013-41 主元素**：值域 $< N$，开长 $N$ 的数组 C，遍历 A 做 `C[A[i]]++`，再扫 C 找是否有 `C[i] > N/2`。只用到 Step1，$O(N)$ 时间、$O(N)$ 空间。
- **2018-41 未出现的最小正整数**：值域未限制，但答案必在 $1\sim N+1$。开长 $N+2$ 的数组 C，遍历 A 时**只对 $1\le A[i]\le N$ 的值**做 `C[A[i]]++`（越界值忽略），再从 $i=1$ 起找第一个 `C[i]==0`，该 $i$ 即答案。$O(N)$ 时间、$O(N)$ 空间。
- **陷阱**：2018 题若直接对负数或大值取下标会越界，必须先判断范围再计数。

## 8. 自测题

**1.** 计数排序 Step2 完成后，`C[i]` 的含义是什么？Step3 中 `B[--C[A[i]]] = A[i]` 为什么要先自减？

**2.** 若把 Step3 改为从前往后扫描（`for i=0..n-1`），计数排序还稳定吗？为什么？

**3.** 数组 A 长度 $N=1000$，值域 $0\sim 999$。计数排序的时间、空间复杂度各是多少？与快排相比谁更优？

**4.**（2018-41 改编）数组 A = `[-1, 3, 2, 1, 5]`，用计数排序思想求未出现的最小正整数，辅助数组应开多大？遍历时哪些元素被计数？

**5.** 判断：计数排序的最好时间复杂度是 $O(N)$，最坏是 $O(N+K)$。

<details>
<summary>答案</summary>

1. `C[i]` 表示原数组中值**小于等于** $i$ 的元素个数。先自减是因为「个数 $c$」对应数组下标 $c-1$，自减后得到正确下标，同时为下一个同值元素预留前一个位置。
2. 不稳定。从前往后放置时，后出现的同值元素会占据更靠前的位置，相对次序反转。稳定性依赖「从后往前 + 先自减」。
3. 时间 $O(N+K)=O(2000)=O(N)$；空间 $O(N+K)=O(N)$。$K$ 与 $N$ 同数量级，计数排序 $O(N)$ 优于快排 $O(N\log N)$，但多花 $O(N)$ 辅助空间。
4. 答案必在 $1\sim N+1=1\sim 6$，辅助数组开 $N+2=7$（下标 $0\sim 6$）。遍历时只对 $1\le A[i]\le N$ 的元素计数，即 3、2、1、5 被计数，$-1$ 忽略。扫 $C[1..]$ 第一个为 0 的是 $C[4]$，答案 4。
5. 错。计数排序执行路径与数据分布无关，最好、最坏、平均均为 $O(N+K)$，不存在 $O(N)$ 的最好情况（除非 $K=O(1)$ 另行讨论）。

</details>

## 9. 背诵卡

1. **三步**：统计次数 → 前缀和（$\le i$ 的个数）→ 从后往前 `B[--C[A[i]]]=A[i]`。
2. **稳定关键**：Step3 必须从后往前，且先自减再作下标。
3. **复杂度**：时间 $O(N+K)$，空间 $O(N+K)$，最好=最坏=平均。
4. **适用**：整数关键字、值域 $K$ 小、最好 $K$ 与 $N$ 同数量级；$K$ 过大则不如快排/堆排。
5. **考试信号**：值域受限或「只求时间高效」→ 用计数排序思想，$O(N)$ 时间 $O(N)$ 空间。
