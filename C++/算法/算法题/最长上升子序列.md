# 最长上升子序列 LIS 学习笔记（超精简版）

## 一、题目定义

给定一个整数序列，找出**最长严格上升子序列**的长度。

- 子序列：不要求连续，但保持原有先后顺序
- 严格上升：后一个数 > 前一个数

## 二、方法一：动态规划 O (n²)

### 1. 状态定义

`dp[i]`：以第 `i` 个元素结尾的最长上升子序列长度

### 2. 初始化

每个元素自身长度为 1：

`dp[i] = 1`

### 3. 状态转移

遍历每个 `i`，再遍历前面所有 `j < i`：

若 `a[j] < a[i]`

dp[i]=max(dp[i], dp[j]+1)

### 4. 答案

整个 `dp` 数组的最大值

### 5. C++ 模板代码

cpp

```
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main()
{
    int n;
    cin >> n;
    vector<int> a(n), dp(n, 1);
    for (int i = 0; i < n; i++) cin >> a[i];

    for (int i = 0; i < n; i++)
        for (int j = 0; j < i; j++)
            if (a[j] < a[i])
                dp[i] = max(dp[i], dp[j] + 1);

    cout << *max_element(dp.begin(), dp.end());
    return 0;
}
```

### 6. 适用范围

n≤5000 完全够用，**思路简单、适合新手**

## 三、方法二：贪心 + 二分 O (n log n)

### 1. 原理

维护一个数组 `res`，始终保持它**尽可能小**，方便后续接更长序列。

- `lower_bound` 找第一个 ≥ 当前数的位置
- 找到则替换，没找到就追加

### 2. C++ 模板代码

cpp

```
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main()
{
    int n, x;
    cin >> n;
    vector<int> res;
    for (int i = 0; i < n; i++)
    {
        cin >> x;
        auto it = lower_bound(res.begin(), res.end(), x);
        if (it == res.end()) res.push_back(x);
        else *it = x;
    }
    cout << res.size();
    return 0;
}
```

### 3. 适用范围

n≤105 大数据必用，速度快

## 四、易错点总结

1. 严格上升用 `a[j] < a[i]`，非严格用 `<=`
2. DP 初始值一定要设为 1
3. 最后答案不是 `dp[n-1]`，是**整个 dp 最大值**
4. 二分版只能求长度，**不能还原序列**；DP 可以还原
