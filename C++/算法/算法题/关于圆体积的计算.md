为什么这里是3.0和4.0而不是3和4

在代码 `double volume = (4.0 / 3.0) * pi * r * r * r;` 中，使用 `4.0` 和 `3.0` 而非 `4` 和 `3`，核心原因是为了**避免整数除法导致的计算错误**，这涉及到 C++ 中 “数据类型运算规则” 的基础语法，具体原理如下：

### 1. 先明确：C++ 中的 “整数除法” 规则

==在 C++ 中，如果两个**整数类型**的数值进行除法运算（比如 `4 / 3`），结果会被强制 “截断取整”（只保留整数部分，丢弃小数部分），而非保留小数。==

- 示例：`4 / 3` 的数学结果是 `1.333...`，但由于 `4` 和 `3` 都是整数，C++ 会将结果截断为整数 `1`；
- 而 ==`4.0 / 3.0` 中，`4.0` 和 `3.0` 是**浮点数类型**（`double` 类型），除法结果会保留小数==，即 `1.333333...`，符合球体体积公式的数学需求。

### 2. 为什么用整数除法会导致最终结果错误？

球体体积公式是 `V = (4/3) * π * r³`，其中 `(4/3)` 是关键系数（约等于 `1.333...`）。

如果写成 `(4 / 3)`（整数除法）：

- 第一步计算 `4 / 3` 得到 `1`；
- 后续计算会变成 `1 * π * r³`，相当于体积被 “少算” 了约 `33%`，完全不符合公式逻辑。

例如：当半径 `r=5` 时（对应样例输入）：

- 正确计算（`4.0/3.0`）：`(4.0/3.0)*3.14*5³ ≈ 1.33333 * 3.14 * 125 = 523.33333`（与样例输出一致）；
- 错误计算（`4/3`）：`1 * 3.14 * 125 = 392.5`（结果完全错误）。

### 3. 延伸：其他 “避免整数除法” 的写法

除了 `4.0 / 3.0`，还有两种常见写法也能避免整数除法，原理相同（都是将其中一个操作数转为浮点数，触发 “浮点数除法”）：

- `4.0 / 3`：`4.0` 是浮点数，`3` 会被自动 “隐式转换” 为浮点数 `3.0`，结果为 `1.333...`；
- `4 / 3.0`：同理，`3.0` 是浮点数，`4` 被转为 `4.0`，结果同样正确。

但 `4.0 / 3.0` 是最直观的写法，能明确告诉阅读者 “这里需要浮点数除法”，可读性更强。

### 总结

用 `4.0` 和 `3.0` 是为了**强制触发浮点数除法**，确保 `(4/3)` 的结果保留小数（`1.333...`），从而符合球体体积公式的数学逻辑；如果用整数 `4` 和 `3`，会因整数除法截断为 `1`，导致最终体积计算结果完全错误。这是 C++ 中 “基础数据类型运算规则” 的典型应用，也是新手容易踩坑的点。
