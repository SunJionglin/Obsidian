

## 一、引言

蛇形方阵是指给定不大于 9 的正整数`n`，生成`n×n`矩阵，从左上角（0,0）位置填入 1 开始，按顺时针方向依次填充 1~n² 的数字，且每个数字占 3 个字符宽度（空格补齐）。本文记录两种主流实现思路：**方向向量法**与**边界控制法**，分析其核心逻辑与代码实现。

## 二、实现方式一：方向向量法

### 1. 核心思路

通过**方向数组**定义顺时针的 4 个移动方向（右、下、左、上），用`dir`变量控制当前方向；循环填充数字时，先计算下一个位置，若位置越界或已填充，则顺时针转向（更新`dir`），再重新计算合法位置，直至填满所有格子。

### 2. 完整代码

cpp

```cpp
#include <iostream>
#include <iomanip>  // 控制输出宽度
using namespace std;

int main() {
    int n;
    cin >> n;
    int matrix[9][9] = {0};  // 初始化n×n矩阵（n≤9，9×9足够）

    // 方向数组：存储4个方向的「行变化量, 列变化量」
    int dirs[4][2] = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
    int dir = 0;  // 方向控制变量：0=右，1=下，2=左，3=上（初始向右）
    int row = 0, col = 0;  // 当前填充位置（起点：左上角）

    // 填充1~n²的数字
    for (int num = 1; num <= n * n; num++) {
        matrix[row][col] = num;  // 当前位置填入数字

        // 计算当前方向下的下一个位置
        int next_row = row + dirs[dir][0];
        int next_col = col + dirs[dir][1];

        // 检查下一个位置是否合法（边界内 + 未填充）
        if (next_row < 0 || next_row >= n || 
            next_col < 0 || next_col >= n || 
            matrix[next_row][next_col] != 0) {
            dir = (dir + 1) % 4;  // 顺时针转向（0→1→2→3→0循环）
            // 按新方向重新计算下一个位置
            next_row = row + dirs[dir][0];
            next_col = col + dirs[dir][1];
        }

        // 更新当前位置为下一个合法位置
        row = next_row;
        col = next_col;
    }

    // 按格式输出（每个数字占3字符）
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cout << setw(3) << matrix[i][j];
        }
        cout << endl;
    }

    return 0;
}
```

### 3. 关键模块解析

#### （1）方向数组`dirs`

- 结构：`dirs[4][2]`，4 行对应 4 个方向，2 列对应「行变化量、列变化量」。
- 含义：
    - `{0,1}`：向右（行不变，列 + 1）
    - `{1,0}`：向下（行 + 1，列不变）
    - `{0,-1}`：向左（行不变，列 - 1）
    - `{-1,0}`：向上（行 - 1，列不变）

#### （2）方向控制变量`dir`

- 取值：0~3，分别对应`dirs`的 4 个方向。
- 转向逻辑：`dir = (dir + 1) % 4`，通过取余 4 实现顺时针循环（避免方向越界）。

#### （3）填充逻辑

1. 从（0,0）开始，依次填充 1~n²；
2. 每次填充后计算下一个位置（当前位置 + 方向增量）；
3. 若下一个位置不合法（越界或已填充），则转向后重新计算；
4. 更新当前位置，进入下一次循环。

## 三、实现方式二：边界控制法

### 1. 核心思路

定义**上、下、左、右 4 个边界**，按 “上边界→右边界→下边界→左边界” 的顺序填充，每填充完一个边界就**收缩对应边界**（如上边界填充完后下移）；循环直至所有边界交叉（填充完成），无需单独判断方向，通过边界收缩控制填充范围。

### 2. 完整代码

cpp

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;
    int matrix[9][9] = {0};  // 初始化矩阵

    // 定义4个边界：初始覆盖整个矩阵
    int top = 0, bottom = n - 1;  // 上边界（行）、下边界（行）
    int left = 0, right = n - 1;  // 左边界（列）、右边界（列）
    int num = 1;  // 待填充数字（从1开始）

    // 边界未交叉则继续填充
    while (num <= n * n) {
        // 1. 填充上边界：从左到右
        for (int col = left; col <= right; col++) {
            matrix[top][col] = num++;
        }
        top++;  // 上边界下移（当前行已填满）

        // 2. 填充右边界：从上到下
        for (int row = top; row <= bottom; row++) {
            matrix[row][right] = num++;
        }
        right--;  // 右边界左移（当前列已填满）

        // 3. 填充下边界：从右到左（需判断上下边界未交叉，避免重复）
        if (top <= bottom) {
            for (int col = right; col >= left; col--) {
                matrix[bottom][col] = num++;
            }
            bottom--;  // 下边界上移
        }

        // 4. 填充左边界：从下到上（需判断左右边界未交叉，避免重复）
        if (left <= right) {
            for (int row = bottom; row >= top; row--) {
                matrix[row][left] = num++;
            }
            left++;  // 左边界右移
        }
    }

    // 格式输出
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cout << setw(3) << matrix[i][j];
        }
        cout << endl;
    }

    return 0;
}
```

### 3. 关键模块解析

#### （1）边界变量初始化

- `top = 0`：初始上边界为第 0 行（最上方）；
- `bottom = n-1`：初始下边界为第 n-1 行（最下方）；
- `left = 0`：初始左边界为第 0 列（最左侧）；
- `right = n-1`：初始右边界为第 n-1 列（最右侧）。

#### （2）填充与边界收缩逻辑

1. **上边界填充**：从左到右遍历`top`行，填充后`top++`（上边界下移，缩小填充范围）；
2. **右边界填充**：从上到下遍历`right`列，填充后`right--`（右边界左移）；
3. **下边界填充**：需先判断`top <= bottom`（避免上下边界交叉导致重复填充），从右到左遍历`bottom`行，填充后`bottom--`；
4. **左边界填充**：需先判断`left <= right`（避免左右边界交叉），从下到上遍历`left`列，填充后`left++`。

#### （3）终止条件

当`num > n×n`时，所有数字填充完成，循环结束（边界交叉时，`num`不会继续增长）。

## 四、两种实现方式对比

|对比维度|方向向量法|边界控制法|
|---|---|---|
|核心思想|控制移动方向，按方向迭代填充|控制边界范围，按边界收缩填充|
|关键变量|方向数组`dirs`、方向`dir`、当前位置`(row, col)`|4 个边界`top/bottom/left/right`、待填充数字`num`|
|转向 / 边界处理|通过`dir = (dir+1)%4`实现顺时针转向，需判断下位置合法性|无需转向，填充后收缩边界，需判断边界是否交叉|
|代码复杂度|中等（需理解方向向量与转向逻辑）|较低（边界收缩逻辑直观，易调试）|
|适用场景|需灵活调整方向的场景（如多方向填充）|规则矩形填充（如蛇形方阵、螺旋矩阵）|
|可读性|依赖对方向向量的理解，新手需适应|边界逻辑贴近人类直观，新手易理解|

## 五、总结

1. 两种方式均能正确生成蛇形方阵，最终输出结果一致；
2. **方向向量法**更灵活，适合需要动态调整方向的场景，但需掌握 “方向向量 + 转向判断” 的逻辑；
3. **边界控制法**更直观，通过边界收缩简化逻辑，减少越界判断，适合新手入门；
4. 实际开发中可根据需求选择：简单矩形填充优先用边界控制法，复杂方向填充用方向向量法。
