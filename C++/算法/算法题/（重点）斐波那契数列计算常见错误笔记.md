# 斐波那契数列计算常见错误汇总与修正 | Obsidian笔记

## 一、核心需求回顾
实现功能：输入n个整数（每个整数代表斐波那契数列的项数m），输出每个项数对应的斐波那契值（规定第1项和第2项均为1，从第3项开始每项等于前两项之和）。


## 二、常见错误分类及修正方案

### 1. 数组/vector声明错误
#### 错误表现：
- 使用未定义变量声明数组：`int arr[i];`（声明时i未定义）
- 用变量作为数组大小（非标准C++）：`int arr[n];`
- 错误声明vector数组：`vector<int> arr[i];` 或 `vector<int> num[arr[i]];`（实际想声明动态大小的vector，却声明了vector数组）

#### 错误原因：
- ==混淆C++标准数组（大小必须为编译时常量）和动态数组（需用vector实现）==
- ==不理解vector的声明语法：`vector<类型> 变量名(大小);` 表示创建指定大小的动态数组==

#### 修正方案：
```cpp
// 正确声明存储n个整数的vector
vector<int> arr(n);  // 而非int arr[n]或vector<int> arr[i]

// 正确声明大小为m的vector（存储斐波那契数列）
vector<int> num(m);  // 而非vector<int> num[arr[i]]
````

### 2. 索引越界问题

#### 错误表现：

- ==访问 vector 的越界索引：`cin >> arr[n];` 或 `int m = arr[n];`（arr 大小为 n，有效索引 0~n-1）==
- ==循环索引范围错误：`for (int i=1; i<=n; i++)`（导致 i=n 时访问 arr [n] 越界）==

#### 错误原因：

- 忽略 C++ 中容器索引从 0 开始的规则
- 循环变量范围与容器大小不匹配

#### 修正方案：

cpp

运行

```cpp
// 循环索引从0开始，范围为0~n-1
for (int i=0; i < n; i++) {
    cin >> arr[i];  // 访问arr[i]而非arr[n]
    int m = arr[i]; // 使用当前索引i获取值，避免越界
}
```

### 3. vector 初始化错误

#### 错误表现：

- 动态 vector 使用初始化列表：`vector<int> num(m) = {1,1};`
- 初始化位置错误：将前两项初始化放在计算循环内部（`for (k=2;...)` 内执行 `num[0]=1;`）

#### 错误原因：

- ==不了解 C++ 中动态大小的 vector 不能用初始化列表赋值==
- 误解初始化逻辑：前两项只需初始化一次，无需每次循环重新赋值

#### 修正方案：

cpp

运行

```cpp
vector<int> num(m);  // 先声明指定大小的vector
// 单独初始化前两项（放在计算循环外）
num[0] = 1;  
num[1] = 1;  
```

### 4. 输入输出错误

#### 错误表现：

- 用圆括号访问 vector 元素：`cin >> arr(n);` 或 `cout << num(m-1);`
- 输出时机错误：在计算循环（`for (k=2;...)`）内部输出，导致一个项数对应多次输出

#### 错误原因：

- 混淆 vector 的访问语法（必须用方括号`[]`，而非圆括号`()`）
- 逻辑设计错误：未区分 “计算过程” 和 “结果输出”

#### 修正方案：

cpp

运行

```cpp
// 正确访问vector元素
cin >> arr[i];  // 方括号访问
cout << num[m-1] << endl;  // 方括号访问

// 正确输出时机：计算循环结束后只输出一次
for (int k=2; k < m; k++) {
    num[k] = num[k-1] + num[k-2];  // 仅计算，不输出
}
cout << num[m-1] << endl;  // 计算完成后输出结果
```

### 5. 语法结构错误

#### 错误表现：

- ==缺少头文件：未包含`#include <vector>`（使用 vector 必须包含）==
- 括号不匹配：缺少闭合的`}`，导致代码结构混乱
- return 语句位置错误：将`return 0;`放在循环内部，导致程序提前结束

#### 错误原因：

- 忽略 C++ 标准库的使用规则（使用容器需包含对应头文件）
- 代码格式不规范，未及时补全括号
- 对程序执行流程理解不清

#### 修正方案：

cpp

运行

```cpp
// 包含必要头文件
#include <iostream>
#include <vector>  // 必须包含，否则vector无法使用

// 正确的括号匹配和return位置
int main() {
    // ... 代码逻辑 ...
    
    // 所有循环和逻辑执行完毕后再return
    return 0;
}
```

## 三、正确代码示例（完整版）

cpp

运行

```cpp
#include <iostream>
#include <vector>  // 必须包含vector头文件
using namespace std;

int main() {
    int n;
    cin >> n;  // 输入要计算的数字个数
    
    vector<int> arr(n);  // 存储n个输入的项数
    for (int i = 0; i < n; i++) {
        cin >> arr[i];  // 读取第i个项数
    }
    
    // 逐个计算每个项数对应的斐波那契值
    for (int i = 0; i < n; i++) {
        int m = arr[i];  // 当前项数
        vector<int> num(m);  // 存储斐波那契数列
        
        // 初始化前两项
        num[0] = 1;
        num[1] = 1;
        
        if (m < 3) {
            // 前两项直接输出1
            cout << num[m-1] << endl;
        } else {
            // 从第3项计算到第m项
            for (int k = 2; k < m; k++) {
                num[k] = num[k-1] + num[k-2];
            }
            // 输出第m项
            cout << num[m-1] << endl;
        }
    }
    
    return 0;
}
```

## 四、错误预防 checklist

1. 使用 vector 时必须包含`#include <vector>`
2. 容器索引从 0 开始，循环范围需为`0 ~ 大小-1`
3. 动态 vector 声明语法：`vector<类型> 变量名(大小);`
4. vector 元素访问必须用方括号`[]`
5. 初始化操作放在计算循环外，避免重复赋值
6. 输出语句放在计算循环外，确保每个结果只输出一次
7. 检查括号匹配，return 语句放在程序末尾
