

## 一、程序功能与背景

该程序用于将汉字点阵的压缩码还原为 N×N 的 01 矩阵。汉字点阵通常由 N×N 的 0 和 1 组成，压缩码通过 "交替记录连续 0 和 1 的个数"（从 0 开始）实现数据压缩。程序的核心任务是解析压缩码，还原出原始的 01 点阵图案。

**压缩码规则**：

- 第一个数字为 N，表示矩阵大小为 N×N
- 后续数字交替表示：连续 0 的个数→连续 1 的个数→连续 0 的个数→...
- 所有数字之和等于 N×N（保证矩阵完整性）

## 二、核心代码实现

cpp

运行

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    int N;
    cin >> N;  // 读取矩阵大小
    vector<int> codes;  // 存储压缩码数据
    int num;
    while (cin >> num) {
        codes.push_back(num);  // 收集压缩码
    }
    
    string matrix_str;  // 存储完整01序列
    char current = '0';  // 初始字符为'0'（从0开始）
    for (int cnt : codes) {  // 遍历压缩码
        matrix_str.append(cnt, current);  // 生成对应数量的当前字符
        current = (current == '0') ? '1' : '0';  // 交替切换字符
    }
    
    // 按行输出矩阵
    for (int i = 0; i < N; ++i) {
        cout << matrix_str.substr(i * N, N) << endl;
    }
    
    return 0;
}
```

## 三、关键语法与功能解析

### 1. 数据收集：`vector`与`push_back`

- **`vector<int> codes`**：动态数组容器，用于存储压缩码中除 N 外的所有数据（连续 0/1 的个数）。
- **`push_back(num)`**：
    - 功能：向 vector 容器末尾添加元素，自动扩容。
    - 作用：通过`while (cin >> num)`循环读取所有压缩码数字，依次存入`codes`，确保后续能完整遍历数据。
    - 示例：输入`7 3 1 6...`时，`codes`最终存储`[3,1,6,...]`。

### 2. 序列生成：`string`与`append`

- **`string matrix_str`**：用于存储完整的 01 字符序列（长度为 N×N）。
- **`append(cnt, current)`**：
    - 功能：向字符串末尾添加`cnt`个`current`字符（`current`为 '0' 或 '1'）。
    - 作用：根据压缩码中的数字生成对应数量的 0 或 1，逐步构建完整序列。
    - 示例：`cnt=3`且`current='0'`时，添加 "000"；`cnt=1`且`current='1'`时，添加 "1"。

### 3. 字符交替：`current`变量

- **初始值为`'0'`的原因**：
    - 压缩码从记录连续 0 开始，需匹配编码规则。
    - 程序最终输出**字符形式**的 0/1（如 "0001000"），而非数字 0/1。字符 '0' 的 ASCII 码为 48，可被字符串正确存储和输出，而数字 0 无法直接作为字符使用。
- **交替逻辑**：`current = (current == '0') ? '1' : '0'`通过三元运算符实现 0 和 1 的切换。

### 4. 遍历压缩码：==`for(int cnt : codes)`==

- **范围 for 循环（foreach 循环）**：
    - 功能：遍历容器中所有元素，无需手动控制索引。
    - 作用：依次取出`codes`中存储的 "连续个数"，配合`append`生成对应字符，是实现压缩码解析的核心循环。
    - 流程：每次循环处理一个压缩码数字→生成对应字符→切换字符类型，直至所有数据处理完毕。

### 5. 矩阵输出：`substr`（string类）

- **`substr(i * N, N)`**：
    - 功能：从字符串的`i*N`位置开始，截取长度为 N 的子串。
    - 作用：将完整的 01 序列分割为 N 行，每行 N 个字符，形成 N×N 矩阵。
    - 示例：N=7 时，第 0 行截取`0~6`位置字符，第 1 行截取`7~13`位置字符，以此类推。

## 四、工作流程总结

1. **输入解析**：读取矩阵大小 N，通过`push_back`收集所有压缩码到`codes`。
2. **序列生成**：通过范围 for 循环遍历`codes`，利用`append`生成 01 序列，`current`控制字符交替。
3. **矩阵输出**：通过`substr`分割序列为 N 行，每行 N 个字符，完成输出。
