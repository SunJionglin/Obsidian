##  Description

输入一个浮点数 n，输出这个浮点数的绝对值。

### Input

输入一个浮点数 n，其绝对值不超过 1000010000。

### Output

输出 n 的绝对值，保留到小数点后两位。



```cpp
```cpp
#include <iostream>

#include <cmath>    // 用于fabs函数（计算浮点数绝对值）
#include <iomanip>  // 用于设置输出精度

using namespace std;

int main() {
    double n;       // 修正：添加分号
    cin >> n;
    
    // 修正：将fabs的结果赋值给n，否则n的值不会改变
    n = fabs(n);
    
    // 修正：设置输出格式，保留小数点后两位
    cout << fixed << setprecision(2) << n << endl;
   
    return 0;
}
```




`fabs(n)` 函数会计算 `n` 的绝对值，但不会修改 `n` 本身，必须将结果赋值给 `n`（即 `n = fabs(n);`），否则输出的还是原始值。


## fabs()求的浮点数绝对值，abs()求的整数绝对值
