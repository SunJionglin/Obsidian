# 组合数 C (n,m) 模 998244353 通俗笔记（含题目 + 代码 + 踩坑）

## 一、题目场景（直接对应代码需求）

### 题目描述

- 输入：T 组测试用例（比如 T=3，每组给两个整数 n 和 m，如 n=5、m=2）
- 输出：每组的组合数 C (n,m) 对 998244353 取模的结果（比如 C (5,2)=10，输出 10）
- 核心定义：C (n,m) 是 “从 n 个物品里选 m 个” 的选法总数，公式为：C(n,m)=m!×(n−m)!n!​
    
    （! 是阶乘，比如 5! = 5×4×3×2×1=120，0! 规定为 1）

### 为什么要取模？

题目中 n 和 m 可能很大（比如 n=1e6），C (n,m) 的结果会是天文数字，计算机存不下，所以用 998244353（竞赛常用质数模数）取模，把结果限制在合理范围。

## 二、你的原代码错在哪？（通俗踩坑分析）

原代码思路是 “分子累乘（n×(n-1)×…×(n-m+1)）÷ 分母（m!）”，但犯了 3 个致命错误，导致结果全错：

cpp

```
// 原代码错误片段
for(int i=1;i<=m;i++){
    M*=i; // 分母 m!，直接累乘
    N*=n-i+1; // 分子 n×(n-1)×…×(n-m+1)
}
ans=N/M; // 直接除法，模运算中不允许！
```

### 错误 1：模运算里不能直接 “除”！

计算机处理 “模 998244353” 时，没有普通除法的概念。比如想算 6÷2 mod 998244353，不能直接用 6/2，而是要用 “逆元”（相当于模意义下的 “倒数”）：

2 的逆元是 499122177，因为 2×499122177 mod 998244353 = 1，所以 6×499122177 mod 998244353 = 3，和 6÷2 结果一致。

### 错误 2：阶乘太大，直接 “溢出”！

13! 就超过了 long long 的最大值（约 9e18），你直接累乘 M 和 N，数值会变成乱码（比如 20! 已经是 2.4e18，21! 就爆了），根本算不出正确结果。

### 错误 3：没 “边算边取模”！

就算不溢出，大数字直接计算会很慢，而且 “先算大数再取模” 和 “边算边取模” 结果可能不一样（正确规则是：(a×b) mod p = (a mod p × b mod p) mod p，必须边算边模）。

## 三、核心解法：预处理 + 逆元（通俗理解）

核心思路：提前算好所有需要的 “阶乘” 和 “阶乘的逆元”（相当于提前准备好 “工具包”），每组查询直接套公式，1 步出结果，又快又对。

### 1. 3 个关键概念（不用背，理解就行）

表格

|概念|通俗解释|用途|
|---|---|---|
|阶乘 fact [i]|fact [i] = i! mod 998244353（比如 fact [5]=120）|直接提供公式里的 n!、m!|
|逆元阶乘 inv_fact [i]|inv_fact [i] 是 fact [i] 的 “模倒数”（比如 inv_fact [2] = 499122177）|代替公式里的 “除法”|
|核心公式|C(n,m) = (fact[n] × inv_fact[m] × inv_fact[n-m]) mod 998244353|直接计算组合数|

### 2. 预处理步骤（提前准备工具包）

预处理就是提前计算 fact [0]~fact [MAXN] 和 inv_fact [0]~inv_fact [MAXN]（MAXN 是题目中 n 的最大值，比如 1e6），后续查询直接用，不用重复算。

#### 步骤 1：计算阶乘 fact []

- 规则：fact [0] = 1（0! 规定为 1），后面的 fact [i] = (fact [i-1] × i) mod 998244353
- 举例：
    
    fact[1] = (fact[0] × 1) mod p = 1
    
    fact[2] = (1 × 2) mod p = 2
    
    fact[3] = (2 × 3) mod p = 6
    
    ... 以此类推，边乘边模，不会溢出。

#### 步骤 2：计算逆元阶乘 inv_fact []

需要用 “费马小定理”（因为 998244353 是质数，逆元 = 底数 ^(p-2) mod p），分两步：

1. 先算最大的 inv_fact [MAXN]：用快速幂计算 fact [MAXN]^(998244353-2) mod 998244353（快速幂是高效算 “大数次方” 的工具，不用慢慢乘）。
2. 倒着算剩下的 inv_fact []：inv_fact [i] = (inv_fact [i+1] × (i+1)) mod 998244353
    
    举例：知道 inv_fact [3]，inv_fact [2] = (inv_fact [3] × 3) mod p，比每个都用快速幂快很多。

#### 步骤 3：快速幂函数（算逆元的工具）

快速幂的作用是 “快速计算 a^b mod p”，比如算 2^10 mod p，不用 2×2×…×2（10 次），而是用 “二分法” 3 步搞定，代码直接套用就行。

## 四、完整可运行代码（带通俗注释）

cpp

```
#include<iostream>
#include<algorithm>
typedef long long ll; // 必须用 long long，防止溢出
using namespace std;

const int mod = 998244353; // 固定模数
const int MAXN = 1e6 + 10; // 题目中 n 的最大范围（按需调整，比如 n≤1e6）

ll fact[MAXN];     // 存阶乘：fact[i] = i! mod mod
ll inv_fact[MAXN]; // 存阶乘的逆元：inv_fact[i] = (i!)的逆元 mod mod

// 快速幂函数：计算 a^b mod mod，快速版（二分思想）
ll qpow(ll a, ll b) {
    ll res = 1; // 结果初始为 1
    while(b > 0) {
        if(b % 2 == 1) { // 如果 b 是奇数，就乘一次 a
            res = res * a % mod; // 边乘边模，防止溢出
        }
        a = a * a % mod; // a 自乘（二分：比如 2^10 = (2^5)^2）
        b = b / 2; // b 减半（二分）
    }
    return res;
}

// 预处理：提前算好 fact 和 inv_fact（只跑一次）
void pre() {
    // 第一步：算阶乘 fact
    fact[0] = 1; // 0! = 1
    for(int i = 1; i < MAXN; i++) {
        fact[i] = fact[i-1] * i % mod; // 前一个阶乘 × 当前 i，取模
    }
    // 第二步：算最大的 inv_fact（用费马小定理）
    inv_fact[MAXN-1] = qpow(fact[MAXN-1], mod - 2);
    // 第三步：倒着算所有 inv_fact
    for(int i = MAXN-2; i >= 0; i--) {
        inv_fact[i] = inv_fact[i+1] * (i+1) % mod;
    }
}

// 计算组合数 C(n,m) 的主函数
ll C(int n, int m) {
    if(m < 0 || m > n) return 0; // 非法情况：选的比总数多，或选负数，选法为 0
    // 核心公式：fact[n] × 逆元(fact[m]) × 逆元(fact[n-m]) mod mod
    return fact[n] * inv_fact[m] % mod * inv_fact[n - m] % mod;
}

int main() {
    pre(); // 程序开始先预处理，只调用一次（千万别放循环里！）
    int T;
    cin >> T;
    while(T--) { // 处理 T 组测试用例
        int n, m;
        cin >> n >> m;
        cout << C(n, m) << endl; // 直接调用函数，输出结果
    }
    return 0;
}
```

## 五、代码怎么用？（傻瓜式套用）

1. 调整 MAXN：如果题目中 n 最大是 2e5，就把 MAXN 改成 2e5 + 10（比最大值大一点，避免数组越界）。
2. 输入输出：按题目要求输入 T 组 n 和 m，直接输出 C (n,m) 的结果。
3. 举例验证：
    
    - 输入：1 5 2 → 输出：10（C (5,2)=10）
    - 输入：1 10 3 → 输出：120（C (10,3)=120）
    - 输入：1 7 4 → 输出：35（C (7,4)=35）
    

## 六、避坑必看（关键注意点）

1. **必须用 long long**：所有存阶乘、逆元、结果的变量都要用 ll，否则会溢出（比如 fact [20] 已经超 int 上限）。
2. **预处理只跑一次**：pre () 函数在 main 里只调用一次，不要放在 while (T--) 里，否则重复计算会超时。
3. **非法情况处理**：当 m > n 或 m <0 时，C (n,m)=0，代码里已经判断，不用自己加逻辑。
4. **模数不能乱改**：998244353 是质数，才能用费马小定理；如果题目换其他质数模数（比如 1e9+7），只改 mod 常量就行。
5. **边算边取模**：所有乘法后都要加 mod，防止溢出，这是竞赛必备习惯。

## 七、通俗总结

组合数模运算的核心就是 “提前准备工具包，公式直接套”：

- 工具包 = 阶乘（fact） + 阶乘逆元（inv_fact）
- 计算逻辑 = 原公式的 “除法”→ 模意义下的 “乘逆元”
- 解决的问题：溢出 + 除法无效 + 计算慢
- 最终效果：预处理一次 O (MAXN)，每组查询 O (1)，大数据也能秒出结果
