# 回文质数查找问题详解（附高效实现方案）

## 一、问题定义

**回文质数**是指既是质数又是回文数的整数。例如 151（质数且从左到右 / 右到左读均为 151）。

本文需解决的问题：在给定范围 `[a, b]`（`5 ≤ a < b ≤ 1e8`）内，找出所有回文质数并输出。

## 二、基础思路与原代码问题分析

### 2.1 基础思路

常规思路是对 `[a, b]` 内的每个数执行两步判断：

1. 是否为回文数（左右对称）；
2. 是否为质数（仅能被 1 和自身整除）。

### 2.2 原代码的缺陷（以用户初始代码为例）

cpp

```cpp
// 原代码核心逻辑（简化版）
for(long i=a;i<=b;i++){
    // 1. 判断是否为回文数
    string s=to_string(i);
    bool isPalin=true;
    for(int j=0;j<s.size()/2;j++){
        if(s[j]!=s[s.size()-1-j]){isPalin=false;}
    }
    // 2. 判断是否为质数
    if(isPalin && isPrime(i)){cout<<i<<endl;}
}
```

**问题分析**：

1. **效率极低**：
    - 对 `[a, b]` 内所有数逐个判断，当 `b=1e8` 时，循环次数达 1 亿次，耗时过长。
    - 质数判断未优化（如对偶数仍检查、因子遍历步长为 1）。
2. **回文判断冗余**：发现不对称后仍继续循环，未及时终止。
3. **未利用回文数特性**：忽略了 “偶数位回文数（除 11 外）必为合数” 的规律，无效计算过多。

## 三、关键优化：利用回文质数的数学特性

### 3.1 回文数的核心特性

- **偶数位回文数（除 11 外）必为合数**：
    
    例如 4 位回文数 `abba`（如 5225）可表示为 `11×(91a + 10b)`，必能被 11 整除，因此不是质数。
    
    （例外：11 是 2 位回文质数，因 `11=1×11`，无其他因子）。
- **质数的奇偶性**：除 2 外，所有质数都是奇数，因此回文质数（除 2 外）必为奇数。

### 3.2 优化策略

1. **缩小范围**：仅处理**奇数位回文数**（1、3、5、7 位）和 11，跳过其他偶数位回文数。
2. **优先生成回文数**：直接构造回文数（而非遍历所有数），再判断是否为质数（回文数数量远少于总数）。
3. **质数判断优化**：
    - 排除偶数（除 2 外）；
    - 因子检查仅需到 `√num`，且步长为 2（只查奇数）。

## 四、高效实现方案

### 4.1 回文数生成方法（按位数构造）

根据位数直接构造回文数，避免无效遍历：

- **1 位回文数**：`d`（`d=1-9`，仅奇数可能为质数：5、7）。
- **2 位回文数**：仅需检查 11（唯一可能为质数的 2 位回文数）。
- **3 位回文数**：`d1d2d1`（`d1=1-9` 奇数，`d2=0-9`），如 101、131。
- **5 位回文数**：`d1d2d3d2d1`（`d1=1-9` 奇数，`d2,d3=0-9`）。
- **7 位回文数**：`d1d2d3d4d3d2d1`（`d1=1-9` 奇数，`d2,d3,d4=0-9`）。

### 4.2 完整代码实现

cpp

```cpp
#include <iostream>
#include <string>
using namespace std;

// 优化的质数判断：排除偶数，仅检查奇数因子
bool isPrime(long num) {
    if (num < 2) return false;
    if (num == 2) return true;
    if (num % 2 == 0) return false; // 偶数直接排除
    for (long i = 3; i * i <= num; i += 2) { // 步长为2，检查奇数
        if (num % i == 0) return false;
    }
    return true;
}

// 生成所有可能的回文质数并检查范围
void findPalindromePrimes(long a, long b) {
    // 1位回文质数（5,7，因a≥5）
    for (int d = 5; d <= 9; d += 2) {
        long p = d;
        if (p >= a && p <= b && isPrime(p)) {
            cout << p << endl;
        }
    }

    // 2位回文质数（仅11）
    long p11 = 11;
    if (p11 >= a && p11 <= b && isPrime(p11)) {
        cout << p11 << endl;
    }

    // 3位回文数：d1 d2 d1
    for (int d1 = 1; d1 <= 9; d1 += 2) { // d1为奇数（避免偶数）
        for (int d2 = 0; d2 <= 9; d2++) {
            long p = d1 * 100 + d2 * 10 + d1;
            if (p > b) break; // 超出范围则停止
            if (p >= a && isPrime(p)) {
                cout << p << endl;
            }
        }
    }

    // 5位回文数：d1 d2 d3 d2 d1
    for (int d1 = 1; d1 <= 9; d1 += 2) {
        for (int d2 = 0; d2 <= 9; d2++) {
            for (int d3 = 0; d3 <= 9; d3++) {
                long p = d1 * 10000 + d2 * 1000 + d3 * 100 + d2 * 10 + d1;
                if (p > b) break;
                if (p >= a && isPrime(p)) {
                    cout << p << endl;
                }
            }
        }
    }

    // 7位回文数：d1 d2 d3 d4 d3 d2 d1（1亿内最大回文数）
    for (int d1 = 1; d1 <= 9; d1 += 2) {
        for (int d2 = 0; d2 <= 9; d2++) {
            for (int d3 = 0; d3 <= 9; d3++) {
                for (int d4 = 0; d4 <= 9; d4++) {
                    long p = d1 * 1000000 + d2 * 100000 + d3 * 10000 + d4 * 1000 + d3 * 100 + d2 * 10 + d1;
                    if (p > b) break;
                    if (p >= a && isPrime(p)) {
                        cout << p << endl;
                    }
                }
            }
        }
    }
}

int main() {
    long a, b;
    cin >> a >> b;
    findPalindromePrimes(a, b);
    return 0;
}
```

## 五、代码解析与效率对比

### 5.1 核心优化点

1. **回文数生成**：通过 “前半部分镜像” 直接构造回文数（如 3 位回文数由 `d1` 和 `d2` 生成），避免遍历非回文数。
2. **范围过滤**：仅生成 1、3、5、7 位回文数和 11，跳过其他偶数位回文数（必为合数）。
3. **质数判断**：排除偶数和不必要的因子检查，减少计算量。

### 5.2 效率对比

- **原方法**：对 1 亿个数逐个判断，回文数约 10 万个，但需先判断 1 亿个数是否为回文，再判断质数，耗时极长。
- **优化方法**：直接生成约 10 万个回文数（1 亿内），再判断质数，运算量减少 99% 以上，可处理 `b=1e8` 的极端情况。

## 七、总结

回文质数问题的核心是**利用数学特性减少无效计算**：

1. 偶数位回文数（除 11 外）必为合数，可直接跳过；
2. 优先生成回文数再判断质数，远高效于遍历所有数；
3. 质数判断需优化（排除偶数、步长为 2）以提升效率。
