# 网格矩形、正方形计数 完整笔记

## 一、基本前提

n 行，m 列方格网格

### 核心结论总览

1. **所有矩形总数（包含正方形）**
2. **正方形个数**
3. **纯长方形个数（不包含正方形）**

---

## 二、总矩形数量（含正方形）

### 1. 原理

一个矩形由 **2 条横线、2 条竖线** 唯一确定

- n 行方格 → 共 n+1 条横线
- m 列方格 → 共 m+1 条竖线

从横线里任选 2 条：组合数

Cn+12​=2n(n+1)​

从竖线里任选 2 条：组合数

Cm+12​=2m(m+1)​

**乘法原理**，两者相乘即为全部矩形：

总矩形

### 2. 代码写法

cpp

```
ll all = (ll)n * (n + 1) / 2 * m * (m + 1) / 2;
```

> 强制转 `long long` 防止 int 溢出！

---

## 三、正方形数量

### 1. 原理

按**边长分类统计**：

- 边长 1：n×m 个
- 边长 2：(n−1)×(m−1) 个
- 边长 3：(n−2)×(m−2) 个
    
    …
    
    直到边长不能再大为止，最大边长为 min(n,m)

求和公式：

正方形

### 2. 代码写法

cpp

```
ll square = 0;
int k_max = min(n, m);
for(int i = 1; i <= k_max; i++){
    square += (ll)(n - i + 1) * (m - i + 1);
}
```

---

## 四、纯长方形（严格不含正方形）

### 1. 原理

总矩形里面，去掉所有正方形，剩下的全是长方形。

长方形总矩形正方形

### 2. 代码写法

cpp

```
ll rect = all - square;
```

---

## 五、完整可直接运行 AC 代码

cpp

```
#include <iostream>
#include <algorithm>
using namespace std;
typedef long long ll;

int main()
{
    int n, m;
    cin >> n >> m;

    // 1. 计算所有矩形（含正方形）
    ll all = (ll)n * (n + 1) / 2 * m * (m + 1) / 2;

    // 2. 计算正方形个数
    ll square = 0;
    int k = min(n, m);
    for (int i = 1; i <= k; i++)
    {
        square += (ll)(n - i + 1) * (m - i + 1);
    }

    // 3. 纯长方形 = 总矩形 - 正方形
    ll rect = all - square;

    cout << square << " " << rect << endl;
    return 0;
}
```

## 七、易错点总结（笔记必记）

1. **必须用 long long**
    
    n,m 稍大数值就会爆 int，所有计数变量都开 `ll`。
2. 矩形公式是**横线竖线组合**，不是格子直接乘。
3. 正方形是**按边长累加**，没有统一简便公式，只能循环求和。
4. 题目问**长方形**，默认**不包含正方形**，一律用 `总矩形-正方形`。
