# C++ 指针与数组的关联（黑马教程 P45 笔记）

## 一、核心关联：数组名本质是指针

数组名在大多数情况下会被隐式转换为**指向数组首元素的常量指针**，这是指针与数组关联的核心基础。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    
    // 数组名 == 数组首元素的地址
    cout << "数组名arr：" << arr << endl;         // 输出首元素地址（如0x7ffd5a5b58c0）
    cout << "首元素地址&arr[0]：" << &arr[0] << endl;  // 与arr值相同
    
    return 0;
}
```

> 关键特性：
> 
> - 数组名是**常量指针**，不能被重新赋值（如`arr = p;`会报错）
> - 数组名代表的是首元素的地址，而非整个数组的地址（特殊场景如`sizeof(arr)`除外）

## 二、通过指针操作数组元素

利用数组名与指针的关联性，可通过指针灵活访问和修改数组元素，常见方式有以下四种：

|访问方式|说明|
|---|---|
|`arr[i]`|数组名 + 下标（最常用）|
|`p[i]`|指针变量 + 下标|
|`*(arr + i)`|数组名 + 偏移量（指针运算）|
|`*(p + i)`|指针变量 + 偏移量（指针运算）|

### 示例代码

cpp

运行

```cpp
int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    int* p = arr;  // 指针p指向数组首元素（等价于p = &arr[0]）
    
    // 四种方式访问第3个元素（i=2）
    cout << "arr[2] = " << arr[2] << endl;        // 3
    cout << "p[2] = " << p[2] << endl;            // 3
    cout << "*(arr + 2) = " << *(arr + 2) << endl;  // 3
    cout << "*(p + 2) = " << *(p + 2) << endl;    // 3
    
    return 0;
}
```

## 三、指针遍历数组

通过指针自增（`p++`）移动指针位置，可高效遍历数组元素，本质是利用指针的偏移特性。

cpp

运行

```cpp
int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    int* p = arr;
    int len = sizeof(arr) / sizeof(arr[0]);  // 计算数组长度
    
    // 指针遍历数组
    for (int i = 0; i < len; i++) {
        cout << *p << " ";  // 输出当前指针指向的元素
        p++;  // 指针向后移动1个int元素（偏移4字节）
    }
    // 输出结果：1 2 3 4 5
    
    return 0;
}
```

> 原理：`p++` 会使指针按**元素类型大小**偏移（int 占 4 字节则偏移 4 字节），保证每次指向一个完整元素。

## 四、指针的算术运算

指针的算术运算与普通变量不同，运算结果与**元素类型大小**相关（而非简单的字节偏移）。

### 常见运算规则

1. `p + n`：指针向后偏移`n`个元素（实际偏移字节数 = `n * sizeof(元素类型)`）
2. `p - n`：指针向前偏移`n`个元素
3. `p2 - p1`：两个指针之间相差的**元素个数**（需指向同一数组才有效）

### 示例代码

cpp

运行

```cpp
int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    int* p = arr;  // 指向arr[0]
    
    cout << "初始p指向：" << *p << endl;  // 1
    p += 2;  // 向后偏移2个元素（指向arr[2]）
    cout << "p+2后指向：" << *p << endl;  // 3
    
    int* p1 = &arr[0];
    int* p2 = &arr[3];
    cout << "p2 - p1 = " << p2 - p1 << endl;  // 3（相差3个元素）
    
    return 0;
}
```

## 五、注意事项与易错点

1. **指针越界风险**
    
    指针偏移不能超过数组范围，否则会访问无效内存（可能导致程序崩溃或数据错误）：
    
    cpp
    
    运行
    
    ```cpp
    // 错误示例：越界访问
    int arr[5] = {1,2,3,4,5};
    int* p = arr;
    for (int i = 0; i <= 5; i++) {  // i=5时访问arr[5]（越界）
        cout << *p++ << endl;
    }
    ```
    
2. **数组名与指针的区别**
    
    - 数组名是**常量指针**，不能执行自增 / 自减（`arr++` 错误）
    - 指针变量是**变量**，可以执行自增 / 自减（`p++` 正确）
3. **sizeof 的差异**
    
    - `sizeof(arr)` 计算**整个数组的总字节数**
    - `sizeof(p)` 计算**指针变量本身的字节数**（64 位系统通常为 8 字节）
    
    cpp
    
    运行
    
    ```cpp
    cout << sizeof(arr) << endl;  // 20（5×4字节）
    cout << sizeof(p) << endl;    // 8（指针大小）
    ```
    

## 六、总结

1. 数组名本质是指向首元素的**常量指针**，是指针与数组关联的核心
2. 访问数组元素的四种等价方式：`arr[i]`、`p[i]`、`*(arr+i)`、`*(p+i)`
3. 指针算术运算以**元素个数**为单位，偏移字节数 = 元素个数 × 类型大小
4. 遍历数组时需避免指针越界，区分数组名（常量）与指针变量（可修改）的特性

通过指针操作数组是 C++ 的重要特性，合理使用可提高数组处理的灵活性和效率，尤其在函数传参和动态数组操作中应用广泛。

# C++ 数组元素逆置案例（基于指针实现）

## 案例需求

将一个 int 类型数组的元素逆序排列（如原数组`{1,2,3,4,5}`逆置后变为`{5,4,3,2,1}`），要求使用**指针**操作实现，而非数组下标。

## 实现思路

1. **定义首尾指针**：用两个指针分别指向数组的第一个元素和最后一个元素
2. **交换元素**：通过指针解引用交换首尾指针指向的元素
3. **移动指针**：首指针向后移动（`start++`），尾指针向前移动（`end--`）
4. **循环终止条件**：当首指针超过尾指针（`start >= end`）时，停止循环

## 代码实现

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. 定义原数组
    int arr[] = {1, 2, 3, 4, 5, 6};
    int len = sizeof(arr) / sizeof(arr[0]);  // 计算数组长度
    
    // 2. 定义首尾指针
    int* start = arr;                  // 首指针指向数组第一个元素（等价于 &arr[0]）
    int* end = arr + len - 1;          // 尾指针指向数组最后一个元素（首地址+长度-1）
    
    // 3. 循环交换元素
    while (start < end) {
        // 交换首尾指针指向的元素
        int temp = *start;
        *start = *end;
        *end = temp;
        
        // 移动指针（向中间靠拢）
        start++;  // 首指针后移
        end--;    // 尾指针前移
    }
    
    // 4. 打印逆置后的数组
    cout << "逆置后的数组：";
    for (int i = 0; i < len; i++) {
        cout << arr[i] << " ";
    }
    // 输出结果：逆置后的数组：6 5 4 3 2 1 
    
    return 0;
}
```

## 关键代码解析

1. **指针初始化**
    
    cpp
    
    运行
    
    ```cpp
    int* start = arr;              // 首指针指向数组开头（arr等价于&arr[0]）
    int* end = arr + len - 1;      // 尾指针计算：首地址 + 元素个数 - 1（指向最后一个元素）
    ```
    
2. **交换逻辑**
    
    - `*start`：通过首指针解引用，获取当前首元素的值
    - `*end`：通过尾指针解引用，获取当前尾元素的值
    - 利用临时变量`temp`完成交换
3. **指针移动**
    
    - `start++`：首指针向后偏移 1 个元素（指向后一个元素）
    - `end--`：尾指针向前偏移 1 个元素（指向前一个元素）
4. **循环终止条件**
    
    - 当`start >= end`时，说明所有元素已完成逆置（中间元素无需交换）

## 为什么用指针实现？

1. **效率更高**：指针直接操作内存地址，无需通过下标计算偏移量
2. **灵活性强**：在函数传参等场景中，指针可直接操作原数组（避免数组拷贝）
3. **体现指针特性**：数组名本质是常量指针，通过指针操作更贴合数组在内存中的存储逻辑

## 注意事项

1. **避免越界**：尾指针初始化时需确保`arr + len - 1`不超过数组范围（依赖正确计算的`len`）
2. **指针移动顺序**：必须先交换元素，再移动指针（若先移动会导致元素访问错误）
3. **适用范围**：该逻辑同样适用于其他类型数组（如`double`、`char`），只需修改指针类型

## 总结

- 核心逻辑：首尾指针向中间靠拢，逐个交换对应元素
- 指针优势：直接操作内存，效率高，适合处理大型数组
- 扩展思路：可封装为函数（如`void reverseArray(int* arr, int len)`），实现通用数组逆置功能
