

## 一、问题描述

**题目**：扫雷游戏中，给定一个 `n` 行 `m` 列的雷区，其中 `*` 表示地雷格，`?` 表示非地雷格。要求计算每个非地雷格周围 8 个方向（上、下、左、右、左上、右上、左下、右下）的地雷数量，并输出整个雷区（地雷格仍用 `*` 表示，非地雷格用周围地雷数表示）。

**输入**：

- 第一行：两个整数 `n` 和 `m`（雷区的行数和列数）。
- 接下来 `n` 行：每行 `m` 个字符，描述雷区（`*` 或 `?`）。

**输出**：

- `n` 行：每行 `m` 个字符，地雷格用 `*` 表示，非地雷格用周围地雷数表示。

## 二、解决代码

cpp

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    // 1. 正确初始化二维vector（n行m列），避免容器类型错误
    vector<vector<char>> minefield(n, vector<char>(m));

    // 2. 先完整读取雷区数据，避免边读边处理导致的未初始化数据访问
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            cin >> minefield[i][j];
        }
    }

    // 3. 定义8个方向的偏移量，简化相邻格子坐标计算
    int directions[8][2] = {
        {-1, -1}, {-1, 0}, {-1, 1},  // 上左、上、上右
        {0, -1},          {0, 1},    // 左、右
        {1, -1},  {1, 0}, {1, 1}     // 下左、下、下右
    };

    // 4. 遍历每个格子计算结果并输出
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            if (minefield[i][j] == '*') {
                // 地雷格直接输出'*'
                cout << '*';
            } else {
                // 非地雷格：统计周围地雷数（解决num作用域和初始化错误）
                int mine_count = 0;  // 在方向循环外初始化，确保累计8个方向的计数
                for (auto& dir : directions) {
                    int x = i + dir[0];  // 相邻格子的行坐标
                    int y = j + dir[1];  // 相邻格子的列坐标

                    // 边界检查：确保相邻格子在雷区范围内（避免越界访问）
                    if (x >= 0 && x < n && y >= 0 && y < m) {
                        if (minefield[x][y] == '*') {
                            mine_count++;  // 累加地雷数
                        }
                    }
                }
                // 将数字转换为字符输出（如1→'1'）
                cout << (char)('0' + mine_count);
            }
        }
        // 每行结束后换行（解决输出格式错误）
        cout << endl;
    }

    return 0;
}
```

## 三、代码与笔记对应分析（解决的错误点）

结合之前的错误分析笔记，代码中针对性解决了以下问题：

|错误类型|代码中如何避免|
|---|---|
|二维容器定义错误|使用 `vector<vector<char>> minefield(n, vector<char>(m))` 定义二维容器，支持 `[i][j]` 访问，避免一维容器或初始化格式错误。|
|`num` 作用域错误|将计数器 `mine_count` 定义在方向循环**外部**（`else` 块内），确保遍历 8 个方向时能累计计数，而非每次循环重置。|
|`num` 未声明 / 初始化|显式声明 `int mine_count = 0`，在使用前完成初始化，避免未定义变量错误。|
|边读边处理数据|先通过嵌套循环完整读取所有雷区数据到 `minefield`，再遍历处理，确保计算时所有格子数据已初始化。|
|输出未换行|在每行的内层循环（`j` 循环）结束后添加 `cout << endl`，保证输出为 `n` 行 `m` 列的正确格式。|
|越界访问|通过 `x >= 0 && x < n && y >= 0 && y < m` 检查相邻格子是否在雷区范围内，避免访问无效内存。|

## 四、示例验证

**输入**：

plaintext

```plaintext
3 3
*??
???
?*?
```

**输出**：

plaintext

```plaintext
*10
221
1*1
```

**解析**：

- 左上角 `*` 是地雷，直接输出。
- 坐标 `(0,1)` 周围有 1 个地雷（左上角），输出 `1`。
- 坐标 `(1,1)` 周围有 2 个地雷（左上角和右下角），输出 `2`。
    
    结果完全符合扫雷游戏规则，代码正确。
