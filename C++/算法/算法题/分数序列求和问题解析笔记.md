
#### 一、问题描述

有一个分数序列：\(\frac{q_1}{p_1}, \frac{q_2}{p_2}, \frac{q_3}{p_3}, ...\)，其中：

- 初始值：\(p_1 = 1, q_1 = 2\)
- 递推关系：\(q_{i+1} = q_i + p_i\)，\(p_{i+1} = q_i\)

例如，序列前 6 项为：\(\frac{2}{1}, \frac{3}{2}, \frac{5}{3}, \frac{8}{5}, \frac{13}{8}, \frac{21}{13}\)。

**任务**：输入一个正整数n（\(n \leq 30\)），计算该序列前n项的和，精确到小数点后 4 位。

#### 二、序列规律分析

通过递推关系推导前几项，可发现序列的规律：

- \(i=1\)：\(p_1=1\)，\(q_1=2\) → 项为 \(\frac{2}{1}\)
- \(i=2\)：\(p_2=q_1=2\)，\(q_2=q_1+p_1=3\) → 项为 \(\frac{3}{2}\)
- \(i=3\)：\(p_3=q_2=3\)，\(q_3=q_2+p_2=5\) → 项为 \(\frac{5}{3}\)
- \(i=4\)：\(p_4=q_3=5\)，\(q_4=q_3+p_3=8\) → 项为 \(\frac{8}{5}\)

可见，p和q的取值与斐波那契数列类似，均通过前两项累加得到，这为递推计算提供了基础。

#### 三、解题思路

1. **初始化**：设定初始值\(p_1=1\)，\(q_1=2\)，并计算第一项的数值\(\frac{q_1}{p_1}\)，加入总和。
2. **递推计算**：从第 2 项到第n项，通过递推关系计算每一项的\(p_i\)和\(q_i\)：
    - \(p_i = q_{i-1}\)（当前p等于前一项的q）
    - \(q_i = q_{i-1} + p_{i-1}\)（当前q等于前一项的q与p之和）
3. **累加求和**：将每一项\(\frac{q_i}{p_i}\)转换为浮点数后累加至总和。
4. **精度控制**：输出总和时保留 4 位小数。

#### 四、C++ 代码实现

cpp

运行

```cpp
#include <iostream>
#include <iomanip>  // 用于控制输出精度
using namespace std;

int main() {
    int n;
    cin >> n;  // 读取输入的n
    
    double sum = 0.0;  // 存储总和
    int p_prev = 1, q_prev = 2;  // 初始化p1和q1
    
    // 累加第一项
    sum += static_cast<double>(q_prev) / p_prev;
    
    // 循环计算第2项到第n项
    for (int i = 2; i <= n; ++i) {
        int current_p = q_prev;  // p_i = q_{i-1}
        int current_q = q_prev + p_prev;  // q_i = q_{i-1} + p_{i-1}
        
        // 累加当前项（转换为浮点数除法）
        sum += static_cast<double>(current_q) / current_p;
        
        // 更新前项值，用于下一次循环
        p_prev = current_p;
        q_prev = current_q;
    }
    
    // 输出结果，固定保留4位小数
    cout << fixed << setprecision(4) << sum << endl;
    
    return 0;
}
```

#### 五、代码解析

1. **头文件**：`#include <iomanip>` 用于`setprecision`控制输出精度。
2. **变量初始化**：
    - `p_prev`和`q_prev`分别存储上一项的p和q，初始值为\(p_1=1\)和\(q_1=2\)。
    - `sum`用于累加总和，初始化为 0.0。
3. **第一项处理**：直接计算\(\frac{q_1}{p_1}\)并加入总和。
4. **循环逻辑**（i从 2 到n）：
    - 根据递推公式计算当前项的p（`current_p`）和q（`current_q`）。
    - 将当前项\(\frac{current_q}{current_p}\)转换为浮点数（`static_cast<double>`）后累加。
    - 更新`p_prev`和`q_prev`为当前项的值，供下一次循环使用。
5. **输出控制**：`fixed << setprecision(4)`确保结果保留 4 位小数。


#### 七、注意事项

1. **浮点数除法**：必须使用`static_cast<double>`将整数转换为浮点数，否则会执行整数除法（丢失小数部分）。
2. **数据类型**：\(n \leq 30\)时，p和q的最大值约为斐波那契数列第 30 项（约 83 万），使用`int`类型即可避免溢出。
3. **精度控制**：`fixed`与`setprecision(4)`配合使用，确保输出恰好保留 4 位小数。
