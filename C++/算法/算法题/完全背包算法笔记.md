
# 完全背包 · 采药问题 笔记

## 📌 题目来源
LiYuxiang 采药（完全背包版本）

## 📝 题意简述
- 总时间 `t`，草药种类 `m`。
- 第 `i` 种草药：采摘耗时 `a_i`，价值 `b_i`。
- **每种草药可无限采摘**（完全背包）。
- 目标：在规定时间内使总价值最大。

## 📊 数据范围
| 变量 | 范围 |
|------|------|
| `m` | 1 ≤ m ≤ 10⁴ |
| `t` | 1 ≤ t ≤ 10⁷ |
| `m × t` | ≤ 10⁷ |
| `a_i, b_i` | 1 ≤ 10⁴ |

> ⚠️ 最大价值约 `t × max(b_i) ≈ 10¹¹`，**必须用 `long long`**！

## 🧠 算法思路
### 状态定义
`dp[j]` = 时间 **恰好为 j** 时的最大总价值。

### 状态转移（完全背包）
对于每种草药 `(a, b)`，**正序**更新：
```
for j = a → t:
    dp[j] = max(dp[j], dp[j - a] + b)
```

### 为什么要正序？
- 完全背包允许同种物品选多次。
- 正序确保 `dp[j-a]` 可能已包含当前物品，实现重复选取。
- 若倒序，则退化为 0/1 背包（每物品限一次）。

### 初始化
`dp[0] = 0`，其余 `dp[j] = 0`（不要求必须装满，允许部分空闲时间）。

### 答案
`dp[t]`

## ⏱ 复杂度分析
- **时间**：`O(mt)`，最大约 10⁷ → 可接受。
- **空间**：`O(t)`，`long long` 数组约 80 MB（`10⁷ * 8B`）。

## 💻 参考代码（C++）
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t, m;
    cin >> t >> m;

    vector<long long> dp(t + 1, 0);  // 注意 long long

    for (int i = 0; i < m; ++i) {
        int a, b;
        cin >> a >> b;
        for (int j = a; j <= t; ++j) {
            dp[j] = max(dp[j], dp[j - a] + b);
        }
    }

    cout << dp[t] << "\n";
    return 0;
}
```

## 🧪 样例验证
输入：
```
70 3
71 100
69 1
1 2
```

运行过程：
1. 草药 `(71, 100)`：j 从 71 开始，但 t=70，无更新。
2. 草药 `(69, 1)`：更新 `dp[69]=1`, `dp[70]=1`。
3. 草药 `(1, 2)`：完全背包，摘 70 个耗时 1 的草药，`dp[70]=140`。

输出：
```
140
``` ✅

## 💡 易错提醒
- **必须 `long long`**，否则会溢出。
- **正序循环** → 完全背包；倒序 → 0/1 背包，别混淆！
- 输入量大时，用 `ios::sync_with_stdio(false);` 加速。
- `m × t ≤ 10⁷` 保证不会超时，但注意 `vector` 可能需在堆上分配，注意内存限制。
