

## 一、问题描述

某校大门外有一条长度为 `l` 米的马路，可视为数轴（一端在 `0`，另一端在 `l`）。数轴上的每个整数点（`0, 1, 2, ..., l`）均种有一棵树，初始树木总数为 `l + 1`（包含两端点）。

现需移除若干区域内的树木（区域用起始坐标 `u` 和终止坐标 `v` 表示，包含端点），且区域间可能重叠。要求计算移除树木后，马路上剩余的树木数量。

### 输入输出说明

- **输入**：第一行含两个整数 `l`（马路长度）和 `m`（移树区域数目）；后续 `m` 行，每行含两个整数 `u`、`v`（区域的起始和终止坐标，满足 `0 ≤ u ≤ v ≤ l`）。
- **输出**：一行整数，代表剩余树木数量。

### 示例（Sample 1）

plaintext

```plaintext
输入：
500 3
150 300
100 200
470 471
输出：298
```

## 二、核心思路

采用 **标记法** 记录每个树木位置的状态，核心逻辑如下：

1. 用数组存储每个坐标点的树木状态（`1` 表示树木存在，`0` 表示树木被移除）；
2. 初始时所有位置标记为 `1`（默认所有树木存在）；
3. 根据输入的移树区域，将对应区间内的数组元素标记为 `0`（标记移除）；
4. 遍历数组，统计标记为 `1` 的元素个数，即为剩余树木数量。

该思路可自然处理区域重叠问题（重复标记 `0` 不影响最终结果），且逻辑直观、易实现。

## 三、解题步骤

### 步骤 1：计算初始树木总数

马路从 `0` 到 `l` 共 `l + 1` 个整数点，因此初始树木总数为 `l + 1`（例如 `l=5` 时，坐标 `0~5` 共 6 棵树）。

### 步骤 2：初始化标记数组

- 数组大小：因 `l` 最大为 `10^4`（题目数据范围），需创建大小为 `10001` 的数组（覆盖 `0~10000` 所有坐标，避免越界）。
- 初始值：将数组所有元素设为 `1`，表示初始时所有位置均有树木。

### 步骤 3：标记被移除的树木

对每个移树区域 `[u, v]`，遍历区间内所有坐标（`j` 从 `u` 到 `v`），将 `tree[j]` 设为 `0`，标记该位置树木被移除。

### 步骤 4：统计剩余树木

遍历数组 `0~l` 区间，累加值为 `1` 的元素个数，结果即为剩余树木数量。

## 四、代码实现与解析

### 完整代码（C++）

cpp

```cpp
#include <iostream>
using namespace std;

int main() {
    int l, m;
    cin >> l >> m;  // 读取马路长度l和区域数目m

    // 初始化标记数组：大小10001（覆盖0~10000），初始全0后手动设为1
    int tree[10001] = {0};
    for (int i = 0; i <= l; ++i) {
        tree[i] = 1;  // 1表示树木存在
    }

    // 处理每个移树区域
    for (int i = 0; i < m; ++i) {
        int u, v;
        cin >> u >> v;  // 读取区域的起始和终止坐标
        // 标记区间[u, v]内的树木为移除（设为0）
        for (int j = u; j <= v; ++j) {
            tree[j] = 0;
        }
    }

    // 统计剩余树木（值为1的位置）
    int remaining = 0;
    for (int j = 0; j <= l; ++j) {
        remaining += tree[j];  // 1累加计数，0不贡献
    }

    cout << remaining << endl;
    return 0;
}
```

### 代码解析

1. **数组初始化**：
    
    - `int tree[10001] = {0};`：创建大小为 `10001` 的数组，初始值全为 `0`（C++ 中数组初始化列表未覆盖的元素默认为 `0`）。
    - 循环 `for (int i = 0; i <= l; ++i) tree[i] = 1;`：将 `0~l` 区间的元素设为 `1`，确保仅标记马路范围内的树木（超出 `l` 的位置无需处理）。
2. **区域处理**：
    
    - 外层循环 `for (int i = 0; i < m; ++i)`：遍历 `m` 个移树区域。
    - 内层循环 `for (int j = u; j <= v; ++j)`：直接遍历当前区域 `[u, v]`，避免遍历整个 `0~l` 区间，提升效率（尤其当 `l` 较大时）。
3. **统计逻辑**：
    
    - 利用 `remaining += tree[j]` 简化计数：`tree[j]` 为 `1` 时累加 `1`（计数），为 `0` 时累加 `0`（不计数），代码更简洁。

## 五、复杂度分析

### 时间复杂度

- 数组初始化：`O(l)`（遍历 `0~l` 共 `l+1` 个元素）。
- 区域处理：`O(m*k)`，其中 `k` 为单个区域的平均长度（最大为 `l`），最坏情况下为 `O(m*l)`。
- 统计剩余树木：`O(l)`（遍历 `0~l` 区间）。

综合最坏时间复杂度为 `O(l + m*l)`，因题目数据范围限制（`l ≤ 10^4`，`m ≤ 100`），最坏总操作量为 `10^4 + 100*10^4 = 1.01*10^6`，远低于计算机处理极限，运行高效。

### 空间复杂度

- 仅使用大小为 `10001` 的数组（固定大小），空间复杂度为 `O(1)`（不随输入规模变化），内存占用极低。

## 六、补充说明

### 关于 “反向标记”

除了 “`1` 表示存在，`0` 表示移除”，也可采用 “`1` 表示移除，`0` 表示存在” 的反向标记逻辑（如之前用户尝试的代码），核心思路一致：

1. 数组初始全为 `0`（表示存在）；
2. 移树区域标记为 `1`（表示移除）；
3. 统计值为 `0` 的元素个数。

两种标记方式均正确，关键是确保 “标记含义” 在整个流程中保持一致（初始化、标记、统计逻辑匹配）。

### 边界处理注意事项

- 数组大小必须覆盖 `0~10000`：因 `l` 最大为 `10^4`，需确保 `tree[10000]` 是合法索引（避免越界）。
- 循环范围包含 `l`：统计和初始化时需遍历 `0~l`（而非 `0~l-1`），避免漏掉 `l` 位置的树木。
