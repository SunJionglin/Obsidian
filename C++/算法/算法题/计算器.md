### Description

一个最简单的计算器，支持 `+,-,*,/` 四种运算。仅需考虑输入输出为整数的情况，数据和运算结果不会超过 `int` 表示的范围。然而：

1. 如果出现除数为 00 的情况，则输出：`Divided by zero!`。
    
2. 如果出现无效的操作符（即不为 `+,-,*,/` 之一），则输出：`Invalid operator!`。
    
3. 除号表示整除，结果向 0 取整。
    

### Input

输入只有一行，共有三个参数，其中第 1,2 个参数为整数，第 3 个参数为操作符`（+,-,*,/）`。

### Output

输出只有一行，一个整数，为运算结果。然而：

1. 如果出现除数为 00 的情况，则输出：`Divided by zero!`。
    
2. 如果出现无效的操作符（即不为 `+,-,*,/` 之一），则输出：`Invalid operator!`。



3. **输入处理**：
    
    - 程序读取两个整数 `a`、`b` 和一个操作符 `op`
    - 输入格式为：整数 整数 操作符（如 "1 2 +"）
4. **运算逻辑**：
    
    - 使用 `switch` 语句根据操作符执行相应运算
    - `+`：输出 `a + b` 的结果
    - `-`：输出 `a - b` 的结果
    - `*`：输出 `a * b` 的结果
    - `/`：输出 `a / b` 的结果（整除，向 0 取整）
5. **特殊情况处理**：
    
    - 当操作符为 `/` 且除数 `b` 为 0 时，输出 "Divided by zero!"
    - 当操作符不是 `+`、`-`、`*`、`/` 中的任何一个时，输出 "Invalid operator!"
6. **示例验证**：
    
    - 输入 "1 2 +" 输出 3（符合样例 1）
    - 输入 "2 4 *" 输出 8（符合样例 2）
    - 输入 "5 0 /" 输出 "Divided by zero!"（符合样例 3）
