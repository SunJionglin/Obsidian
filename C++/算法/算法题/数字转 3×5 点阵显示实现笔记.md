

## 一、问题描述

### 需求

将输入的数字字符串（长度不超过 100）转换为液晶屏风格的点阵显示效果。每个数字用 3×5 的点阵表示（`X`为亮点，`.`为暗点），数字之间用一列`.`间隔，最终输出 5 行字符串。

### 输入

- 第一行：数字位数`n`（1≤n≤100）
- 第二行：长度为`n`的数字字符串（如 "0123456789"）

### 输出

5 行字符串，对应数字的点阵显示效果（每个数字占 3 列，间隔占 1 列）。

## 二、解题思路

核心思路是 **“预先定义点阵 + 按行拼接”**，步骤如下：

1. **定义数字点阵**：为 0-9 每个数字预设 3×5 的点阵（5 行，每行 3 个字符）。
2. **读取输入**：获取数字位数和数字字符串。
3. **按行构建输出**：
    - 外层循环控制 5 行（每行对应所有数字的同一行点阵）。
    - 内层循环遍历每个数字，提取该数字对应行的点阵，拼接后添加间隔（最后一个数字无间隔）。
4. **输出 5 行结果**：每行拼接完成后整体输出。

## 三、核心代码实现
==重点该代码在值与最后一值相同时'.'的输出会混淆==

cpp

运行

```cpp
#include<iostream>
#include<string>
using namespace std;

int main()
{
    // 1. 定义0-9的3×5点阵（num[数字][行号] = 该行的3个字符）
    string num[10][5] = 
    {
        {"XXX", "X.X", "X.X", "X.X", "XXX"},  // 0
        {"..X", "..X", "..X", "..X", "..X"},  // 1
        {"XXX", "..X", "XXX", "X..", "XXX"},  // 2
        {"XXX", "..X", "XXX", "..X", "XXX"},  // 3
        {"X.X", "X.X", "XXX", "..X", "..X"},  // 4
        {"XXX", "X..", "XXX", "..X", "XXX"},  // 5
        {"XXX", "X..", "XXX", "X.X", "XXX"},  // 6
        {"XXX", "..X", "..X", "..X", "..X"},  // 7
        {"XXX", "X.X", "XXX", "X.X", "XXX"},  // 8
        {"XXX", "X.X", "XXX", "..X", "XXX"}   // 9
    };

    // 2. 读取输入
    int n;
    string N;
    cin >> n >> N;

    // 3. 按行拼接并输出
    for(int row = 0; row < 5; row++)  // 遍历5行（0-4）
    {
        for(char c : N)  // 遍历每个数字字符
        {
            int digit = c - '0';  // 字符转数字（如'3'→3）
            cout << num[digit][row];  // 输出当前数字的第row行点阵

            // 非最后一个数字，添加间隔
            if(c != N.back())  
            {
                cout << '.';
            }
        }
        cout << endl;  // 一行所有数字处理完后换行
    }

    return 0;
}
```

## 四、关键逻辑解析

### 1. 数字点阵定义（核心数据）

`string num[10][5]` 是预设的点阵数据，结构说明：

- 第一维索引：数字（0-9）
- 第二维索引：行号（0-4，共 5 行）
- 存储内容：每行 3 个字符（`X`或`.`），表示该数字在该行的显示效果。

例如：

- `num[0][0] = "XXX"` 表示数字 0 的第 0 行是 "XXX"；
- `num[1][4] = "..X"` 表示数字 1 的第 4 行是 "..X"。

### 2. 输入处理

- `cin >> n >> N` 读取数字位数和数字字符串（`N`为输入的数字序列，如 "0123456789"）。

### 3. 行拼接逻辑（核心循环）

#### 外层循环（控制行）

`for(int row = 0; row < 5; row++)`：遍历 5 行，每次处理所有数字的第`row`行点阵。

#### 内层循环（处理每个数字）

`for(char c : N)`：遍历数字字符串中的每个字符，步骤如下：

1. **字符转数字**：`c - '0'` 将字符（如 '5'）转换为对应的整数（5），用于索引点阵数组。
2. **输出当前行点阵**：`cout << num[digit][row]` 输出该数字第`row`行的 3 个字符。
3. **添加间隔**：若当前数字不是最后一个（`c != N.back()`），输出`.`作为间隔（最后一个数字后无间隔）。

#### 换行时机

每行所有数字的对应行点阵拼接完成后，通过`cout << endl`换行，确保最终输出 5 行。

### 4. 关键细节

- **间隔规则**：数字间必须有 1 列`.`，但最后一个数字后无间隔（通过`N.back()`判断是否为最后一个字符）。
- **点阵尺寸**：每个数字固定占 3 列，间隔占 1 列，因此 n 个数字的总列数为 `n×3 + (n-1)×1`（如 2 个数字占 3+1+3=7 列）。

## 六、总结

该方法通过**预先定义点阵数据**和**按行拼接逻辑**，高效实现了数字到 3×5 点阵的转换。核心优势：

1. 点阵数据直观易懂，便于维护和修改；
2. 循环结构清晰，外层控制行、内层处理数字，符合 “逐行显示” 的逻辑；
3. 间隔处理精准，通过`N.back()`确保格式正确。

适用于所有需要将数字转换为固定点阵显示的场景（如液晶屏模拟、字符画生成等）。
