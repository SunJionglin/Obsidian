任意输入一个字符，判断其 ASCII 是否是奇数，若是，输出 YES，否则，输出 NO 。 例如，字符 A 的 ASCII 值是 65，则输出 YES，若输入字符 B(ASCII 值是 66 66)，则输出 NO。 Input 输入一个字符。 Output 如果其 ASCII 值为奇数，则输出 YES，否则，输出 NO。

cpp

```cpp
#include <iostream>
int main() {
    char ch;
    std::cin >> ch;
    // 获取字符的ASCII码值并判断是否为奇数
    if ((int)ch % 2 != 0) {
        std::cout << "YES" << std::endl;
    } else {
        std::cout << "NO" << std::endl;
    }
    return 0;
}
```

逐行解释：

1. `#include <iostream>`：这是一个预处理指令，包含了输入输出流的库文件。在 C++ 中，如果要使用输入输出功能，比如从控制台读取数据（`cin`）或者向控制台输出数据（`cout`），就需要包含这个头文件。
2. `int main()`：这是程序的入口函数，每个 C++ 程序都必须有一个`main`函数。程序从这里开始执行。
3. `char ch;`：声明了一个字符类型的变量`ch`，用于存储从控制台输入的字符。
4. `std::cin >> ch;`：`std::cin` 是输入流对象，`>>` 是输入运算符。这句话的作用是从控制台读取一个字符，并将其存储到变量`ch`中。
5. `if ((int)ch % 2 != 0)`：==这里先将字符`ch`强制转换为`int`类型，因为字符在内存中是以 ASCII 码值存储的，强制转换后就可以得到其对应的整数值。==然后使用取模运算符`%`判断这个整数值是否为奇数。如果余数不为 0，说明是奇数。
6. `std::cout << "YES" << std::endl;`：如果上述条件成立，即字符的 ASCII 码值是奇数，就通过`std::cout`向控制台输出字符串`"YES"`，`<<`是输出运算符，`std::endl`表示换行。
7. `else`：如果`if`条件不成立，即字符的 ASCII 码值是偶数，就执行`else`后面的语句。
8. `std::cout << "NO" << std::endl;`：输出字符串`"NO"`并换行。
9. `return 0;`：`main`函数执行结束，返回 0 表示程序正常结束。在 C++ 中，`main`函数返回 0 是一种约定俗成的表示程序成功运行的方式。
