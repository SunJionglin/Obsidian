

## 一、问题概述

- **问题场景**：火车站的桥可旋转 180 度交换相邻两节车厢，需通过这种交换将车厢按编号从小到大排序，求最少旋转次数。
- **核心本质**：每次旋转只能交换相邻元素，因此排序所需的最少旋转次数 = 序列中**逆序对的总数**。
    - 逆序对定义：对于序列中两个元素，若位置靠前的元素值 > 位置靠后的元素值（即 `i < j 且 arr[i] > arr[j]`），则构成一个逆序对。

## 二、解法一：双重循环直接统计逆序对

### 1. 方法思路

- 对每个元素 `arr[i]`（作为 “位置靠前的元素”），遍历它后面所有元素 `arr[j]`（`j > i`，作为 “位置靠后的元素”）。
- 若 `arr[i] > arr[j]`，则计数加 1（统计为一个逆序对）。
- 最终计数结果即为最少旋转次数。

### 2. 代码实现（C++）

cpp

运行

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int N;
    cin >> N;
    vector<int> arr(N);
    for (int i = 0; i < N; i++) {
        cin >> arr[i];
    }
    
    int count = 0;
    // 外层循环：遍历每个“位置靠前的元素”
    for (int i = 0; i < N; i++) {
        // 内层循环：遍历当前元素后面的所有“位置靠后的元素”
        for (int j = i + 1; j < N; j++) {
            if (arr[i] > arr[j]) {
                count++; // 统计逆序对
            }
        }
    }
    
    cout << count << endl;
    return 0;
}
```

### 3. 优缺点分析

- **优点**：
    - 逻辑简单直观，易于理解和实现（适合初学者）。
    - 无需复杂的数据结构或算法基础。
- **缺点**：
    - 时间复杂度为 `O(n²)`（双重循环遍历），当 `n` 接近 10000 时，可能因操作次数过多（约 1 亿次）超时。
- **适用场景**：数据规模较小（如 `n ≤ 1000`）时使用。

## 三、解法二：归并排序法统计逆序对

### 1. 方法思路

- 利用**归并排序**的分治思想，在排序过程中同步统计逆序对：
    1. 递归将序列分为左右两个子数组，分别统计子数组内部的逆序对。
    2. 合并两个有序子数组时，统计 “左子数组元素> 右子数组元素” 的情况（跨子数组的逆序对）。
    3. 总逆序对 = 左子数组逆序对 + 右子数组逆序对 + 跨子数组逆序对。

### 2. 代码实现（C++）

cpp

运行

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 合并两个有序子数组并统计跨子数组的逆序对
long long mergeAndCount(vector<int>& arr, vector<int>& temp, int left, int mid, int right) {
    int i = left;    // 左子数组起始索引
    int j = mid + 1; // 右子数组起始索引
    int k = left;    // 临时数组起始索引
    long long count = 0;

    // 合并并统计逆序对
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
            // 左子数组剩余元素均大于当前右子数组元素，构成逆序对
            count += (mid - i + 1);
        }
    }

    // 处理剩余元素
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];

    // 复制回原数组
    for (i = left; i <= right; i++) arr[i] = temp[i];

    return count;
}

// 递归归并排序并统计逆序对
long long mergeSortAndCount(vector<int>& arr, vector<int>& temp, int left, int right) {
    long long count = 0;
    if (left < right) {
        int mid = (left + right) / 2;
        count += mergeSortAndCount(arr, temp, left, mid);       // 左子数组逆序对
        count += mergeSortAndCount(arr, temp, mid + 1, right);  // 右子数组逆序对
        count += mergeAndCount(arr, temp, left, mid, right);    // 跨子数组逆序对
    }
    return count;
}

// 计算逆序对总数（最少旋转次数）
long long countInversions(vector<int>& arr) {
    int n = arr.size();
    vector<int> temp(n); // 临时数组用于合并
    return mergeSortAndCount(arr, temp, 0, n - 1);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> arr(n);
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    cout << countInversions(arr) << endl;
    return 0;
}
```

### 3. 优缺点分析

- **优点**：
    - 时间复杂度为 `O(n log n)`，效率高，适合大规模数据（如 `n = 10000` 时可快速处理）。
- **缺点**：
    - 实现较复杂，需要理解归并排序的分治思想和递归逻辑。
- **适用场景**：数据规模较大（如 `n > 1000`）时使用。

## 四、总结

|方法|核心逻辑|时间复杂度|适用场景|实现难度|
|---|---|---|---|---|
|双重循环|直接遍历统计逆序对|`O(n²)`|小规模数据（n ≤ 1000）|简单|
|归并排序|分治合并时统计逆序对|`O(n log n)`|大规模数据（n > 1000）|中等|

两种方法的核心均为 “统计逆序对数量”，因为逆序对数量与 “相邻交换排序的最少次数” 严格等价。实际应用中可根据数据规模选择合适的方法。
