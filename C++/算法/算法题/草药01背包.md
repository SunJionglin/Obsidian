## 一、题目信息

- 题型：**01 背包**
- 规则：每种草药**只能选一次，不能拆分**
- 输入：
    
    - T：总时间（背包容量）
    - M：草药数量
    - 每行：采摘耗时、草药价值
    
- 目标：不超过总时间，求**最大总价值**

## 二、核心概念

1. **dp [j] 含义**
    
    `dp[j]` = 只用 **j 时间** 能采到的最大价值
2. 状态转移方程

cpp

```
dp[j] = max(dp[j], dp[j - 耗时] + 价值);
```

- 不选当前草药：保留 `dp[j]`
- 选当前草药：前面剩余时间最优价值 + 当前草药价值

3. 内层循环**必须倒序**
    
    从总时间 T 往小遍历，**防止同一个草药重复选**

## 三、可直接提交完整代码（C++11，可用 lambda、范围 for）

cpp

```
#include<iostream>
#include<vector>
#include<algorithm>
using namespace std;

int main()
{
    int T, M;
    cin >> T >> M;
    vector<pair<int, int>> herb(M);
    
    // 读入数据
    for(auto &p : herb)
    {
        cin >> p.first >> p.second;
    }

    // dp[j]：j时间能获得的最大价值
    vector<int> dp(T + 1, 0);

    // 01背包核心
    for(auto &p : herb)
    {
        int t = p.first;   // 耗时
        int v = p.second;  // 价值
        // 倒序遍历
        for(int j = T; j >= t; j--)
        {
            dp[j] = max(dp[j], dp[j - t] + v);
        }
    }

    cout << dp[T] << endl;
    return 0;
}
```

## 四、重点笔记总结

1. 为什么**不能用贪心排序**
    
    按「价值 ÷ 时间」性价比排序逐个装，只适合**可以切开**的物品；
    
    草药只能整棵选 / 不选，贪心**一定错**。
    
2. 01 背包固定模板
    

cpp

```
for(每个物品)
    for(容量从大到小)
        dp[j] = max(dp[j], dp[j-w] + v);
```

3. 语法亮点（C++11 可用）

- `vector<pair<int,int>>` 直接存耗时 + 价值
- 范围 `for` 循环 `for(auto &p : herb)` 简洁好写
- 无需手动下标，代码更干净

## 五、易错点

- 内层循环**不能从小到大** → 变成无限拿草药（完全背包）
- 不要用性价比 `sort` 贪心
- dp 数组初始全部为 0
