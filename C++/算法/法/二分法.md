# 二分查找（二分法）完全笔记

## 一、二分法核心定义

二分查找（Binary Search）是一种高效的**有序区间查找算法**，核心思想是「**分治**」：通过不断将查找区间缩小一半，快速定位目标值或满足条件的最优解。

### 核心前提

1. 查找区间是**有序的**（升序 / 降序，默认升序）；
2. 查找区间是**连续的**（无重复或允许重复，需根据场景处理）。

### 核心优势

- 时间复杂度：O(logn)（n 为区间长度），远优于暴力枚举的O(n)；
- 空间复杂度：O(1)（迭代实现）或O(logn)（递归实现，栈空间）。

## 二、二分法适用场景

1. **精确查找**：在有序数组中查找目标值是否存在，返回其索引（如：找指定数字、找第一个等于目标值的位置）；
2. **模糊查找（最优解查找）**：在有序区间中查找满足条件的「最大 / 最小」值（如：砍树问题的最大高度、平方根的整数部分）；
3. **边界查找**：查找目标值的左边界（第一个≥目标值）或右边界（最后一个≤目标值）。

## 三、二分法核心原理（升序区间）

### 1. 区间定义

二分法的关键是「**明确区间的开闭性**」，常用两种区间定义（决定循环条件和边界更新逻辑）：

- **左闭右闭 [left, right]**（最常用，推荐入门）；
- **左闭右开 [left, right)**（适用于部分语言的数组切片场景）。

### 2. 核心步骤（左闭右闭区间）

以「查找满足条件的最优解」为例，步骤固定：

1. **初始化区间**：`left = 区间左边界`（如 0），`right = 区间右边界`（如数组长度 - 1、最大值）；
2. **循环缩小区间**：当 `left ≤ right` 时（闭区间的循环条件）：
    
    - 计算中间值：`mid = left + (right - left) / 2`（避免 `left + right` 溢出）；
    - 判断 mid 是否满足条件：
        
        - 满足条件：记录当前 mid 为候选答案，尝试向「更优方向」缩小区间（如找最大值则向右，找最小值则向左）；
        - 不满足条件：向「满足条件的方向」缩小区间；
        
    
3. **返回候选答案**。

### 3. 为什么要 `mid = left + (right - left) / 2`？

- 避免溢出：若 `left` 和 `right` 接近 `int` 最大值（如 231−1），`left + right` 会超出 `int` 范围，导致溢出；
- 等价于 `(left + right) // 2`（整数除法），但更安全。

## 四、二分法三大模板（升序区间）

### 模板 1：精确查找（找目标值的索引，不存在返回 - 1）

- 区间定义：[left, right]（左闭右闭）；
- 循环条件：`left ≤ right`；
- 边界更新：
    
    - 若 `nums[mid] == target`：直接返回 mid（找到目标）；
    - 若 `nums[mid] 在右半区，`left = mid + 1`（mid 已排除）；
    - 若 `nums[mid] > target`：目标在左半区，`right = mid - 1`（mid 已排除）。
    

cpp

```
int binarySearch(vector target) {
    int left = 0, right = nums.size() - 1;
    while (left         int mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            return mid; // 精确找到，返回索引
        } else if (nums[mid]             left = mid + 1; // 目标在右边，缩小左边界
        } else {
            right = mid - 1; // 目标在左边，缩小右边界
        }
    }
    return -1; // 未找到
}
```

### 模板 2：左边界查找（找第一个≥target 的元素索引）

- 场景：如「砍树问题」中找最小的可行高度、「找第一个大于等于 x 的数」；
- 区间定义：[left, right]；
- 循环条件：`left ≤ right`；
- 核心逻辑：找到满足条件的最小值，需「优先向左缩小区间」。

cpp

```
int leftBound(vector int target) {
    int left = 0, right = nums.size() - 1;
    int ans = nums.size(); // 初始化为无效值（若所有元素都小于target）
    while (left  int mid = left + (right - left) / 2;
        if (nums[mid] >= target) {
            ans = mid; // 记录候选答案（当前mid满足条件）
            right = mid - 1; // 尝试找更小的满足条件的元素，向左缩小
        } else {
            left = mid + 1; // 不满足，向右缩小
        }
    }
    return ans;
}
```

### 模板 3：右边界查找（找最后一个≤target 的元素索引）

- 场景：如「砍树问题」中找最大的可行高度、「找最后一个小于等于 x 的数」；
- 区间定义：[left, right]；
- 循环条件：`left ≤ right`；
- 核心逻辑：找到满足条件的最大值，需「优先向右缩小区间」。


## 五、关键细节：为什么要 `left = mid + 1` / `right = mid - 1`？

### 核心原因：保证区间「严格缩小」，避免死循环

二分法的循环终止条件是 `left > right`，若不进行 `±1` 操作，可能导致区间无法缩小到终止状态，陷入死循环。

#### 反例（不写 ±1 导致死循环）

假设区间 [left=2, right=3]，目标是找满足条件的最大值：

cpp

```
// 错误写法：right = mid（不-1）
while (left  int mid = 2 + (3-2)/2 = 2;
    if (nums[mid]  ans = 2;
        left = 3; // 左边界更新为3
    } else {
        right = 2; // 右边界不变
    }
    // 下一轮：left=3, right=3 → mid=3
    // 若nums[3] ，循环终止；
    // 若nums[3] > target → right=3，此时left=3 无限循环（mid永远=3）
}
```

#### 正确写法（±1 保证区间缩小）

- `left = mid + 1`：mid 已满足条件，后续只需查找 [mid+1, right]，左边界严格右移；
- `right = mid - 1`：mid 不满足条件，后续只需查找 [left, mid-1]，右边界严格左移；
- 最终区间一定会缩小到 `left > right`，循环必然终止。

## 六、常见误区与避坑指南

1. **区间定义与循环条件不匹配**：
    
    - 左闭右闭 [left, right] → 循环条件 `left ≤ right`；
    - 左闭右开 [left, right) → 循环条件 `left 边界不包含，无需` ≤`）；
    - 错误示例：左闭右闭区间用 `left 可能遗漏最后一个元素。
    
2. **mid 计算溢出**：
    
    - 错误写法：`mid = (left + right) / 2`（left 和 right 过大时，求和溢出）；
    - 正确写法：`mid = left + (right - left) / 2`（等价于平均值，无溢出风险）。
    
3. **忘记记录候选答案（模糊查找场景）**：
    
    - 精确查找可直接返回 mid，但模糊查找（找最大 / 最小可行解）需在 mid 满足条件时记录 ans，避免遗漏。
    
4. **处理重复元素时的边界问题**：
    
    - 如数组 [1,2,2,3]，找第一个 2 的索引 → 用左边界模板；
    - 找最后一个 2 的索引 → 用右边界模板；
    - 直接用精确查找模板可能返回任意一个 2 的索引，不符合需求。
    
5. **未考虑目标值超出区间范围**：
    
    - 如找比数组所有元素都大的 target → 左边界模板返回数组长度（无效值）；
    - 需在返回前判断 ans 是否在有效范围内（如 `ans ()`）。
    

## 七、经典例题实战

### 例题 1：x 的平方根（LeetCode 69）

- 题目：给你一个非负整数 x，计算并返回 x 的算术平方根（只保留整数部分）。
- 思路：找最大的整数 k，满足 k2≤x（右边界查找模板）。
- 代码：

cpp

```
int mySqrt(int x) {
    if (x == 0) return 0;
    int left = 1, right = x;
    int ans = 0;
    while (left ) {
        int mid = left + (right - left) / 2;
        if ((long long)mid * mid ) { // 用long long避免溢出
            ans = mid;
            left = mid + 1; // 尝试找更大的k
        } else {
            right = mid - 1;
        }
    }
    return ans;
}
```

### 例题 2：寻找峰值（LeetCode 162）

- 题目：在无序数组中找峰值（峰值元素是指其值大于左右相邻值的元素），假设 nums [-1] = nums [n] = -∞。
- 思路：利用「局部有序性」，mid 与 mid+1 比较：
    
    - 若 nums [mid] +1] → 峰值在右半区（mid+1 可能是峰值）；
    - 若 nums [mid] ≥ nums [mid+1] → 峰值在左半区（mid 可能是峰值）；
    
- 代码：

cpp

```
int findPeakElement(vector<int>& nums) {

        int mid = left + (right - left) / 2;
        if (nums[mid] mid+1]) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }
    return left;
}
```

## 八、二分法思维拓展

1. **无序区间的二分**：只要存在「局部有序性」或「单调性条件」，即使整体无序也可二分（如寻找峰值、旋转排序数组查找）；
2. **多维二分**：在二维有序矩阵中查找（如 LeetCode 240），可将二维转化为一维二分，或分别对行、列二分；
3. **二分答案法**：将「求最优解」转化为「判断某个解是否可行」（如砍树问题、最小化最大值问题），核心是找到「解的区间」和「可行性判断条件」。


# 2. 实数二分（连续小数型）

## 2.1 适用场景

- 求平方根、立方根
- 几何最值、实数最优解
- 答案是**小数、浮点数**

## 2.2 核心规则

1. 用 `double` 类型
2. **不 +1、不 -1**，直接 `left=mid` 或 `right=mid`
3. 退出方式：**固定循环 100 次** 或 **区间足够小**

## 2.3 模板一：固定循环 100 次（推荐，最简单稳）

cpp

```
double left = 最小可能, right = 最大可能;

for (int i = 0; i < 100; ++i) {
    double mid = (left + right) / 2;

    if (check(mid) 满足条件) {
        left = mid;    // 想更大
    } else {
        right = mid;   // 想更小
    }
}

cout << left << endl; // left ≈ right，输出哪个都行
```

## 2.4 模板二：按精度退出

cpp

```
const double eps = 1e-8; // 控制精度
double left = ..., right = ...;

while (right - left > eps) {
    double mid = (left + right) / 2;
    if (check(mid)) {
        left = mid;
    } else {
        right = mid;
    }
}
```

## 2.5 关键点

1. 实数是**连续**的，`mid` 永远能把区间切开
2. **永远不会 `left == right`**，所以不会死循环
3. 不需要判断等于，只需要**足够接近**即可
4. 一般保留 `1e-6`~`1e-8` 精度就够用

# 3. 整数二分 vs 实数二分 对比表

表格

|项目|整数二分|实数二分|
|---|---|---|
|数据类型|int / long long|double|
|区间性质|离散整数|连续实数|
|mid 更新|`left=mid+1` / `right=mid-1`|`left=mid` / `right=mid`|
|循环条件|`left <= right`|循环 100 次 或 `right-left>eps`|
|死循环风险|不写 ±1 极易死循环|永远不会死循环|
|答案是否精确|精确整数|精度范围内近似值|
|边界处理|必须判断到 `left>right`|无限逼近，无需完全相等|

# 5. 一句话终极记忆

- **整数离散会卡 mid，必须 ±1 推进**

- 整数看 `left<=right`，实数看**次数 / 精度**
