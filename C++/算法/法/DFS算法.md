### 深度优先搜索（DFS）算法详解

DFS（Depth-First Search，深度优先搜索）是一种典型的图 / 树遍历算法，核心特点是 “先深后广”—— 就像走迷宫时，遇到岔路就选一条一直走到头，走不通了再回头（回溯）选另一条，直到遍历完所有可达节点。

#### 一、核心思想

1. **访问当前节点**：标记该节点为已访问，避免重复遍历。
2. **递归 / 迭代深入**：对当前节点的**未访问邻接节点**，优先选择一个继续深入遍历。
3. **回溯**：当当前节点的所有邻接节点都已访问完毕，返回上一层节点，继续处理其他未访问的邻接节点。

可以用一句话概括：**“不撞南墙不回头，回头再走其他路”**。

#### 二、DFS 的两种实现方式

下面以**无向图**为例，分别展示最易理解的**递归版**和更贴近底层的**非递归版（栈实现）**。

##### 1. 递归实现（推荐新手先掌握）

递归版利用函数调用栈天然实现 “回溯”，代码简洁直观。

python

运行

```cpp
# 构建无向图的邻接表（表示图的常用方式）
graph = {
    0: [1, 2],
    1: [0, 3, 4],
    2: [0, 5],
    3: [1],
    4: [1, 5],
    5: [2, 4]
}

# 递归实现DFS
def dfs_recursive(node, visited, result):
    # 1. 标记当前节点为已访问，并加入结果集
    visited.add(node)
    result.append(node)
    
    # 2. 遍历当前节点的所有邻接节点
    for neighbor in graph[node]:
        # 3. 若邻接节点未访问，则递归遍历
        if neighbor not in visited:
            dfs_recursive(neighbor, visited, result)

# 初始化：访问集合、结果列表
visited = set()
result = []
# 从节点0开始遍历（可根据需求换起始节点）
dfs_recursive(0, visited, result)

# 输出遍历结果
print("递归版DFS遍历结果:", result)  # 输出：[0, 1, 3, 4, 5, 2]
```

**代码关键解释**：

- `visited` 集合：记录已访问的节点，防止循环遍历（比如无向图中 0→1，1 又能回到 0）。
- `result` 列表：按遍历顺序存储节点，体现 DFS 的 “深度优先” 特性。
- 递归终止条件：当前节点的所有邻接节点都已访问，函数自然返回（回溯）。

##### 2. 非递归实现（栈模拟）

递归本质是调用栈，非递归版手动用栈模拟这一过程，更适合理解 DFS 的底层逻辑。

运行

```cpp
# 非递归（栈）实现DFS
def dfs_stack(start_node):
    # 初始化栈（存储待遍历的节点）、访问集合、结果列表
    stack = [start_node]
    visited = set()
    result = []
    
    while stack:
        # 1. 弹出栈顶节点（后进先出，符合深度优先）
        current = stack.pop()
        
        # 2. 若未访问，则处理该节点
        if current not in visited:
            visited.add(current)
            result.append(current)
            
            # 3. 把邻接节点逆序入栈（保证遍历顺序和递归版一致）
            # 逆序原因：栈是后进先出，正序入栈会导致遍历顺序反转
            for neighbor in reversed(graph[current]):
                if neighbor not in visited:
                    stack.append(neighbor)
    
    return result

# 从节点0开始遍历
result_stack = dfs_stack(0)
print("栈版DFS遍历结果:", result_stack)  # 输出：[0, 1, 3, 4, 5, 2]
```

**代码关键解释**：

- 栈的 “后进先出” 特性：保证每次优先处理最新入栈的邻接节点（即 “深入”）。
- `reversed(graph[current])`：比如节点 0 的邻接节点是 [1,2]，逆序后是 [2,1]，入栈后先弹出 1，和递归版遍历顺序一致。

#### 三、DFS 的典型应用场景

1. **迷宫 / 路径求解**：寻找从起点到终点的路径（找到一条即停止，无需遍历全部）。
2. **树的遍历**：前序、中序、后序遍历本质都是 DFS 的变种（比如二叉树前序遍历：根→左→右）。
3. **连通性检测**：判断图中两个节点是否连通，或找出图的连通分量。
4. **拓扑排序**：对有向无环图（DAG）进行拓扑排序（反向后序遍历）。
5. **回溯算法**：如排列组合、子集生成、数独求解（DFS + 剪枝）。

### 总结

1. **核心逻辑**：DFS 以 “深度” 为优先，通过**递归 / 栈**实现，核心是 “访问 - 深入 - 回溯”。
2. **关键要点**：必须用`visited`标记已访问节点，避免循环遍历；递归版简洁但易栈溢出（数据量大时用非递归版）。
3. **适用场景**：需要 “探到底” 的遍历 / 求解场景，比如找路径、连通性检测，是回溯算法的基础。
