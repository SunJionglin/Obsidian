### 一、哈希表核心概念（通俗理解）

#### 1. 什么是哈希表？

哈希表是一种**键值对（Key-Value）** 存储结构，通过「哈希函数」将 Key 映射到数组的某个位置（称为 “桶”），从而实现 “通过 Key 快速找到 Value”。

- 类比：字典的 “拼音→汉字”（拼音是 Key，汉字是 Value），不用翻整本书，通过拼音直接定位，效率极高；
- 核心：哈希函数（比如把 Key 转换成数组下标）、冲突解决（不同 Key 映射到同一位置时的处理，新手只需了解，不用深钻）。

#### 2. 哈希表 vs 数组 / 链表（核心优势）

表格

|数据结构|查找效率|插入效率|适用场景|
|---|---|---|---|
|数组|O (1)（已知下标）|O(n)|下标连续、固定的场景|
|链表|O(n)|O(1)|频繁插入删除的场景|
|哈希表|O (1)（平均）|O (1)（平均）|快速查找、键值映射的场景|

### 二、C++ 中的哈希表实现（新手必学）

C++ 标准库中没有直接叫 “哈希表” 的类，但提供了两个核心实现：

- `unordered_map`：键值对哈希表（Key 唯一，可通过 Key 查 Value）；
- `unordered_set`：无重复值的哈希集合（仅存 Key，用于快速判断元素是否存在）。

⚠️ 注意：和有序的`map/set`（红黑树实现，O (logn)）不同，`unordered_map/unordered_set`是无序的，效率更高（O (1)）。

cpp

运行

```
#include <unordered_map> // unordered_map
#include <unordered_set> // unordered_set
```

### 三、核心用法（代码示例 + 解释）

#### 场景 1：[[unordered_map]]（键值对映射）

比如 “学生学号→成绩” 的映射，快速通过学号查成绩：

cpp

运行

```cpp
#include <iostream>
#include <unordered_map>
#include <string>
using namespace std;

int main() {
    // 1. 初始化：创建<string, int>类型的哈希表（学号→成绩）
    unordered_map<string, int> score_map;

    // 2. 插入键值对（3种方式）
    score_map["001"] = 95; // 最常用
    score_map.insert({"002", 88});
    score_map.emplace("003", 92); // 效率更高，避免拷贝

    // 3. 查找Key（核心！）
    string id = "002";
    // 方式1：count()判断Key是否存在（返回1/0）
    if (score_map.count(id)) {
        cout << id << "的成绩：" << score_map[id] << endl; // 输出88
    }
    // 方式2：find()返回迭代器（更安全，避免Key不存在时插入默认值）
    auto it = score_map.find("004");
    if (it != score_map.end()) {
        cout << it->first << ":" << it->second << endl; // first=Key，second=Value
    } else {
        cout << "学号004不存在" << endl;
    }

    // 4. 遍历哈希表（无序）
    cout << "\n所有学生成绩：" << endl;
    for (auto& pair : score_map) {
        cout << pair.first << ":" << pair.second << endl;
    }

    // 5. 删除Key
    score_map.erase("001"); // 删除学号001
    cout << "\n删除001后，是否存在：" << score_map.count("001") << endl; // 输出0

    // 6. 清空/大小
    cout << "哈希表大小：" << score_map.size() << endl; // 输出2
    score_map.clear(); // 清空所有元素
    cout << "清空后大小：" << score_map.size() << endl; // 输出0

    return 0;
}
```

#### 场景 2：unordered_set（快速判重 / 查找）

比如 “判断输入的数是否在集合中”：

cpp

运行

```cpp
#include <iostream>
#include <unordered_set>
#include <vector>
using namespace std;

int main() {
    // 1. 初始化
    unordered_set<int> num_set;
    vector<int> nums = {1, 2, 3, 2, 4};

    // 2. 插入元素（自动去重）
    for (int num : nums) {
        num_set.insert(num); // 最终存储{1,2,3,4}
    }

    // 3. 查找元素（核心！）
    int target = 2;
    if (num_set.count(target)) {
        cout << target << "存在于集合中" << endl;
    } else {
        cout << target << "不存在" << endl;
    }

    // 4. 遍历（无序）
    cout << "\n集合中的元素：";
    for (int num : num_set) {
        cout << num << " ";
    }
    cout << endl;

    // 5. 删除元素
    num_set.erase(3);
    cout << "删除3后，集合：";
    for (int num : num_set) {
        cout << num << " ";
    }
    cout << endl;

    return 0;
}
```

### 四、实战场景（贴合你之前的代码）

#### 场景 1：优化 “按索引查元素”（你上一个代码的需求）

如果需要频繁查询 “索引→元素”，哈希表和数组效率相近，但如果索引是字符串 / 非连续整数，哈希表更合适：

cpp

运行

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    unordered_map<int, ll> a_map; // 索引（1~n）→ 元素值

    // 输入n个元素，存入哈希表（索引从1开始）
    for (int i = 1; i <= n; i++) {
        ll x;
        cin >> x;
        a_map[i] = x;
    }

    // 遍历m个查询，输出对应值
    for (int i = 0; i < m; i++) {
        int idx;
        cin >> idx;
        if (a_map.count(idx)) {
            cout << a_map[idx] << endl;
        } else {
            cout << "索引无效" << endl;
        }
    }
    return 0;
}
```

#### 场景 2：统计元素出现次数（高频面试题）

比如 “统计输入数组中每个数出现的次数”：

cpp

运行

```cpp
#include <iostream>
#include <unordered_map>
#include <vector>
using namespace std;

int main() {
    vector<int> nums = {1, 2, 2, 3, 3, 3};
    unordered_map<int, int> count_map; // 数→出现次数

    for (int num : nums) {
        count_map[num]++; // 不存在的Key会自动初始化为0，再++
    }

    // 输出统计结果
    for (auto& pair : count_map) {
        cout << pair.first << "出现：" << pair.second << "次" << endl;
    }
    return 0;
}
```
#### 数组元素次数统计「原理 + 笔记」
###### 一、核心原理（一句话
用 **unordered_map（哈希表）** 做**键值映射**：

- **Key（键）**：数组里的**数字本身**
- **Value（值）**：这个数字**出现的次数**

遍历数组时，每遇到一个数字，就把它对应的次数 +1。

---

## 二、代码逐行原理拆解

cpp

运行

```
vector<int> nums = {1, 2, 2, 3, 3, 3};
// 定义哈希表：key=数组元素，value=出现次数
unordered_map<int, int> count_map;
```

### 关键语句：`count_map[num]++;`

这一行是统计的**核心**，分两种情况：

1. **num 第一次出现**
    
    - `count_map` 里没有这个 key
    - 自动**新建键值对**：`{num, 0}`
    - 再执行 `++` → 变成 `{num, 1}`
    
2. **num 已经出现过**
    
    - 直接找到已有的 key
    - 把对应的 value **+1**
    

---

## 三、运行过程演示（数组 {1,2,2,3,3,3}）

1. 遍历 1 → 无 {1,?} → 新建 {1,0} → 变 {1,1}
2. 遍历 2 → 无 {2,?} → 新建 {2,0} → 变 {2,1}
3. 遍历 2 → 有 {2,1} → 变 {2,2}
4. 遍历 3 → 无 {3,?} → 新建 {3,0} → 变 {3,1}
5. 遍历 3 → 有 {3,1} → 变 {3,2}
6. 遍历 3 → 有 {3,2} → 变 {3,3}

最终哈希表：

`{1:1, 2:2, 3:3}`

## 五、极简记忆笔记

1. **统计次数 = 键值映射**
    
    - 元素 → Key
    - 次数 → Value
    
2. **自动初始化**
    
    - 新元素：`map[num]` 自动变 0，再 +1
    - 老元素：直接 +1
    
3. **效率**
    - 平均 O (n)，比暴力双重循环快得多
### 五、新手避坑点

1. **无序性**：`unordered_map/unordered_set`的遍历顺序和插入顺序无关，若需要有序，用`map/set`（红黑树）；
2. **Key 的要求**：Key 必须是 “可哈希的”（比如 int、string、double，不能是 vector、list）；
3. **哈希冲突**：极端情况下，多个 Key 映射到同一桶，效率会退化为 O (n)（新手不用处理，库已优化）；
4. **避免 Key 不存在时的默认插入**：用`find()`代替`[]`查找（`score_map["004"]`若不存在，会自动插入`"004":0`）；
5. **迭代器失效**：插入 / 删除元素可能导致迭代器失效，遍历中修改需谨慎。

### 总结

1. 核心优势：哈希表（`unordered_map/unordered_set`）提供**O (1) 平均时间复杂度**的查找 / 插入 / 删除，适合 “键值映射、快速判重、统计次数”；
2. 常用场景：
    
    - `unordered_map`：学号→成绩、ID→信息、统计元素次数；
    - `unordered_set`：快速判断元素是否存在、去重；
    
3. 避坑关键：
    - 用`count()`/`find()`判断 Key 是否存在，避免`[]`的默认插入；
    - 无需有序时用`unordered_*`，需要有序时用`map/set`；
    - Key 必须是可哈希类型（int/string 等）。

# `unordered_set`和`unordered_map`的核心差异
包括它们的存储结构、用途、用法等，以便在实际编程中精准选择 —— 这两个都是哈希表实现，但定位和场景完全不同，核心区别在于「是否存储值（Value）」。

### 一、核心区别总述

表格

|类型|本质定位|核心特征|核心用途|
|---|---|---|---|
|`unordered_set`|哈希集合|仅存储**唯一的 Key**，无 Value|快速判断元素是否存在、去重|
|`unordered_map`|哈希表（键值对）|存储**唯一的 Key + 对应的 Value**|键值映射（通过 Key 快速查 Value）、统计次数|

### 二、关键维度对比（新手必看）

表格

|对比维度|unordered_set|unordered_map|
|---|---|---|
|存储内容|单一值（仅 Key）|键值对（Key + Value）|
|核心操作|判断 Key 是否存在、去重、遍历|通过 Key 查 Value、键值映射、统计|
|访问方式|只能遍历 / 查找 Key，无下标访问|可通过`map[key]`访问 Value，或迭代器（`it->first/second`）|
|插入方式|`insert(Key)`（自动去重）|`map[key]=Value` / `insert({Key,Value})` / `emplace(Key,Value)`|
|查找方式|`count(Key)`（返回 1/0）、`find(Key)`|`count(Key)`、`find(Key)`（返回迭代器，可取 Value）|
|元素组成|每个元素就是 Key，无重复|每个元素是`pair<Key, Value>`，Key 无重复，Value 可重复|

### 三、代码示例对比（直观体现差异）

#### 1. unordered_set（仅存 Key，判重 / 去重）

cpp

运行

```
#include <iostream>
#include <unordered_set>
using namespace std;

int main() {
    unordered_set<int> s;
    // 插入Key（自动去重）
    s.insert(1);
    s.insert(2);
    s.insert(2); // 重复，不会存储
    // 查找Key
    if (s.count(2)) {
        cout << "2存在（仅能判断存在性，无值可取）" << endl;
    }
    // 遍历（只有Key）
    cout << "集合元素：";
    for (int key : s) { // 直接遍历Key
        cout << key << " ";
    }
    return 0;
}
// 输出：
// 2存在（仅能判断存在性，无值可取）
// 集合元素：1 2
```

#### 2. unordered_map（存 Key-Value，键值映射）

cpp

运行

```
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    unordered_map<int, string> m;
    // 插入键值对
    m[1] = "苹果";
    m[2] = "香蕉";
    m[2] = "橙子"; // Key=2的Value被覆盖
    // 查找Key并取Value
    if (m.count(2)) {
        cout << "Key=2的Value：" << m[2] << endl; // 可取出具体值
    }
    // 遍历（Key+Value）
    cout << "键值对：";
    for (auto& pair : m) { // pair.first=Key，pair.second=Value
        cout << "(" << pair.first << "," << pair.second << ") ";
    }
    return 0;
}
// 输出：
// Key=2的Value：橙子
// 键值对：(1,苹果) (2,橙子)
```

### 四、选择原则（什么时候用哪个？）

1. **用 unordered_set 的场景**：
    
    - 只需判断 “某个值是否存在”（比如去重、查重）；
    - 只需存储一组不重复的元素，无需关联其他数据。
        
        ✅ 例子：判断输入的数是否在黑名单中、数组去重。
    
2. **用 unordered_map 的场景**：
    
    - 需要 “通过一个值（Key）找到另一个值（Value）”；
    - 需要统计元素出现次数（Key = 元素，Value = 次数）；
    - 需要关联两类数据（比如学号→成绩、ID→姓名）。
        
        ✅ 例子：统计数组中每个数的出现次数、根据用户 ID 查用户名。
    

### 五、共性（容易混淆的点）

1. 都是哈希表实现，平均时间复杂度 O (1)（查找 / 插入 / 删除）；
2. 都是**无序**的（遍历顺序≠插入顺序）；
3. Key 都必须是 “可哈希的”（int、string、double 等，不能是 vector/list）；
4. Key 都唯一（unordered_set 中无重复 Key，unordered_map 中无重复 Key）。

### 总结

1. 核心差异：`unordered_set`只存 Key（判重 / 去重），`unordered_map`存 Key-Value（键值映射）；
2. 选择技巧：“只判断存在性 / 去重” 用 set，“需要映射 / 统计” 用 map；
3. 共性：无序、Key 唯一、O (1) 平均效率、Key 需可哈希。

记住这个核心逻辑：**无值关联用 set，有值映射用 map**，就能在实战中快速选对数据结构。
