
在 Python 中，将整数转换为字符串可以使用内置的`str()`函数，这是最常用和最简单的方法。

  

示例代码如下：

  

python

```python
# 定义一个整数
num = 12345

# 使用str()函数将整数转换为字符串
str_num = str(num)

# 验证转换结果和类型
print(str_num)       # 输出: "12345"
print(type(str_num)) # 输出: <class 'str'>
```

  

除了`str()`函数，还可以使用字符串格式化的方式间接实现转换：

  

python

```python
num = 678
str_num = f"{num}"  # 使用f-string格式化
# 或者
str_num = "%d" % num  # 使用%格式化
# 或者
str_num = "{}".format(num)  # 使用format()方法

print(str_num)  # 输出: "678"
```

  

这些方法都能将整数成功转换为对应的字符串表示形式，其中`str()`函数是最直接和推荐的方式。

在C++

在 C++ 中，将整数转换为字符串有多种方法，以下是几种常用方式：

  

1. 使用`std::to_string`函数（C++11 及以上版本）  
    这是最简单直接的方法，适用于所有基本整数类型：

  

cpp

```cpp
#include <string>
#include <iostream>

int main() {
    int num = 123;
    std::string str = std::to_string(num);
    std::cout << str << " 类型: " << typeid(str).name() << std::endl;
    
    // 也适用于其他整数类型
    long long big_num = 1234567890LL;
    std::string big_str = std::to_string(big_num);
    
    return 0;
}
```

  

2. 使用`std::stringstream`（更灵活，支持格式化）

  

cpp

```cpp
#include <string>
#include <sstream>
#include <iostream>

int main() {
    int num = 456;
    std::stringstream ss;
    ss << num;  // 将整数放入流中
    std::string str = ss.str();  // 从流中获取字符串
    
    std::cout << str << std::endl;
    
    // 支持格式化输出
    ss.clear();  // 清空流状态
    ss.str("");  // 清空流内容
    ss << std::hex << num;  // 转换为十六进制字符串
    std::string hex_str = ss.str();
    std::cout << hex_str << std::endl;  // 输出: 1c8
    
    return 0;
}
```

  

3. 使用 C 语言风格的`sprintf`函数

  

cpp

```cpp
#include <cstdio>
#include <iostream>

int main() {
    int num = 789;
    char buffer[20];  // 需要预先分配足够大的缓冲区
    sprintf(buffer, "%d", num);  // 格式化到缓冲区
    
    std::cout << buffer << std::endl;
    
    return 0;
}
```

  

推荐使用`std::to_string`（简单场景）或`std::stringstream`（需要格式化时），这两种是 C++ 标准中更安全、更符合 C++ 风格的方法。`std::to_string`在 C++11 及以上版本可用，几乎所有现代编译器都支持。
