冒泡排序（Bubble Sort）是一种简单直观的排序算法，核心思想是**通过重复比较相邻元素并交换位置，让最大（或最小）的元素像 “气泡” 一样逐渐 “上浮” 到数组的末端**。每一轮遍历后，未排序部分的最大元素会被 “冒泡” 到正确位置，直到整个数组有序。

### 一、核心原理

1. **比较相邻元素**：从数组起始位置开始，依次比较相邻的两个元素。
2. **交换位置**：如果两个元素的顺序错误（例如，前一个元素大于后一个元素，对于升序排序），则交换它们的位置。
3. **重复遍历**：每完成一轮遍历，最大的元素会 “浮” 到当前未排序部分的末尾；然后缩小排序范围（排除已 “浮” 到末尾的元素），重复上述过程，直到所有元素有序。

### 二、算法步骤（以升序为例）

假设有数组 `arr = [5, 3, 8, 4, 2]`，长度为 `n=5`，排序步骤如下：

#### 第 1 轮（目标：将最大元素 8 移到末尾）：

- 比较 5 和 3：5>3 → 交换 → `[3, 5, 8, 4, 2]`
- 比较 5 和 8：5<8 → 不交换 → `[3, 5, 8, 4, 2]`
- 比较 8 和 4：8>4 → 交换 → `[3, 5, 4, 8, 2]`
- 比较 8 和 2：8>2 → 交换 → `[3, 5, 4, 2, 8]`
- 结果：最大元素 8 已到位（数组末尾），未排序部分为 `[3, 5, 4, 2]`。

#### 第 2 轮（目标：将次大元素 5 移到倒数第 2 位）：

- 比较 3 和 5：3<5 → 不交换 → `[3, 5, 4, 2, 8]`
- 比较 5 和 4：5>4 → 交换 → `[3, 4, 5, 2, 8]`
- 比较 5 和 2：5>2 → 交换 → `[3, 4, 2, 5, 8]`
- 结果：次大元素 5 到位，未排序部分为 `[3, 4, 2]`。

#### 第 3 轮（目标：将第三大元素 4 移到倒数第 3 位）：

- 比较 3 和 4：3<4 → 不交换 → `[3, 4, 2, 5, 8]`
- 比较 4 和 2：4>2 → 交换 → `[3, 2, 4, 5, 8]`
- 结果：4 到位，未排序部分为 `[3, 2]`。

#### 第 4 轮（目标：将剩余元素排序）：

- 比较 3 和 2：3>2 → 交换 → `[2, 3, 4, 5, 8]`
- 结果：数组完全有序。

### 三、优化思路

默认的冒泡排序需要进行 `n-1` 轮遍历，但如果某一轮遍历中**没有发生任何交换**，说明数组已经有序，可以提前结束排序（减少不必要的遍历）。

### 四、代码实现（C++）

#### 基本版本（升序）

cpp

运行

```cpp
#include <iostream>
using namespace std;

// 冒泡排序函数（升序）
void bubbleSort(int arr[], int n) {
    // 外层循环：控制排序轮数（n个元素需要n-1轮）
    for (int i = 0; i < n - 1; ++i) {
        // 内层循环：每轮比较未排序的元素（范围随轮数减少）
        for (int j = 0; j < n - 1 - i; ++j) {  // 每轮少比较i个已排序的元素
            // 若前一个元素大于后一个，交换位置
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main() {
    int arr[] = {5, 3, 8, 4, 2};
    int n = sizeof(arr) / sizeof(arr[0]);  // 数组长度
    
    bubbleSort(arr, n);  // 调用排序函数
    
    // 输出排序结果
    for (int i = 0; i < n; ++i) {
        cout << arr[i] << " ";
    }
    // 输出：2 3 4 5 8
    return 0;
}
```

#### 优化版本（提前结束排序）

cpp

运行

```cpp
void bubbleSortOptimized(int arr[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        bool swapped = false;  // 标记本轮是否发生交换
        for (int j = 0; j < n - 1 - i; ++j) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);  // 使用标准库swap函数交换
                swapped = true;  // 发生交换，标记为true
            }
        }
        // 若本轮未交换，说明数组已有序，直接退出
        if (!swapped) {
            break;
        }
    }
}
```

### 五、算法特性

- **时间复杂度**：
    - 最坏情况（完全逆序）：`O(n²)`（需要 `n-1` 轮，每轮比较 `n-1` 次）。
    - 最好情况（已排序）：`O(n)`（优化版本中，1 轮遍历后无交换，直接结束）。
- **空间复杂度**：`O(1)`（仅用常数个额外变量，原地排序）。
- **稳定性**：稳定排序（相等元素的相对位置不会改变，因为仅当 `arr[j] > arr[j+1]` 时才交换）。
- **适用场景**：数据量小或接近有序的场景（简单易实现，但效率较低，不适合大规模数据）。

### 总结

冒泡排序是通过 “相邻元素比较交换” 让最大元素逐步 “上浮” 的排序算法，实现简单但效率较低。优化版本通过检测 “是否发生交换” 提前结束排序，可提升部分场景的性能。理解其原理有助于掌握更复杂排序算法的核心思想（如比较、交换、缩小问题规模）。
