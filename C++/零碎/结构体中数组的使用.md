在 C++ 中，结构体（`[[struct]]`）的变量**可以使用[[数组]]**，具体分为两种场景：

1. **结构体的成员是[[数组]]**（结构体内部包含[[数组]]作为成员）；
2. **结构体类型的[[数组]]**（[[数组]]的元素是结构体变量）。

### 一、结构体的成员是[[数组]]

结构体可以包含[[数组]]作为成员，用于存储多个同类型的数据（如学生的多门成绩、多个联系方式等）。

#### 示例：结构体包含[[数组]]成员

cpp

运行

```cpp
#include <iostream>
#include <string>
using namespace std;

// 定义一个包含[[数组]]成员的结构体（存储学生的3门成绩）
struct Student {
    string name;       // 姓名
    int scores[3];     // 数组：存储3门成绩（如数学、语文、英语）
};

int main() {
    // 创建结构体变量并初始化
    Student s = {"张三", {90, 85, 95}};  // 数组初始化用{}包裹
    
    // 访问结构体中的数组成员（通过 . 运算符 + 数组下标）
    cout << s.name << "的成绩：" << endl;
    cout << "数学：" << s.scores[0] << endl;  // 访问数组第1个元素
    cout << "语文：" << s.scores[1] << endl;  // 访问数组第2个元素
    cout << "英语：" << s.scores[2] << endl;  // 访问数组第3个元素
    
    // 修改数组成员的值
    s.scores[1] = 90;  // 修改语文成绩为90
    cout << "修改后语文成绩：" << s.scores[1] << endl;
    
    return 0;
}
```

输出：

plaintext

```plaintext
张三的成绩：
数学：90
语文：85
英语：95
修改后语文成绩：90
```

### 二、结构体类型的[[数组]]

可以定义**[[数组]]元素为结构体类型**的[[数组]]（简称 “结构体[[数组]]”），用于批量存储多个结构体对象（如多个学生的信息）。

#### 示例：结构体数组

cpp

运行

```cpp
#include <iostream>
#include <string>
using namespace std;

// 定义结构体（存储学生的姓名和年龄）
struct Student {
    string name;
    int age;
};

int main() {
    // 定义结构体数组（存储3个学生的信息）
    Student classList[3] = {
        {"张三", 16},
        {"李四", 15},
        {"王五", 17}
    };
    
    // 遍历结构体数组（访问每个元素的成员）
    for (int i = 0; i < 3; ++i) {
        cout << "第" << i+1 << "个学生：" 
             << classList[i].name << "，" 
             << classList[i].age << "岁" << endl;
    }
    
    // 修改结构体数组中的成员
    classList[1].age = 16;  // 修改李四的年龄为16
    cout << "修改后李四的年龄：" << classList[1].age << endl;
    
    return 0;
}
```

输出：

plaintext

```plaintext
第1个学生：张三，16岁
第2个学生：李四，15岁
第3个学生：王五，17岁
修改后李四的年龄：16
```

### 三、结构体与[[数组]]结合的常见用法

1. **存储批量的结构化数据**：如班级所有学生的信息（每个学生有姓名、多门成绩等），用 “结构体[[数组]] + 结构体内部[[数组]]” 组合：
    
    cpp
    
    运行
    
    ```cpp
    struct Student {
        string name;
        int scores[5];  // 5门成绩
    };
    Student classList[40];  // 40人的班级
    ```
    
2. **动态管理数据**：结合动态[[数组]]（如 `new` 或 `[[C++/系统/细节/[[[[数据结构]]]]/[[C++/系统/细节/[[数据结构]]/[[C++/系统/细节/[[数据结构]]/[[C++/系统/细节/[[数据结构]]/[[C++/系统/细节/[[数据结构]]/[[C++/系统/细节/[[数据结构]]/vector|vector]]|vector]]|vector]]|vector]]|vector]]|vector]]`），实现灵活的大小调整：
    
    cpp
    
    运行
    
    ```cpp
    #include <vector>
    vector<Student> students;  // 动态结构体数组（可随时添加/删除学生）
    students.push_back({"赵六", {88, 92}});  // 添加一个学生
    ```
    

### 总结

- 结构体**可以包含数组作为成员**，用于存储该结构体对象的多个同类型数据；
- 结构体**可以作为数组的元素**（结构体[[数组]]），用于批量管理多个结构体对象；
- 两者结合是处理复杂结构化数据的常用方式，例如学生信息、商品列表等场景。

使用时通过 **`结构体变量.[[[[[[数组]]]]]]成员[下标]`** 访问结构体内部的[[数组]]元素，通过 **`结构体数组[下标].成员`** 访问结构体[[数组]]中某个元素的成员。
