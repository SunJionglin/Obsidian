**`char` 类型在 C++ 中确实只能存储单个字符**（如 `'a'`、`'5'`、`'-'`、`'X'` 等），这是由它的内存大小决定的（通常占 1 个字节，刚好能存储一个 ASCII 字符）。

但在之前的代码中，我们能存储完整的 ISBN 字符串（如 `"0-670-82162-4"`），是因为使用了 **`char` 数组**（或 `string`，而 `string` 本质上是对 `char` 数组的封装）—— 它通过**多个 `char` 元素的组合**，实现了对 “一串字符” 的存储。

### 具体解释：`char` 与 `char` 数组的关系

可以把 `char` 想象成 “单个字母的格子”，而 `char` 数组是 “一排连续的格子”：

- 每个格子（单个 `char`）只能放一个字符；
- 一排格子（`char` 数组）可以放多个字符，组合起来就是 “字符串”。

#### 举例：用 `char` 数组存储 ISBN 字符串

例如，ISBN `"0-670-82162-4"` 包含 13 个字符（`'0'`、`'-'`、`'6'`、`'7'`、`'0'`、`'-'`、`'8'`、`'2'`、`'1'`、`'6'`、`'2'`、`'-'`、`'4'`），我们可以用一个 `char` 数组存储：

cpp

运行

```cpp
// 定义一个能存13个char的数组（每个元素存一个字符）
char isbn_arr[13];  

// 逐个元素赋值（每个元素都是单个char）
isbn_arr[0] = '0';   // 第1个字符
isbn_arr[1] = '-';   // 第2个字符
isbn_arr[2] = '6';   // 第3个字符
// ... 依次赋值到最后一个字符
isbn_arr[12] = '4';  // 第13个字符（识别码）
```

此时，`isbn_arr` 这个 `char` 数组就完整存储了整个 ISBN 字符串，虽然每个元素（`isbn_arr[0]`、`isbn_arr[1]` 等）都是单个 `char`，但组合起来就成了有意义的字符序列。

### 关键结论

- **单个 `char`**：只能存一个字符（如 `'5'` 或 `'-'`）；
- **`char` 数组**：由多个 `char` 组成，每个元素存一个字符，整体可以存储一串字符（字符串）；
- 代码中对 ISBN 的处理，本质是通过 `char` 数组（或 `string`）的 “多个单个字符” 组合，实现对完整字符串的存储和修改 —— 修改数组的某个下标元素（如 `isbn_arr[12] = '4'`），就是修改字符串中的某一个字符（识别码）。

这就像用多个单个字母的积木，拼出一整个单词或句子，每个积木是单个字母（`char`），整体组合就是完整的文字（字符串）。
