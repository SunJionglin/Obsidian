## 一、核心定义

位运算是直接对整数**二进制位（0/1）** 进行的操作，CPU 原生支持，效率远高于乘法 / 除法等算术运算，常用于高效数值计算、状态表示等场景。

## 二、6 种核心位运算（重点标注高频 / 易错）

表格

|运算符|名称|运算规则（按位）|数学意义 / 典型用途|示例（十进制→二进制）||||
|---|---|---|---|---|---|---|---|
|`<<`|左移|所有位左移 n 位，右侧补 0|等价于 `a×2ⁿ`（无溢出时）|`5<<1` → `00000101`→`00001010` → 结果 = 10||||
|`>>`|右移|无符号数左补 0；有符号数左补符号位|等价于 `a÷2ⁿ`（向下取整）|`5>>1` → `00000101`→`00000010` → 结果 = 2||||
|`&`|按位与|对应位都为 1 则为 1，否则为 0|判断奇偶、消除指定位|`5&3` → `0101&0011=0001` → 结果 = 1||||
|`|`|按位或|对应位有 1 则为 1，否则为 0|置 1 指定位|`5|3`→`0101|0011=0111` → 结果 = 7|
|`^`|按位异或|对应位不同则为 1，相同则为 0|交换变量、找唯一不同数|`5^3` → `0101^0011=0110` → 结果 = 6||||
|`~`|按位取反|所有位取反（0→1，1→0）|翻转所有位（注意符号问题）|`~5` → 无符号 = 250，有符号 =-6||||

### 重点：左移（<<）—— 子集和场景核心用法

- 计算 `2ⁿ` 最优写法：`1LL << n`（必须用`1LL`，避免 int 溢出）；
- 禁止左移负数位（如`1 << -1`），属于 C++ 未定义行为（程序崩溃 / 乱码）。

## 三、优先级（新手必记，避坑关键）

位运算优先级低于算术运算，**左移 / 右移** 与 **乘法 / 除法** 优先级相同，结合方向为「从左到右」。

### 易错对比（子集和代码示例）

|---|---|---|
|`v[i]*1 << n`|`v[i] * (1LL << n)`|避免优先级导致的意外结果|

## 四、高频实用场景（贴合实战）

### 1. 快速计算 2 的幂（子集和核心需求）

cpp

运行

```
ll pow2 = 1LL << n; // 等价于2ⁿ，无浮点误差，效率远高于pow(2,n)
```

✅ 替代`pow(2,n)`（浮点精度误差），✅ 替代循环乘法（效率低）。

### 2. 判断整数奇偶（比 % 更快）

cpp

运行

```
if (x & 1) { /* x是奇数 */ } 
else { /* x是偶数 */ }
```

### 3. 交换两个整数（无需临时变量）

cpp

运行

```
a ^= b; b ^= a; a ^= b; // 最终a、b互换值
```

### 4. 生成所有子集（进阶）

用`0~2ⁿ-1`的二进制表示子集（每一位表示是否选对应元素）：

cpp

运行

```
for (int mask = 0; mask < (1<<n); mask++) { // mask遍历所有子集
    for (int i = 0; i < n; i++) {
        if (mask & (1<<i)) { // 第i位为1 → 选第i个元素
            cout << i << " ";
        }
    }
}
```

## 五、避坑指南（新手高频踩坑）

1. **溢出问题**：
    
    - `int`型左移`31`位会溢出，必须用`long long`（`1LL << 31`）；
    
2. **负数位运算**：
    
    - 有符号数右移会补符号位（如`-5 >> 1 = -3`，非 - 2）；
    - 禁止左移 / 右移负数位（如`a << -1`）；
    
3. **优先级陷阱**：
    
    - 混合算术 / 位运算时，**强制用括号明确顺序**；
    
4. **按位取反符号**：
    
    - 有符号数取反结果为负数（如`~5=-6`），需强转无符号：`(unsigned int)~5`。
    

## 六、实战案例：集合所有子集元素之和（核心代码）

cpp

运行

```
#include <iostream>
#include <vector>
typedef long long ll;
using namespace std;

int main(){
    int a;
    vector<int> v;
    while(cin>>a) v.push_back(a);
    
    if(v.empty()) { cout << 0 << endl; return 0; }
    
    int n = v.size()-1;
    ll tot = 0;
    ll times = 1LL << n; // 核心：用1LL<<n算2ⁿ，无溢出/精度问题
    
    for(int num : v) tot += (ll)num * times;
    cout << tot << endl;
    return 0;
}
```

## 七、核心总结

1. 位运算核心价值：高效操作二进制，尤其适合「2 的幂计算」「状态表示」；
2. 子集和场景关键：`1LL << n` 计算每个元素的出现次数（2^(元素个数 - 1)）；
3. 避坑三要素：括号明确优先级、1LL 防溢出、禁止负数位运算。
