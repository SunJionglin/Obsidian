
# ==ab ? 1:0==

你写的这个表达式是**正确的 C++ 三目运算符用法**。

它的含义是：

- 先判断条件 `a == b` 是否成立
- 如果成立（真），则整个表达式的值为 `1`
- 如果不成立（假），则整个表达式的值为 `0`

等价于以下 if-else 语句：

cpp

运行

```cpp
int result;
if (a == b) {
    result = 1;
} else {
    result = 0;
}
```

例如：

- 当 `a = 5, b = 5` 时，表达式值为 `1`
- 当 `a = 3, b = 4` 时，表达式值为 `0`

这个表达式常用于简洁地表示 “相等则返回 1，不等则返回 0” 的逻辑。

编辑分享

a==b ? 1:0

`a==b ? 1:0` 的核心作用是**用简洁的语法判断两个值是否相等，并返回 1（相等）或 0（不相等）**，在变量赋值、数组初始化、函数返回、条件计数等场景中非常实用。以下是 5 个常见的运用示例，结合完整代码和运行结果说明：

### 示例 1：基础变量赋值（判断两个数是否相等）

场景：比较两个整数 `x` 和 `y` 是否相等，将结果（1/0）存入变量 `isEqual`，后续用该变量做逻辑判断。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 7, y = 7;
    // 用三目运算符直接赋值：x==y 为真，isEqual=1；为假则=0
    int isEqual = (x == y) ? 1 : 0; 

    cout << "x 和 y 是否相等？（1=是，0=否）：" << isEqual << endl;
    
    // 后续可通过 isEqual 做逻辑处理
    if (isEqual == 1) {
        cout << "执行相等时的操作" << endl;
    } else {
        cout << "执行不相等时的操作" << endl;
    }
    return 0;
}
```

**运行结果**：

plaintext

```plaintext
x 和 y 是否相等？（1=是，0=否）：1
执行相等时的操作
```

### 示例 2：数组初始化（标记数组中等于目标值的元素）

场景：创建一个数组，将其中等于 `target=5` 的元素标记为 1，其他标记为 0，快速生成 “匹配掩码”。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[] = {3, 5, 2, 5, 8};
    int target = 5;
    int len = sizeof(arr) / sizeof(arr[0]);
    int mask[len]; // 存储标记结果的数组

    // 遍历数组，用三目运算符初始化 mask
    for (int i = 0; i < len; i++) {
        mask[i] = (arr[i] == target) ? 1 : 0; 
    }

    // 输出结果
    cout << "原数组：";
    for (int num : arr) cout << num << " ";
    cout << "\n匹配掩码（1=等于5，0=不等于5）：";
    for (int m : mask) cout << m << " ";
    return 0;
}
```

**运行结果**：

plaintext

```plaintext
原数组：3 5 2 5 8 
匹配掩码（1=等于5，0=不等于5）：0 1 0 1 0 
```

### 示例 3：函数返回值（简化相等判断函数）

场景：写一个函数 `isSame`，接收两个参数，直接返回 1（相等）或 0（不相等），用三目运算符替代冗余的 `if-else`。

cpp

运行

```cpp
#include <iostream>
using namespace std;

// 函数：判断 a 和 b 是否相等，返回 1/0
int isSame(int a, int b) {
    // 三目运算符直接作为返回值，代码更简洁
    return (a == b) ? 1 : 0; 
}

int main() {
    cout << "isSame(4,4) = " << isSame(4,4) << endl;   // 输出 1
    cout << "isSame(6,9) = " << isSame(6,9) << endl;   // 输出 0
    cout << "isSame(0,0) = " << isSame(0,0) << endl;   // 输出 1
    return 0;
}
```

**运行结果**：

plaintext

```plaintext
isSame(4,4) = 1
isSame(6,9) = 0
isSame(0,0) = 1
```

### 示例 4：条件计数（统计数组中与目标值相等的元素个数）

场景：统计数组中等于 `key=2` 的元素数量，用三目运算符直接累加 1（匹配）或 0（不匹配）。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int nums[] = {2, 1, 2, 3, 2, 5};
    int key = 2;
    int count = 0; // 计数变量
    int len = sizeof(nums) / sizeof(nums[0]);

    // 遍历数组，每匹配一次加 1，否则加 0
    for (int i = 0; i < len; i++) {
        count += (nums[i] == key) ? 1 : 0; 
    }

    cout << "数组中等于 " << key << " 的元素个数：" << count << endl;
    return 0;
}
```

**运行结果**：

plaintext

```plaintext
数组中等于 2 的元素个数：3
```

### 示例 5：直接输出判断结果（无需中间变量）

场景：比较两个字符串的长度（或其他值），直接在 `cout` 中用三目运算符输出 “相等” 或 “不相等”，减少代码行数。

cpp

运行

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s1 = "hello", s2 = "world";
    
    // 直接在输出中用三目运算符：先判断长度是否相等，再输出对应文字
    cout << "s1 和 s2 长度" << ((s1.size() == s2.size()) ? "相等" : "不相等") << endl;
    
    // 再比较内容是否相等
    cout << "s1 和 s2 内容" << ((s1 == s2) ? "相等" : "不相等") << endl;
    return 0;
}
```

**运行结果**：

plaintext

```plaintext
s1 和 s2 长度相等
s1 和 s2 内容不相等
```

### 核心总结

`a==b ? 1:0` 的本质是 **“相等性判断的简洁表达”**，所有需要判断 “是否相等” 并返回 1/0 的场景都能用它替代 `if-else`，让代码更紧凑。注意：表达式外的括号可加可不加（C++ 优先级规则中，三目运算符优先级低于 `==`），但加括号能提高可读性。
