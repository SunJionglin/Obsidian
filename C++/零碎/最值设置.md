# 设置一个整数的最大值
在 C++ 里**快速设置一个整数的最大值**，有 3 种最常用、最标准的方法，我直接给你最实用的写法，拿来就能用。

# 1. 最标准、最推荐（C++11 及以上）

cpp

```cpp
#include <limits>

int max_int = std::numeric_limits<int>::max();
```

  

- 这是**官方、安全、无坑**的写法
- 适用于 `int` / `long` / `long long` / `unsigned` 等所有整数类型

# 2. 最快、最简洁（老代码常用）

cpp

```cpp
#include <climits>

int max_int = INT_MAX;
```

  

- 直接用宏 `INT_MAX`
- 最简短，面试 / 刷题最常用

# 3. 如果你用 long long

cpp

```cpp
#include <climits>
long long max_ll = LLONG_MAX;
```

---

# 快速对照表（直接复制）

cpp

```cpp
int a = INT_MAX;               // int 最大值
long b = LONG_MAX;             // long 最大值
long long c = LLONG_MAX;       // long long 最大值
unsigned int d = UINT_MAX;     // 无符号 int 最大值
```

---

# 小知识

- `INT_MAX` ≈ **2147483647**
- 一般用来做**初始化最小值、无穷大、DP 初始值**等场景

---

### 总结

- 想**最标准**：用 `std::numeric_limits<int>::max()`
- 想**最快最简洁**：用 `INT_MAX`
- 都需要包含头文件：`<climits>` 或 `<limits>`

当然有！**整数最小值**和最大值用法完全对应，我直接给你**最快、最标准、拿来就能用**的写法👇

# C++ 整数最小值（完整版）

## 1. 最快写法（刷题 / 比赛首选）

cpp

```cpp
#include <climits>

int min_int = INT_MIN;         // int 最小值
long min_long = LONG_MIN;      // long 最小值
long long min_ll = LLONG_MIN;  // long long 最小值
```

## 2. 最标准写法（C++ 推荐）

cpp

```cpp
#include <limits>

int min_int = std::numeric_limits<int>::min();
```

---

# 速查表（直接复制）

cpp

```cpp
int      a = INT_MIN;    // -2147483648
long     b = LONG_MIN;
long long c = LLONG_MIN;
```

---

# 小提醒（很重要）

- **有符号整数**：最小值是 **负数**
- `INT_MIN = -2147483648`
- 一般用来做**初始化最大值、DP 边界、比较初始值**

---

### 总结

- 最小值：**INT_MIN**
- 最大值：**INT_MAX**
- 头文件都只需要：`<climits>`
