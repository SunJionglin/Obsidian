// 读取所有输入行并拼接（处理多行输入） 
```cpp
while (getline(cin, line)) { str += line; }
```


这段代码的作用是读取标准输入中的所有行，并将它们拼接成一个字符串 `str`。以下是一些需要注意的细节和说明：

### 核心逻辑

- `getline(cin, line)` 用于从标准输入流 `cin` 中读取一整行内容（包括空格，但不包含换行符 `\n`），并存储到字符串 `line` 中。
- 循环条件 `while (getline(cin, line))` 表示：只要成功读取到一行（未遇到输入结束标志），就继续循环。
- 每次读取后，将当前行 `line` 追加到 `str` 中，实现多行内容的拼接。

### 注意事项

1. **换行符的处理**
    
    `getline` 读取时会丢弃行尾的换行符 `\n`，因此拼接后的 `str` 中**不会保留原始输入的换行分隔符**。
    
    若需要保留换行符，可修改为：
    
    cpp
    
    运行
    
    ```cpp
    str += line + '\n';  // 每行后手动添加换行符
    ```
    
    （但此时最后一行会多一个多余的换行符，需根据需求处理）
    
2. **输入结束的标志**
    
    在终端中，输入结束需手动触发：
    
    - Windows 系统：按 `Ctrl + Z` 后回车。
    - Linux/Mac 系统：按 `Ctrl + D`。
3. **字符串初始化**
    
    需确保 `str` 已正确初始化（如 `std::string str;`），否则可能导致未定义行为。
    

### 示例

若输入：

plaintext

```plaintext
hello
world
123
```

- 原代码拼接后 `str` 为：`"helloworld123"`
- 若添加换行符，则 `str` 为：`"hello\nworld\n123\n"`

根据实际需求（是否保留换行），可调整代码逻辑。

## 如果输入中有空格，这段代码会如何处理？

已完成思考

这段代码会**完整保留输入中的空格**，因为 `getline(cin, line)` 的特性是读取一整行内容（包括该行中的所有空格），直到遇到换行符 `\n` 为止。

具体来说：

`getline` 与 `cin >>` 不同：

- `cin >>` 读取时会自动忽略空格、制表符、换行符等空白字符，只读取非空白内容；
- 而 `getline` 会读取**从当前位置到换行符之前的所有字符**（包括空格、制表符等），并将这些字符完整存入 `line` 中。

### 示例

若输入内容为：

plaintext

```plaintext
hello world
foo bar 123
```

- 第一行 `line` 会被读取为 `"hello world"`（包含中间的空格）；
- 第二行 `line` 会被读取为 `"foo bar 123"`（包含两个空格）；
- 拼接后 `str` 的结果为 `"helloworldfoo bar 123"`（保留了所有原始空格，仅去除了换行符）。

因此，无论输入中包含多少空格（同一行内的），这段代码都会将它们完整保留在拼接后的字符串中。
