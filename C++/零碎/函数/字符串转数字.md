# C++ 字符串转数字 考试笔记

考试核心重点：掌握3个常用字符串转数字函数（stoi、stof、stod），理解其作用、用法、区别及异常情况，补充扩展相关转换场景，避免考试踩坑。

## 一、核心3个转换函数（考试必考）

|函数名|核心作用|数据类型转换|示例|考试注意点|
|---|---|---|---|---|
|stoi|将字符串转换为整数（int类型）|string → int|stoi("123") → 123；stoi("-456") → -456|1. 仅能转换纯整数字符串，含小数或字母会报错；2. 超出int范围（-2147483648~2147483647）会报错|
|stof|将字符串转换为单精度小数（float类型）|string → float|stof("4.321") → 4.321；stof("100.0") → 100.0f|1. 可转换含小数的字符串，整数字符串也可转换（自动补小数位）；2. 精度有限（约6-7位有效数字）|
|stod|将字符串转换为双精度小数（double类型）|string → double|stod("4.321") → 4.321；stod("0.0000123456") → 0.0000123456|1. 精度高于stof（约15-17位有效数字）；2. 考试中需区分float和double的使用场景（高精度计算用stod）|

## 二、函数用法细节（考试易考）

### 1. 语法格式（统一模板）

函数名(字符串变量/字符串常量)，返回对应数据类型的值，示例代码（考试可直接套用）：

```cpp
#include <iostream>
#include <string> // 必须包含string头文件，否则无法使用转换函数
using namespace std;

int main() {
    string s1 = "12345";
    string s2 = "3.14159";
    string s3 = "123.456789012345";
    
    int num1 = stoi(s1);       // 正确：num1 = 12345
    float num2 = stof(s2);     // 正确：num2 ≈ 3.14159
    double num3 = stod(s3);    // 正确：num3 = 123.456789012345
    
    cout << num1 << endl;
    cout << num2 << endl;
    cout << num3 << endl;
    return 0;
}
```

### 2. 常见错误及规避方法（考试高频错题）

- 错误1：忘记包含<string>头文件 → 解决：必须在代码开头添加#include <string>
    
- 错误2：字符串含非数字字符（如"123a"、"4.5b"） → 解决：转换前确保字符串仅含数字、正负号、小数点（且小数点仅1个）
    
- 错误3：转换值超出对应类型范围（如stoi("2147483648")，超出int最大值） → 解决：超大整数用stol（转long），超大小数用stod
    
- 错误4：混淆stof和stod的精度 → 解决：题目要求“高精度小数”用stod，普通小数用stof即可
    

  ## 三、扩展补充（考试可能延伸）

### 1. 其他常用转换函数（了解即可，偶尔考）

- stol：string → long（解决int范围不足的问题，如stol("10000000000")）
    
- stoll：string → long long（更大范围的整数转换）
    
- atof：string → double（与stod功能类似，语法：atof(s.c_str())，需额外转换为C风格字符串）
    
- atoi：string → int（与stoi功能类似，语法：atoi(s.c_str())）
    

### 2. 反向转换（数字转字符串，补充记忆，避免混淆）

考试中可能结合反向转换考查，核心函数：to_string()，可将任意数字类型转为string：

```cpp
int a = 123;
float b = 4.56;
double c = 7.890123;
string s1 = to_string(a); // s1 = "123"
string s2 = to_string(b); // s2 = "4.560000"（float默认保留6位小数）
string s3 = to_string(c); // s3 = "7.890123"（double保留更多小数）
```

### 3. 实战易错点总结（考试必看）

1. 所有转换函数仅能处理“合法数字字符串”，非法字符串（如"abc"、"12.3.4"）会导致程序崩溃；

2. stof和stod转换整数字符串时，会自动转为对应小数（如stof("100") → 100.0f）；

3. 考试中若题目明确要求“整数”，用stoi；要求“小数”，优先看精度，高精度用stod，普通精度用stof。
