在 C 和 C++ 编程语言中，`size_t` 是一个**无符号整数类型**，主要用于表示对象的大小（如内存块大小、数组长度、索引等），其定义包含在 `<stddef.h>`、`<stdlib.h>` 等标准头文件中。

### 核心特性：

1. **无符号性**：`size_t` 是无符号类型（非负整数），这是因为 “大小” 或 “索引” 本质上不可能为负数，用无符号类型更符合逻辑。
    
2. **平台相关性**：`size_t` 的具体底层类型（如 `unsigned int`、`unsigned long` 等）取决于系统架构：
    
    - 32 位系统中，通常等价于 `unsigned int`（4 字节）；
    - 64 位系统中，通常等价于 `unsigned long`（8 字节）。
        
        标准仅规定它必须能容纳当前系统中 “最大对象的大小”（即足够表示任何内存块的字节数）。

### 典型用途：

- `sizeof` 运算符的返回值类型是 `size_t`（用于表示变量 / 类型占用的字节数）。
- 内存分配函数（如 `malloc`、`calloc`）的参数类型是 `size_t`（表示要分配的字节数）。
- 字符串长度函数 `strlen` 的返回值类型是 `size_t`（表示字符串的字符数）。
- 数组索引或循环变量（尤其当索引范围可能接近系统最大内存大小时）。

### 注意事项：

- **无符号运算风险**：由于是无符号类型，若与负数运算或比较，可能导致逻辑错误。例如：
    
    c
    
    运行
    
    ```c
    int i = -1;
    size_t s = 1;
    if (i < s) {  // 错误：i 会被隐式转换为无符号数（极大值），条件实际为 false
        // ...
    }
    ```
    
- 避免混用 `size_t` 与有符号类型（如 `int`）进行运算或比较，可能引发未定义行为或逻辑错误。

总之，`size_t` 是为 “表示大小 / 索引” 设计的类型，使用它能提高代码的可移植性和逻辑合理性。
