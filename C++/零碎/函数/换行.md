在 C++ 中，换行可以通过多种方式实现，具体取决于使用的是 **C++ 风格的输入输出（`iostream`）** 还是 **C 风格的输入输出（`cstdio`）**。以下是最常用的换行方法及区别：

### 一、通用方式：转义字符 `\n`

`\n` 是 C/C++ 中最基础的换行转义字符，可在任何输出语句中使用，本质是插入一个 “换行符”，让光标移到下一行开头。

#### 1. 在 C++ 风格 `cout` 中使用

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "第一行\n";  // 用 \n 换行
    cout << "第二行\n第三行";  // ==可在同一行字符串中直接插入==
    return 0;
}
```

输出：

plaintext

```plaintext
第一行
第二行
第三行
```

#### 2. 在 C 风格 `printf` 中使用

cpp

运行

```cpp
#include <cstdio>

int main() {
    printf("第一行\n");  // 字符串中直接加 \n
    printf("第二行\n第三行");
    return 0;
}
```

输出与上面完全相同。

### 二、C++ 特有：操纵符 `endl`

`endl` 是 `<iostream>` 库提供的操纵符（需包含头文件），功能是 **换行 + 刷新输出缓冲区**。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "第一行" << endl;  // 换行并刷新缓冲区
    cout << "第二行" << endl;
    return 0;
}
```

输出：

plaintext

```plaintext
第一行
第二行
```

### 三、`\n` 与 `endl` 的核心区别

|特点|`\n`|`endl`|
|---|---|---|
|功能|仅换行|换行 + 刷新输出缓冲区|
|效率|更高（不触发刷新）|略低（额外的刷新操作）|
|适用场景|大多数普通输出|需要立即显示结果的场景|

- **缓冲区**：输出内容通常会先存到缓冲区，满了才会真正显示到屏幕。`endl` 会强制刷新，确保内容立即显示（如日志输出、实时进度）。
- **性能影响**：频繁使用 `endl`（如循环中）可能降低效率，此时推荐用 `\n`。
