在 C++ 中，若想让数组的一个元素同时包含两个变量（即一个元素存储两组相关数据），可以通过以下几种方式实现，核心思路是将两个变量 “打包” 成一个复合类型，再用数组存储这种复合类型：

### 方法 1：使用结构体（struct）（最常用）

自定义一个结构体，包含两个成员变量，再创建该结构体的数组。适合需要给两个变量命名（如 x/y、key/value 等）的场景。

cpp

运行

```cpp
#include <iostream>
using namespace std;

// 定义结构体，包含两个变量（例如x和y）
struct Pair {
    int a;  // 第一个变量
    int b;  // 第二个变量
};

int main() {
    // 创建存储结构体的数组（长度为3）
    Pair arr[3];
    
    // 给数组元素赋值（每个元素包含两个变量）
    arr[0].a = 10;
    arr[0].b = 20;
    
    arr[1].a = 30;
    arr[1].b = 40;
    
    arr[2].a = 50;
    arr[2].b = 60;
    
    // 访问数组元素中的两个变量
    cout << "arr[1]的两个变量：" << arr[1].a << ", " << arr[1].b << endl;  // 输出 30, 40
    
    return 0;
}
```

### 方法 2：使用标准库的`pair`（简洁，适合两个元素）

C++ 标准库提供了`pair`模板，专门用于存储两个元素（无需自定义结构体），第一个元素用`first`访问，第二个用`second`访问。

cpp

运行

```cpp
#include <iostream>
#include <utility>  // 必须包含该头文件
using namespace std;

int main() {
    // 创建存储pair的数组（每个pair包含两个int）
    pair<int, int> arr[3];
    
    // 给数组元素赋值
    arr[0] = {10, 20};  // 第一种赋值方式
    arr[1].first = 30;  // 第二种赋值方式
    arr[1].second = 40;
    arr[2] = make_pair(50, 60);  // 第三种赋值方式（推荐）
    
    // 访问元素
    cout << "arr[2]的两个变量：" << arr[2].first << ", " << arr[2].second << endl;  // 输出 50, 60
    
    return 0;
}
```

### 方法 3：使用二维数组（模拟 “两个变量”，适合简单场景）

若两个变量是同类型且无需明确命名，可用二维数组的一行代表 “包含两个变量的元素”（本质是数组的数组）。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    // 二维数组：3个元素，每个元素是包含2个int的数组
    int arr[3][2] = {
        {10, 20},  // 第一个元素包含10和20
        {30, 40},  // 第二个元素包含30和40
        {50, 60}   // 第三个元素包含50和60
    };
    
    // 访问元素中的两个变量（通过列索引0和1）
    cout << "arr[0]的两个变量：" << arr[0][0] << ", " << arr[0][1] << endl;  // 输出 10, 20
    
    return 0;
}
```

### 三种方法对比

|方法|优点|缺点|适用场景|
|---|---|---|---|
|结构体|可自定义成员名称，扩展性强|需要提前定义结构体|需明确区分两个变量（如坐标 x/y）|
|pair|无需自定义，简洁高效|只能存储两个元素，无明确名称|简单的键值对、成对数据|
|二维数组|语法最简单，无需额外类型|变量无名称，仅靠索引区分|两个变量逻辑相似（如数组下标）|

根据需求选择即可，日常开发中**结构体**和**pair**更常用，尤其是结构体，灵活性最高（还可扩展为包含 3 个及以上变量）。
