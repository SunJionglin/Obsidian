

在 C/C++ 中，存储坐标（如二维坐标 `(x,y)`、三维坐标 `(x,y,z)`）最直观的方式是使用**二维数组**，其中每个子数组代表一个坐标的多个分量（如 x、y 值）。以下是具体实现方法和示例：

## 一、存储二维坐标（x, y）

二维坐标由两个分量（x 和 y）组成，可用 `数据类型 数组名[坐标数量][2]` 的形式存储，其中第二个维度固定为 2（分别对应 x 和 y）。

### 1. 定义与初始化

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    // 定义一个存储3个二维坐标的数组：每个坐标是(x,y)
    // 格式：[坐标数量][2]，2表示x和y两个分量
    int coords[3][2] = {
        {10, 20},   // 第一个坐标 (10,20)
        {30, 40},   // 第二个坐标 (30,40)
        {50, 60}    // 第三个坐标 (50,60)
    };

    return 0;
}
```

### 2. 访问坐标分量

通过双重下标访问：

- `coords[i][0]`：第 i 个坐标的 x 分量
- `coords[i][1]`：第 i 个坐标的 y 分量

cpp

运行

```cpp
// 访问并打印所有坐标
for (int i = 0; i < 3; i++) {
    // 第i个坐标的x是coords[i][0]，y是coords[i][1]
    cout << "坐标" << i << "：(" << coords[i][0] << ", " << coords[i][1] << ")" << endl;
}
```

**输出结果**：

plaintext

```plaintext
坐标0：(10, 20)
坐标1：(30, 40)
坐标2：(50, 60)
```

### 3. 动态修改坐标

直接通过下标赋值修改：

cpp

运行

```cpp
// 修改第二个坐标为(35, 45)
coords[1][0] = 35;  // 修改x分量
coords[1][1] = 45;  // 修改y分量

cout << "修改后坐标1：(" << coords[1][0] << ", " << coords[1][1] << ")" << endl;
// 输出：修改后坐标1：(35, 45)
```

## 二、存储三维坐标（x, y, z）

三维坐标包含 x、y、z 三个分量，只需将数组第二个维度改为 3 即可：

cpp

运行

```cpp
int main() {
    // 存储2个三维坐标：[坐标数量][3]
    double threeDCoords[2][3] = {
        {1.5, 2.6, 3.7},   // (1.5, 2.6, 3.7)
        {4.8, 5.9, 6.0}    // (4.8, 5.9, 6.0)
    };

    // 访问第三个分量z
    for (int i = 0; i < 2; i++) {
        cout << "三维坐标" << i << "：(" 
             << threeDCoords[i][0] << ", "   // x
             << threeDCoords[i][1] << ", "   // y
             << threeDCoords[i][2] << ")"    // z
             << endl;
    }
    return 0;
}
```

**输出结果**：

plaintext

```plaintext
三维坐标0：(1.5, 2.6, 3.7)
三维坐标1：(4.8, 5.9, 6)
```

## 三、进阶：用结构体配合数组（更直观）

如果需要更清晰地表示坐标（如通过 `coord.x`、`coord.y` 访问），可以定义**结构体**，再用结构体数组存储：

cpp

运行

```cpp
#include <iostream>
using namespace std;

// 定义坐标结构体
struct Coordinate {
    int x;  // x分量
    int y;  // y分量
};

int main() {
    // 结构体数组：存储4个坐标
    Coordinate points[4] = {
        {0, 0},    // (0,0)
        {100, 200}, // (100,200)
        {300, 400}, // (300,400)
        {500, 600}  // (500,600)
    };

    // 访问方式更直观
    cout << "第二个点的x：" << points[1].x << endl;  // 输出：100
    cout << "第三个点的y：" << points[2].y << endl;  // 输出：400

    return 0;
}
```

## 总结

1. **基础方法**：用二维数组 `[n][2]` 存储 n 个二维坐标（`[n][3]` 存储三维坐标），通过 `[i][0]`/`[i][1]` 访问 x/y。
2. **推荐方法**：定义结构体封装坐标分量，再用结构体数组存储，代码可读性更高（尤其适合复杂场景）。
3. 适用场景：图形学（点、顶点）、游戏开发（角色位置）、地理信息（经纬度）等需要批量存储位置信息的场景。
