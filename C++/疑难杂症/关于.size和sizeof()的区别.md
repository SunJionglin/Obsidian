

在 C/C++ 中，`.size()` 和 `sizeof()` 是两个完全不同的概念，用途、适用场景和实现机制都有本质区别。以下从核心区别、用法示例和常见误区三个方面详细说明：

## 一、核心区别

|特性|`sizeof()`|`.size()`|
|---|---|---|
|**性质**|C/C++ 内置的**运算符**（不是函数）|C++ 标准库容器的**成员函数**|
|**作用**|计算**内存字节数**（变量 / 类型 / 表达式在内存中占用的字节）|计算**容器中元素的个数**|
|**结果确定时机**|编译时确定（静态计算，不依赖运行时数据）|运行时确定（动态计算，依赖容器当前状态）|
|**适用对象**|基本数据类型（int、double 等）、数组、结构体、指针、对象等|C++ 标准库容器（vector、string、list、map 等）|
|**语法形式**|`sizeof(类型)` 或 `sizeof(变量)`（变量可省略括号）|`容器对象.size()`（必须通过容器实例调用，带括号）|

## 二、用法示例

### 1. `sizeof()` 的用法

`sizeof()` 用于计算内存占用，结果是 “字节数”，编译时就已确定。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. 基本数据类型
    cout << sizeof(int) << endl;        // 输出：4（int通常占4字节）
    cout << sizeof(double) << endl;     // 输出：8（double通常占8字节）

    // 2. 数组（计算整个数组的总字节数）
    int arr[5] = {1, 2, 3, 4, 5};
    cout << sizeof(arr) << endl;        // 输出：20（5个int，5×4=20字节）
    cout << sizeof(arr[0]) << endl;     // 输出：4（单个元素的字节数）
    // 用sizeof计算数组元素个数（总字节数/单个元素字节数）
    cout << "数组元素个数：" << sizeof(arr)/sizeof(arr[0]) << endl;  // 输出：5

    // 3. 结构体
    struct Student {
        int id;
        char name[20];
    };
    cout << sizeof(Student) << endl;    // 输出：24（int占4 + char[20]占20）

    return 0;
}
```

### 2. `.size()` 的用法

`.size()` 是 C++ 容器的成员函数，用于返回容器中当前存储的 “元素个数”，结果在运行时确定（随容器元素增减而变化）。

cpp

运行

```cpp
#include <iostream>
#include <vector>   // 需包含vector头文件
#include <string>   // 需包含string头文件
using namespace std;

int main() {
    // 1. vector容器
    vector<int> vec = {10, 20, 30};
    cout << vec.size() << endl;         // 输出：3（当前有3个元素）
    vec.push_back(40);                  // 新增一个元素
    cout << vec.size() << endl;         // 输出：4（元素个数变为4）

    // 2. string（本质是字符容器）
    string str = "hello";
    cout << str.size() << endl;         // 输出：5（有5个字符）
    str += " world";
    cout << str.size() << endl;         // 输出：11（字符数变为11）

    return 0;
}
```

## 三、常见误区

1. **混淆 “字节数” 和 “元素个数”**
    
    - `sizeof(arr)` 对数组返回总字节数，而非元素个数（需手动计算 `sizeof(arr)/sizeof(arr[0])`）。
    - `.size()` 对容器直接返回元素个数，无需额外计算。
2. **数组不能用 `.size()`**
    
    - 数组是 C 风格的静态结构，没有成员函数，因此 `arr.size()` 会报错。
    - 只有 C++ 标准库容器（vector、string 等）才有 `.size()` 方法。
3. **容器不能用 `sizeof()` 获取元素个数**
    
    - `sizeof(vec)` 计算的是 `vector` 容器对象本身的内存大小（而非元素总大小），与元素个数无关。例如：
        
        cpp
        
        运行
        
        ```cpp
        vector<int> vec(100);
        cout << sizeof(vec) << endl;  // 输出：16（64位系统中vector对象本身占16字节，与元素数无关）
        ```
        
4. **`sizeof()` 对指针的特殊性**
    
    - 对指针使用 `sizeof()` 时，返回的是指针本身的内存大小（通常 4 或 8 字节），而非指向对象的大小：
        
        cpp
        
        运行
        
        ```cpp
        int arr[5];
        int* p = arr;
        cout << sizeof(arr) << endl;  // 输出：20（数组总字节数）
        cout << sizeof(p) << endl;    // 输出：8（64位系统中指针占8字节）
        ```
        

## 总结

- `sizeof()` 是编译时运算符，用于计算**内存字节数**，适用于所有数据类型（基本类型、数组、结构体等）。
- `.size()` 是 C++ 容器的运行时成员函数，用于返回**元素个数**，仅适用于标准库容器（vector、string 等）。
- 记住：数组用 `sizeof(arr)/sizeof(arr[0])` 算元素数，容器用 `.size()` 算元素数，二者不可混用。
