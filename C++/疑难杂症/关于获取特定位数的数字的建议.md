
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;  // 读取四位数的个数
    int count = 0;  // 计数器，记录满足条件的数的个数
    
    for (int i = 0; i < n; i++) {
        int num;
        cin >> num;  // 读取每个四位数
        
        // 分解四位数的各个数位
        int a = num / 1000;                // 千位数字
        int remainder = num % 1000;        // 去除千位后剩余的三位数
        int b = remainder / 100;           // 百位数字
        remainder = remainder % 100;       // 去除百位后剩余的两位数
        int c = remainder / 10;            // 十位数字
        int d = remainder % 10;            // 个位数字
        
        // 判断条件：个位数 - 千位数 - 百位数 - 十位数 > 0
        if (d - a - b - c > 0) {
            count++;  // 满足条件则计数器加1
        }
    }
    
    cout << count << endl;  // 输出满足条件的个数
    return 0;
}
```
### 逐行解释：

1. **千位数字（a）的提取**
    
    cpp
    
    运行
    
    ```cpp
    int a = num / 1000;
    ```
    
    - 原理：四位数的千位是最高位，数值范围是 1~9（如 1234 的千位是 1）。
    - 计算逻辑：用原数 `num` 除以 1000（整数除法，自动舍去小数），得到的商就是千位数字。
    - 示例：若 `num=1234`，则 `1234 / 1000 = 1` → `a=1`。
2. **去除千位后剩余的三位数（remainder）**
    
    cpp
    
    运行
    
    ```cpp
    int remainder = num % 1000;
    ```
    
    - 原理：`%` 是取余运算符，`num % 1000` 得到的是 `num` 除以 1000 后的余数，即去除千位后的后三位数字。
    - 示例：`num=1234` 时，`1234 % 1000 = 234` → `remainder=234`（此时剩下 “234”，即原数的后三位）。
3. **百位数字（b）的提取**
    
    cpp
    
    运行
    
    ```cpp
    int b = remainder / 100;
    ```
    
    - 原理：经过步骤 2 后，`remainder` 是一个三位数（或更少），用它除以 100 的商就是百位数字。
    - 示例：`remainder=234` 时，`234 / 100 = 2` → `b=2`（即原数 1234 的百位是 2）。
4. **去除百位后剩余的两位数（更新 remainder）**
    
    cpp
    
    运行
    
    ```cpp
    remainder = remainder % 100;
    ```
    
    - 原理：对当前 `remainder` 取余 100，得到去除百位后的后两位数字。
    - 示例：`remainder=234` 时，`234 % 100 = 34` → 新的 `remainder=34`（剩下 “34”，即原数的后两位）。
5. **十位数字（c）的提取**
    
    cpp
    
    运行
    
    ```cpp
    int c = remainder / 10;
    ```
    
    - 原理：经过步骤 4 后，`remainder` 是一个两位数（或更少），用它除以 10 的商就是十位数字。
    - 示例：`remainder=34` 时，`34 / 10 = 3` → `c=3`（即原数 1234 的十位是 3）。
6. **个位数字（d）的提取**
    
    cpp
    
    运行
    
    ```cpp
    int d = remainder % 10;
    ```
    
    - 原理：对当前 `remainder` 取余 10，得到的余数就是个位数字（因为两位数除以 10 的余数一定是个位数）。
    - 示例：`remainder=34` 时，`34 % 10 = 4` → `d=4`（即原数 1234 的个位是 4）。

### 核心逻辑总结：

这部分代码通过 **“整数除法（/）提取高位，取余运算（%）保留低位”** 的组合，从四位数中依次拆分出千位（a）、百位（b）、十位（c）、个位（d）。整个过程利用了十进制数的 “位权” 特性（千位 = 1000，百位 = 100，十位 = 10，个位 = 1），是处理多位数数位分解的经典方法。

例如，对于四位数 `6119`：

- 千位 `a = 6119 / 1000 = 6`
- 剩余 `remainder = 6119 % 1000 = 119`
- 百位 `b = 119 / 100 = 1`
- 剩余 `remainder = 119 % 100 = 19`
- 十位 `c = 19 / 10 = 1`
- 个位 `d = 19 % 10 = 9`
