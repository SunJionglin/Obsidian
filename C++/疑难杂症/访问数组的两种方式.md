```cpp
#include <iostream>
#include <vector> // 需包含头文件

int main() {
    // 1. 创建vector
    std::vector<int> numbers; // 空向量
    std::vector<std::string> fruits = {"apple", "banana"}; // 初始化

    // 2. 添加元素
    numbers.push_back(10); // 在末尾添加
    numbers.push_back(20);
    numbers.push_back(30);

    // 3. 访问元素（支持[]和at()）
    std::cout << "第一个元素: " << numbers[0] << std::endl;
    std::cout << "第二个元素: " << numbers.at(1) << std::endl;//这里

    // 4. 遍历元素
    std::cout << "所有元素: ";
    for (int num : numbers) { // 范围for循环
        std::cout << num << " ";
    }
    std::cout << std::endl;

    // 5. 其他常用操作
    std::cout << "元素数量: " << numbers.size() << std::endl; // 元素个数
    numbers.pop_back(); // 删除最后一个元素
    std::cout << "删除后数量: " << numbers.size() << std::endl;

    return 0;
}
```



为什么不是numbers[1]

在 C++ 的 `std::vector` 中，`numbers[1]` 和 `numbers.at(1)` 都可以用来访问索引为 1 的元素，**在索引有效的情况下，两者的结果完全相同**（在你提供的代码中，`numbers` 包含 `10, 20, 30`，索引 1 是有效的，所以用 `numbers[1]` 也能正确输出 20）。

它们的核心区别在于 **边界检查机制**：

- `numbers[1]` 使用 `[]` 运算符，**不进行边界检查**。如果索引超出了 vector 的有效范围（比如访问 `numbers[10]`，而 vector 实际只有 3 个元素），会导致 **未定义行为**（可能崩溃、输出垃圾值，或产生其他不可预测的结果）。
- `numbers.at(1)` 使用 `at()` 成员函数，**会进行边界检查**。如果索引无效（超出范围），会主动抛出 `std::out_of_range` 异常，便于捕获和处理错误（例如通过 `try-catch` 块），避免程序直接崩溃。

简单说：

- 用 `[]` 更高效（少了检查开销），但不安全；
- 用 `at()` 稍慢，但更安全（尤其在索引可能无效的场景，比如用户输入的索引）。
