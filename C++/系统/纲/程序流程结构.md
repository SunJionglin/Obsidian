C/C++ 支持三种最基本的程序运行结构，所有复杂程序均可基于这三种结构组合实现：**顺序结构、选择结构、循环结构**。

## 一、三种基本程序结构

|结构类型|核心特点|
|---|---|
|顺序结构|程序按代码书写顺序依次执行，无跳转、无分支|
|选择结构|依据条件是否满足，选择性执行不同代码块（“二选一” 或 “多选一”）|
|循环结构|依据条件是否满足，重复执行某段代码（“重复做”）|

## 二、选择结构：依据条件执行代码

选择结构用于处理 “判断后执行” 的场景，核心语法包括 `if` 语句、[[三目运算符]]、`switch` 语句。

### 2.1 if 语句：灵活的条件判断

`if` 语句是最常用的选择结构，支持单条件、多条件及嵌套判断，分为三种形式：

#### 2.1.1 单行格式 if 语句

**作用**：满足条件则执行单行代码（适合简单判断）

**语法**：`if(条件){ 条件满足时执行的语句 }`

> ⚠️ 注意：if 条件表达式后**不要加分号**，否则会导致代码块与条件脱钩。

**示例：判断高考分数是否过一本线**

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    // 输入分数
    int score = 0;  
    cout << "请输入一个分数：" << endl;  
    cin >> score;  
    cout << "您输入的分数为： " << score << endl;  

    // 单行if判断：分数>600则打印“考上一本”
    if (score > 600)  
    {  
        cout << "我考上了一本大学！！！" << endl;  
    }  

    system("pause");  
    return 0;  
}
```

#### 2.1.2 多行格式 if 语句

**作用**：满足条件执行 A 代码块，不满足执行 B 代码块（“二选一”）

**语法**：`if(条件){ 满足条件执行 }else{ 不满足条件执行 }`

**示例：判断是否考上一本大学**

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    int score = 0;  
    cout << "请输入考试分数：" << endl;  
    cin >> score;  

    if (score > 600)  
    {  
        cout << "我考上了一本大学" << endl;  
    }  
    else  
    {  
        cout << "我未考上一本大学" << endl;  
    }  

    system("pause");  
    return 0;  
}
```

#### 2.1.3 多条件 if 语句

**作用**：处理多个条件的 “多选一” 场景

**语法**：`if(条件1){ 执行1 }else if(条件2){ 执行2 }...else{ 都不满足执行 }`

**示例：多档位分数判断（一本 / 二本 / 三本 / 未本科）**

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    int score = 0;  
    cout << "请输入考试分数：" << endl;  
    cin >> score;  

    if (score > 600)  
    {  
        cout << "我考上了一本大学" << endl;  
    }  
    else if (score > 500)  
    {  
        cout << "我考上了二本大学" << endl;  
    }  
    else if (score > 400)  
    {  
        cout << "我考上了三本大学" << endl;  
    }  
    else  
    {  
        cout << "我未考上本科" << endl;  
    }  

    system("pause");  
    return 0;  
}
```

#### 2.1.4 嵌套 if 语句

**练习案例：一本分数内细分名校**

需求：分数 > 600 为一本，其中 > 700 = 北大，>650 = 清华，否则 = 人大；其他分数按原规则判断。

#### 2.1.5 练习：三只小猪称体重

cpp

```cpp
    system("pause");

}
```

### 2.2 [[三目运算符]]：简洁的二选一判断

**作用**：用一行代码实现简单的 “二选一” 逻辑，返回其中一个结果

**语法**：`表达式1 ? 表达式2 : 表达式3`

- 若「表达式 1」为真（非 0），执行「表达式 2」并返回其结果；
- 若「表达式 1」为假（0），执行「表达式 3」并返回其结果。

**示例：比较两个数的大小并赋值**

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    int a = 10, b = 20, c = 0;  

    // 1. 基本用法：将a和b中的较大值赋值给c
    c = (a > b) ? a : b;  
    cout << "c = " << c << endl;  // 输出：c = 20

    // 2. C++特性：[[三目运算符]]返回变量，可直接赋值
    (a > b ? a : b) = 100;  // 将较大值（b）改为100
    cout << "a = " << a << endl;  // 输出：a = 10
    cout << "b = " << b << endl;  // 输出：b = 100

    system("pause");  
    return 0;  
}
```

> 📌 总结：[[三目运算符]]的优点是简洁，缺点是嵌套使用时可读性差（不建议嵌套）。

### 2.3 switch 语句：多分支固定值判断

**作用**：处理 “多个固定值匹配” 的场景（如菜单选择、评分等级），结构比多条件 `if` 更清晰

**语法**：

cpp

运行

```cpp
switch(表达式)  
{  
    case 结果1: 执行语句; break;  
    case 结果2: 执行语句; break;  
    // ... 更多case
    default: 执行语句; break;  // 所有case不匹配时执行
}
```

**示例：电影评分判断**

需求：10~9 = 经典，8~7 = 非常好，6~5 = 一般，5 分以下 = 烂片。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    int score = 0;  
    cout << "请给电影打分（0~10）：" << endl;  
    cin >> score;  

    switch (score)  
    {  
        case 10:  // 10和9共用同一逻辑
        case 9:  
            cout << "经典" << endl;  
            break;  // 跳出switch，避免向下执行
        case 8:  
            cout << "非常好" << endl;  
            break;  
        case 7:  // 7和6共用同一逻辑
        case 6:  
            cout << "一般" << endl;  
            break;  
        default:  // 0~5分
            cout << "烂片" << endl;  
            break;  
    }  

    system("pause");  
    return 0;  
}
```

> ⚠️ 注意：
> 
> 1. `switch` 的表达式**只能是整型或字符型**（如 `int`、`[[char]]`），不能是浮点型或字符串；
> 2. `case` 后必须加 `break`，否则会 “穿透” 到下一个 `case` 执行（除非故意共用逻辑）；
> 3. 与 `if` 对比：`switch` 不支持区间判断（如 `score>600`），但多分支时执行效率更高、结构更清晰。

## 三、循环结构：重复执行代码块

循环结构用于处理 “重复做某件事” 的场景，核心语法包括 `while`、`do...while`、`for` 循环，以及嵌套循环。

### 3.1 while 循环：先判断后执行

**作用**：满足循环条件时，重复执行循环体

**语法**：`while(循环条件){ 循环语句 }`

- 先判断「循环条件」：若为真，执行循环体；执行后再次判断，直到条件为假，退出循环。
- 必须确保循环体内有 “修改条件” 的语句（如 `num++`），否则会陷入**死循环**。

**示例：打印 0~9 的数字**

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    int num = 0;  
    // 循环条件：num < 10（满足则执行循环体）
    while (num < 10)  
    {  
        cout << "num = " << num << endl;  
        num++;  // 关键：修改循环条件，避免死循环
    }  

    system("pause");  
    return 0;  
}
```

#### 练习：猜数字游戏

需求：系统随机生成 1~100 的数字，玩家猜测：猜大提示 “过大”，猜小提示 “过小”，猜对提示 “胜利” 并退出。

cpp

运行

```cpp
#include <iostream>
#include <cstdlib>  // 用于 rand() 和 srand()
#include <ctime>    // 用于 time()
using namespace std;

int main() {  
    // 1. 生成1~100的随机数（设置随机种子，避免每次结果相同）
    srand((unsigned int)time(NULL));  
    int randomNum = rand() % 100 + 1;  // rand()%100 生成0~99，+1后1~100

    // 2. 循环猜测
    int guessNum = 0;  
    while (true)  // 无限循环，直到猜对才退出
    {  
        cout << "请猜一个1~100的数字：" << endl;  
        cin >> guessNum;  

        if (guessNum > randomNum)  
        {  
            cout << "数字过大，请重试！" << endl;  
        }  
        else if (guessNum < randomNum)  
        {  
            cout << "数字过小，请重试！" << endl;  
        }  
        else  
        {  
            cout << "恭喜你猜对了！胜利！" << endl;  
            break;  // 猜对，跳出循环
        }  
    }  

    system("pause");  
    return 0;  
}
```

### 3.2 do...while 循环：先执行后判断

**作用**：与 `while` 类似，但**先执行一次循环体，再判断条件**（确保循环体至少执行一次）

**语法**：`do{ 循环语句 } while(循环条件);`

> ⚠️ 注意：`do...while` 末尾的 `while` 后必须加**分号**。

**示例：打印 0~9 的数字（先执行一次）**

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    int num = 0;  
    do  
    {  
        cout << "num = " << num << endl;  
        num++;  
    } while (num < 10);  // 分号不可少

    system("pause");  
    return 0;  
}
```

> 📌 总结：`while` 可能一次都不执行（条件初始为假），`do...while` 至少执行一次（适合 “先做再判断” 的场景，如密码验证）。

#### 练习：求所有 3 位数的水仙花数

需求：水仙花数是指 3 位数中，每个位数字的 3 次幂之和等于其本身（如 153 = 1³ + 5³ + 3³），用 `do...while` 实现。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    int num = 100;  // 3位数的起始值
    do  
    {  
        // 1. 提取个位、十位、百位
        int ge = num % 10;        // 个位：num除以10的余数
        int shi = (num / 10) % 10;// 十位：num除以10取整，再取余10
        int bai = num / 100;      // 百位：num除以100取整

        // 2. 判断是否为水仙花数
        if (ge*ge*ge + shi*shi*shi + bai*bai*bai == num)  
        {  
            cout << num << " 是水仙花数" << endl;  
        }  

        num++;  
    } while (num < 1000);  // 循环条件：num < 1000（覆盖所有3位数）

    system("pause");  
    return 0;  
}
```

### 3.3 for 循环：结构清晰的循环

**作用**：将 “初始化、条件判断、更新条件” 整合在一行，结构最清晰，是开发中最常用的循环

**语法**：`for(起始表达式; 条件表达式; 末尾循环体){ 循环语句 }`

- 执行流程：
    1. 执行「起始表达式」（仅一次，初始化循环变量）；
    2. 判断「条件表达式」：若为真，执行循环体；若为假，退出循环；
    3. 执行「末尾循环体」（更新循环变量）；
    4. 回到步骤 2，重复判断。

**示例：打印 0~9 的数字**

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    // 起始表达式：int i=0（初始化循环变量）
    // 条件表达式：i<10（循环条件）
    // 末尾循环体：i++（更新循环变量）
    for (int i = 0; i < 10; i++)  
    {  
        cout << "i = " << i << endl;  
    }  

    system("pause");  
    return 0;  
}
```

> 📌 总结：`for` 循环的优点是结构紧凑，初始化、条件、更新一目了然，适合已知循环次数的场景（如遍历[[数组]]）；`while` 和 `do...while` 更适合未知循环次数的场景（如猜数字）。

#### 练习：敲桌子

需求：从 1 数到 100，若数字个位含 7、十位含 7，或为 7 的倍数，打印 “敲桌子”，否则打印数字。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    for (int i = 1; i <= 100; i++)  
    {  
        // 判断条件：个位=7 或 十位=7 或 是7的倍数
        if (i % 10 == 7 || i / 10 == 7 || i % 7 == 0)  
        {  
            cout << "敲桌子 " << endl;  
        }  
        else  
        {  
            cout << i << " ";  
        }  
    }  

    system("pause");  
    return 0;  
}
```

### 3.4 嵌套循环：循环内套循环

**作用**：在一个循环的循环体中嵌套另一个循环，用于处理 “多层重复” 的场景（如打印矩阵、乘法口诀表）

- 外层循环执行 1 次，内层循环执行**完整一轮**（直到内层条件为假）。

**示例：打印 10x10 的星号矩阵**

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    // 外层循环：控制行数（10行）
    for (int i = 0; i < 10; i++)  
    {  
        // 内层循环：控制每行的星号数（10个）
        for (int j = 0; j < 10; j++)  
        {  
            cout << "* ";  
        }  
        cout << endl;  // 每行结束后[[换行]]
    }  

    system("pause");  
    return 0;  
}
```

#### 练习：打印九九乘法表

需求：用嵌套循环实现九九乘法表（9 行，第 n 行有 n 个式子）。

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    // 外层循环：控制行数（1~9行）
    for (int i = 1; i <= 9; i++)  
    {  
        // 内层循环：控制每行的式子数（第i行有i个式子，乘数从1到i）
        for (int j = 1; j <= i; j++)  
        {  
            cout << j << "×" << i << "=" << j*i << " ";  
        }  
        cout << endl;  // 每行结束后[[换行]]
    }  

    system("pause");  
    return 0;  
}
```

## 四、跳转语句：控制程序流程

跳转语句用于改变程序的默认执行顺序，包括 `break`、`continue`、`goto`。

### 4.1 break 语句：终止结构

**作用**：跳出当前所在的**选择结构**（`switch`）或**循环结构**（`while`/`do...while`/`for`），执行结构后的代码。

#### 场景 1：跳出 switch 语句

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    cout << "请选择副本难度：1-普通，2-中等，3-困难" << endl;  
    int num = 0;  
    cin >> num;  

    switch (num)  
    {  
        case 1:  
            cout << "普通难度" << endl;  
            break;  // 跳出switch，避免执行后续case
        case 2:  
            cout << "中等难度" << endl;  
            break;  
        case 3:  
            cout << "困难难度" << endl;  
            break;  
    }  

    system("pause");  
    return 0;  
}
```

#### 场景 2：跳出循环语句

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    // 循环到i=5时，break跳出循环
    for (int i = 0; i < 10; i++)  
    {  
        if (i == 5)  
        {  
            break;  // 终止for循环
        }  
        cout << i << endl;  // 只打印0~4
    }  

    system("pause");  
    return 0;  
}
```

#### 场景 3：跳出嵌套循环的内层循环

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    // 外层循环10次，内层循环到j=5时break（只打印5个* per行）
    for (int i = 0; i < 10; i++)  
    {  
        for (int j = 0; j < 10; j++)  
        {  
            if (j == 5)  
            {  
                break;  // 只跳出内层循环，外层继续
            }  
            cout << "* ";  
        }  
        cout << endl;  
    }  

    system("pause");  
    return 0;  
}
```

### 4.2 continue 语句：跳过本次循环

**作用**：在循环中，跳过当前轮次中**余下未执行的语句**，直接进入下一轮循环的条件判断（不终止整个循环）。

**示例：打印 1~100 中的奇数**

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    for (int i = 1; i <= 100; i++)  
    {  
        if (i % 2 == 0)  // 若为偶数，跳过本次循环的打印
        {  
            continue;  // 跳过cout，直接进入下一轮（i++）
        }  
        cout << i << " ";  // 只打印奇数
    }  

    system("pause");  
    return 0;  
}
```

> 📌 区别：`break` 终止整个循环，`continue` 只跳过当前轮次。

### 4.3 goto 语句：无条件跳转

**作用**：无条件跳转到程序中指定的 “标记位置”，改变程序流程。

**语法**：

cpp

运行

```cpp
goto 标记名;  // 跳转指令
// ... 其他代码
标记名:  // 跳转目标（标记名自定义，后跟冒号）
```

**示例：跳过中间代码**

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {  
    cout << "1" << endl;  

    goto FLAG;  // 跳转到FLAG标记处

    cout << "2" << endl;  // 被跳过，不执行
    cout << "3" << endl;  // 被跳过，不执行

    FLAG:  // 跳转目标
    cout << "5" << endl;  // 执行：输出1、5

    system("pause");  
    return 0;  
}
```

> ⚠️ 注意：`goto` 语句会破坏程序的结构化流程（如跳过变量初始化、资源释放），导致代码可读性差、难维护，**开发中不建议使用**（仅在特殊场景如多层循环跳出时可考虑）。
