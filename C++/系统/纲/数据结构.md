# 1.[[浮点数]]

==浮点数（Floating-Point Number）是计算机科学中用于表示**非整数（如小数、极大 / 极小值）** 的数值类型，其设计灵感源于数学中的 “科学计数法”，通过 “符号位 + 指数位 + 尾数位” 的结构，在有限的二进制位数内，兼顾数值的**表示范围**和**精度**，是科学计算、工程模拟、金融分析等领域的基础。==


# 2. [[整形]]
==在编程语言中，**整数类型（Integer Type）** 是用于存储没有小数部分的数值的数据类型，是最基础且常用的数据类型之一。==


# 3. [[char]]
==在 C++ 中，`char` 是一种基本数据类型，主要用于表示单个字符==



# 4. [[C++/系统/细节/数据结构/vector]]

==在 C++ 标准库中，`std::vector` 是一种动态数组容器，属于 STL（标准模板库），也==
==指具有大小和方向的量，在编程中常用来表示多维数据（如 2D/3D 坐标、特征向量等）。==


# 5.[[C++/系统/细节/数据结构/size_t|size_t]]

==在 C 和 C++ 中，`size_t` 是一个**标准的无符号整数类型**，主要用于表示**对象的大小**（如内存块大小、数组长度）或**数组 / 容器的索引**。它的设计目的是确保能容纳当前系统中可能出现的最大对象的大小。==

# 6.[[struct]]

==`struct`（结构体）是 C++ 中一种**用户自定义数据类型**，用于将多个不同类型的数据（或函数）封装在一起，形成一个逻辑整体。其核心作用是 “数据聚合”，便于组织和管理相关联的数据。==
