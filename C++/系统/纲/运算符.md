# 1. [[逻辑运算符]]
==逻辑运算符是用于对**bool 类型的值**或**可转换为 bool 类型的表达式**进行逻辑运算的符号，主要用于实现多条件判断。C++ 中常用的逻辑运算符有三种：`!`（逻辑非）、`&&`（逻辑与）、`||`（逻辑或）。==

# 5.[[三目运算符]]
==三目运算符（又称**条件运算符**）是 C++ 中唯一需要三个操作数的运算符，核心作用是**用简洁的语法实现 “二选一” 的条件判断**，可替代简单的 `if-else` 结构，减少代码行数。==
