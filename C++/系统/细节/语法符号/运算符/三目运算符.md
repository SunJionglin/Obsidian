**********# C++ 三目运算符（条件运算符）用法笔记

## 一、定义与基础语法

三目运算符（又称**条件运算符**）是 C++ 中唯一需要三个操作数的运算符，核心作用是**用简洁的语法实现 “二选一” 的条件判断**，可替代简单的 `if-else` 结构，减少代码行数。
返回若变量，可以继续赋值

### 1.1 语法格式

cpp

运行

```cpp
条件表达式 ? 表达式1 : 表达式2;
```

- **执行逻辑**：
    
    1. 先计算「条件表达式」的值（结果为 `true` 或 `false`）；
    2. 若条件为 `true`，整个三目表达式的结果 = 「表达式 1」的值；
    3. 若条件为 `false`，整个三目表达式的结果 = 「表达式 2」的值。
- **示例（基础判断）**：
    
    cpp
    
    运行
    
    ```cpp
    int a = 5, b = 3;
    // 判断 a 是否大于 b，是则返回 a，否则返回 b（求两数最大值）
    int max_val = (a > b) ? a : b; 
    cout << max_val; // 输出：5
    ```
    

### 1.2 核心作用

- 替代**简单的二分支 `if-else`**（如赋值、返回值、输出等场景）；
- 嵌入到表达式中（如函数参数、数组初始化、输出语句），让代码更紧凑。

## 二、优先级与结合性

使用三目运算符时，需注意其优先级和结合性，避免语法歧义。

### 2.1 优先级规则

- 三目运算符的优先级**低于比较运算符（==、>、< 等）和算术运算符**，**高于赋值运算符（=）**。
- 因此，若条件表达式包含比较 / 算术运算，通常无需加括号；若与赋值运算结合，建议加括号明确逻辑。

|运算符类型|示例|优先级关系|
|---|---|---|
|比较运算符|`a == b`|高于三目运算符|
|三目运算符|`cond ? exp1 : exp2`|高于赋值运算符|
|赋值运算符|`x = y`|低于三目运算符|

- **反例（优先级陷阱）**：
    
    cpp
    
    运行
    
    ```cpp
    int x = 2, y = 3;
    // 错误：优先级导致先计算 x = 2 ? ... ，而非 (x == 2) ? ...
    int res = x == 2 ? y : 4; 
    // 正确：建议加括号明确条件，可读性更强
    int res = (x == 2) ? y : 4; 
    ```
    

### 2.2 结合性

三目运算符是**右结合**的（从右向左计算），但不建议嵌套过深（可读性极差）。

- 嵌套示例（不推荐）：
    
    cpp
    
    运行
    
    ```cpp
    int a = 10;
    // 判断 a 的范围：<5 → 0，5~10 → 1，>10 → 2
    int grade = (a < 5) ? 0 : ((a <= 10) ? 1 : 2); 
    ```
    

## 三、核心使用场景（附代码示例）

三目运算符的优势在 “简单二分支” 场景中最明显，以下是 5 个高频场景：

### 3.1 场景 1：变量赋值（替代简单 if-else）

当需要根据条件给变量赋两个固定值时，用三目运算符可一行完成。

#### 示例：判断奇偶性并赋值

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int num = 7;
    // 条件：num % 2 == 0 → 偶数，否则奇数
    string res = (num % 2 == 0) ? "偶数" : "奇数"; 
    cout << num << " 是 " << res; // 输出：7 是 奇数
    return 0;
}
```

#### 对比 if-else 实现（代码更冗长）

cpp

运行

```cpp
string res;
if (num % 2 == 0) {
    res = "偶数";
} else {
    res = "奇数";
}
```

### 3.2 场景 2：直接嵌入输出语句

无需中间变量，直接在 `cout` 中用三目运算符输出条件结果。

#### 示例：比较两个数的大小并输出

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 4, y = 6;
    // 直接在输出中判断并输出结果
    cout << "x 和 y 中，" << ((x > y) ? "x" : "y") << " 更大"; 
    // 输出：x 和 y 中，y 更大
    return 0;
}
```

### 3.3 场景 3：函数返回值（简化返回逻辑）

在函数中，若返回值仅依赖简单二分支判断，可用三目运算符直接返回。

#### 示例：判断两个数是否相等，返回 1/0

cpp

运行

```cpp
#include <iostream>
using namespace std;

// 函数：判断 a 和 b 是否相等，返回 1（相等）或 0（不相等）
int isEqual(int a, int b) {
    return (a == b) ? 1 : 0; // 三目运算符直接作为返回值
}

int main() {
    cout << isEqual(5, 5) << endl;  // 输出：1
    cout << isEqual(3, 7) << endl;  // 输出：0
    return 0;
}
```

### 3.4 场景 4：数组初始化（条件标记）

初始化数组时，用三目运算符标记符合条件的元素（如 1 表示匹配，0 表示不匹配）。

#### 示例：标记数组中等于目标值的元素

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[] = {2, 5, 2, 8, 2};
    int target = 2;
    int len = sizeof(arr) / sizeof(arr[0]);
    int mask[len]; // 存储标记结果的数组

    // 遍历数组，用三目运算符初始化 mask
    for (int i = 0; i < len; i++) {
        mask[i] = (arr[i] == target) ? 1 : 0;
    }

    // 输出结果
    cout << "原数组：";
    for (int num : arr) cout << num << " ";
    cout << "\n匹配掩码（1=等于2，0=不等于2）：";
    for (int m : mask) cout << m << " ";
    // 输出：原数组：2 5 2 8 2  匹配掩码（1=等于2，0=不等于2）：1 0 1 0 1
    return 0;
}
```

### 3.5 场景 5：条件计数（统计符合条件的元素）

统计数组中符合条件的元素个数时，用三目运算符累加 1（符合）或 0（不符合）。

#### 示例：统计数组中大于 5 的元素数量

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int nums[] = {3, 7, 5, 9, 2};
    int count = 0; // 计数变量
    int len = sizeof(nums) / sizeof(nums[0]);

    // 遍历数组，符合条件则加 1，否则加 0
    for (int i = 0; i < len; i++) {
        count += (nums[i] > 5) ? 1 : 0;
    }

    cout << "数组中大于 5 的元素个数：" << count; // 输出：2（7 和 9）
    return 0;
}
```

## 四、注意事项（避坑指南）

三目运算符虽简洁，但滥用会导致代码可读性下降，需注意以下问题：

### 4.1 避免嵌套过深

嵌套超过 2 层的三目运算符会极大降低可读性，此时应改用 `if-else`。

#### 反例（不推荐，可读性差）

cpp

运行

```cpp
int score = 85;
// 嵌套判断成绩等级：<60→F，60~80→C，81~90→B，>90→A
string level = (score < 60) ? "F" : ((score <= 80) ? "C" : ((score <= 90) ? "B" : "A"));
```

#### 正例（推荐用 if-else）

cpp

运行

```cpp
string level;
if (score < 60)      level = "F";
else if (score <= 80) level = "C";
else if (score <= 90) level = "B";
else                  level = "A";
```

### 4.2 确保表达式类型一致

「表达式 1」和「表达式 2」的类型需兼容（可隐式转换或完全一致），否则可能出现编译错误或逻辑错误。

#### 反例（类型不兼容）

cpp

运行

```cpp
// 错误：表达式1是 int，表达式2是 string，无法隐式转换
int res = (a > b) ? 10 : "error"; 
```

#### 正例（类型一致）

cpp

运行

```cpp
// 正确：均为 int 类型
int res = (a > b) ? 10 : -1; 
// 正确：均为 string 类型
string res = (a > b) ? "success" : "error"; 
```

### 4.3 复杂逻辑优先用 if-else

若条件或表达式包含复杂逻辑（如多语句、循环、函数调用），三目运算符会让代码难以维护，此时 `if-else` 更合适。

#### 反例（复杂逻辑不适合三目）

cpp

运行

```cpp
// 错误：表达式中包含多语句，三目运算符不支持
(a > b) ? (cout << "a大", a++) : (cout << "b大", b++); 
```

#### 正例（用 if-else 实现）

cpp

运行

```cpp
if (a > b) {
    cout << "a大";
    a++;
} else {
    cout << "b大";
    b++;
}
```

## 五、总结

### 5.1 三目运算符的优缺点

|优点|缺点|
|---|---|
|代码简洁，减少行数|不支持多语句表达式|
|可嵌入到其他表达式中|嵌套过深可读性差|
|替代简单 if-else，效率相当|类型兼容性要求严格|

### 5.2 适用场景总结

- ✅ 推荐用：简单二分支判断（赋值、返回值、输出）；
- ❌ 不推荐用：嵌套超过 2 层、复杂逻辑（多语句、循环）。

记住：**简洁性的前提是可读性**，不要为了用三目运算符而牺牲代码的可维护性。
