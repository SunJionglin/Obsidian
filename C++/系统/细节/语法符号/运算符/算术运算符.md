# C++ 算术运算符笔记

## 一、算术运算符的分类

C++ 中的算术运算符用于执行基本的数学运算，主要分为两类：

1. 基本算术运算符（+、-、*、/、%）
2. 自增 / 自减运算符（++、--）

## 二、基本算术运算符

### 1. 加法运算符（+）

- 作用：计算两个值的和
- 语法：`a + b`
- 示例：
    
    cpp
    
    运行
    
    ```cpp
    int a = 5, b = 3;
    int sum = a + b;  // sum = 8
    ```
    

### 2. 减法运算符（-）

- 作用：计算两个值的差（前者减后者）
- 语法：`a - b`
- 示例：
    
    cpp
    
    运行
    
    ```cpp
    int a = 5, b = 3;
    int diff = a - b;  // diff = 2
    ```
    

### 3. 乘法运算符（  *  ）

- 作用：计算两个值的乘积
- 语法：`a * b`
- 示例：
    
    cpp
    
    运行
    
    ```cpp
    int a = 5, b = 3;
    int product = a * b;  // product = 15
    ```
    

### 4. 除法运算符（/）

- 作用：计算两个值的商（前者除后者）
- **注意**：
    - 若两个操作数都是整数，结果会自动取整（舍弃小数部分，不是四舍五入）
    - 若有一个操作数是浮点数，结果为浮点数
- 示例：
    
    cpp
    
    运行
    
    ```cpp
    int a = 5, b = 2;
    int div1 = a / b;    // 整数除法，div1 = 2（5÷2=2.5，取整为2）
    
    double c = 5.0, d = 2;
    double div2 = c / d;  // 浮点数除法，div2 = 2.5
    ```
    

### 5. 取模运算符（%，又称求余）

- 作用：计算==两个整数相除==的余数（结果的符号与被除数一致）
- **注意**：仅适用于整数，不能用于浮点数
- 示例：
    
    cpp
    
    运行
    
    ```cpp
    int a = 5, b = 2;
    int mod1 = a % b;  // mod1 = 1（5÷2余1）
    
    int c = 5, d = -2;
    int mod2 = c % d;  // mod2 = 1（余数符号与被除数5一致）
    ```
    

## 三、自增 / 自减运算符

用于对变量的值进行 + 1 或 - 1 操作，分为**前置**和**后置**两种形式。

### 1. 自增运算符（++）

- 作用：使变量的值增加 1
    
- 前置形式（++var）：先让变量 + 1，再使用变量的值
    
- 后置形式（var++）：先使用变量的值，再让变量 + 1
    
- 示例：
    
    cpp
    
    运行
    
    ```cpp
    int a = 5;
    int b = ++a;  // 前置++：a先+1变为6，再赋值给b → a=6, b=6
    
    int c = 5;
    int d = c++;  // 后置++：先将c的值5赋值给d，再让c+1 → c=6, d=5
    ```
    

### 2. 自减运算符（--）

- 作用：使变量的值减少 1
    
- 前置形式（--var）：先让变量 - 1，再使用变量的值
    
- 后置形式（var--）：先使用变量的值，再让变量 - 1
    
- 示例：
    
    cpp
    
    运行
    
    ```cpp
    int a = 5;
    int b = --a;  // 前置--：a先-1变为4，再赋值给b → a=4, b=4
    
    int c = 5;
    int d = c--;  // 后置--：先将c的值5赋值给d，再让c-1 → c=4, d=5
    ```
    

## 四、运算符优先级

算术运算符的优先级（从高到低）：

1. 自增 / 自减运算符（++、--）
2. 乘法、除法、取模（*、/、%）
3. 加法、减法（+、-）

- 同级运算符从左到右依次计算
    
- 可通过括号`()`改变运算顺序
    
- 示例：
    
    cpp
    
    运行
    
    ```cpp
    int result = 2 + 3 * 4;  // 先算3*4=12，再算2+12 → result=14
    int result2 = (2 + 3) * 4;  // 先算括号内2+3=5，再算5*4 → result2=20
    ```
    

## 五、常见注意事项

1. 整数除法会自动舍弃小数部分，如需精确结果需使用浮点数
2. 取模运算符（%）仅适用于整数，浮点数使用会报错
3. 自增 / 自减运算符的前置与后置形式，在单独使用时（如`a++`或`++a`）效果相同；但在表达式中使用时，结果不同，需特别注意
4. 运算时注意数据类型范围，避免溢出（如 int 类型的最大值约为 21 亿，超过会出错）
