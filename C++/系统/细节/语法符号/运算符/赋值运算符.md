### 1. 基本赋值运算符（=）

- **作用**：将右侧表达式的值赋给左侧变量
- **语法**：`变量 = 表达式;`
- **特点**：左侧必须是可修改的变量（左值），右侧可以是常量、变量或表达式

cpp

运行

```cpp
int a;
a = 10;       // 将常量10赋给变量a
int b = 20;
a = b;        // 将变量b的值赋给a
a = a + 5;    // 将表达式结果赋给a（a的值变为25）
```

### 2. 复合赋值运算符

在赋值的同时进行算术运算，是简化写法的语法糖

|运算符|含义|等价表达式|
|---|---|---|
|+=|加后赋值|a += b → a = a + b|
|-=|减后赋值|a -= b → a = a - b|
|*=|乘后赋值|a *= b → a = a * b|
|/=|除后赋值|a /= b → a = a / b|
|%=|取模后赋值|a %= b → a = a % b|

cpp

运行

```cpp
int x = 10;
x += 5;   // 等价于 x = x + 5 → x=15
x -= 3;   // 等价于 x = x - 3 → x=12
x *= 2;   // 等价于 x = x * 2 → x=24
x /= 4;   // 等价于 x = x / 4 → x=6
x %= 3;   // 等价于 x = x % 3 → x=0
```

### 3. 赋值运算符的特性

- **右结合性**：支持链式赋值
    
    cpp
    
    运行
    
    ```cpp
    int a, b, c;
    a = b = c = 5;  // 从右向左执行，最终a、b、c都为5
    ```
    
- **表达式返回值**：赋值表达式本身有返回值，为赋值后左操作数的值
    
    cpp
    
    运行
    
    ```cpp
    int x, y;
    y = (x = 10);  // x被赋值10，表达式(x=10)返回10，因此y=10
    ```
    

### 4. 注意事项

- 区分赋值运算符（=）与相等比较运算符（==）
    
    cpp
    
    运行
    
    ```cpp
    int a = 5;    // 正确：赋值
    if (a == 5) { // 正确：比较
        // 执行逻辑
    }
    if (a = 5) {  // 错误：此处实际是赋值，而非比较（编译器可能警告）
    }
    ```
    
- 复合赋值运算符会自动处理类型转换（遵循 C++ 类型转换规则）
    
    cpp
    
    运行
    
    ```cpp
    int a = 10;
    double b = 3.5;
    a += b;  // 等价于a = a + (int)b → a = 10 + 3 = 13
    ```
    
- 对于自定义类型（类），可以重载赋值运算符实现特殊逻辑
