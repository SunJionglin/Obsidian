逻辑运算符是用于对**bool 类型的值**或**可转换为 bool 类型的表达式**进行逻辑运算的符号，主要用于实现多条件判断。C++ 中常用的逻辑运算符有三种：`!`（逻辑非）、`&&`（逻辑与）、`||`（逻辑或）。

## 一、逻辑运算符分类及基本用法

### 1. 逻辑非（`!`）

- **作用**：对操作数进行 “取反” 操作（真变假，假变真）。
    
- **语法**：`!操作数`
    
- **运算规则**：
    
    - 若操作数为`true`（或非 0 值，C++ 中非 0 即视为真），结果为`false`（0）。
    - 若操作数为`false`（或 0），结果为`true`（1）。
- **示例**：
    

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    bool a = true;
    bool b = false;
    int c = 10;   // 非0值视为true
    int d = 0;    // 0视为false
    
    cout << "!a = " << !a << endl;  // !true → false（输出0）
    cout << "!b = " << !b << endl;  // !false → true（输出1）
    cout << "!c = " << !c << endl;  // !非0 → false（输出0）
    cout << "!d = " << !d << endl;  // !0 → true（输出1）
    return 0;
}
```

输出结果：

plaintext

```plaintext
!a = 0
!b = 1
!c = 0
!d = 1
```

### 2. 逻辑与（`&&`）

- **作用**：判断多个条件是否**同时成立**。
    
- **语法**：`条件1 && 条件2`（可多个条件连续使用，如`a && b && c`）
    
- **运算规则**：
    
    - 只有**所有条件都为真**时，结果才为`true`（1）。
    - 只要**有一个条件为假**，结果就为`false`（0）。
- **示例**：
    

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 10, c = 0;
    cout << (a > 0 && b > 0) << endl;  // 5>0为真，10>0为真 → 结果1
    cout << (a > 0 && c > 0) << endl;  // 5>0为真，0>0为假 → 结果0
    return 0;
}
```

输出结果：

plaintext

```plaintext
1
0
```

### 3. 逻辑或（`||`）

- **作用**：判断多个条件是否**至少有一个成立**。
    
- **语法**：`条件1 || 条件2`（可多个条件连续使用，如`a || b || c`）
    
- **运算规则**：
    
    - 只要**有一个条件为真**，结果就为`true`（1）。
    - 只有**所有条件都为假**时，结果才为`false`（0）。
- **示例**：
    

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = -3, c = 0;
    cout << (a > 0 || b > 0) << endl;  // 5>0为真，-3>0为假 → 结果1
    cout << (c > 0 || b < 0) << endl;  // 0>0为假，-3<0为真 → 结果1
    cout << (c > 0 || b > 0) << endl;  // 0>0为假，-3>0为假 → 结果0
    return 0;
}
```

输出结果：

plaintext

```plaintext
1
1
0
```

## 二、逻辑运算符的 “短路特性”（重点）

逻辑与（`&&`）和逻辑或（`||`）具有**短路求值**的特性：当左边的条件已经能确定整个表达式的结果时，右边的条件将**不再执行**。

### 1. 逻辑与（`&&`）的短路

- 若左边条件为`false`，则无论右边条件是什么，整个表达式结果一定是`false`，因此**右边条件不会执行**。
    
- **示例**：
    

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    // 左边a < 5为假，右边a++不会执行
    if (a < 5 && a++) {
        cout << "条件成立" << endl;
    }
    cout << "a = " << a << endl;  // a仍为10（a++未执行）
    return 0;
}
```

输出结果：

plaintext

```plaintext
a = 10
```

### 2. 逻辑或（`||`）的短路

- 若左边条件为`true`，则无论右边条件是什么，整个表达式结果一定是`true`，因此**右边条件不会执行**。
    
- **示例**：
    

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    // 左边a > 5为真，右边a++不会执行
    if (a > 5 || a++) {
        cout << "条件成立" << endl;
    }
    cout << "a = " << a << endl;  // a仍为10（a++未执行）
    return 0;
}
```

输出结果：

plaintext

```plaintext
条件成立
a = 10
```

## 三、逻辑运算符与按位运算符的区别

注意区分逻辑运算符（`&&`、`||`）与按位运算符（`&`、`|`）：

- **逻辑运算符**：操作对象是 “真假”，返回值是`bool`类型（1 或 0），具有短路特性。
    
- **按位运算符**：操作对象是二进制位，对每一位进行运算，返回值是整数，无短路特性。
    
- **示例对比**：
    

cpp

运行

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1, b = 2;
    cout << (a && b) << endl;  // 逻辑与：1（真）&& 2（真）→ 1
    cout << (a & b) << endl;   // 按位与：01 & 10 → 00（0）
    
    cout << (a || b) << endl;  // 逻辑或：1（真）|| 2（真）→ 1
    cout << (a | b) << endl;   // 按位或：01 | 10 → 11（3）
    return 0;
}
```

## 四、优先级与结合性

- **优先级**：逻辑非（`!`）> 算术运算符 > 关系运算符 > 逻辑与（`&&`）> 逻辑或（`||`）。
    - 例：`!a + b > c && d` 等效于 `((!a) + b) > c && d`
- **结合性**：
    - 逻辑非（`!`）：右结合（从右向左）。
    - 逻辑与（`&&`）、逻辑或（`||`）：左结合（从左向右）。

## 总结

1. 逻辑运算符用于处理 “真假” 判断，核心是`!`（非）、`&&`（与）、`||`（或）。
2. 逻辑与（`&&`）：全真才真，有假则假，左假短路。
3. 逻辑或（`||`）：有真则真，全假才假，左真短路。
4. 短路特性可提高效率，但需注意右侧表达式有副作用（如自增、赋值）时的逻辑正确性。
5. 区分逻辑运算符与按位运算符，避免混淆。
