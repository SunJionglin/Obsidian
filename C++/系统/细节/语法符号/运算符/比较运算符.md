## C++ 比较运算符与逻辑运算符笔记

### 一、比较运算符

用于比较两个值的关系，返回`bool`类型结果（`true`或`false`）

|运算符|名称|示例|说明|
|---|---|---|---|
|`==`|等于|`a == b`|判断 a 和 b 是否相等|
|`!=`|不等于|`a != b`|判断 a 和 b 是否不相等|
|`>`|大于|`a > b`|判断 a 是否大于 b|
|`<`|小于|`a < b`|判断 a 是否小于 b|
|`>=`|大于等于|`a >= b`|判断 a 是否大于或等于 b|
|`<=`|小于等于|`a <= b`|判断 a 是否小于或等于 b|

cpp

运行

```cpp
int a = 10, b = 20;
cout << (a == b) << endl;  // 0（false）
cout << (a != b) << endl;  // 1（true）
cout << (a > b) << endl;   // 0（false）
cout << (a < b) << endl;   // 1（true）
```

**注意**：

- 比较运算符的结果是布尔值，C++ 中用`1`表示`true`，`0`表示`false`
- 不要混淆赋值运算符`=`和相等运算符`==`（常见错误）
