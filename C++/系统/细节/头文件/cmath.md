# C++ 中的 `<cmath>` 库：数学函数的实用工具

`<cmath>` 是 C++ 标准库中的一个重要头文件，提供了一系列常用的数学函数，用于执行各种数学运算，如三角函数、指数函数、对数函数、取整函数等。它是 C 语言中 `<math.h>` 头文件的 C++ 版本，函数通常位于 `std` 命名空间中。

## 包含方式

使用 `<cmath>` 库中的函数时，需要先包含头文件：

cpp

运行

```cpp
#include <cmath>
```

## 常用数学函数分类

### 1. 基本算术函数

| 函数          | 描述               | 示例            | 结果     |
| ----------- | ---------------- | ------------- | ------ |
| `abs(x)`    | 计算整数的绝对值         | `abs(-5)`     | `5`    |
| `fabs(x)`   | 计算浮点数的绝对值        | `fabs(-3.14)` | `3.14` |
| `pow(x, y)` | 计算 x 的 y 次方（x^y） | `pow(2, 3)`   | `8.0`  |
| `sqrt(x)`   | 计算 x 的平方根        | `sqrt(16)`    | `4.0`  |
| `cbrt(x)`   | 计算 x 的立方根        | `cbrt(8)`     | `2.0`  |

### 2. 三角函数（参数为弧度）

| 函数            | 描述                | 示例            | 结果（近似）   |
| ------------- | ----------------- | ------------- | -------- |
| `sin(x)`      | 正弦函数              | `sin(M_PI/2)` | `1.0`    |
| `cos(x)`      | 余弦函数              | `cos(M_PI)`   | `-1.0`   |
| `tan(x)`      | 正切函数              | `tan(M_PI/4)` | `1.0`    |
| `asin(x)`     | 反正弦函数（返回弧度）       | `asin(1.0)`   | `M_PI/2` |
| `acos(x)`     | 反余弦函数（返回弧度）       | `acos(-1.0)`  | `M_PI`   |
| `atan(x)`     | 反正切函数（返回弧度）       | `atan(1.0)`   | `M_PI/4` |
| `atan2(y, x)` | 计算 y/x 的反正切（考虑象限） | `atan2(1, 1)` | `M_PI/4` |

### 3. 指数和对数函数

|函数|描述|示例|结果（近似）|
|---|---|---|---|
|`exp(x)`|计算 e 的 x 次方（e^x）|`exp(1)`|`2.718`|
|`log(x)`|计算自然对数（ln x）|`log(exp(1))`|`1.0`|
|`log10(x)`|计算以 10 为底的对数|`log10(100)`|`2.0`|
|`log2(x)`|计算以 2 为底的对数（C++11 起）|`log2(8)`|`3.0`|

### 4. 取整函数

|函数|描述|示例|结果|
|---|---|---|---|
|`ceil(x)`|向上取整（返回不小于 x 的最小整数）|`ceil(2.3)`|`3.0`|
|`floor(x)`|向下取整（返回不大于 x 的最大整数）|`floor(2.7)`|`2.0`|
|`round(x)`|四舍五入到最近的整数|`round(2.5)`|`3.0`|
|`trunc(x)`|截断小数部分（向零取整）|`trunc(2.7)`|`2.0`|

### 5. 其他常用函数

|函数|描述|示例|结果|
|---|---|---|---|
|`hypot(x, y)`|计算直角三角形的斜边长度（√(x²+y²)）|`hypot(3, 4)`|`5.0`|
|`fmod(x, y)`|计算 x 除以 y 的余数（浮点数取模）|`fmod(5.5, 2)`|`1.5`|
|`remainder(x, y)`|计算带符号的余数|`remainder(5, 3)`|`-1.0`|
|`max(x, y)`|返回两个数中的较大值|`max(3, 5)`|`5`|
|`min(x, y)`|返回两个数中的较小值|`min(3, 5)`|`3`|

### 6. 数学常量

`<cmath>` 还定义了一些常用的数学常量（需要定义 `_USE_MATH_DEFINES` 才能使用某些编译器）：

|常量|描述|近似值|
|---|---|---|
|`M_PI`|圆周率 π|3.141592653589793|
|`M_E`|自然常数 e|2.718281828459045|
|`M_SQRT2`|根号 2|1.4142135623730951|

## 使用示例

下面是一个使用 `<cmath>` 库中多种函数的示例程序：

cpp

运行

```cpp
#include <iostream>
#include <cmath>
#include <iomanip>

using namespace std;

int main() {
    // 基本算术运算
    cout << "abs(-10) = " << abs(-10) << endl;
    cout << "sqrt(25) = " << sqrt(25) << endl;
    cout << "pow(3, 4) = " << pow(3, 4) << endl;
    
    // 三角函数（注意参数是弧度）
    double rad = M_PI / 6; // 30度
    cout << "sin(30°) = " << sin(rad) << endl;
    cout << "cos(30°) = " << cos(rad) << endl;
    
    // 指数和对数
    cout << "exp(2) = " << exp(2) << endl;
    cout << "log(e^3) = " << log(exp(3)) << endl;
    cout << "log10(1000) = " << log10(1000) << endl;
    
    // 取整函数
    cout << "ceil(4.2) = " << ceil(4.2) << endl;
    cout << "floor(4.8) = " << floor(4.8) << endl;
    cout << "round(4.5) = " << round(4.5) << endl;
    
    return 0;
}
```

输出结果：

## 注意事项

1. 大部分函数的参数和返回值都是 `double` 类型，如果需要处理 `float` 或 `long double` 类型，可以使用对应的函数版本，如 `sinf()`（float）、`sinl()`（long double）。
    
2. 三角函数的参数是**弧度**而非角度，如果需要使用角度，需要先进行转换：`弧度 = 角度 × π / 180`。
    
3. 对于定义域有限制的函数（如 `sqrt(x)` 要求 `x ≥ 0`，`log(x)` 要求 `x > 0`），如果传入无效参数，会导致未定义行为，通常会返回 NaN（Not a Number）。
    
4. 不同编译器对某些函数和常量的支持可能略有差异，使用时可以参考具体编译器的文档。
    

`<cmath>` 库为 C++ 程序提供了丰富的数学运算功能，是科学计算、图形处理、物理模拟等领域不可或缺的工具。
