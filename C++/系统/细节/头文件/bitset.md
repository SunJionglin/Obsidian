`<bitset>` 提供**定长二进制位数组**：一个元素只占 1 bit，位运算可以直接整体做。

---

# 一、基本用法

```cpp
#include <bitset>
using namespace std;

bitset<8> b(10);            // 0000 1010
bitset<8> c(string("0110"));// 从字符串构造
cout << b;                  // 直接输出 00001010
cout << b[1];               // 1（下标从低位开始数）
```

长度 `N` 必须是编译期常量，`bitset<N>` 总共占 `N` 位。

# 二、常用接口

| 操作 | 作用 |
| --- | --- |
| `b.set()` / `b.set(i)` | 全部置 1 / 第 i 位置 1 |
| `b.reset()` / `b.reset(i)` | 全部置 0 / 第 i 位置 0 |
| `b.flip()` / `b.flip(i)` | 取反 |
| `b.test(i)` | 第 i 位是否为 1 |
| `b.count()` | 1 的个数 |
| `b.any()` / `b.none()` | 是否有 1 / 是否全 0 |
| `b.to_string()` | 转成 `string` |
| `b.to_ulong()` / `b.to_ullong()` | 转成整数 |

# 三、位运算直接整体做

```cpp
bitset<8> x(10), y(6);
cout << (x & y);    // 按位与
cout << (x | y);    // 按位或
cout << (x ^ y);    // 按位异或
cout << (~x);       // 取反
cout << (x << 2);   // 左移（高位挤掉）
```

不用写循环，编译器会把它编成几条机器指令。

# 四、典型场景

1. **布尔数组**：`bitset<1000005> vis;` 比 `bool` 数组省 8 倍内存。
2. **埃氏筛**：`bitset` 存合数标记，快且省。
3. **状压 / 集合**：用一位表示“某个数在不在集合里”，集合求交并差就是一个位运算。
4. **可达性**：`f |= f << a[i]` 这种写法就是背包的 bitset 优化。

# 五、注意

1. `N` 只在编译期定，运行时才知道大小就用 `vector<bool>` 或 `unsigned long long` 数组。
2. `b[i]` 是**从低位往高位**数，`b[0]` 是最右边那位，别数反。
3. `bitset` 不能动态扩容，超大 N（比如 1e8）仍要注意栈空间，建议放全局。

# 六、一句话总结

`bitset` = 按位存的定长数组，位运算一次做一整排；省内存、状压和筛法首选。
