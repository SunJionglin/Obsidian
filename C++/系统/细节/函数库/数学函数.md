# 数学函数

> 上位索引：[[C++系统函数]] · 头文件：[[cmath]]、[[cstdlib]]、[[limits]]

这篇讲**取整、开方、幂、对数**这四类，重点是「看起来对、结果差 1」的坑。

---

## 一、取整四兄弟

| 函数 | 作用 | `1.5` | `-1.5` |
| --- | --- | --- | --- |
| `floor(x)` | 向下取整（朝 -∞） | 1 | **-2** |
| `ceil(x)` | 向上取整（朝 +∞） | 2 | **-1** |
| `trunc(x)` | 向零取整（砍掉小数） | 1 | -1 |
| `round(x)` | 四舍五入（远离零） | 2 | **-2** |

它们**都返回 `double`**，要整数得自己转：

```cpp
int a = (int)floor(3.7);    // 3
int b = (int)ceil(3.2);     // 4
```

**强制转换 `(int)` 是向零取整，等于 `trunc`**，不是向下取整。负数时两者差 1：

```cpp
(int)(-1.5)      // -1   ← 向零
(int)floor(-1.5) // -2   ← 向下
```

### 整数除法怎么向上取整

不要用 `ceil((double)a / b)`（有精度风险），用整数运算：

```cpp
int up = (a + b - 1) / b;      // a、b 都为正，向上取整
// 例：7 / 2 = 3，向上取整应为 4 → (7+2-1)/2 = 4 ✓
```

## 二、开方

```cpp
double r = sqrt(25.0);      // 5.0
double c = cbrt(27.0);      // 3.0，立方根
```

### 判断完全平方数（有坑）

```cpp
bool isSquare(long long n) {
    long long r = sqrt((double)n);
    // 浮点误差可能差 1，两边都试一下
    return r * r == n || (r + 1) * (r + 1) == n;
}
```

直接写 `if (sqrt(n) == (int)sqrt(n))` 在 `n` 很大时会判错。

### 判断质数：i * i <= n

```cpp
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)     // 别写 i <= sqrt(n)，慢还有精度问题
        if (n % i == 0) return false;
    return true;
}
```

`i * i` 当 `i` 大到 5e4 时 `i*i` 会溢出 `int`，`n` 很大就用 `i <= n / i`。

## 三、幂

```cpp
pow(2, 10);        // 1024.0，返回 double
pow(2, 0.5);       // 1.41421，开方
```

### 三个坑

1. **`pow` 返回浮点**：`pow(2, 10)` 可能算出 `1023.9999999`，`(int)` 一截断就变 1023。
2. **大指数会溢出成 inf**：`pow(10, 400)` 直接是 `inf`。
3. **不要用 `pow` 求整数幂**，手写循环或快速幂。

```cpp
long long ipow(long long a, int b) {
    long long r = 1;
    while (b > 0) {
        if (b & 1) r *= a;
        a *= a;
        b >>= 1;
    }
    return r;
}
```

快速幂取模（比赛常客）：

```cpp
long long qpow(long long a, long long b, long long mod) {
    long long r = 1 % mod;
    a %= mod;
    while (b > 0) {
        if (b & 1) r = r * a % mod;      // 中间结果可能超 long long，超大数要用 __int128
        a = a * a % mod;
        b >>= 1;
    }
    return r;
}
```

## 四、对数与指数

```cpp
log(x);      // 自然对数 ln
log2(x);     // 以 2 为底
log10(x);    // 以 10 为底
exp(x);      // e^x
```

任意底的对数要换底：

```cpp
double logb(double x, double b) { return log(x) / log(b); }
```

**坑**：`log2(8)` 可能算出 `2.9999999`，取整前加 `1e-9`：

```cpp
int k = (int)(log2(n) + 1e-9);      // 2 的整数次幂才准
```

求「二进制最高位」更稳的写法（GCC 内建）：

```cpp
int k = 31 - __builtin_clz(n);      // n > 0 时，2^k <= n < 2^(k+1)
```

## 五、浮点数比较

浮点数**不能直接 `==`**：

```cpp
const double EPS = 1e-8;

bool eq(double a, double b) { return fabs(a - b) < EPS; }
bool lt(double a, double b) { return a < b - EPS; }
bool le(double a, double b) { return a < b + EPS; }
```

`0.1 + 0.2 == 0.3` 是 `false`，这是二进制表示决定的，不是编译器的问题。

## 六、常量

`M_PI` **不是标准**，GCC 能用但别依赖。稳妥写法：

```cpp
const double PI = acos(-1.0);      // 3.141592653589793
```
