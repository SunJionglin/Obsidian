# 类型转换

> 上位索引：[[C++系统函数]] · 头文件：[[string]]、[[cstdlib]]、[[sstream]]

分两块：**数值之间的转换**（截断、溢出）和 **字符串 ↔ 数字**（考试和做题最常错）。

---

## 一、数值之间：隐式与显式

```cpp
int a = 3.99;            // 3，直接截断（编译器可能警告）
int b = (int)3.99;       // 3，显式转换，同样截断
double c = 7 / 2;        // 3.0 ← 先算整数除法 7/2=3，再转 double！
double d = 7.0 / 2;      // 3.5 ← 正确写法
double e = 7 / 2.0;      // 3.5
```

**`7 / 2` 这一步就已经是 `int` 除法**，后面再转 `double` 也救不回来。要么写 `7.0 / 2`，要么 `(double)7 / 2`。

### 负数除法

```cpp
-7 / 2       // -3（向零取整，不是 -4）
-7 % 2       // -1（符号跟着被除数）
```

C++ 的整除是**向零截断**，跟数学上的「向下取整」不是一个东西。写取模类题目时要小心负数。

### 溢出

```cpp
int  x = 2147483647;  x + 1;    // 未定义行为，通常变 -2147483648
long long y = 2147483647;  y + 1;  // 正常 2147483648
```

规则：`int` 约 ±2.1e9，`long long` 约 ±9.2e18。**中间结果也要考虑溢出**：

```cpp
int a = 100000, b = 100000;
long long c = a * b;              // 错！a*b 先按 int 算，已经溢出
long long d = (long long)a * b;   // 对
```

### 有符号 ↔ 无符号

```cpp
unsigned int u = 0;
u - 1;                       // 4294967295，不是 -1
if (-1 < 1u) { }             // 假！-1 被转成无符号大数
```

**别在同一个表达式里混用 `int` 和 `unsigned`**，比较和减法都会变样。

## 二、字符串 → 数字

| 写法 | 头文件 | 非法输入 | 说明 |
| --- | --- | --- | --- |
| `atoi(s)` | [[cstdlib]] | 返回 0 | 遇到非数字字符就停，`"12abc"` → 12 |
| `stoi(s)` | [[string]] | 抛异常 | 有 `pos` 参数，能知道停在哪 |
| `stoll(s)` | [[string]] | 抛异常 | `long long` 版 |
| `stod(s)` | [[string]] | 抛异常 | 浮点版 |
| `strtol(s, &end, base)` | [[cstdlib]] | 返回 0 | 能指定进制，`base=0` 自动识别 `0x` |

```cpp
stoi("123");          // 123
stoi("123abc");       // 123（停在不合法处，不算错）
stoi("12.5");         // 12（遇到小数点就停）
stoi("abc");          // 抛 invalid_argument
```

处理健壮输入要包 `try / catch`：

```cpp
try {
    int x = stoi(s);
} catch (...) {
    cout << "输入不合法" << endl;
}
```

### 十六进制 / 任意进制解析

```cpp
strtol("ff", nullptr, 16);        // 255
strtol("0x1f", nullptr, 0);       // 31，base=0 自动识别前缀
```

## 三、数字 → 字符串

```cpp
to_string(123);        // "123"
to_string(3.14);       // "3.140000" ← 默认补 6 位小数！
to_string(true);       // "1"
```

浮点想要好看的形式，用 [[sstream]] 或 [[iomanip]]：

```cpp
#include <sstream>
stringstream ss;
ss << fixed << setprecision(2) << 3.14159;    // "3.14"
string s = ss.str();
```

### 进制输出

```cpp
stringstream ss;
ss << hex << 255;         // "ff"
ss << oct << 255;         // "377"
ss << bitset<8>(9);       // "00001001"，要 <bitset>
```

或者 C 风格：`printf("%x %o", 255, 255);`

### 手写进制转换（模板题常用）

```cpp
string toBase(unsigned long long n, int base) {
    if (n == 0) return "0";
    string table = "0123456789ABCDEF";
    string s;
    while (n > 0) { s += table[n % base]; n /= base; }
    reverse(s.begin(), s.end());       // 记得反转
    return s;
}
```

## 四、字符与数字

```cpp
char c = '7';
int  x = c - '0';          // 7，靠 ASCII 码差值
char d = x + '0';          // '7'
```

`c - '0'` 是最常用的转换，`int(c)` 得到的是 ASCII 码 55，不是数字 7。
