# 排序与查找

> 上位索引：[[C++系统函数]] · 头文件：[[algorithm]]、[[functional]]

排序题 90% 的分数在**比较器**，二分题 90% 的坑在**边界**。

---

## 一、sort 的三种比较器

```cpp
sort(a, a + n);                                  // 升序
sort(a, a + n, greater<int>());                  // 降序
sort(v.begin(), v.end(), [](int x, int y) {      // 自定义
    return x > y;
});
```

比较器的语义是「x 应不应该排在 y 前面」，返回 `true` 表示 x 在前。

## 二、多关键字排序

```cpp
struct Stu { string name; int score, id; };

sort(v.begin(), v.end(), [](const Stu& a, const Stu& b) {
    if (a.score != b.score) return a.score > b.score;   // 分数降序
    return a.id < b.id;                                 // 同分按 id 升序
});
```

用 `pair` 更省事：`pair<int,int>` 自带「先 first 再 second」的字典序。

## 三、比较器必须满足严格弱序

```cpp
return a.x <= b.x;      // ❌ 错，必须用 <
return a.x < b.x;       // ✅
```

写成 `<=` 会让相等元素互相「小于」，`sort` 可能越界写内存直接崩。**这是 sort 崩溃最常见的原因。**

## 四、二分：库函数版

```cpp
sort(a, a + n);              // 必须先有序！
int p = lower_bound(a, a + n, x) - a;   // 第一个 >= x 的下标
int q = upper_bound(a, a + n, x) - a;   // 第一个 >  x 的下标
bool has = binary_search(a, a + n, x);  // 是否存在
```

`lower_bound` 返回的是**迭代器**，减掉 `begin()` 才是下标。

## 五、二分：手写版（更好用）

```cpp
// 找第一个 >= x 的位置，找不到返回 n
int lowerBound(vector<int>& a, int x) {
    int l = 0, r = (int)a.size();        // 左闭右开
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] >= x) r = mid;
        else l = mid + 1;
    }
    return l;
}

// 找最后一个 <= x 的位置，找不到返回 -1
int lastLE(vector<int>& a, int x) {
    int l = 0, r = (int)a.size() - 1, ans = -1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] <= x) { ans = mid; l = mid + 1; }
        else r = mid - 1;
    }
    return ans;
}
```

`mid = l + (r - l) / 2` 比 `(l + r) / 2` 稳，不会溢出。

## 六、二分答案（重点套路）

**题目长这样**：求最大值最小 / 最小值最大 / 能不能在 k 次内完成。

```cpp
// 例：把数组分成 m 段，使每段和的最大值最小
bool check(long long lim) {
    int cnt = 1; long long sum = 0;
    for (int x : a) {
        if (x > lim) return false;
        if (sum + x > lim) { cnt++; sum = x; }
        else sum += x;
    }
    return cnt <= m;
}

long long l = 0, r = 1e18;         // 答案范围
while (l < r) {
    long long mid = l + (r - l) / 2;
    if (check(mid)) r = mid;       // mid 可行 → 往小找
    else l = mid + 1;
}
cout << l;                          // 最小可行值
```

写二分答案三件事：**答案的单调性**、**check 函数**、**边界写对**。

## 七、找第 k 大

```cpp
nth_element(a, a + k - 1, a + n, greater<int>());   // 第 k 大就位
cout << a[k - 1];
```

平均 O(n)，比整体排序快；但**它只保证第 k 个就位**，其他元素顺序是乱的。

## 八、一页速记

| 我想… | 写法 |
| --- | --- |
| 升序 / 降序 | `sort(b,e)` / `sort(b,e,greater<int>())` |
| 多关键字 | 自定义比较器，先比主键再比次键 |
| 二分查第一个 >= x | `lower_bound` 或手写左闭右开 |
| 最大值最小 | 二分答案 + `check` |
| 第 k 大 | `nth_element` |
| 排序崩了 | 检查比较器是不是写成了 `<=` |
