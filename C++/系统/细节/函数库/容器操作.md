# 容器操作

> 上位索引：[[C++系统函数]] · 头文件：[[vector]]、[[map]]、[[set]]、[[array]]

容器本身怎么定义是头文件笔记的事；这篇讲**用起来最常做的那几件事**，都是模板，直接抄。

---

## 一、排序去重三件套

```cpp
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
```

`unique` **只把重复元素挪到后面，不真删**，返回新的逻辑结尾，所以要配 `erase`。少了后面那半句，`size()` 一点没变。

## 二、遍历删除（最容易写错）

**vector 用下标：**

```cpp
for (size_t i = 0; i < v.size(); ) {
    if (v[i] == 0) v.erase(v.begin() + i);   // 删了不要 i++
    else i++;
}
```

**map / set 用迭代器：**

```cpp
for (auto it = mp.begin(); it != mp.end(); ) {
    if (it->second == 0) it = mp.erase(it);  // erase 返回下一个
    else ++it;
}
```

**千万别**在范围 for 里 `erase`：

```cpp
for (auto x : v) if (x == 0) v.erase(...);   // 迭代器失效，行为未定义
```

## 三、二维数组

```cpp
// 定长
int g[105][105];

// 动态：n 行 m 列，全 0
vector<vector<int>> a(n, vector<int>(m, 0));

// 邻接表
vector<int> g2[100005];
vector<vector<pair<int,int>>> g3(n);    // 带权
```

`vector<vector<int>> a(n, m)` 是**错的**，第二个参数要传 `vector<int>(m)`。

## 四、map 当计数器

```cpp
map<string, int> cnt;
for (auto &s : words) cnt[s]++;         // 不存在自动建 0

// 找出现最多的
int best = 0; string who;
for (auto &[k, v] : cnt)
    if (v > best) { best = v; who = k; }
```

**坑**：`cout << cnt["abc"];` 也会插入一个 0 进去，只查不改请用 `cnt.count("abc")`。

## 五、set 判重与前驱后继

```cpp
set<int> S;
S.insert(x);                       // 自动去重 + 排序
S.count(x);                        // 存在返回 1
auto it = S.lower_bound(x);        // 第一个 >= x
auto jt = S.upper_bound(x);        // 第一个 >  x
```

「边插入边查最近的大于它的数」这种题，`set` 是唯一顺手的写法。

## 六、大小与容量

| 操作 | 作用 |
| --- | --- |
| `v.size()` | 当前元素个数 |
| `v.capacity()` | 已分配的空间 |
| `v.reserve(n)` | 预分配 n 个位置，**不改变 size** |
| `v.resize(n)` | 真把 size 改成 n（多出来的填 0） |
| `v.clear()` | 清空元素，容量不变 |

循环里反复 `push_back` 可以先 `reserve`，减少扩容次数。

## 七、常见坑

1. `v[i]` **不检查越界**，越界是未定义行为，可能崩也可能不崩（更可怕）；要检查用 `v.at(i)`。
2. `vector` 的 `erase` / `push_back` 会让迭代器失效，删完要重新取。
3. `set` / `map` 的元素是**只读**的，不能 `S.begin()->x = 5`。
4. `unordered_map` 的键要能哈希，自定义结构体要自己写哈希函数。

## 八、一页速记

| 我想… | 写法 |
| --- | --- |
| 去重 | `sort` + `unique` + `erase` |
| 边遍历边删（vector） | 下标手动控制 |
| 边遍历边删（map） | `it = mp.erase(it)` |
| 计数 | `cnt[k]++` |
| 判重 + 有序 | `set` |
| 二维动态数组 | `vector<vector<int>> a(n, vector<int>(m, 0))` |
