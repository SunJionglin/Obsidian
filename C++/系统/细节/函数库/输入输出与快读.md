# 输入输出与快读

> 上位索引：[[C++系统函数]] · 头文件：[[iostream]]、[[cstdio]]、[[iomanip]]

这几种写法看着差不多，性能能差十倍，用错了就 TLE 或者读错数据。

---

## 一、三套写法

```cpp
// 1) C++ 流（最方便）
int n;  cin >> n;  cout << n << endl;

// 2) C 风格（最快，格式最灵活）
scanf("%d", &n);  printf("%d\n", n);

// 3) 快读（数据量极大时）
int n = read();
```

日常写作业用第一种；算法题数据到 1e5 以上，加下面两行加速就够。

---

## 二、cin / cout 加速

```cpp
ios::sync_with_stdio(false);   // 关掉与 C 标准流的同步
cin.tie(0);                    // 解除 cin 与 cout 的绑定
```

放在 `main` 开头、**只写一次**。

**加了这两行之后不要再混用 `scanf` / `printf`**，否则顺序会乱（缓冲区不同步）。

---

## 三、读空格的三种情况

```cpp
string s;
cin >> s;                  // 读到空格就停，读不到空格
getline(cin, s);           // 读一整行，保留空格，丢掉换行
cin.getline(buf, 100);     // 读进 char 数组，最多 99 个字符
```

### 最经典的坑

```cpp
int n;
cin >> n;              // 输入 "3\n"，n=3，换行还留在缓冲区
string s;
getline(cin, s);       // 立刻读到空串！
```

修法：中间加一句 `cin.ignore();`，或者干脆全用 `cin >>`。

## 四、格式符（scanf / printf）

| 类型 | scanf | printf |
| --- | --- | --- |
| `int` | `%d` | `%d` |
| `long long` | `%lld` | `%lld` |
| `unsigned` | `%u` | `%u` |
| `float` | `%f` | `%f` |
| `double` | **`%lf`** | `%f`（或 `%lf` 也行） |
| `char` | `%c` | `%c` |
| 字符串 | `%s` | `%s` |
| 十六进制 | `%x` | `%x` |
| 八进制 | `%o` | `%o` |

**`scanf` 读 `double` 必须写 `%lf`**，写 `%f` 会读错（`printf` 里无所谓）。这是最高频的崩溃点。

`%s` 读到空白就停，且**不检查数组长度**，缓冲区开小了会越界。

---

## 五、多组数据

```cpp
// 不知道有多少组，读到结束
int n;
while (cin >> n) {
    cout << n * 2 << "\n";
}

// C 风格
while (scanf("%d", &n) != EOF) { printf("%d\n", n * 2); }

// 第一行给组数
int T; cin >> T;
while (T--) { /* 每组 */ }
```

## 六、输出格式

```cpp
cout << fixed << setprecision(2) << 3.14159;   // 3.14，保留两位小数
cout << setw(5) << 42;                         // "   42"，右对齐宽度 5
cout << setfill('0') << setw(3) << 7;          // "007"
cout << hex << 255;                            // ff
```

- `setprecision(n)` **不加 `fixed`** 表示「有效数字位数」，加了才是小数位数。
- `setw` 只对下一个输出有效，每次都要重新写。

## 七、快读模板（真需要再用）

```cpp
inline int read() {
    int x = 0, f = 1;
    char c = getchar();
    while (c < '0' || c > '9') {
        if (c == '-') f = -1;
        c = getchar();
    }
    while (c >= '0' && c <= '9') {
        x = x * 10 + (c - '0');
        c = getchar();
    }
    return x * f;
}
```

配套的快写：

```cpp
void write(int x) {
    if (x < 0) { putchar('-'); x = -x; }
    if (x > 9) write(x / 10);
    putchar(x % 10 + '0');
}
```

数据 1e6 以上、又不想用 `scanf` 时用；平时别写它，容易读错负数、前导零、行尾。

## 八、一页速记

| 场景 | 写法 |
| --- | --- |
| 常规输入输出 | `cin >>` / `cout <<` |
| 大数据加速 | `sync_with_stdio(false); cin.tie(0);` |
| 读一整行 | `getline(cin, s)`，前面有 `cin >>` 就先 `cin.ignore()` |
| 读 double | `scanf("%lf", &x)` |
| 多组数据 | `while (cin >> n)` |
| 保留小数 | `fixed << setprecision(n)` |
| 极大数据 | 快读 / `scanf` |
