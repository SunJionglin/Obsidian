## 一、[[数学函数]]

数学库的坑几乎都集中在一句话上：**浮点结果差一点点，转成整数就差 1**。

| 函数 | 干什么 | 要提醒的一句 |
| --- | --- | --- |
| `floor(x)` | 向下取整（朝 -∞） | 返回 `double`，`floor(-1.5) = -2` |
| `ceil(x)` | 向上取整（朝 +∞） | `ceil(-1.5) = -1`，与 `floor` 方向相反 |
| `trunc(x)` | 向零取整 | 等价于 `(int)x`，不等于 `floor` |
| `round(x)` | 四舍五入 | 远离零，`round(-1.5) = -2` |
| `sqrt(x)` | 平方根 | 判平方数别只比一次，误差会差 1 |
| `cbrt(x)` | 立方根 | 返回 `double`，判立方数同样要试相邻的整数 |
| `pow(x, y)` | 幂 | 返回 `double`，整数幂用手写快速幂 |
| `log` / `log2` / `log10` | 自然/二/十为底对数 | 换底：`log(x)/log(b)` |
| `exp(x)` | e 的 x 次幂 | 指数大会变 `inf` |
| `fabs(x)` | 浮点绝对值 | 整数用 `<cstdlib>` 的 `abs` |
| `fmod(x, y)` | 浮点取余 | 整数取余直接用 `%` |
| `gcd` / `lcm` | 最大公约 / 最小公倍 | C++17，在 `<numeric>` |

## 二、[[字符处理]]

字符串题里最常错的不是算法，是**边界字符**：空格、大小写、负 `char`。

| 函数 | 干什么 | 要提醒的一句 |
| --- | --- | --- |
| `isalpha(c)` | 是字母吗 | 只认 `a-z A-Z` |
| `isdigit(c)` | 是数字吗 | 只认 `'0'`～`'9'`，`'-'` 不算 |
| `isalnum(c)` | 字母或数字 | 常用来过滤标点 |
| `isspace(c)` | 空白吗 | 空格、`\t`、`\n`、`\r` 都算 |
| `isupper` / `islower` | 大写 / 小写 | 非字母返回假 |
| `isxdigit(c)` | 十六进制字符 | 解析色值时用 |
| `ispunct(c)` | 标点符号 | 统计「非字母」常用它 |
| `toupper(c)` | 转大写 | 非字母原样返回 |
| `tolower(c)` | 转小写 | 比较前统一转小写最省事 |
| `c - '0'` | 字符转数字 | 这是算子，不是函数，但用得最多 |

统一提醒：**参数是 `char` 时先转 `(unsigned char)`**，中文串里会出负数。

## 三、[[排序与查找]]

分数基本在比较器，坑基本在二分边界。

| 函数 | 干什么 | 要提醒的一句 |
| --- | --- | --- |
| `sort(b, e)` | 排序前后两个迭代器 | 默认升序，O(n log n) |
| `sort(b, e, cmp)` | 自定义比较器 | 比较器必须用严格 `<` |
| `greater<T>()` | 降序比较器 | 也可给小根堆用 |
| `stable_sort` | 稳定排序 | 相等元素保持原顺序 |
| `lower_bound` | 第一个 `>= x` | 要求有序，返回迭代器 |
| `upper_bound` | 第一个 `> x` | 配合 `lower_bound` 算出现次数 |
| `binary_search` | 二分查存在 | 只返回 `bool`，不给位置 |
| `nth_element` | 第 k 个就位 | 平均 O(n)，其他元素是乱的 |
| `max_element` / `min_element` | 最值位置 | 返回迭代器，要 `*` 取值 |
| `reverse` | 反转区间 | 判回文常和 `==` 配 |

## 四、[[容器操作]]

容器笔记单独写，是因为**用法比定义重要**。

| 操作       | 写法                                 | 要提醒的一句                  |
| -------- | ---------------------------------- | ----------------------- |
| 尾部追加     | `push_back(x)` / `emplace_back(x)` | `emplace` 少一次拷贝         |
| 尾部删除     | `pop_back()`                       | 不返回值，先取再删               |
| 指定位置插入   | `insert(v.begin()+i, x)`           | `vector` 会挪动后面全部元素      |
| 指定位置删除   | `erase(v.begin()+i)`               | 返回下一个位置                 |
| 删除所有等于 x | `erase(remove(...), end())`        | 少后半句等于没删                |
| 改大小      | `resize(n)` / `resize(n, 0)`       | `reserve` 只改容量不改 size   |
| 清空       | `clear()`                          | 容量不变，内存不还               |
| 大小       | `size()` / `empty()`               | 两者等价，`empty` 更语义化       |
| 带检查访问    | `at(i)`                            | `[]` 越界不报错，更危险          |
| map 计数   | `mp[k]++`                          | 查询也会插入新键                |
| map 查存在  | `count(k)` / `find(k)`             | 只查不改用这两个                |
| map 删除   | `erase(k)`                         | 边遍历边删用 `it = erase(it)` |
| set 去重   | `insert(x)`                        | 自动排序                    |
| set 前驱后继 | `lower_bound` / `upper_bound`      | 边插边查的唯一选择               |

## 五、[[类型转换]]

两个坑：整数除法截断、乘法溢出。字符串转数字另算一类。

| 函数 / 写法 | 干什么 | 要提醒的一句 |
| --- | --- | --- |
| `(int)x` | 强制转换 | 向零截断，不是四舍五入 |
| `(double)a / b` | 整数除法求小数 | 括号别漏，`7/2` 已经是 3 |
| `static_cast<int>(x)` | 显式转换 | 比 `(int)` 更明确 |
| `stoi(s)` | 字符串转 int | 非法输入抛异常 |
| `stoll(s)` | 字符串转 long long | 大数必用 |
| `stod(s)` | 字符串转 double | 科学计数法也能读 |
| `to_string(x)` | 数字转字符串 | 浮点默认补 6 位小数 |
| `atoi(s)` | C 风格转数字 | 非法返回 0，不报错 |
| `strtol(s, &end, base)` | 指定进制 | `base=0` 自动识别 `0x` |

## 六、[[输入输出与快读]]

三种写法性能差十倍，格式符写错是高频崩溃点。

| 写法 | 干什么 | 要提醒的一句 |
| --- | --- | --- |
| `cin >> x` | 标准读入 | 自动跳过空白 |
| `cout << x` | 标准输出 | 大数据用 `'\n'` 不用 `endl` |
| `getline(cin, s)` | 读一整行 | 前面有 `cin >>` 要先 `ignore()` |
| `cin.getline(buf, n)` | 读进 char 数组 | 最多 n-1 个字符 |
| `scanf("%d", &x)` | C 风格读入 | 读 double 必须 `%lf` |
| `printf("%d", x)` | C 风格输出 | 格式符和类型必须对上 |
| `sync_with_stdio(false)` | 关同步 | 只写一次，之后别混用 scanf |
| `cin.tie(0)` | 解绑定 | 和上面配对使用 |
| `fixed` + `setprecision(n)` | 保留 n 位小数 | 不加 fixed 是有效数字 |
| `setw(n)` / `setfill(c)` | 宽度 / 填充 | `setw` 只对下一次输出有效 |
| `hex` / `oct` | 十六 / 八进制输出 | 输出完记得改回 `dec` |
| `read()` 快读 | 极大数据读入 | 自己写的，容易漏负数 |

## 七、[[随机与计时]]

造数据靠随机，验证靠对拍，评估靠计时，三件事一套流程。

| 函数 / 写法 | 干什么 | 要提醒的一句 |
| --- | --- | --- |
| `rand()` | 伪随机 | 范围常只有 32767 |
| `srand(time(0))` | 设种子 | 整个程序只调一次 |
| `mt19937` | 高质量随机引擎 | 对拍必用 |
| `uniform_int_distribution(l, r)` | 区间均匀整数 | 分布对象别放循环里 |
| `shuffle(b, e, rng)` | 随机打乱 | 替代已废弃的 `random_shuffle` |
| `clock()` | CPU 用时 | 除以 `CLOCKS_PER_SEC` |
| `steady_clock::now()` | 单调时钟 | 测速比 `clock` 准 |
| `duration_cast<ms>(d)` | 时间单位换算 | 会截断，看毫秒够了 |

## 按学习顺序读

**第一轮（语法课同步）**：[[输入输出与快读]] → [[类型转换]] → [[字符处理]]

**第二轮（开始刷题）**：[[排序与查找]] → [[容器操作]]
排序 + 二分 + 容器是算法题的通用底座，不熟会卡在写代码上。

**第三轮（想更稳）**：[[数学函数]] → [[随机与计时]]
前者防「结果差 1」，后者用来对拍造数据，属于提分项。
