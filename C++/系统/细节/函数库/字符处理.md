# 字符处理

> 上位索引：[[C++系统函数]] · 头文件：[[cctype]]、[[string]]

考试里一大半字符串题，真正难的不是字符串算法，是**字符的边界**：空格、大小写、负字符、`'0'` 和 0。

---

## 一、判断与转换

| 函数 | 判断什么 | 备注 |
| --- | --- | --- |
| `isalpha(c)` | 字母 | 只看 `a-z A-Z` |
| `isdigit(c)` | 数字 | `'0'`～`'9'` |
| `isalnum(c)` | 字母或数字 | — |
| `isspace(c)` | 空白 | 空格、`\t`、`\n`、`\r`、`\f`、`\v` |
| `isupper(c)` / `islower(c)` | 大写 / 小写 | — |
| `toupper(c)` / `tolower(c)` | 转大小写 | 非字母原样返回 |

**它们接收 `int`，返回 `int`**，非 0 表示真：

```cpp
if (isdigit(c)) { }        // 千万别写 if (isdigit(c) == 1)
```

## 二、最容易出事的坑：负字符

```cpp
char c = s[i];
isspace(c);                // 参数是 char，可能被解释成负数 → 未定义行为
isspace((unsigned char)c); // 标准写法
```

含中文的字符串里，`char` 的值为负，直接传进去有概率乱判断甚至崩。**养成先转 `unsigned char` 的习惯**。

## 三、字符 ↔ 数字

```cpp
char c = '7';
int  x = c - '0';          // 7
char d = x + '0';          // '7'

int y = c;                 // 55，是 ASCII 码，不是数字
```

`isdigit(c)` 判断 → `c - '0'` 取值，这是标准两步走。

## 四、整串大小写

```cpp
// 转大写
for (char &c : s) c = toupper(c);

// 或者用 transform
transform(s.begin(), s.end(), s.begin(), ::toupper);
```

注意 `::toupper` 前面的冒号，直接写 `toupper` 遇到重载会编译不过。

## 五、统计字母出现次数

```cpp
int cnt[26] = {0};
for (char c : s)
    if (isalpha(c)) cnt[tolower(c) - 'a']++;

for (int i = 0; i < 26; i++)
    if (cnt[i]) cout << char('a' + i) << ": " << cnt[i] << endl;
```

这个模板能解决「统计词频」「找出现最多的字母」「判断能否重排成回文」一大类题。

## 六、判断回文

```cpp
bool isPalindrome(const string& s) {
    int i = 0, j = (int)s.size() - 1;
    while (i < j) {
        if (s[i] != s[j]) return false;
        i++; j--;
    }
    return true;
}
```

要忽略大小写和标点，就先过滤出一个纯字母串：

```cpp
string t;
for (char c : s)
    if (isalnum(c)) t += tolower(c);
return isPalindrome(t);
```

`s.size()` 是 `unsigned`，减到 0 还继续会变成巨大数，**先转 `int` 再减**。

## 七、一页速记

| 我想… | 写法 |
| --- | --- |
| 判断是不是数字字符 | `isdigit((unsigned char)c)` |
| 字符转数字 | `c - '0'` |
| 整串转大写 | `for (char &c : s) c = toupper(c);` |
| 统计字母频次 | `cnt[tolower(c) - 'a']++` |
| 忽略大小写比较 | 两边都 `tolower` 再比 |
| 判回文 | 双指针，下标用 `int` |
