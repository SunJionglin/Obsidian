# 随机与计时

> 上位索引：[[C++系统函数]] · 头文件：`<cstdlib>`、`<ctime>`、`<random>`、`<chrono>`

两个用途：**造数据对拍** 和 **给算法计时**。

---

## 一、老写法：rand()

```cpp
#include <cstdlib>
#include <ctime>

srand(time(0));          // 种子，整个程序只调一次
int x = rand();          // 0 ～ RAND_MAX（通常 32767）
int y = rand() % 100;    // 0 ～ 99
```

### 三个坑

1. **范围太小**：`RAND_MAX` 常见只有 32767，想随机到 1e9 得拼两次。
2. **低位随机性差**：`rand() % 2` 在有些编译器上 0 和 1 会交替出现。要范围大用比例法：

```cpp
int rnd(int l, int r) {                 // 随机数落进 [l, r]
    return l + (int)(1.0 * rand() / RAND_MAX * (r - l + 1));
}
```

3. **`srand` 调多次**：放在循环里会得到一串相同值，因为同一秒种子一样。

```cpp
for (int i = 0; i < 10; i++) { srand(time(0)); cout << rand(); }   // 全一样，错！
```

## 二、新写法：mt19937

```cpp
#include <random>
#include <chrono>

mt19937 rng(chrono::steady_clock::now().time_since_epoch().count());

// 取 [l, r] 的整数
int rnd(int l, int r) {
    uniform_int_distribution<int> d(l, r);
    return d(rng);
}

// 取 [0, 1] 的浮点
double rndf() {
    uniform_real_distribution<double> d(0.0, 1.0);
    return d(rng);
}
```

`mt19937` 周期 2^19937-1，质量比 `rand` 好得多，做**对拍**必须用它。**注意 `distribution` 对象别每次循环都重建**（慢），放循环外或做 `static`。

## 三、随机打乱

```cpp
#include <algorithm>
#include <random>

mt19937 rng(12345);                        // 固定种子，结果可复现
shuffle(a.begin(), a.end(), rng);          // 比 random_shuffle 好，后者已废弃
```

固定种子 + `shuffle` 能做出「看起来随机、实际可复现」的测试数据，调试非常有用。

## 四、计时：clock()

```cpp
#include <ctime>

clock_t st = clock();
// ... 要测的代码 ...
double sec = (double)(clock() - st) / CLOCKS_PER_SEC;
cout << fixed << setprecision(3) << sec << " s" << endl;
```

`CLOCKS_PER_SEC` 一般是 1e6，单位是 **CPU 时间**，不是真实经过的时间。

精度更高的版本：

```cpp
#include <chrono>
auto st = chrono::steady_clock::now();
// ... 代码 ...
auto ed = chrono::steady_clock::now();
double ms = chrono::duration<double, milli>(ed - st).count();
```

## 五、对拍怎么用（重点）

1. 写三个程序：`gen.cpp`（随机造数据）、`std.cpp`（暴力正确解）、`mine.cpp`（你的解）。
2. 循环：造数据 → 跑两个程序 → 比输出。

```cpp
// gen.cpp：输出一组随机数据
int main() {
    mt19937 rng(chrono::steady_clock::now().time_since_epoch().count());
    uniform_int_distribution<int> n(1, 100), v(1, 1000);
    int t = n(rng);
    cout << t << endl;
    for (int i = 0; i < t; i++) cout << v(rng) << " ";
    cout << endl;
    return 0;
}
```

命令行里用脚本循环 `gen > in.txt`、`std < in.txt > a.txt`、`mine < in.txt > b.txt`、`diff a.txt b.txt`，一致就继续，不一致就停下看 `in.txt`。

**对拍三件套的价值**：比盯着代码找 bug 快十倍，尤其是边界和溢出问题。

## 六、一页速记

| 我想… | 写法 |
| --- | --- |
| 快速要个随机数 | `rand() % n`（凑合用） |
| 认真造数据 | `mt19937` + `uniform_int_distribution` |
| 打乱数组 | `shuffle(v.begin(), v.end(), rng)` |
| 测代码用时 | `clock()` + `CLOCKS_PER_SEC` |
| 高精度计时 | `chrono::steady_clock` |
| 结果可复现 | 用固定种子，别用 `time(0)` |
