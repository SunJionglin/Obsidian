

在 C 和 C++ 中，`size_t` 是一个**标准的无符号整数类型**，主要用于表示**对象的大小**（如内存块大小、数组长度）或**数组 / 容器的索引**。它的设计目的是确保能容纳当前系统中可能出现的最大对象的大小。

### 核心特性

1. **无符号性**：`size_t` 是**无符号类型**（unsigned），因此它的值始终是非负的（≥ 0）。
2. **位数适配**：`size_t` 的位数通常与系统的**指针位数**一致（32 位系统中为 32 位，64 位系统中为 64 位），这保证了它能表示当前系统中最大的内存块或对象大小。
3. **标准定义**：在 C 中定义于 `<stddef.h>` 头文件，在 C++ 中定义于 `<cstddef>` 头文件（但很多常用头文件如 `<string>`、`<vector>` 等也会间接包含它，因此实际使用中常不需要显式包含 `<cstddef>`）。

### 主要用途

`size_t` 是表示 “大小” 和 “索引” 的 “标准选择”，常见场景包括：

1. **`sizeof` 运算符的返回值**：`sizeof` 用于计算对象或类型的大小，其结果类型正是 `size_t`。
    
    示例：
    
    cpp
    
    运行
    
    ```cpp
    int x;
    size_t size = sizeof(x);  // 正确：sizeof 返回 size_t
    ```
    
2. **容器的大小和容量**：C++ 标准容器（如 `std::vector`、`std::string`）的 `size()`、`capacity()` 等成员函数的返回值类型是 `size_t`。
    
    示例：
    
    cpp
    
    运行
    
    ```cpp
    std::vector<int> vec = {1, 2, 3};
    size_t len = vec.size();  // len 为 3（类型为 size_t）
    ```
    
3. **数组索引**：用于遍历数组或容器时的索引（避免使用有符号类型如 `int` 导致的潜在溢出问题）。
    
    示例：
    
    cpp
    
    运行
    
    ```cpp
    int arr[5] = {10, 20, 30, 40, 50};
    for (size_t i = 0; i < 5; ++i) {  // i 为 size_t 类型，适合作为索引
        std::cout << arr[i] << " ";
    }
    ```
    
4. **内存分配函数参数**：如 `malloc`、`calloc` 等函数的参数类型是 `size_t`，用于指定分配的字节数。
    
    示例：
    
    cpp
    
    运行
    
    ```cpp
    int* ptr = (int*)malloc(10 * sizeof(int));  // 参数 10*sizeof(int) 是 size_t 类型
    ```
    

### 注意事项

1. **无符号的陷阱**：由于 `size_t` 是无符号的，若用于表示 “可能为负的值” 或参与 “可能产生负数的运算”，会导致意外结果。
    
    例如，以下循环会**无限执行**（因为 `i` 是无符号类型，`i >= 0` 永远为真，且 `--i` 会在 `i=0` 时溢出为最大值）：
    
    cpp
    
    运行
    
    ```cpp
    for (size_t i = 5; i >= 0; --i) {  // 错误：无限循环！
        // ...
    }
    ```
    
2. **与有符号类型的混合使用**：当 `size_t` 与有符号类型（如 `int`）混合比较或运算时，编译器会将有符号类型隐式转换为无符号类型，可能导致逻辑错误。
    
    示例：
    
    cpp
    
    运行
    
    ```cpp
    size_t a = 10;
    int b = -5;
    if (a < b) {  // 错误：b 被转换为无符号数（极大值），导致条件为真
        // 实际不会执行的逻辑
    }
    ```
    

### 总结

`size_t` 是 C/C++ 中用于表示 “大小” 和 “索引” 的标准无符号类型，适配系统位数，确保能容纳最大对象大小。使用时需注意其无符号特性，避免与有符号类型混合运算或用于可能产生负数的场景。
