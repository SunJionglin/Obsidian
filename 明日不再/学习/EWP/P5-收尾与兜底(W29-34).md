## 三、C++ 加分模块规格（W29–30）

**选题（二选一）**

1. 文本预处理：切分、清洗、去重（比 Python 快 5–20 倍）。
2. 相似度计算：cosine/Jaccard 的批量计算。

**要求**

- 用现代 C++（`std::string_view`、STL 容器），代码 200–400 行。
- pybind11 暴露 Python 接口；项目 C 里真实调用。
- benchmark：同数据下 Python 实现 vs C++ 实现的耗时对比表。

**简历写法**：「用 C++ 重写 RAG 预处理模块（pybind11 接入），预处理耗时降低 8 倍。」
