# 蓝桥杯 A 组 · 知识点地图

> 依据：官方《蓝桥杯大赛软件赛知识点大纲》[第十五届 PDF](https://x-static.lanqiao.cn/upload/202401/courseimg/d8312a5e-2d8a-45a8-b1d6-7858c9e83be3.pdf)（2026-11-07 下载核对）。
> 大纲原文两条关键规则：**「难度系数 1–10 依次递增」**、**「各组考点向上兼容：A 组需同时掌握 B 组和 C 组知识点」**。
> 所以「A 组 = C 组 + B 组 + A 组专属那 15 点」。A 组专属那 15 点是压轴题用的，不是地基——**先地基后压轴**，顺序反了会在省赛就翻车。

**这张表怎么用**：不是课本，是检查口。每点三问——机制说得出来吗？模板默得出来吗？洛谷原题 40 分钟内 AC 吗？三问过两问算「会」，只过第一问算「知道」，第一问都过不了就是没学。

## 一 · 国奖要什么：知识面 ≠ 分数线

官方只公布奖项不公布分数线，下面的分数是**按近年 A 组题目难度、8 题 100 分结构、按测试点给分估出来的，不是官方线**，用来定「做到几题就够」，不要当承诺。

| 目标 | 省赛（8 题 / 100 分） | 国赛 | 必须过的知识面 | 允许空白 |
| --- | --- | --- | --- | --- |
| 省三 | 20–30 分（2–3 题） | — | C 层 1–11 | 全部 B 层 |
| 省二 | 40–50 分（4 题） | — | C 层 + 搜索/贪心/一维 DP | 图论、高级结构 |
| **省一**（= 晋级国赛的唯一门票，各省约前 10%） | 60–70 分（5–6 题） | — | C 层 + B 层 12–24 + 27、28、43 | A 层全部 |
| 国三 | 省一 | 40–50 分 | 省一 + B 层 25–47 的「能读题解」 | A 层全部 |
| 国二 | 省一（省内排名靠前） | 60–70 分 | 省一 + 树状数组/线段树/背包全套/区间 DP/数位 DP/KMP/Manacher | A 层大部分 |
| **国一** | 省一（约前 1–3%） | 80+ 分（7 题左右） | 全 B 层到「能默写」+ A 层挑 4–6 点 | 后缀自动机、树套树、动态树、生成函数 |

**为什么是这条线**：省赛前 10% 才是省一，国赛参赛资格 = 省一；所以「国奖」的真实门槛是**省赛先进前 10%**，国赛再拼一轮。省赛拼的是「简单题不丢分 + 中档题全拿」，国赛拼的是「压轴题拿部分分」。这两件事练法不同：省赛练**限时与覆盖率**，国赛练**深水模板 + 部分分设计**。

## 二 · 第 0 层：竞赛工程（W1 就补齐，不补的话后面每次都在为它付费）

| 编号 | 点 | 机制 / 边界 | 验收 |
| --- | --- | --- | --- |
| 0.1 | C++ 提交模板 | `#include <bits/stdc++.h>` + `using namespace std;` + 单文件、无文件读写、stdin/stdout；蓝桥评测只收源码，不能带工程文件 | 手敲一遍 ≤2 分钟，不抄 |
| 0.2 | 快读与输出 | `scanf` / `cin` + `ios::sync_with_stdio(0); cin.tie(0);`；1e6 行输入时 cin 不解绑会超时 | 造 1e6 行输入，对比解绑前后耗时 |
| 0.3 | 整型与溢出 | 蓝桥爱给 1e9 级数据，`int` 两数相乘就溢出；`long long`、`%lld`、`1LL*x`；取模后再乘 | 写出 3 种溢出并改对 |
| 0.4 | 数组与栈空间 | 全局数组开 `1e7` 级；递归深度 1e5 会爆栈（A 组常见坑），要么改栈大小要么写迭代 | 递归 1e5 层跑一次，看结果 |
| 0.5 | 复杂度估时 | 1 秒 ≈ 1e8 次简单操作；n=1e5 → O(n log n)；n=1e3 → O(n²) 还活着；n=1e9 → 只能 O(1)/O(log n) | 拿 5 道题先估再交，比实际耗时 |
| 0.6 | 对拍脚本 | 生成器 + 暴力 + 正解，循环 `diff`；蓝桥不给测试点反馈，对拍是唯一自测手段 | 写一次，跑通，存进模板库 |
| 0.7 | 部分分设计 | 按数据范围写「暴力档」：n≤20 爆搜、n≤1e3 三方枚举、n≤1e5 正解；先交暴力再改 | 一道题写出两档并都能跑 |

## 八 · 自测（合上笔记答，答不上就回去补那一节）

<details>
<summary>Q1：为什么 0/1 背包要逆序枚举容量，完全背包却要正序？</summary>

逆序保证「每件物品只用一次」：更新 f[j] 时读到的 f[j-w] 还是上一轮（没放本物品）的值。正序会让 f[j-w] 先被本轮更新，同一件物品被重复放——那正好是完全背包要的效果。
</details>

<details>
<summary>Q2：线段树的懒惰标记什么时候下推？不下推会出什么错？</summary>

访问子区间之前必须下推（查询、或继续向下修改时）。不下推就会用「父节点还没传给子节点的旧值」去算答案，表现为：整段修改后查子区间，答案对不上。第二种错是下推后忘记清空标记，导致重复累加。
</details>

<details>
<summary>Q3：Dijkstra 为什么不能有负权边？负权怎么办？</summary>

Dijkstra 的正确性靠「已出堆的点最短路已定」，负权边会让后来者更短，这个前提破掉。有负权用 Bellman-Ford / SPFA（会被卡），有负环要先判环；全源且 n≤500 用 Floyd。
</details>

<details>
<summary>Q4：省赛只剩 40 分钟，还有两道题没动，先做哪道？</summary>

先做**数据范围最小、最容易拿部分分**的那道，哪怕它是 20 分题。蓝桥按测试点给分，暴力过 3 个点就是分；死磕一道正解可能 0 分。顺序永远是：填空 → 能拿满的简单题 → 部分分 → 正解。
</details>

<details>
<summary>Q5：为什么说「A 组专属知识点」不是地基？</summary>

因为省赛 8 题里它们最多占 1–2 题，而它们每个都要 10–20 小时才到「能默写」。同样时间投在 B 层的线段树/DP 上，能多拿 3–4 题。国奖的算法是「B 层稳稳拿满 + A 层用暴力拿部分分」，不是「A 层全会」。
</details>
