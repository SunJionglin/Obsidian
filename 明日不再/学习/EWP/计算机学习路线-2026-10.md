## 2. 现实判断：大二暑假实习怎么找

**先说清楚三件事，避免走弯路**

1. **大厂「暑期实习」主要面向大三**（2028 届及更早），2029 届大二能投的岗位有限；不要只盯着大厂暑期实习。
2. **日常实习是全年滚动招聘**，中小厂、AI 初创、外包/远程团队对大二更友好；这才是主战场。
3. **大二能拿什么**：AI 应用（RAG/Agent）方向的项目 + Python 工程能力，比「学过 C++ 语法」更有辨识度。

**目标公司分层**

| 层级 | 例子 | 策略 |
| --- | --- | --- |
| 第一优先 | AI 应用初创、AI 工具团队、垂直行业 AI 部门 | 项目对口、能干活就收；投递时附 demo |
| 第二优先 | 中小厂 Python 后端、数据平台、自动化工具 | 看基础和项目，笔试难度中等 |
| 冲刺 | 大厂日常实习、低年级计划 | 有岗就投，不押宝 |
| 兜底 | 实验室项目、开源之夏、远程实习、学长内推 | 保证暑假有事做、有产出 |

**差异化打法**

- 简历上放一个「有评估数据」的 AI 应用项目，比放三个 CRUD 项目强。
- 每个项目都部署上线、有 README、有 demo 链接；面试时能现场打开。
- 用 AI 工具提效，但能讲清每一行为什么这么写——这是 2026 年面试官最在意的分水岭。

1. 每两周必须有一个能运行、能演示的东西。

## 5. 分阶段详解

### P0 · Python 语法补齐 + 工具与 Linux + 算法入门（W1–3，54h）

**目标**

1. 把「知道语法」变成「能独立写 200 行脚本」。
2. 会用 Git、Linux 终端、VS Code、uv。
3. 认识复杂度，能写数组/哈希/链表的基础题。

**知识清单（必须）**

- Python：变量与类型、字符串、列表/元组/字典/集合、分支循环、函数与参数、文件读写、异常处理、类与对象入门。
- 工具：终端与 Linux 基础命令（文件/权限/管道/进程/ssh）、Git 提交/分支、VS Code 调试、`uv` 建环境。
- 算法：时间/空间复杂度、数组与字符串、链表、栈与队列、哈希表。
- 刷题：LeetCode Easy 50 道（数组 20、哈希 15、链表 10、栈队列 5）。

**每天怎么练**

- 30 分钟看/抄示例，60 分钟自己写，30 分钟做 1 道题。
- 每周日把一个星期的代码整理成一个仓库，写 README。

**项目：小工具（W3）**

- 选题：文件批量重命名 / 通讯录管理 / 单词本 / CSV 统计，四选一。
- 要求：命令行参数、文件读写、异常处理、至少 5 个函数、README。
- 验收：能处理错误输入不崩；代码 150–250 行。

**资源**

- 《Python 编程：从入门到实践》第 1–11 章（只做练习，不抄代码）。
- Python 官方 Tutorial 前 9 章。
- 《Hello 算法》第 1–5 章（数组、链表、栈队列、哈希）。
- LeetCode 新手题单。

**验收标准**

- 不看教程写出「读文件 → 处理 → 写文件」的完整脚本。
- 能说出 list/dict/set 的查找复杂度。
- Git 能独立提交、回滚、开分支。

**常见坑**：只看视频不动手；追求一次写对；不做题只学语法。

### P1 · Python 工程化 + 算法核心 + AI 初体验（W4–9，108h）

**目标**

1. 能写有函数拆分、有测试、能打包的 Python 项目。
2. 掌握树、堆、排序、二分，累计 80 题。
3. 第一次接 LLM API，做出一个能演示的 AI 小工具。

**知识清单（必须）**

- Python 进阶：闭包、装饰器、面向对象、`dataclass`、异常与上下文管理器、迭代器与生成器、模块与包、类型注解。
- 工程：`uv`、`pyproject.toml`、`pytest`、`ruff`、`mypy`、`logging`、`argparse`。
- 算法：二叉树遍历、BST、堆与优先队列、排序（快排/归并）、二分查找。
- AI：LLM API 调用、流式输出、prompt 基本结构、结构化输出（JSON）、工具调用（function calling）概念、错误重试与限流。

**项目 A：AI 命令行助手（W7–9）**

- 功能：接一个 LLM API，支持多轮对话、流式输出、一个本地工具（读文件/查天气/算数任选）、配置管理、错误重试。
- 要求：API key 从环境变量读；有单元测试（mock API）；`uv` 打包；README 有演示 GIF 或截图。
- 验收：断网/超时有友好提示；能讲清一次请求的完整链路。
- 简历写法：「Python 命令行 AI 助手：接入 LLM API，支持流式输出与工具调用，含重试、限流与测试」。

**算法进度**：累计 80 题（Easy 50 + Medium 30），开始写题解笔记。

**资源**

- 《流畅的 Python》选读（函数、类、生成器）。
- pytest / ruff / mypy 官方文档。
- 《Hello 算法》第 6–8 章（树、堆、图入门）。
- DeepSeek / OpenAI API 文档（选一个，读 quickstart + function calling）。
- 代码随想录（二叉树、回溯专题）。

**验收标准**

- 能写带 fixture 的 pytest 测试。
- 能解释生成器为什么省内存、装饰器怎么工作。
- 项目 A 能在别人电脑上按 README 跑起来。

**常见坑**：项目做到一半换题；API 报错就放弃；不写测试。

### P2 · 后端基础 + RAG 入门 + 开始投递（W10–15，108h）

**目标**

1. 能写一个带数据库、缓存、鉴权的 Web 服务并部署上线。
2. 理解 RAG 全流程，做出文档问答应用。
3. 1 月开始投日常实习，2 月投暑期实习。

**知识清单（必须）**

- Web：HTTP、REST、状态码、FastAPI 路由/依赖注入/Pydantic 校验。
- 数据库：SQL 基础、表设计、索引、事务；MySQL 8.4（InnoDB）。
- ORM：SQLAlchemy 2.0 + Alembic 迁移。
- 缓存：Redis 基础、缓存穿透/击穿。
- 部署：Docker、docker compose、Nginx 反代、Linux 服务器、GitHub Actions。
- RAG：文档切分、embedding、向量库（Chroma 或 Qdrant）、相似度检索、引用来源、失败兜底。
- 算法：图 BFS/DFS、回溯、DP 入门；累计 110 题。

**项目 B：文档问答 Web 应用（W12–15）**

- 功能：上传 PDF/Markdown → 切分入库 → 提问 → 带引用回答 → 历史记录。
- 技术：FastAPI + MySQL + 向量库（Chroma）+ LLM API + Docker 部署。
- 要求：有登录或访问码；有 20 条测试问题；记录命中率与延迟；线上可访问。
- 验收：面试官能当场打开用；能讲清「检索不到时怎么办」。

**投递动作**

- 1 月起：整理简历 v1，注册牛客/BOSS/实习僧，每周投 10 家日常实习。
- 2 月起：暑期实习与低年级项目全投，记录投递表（公司/岗位/时间/状态）。
- 每周复盘：投了多少、回了多少、挂在哪一轮。

**资源**

- FastAPI 官方 Tutorial（全读）。
- MySQL 官方文档（索引、事务、EXPLAIN）。
- SQLAlchemy 2.0 文档（ORM 快速入门 + 迁移）。
- RAG 相关：LangChain/LlamaIndex 文档选一个（只学检索链路，不陷进去）。
- 《Hello 算法》第 9–11 章（图、排序、搜索）。

**验收标准**

- 能设计 3 张表并解释索引。
- 能独立部署一个可访问服务。
- 能画出 RAG 流程图并说出每步的失败模式。

**常见坑**：环境部署卡一周；RAG 只调库不做评估；投递等「准备好」才投。

### P3 · AI 应用强化 + 旗舰项目 + 面试启动（W16–22，02/15–04/04，126h）

**目标**

1. 做出一个有评估数据、能讲 30 分钟的 AI 应用旗舰项目。
2. 掌握 Agent、MCP、RAG 进阶与成本/安全。
3. 开始模拟面试，积累面试素材。

**知识清单（必须）**

- RAG 进阶：混合检索（BM25 + 向量）、rerank、多路召回、查询改写、长文档策略。
- 评估：构建 30–50 条 eval 集、命中率/忠实度/延迟/成本、LLM-as-judge 的偏差。
- Agent：工具调用、规划、记忆、失败重试、多步任务；MCP 协议与工具权限。
- 工程：流式、并发、缓存、超时、限流、日志与追踪。
- 安全：prompt 注入、越权工具、数据泄露、输出校验。
- 算法：累计 140 题，开始限时训练。
- 面试：Python 八股、后端基础、项目追问。

**项目 C（旗舰）：带评估的 AI 应用（W16–22）**

- 选题三选一：
  1. 课程/个人知识库助手：多文档、混合检索、引用、评估面板。
  2. 代码库问答助手：仓库解析、切片、检索、引用到文件行。
  3. 客服/工单助手：意图识别、工具调用（查订单）、人工兜底。
- 必须有的东西：eval 集与指标、成本估算、错误日志、部署、README 架构图、一篇技术博客。
- 加分项：一个 C++/pybind11 写的性能模块（如文本预处理/相似度计算），用来讲「跨语言优化」。
- 验收：10 个真实用户试用（同学即可）；能回答「为什么不用现成框架」「检索错了怎么修」。

**面试启动**

- 每周 1 次模拟面试（同学互面或 AI 模拟），录音复盘。
- 整理「项目追问 20 问」：为什么做、怎么设计、瓶颈、数据、如果重做。

**资源**

- MCP 官方文档。
- RAG 评估相关博客/论文（选读 2–3 篇）。
- 《Designing Data-Intensive Applications》选读（第 1、2 章）。
- 牛客 AI 应用/后端面经。

**验收标准**

- 能白板画出项目架构并讲清取舍。
- 能回答 10 个 RAG/Agent 设计题。
- 项目有可复现的评估数据。

## 8. 算法计划：250 题次怎么排

| 阶段 | 题量 | 重点 | 方式 |
| --- | --- | --- | --- |
| P0 | 50 | 数组、哈希、链表、栈队列 | 每天 1 题，Easy 为主 |
| P1 | +30（累计 80） | 二叉树、堆、排序、二分 | 每天 1 题，Medium 为主 |
| P2 | +30（累计 110） | 图、回溯、DP 入门 | 每天 1 题 + 周赛 |
| P3 | +30（累计 140） | DP、字符串、综合 | 限时 45 分钟 |
| P4 | +60 题次（累计 200）+ 错题三刷 40 | 高频补充、错题三刷、Hot 100 | 模拟面试 |

**方法**

- 每题限时 25 分钟；不会就看题解，第二天默写。
- 三行笔记：思路、复杂度、易错点。
- 每周日重做 3 道错题。
- C++ 对照：每周挑 2 题用 C++ 写，保持手感，不额外花时间。

**题单**：LeetCode Hot 100、代码随想录、剑指 Offer（选）。

## 9. AI 应用强化地图（本路线重点）

| 层级 | 学什么 | 产出 | 时间 |
| --- | --- | --- | --- |
| L1 调用 | LLM API、流式、重试、结构化输出、成本 | 项目 A | W7–9 |
| L2 检索 | 切分、embedding、向量库、引用 | 项目 B | W12–15 |

- 忽视成本与延迟——生产环境第一课。
- 不做安全——prompt 注入、工具越权是必问题。
