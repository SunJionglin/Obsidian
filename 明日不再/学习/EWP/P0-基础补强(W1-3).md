## 三、知识点清单（按周）

**W1**

- 环境：`uv python install 3.14`、`uv init`、VS Code 调试器、Git `init/add/commit/push`。
- Linux 与终端：`ls/cd/pwd/mkdir/rm/mv/cp/find/grep`、权限 `chmod/chown`、管道与重定向、`ps/top/kill`、`ssh/scp`、`tar`、`curl`。
- 类型与容器：list 切片、dict 遍历与 get、set 去重、tuple 解包。
- 控制流：for-else、while-else、enumerate、range 步长。
- 函数：位置/关键字/默认参数、返回值、作用域。

**W2**

- 文件：`with open(...) as f`、read/readlines、写模式。
- 字符串：strip、split、join、replace、find、format/f-string、切片反转。
- 异常：try/except/else/finally、捕获具体异常、raise。
- 类入门：class、__init__、self、方法、属性。
- Git：branch、checkout、merge、restore、log。

**W3**

- 链表：节点类、增删改查、遍历。
- 栈/队列：list 模拟栈、deque 双向操作。
- 二分：左闭右开模板、边界收缩。
- 复杂度：O(1)/O(n)/O(n²)/O(log n) 各举一例。

**附 · Linux 必会清单（W1–W3 打底，每天 10 分钟）**

- 文件与权限：`ls/cd/pwd/mkdir/rm/mv/cp/find/grep/xargs`、`chmod/chown`、`ln`、`tar`。
- 文本与管道：`|`、`>`、`>>`、`tee`、`head/tail`、`sort/uniq/wc`、`awk/sed` 基础。
- 进程与资源：`ps/top/htop`、`kill/pkill`、`nohup`、`jobs`、`df/du`。
- 网络排查：`curl`、`ping`、`ss -lntp`、`dig`、`ssh/scp/rsync`。
- 服务与脚本：`systemctl start/enable/status`、`journalctl -u`、`cron`、bash 变量/条件/循环。
- 练习方式：macOS 上练日常命令；Linux 用一台 VPS 或 UTM/WSL 虚拟机，每周 2 次、每次 20 分钟。
- 验收：不用图形界面完成「传文件 → 起服务 → 查日志 → 排查端口占用」。

## 六、项目：小工具（W2 周六立项 → W3 周六收尾）

**选题四选一**

1. 文件批量重命名（按日期/前缀/序号）
2. 通讯录管理（增删改查 + 保存到文件）
3. 单词本（背词 + 听写 + 打卡记录）
4. CSV 成绩统计（读文件 → 算平均/排名 → 写报告）

**里程碑**

| 时间 | 任务 |
| --- | --- |
| W2 周六 | 选型；设计数据结构；写出主循环骨架 |
| W2 周日 | 完成 1 个核心功能（如重命名/录入） |
| W3 周三 | 完成全部功能 |
| W3 周五 | 错误处理：空输入、文件不存在、非法参数 |
| W3 周六 | README + 提交 GitHub + 截图 |

**技术点**：argparse 或 input 菜单、文件读写、异常处理、函数拆分、模块组织。

**验收**：150–250 行；处理错误输入不崩；README 有安装与使用说明；Git 有提交历史。

**简历写法**：「Python 文件管理 CLI：支持批量重命名与配置，含错误处理与使用文档」。

### 一 · 学什么（竞赛工程 + C 层地基）

**竞赛工程（第 0 层，7 点）**：C++ 提交模板、快读与输出解绑、`long long` 与溢出、数组与递归深度、复杂度估时（1s ≈ 1e8 次）、对拍脚本、部分分分档设计。
**C 层地基（大纲编号 1–11，A 组同样考）**：

| # | 知识点 | 大纲难度 | 一句话机制 / 边界 |
| --- | --- | --- | --- |
| 1 | 枚举 | 1–3 | 定范围 + 剪枝；1e8 以内可枚举，1e9 必须换思路 |
| 2 | 模拟 | 1–3 | 按题意推状态，坑在边界与下标 |
| 3 | 排序基础 | 2 | `sort` + `cmp` 必须严格弱序，相等返回 `false`，否则 RE |
