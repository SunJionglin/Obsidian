# 01 数学一

> 150 分：高数约 82（56%）、线代 34（22%）、概率 34（22%）。
> 特点：**选择题 50（10 题 × 5）+ 填空题 30（6 题 × 5）+ 解答题 70（6 题）**。目标 130 = 客观题最多丢 10 分，大题丢 ≤10。

## 一、目标拆解

| 部分 | 分值 | 目标 | 意思 |
| --- | --- | --- | --- |
| 高数 | 82 | 70 | 压轴题（级数/中值定理/曲线积分）可以丢一半 |
| 线代 | 34 | 30 | 这科最好拿分，丢不起 |
| 概率 | 34 | 30 | 题型固定，必须稳 |
| 客观题 | 80 | 70+ | 会做的必须全对 |

**一句话**：高数决定上限，线代概率决定下限。130 分 = 客观题只错 2 道 + 大题做对 5 道。

## 二、五档标准

| 档 | 判断标准 | 自检 |
| --- | --- | --- |
| ① 认识 | 能说出定义、定理条件与结论 | 合书口述，不看公式表 |
| ② 基础题 | 练习册基础题正确率 ≥ 80% | 20 道限时 40 分钟 |
| ③ 综合 | 跨章综合题能下手，知道选哪种方法 | 真题里的中档解答题 |
| ④ 真题 | 一套真题 130±5 | 3 小时计时 |
| ⑤ 稳定 | 两套连做都在 128 以上 | 全真模拟 |

## 三、高数（82）

| 章节 | 到什么程度 | 常见失分点 |
| --- | --- | --- |
| 极限与连续 | 七种未定式、等价无穷小、夹逼、单调有界 | 等价无穷小替换的适用条件 |
| 一元微分 | 求导、隐函数、参数方程、中值定理证明 | 构造辅助函数 |
| 一元积分 | 不定积分技巧、定积分性质、反常积分敛散 | 分段函数积分 |
| 多元微分 | 偏导、全微分、极值、条件极值（拉格朗日） | 隐函数求二阶偏导 |
| 重积分 | 二重三重积分的坐标系与积分次序 | 极坐标/柱坐标的定限 |
| 曲线曲面积分 | 格林、高斯、斯托克斯，第一二类互化 | 方向与正负号 |
| 级数 | 常数项级数敛散、幂级数收敛域、傅里叶 | 比值法失效时的判断 |
| 微分方程 | 一阶（可分离/线性）、二阶常系数、欧拉方程 | 特解设法 |

**高数到 ④ 的核心**：不是会做难题，是**基础题不丢分**。中值定理和级数压轴可以放，其余必须稳。

## 四、线代（34）

| 章节 | 到什么程度 |
| --- | --- |
| 行列式 | 性质与计算、按行展开、特殊行列式 |
| 矩阵 | 运算、逆、秩、分块、初等变换 |
| 向量组 | 线性相关、极大无关组、秩的关系 |
| 线性方程组 | 解的结构、通解、含参数讨论 |
| 特征值 | 特征值与特征向量、相似对角化、实对称矩阵 |
| 二次型 | 标准形、正定性、合同变换 |

**线代的特点**：整本书是一张网（秩贯穿始终）。学到 ④ 的标志是：**能画出一张「秩 ↔ 方程组 ↔ 向量组 ↔ 特征值」的关系图**。

## 五、概率（34）

| 章节 | 到什么程度 |
| --- | --- |
| 随机事件 | 概率公式、条件概率、全概率与贝叶斯 |
| 一维随机变量 | 分布函数、密度、常见分布、函数分布 |
| 多维随机变量 | 联合/边缘/条件分布、独立性、两个随机变量函数分布 |
| 数字特征 | 期望、方差、协方差、相关系数 |
| 大数定律与中心极限定理 | 条件与结论、近似计算 |
| 数理统计 | 三大分布、矩估计、最大似然、区间估计 、假设检验 |

**概率到 ③ 就够了**：题型很固定，把卷积公式、二维函数分布、最大似然三类练熟即可。

## 六、推进顺序（只排先后）

```
第一步  高数（占分一半，最花时间，先修完一轮）
第二步  线代（成网，一轮修完立刻做题串联）
第三步  概率（题型固定，放最后效率最高）
第四步  三轮：强化题 → 真题（按年份）→ 真题（按套卷限时）
```

每章的推进都是：① 认识 → ② 基础题 → ③ 综合题。**没过 ② 不要进下一章**，数学的债到最后还不起。

## 七、笔记与复习怎么配合

- 公式不要抄大段，**每个公式配一道自己错的题**，错在哪就写在公式旁边。
- 用 D+1/2/4/7/15/30 的复习卡机制（和 While Back 复习卡同一套，见 [[Day 1]] 的结构），复习内容只有两样：**公式默写 + 错题重做**。
- 每章结束时做一张「方法索引」：看到什么题型用哪种方法（例如「求极限先看是否 0/0，再试等价无穷小」）。

## 八、自测标准

| 检查点 | 达标线 |
| --- | --- |
| 一章学完 | 基础题 20 道，40 分钟内对 16 道以上 |
| 一轮结束 | 综合题正确率 60% 以上 |
| 真题第一遍 | 100 分以上 |
| 真题第二遍 | 125 分以上 |
| 考前模拟 | 连续两套 128 以上 |
