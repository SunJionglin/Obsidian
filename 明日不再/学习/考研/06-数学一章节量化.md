# 数学一 · 章节量化表

> 每章四件事：**考什么内容、真题怎么出题、重点到几颗星、学到什么程度（可量化）**。
> 档位定义见 [[00-考研总纲]]：① 认识 ② 基础题 ③ 综合 ④ 真题 ⑤ 稳定。
> 重点星级：★★★ 必考且分值高 / ★★ 常考 / ★ 低频但可能出。

## 一、整卷题型结构（先知道分数从哪来）

| 题型 | 题量 | 每题分 | 合计 | 特点 |
| --- | --- | --- | --- | --- |
| 选择题 | 10 | 5 | 50 | 计算量小、概念题多 |
| 填空题 | 6 | 5 | 30 | 一步算错就 0 分，最考验基本功 |
| 解答题 | 6 | 10–12 | 70 | 前 4 题常规，后 2 题压轴 |

分值分布：高数约 82、线代 34、概率 34。**客观题 80 分决定你能不能上 120**。

## 二、高等数学（约 82 分）

### 第 1 章 函数、极限与连续

| 项 | 内容 |
| --- | --- |
| 核心内容 | 函数性质（奇偶/周期/有界）、数列与函数极限、无穷小比较、连续性、间断点分类、闭区间连续性质（零点/介值/最值） |
| 真题题型 | 选择/填空必有一题：求极限（0/0、∞/∞、1^∞）；判断间断点类型；无穷小阶的比较；用介值定理证明根的存在 |
| 重点 | ★★★（每年必考，且是后面一切的基础） |
| 目标档位 | ② 必须满，极限计算到 ③ |
| 量化标准 | ① 等价无穷小替换表默写 12 组；② 20 道极限题限时 40 分钟，对 ≥18；③ 1^∞ 型必须用 `e^{lim f(x)g(x)}` 一类方法，不能靠洛必达硬算；④ 间断点分类判断 10 题全对 |
| 易错 | 等价无穷小只能用于乘除，加减要谨慎；洛必达用前必须先验证 0/0 或 ∞/∞ |

### 第 2 章 一元函数微分学

| 项 | 内容 |
| --- | --- |
| 核心内容 | 导数定义、求导法则（复合/隐函数/参数方程/反函数）、高阶导数、微分中值定理（罗尔/拉格朗日/柯西/泰勒）、单调性与极值、凹凸与拐点、渐近线、曲率 |
| 真题题型 | 选择/填空：求导、切线方程、拐点个数；解答题常出**中值定理证明**（构造辅助函数）或**不等式证明** |
| 重点 | ★★★（中值定理是压轴常客） |
| 目标档位 | ② 全章；中值定理证明到 ③ |
| 量化标准 | ① 求导 30 题限时 40 分钟，对 ≥27；② 罗尔/拉格朗日/柯西三个定理的条件与结论能默写；③ 中值定理证明题：题库 15 道，能独立写出 ≥9 道；④ 渐近线求法（三类）10 题全对 |
| 易错 | 构造辅助函数是难点，要按「要证的式子反推」；分段点处可导性要用定义验证 |

### 第 3 章 一元函数积分学

| 项 | 内容 |
| --- | --- |
| 核心内容 | 不定积分（换元/分部/有理函数）、定积分性质与计算、变上限积分、反常积分敛散、定积分应用（面积/体积/弧长/物理） |
| 真题题型 | 选择/填空：反常积分敛散、变上限求导；解答题：定积分计算、几何应用、不等式估计 |
| 重点 | ★★★ |
| 目标档位 | ② 全章，应用类到 ③ |
| 量化标准 | ① 不定积分 30 题 45 分钟对 ≥24；② 分部积分与换元能说清「什么时候用哪个」；③ 变上限积分求导 10 题全对；④ 反常积分敛散判断 12 题对 ≥10；⑤ 旋转体体积/弧长公式默写 |
| 易错 | 换元忘了换上下限；反常积分要拆成「瑕点 + 极限」写 |

### 第 4 章 向量代数与空间解析几何

| 项 | 内容 |
| --- | --- |
| 核心内容 | 向量运算（点积/叉积/混合积）、平面与直线方程、距离与夹角、曲面与空间曲线、旋转曲面 |
| 真题题型 | 选择/填空为主：求平面/直线方程、判断位置关系；偶与线代/重积分结合 |
| 重点 | ★（低频，但计算题常作为大题第一小问） |
| 目标档位 | ② |
| 量化标准 | ① 点积叉积几何意义能说清；② 给三点求平面方程 10 题对 ≥8；③ 点到平面/直线的距离公式默写 |
| 易错 | 叉积方向与右手系；平面法向量取错导致整题错 |

### 第 5 章 多元函数微分学

| 项 | 内容 |
| --- | --- |
| 核心内容 | 偏导数、全微分、复合函数求导（链式法则）、隐函数求导、方向导数与梯度、极值与条件极值（拉格朗日乘数法）、几何应用（切平面/法线） |
| 真题题型 | 选择/填空：偏导与全微分、梯度；解答题：条件极值（最值应用）、隐函数求二阶偏导 |
| 重点 | ★★★（条件极值几乎年年考） |
| 目标档位 | ② 全章，条件极值到 ③ |
| 量化标准 | ① 二阶偏导与混合偏导计算 15 题对 ≥13；② 拉格朗日乘数法解条件极值 12 题，独立完成 ≥9；③ 隐函数求导（一阶/二阶）8 题对 ≥7 |
| 易错 | 高阶混合偏导的可交换条件；条件极值要检验边界 |

### 第 6 章 多元函数积分学（重积分 + 曲线曲面积分）

| 项 | 内容 |
| --- | --- |
| 核心内容 | 二重积分（直角/极坐标、交换次序）、三重积分（柱/球坐标）、第一类曲线/曲面积分、第二类曲线/曲面积分、格林公式、高斯公式、斯托克斯公式 |
| 真题题型 | 选择/填空：积分值与坐标系选择；**解答题几乎必出一题**：格林公式或高斯公式计算，注意方向与补面 |
| 重点 | ★★★（分值大、难度高，是最容易拉开差距的一章） |
| 目标档位 | ② 全章；三大公式到 ③ |
| 量化标准 | ① 二重积分 20 题（含交换次序）对 ≥16；② 三重积分球坐标定限 10 题对 ≥8；③ 格林/高斯/斯托克斯公式的适用条件与符号规则能默写；④ 第二类曲线积分「补线/补面」题 15 道独立完成 ≥10 |
| 易错 | 格林公式要求闭曲线且正向；高斯公式要求闭曲面且外侧，不闭要补面；方向反了整题负号错 |

### 第 7 章 无穷级数

| 项 | 内容 |
| --- | --- |
| 核心内容 | 常数项级数敛散判别（比较/比值/根值/积分/莱布尼茨）、绝对与条件收敛、幂级数收敛半径与收敛域、函数展开（泰勒/间接法）、傅里叶级数 |
| 真题题型 | 选择/填空：判敛散、收敛半径；解答题：幂级数求和函数，或证明级数收敛 |
| 重点 | ★★★（解答题高频，且常是压轴） |
| 目标档位 | ②；求和函数到 ③ |
| 量化标准 | ① 判敛散 20 题对 ≥16；② 收敛半径与端点讨论 12 题全对（端点必须单独判）；③ 幂级数求和函数 10 题独立完成 ≥6（这是压轴难度，允许放一半） |
| 易错 | 比值法极限为 1 时失效，要换比较法；端点敛散必须单独讨论，不能直接写区间 |

### 第 8 章 常微分方程

| 项 | 内容 |
| --- | --- |
| 核心内容 | 一阶方程（可分离/齐次/一阶线性/伯努利）、可降阶高阶方程、二阶常系数线性方程（齐次与非齐次）、欧拉方程、微分方程应用 |
| 真题题型 | 选择/填空：方程类型识别与通解；解答题：应用题（几何/物理建模）或含参讨论 |
| 重点 | ★★（题型固定，容易拿分） |
| 目标档位 | ② 全章（这章必须满，是送分题） |
| 量化标准 | ① 一阶线性方程通解公式默写；② 二阶常系数三类右端（多项式/指数/三角）特解设法 15 题全对；③ 应用题 10 道独立完成 ≥8 |
| 易错 | 特解形式设错（共振情形要乘 x）；通解常数 C 的位置 |

## 五、全书推进的量化门槛

| 阶段 | 门槛 | 没到的处理 |
| --- | --- | --- |
| 一章学完 | 该章基础题 20 道，40 分钟内对 ≥16 | 不进下一章，重刷基础题 |
| 一轮结束 | 全书综合题正确率 ≥60% | 找出错得最多的两章重做 |
| 真题第一遍 | ≥100 分 | 按错题章节回炉 |
| 真题第二遍 | ≥125 分 | 只补错题 |
| 考前 | 连续两套 ≥128 | 保持不松 |

## 六、时间分配原则（不排日期，只排比例）

- 高数 : 线代 : 概率 ≈ **5 : 2.5 : 2.5**（按分值，但线代概率要保证不丢分）
- 每章内部：**基础题 60% 时间、综合题 30%、错题回顾 10%**
- 数学每天必须有，断一天要补回来——数学是唯一「断了就退步」的科目。
