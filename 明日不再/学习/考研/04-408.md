# 04 408 · 计算机学科专业基础

> 150 分，四门合卷：数据结构 45 + 组成原理 45 + 操作系统 35 + 计算机网络 30。
> 特点：**选择题 80 分（40 题 × 2 分）占地基，综合应用题 70 分（7 题）拉开差距**。目标 125 = 选择错 ≤6 题（丢 12），大题丢 ≤13。

## 一、四门课的分值与目标

| 科目 | 分值 | 题型分布 | 目标 | 难点 |
| --- | --- | --- | --- | --- |
| 数据结构 | 45 | 选择 11 题 + 算法大题 1（15 分） | 38 | 算法题要写代码/伪码；B 树、图手算 |
| 组成原理 | 45 | 选择 11 题 + 综合 2 题 | 37 | 最难，流水线、Cache、数据通路 |
| 操作系统 | 35 | 选择 10 题 + 综合 2 题 | 30 | PV 操作、页表地址转换 |
| 计算机网络 | 30 | 选择 8 题 + 综合 1 题 | 20 | 计算多，但套公式就行 |

## 二、五档标准（四门通用）

| 档 | 数据结构 | 组成原理 | 操作系统 | 网络 |
| --- | --- | --- | --- | --- |
| ① 认识 | 说清每种结构的特点 | 说清各部件作用 | 说清进程/内存/文件是什么 | 说清每层干什么 |
| ② 基础题 | 课后选择 80% 对 | 课后选择 80% 对 | 课后选择 80% 对 | 课后选择 80% 对 |
| ③ 综合 | 能手算 B 树/图/排序 | 能手算 Cache/流水线 | 能写 PV、算页表 | 能算子网/窗口/CRC |
| ④ 真题 | 真题数据结构部分 ≥ 34 | 组原部分 ≥ 34 | OS 部分 ≥ 28 | 网络部分 ≥ 18 |
| ⑤ 稳定 | 整套真题 125+，连做两套稳定 | | | |

## 三、数据结构（45）

| 模块 | 到什么程度 | 你现在的底子 |
| --- | --- | --- |
| 线性表 | 顺序表/链表的插入删除复杂度会算 | ✅ 力扣题感够，缺手算复杂度表 |
| 栈队列 | 会判断出栈序列、表达式求值 | ✅ 基本够 |
| 树 | 二叉树遍历、线索树、哈夫曼、并查集 | ⚠️ 要到「能手画」程度 |
| 图 | 邻接矩阵/表、DFS/BFS、最小生成树、最短路、拓扑 | ⚠️ 手算 Prim/Kruskal/Dijkstra 表 |
| 查找 | 折半查找判定树、B 树插入删除、哈希冲突 | ❌ 最缺，力扣不考 B 树 |
| 排序 | 各排序的过程、复杂度、稳定性比较表 | ⚠️ 要能手画每趟结果 |
| 算法题 | 15 分大题：写算法 + 说明复杂度 | ✅ 你的刷题量足够，注意写伪码规范 |

**加码点**：B 树/B+ 树、图的手算、各排序每趟变化——这三块力扣练不到，必须单独练。

## 四、组成原理（45）最难，也最容易丢分

| 模块 | 到什么程度 | 现有资源 |
| --- | --- | --- |
| 数据表示 | 补码、浮点 IEEE754、大小端 | ✅ [[底层原理线-36周]] W1 有基础 |
| 运算器 | 加减乘除运算、溢出判断 | ❌ 要新学 |
| 存储系统 | Cache 映射（直接/全相联/组相联）与命中率计算 | ⚠️ CSAPP 6 章有，要按 408 口径练 |
| 指令系统 | 寻址方式、指令格式、CISC/RISC | ❌ 要新学 |
| CPU | 数据通路、控制器、流水线（加速比、冲突） | ❌ 最难，必须画图 |
| 总线与 IO | 中断、DMA、IO 方式 | ⚠️ [[06-计算机组成原理]] 只到「知道」 |

**加码点**：这是你现有笔记里最薄的一门（只到 ② 档）。408 里它和数据结构同分，必须提到 ④。

## 五、操作系统（35）

| 模块 | 到什么程度 |
| --- | --- |
| 进程与线程 | 状态转换图、调度算法（FCFS/SJF/RR）算周转时间 |
| 同步互斥 | PV 操作写生产者消费者/读者写者/哲学家 |
| 死锁 | 四个必要条件、银行家算法算安全序列 |
| 内存管理 | 分页/分段、地址转换、页面置换（FIFO/LRU/OPT）算缺页率 |
| 文件系统 | 索引结构、空闲空间管理、磁盘调度（FCFS/SSTF/SCAN） |
| IO 管理 | 缓冲区、SPOOLing |

**加码点**：PV 操作和地址转换是必考大题，你现在只有面试级的理解，要练到能写能算。

## 六、计算机网络（30）

| 模块 | 到什么程度 |
| --- | --- |
| 体系结构 | 分层、各层协议与设备归属 |
| 物理层 | 奈氏/香农、编码（曼彻斯特） |
| 链路层 | CRC 手算、海明码、滑动窗口（GBN/SR 窗口大小）、CSMA/CD 最小帧长 |
| 网络层 | 子网划分、CIDR 聚合、路由协议对比、IP 分片 |
| 传输层 | 三次握手四次挥手、拥塞控制（cwnd 变化图）、TCP 序号确认号计算 |
| 应用层 | DNS 解析过程、HTTP 报文、FTP 双连接 |

**你已经有的**：[[00-王道计算机网络总纲]] 九篇 + 12 张图，内容覆盖度够，**缺的是真题级计算速度和错题**。

## 七、四门的推进顺序（只排先后）

```
第一步  数据结构 + 组成原理（分最高，也最花时间）
第二步  操作系统（PV 与地址转换单独练）
第三步  计算机网络（你的基础最好，放后面快速过）
第四步  四门合卷真题（限时，练跨科切换）
```

每门都是「① 认识 → ② 基础题 → ③ 综合 → ④ 真题」逐档推，一档不过不进下一档。

## 八、真题与错题

- 408 真题从 2009 年开始，**至少刷两遍**：第一遍按章节，第二遍按套卷限时。
- 错题本按「知识点 + 错因」记，不抄题：例如「Cache 组相联——忘了先算组数」。
- 选择题错 6 题以上，说明某一门还在 ③ 档，回去补那门，不要继续刷套卷。
