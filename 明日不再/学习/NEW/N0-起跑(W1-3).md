## 三 · 知识点清单（按周）

### W1 · 环境与语法①

**环境与工具**
- `uv python install` / `uv init` / `uv run`；VS Code 选 `.venv` 解释器、断点单步
- Git：`init` / `add` / `commit` / `push` / `log --oneline` / `status`
- Linux：`ls -la`、`cd`、`pwd`、`mkdir -p`、`cp`、`mv`、`rm -r`、`cat/head/tail`、`wc -l`、`ls > list.txt`
- 权限：`ls -l` 的 9 位、`chmod 755/644`、`chown`
- 进程与网络：`ps`、`top`、`kill`、`ss -lntp`、`curl`、`ssh`、`scp`

**语言**
- 五种基础类型与转换；`type()` / `isinstance()`；`is` vs `==`
- 字符串：下标、切片、不可变、`strip/split/join/replace/find`
- 容器：list 增删查与切片、dict 遍历与 `get`、set 去重、tuple 解包
- 控制流：`if/elif/else`、`for/while`、`break/continue`、`for-else`、`enumerate`、`range` 步长
- 函数：位置/关键字/默认参数、返回值、作用域、嵌套调用
- 真值：`False/None/0/""/[]/{}` 为假；`and/or` 返回操作数；短路
- `input()` 永远返回 str；`print(sep/end)`

**蓝桥（C 层）**
- 竞赛 IO：单文件模板、`#include <bits/stdc++.h>`、快读、`long long` 与溢出、数组大小与递归深度
- 复杂度估时：1s ≈ 1e8 次
- 排序：`sort` + `cmp` 严格弱序
- 二分：四种边界（左闭右闭 / 左闭右开 / 存在性 / 二分答案）

### W2 · 字符串、文件与类

**文件与文本**
- `open(path, mode, encoding)`；`r/w/a/x` 语义；`with` 与上下文管理器
- 三种读法：`read()` / `readline(s)` / `for line in f`；`rstrip("\n")` vs `strip()`
- 写：`write` / `print(file=)` / `writelines`；`flush` / `close`
- `pathlib`：`Path` 拼路径、`exists/suffix/stem/parent`、`glob/rglob`、`read_text/write_text`、`mkdir(parents, exist_ok)`
- 编码：UTF-8 必写；`UnicodeDecodeError`；`utf-8-sig`（BOM）
- 命令行 ↔ pathlib：`find` ↔ `rglob`、`grep` ↔ 逐行读

**语言**
- 字符串解析：`split(None)` vs `split(" ")`、`maxsplit`、`partition`、`rsplit`、`re.split`
- 拼接：`join` 的硬要求、`+=` 的 O(n²)、`translate`、`is*` 系列
- 正则边界：`match/search/fullmatch`、`findall/sub`、贪婪与非贪婪、预编译
- 异常：`try/except/else/finally` 时序、只捕预期异常、`raise ... from e`
- 类入门：`class`/`__init__`/`self`、实例 vs 类属性（可变类属性的坑）、`__repr__`
- 模块与包：`import` 缓存、`__init__.py`、相对导入、`if __name__ == "__main__"`
- Git：`switch -c`、`merge`、`restore`、`reset --soft/--mixed/--hard`、`.gitignore`

**蓝桥**
- 二分答案：`check` 单调性、`(l+r+1)>>1` 配 `l=mid`
- 前缀和：`s[i]=s[i-1]+a[i]`，区间和 O(1)
- 差分：`d[l]+=v; d[r+1]-=v`，末尾前缀和还原；数组开 n+2

### W3 · 链表、栈队列与二分

**语言与结构**
- 链表：节点类、虚拟头节点、增删改查、反转（迭代/递归）
- 栈：list 模拟、括号匹配、最小栈
- 队列：`collections.deque`、双端操作、用栈实现队列
- 二分：左闭右开模板、边界收缩、`lower_bound` 手写

**复杂度**
- O(1)/O(n)/O(n²)/O(log n) 各举一例；`list` 的 `in` 是 O(n)、`set` 是 O(1)
- 空间：原地 vs 额外数组；递归栈深度

**蓝桥**
- 贪心：排序 + 交换论证；哈夫曼（合并果子）
- 堆：`priority_queue` 小根、`heapq`；对顶堆
- 单调栈：找下一个更大元素，每个下标进出一次
- 单调队列：滑窗最值，弹队尾 + 弹过期队头

**要求**
- 命令行参数（位置参数 + `--dry-run`）；文件读写；异常处理（目录不存在/重名/权限）
- 至少 5 个函数，主函数只做编排；README 写清「怎么装、怎么跑、例子」

## 九 · 常见坑

1. **只看视频不动手**：看完 10 分钟必须敲一遍，否则等于没看。
2. **追求一次写对**：先写出来再重构，卡 20 分钟就看题解，次日默写。
3. **只学语法不做题**：题是唯一能验证「会不会」的尺子。
4. **`"w"` 模式清空文件**：改数据前先 `exists()` + 备份，或先 `r` 读。
5. **不写 `encoding="utf-8"`**：换机器就乱码；Windows 上必踩。
6. **`cmp` 不严格弱序**：相等返回 `true` → RE。
7. **二分 `(l+r)/2` 配 `l=mid`**：死循环；求最大必须上取整。
8. **递归 1e5 层**：爆栈；CSES 题要有意识。
9. **蓝桥直接写正解**：按测试点给分，先交暴力档再优化。
