# NEW · 00 总览与路线图

> 这套东西是**按时间与进度切的整合视图**：每个阶段里三条线（蓝桥 / 408 / 主线项目与面试）同时推进，互相喂食，不是三个孤立的节点。
> 旧的 `EWP/`（P0–P6）、`EW/`（周计划与每日卡）仍然是**素材与明细**；`NEW/` 是**读法**——先看这里知道「这一段在干什么」，再跳进旧目录拿细节。
> 三句总纲：**先拿省一/国奖 → 再用项目换实习 → 最后用 16 个月换 400 分。**

---

## 一 · 为什么按阶段切，不按目标切

三个目标不是排队，是**接力**：

```
蓝桥（算法 + 限时） ──算法手感──▶ Ⅰ/Ⅱ/Ⅲ 面与笔试
       │
       └──数据结构 70%──▶ 408 第一轮 ──▶ 考研 408
主线项目 A/B/C ──简历──▶ 暑期实习 ──▶ 面试八股 / 工程能力
408 第一轮（192h）──省下时间──▶ ③ 期让给数学
```

所以每一段都要写清：**这一段三条线各做什么、这一段结束时交出什么、下一段靠它什么**。

## 五 · 怎么用这套 NEW

1. **换段时**：打开下一段的文件，看「这一阶段要什么」和「逐周表」，把周的骨架先立起来。
2. **每周日**：周计划（自动生成）仍然落在 `EW/W{N}`；`NEW` 只提供该周的**该做什么、做到什么程度**。
3. **每段末**：在本段文件里填「本段复盘」，并把「留给下一段的东西」勾掉。
4. **进度对不上时**：改 `NEW` 的段文件，不要改 `EWP` 的题单——`EWP` 是素材，`NEW` 是判断。
5. **命名**：`N0-…` 到 `N8-…`；每段一个文件，不拆碎。
