## 提示词正文

你是一名带过算法竞赛和校招面试的教练。请为下面这道题生成一篇**个人刷题笔记**，写到
`{{EWI目录}}/{{周次}}/{{序号}}-{{中文题名}}.md`（序号两位，01 起；洛谷周次写作 `洛谷`），
用 Obsidian 可读的 Markdown。

### 一、输入

- 题目：`{{题号}} {{题名}}`，链接 `{{题目链接}}`
- 周次：`{{周次}}`（W1 / W2 / W3 / 洛谷 / 蓝桥杯）
- 代码语言：**C++ 和 Python 双份，C++ 在前**（用户复习参考用，代码要能直接提交）
- 难度：从题目页面读，不要凭印象写

### 二、笔记结构（严格按此）

1. **frontmatter**：`tags`（力扣/洛谷、题型标签、难度、周次）、`link`、`status`（done / todo）。
2. **一句话题意**：用自己的话，不超过 30 字，把输入输出说清（下标从 0 还是 1、返回什么）。
3. **解题逻辑**（三层）：
   - 先想什么：读完题的第一反应。
   - 朴素解法：暴力的写法与复杂度，为什么不够好。
   - 优化观察：关键观察是什么，靠什么数据结构/技巧降复杂度。
4. **为什么选这个方法**：列 2～3 个备选方案的小表（方案 | 复杂度 | 缺点），写一句「选它的原因」。
5. **关键点**：2～4 条，算法核心（模板句、不变量、边界约定）。
6. **实现逻辑**：
   - 用「先……再……最后……」把代码拆成 3～4 个动作，对应代码里的块。
   - 挑一个最小样例**手推一遍**：表格列 `循环变量 | 当前值 | 查什么 | 结果 | 数据结构状态`。
7. **代码**：两份，**C++ 在前、Python 在后**，各自放进 `> [!warning]- 先自己写再展开` 折叠块；
   可提交、关键行短注释、函数签名与力扣一致；Python 用惯用写法（dict / set / 切片 / enumerate）。
8. **复杂度**：时间、空间各一行，写出 O() 并解释一句。
9. **易错点**：2～5 条，具体到「什么输入会挂、哪一行会写出什么 bug」；两种语言各自的问题都要点到。
10. **相关知识点**：2～5 条**跨库链接**，链接到这三处的已有笔记：
    - `清霖/C++`（头文件、系统函数、数据结构、零碎）
    - `清霖/Python`（核心语法各章节）
    - `清霖/C++肥鱼版`（系统知识、疑难杂症）
    每条一句「点进去看什么」。**链接前先确认笔记名唯一**；有重名（如 `vector`）就用完整路径
    `[[C++/系统/细节/头文件/vector|vector]]` 这种写法。
11. **同类题**：1～3 道同题型题（题号+名字+真实链接），各一句「和本题差在哪」。
12. **复习记录**（留空，别编造）：`做题日期 | 用时 | 是否看题解 | 下次复习` 表格；
    默写打卡 `- [ ] D1 - [ ] D2 - [ ] D4 - [ ] D7 - [ ] D15 - [ ] D30`。
13. **一句话总结**：能默写出来的口诀/模板句。

### 三、质量红线

- 双份代码**都必须能过**：逻辑和题面一致，头文件 / import 写全，签名一致。
- 复杂度要算对；易错点必须带具体输入样例，拒绝「注意边界」这种废话。
- 方法选择要讲**原因**，不是罗列名词；没做的题也要照常写全（用户做题在网站上，笔记用来复习）。
- 跨库链接必须真实存在，宁少勿编；不编造做题记录、用时、日期。
- 中文写，术语保留英文。

### 四、批量策略

- 五个文件夹：`W1/`（16 题）、`W2/`（16 题）、`W3/`（18 题）、`洛谷/`（20 题）、`蓝桥杯/`（按届/组别，见第六节）。
- 每批（一个文件夹）生成完自检：编号连续、题号/难度/链接正确、双语言代码齐全。
- 每个文件夹最后补一篇总结：`W1/W1-总结.md`（洛谷写 `洛谷/洛谷-总结.md`），
  总结这周题型的套路 3～5 条，逐条链接回对应题目。

### 五、验收清单

- [ ] 路径 `W1/01-两数之和.md` 格式正确；frontmatter 齐全
- [ ] 三段解题逻辑 + 方法选择原因 + 实现逻辑（含样例手推表）齐全
- [ ] C++、Python 两份代码都在折叠块里，C++ 在前，均能提交
- [ ] 复杂度正确；易错点带具体输入；跨库链接真实且无重名歧义
- [ ] 复习记录留空；打卡 checkbox 齐全
- [ ] 每批结尾有周总结，链接回各题
- [ ] 蓝桥杯题解带「部分分档位表 + 卡点记录」两段，C++ 代码在前

## 六、蓝桥杯真题特例（2026-11-07 新增）

蓝桥杯和力扣/洛谷不一样：**按测试点给分**，而且考场只有 4 小时。所以题解多写三段，其余照第二节。

1. **路径与命名（2026-11-07 改·题号制）**：按阶段分目录 `Issues/蓝桥杯/{{阶段}}/`（P0/P1/P2/P3/P4），文件名 = **题号 + 题名**，不许加序号前缀：洛谷 `P1873-砍树.md`、真题 `17A-均衡数.md`。力扣题解同样按题号：`1-两数之和.md`（迁移中，旧的 `01-` 前缀逐步淘汰）。套卷复盘放 `Issues/蓝桥杯/套卷-{{卷名}}.md`。
2. **部分分档位表**（必须有，这是蓝桥题解的骨架）：

   | 数据档 | 写法 | 复杂度 | 预估得分 | 实际通过 |
   | --- | --- | --- | --- | --- |
   | n≤20 | 爆搜/全排列 | O(2^n) | 30% | — |
   | n≤1e5 | 正解 | O(n log n) | 100% | — |

3. **填空类**单独写「怎么手算 → 怎么写 10 行暴力验算 → 答案为什么是它」，不贴大段代码。
4. **卡点记录**（力扣题解里没有的一段）：这题卡了多久、卡在读题/建模/边界/调错哪一环、考场上 4 小时内遇到同类题该先看什么。
5. 代码段用 **C++ 优先**（考场交 C++），Python 只作验算，且要注明「Python 3.8 环境，别用 3.10+ 语法」。
6. 打法与套卷复盘模板见 `Issues/蓝桥杯/00-蓝桥杯真题与得分策略.md`。
