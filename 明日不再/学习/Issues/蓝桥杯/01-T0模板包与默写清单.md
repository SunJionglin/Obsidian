# T0 模板包 · 18 个必须能默写的竞赛模板

> 用法：**每天 20–30 分钟默写 1–2 个**，循环到能闭卷敲出来为止（W1 起贯穿到 W32）。

```cpp
// 2 · 找左边界（第一个 >= x 的位置）
int l = 0, r = n;
while (l < r) { int mid = l + (r - l) / 2; if (a[mid] < x) l = mid + 1; else r = mid; }
// l == n 表示不存在
```

```cpp
// 3 · 二分答案（求最大值）
int l = 0, r = INF;
while (l < r) { int mid = (l + r + 1) >> 1; if (check(mid)) l = mid; else r = mid - 1; }
```

```cpp
// 5 · 差分：区间 [l,r] 加 v
d[l] += v; d[r + 1] -= v;

```

```cpp
// 8 · 并查集
int fa[N];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
void merge(int x, int y) { fa[find(x)] = find(y); }
```

```cpp
// 10 · 树状数组
long long c[N];
void add(int i, int v) { for (; i <= n; i += i & -i) c[i] += v; }
long long sum(int i) { long long s = 0; for (; i; i -= i & -i) s += c[i]; return s; }
```

```cpp
// 13 · KMP 前缀函数（0-based）
int pi[N];
for (int i = 1; i < m; i++) {
    int j = pi[i - 1];
    while (j && p[i] != p[j]) j = pi[j - 1];
    if (p[i] == p[j]) j++;
    pi[i] = j;
}
// 匹配：失配时 j = pi[j-1]
```

```cpp
// 15 · Dijkstra（堆优化）
vector<pair<int, int>> g[N];
long long dis[N]; bool vis[N];
priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<>> pq;
dis[s] = 0; pq.push({0, s});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (vis[u]) continue;
    vis[u] = 1;
    for (auto [v, w] : g[u]) if (dis[v] > d + w) { dis[v] = d + w; pq.push({dis[v], v}); }
}
```

## 三、默写规矩

1. **闭卷 + 计时**：单模板目标 ≤3 分钟（线段树 ≤8 分钟）。超时就算没过。
2. **写完立刻拿模板题交一遍**：默写对了但边界错了，等于没会——用 [[蓝桥杯A组-国奖线]] 那张表里的洛谷题验证。
3. **错了写在「常见坑」那列**，别重抄一遍模板；下次只回看这一列。
4. **每周日抽查 3 个**（从「三默」还没打勾的里抽），抽不出来就降回「首默」重来。
5. **考前两周全量过一遍**（W21–W22、W31–W32），只过骨架不看细节。
