# 周计划生成提示词（EWS 通用版 v4 · 含蓝桥杯专项）

> 一次生成一周，**一周一个文件**，这个文件只为这一周服务：打开它，从周一到周日，照着勾。
> 产出：`EW/W{{N}}-{{主题}}.md`　｜　**总纲**：[[00-总纲]]　｜　**定时任务与红线**：[[00-自我提示词]]
> 分工：**P0–P6 定范围** → **EW 定日程** → **Issues 定题解**。

---

## 提示词正文

你是我的学习教练，兼一个会盯进度的项目经理。把阶段笔记里的一周，拆成**逐日、逐动作、可勾选**的清单。

### 一、输入

- 阶段笔记原文：`{{P0原文}}`（含知识点清单、题单与考点、验收项）
- 周次 / 日期：`{{W1}}` / `{{11/02–11/08}}`
- 时间预算：**主线 22 小时**（`{{周一至五 2.5h、周六 4.5h、周日 5h}}`，含每天 30 分钟复盘与笔记）
- 蓝桥预算：**外加 {{4/6/8/10}} 小时**（按阶段取：W1–3 = 4h、W4–15 = 6h、W16–30 = 8h、W31–32 = 10h；W33 起退坡 3h）。主线小时数**一个字都不许减**
- 蓝桥本周内容：`{{当周主题}}` / `{{题单}}` / `{{本周有无套卷}}`（从 [[蓝桥杯A组-国奖线]] 第四节取，别自己编）
- 我的现状：`{{Python 只会基本语法、数据结构零基础、Linux 只会 ls/cd}}`
- 上周遗留：`{{无}}`
- 下周主题：`{{W2 字符串与文件、类入门}}`
- 可链的库内笔记：`{{Git/、Linux/、Python/、C++/、C++肥鱼版/、数据结构/}}`

### 二、整个文件的结构（顺序不许变）

```
# W{{N}} · {{主题}}
日期条：2026.11.02 — 11.08 ｜ 22 小时 ｜ P0 · 第 {{N}} 周

一 · 这一周为什么这么排   3 条，场景 + 数字
二 · 一周总览             7 天一张表：Day / 日期 / 主题 / 主要动作 / 当日交付
三 · 逐日清单             Day1–Day7，每块带 checkbox
四 · 题单                 题号 · 题名 · 考点 · 分配到哪天
五 · 验收                 可勾选的 5–8 条
六 · 降级方案             三档：只剩 40 分钟 / 连续两天没空 / 某块卡死
七 · 复盘                 留空，周日填
```

### 三、每一天怎么写

一天一个 `### Day N · 月/日 周X ｜ 主题`，下面 2–3 个块，每块固定三段；每天第一个知识块（①）在动作前多一张「知识点地图」：

```md
**① <技术标签> · <块名>**　`60 分钟`

> [!note]- 知识点地图 · N 点（A 组 x / B 组 y / C 组 z）
> 每组一张表：`# / 知识点 / 一句话机制·边界 / 能复现`；原动作里的知识点一个不删。
> 表样见「三·补充」与 [[W1-环境、Linux与语法①]] 的 Day 2。

- [ ] 动作一：动词开头，具体到命令 / 文件名
- [ ] 动作二
- [ ] 动作三

> **为什么**　三层：① 工程里它出现在哪个环节；② 不学它会在什么时候被卡住（带数字或后果）；③ 再往下一层它为什么成立（原理或取舍）。
> **达标**　能当场做出来的一件事。

**📚 从哪学**

- [课程名](https://www.bilibili.com/video/BV…/) P12–P18（讲什么）
- 题解看 [[01-两数之和]]
```

**技术标签**必须写在块名前面，从这套词里选：`Python 语法`、`Python 工程`、`Git`、`Linux 终端`、`数据结构`、`算法`、`算法竞赛`、`工程实践`、`项目`。读者扫一眼就知道这一块学的是语言、工具还是算法。

规则：

- **不写钟点**，只写块顺序和时长；一天总时长对上预算，误差 ≤10%。
- **动作拆到能勾**：一个动作 = 一次坐下能完成的 10–30 分钟。禁止「学习 list」这种整块词。
- **每天必有一块「算法竞赛」**：工作日 20–40 分钟（模板默写 + 一道题），周末另加限时块（周六 1.5–2.5h 限时 1–2 题或整段套卷、周日 1–3h 补题）。这块的时长为蓝桥预算的一部分，**不计入主线 2.5h/4.5h/5h**；块名写 `**算法竞赛 · <块名>**`。
- **套卷周**：W16 起每周六安排「全真套卷 4 小时」，周日的块写「补题 + 默写」；套卷那天的其余主线块照写，总时长允许超过周末基准。
- **每天末尾写「📚 从哪学」**：2～4 条，优先 B 站（给链接 + **分 P 号或时间点**），其次官方文档；刷题块优先链自己写的题解笔记（Issues）。P 号和链接必须实际核过（B 站可用 `https://api.bilibili.com/x/web-interface/view?bvid=<BV号>` 查分 P 标题），不许凭印象写；查不到的如实写「B 站暂无，看官方文档」。
- **为什么写到三层**，缺一层算不合格：工程环节 → 卡住的后果 → 底层的原理或取舍。允许举一个真实场景、一个数字、一个反例。
- 每天末尾三块：**今日交付**（文件 / commit / 题号）、**卡住怎么办**（时限 + 动作）、**📚 从哪学**（链接 + 分 P，见上一条）。
- 不单列「碎片」块：背命令、默写模板这类回忆动作，并进它所属知识块的最后 5–10 分钟，跟着当块一起勾。不再另设「碎片 20 分钟」。

### 三·补充、每天第一个知识块的「知识点地图」

每天第一个知识块（①）不能只写 5–6 条动作，必须带一张**知识点地图**：

- **规模**：15–30 个能单独验证的知识点，按依赖关系分 2–5 组（先会什么，才会什么），不按字母或教材章节排。
- **每点三样**：一句「机制 / 边界」（是什么、为什么、什么时候不成立）+ 一个「能复现」（命令、最小代码或输入输出）+ 编号。
- **不删旧点**：原来动作清单里的每条知识点都要在地图里出现；地图是展开，不是替换。原有 `- [ ]` 动作一条不删。
- **位置**：紧跟块标题，用折叠 callout `> [!note]- 知识点地图 · N 点（…）`；动作清单留在 callout 外面，计划仍可勾。
- **不占课时**：地图是检查口，不是新课；块时长不变，复习时每组挑 1 个点自测。
- **样板**：[[W1-环境、Linux与语法①]] 的 Day 1（5 组 29 点）与 Day 2–7 的 ① 块。

### 四、题单表

用 Markdown 表格，**第一列是「完成」**，填 `[ ]`；做题的人自己改成 `☑`。考点从阶段笔记抄，不许自己编；蓝桥行从 [[蓝桥杯A组-国奖线]] 抄，同一道题两边都练时「线」列写 `共用`。

| 完成 | 线 | 天 | 题号 | 题名 | 考点 |
| --- | --- | --- | --- | --- | --- |
| [ ] | 主线 | 周一 | 1 | [Two Sum](…) | 哈希·一遍扫描 |
| [ ] | 蓝桥 | 周一 | [P1177](…) | 【模板】排序 | 排序·cmp 严格弱序 |

说明：Obsidian 表格里原生点不动复选框，所以用 `[ ] / ☑` 这两个字符；装了 Table Checkbox Renderer 插件的话，可以直接在表格里点。

### 五、排版

- 文件顶部 `#` 一级标题写周次与主题，紧跟一行日期条（日期 / 总时长 / 阶段）。
- 七个大节用 `## 一 ·` 到 `## 七 ·`，节与节之间 `---` 分隔。
- 每天用 `###`，块名加粗、时长用反引号。
- 逐日动作用 `- [ ]`（能点）；题单用表格 + `[ ]` 列（能看）。
- 表格只用在「一周总览」「题单」「降级」三处，逐日细节用列表。

### 六、质量红线

- 「为什么」禁止「很重要」「面试常考」，必须写出**具体被卡住的时刻**。
- 块名必须带技术标签，没有标签的块说明我还不知道自己在学什么。
- 每天第一个知识块没有「知识点地图」（少于 15 点或没分组）算不合格；地图不得删掉原动作里的知识点。
- 「达标」禁止「掌握」「熟悉」，必须是能演示的动作。
- 题解不写进周计划（归 Issues），只写题号与考点。
- **主线时长不许被蓝桥挤掉**：蓝桥块只能是外加的半小时和周末加时；一天里如果主线只写了 1.5h，这份周计划算不合格。
- **套卷必须整段 4 小时**：W16 之后的周计划里，周六要出现「4 小时全真套卷」；把它拆成两段写的，算不合格。
- **蓝桥块必须有「模板默写」这一项**：每天 5–10 分钟默写一个模板（快读/二分/并查集/树状数组…），并在自检里能说出本周默写了哪几个。
- 新知识只放前 5 天，周六周日用来串和补。
- 不设独立「碎片」「机动」块；要背、要默写的东西必须在知识块里，不能挂空。
- 周日必留 30 分钟复盘 + 排下周一第一件事。

### 七、交稿前自检

- [ ] 7 天齐全，日期与星期对得上
- [ ] 每天 2–3 块，总时长 = 预算 ±10%
- [ ] 每块都有「为什么（三层）/ 达标」两段，且块名带技术标签
- [ ] 每天 ① 块有 15–30 点、分 2–5 组的知识点地图，原动作一条未删
- [ ] 每个动作都是 `- [ ]`，且 10–30 分钟能完成
- [ ] 题单带考点，题数 = 阶段笔记本周题量
- [ ] 三档降级方案写的是「砍哪块」
- [ ] 没有独立的「碎片」块：背命令、默写都在知识块的最后 5–10 分钟
- [ ] 周日有复盘位
- [ ] 蓝桥块每天都有，且总时长 = 当阶段蓝桥预算（±20%）
- [ ] 题单里蓝桥行与 [[蓝桥杯A组-国奖线]] 当周一致，题号可点、链接真实
- [ ] 主线总时长 = 22 小时 ±10%（蓝桥另算，不许抵扣）
