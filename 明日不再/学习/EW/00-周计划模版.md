## 一 · 这一周为什么这么排

1. **{{环境与 Git}}**　实习第一天就是配环境、clone 仓库、建分支；这套不熟，第一天就要开口问人，问完还未必敢动手。

3. **{{容器与复杂度}}**　一万行日志查重，list 套 list 要跑三分钟，dict 两秒；面试第一问也是它。
4. **{{蓝桥杯 A 组（外加）}}**　2027-04-10 省赛 4 小时 8 题，8 题里 4–5 题靠模板就能拿；模板没默写下来，考场上现推就是丢 30 分。这 4 小时不占主线，加在上面三条之外。

## 三 · 逐日清单

### Day 1 · 11/02 周一 ｜ 环境与第一个仓库

**① Python 工程 · 装环境与第一个仓库**　`50 分钟`

- [ ] `brew install uv`，装完 `uv --version` 看到版本号
- [ ] `uv python install 3.12`，`uv python list` 确认装上了
- [ ] `uv init py-practice`，`uv run main.py` 打出 hello
- [ ] VS Code 打开目录，选 `.venv` 里的解释器，打断点单步跑一次
- [ ] GitHub 建空仓库，`git init` → `git add .` → `git commit -m "init"` → `git push -u origin main`

> **为什么**　工程里「能跑起来」排在「写得漂亮」前面：clone → 装依赖 → 跑测试 → 提 PR，是每天重复五遍的动作；这步不熟，第一天每个任务都要先卡半小时。再往下一层，虚拟环境解决的是依赖冲突：全局只能装一个版本，两个项目要不同版本就得打架，隔离之后互不干扰——这就是 `.venv` 存在的全部理由。
> **达标**　从空目录到 `git push` 成功，20 分钟内完成，不看教程。

**② Linux 终端 · 文件操作与权限**　`45 分钟`

- [ ] `ls -la`、`cd`、`pwd`，说出 `-l`、`-a` 各管什么
- [ ] `mkdir -p demo/a/b`，再 `cp`、`mv`、`rm -r` 各走一遍
- [ ] `cat` / `head -3` / `tail -3` 看同一个文件
- [ ] `ls | wc -l` 数文件数，`ls > list.txt` 写进文件
- [ ] 读懂 `ls -l` 的 9 位权限，`chmod 755` / `644` 各改一次
- [ ] 合上笔记，默写今天用过的 10 条命令，每条一句「干什么」

> **为什么**　线上排查第一步永远是「进目录、看日志、翻配置」；不会这些，服务器上连日志都找不到。再深一层，`rm -rf` 没有回收站、`>` 会直接清空文件、`chmod 777` 等于把门敞开，`ls -l` 开头那 9 位就是权限表——这些不是知识，是事故的入口，所以要在安全目录里先练出肌肉记忆。
> **达标**　不看笔记，完成「建三层目录 → 复制 → 改名 → 删除」，并默写出 10 条命令。

**③ 算法 · 哈希入门**　`35 分钟`

- [ ] [1. Two Sum](https://leetcode.cn/problems/two-sum/) —— 先写双重循环，再换哈希
- [ ] [217. Contains Duplicate](https://leetcode.cn/problems/contains-duplicate/) —— set 一行解决

> **为什么**　暴力解 $O(n^2)$：一万条就是五千万次比较，接口从 200ms 变 20 秒。哈希把「查一个东西在不在」从逐个翻变成按地址直接取，缓存、去重、计数、路由表全建在它上面。不学它，就会写出「本地一百条飞快、上线十万条超时」的代码。
> **达标**　两道都不看题解写出，说清时间与空间复杂度。

**④ 复盘与笔记**　`30 分钟`

- [ ] 三行日志：学了什么、卡在哪、明天第一件事
- [ ] 把踩的坑补进笔记，能复述再算过

**⑤ 算法竞赛 · 蓝桥模板与第一道真题**　`20 分钟`

- [ ] 手敲一遍 C++ 提交模板：`bits/stdc++.h` + `using namespace std;` + `int main()`，计时，目标 ≤2 分钟
- [ ] 写一次「快读 + `long long` + 数组开 1e5+10」的骨架，跑通一组数据
- [ ] 用 [P16224 均衡数](https://www.luogu.com.cn/problem/P16224)（2026 省 A · 进制）练一遍「读题 3 分钟 → 想暴力 → 再想正解」
- [ ] 把模板存成 snippet，后面 36 周每天抓 20 分钟默写

> **为什么**　蓝桥省赛 8 题 4 小时，人均只能做完 4–5 题，**模板不熟就从「想思路」的时间里再扣 20 分钟**。这道是结果填空题（按近年结构 5 分），正解是进制 + 数位，暴力也能过——正好用来练「先拿分再优化」的考场习惯，而不是练算法。
> **达标**　模板 2 分钟内手敲完；说出这题暴力能拿几分、正解多花多少时间。

**今日交付**　GitHub 上多一个 `py-practice` 仓库（≥2 次提交）+ 一张 10 行命令清单。
**卡住怎么办**　装环境超过 40 分钟就换系统自带 Python，先把仓库跑通；环境问题记进「遗留」，周日集中处理。
