# 02 物理层

> 物理层只干一件事：**把 0 和 1 变成能在线上跑的波形，送到对面再还原成 0 和 1**。
> 这一篇有一半是计算题（奈氏、香农、波特率），零基础就按「为什么有上限 → 公式怎么来 → 代数字」这个顺序看。

## 2.0 先讲清楚：物理层在解决什么问题

上层的链路层交下来一串比特（比如 `10110010`），物理层要把它变成电压高低、光的强弱、电磁波的变化，送进网线。对面收到波形，再判断「这是 1 还是 0」。

所以物理层要回答四个问题：

1. 用**什么形状**表示 1 和 0（编码/调制）
2. 用什么**介质**传输（双绞线/光纤/无线）
3. 最多能传**多快**（奈氏、香农两条极限）
4. 用什么**设备**延长距离（中继器、集线器）

## 2.1 基本术语

| 术语 | 是什么 | 举例 |
| --- | --- | --- |
| 数据 | 传送的信息本身 | 一段文字、一张图 |
| 信号 | 数据的物理表现 | 电压随时间变化的那条曲线 |
| 码元 | 用一个固定时长的波形表示的信息单位 | 一个 200 ms 的波形 |
| 波特率（码元率） | 每秒传多少个码元 | 1000 Baud = 每秒 1000 个波形 |
| 比特率（数据率） | 每秒传多少 bit | 2000 bit/s |

**关键：一个码元可以带多个 bit。** 比如用 4 种不同的波形（4 种电压等级）表示 `00/01/10/11`，那一个码元就带 2 bit。

```
比特率 = 波特率 × log₂V        （V = 码元的离散状态数）
```

**例题**：波特率 1200 Baud，用 4 相调制（V=4），比特率是多少？
`1200 × log₂4 = 1200 × 2 = 2400 bit/s`

反过来：要传 9600 bit/s，V=16（16 种状态），需要多少波特？
`log₂16 = 4`，所以 `9600 / 4 = 2400 Baud`。

> 理解方式：比特率是「真正送出去的信息量」，波特率是「线上每秒变化几次」。一个波形能装几个 bit，取决于它能区分多少种状态。

## 2.2 两条极限公式：为什么再好的线也有上限

### 2.2.1 奈奎斯特：没有噪声时的上限

理想低通信道，带宽 W Hz。信号最多每秒变化 2W 次（采样定理的结论，记住即可），每次最多带 log₂V 个 bit：

```
C = 2W · log₂V     (bit/s)
```

**例题**：带宽 4 kHz，16 种码元状态。
`C = 2 × 4000 × log₂16 = 8000 × 4 = 32000 bit/s = 32 kbit/s`

注意：这条公式里没有信噪比，因为假设「没有噪声」。

### 2.2.2 香农：有噪声时的上限

真实信道有噪声，噪声会让波形失真，状态越多越容易认错。香农给出上限：

```
C = W · log₂(1 + S/N)      (bit/s)
```

- `W` 带宽（Hz）
- `S/N` 信噪比，是**功率比**，不是 dB

**dB 换算**（考试必考）：

```
S/N(dB) = 10 · log₁₀(S/N)
```

| 给出的 dB | 折算 S/N |
| --- | --- |
| 10 dB | 10 |
| 20 dB | 100 |
| 30 dB | 1000 |
| 40 dB | 10000 |

**例题**：带宽 3 kHz，信噪比 30 dB。
1. 先换算：`10·log₁₀(S/N) = 30` → `S/N = 1000`
2. 代入：`C = 3000 × log₂(1001) ≈ 3000 × 9.97 ≈ 29.9 kbit/s`

### 2.2.3 两条公式怎么一起用

- 题目说「无噪声」→ 用奈氏，看带宽和码元状态数。
- 题目给信噪比 → 用香农。
- 两个条件都给 → **分别算出两个值，取较小者**才是实际上限。

| 公式 | 需要的参数 | 回答的问题 |
| --- | --- | --- |
| 奈氏 | W、V | 理想情况下最多能传多快 |
| 香农 | W、S/N | 有噪声时最多能传多快 |

## 2.3 编码：数字数据 → 数字信号

编码就是「用什么波形表示 0 和 1」。四种必须会画：

| 编码 | 规则 | 效率 | 特点 |
| --- | --- | --- | --- |
| 不归零 NRZ | 高电平=1，低电平=0 | 100% | 简单，但连续多个 1 或 0 时接收方没法对齐时钟 |
| 归零 NRZI（差分） | 电平变化表示 1，不变化表示 0 | 100% | 抗干扰比 NRZ 好 |
| 曼彻斯特 | 每个码元**中间必跳变**：高→低为 1，低→高为 0 | 50% | 自带时钟同步，10BASE-T 以太网用 |
| 差分曼彻斯特 | 码元**开头跳变**表示 0，不跳变表示 1；中间仍必跳变做同步 | 50% | 抗干扰最好，令牌环网用 |

![[图/编码波形.png]]

> 同是 `1 0 1 1 0`：NRZ 直接高低电平；曼彻斯特每个码元中间必跳一次（跳变方向定 0/1）；差分曼彻斯特看码元**开头**跳不跳来定 0/1，中间那一跳只负责同步。

**为什么曼彻斯特效率只有 50%**：一个 bit 要用两个码元表示（中间那次跳变是必需的开销），所以码元速率是比特率的两倍。传 1 Mbit/s 需要 2 Mbaud。

**为什么「自带同步」很重要**：接收方要知道每个 bit 从哪开始到哪结束。NRZ 遇到 `11111111` 就一直是一条高电平，接收方分不清是 8 个 1 还是 5 个 1；曼彻斯特每隔半个码元必跳一次，时钟就能对齐。

## 2.4 调制：数字数据 → 模拟信号

调制是把 0/1 装到载波上，改变载波的某个参数：

| 方式 | 改什么 | 特点 |
| --- | --- | --- |
| ASK（幅移键控） | 振幅 | 最简单，抗噪差 |
| FSK（频移键控） | 频率 | 抗噪较好，实现简单 |
| PSK（相移键控） | 相位 | 常用，抗噪好 |
| QAM（正交幅度调制） | 振幅 + 相位 | 一个码元带多个 bit |

**QAM 为什么能带多位**：16-QAM 有 16 种「振幅+相位」组合，每种组合表示 4 bit（`log₂16 = 4`）。所以 2400 Baud 的 16-QAM 能传 9600 bit/s。

## 2.5 传输介质

| 介质 | 优点 | 缺点 | 用在哪 |
| --- | --- | --- | --- |
| 双绞线（UTP/STP） | 便宜、好布线 | 抗干扰一般、距离短 | 以太网、电话线 |
| 同轴电缆 | 抗干扰好、带宽较高 | 粗、贵 | 有线电视、早期以太网 |
| 单模光纤 | 带宽极大、传输距离远、抗电磁干扰 | 贵、需激光光源 | 骨干网、跨城 |
| 多模光纤 | 便宜、易接 | 距离短、有模式色散 | 机房内部、楼内 |
| 无线（无线电/微波/红外） | 不用布线 | 易受干扰、需频谱 | WLAN、移动网络 |

记法：**单模细芯 + 激光 = 远；多模粗芯 + LED = 近。**

## 2.6 物理层设备

| 设备 | 干什么 | 层次 | 关键特点 |
| --- | --- | --- | --- |
| 中继器 | 把衰减的信号放大整形再发出去 | 物理层 | 只延长距离，不看内容 |
| 集线器 Hub | 多端口中继器 | 物理层 | 收到什么就向所有端口广播；半双工；所有端口共享带宽 |

**为什么集线器会被淘汰**：

- 所有端口在**同一个冲突域**：两台同时发就撞（CSMA/CD 只能「撞了再退避」）；
- **共享带宽**：10 Mbit/s 的 Hub 接 10 台机器，平均每台 1 Mbit/s；
- 只在物理层做信号复制，不懂 MAC 地址，无法定向转发。

换成交换机后：每个端口一个冲突域、独享带宽、按 MAC 地址转发。

## 2.7 常见易错点

1. 带宽在物理层是 **Hz**，在网络性能里是 **bit/s**，看题干。
2. 香农公式里的 S/N 是**功率比**，给 dB 必须换算；`20 dB = 100`，不是 20。
3. 曼彻斯特和差分曼彻斯特效率都是 **50%**，传 1 Mbit/s 需要 2 Mbaud。
4. 奈氏公式里的 V 是码元**状态数**，不是「二进制位数」。
5. 集线器不隔离冲突域，也不隔离广播域；交换机隔离冲突域但不隔离广播域。
6. QAM 一个码元带的 bit 数 = `log₂(状态数)`，不是固定 4 bit。

## 2.8 自测

<details>
<summary>Q1：带宽 4 kHz、无噪声、16 种码元，最高数据率？</summary>

`C = 2W·log₂V = 2×4000×4 = 32 kbit/s`
</details>

<details>
<summary>Q2：信噪比 20 dB、带宽 1 MHz，香农极限？</summary>

20 dB → S/N = 100；`C = 10⁶ × log₂(101) ≈ 6.66 Mbit/s`
</details>

<details>
<summary>Q3：为什么曼彻斯特编码只发挥一半带宽？</summary>

一个 bit 需要两个码元（中间必须跳变用于同步），码元速率是比特率的两倍，所以效率 50%。
</details>

<details>
<summary>Q4：集线器和交换机最本质的区别？</summary>

集线器在物理层复制信号，所有端口同一冲突域、共享带宽；交换机在链路层按 MAC 地址转发，每端口独立冲突域、独享带宽。
</details>

<details>
<summary>Q5：2400 Baud 的 16-QAM，比特率多少？</summary>

`log₂16 = 4`，所以 `2400 × 4 = 9600 bit/s`。
</details>

<details>
<summary>Q6：1000 km 光纤、带宽 10 Gbit/s，时延带宽积多少？（信号速度 2×10⁸ m/s）</summary>

传播时延 = `10⁶ m ÷ 2×10⁸ m/s = 5 ms`；时延带宽积 = `5×10⁻³ × 10×10⁹ = 5×10⁷ bit = 50 Mbit`。
意思是在这条链路上「正在飞」的数据最多有 50 Mbit。
</details>
