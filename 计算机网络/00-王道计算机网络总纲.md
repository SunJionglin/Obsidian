## 二、知识树

```
计算机网络
├── 1 概述        体系结构与性能指标
│   ├─ 交换方式（电路/报文/分组）
│   └─ 分层模型（OSI / TCP-IP）
├── 2 物理层      比特怎么变成信号
│   ├─ 编码与调制
│   └─ 奈氏 / 香农上限
├── 3 数据链路层  相邻节点怎么可靠传帧
│   ├─ 组帧 / 差错控制（CRC、海明）
│   ├─ 流量控制（停等 / GBN / SR）
│   └─ 介质访问控制（CSMA/CD、CSMA/CA）
├── 4 网络层      跨网络怎么寻址与选路
│   ├─ IP 地址 / 子网 / CIDR / NAT
│   ├─ 配套协议（ARP、DHCP、ICMP）
│   └─ 路由协议（RIP、OSPF、BGP）
├── 5 传输层      进程之间怎么可靠通信
│   ├─ UDP / TCP 报文
│   ├─ 连接管理（三次握手、四次挥手）
│   └─ 可靠传输 / 流量控制 / 拥塞控制
└── 6 应用层      应用自己的规矩
    ├─ DNS / FTP / 邮件
    └─ WWW / HTTP
```

## 四、怎么学（零基础版）

1. **先建画面**：读 01 的 §1.0 和 §1.6，知道「分层」是为了什么，再往下。
2. **一层一层过**：每篇顺序是「先讲问题 → 概念 → 公式/规则 → 例题 → 易错 → 自测」。自测答不出就回读对应小节。
3. **计算题单独练**：时延（01）、奈氏香农（02）、CRC 与海明（03）、子网划分与聚合（05）、拥塞窗口（08）——这五处是 408 计算题的集中地，每个都备了完整算例。
4. **图当路线图**：每篇开头那张图先看一遍，读完再回来看，能对上每一块在讲什么。
5. **配套实操**：Linux 里 `ip addr`、`ping`、`ss -tulnp`、`curl -I`、`dig` 都能在机器上验证这些协议，边敲边对。
